# enoobis.ru — agent rules

## язык
- всегда отвечать на русском.

## дизайн
- радикальный минимализм. убирать всё, что не поддерживает основной сценарий.
- пользователь должен понять интерфейс за 3 секунды.
- одна цель на экран. одна основная кнопка.
- второстепенные функции скрывать или убирать вглубь.
- спокойный визуальный стиль, без декора, без теней, без градиентов.
- минимум текста, максимум ясности.
- "less is more" во всём.

## текст
- весь ui-текст строчными буквами. никаких "Заголовок" — только "заголовок".
- никаких "Б", "О", "Н" в начале меток. подсказки, кнопки, заголовки — всё с маленькой.

## код
- очень чистый код. без декоративных комментариев.
- typescript строго, без any.
- vue 3 composition api + `<script setup lang="ts">`.
- общие токены оформления — через css-переменные из `frontend/src/assets/main.css`.

## процесс
перед коммитом проверять:
1. можно ли убрать ещё один элемент?
2. понятно ли что делать за 3 секунды?
3. есть ли визуальный шум?
4. это самый короткий путь к цели?
