перечисления представляют типы данных, содержащие набор именованных констант, каждой из которых сопоставлено целочисленное значение. перечисление определяется с помощью ключевого слова **enum**:

```c
enum название_перечисление { константа1, константа2, ... константаN };
```

после слова **enum** указывается имя перечисления (тег), затем в фигурных скобках перечисляются константы перечисления.

определим и используем простейшее перечисление:

```c
#include <stdio.h>

enum operation // арифметическая операция
{
    ADD,        // сложение
    SUBTRACT,   // вычитание
    MULTIPLY    // умножение
};
int main(void)
{
	enum operation op;  // определяем переменную перечисления
    op = ADD;           // присваиваем ей одну из констант перечисления
    printf("Operation: %d\n", op);
	return 0;
}
```

здесь определено перечисление с именем `operation`, которое условно представляет арифметическую операцию. оно определяет три константы: ADD, SUBTRACT и MULTIPLY.

в функции main определяется переменная перечисления:

```c
enum operation op
```

этой переменной можно присвоить одну из констант перечисления. здесь ей присваивается константа `ADD`:

```c
op = ADD;
```

далее эту константу можно использовать. в примере её значение просто выводится на консоль как число. каждой константе фактически соответствует целочисленное значение: первой константе число 0, второй число 1, третьей 2 и так далее. в c константы перечисления имеют тип int, а сам перечислимый тип совместим с некоторым целочисленным типом, выбор которого оставлен реализации, поэтому значение передаётся в printf по спецификатору `%d`. консольный вывод будет следующим:

```bash
Operation: 0
```

значение константы можно также присвоить числовой переменной:

```c
enum operation op = MULTIPLY;
int opCode = op;
printf("Operation Code: %d\n", opCode);		// Operation Code: 2
```

в c преобразование между перечислением и int выполняется неявно в обе стороны, тогда как в c++ неявное преобразование int в перечисление запрещено, а для enum class запрещено и обратное. поэтому в c перечисление не обеспечивает строгой типобезопасности: переменной перечислимого типа можно присвоить и число, не соответствующее ни одной константе.

если значения по умолчанию не подходят, константам можно явно присвоить числовые значения. можно указать значение только для первой константы, тогда каждая последующая получит значение на единицу больше предыдущей:

```c
enum operation
{
    ADD = 5,     
    SUBTRACT,   // 6
    MULTIPLY    // 7
};
```

можно присвоить всем константам уникальные значения:

```c
enum operation
{
    ADD = 1, 
    SUBTRACT = 2,
    MULTIPLY = 4
};
```

#### установка псевдонимов

запись перечислимого типа можно сократить с помощью псевдонимов:

```c
#include <stdio.h>

typedef enum
{
    ADD,        // сложение
    SUBTRACT,   // вычитание
    MULTIPLY    // умножение
} operation;

int main (void)
{
    operation op = SUBTRACT;
    printf("operation: %d\n", op);      // operation: 1
    return 0;
}
```

здесь `operation` является псевдонимом типа перечисления `enum { ADD, SUBTRACT, MULTIPLY }`. соответственно вместо `enum operation` достаточно написать `operation`.

#### определение переменной без имени типа

если перечисление используется только в одном месте, можно сразу определить его переменную, не объявляя имени типа:

```c
#include <stdio.h>

struct BinaryOp{
    int n1;
    int n2;
    enum {  ADD,  SUBTRACT,  MULTIPLY } op;
};

int main (void)
{
    struct BinaryOp mulOp = {.n1 = 6, .n2 = 8, .op = MULTIPLY};
    printf("Operands: %d and %d. Operation: %d\n", mulOp.n1, mulOp.n2, mulOp.op);      
    // Operands: 6 and 8. Operation: 2
    return 0;
}
```

здесь структура BinaryOp представляет некоторую бинарную операцию над двумя операндами. поле op в структуре BinaryOp имеет тип безымянного перечисления `enum { ADD, SUBTRACT, MULTIPLY }`, которое нигде вне данной структуры не используется. при этом константы перечисления, в отличие от тегов и полей структуры, принадлежат обычному пространству имён объемлющей области видимости, поэтому ADD, SUBTRACT и MULTIPLY доступны и за пределами структуры, что и позволяет использовать MULTIPLY в инициализаторе в функции main.

### применение перечислений

константы перечисления нередко выступают набором состояний, и в зависимости от состояния программа выполняет ту или иную логику. например:

```c
#include <stdio.h>

enum operation // арифметическая операция
{
    ADD = 1,        // сложение
    SUBTRACT = 2,   // вычитание
    MULTIPLY = 4    // умножение
};
int calculate(int x, int y, enum operation op)
{
    switch(op)
    {
        case ADD:
            return x + y;
        case SUBTRACT:
            return x - y;
        case MULTIPLY:
            return x * y;
        default: 
            return 0;
    }
}
int main(void)
{
	enum operation op = MULTIPLY;
    int result = calculate(4, 3, op);
    printf("Result: %d\n", result);     // Result: 12

    result = calculate(4, 3, ADD);
    printf("Result: %d\n", result);     // Result: 7

    result = calculate(4, 3, SUBTRACT);
    printf("Result: %d\n", result);     // Result: 1
	return 0;
}
```

здесь определена функция `calculate()`, выполняющая арифметическую операцию. первые два параметра функции задают два числа, над которыми выполняется операция, а третий параметр, значение перечисления operation, определяет тип операции. в самой функции в зависимости от третьего параметра выполняется соответствующая операция и возвращается её результат.

в функции main функция calculate трижды вызывается с одними и теми же числами, но с разными типами операций.

разумеется, можно было бы обойтись без перечислений, используя обычные числа. однако, во-первых, перечисления дают своим константам описательные имена, которые часто говорят сами за себя, например ADD (сложение). во-вторых, перечисление задаёт ограниченный набор констант, которым проще управлять, чем разрозненными числами. кроме того, компиляторы gcc и clang при флаге `-Wswitch` (входит в `-Wall`) предупреждают, если в switch по значению перечисления без ветки default обработаны не все его константы.
