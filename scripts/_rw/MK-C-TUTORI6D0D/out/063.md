работа с бинарными файлами ведётся посредством посимвольного чтения и записи. поскольку объект типа `char` по определению занимает ровно один байт, фактически речь идёт о побайтовой записи и побайтовом чтении.

### запись файла

для записи символа в файл применяется функция **putc()** со следующим прототипом:

```c
int putc(int c, FILE *stream);
```

в функцию передаются символ, который требуется записать, и указатель на файловый поток. результатом функции является записанный символ, а при ошибке возвращается EOF. putc допускается реализовывать как макрос, поэтому аргумент stream может вычисляться более одного раза, тогда как функция fputc гарантированно является функцией.

```c
#include <stdio.h>
 
int main(void)
{
	// записываемая строка
    char message[] = "Hello enoobis.ru!";
	// файл для записи
    char * filename = "data.txt";
	// находим длину записываемой строки
    int n = sizeof(message)/sizeof(message[0]);

    FILE * fp= fopen(filename, "w");
    if(fp)
    {
        // посимвольно записываем в файл
        for(int i=0; i < n; i++)
        {
            putc(message[i], fp);
        }
        
        fclose(fp);
        printf("File has been written\n");
    }
}
```

программа обходит массив символов message и каждый символ записывает в файл data.txt (расположенный в текущей папке), передавая его функции `putc()`. длина n, вычисленная через sizeof, включает завершающий нулевой символ, поэтому в файл попадает и он.

### чтение файла

для чтения одного символа служит функция **getc()** (функция **fgetc()** аналогична ей). её прототип:

```c
int getc(FILE *stream);
```

функция принимает указатель на файловый поток и возвращает считанный из файла символ, точнее его числовой код.

при каждом чтении или записи одного символа указатель текущей позиции в потоке увеличивается, что и обеспечивает последовательное продвижение по файлу.

ниже считывается ранее записанный файл `data.txt`:

```c
#include <stdio.h>
 
int main(void)
{
	// символ для считывания
    char c;
	// файл для чтения
    char * filename = "data.txt";

    FILE * fp= fopen(filename, "r");
    if(fp)
    {
        // считываем посимвольно из файла
        while((c=getc(fp))!= EOF)
        {
            printf("%c", c);
        }
        fclose(fp);
    }
}
```

символы считываются по одному вызовом `getc()`. особого внимания заслуживает условие завершения цикла: по достижении конца файла функция getc() возвращает значение **EOF** ("end of file", конец файла), определённое в stdio.h, поэтому файл читается до получения EOF. именно для того, чтобы EOF отличался от любого допустимого байта, getc возвращает int, а не char. при сохранении результата в переменную типа char, как в примере, байт 0xFF на платформах со знаковым char становится неотличим от EOF, а на платформах с беззнаковым char условие никогда не выполнится, поэтому в надёжном коде для результата используют переменную типа int.

в результате на консоль выводится ранее записанное сообщение.
