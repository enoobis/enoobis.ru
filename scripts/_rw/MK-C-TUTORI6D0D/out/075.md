стандартная библиотека c предоставляет ряд математических функций. они объявлены в разных заголовочных файлах, но большая часть сосредоточена в файле **math.h**. в unix-подобных системах при компоновке программ, использующих math.h, для gcc часто требуется явно подключить библиотеку libm флагом `-lm`.

### степень числа. pow

функция **pow()**, объявленная в заголовочном файле `math.h`, возвращает результат возведения числа в степень:

```c
#include <stdio.h>
#include <math.h>

int main(void)
{
	printf("pow(2, 3) = %.f\n", pow(2, 3));	// 2 в степени 3
	printf("pow(5, 2) = %.f\n", pow(5, 2));	// 5 в степени 2
	return 0;
}
```

функция принимает и возвращает значения типа `double`; целочисленные аргументы неявно преобразуются к double. вычисление выполняется в арифметике с плавающей точкой, поэтому для больших целых результат может быть неточным, и для целочисленного возведения в степень pow не всегда подходит.

для чисел типа `float` и `long double` определены функции `powf()` и `powl()` соответственно. отдельные имена нужны потому, что в c нет перегрузки функций; обобщённые макросы из tgmath.h выбирают нужный вариант по типу аргумента.

### округление числа. round

функция **round()** округляет число до ближайшего целого. параметр имеет тип `double`, результат тоже возвращается как double:

```c
#include <stdio.h>
#include <math.h>

int main(void)
{
	 double n1 = 3.14;
 	printf("round(%.2f) = %.2f\n", n1, round(n1));	// round(3.14) = 3.00
	 double n2 = 3.49;
 	printf("round(%.2f) = %.2f\n", n2, round(n2));	// round(3.49) = 3.00
	 double n3 = 3.5;
 	printf("round(%.2f) = %.2f\n", n3, round(n3));	// round(3.50) = 4.00
	return 0;
}
```

половинные значения round округляет от нуля, независимо от текущего режима округления: round(3.5) равно 4, round(-3.5) равно -4. этим она отличается от функций rint и nearbyint, которые используют текущий режим, по умолчанию округление к ближайшему чётному. функция введена в c99.

### квадратный корень. sqrt

функция **sqrt()** возвращает квадратный корень числа типа `double`:

```c
#include <stdio.h>
#include <math.h>

int main(void)
{
	double n1 = 224;
 	printf("sqrt(%.f) = %.f\n", n1, sqrt(n1));	// sqrt(224) = 15
	double n2 = 36;
 	printf("sqrt(%.f) = %.f\n", n2, sqrt(n2));	// sqrt(36) = 6
	return 0;
}
```

точное значение корня из 224 равно примерно 14.97, а 15 получается из-за округления при выводе по спецификатору `%.f`. для отрицательного аргумента возникает ошибка области определения, и результатом является nan.

для получения квадратного корня числа `float` есть функция **sqrtf()**, а для числа типа `long double` функция **sqrtl()**

### abs

функция **abs**, объявленная в файле "stdlib.h", возвращает абсолютное значение целого числа типа int

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
	int m = -15;
	int n = 24;

 	printf("abs(m) = %d \n", abs(m));	// abs(m) = 15
 	printf("abs(n) = %d \n", abs(n));	// abs(n) = 24
	return 0;
}
```

для чисел типов `long` и `long long` в "stdlib.h" определены функции `labs` и `llabs` соответственно. для чисел с плавающей точкой в файле `math.h` определены функции `fabs`, `fabsf` и `fabsl` (для double, float и long double). все эти функции работают аналогично `abs()`. в дополнительном коде abs(INT_MIN) не представим в типе int, поэтому такой вызов приводит к неопределённому поведению.
