при работе с текстовыми файлами гораздо проще обрабатывать данные не как отдельные символы, а как строки, используя функции **fgets()** и **fputs()**.

### запись текстового файла

функция **fputs()** записывает в файл строку, то есть последовательность символов, завершающуюся символом '\0'. её прототип:

```c
int fputs(const char *s, FILE *stream);
```

первый параметр функции задаёт записываемую строку, второй представляет указатель на файловый поток. при успешном выполнении функция возвращает неотрицательное целое число, при ошибке записи возвращается значение **EOF**.

завершающий нулевой символ '\0' в файл не записывается: он служит лишь признаком конца строки в памяти. в отличие от puts, функция fputs не добавляет и символ перевода строки.

пример записи строки в файл:

```c
#include <stdio.h>
 
int main(void)
{
    // строка для записи
    char * message = "Hello enoobis.ru!\nAn apple a day keeps the doctor away";
    // файл для записи
    char * filename = "data.txt";
    // запись в файл
    FILE *fp = fopen(filename, "w");
    if(fp)
    {
        // записываем строку
        fputs(message, fp);
        fclose(fp);
        printf("File has been written\n");
    }
}
```

запись устроена просто: файл открывается для записи, и вызов `fputs(message, fp)` заносит в него требуемую строку.

### чтение текстового файла

функция **fgets()** считывает из файла одну строку и имеет следующий прототип:

```c
char * fgets(char *s, int n, FILE *sream);
```

первый параметр `char *s` задаёт строку, в которую выполняется считывание. второй параметр, число `n`, указывает, сколько символов необходимо считать. третий параметр представляет файловый поток, из которого ведётся чтение.

за один вызов функция считывает из файла не более n-1 символов. чтение прекращается, когда прочитано n-1 символов или встретился символ перевода строки \n. все считанные символы, в том числе \n, записываются в строку s, а в конец строки дописывается нулевой символ '\0'. ограничение n-1 оставляет место под завершающий нуль и гарантирует, что запись не выйдет за пределы буфера, чем fgets принципиально отличается от удалённой из стандарта c11 функции gets.

при успешном завершении функция возвращает указатель `s`, а при ошибке или достижении конца файла возвращается значение **NULL**.

чтение данных из записанного выше файла "data.txt":

```c
#include <stdio.h>
 
int main(void)
{
    // файл чтения
    char * filename = "data.txt";
    // буфер для считавания данных из файла
    char buffer[256];
    // чтение из файла
    FILE *fp = fopen(filename, "r");
    if(fp)
    {
        // пока не дойдем до конца, считываем по 256 байт
        while((fgets(buffer, 256, fp))!=NULL)
        {
            printf("%s", buffer);
        }
        fclose(fp);
    } 
}
```

файл открывается для чтения, и в цикле вызовом `fgets(cc, 256, fp)` из него считывается до 256 символов, которые затем выводятся на консоль. когда данные в файле заканчиваются, функция возвращает NULL, и цикл завершается.

### копирование файлов

ещё один пример работы с текстовыми файлами: копирование содержимого одного файла в другой.

```c
#include <stdio.h>

int main(void)
{
	char * filename1 = "data1.txt";
	char * filename2 = "data2.txt";
	char buffer[256];
	FILE *f1 = fopen(filename1, "r");   // файл на чтение
    FILE *f2 = fopen(filename2, "w");   // файл на запись
	if(!f1 || !f2)
	{
		printf("Error occured while opening file\n");
	}
	else
	{
		// пока не дойдем до конца, считываем по 256 байт из файла f1
        while((fgets(buffer, 256, f1))!=NULL)
        {
            // записываем строку в файл f2
            fputs(buffer, f2);
            printf("%s", buffer);
        }
	}
	
	fclose(f1);
	fclose(f2);
	
	return 0;
}
```
