перебор коллекций данных в стиле `for-each` является распространённым способом обхода наборов данных в различных языках программирования. в языке c по умолчанию отсутствует подобная конструкция, но с помощью макросов сооружается некоторый аналог. макрос здесь снова выступает синтаксическим сахаром: он разворачивается в обычный `for`, не вводя в язык новых форм управления.

в зависимости от типа перебираемых данных, задач и прочих условий реализации `for-each` различаются. ниже несколько примеров. простейший:

```c


#include <stdio.h>

#include <stdlib.h>



#define foreach( iter__, head__ ) \

  for ( iter__ = (head__); iter__ != 0; iter__ = iter__->next )



typedef struct node{

    struct node* next;

    int value;

} node;



int main( void )

{

    // узлы списка

    node n1 = {.value = 2};

    node n2 = {.value = 3};

    node n3 = {.value = 4};

    node n4 = {.value = 5};

    // устанавливаем отношения между узлами, формируя однонаправленный список

    n1.next = &n2; 

    n2.next = &n3;

    n3.next = &n4;

    n4.next = 0;



    node* v; // переменная, в которую извлекаем каждый узел списка

    // применение for-each - каждый элемент 

    foreach(v, &n1) printf("%d\n", v->value);

}
```

эта программа создаёт и инициализирует простой односвязный список, а затем использует специальный макрос `foreach` для обхода списка и вывода значения каждого узла.

вначале идёт определение макроса `foreach`:

```c


#define foreach( iter__, head__ ) \

  for ( iter__ = (head__); iter__ != 0; iter__ = iter__->next )
```

макрос принимает две переменных:

- `iter__` : переменная, которая будет указывать на текущий узел в каждой итерации.

- `head__` : указатель на первый узел списка.

двойное подчёркивание в именах параметров снижает риск затенения имён в точке вызова. макрос требует, чтобы у типа узла было поле `next`; это структурный контракт, который препроцессор проверить не может.

после заголовка макроса идёт определение цикла for, с помощью которого и происходит собственно перебор данных:

- `v = (&n1)` : в начале цикла `v` (итератор) инициализируется адресом первого узла списка (`n1`).

- `v != 0` : условие продолжения цикла. цикл продолжается до тех пор, пока `v` не станет нулевым указателем (NULL), что означает конец списка.

- `v = v->next` : в каждой итерации `v` переходит к следующему узлу в списке, используя поле `next` текущего узла.

в качестве примера для перебора данных определена структура `node`:

```c


typedef struct node{

    struct node* next;

    int value;

} node;
```

здесь поле `struct node* next` хранит указатель на следующий узел в списке, а поле `int value` представляет целочисленное значение: собственно те данные, которые хранятся в данном узле. самоссылочный тип обязателен для односвязного списка; `typedef` даёт короткое имя `node` как для объекта, так и для указателя на следующий узел через `struct node*`.

в функции `main` создаются узлы списка и устанавливаются связи между ними:

```c


node n1 = {.value = 2};

node n2 = {.value = 3};

node n3 = {.value = 4};

node n4 = {.value = 5};



n1.next = &n2;

n2.next = &n3;

n3.next = &n4;

n4.next = 0; // или NULL
```

узлы имеют автоматическое время жизни, список не владеет памятью кучи. поле `next` у последнего узла обнуляется явно: designated initializer задал только `value`, указатель иначе содержал бы неопределённое значение.

в конце идёт собственно итерация по списку с помощью `foreach`:

```c


node* v; // переменная, в которую извлекаем каждый узел списка

foreach(v, &n1) printf("%d\n", v->value);
```

здесь объявляется указатель `v` типа `node*`. затем используется макрос `foreach`. он начинает обход с узла `n1`. в каждой итерации `v` указывает на текущий узел. процесс продолжается до тех пор, пока `v` не станет `NULL` (после `n4`), что завершает цикл. итератор обязан быть объявлен снаружи: макрос присваивает ему значение, но не вводит новую область видимости.

вывод программы

```bash


2

3

4

5
```

предыдущий пример перебора списка привязан к конкретной реализации. в прошлой статье (enoobis.ru) был показан пример универсального обобщённого списка, который не зависит от конкретного типа данных. ниже макрос перебора в стиле for-each для подобного списка:

```c


#include <stdio.h>

#include <stdlib.h>



#define DEFINE_LIST(T) \

typedef struct { \

    T* data; \

    size_t count; \

    size_t size; \

} list_##T; \

\

void list_##T##_new(list_##T* v) { \

    v->data = NULL; \

    v->count= v->size = 0; \

} \

\

void list_##T##_push(list_##T* v, T elem) { \

    if (v->count == v->size) { \

        v->size = v->size ? v->size << 1 : 1; \

        v->data = (T*)realloc(v->data, v->size * sizeof(T)); \

    } \

    v->data[v->count++] = elem; \

} \

\

T list_##T##_pop(list_##T* v) { \

    return v->data[--v->count]; \

} \

\

void list_##T##_free(list_##T* v) { \

    free(v->data); \

    list_##T##_new(v); \

}

DEFINE_LIST(int) // определяем список





// Определение макроса перебора в стиле for-each

#define for_each(elem_name, list_ptr) \

    for (size_t i = 0; i < (list_ptr)->count;i++) \

        if((elem_name = (list_ptr)->data[i]), 1)



int main( void )

{

    list_int numbers; // определяем переменную списка

    list_int_new(&numbers);     // инициализируем его поля

    // добавляем несколько элементов

    list_int_push(&numbers, 11);

    list_int_push(&numbers, 12);

    list_int_push(&numbers, 13);



    puts("List items:");

    int item; // Объявляем переменную для элемента

    for_each(item, &numbers) {

        printf("%d\n", item);

    }



    list_int_free(&numbers);  // очищаем память под список

}
```

подробный разбор макросов, которые определяют функционал обобщённого списка, дан в прошлой статье. ниже только макрос `for_each`:

- здесь определяется макрос, который принимает два параметра: перебираемый список в виде параметра list_ptr и параметр elem_name, название переменной, в которую помещается каждый элемент списка. важно: elem_var должна быть объявлена перед использованием макроса.

```c
#define for_each(elem_name, list_ptr)
```

- стандартный цикл for, который итерируется по индексам списка от 0 до count - 1

```c
for (size_t i = 0; i < (list_ptr)->count; i++) \
```

- хитрая часть. вначале происходит присваивание текущего элемента списка переменной elem_var: `(elem_name = (list_ptr)->data[i])`. далее идёт часть `, 1`: оператор запятой вычисляет свои операнды слева направо и возвращает значение правого операнда. после присваивания elem_var выражение всегда возвращает 1 (true). это означает, что тело if (и, следовательно, тело "for-each" цикла) всегда будет выполняться. это позволяет выполнить операцию присваивания и при этом гарантировать выполнение следующего блока кода, который будет телом цикла.

```c
if((elem_name = (list_ptr)->data[i]), 1)
```

приём с `if` и оператором запятой нужен затем, чтобы макрос оставался заголовком, за которым пишут либо один оператор, либо блок в фигурных скобках, как после обычного `for`. индекс `i` вводится в заголовке цикла и после макроса недоступен, если не захвачен телом. элемент копируется по значению в `elem_name`; изменение `item` внутри цикла не меняет элемент в `data`.

консольный вывод программы:

```bash


List items:

11

12

13
```
