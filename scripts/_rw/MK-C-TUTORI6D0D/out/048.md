элементом структуры может быть не только значение примитивного типа вроде int или char, массив или указатель, но и другая структура. такая композиция позволяет строить составные типы данных иерархически, причём вложенная структура хранится непосредственно внутри объемлющей, а не по ссылке, как это происходит с полями объектного типа в java.

рассмотрим следующую программу:

```c
#include <stdio.h>
 
struct company
{
	char* name;
	char* country;
};
struct phone
{
	char* title;
	int price;
	struct company manufacturer;
};

int main(void)
{
	struct phone realmeC31;
	realmeC31.title = "Realme C31";
    realmeC31.price = 7900;
	// устанавливаем значения для вложенной структуры
    realmeC31.manufacturer.name = "Realme";
    realmeC31.manufacturer.country = "China";

	printf("Phone: %s \n", realmeC31.title);
	printf("Price: %d \n", realmeC31.price);
	printf("Manufacturer: %s \n", realmeC31.manufacturer.name);
	return 0;
}
```

определённые здесь структуры моделируют объекты предметной области. структура company описывает компанию, её элементы `name` и `country` хранят название и страну компании соответственно. структура phone описывает смартфон и содержит три элемента: title (название), price (цена) и manufacturer (компания-производитель). последний элемент сам имеет тип struct company. поскольку company должна быть полным типом в точке объявления поля manufacturer, её определение предшествует определению phone. доступ к полям вложенной структуры выполняется цепочкой операций «точка»: сначала выбирается элемент объемлющей структуры, затем элемент вложенной:

```c
realmeC31.manufacturer.name
```

такая форма обращения используется при любых операциях над элементами вложенной структуры company. в качестве примера рассмотрим ввод данных с консоли:

```c
#include <stdio.h>

struct company
{
	char name[20];
	char country[20];
};
struct phone
{
	char title[20];
	int price;
	struct company manufacturer;
};

int main(void)
{
	struct phone myphone;
	printf("Enter title: ");
	scanf("%20[^\n]", myphone.title);
	printf("Enter price: ");
	scanf("%d", &myphone.price);
	printf("Enter manufacturer: ");
	scanf("%20s", myphone.manufacturer.name);
	printf("Enter country: ");
	scanf("%20s", myphone.manufacturer.country);
	
	printf("\nPhone: %s \n", myphone.title);
	printf("Price: %d \n", myphone.price);
	printf("Manufacturer: %s (%s) \n", myphone.manufacturer.name, myphone.manufacturer.country);
	return 0;
}
```

в этом варианте поля объявлены как массивы char фиксированной длины, а не как указатели, поэтому память под строки входит в состав самого объекта и scanf может записывать в неё данные. для ввода, например, имени компании-производителя функции scanf передаётся адрес соответствующего элемента `myphone.manufacturer.name`. так как это массив, в выражении он неявно преобразуется к указателю на свой первый элемент, и операция взятия адреса не требуется, в отличие от поля price типа int, для которого используется `&myphone.price`.

результат работы программы:

```consoletext
Enter title: Realme C30
Enter price: 7900
Enter manufacturer: Realme
Enter country: China

Phone: Realme C30
Price: 7900
Manufacturer: Realme (China)
```

#### инициализация

при инициализации объемлющей структуры можно сразу инициализировать и вложенную:

```c#
#include <stdio.h>
 
struct company
{
	char* name;
	char* country;
};
struct phone
{
	char* title;
	int price;
	struct company manufacturer;
};

int main(void)
{
	struct phone realmeC31= {"Realme C31", 7900, {"Realme", "China"}};

	printf("Phone: %s \n", realmeC31.title);
	printf("Price: %d \n", realmeC31.price);
	printf("Manufacturer: %s \n", realmeC31.manufacturer.name);
	return 0;
}
```

структура phone имеет три элемента, последний из которых сам является составным и содержит два элемента, поэтому в списке инициализации структуры phone задаются четыре значения:

```c
struct phone realmeC31 = {"Realme C31", 7900, {"Realme", "China"}};
```

значения для вложенной структуры заключаются во внутреннюю пару фигурных скобок. схематически это можно записать так:

```c
struct phone realmeC31 = {title, price, {manufacturer.name, manufacturer.country}};
```

значения, как и в случае простых структур, сопоставляются элементам в порядке их объявления, в том числе внутри вложенных структур. стандарт c допускает и опускание внутренних скобок (тогда инициализаторы распределяются по элементам подряд), однако явные скобки делают соответствие значений полям очевидным, а некоторые компиляторы при их отсутствии выдают предупреждение `-Wmissing-braces`.
