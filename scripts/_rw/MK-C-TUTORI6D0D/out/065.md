встроенные функции **fwrite()** и **fread()** упрощают запись в файл и чтение из файла сложных данных. ниже разбирается их применение.



### fwrite



функция **fwrite** предназначена для записи данных из массива. её определение:



```c


size_t fwrite( const void *buffer, size_t size, size_t count, FILE *stream );
```



функция принимает следующие параметры:





- buffer : указатель на первый объект массива, который должен быть записан

- size : размер каждого объекта

- count : количество объектов, которые нужно записать

- stream указатель на файловый поток для записи



результатом функции является количество записанных объектов. оно может оказаться меньше параметра `count`, если при записи произошла ошибка



по семантике, заданной стандартом, функция записывает каждый объект как массив значений `unsigned char`, вызывая для каждого значения unsigned char функцию **fputc**. реальные реализации копируют данные в буфер потока блоками, но наблюдаемое поведение остаётся тем же.



простейший пример: запись строки.



```c


#include <stdio.h>



int main() {

    char str[] = "Hello enoobis.ru";

    size_t N = sizeof(str);

    FILE *fp = fopen("data.txt", "w");

    size_t count = fwrite(str, sizeof str[0], N, fp);

    printf("wrote %zu elements out of %zu\n", count,  N);

    fclose(fp);

}
```



строка str записывается в файл "data.txt". длина строки вычисляется выражением `sizeof(str)`, а размер одного символа выражением `sizeof str[0]` (в принципе здесь можно сразу указать 1, поскольку sizeof(char) по определению равен единице). при успешной записи консоль выведет



```bash
wrote 18 elements out of 18
```



### fread



функция **fread** предназначена для считывания данных из файла в массив. её определение:



```c


size_t fread( const void *buffer, size_t size, size_t count, FILE *stream );
```



функция принимает следующие параметры:




- buffer : указатель на массив, в который нужно считать данные

- size : размер каждого объекта

- count : количество объектов, которые нужно считать

- stream указатель на файловый поток для чтения



результатом функции является количество считанных объектов. оно может оказаться меньше параметра `count`, если при чтении произошла ошибка или достигнут конец файла.



по семантике функция считывает данные с помощью функции **fgetc()** в буфер, который рассматривается как массив значений `unsigned char`. в стандартной библиотеке первый параметр fread объявлен как `void *` без квалификатора const, поскольку буфер изменяется.



простейший пример: чтение строки из записанного выше файла.



```c


#include <stdio.h>



int main() {

    int N  = 20;

    char str[N];   // определяем буфер достаточной длины



    FILE *fp = fopen("data.txt", "r");

    size_t count = fread(str, sizeof str[0], N, fp); 

    printf("read %zu elements out of %d\n", count,  N);

    printf(str);

    fclose(fp);

}
```



данные считываются в строку str. консольный вывод будет следующим:



```bash


read 18 elements out of 20

Hello enoobis.ru
```



### отслеживание ошибок



при записи или чтении возможны ошибки. например, при чтении может потребоваться получить данные определённого объёма, но в файле их окажется меньше, и чтение дойдёт до конца файла. конец файла отслеживается функцией **feof()**, которая принимает указатель на файл и возвращает ненулевое значение, если установлен индикатор конца файла. дополнительно функция **ferror()**, которой также передаётся указатель на файл, позволяет узнать, произошла ли ошибка при работе с файлом. оба индикатора хранятся в состоянии потока и устанавливаются предшествующими операциями ввода-вывода, поэтому проверять их имеет смысл после неудачного чтения, а не до него. пример чтения данных из файла:



```c


#include <stdio.h>



int main() {

    int N  = 20;

    char str[N];   // определяем буфер достаточной длины



    FILE *fp = fopen("data.txt", "r");

    int count = fread(str, sizeof str[0], N, fp);

    if(count == N)

    {

        printf("%s \n", str);

    }

    else

    {

        if (feof(fp))   // если конец файла

        {

            printf("Unexpected end of file\n");

            printf("Available: %s",str);

        }

        else if (ferror(fp))    // если ошибка

            perror("Error while reading file\n");

    }

    fclose(fp);

}
```



выражение `feof(fp)` проверяет, достигнут ли конец файла. сам по себе конец файла ошибкой не является. наличие ошибки проверяется выражением `ferror(fp)`



### запись и чтение структур



запись и чтение строки не самая сложная задача, и её можно решить и другими способами. однако функции fwrite и fread позволяют работать и с другими объектами, даже если те не являются массивами. функции принимают буфер в виде указателя `void *`, а им может быть адрес любого объекта, поскольку любой объект допустимо рассматривать как массив из одного элемента. ниже показано, как записать и считать структуры. для этого определяется следующая программа:



```c


#include <stdio.h>



struct person

{

    char name[20];

    int age;

};



int main() {

    // запись файла

    struct person tom = {"Tom", 22}; // структура для записи

    int size = sizeof(struct person);

    FILE *fp = fopen("person.bin", "w");

    // записываем одну структуру

    size_t count = fwrite(&tom, size, 1, fp); 

    printf("wrote %zu elements out of %d\n", count,  1);

    fclose(fp);



    // считывание структуры

    struct person unknown;  // структура для чтения

    fp = fopen("person.bin", "r");

    // считываем одну структуру

    count = fread(&unknown, size, 1, fp); 

    if(count == 1)

    {  

        printf("Name: %s \n", unknown.name);

        printf("Age: %d \n", unknown.age);

    }

    fclose(fp);

}
```



записывается структура типа person. для этого функции `fwrite()` передаётся адрес структуры:



```c
fwrite(&tom, size, 1, fp);
```



после записи данные считываются в структуру unknown, для чего функции `fread()` передаётся адрес этой структуры:



```c
fread(&unknown, size, 1, fp);
```



### запись и чтение массива структур



аналогичным образом записывается и считывается массив структур. для этого определяется следующая программа:



```c


#include <stdio.h>



struct person

{

    char name[20];

    int age;

};



int main() {

    char * filename = "people.bin";

    

    // массив для записи

    struct person people[] = { {"Tom", 23}, {"Alice", 27}, {"Bob", 31}, {"Kate", 29 }};

    int size = sizeof(people[0]);              // размер всего массива

    int count = sizeof(people)  / size;         // количество структур 

    

    // запись файла

    FILE *fp = fopen(filename, "w");

    // записываем массив структур

    size_t written = fwrite(people, size, count, fp); 

    printf("wrote %zu elements out of %d\n", written, count);

    fclose(fp);



    // считывание файла

    struct person users[count];  // массив для чтения структур

    fp = fopen(filename, "r");

    size_t read = fread(users, size, count, fp); 

    printf("read %zu elements\n", read);



    if(read > 0)

    {  

        for(int i = 0; i < count; i++)

        {

            printf("Name: %s \t Age: %d\n", users[i].name, users[i].age);

        }

    }

    fclose(fp);

}
```



в файл записывается массив структур people, а считывается он в массив users. консольный вывод программы:



```bash


wrote 4 elements out of 4

read 4 elements

Name: Tom        Age: 23

Name: Alice      Age: 27

Name: Bob        Age: 31

Name: Kate       Age: 29
```



### считывание по одной структуре



в примерах выше все ранее записанные данные считывались разом. однако может потребоваться вывести на консоль не всех пользователей, а лишь некоторых, например имеющих определённое имя или возраст. можно было бы считать весь массив и затем пройти по нему в цикле в поиске нужных данных. но можно и считывать из файла по одному объекту и проверять каждый, что требует памяти лишь под один элемент независимо от размера файла. для этого определяется следующая программа:



```c


#include <stdio.h>



struct person

{

    char name[20];

    int age;

};



void save(char*);

void read_by_age(char*, int);



int main() {

    char * filename = "people.bin";

    save(filename);

    read_by_age(filename, 22);   // находим пользователей, которым 22 года

}



// записываем данные

void save(char* filename)

{

    struct person people[] = { {"Tom", 22}, {"Bob", 33}, {"Kate", 33 }, {"Alice", 22}};

    int size = sizeof(people[0]);              // размер всего массива

    int count = sizeof(people)  / size;         // количество структур 



    FILE *fp = fopen(filename, "w");

    size_t written = fwrite(people, size, count, fp); 

    printf("wrote %zu elements out of %d\n", written, count);

    fclose(fp);

}

// выводим данные на консоль для возраста age

void read_by_age(char* filename, int age)

{

    struct person p;  // структур для считывания файла

    FILE* fp = fopen(filename, "r");

    while(fread(&p, sizeof(p), 1, fp) == 1)

    {

        if(p.age == age)    // если пользователь имеет определенный возраст

        {

            printf("Name: %s \t Age: %d \n", p.name, p.age);

        }

    }

    fclose(fp);

}
```



запись и чтение разнесены по отдельным функциям. если функция `save()` записывает в файл весь массив структур разом, то функция `read_by_age()` считывает структуры по одной в цикле, пока в файле остаются данные. если поле age очередной структуры совпадает с параметром age, структура выводится на консоль.
