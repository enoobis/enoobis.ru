одной из распространённых сред разработки для программирования под windows является **visual studio**. в курсе используется бесплатная полнофункциональная редакция visual studio 2019 community, доступная по адресу [https://visualstudio.microsoft.com/ru/vs/community/](https://visualstudio.microsoft.com/ru/vs/community/). в её состав входит компилятор msvc (microsoft visual c++), который компилирует и код на c.

после загрузки и запуска установщика visual studio в нём нужно отметить пункт **Разработка классических приложений на C++**. отдельной рабочей нагрузки для c нет: компилятор c поставляется в составе инструментария c++.

![установка с++ в visual studio](/uploads/course-lectures/81fb16f69e9709b740b8d065617672fcc34264a5.png)

после выбора необходимых пунктов установка запускается нажатием ОК. когда visual studio установлена, создадим первый проект. для этого откроем visual studio и на стартовом экране выберем тип **Empty Project** для языка c++:

![первый проект на си в visual studio](/uploads/course-lectures/abf4d4fd94966c01fba54f64051752474b9279bc.png)

на следующем экране в поле имени проекта укажем HelloApp; здесь же можно задать расположение проекта. затем нажмём Create, чтобы создать проект.

![первый проект на си в visual studio](/uploads/course-lectures/b29014819b38dca2ea71753b1ff7e64098601f85.png)

visual studio создаст пустой проект. добавим в него текстовый файл для исходного кода: в окне Solution Explorer (Обозреватель решений) щёлкнем правой кнопкой мыши по узлу **Source Files** и в контекстном меню выберем **Add -> New Item...**:

![добавление файла на си в visual studio](/uploads/course-lectures/8117a4a0efca6af0c759442819e8d3f3ba27f7d5.png)

откроется окно добавления нового элемента:

![добавление исходного файла на си в visual studio](/uploads/course-lectures/34281b465e0c961ff7559aec9b390c34cb9afdb8.png)

в нём выберем пункт **C++ File(.cpp)**, а внизу окна укажем имя файла **hello.c**. исходные файлы на c, как правило, имеют расширение .c. оно указывает, что файл содержит исходный код на языке c и должен обрабатываться соответствующим компилятором; msvc по умолчанию выбирает режим компиляции именно по расширению файла.

### настройка проекта

после добавления файла изменим параметры проекта. для этого перейдём к пункту меню **Project -> Properties**

![свойства проекта на си в visual studio](/uploads/course-lectures/c1747a66a7dba089b09622b559ca1090f9646d0f.png)

в окне свойств проекта в левой части перейдём к секции **С/С++** и далее к пункту **Advanced**:

![установка компилятора для языка си в vs](/uploads/course-lectures/964283ec99019aa137dadc2d62c7fab5789e1064.png)

в правой части окна для поля **Compile As** установим значение **Compile as C Code (/TC)**. эта настройка предписывает компилировать исходный код по умолчанию именно как код c, а не c++, независимо от расширения файлов. разница существенна: c не является подмножеством c++, и ряд конструкций (например, неявное приведение `void*` к другому типу указателя или составные литералы) трактуется в двух языках по-разному.

после установки значения нажмём кнопку "Применить", чтобы новые параметры конфигурации вступили в силу.

для работы с c полезна ещё одна настройка: выбор стандарта языка. перейдём к пункту **С/С++ -> Language**. в поле **C Language Standard** можно указать один из доступных стандартов c, по которому будет выполняться компиляция (в актуальных версиях msvc это, в частности, c11 и c17, ключи `/std:c11` и `/std:c17`):

![настройка стандарта языка си в visual studio](/uploads/course-lectures/e9b9a837dbaee8d6864a8aa91ae9f0cb186b9240.png)

для рассматриваемого примера выбор стандарта значения не имеет, поэтому оставим этот параметр по умолчанию.

### определение кода программы

после добавления файла **hello.c** проект будет иметь следующую структуру:

![структура проекта на си в visual studio](/uploads/course-lectures/c20c19152d8cf2946cc0d2c0fc678f2a31198ef3.png)

кратко разберём эту структуру. окно Solution Explorer отображает решение (solution), здесь оно называется HelloApp. решение может включать несколько проектов; по умолчанию в нём один проект с тем же именем HelloApp. в проекте есть ряд узлов:

- External Dependencies : отображает файлы, которые используются в исходном коде, но не входят в состав проекта

- Header Files : предназначен для заголовочных файлов с расширением .h

- Resource Files : предназначен для файлов ресурсов, например, изображений

- Source Files : содержит файлы с исходным кодом

эти узлы являются логическими фильтрами представления и не обязательно соответствуют каталогам файловой системы.

определим в файле hello.c простейший код, выводящий строку на консоль:

```c
#include <stdio.h>			// подключаем заголовочный файл stdio.h
int main(void)						// определяем функцию main
{									// начало функции
	printf("Hello enoobis.ru!\n");	// выводим строку на консоль
	return 0;						// выходим из функции
}									// конец функции
```

это тот же код, который рассматривался в предыдущих темах о компиляции с помощью gcc.

запустим программу. для этого в visual studio нажмём сочетание клавиш Ctrl+F5 или выберем пункт меню **Debug -> Start Without Debugging**:

![запуск программы на си в visual studio](/uploads/course-lectures/d2d4cf8ca19a6cb19c6f1def2e8d736204b85725.png)

visual studio передаст исходный код компилятору, который вместе с компоновщиком построит исполняемый файл exe, после чего он будет запущен. в открывшейся консоли появится выведенное сообщение:

![первое приложение на языке программирования си](/uploads/course-lectures/093924c90c7e6bd1336974d23ac4865a7423e89e.png)

в каталоге проекта `x64/Debug` находится скомпилированный файл exe, который можно запускать независимо от visual studio:

![компиляция кода на языке программирования си](/uploads/course-lectures/8c771432a8bd99c1c1f08c1a0764f6c157ab9a22.png)

файл **HelloApp.exe** и представляет скомпилированный исполняемый файл. имя каталога отражает выбранные платформу (x64) и конфигурацию (Debug); сборка в конфигурации Release поместит результат в `x64/Release` и будет выполнена с оптимизациями и без отладочной информации по умолчанию.
