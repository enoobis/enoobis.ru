для вывода на консоль в языке программирования c применяется функция **printf()**. вывод простой строки не требует дополнительных соглашений, тогда как вывод данных других типов подчиняется правилам форматирования: функция интерпретирует строку формата и сопоставляет спецификации преобразования последующим аргументам.

формальное определение функции printf выглядит следующим образом:

```c
printf(строка_форматирования, список_аргументов)
```

первый параметр представляет строку, которая может содержать произвольный текст в двойных кавычках. например:

```c
#include <stdio.h>
int main(void)
{
	printf("Hello world!");
	return 0;
}
```

кроме обычного текста в строку передаются специальные группы символов, которые называются управляющими последовательностями. они кодируют символы, которые нельзя или неудобно записать буквально внутри строкового литерала. наиболее распространённые из них:

- \n : перевод на новую строку

- \t : табуляция

- \r : возврат каретки (курсора) в начало строки

- \\ : обратный слеш

- \' : одинарная кавычка

- \" : двойная кавычка

например:

```c
#include <stdio.h>
int main(void)
{
	printf("The book \"The C Programming Language\"\nBrian Kernighan, Dennis Ritchie");
	return 0;
}
```

консольный вывод:

```consoletext
The book "The C Programming Language"
Brian Kernighan, Dennis Ritchie
```

### спецификации преобразования

спецификации преобразования задают формат вывода различных типов данных. формальное определение спецификации преобразования выглядит следующим образом:

```c
% флаги ширина_поля.точность модификатор спецификатор
```

из этих компонентов обязательными являются только два: `%` и `спецификатор`. остальные поля необязательны и уточняют выравнивание, ширину, точность и ранг целого или вещественного типа.

спецификаторы:

- %c : для вывода отдельных символов (тип char)

- %s : для вывода строк

- %d : для вывода целых чисел со знаком (тип int)

- %i : для вывода целых чисел со знаком (тип int)

- %u : для вывода целых положительных чисел (тип unsigned)

- %f : для вывода чисел с плавающей точкой (float, double)

- %F : для вывода чисел с плавающей точкой в верхнем регистре (float, double)

- %e : для вывода экспоненциального представления чисел с плавающей точкой (float, double)

- %E : для вывода экспоненциального представления чисел с плавающей точкой в верхнем регистре (float, double)

- %g : для вывода чисел используется более короткий из форматов %e или %f

- %G : для вывода чисел используется более короткий из форматов %E или %F

- %o : для вывода восьмеричных чисел без знака

- %x : для вывода шестнадцатеричных чисел

- %X : для вывода шестнадцатеричных чисел в верхнем регистре

- %% : для вывода знака процента

применение нескольких спецификаторов:

```c
#include <stdio.h>
int main(void)
{
	float r = 71.8986;
	printf("x = %f \n", r);
	printf("x = %e \n", r);
	
	char symbol = 'r';
	printf("symbol = %c \n", symbol);
	
	unsigned int number = 23;
	printf("number = %u \n", number);
	
	printf("%s \n", "Hello Word 2013");
	return 0;
}
```

значения для спецификаторов передаются через аргументы, которые идут после строки форматирования в функции printf. `printf` сопоставляет спецификаторы аргументам по порядку. несоответствие числа или типов аргументов спецификаторам приводит к неопределённому поведению: функция вариативная, и компилятор не приводит аргумент к типу, ожидаемому спецификатором.

консольный вывод:

```consoletext
x = 71.898598
x = 7.189860e+001
symbol = r
number = 23
Hello Word 2013
```

для вывода числовых значений с плавающей точкой используются ширина поля и точность. ширина поля представляет целое положительное число, которое задаёт минимальную длину выводимого значения в символах. если представление длиннее указанной ширины, поле расширяется, значение не усекается. точность: целое положительное число, которое задаёт количество цифр в дробной части. например:

```c
float r = 71.8986;
printf("x = %4.2f \n", r);	// 71.90
```

здесь спецификация преобразования представляет строку "%4.2f", где "4" : ширина поля (для вывода числа отводится не менее 4 символов), а "2" : точность (2 цифры в дробной части). округление при выводе выполняет сама функция форматирования, исходное значение переменной не изменяется.

модификаторы уточняют выводимое значение и задают ранг типа аргумента, который иначе был бы истолкован как int или double. используются следующие модификаторы:

- h : для вывода значений short int

- l : для вывода значений long int и unsigned long int

- ll : для вывода значений long long int и unsigned long long int

- L : для вывода значений long double

```c
short r = 7100;
printf("x = %hd", r);
```

в функцию printf можно передавать несколько значений:

```c
printf("Name=%s \t Age=%d \t Weight=%3.2f", "Tom", 23, 63.3456);
```

первый спецификатор в строке форматирования : "%s", и для него значение берётся из первого аргумента, строки "Tom". второй спецификатор : "%d", для него значение берётся из второго аргумента, числа 23. далее по тому же правилу: k-й спецификатор потребляет k-й аргумент после строки формата.

дополнительно применяются флаги, которые управляют форматированием вывода:

- - : указывает, что выравнивание будет идти от левого края (по умолчанию используется выравнивание справа).

- + : если выводимое значение имеет знак (+ или -), то оно выводится. без данного флага знак выводится только в случае отрицательного значения.

- пробел : вставляет пробел на месте знака перед положительными числами

- # : при использовании со спецификаторами "o", "x", "X" значение числа выводится с предшествующими символами 0, 0x или 0X. при использовании со спецификаторами "f", "g", "G" десятичная точка будет выводиться, даже если в числе нет дробной части

пример использования флагов:

```c
#include <stdio.h>

int main(void)
{
	printf("%d \n", 8);
	printf("% d \n", 8);
	printf("%+d \n", +8);
	printf("%#o \n", 8);
	printf("%#f \n", 8.);

	printf("%9s %d \n", "Tom", 38);
    printf("%-9s %d \n", "Tom", 38);

	return 0;
}
```

консольный вывод:

```consoletext
8
 8
+8
010
8.000000

      Tom 38 
Tom       38
```
