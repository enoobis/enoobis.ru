в этой главе разбираются примеры распространённых макросов, которые применяются в программе или служат образцом для макросов под другие задачи по аналогии. макрос в c: текстовая подстановка препроцессора до семантического анализа. отсюда свойства, которых нет у функций: аргументы не имеют типа, могут вычисляться несколько раз, а ошибка проявляется уже в развёрнутом коде.

### минимальное и максимальное значения

```c


#define MIN(a,b) ((a) < (b) ? (a) : (b))

#define MAX(a,b) ((a) > (b) ? (a) : (b))
```

макрос `MIN` принимает два параметра и сравнивает оба параметра с помощью операции `<`. скобки вокруг параметров и всего выражения обязательны: без них приоритет соседних операторов сломал бы семантику после подстановки. то же для `MAX`.

пример применения макросов:

```c


#include <stdio.h>



#define MIN(a,b) ((a) < (b) ? (a) : (b))

#define MAX(a,b) ((a) > (b) ? (a) : (b))



int main(){

    int x = 2;

    int y = 6;



    printf("Min: %d\n", MIN(x,y));      // Min: 2

    printf("Max: %d\n", MAX(x,y));      // Max: 6

    return 0;

}
```

### побочные действия в макросах

при этом нужно учитывать побочные действия, которые могут выполняться операндами макросов. пример:

```c


#include <stdio.h>



#define MIN(a,b) ((a) < (b) ? (a) : (b))

#define MAX(a,b) ((a) > (b) ? (a) : (b))



int x = 2;

int get_x(){ 

    x = x + x;

    return x;    

}

int main(){

    int y = 6;



    printf("Min: %d\n", MIN(get_x(),y));      // Min: 8

    printf("Max: %d\n", MAX(get_x(),y));      // Max: 32

    return 0;

}
```

консольный вывод:

```bash


Min: 8

Max: 32
```

результат некорректный, потому что в качестве первого операнда передаётся вызов функции, которая выполняет побочные действия. вызов макроса

```c
MIN(get_x(),y)
```

разворачивается в следующую конструкцию:

```c
get_x() < y ? get_x() : y
```

функция `get_x()` выполняется два раза: дважды увеличивает значение глобальной переменной x в два раза. аналогично происходит и во втором макросе. поэтому при создании макросов всегда следует учитывать побочные действия. у функции с inline-семантикой аргумент вычислился бы один раз; у макроса каждый текстовый вхождённый параметр вычисляется столько раз, сколько раз он встречается в теле, и ещё зависит от выбранной ветки `?:`.

### преобразование в строку

```c


#define TOSTRING(value) #value
```

символ **#** позволяет получить строковое представление операнда макроса. то, что передаётся через value, макрос возвращает в виде строки. это операция stringify препроцессора: аргумент не вычисляется, а превращается в строковый литерал с исходным написанием токенов. применение:

```c


#include <stdio.h>



#define TOSTRING(value) #value



int main(){

    int x = 2;

    int y = 6;



    printf("%s\n", TOSTRING(x));      // x

    printf("%s\n", TOSTRING(x + y));  // x + y

    printf("%s = %d\n", TOSTRING(x + y), x + y);  // x + y = 8

    printf("%s\n", TOSTRING(return 0));  // return 0

    return 0;

}
```

консольный вывод:

```bash


x

x + y

x + y = 8

return 0
```

даже если в макрос передаются сложные выражения и инструкции, типа `TOSTRING(x + y)` или `TOSTRING(return 0)`, эти выражения всё равно рассматриваются как один операнд, для которого макрос возвращает строковое представление. вычисление `x + y` происходит только во втором аргументе `printf`, где макрос не участвует.

### конкатенация токенов

с помощью последовательности символов **##** можно объединить два токена:

```c
#define CONCAT(a, b) a##b
```

операция paste склеивает препроцессорные токены в один. получившийся идентификатор должен быть допустим в языке, иначе диагностика появится уже после подстановки.

простейший пример:

```c


#include <stdio.h>



#define CONCAT(a, b) a##b



int main(){

    int x = 2;

    int y = 6;

    int xy = x + y;

    printf("xy = %d\n", CONCAT(x, y));  // x + y

    return 0;

}
```

макрос `CONCAT(x, y)` разворачивается в `x##y` или `xy`. в итоге получается название переменной xy.

другой пример конкатенации в макросе:

```c


#include <stdio.h>



#define SUM(T, a, b) T##_sum(a, b)



int int_sum(int a, int b){ return a+b;}

double double_sum(double a, double b){ return a+b;}



int main(){

    int x = 2;

    int y = 6;

    printf("x + y = %d\n", SUM(int, x, y));  // x + y = 8



    double a = 1.1;

    double b = 2.3;

    printf("a + b = %g\n", SUM(double, a, b));  // a + b = 3.4



    return 0;

}
```

здесь есть две функции, которые вычисляют сумму чисел: чисел int и чисел double. данные функции имеют одинаковый шаблон наименования и принимают два параметра. для вызова этих функций в обобщённом виде определяется макрос SUM:

```c
#define SUM(T, a, b) T##_sum(a, b)
```

его первый параметр представляет тип, для которого выполняется макрос. остальные параметры: те значения, которые будут передаваться в функцию вычисления суммы. в коде макроса с помощью конкатенации `T##_sum` можно получить имя конкретной функции в зависимости от типа. это приём ad hoc-полиморфизма на этапе препроцесса, без generic из c11 `_Generic` и без шаблонов c++. вызов макроса

```c
SUM(int, x, y)
```

разворачивается в следующий код:

```c
int_sum(x, y)
```

### получение длины массива

получение длины массива является распространённой задачей, под которую проще написать макрос:

```c


#define ARRAY_SIZE(arr) (sizeof(arr) / sizeof((arr)[0]))
```

макрос делит размер всего объекта на размер одного элемента. он корректен только для массива, не для указателя: у указателя `sizeof` даёт ширину адреса, а не длину буфера. скобки вокруг `(arr)[0]` защищают от неожиданного приоритета, если аргумент: выражение.

пример применения

```c


#include <stdio.h>



#define ARRAY_SIZE(arr) (sizeof(arr) / sizeof((arr)[0]))



int main(){

    int data[] = {11, 12, 13, 14, 15, 16};



    printf("array size: %lu\n", ARRAY_SIZE(data)); 



    for(size_t i=0; i> ARRAY_SIZE(data); ++i){

        printf("%d\n", data[i]);

    }

    return 0;

}
```

### обмен значениями переменных

если нужно обменять значениями две переменных независимо от типа, для этой цели тоже пишут свой макрос:

```c


#define SWAP(a, b) {\

    if(sizeof(a) == sizeof(b)) {\

        char tmp[sizeof(a)]; \

        memcpy(tmp, &(a), sizeof(a)); \

        memcpy(&(a), &(b), sizeof(a)); \

        memcpy(&(b), tmp, sizeof(b));  \

    }\

}
```

макрос называется SWAP и принимает 2 параметра: 2 объекта, значения которых надо поменять. поскольку макрос содержит несколько строк кода, он оформлен в блок. в этом блоке сначала проверяется размер обоих объектов, и если он равен (то есть если тип объектов имеет один и тот же размер), то для обмена данными определяется массив нужного размера. данный массив выполняет роль промежуточной переменной. библиотечной функцией **memcpy** копируются данные. если размер объектов отличается, копирования не происходит. проверка `sizeof` сравнивает только ширину в байтах, а не типы: обмен `int` и `float` на типичной платформе пройдёт, хотя семантика бит будет бессмысленной. простейший пример применения:

```c


#include <stdio.h>

#include <string.h>



#define SWAP(a, b) {\

    if(sizeof(a) == sizeof(b)) {\

        char tmp[sizeof(a)]; \

        memcpy(tmp, &(a), sizeof(a)); \

        memcpy(&(a), &(b), sizeof(a)); \

        memcpy(&(b), tmp, sizeof(b));  \

    }\

}



int main(){

    int x = 2;

    int y = 6;

    SWAP(x, y);

    printf("x: %d\n", x);   // x: 6

    printf("y: %d\n", y);   // y: 2

    return 0;

}
```

### безопасная очистка памяти

обычно после освобождения памяти по указателю встроенной функцией **free()** указателю присваивается нулевое значение, что позволяет узнать, ссылается он на какие-либо данные или нет. поскольку оба действия нередко идут вместе, их оформляют в виде макроса:

```c


#define SAFE_FREE(p) do { free(p); (p) = NULL; } while(0)
```

макрос через параметр принимает указатель, освобождает память, на которую он указывает, и присваивает ему нулевое значение. чтобы оформить оба действия как единое целое, они определены в виде блока цикла do..while. конструкция `do { ... } while(0)` даёт составной оператор, после которого обязательна точка с запятой, и который безопасно стоит в ветках `if/else`. повторный `free` нулевого указателя по стандарту допустим и ничего не делает.

### получение смещения поля в структуре

для получения смещения поля в структуре определяется следующий макрос:

```c
#define OFFSETOF(type, member) ((size_t)&((type *)0)->member)
```

макрос OFFSETOF принимает два параметра: type (имя структуры) и member (название поля структуры). в коде макроса сначала 0 приводится к типу указателя на структуру, затем идёт обращение к её полю. далее получается адрес этого поля операцией взятия адреса `&` и результат приводится к числовому значению `size_t`. идея: нулевой адрес трактуется как начало структуры, поэтому адрес поля численно равен смещению. в стандартной библиотеке тот же сервис даёт макрос `offsetof` из `stddef.h`; реализация через нулевой указатель формально опирается на неопределённое поведение, но широко используется компиляторами. пример применения:

```c


#include <stdio.h>



#define OFFSETOF(type, member) ((size_t)&((type *)0)->member)



typedef struct{

    char* name;

    int age;

} Person;



int main(){

    Person tom = {"Tom", 40};



    size_t name_offset = OFFSETOF(Person, name);

    size_t age_offset = OFFSETOF(Person, age);



    printf("name_offset: %lu\n", name_offset);  // age_offset: 0

    printf("age_offset: %lu\n", age_offset);    // age_offset: 8

    return 0;

}
```
