нередко возникает необходимость работать не с одиночными значениями, а с наборами однотипных данных. в языке c для этого служат массивы. **массив** представляет последовательность объектов одного типа, размещённых в смежных ячейках памяти. объявление массива имеет вид:

```c
тип_переменной название_массива [длина_массива]
```

после типа элемента указывается имя массива, затем в квадратных скобках его длина, то есть число элементов. длина входит в тип объекта: `int[4]` и `int[5]` в системе типов c различны. пример массива из четырёх чисел:

```c


int main(void)

{

	int numbers[4];

	return 0;

}
```

к отдельным элементам обращаются по индексу, целочисленному смещению от начала массива. индекс записывается в квадратных скобках после имени:

```c


#include <stdio.h>



int main(void)

{

	int numbers[4];

	numbers[0] = 1;

	numbers[1] = 2;

	numbers[2] = 3;

	numbers[3] = 4;

	

	printf("numbers[0] = %d \n", numbers[0]);	// 1 - первый элемент

	printf("numbers[2] = %d \n", numbers[2]);	// 3 - третий элемент

	return 0;

}
```

индексация начинается с нуля, поэтому первый элемент доступен как `numbers[0]`, а последний при длине n как `numbers[n - 1]`. выход за границы массива стандарт не проверяет: такое обращение есть неопределённое поведение.

массив можно объявить и сразу инициализировать. для этого применяется инициализатор: список значений в фигурных скобках:

```c


int numbers[4] = { 1, 2, 3, 5 };		// инициализация массива

printf("numbers[2] = %d", numbers[2]);	// 3
```

значения в инициализаторе перечисляются через запятую и последовательно присваиваются элементам, начиная с индекса 0. соответствие значений и индексов для примера выше:

| Значение | 1 | 2 | 3 | 5 |
| --- | --- | --- | --- | --- |
| Индекс | 0 | 1 | 2 | 3 |

при инициализации длину можно не указывать явно: компилятор выведет её из числа элементов в инициализаторе:

```c


int numbers[] = { 1, 2, 3, 5 };
```

необязательно задавать значения для всех элементов. если размер указан, а инициализатор короче, оставшиеся элементы получают нулевое значение соответствующего типа (для `int` это 0):

```c
int numbers[5] = { 10, 12};	// 10, 12, 0, 0, 0
```

в рамках инициализации задаются два первых элемента, остальные три получают 0.

язык c начиная с c99 допускает и выборочную инициализацию не по порядку, designated initializers: элемент задаётся конструкцией `[индекс] = значение`.

```c
int numbers[5] = { [1]=11, [3] = 13 };
```

инициализируются только элементы с индексами 1 и 3. остальные получают значение по умолчанию 0. итоговый объект эквивалентен следующему:

```c
int numbers[5] = { 0, 11, 0, 13, 0 };
```

### размер и количество элементов массива

размер массива в байтах не всегда очевиден из текста программы, особенно если длина выведена из инициализатора. оператор **sizeof** возвращает размер операнда в байтах в виде значения типа **size_t**:

```c


#include <stdio.h>



int main(void)

{

    int numbers[] = { 5, 6, 7};

	size_t size = sizeof(numbers);

    printf("numbers size: %zu \n", size);     // numbers size: 12

    return 0;

}
```

для массива `{ 5, 6, 7}` оператор `sizeof` даёт 12 байт: три объекта типа int, каждый из которых на типичной архитектуре занимает 4 байта. для массива с известным на этапе компиляции размером `sizeof` вычисляется во время компиляции. тип результата **size_t** есть беззнаковый целый тип, достаточный для представления размера любого объекта; в исходном изложении он отождествляется с **unsigned long long**, то есть 64-разрядным беззнаковым целым. на 64-разрядной windows (модель llp64) это обычно так, на lp64 (linux, macos) `size_t` чаще совпадает с `unsigned long`, тоже 64-битным. для вывода на консоль применяется спецификатор **%zu**.

число элементов получают делением размера массива на размер одного элемента:

```c


#include <stdio.h>



int main(void)

{

    int numbers[] = { 5, 6, 7};

    size_t size = sizeof(numbers);

    size_t count = sizeof(numbers) / sizeof(int);

    printf("numbers size: %zu \n", size);     	// numbers size: 12

    printf("numbers count: %zu \n", count);     	// numbers count: 3

    return 0;

}
```

тот же результат даёт деление размера массива на размер его первого элемента, без явного повторения типа:

```c


#include <stdio.h>



int main(void)

{

    int numbers[] = { 5, 6, 7};

	size_t size = sizeof(numbers);

	size_t count = sizeof(numbers) / sizeof(numbers[0]);

    printf("numbers size: %zu \n", size);     	// numbers size: 12

    printf("numbers count: %zu \n", count);     	// numbers count: 3

    return 0;

}
```

вторая форма устойчивее к смене типа элемента. `sizeof` даёт размер всего массива только пока имя не преобразовалось к указателю: параметр функции, объявленный как массив, имеет тип указателя, и `sizeof` вернёт размер указателя вместо размера исходного объекта.

### динамическое вычисление значений массива

элементы массива могут вычисляться выражениями во время инициализации и в последующих присваиваниях. пример:

```c


int sizes[] = {sizeof(int), sizeof(long), sizeof(long long)};  // numbers = {4, 4 (Windows) или 8 (Linux/MacOS), 8}

sizes[1] = sizeof(char);  // sizes[1] = 1
```

каждый элемент инициализируется результатом оператора `sizeof` (скобки вокруг имени типа не превращают его в вызов функции), который возвращает размер типа в байтах. последующее присваивание `sizes[1] = sizeof(char)` замещает уже сохранённое значение. комментарий в примере фиксирует типичные размеры: `int` обычно 4 байта, `long` 4 байта на windows и 8 на linux/macos, `long long` 8 байт.

### перебор элементов массива

элементы массива перебирают циклическими конструкциями:

```c


#include <stdio.h>



int main(void)

{

	int numbers[] = { 10, 12, 13, 54, 43 };

    size_t count = sizeof(numbers) / sizeof(numbers[0]);

	for(size_t i =0; i < count; i++)

	{

		printf("numbers[%zu] = %d \n", i, numbers[i]);

	}

	return 0;

}
```

в качестве типа индекса используется `size_t`, тот же беззнаковый тип, которым выражен размер. на практике встречается и **int**, и **unsigned int**:

```c


#include <stdio.h>

 

int main(void)

{

	int numbers[] = { 10, 12, 13, 54, 43 };

    size_t count = sizeof(numbers) / sizeof(numbers[0]);

    // int в качестве индекса

	for(int i =0; i < count; i++)

	{

		printf("numbers[%d] = %d \n", i, numbers[i]);

	}

	return 0;

}

</pre

<p>В целом мы получим тот же результат. Но в общем рекомендуемым способом все таки является использование <code>size_t</code>, поскольку этот тип допускает количество, 

которое может не вписаться в допустимый диапазон чисел типов <code>int</code> или <code>unsigned int</code>.</p>



<h3>Динамическая установка размера массива</h3>

<p>Размер массива можно установить динамически с помощью переменной/константы:</p>

<pre class="brush:c;">

#include <stdio.h>



int main(void)

{

	int maxSize = 3;

    int array[maxSize];

    array[0] = 1;

    array[1] = 2;

    array[2] = 3;

    for (int i = 0; i < maxSize; i++)

    {

        printf("%d", array[i]);

    }

	return 0;

}
```

результат перебора тот же. рекомендуемым типом индекса остаётся `size_t`: он покрывает любое число элементов, представимое как размер объекта, тогда как диапазон `int` и даже `unsigned int` на части платформ уже этого размера. сравнение знакового индекса с `size_t` к тому же вовлекает целочисленные преобразования.

### динамическая установка размера массива

размер массива автоматической памяти можно задать не константой времени компиляции, а значением переменной. такие объекты называют массивами переменной длины (vla, c99). в примере выше `maxSize` вычисляется во время выполнения, и объявление `int array[maxSize]` отводит соответствующее число элементов. в c11 поддержка vla стала необязательной: реализация вправе их не предоставлять.

при динамической установке размера нельзя одновременно задать инициализатор:

```c


int maxSize = 3;

int array[maxSize] = {1, 2, 3};	// ! Ошибка, так нельзя
```

список в фигурных скобках относится к объектам, размер которых известен на этапе компиляции. у vla размер вычисляется во время выполнения, поэтому инициализатор запрещён.

### константные массивы

после инициализации элементы обычного массива можно изменять многократно:

```c


#include <stdio.h>

 

int main(void)

{

    int numbers[3] = {11, 12, 13};

    numbers[1] = 22;        // изменяем второй элемент

    printf("numbers[1] = %d", numbers[1]);  // numbers[1] = 22

    return 0;

}
```

если модификация нежелательна, массив объявляют с квалификатором `const`:

```c


#include <stdio.h>

 

int main(void)

{

    const int numbers[3] = {11, 12, 13};

    // numbers[1] = 22; // Нельзя изменить - массив константный

    printf("numbers[1] = %d", numbers[1]);  // numbers[1] = 22

    return 0;

}
```

попытка изменить элемент константного массива диагностируется уже на этапе компиляции. `const` здесь запрещает модификацию через данное lvalue; класс хранения и размещение в памяти от квалификатора сами по себе не меняются.

### многомерные массивы

массивы могут быть многомерными: элемент такого массива сам является массивом, и эта вложенность может продолжаться. на практике чаще всего используют двумерные массивы, которые интерпретируют как таблицы. пример массива чисел:

```c
int numbers[3][2] = { {1, 2}, {4, 5}, {7, 8} };
```

массив `numbers` содержит три элемента (три строки), каждый из которых есть массив из двух элементов (два столбца). в табличном виде:

| 1 | 2 |
| --- | --- |
| 4 | 5 |
| 7 | 8 |

для обращения к элементу вложенного массива нужны два индекса:

```c


int numbers[3][2] = { {1, 2}, {4, 5}, {7, 8} };

printf("numbers[1][0] = %d \n", numbers[1][0]);		// 4
```

другой пример: две строки и три столбца:

```c
int numbers[2][3] = { {1, 2, 4}, {5, 7, 8} };
```

графически:

| 1 | 2 | 4 |
| --- | --- | --- |
| 5 | 7 | 8 |

перебор двумерного массива выполняется вложенными циклами: внешний проходит по строкам, внутренний по столбцам строки:

```c


#include <stdio.h>



int main(void)

{

	int numbers[3][2] = { {1, 2}, {4, 5}, {7, 8} };

	// проходим по 3 строкам таблицы

	for(int i =0; i < 3; i++)

	{

		// проходим по 2 столбцам каждой строки

		for(int j =0; j<2; j++)

		{

			printf("numbers[%d][%d] = %d \n", i, j, numbers[i][j]);

		}

	}

	return 0;

}
```

как и для одномерного массива, оператор **sizeof** даёт размер всего объекта и размер подмассива (строки):

```c


#include <stdio.h>

 

int main(void)

{

    int numbers[3][2] = { {1, 2}, {4, 5}, {7, 8} };

    size_t rows_count = sizeof(numbers) / sizeof(numbers[0]);           // 3

    size_t columns_count = sizeof(numbers[0]) / sizeof(numbers[0][0]);  // 2

    printf("rows count = %zu \n", rows_count);

    printf("columns count = %zu \n", columns_count);

    // проходим по 3 строкам таблицы

    for(size_t i =0; i < rows_count; i++)

    {

        // проходим по 2 столбцам каждой строки

        for(size_t j =0; j<columns_count; j++)

        {

            printf("numbers[%zu][%zu] = %d \n", i, j, numbers[i][j]);

        }

    }

    return 0;

}
```

консольный вывод:

```bash


rows count = 3

columns count = 2

numbers[0][0] = 1

numbers[0][1] = 2

numbers[1][0] = 4

numbers[1][1] = 5

numbers[2][0] = 7

numbers[2][1] = 8
```

число строк есть `sizeof(numbers) / sizeof(numbers[0])`, число столбцов: `sizeof(numbers[0]) / sizeof(numbers[0][0])`. двумерные и прочие многомерные массивы в c суть синтаксическая абстракция над одним сплошным блоком памяти. в реальности любой массив одномерен: элементы идут подряд в порядке row-major, сначала полностью первая строка, затем вторая и так далее. с табличными данными двумерный синтаксис удобнее, однако инициализировать многомерный массив допустимо и плоским списком, как одномерный:

```c


int numbers[3][2] = { 1, 2, 4, 5, 7, 8 };
```

### строки

для массивов прочих типов действуют те же правила, что для массивов чисел. отдельно рассматривают массивы символов. во многих языках есть самостоятельный строковый тип. в языке c строки представляются массивами `char`: строка и есть последовательность символов, завершённая нулевым байтом. пример:

```c


#include <stdio.h>



int main(void)

{

    char message[] = "Hello";

    printf("message: %s \n", message);     // message: Hello

    return 0;

}
```

строковый литерал записывается в двойных кавычках. если в программе нужны строки, для них используют массивы символов.

кроме символов, заключённых в кавычки, каждая строка содержит завершающий символ `'\0'` (нулевой байт, первый символ таблицы ascii). в c нулевой байт служит признаком конца строки для библиотечных функций вроде `printf` со спецификатором `%s`. поэтому в `"Hello"` не 5 символов, а 6.

| H | e | l | l | o | \0 |
| --- | --- | --- | --- | --- | --- |

перебор всех байтов строки, включая завершающий нуль, с выводом десятичных кодов ascii:

```c


char message[] = "Hello";

size_t length = sizeof(message)/sizeof(char);   // 6 символов

for(size_t i=0; i<length; i++)

{

	printf("%d ", message[i]);

}
```

в конце последовательности виден нулевой символ:

```bash


72 101 108 108 111 0
```

если массив `message` задавать не строковым литералом, а списком символов, завершающий нуль нужно указать явно:

```c
char message[] = {'H', 'e', 'l', 'l', 'o', '\0'};
```

### задачи с массивами

работа с массивами на примере умножения матриц:

```c


#include <stdio.h>

 

int main(void)

{

    const int r1 = 3, c1r2=2, c2=1;

    int matrix1[3][2] = {{1, 2},{3, 4},{5, 6}};

    int matrix2[2][1] = {{10},{20}};

    int matmult[r1][c2];



    // инициализируем результирующую матрицу

    for(int i=0;i<r1;i++)

    {

        for(int j=0;j<c2;j++)

        {

            matmult[i][j]=0;

        }

    }



    for(int i=0;i<r1;i++)

    {

        for(int j=0;j<c2;j++)

        {

            for(int k=0;k<c1r2;k++)

            {

                matmult[i][j] = matmult[i][j] + matrix1[i][k] * matrix2[k][j];

            }

        }

    }



    printf("Result \n");

    for(int i=0;i<r1;i++)

    {

        for(int j=0;j<c2;j++)

        {

            printf("%d ",matmult[i][j]);

        }

        printf("\n");

    }

}
```

заданы две матрицы. `matrix1[3][2]` имеет три строки и два столбца:

| 1 | 2 |
| --- | --- |
| 3 | 4 |
| 5 | 6 |

вторая матрица состоит из одного столбца:

| 10 |
| --- |
| 20 |

размеры строк и столбцов вынесены в константы:

```c


const int r1 = 3,       // число строк в 1-й матрице

          c1r2=2,     // число столбцов в 1-й и число строк во 2-й матрице

          c2=1;       // число столбцов во 2-й матрице
```

результирующая матрица произведения `matmult`:

```c
int matmult[r1][c2];
```

её элементы сначала обнуляются.

при умножении матриц результат имеет число строк первой матрицы и число столбцов второй. элемент на i-й строке и j-м столбце равен сумме произведений элементов i-й строки первой матрицы на соответствующие элементы j-го столбца второй.

```browser


c<sub>2,1</sub> = a<sub>2,1</sub> * b<sub>1,1</sub> + a<sub>2,2</sub> * b<sub>2,1</sub>
```

во внешнем цикле по i перебираются строки первой матрицы:

```c
for(int i=0;i<r1;i++)
```

во вложенном цикле по j перебираются столбцы второй матрицы:

```c
for(int j=0;j<c2;j++)
```

цикл по k умножает элемент k-го столбца первой матрицы на элемент k-й строки второй и накапливает сумму:

```c


for(int k=0;k<c1r2;k++)

{

    matmult[i][j] = matmult[i][j] + matrix1[i][k] * matrix2[k][j];

}
```

результат: матрица из трёх строк и одного столбца:

```bash


Result

50

110

170
```
