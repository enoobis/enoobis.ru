функция может принимать параметры. параметры позволяют передать в функцию данные извне и настроить её выполнение. они перечисляются в скобках после имени функции и определяются так:

```c
тип имя_функции (тип параметр1, тип параметр2,... тип параметрN)
```

для каждого параметра сначала указывается тип, затем имя. следующий параметр определяется через запятую.

пусть функция должна выводить на консоль разные сообщения. для этого определим функцию, которая принимает в качестве параметра массив символов:

```c
#include <stdio.h>

// функция принимает массив символов
void print_message(char message[])
{
	printf("%s\n", message);
}

int main(void)
{
	print_message("Hello enoobis.ru!");
	print_message("Hello World!");
	print_message("Hello work...");
}
```

функция `print_message()` принимает один параметр с именем `message`, объявленный с типом `char[]`. по правилам c параметр типа «массив» автоматически корректируется до указателя, так что фактический тип `message` есть `char *`, и копирование массива при вызове не происходит. параметр `message` называют **формальным параметром**.

в функции `main` функция print_message вызывается трижды с разными значениями: строками "Hello enoobis.ru!", "Hello World!" и "Hello work...". такие значения называют **аргументами**, или фактическими параметрами. в итоге на консоль выводятся три строки:

```consoletext
Hello enoobis.ru!
Hello World!
Hello work...
```

в main отсутствует оператор return: начиная с c99, достижение закрывающей скобки main эквивалентно `return 0;`, для других функций это правило не действует.

прототип функции `print_message()` выглядел бы так:

```c
void print_message(char[]);
```

полный пример с прототипом:

```c
#include <stdio.h>

// прототип функции print_message
void print_message(char[]);

int main(void)
{
	print_message("Hello enoobis.ru!");
}
// определение функции print_message
void print_message(char message[])
{
	printf("%s\n", message);
}
```

в прототипе имена параметров можно опустить: для проверки вызова компилятору достаточно типов.

если нужно несколько параметров, они перечисляются через запятую. например, функция, вычисляющая сумму двух чисел:

```c
#include <stdio.h>

void sum(int x, int y)
{
	printf("%d + %d = %d \n", x, y,  x + y);
}

int main(void)
{
	sum(1, 2);
	sum(4, 5);
	sum(6, 2);
}
```

функция `sum()` принимает два параметра типа **int**.

в функции main она вызывается трижды, и каждый раз получает по два аргумента для параметров x и y. соответствие между аргументами и параметрами устанавливается позиционно: первый аргумент задаёт значение первого параметра, второй аргумент второго параметра и так далее. именованных аргументов и значений по умолчанию в c нет. консольный вывод программы:

```consoletext
1 + 2 = 3
4 + 5 = 9
6 + 2 = 8
```

прототип функции `sum` выглядел бы так:

```c
void sum(int, int);
```

типы аргументов должны соответствовать типам параметров. если они не совпадают, компилятор при наличии прототипа выполняет неявное преобразование, как при присваивании.

например, выше использовалась функция `void sum(int, int)`. если передать в sum значения другого типа, компилятор попытается привести их к int:

```c
int main(void)
{
	sum(1.4, 2.5);  // передаем значения double
	sum(1.4f, 2.5f);  // передаем значения float
}
```

в обоих случаях функция sum фактически получит числа 1 и 2: преобразование вещественного числа в целое отбрасывает дробную часть. такие сужающие преобразования допустимы без явного приведения, но флаг `-Wconversion` в gcc и clang позволяет получать о них предупреждения.

### процесс передачи параметров

в c параметры всегда передаются в функцию **по значению**, поэтому функция не может изменить переданные ей аргументы. рассмотрим пример:

```c
#include <stdio.h>

void increase(int x)
{
	x = 2 * x;
	printf("Increase func: x = %d \n", x);
}

int main(void)
{
	int a = 25;
	increase(a);
	printf("Main func: a = %d \n", a);
}
```

функция increase получает через параметр число и увеличивает его вдвое.

в функции main вызывается функция increase, которой передаётся значение переменной `a`. после того как increase отработала и изменила значение своего параметра, проверяется значение переменной `a`.

при выполнении видно, что изменение параметра внутри increase действует только в пределах этой функции. вне её значение переменной a остаётся прежним:

```consoletext
Increase func: x = 50
Main func: a = 25
```

причина в следующем. параметры функции являются её локальными переменными с автоматическим временем хранения: при каждом вызове для них выделяется отдельная память (в стеке или в регистрах, в зависимости от соглашения о вызовах). для функций без прототипа и для переменной части списка аргументов (как у printf) действуют стандартные повышения аргументов: значения типа **float** передаются как **double**, а значения типов **char** и **short int** как **int**.

при вызове функции вычисляются значения аргументов, после чего они заносятся в память, отведённую под параметры. при наличии прототипа каждый аргумент преобразуется к объявленному типу параметра; без прототипа значения типа **float** преобразуются в **double**, а значения типов **char** и **short int** в **int**. порядок вычисления самих аргументов стандартом не определён.

если в вызов передаётся переменная, функция получает копию её значения, поэтому никакие манипуляции с параметром внутри функции не затрагивают исходную переменную. изменить объект вызывающей стороны можно, только передав его адрес, то есть указатель, который сам тоже копируется по значению.

после завершения функции память, выделенная под параметры, освобождается.

### константные параметры

значение параметра внутри функции можно изменить:

```c
void change(int n)
{
    n = n * 2;		// значение параметра изменяется
    printf("n = %d \n", n);
}
```

такое поведение не всегда желательно. нередко требуется гарантировать, что параметр сохраняет своё значение на протяжении всей работы функции. для этого параметр объявляется константным с помощью ключевого слова **const**:

```c
void change(const int n)
{
    //n = n * 2;	// теперь параметр n нельзя изменить
    int m = n * 2;
    printf("n = %d \n", n);
    printf("m = %d \n", m);
}
```

попытка изменить значение константного параметра приводит к ошибке компиляции. если нужны промежуточные вычисления, используется дополнительная переменная. квалификатор const у параметра, передаваемого по значению, касается только реализации функции и не влияет на её тип: прототипы `void change(int)` и `void change(const int)` совместимы, поэтому в объявлениях его обычно опускают.
