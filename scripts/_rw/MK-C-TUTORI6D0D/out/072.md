заголовочный файл **string.h** объявляет функции для работы со строками, то есть с массивами char, завершёнными нулевым символом. ниже рассматриваются наиболее употребительные из них.



### длина строки. strlen



функция **strlen()** возвращает количество символов строки без учёта завершающего нулевого байта. её описание:



```c


sizet_t strlen (const char* str);
```



параметром служит строка, длину которой требуется найти. результат имеет тип `size_t`: беззнаковый целочисленный тип, предназначенный специально для представления размеров объектов и являющийся типом результата оператора sizeof. поскольку в c строка не хранит свою длину, strlen просматривает символы до первого нулевого байта, и её сложность линейна, O(n), в отличие от языков, где длина является полем строкового объекта.



пример вычисления длины строки:



```c


#include <stdio.h>

#include <string.h>



int main(void)

{

	const char str[] = "Hello";

 	size_t length = strlen(str);

 	printf("String length: %zu \n", length);	// String length: 5

	return 0;

}
```



для вывода на консоль значения типа `size_t` применяется спецификатор `%zu`, введённый в c99.



### сравнение строк. strcmp



для сравнения строк применяется функция **strcmp()** со следующим прототипом:



```c
int strcmp (const char* str1, const char* str2);
```



функция принимает две строки и сравнивает их посимвольно, при этом символы интерпретируются как unsigned char. результатом является целое число:





- если строки равны, возвращается 0

- если первый несовпадающий символ первой строки в лексикографическом порядке предшествует символу второй строки, возвращается число меньше 0

- если первый несовпадающий символ первой строки в лексикографическом порядке следует за символом второй строки, возвращается число больше 0



стандарт гарантирует только знак результата, конкретная величина зависит от реализации, поэтому сравнивать результат следует с нулём, а не с 1 или -1. сравнение указателей через `==` проверяет идентичность адресов, а не равенство содержимого, поэтому для строк нужна именно strcmp.



пример сравнения двух строк:



```c


#include <stdio.h>

#include <string.h>



int main(void)

{

	const char *str1 = "Hello";

	const char *str2 = "Hello";

	int result = strcmp(str1, str2);

	if (result == 0)

 	{

 		printf("Strings are equal \n");

 	}

 	else

 	{

 		printf("Strings are not equal \n");

 	}

	return 0;

}
```



### объединение строк. strcat



функция **strcat** выполняет конкатенацию двух строк. её прототип:



```c


char *strcat(char *destination_str, const char *source_str);
```



функция дописывает строку `source_str` в конец строки `destination_str`, начиная с позиции её нулевого байта, и возвращает `destination_str`. массив первой строки должен быть достаточно велик, чтобы вместить результат вместе с завершающим нулевым символом; функция этого не проверяет, и выход за границу массива является неопределённым поведением:



```c


#include <stdio.h>

#include <string.h>



int main(void)

{

	char destination[30] = "Hello ";

 	char source[30] = "enoobis.ru";

 	strcat(destination, source);

 	printf("%s\n", destination);	// Hello enoobis.ru

	return 0;

}
```



### копирование строк. strcpy



функция **strcpy** копирует символы одной строки в другую. её прототип:



```c


char *strcpy(char *destination_str, const char *source_str);
```



функция копирует символы из строки `source_str` в `destination_str` вместе с завершающим нулевым байтом. массив назначения должен иметь достаточную длину, чтобы вместить копируемую строку. если области памяти источника и назначения перекрываются, поведение не определено.



пример копирования одной строки в другую:



```c


#include <stdio.h>

#include <string.h>



int main(void)

{

	char destination[20];

 	char source[20] = "Hello enoobis.ru!";

 	strcpy(destination, source);

 	printf("%s\n", destination);	// Hello enoobis.ru

	return 0;

}
```



strcpy копирует символы из source в destination, пока не встретит нулевой байт \0, и ничего не знает о размере приёмника. это потенциальный источник переполнения буфера, одной из классических уязвимостей программ на c. для ограничения копирования существует функция **strncpy**, которая третьим параметром принимает максимальное количество копируемых символов:



```c


#include <stdio.h>

#include <string.h>

 

int main(void)

{

    char destination[20];

    char source[20] = "Hello enoobis.ru!!";

	int n = 20; 	// количество копируемых символов

    strncpy(destination, source, 20);

	destination[n-1] = '\0';

    printf("%s\n", destination);    // Hello enoobis.ru

    return 0;

}
```



у **strncpy** есть другая проблема: если длина исходной строки не меньше n, скопированная строка не завершается нулевым байтом, и последующая работа с ней как со строкой снова может привести к выходу за границы буфера. если же исходная строка короче, оставшиеся позиции заполняются нулями. поэтому после копирования нулевой байт следует устанавливать вручную:



```c
destination[n-1] = '\0';
```



кроме того, можно использовать функцию **strncpy_s**, которая считается более безопасной:



```c


errno_t strncpy_s(char * destination, size_t destmax, const char * source, size_t srcmax);
```



эта функция принимает дополнительные параметры: `destmax`, размер буфера destination, то есть максимальное количество символов, которое в него можно записать, и `srcmax`, максимальное количество символов, копируемых из строки source. результат всегда завершается нулевым байтом, а при нарушении ограничений функция возвращает ненулевой код ошибки типа errno_t. strncpy_s относится к необязательному приложению k стандарта c11 (bounds-checking interfaces) и реализована главным образом в библиотеке microsoft visual c++; glibc её не поддерживает, о наличии сообщает макрос `__STDC_LIB_EXT1__`:



```c


#include <stdio.h>

#include <string.h>

 

int main(void)

{

    char destination[20];

    char source[] = "Hello enoobis.ru!";

	int n = 20; 	// количество копируемых символов

    strncpy_s(destination, n, source, n); 

    printf("%s\n", destination);    // Hello enoobis.ru

    return 0;

}
```



### поиск подстроки в строке. strstr



функция **strstr** ищет в строке заданную подстроку. её прототип:



```c
char *strstr(const char* string, const char* substring);
```



функция ищет подстроку `substring` в строке `string` и возвращает указатель на первый символ её первого вхождения, то есть адрес подстроки внутри исходной строки, либо NULL, если вхождение не найдено. разность этого указателя и адреса начала строки даёт индекс подстроки; результат вычитания указателей имеет тип ptrdiff_t:



```c


#include <stdio.h>

#include <string.h>



int main(void)

{

 	char text[20] = "Hello enoobis.ru!";

	char substring[14] = "enoobis.ru";

	char *substring_ptr = strstr(text, substring);

	// если подстрока найдена

	if(substring_ptr)

	{

		// вычисляем позицию подстроки в строке

		long position = substring_ptr - text;

		printf("Substring index: %ld\n", position);		// Substring index: 6

	}

	else	// если подстрока не найдена

	{

		printf("Substring not found\n");

	}

	return 0;

}
```
