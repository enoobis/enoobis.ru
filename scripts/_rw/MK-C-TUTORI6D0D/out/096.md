язык программирования python располагает обширной функциональностью и библиотеками, реализация которых на c заняла бы значительное время; особенно это касается машинного обучения. поэтому естественно желание взять готовую функциональность на python и включить её в программу на c. python предоставляет для этого механизм **Embedded Python** (встраиваемый python): в программу на c встраивается интерпретатор python, и программа выполняет код на python. по отношению к расширению python модулями на c (extending) это обратная схема: управление находится у программы на c, а интерпретатор выступает библиотекой, которую она вызывает через c api cpython. рассмотрим, как это сделать.

### настройка и компиляция в windows

для работы в windows прежде всего нужно знать путь к установленному интерпретатору python, например `C:\Users\eugen\AppData\Local\Programs\Python\Python311`. для упрощения работы зададим в переменных среды переменную **PYTHONHOME**, указывающую на каталог, где установлен python. эта переменная используется интерпретатором для поиска стандартных библиотек:

![настройка pythonhome для embedded python](/uploads/course-lectures/43788ecc7bac41080ba711ed20d8bd785293f83b.png)

определим файл **app.c** со следующей программой на c:

```c
#include <Python.h>

int main()
{
    Py_Initialize();
    PyRun_SimpleString("print('Hello enoobis.ru')");
    Py_Finalize();
    return 0;
}
```

чтобы встроить python в программу, прежде всего подключается заголовочный файл **Python.h**. он по умолчанию устанавливается вместе с остальными файлами интерпретатора python и находится в папке интерпретатора в каталоге `include`. документация python рекомендует подключать `Python.h` раньше любых стандартных заголовков, поскольку он может определять макросы, влияющие на их поведение.

![python.h в программе на языке c](/uploads/course-lectures/f82762179242a775a7fa924186306a8b89484ff5.png)

в программе сначала вызывается функция **Py_Initialize()**. она инициализирует интерпретатор python, таблицу модулей и пути поиска модулей. до её вызова большинство функций c api использовать нельзя.

для выполнения кода python применяется функция **PyRun_SimpleString()**, которой передаётся исходный код python в виде строки

```c
PyRun_SimpleString("print('Hello enoobis.ru')");
```

код python здесь выводит строку на консоль с помощью функции `print()`. функция выполняет код в пространстве имён модуля `__main__` и возвращает 0 при успехе или -1, если возникло исключение; сведения об исключении при этом печатаются, а сам объект исключения программе на c недоступен.

после выполнения кода python вызывается функция **Py_Finalize()**, которая завершает работу интерпретатора и освобождает выделенную для него память.

для компиляции в windows используется компилятор `gcc`. выполним команду

```bash
gcc -Wall -I %PYTHONHOME%\include -L %PYTHONHOME%\libs -o app.exe app.c -lpython311 & app
```

опцией **-I** компилятору передаётся путь к заголовочным файлам, то есть папка `%PYTHONHOME%\include`. чтобы не писать полный путь, его часть заменяется значением ранее заданной переменной `PYTHONHOME`

опцией **-L** указывается путь к библиотеке python, то есть `%PYTHONHOME%\libs`

поскольку в примере используется python 3.11, указывается параметр `-lpython311`. имя библиотеки отражает версию интерпретатора, поэтому для другой версии параметр меняется соответственно. во время выполнения программе также требуется динамическая библиотека `python311.dll`, которая должна находиться в одном из каталогов поиска dll.

при выполнении программы будет выполнен код python, который выведет на консоль строку:

```bash
c:\C>gcc -Wall -I %PYTHONHOME%\include -L %PYTHONHOME%\libs -o app app.c -lpython311 & app
Hello enoobis.ru

c:\C>
```

наряду с вызовами python программа может содержать и любые другие инструкции на c:

```c
#include <stdio.h>
#include <Python.h>

int main()
{
    printf("Python program starts\n");
    Py_Initialize();
    PyRun_SimpleString("print('Hello enoobis.ru')");
    Py_Finalize();
    printf("Python program ends\n");
    return 0;
}
```

### компиляция в linux

в linux компиляция выполняется несколько иначе. в ubuntu применяется следующая команда:

```bash
gcc -Wall $(python3-config --cflags) -o app app.c $(python3-config --embed --ldflags)
```

утилита `python3-config` выводит флаги компиляции и компоновки для установленной версии python. флаг `--embed` (начиная с python 3.8) добавляет к флагам компоновки саму библиотеку `libpython`, которая нужна именно при встраивании, а не при сборке модулей расширения.

### использование библиотек python

аналогично выполняется и более сложный код python, в том числе использующий сторонние библиотеки. построим, например, график с помощью библиотек `numpy` и `matplotlib`. сначала эти библиотеки нужно установить пакетным менеджером pip:

```bash
pip install numpy
pip install matplotlib
```

библиотеки должны быть установлены именно для того интерпретатора, который встраивается в программу. для построения графика определим на c следующую программу:

```c
#include <Python.h>
int main()
{
    Py_Initialize();
    PyRun_SimpleString(
"import numpy as np\n"
"import matplotlib.pyplot as plt\n"
"x = np.array(range(0, 8))\n"
"y = eval('2 * x + 1')\n"
"plt.title('y = 2x + 1')\n"
"plt.xlabel('x')\n"
"plt.ylabel('y')\n"
"plt.plot(x,y)\n"
"plt.show()");
    Py_Finalize();
    return 0;
}
```

код python записан как последовательность соседних строковых литералов c, которые компилятор склеивает в одну строку; символы `\n` разделяют инструкции python. сначала подключается функциональность библиотек `numpy` и `matplotlib`.

```python
import numpy as np
import matplotlib.pyplot as plt
```

далее формируются значения, откладываемые по оси x:

```python
x = np.array(range(0, 8))
```

для этого применяется функция `np.array()` библиотеки numpy, которая создаёт из диапазона массив чисел от 0 до 7.

затем по значениям x вычисляются значения y по заданной формуле. строится график функции `y = 2x + 1`. для вычисления значений y применяется встроенная функция python `eval()`, вычисляющая произвольное выражение. поскольку `x` является массивом numpy, арифметические операции в выражении выполняются поэлементно (векторизованно).

```python
y = eval('2 * x + 1')
```

затем задаётся заголовок графика

```python
plt.title('y = 2x + 1')
```

задаются текстовые метки осей x и y:

```python
plt.xlabel('x')
plt.ylabel('y')
```

в конце график строится и отображается на экране:

```python
plt.plot(x,y)
plt.show()
```

### выполнение файла с кодом python

если инструкций на python много, их удобнее вынести в отдельный файл. в программе на c этот файл выполняется функцией **PyRun_SimpleFile()**, которая имеет следующее определение:

```c
int PyRun_SimpleFile(FILE *fp, const char *filename)
```

первым параметром передаётся указатель на открытый файл, вторым имя файла.

например, определим в одной папке с программой файл **main.py** со следующим кодом на python:

```python
print("Hello Python in C")
```

этот код просто выводит строку на консоль.

в главном файле программы на c (пусть он называется **app.c**) выполним этот скрипт python:

```c
#include <Python.h>

int main()
{
    char filename[] = "main.py";
    Py_Initialize();
    FILE* fp = fopen(filename, "rb");	// открываем файл и 
	if(fp)
    	PyRun_SimpleFile(fp, filename);		// выполняем программу python
    Py_Finalize();
    return 0;
}
```

здесь файл сначала открывается функцией `fopen()` в двоичном режиме для чтения, и программа получает указатель на файл, после чего выполняется содержащийся в нём код python. функция `PyRun_SimpleFile()` не закрывает файл, поэтому в аккуратной реализации его следует закрыть вызовом `fclose()`. в windows передача `FILE*` в библиотеку python работает корректно лишь при условии, что программа и python используют одну и ту же библиотеку времени выполнения c. в итоге на консоль будет выведено

```bash
Hello Python in C
```
