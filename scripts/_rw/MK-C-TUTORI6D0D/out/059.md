в предыдущих темах рассматривалось выделение и освобождение динамической памяти под массивы. при выделении памяти функциями **malloc()/calloc()/realloc()** получается указатель на выделенный блок. этот блок можно использовать везде, где доступен указатель. время жизни объекта в куче (allocated storage duration) не совпадает со временем жизни самого указателя: указатель может исчезнуть раньше объекта, тогда блок утечёт, либо объект освободят раньше указателя, тогда указатель станет висячим.

указатель имеет те же области видимости, что и обычные переменные. область видимости задаёт не только контекст, в котором указатель можно использовать, но и момент, когда необходимо освобождать выделенную динамическую память. в зависимости от области видимости указателя возможны три варианта:

- указатель определён в блоке кода. в этом случае указатель доступен только в пределах данного блока. память необходимо освобождать при выходе из этого блока, иначе адрес будет потерян.

- указатель определён как статический объект. в этом случае динамическая память выделяется один раз и доступна через указатель при каждом повторном входе в блок. память освобождают только после завершения её использования.

- указатель является глобальным объектом по отношению к блоку. динамическая память доступна во всех блоках, где доступен указатель, а освобождают её только после завершения использования.

### указатель как локальный объект

первый вариант: указатель определён в функции. переменная указателя имеет автоматическую продолжительность хранения и уничтожается при выходе из функции; блок в куче при этом сам не освобождается.

```c
#include <stdio.h>
#include <stdlib.h>
 
void createPointer()
{
    int *p = malloc(sizeof(int));
    if(!p) return;  // если выделение памяти прошло неудачно, выходим из функции

    *p = 1;
    printf("%d \n", (*p));
    free(p);    // конец блока - освобождаем память
}
 
int main(void)
{
    createPointer();
    createPointer();
    createPointer();
    return 0;
}
```

для демонстрации указатель **p** указывает на блок выделенной динамической памяти размером 4 байта, то есть на один элемент типа **int**. переменная указателя определена в автоматической памяти как локальная переменная функции createPointer, поэтому выделенная динамическая память доступна только в рамках этой функции. в конце выполнения функции память освобождают вызовом `free()`. проверка `if(!p) return;` обязательна: разыменование нулевого указателя даёт неопределённое поведение.

при каждом новом вызове createPointer из main динамическая память выделяется заново. три вызова соответствуют трём независимым парам malloc/free.

то же относится к вложенным блокам:

```c
#include <stdio.h>
#include <stdlib.h>

void createPointer()
{
    printf("Code block starts\n");
    {
        int* p = malloc(sizeof(int));
        if (!p) return;  // если выделение памяти прошло неудачно, выходим из функции
        *p = 1;
        printf("%d \n", (*p));
        free(p);    // конец блока - освобождаем память
    }
    printf("Code block ends\n");
}

int main(void)
{
    createPointer();
    return 0;
}
```

указатель определяется во вложенном безымянном блоке; до конца этого блока память должна быть освобождена. после закрывающей скобки блока имя p вне области видимости, обратиться к блоку уже нельзя. `return` из вложенного блока всё равно выходит из функции, а не только из блока: при неуспехе malloc последующий вывод `Code block ends` не выполняется.

### указатель как статический объект

второй вариант: указатель определён как статический объект. спецификатор `static` у локальной переменной даёт статическую продолжительность хранения: объект существует всё время выполнения программы, инициализация `NULL` выполняется один раз.

```c
#include <stdio.h>
#include <stdlib.h>

int * createPointer()
{
	static int *p = NULL;
	if(p==NULL)
	{
		p = malloc(sizeof(int));
		*p = 1;
	}
	printf("%d \n", (*p));
	(*p)++;
	return p;
}

int main(void)
{
	int *ptr;
	ptr=createPointer();
	ptr=createPointer();
	ptr=createPointer();
	free(ptr);
	return 0;
}
```

выделенная динамическая память после выхода из createPointer сохраняется, повторно выделять её незачем. указатель **p** изначально имеет значение NULL; проверка на это значение решает, нужно ли вызывать malloc. после успешного выделения тот же указатель и тот же блок используются при следующих входах в функцию, поэтому счётчик `*p` растёт. если malloc вернул NULL, последующее `*p` остаётся неопределённым поведением: перед разыменованием нужна отдельная проверка.

статический указатель перестаёт быть нужен в конце работы программы. при вызове createPointer указатель сохраняют в переменную ptr, и в конце функции main выделенную память освобождают через free. все три вызова возвращают один и тот же адрес, поэтому достаточно одного `free(ptr)`.

консольный вывод:

```consoletext
1
2
3
```

### указатель как глобальный объект

третий вариант: указатель является глобальным объектом (область видимости файла, статическая продолжительность хранения). любой функции единицы трансляции доступен один и тот же указатель.

```c
#include <stdio.h>
#include <stdlib.h>

int* p = NULL; // глобальный объект

void createPointer()
{
	printf("%d \n", (*p));
	(*p)++;
}

int main(void)
{
	p = malloc(sizeof(int));
	*p = 1;

	createPointer();
	createPointer();
	createPointer();

	free(p);
	return 0;
}
```

указатель определён как глобальный объект, поэтому динамическую память освобождают, когда она больше не нужна. функция **free()** вызывается ближе к концу функции **main**. createPointer память не выделяет и не освобождает: она только использует уже установленный указатель. после `free(p)` глобальный p по-прежнему хранит прежний адрес; безопаснее обнулить его, если дальнейшие вызовы ещё возможны.
