структура в языке программирования c представляет собой составной тип данных, который состоит из других компонентов. в отличие от массива эти компоненты могут представлять различные типы данных. элементы структуры (члены, members) размещаются в объекте последовательно, с возможным выравниванием и промежутками (padding), задаваемыми реализацией.

### объявление и определение структуры

перед тем как использовать структуру, её надо объявить. для определения структуры применяется ключевое слово **struct**. есть два типа объявления структуры. в первом случае после ключевого слова **struct** идёт имя структуры (тег, tag):

```c


struct имя_структуры;
```

имя_структуры представляет произвольный идентификатор, к которому применяются те же правила, что и при наименовании переменных. например:

```c


struct person;



int main(void) {



    return 0;

}
```

в примере объявлена структура person. однако это **объявление** без **определения**. с такой структурой сложно что-то сделать, и она представляет **неполный тип** (incomplete type), поскольку неизвестен размер, который занимает эта структура. неполный тип нельзя инстанцировать как объект, нельзя вычислить sizeof и нельзя обратиться к полям: компилятор ещё не знает раскладку.

второй тип объявления структуры, с определением, выглядит следующим образом:

```c


struct имя_структуры

{

	компоненты_структуры

};
```

после имени структуры в фигурных скобках помещаются компоненты структуры: объекты, которые составляют структуру. в отличие от функции при определении структуры после закрывающей фигурной скобки идёт точка с запятой. точка с запятой завершает объявление типа, а не составную инструкцию.

например, определим простейшую структуру:

```c


struct person

{

	char* name;

	int age;

};
```

здесь определена структура `person`, которая имеет два элемента: `age` (представляет тип `int`) и `name` (представляет указатель на тип `char`). имя `person` принадлежит пространству тегов языка c, отдельно от пространства обычных идентификаторов: само по себе слово `person` ещё не является именем типа.

все элементы структуры объявляются как обычные переменные. но в отличие от переменных при определении элементов структуры для них не выделяется память, и их нельзя инициализировать. по сути определяется новый тип данных: схема раскладки, а не объект.

можно объявить структуру с одним и тем же именем несколько раз, но нельзя определить структуру более одного раза. повторное определение с тем же тегом в одной области видимости есть ошибка.

```c


#include <stdio.h>



struct person;

struct person {

    char * name;

    int age;

};

struct person;

struct person;



int main(void){



    return 0;

}
```

в примере выше все объявления структуры person будут относиться к одной и той же структуре: несколько forward-объявлений допустимы, полное определение одно.

### использование структуры

после определения структуры её можно использовать. для начала определяется объект структуры, по сути обычная переменная, которая будет представлять выше созданный тип:

```c


// определение структуры person

struct person

{

    char * name;

    int age;

};



int main(void)

{

    // определение переменной, которая представляет структуру person

    struct person tom;

}
```

здесь определена переменная tom, которая представляет структуру `person`. при каждом определении переменной типа структуры ей выделяется память, необходимая для хранения её элементов, с учётом выравнивания. размер объекта равен `sizeof(struct person)` и в общем случае не меньше суммы размеров полей.

#### инициализация структуры

при определении переменной структуры её можно сразу инициализировать, присвоив какое-нибудь значение. инициализация структур аналогична инициализации массивов: в фигурных скобках передаются значения для элементов структуры. есть два способа инициализации структуры.

- по позиции : значения передаются элементам структуры в том порядке, в котором они следуют в структуре: так как в структуре person первым определено поле `name`, которое представляет указатель на тип `char` или строку, соответственно вначале идёт строка. вторым идёт поле age, которое представляет тип int, число, то в фигурных скобках после строки идёт число, которое передаётся элементу `age`. и так далее для всех элементов структуры по порядку.

```c
struct person tom = {"Tom", 23};
```

- по имени : значения передаются элементам структуры по имени, независимо от порядка. в этом случае перед именем элемента указывается точка, например, `.name`. такая форма (designated initializer) входит в стандарт с c99 и не зависит от перестановки полей в определении типа.

```c
struct person tom = {.name="Tom", .age=23};
```

#### обращение к элементам структуры

также после создания переменной структуры можно обращаться к её элементам: получать их значения или, наоборот, присваивать им новые значения. для обращения к элементам структуры используется операция «точка»:

```c
имя_переменной_структуры.имя_элемента
```

операция `.` выбирает lvalue поля из объекта структуры. теперь объединим всё вместе в рамках программы:

```c


#include <stdio.h>



struct person

{

	char * name;

	int age;

};



int main(void)

{

	struct person tom = {"Tom", 23};

	printf("Age: %d \t Name: %s", tom.age, tom.name);

	return 0;

}
```

консольный вывод программы:

```bash


Age: 23 	 Name: Tom
```

можно инициализировать элементы структуры по отдельности. до первого присваивания поля автоматического объекта содержат неопределённые значения, как и неинициализированные локальные переменные тех же типов:

```c


#include <stdio.h>

 

struct person

{

    char * name;

    int age;

};

 

int main(void)

{

    struct person tom;

    tom.name ="Tom";

    tom.age = 22;

    printf("Name:%s \t Age: %d\n", tom.name, tom.age);

    return 0;

}
```

#### объявление, определение и использование

полноценно использовать структуру (обращаться к её полям) можно в основном после её определения. важно зафиксировать, как влияет определение структуры на её использование. например:

```c


#include <stdio.h>



struct person; // структура объявлена, но НЕ определена, она пока представляет неполный тип



// структура определена, мы ее можем полноценно использовать

struct person {

    char * name;

    int age;

};



int main(void){



    struct person tom = {"Tom", 22};

    printf("Name: %s  Age: %d\n", tom.name, tom.age);



    return 0;

}
```

здесь сначала объявляется структура без определения:

```c


struct person;
```

и лишь затем определяется:

```c


struct person {

    char * name;

    int age;

};
```

после этого в функции main можно создавать её переменные, обращаться к её полям:

```c


struct person tom = {"Tom", 22};

printf("Name: %s  Age: %d\n", tom.name, tom.age);
```

но рассмотрим другую ситуацию:

```c


#include <stdio.h>



struct person; // структура объявлена, но НЕ определена, она пока представляет неполный тип



int main(void){



    // в этой точке структура person объявлена, но НЕ определена. Мы не можем определять ее переменные, обращаться к полям

    // error: variable ‘tom’ has initializer but incomplete type

    // struct person tom = {"Tom", 22};

    // printf("Name: %s  Age: %d\n", tom.name, tom.age);



    return 0;

}

// структура определена, мы ее можем полноценно использовать

struct person {

    char* name;

    int age;

};
```

здесь структура person определена уже после функции main, и до своего определения она представляет неполный тип: компилятор не знает его размера и никаких полей в нём, соответственно полноценно использовать её нельзя. единственным сценарием использования неполного типа (в том числе и неопределённой структуры) является определение указателя на этот тип:

```c


#include <stdio.h>



struct person; // структура объявлена, но НЕ определена, она пока представляет неполный тип



int main(void){



    struct person* tom;  // указатель на структуру person



    return 0;

}

// структура определена, мы ее можем полноценно использовать

struct person {

    char* name;

    int age;

};
```

здесь переменная tom представляет именно указатель на структуру person. подробнее указатели на структуры рассматриваются далее, но в любом случае это единственная возможность использования неполного типа, поскольку указатель есть полный тип: его размер компилятору известен и на 64-разрядных системах составляет 8 байт. указатель на неполный тип достаточен для объявления, передачи и хранения адреса; разыменование и арифметика указателей требуют уже полного типа.

### объединение определения структуры и её переменных.

можно одновременно совмещать определение типа структуры и её переменных:

```c


#include <stdio.h>



struct person

{

	char * name;

	int age;

} tom;		// определение структуры и ее переменной



int main(void)

{

	tom.age = 38;

    tom.name = "Tom";

	printf("Name:%s \t Age: %d\n", tom.name, tom.age);

	return 0;

}
```

после определения структуры, но до точки с запятой, можно указать переменные этой структуры. а затем присвоить полям структуры значения. такие переменные имеют ту же область видимости, что и определение типа: здесь tom глобальна.

можно тут же инициализировать структуру:

```c


#include <stdio.h>

 

struct person

{

    char * name;

    int age;

} tom = {38, "Tom"};

 

int main(void)

{

    printf("Name:%s \t Age: %d\n", tom.name, tom.age);

    return 0;

}
```

позиционная инициализация следует порядку объявления полей (`name`, затем `age`). запись `{38, "Tom"}` в этом примере не согласована с этим порядком: корректная позиционная форма для данной раскладки имела бы вид `{"Tom", 38}`.

можно определить сразу несколько переменных:

```c


struct person

{

    char * name;

    int age;

} tom, bob, alice;
```

при подобном определении можно даже не указывать имя структуры:

```c


struct

{

	char * name;

	int age;

} tom;
```

в этом случае компилятор всё равно будет знать, что переменная tom представляет структуру с двумя элементами name и age. и соответственно с этими переменными также можно работать. другое дело, что нельзя задать новые переменные этой структуры в других местах программы: у типа нет тега, и сослаться на него повторно нельзя. все объекты этого безымянного типа должны быть перечислены в том же объявлении.

### typedef

ещё один способ определения структуры представляет ключевое слово **typedef**:

```c


#include <stdio.h>



typedef struct

{

	char* name;

	int age;

} person;



int main(void)

{

	person tom = {"Tom", 23};

	printf("Name:%s \t Age: %d\n", tom.name, tom.age);

	return 0;

}
```

в конце определения структуры после закрывающей фигурной скобки идёт её обозначение, здесь `person`. в дальнейшем это обозначение можно использовать для создания переменной структуры. при этом в отличие от примеров выше при определении переменной не надо использовать слово **struct**. `typedef` вводит синоним в пространство обычных имён, поэтому `person` становится именем типа, как int или char.

### директива define

ещё один способ определить структуру представляет применение препроцессорной директивы **#define**:

```c


#include <stdio.h>



#define PERSON struct {int age;	char name[20];}



int main(void)

{

	PERSON tom = {23, "Tom"};

	printf("Name:%s \t Age: %d\n", tom.name, tom.age);

	return 0;

}
```

директива define определяет константу PERSON, вместо которой при обработке исходного кода препроцессором будет вставляться код структуры `struct {int age; char name[20];}`. это чисто текстуальная подстановка, без нового имени типа в смысле языка: каждый раз раскрывается безымянная структура, и совместимость таких раскрытий между собой не гарантируется так, как у одного тега или typedef.

### область действия структуры

как и функции и переменные, структуры имеют область видимости и видны только в той области, в которой они объявлены. если структура объявлена вне функций на уровне файла, то она видна с точки, где она объявлена, до конца файла.

```c


#include <stdio.h>

 

struct person

{

    char * name;

    int age;

};



void print_person(){

    struct person bob = {"Bob", 33};

    printf("Name: %s   Age: %d\n", bob.name, bob.age);

}

int main(void)

{

    struct person tom = {"Tom", 22};

    printf("Name: %s  Age: %d\n", tom.name, tom.age);

    print_person();

    return 0;

}
```

структура person объявлена вне какой-либо функции и видна в любом месте файла после объявления. для демонстрации в примере выше её используют в функции main и функции print_person (и вообще любой другой функции, которая идёт после объявления структуры).

если структура объявлена в блоке кода, то соответственно она видна до конца этого блока.

```c


#include <stdio.h>



// здесь нельзя использовать структуру person, так как она определена в функции main

void print_person(){

    //struct person bob = {"Bob", 33};

    // printf("Name: %s   Age: %d\n", bob.name, bob.age);

}

// структура person видна только в функции main с момента своего определения

int main(void)

{

    struct person {

        char * name;

        int age;

    };

    struct person tom = {"Tom", 22};

    printf("Name: %s  Age: %d\n", tom.name, tom.age);

    return 0;

}
```

причём в качестве области видимости может выступать любой блок кода, необязательно функция. например, анонимный блок кода:

```c


#include <stdio.h>



int main(void){



    // вне этого блока кода структура person не видна

    {

        struct person {

            char * name;

            int age;

        };

        struct person tom = {"Tom", 22};

        printf("Name: %s  Age: %d\n", tom.name, tom.age);

    }

    // здесь структура person уже не видна

    //struct person bob = {"Bob", 33};

    //printf("Name: %s   Age: %d\n", bob.name, bob.age);



    return 0;

}
```

здесь структура person объявлена внутри блока кода, соответственно вне этого блока её использовать нельзя. область видимости тега ограничена блоком так же, как область видимости локальной переменной.

если одна и та же структура объявлена в двух разных областях, то одна структура скрывает ранее объявленную:

```c


#include <stdio.h>



// структура уровня файла

struct number {

    int x;

};



int main(void){



    // структура уровня функции - она скрывает структуру number уровня файла

    struct number {

        long y;

    };

    struct number n1 = {22};

    printf("n1: %ld\n", n1.y);



    return 0;

}
```

здесь структура `struct number { long y;}` скрывает структуру `struct number { int x;}`. поэтому внутри функции main обращение к структуре number будет представлять именно структуру `struct number { long y;}`. имена тегов подчиняются обычным правилам сокрытия (name hiding) вложенных областей видимости.

но даже если внешняя структура из окружающей области видимости скрывается, её поля по-прежнему видны:

```c


#include <stdio.h>



// структура уровня файла

struct number {

    int x;

};



struct number external = {5};



int main(void){



    // структура уровня функции - она скрывает структуру number уровня файла

    struct number {

        long y;

    };

    struct number internal = {22};



    printf("external: %d\n", external.x);  // external: 5

    printf("internal: %ld\n", internal.y);    // internal: 22



    return 0;

}
```

здесь сначала объявляется структура number уровня файла. затем определяется переменная external этого типа. в функции main объявляется другой тип структуры с тем же именем, который скрывает внешнее объявление. затем объявляется переменная internal с этим новым типом. в функции main по-прежнему можно получить доступ к полям обеих переменных. даже внутри функции main компилятор знает о внешней структуре number, и он также знает, что переменная external принадлежит этому типу: тип объекта фиксируется в точке его определения и не меняется из-за последующего сокрытия тега.

### копирование структур

одну структуру можно присваивать другой структуре того же типа. при копировании элементы структуры получают копии значений:

```c


#include <stdio.h>

 

struct person

{

    char * name;

    int age;

};

 

int main(void)

{

    struct person tom = {"Tom", 38};

    // копируем значения из структуры tom в структуру bob

    struct person bob = tom;

    bob.name = "Bob";

    printf("Name: %s \t Age: %d \n", bob.name, bob.age);

    printf("Name: %s \t Age: %d \n", tom.name, tom.age);

    return 0;

}
```

в переменную `bob` копируются данные из структуры `tom`. далее для структуры `bob` меняется значение поля `name`. в итоге получится следующий консольный вывод:

```bash


Name: Bob         Age: 38

Name: Tom         Age: 38
```

копирование поэлементное и поверхностное: для поля-указателя копируется сам указатель, а не объект, на который он ссылается. после `bob.name = "Bob"` указатели `tom.name` и `bob.name` адресуют разные строковые литералы, поэтому `tom` не меняется. если бы оба указывали на один буфер, изменение через один объект затронуло бы и другой.

### ввод с консоли данных для структуры

с элементами структуры можно производить все те же операции, что и с переменными тех же типов. например, добавим ввод с консоли:

```c


#include <stdio.h>



struct person

{

	int age;

	char name[20];

};

int main(void)

{

	struct person tom = {23, "Tom"};

	printf("Enter name: ");

	scanf("%s", tom.name);

	printf("Enter age: ");

	scanf("%d", &tom.age);

	printf("Name:%s \t Age: %d\n", tom.name, tom.age);

	return 0;

}
```

для массива `tom.name` оператору `scanf` передаётся само имя массива, оно преобразуется к указателю на первый элемент. для `tom.age` нужен адрес скалярного объекта, поэтому пишется `&tom.age`.

консольный вывод программы:

