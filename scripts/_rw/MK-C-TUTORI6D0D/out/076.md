в программах часто требуется преобразовать число в строку или строку в число. для этого в стандартной библиотеке c определены, в частности, функции **strtol()** и **snprintf()**.

### из строки в число. strtol

функция **strtol()** преобразует строку в число типа `long int`. функция объявлена в заголовочном файле `stdlib.h` и имеет следующий прототип:

```c
long strtol(const char *restrict str, char **restrict str_end, int base);
```

параметры функции

- `str`: строка с числом, которое требуется преобразовать в числовой тип. квалификатор restrict, введённый в c99, сообщает компилятору, что в пределах функции к объекту обращаются только через данный указатель и никакой другой параметр не указывает на ту же память; это разрешает компилятору более агрессивную оптимизацию.

- `str_end`: указатель, в который записывается адрес первого символа, следующего за разобранным числом. параметр можно игнорировать, передавая значение `NULL`

- `base`: основание системы счисления, в которой записано число в строке (значение от 2 до 36). при значении 0 основание определяется по префиксу: `0x` означает шестнадцатеричное число, ведущий `0` восьмеричное, иначе десятичное.

результатом функции является преобразованное число типа `long`. ведущие пробельные символы пропускаются. если преобразование невозможно, возвращается 0, а при выходе за диапазон long возвращается LONG_MAX или LONG_MIN и errno получает значение ERANGE. в отличие от устаревшей atoi, strtol позволяет отличить ошибку от корректного нуля.

например, преобразуем строку в число в десятичной системе:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
	const char * str = "24 flowers";
 	long result = strtol(str, NULL, 10);
 	printf("Result: %ld\n", result);	// Result: 24
	return 0;
}
```

в этом примере второй параметр не использовался: ему передавалось значение `NULL`, и функция работала корректно. однако он полезен, если требуется получить остаток строки после числа:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
	const char * str = "24 flowers";
	char* str_end;
 	long result = strtol(str, &str_end, 10);
 	printf("Result: %ld\n", result);				// Result: 24
	printf("Rest of the string:%s\n", str_end);		// Rest of the string: flowers
	return 0;
}
```

если str_end после вызова равен str, ни одной цифры разобрано не было; этим признаком проверяют, содержала ли строка число.

### из числа в строку. snprintf

функция **snprintf()** записывает форматированное представление значений, в частности чисел, в строку. функция объявлена в заголовочном файле `stdio.h`, введена в c99 и имеет следующий прототип:

```c
int snprintf(char *restrict str_buffer, size_t buffer_size, const char *restrict format, ... );
```

параметры функции

- `str_buffer`: строка, в которую помещается результат преобразования.

- `buffer_size`: размер буфера. функция записывает в строку не более `buffer-size - 1` символов и добавляет завершающий нулевой байт

- `format`: задаёт формат преобразования в строку.

функция возвращает количество символов (без завершающего нулевого байта), которое было бы записано при неограниченном размере буфера. если это значение не меньше buffer_size, результат был усечён. при ошибке кодирования возвращается отрицательное число. ограничение размера отличает snprintf от sprintf и исключает переполнение буфера.

пример преобразования:

```c
#include <stdio.h>

int main(void)
{
	int number = 354;
 	char str [10];
 	snprintf(str, sizeof str, "%d", number);
 	printf("Result: %s\n", str);		// Result: 354
	return 0;
}
```

строка форматирования может содержать несколько спецификаторов:

```c
#include <stdio.h>

int main(void)
{
	int count = 3;
	double price = 79.99;
 	char str [50];
 	snprintf(str, sizeof str, "Count: %d \tPrice: %.2f", count, price);
 	printf("%s\n", str);		// Count: 3        Price: 79.99
	return 0;
}
```
