условные конструкции направляют выполнение программы по одному из возможных путей в зависимости от значения условия. в языке c для этого предусмотрено несколько операторов.

### оператор if

оператор if проверяет истинность условия и, если оно истинно, выполняет следующую за ним инструкцию или блок инструкций. сокращённая форма оператора выглядит так:

```c
if (условие) инструкция;
```

условием может служить любое выражение скалярного типа, то есть арифметического типа или указатель. если его значение отлично от нуля (выражение истинно), выполняется последующая инструкция. в c нет требования, чтобы условие имело логический тип, как, например, в java или c#, и проверка сводится к сравнению значения с нулём:

```c


#include <stdio.h>



int main(void)

{

    if(1) printf("Hello C \n");

     

    if(0) printf("Hello World \n");

     

    return 0;

}
```

в этой программе две условные конструкции **if**. в обоих случаях инструкцией служит вызов функции printf, а условием является просто число. в первом случае «условие» равно 1, то есть истинно (истиной считается любое число, кроме 0), поэтому выполняется функция `printf`, которая выводит на консоль строку "Hello C".

во втором случае «условие» равно 0, то есть ложно, поэтому инструкция `printf("Hello World \n")` не выполняется.

в приведённом примере условиями служили числа 1 и 0. на практике условием обычно является результат некоторого выражения, как правило операции сравнения или логической операции. все такие выражения в конечном счёте дают либо 0 (условие ложно), либо ненулевое значение (условие истинно). пример с операциями сравнения:

```c


#include <stdio.h>



int main(void)

{

    int n = 10;



    if(n == 20) printf("n = 20 \n");

    if(n == 10) printf("n = 10 \n");

     

    return 0;

}
```

здесь также две условные конструкции if. в первой условие `n == 20` ложно и возвращает 0, поскольку значение переменной n не равно 20, поэтому инструкция `printf("n = 20 \n")` не выполняется.

во второй операция сравнения `n == 10` возвращает 1, условие истинно, и выполняется инструкция `printf("n = 10 \n")`.

если в конструкции if требуется выполнить не одну, а несколько инструкций, они объединяются в блок кода (составной оператор) с помощью фигурных скобок. синтаксически блок является одной инструкцией и одновременно задаёт собственную область видимости для объявленных в нём переменных:

```c


#include <stdio.h>



int main(void)

{

    int x = 60;

     

    if(x > 50) 

    {

        printf("if statement \n");

        printf("x is greater than 50 \n");

    }

    return 0;

}
```

здесь проверяется, больше ли значение переменной x, чем 50, и если условие истинно, выполняется следующий за ним блок из двух инструкций

условия могут быть и составными:

```c


#include <stdio.h>



int main(void)

{

    int x = 50;

    int y = 60;

    if (x > 20 && y < 100)

    {

        printf("the condition is true\n");

    }

    return 0;

}
```

здесь проверяется, больше ли значение переменной x, чем 20, и меньше ли значение переменной y, чем 100. два условия соединены операцией `&&`, поэтому общее условие истинно только тогда, когда одновременно выполняются оба условия.

### выражение else

часто требуется задать две альтернативные последовательности действий: одну для случая, когда условие истинно, другую для случая, когда оно ложно. для этого служит полная форма конструкции if, **if..else**:

```c


if(условие)

	инструкция_1

else

	инструкция_2
```

после оператора **else** указываются инструкции, которые выполняются, если выражение условия ложно, то есть возвращает 0. если условие истинно, выполняется инструкция после оператора **if**, если ложно, выполняется инструкция после оператора **else**. при вложенных конструкциях else всегда относится к ближайшему предшествующему if без собственной ветви else (так разрешается проблема «висячего else»), поэтому во вложенных условиях фигурные скобки делают структуру однозначной для читателя.

```c


int x = 60;

if(x > 60) 

	printf("x is greater than 60 \n");

else

	printf("x is less or equal 60 \n");
```

однако в этом примере возможны три исхода: переменная x может быть больше 60, меньше 60 или равна 60. для проверки альтернативных условий используются выражения **else if**. отдельного ключевого слова elseif в c нет: else if представляет собой ветвь else, инструкцией которой является очередной оператор if:

```c


int x = 60;

	

if(x > 60) 

	printf("x is greater than 60 \n");

else if (x < 60)

	printf("x is less than 60 \n");

else

	printf("x is equal 60 \n");
```

в результате программа получает три ветви выполнения.

если в какой-либо ветви должна выполняться последовательность инструкций, эти инструкции также оформляются в блок кода:

```c


#include <stdio.h>



int main(void)

{

    int x = 60;

     

    if(x > 60)

    {

        printf("if statement \n");

        printf("x is greater than 60 \n");

    }

    else if (x < 60)

    {

        printf("else if statement \n");

        printf("x is less than 60 \n");

    }

    else

    {

        printf("else statement \n");

        printf("x is equal 60 \n");

    }

    return 0;

}
```

### конструкция switch

другую форму организации ветвления представляет конструкция **switch...case**. она имеет следующий вид:

```c


switch(выражение)

{

	case константа_1: инструкции_1;

	case константа_2: инструкции_2;

	

	default: инструкции;

}
```

после ключевого слова **switch** в скобках указывается управляющее выражение. его значение сравнивается со значениями после операторов **case**, и при совпадении управление передаётся на соответствующую метку **case**. по семантике метки case являются метками перехода внутри тела switch, поэтому компилятор может реализовать конструкцию таблицей переходов, а не цепочкой сравнений.

управляющее выражение должно иметь целочисленный тип, а константы после оператора **case** должны быть целочисленными константными выражениями, известными во время компиляции, например значениями типов `char, int` и `unsigned`. повторяющиеся значения меток в одном switch недопустимы. пример проверки значения числа с помощью конструкции **switch**:

```c


#include <stdio.h>



int main(void)

{

	int x = 2;

	

	switch(x)

	{

		case 1: 

			printf("x = 1 \n");

			break;

		case 2: 

			printf("x = 2 \n");

			break;

		case 3: 

			printf("x = 3 \n");

			break;

	}

	return 0;

}
```

здесь управляющим выражением служит переменная `x`. её значение последовательно сравнивается со значениями после операторов `case`:

- сначала проверяется выражение `case 1` . переменная x не равна 1, поэтому выполнение переходит к следующему оператору case.

- затем проверяется выражение `case 2` . переменная x равна 2, поэтому выполняются инструкции этого оператора case. чтобы последующие блоки case не выполнялись, в конце каждого блока ставится оператор break . при его выполнении происходит выход из конструкции `switch..case`

```c


case 2: 

	printf("x = 2 \n");

	break;
```

в итоге консольный вывод будет следующим:

```bash
x = 2
```

при определении блоков case нельзя забывать про операторы **break**. ниже предыдущий пример переписан без операторов **break**:

```c


#include <stdio.h>

 

int main(void)

{

	int x = 2;

	

	switch(x)

	{

		case 1: 

			printf("x = 1 \n");

		case 2: 

			printf("x = 2 \n");

		case 3: 

			printf("x = 3 \n");

	}

	return 0;

}
```

поскольку x=2, выполняется блок инструкций после выражения `case 2`. этот блок не завершается оператором **break**, поэтому управление «проваливается» (fall-through) дальше и выполняются все последующие блоки case, пока не встретится оператор break или конец конструкции switch. консольный вывод:

```bash


x = 2

x = 3
```

в конце конструкции switch может находиться блок **default**. он необязателен и выполняется, если ни в одном из блоков case совпадения не найдено. пример сравнения значения переменной с набором значений:

```c


#include <stdio.h>



int main(void)

{

	int x = 5;

	

	switch(x)

	{

		case 1: 

			printf("x = 1 \n");

			break;

		case 2: 

			printf("x = 2 \n");

			break;

		case 3: 

			printf("x = 3 \n");

			break;

		default: 

			printf("x is undefined \n");

			break;

	}

	return 0;

}
```

значение x здесь не совпадает ни с одним из значений после операторов case, поэтому выполняется блок **default**. консольный вывод:

```bash


x is undefined
```

### тернарный оператор

тернарный оператор **?:** позволяет сократить запись простейших условных конструкций if. в отличие от if, это выражение, а не инструкция, поэтому оно имеет значение и может использоваться, например, в инициализаторе. форма оператора следующая:

```c


[первый операнд - условие] ? [второй операнд] : [третий операнд]
```

оператор принимает сразу три операнда. в зависимости от условия он возвращает второй или третий операнд: если условие отлично от нуля (истинно), возвращается второй операнд, если равно 0 (ложно), возвращается третий. вычисляется только один из двух последних операндов, а после вычисления условия стоит точка следования. например:

```c


#include <stdio.h>



int main(void)

{

	int x=5;

	int y=2;

	

	int z = x > y ? x-y : x+y;

	

	printf("z = %d", z);		// z = 3

    return 0;

}
```

результат тернарной операции здесь присваивается переменной z. операция имеет следующие операнды:

- условие

```c
x > y
```

- выражение, вычисляемое, если условие истинно

```c
x - y
```

- выражение, вычисляемое, если условие ложно

```c
x + y
```

условие `x > y` в данном примере истинно (x больше, чем y), поэтому вычисляется разность `x - y`, и переменная `z` получает её результат, число 3.
