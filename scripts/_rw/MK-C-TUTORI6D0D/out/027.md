### массивы указателей



указатели сами являются значениями и потому могут храниться в массивах. так получается массив указателей.



массив указателей определяется одним из трёх способов:


```c


тип *имя_массива [размер];

тип *имя_массива [] = инициализатор;

тип *имя_массива [размер] = инициализатор;
```



согласно правилам разбора деклараторов в c, операция индексирования [] связывается с именем сильнее, чем *, поэтому `тип *имя[размер]` читается как «массив указателей на тип». применим все три способа:



```c


int array[] = {1, 2, 3, 4};

int *p1[3];

int *p2[] = { &array[1], &array[2], &array[0] };

int *p3[3] = { &array[3], &array[1], &array[2] };
```



массив указателей `p1` состоит из трёх элементов, но не инициализирован. если он объявлен как локальная переменная, его элементы имеют неопределённые значения, и разыменовывать их нельзя; при статическом времени хранения они были бы инициализированы нулевыми указателями.



массивы `p2` и `p3` хранят в качестве элементов адреса элементов массива array.



выведем на консоль значения, на которые ссылаются указатели:



```c


#include <stdio.h>

 

int main(void)

{   

    int array[] = {1, 2, 3, 4};

	int *p[] = { &array[1], &array[2], &array[0] };



    for(int i = 0; i < 3; i++)

    {

        printf("%d", *p[i]);

    }

    return 0;

}
```



выражение `*p[i]` сначала выбирает i-й адрес в массиве p, а затем применяет к нему разыменование и получает данные по этому адресу. в итоге на консоль в одну строку выводится:


```consoletext
231
```

 

вместо `*p[i]` можно написать `**(p+i)`. в выражении `p+i` к адресу, в который низводится имя массива `p`, прибавляется число `i`, что даёт перемещение по указателям в массиве p. выражение `*(p+i)` разыменовывает i-й указатель массива и даёт адрес одного из элементов массива `array`. выражение `**(p+i)` получает значение по адресу элемента массива array, полученному на предыдущем шаге.

```c


#include <stdio.h>

 

int main(void)

{   

    int array[] = {1, 2, 3, 4};

	int *p[] = { &array[1], &array[2], &array[0] };



    for(int i = 0; i < 3; i++)

    {

        printf("%d", **(p+i));

    }

    return 0;

}
```

### указатель на массив

от массива указателей следует отличать указатель на массив:



```c


int array[] = {11, 12, 13};

int (*pa)[3] = &array;  // указатель на массив с 3 элементами int
```



здесь переменная pa определена как указатель на массив из трёх элементов типа int и инициализируется адресом массива array из 3 элементов. размер массива входит в тип: `int (*)[3]` и `int (*)[5]` являются разными, несовместимыми типами. имя переменной заключается в скобки, чтобы * связалась с именем раньше, чем []. формально определение указателя на массив выглядит так:



```c


тип_элементов_массива (*имя_переменной_указателя)[количество_элементов];
```



если присвоить такой переменной адрес массива другого размера, результат не определён:



```c


int array2[] = {11, 12, 13, 14, 15};

int (*pa)[3] = &array;  // указатель на массив с 3 элементами int
```



(подразумевается инициализация `&array2`.) с точки зрения стандарта это инициализация указателя значением несовместимого типа, то есть нарушение ограничения. gcc, например, пропускает такое определение, но выдаёт предупреждение, а в последних версиях (начиная с gcc 14) по умолчанию считает это ошибкой.



количество элементов массива можно не указывать:



```c


int array2[] = {11, 12, 13, 14, 15};

int (*pa)[] = &array2; // указатель типа int (*)[5]
```



строго говоря, тип pa в этом случае `int (*)[]`, то есть указатель на массив неизвестного размера: он совместим с `int (*)[5]`, поэтому инициализация допустима, но размер в тип не выводится, и выражение `sizeof(*pa)` для такого указателя некорректно.



указатель на массив позволяет манипулировать массивом, на который он указывает. разыменование даёт сам массив, который в выражении низводится до адреса первого элемента, и через него можно обращаться к элементам:



```c


int array[] = {11, 12, 13};

int (*pa)[3] = &array;  // указатель на массив 



printf("array[0] = %d\n", (*pa)[0]);

printf("array[1] = %d\n", (*pa)[1]);

printf("array[2] = %d\n", (*pa)[2]);
```



указатели на массив удобны для обращения к подмассивам многомерных массивов. например:


```c


int array[3][2] = {{11, 12}, {13, 14}, {15, 16}};

int (*pa)[2] = array + 1;  // указатель на массив с двумя элементами

    

for(size_t i = 0; i < sizeof(*pa)/sizeof(*pa[0]); i++)

{

    printf("%d, ", (*pa)[i]);

}

printf("\n");
```



многомерный массив array состоит из 3 элементов, каждый из которых является массивом из двух int. имя array низводится до указателя типа `int (*)[2]` на первый подмассив, а прибавление единицы сдвигает его на размер целого подмассива, то есть на 2 * sizeof(int) байт. указатель pa указывает на массив из двух элементов и получает адрес **второго подмассива** массива array:


```c
int (*pa)[2] = array + 1
```



то есть pa указывает на подмассив `{13, 14}`.



сравнение указателя на массив с массивом указателей:



```c


int array[] = {11, 12, 13};

int (*pa)[3] = &array;  // указатель на массив 

int *pb[] = { &array[1], &array[2], &array[0] }; // массив указателей



// перебираем массив через указатель на массив

printf("Pointer to Array\n");

for(size_t i = 0; i < sizeof(*pa)/sizeof(*pa[0]); i++)

{

	printf("%d\n", (*pa)[i]);

}



// перебираем массив указателей

printf("Array of Pointers\n");

for(size_t i = 0; i < sizeof(pb)/sizeof(pb[0]); i++)

{

	printf("%d\n", *pb[i]);

}
```



pa является одним указателем, и `sizeof(*pa)` даёт размер всего массива из трёх int, тогда как pb является массивом из трёх указателей, и `sizeof(pb)` равен трём размерам указателя.




### указатель и массив строк



поскольку указатель на **char** может представлять строку, массив указателей на **char** представляет собой массив строк:



```c


#include <stdio.h>



int main(void)

{	

	char *fruit[] = {"apricot", "apple", "banana", "lemon", "orange"};

	for(int i=0; i < 5; i++)

	{

		printf("%s \n", fruit[i]);

	}

	return 0;

}
```



массив указателей `fruit` хранит пять строк, а фактически пять адресов, по которым размещены начальные символы каждой строки. сами строки остаются литералами и, в отличие от двумерного массива char, могут иметь разную длину без перерасхода памяти. результат работы программы:


 

```consoletext


apricot

apple

banana

lemon

orange
```


 

эквивалентная запись через арифметику указателей:



```c


#include <stdio.h>



int main(void)

{	

	char *fruit[] = {"apricot", "apple", "banana", "lemon", "orange"};

	for(int i=0; i < 5; i++)

	{

		printf("%s \n", *(fruit + i));

	}

	return 0;

}
```



### указатели на указатели



помимо обычных указателей, в c можно создавать указатели на другие указатели. если обычный указатель хранит адрес переменной, то указатель на указатель хранит адрес указателя. такую схему называют многоуровневой адресацией.



например:



```c
int **ptr;
```



переменная ptr является указателем на указатель на объект типа **int**. две звёздочки в определении означают двухуровневую адресацию. например:



```c


#include <stdio.h>

 

int main(void)

{   

    int  x = 22;

	int *px = &x;		// указатель px хранит адрес переменной x

	int **ppx = &px;	// указатель ppx хранит адрес указателя px

		

	printf("Address of px: %p \n", (void *)ppx);

	printf("Address of x: %p \n", (void *)*ppx);

	printf("Value of x: %d \n", **ppx);

    return 0;

}
```



указатель `ppx` хранит адрес указателя `px`. выражение `*ppx` даёт значение, хранящееся в указателе `px`, то есть адрес переменной `x`, а выражение `**ppx` даёт значение по адресу из `px`, то есть значение переменной `x`. типичные применения двухуровневой адресации: изменение указателя вызывающей стороны внутри функции и работа с массивами указателей, например с параметром `argv` функции main.
