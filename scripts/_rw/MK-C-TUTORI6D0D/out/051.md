как и любой другой объект, структура может выступать параметром функции и её возвращаемым значением.

### структура как параметр функции

при передаче структуры в качестве аргумента функция получает копию значений структуры:

```c
#include <stdio.h>
 
struct person
{
    char* name;
    int age;
};
 
void print_person(struct person user)
{
    printf("Name: %s \n", user.name);
    printf("Age: %d \n", user.age);
}

int main(void)
{
    struct person tom = {.name = "Tom", .age=38 };
    print_person(tom);
    return 0;
}
```

здесь функция `print_person()` принимает объект структуры person и выводит значения его элементов на консоль.

чтобы не записывать тип параметра полностью как `struct person`, можно определить псевдоним структуры:

```c
#include <stdio.h>
 
typedef struct 
{
    char* name;
    int age;
} person;
 
void print_person(person user)
{
    printf("Name: %s \n", user.name);
    printf("Age: %d \n", user.age);
}

int main(void)
{
    person tom = {.name = "Tom", .age=38 };
    print_person(tom);
    return 0;
}
```

здесь typedef вводит имя person для безымянного структурного типа, и это имя используется как полноценный спецификатор типа без ключевого слова struct.

### указатели на структуру как параметры

при использовании структур в качестве параметров следует учитывать, что при вызове функции для параметра-структуры, как и для параметров типа int или char, выделяется память, в которую копируются значения элементов структуры. в c все аргументы передаются по значению, и структура не исключение, поэтому изменения параметра внутри функции не затрагивают исходную структуру вызывающей стороны. для массивов, вложенных в структуру как поля, это означает копирование всего их содержимого, а для полей-указателей копируется только адрес, но не данные, на которые он указывает.

если требуется сократить расход памяти и время на копирование (особенно для больших структур) или дать функции возможность изменять исходную структуру, в функцию передаётся указатель на структуру:

```c
#include <stdio.h>
 
struct person
{
    char* name;
    int age;
};

void change_person(struct person * user)
{
    user->age = user->age + 1;
} 
int main(void)
{
    struct person bob = {"Bob", 22};
    printf("Before change. %s : %d \n", bob.name, bob.age);
    change_person(&bob);
    printf("After change. %s : %d \n", bob.name, bob.age);
    return 0;
}
```

в этом примере функция `change_person` принимает указатель на структуру person и увеличивает на единицу значение элемента age.

для проверки в функции main данные объекта person выводятся на консоль до и после вызова функции change_person.

```consoletext
Before change. Bob : 22
After change. Bob : 23
```

если функция должна лишь читать данные, параметр обычно объявляют как указатель на константную структуру (`const struct person *`): тем самым сохраняется экономия на копировании, а компилятор запрещает модификацию объекта через этот указатель.

### структура как результат функции

функция может также возвращать объект структуры:

```c
#include <stdio.h>
 
struct person
{
    char* name;
    int age;
};

struct person create_person(char* name, int age)
{
    struct person user;
    user.name = name;
    user.age = age;
    return user;
} 
int main(void)
{
    struct person bob = create_person("Bob", 22);
    printf("Name: %s \n", bob.name);
    printf("Age: %d \n", bob.age);
    return 0;
}
```

здесь функция `create_person()` создаёт на основе полученных параметров объект структуры person и возвращает его в качестве результата. возврат выполняется по значению, то есть вызывающая сторона получает копию локальной переменной user, поэтому, в отличие от возврата указателя на локальный объект, такой код корректен. на распространённых abi небольшие структуры возвращаются в регистрах, а большие через память, выделенную вызывающей стороной.
