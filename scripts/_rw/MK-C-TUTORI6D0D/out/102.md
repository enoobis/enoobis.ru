преобразование строки в число является одной из распространённых операций в различных языках программирования. язык c не исключение. однако в c есть различные способы преобразования строки в целое число. ниже эти способы. библиотечные функции семейства `strto*` задают определённую семантику конца разбора и переполнения; функции `ato*` оставляют ошибку неотличимой от нулевого результата.

функция strtol() (расшифровывается как "string to long") похожа на функцию `atoi()`, но обеспечивает больший контроль и обработку ошибок по сравнению с atoi и возвращает значение типа long:

```c


long strtol(const char *str, char **endptr, int base);
```

она принимает три параметра:

- `str` : строка для преобразования в целое число.

- `endptr` : указатель на указатель на символ. функция записывает в *endptr адрес первого символа, который не удалось преобразовать. это можно использовать для проверки, был ли обработан весь string, или для продолжения парсинга. при успешном преобразовании всей строки `*endptr` указывает на завершающий нулевой символ.

- `base` : основание системы счисления (от 2 до 36). если передать 0, система счисления будет определена автоматически: десятичная, по ведущему "0" восьмеричная, по ведущему "0x" или "0X" шестнадцатеричная.

пропускаются ведущие пробельные символы в смысле `isspace`. знак `+` или `-` допустим перед цифрами. цифры выше 9 кодируются буквами a-z (регистр не важен), поэтому base до 36.

пример применения:

```c


#include <stdio.h>

#include <stdlib.h>



int main(void)

{

    char* str = "31415";



    char* endptr; 



    long num = strtol(str, &endptr, 10);

    printf("num: %ld\n", num);  // num: 31415

 

    return 0;

}
```

преобразование может завершиться неудачно: в этом случае функция возвратит 0. однако endptr в этом случае будет содержать символ, на котором завершено преобразование. например:

```c


#include <stdio.h>

#include <stdlib.h>



int main(void)

{

    char* str = "ab31415";



    char* endptr; 



    long num = strtol(str, &endptr, 10);

    printf("num: %ld   endptr: %c\n", num, *endptr);  // num: 0   endptr: a

 

    return 0;

}
```

здесь при преобразовании строки "ab31415" преобразование завершится на первом же символе, "a", соответственно параметр endptr будет содержать указатель на этот символ. отличие от успешного нуля: при строке "0" указатель endptr продвинется за цифру, при полном отказе endptr равен исходному `str`.

при переполнении функция возвращает значения констант `LONG_MAX` или `LONG_MIN` (определены в `limits.h`), а глобальная переменная errno устанавливается в `ERANGE`. пример использования функции с проверкой ошибок:

```c


#include <stdlib.h>

#include <stdio.h>

#include <errno.h> // Для errno

#include <limits.h> // Для LONG_MAX, LONG_MIN



int main() {

    char *str = "123abc";

    char *endptr;

    long result;



    errno = 0; // Сбрасываем errno перед вызовом

    result = strtol(str, &endptr, 10);



    // Проверяем возможные ошибки

    if (errno == ERANGE) {

        puts("Произошло переполнение! Значение слишком велико");

        if (result == LONG_MAX) {

            puts("Переполнение вверх (MAX)");

        } else if (result == LONG_MIN) {

            puts("Переполнение вниз (MIN)");

        }

    }

    // Проверяем, были ли преобразованы какие-либо цифры

    else if (endptr == str) {

        puts("Не найдено ни одной цифры для преобразования");

    }

    // Проверяем, дошли ли мы до конца строки ('\0')

    else if (*endptr != '\0') {

        printf("Преобразование успешно, но остановилось на символе: '%c'\n", *endptr);

        printf("Остаток строки: '%s'\n", endptr);

    }

    else {

        puts("Преобразование прошло успешно и полностью.");

    }



    printf("Результат: %ld\n", result);

    return 0;

}
```

errno нужно обнулять до вызова: `strtol` не сбрасывает его при успехе, и прежнее значение `ERANGE` от другой функции дало бы ложную диагностику. вывод программы:

```bash


Преобразование успешно, но остановилось на символе: 'a'

Остаток строки: 'abc'

Результат: 123
```

функция strtoll() работает аналогичным образом, только возвращает значение long long int:

```c


long long int strtoll(const char *str, char **endptr, int base);
```

границы переполнения тогда `LLONG_MAX` и `LLONG_MIN`. для беззнаковых величин есть `strtoul` и `strtoull`.

## устаревшие функции atol и atoll

говоря о преобразовании строк в целые числа, нельзя обойти функции atol() и atoll(), которые считаются устаревшими и менее безопасными, чем их аналоги `strtol()` и `strtoll()`, но тем не менее их всё еще можно встретить, особенно в старых программах.

эти функции имеют следующие прототипы:

```c


long int atol(const char *str);

long long int atoll(const char *str);
```

как они работают:

- функция принимает указатель на строку `str`.

- она игнорирует ведущие пробельные символы (пробелы, табуляцию).

- преобразует последующие цифры в число `long int`.

- прекращает работу при встрече первого символа, который не может быть частью числа.

- возвращаемое значение: результат преобразования. если преобразование невозможно, возвращает 0.

главная проблема с этими функциями состоит в том, что невозможно отличить успешное преобразование строки "0" от неудачного преобразования (например, строки "abc"), так как в обоих случаях будет возвращаться 0. переполнение для `atol` в iso c относится к неопределённому поведению, тогда как `strtol` фиксирует его через `ERANGE`. например:

```c


#include <stdlib.h>

#include <stdio.h>



int main() {

    char *valid_str = "12345";

    char *invalid_str = "abc";

    char *zero_str = "0";



    long num1 = atol(valid_str);   // num1 = 12345

    long num2 = atol(invalid_str); // num2 = 0 (но это ошибка!)

    long num3 = atol(zero_str);    // num3 = 0 (успешное преобразование)



    printf("%ld, %ld, %ld\n", num1, num2, num3);

    // Вывод: 12345, 0, 0

    // Непонятно, 0 - это результат или ошибка?

    return 0;

}
```

## функция atoi()

функция atoi() определена в заголовочном файле `stdlib.h` и принимает в качестве аргумента массив символов или строковый литерал и возвращает соответствующее значение в виде целого числа:

```c
int atoi( const char * str);
```

название самой функции расшифровывается как "ascii to integer". результат имеет тип `int`, а не `long`, поэтому диапазон уже, чем у `atol`.

пример применения:

```c


#include <stdio.h>

#include <stdlib.h>



int main(void)

{

    char* str = "234";

  

    int num = atoi(str);

  

    printf("Result: %d\n", num);  // Result: 234

 

    return 0;

}
```

однако эта функция имеет те же проблемы, что и ранее рассмотренные `atol()` и `atoll()`: при неудачном преобразовании функция возвращает 0 без какой-либо индикации неудачи преобразования.

если строка содержит нецифровые символы, то функция завершает преобразование на первом нецифровом символе:

```c


#include <stdio.h>

#include <stdlib.h>



int main(void)

{

    char* str = "3.1415";

  

    int num = atoi(str);

  

    printf("Result: %d\n", num);  // Result: 3

 

    return 0;

}
```

точка в "3.1415" не является десятичной цифрой целого числа, поэтому разбор останавливается на "3". дробная часть отбрасывается, а не округляется.

## функция sscanf

функция sscanf() из заголовочного файла `stdio.h` имеет прототип

```c
int sscanf(const char *str, const char *format, ...);
```

параметры функции:

- `str` : исходная строка для преобразования

- `format` : строка, содержащая спецификаторы формата

- `...` : список переменных аргументов, содержащий адреса переменных, в которых нужно сохранить входные данные.

функция возвращает число успешно присвоенных спецификаторов либо `EOF` при неудаче до первого присваивания. для одного `%d` успех: возврат 1.

пример применения:

```c


#include <stdio.h>



int main(void)

{

    char* str = "345";



    int num;  // во что помещаем преобразованные данные



    sscanf(str, "%d", &num);

    printf("num: %d\n", num);  // num: 345

 

    return 0;

}
```

если строка начинается не на цифровые символы, результат неопределён: в `num` может остаться прежнее содержимое, если спецификатор не был прочитан. возврат sscanf в примере не проверяется.

## ручное преобразование

с помощью цикла можно посимвольно перебрать строку и, используя их коды ascii, преобразовать в соответствующие числа. пример:

```c


#include <stdio.h>



int main(void)

{

    char* str = "234";



    int num = 0;



    for (int i = 0; str[i] != '\0'; i++) {

        

        num = num * 10 + (str[i] - 48);

    }

    printf("num: %d\n", num);  // num: 234

 

    return 0;

}
```

общий алгоритм действий:

- инициализируем переменную `num = 0`, в которую будем помещать преобразованное число.

- начинаем перебирать строку str с начала, пока не дойдем до нулевого символа (окончания строки).

- каждый символ (по индексу i) преобразуем в соответствующее целое число, используя смещение в таблице ascii (`str[i] - 48`)

- складываем полученное значение с `num * 10`, чтобы сохранить разрядность.

код символа `'0'` в ascii равен 48, поэтому вычитание 48 (или `'0'`) переводит символ-цифру в значение 0..9. алгоритм предполагает, что строка состоит только из десятичных цифр без знака и без проверки переполнения `int`.
