### установка clang

одним из наиболее распространённых компиляторов языка c является **clang**, развиваемый в рамках проекта llvm. ниже рассматривается создание первой простейшей программы на c с помощью clang под windows. архитектурно clang выступает фронтендом: он выполняет лексический и синтаксический анализ, семантическую проверку и порождает промежуточное представление llvm ir, а оптимизация и генерация машинного кода выполняются общими компонентами llvm.

прежде всего устанавливается сам компилятор. clang развивается в рамках проекта **llvm**, репозиторий которого размещён на github: [https://github.com/llvm/llvm-project](https://github.com/llvm/llvm-project). проект предоставляет готовый установщик компилятора для windows.

установщик загружается со страницы релизов репозитория по ссылке [https://github.com/llvm/llvm-project/releases/](https://github.com/llvm/llvm-project/releases/)

![загрузка установщика компилятора clang для c на windows](/uploads/course-lectures/20cf1b9457acc4c1ec7d1d62cd42f09aea39b3b0.png)

в самом верху страницы находятся ссылки на последнюю версию. ссылка на установщик для windows по умолчанию может быть скрыта, в этом случае под набором ссылок нажимается **Show All assets**. среди появившихся ссылок находится пункт **LLVM-XX.X.X-win64.exe**, где `XX.X.X` обозначает версию. в примере курса это файл **LLVM-18.1.0-win64.exe**

![установка компилятора clang для c на windows](/uploads/course-lectures/f828964bb5ee585f2608b5d2859917ff7ee3cdad.png)

это сборка для 64-битной windows. для 32-битной ос загружается файл **LLVM-18.1.0-win32.exe**

после загрузки файл запускается.

![установка компилятора clang++ для c на windows](/uploads/course-lectures/76c5b000e9ebb9a5da2be8d01c1a73fee960c5f9.png)

на стартовом экране программы нажимается кнопка "далее". затем принимается лицензионное соглашение.

![лицензия компилятора clang для c на windows](/uploads/course-lectures/9d55c9766ff7367ff6355798c2fc72a5e952013a.png)

далее указываются опции установки:

![добавление пути к компилятору clang для c в переменные среды на windows](/uploads/course-lectures/3195a8de6cb25fd6f53cef7f4d4fbc6b6cc96335.png)

чтобы при компиляции не указывать полный путь к компилятору и не добавлять его вручную в переменные среды, в этом окне выбирается пункт **Add LLVM to the system PATH for current user**

в следующем окне указывается папка установки. можно оставить путь по умолчанию "C:/Program Files/LLVM":

![путь к каталогу компилятора clang для c на windows](/uploads/course-lectures/8320191517eabe34df1f0fe543abab0937365372.png)

в последующих окнах все опции остаются по умолчанию, после чего запускается установка. по её успешном завершении clang готов к использованию.

![установка на windows компилятора clang для c](/uploads/course-lectures/140fd8334098e94a9c1d3ed81f702b2e9a0f7dfc.png)

для проверки установки clang в терминале или командной строке вводится команда

```bash
clang --version
```

в ответ отображается базовая информация о компиляторе: версия, целевая платформа и т.д.:

```bash
C:\Users\eugen>clang --version
clang version 18.1.0
Target: x86_64-pc-windows-msvc
Thread model: posix
InstalledDir: C:\Program Files\LLVM\bin
```

строка target содержит целевую тройку (target triple): архитектуру, производителя, ос и окружение. суффикс `msvc` означает, что clang по умолчанию использует заголовки, библиотеки и компоновщик из инструментария microsoft visual c++, поэтому для успешной компоновки на машине должны быть установлены средства сборки visual studio или windows sdk.

### первая программа

после завершения установки в каталоге **C:\Program Files\LLVM\bin** находятся все необходимые файлы компиляторов:

![компилятор clang для языка c на windows](/uploads/course-lectures/b262bd685e99e354d3fc7ff49d3bda2aa8de8b66.png)

в частности, файл **clang.exe** предназначен для компиляции программ на языке c.

### создание первой программы

после установки компилятора можно написать первую программу. для набора исходного кода подойдёт любой текстовый редактор: распространённый visual studio code или даже встроенный блокнот.

на диске создаётся папка для исходных файлов, а в ней новый файл с именем **hello.c**.

![первая программа на си в windows](/uploads/course-lectures/a13de346f4504c3b7efab8da0efda357429f41da.png)

в примерах курса файл hello.c находится в папке C:\c.

в файле **hello.c** определяется простейший код, выводящий строку на консоль:

```c
#include <stdio.h>			// подключаем заголовочный файл stdio.h
int main(void)						// определяем функцию main
{									// начало функции
	printf("Hello enoobis.ru!\n");	// выводим строку на консоль
	return 0;						// выходим из функции
}									// конец функции
```

для вывода строки на консоль необходимо подключить соответствующий функционал. для этого в начале файла стоит строка

```c
#include <stdio.h>
```

директива препроцессора include подключает заголовочный файл stdio.h, содержащий объявление функции printf, которая выводит строку на консоль. сама реализация printf находится в стандартной библиотеке и подключается на этапе компоновки.

далее следует определение функции **int main(void)**. функция main должна присутствовать в любой размещённой (hosted) программе на c, с неё начинается выполнение приложения.

ключевое слово **int** в определении `int main(void)` указывает, что функция возвращает целое число. слово void в скобках означает, что функция не принимает параметров.

тело функции main заключено в фигурные скобки {}. в теле функции строка выводится на консоль с помощью функции printf, которой передаётся выводимая строка "Hello enoobis.ru!".

в конце выполняется выход из функции оператором **return**. поскольку функция должна возвращать целое число, после return указывается 0. ноль служит индикатором успешного завершения программы.

каждая инструкция в функции завершается точкой с запятой.

![язык программирования си в visual studio code](/uploads/course-lectures/98922a8b3eea198e0b2ab6f5f069199299739282.png)

далее файл компилируется. для этого открывается командная строка windows, и командой cd выполняется переход в папку с исходным файлом:

```bash
cd C:\c
```

для компиляции исходного кода компилятору clang в качестве параметра передаётся файл hello.c:

```bash
clang hello.c -o hello.exe
```

дополнительный необязательный параметр `-o hello.exe` задаёт имя скомпилированного файла hello.exe. без этого параметра файл получит имя по умолчанию a.exe.

после выполнения команды создаётся исполняемый файл hello.exe. при его запуске консоль выведет строку "Hello enoobis.ru!", как и задано в коде.

![запуск компилятора clang на windows для компиляции программы на языке c](/uploads/course-lectures/54d3800976e1245f17120fa4c3677b1436842583.png)

если вместо командной строки используется оболочка powershell, файл запускается командой "./hello": powershell, в отличие от cmd, не ищет исполняемые файлы в текущем каталоге без явного указания пути.
