условные операции проверяют истинность некоторого условия и оперируют понятиями «истина» (условие верно) и «ложь» (условие неверно). в c истине соответствует значение 1, а лжи значение 0. результат таких операций имеет тип int: отдельный логический тип появился в стандарте только в c99 (_Bool, а в c23 bool стал ключевым словом), но операции сравнения и логические операции по-прежнему возвращают int. к условным операциям относятся операции сравнения и логические операции. оба вида применяются к арифметическим операндам, то есть к числам (а также к указателям, что будет рассмотрено позднее).

### операции сравнения

операции сравнения, которые также называют операциями отношения, сравнивают два значения и возвращают **1**, если выражение истинно, и **0**, если оно ложно. в языке c определены следующие операции сравнения:

- == операция «равно». возвращает 1, если оба операнда равны, и 0, если они не равны. в первом случае переменная `c` хранит результат выражения `a == b` . значения a и b не равны, поэтому выражение возвращает 0, и переменная c получает значение 0. во втором случае переменная `result` хранит результат выражения `num == 2 + 3;` , где вторым операндом служит результат операции `2 + 3` : арифметические операции имеют более высокий приоритет, чем сравнение, поэтому сложение выполняется первым. переменная `num` равна 5, выражение возвращает 1, и переменная `result` получает значение 1.

```c
#include <stdio.h>
 
int main(void)
{
    int a = 10;
    int b = 4;
    int c = a == b;	                // 0 - числа НЕ равны
    printf("c = %d \n", c);         // c = 0

    int num = 5;
    int result = num == 2 + 3;	    // 1 - числа равны
    printf("result = %d \n", result);     // result = 1
    return 0;
}
```

- != операция «не равно». возвращает 1, если первый операнд не равен второму, и 0, если операнды равны:

```c
int c = 10 != 4;	// 1
int d = 4 != 4;     // 0
```

- > операция «больше чем». возвращает 1, если первый операнд больше второго, и 0, если первый операнд меньше второго или равен ему:

```c
int a = 10;
int b = 4;
int c = a > b;	// 1
```

-  = операция «больше или равно» (>=). возвращает 1, если первый операнд больше второго или равен ему, и 0, если первый операнд меньше второго. аналогично определены операции «меньше чем» (<) и «меньше или равно» (<=):

```c
int c = 10 >= 4;	// 1
```

как правило, операции отношения используются в условных конструкциях вида if...else, которые рассматриваются далее в курсе.

### логические операции

логические операции обычно применяются к результатам отношений и объединяют несколько операций сравнения в одно условие. любое ненулевое значение операнда трактуется как истина, нуль трактуется как ложь. к логическим операциям относятся следующие:

- ! (операция отрицания). если операнд равен 0, возвращает 1, в противном случае возвращает 0.

```c
int c = !2;	// 0
int d = !0;	// 1
```

- && (конъюнкция, логическое умножение). возвращает 1, если оба операнда не равны 0, и 0, если хотя бы один операнд равен 0. операция вычисляется по сокращённой схеме (short-circuit evaluation): левый операнд вычисляется первым, и если он равен 0, правый не вычисляется вовсе, а между вычислением операндов стоит точка следования.

```c
int c = -2 && 5;	// 1
int d = 0 && 7;		// 0
```

- || (дизъюнкция, логическое сложение). возвращает 1, если хотя бы один операнд не равен 0, и 0, если оба операнда равны 0. сокращённая схема здесь симметрична: если левый операнд отличен от нуля, правый не вычисляется.

```c
int c = -2 || 5;	// 1
int d = 0 || 7;		// 1
int e = 0 || 0;		// 0
```

пример совместного использования нескольких логических операций и операций сравнения:

```c
int a = -2 > 5;			// 0
int b = 0 < 7;			// 1
int c = 0 == 0;		     // 1
int d = a && b || c; 		// 1

printf("a = %d \n", a);
printf("b = %d \n", b);
printf("c = %d \n", c);
printf("d = %d \n", d);
```

операции сравнения имеют более высокий приоритет, чем логические операции, поэтому сравнения можно подставить в выражение напрямую, без скобок. среди логических операций && связывает сильнее, чем ||, так что выражение ниже вычисляется как ((-2 > 5) && (0 < 7)) || (0 == 0):

```c
int d = -2 > 5 && 0 < 7 || 0 == 0; 		// 1
```
