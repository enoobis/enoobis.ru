ещё один способ чтения и записи информации в файлах предоставляют функции **fprintf()** и **fscanf()**. они позволяют форматировать соответственно записываемые и считываемые данные.

### форматированный вывод

функция **fprintf()** имеет следующий синтаксис:

```c
int fprintf(указатель_на_поток, строка_форматирования, список_аргументов);
```

функция записывает в файл данные, переданные в качестве третьего параметра, с учётом форматирования, которое задаёт строка форматирования. первый параметр представляет указатель на файловый поток, в который выполняется запись. функция является вариадической: количество и типы аргументов определяются спецификаторами строки форматирования во время выполнения, а компилятор лишь по возможности сверяет их в виде предупреждений.

строка форматирования и передача в неё значений устроены так же, как у функции printf(), которая по сути эквивалентна fprintf с потоком stdout

пример записи в файл массива структур:

```c
#include <stdio.h>

struct person
{
    char name[20];
    int age;
};
int main(void)
{
    char * filename = "users.dat";
    struct person people[] = { {"Tom", 23}, {"Alice", 27}, {"Bob", 31}, {"Kate", 29} };
    // количество записываемых структур
    int n = sizeof(people)/sizeof(people[0]);
    FILE *fp = fopen(filename, "w");
    if (!fp)
    {
        printf("Error occured while opening file\n");
        return 1;
    }
     
    for(int i=0; i < n; i++)
    {
        fprintf(fp, "%s  %d\n", people[i].name, people[i].age);
    }
    fclose(fp);
    printf("File has been written\n");
    return 0;
}
```

каждая структура содержит два поля: строковое поле name и числовое поле age. поэтому строка форматирования включает соответствующие спецификаторы: `"%s %d\n"`.

после записи получается текстовый файл users.dat, который можно просмотреть в любом текстовом редакторе. в отличие от побайтовой записи структур, такое текстовое представление не зависит от выравнивания и порядка байтов платформы, но требует разбора при чтении.

### форматированный ввод

для чтения данных в определённом формате применяется функция **fscanf()** со следующим синтаксисом:

```c
int fscanf(указатель_на_поток, строка_форматирования, список_аргументов);
```

по существу эта функция аналогична функции scanf(), которая используется для ввода с консоли, только ввод выполняется из файла, указатель на который передаётся первым параметром.

функция возвращает числовое значение: количество успешно присвоенных аргументов. если конец файла достигнут до первого преобразования, функция возвращает значение EOF.

пример чтения и вывода на консоль данных, ранее записанных в файл users.dat:

```c
#include <stdio.h>

int main(void)
{	
	char * filename = "users.dat";
	char name[20];  // для считывания имени
	int age;        // для считывания возраста
	FILE *fp = fopen(filename, "r");
	if (!fp)
	{
		printf("Error occured while opening file\n");
		return 1;
	}
	
	while((fscanf(fp, "%20s  %d\n", name, &age))!=EOF)
	{
		printf("%s  %d\n", name, age);
	}
	fclose(fp);
	return 0;
}
```

для считывания данных определены вспомогательные переменные name и age, и при вызове fscanf в списке аргументов передаются их адреса: функция записывает результат по указателям, поскольку в c аргументы передаются по значению. строка форматирования при этом совпадает со строкой, которая использовалась при записи в файл в предыдущем примере: `"%s %d\n"`. ширина в спецификаторе %20s ограничивает число считываемых символов, однако к ней добавляется завершающий нуль, поэтому для буфера из 20 элементов строго корректной была бы ширина 19.

пока при считывании не достигнут конец файла и функция не вернула EOF, она заполняет переменные name и age, значения которых затем выводятся на консоль. в итоге получается следующий консольный вывод:

```consoletext
Tom		23
Alice	27
Bob		31
Kate	29
```
