указатели в языке c поддерживают ограниченный набор операций: присваивание, получение адреса самого указателя, разыменование, часть арифметических операций и операции сравнения. семантика арифметики и сравнения определяется не «сырым» числом адреса, а типом указываемого объекта и, для отношения порядка, принадлежностью одному массиву.

### присваивание

указателю можно присвоить адрес объекта того же типа, значение другого указателя совместимого типа либо константу **NULL**.

присвоение адреса уже рассматривалось: адрес объекта даёт операция **&**:

```c
int a = 10;
int *pa = &a;	// указатель pa хранит адрес переменной a
```

указатель и переменная должны иметь согласованный тип, здесь int. присвоение адреса `int` указателю `double *` без приведения нарушением ограничений типа.

присвоение указателю другого указателя:

```c
#include <stdio.h>

int main(void)
{
	int a = 10;
	int b = 2;
	
	int *pa = &a;
	int *pb = &b;
	
	printf("Variable a: address=%p \t value=%d \n", (void*)pa, *pa);
	printf("Variable b: address=%p \t value=%d \n", (void*)pb, *pb);
	
	pa = pb;	// теперь указатель pa хранит адрес переменной b
	printf("Variable b: address=%p \t value=%d \n", (void*)pa, *pa);
	
	return 0;
}
```

когда указателю присваивается другой указатель, первый начинает указывать на тот же адрес, что и второй. копируется значение адреса, указываемый объект не дублируется: после `pa = pb` оба указателя ссылаются на `b`, переменная `a` остаётся на месте.

если указатель не должен ссылаться на конкретный объект, ему присваивают нулевое значение константой **NULL**, объявленной в заголовочном файле `stdio.h` (и в `stddef.h`):

```c
int *pa = NULL;
```

`NULL` в c есть нулевой указатель, гарантированно несравнимый по равенству ни с одним объектом. разыменование нулевого указателя есть неопределённое поведение. проверка `p == NULL` перед доступом по адресу отделяет «указатель ни на что» от валидного адреса.

### разыменование указателя

операция разыменования в виде `*имя_указателя` даёт lvalue объекта по адресу, который хранится в указателе.

```c
#include <stdio.h>

int main(void)
{
	int a = 10;
	
	int *pa = &a;
	int *pb = pa;
	
	*pa = 25;
	
	printf("Value on pointer pa: %d \n", *pa);	// 25
	printf("Value on pointer pb: %d \n", *pb);	// 25
	printf("Value of variable a: %d \n", a);	// 25
	
	return 0;
}
```

через выражение `*pa` читается значение по адресу из `pa`, через `*pa = значение` по этому адресу записывается новое значение.

поскольку `pa` указывает на переменную `a`, изменение объекта по адресу меняет и `a`. `pb` получил тот же адрес, что `pa`, поэтому `*pa`, `*pb` и `a` обозначают один объект: после `*pa = 25` все три дают 25.

### указатель на void

указатели типизированы. `int*` указывает на объект `int` и не может без преобразования указывать на `float`. указатель типа **void*** способен хранить адрес объекта любого типа. в c указатели на объекты неявно преобразуются к **void*** и обратно:

```c
#include <stdio.h>
 
int main(void)
{
    int x = 123;
    int *ip = &x;       // указатель хранит адрес объекта int
    void *vp; 
    vp = ip;            // void-указатель получает адрес из указателя ip
    printf("Value: %d\n", *((int *)vp));    // Value: 123

    return 0;
}
```

к void-указателю нельзя применить разыменование: тип `void` неполного размера, выражение `*vp` не имеет типа объекта. чтобы прочитать значение, указатель сначала приводят к типу, соответствующему реальному объекту:

```c
printf("Value: %d\n", *((int *)vp));
```

одно из распространённых применений void-указателя: передача адреса в `printf` со спецификатором `%p`:

```c
#include <stdio.h>

int main(void)
{
    int x = 123;
    int *ip = &x;                   // указатель хранит адрес объекта int
    void *vp = ip;                  // void-указатель получает адрес из указателя ip
    printf("vp: %p\n", vp);         // получаем адрес, который хранится в указателе vp
    printf("ip: %p\n", (void*)ip);  // преобразование к типу void* - получаем адрес из указателя ip

    return 0;
}
```

если нужно напечатать адрес из указателя другого типа, по стандарту его сначала преобразуют к `void*`. `malloc` и родственные функции возвращают `void*` именно как универсальный адрес сырой памяти, который затем приводят к нужному типу объекта.

### адрес указателя

указатель хранит адрес переменной, и по этому адресу читается её значение. сам указатель, как любой объект, тоже занимает ячейки памяти и имеет собственный адрес. этот адрес даёт та же операция **&**:

```c
int a = 10;
int *pa = &a;
printf("address of pointer=%p \n",  (void*)&pa);  // адрес указателя
printf("address in pointer=%p \n",  (void*)pa);	  // адрес, который хранится в указателе - адрес переменной a			
printf("value on pointer=%d \n", *pa);			  // значение по адресу в указателе - значение переменной a
```

`&pa` имеет тип «указатель на указатель на int» (`int **`). значение `pa` есть адрес `a`; значение `&pa` есть адрес объекта `pa`. путать эти два адреса нельзя: запись по `&pa` изменила бы сам указатель, запись по `pa` изменила бы `a`.

### операции сравнения

к указателям применимы операции сравнения **>**, **>=** и остальные операции отношения и равенства. равенство `==` / `!=` определено для указателей на объекты (включая нулевой): два указателя равны, если адресуют один и тот же объект либо оба нулевые. упорядочение `>`, `>=`, `<`, `<=` стандарт задаёт для указателей на элементы одного массива (и позицию сразу за последним элементом): указатель с большим индексом считается большим. сравнение указателей на объекты из разных массивов или на независимые переменные, не образующие массив, даёт неопределённое поведение, хотя конкретная реализация может сравнить числовые адреса. иллюстративный вывод:

```consoletext
pa (0060FEA4) is greater than pb (0060FEA0)
```

здесь адрес `pa` больше адреса `pb` в выбранной раскладке стека. сам по себе такой результат говорит лишь о взаимном расположении двух ячеек в данном запуске.

### приведение типов

иногда указателю одного типа присваивают значение указателя другого типа. тогда выполняют явное приведение:

```c
char c = 'N';
char *pc = &c;
int *pd = (int *)pc;
printf("pc=%p \n",  (void*)pc);
printf("pd=%p \n",  (void*)pd);
```

после приведения `pc` и `pd` хранят один и тот же адрес, но трактуют его как начало объектов разных типов. печать адреса через `%p` после приведения к `void*` определена. разыменование `pd` как `int *`, если объект по адресу имеет тип `char` и, возможно, не выровнен для `int`, нарушает правила aliasing и выравнивания.
