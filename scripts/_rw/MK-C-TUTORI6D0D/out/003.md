далее рассматривается создание первой программы в linux, на примере ubuntu. многие дистрибутивы linux, в том числе ubuntu, как правило, уже содержат установленный компилятор gcc, который можно использовать сразу. если он не установлен, его можно доустановить в терминале командой:

```c
sudo apt-get install gcc
```

в остальном, при использовании компилятора gcc, процесс аналогичен созданию программы в windows.

в файловой системе определяется каталог для исходных файлов на c, и в нём создаётся новый файл **hello.c** со следующим кодом:

```c
#include <stdio.h>		// подключаем заголовочный файл stdio.h
int main(void)					// определяем функцию main
{								// начало функции
	printf("Hello World! \n");	// выводим строку на консоль
	return 0;					// выходим из функции
}								// конец функции
```

это тот же код, что и в случае windows, поскольку программы на c в значительной степени переносимы на уровне исходного кода. различается лишь среда: компилятор порождает исполняемый файл в формате elf, а функции стандартной библиотеки предоставляет системная реализация, в ubuntu это glibc.

чтобы вывести строку на консоль, директивой include подключается заголовочный файл stdio.h.

```c
#include <stdio.h>
```

этот заголовочный файл содержит объявление функции printf, которая выводит строку на консоль.

далее следует определение функции **int main(void)**, главной функции, которая должна присутствовать в любой программе на c. с неё начинается выполнение приложения.

ключевое слово **int** в определении `int main(void)` указывает, что функция возвращает целое число. слово void в скобках означает, что функция не принимает параметров. всё содержимое функции заключается в фигурные скобки.

в самой функции строка выводится на консоль с помощью функции printf, которой передаётся выводимая строка "Hello world!".

в конце выполняется выход из функции оператором **return**. поскольку функция должна возвращать целое число, после return указывается 0. ноль служит индикатором успешного завершения программы, в оболочке этот код завершения доступен через переменную `$?`.

в терминале командой cd выполняется переход в каталог, где расположен файл с исходным кодом.

далее программа компилируется командой

```consoletext
gcc hello.c
```

в результате в папке с файлом hello.c появляется скомпилированный файл, который по умолчанию называется **a.out**. он запускается следующей командой:

```consoletext
./a.out
```

префикс `./` нужен потому, что текущий каталог в unix-подобных системах по соображениям безопасности обычно не входит в переменную PATH.

на консоль будет выведена сакраментальная строка "Hello World!".
