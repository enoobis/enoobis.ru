циклы позволяют многократно выполнять одно и то же действие в зависимости от некоторого условия. в языке c определены следующие виды циклов:

- for

- while

- do...while

### цикл for

формальное определение цикла for выглядит так:

```c


for (инициализация; условие; приращение;)

{

    // тело цикла

}
```

заголовок цикла состоит из трёх частей (лишняя точка с запятой после приращения в схеме выше в реальном коде не ставится). первая часть, инициализация, выполняется один раз перед началом цикла и задаёт начальное состояние. как правило, здесь инициализируются счётчики, то есть переменные, которые управляют выполнением цикла. начиная с c99 в этой части можно объявить переменную, и её область видимости ограничена самим циклом.

вторая часть, условие, определяет, выполняется ли очередная итерация. обычно в качестве условия используется операция сравнения: если она возвращает ненулевое значение (условие истинно), выполняется тело цикла, а затем вычисляется третье выражение. условие проверяется перед каждой итерацией, поэтому тело цикла for может не выполниться ни разу.

третья часть, приращение, задаёт изменение параметров цикла. обычно здесь увеличивается счётчик.

стандартный цикл **for** на примере вывода на консоль чисел от 0 до 5:

```c


#include <stdio.h>



int main(void)

{

	for (int i = 0; i < 6; i++)

	{

		printf("%d", i);

	}

	return 0;

}
```

первая часть заголовка, `int i = 0`, создаёт и инициализирует счётчик i. счётчик не обязан иметь тип int, это может быть и другой числовой тип, например float, хотя вещественный счётчик чреват ошибками округления при сравнении. перед выполнением цикла его значение равно 0. по сути это то же самое, что объявление переменной.

вторая часть задаёт условие выполнения цикла. здесь цикл выполняется, пока i не достигнет 6.

третья часть увеличивает счётчик на единицу. увеличивать его именно на единицу необязательно: счётчик можно уменьшать (i--) или изменять на другую величину (i+=2).

в итоге тело цикла выполнится 6 раз, пока значение `i` не станет равным 6, и при каждом проходе это значение увеличивается на 1.

```consoletext
012345
```

каждый отдельный проход цикла называется итерацией, то есть в примере выше выполнено 6 итераций.

более сложный пример, вывод квадратов чисел от 0 до 8:

```c


#include <stdio.h>

int main(void)

{

	for (int i = 0; i < 9; i++)

	{

		printf("%d * %d = %d \n", i, i,  i * i);

	}

	return 0;

}
```

здесь тело цикла выполнится 9 раз, пока значение i не станет равным 9, и каждый раз это значение увеличивается на 1.

```consoletext


0 * 0 = 0

1 * 1 = 1

2 * 2 = 4

3 * 3 = 9

4 * 4 = 16

5 * 5 = 25

6 * 6 = 36

7 * 7 = 49

8 * 8 = 64
```

указывать все три выражения в заголовке цикла необязательно, любое из них или даже все можно опустить:

```c


int i = 1;

for ( ; i < 9 ; )

{

	printf("%d * %d = %d \n", i, i,  i * i);

	i++;

}
```

формально определение цикла осталось прежним, только первое и третье выражения в заголовке отсутствуют: `for (; i < 9;)`. инициализация вынесена до цикла, а приращение перенесено в его тело. если опущено условие, оно считается всегда истинным, и цикл становится бесконечным. такой цикл с одним лишь условием по смыслу совпадает с циклом while, который записывается как `while (условие) инструкция`: пока условие, например `i > 0`, истинно, выполняются действия цикла, скажем `printf("%d \n", i)` и `i--`. цикл do...while отличается тем, что условие проверяется после тела, поэтому тело выполняется хотя бы один раз.

### операторы continue и break

иногда цикл требуется завершить досрочно. для этого служит оператор **break**. например:

```c


int i = 1;

for ( ; ; )

{

	printf("%d * %d = %d \n", i, i,  i * i);

	i++;

	if (i > 5) break;

}
```

здесь заголовок не содержит ни одного выражения, и цикл формально бесконечен. когда значение переменной i превышает 5, оператор **break** выполняет выход из цикла. break прерывает только ближайший объемлющий цикл (или switch), для выхода из вложенных циклов требуются флаги или goto.

в отличие от оператора `break`, оператор **continue** завершает текущую итерацию и передаёт управление к следующей. в цикле for перед следующей итерацией при этом вычисляется выражение приращения. пусть требуется посчитать сумму только нечётных чисел из некоторого диапазона:

```c


#include <stdio.h>

int main(void)

{

	int result = 0;

	for (int i=0; i<10; i++)

	{

		if (i % 2 == 0) continue;

		result +=i;

	}

	printf("result = %d", result);	// 25

	return 0;

}
```

чётность числа определяется по остатку от целочисленного деления на 2: если он равен 0, оператор continue переходит к следующей итерации цикла. если число нечётное, оно прибавляется к сумме остальных нечётных чисел.
