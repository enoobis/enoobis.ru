при запуске программы на си автоматически открываются ряд потоков, основными из которых являются следующие:

- стандартный поток ввода stdin

- стандартный поток вывода stdout

- стандартный поток вывода сообщений об ошибках stderr

стандартный поток ввода **stdin** по умолчанию соответствует клавиатуре, а потоки **stdout** и **stderr** : экрану монитора.

семантика этих трёх потоков задана стандартом iso c: они имеют статическую продолжительность жизни и связываются с объектами `FILE` ещё до входа в `main`. **stderr** по умолчанию не полностью буферизуется, поэтому диагностические сообщения появляются даже если **stdout** ещё держит данные в буфере. перенаправление на уровне оболочки подменяет соответствующие дескрипторы, не меняя исходный текст программы.

для управления вводом-выводом с помощью этих потоков используются ряд функций:

- getchar() : ввод с клавиатуры одного символа

- putchar() : вывод на консоль одного символа

- fgets() : ввод одной строки

- puts() / fputs() : вывод одной строки на консоль

- scanf() : ввод с консоли с форматированием данных

- sscanf() : ввод с из строки с форматированием данных

- printf() : вывод с форматированием данных

функции printf и scanf уже рассматривались ранее, поэтому ниже разбирается, как применять остальные функции.

### ввод и вывод символов

для ввода и вывода символа применяются функции **getchar()** и **putchar()**. на самом деле они полноценными функциями не являются, а определены как макросы в заголовочном файле **stdio.h**:

```c


#define getchar()	getc(stdin)

#define putchar(c)	putc((c), stdout)
```

макрос подставляет вызов `getc`/`putc` с фиксированным потоком. из-за этого `&getchar` взять нельзя, а повторное вычисление аргумента `putchar(c++)` зависит от того, макрос это или функция. стандарт допускает и настоящие функции с теми же именами, если макросы предварительно отменить через `#undef`.

#### вывод символа

для вывода отдельного символа на консоль предназначена функция **putchar()** со следующим прототипом:

```c
int putchar(int c);
```

выводимый символ в виде числового кода передаётся в putchar в качестве параметра, он же возвращается функцией. аргумент имеет тип `int`, а не `char`: это позволяет передать как значение `unsigned char`, так и `EOF`.

```c


#include <stdio.h>



int main(void)

{

	char c = 'A';

	putchar(c);		// Выводим символ A

}
```

#### ввод символа

для ввода одного символа с клавиатуры применяется функция **getchar()**, которая имеет следующий прототип:

```c
int getchar(void);
```

в качестве результата функция возвращает числовой код введённого символа. при конце потока или ошибке возвращается `EOF`, поэтому результат сохраняют в `int`, а не в `char`: иначе `EOF` неотличим от символа с кодом 0xff на платформах со знаковым `char`.

при использовании функции **getchar** следует учитывать, что при печати текста посредством клавиатуры в буфер операционной системы заносятся коды печатаемых символов, а сами символы отображаются на экране. получение программой введённого символа из буфера производится с помощью нажатия клавиши enter.

и если буфер операционной системы не пуст, то при вызове функции **getc()** она получает очередной символ из буфера. если же буфер пуст, то происходит чтение байта из потока ввода с помощью системной функции, название которой зависит от операционной системы.

при этом при нажатии клавиши enter в буфер также помещается код этой клавиши. то есть если ввести один символ и нажать enter, в буфере окажутся два числовых кода: введённого символа и клавиши enter. это надо учитывать при работе с функцией getchar. в частности, простой, но показательный пример:

```c


#include <stdio.h>



int main(void)

{

    printf("1");

	getchar(); // ожидание ввода символа

	printf("2");

	getchar(); // ожидание ввода символа

	printf("3");

	

    return 0;

}
```

сначала на экран выводится цифра 1, после чего функция getchar ожидает ввода символа. если после ввода символа нажать enter, то в буфер будут помещены два числовых кода: введённого символа и клавиши enter. поэтому при втором вызове getchar эта функция считывает байт из буфера, то есть числовой код клавиши enter.

например, при первом вызове функции getchar вводится символ "a", а затем enter:

```consoletext


1a

23
```

но если при каждом вызове getchar только нажимать клавишу enter, тогда в буфер будет заноситься только код этой клавиши, и соответственно программа будет работать, как и ожидалось:

```consoletext


1

2

3
```

функции getchar и putchar для ввода и вывода символов с клавиатуры:

```c


#include <stdio.h>



int main(void)

{

    int c;

	

	while((c=getchar())!=EOF)

	{

		putchar(c);

	}

    return 0;

}
```

функция `getchar()` считывает числовой код символа, который потом выводится в функции `putchar()`. для выхода из программы вводится комбинация клавиш ctrl+c.

ctrl+c завершает процесс сигналом (`SIGINT` на unix-подобных системах), а не сообщает о конце потока. признак `EOF` для терминала: ctrl+d на unix-подобных системах и ctrl+z на windows.

### ввод и вывод строк

#### вывод строк и puts

для вывода одной строки на консоль предназначена функция **puts()** со следующим прототипом:

```c
int puts(const char *str);
```

в качестве параметра передаётся указатель на строку, а возвращаемым результатом функции является последний выведенный символ. стандарт iso c требует лишь неотрицательное значение при успехе и `EOF` при ошибке; конкретный «последний символ» в возвращаемом значении реализацией не гарантируется.

при этом функция **puts()** будет выводить символы переданной строки, пока не дойдёт до нулевого символа '\0'. если же выводимый массив символов не содержит этого символа, то результат программы неопределён. например:

```c


#include <stdio.h>

 

int main(void)

{

    puts("Hello World");        // выводим строковый литерал



    char* name = "Hello enoobis.ru";

    puts(name);                 // выводим значение переменной



    return 0;

}
```

консольный вывод:

```consoletext


Hello World

Hello enoobis.ru
```

**puts** дописывает символ перевода строки после содержимого; в литералах примера `\n` поэтому не нужен.

#### вывод строк и fputs

функция **fputs()** также записывает в поток вывода строку, то есть набор символов, который завершается символом '\0'. при записи строки нулевой символ '\0' не записывается. она имеет следующий прототип:

```c
int fputs(const char *s, FILE *stream);
```

первый параметр функции: записываемая строка, а второй: указатель на поток вывода. в качестве результата функция возвращает неотрицательное целое число. при ошибках в процессе записи возвращается значение **EOF**.

в отличие от **puts**, **fputs** не добавляет перевод строки: его надо включить в саму строку, если он нужен. тем же вызовом записывают и в файл, подставив соответствующий `FILE*`.

запись в стандартный поток вывода, то есть на консоль. в качестве второго параметра передаётся значение **stdout**:

```c


#include <stdio.h>

  

int main(void)

{

    fputs("Hello enoobis.ru.\n", stdout);

    return 0;

}
```

#### ввод строк и fgets

для ввода строки с клавиатуры применяется функция **fgets()**, которая имеет следующий прототип:

```c


char *fgets(char *str, int count, FILE *stream);
```

параметры функции

- `char *str` : строка, в которую производится считывание.

- `int count` : сколько символов необходимо считывать.

- `FILE *stream` : файловый поток, из которого производится считывание. в качестве потока ввода может выступать и консольный ввод.

функция **fgets()** прекращает считывание, когда пользователь нажимает клавишу enter, то есть когда в поток добавляется символ перевода строки. чтение также останавливается после `count - 1` символов либо при конце потока: в буфер всегда дописывается '\0', если хотя бы один символ удалось прочитать.

считывание строки с консоли. для этого в качестве третьего параметра в функцию передаётся значение **stdin**:

```c


#include <stdio.h>



#define MAX 15



int main(void)

{

 	char name[MAX];

    printf("Enter name: ");

 	fgets(name, MAX, stdin);

 	printf("Your name: %s\n", name);

	return 0;

}
```

здесь функция fgets считывает не более 15 символов в строку name, а в реальности функция предложит ввести 14 символов, так как последний символ зарезервирован для нулевого символа '\0'. если будет введено больше символов, то fgets всё равно считает не более 15 символов (включая завершающий '\0'). функция позволяет ограничить количество считываемых символов и поэтому считается безопасной относительно переполнения буфера, в отличие от устаревшей `gets`.

пример работы программы:

```consoletext


Enter name: Tom Smith

Your name: Tom Smith
```

символ перевода строки, если он уместился, остаётся в буфере: `name` может содержать `"Tom Smith\n"`. это отличает `fgets` от спецификатора `%s` в `scanf`.

функция **fgets()** возвращает указатель `char *` : указатель на буфер, в который считаны данные. в реальности это тот же самый буфер, который передавался в качестве первого параметра, то есть в примере выше это массив name. однако этот результат может пригодиться для проверки успешности выполнения функции: если считывание прошло неудачно, то функция возвращает **NULL**:

```c


#include <stdio.h>

#define MAX 15



int main(void)

{

 	char name[MAX];

    printf("Enter name: ");

 	if(fgets(name, MAX, stdin) != NULL)

	// if(fgets(name, MAX, stdin)) - можно сократить

	{

		printf("Your name: %s\n", name);

	}

 	else

	{

		printf("Critical Error!!!");

	}

	return 0;

}
```

для эмуляции ошибки можно передать в функцию вторым параметром число 0.

### fgets и scanf

при использовании функции `fgets()` после функции `scanf()` можно столкнуться с некорректным вводом:

```c


#include <stdio.h>



#define N 32



int main(void){

    int age;

    char name[N];

    // считываем возраст в переменную age

    printf("Input age: ");

    scanf("%d", &age);

    // считываем строку в переменну. name

    printf("Input name: ");

    fgets(name, N, stdin);



    // проверяем ввод

    printf("Age: %d\n", age);

    printf("Name: %s\n", name);

}
```

сначала с помощью функции `scanf()` считывается число в переменную age. после этого считывается имя, строка с помощью функции `fgets()`, в переменную name. результат работы программы:

```bash


Input age: 39

Input name: Age: 39Name:
```

ввод имени с помощью fgets как будто пропускается. по крайней мере имя ввести нельзя, а программа сразу же выводит результат.

дело в том, что функция `scanf()` считывает именно то, что ей предписано: число в виде переменной типа int. все остальные символы остаются в буфере, в который предварительно попадают введённые с клавиатуры символы. так, после ввода возраста нажимается клавиша enter, и в буфер попадает символ "\n", то есть перевод строки. и fgets считывает этот символ из буфера, после чего ввод имени завершается. это не то поведение, на которое рассчитывали.

чтобы исправить ситуацию, применяются различные приёмы. ниже два из них. все они сводятся к тому, чтобы вынуть из буфера этот символ перевода строки.

первый способ: считывание символа с помощью вызова `scanf("%*c")`:

```c


#include <stdio.h>



#define N 32



int main(void){

    int age;

    char name[N];

    // считываем возраст в переменную age

    printf("Input age: ");

    scanf("%d", &age);



    scanf("%*c"); // вытаскиваем символ из буфера

    // считываем строку в переменну. name

    printf("Input name: ");

    fgets(name, N, stdin);



    // проверяем ввод

    printf("Age: %d\n", age);

    printf("Name: %s\n", name);

}
```

спецификатор `%*c` читает один символ и отбрасывает его: модификатор `*` подавляет присваивание.

второй способ: символ считывается с помощью `getchar()`:

```c


#include <stdio.h>



#define N 32



int main(void){

    int age;

    char name[N];

    // считываем возраст в переменную age

    printf("Input age: ");

    scanf("%d", &age);



    getchar(); // вытаскиваем символ из буфера

    // считываем строку в переменну. name

    printf("Input name: ");

    fgets(name, N, stdin);



    // проверяем ввод

    printf("Age: %d\n", age);

    printf("Name: %s\n", name);

}
```

оба приёма хрупки, если после числа в буфере оказалось несколько символов, а не один `\n`. надёжнее читать обе лексемы через `fgets` и разбирать строку `sscanf`, либо явно вычищать буфер до перевода строки.

результат работы программы:

```bash


Input age: 39

Input name: Tom

Age: 39

Name: Tom
```
