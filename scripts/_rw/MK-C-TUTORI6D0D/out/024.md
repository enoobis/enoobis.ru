отдельного разговора заслуживают указатели на константы и константные указатели. начать стоит с того, что значения констант доступны для манипуляций через указатели. хотя константа задумана как неизменяемая сущность, указатель позволяет записать в неё новое значение. например:

```c
#include <stdio.h>


int main(void)
{
    const int cx = 10;
	// получаем адрес константы, преобразуем в указатель типа int* и изменяем по нему значение
    *(int*) &cx = 20;	
    printf("cx: %d\n", cx);  // cx: 20

	// то же самое, только разбито на два этапа
    int* cx_p = &cx;	
    *cx_p = 66;
    printf("cx: %d\n", cx);	// cx: 66
    return 0;
}
```

с точки зрения стандарта такой код некорректен. неявное преобразование `const int *` в `int *` во втором фрагменте отбрасывает квалификатор и является нарушением ограничения, на которое компилятор обязан выдать диагностику (gcc выводит предупреждение). явное приведение в первом фрагменте диагностику подавляет, но сама запись в объект, объявленный с const, даёт неопределённое поведение. показанный вывод характерен для сборки без оптимизаций; при оптимизации компилятор вправе подставлять в printf исходное значение 10, а константа со статическим временем хранения может оказаться в памяти только для чтения, и запись приведёт к аварийному завершению.

### указатели на константы

помимо переменных, программа на c может хранить данные в константах, объявленных с ключевым словом **const**. указатель тоже может указывать на константу, и в этом случае в его определении также ставится const:

```c
#include <stdio.h>

int main(void)
{
	const int a = 10;
	const int *pa = &a;
	printf("address=%p \t value=%d \n", pa, *pa);
	
	return 0;
}
```

здесь указатель `pa` указывает на константу `a`. изменить значение по адресу, который хранится в указателе, через него не получится, например так:

```c
*pa = 34;
```

такая запись приводит к ошибке компиляции: выражение `*pa` имеет тип `const int` и не является модифицируемым lvalue.

возможна ситуация, когда указатель на константу на самом деле указывает на обычную переменную:

```c
#include <stdio.h>

int main(void)
{
	int a = 10;
	const int *pa = &a;
	printf("value=%d \n", *pa);		// 10
	a = 22;
	printf("value=%d \n", *pa);		// 22
	//*pa = 34;		// так делать нельзя
	
	return 0;
}
```

в этом случае саму переменную можно изменять напрямую, но изменить её значение через указатель по-прежнему нельзя. квалификатор const у указываемого типа описывает не свойство объекта, а права доступа через конкретный путь: `const int *` означает «только чтение через этот указатель». преобразование `int *` в `const int *` безопасно и выполняется неявно, обратное требует явного приведения.

через указатель на константу нельзя изменить значение переменной или константы, но самому указателю можно присвоить адрес любой другой переменной или константы:

```c
int a = 10;
const int *pa = &a;		// указатель указывает на переменную a
const int b = 45;
pa = &b;				// указатель указывает на константу b
```

### константные указатели

кроме того, можно определять **константные указатели**. они не позволяют менять хранимый в них адрес, но позволяют менять значение по этому адресу. квалификатор здесь ставится после звёздочки и относится к самому указателю; объявление удобно читать справа налево: `pa` есть константный указатель на int.

```c
int a = 10;
int *const pa = &a;
printf("value=%d \n", *pa);		// 10
*pa = 22;						// меняем значение
printf("value=%d \n", *pa);		// 22

int b = 45;
// pa = &b;			так нельзя сделать
```

константный указатель, как и любой const-объект, должен быть инициализирован при определении, поскольку присвоить ему значение позже нельзя.

### константный указатель на константу

объединение двух предыдущих случаев даёт **константный указатель на константу**, который не позволяет менять ни хранимый в нём адрес, ни значение по этому адресу:

```c
int a = 10;
const int *const pa = &a;

//*pa = 22;	 так сделать нельзя

int b = 45;
// pa = &b;	 так сделать нельзя
```
