для ввода данных из консоли применяется функция **scanf()**. она объявлена в заголовочном файле **stdio.h**, там же, где и `printf`, и имеет следующее формальное определение:

```c
scanf(форматная_строка, аргументы)
```

и форматная строка, и аргументы для `scanf` обязательны. в отличие от `printf`, аргументы должны быть lvalue, в которые функция запишет преобразованные значения: семантика вызова требует передачи адресов объектов-приёмников.

форматная строка содержит спецификации преобразования, которые определяют, как интерпретировать вводимые данные. общий вид спецификации:

```c
% * ширина_поля модификатор спецификатор
```

из этих элементов обязательны только два: знак процента `%` и спецификатор. остальные поля необязательны и уточняют ширину, назначение и размер типа.

спецификатор задаёт тип вводимых данных:

- %c : считывает один символ

- %d : считывает десятичное целое число

- %i : считывает целое число в любой системе (десятичной, шестнадцатеричной, восьмеричной)

- %u : считывает положительное целое число

- %e : считывает число с плавающей точкой в экспоненциальной форме

- %E : считывает число с плавающей точкой в экспоненциальной форме с заглавным символом экспоненты

- %f : считывает число с плавающей точкой

- %F : считывает число с плавающей точкой

- %g : считывает число с плавающей точкой

- %G : считывает число с плавающей точкой

- %o : считывает восьмеричное число

- %x : считывает шестнадцатеричное число

- %X : считывает шестнадцатеричное число

- %s : считывает строку

- %% : считывает символ процента

`%i` отличается от `%d` тем, что основание системы счисления выводится из префикса входной лексемы: `0x` задаёт шестнадцатеричную запись, ведущий `0` без `x` задаёт восьмеричную. `%d` всегда трактует последовательность как десятичную. `%u` соответствует беззнаковому целому: ноль допустим, знак минус формально не входит в ожидаемую лексику.

символ звёздочки `*` в спецификации преобразования подавляет присваивание: соответствующий фрагмент ввода считывается и отбрасывается, объект-приёмник для него не передаётся.

ширина поля: целое положительное число, ограничивающее, сколько символов (для однобайтовой кодировки совпадает с числом байт) будет учтено при данном преобразовании. чтение останавливается раньше, если встретился разделитель или данные кончились.

модификаторы уточняют размер типа приёмника. в частности:

- h : для ввода значений типа short int ( `%hd` )

- l : для ввода значений типа long int ( `%ld` ) или double ( `%lf` , `%le` )

- L : для ввода значений типа long double ( `%Lf` , `%Le` )

несоответствие модификатора фактическому типу аргумента даёт неопределённое поведение: `scanf` не знает тип объекта, он следует только форматной строке.

в качестве аргументов в **scanf()** передаются адреса переменных, которые получат введённое значение. адрес берётся унарной операцией **&**. если переменная называется `age`, её адрес есть `&age`. запись по адресу нужна потому, что аргументы функций в c передаются по значению: без адреса `scanf` не смог бы изменить объект вызывающей стороны.

пример ввода целого числа с консоли:

```c
#include <stdio.h>

int main(void)
{
	int age;
	printf("Input your age:");
	scanf("%d", &age);
	
	printf("age = %d", age);
	return 0;
}
```

для переменной `age` типа **int** в форматную строку передаётся спецификатор **%d**. ни звёздочка, ни ширина поля, ни модификаторы не используются. второй параметр: адрес `age`, выражение `&age`.

после успешного преобразования значение доступно в переменной, его можно, например, вывести на консоль:

```bash
Input your age:44
age = 44
```

ввод данных других типов устроен так же, меняются спецификатор и модификатор:

```c
#include <stdio.h>

int main(void)
{
	double price;
    long code;
	printf("Enter the product code: ");
	scanf("%ld", &code);
	printf("Enter the price: ");
	scanf("%lf", &price);
	printf("Product code: %ld \t price: %.2lf \n", code, price);
	return 0;
}
```

`long` требует `%ld`, `double` требует `%lf` (для `scanf` спецификатор `%f` соответствует `float`, в отличие от `printf`, где `%f` печатает `double`). после ввода значения используются дальше, в том числе выводятся на консоль:

```bash
Enter the product code: 1234
Enter the price: 234.567
Product code: 1234       price: 234.57
```

несколько значений можно прочитать одним вызовом. разделителем во входном потоке служит пробел (и вообще пробельные символы: пробел, табуляция, перевод строки):

```c
#include <stdio.h>

int main(void)
{
    int count;
	double price;
    long code;
	printf("Enter product data: ");
	scanf("%ld %d %lf", &code, &count, &price);
	printf("Product code: %ld \tcount: %d \tprice: %.2lf\n", code, count, price);
	return 0;
}
```

`scanf` сопоставляет спецификации с лексемами ввода и записывает преобразованные значения в переданные объекты. консольный ввод-вывод:

```bash
Enter product data: 1234 3 234.56
Product code: 1234      count: 3        price: 234.56
```

### ввод строк

**scanf()** позволяет вводить и строки. пример:

```c
#include <stdio.h>

int main(void)
{
	char name[10];
	// вводим имя
	printf("Enter your name: ");
	scanf("%10s", name);
	
	printf("Name: %s \n",name);
	return 0;
}
```

под имя выделяется массив из 10 символов. теоретически во входном потоке может оказаться больше символов, поэтому в форматную строку передаётся ширина поля `%10s`: функция прекратит чтение, когда наберёт указанное число символов либо встретит пробельный разделитель. для массива `char name[10]` безопасная ширина равна 9: `scanf` дописывает завершающий `'\0'`, и `%10s` может записать 11 байт.

для ввода строки перед именем переменной не ставится операция взятия адреса.

```c
scanf("%10s", name);
```

имя массива в выражении преобразуется к указателю на первый элемент, то есть уже является адресом. передача `&name` имела бы тип `char(*)[10]` и не соответствовала бы спецификатору `%s`.

возможный консольный вывод:

```bash
Enter your name: Tom
Name: Tom
```

у `%s` есть существенное ограничение: преобразование останавливается на первом пробельном символе. составное имя, в котором подстроки разделены пробелами, например `"Tom Smith"`, будет прочитано только до пробела:

```bash
Enter your name: Tom Smith
Name: Tom
```

чтобы прочитать строку до конца строки ввода, применяют scanset, набор допустимых символов в квадратных скобках:

```c
#include <stdio.h>
int main(void)
{
	char name[10];
	printf("Enter your name: ");
	scanf("%10[^\n]", name);
	
	printf("Name: %s \n",name);
	return 0;
}
```

спецификатор `%10[^\n]` по-прежнему ограничивает чтение десятью символами. квадратные скобки `[]` задают множество символов, которые извлекаются из ввода, либо, при ведущем `^`, множество символов-ограничителей. выражение `[^\n]` означает: читать, пока не встретится символ перевода строки `'\n'`, то есть пока не будет нажата клавиша enter. пробелы при этом входят в считанную последовательность.
