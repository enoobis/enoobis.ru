### установка компилятора

первая простейшая программа на c в этом курсе создаётся с помощью компилятора **gcc**, одного из наиболее популярных компиляторов c, доступного для разных платформ. подробная информация о gcc приведена на официальном сайте проекта [https://gcc.gnu.org/](https://gcc.gnu.org/). gcc (gnu compiler collection) представляет собой набор компиляторов с общей инфраструктурой оптимизации и генерации кода, а программа `gcc` выступает драйвером, который последовательно вызывает препроцессор, собственно компилятор, ассемблер и компоновщик.

набор компиляторов gcc распространяется в различных сборках. для windows одной из наиболее популярных является пакет средств разработки некоммерческого проекта **msys2**. msys2 требует 64-битную windows 7 или более позднюю версию, vista, xp и более ранние системы не поддерживаются (актуальные версии msys2 уже требуют windows 10 и выше).

программа установки msys2 загружается с официального сайта [MSYS2](https://www.msys2.org/):

![установка msys для разработки под с](/uploads/course-lectures/9005c6d416f1ef3b101c40f18c6736f28a2c0730.png)

после загрузки запускается программа установки:

![установка пакета mingw-w64 и msys2 на windows](/uploads/course-lectures/5ba2a9584f6845a83f2ef1b82211ef1ac5df6c20.png)

на первом шаге предлагается выбрать каталог установки, по умолчанию это C:\msys64:

![установка компиляторов си msys2 на windows](/uploads/course-lectures/ce101976c7926b99e82229f7220da59cd4b35d4c.png)

каталог можно оставить по умолчанию или изменить. на следующем шаге задаются параметры ярлыка в меню пуск, затем выполняется сама установка. по её завершении отображается финальное окно, в котором нажимается кнопка завершить.

![установка компиляторов msys2 на windows](/uploads/course-lectures/89abbc2d1dce1f7aded53a86a77af598e3a2e897.png)

после установки запускается консольное приложение MSYS2.exe. если по каким-то причинам оно не запустилось, в папке установки C:/msys64 следует найти файл **usrt_64.exe**:

![компиляторы msys2.exe на windows](/uploads/course-lectures/24ebe23849387f1e755f1283142e90b2885d1b94.png)

далее устанавливается собственно набор компиляторов gcc. для этого в приложении вводится команда:

```consoletext
pacman -S mingw-w64-ucrt-x86_64-gcc
```

для управления пакетами msys2 использует пакетный менеджер pacman, заимствованный из arch linux. приведённая команда указывает pacman установить пакет `mingw-w64-ucrt-x86_64-gcc`, содержащий набор компиляторов gcc (имя пакета указывается после параметра `-S`). префикс `ucrt` означает, что программы будут компоноваться с universal c runtime, современной реализацией стандартной библиотеки c от microsoft.

![установка компиляторов msys2 на windows](/uploads/course-lectures/238c9885e85ef5249d6a21a1f74fea80dee0339e.png)

### создание первой программы

после установки компилятора можно написать первую программу. для набора исходного кода подойдёт любой текстовый редактор: распространённый visual studio code или даже встроенный блокнот.

на диске создаётся папка для исходных файлов, а в ней новый файл с именем **hello.c**.

![первая программа на си в windows](/uploads/course-lectures/a13de346f4504c3b7efab8da0efda357429f41da.png)

в примерах курса файл hello.c находится в папке C:\c.

в файле **hello.c** определяется простейший код, выводящий строку на консоль:

```c
#include <stdio.h>			// подключаем заголовочный файл stdio.h
int main(void)						// определяем функцию main
{									// начало функции
	printf("Hello enoobis.ru!\n");	// выводим строку на консоль
	return 0;						// выходим из функции
}									// конец функции
```

для вывода строки на консоль необходимо подключить соответствующий функционал. для этого в начале файла стоит строка

```c
#include <stdio.h>
```

директива препроцессора include подключает заголовочный файл stdio.h, содержащий объявление функции printf, которая выводит строку на консоль. препроцессор буквально подставляет содержимое заголовка в текст программы до начала компиляции, поэтому к моменту разбора вызова `printf` компилятору уже известен её прототип.

далее следует определение функции **int main(void)**. функция main должна присутствовать в любой размещённой (hosted) программе на c, с неё начинается выполнение приложения.

ключевое слово **int** в определении `int main(void)` указывает, что функция возвращает целое число. слово void в скобках означает, что функция не принимает параметров. в c, в отличие от c++, пустой список параметров `()` до c23 означал функцию с неуказанными параметрами, поэтому явное `void` здесь имеет содержательный смысл.

тело функции main заключено в фигурные скобки {}. в теле функции строка выводится на консоль с помощью функции printf, которой передаётся выводимая строка "Hello enoobis.ru!".

в конце выполняется выход из функции оператором **return**. поскольку функция должна возвращать целое число, после return указывается 0. ноль служит индикатором успешного завершения программы: возвращаемое из main значение передаётся окружению как код завершения процесса.

каждая инструкция в функции завершается точкой с запятой.

![язык программирования си в visual studio code](/uploads/course-lectures/98922a8b3eea198e0b2ab6f5f069199299739282.png)

далее файл компилируется. для этого открывается командная строка windows, и командой cd выполняется переход в папку с исходным файлом:

```consoletext
cd C:\c
```

для компиляции исходного кода компилятору gcc в качестве параметра передаётся файл hello.c:

```consoletext
gcc hello.c
```

в результате создаётся исполняемый файл, который в windows по умолчанию называется **a.exe**. его можно запустить:

```consoletext
a.exe
```

консоль выведет строку "Hello enoobis.ru!", как и задано в коде.

имя выходного файла можно задать флагом **-o**, передав ему имя файла, в который будет скомпилирована программа. например:

```consoletext
gcc hello.c -o hello.exe
```

в этом случае программа компилируется в файл `hello.exe`, который также можно запустить.

![запуск компилятора gcc на windows](/uploads/course-lectures/4704e67c7c45eb487af18a25d86c043d927f748f.png)

чтобы не вводить две команды, одну для компиляции и другую для запуска, их можно объединить:

```consoletext
gcc hello.c -o hello.exe & hello
```

эта команда сначала компилирует код в файл hello.exe, а затем сразу запускает его. оператор `&` в cmd выполняет вторую команду независимо от успеха первой, при необходимости запуска только после успешной компиляции используется `&&`.
