на структуры, как и на объекты любых других типов, можно определять указатели. например, указатель на структуру person объявляется так:

```c
struct person *p;
```

указатели на структуры можно создавать и для безымянных структурных типов. в этом случае тип указателя доступен только в данном объявлении, и объявить позднее совместимый с ним указатель через имя типа уже не получится:

```c


struct

{

	int age;

	char name[20];

} *p1, *p2;
```

значением такого указателя служит адрес объекта структуры того же типа:

```c


struct person kate = {31, "Kate"};

struct person *p_kate = &kate;
```

через указатель на структуру обеспечивается доступ к её элементам. для этого существуют две формы записи. первая использует операцию разыменования, после которой к полученному объекту применяется операция «точка». скобки здесь обязательны, поскольку приоритет постфиксной операции «.» выше, чем у унарной «*»:

```c
(*указатель_на_структуру).имя_элемента
```

вторая форма использует операцию **->** (операцию «стрелка»), которая по определению эквивалентна первой и служит лишь синтаксическим сокращением:

```c
указатель_на_структуру->имя_элемента
```

применим обе формы для обращения к элементам структуры:

```c


#include <stdio.h>



struct person 

{

	int age;

	char name[20];

};



int main(void)

{

	struct person kate = {31, "Kate"};

	// указатель на переменную kate

	struct person * p_kate = &kate;

	

	// получаем значение элемента name

	// получаем значение элемента age

	char * name = p_kate->name;

	int age = (*p_kate).age;

	

	printf("name = %s \t age = %d \n", name, age);

	

	// изменим элемент age в структуре

	p_kate->age = 32;

	printf("name = %s \t age = %d \n", kate.name, kate.age);

	return 0;

}
```

здесь определяется указатель p_kate на переменную kate. через этот указатель можно как читать, так и изменять значения элементов структуры, и изменения видны при последующем обращении к самой переменной kate, поскольку указатель и переменная обозначают один и тот же объект в памяти.

### ссылка структуры на саму себя

элементом структуры может быть указатель на структуру того же типа. такая конструкция типична для структур данных, состоящих из связанных звеньев, например для связных списков, где каждый элемент хранит указатель на следующий и/или предыдущий элемент того же структурного типа. это допустимо, потому что внутри собственного определения структура является неполным типом, а указатель на неполный тип объявлять разрешено: его размер известен независимо от размера структуры. например:

```c


struct node

{

    char* value;     // значение 

    struct node* next;     // указатель на следующий узел

};
```

структура `node` имеет два элемента. элемент `value` хранит собственно значение узла, а элемент `next` является указателем на следующий объект структуры node. назначение такого указателя видно из следующего примера:

```c


#include <stdio.h>

 

struct node

{

    char* value;

    struct node* next;

};

 

int main(void)

{

    struct node kate = {.value = "Kate"};

    struct node tom = {.value = "Tom" };

    struct node bob = {.value = "Bob"};



    kate.next = &tom;   // Kate - Tom

    tom.next = &bob;    // Tom - Bob



    // устанавливаем указатель на первую структуру в цепочке

    struct node * pointer = &kate;

    while(pointer != NULL)

    {

        printf("value = %s \n", pointer->value);

        pointer = pointer->next;		// переходим к следующему объекту

    }

    return 0;

}
```

здесь определяются три переменные структурного типа: kate, tom и bob. поскольку при инициализации с назначенными инициализаторами явно задаётся только поле value, остальные поля инициализируются нулём, то есть next изначально равен `NULL`. у объекта kate элемент next указывает на объект tom:

```c
kate.next = &tom;
```

а у объекта tom элемент next указывает на объект bob:

```c
tom.next = &bob;
```

в результате образуется цепочка `Kate - Tom - Bob`, то есть простейший односвязный список объектов структуры node.

с помощью этих указателей по списку можно перемещаться в прямом направлении. для этого сначала указатель устанавливается на первую структуру:

```c
struct node * pointer = &kate;
```

далее в цикле while, пока указатель pointer не перестанет указывать на какой-либо объект структуры (то есть пока он не станет равен `NULL`), выводится значение `value` текущего объекта, на который указывает pointer, после чего указателю присваивается значение `pointer->next`, то есть выполняется переход к следующей структуре в списке:

```c


while(pointer != NULL)

{

    printf("value = %s \n", pointer->value);

    pointer = pointer->next;

}
```

так можно определять связанные наборы объектов без использования массивов. в отличие от массива, элементы такого списка не обязаны располагаться в памяти непрерывно, вставка и удаление узла выполняются за константное время, если известен предшествующий узел, а доступ к произвольному элементу требует линейного обхода.

### объявление структуры

указатели на структуры оказываются полезны и в том случае, когда определение структуры следует после её использования. например:

```c


struct rectangle

{

    struct color background;

    unsigned width;

    unsigned height;

};

struct color

{

    unsigned char red; 

    unsigned char green; 

    unsigned char blue; 

    unsigned char alpha; 

};
```

здесь структура rectangle (прямоугольник) содержит поле, имеющее тип структуры color (цвет фона). однако структура color определена после структуры rectangle, поэтому при компиляции возникает ошибка:

```bash
error: field 'background' has incomplete type
```

как следует из сообщения, тип поля background, то есть структура color, в этой точке является неполным (incomplete type). для размещения поля по значению компилятору необходимо знать его размер и выравнивание, а у неполного типа они неизвестны. можно было бы просто определить структуру color до структуры rectangle, но в крупных программах из множества файлов отследить весь порядок определения и использования типов бывает затруднительно. кроме того, может потребоваться определить структуры, которые рекурсивно ссылаются друг на друга, например так:

```c


struct A

{

    struct B b; // Ошибка - incomplete type

}

struct B

{

    struct A a;

}
```

взаимное включение по значению невозможно в принципе, поскольку размер каждой из структур тогда должен был бы включать размер другой. в таких случаях структура сначала объявляется (без определения её полей), а при использовании применяется указатель на неё:

```c


#include <stdio.h>



struct color;       // объявление структуры

struct rectangle

{

    struct color* background;   // указатель на структур

    unsigned width;

    unsigned height;

};

struct color        // определение структуры

{

    unsigned char red; 

    unsigned char green; 

    unsigned char blue; 

    unsigned char alpha; 

};

  

int main(void)

{

    // пример использования

    struct  color backgroundColor = {255, 0, 0, 125};

    struct rectangle rect = {.width=100, .height=50, .background = &backgroundColor};

    printf("Rectangle color: %d, %d, %d", 

                        rect.background->red, 

                        rect.background->blue, 

                        rect.background->green);

    return 0;

}
```

аналогично решается задача с взаимно рекурсивными структурами:

```c


struct B;   // объявление

struct A

{

    struct B* b;    // указатель на структуру

};

struct B    // определение

{

    struct A* a;

};
```

### более сложные случаи

рассмотрим следующий пример:

```c


#include <stdio.h>



// указатель на константную структуру

const struct Number { int value; } * p;



int main(void)

{

    struct Number num = {6};

    num.value = 7;

    printf("num: %d\n", num);  // num: 7

    //p->value = 9;     // нельзя

    //printf("pvalue: %d\n", p->value);   // Segmentation fault

    

    p = &num;   // переустанавливаем указатель, но изменить по нему значение опять нельзя

    printf("pvalue: %d\n", p->value);   // pvalue: 7

    // p->value = 9;     // нельзя



    return 0;

}
```

здесь одновременно с определением структуры Number определяется указатель p. квалификатор const относится к типу структуры, поэтому p является указателем на константную структуру: изменить значение объекта через этот указатель нельзя, тогда как сам указатель изменять можно. поскольку p объявлен в области видимости файла, он имеет статическую длительность хранения и неявно инициализируется значением `NULL`, поэтому его разыменование до присваивания адреса приводит к ошибке сегментации. отдельно отметим, что передача структуры в printf по спецификатору `%d`, как в строке с `num`, формально является неопределённым поведением, и вывод `num: 7` в комментарии отражает лишь типичное поведение на конкретной платформе.

другой пример:

```c


#include <stdio.h>



// PNumber - тип указателей на константную структуру

typedef const struct Number { int value; } *PNumber;



int main(void)

{

    struct Number num = {6};

    num.value = 7;

    printf("num: %d\n", num);  // num: 7

    

    PNumber p = &num;   // PNumber - это тип - указатель на константу-структуру

    printf("pvalue: %d\n", p->value);   // pvalue: 7

    //p->value = 9;     // нельзя



    // но можно изменить значение самого указателя

    struct Number num2 = {8};

    p = &num2;   

    printf("pvalue: %d\n", p->value);   // pvalue: 8

    return 0;

}
```

здесь с помощью typedef определяется имя PNumber, обозначающее тип указателя на константную структуру Number. соответственно изменить значение объекта по указателю типа PNumber также нельзя. однако можно изменить значение самого указателя, то есть установить его на адрес другой переменной.

при этом такой указатель можно сделать и константным:

```c


#include <stdio.h>



// PNumber - тип указателей на константную структуру

typedef const struct Number { int value; } *PNumber;



int main(void)

{

    int x = 5;

    const int cx = 10;

    struct Number num1 = {6};

    struct Number num2 = {7};

    

    const PNumber p = &num1;   

    printf("pvalue: %d\n", p->value);   // pvalue: 6

    // p = &num2;   // так нельзя

    // printf("pvalue: %d\n", p->value); 



    return 0;

}
```

в объявлении `const PNumber p` квалификатор const применяется к самому типу-синониму, то есть к указателю, а не к структуре: typedef не является текстовой подстановкой, поэтому запись не эквивалентна `const const struct Number *p`. в результате p становится константным указателем на константную структуру, и ни изменить объект через него, ни переустановить сам указатель на другой адрес нельзя.
