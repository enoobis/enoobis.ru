**составные литералы** (**compound literals**), введённые стандартом c99, позволяют сократить код и использовать литералы, представляющие значение структуры, без определения именованной переменной структуры. синтаксически составной литерал выглядит как приведение типа, за которым следует список инициализации. рассмотрим следующую программу:

```c
#include <stdio.h>

typedef struct{
    int x;
    int y;
} Point; 

void print_point(Point p){
    printf("(X:%d; Y:%d)\n", p.x, p.y);
}

int main() {
    
    print_point((Point){.x=1, .y=2});
    print_point((Point){3, 4});

    return 0;
}
```

здесь определена простейшая структура Point с двумя полями, а для её вывода на консоль определена функция print_point. в функции main в функцию print_point передаются две структуры, однако переменные этой структуры явно не определяются: вместо них используются составные литералы, которые создают безымянные объекты типа Point. в первом случае применяется форма литерала с назначенными инициализаторами, то есть с указанием имён полей:

```c
print_point((Point){.x=1, .y=2});
```

во втором случае значения сопоставляются полям по позиции:

```c
print_point((Point){3, 4});
```

консольный вывод:

```bash
(X:1; Y:2)
(X:3; Y:4)
```

составной литерал является lvalue и обозначает объект: внутри функции он имеет автоматическую длительность хранения, связанную с объемлющим блоком, а вне функций статическую. поэтому составные литералы можно применять везде, где требуется значение структуры. типичный пример: возврат структуры из функции:

```c
#include <stdio.h>

typedef struct{
    int x;
    int y;
} Point; 

void print_point(Point p){
    printf("(X:%d; Y:%d)\n", p.x, p.y);
}

Point create_point(int x, int y){
    return (Point) {x, y};
}
int main() {

    Point p = create_point(170, 150);
    print_point(p);
    return 0;
}
```

функция create_point возвращает структуру, сформированную составным литералом, и определять для этого отдельную переменную не требуется. значение возвращается копией, поэтому окончание времени жизни литерала при выходе из функции на корректность не влияет.

составные литералы применимы и к массивам:

```c
#include <stdio.h>

typedef struct{
    int x;
    int y;
} Point; 


void print_points(Point* points, size_t count){
    for(size_t i=0; i<count; ++i){
        printf("(X:%d; Y:%d)\n", points[i].x, points[i].y);
    }
}

int main() {
    
    print_points((Point[]){{5, 10}, {10, 15}, {15, 20}}, 3);
    print_points((Point[]){{.x=6, .y=11}, {.x=11, .y=16}, {.x=16, .y=21}}, 3);

    return 0;
}
```

здесь в функцию print_points передаются массивы структур, заданные составными литералами. размер массива выводится из числа инициализаторов, а сам массив при передаче преобразуется к указателю на первый элемент, поэтому количество элементов передаётся отдельным аргументом.
