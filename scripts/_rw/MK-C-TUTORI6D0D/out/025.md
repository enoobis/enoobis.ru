в c массивы и указатели тесно связаны. к элементам массива можно обращаться через указатели так же свободно, как через индексы.



имя массива без индекса в выражении в c даёт адрес его первого элемента. соответственно, сочетание имени массива и индекса позволяет получить адрес любого элемента:



```c


int numbers[] = {11, 12, 13, 14}; 

    

for(size_t i=0; i< sizeof(numbers) / sizeof(numbers[0]); ++i){

    printf("numbers[%d]: %p\n", i, numbers+i);

}
```



пример вывода (для переменной типа size_t корректный спецификатор `%zu`, а аргумент для `%p` строго должен иметь тип `void *`, но на распространённых платформах код работает и так):



```bash


numbers[0]: 0x7fffb4d10140

numbers[1]: 0x7fffb4d10144

numbers[2]: 0x7fffb4d10148

numbers[3]: 0x7fffb4d1014c
```



конкретные адреса от запуска к запуску могут различаться, но адрес каждого следующего элемента всегда отличается от предыдущего на размер элемента. вывод показывает, что элементы массива расположены в памяти непрерывно, и стандарт это гарантирует. графически это можно представить так:



| Адрес | 0xd10140 | 0xd10144 | 0xd10148 | 0xd1014c |
| --- | --- | --- | --- | --- |
| Значение | 11 | 12 | 13 | 14 |



поскольку имя массива в выражении превращается в указатель на первый элемент, операция разыменования, применённая к нему, даёт значение по этому адресу:



```c


#include <stdio.h>



int main(void)

{

	int array[] = {1, 2, 3, 4, 5};

	printf("array[0] = %d", *array);	// array[0] = 1



    return 0;

}
```



связь массива и указателя прямо зафиксирована стандартом языка c (раздел 6.3.2.1, параграф 3): «за исключением случаев, когда это операнд оператора sizeof или унарный оператор &... выражение, имеющее тип «массив типа», преобразуется в выражение с типом «указатель на тип», которое указывает на начальный элемент объекта массива и не является lvalue». иначе говоря, массив как целое участвует лишь в операциях sizeof и & (а также служит строковым литералом при инициализации массива), во всех остальных контекстах он неявно преобразуется к соответствующему типу указателя. это преобразование называют низведением массива (array decay), и именно поэтому массив нельзя передать в функцию или вернуть из неё по значению.




прибавляя целое число к имени массива, можно получить указатель на соответствующий элемент:


```c


#include <stdio.h>



int main(void)

{

	int array[] = {1, 2, 3, 4, 5};

	int second = *(array + 1); // получим второй элемент

	printf("array[1] = %d", second);	// array[1] = 2



    return 0;

}
```



более того, обращение к элементу массива через квадратные скобки, например:


```c
array[2]
```



компилятор по определению трактует как `*(array + 2)`, то есть как прибавление индекса к указателю на начальный элемент:


```c
array+2
```



поскольку сложение коммутативно, допустима даже запись `2[array]`, которая тоже является корректным обращением к элементу массива:


```c


#include <stdio.h>



int main(void)

{

	int array[] = {1, 2, 3, 4, 5};

    int third = 2[array];

	printf("array[2] = %d", third);	// array[2] = 3



    return 0;

}
```




соответственно, обойти все элементы массива можно, прибавляя к адресу последовательные смещения:


```c


#include <stdio.h>



int main(void)

{

    int array[5] = {1, 2, 3, 4, 5};

     

    for(int i = 0; i < 5; i++)

    {

        void* address = array + i;  // получаем адрес i-го элемента массива

        int value = *(array + i);   // получаем значение i-го элемента массива

        printf("array[%d]: address=%p \t value=%d \n", i, address, value);

    }

    return 0;

}
```



например, адрес второго элемента задаётся выражением `a+1`, а его значение выражением `*(a+1)`.



сложение и вычитание здесь подчиняются тем же правилам, что и в арифметике указателей. прибавление единицы увеличивает адрес на размер элемента массива. массив в примере имеет тип **int**, размер которого обычно составляет 4 байта, поэтому прибавление единицы увеличивает адрес на 4, прибавление 2 увеличивает его на 4 * 2 = 8, и так далее.



результат работы программы на тестовой машине:



```bash


array[0]: address=0060FE98	value=1

array[1]: address=0060FE9C	value=2

array[2]: address=0060FEA0	value=3

array[3]: address=0060FEA4	value=4

array[4]: address=0060FEA8	value=5
```



при этом имя массива не является обычным указателем: оно обозначает сам объект массива, а результат его преобразования не является lvalue. поэтому изменить «адрес массива» нельзя, например так:



```c


int array[5] = {1, 2, 3, 4, 5};

array++;			// так сделать нельзя

int b = 8;

array = &b;			// так тоже сделать нельзя
```



### использование указателя для работы с массивом



имя массива всегда даёт адрес первого элемента, поэтому его можно присвоить отдельному указателю и обращаться к элементам массива через этот указатель:



```c


#include <stdio.h>

 

int main(void)

{

    int array[5] = {1, 2, 3, 4, 5};

    int *ptr = array;	// указатель ptr хранит адрес первого элемента массива array

    printf("value: %d \n", *ptr);	// 1

    return 0;

}
```



прибавляя к указателю или вычитая из него целое число, можно перемещаться по элементам массива. например, переход к третьему элементу:



```c


#include <stdio.h>

 

int main(void)

{

    int array[5] = {1, 2, 3, 4, 5};

    int *ptr = array;	// указатель ptr хранит адрес первого элемента массива array

    ptr = ptr + 2;      // перемезаем указатель на 2 элемента вперед

    printf("value: %d \n", *ptr);	// value: 3

    return 0;

}
```



указатель `ptr` изначально указывает на первый элемент массива. после увеличения на 2 он пропускает два элемента и указывает на `array[2]`.



как и для любых других данных, через указатель можно изменить значение элемента массива:


```c


#include <stdio.h>

 

int main(void)

{

    int array[5] = {1, 2, 3, 4, 5};

    int *ptr = array;	    // указатель ptr хранит адрес первого элемента массива array

    ptr = ptr + 2;          // переходим к третьему элементу

    *ptr = 8;               // меняем значение элемента, на который указывает указатель



    printf("array[2]: %d \n", array[2]);	// array[2] : 8

    return 0;

}
```



к указателю, как и к массиву, применима операция индексирования. это прямое следствие того, что `E1[E2]` определено как `*((E1)+(E2))` и на самом деле всегда работает с указателем:


```c


#include <stdio.h>

 

int main(void)

{

    int array[5] = {1, 2, 3, 4, 5};

    int *ptr = array;	    // указатель ptr хранит адрес первого элемента массива array



    int value = ptr[2];     // используем индексы - получаем 3-й элемент (элемент с индексом 2)



    printf("value: %d \n", value);	// value: 3

    return 0;

}
```
