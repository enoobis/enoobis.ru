язык c допускает функции с нефиксированным количеством параметров (вариадические функции). более того, неизвестным может быть не только число параметров, но и их типы: точный состав аргументов становится известен лишь в момент вызова функции, и компилятор не может проверить их на соответствие сигнатуре.

для обозначения параметров переменной длины в таких функциях используется многоточие:

```c
тип имя_функции(обязательные параметры, ...)
```

при этом функция должна иметь как минимум один обязательный параметр (стандарт c23 снял это ограничение и разрешил объявление вида `f(...)`, но в предшествующих версиях оно действует). например:

```c
int sum(int n, ...)
{
	//..........
}
```

для работы с переменным количеством параметров неопределённых типов стандартный заголовочный файл **stdarg.h** определяет специальные макросы:

```c
va_start();
va_arg();
va_end();
```

все эти макросы используют специальный тип данных **va_list**, также определённый в **stdarg.h**, который позволяет обходить нефиксированный набор параметров.

макрос **va_start** имеет следующее определение:

```c
void va_start(va_list param, последний_явный_параметр);
```

первый параметр макроса, `param`, связывает объект **va_list** с первым необязательным параметром. чтобы это сделать, вторым параметром в макрос передаётся последний обязательный параметр функции: от него объект **va_list** нацеливается на позицию первого необязательного параметра. в этой роли **va_list** фактически работает как указатель, хотя стандарт оставляет его устройство на усмотрение реализации, и на ряде архитектур, например x86-64 с соглашением system v, это структура, учитывающая передачу аргументов через регистры.

макрос **va_arg** имеет следующее определение:

```c
type va_arg(va_list param, type);
```

этот макрос возвращает значение очередного параметра типа `type` и переводит **va_list** на следующий необязательный параметр. тип должен совпадать с фактическим типом аргумента после стандартных повышений (default argument promotions): `char` и `short` передаются как `int`, `float` как `double`. несовпадение ведёт к неопределённому поведению.

макрос **va_end** завершает работу с переменным списком параметров и должен быть вызван перед выходом из функции. его определение:

```c
void va_end(va_list param);
```

в качестве параметра **va_end** принимает тот же объект va_list, который ранее использовался в макросах va_start и va_arg.

определим, например, функцию, вычисляющую сумму нефиксированного количества чисел:

```c
#include <stdio.h>
#include <stdarg.h>

int sum(int n, ...)
{
	int result = 0;
	va_list factor;			//указатель va_list
	va_start(factor, n);	// устанавливаем указатель
	for(int i=0;i<n; i++)
	{
		result += va_arg(factor, int);	// получаем значение текущего параметра типа int
	}
	va_end(factor);	// завершаем обработку параметров
	return result;
}

int main(void)
{	
	printf("%d \n", sum(4, 1, 2, 3, 4));
	printf("%d \n", sum(5, 12, 21, 13, 4, 5));
	return 0;
}
```

в функции `sum()` сначала объявляется объект `va_list factor;`.

затем он связывается с первым необязательным параметром: `va_start(factor, n);`.

в цикле перебираются все необязательные параметры, и их значения прибавляются к переменной result: `result += va_arg(factor, int);`.

в конце обработка параметров завершается: `va_end(factor);`.

результат этой программы тот же, что и в предыдущем случае. однако количество необязательных параметров здесь по-прежнему приходится передавать первым параметром функции sum, а их тип int известен заранее. сам механизм не позволяет узнать ни число, ни типы переданных аргументов, поэтому эта информация всегда должна поступать по соглашению между вызывающей и вызываемой стороной.

используемые функции ввода-вывода **printf()** и **scanf()** тоже принимают неопределённое число параметров, причём их типы также заранее не определены:

```c
int printf(const char* format, ...);
int scanf(const char* format, ...);
```

для идентификации типов аргументов параметр format содержит спецификаторы %d, %c и так далее. определим, например, собственную функцию, которая выводит текст на экран, принимая параметры разных типов:

```c
#include <stdio.h>
#include <stdarg.h>

void display(char* format, ...)
{
	int d; 
	double f;
	va_list factor;			// указатель на необязательный параметр
	va_start(factor, format);	// устанавливаем указатель
	
	for(char *c = format;*c; c++)
	{
		if(*c!='%')
		{
			printf("%c", *c);
			continue;
		}
		switch(*++c)	// если символ - %, то переходим к следующему символу
		{
			case 'd': 
				d = va_arg(factor, int);
				printf("%d", d);
				break;
			case 'f': 
				f = va_arg(factor, double);
				printf("%.2lf", f);
				break;
			default:
				printf("%c", *c);
		}
	}
	va_end(factor);
}

int main(void)
{	
	display("Count: %d \tPrice: %f", 24, 68.4);
	return 0;
}
```

для простоты в примере поддерживаются только два спецификатора: d (для типа int) и f (для типа double). функция display с помощью указателя `char *c` перебирает символы переданной строки format, пока указатель не дойдёт до нулевого символа (`*c!='\0'`). если символ не равен знаку %, он выводится как есть. иначе анализируется символ после знака %, d или f, и в зависимости от него извлекается либо объект int, либо объект double. именно так строка формата заменяет отсутствующую в языке информацию о типах вариадических аргументов, а компиляторы вроде gcc и clang умеют проверять её соответствие аргументам для функций семейства printf.
