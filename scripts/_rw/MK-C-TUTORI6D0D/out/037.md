определение функции, то есть её возвращаемый тип и типы параметров, задаёт тип функции, и этому типу можно дать имя. для этого применяется спецификатор **typedef**:

```c
typedef возвращаемый_тип (название)(типы_параметров);
```

именованный тип функции упрощает работу с указателями на функции, поскольку избавляет от громоздких деклараторов. простейший пример:

```c
#include <stdio.h>
 
typedef void (message)(void);

void hello() { printf("Hello, World \n"); }
void goodbye() { printf("Good Bye, World \n");}

int main(void)
{
    message* mes1 = &hello;  // указатель указывает на функцию hello
    message* mes2 = &goodbye;  // указатель указывает на функцию goodbye

    mes1();      // Hello, World
    mes2();      // Good Bye, World
     
    return 0;
}
```

здесь определяется тип message, который служит псевдонимом для типа функции, не принимающей параметров и ничего не возвращающей (возвращаемый тип `void`). typedef не создаёт нового типа, а лишь вводит синоним существующего.

```c
typedef void (message)(void);
```

этот тип применяется для объявления переменных или параметров, представляющих функцию без параметров и без возвращаемого результата. для проверки в программе определены две такие функции, hello() и goodbye(). соответственно объявляется указатель на тип message, и ему присваивается адрес одной из них:

```c
message* mes1 = &hello;  // указатель указывает на функцию hello
```

переменная mes1 является указателем на функцию типа message и хранит адрес функции hello. дальше mes1 вызывается как обычная функция, а фактически вызывается функция, адрес которой хранится в mes1:

```c
mes1();      // Hello, World
```

консольный вывод:

```bash
Hello, World
Good Bye, World
```

рассмотрим другой пример, с параметрами и возвращаемым результатом:

```c
#include <stdio.h>
 
typedef int (binary_op)(int, int);	// определяем тип binary_op

int sum(int x, int y) { return x + y;}
int subtract(int x, int y) { return x - y;}

int main(void)
{
    int a = 10;
    int b = 5;
    int result;
    binary_op *op1 =&sum;
    binary_op *op2 =&subtract;

    result = op1(a, b);
    printf("result = %d \n", result);       // result=15 

    result = op2(a, b);
    printf("result = %d \n", result);       // result=5
     
    return 0;
}
```

здесь определяется тип binary_op, представляющий функцию, которая принимает два параметра типа `int` и возвращает значение `int`.

```c
typedef int (binary_op)(int, int);	// определяем тип binary_op
```

с помощью этого типа объявляются переменные, указывающие на функции с соответствующими типами параметров и возвращаемым типом:

```c
binary_op *op1 =&sum;
```

переменная op1 является указателем на функцию типа binary_op, и ей присваивается адрес функции sum. явный оператор `&` здесь необязателен, поскольку имя функции и так преобразуется в указатель. op1 вызывается как обычная функция: ей передаются аргументы и от неё получается результат:

```c
result = op1(a, b);
```

тип функции полезен там, где требуется указать сигнатуру функции, а полная запись получается громоздкой. например, тип функции можно использовать в прототипе:

```c
#include <stdio.h>
 
typedef int (binary_op)(int, int);

binary_op sum;  // прототип функции sum

int main(void)
{
    binary_op* op1 = &sum; 
    printf("result = %d \n", op1(10,5));       // result=15 
     
    return 0;
}

int sum(int x, int y) { return x + y;}
```

таким способом можно только объявить функцию: определение с телом через typedef-имя типа функции записать нельзя, поэтому сама sum определяется обычным образом.

### массивы функций

аналогично объявляется массив указателей на функции:

```c
#include <stdio.h>
 
typedef int (binary_op)(int, int);

int sum(int x, int y) { return x + y;}
int subtract(int x, int y) { return x - y;}
int multiply(int x, int y) { return x * y;}

int main(void)
{
    binary_op* operations[] = {&sum, &subtract, &multiply};   // массив функций binary_op
    printf("result = %d \n", operations[0](10,5));       // result=15 
    printf("result = %d \n", operations[1](10,5));       // result=5 
    printf("result = %d \n", operations[2](10,5));       // result=50 
     
    return 0;
}
```

массив именно указателей, а не функций: массив функций в c невозможен, так как функции не являются объектами и не имеют размера.

### тип функции-указатель

typedef может сразу задавать тип указателя на функцию. например:

```c
typedef int (*binary_op)(int, int);
```

в этом случае binary_op уже обозначает указатель, и звёздочка при объявлении переменной не нужна:

```c
#include <stdio.h>
 
typedef int (*binary_op)(int, int);

int sum(int x, int y) { return x + y;}

int main(void)
{
    binary_op op1 = &sum;   // op1 уже изначально представляет указатель
    printf("result = %d \n", op1(10,5));       // result=15 
     
    return 0;
}
```
