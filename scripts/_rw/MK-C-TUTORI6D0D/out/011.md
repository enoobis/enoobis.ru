отличительным признаком переменных является то, что в течение работы программы их значение можно многократно изменять. переменная обозначает объект в памяти: присваивание заменяет содержимое этой области, имя при этом остаётся тем же, тип фиксирован во время компиляции.

```c
#include <stdio.h>

int main(void)
{
	int number = 2;
	printf("number = %d \n", number);
	number = 55;
	printf("number = %d \n", number);
	number = -23;
	printf("number = %d \n", number);
	return 0;
}
```

здесь переменная number последовательно меняет своё значение:

```consoletext
number = 2
number = 55
number = -23
```

в отличие от переменных, значение константы устанавливается один раз при объявлении. для определения константы используется ключевое слово **const**:

```c
#include <stdio.h>

int main(void)
{
	const int number = 2;
	printf("number = %d \n", number);
	// number = 55;  эта строка работать не будет, так как number - это константа
	return 0;
}
```

если в коде содержится изменение константы, компилятор не сможет скомпилировать такую программу. квалификатор `const` в c означает, что изменение запрещено через данное lvalue: попытка присваивания диагностируется на этапе компиляции. снятие `const` через приведение указателя и последующая запись приводят к неопределённому поведению, если объект был определён как константный.

как правило, в виде констант определяются значения, которые должны оставаться постоянными в течение работы всей программы и не могут быть изменены. если программа выполняет математические операции с использованием числа PI, это значение определяют как константу, поскольку оно неизменно:

```c
const float PI = 3.14;
```

в c объект с квалификатором `const` не является целочисленным константным выражением в смысле стандарта: его нельзя использовать там, где требуется константа времени компиляции, например как размер массива в c89. для таких целей применяются перечисление или макрос `#define`. в c++ `const int` с инициализатором-константой уже образует константное выражение, а c23 добавил в язык спецификатор `constexpr`.
