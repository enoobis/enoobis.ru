в процессе разработки нередко требуется выводить отладочную информацию о состоянии программы. для этого подходят и стандартные функции вывода на консоль, однако вывод можно сделать более структурированным, оформив его в виде макроса. например:

```c
#ifdef DEBUG
#define DEBUG_PRINT(fmt, ...) fprintf(stderr, "DEBUG: %s:%d:%s(): " fmt "\n", \
                                __FILE__, __LINE__, __func__, __VA_ARGS__)
#else
#define DEBUG_PRINT(fmt, ...) ((void)0)
#endif
```

разберём этот макрос. сначала проверяется, определён ли макрос `DEBUG`:

```c
#ifdef DEBUG
```

тем самым вывод отладочной информации включается глобально определением этого макроса, а если выводить ничего не нужно, его достаточно не определять. определить DEBUG можно не только директивой #define в исходном тексте, но и ключом компилятора, например `-DDEBUG` в gcc и clang, не меняя код.

затем следует собственно определение макроса `DEBUG_PRINT`. он принимает как минимум один параметр, fmt:

```c
DEBUG_PRINT(fmt, ...)
```

fmt представляет произвольный идентификатор, через который передаётся строка форматирования для вывода информации на консоль. за ним следует многоточие **...**, означающее, что макрос принимает переменное число параметров (один, два, три или в принципе ноль). эти параметры подставляются в строку форматирования при выводе на консоль. при нулевом числе дополнительных аргументов в данном определении после `__func__` останется лишняя запятая, и до c23 такой вызов не скомпилируется; gcc и clang предлагают для этого расширение `, ##__VA_ARGS__`, а c23 вводит стандартную конструкцию `__VA_OPT__`.

сам макрос разворачивается в следующий код:

```c
fprintf(stderr, "DEBUG: %s:%d:%s(): " fmt "\n", \
      __FILE__, __LINE__, __func__, __VA_ARGS__)
```

для вывода применяется встроенная функция форматированного вывода fprintf(). её первый параметр задаёт поток, в который выполняется вывод. здесь это стандартный поток stderr, предназначенный обычно для вывода ошибок. stderr по умолчанию не буферизуется, поэтому отладочные сообщения появляются сразу и не теряются при аварийном завершении программы.

второй параметр функции fprintf() представляет строку форматирования:

```c
"DEBUG: %s:%d:%s(): " fmt "\n"
```

строка форматирования состоит из трёх подстрок. в c соседние строковые литералы конкатенируются на этапе трансляции, достаточно расположить их рядом. первая подстрока содержит три спецификатора для вывода "%s:%d:%s()". вторая подстрока, fmt, представляет строку форматирования, переданную через первый параметр макроса DEBUG_PRINT. из этого следует, что fmt обязан быть строковым литералом, а не переменной типа char*. третья подстрока, "\n", выполняет перевод строки.

для переноса определения макроса на следующую строку служит обратный слеш \, далее следуют параметры, подставляемые в строку форматирования. на место спецификаторов в "DEBUG: %s:%d:%s():" подставляются значения встроенных макросов `__FILE__` (имя файла) и `__LINE__` (номер строки), а также предопределённого идентификатора `__func__` (имя функции). `__FILE__` и `__LINE__` раскрываются препроцессором в месте вызова макроса, а `__func__` с c99 представляет неявно объявленный в каждой функции статический массив символов с её именем.

все произвольные значения, переданные в макрос на место многоточия, доступны через встроенный идентификатор `__VA_ARGS__`: это значения, которые передаются в строку fmt.

приведённое определение действует, если константа DEBUG **определена**. на случай, если она не определена, задаётся заглушка:

```c
#define DEBUG_PRINT(fmt, ...) ((void)0)
```

заглушка фактически ничего не выполняет. выражение `((void)0)` выбрано вместо пустой подстановки, чтобы вызов макроса оставался корректным выражением, например в операторе с запятой, и не вызывал предупреждений о пустой инструкции. аргументы при этом не вычисляются, поэтому побочные эффекты в них в режиме без отладки пропадают.

применение макроса:

```c
#include <stdio.h>

#define DEBUG  // подключаем отладочное логгирование

#ifdef DEBUG
#define DEBUG_PRINT(fmt, ...) fprintf(stderr, "DEBUG: %s:%d:%s(): " fmt "\n", \
                                __FILE__, __LINE__, __func__, __VA_ARGS__)
#else
#define DEBUG_PRINT(fmt, ...) ((void)0)
#endif


int sum(int a, int b){
    DEBUG_PRINT("Parameters: %d %d", a, b);
    return a + b;
}

int main(){
    int x = 2;
    int y = 4;
    printf("x + y = %d\n", sum(x, y));
    return 0;
}
```

здесь константа DEBUG определена, поэтому логирование выполняется. при большом числе файлов определение константы естественно вынести в общий заголовочный файл. для проверки служит функция sum, в которой логируются параметры:

```c
int sum(int a, int b){
    DEBUG_PRINT("Parameters: %d %d", a, b);
    return a + b;
}
```

строка "Parameters: %d %d" передаётся в макрос через параметр fmt, а переменные a и b представляют произвольные параметры макроса, доступные через __VA_ARGS__.

консольный вывод может выглядеть так:

```bash
DEBUG: test.c:15:sum(): Parameters: 2 4
x + y = 6
```

### модификации макросов отладки

выше показан один из распространённых макросов отладки, выводящий отладочную информацию на консоль. в целом же отладочные макросы гораздо разнообразнее и в зависимости от задачи принимают различные формы. рассмотрим следующую программу:

```c
#include <stdio.h>

#define YYDEBUG

#ifdef YYDEBUG
#define DEBUG(expr) { expr;}
#else
#define DEBUG(expr)
#endif

int main (void)
{
    DEBUG(puts("Hello 1"));
    DEBUG(puts("Hello 2"));
    return 0;
}
```

если макрос `YYDEBUG` определён, приложение находится в режиме отладки, и далее определяется макрос DEBUG:

```c
#ifdef YYDEBUG
#define DEBUG(expr) { expr;}
```

этот макрос принимает выражение, которое выполняется внутри блока кода.

если `YYDEBUG` не определён, макрос DEBUG также определяется, но переданное в него выражение не выполняется:

```c
#else
#define DEBUG(expr)
#endif
```

рассмотрим применение макроса в функции main:

```c
DEBUG(puts("Hello 1"));
```

если макрос `YYDEBUG` определён, фактически выполняется код `{puts("Hello 1");}`. если `YYDEBUG` не определён, выражение `DEBUG(puts("Hello 1"));` заменяется пустотой, от него остаётся лишь пустая инструкция `;`, и ничего не выполняется. имя YYDEBUG заимствовано из соглашений генераторов синтаксических анализаторов yacc и bison, где этот макрос включает трассировку разбора.
