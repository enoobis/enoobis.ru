вместе с компилятором c поставляется стандартная библиотека c: набор функций, макросов и типов, объявленных в заголовочных файлах. её состав фиксируется стандартом языка, и с принятием новых редакций стандарта библиотека расширяется. конкретная реализация (glibc, musl, msvcrt и ucrt в windows) может поддерживать стандарт не полностью, особенно в части необязательных возможностей c11. ниже приведён краткий обзор состава библиотеки.

заголовочные файлы, доступные во всех редакциях стандарта:

-   `<assert.h>`: содержит макросы для тестирования и проверки утверждений во время выполнения

-   `<ctype.h>`: предоставляет функции для классификации и преобразования отдельных символов

-   `<errno.h>`: макросы для работы с кодами ошибок

-   `<float.h>`: определяет константы, описывающие характеристики типов с плавающей точкой

-   `<limits.h>`: определяет диапазоны значений встроенных целочисленных типов

-   `<locale.h>`: содержит средства локализации

-   `<math.h>`: математические функции

-   `<setjmp.h>`: макросы и функции для нелокальных переходов

-   `<signal.h>`: средства обработки сигналов

-   `<stdarg.h>`: определяет макросы для работы с переменным количеством параметров в функциях

-   `<stddef.h>`: определяет макросы и типы общего назначения, такие как NULL, wchar_t, size_t и другие

-   `<stdio.h>`: функции для работы с системой ввода-вывода

-   `<stdlib.h>`: функции общего назначения, в том числе для управления динамической памятью

-   `<string.h>`: функции для работы со строками

-   `<time.h>`: средства для работы с датами и временем

-   `<wchar.h>`: средства для работы с символами, которые занимают больше 1 байта

-   `<wctype.h>`: средства для классификации символов, которые занимают больше 1 байта

-   `<iso646.h>`: определяет макросы-синонимы для поразрядных и логических операций

строго говоря, три последних заголовка появились в поправке c95 (iso/iec 9899/amd1:1995), но сейчас они присутствуют во всех используемых на практике реализациях.

в стандарте c99 были добавлены:

-   `<complex.h>`: для работы с комплексными числами

-   `<fenv.h>`: содержит средства для управления окружением вычислений с плавающей точкой: режимами округления и флагами исключений

-   `<inttypes.h>`: содержит макросы для форматного ввода-вывода целых чисел фиксированного размера и функции для работы с типом intmax_t

-   `<stdbool.h>`: содержит макросы для работы с типом данных bool

-   `<stdint.h>`: объявляет целочисленные типы фиксированного размера и макросы, задающие их пределы

-   `<tgmath.h>`: включает заголовки "math.h" и "complex.h" и определяет обобщённые по типу макросы, которые по типу аргументов выбирают, какую функцию вызвать. это одна из немногих форм статического полиморфизма в c до появления `_Generic` в c11

в стандарте c11 были добавлены:

-   `<threads.h>`: содержит макросы, типы, константы и функции для работы с потоками выполнения

-   `<stdalign.h>`: определяет макросы для управления выравниванием данных

-   `<stdatomic.h>`: определяет атомарные типы и операции

-   `<stdnoreturn.h>`: предоставляет макрос для функций, которые не возвращают управление

-   `<uchar.h>`: предоставляет функции и типы для работы с символами юникод

поддержка `<threads.h>` и `<stdatomic.h>` в стандарте c11 необязательна: реализация сообщает об их отсутствии макросами `__STDC_NO_THREADS__` и `__STDC_NO_ATOMICS__`.

далее рассматриваются наиболее употребительные средства, объявленные в этих заголовочных файлах.
