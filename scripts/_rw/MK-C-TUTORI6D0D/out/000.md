язык программирования c (си) относится к числу самых популярных и широко распространённых языков. это компилируемый язык общего назначения со статической типизацией, разработанный в 1969-1973 годах в bell labs деннисом ритчи (dennis ritchie). статическая типизация здесь означает, что тип каждого выражения известен во время компиляции, а проверка согласованности типов выполняется транслятором до запуска программы.

c нередко называют языком "среднего уровня" или даже "низкого уровня": он сочетает конструкции языков высокого уровня с выразительностью и производительностью, сопоставимыми с ассемблером, и остаётся близким к аппаратной архитектуре. программа на c способна работать с данными на уровне байтов, адресов и битовых полей и одновременно использовать структурные конструкции управления потоком выполнения. модель памяти языка прозрачна для программиста: объекты располагаются в адресуемой памяти, указатель является значением адреса, а управление динамической памятью выполняется явно, без сборщика мусора.

первоначально c создавался как инструмент для написания операционной системы unix. впоследствии он стал одним из самых популярных языков, а его основной областью применения стало системное программирование: операционные системы, драйверы, служебные утилиты, антивирусы и т.д. ядро linux в большей части написано на c. однако применение языка системным программированием не ограничивается. c подходит для программ любого уровня, где критичны скорость работы и производительность. на нём пишут и прикладные приложения, и даже веб-сайты (через технологию cgi, common gateway interface). для графических интерфейсов и веб-приложений, как правило, выбирают более подходящие инструменты, тем не менее круг применения c остаётся широким, что во многом и определило популярность языка. в известном рейтинге языков программирования tiobe c долгое время уверенно удерживал второе место.

при больших возможностях c остаётся сравнительно простым языком. в нём немного конструкций, стандартная библиотека невелика, язык легко осваивается. по этой причине его нередко выбирают как язык для изучения программирования вообще.

c является компилируемым языком: компилятор транслирует исходный код в исполняемый файл, содержащий машинные инструкции целевой архитектуры. платформы различаются набором инструкций, форматом исполняемых файлов и соглашениями о вызовах, поэтому скомпилированную программу нельзя просто перенести на другую платформу и запустить. переносимость c обеспечивается на уровне исходного кода: компиляторы, библиотеки и инструменты разработки существуют почти для всех распространённых платформ, и один и тот же исходный текст можно скомпилировать в приложения для каждой из них. стандарт при этом намеренно оставляет часть поведения зависящим от реализации (размеры целочисленных типов, знаковость `char` и др.), что позволяет эффективно отображать язык на разные архитектуры.

развитие c сильно повлияло на эволюцию языков программирования в целом. его синтаксис лёг в основу c++, c#, java, php, javascript. отдельно стоит сказать о связи с c++. c++ непосредственно произошёл от c, но затем языки развивались раздельно, и между ними возникла несовместимость. стандарт c99 добавил в c ряд возможностей, конфликтующих с c++ (например, массивы переменной длины и назначенные инициализаторы в их исходной форме). в результате сегодня оба языка фактически самостоятельны и развиваются независимо.

### основные особенности c

- универсальность: один и тот же код может быть скомпилирован почти на любой платформе (при наличии для неё компилятора)

- высокая скорость выполнения

- компактность, небольшой размер скомпилированных файлов

### основные этапы развития

в 1978 году брайан керниган и деннис ритчи опубликовали первое издание своей знаменитой книги "язык программирования си". долгое время она служила неформальной спецификацией языка. быстрое распространение c потребовало выработки общего стандарта, и в 1983 году ansi (американский национальный институт стандартов) создал комитет для разработки спецификации. в 1989 году спецификация была утверждена, эту версию языка принято называть ansi c или c89. в 1990 году международная организация по стандартизации (iso) приняла её с небольшими редакционными изменениями под названием iso/iec 9899:1990, сокращённо c90.

в конце 1990-х годов стандарт был пересмотрен, и в 1999 году вышла новая редакция, которую принято называть c99 (официальное название iso 9899:1999). в 2018 году вышел стандарт c17 (официальное название iso/iec 9899:2018), который в основном исправляет дефекты c11 без новых возможностей языка. на момент написания исходной версии материала ожидался выход стандарта c23, он был опубликован в 2024 году как iso/iec 9899:2024. список всех стандартов:

- ANSI C Standard (ansi c / c89)

- c90 (ISO/IEC 9899:1990)

- c99 (ISO/IEC 9899:1999)

- c11 (ISO/IEC 9899:2011)

- c17 (ISO/IEC 9899:2018)

- c23 (ISO/IEC 9899:2024, ожидался в 2023 году, опубликован в 2024)

### компиляторы и среды разработки

для написания программ на c необходимы как минимум два компонента: текстовый редактор для исходного кода и компилятор, который транслирует код в исполняемый файл. текстовый редактор подойдёт любой. в рамках курса рекомендуется кроссплатформенный редактор [Visual Studio Code](https://code.visualstudio.com/download), который поддерживает расширения для разных языков, в том числе для c.

среди компиляторов c выделяются следующие:

- gcc от проекта gnu

- clang

далее в курсе основным компилятором будет **gcc**, как один из наиболее распространённых на сегодняшний день.

при выборе компилятора возникает вопрос о поддержке определённых стандартов, особенно если требуются возможности, введённые в последних редакциях языка. степень поддержки разными компиляторами сведена на странице [https://en.cppreference.com/w/c/compiler_support](https://en.cppreference.com/w/c/compiler_support).
