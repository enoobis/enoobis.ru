переменная имеет определённый тип. тип задаёт множество допустимых значений переменной, объём памяти, который она занимает, и набор допустимых операций. в c определены следующие базовые типы данных:

- char : представляет один символ. занимает в памяти 1 байт (8 бит). по определению `sizeof(char)` равен 1: байт в c является минимальной адресуемой единицей памяти, хотя стандарт допускает байты шире 8 бит (макрос `CHAR_BIT`).

- unsigned char : представляет один символ. занимает в памяти 1 байт (8 бит). может хранить любое значение из диапазона от 0 до 255

- signed char : представляет один символ. занимает в памяти 1 байт (8 бит). может хранить любое значение из диапазона от -128 до 127

- short : представляет целое число в диапазоне от -32768 до 32767. занимает в памяти 2 байта (16 бит). имеет псевдонимы short int , signed short и signed short int .

- unsigned short : представляет целое число в диапазоне от 0 до 65535. занимает в памяти 2 байта (16 бит). имеет псевдоним unsigned short int .

- int : представляет целое число. в зависимости от архитектуры процессора может занимать 2 байта (16 бит) или 4 байта (32 бита). на основных платформах, 64-разрядных windows, linux (включая android) и macos, размер int составляет 4 байта. диапазон предельных значений соответственно варьируется от -32768 до 32767 (при 2 байтах) или от -2 147 483 648 до 2 147 483 647 (при 4 байтах) и шире. имеет псевдонимы signed int и signed

- unsigned int : представляет неотрицательное целое число. в зависимости от архитектуры процессора может занимать 2 байта (16 бит) или 4 байта (32 бита), поэтому диапазон предельных значений меняется: от 0 до 65535 (для 2 байт) либо от 0 до 4 294 967 295 (для 4 байт). имеет псевдоним unsigned : то же самое, что и unsigned int

- long : представляет целое число и занимает в памяти 4 байта (32 бита) или 8 байт (64 бита). в зависимости от размера находится в диапазоне от -2 147 483 648 до 2 147 483 647 (4 байта) либо от -9223372036854775807 до +9 223 372 036 854 775 807 (8 байт). на распространённых платформах в 64-разрядной windows long занимает 4 байта (модель данных llp64), а в 64-разрядных linux и macos 8 байт (модель lp64). имеет псевдонимы long int , signed long int и signed long .

- unsigned long : представляет целое число и занимает в памяти 4 байта (32 бита) или 8 байт (64 бита). в зависимости от размера находится в диапазоне от 0 до 4 294 967 295 (4 байта) или от 0 до 18 446 744 073 709 551 615 (8 байт). имеет псевдоним unsigned long int .

- long long : представляет целое число в диапазоне от -9223372036854775807 до +9 223 372 036 854 775 807. занимает в памяти, как правило, 8 байт (64 бита). имеет псевдонимы long long int , signed long long int и signed long long . тип введён стандартом c99.

- unsigned long long : представляет целое число в диапазоне от 0 до 18 446 744 073 709 551 615. занимает в памяти, как правило, 8 байт (64 бита). имеет псевдоним unsigned long long int .

- float : представляет вещественное число одинарной точности с плавающей точкой в диапазоне +/- 3.4E-38 до 3.4E+38. в памяти занимает 4 байта (32 бита)

- double : представляет вещественное число двойной точности с плавающей точкой в диапазоне +/- 1.7E-308 до 1.7E+308. в памяти занимает 8 байт (64 бита)

- long double : представляет вещественное число расширенной точности с плавающей точкой в диапазоне +/- 3.4E-4932 до 1.1E+4932. в памяти занимает 10 байт (80 бит). на некоторых системах может занимать 96 и 128 бит. в msvc long double совпадает с double и занимает 8 байт.

- void : тип без значения. множество его значений пусто: он используется для обозначения отсутствия результата функции, пустого списка параметров и в составе обобщённого указателя `void *`.

на практике float и double почти повсеместно соответствуют форматам binary32 и binary64 стандарта ieee 754, хотя сам стандарт c этого не требует (соответствие объявляется макросом `__STDC_IEC_559__`).

### целочисленные типы

наиболее распространённым целочисленным типом является **int** (псевдонимы **signed int** и **signed**). он представляет целое число со знаком и обычно занимает 4 байта: по замыслу языка это естественный размер слова целевой архитектуры. переменной такого типа можно присвоить целое число:

```c


int age = 38;

signed int number = 2;

signed temps = -3;
```

для определения переменной некоторого типа допустимо использовать любой из его псевдонимов. в примере выше определяются три переменные типа `int`, хотя в каждом случае используется своё обозначение типа: `int`, `signed int` и `signed`.

#### суффиксы целочисленных типов

десятичная целочисленная константа по умолчанию имеет тип первого из `int`/`long int`/`long long int`, в котором она представима, и при присвоении переменным других типов выполняется преобразование. чтобы явно указать тип числа, к нему добавляется суффикс:

| Тип | Суффикс |
| --- | --- |
| unsigned int , unsigned long int и unsigned long long int | u или U |
| unsigned long int и unsigned long long int | ul или UL |
| long long int | ll или LL |
| unsigned long long int | ull или ULL |

отдельные суффиксы есть не у всех типов, а к некоторым типам применимо несколько суффиксов. если требуется хранить только неотрицательные числа, можно взять тип **unsigned int**. для констант этого типа применяется суффикс **u** или **U**:

```c


#include <stdio.h>

 

int main(void)

{

    unsigned number1 = 4294967294u; 

    unsigned int number2 = 22U;  

    printf("number1 = %u\n", number1);

    printf("number2 = %u\n", number2);

    return 0;

}
```

при выводе таких чисел на консоль применяется спецификатор **%u**.

переменной можно присвоить число и без суффикса, результат будет тем же:

```c


unsigned number1 = 4294967294;  // без суффикса u

unsigned int number2 = 22;      // без суффикса u

printf("number1 = %u\n", number1);

printf("number2 = %u\n", number2);
```

назначение суффикса в следующем. без него десятичная константа рассматривается как значение типа `int`/`long int`/`long long int`, и при присвоении переменной типа `unsigned int` выполняется преобразование. суффикс задаёт тип константы непосредственно. для констант преобразование выполняется во время компиляции и на время выполнения не влияет, однако тип литерала определяет тип выражения, в котором он участвует, и в арифметике, например при сдвигах или сравнении со знаковыми значениями, это меняет семантику результата.

пример определения данных других типов:

```c


#include <stdio.h>

 

int main(void)

{

    unsigned short number1 = 1u; 

    unsigned short int number2 = 2u;  

    short number3 = 3; 

    short int number4 = -4;  

    signed short number5 = 5;  

    signed short int number6 = -6;  



    long number7 = -2147483648l;

    long int number8 = -2147483648L;

    signed long number9 = 2147483647l;

    signed long int number10 = 2147483647L;



    unsigned long number11 = 4294967295ul;

    unsigned long int number12 = 4294967295UL;



    long long number13 = -9223372036854775807ll;

    long long int number14 = 9223372036854775807ll;

    signed long long number15 = -9223372036854775807LL;

    signed long long int number16 = 9223372036854775807LL;



    unsigned long long number17 = 18446744073709551615ull;

    unsigned long long int number18 = 18446744073709551615ULL;

   

    printf("number1 = %hu\n", number1);

    printf("number2 = %hu\n", number2);

    printf("number3 = %d\n", number3);

    printf("number4 = %d\n", number4);

    printf("number5 = %d\n", number5);

    printf("number6 = %d\n", number6);

    printf("number7 = %ld\n", number7);

    printf("number8 = %ld\n", number8);

    printf("number9 = %ld\n", number9);

    printf("number10 = %ld\n", number10);

    printf("number11 = %lu\n", number11);

    printf("number12 = %lu\n", number12);

    printf("number13 = %lld\n", number13);

    printf("number14 = %lld\n", number14);

    printf("number15 = %lld\n", number15);

    printf("number16 = %lld\n", number16);

    printf("number17 = %llu\n", number17);

    printf("number18 = %llu\n", number18);

    return 0;

}
```

спецификатор, который используется для вывода числа на консоль в функции `printf()`:

| Тип | Спецификатор |
| --- | --- |
| unsigned short | hu |
| long | ld |
| unsigned long | lu |
| long long | lld |
| unsigned long long | llu |

несоответствие спецификатора фактическому типу аргумента приводит к неопределённому поведению: `printf` является вариативной функцией, и компилятор не преобразует аргумент к ожидаемому типу. gcc и clang диагностируют такие ошибки при флаге `-Wall` (предупреждение `-Wformat`).

#### определение чисел в различных системах

c позволяет записывать целые константы в разных системах счисления. числа в двоичной системе начинаются с символов **0b**, за которыми следует набор единиц и нулей, представляющих число. двоичные литералы стандартизованы в c23, до этого они были расширением gcc и clang. восьмеричные числа начинаются с цифры 0, за которой следуют цифры от 0 до 7. шестнадцатеричные числа начинаются с **0x** или **0X**, за которыми следуют шестнадцатеричные цифры от 0 до 9 и от A до F. например:

```c


#include <stdio.h>

 

int main(void)

{

    int code1 = 0b1011;     // двоичная система - число 11

    int code2 = 013;        // восьмеричная система - число 11

    int code3 = 11;        // десятичная система - число 11

    int code4 = 0xB;        // шестнадцатеричная система - число 11

    printf("code1 = %d\n", code1);    //  code1 = 11

    printf("code2 = %d\n", code2);    //  code2 = 11

    printf("code3 = %d\n", code3);    //  code3 = 11

    printf("code4 = %d\n", code4);    //  code4 = 11

    return 0;

}
```

здесь определены четыре переменные, и каждая хранит одно и то же число 11, записанное в разных системах счисления. система счисления относится только к записи литерала в исходном тексте, внутреннее представление значения от неё не зависит.

при определении переменных значение не должно выходить за пределы, допустимые для её типа. например:

```c


unsigned short int number = -65535;
```

при компиляции программы с этой строкой gcc сообщит, что значение -65535 не входит в диапазон допустимых значений типа unsigned short int (диагностика `-Woverflow`, по умолчанию в виде предупреждения). с точки зрения семантики языка преобразование в беззнаковый тип определено и выполняется по модулю степени двойки, равной разрядности типа, поэтому переменная получит значение 1. переполнение знаковых целых при арифметических операциях является неопределённым поведением.

### числа с плавающей точкой

числа с плавающей точкой представлены тремя типами: **float**, **double**, **long double**. разделителем целой и дробной частей служит точка. по умолчанию все дробные литералы имеют тип **double**, который занимает 8 байт:

```c


#include <stdio.h>

 

int main(void)

{

    double number = 3.14159;

    printf("number = %f\n", number);

    return 0;

}
```

для вывода значения double на консоль используются спецификаторы **f** и **lf**. в `printf` они эквивалентны: аргумент float при передаче в вариативную функцию повышается до double, и различие между f и lf существенно только для `scanf`. чтобы указать, что число имеет тип **float**, применяется суффикс **f**, а для **long double** суффикс **l**:

```c


#include <stdio.h>

 

int main(void)

{

    float number1 = 3.14f;

    long double number2 = 123456.789l;

    printf("number1 = %f\n", number1);

    printf("number2 = %Lf\n", number2);

    return 0;

}
```

для вывода данных типа **long double** на консоль применяется спецификатор **Lf**, однако на некоторых платформах он работает некорректно и показывает 0. типичный случай: mingw-сборки gcc, где компилятор использует 80-битный long double, а библиотека времени выполнения microsoft считает его 64-битным.

### символы

символьных типов в c три: **char**, **signed char** и **unsigned char**. на практике для работы с символами применяется тип **char**. стандарт не фиксирует знаковость char и оставляет выбор реализации. при этом char в любом случае является отдельным, третьим типом, несовместимым ни с signed char, ни с unsigned char. как правило, char определяется как знаковый тип с диапазоном значений от -128 до 127. в частности, так задано в system v abi, определяющем общие правила для unix-систем, включая linux, на архитектуре x86-64; на arm в linux char, напротив, беззнаковый.

значениями этого типа служат символьные литералы, то есть символы в одинарных кавычках. переменной этого типа можно присвоить символ в одинарных кавычках:

```c
char letter = 'A';
```

здесь определяется переменная letter, хранящая символ 'A'. фактически переменная типа char хранит число. при присваивании символа она получает его числовой код из таблицы, сопоставляющей числовые коды и символы. наиболее распространена таблица ascii, сопоставляющая символы с числами от 0 до 127. содержимое определённой выше переменной letter можно вывести на консоль:

```c


#include <stdio.h>

 

int main(void)

{

    char letter = 'A';

    printf("letter: %d \n", letter);    // letter: 65

    printf("letter: %c \n", letter);    // letter: A

    return 0;

}
```

числовой код символа 'A' в таблице ascii равен 65. значение переменной letter выводится дважды. в первом случае используется спецификатор `%d` для вывода числового кода символа, во втором спецификатор `%c`, который выводит на консоль сам символ. при выполнении программа выведет на консоль:

```bash


letter: 65

letter: A
```

вместо символа в одинарных кавычках можно присвоить непосредственно числовой код:

```c


#include <stdio.h>

 

int main(void)

{

    char letter = 65;

    printf("letter: %d \n", letter);    // letter: 65

    printf("letter: %c \n", letter);    // letter: A

    return 0;

}
```

результат будет тем же.

символьные литералы в одинарных кавычках в c имеют тип **int**, поэтому `sizeof('A')` равен `sizeof(int)`. в c++ тот же литерал имеет тип char, и это одно из известных расхождений двух языков.

### typedef

оператор **typedef** определяет псевдоним для существующего типа. это требуется, когда название типа слишком длинное и его сокращают. typedef не создаёт нового типа: псевдоним полностью взаимозаменяем с исходным типом, система типов их не различает.

общая форма оператора

```c
typedef существующий_тип псевдоним
```

для типа `unsigned char` задаётся псевдоним `BYTE`:

```c
typedef unsigned char BYTE;
```

после этого псевдоним используется как любой другой тип:

```c


#include <stdio.h>



typedef unsigned char BYTE;



int main(void)

{

	BYTE byte = 22;

    printf("byte = %d", byte);

}
```

### размер типов данных

в приведённом выше списке для каждого типа указан занимаемый им объём памяти. предельные размеры типов разработчики компиляторов выбирают самостоятельно, исходя из аппаратных возможностей платформы. стандарт устанавливает лишь минимальные значения: для типов int и short это 16 бит, для типа long 32 бита, для long long 64 бита. размер типа long должен быть не меньше размера int, а размер int не меньше размера short. на практике используются размеры, указанные выше при описании типов данных. фактические пределы конкретной реализации заданы макросами в заголовке `limits.h` (`INT_MAX`, `LONG_MIN` и другие), а при необходимости типов фиксированной разрядности применяются `int32_t`, `uint64_t` и подобные из `stdint.h`.

когда необходимо точно знать размер определённого типа, в c применяется оператор sizeof, который возвращает размер в байтах, занимаемый выражением или типом. значение sizeof, как правило, вычисляется во время компиляции и является константным выражением (исключение составляют массивы переменной длины).

чтобы получить размер типа данных, этот тип помещается в скобки после `sizeof`:

```c


#include <stdio.h>



int main(void)

{

	printf("sizeof(int): %lu\n", sizeof(int));

    printf("sizeof(long): %lu\n", sizeof(long));

    printf("sizeof(unsigned long long): %lu\n", sizeof(unsigned long long));

	return 0;

}
```

здесь определяется размер трёх типов. на 64-разрядном linux консольный вывод будет следующим:

```bash


sizeof(int): 4

sizeof(long): 8

sizeof(unsigned long long): 8
```

оператор `sizeof` возвращает размер в виде значения типа **size_t**. size_t не является самостоятельным типом, а представляет псевдоним, определённый через typedef. на 64-битном linux `size_t` является псевдонимом unsigned long, на других системах для `size_t` может использоваться иной тип (в 64-битной windows это unsigned long long). для работы с размерами следует использовать псевдоним `size_t`, а не конкретный тип, например `unsigned long`. для вывода этого значения на консоль в функции `printf` здесь применяется спецификатор `%lu` (long unsigned), а переносимым вариантом начиная с c99 является `%zu`. результат оператора можно присвоить другой переменной:

```c


#include <stdio.h>



int main(void)

{

	size_t int_size = sizeof(int);

    printf("sizeof(int): %lu\n", int_size);

	return 0;

}
```

`sizeof` также может вычислять размер объекта, например переменной. имя объекта указывается в скобках либо после оператора без скобок. скобки обязательны только для имени типа: sizeof является унарным оператором, а не функцией.

```c


#include <stdio.h>



int main(void)

{

	int number = 2;

	printf("sizeof(number): %lu\n", sizeof(number));

    printf("sizeof number: %lu\n", sizeof number);

	return 0;

}
```

консольный вывод:

```bash


sizeof(number): 4

sizeof number: 4
```

размер переменной number составляет 4 байта, поскольку её тип `int`, и переменная имеет тот же размер.

оператор `sizeof` может возвращать размер результата выражения. например:

```c


#include <stdio.h>



int main(void)

{

    size_t size = sizeof printf("hello enoobis.ru");

    printf("sizeof printf('hello enoobis.ru'): %lu\n", size);

	return 0;

}
```

переменной size присваивается результат выражения `sizeof printf("hello enoobis.ru")`. может показаться, что оператор `sizeof` вычисляет размер выражения `printf("hello enoobis.ru")`. в действительности `sizeof` вычисляет размер **результата** выражения `printf("hello enoobis.ru")`, точнее результата функции `printf()`. результат этой функции имеет тип `int`, поэтому переменная size равна 4. само выражение `printf("hello enoobis.ru")` не выполняется: операнд sizeof не вычисляется, компилятору достаточно знать его статический тип.

другой пример:

```c


#include <stdio.h>



int main(void)

{

    size_t size = sizeof sizeof(int);

    printf("sizeof sizeof(int): %lu\n", size);

	return 0;

}
```

здесь оператор sizeof возвращает размер результата другого оператора sizeof, то есть размер типа size_t, который на 64-битных платформах составляет 8 байт.

```bash
sizeof sizeof(int): 8
```
