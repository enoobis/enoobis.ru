отдельную группу операций в языке c составляют операции присваивания. это бинарные операции, причём левым операндом может быть только модифицируемое lvalue, то есть выражение, обозначающее объект в памяти, значение которого разрешено изменять, например переменная. константа, литерал или результат арифметического выражения слева от знака присваивания стоять не могут.

базовая операция присваивания **=** записывает значение правого операнда в левый операнд:

```c
int x = 2 + 5
```

выражение `2 + 5` служит правым операндом, и его значение присваивается левому операнду. строго говоря, в объявлении `int x = 2 + 5` знак = вводит инициализатор, а не операцию присваивания, однако семантика передачи значения здесь та же.

тип значения правого операнда не обязан совпадать с типом левого. в этом случае компилятор выполняет неявное преобразование значения правого операнда к типу левого операнда, и при сужающих преобразованиях часть информации может быть потеряна.

допускается и множественное присваивание:

```c
int a, b, c;	
a = b = c = 34 +7;
```

операция присваивания ассоциативна справа налево, а её значением является значение, записанное в левый операнд. поэтому сначала вычисляется выражение `c = 34 +7`: значение правого операнда `34 +7` присваивается левому операнду c, и переменная c получает значение 41. затем вычисляется выражение `b = c`: значение правого операнда **c** (41) присваивается левому операнду **b**. в конце вычисляется выражение `a = b`: значение правого операнда **b** (41) присваивается левому операнду **a**.

все остальные операции присваивания представляют собой составное присваивание, то есть сочетание простого присваивания с другой бинарной операцией. отличие от развёрнутой записи состоит в том, что левый операнд вычисляется только один раз, это существенно, если его вычисление содержит побочные эффекты:

- += : присваивание после сложения. присваивает левому операнду сумму левого и правого операндов: A += B эквивалентно A = A + B

- -= : присваивание после вычитания. присваивает левому операнду разность левого и правого операндов: A -= B эквивалентно A = A - B

- *= : присваивание после умножения. присваивает левому операнду произведение левого и правого операндов: A *= B эквивалентно A = A * B

- /= : присваивание после деления. присваивает левому операнду частное левого и правого операндов: A /= B эквивалентно A = A / B

- %= : присваивание после деления по модулю. присваивает левому операнду остаток от целочисленного деления левого операнда на правый: A %= B эквивалентно A = A % B

-  >= : присваивание после сдвига разрядов (<<= и >>=). <<= присваивает левому операнду результат сдвига его битового представления влево на число разрядов, равное значению правого операнда: A <<= B эквивалентно A = A << B. >>= присваивает левому операнду результат сдвига его битового представления вправо на число разрядов, равное значению правого операнда: A >>= B эквивалентно A = A >> B

- &= : присваивание после поразрядной конъюнкции. присваивает левому операнду результат поразрядной конъюнкции его битового представления с битовым представлением правого операнда: A &= B эквивалентно A = A & B

- |= : присваивание после поразрядной дизъюнкции. присваивает левому операнду результат поразрядной дизъюнкции его битового представления с битовым представлением правого операнда: A |= B эквивалентно A = A | B

- ^= : присваивание после операции исключающего или. присваивает левому операнду результат операции исключающего или его битового представления с битовым представлением правого операнда: A ^= B эквивалентно A = A ^ B

примеры операций:

```c
int a = 5;
a += 10;		// 15
a -= 3;			// 12
a *= 2;			// 24
a /= 6;			// 4
a <<= 4;		// 64
a >>= 2;		// 16
```
