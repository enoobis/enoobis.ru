директивы условной компиляции позволяют в зависимости от условий добавить в файл определённый код. условие вычисляется препроцессором до компиляции, поэтому в итоговую единицу трансляции попадает только выбранная ветвь: остальной текст отбрасывается и компилятору не виден. это отличает их от оператора if языка, который существует во время выполнения.

прежде всего это такие директивы как **#if/#else/#endif**, действие которых напоминает условную конструкцию if:

```c
#if условие
исходный_код
#endif
```

если условие возвращает ненулевое значение (то есть оно истинно), то в итоговый исходный файл вставляется исходный код, который расположен между директивами **#if** и **#endif**. выражение после `#if` есть целочисленное константное выражение препроцессора: допустимы литералы, макросы, арифметика и логика, но не переменные времени выполнения и не sizeof.

```c
#include <stdio.h>
#define N 22

int main(void)
{
#if N==22
	printf("N=22");
#endif
	return 0;
}
```

здесь макрос N равен 22, условие `N==22` истинно, и в программу попадает вызов `printf("N=22")`. если бы N имел другое значение, этот вызов отсутствовал бы в компилируемом тексте.

директива **#else** позволяет задать альтернативный код, который компилируется, если условие не верно:

```c
#include <stdio.h>
#define N 22
 
int main(void)
{
#if N==22
    printf("N=22");
#else
    printf("N is undefined");
#endif
    return 0;
}
```

с помощью директивы **#elif** можно проверять дополнительные условия. цепочка `#if` / `#elif` / `#else` / `#endif` выбирает не более одной ветви, как каскад if-else в языке, но на этапе препроцессора:

```c
#include <stdio.h>
#define N 24

int main(void)
{
#if N==22
	printf("N = 22");
#elif N==24
	printf("N=24");
#else
	printf("N is undefined");
#endif
	return 0;
}
```

### #ifdef

с помощью директивы **#ifdef** можно проверять, определён ли идентификатор, и если он определён, вставлять в исходный код определённый текст. `#ifdef X` эквивалентно `#if defined(X)` и не смотрит на значение макроса, только на факт его существования:

```c
#include <stdio.h>
#define DEBUG

int main(void)
{
#ifdef DEBUG
	printf("Debug mode");
#endif
	return 0;
}
```

обратным действием обладает директива **#ifndef**: она включает текст, если идентификатор не определён. эту форму также используют для include guard в заголовочных файлах: повторное включение одного заголовка не приводит к повторному определению типов и макросов.

```c
#include <stdio.h>
//#define DEBUG

int main(void)
{
#ifndef DEBUG
	printf("Production mode");
#else
	printf("Debug mode");
#endif
	return 0;
}
```

в примере определение DEBUG закомментировано, поэтому срабатывает ветвь `#ifndef DEBUG` и компилируется вывод "Production mode". если строку `#define DEBUG` раскомментировать, будет выбрана ветвь `#else`.

если одновременно надо проверить значения двух идентификаторов, можно использовать специальный оператор **defined**. он истинен, когда идентификатор определён как макрос, и может входить в булевы комбинации внутри `#if` и `#elif`:

```c
#include <stdio.h>
#define BETA
#define DEBUG

int main(void)
{
#if defined DEBUG && !defined BETA
	printf("debug mode; final version");
#elif defined DEBUG && defined BETA
	printf("debug mode; beta version");
#else
	printf("undefined mode");
#endif
	return 0;
}
```

выражение `defined DEBUG && !defined BETA` отбирает отладочную сборку без метки бета-версии, `defined DEBUG && defined BETA` отбирает отладочную бета-сборку, а `#else` покрывает остальные конфигурации. такие проверки задают семейство сборок из одного исходного текста, не дублируя файлы.
