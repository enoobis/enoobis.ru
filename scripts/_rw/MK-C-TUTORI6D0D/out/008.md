для хранения данных в языке программирования c используются **переменные**. переменная характеризуется типом, именем и значением. в терминах стандарта переменная представляет собой именованный объект, то есть область памяти, содержимое которой интерпретируется в соответствии с типом.

перед использованием любую переменную необходимо определить. синтаксис определения переменной выглядит следующим образом:

```c
тип_переменной имя_переменной;
```

например, простейшее определение переменной:

```c
int number;
```

здесь определена переменная number типа **int**. определение переменной является отдельной конструкцией, поэтому после него ставится точка с запятой. тип фиксируется во время компиляции и не меняется на протяжении всего времени жизни переменной, в отличие от языков с динамической типизацией, где тип связан со значением, а не с именем.

имя переменной может состоять из букв латинского алфавита, цифр и знака подчёркивания. при этом имя должно начинаться с буквы или со знака подчёркивания.

```c
int _number33;
```

у компиляторов нередко есть ограничение на длину значимой части имени: для одних компиляторов имя переменной не должно превышать 31 символа, у других ограничение может быть жёстче. стандарт c99 гарантирует различение как минимум первых 63 символов внутренних идентификаторов и 31 символа внешних. имена, начинающиеся с подчёркивания и заглавной буквы или с двух подчёркиваний, зарезервированы за реализацией, и использовать их в собственном коде не рекомендуется.

кроме того, c является регистрозависимым языком, то есть регистр символов значим. в следующем коде определяются две разные переменные:

```c
int number;
int Number;
```

поэтому переменная Number не совпадает с переменной number.

в языке также есть ряд зарезервированных слов, которые нельзя использовать в качестве имени переменной. их немного: `auto, break, case, char, const, continue, default, do, double, else, enum, extern, float, for, goto, if, int, long, register, return, short, signed, sizeof, static, struct, switch, typedef, union, unsigned, void, volatile, while`. это набор ключевых слов c89, последующие стандарты добавили к нему, в частности, `inline`, `restrict`, `_Bool` (c99), `_Alignas`, `_Atomic`, `_Generic`, `_Noreturn`, `_Static_assert`, `_Thread_local` (c11), а c23 сделал ключевыми словами `bool`, `true`, `false`, `nullptr`, `constexpr`, `typeof` и др.

нельзя объявить в одной области видимости больше одной переменной с одним и тем же именем, например:

```c
int number;
int number;
```

такое определение вызовет ошибку на этапе компиляции. исключение составляют предварительные определения (tentative definitions) на уровне файла, где повторное `int number;` без инициализатора допустимо, однако внутри функции это всегда ошибка.

можно определить сразу несколько переменных:

```c
int number1, number2, number3;
```

здесь определены три переменные: number1, number2 и number3.

### присвоение значения

при определении локальной переменной без инициализатора её значение неопределено: память содержит то, что в ней оказалось ранее, и чтение такого значения является ошибкой программы. переменные со статической длительностью хранения (глобальные и объявленные со `static`) при этом инициализируются нулём. в дальнейшем переменной можно присвоить конкретное значение:

```c
int number;
number = 2;
```

```c
#include <stdio.h>

int main(void)
{
	int number;
	number = 2;
	printf("number = %d \n", number);
	return 0;
}
```

для вывода числа на консоль используется спецификатор %d, вместо которого подставляется значение переменной number. в результате консольный вывод будет следующим:

```consoletext
number = 2
```

переменной можно также задать начальное значение непосредственно при определении. такой приём называется **инициализацией**. синтаксически инициализация отличается от присваивания: это часть объявления, а не выражение, и для неё действуют свои правила, например, только инициализацией можно задать значение константного объекта или массива целиком:

```c
#include <stdio.h>

int main(void)
{
	int number = 2;
	printf("number = %d \n", number);
	return 0;
}
```

можно инициализировать сразу несколько переменных:

```c
#include <stdio.h>
 
int main(void)
{
    int number1 = 1, number2 = 2, number3 = 3;
    printf("number1 = %d \n", number1);
    printf("number2 = %d \n", number2);
    printf("number3 = %d \n", number3);
    return 0;
}
```
