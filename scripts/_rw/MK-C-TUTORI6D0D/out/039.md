в c одна функция может возвращать указатель на другую функцию. это оправдано, когда имеется ограниченный набор вариантов выполняемых функций и нужно выбрать один из них, причём сам набор и правило выбора инкапсулированы в промежуточной функции, своего рода фабрике.

пусть требуется выбрать и выполнить одну из трёх арифметических операций:

```c
#include <stdio.h>

int sum(int x, int y)
{
    return x + y;
}
int subtract(int x, int y)
{
    return x - y;
}
int multiply(int x, int y)
{
    return x * y;
}

//  int choice - выбранный пункт
int (*select(int choice))(int, int)
{
    // возвращаем нужную функцию
    switch (choice)
    {
        case 2:
            return subtract;
        case 3:
            return multiply;
        default:
            return sum;
    }
}
int main(void)
{
    int (*operation)(int, int);    // указатель на выбранную функцию
    operation = select(1);  // получаем указатель на функцию sum - сложение
    int result = operation(6, 4); // выполняем функцию
    printf("result: %d \n", result); // result: 10

    return 0;
}
```

в программе предполагается, что пользователь выбирает для выполнения одну из трёх функций, sum, subtract или multiply, каждая из которых реализует определённое действие.

все выбираемые функции имеют один и тот же прототип:

```c
int operation(int, int);
```

то есть возвращают значение типа `int` и принимают два параметра типа `int`.

сам выбор происходит в функции `select()`. она возвращает указатель на функцию, по сути выбранную функцию. её заголовок:

```c
int (*select(int choice))(int, int)
```

по компонентам заголовок устроен так:

```c
тип_указателя_на_функцию (*select(параметры_функции))(параметры_указателя_на_функцию)
```

сначала указывается возвращаемый тип той функции, указатель на которую возвращается (здесь `int`).

далее в скобках идут имя самой функции и её параметры: `(*select(int choice))`. функция `select`, возвращающая указатель на функцию, принимает один параметр choice, условный номер арифметической функции.

затем идут типы параметров функции, указатель на которую возвращается: `(int, int)`.

в итоге функция `select()` имеет один параметр `choice` типа `int` и возвращает указатель на функцию с прототипом `int action(int, int)`. такой заголовок читается по правилу "изнутри наружу": от имени select сначала к её параметрам, затем к `*` возвращаемого указателя и, наконец, к сигнатуре функции, на которую он указывает.

в самой функции `select()` в зависимости от значения параметра `choice` возвращается определённая функция:

```c
switch (choice)
{
    case 2:
        return subtract;
    case 3:
        return multiply;
    default:
        return sum;
}
```

в функции `main` сначала объявляется указатель, соответствующий прототипу арифметических функций sum, subtract, multiply:

```c
int (*operation)(int, int);
```

затем этому указателю присваивается результат функции `select`, которой передаётся номер функции:

```c
operation = select(1);
```

для номера 1 функция select возвращает функцию `sum`, поэтому переменная-указатель `operation` хранит адрес функции sum.

далее вызывается функция, на которую указывает указатель, и ей передаются два числа в качестве аргументов:

```c
int result = operation(6, 4); // выполняем функцию
```

аналогично получаются и другие функции:

```c
int main(void)
{
    int (*operation)(int, int) = select(2);  // получаем указатель на функцию subtract
    printf("result: %d \n", operation(6, 4)); // result: 2

    operation = select(3);  // получаем указатель на функцию multiply
    printf("result: %d \n", operation(6, 4)); // result: 24
    return 0;
}
```

определение функции, возвращающей указатель на функцию, читается тяжело, поэтому для упрощения кода и повышения читаемости можно определить псевдоним типа функции:

```c
#include <stdio.h>
 
typedef int (binary_op)(int, int);

int sum(int x, int y) { return x + y;}
int subtract(int x, int y) { return x - y;}
int multiply(int x, int y) { return x * y;}

int operation(binary_op op, int a, int b){ return op(a, b);}

//  int choice - выбранный пункт
binary_op* select(int choice)
{
    // возвращаем нужную функцию
    switch (choice)
    {
        case 2:
            return &subtract;
        case 3:
            return &multiply;
        default:
            return &sum;
    }
}
int main(void)
{
    binary_op* operation = select(1);  // получаем указатель на функцию sum - сложение
    int result = operation(6, 4); // выполняем функцию
    printf("result: %d \n", result); // result: 10

    return 0;
}
```

здесь сначала определяется псевдоним binary_op для функции, которая принимает два параметра типа `int` и возвращает значение типа `int`:

```c
typedef int (binary_op)(int, int);
```

затем этот тип, точнее указатель на него, используется как тип результата функции. возвращать сам тип функции нельзя: функция в c может возвращать указатель на функцию, но не функцию.

```c
binary_op* select(int choice)
{ 
    ..................
}
```

в функции main указатель на возвращённую функцию сохраняется в переменной operation, и через неё функция вызывается:

```c
binary_op* operation = select(1);
int result = operation(6, 4);
```
