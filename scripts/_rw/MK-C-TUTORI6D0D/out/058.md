работа функций выделения и освобождения памяти рассматривается на более сложной задаче: динамическое выделение памяти для двумерного зубчатого массива произвольной длины. в отличие от прямоугольного массива `int a[n][m]` с непрерывным размещением зубчатый массив есть массив указателей на строки разной длины; каждая строка выделяется отдельным вызовом и освобождается отдельно.

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
	int **table;	// указатель для блока памяти для массива указателей
	int *rows;		// указатель для блока памяти для хранения информации по строкам

	int rowscount;	// количество строк
	int d;		// вводимое число
	
	// ввод количества строк
	printf("Rows count=");
	scanf("%d", &rowscount);

	// выделяем память для двухмерного массива
	table = calloc(rowscount, sizeof(int*));
	rows = malloc(sizeof(int)*rowscount);
	// цикл по строкам
	for (int i = 0; i<rowscount; i++)
	{
		printf("\nColumns count for row %d=", i);
		scanf("%d", &rows[i]);
		table[i] = calloc(rows[i], sizeof(int));

		for (int j = 0; j<rows[i]; j++)
		{
			printf("table[%d][%d]=", i, j);
			scanf("%d", &d);
			table[i][j] = d;
		}
	}
	printf("\n");

	// вывод введенных чисел на консоль
	for (int i = 0; i<rowscount; i++)
	{
		printf("\n");

		for (int j = 0; j<rows[i]; j++)
		{
			printf("%d \t", table[i][j]);
		}
		// освобождение памяти для одной строки
		free(table[i]);
	}
	
	// освобождение памяти
	free(table);
	free(rows);

	return 0;
}
```

переменная `table` представляет указатель на массив указателей типа **int***. каждый указатель table[i] в этом массиве указывает на подмассив элементов типа **int**, то есть на отдельную строку таблицы. сама переменная `table` есть указатель на массив указателей на строки: тип `int **`, двойное разыменование даёт элемент `table[i][j]`.

память выделяется не для прямоугольного двумерного массива, а для зубчатого, где разные строки могут иметь разное число столбцов. для хранения числа элементов в каждом подмассиве определяется указатель `rows` типа **int**. он хранит количество столбцов для каждой строки таблицы и индексируется тем же i, что и строки `table`.

сначала вводится количество строк в переменную `rowscount`. количество строк равно числу указателей в массиве, на который указывает `table`, и одновременно числу элементов в динамическом массиве, на который указывает `rows`. поэтому вначале для обоих массивов выделяется память. `calloc` для table обнуляет указатели; если последующее выделение строки оборвётся, нулевые элементы проще отличить от уже выделенных.

```c
table = calloc(rowscount, sizeof(int*));
rows = malloc(sizeof(int)*rowscount);
```

далее в цикле вводится количество столбцов для каждой строки. введённое значение попадает в массив rows. в соответствии с этим значением для каждой строки выделяется необходимый размер памяти:

```c
scanf("%d", &rows[i]);
table[i] = calloc(rows[i], sizeof(int));
```

затем вводятся элементы каждой строки. индексация `table[i][j]` корректна, потому что `table[i]` указывает на непрерывный блок из `rows[i]` объектов int.

в конце работы программы при выводе происходит освобождение памяти. память выделялась для каждой строки таблицы, поэтому каждую строку освобождают до освобождения массива указателей: иначе адреса строк будут потеряны, и возникнет утечка.

```c
free(table[i]);
```

кроме того, освобождается память, выделенная для указателей table и rows:

```c
free(table);
free(rows);
```

порядок обратен порядку выделения: сначала строки, затем массив указателей и массив длин. обращение к `table[i]` после `free(table)` было бы неопределённым поведением.

консольный вывод программы:

```consoletext
Rows count=2

Columns count for 1=3
table[0][0]=1
table[0][1]=2
table[0][2]=3

Columns count for 2=2
table[1][0]=4
table[1][1]=5

1	2	3
4	5
```
