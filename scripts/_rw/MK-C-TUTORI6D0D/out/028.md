если переменные и константы хранят состояние программы, то функции задают её поведение. функция представляет собой именованный фрагмент кода, который можно многократно использовать в разных частях программы. функции в c не являются объектами первого класса: их нельзя создавать во время выполнения или вкладывать друг в друга, но на них можно ссылаться через указатели.

### определение функции

формальное определение функции выглядит так:

```c
тип имя_функции(параметры)
{
	выполняемые_инструкции
}
```

первая строка является заголовком функции, или её сигнатурой. сначала указывается возвращаемый тип. если функция не возвращает значения, используется тип **void**.

затем следует имя функции: произвольный идентификатор, к которому применяются те же правила, что и к именам переменных.

после имени в круглых скобках перечисляются параметры. функция может не иметь параметров, тогда указываются пустые скобки.

за заголовком в фигурных скобках идёт тело функции, содержащее выполняемые инструкции.

в предыдущих темах уже использовались как минимум две функции: каждая программа на c обязана содержать функцию **main**, а для вывода строки на консоль применялась функция `printf()`. определим простейшую собственную функцию:

```c
#include <stdio.h>

void hello()
{
	printf("Hello!\n");
}

int main(void)
{	
	return 0;
}
```

помимо стандартной функции `main` здесь определена функция `hello`. она имеет тип **void**, то есть ничего не возвращает. параметров у неё нет, поэтому после имени стоят пустые круглые скобки. единственное действие этой функции: вывод на консоль строки "Hello!".

однако если запустить программу в таком виде, на консоль ничего не выводится: определение функции само по себе не приводит к её выполнению, и функция `hello()` ни разу не исполняется.

### вызов функции

чтобы функция выполнилась, её нужно вызвать. вызов имеет вид:

```c
имя_функции(аргументы);
```

после имени функции в скобках перечисляются аргументы, то есть значения для параметров функции.

любая программа должна содержать как минимум одну функцию с фиксированным именем **main()**, с которой начинается выполнение (для размещаемых, hosted, реализаций). поэтому для выполнения функции hello её нужно вызвать из main.

```c
#include <stdio.h>

// определение функции
void hello()
{
	printf("Hello!\n");
}

int main(void)
{	
	hello();	// вызов функции
	hello();	// вызов функции
	return 0;
}
```

здесь функция hello вызывается дважды. в этом и состоит смысл функций: общее действие, даже из нескольких строк, выносится в отдельную функцию и затем многократно вызывается в разных местах программы. функция `hello()` не имеет параметров, поэтому при вызове ей не передаются аргументы и указываются пустые круглые скобки:

```c
hello();
```

в итоге программа дважды выводит строку "Hello".

### прототип или описание функции

при этом нужно учитывать, что компилятор должен знать о функции до точки её вызова: c транслирует единицу компиляции за один проход сверху вниз. поэтому вызов должен располагаться после определения функции, как в примере выше. в ряде языков порядок объявлений значения не имеет, в c же он существенен. если сначала вызвать функцию, а потом определить её, можно получить ошибку компиляции, как в следующем случае:

```c
#include <stdio.h>

int main(void)
{
	hello();
	hello();
	return 0;
}

void hello()
{
	printf("Hello!\n");
}
```

некоторые компиляторы всё же скомпилируют этот код, но выдадут предупреждение. это наследие c89, где необъявленная функция неявно считалась возвращающей int. начиная с c99 неявные объявления из языка исключены, а gcc 14 и новее по умолчанию считают такой код ошибкой. к тому же неявное объявление `int hello()` конфликтует с последующим определением `void hello()`.

другой способ решить проблему заключается в использовании описания функции, которое также называют **прототипом**. формально прототип выглядит так:

```c
тип имя_функции(параметры);
```

по сути это заголовок функции, завершённый точкой с запятой. для функции hello прототип выглядит так:

```c
void hello();
```

применим прототип функции:

```c
#include <stdio.h>

// описание
void hello(void);

int main(void)
{
	hello();
	hello();
	return 0;
}

// определение
void hello()
{
	printf("Hello!\n");
}
```

хотя определение функции расположено после её вызова, описание предшествует вызову, поэтому компилятор уже знает о функции hello, и программа работает без проблем. проверку типов на этапе компиляции выполняет компилятор по прототипу, а связывание вызова с определением выполняет компоновщик, поэтому определение может находиться и в другом файле.

если функция не принимает параметров, в скобках её прототипа указывается `void`, как в примере выше с функцией `hello`. до стандарта c23 пустые скобки в объявлении означали не «без параметров», а «параметры не указаны», и компилятор не проверял аргументы при вызове; запись `(void)` однозначна во всех версиях языка. в c23 пустые скобки стали эквивалентны `(void)`.
