директива **#define** связывает идентификатор с последовательностью символов, которая подставляется вместо идентификатора всякий раз, когда он встречается в исходном файле. подстановка выполняется препроцессором чисто текстуально, до компиляции, и не подчиняется правилам областей видимости языка. формальное определение директивы:

```c
#define идентификатор последовательность_символов
```

определяемый идентификатор также называют препроцессорным символом или макросом. используем директиву #define:

```c
#include <stdio.h>
#define N 23
 
int main(void)
{
	int x = N;
    printf("Number: %d", x);   // Number: 23
    return 0;
}
```

здесь определён один идентификатор N. везде, где в программе встречается этот идентификатор, он заменяется на число 23. например, строка

```c
int x = N;
```

после обработки препроцессором примет вид

```c
int x =23;
```

более сложный пример:

```c
#include <stdio.h>

#define BEGIN {
#define END }
#define N 23
 
int main(void)
BEGIN
	int x = N;
    printf("Number: %d", x);   // Number: 23
    return 0;
END
```

здесь определены три идентификатора: BEGIN, END и N. все вхождения лексемы "BEGIN" заменяются на открывающую фигурную скобку, "END" на закрывающую, а "N" на число 23. пример показывает, что макросы способны изменить внешний синтаксис программы, и именно поэтому злоупотребление ими считается дурным тоном.

после обработки препроцессором функция main приобретает следующий вид:

```c
int main(void)
{
	int x = 23;
	printf("Number: %d", x);
	return 0;
}
```

`#define` может задавать и более сложные выражения, в том числе макросы с параметрами. например:

```c
#include <stdio.h>

#define ADD(a,b) (a+b)

int main(void)
{
	int n1 = 10;
    int n2 = 5;
    printf("%d + %d = %d", n1, n2, ADD(n1, n2));  // 10 + 5 = 15
}
```

здесь выражение `ADD(a,b)` заменяется операцией сложения двух чисел `(a + b)`. в отличие от вызова функции, аргументы макроса подставляются как текст и не вычисляются заранее, поэтому тело макроса заключают в скобки, как здесь, а каждый параметр внутри тела тоже принято брать в скобки: без внешних скобок выражение `ADD(1, 2) * 3` раскрылось бы в `1+2 * 3` и из-за приоритета операций дало бы 7. кроме того, аргумент с побочным эффектом может вычисляться столько раз, сколько параметр встречается в теле.

директива #define особенно полезна для задания размеров массивов:

```c
#include <stdio.h>

#define N 4

int main(void)
{
	int numbers[N] = {1, 2, 3, 4};
	for(int i=0; i<N; i++)
	{
		printf("%d ", numbers[i]);
	}
	return 0;
}
```

если размер массива потребуется изменить глобально, достаточно поменять значение N в директиве define. поскольку N раскрывается в целочисленную константу, массив остаётся массивом фиксированной длины, а не массивом переменной длины, как было бы при использовании переменной.

препроцессор не заменяет последовательности символов внутри строковых и символьных литералов, то есть в двойных и одинарных кавычках, а также в комментариях:

```c
#include <stdio.h>

#define N 4

int main(void)
{
	char symbol = 'N';
	printf("%c \n", symbol);	// N
	printf("N");				//N
	return 0;
}
```

причём если сам идентификатор должен быть одним словом, то его последовательность символов может состоять из нескольких слов или символов, разделённых пробелами:

```c
#define REAL long double
```

### директива #undef

один и тот же идентификатор можно определять несколько раз:

```c
#define N 23
#define N 32
#define N 55
```

однако стандарт допускает повторное определение только с идентичным телом, поэтому компиляторы, в частности gcc, выдают предупреждения при переопределении идентификатора с другим значением. чтобы избежать этого, используется директива **#undef**, отменяющая действие макроса. её определение:

```c
#undef идентификатор
```

например:

```c
#include <stdio.h>

#define STRING "Good morning \n"

int main(void)
{
	printf(STRING);
	#undef STRING
	#define STRING "Good afternoon \n"
	printf(STRING);
	#undef STRING
	#define STRING "Good evening \n"
	printf(STRING);
	return 0;
}
```

директивы здесь стоят внутри функции, но это ни на что не влияет: препроцессор обрабатывает их последовательно по тексту, независимо от структуры программы.

### определение константы в командной строке

в компиляторе gcc флаг **-D** позволяет определить константу так же, как это делает директива **#define**. для этого применяется выражение

```c
gcc -D ИЛЕНТИФКАТОР=ЗНАЧЕНИЕ
```

определим, например, следующую программу:

```c
#include <stdio.h>

int main(void)
{
    int x = NUMBER;

    printf("x = %d\n", x);
    return 0;
}
```

здесь переменной x присваивается значение идентификатора NUMBER. он нигде в коде не определён, и среда разработки или текстовый редактор могут подчёркивать его как некорректный.

скомпилируем программу следующей командой (пусть исходный файл называется "app.c"):

```bash
gcc -D NUMBER=25 app.c -o app.exe & app.exe
```

здесь определяется препроцессорный символ NUMBER со значением 25. в итоге программа успешно компилируется, а переменная x получает значение 25. этот приём широко используется в системах сборки для передачи конфигурации, например версии или флагов отладки, без изменения исходного кода.
