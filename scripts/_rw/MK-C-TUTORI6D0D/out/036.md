в языке c функция, как и объект данных, имеет адрес, и на неё можно получить указатель. **указатель на функцию** представляет собой выражение или переменную, значением которых служит адрес функции, то есть адрес начала её исполняемого кода в памяти. стандарт c строго разделяет указатели на объекты и указатели на функции: преобразование между ними, например через `void *`, стандартом не определено, хотя posix его допускает.

чаще всего указатель на функцию возникает из её имени: в большинстве контекстов обозначение функции неявно преобразуется в указатель на неё. через имя функция вызывается и возвращает результат своей работы.

указатель на функцию можно также объявить в виде отдельной переменной со следующим синтаксисом:

```c
тип (*имя_указателя) (типы_параметров);
```

здесь тип обозначает тип возвращаемого функцией значения.

имя_указателя представляет произвольный идентификатор, выбранный по правилам именования переменных.

после имени указателя в скобках через запятую перечисляются типы параметров. если функция не принимает параметров, указывается `void`.

определим, например, указатель на функцию:

```c
void (*message) (void);
```

здесь объявлен указатель с именем **message**. он может указывать на функции без параметров, возвращающие тип `void` (то есть ничего не возвращающие). запись `(void)` после имени указателя означает, что функция не принимает параметров.

применим этот указатель:

```c
#include <stdio.h>

void hello()
{
    printf("Hello, World \n");
}
void goodbye()
{
    printf("Good Bye, World \n");
}
int main(void)
{
    // определяем указатель на функцию
    void (*message) (void);
     
    message=hello;  // указатель указывает на функцию hello
    message();      // вызываем функцию, на которую указыывет указатель
    message = goodbye;  // указатель указывает на функцию goodbye
    message();      // вызываем функцию, на которую указыывет указатель
    return 0;
}
```

указателю на функцию можно присвоить функцию, совпадающую с ним по возвращаемому типу и спецификации параметров:

```c
message=hello;
```

после этого указатель message хранит адрес функции hello, и через обращение к указателю эта функция вызывается:

```c
message();
```

затем указателю присваивается адрес другой функции. вызов через указатель разрешается во время выполнения, а не во время компиляции, и на этом построены механизмы обратных вызовов и динамической диспетчеризации в c. результат программы:

```consoletext
Hello, World
Good Bye, World
```

при объявлении указателя на функцию принципиальны скобки вокруг имени. объявление, использованное выше,

```c
void (*message) (void);
```

НЕ равнозначно следующему:

```c
void *message (void);
```

во втором случае объявлен не указатель на функцию, а прототип функции message, возвращающей указатель типа **void***. причина в приоритетах деклараторов: суффикс `()` связывается с именем сильнее, чем префикс `*`, и скобки меняют этот порядок.

указатель на функцию должен совпадать с функцией по типу возвращаемого значения и типам параметров, иначе он не может на неё указывать. вызов функции через указатель несовместимого типа приводит к неопределённому поведению.

рассмотрим ещё один указатель, на функцию, которая возвращает значение типа `int` и принимает два параметра типа `int`:

```c
#include <stdio.h>

int sum(int x, int y)
{
	return x + y;
}
int subtract(int x, int y)
{
	return x - y;
}
int main(void)
{
	int a = 10;
	int b = 5;
	int result;
	int (*operation)(int, int);
	
	operation=sum;
	result = operation(a, b);
	printf("result = %d \n", result);		// result=15
	
	operation = subtract;
	result = operation(a, b);
	printf("result = %d \n", result);		// result=5
	
	return 0;
}
```

здесь объявлен указатель operation, который может указывать на функцию с двумя параметрами типа **int**, возвращающую значение типа **int**. соответственно указателю присваиваются адреса функций sum и subtract, и они вызываются через него с передачей нужных значений параметров.

### массивы указателей на функции

помимо одиночных указателей на функции можно объявлять их массивы. формальный синтаксис:

```c
тип (*имя_массива[размер]) (параметры)
```

например:

```c
double (*actions[]) (int, int)
```

здесь actions представляет массив указателей на функции, каждая из которых должна принимать два параметра типа **int** и возвращать значение типа **double**.

применение массива указателей на функции на примере:

```c
#include <stdio.h>

void sum(int x, int y)
{
	printf("x + y = %d \n", x + y);
}
void subtract(int x, int y)
{
	printf("x - y = %d \n", x - y);
}
void multiply(int x, int y)
{
	printf("x * y = %d \n", x * y);
}
int main(void)
{
	int a = 10;
	int b = 5;
	void (*operations[3])(int, int) = {sum, subtract, multiply};
	
	// получаем длину массива
	int length = sizeof(operations)/sizeof(operations[0]);
	
	for(int i=0; i < length; i++)
	{
		operations[i](a, b);	// вызов функции по указателю
	}
	
	return 0;
}
```

здесь массив operations содержит три функции, sum, subtract и multiply, которые функция main последовательно вызывает, перебирая массив в цикле. такая таблица переходов (dispatch table) часто заменяет длинные конструкции switch, например в интерпретаторах и конечных автоматах.
