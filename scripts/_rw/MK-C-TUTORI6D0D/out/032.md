каждая переменная обладает определённой областью видимости (scope). область видимости есть участок текста программы, в пределах которого имя переменной можно использовать. её следует отличать от времени жизни (в терминах стандарта, времени хранения): область видимости является статическим, лексическим свойством имени и определяется на этапе компиляции, а время жизни описывает период выполнения программы, в течение которого существует сам объект.

по этим признакам переменные делятся на глобальные и локальные, или автоматические.

### локальные автоматические переменные

локальные переменные определяются внутри блока кода (например, внутри функции) и существуют только в пределах этого блока. они имеют автоматическое время хранения: при входе в блок для них выделяется память (её называют автоматической памятью), а по завершении блока выделенная память освобождается, и объекты перестают существовать. в типичных реализациях автоматическая память выделяется в кадре стека вызовов или в регистрах. локальная переменная без инициализатора имеет неопределённое значение.

```c
#include <stdio.h>

void printn()
{
	int n = 63;
	printf("n=%d \n", n);
}

int main(void)
{
	int a = 2;
	printn();				// n=63
	//n++;		так сделать нельзя, так как n определена в функции printn
	printf("a=%d \n", a);	// a=2
	return 0;
}
```

в функции printn определена автоматическая переменная n, в функции main определена автоматическая переменная a. вне своих функций эти переменные недоступны. например, переменную n нельзя использовать в функции main, поскольку её область видимости ограничена функцией printn.

то же относится к переменным, определённым во вложенных блоках кода, например в условных конструкциях if..else, switch..case, циклах for, while, do..while. например:

```c
void printn()
{
	{
		int n = 20;		// локальная переменная
		printf("%d \n", n);
	}
	printf("%d \n", n);	// Ошибка - здесь переменная n не видна
}
```

переменная `n` по-прежнему локальная и автоматическая, но определена не просто в функции, а во вложенном блоке внутри неё. вне этого блока её нельзя использовать даже в той же функции: область видимости заканчивается закрывающей скобкой блока, и одновременно с этим заканчивается время жизни объекта. переменная, объявленная в заголовке цикла for, видна только внутри этого цикла.

### глобальные переменные

глобальные переменные определяются в файле программы вне любых функций и доступны любой функции этого файла, расположенной после их объявления. они имеют область видимости файла и статическое время хранения: существуют на протяжении всего выполнения программы, а при отсутствии явного инициализатора инициализируются нулём.

```c
#include <stdio.h>

int n = 5;

void printn()
{
	n++;
	printf("n=%d \n", n);
}

int main(void)
{
	printn();			// n=6
	n++;
	printf("n=%d \n", n);	// n=7
	
	return 0;
}
```

здесь переменная n глобальная и доступна из любой функции, и любая функция может изменить её значение. именно поэтому глобальное изменяемое состояние затрудняет анализ программы: зависимость функции от такой переменной не отражена в её сигнатуре.

### сокрытие переменных

автоматические переменные, определённые внутри блока кода, могут скрывать внешние переменные с тем же именем:

```c
#include <stdio.h>

int n = 5;

int main(void)
{
	int n = 10;
	printf("n=%d \n", n);		// n=10
	{
		int n = 20;
		printf("n=%d \n", n);	// n=20
	}
	return 0;
}
```

здесь определены три переменные с именем **n**. автоматическая переменная n, определённая на уровне функции main (`int n = 10;`), скрывает глобальную переменную n. переменная n, определённая во вложенном блоке, скрывает переменную, определённую на уровне функции main. имя всегда разрешается к объявлению из ближайшей объемлющей области видимости. в отличие от c++, в c нет оператора `::`, поэтому из места сокрытия обратиться к глобальной переменной по имени нельзя.

### статические переменные

помимо глобальных и автоматических, существует особый вид переменных: **статические переменные**. они определяются внутри функций с помощью ключевого слова **static**. автоматические переменные создаются и инициализируются при каждом входе в функцию, статические же инициализируются только один раз, до начала выполнения программы, а при последующих вызовах функции используется сохранённое значение. статическая локальная переменная сочетает область видимости блока со статическим временем хранения, как у глобальной переменной, поэтому её инициализатор должен быть константным выражением.

например, пусть есть функция с обычной автоматической переменной:

```c
#include <stdio.h>

void display()
{
	int i = 0;
	i++;
	printf("i=%d \n", i);
}

int main(void)
{
	display();
	display();
	display();
	return 0;
}
```

функция display вызывается трижды, и при каждом вызове заново выделяется память для определённой в ней переменной i, а по завершении display эта память освобождается. поэтому при каждом вызове выводится одно и то же значение:

```bash
i=1
i=1
i=1
```

теперь сделаем переменную i статической:

```c
#include <stdio.h>

void display()
{
	static int i = 0;
	i++;
	printf("i=%d \n", i);
}

int main(void)
{
	display();
	display();
	display();
	return 0;
}
```

к объявлению переменной добавлено ключевое слово static, поэтому по завершении функции display переменная не уничтожается, а её значение сохраняется в памяти (в типичных реализациях в секции .data или .bss) между вызовами. результат работы программы меняется:

```bash
i=1
i=2
i=3
```

обратной стороной такого скрытого состояния является то, что функция перестаёт быть реентерабельной и без дополнительной синхронизации небезопасна при вызове из нескольких потоков.
