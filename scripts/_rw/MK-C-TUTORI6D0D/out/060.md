в предыдущей теме рассматривались функции calloc, malloc и realloc, результатом которых является указатель. функция, следовательно, способна не только принимать указатели в качестве параметров, но и возвращать указатель. определение такой функции имеет следующий общий вид:

```c
тип *имя_функции (параметры) 
{
	// тело функции
	тип *имя_указателя;
	return  имя_указателя;
}
```

преимущество указателя как возвращаемого типа состоит в том, что через него из функции можно передать вызывающей стороне набор значений, в частности массив. поскольку в c массив не может быть возвращён по значению, возврат указателя на первый элемент остаётся основным способом вернуть последовательность данных. в качестве примера рассматривается программа с двумя массивами, которые складываются поэлементно специальной функцией:

```c
#include <stdio.h>
#include <stdlib.h>
 
int *addArrays(int a[], int b[], int n) 
{
    int *ptr = calloc(n, sizeof(int)); 
 
     for (int i = 0; i < n; i++)
        ptr[i] = a[i] + b[i];
 
     return ptr;
}
 
int main(void)
{
    int a[] = {3,4,5,6,7};
    int b[] = {1,1,1,1,1};
 
    int n = sizeof(a)/sizeof(a[0]);
    int *ptr = addArrays(a, b, n);

    for(int i = 0; i < n; i++)
        printf("%d \t", ptr[i]);

    free(ptr);
    return 0;
}
```

для хранения результатов сложения функция `addArrays()` выделяет динамическую память, на которую указывает ptr. затем эта область заполняется суммами соответствующих элементов двух массивов, а сам указатель ptr служит возвращаемым значением. время жизни динамически выделенного объекта не связано с фреймом стека функции, поэтому после возврата память остаётся корректной, а ответственность за её освобождение переходит к вызывающему коду.

в функции main возвращённый указатель сохраняется, после чего перебираются все значения в динамической памяти:

```c
int *ptr = addArrays(a, b, n);
for(int i = 0; i < n; i++)
    printf("%d \t", ptr[i]);
```

когда указатель больше не нужен, выделенная ранее память освобождается функцией `free()`.

программа выводит следующее:

```consoletext
4	5	6 	7	8
```

указатель, возвращаемый из функции, не должен содержать адрес локальной переменной, поскольку локальная переменная с автоматической продолжительностью хранения существует лишь во время выполнения функции. после возврата такой указатель становится висячим, а любое обращение по нему приводит к неопределённому поведению. как уже говорилось, указатель может ссылаться на массив, поэтому для иллюстрации функция addArrays изменяется так:

```c
int *addArrays(int a[], int b[], int n) 
{
	int ptr[n];
    for (int i = 0; i < n; i++)
		ptr[i] = a[i] + b[i];

    return ptr;
}
```

такой пример не удаётся корректно скомпилировать, поскольку массив ptr объявлен здесь как локальная переменная: компилятор диагностирует возврат адреса локального объекта, а при строгих настройках диагностики сборка завершается ошибкой.
