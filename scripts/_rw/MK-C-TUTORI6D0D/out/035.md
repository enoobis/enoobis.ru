при рассмотрении передачи параметров в функцию указывалось, что в c параметры передаются по значению: функция получает копию аргумента и не может изменить сам аргумент. однако если параметром служит указатель, функция получает копию адреса, и через неё становится доступно и изменяемо значение исходного объекта. так в c моделируется передача по ссылке, которой в языке как отдельного механизма нет, в отличие от c++ или pascal.



пусть имеется простейшая функция, увеличивающая число на единицу:



```c

#include <stdio.h>

void increment(int x)
{
	x = x + 1;
	printf("increment function: %d \n", x);
}

int main(void)
{
	int n = 10;
	increment(n);
	printf("main function: %d \n", n);
	return 0;
}
```



здесь переменная n передаётся в качестве аргумента параметру x. передача выполняется по значению, поэтому изменение параметра x внутри increment никак не отражается на переменной n. это видно по результату запуска:



```bash

increment function: 11
main function: 10
```



изменим функцию increment, сделав параметр указателем:



```c

#include <stdio.h>

void increment(int *x)
{
	*x = *x + 1;
	printf("increment function: %d \n", *x);
}

int main(void)
{
	int n = 10;
	increment(&n);
	printf("main function: %d \n", n);
	return 0;
}
```



теперь функция increment разыменовывает указатель, получает значение и увеличивает его на единицу.



```c
*x = *x + 1;
```



так изменяется значение, расположенное по адресу, который хранится в указателе x.



поскольку функция принимает указатель, при вызове ей необходимо передать адрес переменной: `increment(&n);`.



в итоге изменение через параметр x отражается и на переменной n:



```bash

increment function: 11
main function: 11
```



ещё один показательный пример указателей в параметрах: функция обмена значений.



```c

#include <stdio.h>

void swap(int *a, int *b)
{
	int temp = *a;
	*a = *b;
	*b=temp;
}
int main(void)
{
	int x = 100;
	int y = 200;
	swap(&x, &y);
	printf("x=%d \t y=%d \n", x, y);
	return 0;
}
```



функция `swap()` принимает два указателя, и обмен значениями выполняется через промежуточную переменную temp.



при вызове swap ей передаются адреса переменных x и y, поэтому после возврата их значения оказываются переставлены. без указателей такую функцию в c написать нельзя: обмен копий не затронул бы вызывающую сторону.



### константные параметры



если необходимо запретить изменение значения через параметр-указатель внутри функции, параметр объявляется константным:



```c

#include <stdio.h>

// константный параметр
int twice(const int *x)
{
	//*x = *x * *x;     // так нельзя, так как x - константный параметр
    int y = *x + *x;
	return y;
}

int main(void)
{
	int n = 10;
	int m = twice(&n);
	printf("n = %d \n", n);     // n = 10
	printf("m = %d \n", m);     // m = 20
	return 0;
}
```



фактически такой параметр является указателем на константу: изменить значение, на которое он указывает, внутри функции нельзя. сам указатель при этом остаётся изменяемым, а квалификатор const в сигнатуре служит ещё и частью контракта функции, сообщая вызывающей стороне, что объект не будет модифицирован.



### массивы в параметрах



если функция принимает в качестве параметра массив, ей фактически передаётся только адрес начала массива: выражение типа массива при передаче преобразуется в указатель на первый элемент. как и в случае с указателями, функции доступен адрес, по которому можно менять значения, в отличие от параметров примитивных типов, передаваемых по значению.



определим, например, функцию, увеличивающую элементы массива в два раза:



```c

#include <stdio.h>

void twice(size_t n, int p[])
{
	for(size_t i = 0; i < n; i++)
	{
		p[i]= p[i] * 2;
	}
}
int main(void)
{
	int nums[] = {1, 2, 3, 4, 5};
	// получаем количество элементов массива
	size_t length = sizeof(nums)/sizeof(nums[0]);
	
	twice(length, nums);
	
	for(size_t i=0; i<length; i++)
	{
		printf("%d \t", nums[i]);
	}
	
	return 0;
}
```



функция twice принимает массив и число его элементов и в цикле удваивает каждый элемент. длину приходится передавать отдельно, поскольку информация о размере при преобразовании массива в указатель теряется, и `sizeof` внутри функции дал бы размер указателя.



в функции main массив передаётся в twice, а затем выводится на консоль. результат показывает, что массив nums был изменён:



```bash

2	4	6	8	10
```



так как передача массива в функцию фактически означает передачу адреса первого элемента, параметр-массив можно заменить указателем:



```c

#include <stdio.h>

void twice(size_t n, int *p)
{
	for(size_t i=0; i<n; i++)
	{
		*p= *p * 2;	// увеличиваем значение по указателю
		p = p + 1; // перемещаем указатель на следующий элемент
	}
}
int main(void)
{
	int nums[] = {1, 2, 3, 4, 5};
	size_t length = sizeof(nums)/sizeof(nums[0]);
	
	twice(length, nums);
	
	for(size_t i=0; i<length; i++)
	{
		printf("%d \t", nums[i]);
	}
	
	return 0;
}
```



разницы между этими вариантами по существу нет: компилятор в любом случае трактует параметр типа `int array[]` как указатель `int* array`, это правило настройки типа параметра закреплено стандартом.



при определении параметра можно даже указать длину массива, которая будет обозначать **минимально допустимое** количество элементов:



```c

#include <stdio.h>
 
// функция ожидает получить массив как минимум из 4 элементов
void twice(int numbers[4])
{
	for(size_t i = 0; i < 4; i++)
	{
		numbers[i]= numbers[i] * 2;
        printf("%d \t", numbers[i] * 2);
	}
}
int main(void)
{
	int nums[5] = {1, 2, 3, 4, 5};
	twice(nums);
	return 0;
}
```



тем не менее если передать массив меньшей длины, конкретное поведение зависит от компилятора: размер в такой записи семантически игнорируется, параметр всё равно остаётся указателем. gcc, например, успешно скомпилирует программу, хотя и выдаст предупреждение.



начиная со стандарта c99 язык позволяет задать минимальную длину массива с помощью ключевого слова **static**:



```c

// ожидаем массив как минимум с 4 элементами
void twice(int numbers[static 4])
```



такая запись является обязательством вызывающей стороны: передача указателя на меньшее число элементов или нулевого указателя ведёт к неопределённому поведению, а компилятор может использовать это обещание при оптимизации и диагностике.



#### константный массив



массив можно передать и как константный, тогда значения его элементов изменить нельзя:



```c

#include <stdio.h>
 
// массив p - константный
void twice(size_t n, const int p[])
{
	for(size_t i = 0; i < n; i++)
	{
		// p[i]= p[i] * 2;  // Так нельзя - массив константный
        printf("%d \t", p[i] * 2);
	}
}
int main(void)
{
	int nums[] = {1, 2, 3, 4, 5};
	// получаем количество элементов массива
	size_t length = sizeof(nums)/sizeof(nums[0]);
	twice(length, nums);
	return 0;
}
```
