язык c поддерживает все основные арифметические операции. они применяются к числовым значениям, а значения, участвующие в операции, называются операндами. тип результата определяется типами операндов после обычных арифметических преобразований (usual arithmetic conversions), которые стандарт описывает отдельно от самих операций. перечень арифметических операций c:

- + операция сложения возвращает сумму двух чисел:

```c
#include <stdio.h>

int main(void)
{
	int a = 67;
	int b = 33;
	int c = a + b + 7;
	printf("a + b + 7 = %d \n", c);		// 107
	return 0;
}
```

- - операция вычитания возвращает разность двух чисел:

```c
#include <stdio.h>

int main(void)
{
	int a = 67;
	int b = 33;
	int c = a - b;
	printf("a - b = %d \n", c);		// 34
	return 0;
}
```

- * операция умножения возвращает произведение двух чисел:

```c
int c = 15 * 3;		// 45
```

- / операция деления двух чисел. если оба операнда целые, выполняется целочисленное деление: дробная часть отбрасывается (начиная с c99 результат усекается в сторону нуля), и это происходит до присваивания, поэтому результат остаётся целым даже тогда, когда он записывается в переменную типа float. чтобы получить вещественный результат, хотя бы один из операндов должен иметь вещественный тип, тогда второй операнд будет преобразован к нему и деление выполнится в арифметике с плавающей точкой:

```c
#include <stdio.h>
 
int main(void)
{
    int a = 15 / 3;         // 5
    float d = 34.0 / 3.0;   // 11.333333

    printf("a=%d \n", a);
    printf("d=%f \n", d);
    return 0;
}
```

```c
float f = 10 / 4;
printf("f = %f \n", f);		// 2.0
```

```c
float f = 10.0 / 4;
printf("f = %f \n", f);		// 2.5
```

- % возвращает остаток от деления двух чисел (деление по модулю). операция определена только для целых операндов, а знак результата совпадает со знаком делимого, так что выполняется тождество (a/b)*b + a%b == a:

```c
int a = 35 % 3;			// 2 (35 - 33 = 2)
```

операции *, / и % имеют более высокий приоритет, чем + и -:

```c
int a = 8;
int b = 7;
int c = a + 5 * b;		// 43
printf("c = %d \n", c);	// 43
```

результатом здесь будет число 43:

- 5 * b = 35

- a + 35 = 43

скобки позволяют переопределить порядок вычислений, чтобы операции с более низким приоритетом выполнялись раньше операций с более высоким приоритетом:

```c
int a = 8;
int b = 7;
int c = (a + 5) * b;	// 91
```

результатом здесь будет число 91:

- a + 5 = 13

- 13 * b = 91

помимо бинарных операций, в c есть унарные операции над одним операндом: ++ (инкремент) и -- (декремент). операнд обязан быть модифицируемым lvalue, поскольку операция изменяет хранимое значение. каждая из них существует в двух формах, префиксной и постфиксной, которые различаются значением всего выражения, а не побочным эффектом.

- префиксный инкремент (++x). увеличивает значение переменной на единицу, и значением выражения ++x становится уже увеличенное значение

```c
int a = 8;
int b = ++a;
printf("a = %d \n", a);	// 9
printf("b = %d", b);	// 9
```

- постфиксный инкремент (x++). увеличивает значение переменной на единицу, однако значением выражения x++ остаётся то, которое переменная имела до увеличения:

```c
int a = 8;
int b = a++;
printf("a = %d \n", a);	// 9
printf("b = %d", b);	// 8
```

- префиксный декремент (--x). уменьшает значение переменной на единицу, и значением выражения --x становится уже уменьшенное значение

```c
int a = 8;
int b = --a;
printf("a = %d \n", a);	// 7
printf("b = %d", b);	// 7
```

- постфиксный декремент (x--). уменьшает значение переменной на единицу, однако значением выражения x-- остаётся то, которое переменная имела до уменьшения:

```c
int a = 8;
int b = a--;
printf("a = %d \n", a);	// 7
printf("b = %d", b);	// 8
```

более сложный случай:

```c
int a = 8;
int b = 7;
int c = a+++b;
printf("a = %d \n", a);	// 9
printf("b = %d \n", b);	// 7
printf("c = %d \n", c);	// 15
```

такое выражение разбирается как постфиксный инкремент, за которым следует сложение. причина лежит на уровне лексического анализа: лексер действует по правилу максимального захвата (maximal munch) и выделяет самую длинную возможную лексему, поэтому последовательность +++ распадается на ++ и +. фактически выражение эквивалентно следующему:

```c
int c = (a++) + b;
```

по тому же правилу разбирается и выражение с постфиксным декрементом: `int c = a---b;`.
