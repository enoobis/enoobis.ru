для компиляции программ на c в macos одним из наиболее популярных компиляторов является **clang** (он применяется также для компиляции программ на c++ и objective-c). принято считать, что clang работает быстрее и потребляет меньше памяти, чем gcc. для работы с clang в macos необходимо установить **xcode command line tools**. самый простой способ установить их: установить сам xcode, вместе с которым автоматически устанавливаются и xcode command line tools. без полного xcode инструменты можно установить отдельно командой `xcode-select --install`. в macos команда `gcc` по умолчанию тоже указывает на clang.

для работы в файловой системе определяется каталог для исходных файлов на c, и в нём создаётся новый файл **hello.c** со следующим кодом:

```c
#include <stdio.h>		// подключаем заголовочный файл stdio.h
int main(void)					// определяем функцию main
{								// начало функции
	printf("Hello enoobis.ru! \n");	// выводим строку на консоль
	return 0;					// выходим из функции
}								// конец функции
```

этот код совпадает с тем, что применялся для windows и linux.

чтобы вывести строку на консоль, директивой include подключается заголовочный файл stdio.h.

```c
#include <stdio.h>
```

этот заголовочный файл содержит объявление функции printf, которая выводит строку на консоль.

далее следует определение функции **int main(void)**, главной функции, которая должна присутствовать в любой программе на c. с неё начинается выполнение приложения.

ключевое слово **int** в определении `int main(void)` указывает, что функция возвращает целое число. слово void в скобках означает, что функция не принимает параметров. всё содержимое функции заключается в фигурные скобки.

в самой функции строка выводится на консоль с помощью функции printf, которой передаётся выводимая строка "Hello enoobis.ru!".

в конце выполняется выход из функции оператором **return**. поскольку функция должна возвращать целое число, после return указывается 0. ноль служит индикатором успешного завершения программы.

в терминале командой cd выполняется переход в каталог, где расположен файл с исходным кодом.

далее программа компилируется командой

```consoletext
clang hello.c
```

в результате в папке с файлом hello.c появляется скомпилированный файл, который по умолчанию называется **a.out**. он запускается следующей командой:

```consoletext
./a.out
```

на консоль будет выведена строка "Hello enoobis.ru!".

при компиляции флагом **-o** можно задать имя выходного файла:

```consoletext
clang hello.c -o app
```

в этом случае создаётся файл **app**, который также будет находиться в папке с файлом hello.c. запускается он следующим образом:

```consoletext
./app
```
