заголовочный файл **time.h** объявляет функции для работы с датой и временем. функция **time** возвращает текущее календарное время в виде значения типа **time_t** и имеет следующий прототип:

```c
time_t time(time_t *arg);
```

стандарт c определяет time_t лишь как вещественный (арифметический) тип и не фиксирует его кодировку; в posix-системах и в windows это число секунд, прошедших с 1 января 1970 года utc (эпоха unix), обычно 64-битное. параметром передаётся указатель на объект типа `time_t`, в который помещается текущее время. получить его можно двумя способами:

- как результат функции `time()`: в этом случае в качестве аргумента передаётся значение NULL.

```c
time_t mytime = time(NULL);
```

- через параметр-указатель:

```c
time_t mytime;
time(&mytime);
```

в обоих случаях `mytime` будет содержать текущее время. второй способ сохранился по историческим причинам: в ранних версиях unix функция не могла вернуть 32-битное значение как результат.

чтобы получить дату и время в разложенном виде, по компонентам (часы, минуты и т.д.), значение `time_t` преобразуется в структуру **tm** функцией **localtime()**:

```c
time_t mytime = time(NULL);
struct tm *now = localtime(&mytime);
```

в функцию `localtime()` передаётся указатель на объект `time_t`. преобразование выполняется с учётом текущего часового пояса; функция gmtime выполняет аналогичное преобразование в utc. localtime возвращает указатель на статический объект, который перезаписывается последующими вызовами, поэтому функция не реентерабельна и не потокобезопасна. для многопоточного кода существуют localtime_r в posix и localtime_s в c11 (приложение k) и в microsoft visual c++, причём сигнатуры двух последних различаются.

структура **tm** хранит компоненты даты и времени в элементах типа **int**:

- tm_sec: секунды от 0 до 60 (значение 60 допускается для високосной секунды)

- tm_min: минуты от 0 до 59

- tm_hour: часы от 0 до 23

- tm_mday: день месяца от 1 до 31

- tm_mon: месяц от 0 до 11

- tm_year: число лет, прошедших с 1900 года

- tm_wday: день недели от 0 до 6 (воскресенье имеет номер 0)

- tm_yday: количество дней, прошедших с 1 января, от 0 до 365

- tm_isdst: если больше 0, действует летнее время; если равно 0, летнее время не действует; отрицательное значение означает, что сведения недоступны.

выведем текущие дату и время на консоль:

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
	time_t mytime = time(NULL);
 	struct tm *now = localtime(&mytime);
 	printf("Date: %d.%d.%d\n", now->tm_mday, now->tm_mon + 1, now->tm_year + 1900);
 	printf("Time: %d:%d:%d\n", now->tm_hour, now->tm_min, now->tm_sec);
	return 0;
}
```

поскольку нумерация месяцев начинается с нуля, к номеру месяца прибавляется 1. аналогично, поскольку год отсчитывается от 1900, к значению года прибавляется 1900. консольный вывод будет примерно таким:

```consoletext
Date: 13.1.2023
Time: 13:13:24
```

### форматирование даты и времени. strftime

функция **strftime()** преобразует дату и время в строку заданного формата:

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
	time_t mytime = time(NULL);
 	struct tm *now = localtime(&mytime);
 	char str[20];
 	strftime(str, sizeof(str), "%T", now);
 	printf("Time: %s\n", str);
	return 0;
}
```

функция **strftime** принимает четыре аргумента.

- первый аргумент задаёт строку, в которую помещается результат. здесь это массив `char str[20]`

- второй аргумент задаёт максимальный размер этой строки, включая завершающий нулевой символ. здесь это вся строка.

- третий аргумент задаёт строку формата. здесь применяется спецификатор "%T", который выводит время в формате "часы:минуты:секунды".

- четвёртый аргумент задаёт дату и время в виде структуры tm

в данном примере извлекается только время, и отформатированная строка помещается в массив `str`. функция возвращает количество записанных символов без нулевого байта, а если результат не помещается в буфер, возвращает 0, и содержимое буфера в этом случае не определено. вывод названий месяцев и дней недели зависит от текущей локали (категория LC_TIME).

некоторые спецификаторы форматирования даты и времени:

- `%H` возвращает часы

- `%M` возвращает минуты

- `%S` возвращает секунды

- `%d` возвращает номер дня

- `%m` возвращает номер месяца

- `%h` возвращает сокращённое название месяца (синоним `%b`)

- `%y` возвращает год в виде последних двух цифр

- `%Y` возвращает год в виде четырёх цифр

- `%D` выводит дату, аналогичен набору спецификаторов `%m/%d/%y`

- `%T` выводит время, аналогичен набору спецификаторов `%H:%M:%S`

спецификаторы `%h`, `%D` и `%T` введены в c99 из posix. получение даты выглядело бы следующим образом:

```c
strftime(str, sizeof(str), "%D", now);
```
