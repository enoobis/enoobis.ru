### операции сдвига

каждое целое число хранится в памяти как фиксированное количество двоичных разрядов. операции сдвига смещают это битовое представление на заданное число разрядов влево или вправо. они определены только для целочисленных операндов, а тип результата совпадает с типом левого операнда после целочисленного повышения (integer promotion). операций сдвига две:

- << сдвигает битовое представление числа влево на заданное количество разрядов, освобождающиеся младшие разряды заполняются нулями. для неотрицательного значения, которое не переполняет тип, сдвиг на n разрядов эквивалентен умножению на 2 в степени n.

-  > (>>) сдвигает битовое представление числа вправо на заданное количество разрядов. для беззнаковых и неотрицательных знаковых значений это эквивалентно целочисленному делению на 2 в степени n. результат сдвига вправо отрицательного числа стандарт оставляет на усмотрение реализации, а сдвиг на величину, большую или равную разрядности типа, а также на отрицательную величину, даёт неопределённое поведение.

применение операций:

```c


int a = 2 << 2;			// 10  на два разрядов влево = 1000 - 8

int b = 16 >> 3;			// 10000 на три разряда вправо = 10 - 2
```

число 2 в двоичном представлении записывается как 10. при сдвиге на два разряда влево получается 1000, что в десятичной системе равно 8.

число 16 в двоичном представлении записывается как 10000. при сдвиге на три разряда вправо три младших разряда отбрасываются и получается 10, что в десятичной системе равно 2.

### поразрядные операции

поразрядные операции также выполняются над отдельными разрядами целочисленных операндов, причём каждый разряд результата зависит только от разрядов операндов в той же позиции:

- & : поразрядная конъюнкция (операция и, или поразрядное умножение). разряд результата равен 1, если соответствующие разряды обоих чисел равны 1

- | : поразрядная дизъюнкция (операция или, или поразрядное сложение). разряд результата равен 1, если хотя бы один из соответствующих разрядов равен 1

- ^ : поразрядное исключающее или. разряд результата равен 1, если ровно один из соответствующих разрядов равен 1

- ~ : поразрядное отрицание. инвертирует все разряды операнда: разряд, равный 1, становится равен 0, а разряд, равный 0, получает значение 1.

поразрядные операции & и | не следует путать с логическими && и ||: первые вычисляют оба операнда и работают с каждым битом, вторые трактуют операнд целиком как истину или ложь и используют сокращённое вычисление.

применение операций:

```c


int a = 5 | 2;			// 101 | 010 = 111  - 7

int b = 6 & 2;			// 110 & 010 = 10  - 2

int c = 5 ^ 2;			// 101 ^ 010 = 111 - 7



int f = 12;              // 00001100

int d = ~f;			// 11110011   или -13

	

printf("a = %d \n", a);

printf("b = %d \n", b);

printf("c = %d \n", c);

printf("d = %d \n", d);
```

например, выражение `5 | 2` равно 7. число 5 в двоичной записи равно 101, а число 2 равно 10, или 010. соответствующие разряды обоих чисел складываются по правилу: если хотя бы один разряд равен 1, результат равен 1. получается следующее:

| 1 | 0 | 1 |
| --- | --- | --- |
| 0 | 1 | 0 |
| 1 | 1 | 1 |

в итоге получается число 111, которое в десятичной записи равно 7.

другое выражение, `6 & 2`. число 6 в двоичной записи равно 110, а число 2 равно 10, или 010. соответствующие разряды обоих чисел перемножаются: произведение равно 1, только если оба разряда равны 1, иначе оно равно 0. получается следующее:

| 1 | 1 | 0 |
| --- | --- | --- |
| 0 | 1 | 0 |
| 0 | 1 | 0 |

результатом является число 010, которое в десятичной системе равно 2.

остаётся последний пример, инверсия числа.

#### представление отрицательных чисел

для представления чисел со знаком в c используется дополнительный код (two's complement), в котором старший разряд играет роль знакового. до c23 стандарт допускал также обратный код и представление «знак и величина», но на практике все распространённые платформы используют дополнительный код, а c23 закрепил его как единственно допустимое представление. если старший разряд равен 0, число положительное, и его двоичное представление совпадает с представлением беззнакового числа. например, 0000 0001 в десятичной системе означает 1.

если старший разряд равен 1, число отрицательное. например, 1111 1111 в десятичной системе представляет -1, а 1111 0011 представляет -13. поэтому ~12 и даёт -13: для любого x в дополнительном коде выполняется тождество ~x == -x - 1.

чтобы получить из положительного числа противоположное ему отрицательное, достаточно инвертировать все разряды и прибавить единицу:

```c


int x = 12;

int y = ~x;

y += 1;

printf("y = %d \n", y);   // y=-12
```

### примеры применения поразрядных операций

поразрядные операции применяются достаточно широко, прежде всего в низкоуровневом программировании, криптографии и ряде других областей: работа с регистрами устройств, битовыми флагами, масками, упакованными форматами данных. ниже рассматриваются простейшие примеры.

#### проверка установки определённого бита

пусть требуется проверить, установлен ли определённый бит числа. эту задачу решает следующая программа:

```c


#include <stdio.h>



int main(void)

{

    int num = 255; // 0b11111111;

    int bit = 5;

    int result = num & (1 << bit);  // 0b00100000 или 32

    printf("result: %d\n", result); 



    return 0;

}
```

переменная num содержит исходное число, в котором проверяется бит, а переменная bit задаёт номер проверяемого разряда. здесь она равна 5, поэтому проверяется, установлен ли 5-й бит числа num (нумерация разрядов начинается с нуля). для этого вычисляется выражение:

```brush


int result = num & (1 << bit);
```

вначале единица сдвигается влево на bit разрядов: `1 << bit` даёт маску, в которой установлен только проверяемый разряд (здесь 0b00100000, то есть 32). затем поразрядная конъюнкция с num обнуляет все остальные разряды, так что результат отличен от нуля тогда и только тогда, когда искомый бит установлен.
