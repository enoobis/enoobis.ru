все данные программы, в частности переменные, размещаются в памяти по определённым адресам. указатели позволяют обращаться к этим адресам напрямую и тем самым манипулировать объектами. **указатели** представляют собой объекты, значением которых служат адреса других объектов (переменных, констант, указателей) или функций. управление памятью в языке c строится на указателях: через них выражаются передача по адресу, динамическое выделение, связь массива с первым элементом.

### определение указателя

для определения указателя указывают тип объекта, на который он ссылается, и символ звёздочки `*`.

```c
тип_данных* название_указателя;
```

сначала записывается тип данных, на который указывает указатель, и символ `*`, затем имя. пробел вокруг `*` на семантику не влияет: `int* p` и `int *p` обозначают один и тот же тип «указатель на int». декларатор привязывает `*` к имени, поэтому `int* p, q` объявляет указатель `p` и обычный `int q`.

пример указателя на объект типа int:

```c
int *p;
```

пока указатель не связан ни с каким объектом, его значение неопределено, и разыменование недопустимо. далее указателю присваивается адрес переменной:

```c
int main(void)
{
    int x = 10;		// определяем переменную
    int *p;			// определяем указатель
    p = &x;			// указатель получает адрес переменной
    return 0;
}
```

### получение адреса данных

указатель хранит адрес объекта в памяти. адрес переменной даёт унарная операция **&**. она применима только к объектам, которые имеют место в памяти, то есть к переменным и элементам массива: к литералам, битовым полям и к результату приведения, не являющемуся lvalue, операция `&` не применяется.

переменная `x` имеет тип int, и указатель, хранящий её адрес, тоже должен иметь тип «указатель на int». типы должны соответствовать: присвоение адреса объекта одного типа указателю на другой без явного приведения в целом запрещено (кроме особых случаев вроде `void *`).

какой именно адрес получила переменная `x`, зависит от размещения кадра стека, выравнивания и, на современных системах, aslr. для вывода значения указателя служит спецификатор **%p**:

```c
#include <stdio.h>

int main(void)
{
	int x = 10;
	int *p;
	p = &x;
	printf("%p \n", p);		// 0060FEA8
	return 0;
}
```

в приведённом запуске машинный адрес переменной `x` равен 0x0060FEA8. для адресов принята шестнадцатеричная запись. в другом запуске или на другой машине адрес будет иным. фактически адрес есть целочисленное значение в шестнадцатеричном формате, достаточное для идентификации ячейки памяти.

в памяти по адресу 0x0060FEA8 располагается объект `x`.

![указатели в языке си](/uploads/course-lectures/fc253eb092d5768fbea339ad73556de93068d182.png)

поскольку `x` имеет тип **int**, на большинстве архитектур объект занимает 4 байта (на конкретных платформах `sizeof(int)` может отличаться). переменная типа int последовательно займёт ячейки с адресами 0x0060FEA8, 0x0060FEA9, 0x0060FEAA, 0x0060FEAB.

![указатели в си](/uploads/course-lectures/5e50002483c80887ee7c035f49210af2921bfd7a.png)

указатель **p** хранит адрес, по которому расположен `x`, то есть 0x0060FEA8. сам указатель занимает отдельный объект: на 64-разрядной платформе обычно 8 байт, независимо от размера указываемого типа.

при выводе адреса функция `printf()` ожидает, что аргумент для `%p` имеет тип `void*`, то есть указатель на `void`. часть компиляторов при соответствующих настройках выдаёт предупреждение, если передан типизированный указатель. канонически указатель приводят к `void *`:

```c
printf("%p \n", (void *)p);
```

### получение значения по адресу

поскольку указатель хранит адрес, по этому адресу можно прочитать значение, то есть содержимое `x`. для этого служит операция `*` , операция разыменования (dereference operator). её результат есть lvalue объекта, на который указывает указатель. применим разыменование и получим значение `x`:

```c
#include <stdio.h>

int main(void)
{
	int x = 10;
	int *p;
	p = &x;
	printf("Address = %p \n", (void*) p);
	printf("x = %d \n", *p);
	return 0;
}
```

консольный вывод:

```consoletext
Address = 0060FEA8
x = 10
```

значение, полученное разыменованием, можно присвоить другой переменной:

```c
int x = 10;
int *p  = &x;
int y = *p;		// присваиваем переменной y значение по адресу из указателя p
printf("x = %d \n", y);	// 10
```

переменной `y` присваивается значение по адресу из указателя `p`, то есть значение `x`.

через указатель можно и изменить объект по хранимому адресу:

```c
int x = 10;
int *p = &x;
*p = 45;
printf("x = %d \n", x);	 // 45
```

по адресу, на который указывает `p`, расположен `x`, поэтому изменяется именно `x`. оба имени, `x` и `*p`, обозначают один и тот же объект.

несколько указателей разных типов:

```c
#include <stdio.h>

int main(void)
{
	char c = 'N';
	int d = 10;
	short s = 2;
	
	char *pc = &c;			// получаем адрес переменной с типа char
	int *pd = &d;			// получаем адрес переменной d типа int
	short *ps = &s;			// получаем адрес переменной s типа short
	
	printf("Variable c: address=%p \t value=%c \n", (void*) pc, *pc);
	printf("Variable d: address=%p \t value=%d \n", (void*) pd, *pd);
	printf("Variable s: address=%p \t value=%hd \n", (void*) ps, *ps);
	return 0;
}
```

возможный консольный вывод на той же иллюстративной раскладке стека:

```consoletext
Variable c: address=0060FEA3	value=N
Variable d: address=0060FE9C	value=10
Variable s: address=0060FE9A	value=2
```

по адресам видно, что переменные часто лежат в памяти рядом, но не обязательно в том порядке, в котором они записаны в исходном тексте: компилятор вправе переставлять локальные объекты, добавлять выравнивание и не использовать часть слотов.
