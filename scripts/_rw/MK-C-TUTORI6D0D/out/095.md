qt creator представляет кроссплатформенную интегрированную среду разработки (ide), работающую в windows, linux и macos и предназначенную для разработки настольных и мобильных приложений, а также приложений для встраиваемых платформ. хотя среда ориентирована прежде всего на фреймворк qt и c++, она поддерживает и проекты на чистом c. рассмотрим, как создать простейший проект на c в qt creator.

сначала загрузим программу установки со страницы [https://www.qt.io/download-qt-installer](https://www.qt.io/download-qt-installer)

сайт автоматически определяет текущую операционную систему и предлагает загрузить для неё онлайн-установщик. загрузка начинается нажатием кнопки Download:

![загрузка программы установки qt](/uploads/course-lectures/25e0705b7f1c253c2b454a00c4243c16365ac305.png)

### установка

далее отметим пару флажков и нажмём кнопку "Далее". эти флажки фиксируют обязательства по использованию qt под открытой лицензией (lgpl/gpl), которая и позволяет пользоваться средой бесплатно:

![обязательства по использованию qt в качестве открытого по](/uploads/course-lectures/844e64957039812e5221eb666bce94a76745193a.png)

после этого начинается собственно установка; на этом шаге также отметим пару флажков и нажмём кнопку "Далее":

![установка qt](/uploads/course-lectures/65b21cc02fe4ca24cdf743ee557b0759807282cc.png)

затем установщик предложит выбрать, отправлять ли отчёты:

![send reports in qt](/uploads/course-lectures/999803135d324e9e25f6a603ab4ec594f886e569.png)

далее указывается каталог установки (можно оставить каталог по умолчанию), а также тип установки:

![installation in qt](/uploads/course-lectures/57b040857b5746e4e64011c66a87aaeee492c8ed.png)

в качестве типа установки можно выбрать "Выборочная установка"; тогда на следующем шаге потребуется указать устанавливаемые компоненты:

![выбор компонентов для установки qt](/uploads/course-lectures/786d9a95ac36fc6f7615fd36f742ebf5cb8296ae.png)

в примере выбрана последняя на момент подготовки материала версия qt 6.2.3 за исключением двух пакетов (msvc 2019). при установке в windows прежде всего следует отметить компилятор mingw, на момент подготовки материала это **MinGW 11.2.0. 64-bit**. mingw представляет порт набора компиляторов gcc под windows, и именно он будет компилировать код на c. остальные компоненты устанавливаются по необходимости. при установке нужно учитывать свободное место на диске, так как некоторые компоненты занимают довольно много места.

набор компонентов зависит от операционной системы. например, набор компонентов qt 6.2.3 для macos:

![выбор компонентов для установки qt](/uploads/course-lectures/d34e0619d9bcf573bd84b94ab62acbabd1c4aec1.png)

затем нужно принять лицензионное соглашение и настроить ярлык в меню Пуск, после чего нажать кнопку "Установить":

![начало установки qt creator](/uploads/course-lectures/1c5fff8bf8f9db5ce99c9682f038e10a3150ca05.png)

### создание проекта на c в qt creator

после завершения установки запустим qt creator. на стартовом экране выберем вкладку **Projects** (Проекты) и нажмём на ней кнопку **New** (Создать):

![первый проект в qt creator](/uploads/course-lectures/14a588fadc7419242fa431e43e3963540e5251a9.png)

в окне создания нового проекта в качестве шаблона выберем **Plain C Application**:

![первый проект на языке си в qt creator](/uploads/course-lectures/c1265741747289d2a62f56af0f9d1e3ccebd5ee7.png)

далее задаются имя проекта и каталог его размещения:

![первый проект си в qt creator](/uploads/course-lectures/5bfd72441b76ffddb1323847db6558321e4e8224.png)

на следующих шагах оставим значения по умолчанию (в том числе систему сборки, например cmake или qmake, и комплект инструментов kit, связывающий компилятор, отладчик и версию qt). на последнем шаге нажмём кнопку Finish, чтобы создать проект:

![создание проекта plain c application в qt creator](/uploads/course-lectures/9b46f19902efb7bfbe2fa9b246ca76c612672d04.png)

откроется проект с содержимым по умолчанию:

![проект plain c application в qt creator](/uploads/course-lectures/e53e12488104660768bc1a5467ea5be47306c7cb.png)

проект содержит один файл **main.c**, код которого открыт в текстовом редакторе в центральной части окна:

```c
#include <stdio.h>

int main()
{
    printf("Hello World!\n");
    return 0;
}
```

запустим программу, нажав зелёную стрелку в нижнем левом углу qt creator. среда соберёт проект и в нижней части окна откроет панель Application Output с результатом работы скомпилированной программы

![первая программа на си в qt creator](/uploads/course-lectures/c3b35ffb065395fb55c2fa82591869caca35c64c.png)
