из структур можно составлять массивы так же, как из значений любых других типов, и все формы определения массива структур аналогичны определению массивов других типов:

```c
struct person people[10];
```

здесь определён массив из 10 элементов типа struct person. элементы располагаются в памяти непрерывно, и шаг между соседними элементами равен `sizeof(struct person)`, включая возможные байты выравнивания в конце структуры.

используем массив структур в программе:

```c
#include <stdio.h>

struct person 
{
	int age;
	char name[20];
};

int main(void)
{
	struct person people[] = { {23, "Tom"}, {32, "Bob"}, {26, "Alice"}, {41, "Sam"}};
	int n = sizeof(people)/sizeof(people[0]);
	for(int i=0; i<n; i++)
	{
		printf("Name:%s \t Age: %d \n", people[i].name, people[i].age);
	}
	return 0;
}
```

массив people содержит 4 объекта person. размер массива здесь выводится компилятором из списка инициализации, а число элементов вычисляется выражением `sizeof(people)/sizeof(people[0])`, которое вычисляется на этапе компиляции и корректно только для массива, но не для указателя на его первый элемент. при инициализации данные каждой отдельной структуры заключаются во вложенные фигурные скобки:

```c
{ {23, "Tom"}, {32, "Bob"}, {26, "Alice"}, {41, "Sam"}}
```

к элементам массива структур обращаются по индексу, например `people[0]`. чтобы обратиться к элементу структуры из массива, после индекса через точку указывается имя элемента структуры: `people[i].name`

консольный вывод программы:

```consoletext
Name: Tom		Age: 23
Name: Bob		Age: 32
Name: Alice		Age: 26
Name: Sam		Age: 41
```

как и с массивами других типов, с массивами структур можно работать через указатели:

```c
#include <stdio.h>

struct person 
{
	int age;
	char name[20];
};

int main(void)
{
	struct person people[] = { {23, "Tom"}, {32, "Bob"}, {26, "Alice"}, {41, "Sam"}};
	
	int n = sizeof(people)/sizeof(people[0]);
	
	for(struct person *p=people; p < people+n; p++)
	{
		printf("Name:%s \t Age: %d \n", p->name, p->age);
	}
	return 0;
}
```

здесь массив people содержит те же 4 элемента person. для их перебора создаётся указатель *p, который устанавливается на начало массива people, и в цикле элементы структур читаются через этот указатель операцией `->`. после каждой итерации указатель увеличивается на единицу, то есть по правилам адресной арифметики смещается в памяти на число байт, занимаемое одной структурой. перебор продолжается, пока указатель не достигнет конца массива, который задаётся выражением people+n. указатель на позицию сразу за последним элементом стандарт разрешает вычислять и сравнивать, но не разыменовывать, поэтому условие `p < people+n` корректно.
