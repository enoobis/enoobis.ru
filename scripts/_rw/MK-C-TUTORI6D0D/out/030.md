функция может иметь результат, то есть значение, которое она возвращает вызывающему коду. для возврата результата служит оператор **return**, который применяется в двух формах:

```c
return;
return выражение;
```

первая форма используется в функциях, которые не возвращают значения, то есть имеют возвращаемый тип **void**.

вторая форма применяется, если возвращаемый тип функции отличен от **void**. выражение после оператора **return** задаёт возвращаемое значение; оно вычисляется и неявно преобразуется к возвращаемому типу функции, как при присваивании.

в прошлой теме была определена функция `sum` с возвращаемым типом **void**, которая ничего не возвращает:

```c
void sum(int x, int y)
{
	printf("%d + %d = %d \n", x, y,  x + y);
}
```

хотя в ней нет явного оператора **return**, достижение закрывающей фигурной скобки функции означает возврат управления, так что поведение такое же, как если бы в конце стоял оператор return без выражения:

```c
void sum(int x, int y)
{
	printf("%d + %d = %d \n", x, y,  x + y);
	return;
}
```

оба определения фактически равнозначны.

функция также может возвращать конкретное значение. изменим функцию sum так, чтобы она возвращала сумму чисел:

```c
#include <stdio.h>

int sum(int x, int y)
{
	return x + y;
}

int main(void)
{
	int x = 25;
	int y = 15;
	int result = sum(x, y);
	printf("%d + %d = %d \n", x, y, result);
}
```

теперь возвращаемый тип функции sum равен **int**. если тип функции отличен от **void**, функция должна вернуть значение этого типа. для этого применяется оператор **return**, за которым следует возвращаемое значение. стандарт c формально не запрещает функции дойти до закрывающей скобки без return, но если вызывающий код использует результат, поведение не определено; компиляторы выдают на это предупреждение (`-Wreturn-type`). исключение составляет только main.

здесь функция sum возвращает сумму своих параметров:

```c
return x + y;
```

если функция возвращает значение, его можно сохранить в переменной при вызове:

```c
int result = sum(x, y);
```

результат можно и проигнорировать, просто вызвав функцию как инструкцию: значение будет отброшено.

прототип функции sum выглядит так:

```c
int sum(int, int);
```

логика возврата результата может быть сложнее. например:

```c
#include <stdio.h>

int calculate(int x, int y, char operation)
{
	if(operation=='+')
	{
		return x + y;
	}
	else if(operation=='-')
	{
		return x - y;
	}
	else
	{
		return 0;
	}
}

int main(void)
{
	int x = 30;
	int y = 10;
	int result1 = calculate(x, y, '+');
	int result2 = calculate(x, y, '-');
	int result3 = calculate(x, y, 'g');

	printf("%d + %d = %d \n", x, y, result1);
	printf("%d - %d = %d \n", x, y, result2);
	printf("%d \n", result3);
}
```

функция `calculate()` принимает три параметра. первые два задают числа, над которыми выполняется арифметическая операция, третий задаёт знак операции. в зависимости от знака функция возвращает сумму или разность чисел, а если операция не поддерживается, возвращает 0. оператор return немедленно завершает функцию, поэтому каждая ветвь условия заканчивает выполнение независимо от остальных. возврат 0 как признака ошибки неоднозначен, поскольку 0 может быть и законным результатом; в c ошибки обычно сообщают через отдельный код возврата или выходной параметр-указатель.
