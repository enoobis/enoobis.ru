программа на языке c состоит из набора директив препроцессора, определений функций и глобальных объектов. директивы препроцессора управляют преобразованием текста до его компиляции. глобальные объекты задают используемые данные, то есть состояние программы, а функции определяют её поведение. в терминах стандарта текст программы после препроцессирования образует единицу трансляции (translation unit), которая компилируется независимо от остальных и затем объединяется с ними компоновщиком. простейшая программа на c, определённая в прошлых темах:

```c
#include <stdio.h>
int main(void)
{
	printf("Hello enoobis.ru! \n");
	return 0;
}
```

### инструкции

простейшим строительным элементом программы на c являются инструкции (statements). каждая инструкция выполняет определённое действие. в c инструкция завершается точкой с запятой (;), которая указывает компилятору на её конец. например:

```c
printf("Hello enoobis.ru!");
```

вызов функции printf, выводящей на консоль строку "Hello enoobis.ru!", является инструкцией и завершается точкой с запятой. формально это инструкция-выражение: выражение вызова функции, за которым следует `;`, а его значение отбрасывается.

набор инструкций может образовывать блок кода. блок оформляется фигурными скобками, инструкции, составляющие его тело, помещаются между открывающей и закрывающей скобками:

```c
{
	printf("Hello enoobis.ru!");
	printf("Bye world!");
}
```

в этом блоке две инструкции. обе представляют вызов функции `printf()` и выводят определённую строку на консоль. блок (составная инструкция) синтаксически считается одной инструкцией и одновременно задаёт собственную область видимости для объявленных в нём идентификаторов.

### директивы препроцессора

для вывода данных на консоль в примере выше используется функция **printf()**. чтобы она вообще стала доступна в программе на c, в начале файла с исходным кодом директивой **include** подключается заголовочный файл stdio.h.

директива **include** относится к директивам препроцессора. помимо include существует ряд других директив, например define.

каждая директива препроцессора размещается на отдельной строке. в отличие от обычных инструкций c, завершающихся точкой с запятой **;**, признаком конца препроцессорной директивы служит перевод строки. кроме того, директива должна начинаться со знака решётки #.

директива "include" определяет, какие файлы следует включить в данном месте в текст программы. по умолчанию подключаются стандартные файлы из каталога так называемых "заголовочных файлов", которые обычно поставляются вместе со стандартной библиотекой компилятора. файл "stdio.h" является одним из таких заголовочных файлов. форма `#include <...>` ищет файл в системных каталогах, форма `#include "..."` сначала ищет его относительно текущего файла.

сам термин "заголовочный файл" (header file) подразумевает включение текста файла именно в начало, или заголовок, программы. поэтому заголовочные файлы подключаются, как правило, в начале исходного кода. кроме того, заголовочный файл должен быть подключён до вызова функций, которые он объявляет. например, stdio.h содержит объявление функции printf, поэтому его необходимо подключить до вызова printf. это следствие однопроходной модели компиляции c: идентификатор должен быть объявлен до точки использования.

в целом директивы препроцессора не обязательно размещать в начале файла.

при компиляции исходного кода сначала работает препроцессор, который сканирует текст в поисках строк, начинающихся с символа #. такие строки препроцессор воспринимает как директивы и на их месте выполняет преобразование текста. например, на месте директивы `#include <stdio.h>` вставляется содержимое файла stdio.h. результат этого этапа можно увидеть, запустив gcc с флагом `-E`.

### функция main

точкой входа любой программы на c является функция **main()**. именно с неё начинается выполнение приложения. её имя **main** фиксировано и одинаково для всех программ на c.

функция также является блоком кода, поэтому её тело обрамляется фигурными скобками, между которыми располагается набор инструкций.

в литературе и примерах встречаются модификации этой функции. в частности, вместо приведённого выше определения можно написать:

```c
#include <stdio.h>
void main()
{
	printf("Hello enoobis.ru!");
}
```

или

```c
#include <stdio.h>
int main()
{
	printf("Hello enoobis.ru!");
	return 0;
}
```

такие определения не приведут к ошибке, и программа также выведет строку "Hello enoobis.ru" на консоль. большинство компиляторов их принимает. строго говоря, стандарт гарантирует только формы `int main(void)` и `int main(int argc, char *argv[])`, а прочие допускает как определяемые реализацией, поэтому `void main()` непереносима, и компилятор в режиме `-pedantic` выдаст предупреждение. начиная с c99, достижение закрывающей скобки main эквивалентно `return 0;`.

### комментарии

программа может сопровождаться комментариями. комментарии содержат описание программы и характеристики кода. при компиляции они не учитываются и не влияют на работу программы: на этапе трансляции каждый комментарий заменяется одним пробелом. при этом они помогают программисту понять, как работает код.

в c используются два типа комментариев: блочный и строчный. блочный заключается между символами **/* текст комментария */** и может занимать несколько строк. блочные комментарии не вкладываются друг в друга: первая же последовательность `*/` завершает комментарий. например:

```c
#include <stdio.h>

/* Функция main выводит 
	на консоль строку Hello World */
int main(void)
{
	printf("Hello enoobis.ru! \n");
	return 0;
}
```

строчный комментарий располагается на одной строке после двойного слеша. эта форма вошла в стандарт c только в c99, ранее она была заимствованным из c++ расширением:

```c
#include <stdio.h>		// подключаем заголовочный файл stdio.h

int main(void)					// определяем функцию main
{								// начало функции
	printf("Hello enoobis.ru!");		// выводим строку на консоль
	return 0;					// выходим из функции
}								// конец функции
```
