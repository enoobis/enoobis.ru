функция **sscanf** выполняет форматированное чтение не из потока, а из строки, то есть из массива символов, завершённого нулевым символом, и записывает разобранные значения в переменные. её прототип:

```c
int sscanf (const char * buffer, const char * format, …);
```

первый параметр задаёт строку-источник, второй задаёт формат считывания. последующие аргументы являются указателями на переменные, в которые записываются результаты. функция вариадическая, поэтому компилятор в общем случае не может проверить соответствие типов аргументов спецификаторам: ответственность за согласованность формата и типов лежит на программисте, а несоответствие приводит к неопределённому поведению. возвращаемое значение равно числу успешно присвоенных элементов (или `EOF`, если ввод закончился до первого преобразования), и его проверка позволяет обнаружить ошибки разбора.

пример чтения данных из строки:

```c
#include <stdio.h>

int main(void)
{
	char buff[50] = "F 69 123.45";
 	char c;
 	int n;
 	double d;
 	sscanf(buff, "%c %d %lf", &c, &n, &d);
 	printf("Values: %c, %d, %lf\n", c, n, d);
	return 0;
}
```

строка-источник здесь следующая:

```c
"F 69 123.45"
```

значения в ней разделены пробелом. в общем случае разделителем служит любая последовательность пробельных символов: пробелов, табуляций и переводов строки. пробел в строке формата соответствует любой такой последовательности, включая пустую.

эта строка передаётся в **sscanf** первым аргументом, а её значения считываются в переменные `c`, `n`, `d`.

второй аргумент, формат считывания, определяет, как фрагменты строки сопоставляются с переменными:

```c
"%c %d %lf"
```

поскольку значения в строке buff разделены пробелами, спецификаторы в строке формата тоже разделены пробелами. спецификатор `%c` считывает ровно один символ в переменную `c` типа char; в отличие от большинства других спецификаторов, он не пропускает ведущие пробельные символы.

спецификатор `%d` считывает целое число в переменную `n`.

спецификатор `%lf` считывает число с плавающей точкой в переменную `d` типа `double`. модификатор `l` здесь обязателен: в функциях семейства scanf `%f` соответствует указателю на `float`, а `%lf` указателю на `double`, тогда как в printf оба спецификатора эквивалентны из-за продвижения аргументов вариадических функций до `double`.

в результате консольный вывод будет таким:

```consoletext
Values: F, 69, 123.450000
```

формат считывания должен соответствовать структуре строки-источника. обычные символы формата, отличные от пробельных и `%`, должны буквально совпадать с символами входа. если бы данные в строке были разделены запятыми, запятые следовало бы указать и в формате:

```c
#include <stdio.h>

int main(void)
{
	char buff[50] = "F, 69, 123.45";
 	char c;
 	int n;
 	double d;
 	sscanf(buff, "%c, %d, %lf", &c, &n, &d);
 	printf("Values: %c, %d, %.2lf\n", c, n, d);
	return 0;
}
```

ещё один пример: строка содержит данные пользователя, имя, возраст и зарплату, которые считываются в отдельные переменные:

```c
#include <stdio.h>

int main(void)
{
	char buff[50] = "Tom 23 505.99";
 	char name[10];
 	int age;
 	double salary;
 	sscanf(buff, "%s %d %lf", name, &age, &salary);
 	printf("Name: %s \tAge: %d \tSalary: %.2lf\n", name, age, salary);
	return 0;
}
```

для `name` оператор `&` не нужен, поскольку имя массива в выражении неявно преобразуется в указатель на первый элемент. спецификатор `%s` читает последовательность непробельных символов и не ограничивает её длину, поэтому при входе длиннее буфера происходит переполнение; на практике ширину указывают явно, например `%9s` для массива из 10 символов.

строка формата может быть и более сложной:

```c
#include <stdio.h>

int main(void)
{
    char *buff = "Name is Tom and age is 38";
    char name[10];
    int age;

    sscanf(buff, "Name is %s and age is %d", name, &age);

    printf("Name: %s \tAge: %d\n", name, age);  // Name: Tom       Age: 38
    return 0;
}
```

исходная строка содержит текст `"Name is Tom and age is 38"`, и на неё накладывается шаблон `"Name is %s and age is %d"`. литеральные части шаблона сопоставляются с входом посимвольно, спецификатор `%s` захватывает строку "Tom", а спецификатор `%d` число 38. если литеральная часть не совпала, разбор прекращается, и функция возвращает число уже выполненных присваиваний.

#### считывание с консоли

в сочетании с функцией **fgets()** функция sscanf позволяет считывать данные с консоли:

```c
#include <stdio.h>

int main(void)
{
	char buff[50];
 	char name[10];
 	int age;
 	double salary;
    printf("Enter the data\n");
    if(!fgets(buff, 50, stdin))
    {
        printf("Fatal Error!\n");
        return 1;
    }
 	sscanf(buff, "%s %d %lf", name, &age, &salary);
 	printf("Name: %s \tAge: %d \tSalary: %.2lf\n", name, age, salary);
	return 0;
}
```

пример консольного ввода:

```consoletext
Enter the data
Tom 38 456.78
Name: Tom       Age: 38         Salary: 456.78
```

у такого подхода есть преимущество перед прямым чтением через **scanf**. функция `scanf` извлекает из входного буфера только символы, соответствующие спецификаторам, поэтому при несоответствии ввода формату оставшиеся в буфере символы будут прочитаны следующим вызовом scanf. связка fgets и sscanf отделяет чтение строки целиком от её разбора: строка извлекается из потока полностью, и ошибка разбора не нарушает состояние потока stdin.

### sprintf

функция **sprintf** выполняет обратную операцию: форматированно записывает данные в строку.

```c
int sprintf(char *_Buffer, const char *_Format, ...)
```

первый параметр является указателем на буфер, в который выполняется запись. второй параметр задаёт строку форматирования. дополнительные аргументы передают значения для спецификаторов из строки форматирования. функция возвращает количество записанных символов без учёта завершающего нулевого символа, который при этом тоже записывается в буфер; при ошибке возвращается отрицательное значение. размер буфера функция не проверяет, поэтому в современном коде предпочтительна `snprintf` из c99, принимающая максимальный размер буфера.

пример использования:

```c
#include <stdio.h>

void main (void)
{
    int age = 38;
    char* name = "Tom";
    char text[50];  
    int charNumber = sprintf (text, "Name: %s  Age: %d\n", name, age);  
    printf (text);  // Name: Tom  Age: 38
    printf("text length: %d", charNumber);  // text length: 19
}
```

в переменную `text` записывается строка по шаблону `"Name: %s Age: %d\n"`, в котором спецификаторы заменяются значениями переменных `name` и `age`. возвращённое значение 19 равно длине получившейся строки, включая символ перевода строки, но без нулевого символа. передача сформированной строки в printf в качестве формата допустима здесь лишь потому, что она не содержит символов `%`; в общем случае это уязвимость форматной строки, и безопаснее писать `printf("%s", text)`.
