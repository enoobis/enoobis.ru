функция **main** может получать значения извне при запуске программы. для этого стандарт предусматривает следующую сигнатуру:

```c
int main(int argc, char *argv[])
```

параметр **argc** (argument count) содержит количество аргументов командной строки, переданных приложению.

параметр **argv** (argument vector) является указателем на массив строк, представляющих переданный набор аргументов. стандарт гарантирует, что `argv[argc]` равен нулевому указателю, поэтому массив можно обходить и без argc.

выведем, например, все аргументы из массива `argv` на консоль:

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
 	for (int i = 0; i < argc; i++)
 	{
		printf("%s \n", argv[i]);
	}
	return 0;
}
```

если приложению НЕ передано ни одного аргумента, `argc` равен 1, а элемент `argv[0]` содержит имя исполняемого файла, точнее ту строку, которой программа была запущена (её точный вид зависит от операционной системы и оболочки). пусть приложение компилируется в файл `hello.exe`, тогда при запуске этого файла командой

```consoletext
hello
```

значение элемента `argv[0]` будет равно "hello", и это единственный элемент массива.

передадим приложению аргументы, запустив hello.exe следующей командой:

```consoletext
hello Tom Bob Sam
```

тогда программа получит все строки через массив argv и выведет их на консоль. разбиение командной строки на отдельные аргументы по пробелам выполняет оболочка или среда выполнения, а не сама программа:

```consoletext
hello
Tom
Bob
Sam
```
