на структуры во многом похожи объединения. **объединения** (union) позволяют определить собственный тип данных и хранят набор элементов, однако в отличие от структуры все элементы объединения имеют нулевое смещение относительно начала объекта. разные элементы занимают один и тот же участок памяти: их объектные представления накладываются друг на друга. размер объединения не меньше размера наибольшего члена и может быть увеличен до кратности выравниванию самого строго выровненного члена.

для определения объединений применяется ключевое слово **union** и следующий формальный синтаксис:

```c


union имя_объединения

{

	тип элемент1;

	тип элемент2;

	.............

	тип элементN;

};
```

объединение определяется так же, как структура, только вместо слова **struct** используется ключевое слово **union**.

ниже определяется простейшее объединение, которое хранит символ и его числовой код из таблицы ascii:

```c


union ascii

{

	int digit;

	char letter;

};
```

объединение ascii хранит в одном и том же участке памяти объект int (числовой код символа) и объект char (сам символ). конкретный размер выделенной памяти зависит от системы и реализации; в общем случае размещение выглядит следующим образом:

![объединение union в языке программирования си](/uploads/course-lectures/769327908389f8f63409c07cb5525d09f75ad5e9.png)

на большинстве платформ объект объединения `code` занимает 4 байта, поскольку размер int равен 4, а char короче. длины элементов могут различаться, и тогда размер объединения определяется по наибольшему элементу с учётом выравнивания.

после определения типа объединения создаётся его переменная, которой затем присваивается значение:

```c
union ascii code;
```

при определении переменной объединения её можно сразу инициализировать. позиционный инициализатор задаёт значение первого члена объединения. здесь это элемент digit типа int, поэтому передаётся целое число. стандарт c99 допускает назначенные инициализаторы, которыми можно инициализировать любой выбранный член.

```c
union ascii code = {120};
```

для обращения к элементам объединения, как и в случае структур, применяется операция точка:

```c


#include <stdio.h>



union ascii

{

	int digit;

	char letter;

};



int main(void)

{

	union ascii code;

	code.digit = 120;

	printf("%d - %c \n", code.digit, code.letter);	// 120 - x

	printf("%d - %d \n", code.digit, code.letter);	// 120 - 120

	

	code.letter = 87;

	printf("%d - %c \n", code.digit, code.letter);	// 87 - W

	

	return 0;

}
```

создаётся переменная code, представляющая объединение ascii. элементу `digit` (числовой код символа) присваивается число 120:

```c
code.digit = 120;
```

оба элемента, letter и digit, занимают одну и ту же память, поэтому байты объекта одни и те же: при обращении к `code.digit` они интерпретируются как объект int, при обращении к `code.letter` как объект char. чтение члена, отличного от последнего записанного, в c трактуется как переинтерпретация объектного представления; для char такое чтение корректно, поскольку char может накладываться на любой объект.

```c


printf("%d - %c \n", code.digit, code.letter);	// 120 - x

printf("%d - %d \n", code.digit, code.letter);	// 120 - 120
```

изменение одного члена меняет общее объектное представление и тем самым значение, наблюдаемое через другой член.

```c


code.letter = 87;

printf("%d - %c \n", code.digit, code.letter);	// 87 - W
```

### анонимные объединения и установка псевдонима с помощью typedef

допускаются объединения без тега (безымянный тип объединения). в учебной литературе их часто называют анонимными; в стандарте c11 анонимным объединением называется безымянный член-объединение внутри структуры, чьи поля поднимаются в охватывающую область видимости. ниже задан безымянный тип и сразу определены переменные этого типа:

```c


#include <stdio.h>



union

{

	int digit;

	char letter;

} code1, code2;		// переменные code1, code2



int main(void)

{

	code1.digit = 122;

	code2.digit = 84;

	printf("%d - %c \n", code1.digit, code1.letter);

	printf("%d - %c \n", code2.digit, code2.letter);

	

	return 0;

}
```

оператором **typedef** задаётся псевдоним для объединения:

```c


typedef union ascii

{

	int digit;

	char letter;

} ascii_code;
```

псевдонимом является идентификатор `ascii_code`, поэтому следующие определения переменных эквивалентны:

```c


union ascii code = {22};

ascii_code code2 = {22};
```

псевдоним можно установить и для объединения без тега:

```c


typedef union

{

	int digit;

	char letter;

} ascii_code;
```

### пример с объединениями

объединения применяют для хранения значения одного из нескольких типов в общей памяти. выше объединение хранило данные типов int и char в смысле общего представления: int и char накладываются друг на друга, и числовой код символа выразим и через char, и через int. более показательный пример: размеченное объединение (tagged union), где дискриминант хранится отдельно от полезной нагрузки.

```c


#include <stdio.h>



typedef enum{

    NODE_STRING,

    NODE_INT

} node_type;



typedef union

{

    int int_value;

    char* str_value;

} node_data;



typedef struct{



    node_type type;

    node_data data;



} node;



void print_node(node n){



    if(n.type == NODE_STRING){

        printf("String: %s\n", n.data.str_value);

    }

    else if(n.type == NODE_INT){

        printf("Int: %d\n", n.data.int_value);

    }

}



int main(void) {

    node n1; 

    n1.type = NODE_INT; 

    n1.data.int_value=22;



    node n2;

    n2.type = NODE_STRING; 

    n2.data.str_value= "Hello World";

    

    print_node(n1);

    print_node(n2);

    

    return 0;

}
```

определяется структура node с двумя полями: признак активного варианта в виде перечисления node_type и данные в виде поля node_data. перечисление node_type принимает значения `NODE_STRING` и `NODE_INT` и указывает, хранит ли структура строку или целое число. инвариант состоит в том, что значению type соответствует активный член объединения data. объединение node_data имеет два поля:

```c


typedef union

{

    int int_value;

    char* str_value;

} node_data;
```

если структура представляет число, к данным обращаются через поле `int_value`, если строку через поле `str_value`.

для вывода данных структуры node определяется отдельная функция `print_node()`:

```c


void print_node(node n){



    if(n.type == NODE_STRING){

        printf("String: %s\n", n.data.str_value);

    }

    else if(n.type == NODE_INT){

        printf("Int: %d\n", n.data.int_value);

    }

}
```

в зависимости от типа структуры обращение идёт к полю `n.data.str_value` или `n.data.int_value`.

в функции main для проверки создаются две структуры и их данные выводятся на консоль. консольный вывод программы:

```bash


Int: 22

String: Hello World
```

### указатели на объединения

как и для структур, допускаются указатели на объединения. для обращения к элементам объединения по указателю применяется тот же синтаксис, что и для структур:

```c


(* указатель_на_объединение).имя_элемента

указатель_на_объединение->имя_элемента
```

использование указателей на объединения:

```c


#include <stdio.h>



union ascii

{

	int digit;

	char letter;

};



int main(void)

{

	union ascii code = {45};

	union ascii * p_code = &code;

	printf("%d \n", p_code->digit);	// 45

	p_code->digit= 89;

	printf("%d \n", code.digit);		// 89

	

	return 0;

}
```
