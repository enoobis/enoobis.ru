в c файл рассматривается как неструктурированная последовательность байтов. с этой точки зрения файлом в c может оказаться как собственно файл на жёстком диске, так и принтер, дисплей и другие подключаемые устройства ввода-вывода. подобная абстракция унаследована от unix, где устройства также представлены файлами, и позволяет обрабатывать разнородные источники данных единым набором функций.

как правило, приложение и файл обмениваются блоками байтов фиксированной длины (обычно эта длина является степенью двойки, например 256 или 512 байт).

при чтении данные сначала помещаются в буфер операционной системы, а затем побайтно передаются приложению.

при записи данные накапливаются в буфере и при его заполнении записываются на диск единым блоком байтов.

буферы представляют собой участки оперативной памяти, поэтому обмен между приложением и буфером происходит значительно быстрее, чем взаимодействие с физическими устройствами вроде принтера. буферизация сокращает число системных вызовов, которые обходятся дороже обычных обращений к памяти.

файл вместе со средствами буферизации, которые к нему прилагаются, образует **поток**.

в c имеются все необходимые средства для работы с файлами и устройствами ввода-вывода. для их применения в программу подключается заголовочный файл **stdio.h**.

прежде чем работать с потоком, его необходимо открыть. открытие потока выполняет функция **fopen()** со следующим прототипом:

```c
FILE * fopen(имя_файла, режим_открытия);
```

первый параметр задаёт имя открываемого файла, второй определяет режим открытия, от которого зависит, какие операции с файлом допустимы.

функция возвращает указатель на структуру типа **FILE**, определённого в том же stdio.h. этот указатель идентифицирует поток в программе, и через него выполняется любое обращение к открытому файлу. внутреннее устройство FILE стандартом не фиксируется, поэтому программа работает с ним исключительно как с непрозрачным дескриптором через библиотечные функции.

при открытии поток связывается с этой структурой.

#### режимы открытия

каждый режим задаётся строкой символов. в частности, доступны следующие режимы:

- "w" : текстовый файл открывается для записи. если файл уже существовал, он пересоздаётся и записывается заново

- "r" : текстовый файл открывается для чтения

- "a" : текстовый файл открывается для добавления новых данных. если файл существовал ранее, данные просто дописываются в него

- "w+" : текстовый файл создаётся для записи/записи. если файл ранее существовал, при первой записи после открытия он пересоздаётся и записывается заново, а при последующих записях после открытия данные добавляются без перезаписи.

- "r+" : текстовый файл открывается для чтения/записи. запись допустима в любом месте файла, кроме его конца, то есть увеличение размера файла недопустимо.

- "a+" : текстовый файл открывается или создаётся (при отсутствии) для чтения/записи. в отличие от режима w+, файл при открытии не пересоздаётся, а в отличие от режима r+, данные можно записывать в конец файла

- "wb" : бинарный файл открывается для записи

- "rb" : бинарный файл открывается для чтения

- "ab" : бинарный файл открывается для дозаписи

- "w+b" : бинарный файл создаётся для записи/чтения

- "r+b" : бинарный файл открывается для чтения/записи

- "a+b" : бинарный файл открывается или создаётся (при отсутствии) для чтения/дозаписи

режимы разграничивают доступ к файлу: его можно открыть только для чтения, только для записи или для обеих операций сразу. кроме того, именно на уровне режима файлы разделяются на текстовые и бинарные, и программа обрабатывает файл по-разному в зависимости от выбранного режима. в текстовом режиме реализация вправе преобразовывать символы конца строки (в windows последовательность `\r\n` превращается в `\n` при чтении и обратно при записи), тогда как в бинарном режиме байты передаются без изменений. неверно заданный режим может привести к некорректной интерпретации содержимого файла.

#### закрытие файла

по окончании работы файл следует закрыть. для этого служит функция **fclose()**:

```c
int fclose(указатель_на_поток);
```

единственный параметр функции представляет собой полученный при открытии указатель на структуру FILE, связанную с файлом. закрытие сбрасывает в файл содержимое буфера и освобождает ресурсы, занятые потоком.

функция возвращает 0 при успешном выполнении и встроенное значение **EOF** в случае ошибки.

в следующем примере открывается и закрывается файл "data.txt", расположенный в той же папке, что и исполняемая программа:

```c
#include <stdio.h>

int main(void)
{
	FILE * fp = fopen("data.txt", "w");
	fclose(fp);
	return 0;
}
```

если файл находится в другом месте, указывается соответствующий относительный или абсолютный путь, например "С:\\data.txt" (если файл `data.txt` расположен в корне диска c). обратная косая черта в строковом литерале c является началом escape-последовательности, поэтому в пути она удваивается.

### обработка ошибок

при открытии или создании файла возможен ряд ошибок: например, файл, открываемый для чтения, отсутствует, не хватает памяти и т.д. при возникновении ошибки функция `fopen()` возвращает значение **NULL**, поэтому ошибку обрабатывают проверкой результата функции:

```c
#include <stdio.h>
 
int main(void)
{
	FILE * fp= fopen("data28.txt", "r");
	if(fp==NULL)
	{
		perror("Error occured while opening data28.txt");
		return 1;
	}
	
	fclose(fp);
	return 0;
}
```

для вывода сообщения об ошибке на консоль применяется встроенная функция **perror()**, которая дополняет переданную строку текстовым описанием текущего значения errno. поскольку после неудачного открытия файла дальнейшие действия не имеют смысла, вызов **return 1;** завершает работу приложения и возвращает число, отличное от нуля (ненулевое значение обычно трактуется как код ошибки).

если по указанному пути файла не окажется, консоль выведет следующую ошибку:

```consoletext
Error occured while opening data28.txt: No such file or directory
```
