-   : определяет размеры для встроенных типов данных

-   : содержит функционал для локализации

-   : макросы и функции для работы с переходами

-   : определяет макросы для работы с переменным количеством параметров в функциях

-   : определяет макросы общего назначения, типа NULL, wchar_t, size_t и др.

-   : функции для работы с системой ввода-вывода
