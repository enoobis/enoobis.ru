Ранее мы рассмотрели, что строка по сути является набором символов, окончанием которого служит нулевой символ '\0'. И фактически строку можно представить в виде массива:



```c

char hello[] = "Hello";
```



В данном случае из символов строки формируется массив из 6 символов. То есть фактически мы могли бы написать:



```c

 char hello[] = {'H', 'e', 'l', 'l', 'o', '\0'};
```



Обратите внимание, что в строке 5 символов, но массив содержит 6 символов. Так как строковые литералы завершаются по умолчанию нулевым байтом, то соотвественно и последний символ в массиве будет представлять нулевой байт, а сам массив будет содержать 6 символов.



Но в примере выше длина массива устанавливалась автоматически на основании присваиваемого значения. Если для массива явным образом определена длина, то все немного сложнее. Мы можем присвоить такому массиву строку, в которой меньше символов или больше символов, чем ожидает массив. Рассмотрим разные варианты.



Если массиву передается то количество символов, которое имеет строка:



```c

char abc[4] = "abc";
```



Здесь массив имеет длину в 4 символа и ему присваивается строка с 4 символами (включая завершающий нулевой байт). То есть фактически мы получим:



```c
char abc[4] = {'a', 'b', 'c', '\0'};
```



Если длина массива соответствует длине строки без учета нулевого байта:



```c

char abc[3] = "abc";
```



Здесь массив имеет длину в 3 символа, в этом случае завершающий нулевой байт НЕ добавляется в массив. То есть фактически мы получим:



```c
char abc[3] = {'a', 'b', 'c'};
```



Если размер массива больше размера строки, то оставшееся место в массиве заполняется нулевыми байтами. Например:



```c

char abc[5] = "abc";
// эквивалентно
char abc[4] = {'a', 'b', 'c', '\0', '\0'};
```



Если же массиву присваивается строка, в которой больше символов, чем длина массива (без учета завершающего нулевого байта), тогда много зависит от реализации. Например:



```c
char abc[2] = "abc";
```



Так, компилятор GCC успешно скомпилирует данный пример и определит массив с двумя первыми символами из строки "abc", но при этом выведет предупреждение.



### Указатель на char



Но в языке Си также для представления строк можно использовать указатели на тип **char**:



```c

#include <stdio.h>
 
int main(void)
{
	char *hello = "Hello enoobis.ru!";	// указатель на char - фактически строка
	printf("%s", hello);
	return 0;
}
```



В данном случае с точки зрения обращения к обеим строкам оба определения строки - с помощью массива и указателя будут в равнозначны. Тем не менее здесь есть различие. Для понимая этого различия сначала рассмотрим такой процесс как интернирование строк.




### String interning



В языке Си для работы со строками применяется такой механизм как **string interning** или **интернирование строк**. В этом случае строки в виде строковых литералов сохраняются в приложении в секции **.rodata** (read-only data), которые предназначены для данных только для чтения, а строковые литералы рассматриваются как неизменяемые данные. Например, возьмем следующую программу:



```c

#include <stdio.h>

char* str1 = "Hello";
char* str2 = "World";

int main(void)
{
    printf("str1 = %p \n", &str1[0]);
    printf("str2 = %p \n", &str2[0]);
     
    return 0;
}
```



Здесь определены две строки - str1 и str2, в функции main выводим адрес первого символа каждой из этих строк. Так, в моем случае я получу вывод:



```bash

str1 = 00007FF75E674000
str2 = 00007FF75E674006
```



По выводу видно, что первый символ второй строки расположен через 6 байтов начала первой строки. То есть строки расположены в памяти рядом друг с другом.



Но теперь сделаем строки одинаковыми:



```c

#include <stdio.h>

char* str1 = "Hello World";
char* str2 = "Hello World";

int main(void)
{
    printf("str1 = %p \n", &str1[0]);
    printf("str2 = %p \n", &str2[0]);
     
    return 0;
}
```



Теперь вывод будет другим:



```bash

str1 = 00007FF75F674000
str2 = 00007FF75F674000
```



Оба адреса одинаковые, потому что обе переменных в реальности указывают на одну и ту же строку. Интернирование строк позволяет избежать дублирования строк, более эффективно использовать память. Причем здесь не важно, что переменные являются глобальными. Они также могут быть локальными, но все равно будут указывать на один и тот же адрес в **.rodata**.



```c

#include <stdio.h>

int main(void)
{
    char* str1 = "Hello World";
    char* str2 = "Hello World";
    printf("str1 = %p \n", &str1[0]);
    printf("str2 = %p \n", &str2[0]);
     
    return 0;
}
```



Стоит отметь, что мы сразу можем получить адрес, по которому располагается строка:



```c

#include <stdio.h>

int main(void)
{
    char* str1 = "Hello World";
    char (*str2)[] = &"Hello World";
    printf("str1 = %p \n", &str1[0]);
    printf("str2 = %p \n", str2);
     
    return 0;
}
```



В данном случае str2 представляет указатель на массив символов и хранит адрес строки "Hello World". В итоге значения `&str1[0]` и `str2` опять же будут совпадать.



### Изменение строк



Сохранение строки по указателю в секцию rodata означает, что мы не сможем изменить эту строку. Например:



```c

#include <stdio.h>

int main(void)
{
    char* text = "Hello";
    text[1] = 'a';
    printf("New text: %s\n", text);
    return 0;
}
```



В данном случае мы пытаемся изменить второй символ (символ по индексу 1) на "a". Но при попытке запуска программы мы получим ошибку. В случае с GCC это Segmentation fault.



То же самое касается изменения строки через синтаксис указателей:



```c

char* text = "Hello";
*text = 'a';  // Ошибка
```



Теперь же вместо указателя используем массив:



```c

#include <stdio.h>

int main(void)
{
    
    char text[] = "Hello";
    text[1] = 'a';
    *text = 'B';
    *(text+2) = 'b';
    printf("%s\n", text); // Bablo
    return 0;
}
```



Теперь все нормально выполниться, а на консоль будет выведена строка "Bablo". Причем для изменения, как видно из примера, можно применять как синтаксис массивов, так и синтаксис указателей.



### Пустая строка и NULL



Указателем на символы также можно присваивать значение NULL , как и другим указателям:



```c

char* text = NULL;
if(!text) puts("text is null");
```



Однако этот случай надо отличать от пустой строки: пустая строка имеет один символ - нулевой байт:



```c

char* text1= NULL; // строка не инициализирована
char* text2= "\0"; // пустая строка
char text3[5]; // строка формально неинициализирована, но содержит мусор
char text4[5] = {'\0'}; // пустая строка
```
