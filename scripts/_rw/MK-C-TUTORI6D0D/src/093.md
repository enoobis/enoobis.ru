Одной из частых задач при написании программ является реализация безопасной обработки ошибок. Ряд современных языков программирования (например, Rust и т.д.) предоставляют специальные типы результата, который представляет либо успешное выполнение некоторой операции с результатом этой операции, либо ошибку. Этот так называемый шаблон Result, который предполагает явную обработку ошибок. При таком подходе операция возвращает один объект Result, который может быть либо Ok (успех), либо Error (сбой). Этот шаблон заставляет разработчиков явно проверять состояние успеха или ошибки, что делает поток выполнения кода и потенциальные точки отказа более понятными и менее подверженными ошибкам во время выполнения. При этом объект Result обычно инкапсулирует результат, если операция выполнена успешно, или подробную информацию об ошибке (например, код ошибки и описание), если операция выполнена успешно. Подобный подход делает код более предсказуемым и тестируемым.



С использованием макросов C мы можем легко реализовать подобный механизм. В частности, для этого рассмотрим следующие макросы:



```c

typedef enum {OK=1, ERR=0} result_type;

#define DEFINE_RESULT(T) \
typedef struct { \
    result_type type;\
    T* data; \
} Result_##T;\
\
Result_##T Ok_##T(T* data) { \
    Result_##T v = { .data = data, .type = OK}; \
    return v; \
}; \
\
Result_##T Err_##T() { \
    Result_##T v = { .data = 0, .type = ERR};\
    return v; \
};

#define RESULT(T)  Result_##T
#define Ok(T)  Ok_##T
#define Err(T)  Err_##T
```



Вначале определяется перечисление `result_type`, которое представляет тип результата. Здесь у нас два стандартных варианты: успех или ошибка (OK или ERR).



Затем определяем макрос `DEFINE_RESULT(T)`, который будет развертываться в структуру с именем `Result_##T`. Эта структура содержит тип операции (поле `type`) и указатель data на сами данные. По сути с помощью макроса `DEFINE_RESULT(T)` создается "обертка" над данными типа T. Оператор `##` в макросах C соединяет два фрагмента текста в один идентификатор во время предварительной обработки кода. И когда препроцессор видит `Result_##T`, он заменяет `T` на аргумент макроса и убирает `##`.



Например, если у нас будет вызов `DEFINE_RESULT(Person)`, то `T` это Person, а `Result_##T` превращается в `Result_Person`. Если же `T` - это `int`, то получится `Result_int`.



В итоге это позволяет C-компилятору воспринимать результат как уникальное имя структуры или функции, которое определили один раз в макросе.



Далее определены вспомогательные функции `Ok_T` и `Err_T` для удобного создания успешных или ошибочных результатов. Это позволяет функции возвращать не просто "указатель или NULL", а явный статус операции вместе с данными.



Однако есть нюанс: если передать в такой макрос тип из двух слов (например, `unsigned int`), программа выдаст ошибку, так как идентификатор `Result_unsigned int` недопустим (содержит пробел). В таких случаях сначала создают `typedef`.




Посмотрим применение этих макросов на примере:



```c

#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <assert.h>

typedef enum {OK=1, ERR=0} result_type;
#define DEFINE_RESULT(T) \
typedef struct { \
    result_type type;\
    T* data; \
} Result_##T;\
\
Result_##T Ok_##T(T* data) { \
    Result_##T v = { .data = data, .type = OK}; \
    return v; \
}; \
\
Result_##T Err_##T() { \
    Result_##T v = { .data = 0, .type = ERR};\
    return v; \
};

#define RESULT(T)  Result_##T
#define Ok(T)  Ok_##T
#define Err(T)  Err_##T


typedef struct{
    char* name;
    unsigned age;
} Person;


DEFINE_RESULT(Person)

// создание Person
RESULT(Person) Person_new(char* person_name, unsigned person_age) {
    // если нереальный возраст
    if(person_age > 110) {
        printf("Error: invalide age `%u`\n", person_age);
        return Err(Person)();
    }
    // если пустое имя 
    if(!person_name){
        puts("Error: name is NULL");
        return Err(Person)();
    }

    Person* p = malloc(sizeof(*p));

    if(!p){
        printf("Unable to locate a memory for a Person\n");
        return Err(Person)();
    }
    p->name = strdup(person_name);
    if(!p->name){
        printf("Unable to locate a memory for a Person name\n");
        return Err(Person)();
    }
    p->age = person_age;

    return Ok(Person)(p);
}
// удаляем объект Person
void Person_delete(Person* p){
    if(!p) return;
    if(p->name) free(p->name);
    free(p);
}
// тестируем успешное создание объекта Person
void test_create_person_ok(){

    // Arrange
    char* name = "Tom";
    unsigned age = 22;

    // Act
    RESULT(Person) result = Person_new(name, age);

    // Assert
    assert((result.type ==OK) && "Unable to create person");
    assert((result.data !=0) && "Null result after creating person");
    // проверяем результат
    Person* p = result.data;
    assert((!strcmp(p->name, name) && "Invalid person name"));
    assert((p->age == age) && "Invalid person age");

    puts("test_create_person_ok() PASSED!");

    if(p) Person_delete(p);
}

// тестируем некорректное имя
void test_create_person_failed_name(){

    // Arrange
    char* name = NULL;
    unsigned age = 22;

    // Act
    RESULT(Person) result = Person_new(name, age);

    // Assert
    assert((result.type ==ERR) && "test_create_person_failed_name() FAILED");

    puts("test_create_person_failed_name() PASSED!");
}

// тестируем некорректный возраст
void test_create_person_failed_age(){

    // Arrange
    char* name = "Tom";
    unsigned age = 122;

    // Act
    RESULT(Person) result = Person_new(name, age);

    // Assert
    assert((result.type ==ERR) && "test_create_person_failed_age() FAILED");

    puts("test_create_person_failed_age() PASSED!");
}

int main(void){

    test_create_person_ok();
    test_create_person_failed_age();
    test_create_person_failed_name();
    return 0;
}
```



Для тестирования макросов здесь определена структура Person, которая хранит имя (динамическая строка) и возраст.



При вызове `DEFINE_RESULT(Person)` препроцессор генерирует:



```c

typedef struct {
    result_type type;
    Person* data;
} Result_Person; // Склеилось в одно слово
```



То же самое происходит с функциями:





- `Ok_##T` становится `Ok_Person`

- `Err_##T` становится `Err_Person`




Для создания объекта структуры определена функция `Person_new()`. Это своего рода конструктор с валидацией. Например, если возраст больше 110 или имя пустое, возвращается `Err(Person)`:



```c

// если нереальный возраст
if(person_age > 110) {
    printf("Error: invalide age `%u`\n", person_age);
    return Err(Person)();
}
// если пустое имя 
if(!person_name){
    puts("Error: name is NULL");
    return Err(Person)();
}
```



В случае успеха выделяется память под структуру, копируется строка (strdup). И в итоге возвращается созданный объект:



```c

return Ok(Person)(p);
```



Функция `Person_delete:()` выполняет роль деструктора, который освобождает память - сначала имя, потом саму структуру.



В функции `main` запускаются три теста, которые используют стандартный `assert`:





- `test_create_person_ok` : Проверяет создание корректного объекта.

- `test_create_person_failed_name` : Проверяет реакцию на NULL вместо имени.

- `test_create_person_failed_age` : Проверяет валидацию возраста (граница 110 лет).



В итоге при запуске программы отработают все эти три теста, и прогармма выведет:



```bash

test_create_person_ok() PASSED!
Error: invalide age `122`
test_create_person_failed_age() PASSED!
Error: name is NULL
test_create_person_failed_name() PASSED!
```
