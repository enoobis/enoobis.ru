Стек (stack) — представляет структуру данных, которая работает по принципу "последним пришёл — первым ушёл" (LIFO). В реальности есть множество способов реализации стека, часто с помощью указателей. И макросы в Си также предоставляют один из способов для реализации стека. Так, рассмотрим следующую программу:

```c
#include <stdio.h>

#define SIZE 8  // размер стека

int stack[SIZE];

int* sp = &stack[-1];  // указатель на верхушку стека (на позицию перед стеком)

#define STACK_FULL()  (((sp-stack) + 1) >= SIZE)    // полный стек
#define STACK_EMPTY()  (((sp-stack) + 1) == 0)    // пустой стек

#define STACK_USED() ((sp-stack) + 1)  // сколько мест в стеке использовано
#define CLEAR_STACK (sp = stack - 1)    // сбрасываем стек
#define PUSH(n) (*++sp = (n))   // добавляем в стек
#define POP() (*sp--)       // получаем значение из стека


int main (void)
{
    // добавляем в стек в стек числа от 0 до  10 или до SIZE
    int i = 10; 
    while(!STACK_FULL()){
        PUSH(i);
        i++;
    }
    // выводим содержимое стека
    for(size_t i = 0; i < SIZE; ++i){
        printf("stack[%lu]: %d\n", i, stack[i]);
    }
    // извлекаем данные из стека
    while(!STACK_EMPTY()){
        printf("%d\n", POP());
    }

   return 0;
}
```

Здесь стек реализован с помощью массива и указателя, а операции над стеком описаны через макросы. Рассмотрим основные моменты.

Сначала идет описание основных компонентов:

```c
#define SIZE 8
int stack[SIZE];
int* sp = &stack[-1];
```

- константа `SIZE` задает максимальный размер стека (до 8 элементов).

- `stack` — массив, который хранит элементы стека.

- `sp` — указатель на текущую вершину стека. Изначально он указывает на позицию перед началом массива, то есть стек пуст.

Далее определяются макросы для работы со стеком:

- `STACK_FULL()` : проверяет, заполнен ли стек

- `STACK_EMPTY()` : проверяет, пуст ли стек

- `STACK_USED()` : возвращает количество элементов в стеке

- `CLEAR_STACK` : очищает стек (сбрасывает `sp` в начальное состояние)

- `PUSH(n)` : добавляет элемент в стек

- `POP()` : извлекает элемент из вершины стека

Основная логика функции `main()` разбивается на три части:

- Заполнение стека: В цикл добавляются числа, начиная с 10, до тех пор, пока стек не заполнится (максимум 8 элементов).

```c
   int i = 10;
   while(!STACK_FULL()){
       PUSH(i);
       i++;
   }
```

- Вывод содержимого стека (внутри массива): Это просто просмотр содержимого массива `stack` — он уже содержит 8 элементов.

```c
   for(size_t i = 0; i < SIZE; ++i){
       printf("stack[%lu]: %d\n", i, stack[i]);
   }
```

- Извлечение из стека: Здесь идет последовательное извлечение и печать значений из стека — происходит в обратном порядке по сравнению с тем, как они были добавлены.

```c
   while(!STACK_EMPTY()){
       printf("%d\n", POP());
   }
```

Пример вывода:

```bash
stack[0]: 10
stack[1]: 11
stack[2]: 12
stack[3]: 13
stack[4]: 14
stack[5]: 15
stack[6]: 16
stack[7]: 17
17
16
15
14
13
12
11
10
```

Таким образом, мы можем определить стек через указатели и макросы без использования структур или динамической памяти. Этот подход полезен для понимания работы с памятью на низком уровне и принципов работы стека. Важно понимать, что манипуляции с указателями вне границ массива, как `&stack[-1]`, потенциально опасны и допустимы только при особом контроле, как в этом случае.
