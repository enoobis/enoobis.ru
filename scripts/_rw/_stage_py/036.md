кортеж (`tuple`) задаёт конечную последовательность элементов. по устройству он близок к списку, однако тип неизменяемый: после создания нельзя добавить элемент, удалить элемент или заменить уже записанное значение. состояние экземпляра фиксируется в момент конструирования. если каждый элемент хешируем, хешируем и сам кортеж, и тогда он допустим как ключ словаря и как элемент множества.

кортеж записывается перечислением значений через запятую в круглых скобках.

@@FENCE_0@@

скобки только группируют выражение. кортеж создаёт запятая, поэтому та же последовательность записывается и без скобок.

@@FENCE_1@@

кортеж из одного элемента требует запятую после этого элемента. без неё скобки означают группировку, и выражение `("Tom")` остаётся строкой.

@@FENCE_2@@

кортеж строится и из другого набора, например из списка. список передаётся встроенной функции `tuple()`, которая возвращает кортеж с теми же элементами в том же порядке.

@@FENCE_3@@

число элементов возвращает встроенная функция `len()`.

@@FENCE_4@@

### обращение к элементам кортежа

индексация устроена так же, как у списка. индекс `0` адресует первый элемент с начала, индекс `-1` адресует первый элемент с конца. отрицательные индексы отсчитываются от длины последовательности.

@@FENCE_5@@

запись по индексу для кортежа не определена. операция ниже завершается исключением `TypeError`, потому что экземпляр не поддерживает присваивание элементу.

@@FENCE_6@@

кортеж раскладывается по позициям в отдельные переменные. элемент с индексом 0 попадает в первую переменную, элемент с индексом 1 во вторую, и далее в том же порядке. число имён слева обязано совпадать с числом элементов, иначе разложение завершается ошибкой.

@@FENCE_7@@

### получение подкортежей

срез кортежа записывается так же, как срез списка, и возвращает новый кортеж, не изменяя исходный. границы полуоткрытые: начальный индекс входит в срез, конечный не входит. опущенная левая граница означает начало последовательности, опущенная правая означает конец.

@@FENCE_8@@

### кортеж как параметр и результат функций

кортеж используется там, где функция должна вернуть сразу несколько значений. выражения, перечисленные через запятую после `return`, образуют один кортеж. вызывающий код получает один объект.

@@FENCE_9@@

при вызове оператор `*` распаковывает кортеж в позиционные аргументы: каждый элемент занимает очередной параметр. если элементов меньше, чем параметров, недостающие аргументы передаются отдельно, как в вызове с кортежем из двух полей и отдельной строкой `Microsoft`. если элементов ровно столько, сколько параметров, распакованного кортежа достаточно.

@@FENCE_10@@

### перебор кортежей

перебор выполняется циклами `for` и `while`. цикл `for` получает у кортежа итератор и на каждой итерации связывает очередной элемент с переменной цикла.

@@FENCE_11@@

цикл `while` обращается к элементам по индексу. индекс растёт, пока остаётся строго меньше длины кортежа.

@@FENCE_12@@

### проверка наличия значения

операция `in` проверяет, входит ли значение в кортеж. для кортежа это линейный просмотр: элементы сравниваются по порядку, пока не найдено совпадение или последовательность не кончится. ветвь `else` выполняется, когда совпадения нет.

@@FENCE_13@@
