диапазон, объект типа `range`, представляет неизменяемую последовательность целых чисел. для построения вызывается `range` в одной из трёх форм.

- `range(stop)`: все целые от 0 до `stop`, не включая `stop`
- `range(start, stop)`: все целые от `start` включительно до `stop` не включая
- `range(start, stop, step)`: целые от `start` включительно до `stop` не включая, с приращением `step`

интервал полуоткрытый справа во всех трёх формах. шаг может быть отрицательным, и тогда последовательность убывает. вызовы ниже показывают те же формы.

@@FENCE_0@@

чаще всего диапазон стоит в цикле `for`. цикл получает итератор диапазона и связывает с переменной очередное целое. аргумент `end=" "` подставляет пробел вместо перевода строки, поэтому числа от 0 до 4 печатаются в одной строке. комментарий в коде фиксирует этот вывод.

@@FENCE_1@@

вложенные циклы по двум диапазонам печатают таблицу умножения. внешний цикл задаёт первый множитель от 1 до 9, внутренний задаёт второй множитель в тех же границах. `end="\t"` разделяет произведения табуляцией, `print("\n")` завершает строку таблицы.

@@FENCE_4@@

объём памяти диапазона не зависит от того, сколько чисел он описывает. объект хранит только начало, конец и шаг, а очередное значение вычисляется при обращении. длинный диапазон занимает столько же памяти, сколько короткий. в python 3 `range` является последовательностью: у объекта есть длина и индексация, а повторный перебор того же объекта снова отдаёт те же числа. проверка вхождения целого числа выполняется по этим трём параметрам, без прохода по всем элементам.
