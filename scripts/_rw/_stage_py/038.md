словарь (`dictionary`) хранит коллекцию элементов, у каждого из которых есть уникальный ключ и связанное с ним значение. поиск, вставка и удаление по ключу в среднем занимают постоянное время: реализация основана на хеш-таблице. ключ обязан быть хешируемым, значение может иметь любой тип. с версии python 3.7 порядок вставки ключей входит в семантику языка: перебор воспроизводит этот порядок.

определение словаря имеет такой синтаксис.

@@FENCE_0@@

в фигурных скобках через запятую перечисляются элементы. у каждого элемента сначала записывается ключ, затем двоеточие и значение.

словарь `users` ниже использует в качестве ключей числа, в качестве значений строки. элемент с ключом `1` имеет значение `Tom`, элемент с ключом `2` имеет значение `Bob`, элемент с ключом `3` имеет значение `Bill`.

@@FENCE_1@@

в словаре `emails` ключами служат строки, электронные адреса, и значениями тоже строки, имена пользователей.

@@FENCE_2@@

ключи и значения не обязаны принадлежать одному типу. в одном словаре соседствуют разные типы ключей и разные типы значений.

@@FENCE_3@@

пустой словарь не содержит элементов и записывается пустыми фигурными скобками.

@@FENCE_4@@

тот же пустой словарь создаёт вызов `dict()` без аргументов.

@@FENCE_5@@

### преобразование списков и кортежей в словарь

словарь и список устроены по-разному, но список особого вида преобразуется в словарь встроенной функцией `dict()`. список должен содержать вложенные списки, и каждый вложенный список должен состоять из двух элементов. при преобразовании первый элемент пары становится ключом, второй значением.

@@FENCE_6@@

так же преобразуется двумерный кортеж, то есть кортеж, элементами которого являются кортежи из двух полей. `dict()` снова читает пары и строит отображение ключ-значение. повторный ключ в источнике оставляет в словаре последнее встреченное значение.

@@FENCE_7@@

### получение и изменение элементов

к элементу обращаются по ключу в квадратных скобках после имени словаря.

@@FENCE_8@@

чтение возвращает значение, запись по существующему ключу заменяет значение и сохраняет ключ.

@@FENCE_9@@

если при записи ключа в словаре ещё нет, пара добавляется. размер словаря увеличивается на один элемент.

@@FENCE_10@@

чтение по ключу, которого нет, завершается исключением `KeyError`. операция не создаёт элемент и не возвращает значение по умолчанию.

@@FENCE_11@@

перед обращением наличие ключа проверяется выражением `ключ in словарь`. выражение возвращает `True`, если ключ присутствует. поиск идёт по ключам. совпадение искомой строки с одним из значений само по себе результат не меняет.

@@FENCE_12@@

для чтения есть метод `get` с двумя формами.

- `get(key)`: возвращает элемент с ключом `key`. если такого ключа нет, возвращает `None`
- `get(key, default)`: возвращает элемент с ключом `key`. если такого ключа нет, возвращает значение по умолчанию `default`

в отличие от квадратных скобок, `get` при отсутствии ключа исключения не возбуждает.

@@FENCE_13@@

### удаление

удаление элемента по ключу выполняет оператор `del`.

@@FENCE_14@@

если такого ключа нет, `del` тоже возбуждает `KeyError`. перед удалением наличие ключа проверяют тем же выражением `in`.

@@FENCE_15@@

второй способ удаления даёт метод `pop()`. у него две формы.

- `pop(key)`: удаляет элемент по ключу `key` и возвращает удалённое значение. если ключа нет, возбуждается `KeyError`
- `pop(key, default)`: удаляет элемент по ключу `key` и возвращает удалённое значение. если ключа нет, возвращается `default`, и словарь не меняется

@@FENCE_16@@

чтобы удалить все элементы и оставить тот же объект пустым, вызывается `clear()`.

@@FENCE_17@@

### копирование и объединение словарей

`copy()` копирует содержимое словаря и возвращает новый словарь. копия поверхностная: вложенные изменяемые объекты не дублируются, а разделяются между исходным словарём и копией. строки и числа, как в примере, при этом ведут себя как независимые значения, потому что сами неизменяемы.

@@FENCE_18@@

`update()` объединяет два словаря. пары из аргумента добавляются в словарь, у которого метод вызван. при совпадении ключа новое значение заменяет прежнее.

@@FENCE_19@@

словарь `users2` остаётся прежним. меняется только `users`: в него попадают элементы второго словаря. если оба исходных словаря нужно сохранить, а объединение получить в третьем объекте, один словарь сначала копируется, и уже у копии вызывается `update`.

@@FENCE_20@@

### перебор словаря

перебор выполняет цикл `for`. итерация по словарю отдаёт ключи в порядке вставки. значение текущего элемента получается отдельным обращением по этому ключу.

@@FENCE_21@@

на каждом шаге цикл связывает имя с ключом, а выражение `users[key]` читает соответствующее значение.

другой перебор даёт метод `items()`.

@@FENCE_22@@

`items()` возвращает представление пар. каждая пара является кортежем из ключа и значения, и при переборе эти два поля сразу связываются с переменными `key` и `value`. представление связано со словарём: оно не копирует пары в отдельный список.

ключи и значения перебираются и по отдельности. ключи отдаёт метод `keys()`.

@@FENCE_23@@

такой перебор избыточен. без вызова `keys()` итерация по словарю и так отдаёт ключи, что уже показано выше.

только значения отдаёт метод `values()`.

@@FENCE_24@@

### комплексные словари

кроме чисел и строк словарь хранит и составные объекты: списки, кортежи и другие словари. значением элемента тогда является целый объект, а ключ по-прежнему хешируемый.

@@FENCE_25@@

в этом примере значение каждого элемента само является словарём. набор полей у вложенных словарей может различаться: у одного элемента есть ключ `skype`, у другого его нет.

обращение к полю вложенного словаря требует двух ключей. первый выбирает внешний элемент, второй выбирает поле внутри него. запись по тем же двум ключам заменяет вложенное значение.

@@FENCE_26@@

если второго ключа во вложенном словаре нет, чтение возбуждает `KeyError`. внешний ключ при этом может существовать: исключение относится к внутреннему обращению.

@@FENCE_27@@

ошибка снимается проверкой ключа во вложенном словаре. выражение `in` снова относится к ключам того словаря, у которого оно записано.

@@FENCE_28@@

альтернатива проверке состоит в вызове `get()` у вложенного словаря. метод возвращает запасное значение, если внутреннего ключа нет. если отсутствует сам внешний ключ, выражение `users["Tom"]` по-прежнему завершается `KeyError`: `get` в примере вызывается уже у найденного вложенного словаря.
