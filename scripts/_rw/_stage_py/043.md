встроенная функция `zip()` объединяет элементы нескольких коллекций в один набор кортежей. коллекциями могут быть списки, словари, кортежи и строки. объединяемые объекты передаются аргументами через запятую.

@@FENCE_0@@

результатом является итератор по кортежам. кортеж с очередным номером содержит элементы с тем же номером из каждой коллекции-аргумента: первый кортеж собирает первые элементы, второй кортеж собирает вторые элементы, и далее тем же правилом. итератор останавливается, когда заканчивается самая короткая коллекция. число кортежей равно числу элементов в наименьшей из объединяемых коллекций.

пример с двумя списками одинаковой длины показывает это соответствие по позициям.

@@FENCE_1@@

в `zip()` передаются два списка, в каждом по три элемента. функция собирает элементы одной позиции в отдельный кортеж. получаются три кортежа по два элемента, потому что аргументов два и длина каждого списка равна трём. цикл перебирает результат и связывает очередной кортеж с переменной `user`.

полученный кортеж можно сразу разложить на отдельные переменные в заголовке цикла.

@@FENCE_2@@

результат можно сначала связать с переменной и перебрать уже её.

@@FENCE_3@@

печать `users` показывает объект `zip`. результат функции является итератором. список кортежей из него получают отдельно, конструктором `list`, когда нужно материализовать все пары. итератор одноразовый: после полного прохода повторный перебор того же объекта новых элементов не даёт.

вызов без аргументов возвращает пустой итератор. цикл по нему не выполняет тело ни разу.

@@FENCE_4@@

вызов с одним итерируемым аргументом возвращает итератор одноэлементных кортежей. размер кортежа совпадает с числом переданных коллекций, здесь с единицей.

@@FENCE_5@@

словарь при переборе отдаёт ключи, поэтому `zip` от словаря с одним элементом получает ключ `1` и упаковывает его в кортеж `(1,)`.

размер возвращаемых кортежей и дальше равен числу коллекций, переданных в функцию. если передана одна коллекция, например список, для каждого её элемента создаётся свой одноэлементный кортеж.

@@FENCE_6@@

если списки разной длины, `zip()` останавливается на самом коротком. элементы более длинного списка, которым нет пары, в результат не входят.

@@FENCE_7@@

ниже разобраны типичные задачи, которые решаются через `zip()`.

### объединение списков

самый частый случай состоит в объединении списков. в первом примере имена и возрасты уже складывались в ряд кортежей, и каждый кортеж описывал одного пользователя. из того же итератора получается один список кортежей.

@@FENCE_8@@

так же объединяется и большее число списков. в каждый кортеж тогда входит по одному элементу из каждого списка.

@@FENCE_9@@

### разложение списка кортежей

список кортежей раскладывается на отдельные кортежи обратной операцией. распаковка `*users` передаёт каждый кортеж отдельным аргументом `zip`, и `zip` собирает поля одной позиции вместе. на выходе два кортежа: все имена и все возрасты.

@@FENCE_10@@

### одновременный перебор нескольких списков

`zip` нужен и тогда, когда несколько списков нужно пройти синхронно, не собирая промежуточный список пар.

@@FENCE_11@@

### создание словарей

элементы двух списков или кортежей сопоставляются по позиции и превращаются в словарь. элементы первого списка становятся ключами, элементы второго становятся значениями. конструктор `dict` принимает как раз набор пар.

@@FENCE_12@@

### работа с диапазонами

`zip` объединяет и диапазоны с другими последовательностями. `range` отдаёт целые по мере запроса, `zip` забирает их по одному и ставит в пару с элементом второй коллекции.

@@FENCE_13@@

### сравнение элементов в списках

`zip()` ставит рядом элементы двух списков с одинаковым индексом, и их можно сравнить поэлементно. включение ниже записывает в список результат сравнения каждой пары.
