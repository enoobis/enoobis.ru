включение списка (`list comprehension`) задаёт список выражением над другим набором данных. синтаксис короче эквивалентного цикла с `append`, семантика та же: создаётся новый список.

@@FENCE_0@@

у конструкции четыре составляющие.

- `iterable`: перебираемый источник. им может быть список, множество, другая последовательность или объект, который отдаёт набор значений, в том числе результат `range()`
- `item`: элемент, извлекаемый из источника на текущем шаге
- `expression`: выражение, значение которого помещается в создаваемый список
- `condition`: необязательный фильтр. элемент, который условию не удовлетворяет, в список не включается

требуется отобрать из списка числа больше нуля. без включения это записывается циклом: пустой список наполняется методом `append`, когда `n > 0`.

@@FENCE_1@@

то же отображение записывается включением.

@@FENCE_2@@

выражение `[n for n in numbers if n > 0]` читается так: из списка `numbers` каждый элемент связывается с `n`, и если `n` больше 0, значение `n` попадает в результирующий список. в python 3 переменная элемента живёт в области видимости самого включения и не подменяет одноимённую переменную снаружи.

### источник данных iterable

источником может быть любой итерируемый объект: список, словарь, множество, строка, результат функции. `range()` отдаёт целые от нуля до указанной границы, не включая её.

@@FENCE_3@@

той же конструкцией из словаря получают список. при переборе словарь отдаёт ключи, поэтому включение ниже собирает ключи.

@@FENCE_4@@

### возвращение результата

`expression` вычисляется на каждом отобранном элементе, и его значение помещается в новый список. в примерах выше выражение совпадало с самим элементом.

@@FENCE_5@@

здесь `expression` и есть элемент `n`, извлечённый из `numbers`. на его месте может стоять другое выражение. удвоение записывается так.

@@FENCE_6@@

`expression` в этом включении равно `n * 2`.

выражение может быть и условным. условное выражение стоит на месте значения и выбирает, что именно положить в список. оно не отбрасывает элементы.

@@FENCE_7@@

`expression` здесь равно `n * 2 if n > 0 else n`: при `n > 0` в список попадает `n * 2`, в остальных случаях попадает `n`. длина результата совпадает с длиной источника, потому что фильтра в конце включения нет.

во `expression` выполняются и другие преобразования. из словаря можно собрать строки, в которых рядом стоят ключ и значение по этому ключу.

@@FENCE_8@@

### условие

`condition` задаёт фильтр источника. во включение попадают только те элементы, для которых условие истинно. чётные числа из диапазона отбираются остатком от деления на 2.

@@FENCE_9@@

тот же фильтр применяется к ключам словаря: в список попадают только ключи, длина которых больше 3, уже в виде строки «ключ: значение».
