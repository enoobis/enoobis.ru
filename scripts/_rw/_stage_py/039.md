множество (`set`) хранит набор уникальных элементов. порядок элементов язык не фиксирует, индексации по позиции у множества нет. элемент обязан быть хешируемым: множество, как и словарь, построено на хеш-таблице. литерал записывается фигурными скобками, элементы перечисляются через запятую.

@@FENCE_0@@

в литерале строка `Tom` записана дважды, а при печати она появляется один раз. множество хранит только уникальные значения, повторная вставка того же элемента состояние не меняет. порядок в комментарии к `print` относится к одному конкретному выводу и контрактом типа не является.

построить множество можно функцией `set()`, передав ей список или кортеж. конструктор обходит источник и оставляет по одному экземпляру каждого значения.

@@FENCE_1@@

пустые фигурные скобки `{}` обозначают пустой словарь. пустое множество даёт вызов `set()` без аргументов: конструктор без источника создаёт множество длины 0.

@@FENCE_2@@

длину множества, число хранимых уникальных элементов, возвращает встроенная функция `len()`.

@@FENCE_3@@

### добавление элементов

один элемент добавляется методом `add()`. если равный элемент уже есть, множество не меняется.

@@FENCE_4@@

### удаление элементов

один элемент удаляется методом `remove()`. если такого элемента нет, метод возбуждает `KeyError`. перед удалением наличие проверяется операцией `in`.

@@FENCE_5@@

метод `discard()` удаляет элемент, если он есть, и ничего не делает, если его нет. исключения при отсутствии элемента нет.

@@FENCE_6@@

все элементы удаляет `clear()`. объект множества остаётся, содержимое становится пустым.

@@FENCE_7@@

### перебор множества

элементы перебирает цикл `for`. на каждой итерации очередной элемент связывается с переменной `user`. полагаться на порядок обхода нельзя: он не входит в семантику типа.

@@FENCE_8@@

при таком переборе каждый элемент по очереди попадает в переменную `user`.

### операции с множествами

`copy()` копирует содержимое множества в новый объект, который связывается с другой переменной. дальнейшие добавления и удаления у одной переменной другую не затрагивают.

@@FENCE_9@@

### объединение множеств

`union()` объединяет два множества и возвращает новое. исходные множества не изменяются. элемент, который входит хотя бы в одно из них, входит в результат ровно один раз.

@@FENCE_10@@

ту же операцию записывает оператор `|`, логическое сложение множеств. результат снова является новым множеством.

@@FENCE_11@@

### пересечение множеств

пересечение содержит только те элементы, которые одновременно входят в оба множества. `intersection()` выполняет операцию и возвращает новое множество, не изменяя операнды.

@@FENCE_12@@

ту же операцию записывает оператор `&`, логическое умножение множеств. результат совпадает с результатом `intersection()`.

@@FENCE_13@@

вариант `intersection_update()` записывает пересечение в первое множество. второй операнд не меняется, прежнее содержимое первого замещается.

@@FENCE_14@@

### разность множеств

разность возвращает элементы, которые есть в первом множестве и отсутствуют во втором. её вычисляет метод `difference` или оператор вычитания `-`. оба варианта в примере дают одно и то же новое множество. операнды местами не симметричны: `users2 - users` содержал бы другие элементы.

@@FENCE_15@@

симметрическая разность возвращает все элементы обоих множеств, кроме общих. её вычисляет `symmetric_difference()` или оператор `^`.

@@FENCE_16@@

### отношения между множествами

`issubset` проверяет, является ли текущее множество подмножеством другого, то есть входит ли каждый его элемент в аргумент.

@@FENCE_17@@

`users` целиком содержится в `superusers`, поэтому первый вызов возвращает `True`. обратное включение ложно: в `superusers` есть элементы, которых нет в `users`, и второй вызов возвращает `False`.

`issuperset` возвращает `True`, если текущее множество является надмножеством другого, то есть содержит все его элементы.

@@FENCE_18@@

здесь отношение обратное предыдущему. `users` не содержит `superusers`, а `superusers` содержит `users`.

### frozen set

`frozen set` является неизменяемым вариантом множества. экземпляр создаётся функцией `frozenset`.

@@FENCE_19@@

в `frozenset` передаётся набор элементов: список, кортеж или другое множество. после создания нельзя ни добавить элемент, ни удалить уже имеющийся. из-за неизменяемости такой объект хешируем и может сам быть элементом множества или ключом словаря. набор операций поэтому ограничен.

- `len(s)`: возвращает длину множества
- `x in s`: возвращает `True`, если элемент `x` присутствует в множестве `s`
- `x not in s`: возвращает `True`, если элемент `x` отсутствует в множестве `s`
- `s.issubset(t)`: возвращает `True`, если `t` содержит множество `s`
- `s.issuperset(t)`: возвращает `True`, если `t` содержится в множестве `s`
- `s.union(t)`: возвращает объединение множеств `s` и `t`
- `s.intersection(t)`: возвращает пересечение множеств `s` и `t`
- `s.difference(t)`: возвращает разность множеств `s` и `t`
- `s.copy()`: возвращает копию множества `s`

методы, возвращающие набор, строят новый объект и не меняют исходный `frozenset`.
