обращение к элементам представления выполняется отложенно. объект представления строится сразу, а фильтрация и преобразование элементов выполняются в момент обращения к ним, при обходе. это позволяет составлять цепочки представлений без промежуточных контейнеров и без потери производительности на копирование последовательности на каждом шаге.

например, нужно взять 3 элемента, начиная с третьего. задача раскладывается на два этапа:

- пропустить 2 элемента:

```cpp
std::views::drop(2)
```

- взять 3 элемента:

```cpp
std::views::drop(2)
```

операция **|** объединяет эти операции и создаёт единое представление. каждый адаптер возвращает диапазон, который может стоять слева от следующего `|`. во фрагменте второго этапа повторён вызов `std::views::drop`, а в собранной программе ниже вторым звеном стоит взятие трёх элементов, `std::views::take(3)`: сначала отбрасываются два элемента, затем из оставшегося суффикса берутся три.

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges>



int main()

{

    std::vector<std::string> people { "Tom", "Bob", "Alice", "Sam", "Kate", "Alex"}; 



    // пропускаем 2 элемента и берем 3 элемента

    auto view = people | std::views::drop(2) | std::views::take(3);



    for(const auto& person: view)

    {

        std::cout << person << std::endl;

    }

}
```

вывод программы:

```bash


Alice

Sam

Kate
```

так же наращивается цепочка и из большего числа операций, в том числе из представлений других типов. например, данные фильтруются и преобразуются:

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges>



class Person

{

public:

    Person(std::string name, unsigned age): name{name}, age{age}{}

    std::string getName() const {return name;}

    unsigned getAge() const {return age;}

    void print() const  

    {

        std::cout << name <<"\t" << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

}; 

int main()

{

    std::vector<Person> people 

    {

        Person{"Tom", 38}, Person{"Kate", 31}, Person{"Bob", 42}, 

        Person{"Alice", 34}, Person{"Sam", 25}

    };

    // фильтрация Person с age > 33

    auto ageMoreThan33 = [](const Person& p){return p.getAge() > 33;};

    // функция преобразования из Person в string

    auto personToString = [](const Person& p){return p.getName();};

    

    auto view = people | 

        std::views::filter(ageMoreThan33) |

        std::views::transform(personToString);



    for(const auto& person: view)

    {

        std::cout << person << std::endl;

    }

}
```

сначала отбираются все объекты `Person`, у которых поле `age` больше 33, затем отобранные объекты преобразуются в строку: для каждого объекта `Person` возвращается значение поля `name`. порядок адаптеров существенен. `filter` сужает последовательность объектов, `transform` меняет тип элемента. предикат `ageMoreThan33` ожидает `Person`, поэтому он стоит до проекции в строку.

```cpp


auto view = people | 

        std::views::filter(ageMoreThan33) |

        std::views::transform(personToString);
```

вывод программы:

```bash


Tom

Bob

Alice
```
