ещё один распространённый компилятор приложений на c++ выходит из visual c++ компании microsoft. обычно он поставляется как часть среды visual studio, но ставить всю среду, чтобы пользоваться visual c++, не обязательно. здесь программы компилируются из командной строки. работа в visual studio разбирается отдельно, в одной из следующих лекций. visual c++ работает только под windows: инструмент привязан к объектному формату, заголовочным файлам и библиотекам этой системы.

для установки visual c++ нужен пакет **microsoft c++ build tools**. он загружается со страницы [https://visualstudio.microsoft.com/visual-cpp-build-tools/](https://visualstudio.microsoft.com/visual-cpp-build-tools/), кнопка загрузки называется "Download Build Tools":

![загрузка microsoft c++ build tools](/uploads/course-lectures/7b70a8b2f52411c7bd66770340465258f1575873.png)

загруженный файл запускается. в результате устанавливается и открывается visual studio installer:

![установка microsoft c++ build tools](/uploads/course-lectures/1ae9b8a59789777ef213ecbbf5906dde9f564b66.png)

в установщике выбирается пункт **Разработка классических приложений на C++**. этот набор приносит компилятор, компоновщик, заголовки windows sdk и стандартную библиотеку.

после установки в меню пуск, в пункте "Visual Studio", появляется ряд подпунктов:

![установка microsoft c++ build tools](/uploads/course-lectures/55603e58af65fc855ce2bd0e9a7feba1dd835526.png)

для командной сборки нужны прежде всего **Developer Command Prompt for VS 2022** и **x64 Native Tools Command Prompt for VS 2022**. годится любая из этих оболочек. дальше используется **x64 Native Tools Command Prompt for VS 2022**: она сразу настраивает окружение на 64-разрядную windows. при старте такая оболочка выполняет сценарий `vcvarsall.bat`, который прописывает в `PATH`, `INCLUDE` и `LIB` каталоги компилятора и библиотек. обычная командная строка windows этого окружения не содержит, и команда `cl` в ней не находится.

открывается **x64 Native Tools Command Prompt for VS 2022**, в неё вводится команда **cl**:

[ /link linkoption... ]` разделяет параметры компиляции, имена исходных файлов и параметры, которые передаются компоновщику после `/link`.

### создание первой программы

компилятор установлен, дальше набирается первая программа. для исходного текста годится любой редактор, в том числе visual studio code или встроенный блокнот.

на диске c создаётся каталог для исходных файлов. в нём создаётся текстовый файл и переименовывается в **hello.cpp**. исходный текст на c++ хранится в обычных текстовых файлах, у которых, как правило, расширение **cpp**.

![первая программа на с++](/uploads/course-lectures/9486138465d1bc14039dfd3a8d3ed484f143b7d7.png)

в примере файл **hello.cpp** лежит в каталоге C:\cpp.

в файле **hello.cpp** записывается минимальная программа, которая выводит строку на консоль:

```cpp


#include <iostream>        		// подключаем заголовочный файл iostream



int main()							// определяем функцию main

{									// начало функции

	std::cout << "Hello enoobis.ru!";	 // выводим строку на консоль

	return 0;						// выходим из функции

}									// конец функции
```

чтобы вывести строку, подключается интерфейс библиотеки. в начале файла стоит строка

```cpp
#include <iostream>
```

это директива препроцессора. она подключает заголовочный файл `iostream`, в котором объявлены стандартные потоки вывода. заголовок нужен для обращения к `std::cout`.

далее определяется функция **main**. она обязана присутствовать в программе на c++: выполнение приложения начинается с неё.

у функции main четыре составляющие:

- тип возвращаемого значения. здесь это тип `int`. функция должна вернуть целое число

- имя функции. функция называется `main`

- список параметров. после имени в скобках идёт список параметров. скобки пусты: эта форма `main` параметров не принимает

- тело функции. после списка параметров в фигурных скобках записываются действия функции

```cpp


{

	std::cout << "Hello enoobis.ru!";

	return 0;

}
```

в теле строка выводится на консоль. стандартный поток вывода **std::cout** связан со стандартным выводом процесса. оператор **<<** передаёт в этот поток строковый литерал "Hello enoobis.ru!".

выход из функции выполняет оператор **return**. результат имеет тип `int`, после `return` указано число 0. нуль является признаком успешного завершения программы.

после каждой инструкции в c++ ставится точка с запятой.

каждая строка листинга снабжена комментарием. всё, что записано после `//`, является комментарием. при компиляции комментарий не учитывается, в программу не входит и служит только пояснением к коду.

![язык программирования с++ в visual studio code](/uploads/course-lectures/47776cb1e4674fa5de3ea59cf54c7ac13aeb7f93.png)

файл компилируется из оболочки **x64 Native Tools Command Prompt for VS 2022**. команда **cd** переходит в каталог с исходным файлом:

```bash
cd C:\cpp
```

запускать нужно именно **x64 Native Tools Command Prompt for VS 2022** или **Developer Command Prompt for VS 2022**, а не обычную командную строку и не обычный терминал windows. вне подготовленного окружения компилятор `cl` и каталоги заголовков недоступны.

компилятору **cl** передаётся файл hello.cpp и параметр `/EHsc`:

```bash
cl /EHsc hello.cpp
```

параметр `/EHsc` включает синхронную модель исключений c++: компилятор строит таблицы раскрутки стека в предположении, что исключение порождает инструкция `throw`, а функции языка c исключений не бросают. без этой модели обработка исключений стандартной библиотеки для `cl` не определена, поэтому в курсе параметр указывается при каждой сборке.

в результате появляется исполняемый файл. по умолчанию он называется hello.exe: имя берётся из имени исходного файла. запуск печатает строку "Hello enoobis.ru!", как записано в программе. полный протокол сеанса:

```bash


**********************************************************************

** Visual Studio 2022 Developer Command Prompt v17.9.3

** Copyright (c) 2022 Microsoft Corporation

**********************************************************************

[vcvarsall.bat] Environment initialized for: 'x64'



C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools>cd c:\cpp



c:\cpp>cl /EHsc hello.cpp

Microsoft (R) C/C++ Optimizing Compiler Version 19.39.33522 for x64

Copyright (C) Microsoft Corporation.  All rights reserved.



hello.cpp

Microsoft (R) Incremental Linker Version 14.39.33522.0

Copyright (C) Microsoft Corporation.  All rights reserved.



/out:hello.exe

hello.obj



c:\cpp>hello

Hello enoobis.ru!

c:\cpp>
```

в протоколе видны два шага, которые драйвер `g++` обычно скрывает. компилятор переводит hello.cpp в объектный файл hello.obj, затем компоновщик (incremental linker) собирает из него hello.exe и сообщает это строкой `/out:hello.exe`. команда `hello` запускает полученный файл, и на консоли появляется текст программы.
