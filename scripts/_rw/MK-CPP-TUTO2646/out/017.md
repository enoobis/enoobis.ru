операции присваивания записывают значение в объект. у операции два операнда, причём левый операнд обязан быть модифицируемым именующим выражением, например переменной. такое выражение называется lvalue: оно обозначает объект, в который можно записать результат. константа и временное значение левым операндом присваивания не являются.

базовая операция `=` записывает значение правого операнда в объект, обозначенный левым операндом:

```cpp
int x {}; 
x = 2;
```

после этого оператора переменная `x`, левый операнд, хранит значение 2, правый операнд.

тип правого операнда может не совпадать с типом левого. тогда компилятор пытается преобразовать правый операнд к типу левого по правилам неявных преобразований. если преобразование недопустимо, программа не компилируется. при списковой инициализации сужающее преобразование запрещено строже, чем при присваивании уже созданному объекту.

присваивание правоассоциативно: группа присваиваний выполняется справа налево. поэтому допустима цепочка:

```cpp
int a {}, b{}, c{};	
a = b = c = 34;
```

сначала вычисляется выражение `c = 34`. значение правого операнда `34` записывается в левый операнд `c`, а результатом операции становится lvalue, ссылающееся на `c`. затем вычисляется `b = c`: значение правого операнда `c`, равное 34, записывается в `b`. в конце вычисляется `a = b`: значение `b` записывается в `a`. в итоге все три объекта содержат 34. результат присваивания можно использовать в более крупном выражении именно потому, что операция возвращает левый операнд, а не временную копию.

у присваивания низший приоритет среди обычных операций, поэтому оно выполняется после арифметики в том же выражении:

```cpp
int x {};
x = 3 + 5;
```

по таблице приоритетов сначала вычисляется `3 + 5`, и только затем сумма записывается в `x`.

остальные операции присваивания сочетают простую запись с другой операцией и имеют общую форму `op=`:

- `+=`: присваивание после сложения. левому операнду присваивается сумма левого и правого операндов: `A += B` эквивалентно `A = A + B`
- `-=`: присваивание после вычитания. левому операнду присваивается разность левого и правого операндов: `A -= B` эквивалентно `A = A - B`
- `*=`: присваивание после умножения. левому операнду присваивается произведение левого и правого операндов: `A *= B` эквивалентно `A = A * B`
- `/=`: присваивание после деления. левому операнду присваивается частное левого и правого операндов: `A /= B` эквивалентно `A = A / B`
- `%=`: присваивание после деления по модулю. левому операнду присваивается остаток от целочисленного деления левого операнда на правый: `A %= B` эквивалентно `A = A % B`
- `<<=`: присваивание после сдвига разрядов влево. левому операнду присваивается результат сдвига его битового представления влево на число разрядов, заданное правым операндом: `A <<= B` эквивалентно `A = A << B`
- `>>=`: присваивание после сдвига разрядов вправо. левому операнду присваивается результат сдвига его битового представления вправо на число разрядов, равное значению правого операнда: `A >>= B` эквивалентно `A = A >> B`
- `&=`: присваивание после поразрядной конъюнкции. левому операнду присваивается результат поразрядной конъюнкции его битового представления с битовым представлением правого операнда: `A &= B` эквивалентно `A = A & B`
- `|=`: присваивание после поразрядной дизъюнкции. левому операнду присваивается результат поразрядной дизъюнкции его битового представления с битовым представлением правого операнда: `A |= B` эквивалентно `A = A | B`
- `^=`: присваивание после исключающего или. левому операнду присваивается результат исключающего или его битового представления с битовым представлением правого операнда: `A ^= B` эквивалентно `A = A ^ B`

запись `A = A + B` и запись `A += B` совпадают по результату для встроенных арифметических типов, но в составной форме левый операнд вычисляется один раз. для выражения с побочным эффектом это уже другое поведение.

примеры составных присваиваний:

```c
#include <iostream>

int main()
{
    int a {5};
    a += 10;		// 15
    a -= 3;			// 12
    a *= 2;			// 24
    a /= 6;			// 4
    a <<= 4;	// 64
    a >>= 2;	// 16
    std::cout << "a = " << a << std::endl;
}
```
