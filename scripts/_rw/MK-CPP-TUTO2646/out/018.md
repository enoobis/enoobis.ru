условное выражение задаёт условие и имеет тип `bool`: значение `true`, если условие истинно, и `false`, если условие ложно. к условным выражениям относятся операции сравнения и логические операции. для встроенных арифметических типов сравнение выполняется по значению после обычных арифметических преобразований операндов к общему типу.

### операции сравнения

в c++ определены следующие операции сравнения:

- `==`, операция «равно». возвращает `true`, если оба операнда равны, и `false`, если они не равны:

```cpp


int a {10};

int b {4};

bool c {a == b};	// false

bool d {a == 10};	// true
```

- `>`, операция «больше». возвращает `true`, если первый операнд больше второго, иначе возвращает `false`:

```cpp


int a {10};

int b {4};

bool c {a > b};	// true
```

- `<`, операция «меньше». возвращает `true`, если первый операнд меньше второго, иначе возвращает `false`. семантика симметрична операции `>`.
- `>=`, операция «больше или равно». возвращает `true`, если первый операнд больше второго или равен ему, и `false`, если первый операнд меньше второго:

```cpp


bool c = 10 >= 4;	// true

bool d = 10 >= 14;	// false
```

- `<=`, операция «меньше или равно». возвращает `true`, если первый операнд меньше второго или равен ему, и `false`, если первый операнд больше.
- `!=`, операция «не равно». возвращает `true`, если первый операнд не равен второму, и `false`, если оба операнда равны:

```cpp


bool c {10 != 4};	// true

bool d = 4 != 4;	// false
```

при выводе значения типа `bool` на консоль по умолчанию печатается 1, если значение `true`, и 0, если значение `false`. поток выводит `bool` как целое, пока не включён другой формат:

```cpp


#include <iostream> 



int main()

{

    int a {8};

    int b {11};

    bool c {a == b};    // false

    bool d {a != b};    // true

    std::cout << "c = " << c << std::endl;  // c = 0

    std::cout << "d = " << d << std::endl;  // d = 1

}
```

чтобы вывести текст `true` или `false`, перед значением указывают манипулятор `std::boolalpha`:

```cpp


#include <iostream> 



int main()

{

    int a {8};

    int b {11};

    bool c {a == b};    // false

    bool d {a != b};    // true

    std::cout << "c = " << std::boolalpha << c << std::endl;  // c = false

    std::cout << "d = " << std::boolalpha << d << std::endl;  // d = true

}
```

манипулятор устанавливает флаг форматирования потока. флаг сохраняется у этого потока и действует на последующие выводы `bool`, пока его не сменят на `std::noboolalpha`.

операции сравнения обычно входят в условные конструкции вида `if` и `else`, которые разбираются далее. сами по себе они не управляют переходом: они только вычисляют значение типа `bool`.

### логические операции

логические операции соединяют несколько условий. к ним относятся:

- `!`, операция отрицания. унарная операция: возвращает `true`, если операнд равен `false`, и возвращает `false`, если операнд равен `true`. операнд приводится к `bool`.

```cpp


bool a {true};

bool b {!a};	// false

bool c {!b};	// true
```

- `&&`, конъюнкция, логическое умножение. возвращает `true`, если оба операнда не равны `false`. возвращает `false`, если хотя бы один операнд равен `false`.

```cpp


bool a {true};

bool b {false};

bool c {a && b};	// false

bool d {a && true};	// true
```

- `||`, дизъюнкция, логическое сложение. возвращает `true`, если хотя бы один операнд равен `true`. возвращает `false`, если оба операнда равны `false`.

```cpp


bool a {true};

bool b {false};

bool c {a || b};		// true

bool d {b || false};	// false
```

- `^`, исключающее или. возвращает `true`, если операнды имеют разные значения, и `false`, если оба операнда равны.

```cpp


bool a {true};

bool b {false};

bool c {a ^ b};		     // true

bool d {b ^ false};	    // false

bool d {a ^ true};	    // false
```

для типа `bool` операция `^` выполняется как поразрядное исключающее или после целочисленного продвижения: `true` становится 1, `false` становится 0. оба операнда вычисляются всегда. сокращённого вычисления у `^` нет.

логическими операциями объединяют операции сравнения и другие логические операции:

```cpp


#include <iostream> 



int main()

{

    int a {5};

    int b {8};

    bool result1 = a ==5 && b > 8;  // если и a ==5, и b > 8

    bool result2 = a ==5 || b > 8;  // если или a ==5, или b > 8 (или оба варианты истины)

    bool result3 = a ==5 ^ b > 8;  // если оба операнда возвращают разные значения



    std::cout << "(a ==5 && b > 8) - " << std::boolalpha << result1 << std::endl;

    std::cout << "(a ==5 || b > 8) - " << std::boolalpha << result2 << std::endl;

    std::cout << "(a ==5 ^ b > 8) - " << std::boolalpha << result3 << std::endl;

}
```

приоритет операций сравнения выше приоритета логических операций. в выражении `a == 5 && b > 8` сначала вычисляются сравнения `a == 5` и `b > 8`, и только затем логическое умножение. скобки здесь не обязательны, но делают структуру условия явной.

первое условие `a == 5 && b > 8` истинно только когда истинны оба сравнения. условие `a == 5 || b > 8` истинно, когда хотя бы одно сравнение возвращает `true`. условие с `^` истинно, когда два сравнения дают разные значения. консольный вывод программы:

```bash


(a ==5 && b > 8) - false

(a ==5 || b > 8) - true

(a ==5 ^ b > 8) - true
```

операторы `&&` и `||` вычисляются по сокращённой схеме (short-circuit evaluation). если первого операнда достаточно, чтобы определить результат всей операции, второй операнд не вычисляется. для конъюнкции:

```cpp


int a {5};

int b {8};

bool result1 = a ==6 && b ==8;
```

первый операнд, выражение `a == 6`, возвращает `false`. для `&&` второй операнд уже не меняет результат: операция в любом случае даёт `false`, и выражение `b == 8` не вычисляется. на этом основаны идиомы вида `p && p->next`: обращение к объекту справа выполняется только если указатель слева не нулевой.

та же схема у дизъюнкции:

```cpp


int a {5};

int b {8};

bool result1 = a ==5 || b ==0;
```

первый операнд, выражение `a == 5`, возвращает `true`. для `||` результат уже равен `true`, и второй операнд не вычисляется. побочный эффект во втором операнде `&&` или `||` поэтому может не произойти, и порядок операндов входит в семантику выражения.
