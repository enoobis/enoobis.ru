### инструкции

программа на c++ состоит из инструкций. каждая инструкция (statement) выполняет некоторое действие. в конце инструкции ставится точка с запятой (`;`). этот знак сообщает компилятору, что инструкция закончена. пример:

```c
std::cout << "Hello World!";
```

строка выводит на консоль текст "Hello world!", является инструкцией и поэтому заканчивается точкой с запятой. инструкция такого вида называется инструкцией-выражением: вычисляется выражение, его результат отбрасывается, а точка с запятой завершает конструкцию.

набор инструкций может составлять блок. блок заключается в фигурные скобки, инструкции стоят между открывающей и закрывающей скобкой:

```c


{

	std::cout << "Hello World!";

	std::cout << "Bye World!";

}
```

в блоке две инструкции, каждая выводит на консоль свою строку. блок задаёт область видимости: имена, объявленные внутри, снаружи не видны. с точки зрения грамматики блок сам является инструкцией и точкой с запятой не закрывается.

### функция main

в программе на c++ должна быть по меньшей мере одна функция, функция **main()**. выполнение приложения начинается с неё. имя **main** фиксировано и во всех программах на c++ одно и то же. среда выполнения вызывает эту функцию после инициализации объектов со статическим временем хранения.

функция тоже является блоком кода, поэтому её тело обрамляется фигурными скобками, а между скобками записывается набор инструкций.

в первой программе функция main выглядела так:

```c


#include <iostream>               // подключаем заголовочный файл iostream

 

int main()                          // определяем функцию main

{                                   // начало функции

    std::cout << "Hello World!";   // выводим строку на консоль

    return 0;                       // выходим из функции

}                                   // конец функции
```

определение начинается с возвращаемого типа. функция main должна вернуть число, поэтому определение открывается ключевым словом **int**. возвращённое значение становится кодом завершения процесса.

далее стоит имя функции, **main**. после имени в скобках идёт список параметров. в этом определении параметров нет, скобки пусты. есть и другие формы `main`, которые параметры принимают. часто встречается такое определение:

```cpp


int main (int argc, char *argv[]) 

{

	

}
```

здесь `argc` имеет тип `int` и хранит число аргументов командной строки, а `argv` является массивом указателей на строки этих аргументов. первый элемент, при ненулевом `argc`, указывает на имя, под которым программу запустили. пустое тело в листинге только показывает форму заголовка.

после списка параметров идёт блок, и уже в нём инструкциями записаны действия функции main.

в конце функции стоит инструкция **return**:

```cpp
return 0;
```

инструкция завершает выполнение функции и передаёт управление туда, откуда функцию вызвали. для `main` управление возвращается операционной системе.

число 0 после оператора `return` сообщает операционной системе, что функция завершилась успешно, без ошибки. ненулевой код принято читать как признак аварийного завершения, конкретные ненулевые значения программа выбирает сама.

в функции main инструкцию `return 0;` можно опустить:

```cpp


#include <iostream>

 

int main()

{

    std::cout << "Hello enoobis.ru!";

}
```

если управление доходит до закрывающей скобки `main`, это равносильно `return 0;`. правило относится только к `main`. у любой другой функции с результатом типа `int` выход без `return` оставляет результат неопределённым.

### директивы препроцессора

в примере выше на консоль выводится строка. чтобы пользоваться выводом, в начале исходного файла подключается библиотечный заголовок iostream директивой **include**.

```cpp
#include <iostream>               // подключаем библиотеку iostream
```

директива **include** является директивой препроцессора. каждая такая директива занимает одну строку. обычная инструкция c++ заканчивается точкой с запятой **;**, а директива препроцессора заканчивается переводом строки. директива начинается со знака `#`. директива `include` указывает, какой файл подставить в программу в этом месте. при угловых скобках, как в `#include <iostream>`, файл ищется среди стандартных заголовков. подстановка текстовая и выполняется до семантического анализа: компилятор уже видит текст заголовка как часть единицы трансляции.

### комментарии

исходный текст может содержать комментарии. комментарий поясняет смысл программы и отдельных её частей. при компиляции комментарии отбрасываются и не влияют ни на поведение приложения, ни на его размер: в объектный код они не попадают. на ранней фазе трансляции комментарий заменяется пробелом, поэтому он может разделять лексемы, но сам лексемой не является.

в c++ два вида комментариев: однострочный и многострочный. однострочный комментарий занимает одну строку и начинается с `//`:

```cpp


#include <iostream>               // подключаем библиотеку iostream

 

int main()                          // определяем функцию main

{                                   // начало функции

    std::cout << "Hello World!";   // выводим строку на консоль

    return 0;                       // выходим из функции

}                                   // конец функции
```

многострочный комментарий заключается между `/*` и `*/`. он может занимать несколько строк. пример:

```c


#include <iostream>

/*

	Определение функции Main

	Выводит на консоль строку Hello World!

*/

int main()

{

	std::cout << "Hello World!"; // вывод строки на консоль

	return 0;

}
```

многострочный комментарий не вкладывается сам в себя: первая пара `*/` его закрывает. однострочный комментарий заканчивается концом строки.

### компиляция

построение исполняемого файла из исходного текста на c++ в общем случае проходит три этапа:

- препроцессор обрабатывает все директивы препроцессора (например, директиву `#include`)

- компилятор обрабатывает каждый файл с исходным текстом и создаёт из него объектный файл с машинным кодом. если код разнесён по нескольким исходным файлам, для каждого создаётся свой объектный файл

- компоновщик (линкер, линковщик) объединяет все объектные файлы в одну программу. этот шаг называется компоновкой, или линковкой

если исходный текст лежит в трёх файлах **.cpp**, цепочка выглядит так: три независимые трансляции дают три объектных файла, а компоновщик разрешает внешние ссылки между ними и присоединяет стандартную библиотеку.
