### установка компилятора

первая программа на c++ в этом разделе собирается компилятором **g++**. это одна из самых распространённых реализаций c++, она доступна на разных платформах и входит в набор компиляторов gcc. подробности о g++ приведены на сайте проекта [https://gcc.gnu.org/](https://gcc.gnu.org/). драйвер `g++` отличается от драйвера `gcc` тем, что выбирает режим языка c++ и компонует программу со стандартной библиотекой c++.

набор gcc распространяется в разных сборках. для windows одной из распространённых является пакет средств разработки некоммерческого проекта **msys2**. для msys2 нужна 64-битная windows 7 или более новая система: vista, xp и более ранние версии не подходят.

программа установки msys2 загружается с официального сайта [MSYS2](https://www.msys2.org/):

![установка msys для разработки под с++](/uploads/course-lectures/9005c6d416f1ef3b101c40f18c6736f28a2c0730.png)

после загрузки запускается программа установки:

![установка пакета mingw-w64 и msys2 на windows](/uploads/course-lectures/5ba2a9584f6845a83f2ef1b82211ef1ac5df6c20.png)

на первом шаге предлагается каталог установки. по умолчанию это каталог C:\msys64:

![установка компиляторов c++ msys2 на windows](/uploads/course-lectures/ce101976c7926b99e82229f7220da59cd4b35d4c.png)

каталог можно оставить по умолчанию или изменить. на следующем шаге задаются параметры ярлыка в меню пуск, затем выполняется установка. по завершении появляется финальное окно, в нём нажимается кнопка "Завершить".

![установка компиляторов msys2 на windows](/uploads/course-lectures/89abbc2d1dce1f7aded53a86a77af598e3a2e897.png)

после установки запускается консольное приложение MSYS2.exe. если оно не запустилось, в каталоге установки C:/msys64 нужно найти файл **usrt_64.exe**:

![компиляторы msys2.exe на windows](/uploads/course-lectures/24ebe23849387f1e755f1283142e90b2885d1b94.png)

дальше устанавливается сам набор компиляторов gcc. в окне этой оболочки вводится команда:

```consoletext
pacman -S mingw-w64-ucrt-x86_64-gcc
```

пакетами msys2 управляет пакетный менеджер pacman, перенесённый из arch linux. команда предписывает pacman установить пакет `mingw-w64-ucrt-x86_64-gcc`: имя пакета стоит после параметра `-S`. пакет содержит набор компиляторов gcc. префикс `ucrt` означает компоновку с universal c runtime, современной реализацией стандартной библиотеки c от microsoft, а `x86_64` задаёт 64-разрядную целевую архитектуру. mingw-w64 является портом gcc на windows.

![установка компиляторов msys2 на windows](/uploads/course-lectures/238c9885e85ef5249d6a21a1f74fea80dee0339e.png)

после завершения установки можно переходить к программам на c++. в каталоге установки, в папке **C:\msys64\ucrt64\bin**, лежат файлы компиляторов:

![компилятор g++ на windows](/uploads/course-lectures/b6acab3972e48e3bb725230d48715d125e3be676.png)

файл **g++.exe** и есть компилятор языка c++. рядом обычно находится **gcc.exe**: это драйвер для языка c из того же набора.

чтобы не указывать полный путь к компилятору при каждом запуске, каталог с ним добавляют в переменные среды. оболочка ищет исполняемые файлы в каталогах из переменной `PATH`. в окне поиска windows вводится строка "изменение переменных среды текущего пользователя":

![изменение переменных среды текущего пользователя в windows](/uploads/course-lectures/d5c71d960f3b79a66ccecfa14f5f303468161a02.png)

![определение пути к компилятору g++ в переменных среды на windows](/uploads/course-lectures/afb5926937a1ca422c786b6aa473c23dc86b0b4b.png)

### создание первой программы

компилятор установлен, дальше набирается первая программа. для исходного текста годится любой редактор, в том числе visual studio code или встроенный блокнот.

на диске c создаётся каталог для исходных файлов. в нём создаётся текстовый файл и переименовывается в **hello.cpp**. исходный текст на c++ хранится в обычных текстовых файлах, у которых, как правило, расширение **cpp**. по расширению драйвер `g++` выбирает язык c++.

![первая программа на с++](/uploads/course-lectures/9486138465d1bc14039dfd3a8d3ed484f143b7d7.png)

в примере файл **hello.cpp** лежит в каталоге C:\cpp.

в файле **hello.cpp** записывается минимальная программа, которая выводит строку на консоль:

```cpp


#include <iostream>        		// подключаем заголовочный файл iostream



int main()							// определяем функцию main

{									// начало функции

	std::cout << "Hello enoobis.ru!";	 // выводим строку на консоль

	return 0;						// выходим из функции

}									// конец функции
```

чтобы вывести строку, к программе подключается нужный интерфейс библиотеки. в начале файла стоит строка

```cpp
#include <iostream>
```

это директива препроцессора. препроцессор обрабатывает её до собственно компиляции и подставляет в это место содержимое заголовочного файла `iostream`. заголовок объявляет стандартные потоки ввода-вывода в пространстве имён `std`. без него имя `std::cout` в программе не объявлено.

далее определяется функция **main**. она обязана присутствовать в программе на c++: после инициализации объектов со статическим временем хранения среда выполнения передаёт управление именно в `main`.

у функции main четыре составляющие:

- тип возвращаемого значения. здесь это тип `int`. функция должна вернуть целое число, и это число становится кодом завершения процесса для операционной системы

- имя функции. функция называется `main`

- список параметров. после имени в скобках перечисляются параметры. скобки пусты: эта форма `main` параметров не принимает

- тело функции. после списка параметров в фигурных скобках записываются действия, которые функция выполняет

```cpp


{

	std::cout << "Hello enoobis.ru!";

	return 0;

}
```

в теле строка выводится на консоль. консоль представлена стандартным потоком вывода **std::cout**, объектом класса потока, связанным со стандартным выводом процесса. оператор **<<** передаёт в этот поток строковый литерал "Hello enoobis.ru!". для `ostream` оператор перегружен и выполняет форматированную вставку символов в поток. для целых тот же знак означает побитовый сдвиг.

выход из функции выполняется оператором **return**. тип результата `int`, поэтому после `return` указано число 0. нуль служит признаком успешного завершения: операционная система получает код выхода 0.

после каждой инструкции в c++ ставится точка с запятой. точка с запятой завершает инструкцию-выражение, и по ней транслятор проводит границу между инструкциями.

каждая строка в листинге снабжена комментарием. текст после `//` является комментарием. на фазе трансляции комментарий отбрасывается, в объектный код не входит и на размер программы не влияет. комментарий описывает, что делает соответствующая строка.

![язык программирования с++ в visual studio code](/uploads/course-lectures/47776cb1e4674fa5de3ea59cf54c7ac13aeb7f93.png)

файл компилируется из командной строки windows. команда `cd` переходит в каталог с исходным файлом:

```bash
cd C:\cpp
```

компилятору передаётся имя файла hello.cpp:

```bash
g++ hello.cpp -o hello
```

необязательный параметр `-o hello` задаёт имя результата: hello.exe. если параметр опустить, файл получит имя по умолчанию, a.exe. драйвер при этом проводит препроцессирование, компиляцию в объектный код, ассемблирование и компоновку со стандартной библиотекой.

после команды появляется исполняемый файл. в windows он по умолчанию называется hello.exe. запуск этого файла выводит на консоль строку "Hello enoobis.ru!", как и записано в программе.

![запуск компилятора g++ на windows](/uploads/course-lectures/9fc393f456dfa0c58bbe38ff641122e6439a3ae4.png)

если вместо командной строки cmd открыта оболочка powershell, файл запускается командой "./hello". powershell не ищет исполняемый файл в текущем каталоге без явного префикса `./`.

компиляцию и запуск можно записать одной строкой:

```bash
g++ hello.cpp -o hello.exe & hello.exe
```

в cmd символ `&` разделяет две последовательные команды: сначала сборка, затем запуск hello.exe.
