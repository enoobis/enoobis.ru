тип `shared_ptr<T>` создаёт указатели на объекты, у которых владельцев может быть несколько. допускается много объектов `shared_ptr`, хранящих один и тот же адрес. владение общее: объект удаляется, когда последний владелец его отпускает.

для этого ведётся подсчёт ссылок (reference counting). счётчик лежит в управляющем блоке, отдельном от самого объекта, и меняется атомарно, поэтому копии `shared_ptr` можно передавать между потоками. сам динамический объект при этом никакой синхронизации не получает. каждый раз, когда создаётся новый `shared_ptr` на уже учтённый адрес, счётчик владельцев этого адреса увеличивается. когда `shared_ptr` уничтожается или ему присваивают другой адрес, счётчик уменьшается на единицу. когда объектов `shared_ptr` с этим адресом не остаётся, счётчик обнуляется, и объект удаляется.

`std::make_shared` обычно размещает объект и управляющий блок одним выделением. отдельная пара «объект и блок» потребовала бы двух обращений к аллокатору. у `unique_ptr` управляющего блока нет: владелец всегда один, и хранить счётчик незачем.

без явной инициализации `shared_ptr` получает значение `nullptr`:

```cpp
std::shared_ptr<int> ptr;   // ptr = nullptr
```

конкретное значение задают функцией `std::make_shared`:

```cpp
std::shared_ptr<int> ptr {std::make_shared<int>(22)};
```

через `shared_ptr`, как и через обычный указатель, динамический объект читают и изменяют. разыменование требует непустого указателя:

```cpp


#include <iostream>

#include <memory>



int main()

{

    std::shared_ptr<int> ptr {std::make_shared<int>(22)};



    std::cout << "address: " << ptr << std::endl;       // address: 0x1e004671260

    std::cout << "old value: " << *ptr << std::endl;    // old value: 22

    *ptr = 33;    // меняем значение 

    std::cout << "new value: " << *ptr << std::endl;    // new value: 33

}
```

печать самого `shared_ptr` оператором `<<` выводит хранимый адрес. этот оператор есть с c++11, в отличие от `unique_ptr`, у которого он появился в c++20.

`shared_ptr` инициализируют другим `shared_ptr`. оба тогда хранят один адрес, а копирование увеличивает счётчик:

```cpp


#include <iostream>

#include <memory>



int main()

{

    std::shared_ptr<int> ptr1 {std::make_shared<int>(22)};

    std::shared_ptr<int> ptr2 {ptr1};   // ptr2 ссылается на тот же объект, что и ptr1



    std::cout << "ptr1 address: " << ptr1 << std::endl;

    std::cout << "ptr1 value: " << *ptr1 << std::endl; 

    std::cout << "ptr2 address: " << ptr2 << std::endl;

    std::cout << "ptr2 value: " << *ptr2 << std::endl;

}
```

пример консольного вывода:

```bash


ptr1 address: 0x15fbbf81020

ptr1 value: 22

ptr2 address: 0x15fbbf81020

ptr2 value: 22
```

адреса совпадают: `ptr2` построен копированием `ptr1` и присоединился к тому же управляющему блоку. уничтожение одного из них уменьшит счётчик до единицы и объект не удалит. объект будет удалён, когда исчезнет и второй владелец.

начиная со стандарта c++20 `shared_ptr` указывает на массив. до c++20 специализация на массив не имела оператора `[]`, а удалитель по умолчанию вызывал `delete`, что для памяти от `new[]` неверно. в c++20 добавлены и `make_shared` для массива, и оператор индексации, и удаление через `delete[]`.

указатель на массив:

```cpp


unsigned n{5};   // размер массива

auto pnumbers { std::make_shared<int[]>(n) };    // массив из n элементов, равных 0
```

`pnumbers` указывает на массив из 5 элементов. все элементы уже инициализированы значением по умолчанию. для встроенных типов это 0.

к элементу обращаются квадратными скобками:

```cpp


#include <iostream>

#include <memory>



int main()

{

    unsigned n{5};   // размер массива

    auto pnumbers { std::make_shared<int[]>(n) };    // массив {0, 0, 0, 0, 0}



    std::cout << "pnumbers[1] initial value: " << pnumbers[1] << std::endl; // pnumbers[1] initial value: 0

    pnumbers[1] = 121;  // изменяем значение

    std::cout << "pnumbers[1] new value: " << pnumbers[1] << std::endl;     // pnumbers[1] new value: 121

}
```

массив обходят циклом:

```cpp


#include <iostream>

#include <memory>



int main()

{

    unsigned n{5};   // размер массива

    auto pnumbers { std::make_shared<int[]>(n) };    // массив из n элементов



    // изменим и выведем все элементы на консоль

    for (unsigned i {}; i < n; i++)

    {

        pnumbers[i] = i+1;

        std::cout << "pnumbers[" << i <<"] = " << pnumbers[i] << std::endl;

    }

}
```

консольный вывод:

```bash


pnumbers[0] = 1

pnumbers[1] = 2

pnumbers[2] = 3

pnumbers[3] = 4

pnumbers[4] = 5
```
