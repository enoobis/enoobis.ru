стандартная библиотека c++ предоставляет функции классификации и смены регистра символов. они объявлены в `<cctype>`, принимают аргумент типа `int` и описывают символ в текущей локали c. по умолчанию локаль есть `"C"`, и классы символов совпадают с набором ascii. аргумент должен быть представим как `unsigned char` либо равен `EOF`. передача отрицательного `char` при знаковом `char` дает неопределенное поведение, поэтому перед вызовом значение приводят к `unsigned char`.

- `isupper(c)` : проверяет, является ли `c` заглавной буквой. в локали `"C"` это буквы от `A` до `Z`

- `islower(c)` : проверяет, является ли `c` буквой нижнего регистра. в локали `"C"` это буквы от `a` до `z`

- `isalpha(c)` : проверяет, является ли `c` алфавитным символом

- `isdigit(c)` : проверяет, является ли `c` цифрой от `0` до `9`. эта проверка не зависит от локали

- `isxdigit(c)` : проверяет, является ли `c` шестнадцатеричной цифрой, от `0` до `9`, от `a` до `f` или от `A` до `F`

- `isalnum(c)` : проверяет, является ли `c` алфавитно-цифровым символом. условие совпадает с `isalpha(c) || isdigit(c)`

- `isspace(c)` : проверяет, является ли `c` пробелом (` `), переводом строки (`\n`), возвратом каретки (`\r`), переводом страницы (`\f`), горизонтальной (`\t`) или вертикальной (`\v`) табуляцией

- `isblank(c)` : проверяет, является ли `c` пробелом (` `) или символом горизонтальной табуляции (`\t`)

- `ispunct(c)` : проверяет, является ли `c` символом пунктуации. в локали `"C"` это графический символ, не буква и не цифра. в лекции к таким символам отнесены: `_ { } [ ] # ( ) % : ; ? * + - / ^ & | ~ ! = "`

- `isprint(c)` : проверяет, является ли `c` печатным символом. в этот класс входят прописные и строчные буквы, цифры, знаки пунктуации и пробел

- `iscntrl(c)` : проверяет, является ли `c` управляющим непечатным символом

- `isgraph(c)` : проверяет, имеет ли `c` графическое представление. в локали `"C"` это печатные символы без пробела

- `tolower(c)` : переводит символ `c` в нижний регистр. если соответствия нет, возвращается сам символ. тип результата есть `int`

- `toupper(c)` : переводит символ `c` в верхний регистр. если соответствия нет, возвращается сам символ. тип результата есть `int`

проверка регистра одного символа:

```cpp


#include <iostream> 



int main()

{

    unsigned char letter {'a'};

    if (std::isupper(letter))

        std::cout << "Uppercase letter" << std::endl;

    else if (std::islower(letter))

        std::cout << "Lowercase letter" << std::endl;

    else    // если не буквенный символ

        std::cout << "Undefined" << std::endl;

}
```

те же функции постоянно используются при разборе строк. простейшая задача: из текста `Phone number: +1(234)456-78-90` оставить только цифры телефонного номера.

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Phone number: +1(234)456-78-90"};

    std::string phone;  // строка для хранения номера

    for(unsigned i{}; i < text.length(); i++)

    {

        // проверяем, является ли символ цифрой

        if(std::isdigit(text[i]))

        {

            // добавляем в строку номера телефона

            phone += text[i];

        }

    }

    std::cout << phone << std::endl;    // 12344567890

}
```

цикл проходит по всем символам `text`. если `std::isdigit` признает символ цифрой, символ дописывается в строку `phone`. скобки, знак `+` и дефисы в номер не попадают.

другая задача состоит в сравнении двух строк без учета регистра. оператор `==` сравнивает коды символов и учитывает регистр. строки, у которых хотя бы одна пара символов различается регистром, не равны. лекция показывает такой отрицательный результат:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string word1 {"HELLO"};

    word1 = "hello";

    std::string word2 {"hello"};

    if(word1 == word2)

    {

        std::cout << "strings are equal" << std::endl;

    }

    else

    {

        std::cout << "strings are not equal" << std::endl;

    }

}
```

результат, приведенный для этого сравнения:

```bash
strings are not equal
```

в листинге `word1` сначала получает `HELLO`, затем выполняется присваивание `word1 = "hello"`. после присваивания оба операнда равны `hello`, и условие `word1 == word2` истинно. ветка с текстом `strings are not equal` при таком присваивании не выполняется. семантика `operator==` от этого не меняется: равны строки одинаковой длины с попарно равными кодами символов. неравенство `HELLO` и `hello` наблюдается, если сравнить исходное значение `word1` до перезаписи.

сравнение без учета регистра переводит символы в один регистр и сравнивает уже коды результата:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string word1 {"HELLO"};

    std::string word2 {"hello"};

    bool is_equal{true};    // равны ли строки

    if(word1.length() != word2.length())

    {

        is_equal = false;

    }

    else

    {

        // сравниваем все символы

        for(unsigned i{}; i < word1.length(); i++)

        {

            // переводим символы в нижний регистр и сравниваем

            if(std::tolower(word1[i]) != std::tolower(word2[i]))

            {

                // если символы не равны, сбрасываем флаг равенства

                is_equal = false;

                break;      // выходим из цикла

            }

        }

    }   

    if(is_equal)

    {

        std::cout << word1 << " and " << word2 << " are equal" << std::endl;

    }

    else

    {

        std::cout << word1 << " and " << word2 << " are not equal" << std::endl;

    }

}
```

сначала сравниваются длины. при разных длинах строки не равны, и посимвольный проход не нужен. при равных длинах цикл применяет `std::tolower` к каждой паре символов. в локали `"C"` функция меняет только `A`...`Z`. если хотя бы одна пара приведенных символов различается, флаг `is_equal` сбрасывается в `false`, и `break` завершает цикл: дальнейшие позиции результат уже не изменят.

результат программы:

```bash
HELLO and hello are equal
```
