алгоритмы стандартной библиотеки c++ являются обобщёнными функциями. они объявлены в заголовочном файле `<algorithm>` и применяются к диапазонам элементов: контейнеру или массиву. ниже разобраны наиболее употребительные алгоритмы поиска экстремума.

функции `std::min_element` и `std::max_element` возвращают соответственно минимальный и максимальный элемент диапазона. коллекцией может служить любой контейнер или массив, для которого определены итераторы. диапазон задаётся парой итераторов. начальный итератор указывает на первый элемент, конечный указывает на позицию за последним элементом. принятая в библиотеке семантика полуинтервала `[first, last)` означает, что `last` не разыменовывается, а число элементов равно разности итераторов, если они допускают вычитание.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
 
int main()
{
    std::vector<int> numbers { 1, 2, 3, 4, 5, 6, 7, 8};
    std::cout << "Min: " << *std::min_element(begin(numbers), end(numbers)) << std::endl;
    std::cout << "Max: " << *std::max_element(begin(numbers), end(numbers)) << std::endl;
}
```

минимальный и максимальный элементы ищутся на всём векторе `numbers`: от итератора `begin(numbers)` до итератора `end(numbers)`. обе функции возвращают итератор на элемент. само значение получают разыменованием: `*std::min_element(...)`. вывод программы:

```bash
Min: 1
Max: 8
```

диапазон поиска не обязан покрывать контейнер целиком. он может быть собственным поддиапазоном, ограниченным произвольной парой итераторов, и тогда минимум и максимум вычисляются только на нём. например, отрезок от второго элемента до предпоследнего задаётся начальным итератором, сдвинутым на одну позицию вперёд, и конечным итератором, сдвинутым на одну позицию назад от `end`: полуинтервал тогда включает предпоследний элемент и исключает последний. в вызове ниже границами снова служат начало и конец контейнера:

```cpp
std::cout << "Min: " << *std::min_element(begin(numbers), end(numbers)) << std::endl;
std::cout << "Max: " << *std::max_element(begin(numbers), end(numbers)) << std::endl;
```

минимум и максимум одновременно возвращает `std::minmax_element()`. она тоже принимает итераторы границ поиска. результат имеет тип `std::pair`: первый член пары является итератором на минимальный элемент, второй на максимальный. в c++17 структурированная привязка `const auto [min, max]` разворачивает эту пару в два имени, после чего значения по-прежнему получают разыменованием.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
 
int main()
{
    std::vector<int> numbers { 1, 2, 3, 4, 5, 6, 7, 8};
    const auto [min, max] = std::minmax_element(begin(numbers), end(numbers));
    std::cout << "Min: " <<  *min << std::endl;
    std::cout << "Max: " << *max << std::endl;
}
```
