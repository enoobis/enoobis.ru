одним из самых распространённых компиляторов c++ в macos является **clang**. чтобы работать с clang в macos, нужна утилита **xcode command line tools**. самый прямой способ получить её состоит в том, чтобы поставить xcode: вместе с ним устанавливается и xcode command line tools. в этот набор входят драйвер `clang++`, заголовки и библиотеки sdk.

в файловой системе выбирается каталог для исходных текстов на c++, и в нём создаётся файл **hello.cpp** с таким кодом:

```cpp
#include <iostream>        		// подключаем заголовочный файл iostream

int main()							// определяем функцию main
{									// начало функции
	std::cout << "Hello enoobis.ru!";	// выводим строку на консоль
	return 0;						// выходим из функции
}									// конец функции
```

это тот же текст, что и в разделах про windows и linux. на уровне исходного кода программы на c++ в значительной степени переносимы.

чтобы вывести строку, подключается интерфейс библиотеки. в начале файла стоит строка

```cpp
#include <iostream>
```

это директива препроцессора. она подключает заголовочный файл `iostream`, в котором объявлены стандартные потоки. заголовок нужен для вывода строки на консоль.

далее определяется функция **main**. она обязана присутствовать в программе на c++: выполнение приложения начинается с неё.

у функции main четыре составляющие:

- тип возвращаемого значения. здесь это тип `int`. функция должна вернуть целое число

- имя функции. функция называется `main`

- список параметров. после имени в скобках идёт список параметров. скобки пусты: эта форма `main` параметров не принимает

- тело функции. после списка параметров в фигурных скобках записываются действия функции

```cpp
{
	std::cout << "Hello enoobis.ru!\n";
	return 0;
}
```

в теле строка выводится на консоль. стандартный поток вывода **std::cout** связан со стандартным выводом процесса. оператор **<<** передаёт в этот поток строку символов. в листинге тела строка заканчивается последовательностью `\n`, которая переводит курсор на следующую строку.

выход из функции выполняет оператор **return**. результат имеет тип `int`, после `return` указано число 0. нуль является признаком успешного завершения программы.

после каждой инструкции в c++ ставится точка с запятой.

компиляция выполняется такой командой:

```consoletext
clang++ hello.cpp -o hello
```

сначала указан компилятор, **clang++**. через пробел стоит имя исходного файла, который компилятор должен перевести в программу, здесь это **hello.cpp**. драйвер `clang++` выбирает язык c++ и подключает стандартную библиотеку c++.

помимо имени исходного файла передаётся параметр `-o hello`. он задаёт имя выходного файла, hello. если параметр не передать, создаётся файл с именем по умолчанию, a.out.

после команды в каталоге с hello.cpp появляется файл **hello**. он запускается так:

```consoletext
./hello
```

префикс `./` указывает оболочке взять файл из текущего каталога: каталог запуска в `PATH` macos по умолчанию не входит. на консоль выводится строка "Hello enoobis.ru!".
