### математические константы

начиная со стандарта c++20 стандартная библиотека в заголовочном файле `numbers` задаёт набор встроенных математических констант. некоторые наиболее употребительные:

- `std::numbers::e`: число 2.71828, основание натурального логарифма

- `std::numbers::pi`: число π, `3.14159...`

- `std::numbers::sqrt2`: квадратный корень числа 2, `1.41421...`

- `std::numbers::phi`: золотое сечение, число фидия, φ, `1.618...`

все эти имена имеют тип `double`. в том же заголовке рядом определены шаблоны переменных с суффиксом `_v`, параметризованные типом с плавающей точкой. имя без суффикса совпадает со специализацией такого шаблона для `double`.

### математические функции

заголовочный файл `cmath` стандартной библиотеки c++ объявляет набор математических функций для программ. перегрузки для типов с плавающей точкой находятся в пространстве имён `std`. примеры ниже подключают заголовок `math.h` и вызывают функции как `std::`. наиболее употребительные из них:

- `abs(arg)`: вычисляет абсолютное значение `arg`. большинство функций этого списка возвращает плавающий результат. `abs` возвращает целочисленный тип, если `arg` является целым числом, и плавающий тип, если аргумент имеет плавающий тип

- `ceil(arg)`: вычисляет ближайшее целое, большее или равное `arg`, и возвращает его числом с плавающей точкой. округление идёт в сторону плюс бесконечности. выражение `std::ceil(2.5)` возвращает `3.0`, а `std::ceil(-2.5)` возвращает `-2.0`

- `floor(arg)`: вычисляет ближайшее целое, меньшее или равное `arg`, и возвращает его числом с плавающей точкой. округление идёт в сторону минус бесконечности. выражение `std::floor(2.5)` возвращает `2.0`, а `std::floor(-2.5)` возвращает `-3.0`

- `exp(arg)`: вычисляет значение основания натурального логарифма в степени `arg`

- `log(arg)`: вычисляет натуральный логарифм числа `arg`, логарифм по основанию `e`. в арифметике ieee 754 отрицательный аргумент даёт нечисло, логарифм нуля даёт минус бесконечность

- `log10(arg)`: вычисляет логарифм по основанию 10 от `arg`

- `pow(arg1, arg2)`: вычисляет значение `arg1`, возведённое в степень `arg2`. числа `arg1` и `arg2` могут быть целочисленными или с плавающей точкой, результат имеет плавающий тип. результат `std::pow(2, 3)` равен `8.0`, а `std::pow(4, 0.5)` равен `2.0`

- `sqrt(arg)`: вычисляет квадратный корень из `arg`. отрицательный аргумент в арифметике ieee 754 даёт нечисловой результат

- `round(arg)`, `lround(arg)` и `llround(arg)` округляют число до ближайшего целого. разница между ними состоит в типе возвращаемого результата: `round()` возвращает число с плавающей точкой, `lround(arg)` возвращает число `long`, а `llround(arg)` возвращает `long long`. значение, равноудалённое от двух соседних целых, округляется в сторону от нуля: `std::lround(0.5)` возвращает `1L`, а `std::round(-1.5f)` возвращает `-2.0f`

- `sin(arg)`: вычисляет синус угла. `arg` задаёт угол в радианах

- `cos(arg)`: вычисляет косинус угла, аргумент также в радианах

- `tan(arg)`: вычисляет тангенс угла, аргумент в радианах

- `isinf(arg)`: возвращает `true`, если аргумент представляет положительную или отрицательную бесконечность

- `isnan(arg)`: возвращает `true`, если аргумент представляет `NaN`

пример применения некоторых функций:

```cpp
#include <iostream>
#include <math.h>   // подключаем заголовочный файл math.h

int main()
{
    std::cout << "abs(-3) = " << std::abs(-3)<< "\n";
    std::cout << "pow(-3, 2) = " << std::pow(-3, 2)<< "\n";
    std::cout << "round(-3.4) = " << std::round(-3.2)<< "\n";
    std::cout << "ceil(3.2) = " << std::ceil(3.2)<< "\n";
    std::cout << "floor(3.2) = " << std::floor(3.2)<< "\n";
    std::cout << "ceil(-3.2) = " << std::ceil(-3.2)<< "\n";
    std::cout << "floor(-3.2) = " << std::floor(-3.2)<< "\n";
}
```

консольный вывод:

```consoletext
abs(-3) = 3
pow(-3, 2) = 9
round(-3.4) = -3
ceil(3.2) = 4
floor(3.2) = 3
ceil(-3.2) = -3
floor(-3.2) = -4
```

проверка результата арифметических операций на `NaN` и бесконечность:

```cpp
#include <iostream>
#include <math.h>

int main()
{
    double a{ 1.5 }, b{-1.5}, c{}, d {};
    std::cout << a << "/" << b << " is Infinity? " << std::isinf(a / b) << std::endl;
    std::cout << a << "/" << b << " is Nan? " << std::isnan(a / b) << std::endl;
    std::cout << a << "/" << c << " is Infinity? " << std::isinf(a / c) << std::endl;
    std::cout << c << "/" << d << " is NaN? " << std::isnan(c / d) << std::endl;
}
```

консольный вывод:

```consoletext
1.5/-1.5 is Infinity? 0
1.5/-1.5 is Nan? 0
1.5/0 is Infinity? 1
0/0 is NaN? 1
```

во втором фрагменте `a` и `b` получают значения `1.5` и `-1.5`, а `c` и `d` инициализируются нулём. частное `a/b` конечно, поэтому и `isinf`, и `isnan` дают ложь, и поток печатает `0`. деление ненулевого числа с плавающей точкой на нуль в арифметике ieee 754 даёт бесконечность, поэтому `isinf(a/c)` печатает `1`. деление нуля на нуль даёт `NaN`, поэтому `isnan(c/d)` печатает `1`. обе функции возвращают `bool`. без манипулятора `boolalpha` поток выводит ложь как `0` и истину как `1`.
