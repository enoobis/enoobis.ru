### добавление элементов в вектор

элемент в конец вектора добавляет `push_back()`. аргумент копируется или перемещается в новую позицию. если `size()` совпал с `capacity()`, вектор выделяет новый буфер и переносит в него существующие элементы. рост ёмкости геометрический, поэтому серия добавлений в конец имеет амортизированную постоянную сложность. перераспределение буфера делает недействительными прежние итераторы, ссылки и указатели.

```cpp


#include <iostream>

#include <vector>

 

int main()

{

	std::vector<int> numbers;		// пустой вектор

	numbers.push_back(5);

	numbers.push_back(3);

	numbers.push_back(10);

	for(int n : numbers)

		cout << n << "\t";		// 5	3	10

	

    std::cout << std::endl;

}
```

число элементов вектора меняется во время выполнения. длина встроенного массива зафиксирована типом и выделенной памятью, расширить тот же объект массива нельзя. новые значения поэтому добавляются в вектор по ходу работы программы.

`emplace_back()` тоже помещает элемент в конец. аргументы передаются конструктору, и объект создаётся сразу в буфере контейнера, без отдельной временной величины, которую затем нужно переместить. для `int` различие с `push_back()` на результате не сказывается. для типа с нетривиальным конструктором `emplace_back` не строит лишний временный объект.

```cpp


std::vector<int> numbers{ 1, 2, 3, 4, 5 };

numbers.emplace_back(8);	// numbers = { 1, 2, 3, 4, 5, 8 };
```

### добавление элементов на определенную позицию

вставка в произвольную позицию задаётся итератором этой позиции. элементы, начиная с неё, сдвигаются к концу, поэтому вставка в начало или в середину `std::vector` линейна по числу сдвинутых элементов.

- `emplace(pos, value)`: создаёт элемент из аргументов на позиции итератора `pos`
- `insert(pos, value)`: вставляет готовый элемент `value` на позицию итератора `pos`. для уже построенного значения размещение совпадает по результату с `emplace`
- `insert(pos, n, value)`: вставляет n копий `value`, начиная с позиции `pos`
- `insert(pos, begin, end)`: вставляет, начиная с `pos`, элементы полуоткрытого диапазона `[begin, end)` другого контейнера
- `insert(pos, values)`: вставляет список инициализации, начиная с позиции `pos`

функция `emplace`:

```cpp


std::vector<int> numbers{ 1, 2, 3, 4, 5 };

auto iter = numbers.cbegin();	// константный итератор указывает на первый элемент

numbers.emplace(iter + 2, 8); // добавляем после второго элемента  numbers = { 1, 2, 8, 3, 4, 5};
```

функция `insert`:

```cpp


std::vector<int> numbers1{ 1, 2, 3, 4, 5 };

auto iter1 = numbers1.cbegin();	// константный итератор указывает на первый элемент

numbers1.insert(iter1 + 2, 8); // добавляем после второго элемента  

//numbers1 = { 1, 2, 8, 3, 4, 5};



std::vector<int> numbers2 { 1, 2, 3, 4, 5 };

auto iter2 = numbers2.cbegin();	// константный итератор указывает на первый элемент

numbers2.insert(iter2 + 1, 3, 4); // добавляем после первого элемента три четверки  

//numbers2 = { 1, 4, 4, 4, 2, 3, 4, 5};



std::vector<int> values { 10, 20, 30, 40, 50 };

std::vector<int> numbers3 { 1, 2, 3, 4, 5 };

auto iter3 = numbers3.cbegin();	// константный итератор указывает на первый элемент

// добавляем после первого элемента три первых элемента из вектора values

numbers3.insert(iter3 + 1, values.begin(), values.begin() + 3);

//numbers3 = { 1, 10, 20, 30, 2, 3, 4, 5};



std::vector<int> numbers4 { 1, 2, 3, 4, 5 };

auto iter4 = numbers4.cend();	// константный итератор указывает на позицию за последним элементом

// добавляем в конец вектора numbers4 элементы из списка { 21, 22, 23 }

numbers4.insert(iter4, { 21, 22, 23 });

//numbers4 = { 1, 2, 3, 4, 5, 21, 22, 23};
```

позиция во всех вызовах задаётся константным итератором, сдвинутым на нужное число элементов. сдвиг определён, потому что итератор вектора поддерживает арифметику произвольного доступа. вставка может перераспределить буфер и сделать недействительными итераторы, указатели и ссылки на элементы.

### удаление элементов

полное очищение вектора выполняет `clear()`: размер становится равным нулю, элементы уничтожаются. стандарт не требует при этом освобождать буфер, `capacity()` может сохраниться.

```cpp


std::vector<int> v { 1,2,3,4 };

v.clear();
```

`pop_back()` удаляет последний элемент. для вектора это операция постоянного времени, ёмкость обычно не уменьшается.

```cpp


std::vector<int> v { 1,2,3,4 };

v.pop_back();		// v = { 1,2,3 }
```

удаление из начала или из середины выполняет функция-член `erase`. свободная функция `std::erase`, добавленная в c++20, описана ниже и решает другую задачу: она убирает все элементы, равные заданному значению.

- `erase(p)`: удаляет элемент, на который указывает итератор `p`. возвращает итератор на элемент, следующий за удалённым, либо `end()`, если удалён последний элемент
- `erase(begin, end)`: удаляет полуоткрытый диапазон `[begin, end)`. возвращает итератор на элемент, следующий за последним удалённым, либо `end()`, если диапазон доходил до конца контейнера

применение:

```cpp


std::vector<int> numbers1 { 1, 2, 3, 4, 5, 6 };

auto iter = numbers1.cbegin(); // указатель на первый элемент

numbers1.erase(iter + 2);	// удаляем третий элемент

// numbers1 = { 1, 2, 4, 5, 6 }



std::vector<int> numbers2 = { 1, 2, 3, 4, 5, 6 };

auto begin = numbers2.cbegin(); // указатель на первый элемент

auto end = numbers2.cend();		// указатель на последний элемент

numbers2.erase(begin + 2, end - 1);	// удаляем с третьего элемента до последнего

// numbers2 = {1, 2, 6}
```

в первом вызове `iter + 2` указывает на третий элемент со значением 3. после удаления последовательность равна `{1, 2, 4, 5, 6}`. во втором вызове диапазон начинается с третьего элемента и заканчивается на `end() - 1`, поэтому последний элемент сохраняется и остаётся `{1, 2, 6}`. элементы правее точки удаления сдвигаются влево, сложность линейна по числу сдвинутых элементов. итераторы на удалённые элементы и на элементы за местом удаления становятся недействительными.

начиная со стандарта c++20 определена свободная функция `std::erase()`. в класс `std::vector` она не входит. первым аргументом передаётся вектор, вторым значение, все вхождения которого нужно удалить.

```cpp


std::vector<int> numbers3 { 1, 2, 3, 1, 5, 6 };

std::erase(numbers3, 1); // numbers3 = { 2, 3, 4, 5, 6 }
```

из `numbers3` удаляются все элементы, равные 1. исходная последовательность `{1, 2, 3, 1, 5, 6}` после удаления обоих вхождений 1 равна `{2, 3, 5, 6}`.

### размер вектора

`size()` возвращает число элементов. `empty()` возвращает истину, если вектор пуст, и ложь в противном случае. у вектора размер хранится явно, обе проверки выполняются за постоянное время.

```cpp


#include <iostream>

#include <vector>

 

int main()

{

	std::vector<int> numbers{1, 2, 3};

	if(numbers.empty())

		std::cout << "Vector is empty" << std::endl;

	else

		std::cout << "Vector has size " << numbers.size() << std::endl;

}
```

`resize()` меняет размер и имеет две формы:

- `resize(n)`: оставляет n первых элементов. если элементов больше n, хвост отбрасывается. если элементов меньше n, недостающие добавляются и инициализируются значением по умолчанию (для целочисленного типа это 0)
- `resize(n, value)`: так же оставляет n первых элементов. если элементов меньше n, недостающие получают значение `value`

применение:

```cpp


std::vector<int> numbers1 { 1, 2, 3, 4, 5, 6 };

numbers1.resize(4);	// оставляем первые четыре элемента - numbers1 = {1, 2, 3, 4}



numbers1.resize(6, 8);	 // numbers1 = {1, 2, 3, 4, 8, 8}
```

вызов `resize` способен сделать недействительными итераторы, указатели и ссылки на элементы. при увеличении размера возможно перераспределение буфера, при уменьшении инвалидируются позиции отброшенного хвоста.

### изменение элементов вектора

`assign()` заменяет всё содержимое вектора новым набором. прежние элементы уничтожаются, размер становится равен длине нового набора.

```cpp


std::vector<std::string> langs = { "Java", "JavaScript", "C"};

langs.assign(4, "C++"); // langs = {"C++", "C++", "C++", "C++"}
```

здесь элементы заменяются четырьмя строками `"C++"`.

новый набор можно передать списком инициализации:

```cpp


std::vector<std::string> langs{ "Java", "JavaScript", "C"};

langs.assign({ "C++", "C#", "C"}); // langs = { "C++", "C#", "C"}
```

`swap()` обменивает содержимое двух векторов. для `std::vector` обмен выполняется за постоянное время: меняются внутренние указатели на буферы, элементы по одному не копируются. итераторы остаются действительными и после обмена указывают на те же элементы, уже принадлежащие другому вектору.

```cpp


std::vector<std::string> clangs { "C++", "C#", "Java" };

std::vector<std::string> ilangs { "JavaScript", "Python", "PHP"};

clangs.swap(ilangs);	// clangs = { "JavaScript", "Python", "PHP"};

for(std::string lang : clangs)

{

	std::cout << lang <<  std::endl;

}
```

### сравнение векторов

векторы поддерживают операции сравнения `<`, `<=`, `>`, `>=`, `==`, `!=`. сравнение идёт по парам элементов на одинаковых позициях и является лексикографическим, по тем же правилам, что `std::lexicographical_compare`. векторы равны, когда их размеры совпадают и элементы на каждой позиции равны. иначе они не равны. отношение `<` истинно, если в первой различающейся позиции элемент левого вектора меньше элемента правого, либо если общий префикс совпал и левый вектор короче.

```cpp


std::vector<int> v1 {1, 2, 3};

std::vector<int> v2 {1, 2, 3};

std::vector<int> v3 {3, 2, 1};

	

bool v1v2 = v1 == v2; 	// true

bool v1v3 = v1 != v3;	// true

bool v2v3 = v2 == v3;	// false
```
