представление **transform** преобразует данные из одного типа в другой. для создания представления применяется конструктор **std::ranges::transform_view**, который принимает контейнер, данные которого нужно преобразовать, и функцию преобразования. новый контейнер при этом не строится: функция вызывается при обращении к очередному элементу.

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <ranges>

class Person
{
public:
    Person(std::string name, unsigned age): name{name}, age{age}{}
    std::string getName() const {return name;}
    unsigned getAge() const {return age;}
    void print() const  
    {
        std::cout << name <<"\t" << age << std::endl;
    }
private:
    std::string name;
    unsigned age;
}; 
int main()
{
    std::vector<Person> people 
    {
        Person{"Tom", 38}, Person{"Kate", 31}, Person{"Bob", 42}, 
        Person{"Alice", 34}, Person{"Sam", 25}
    };
    auto personToString = [](const Person& p){return p.getName();};
    auto view = = std::ranges::transform_view{people, personToString};

    for(const auto& person: view)
    {
        std::cout << person << std::endl;
    }
}
```

в функцию преобразования передаётся объект того типа, элементы которого хранятся в контейнере, здесь это объекты `Person`. функция преобразования задана лямбда-выражением, которое преобразует объект `Person` в строку и возвращает имя:

```cpp
auto personToString = [](const Person& p){return p.getName();};
```

в конструктор представления передаются контейнер и функция преобразования:

```cpp
auto view = = std::ranges::transform_view{people, personToString};
```

в итоге получается представление, которое содержит только строки, имена пользователей. тип элемента представления совпадает с типом возвращаемого значения функции преобразования. вывод:

```bash
Tom
Kate
Bob
Alice
Sam
```

в качестве альтернативы используется функция **std::views::transform()**, которая принимает функцию преобразования и возвращает адаптер:

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <ranges>

class Person
{
public:
    Person(std::string name, unsigned age): name{name}, age{age}{}
    std::string getName() const {return name;}
    unsigned getAge() const {return age;}
    void print() const  
    {
        std::cout << name <<"\t" << age << std::endl;
    }
private:
    std::string name;
    unsigned age;
}; 
int main()
{
    std::vector<Person> people 
    {
        Person{"Tom", 38}, Person{"Kate", 31}, Person{"Bob", 42}, 
        Person{"Alice", 34}, Person{"Sam", 25}
    };
    auto personToString = [](const Person& p){return p.getName();};
    auto view = people | std::views::transform(personToString);

    for(const auto& person: view)
    {
        std::cout << person << std::endl;
    }
}
```

для создания представления используется операция `|`, которая применяется к контейнеру и к функции `std::views::transform`:

```cpp
auto view = people | std::views::transform(personToString);
```
