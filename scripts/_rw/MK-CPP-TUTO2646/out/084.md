конструкции `try-catch` допускают вложение: одна конструкция может целиком располагаться внутри блока `try` другой. если исключение возникает во вложенной конструкции, поиск обработчика начинается с её блоков `catch`. выбирается первый блок, параметр которого соответствует типу выброшенного объекта. если во вложенной конструкции подходящий `catch` отсутствует, поиск продолжается во внешней конструкции `try-catch`. при выходе из внутреннего блока `try` без обработчика выполняется раскрутка стека для объектов с автоматическим временем хранения, созданных в этом блоке: их деструкторы вызываются до входа во внешний `catch`.

```cpp
#include <iostream>

double divide(int a, int b)
{
    if(!b)  // если b == 0
    {
        throw "Division by zero";
    }
	return a / b;
}
int main()
{
    try
    {
        try
        {
            int a{10}, b{};
            double result {divide(a, b)};
            std::cout << result << std::endl;
        }
        catch (const char* error)
        {
            std::cout << "Inner execption: " << error << std::endl;
        }
        std::cout << "Inner try-catch finished" << std::endl;
    }
    catch (const char* error)
    {
        std::cout << "External execption: " << error << std::endl;
    }
    std::cout << "External try-catch finished" << std::endl;
}
```



функция `divide()` вызывается во внутренней конструкции `try-catch`. оператор `throw` создаёт объект исключения. строковый литерал имеет тип `const char*` и не входит в иерархию `std::exception`, поэтому его примет только обработчик с совместимым типом указателя, а не `const std::exception&`. во вложенной конструкции есть блок `catch` с параметром `const char*`, поэтому исключение обрабатывается внутри. после обработчика выполнение продолжается обычным порядком: выполняется оператор, печатающий завершение внутреннего `try-catch`, а внешний блок `catch` не выполняется. консольный вывод:

```bash
Inner execption: Division by zero
Inner try-catch finished
External try-catch finished
```



если во вложенной конструкции нет обработчика нужного типа, исключение передаётся наружу:

```cpp
#include <iostream>

double divide(int a, int b)
{
    if(!b)  // если b == 0
    {
        throw "Division by zero";
    }
	return a / b;
}
int main()
{
    try
    {
        try
        {
            int a{10}, b{};
            double result {divide(a, b)};
            std::cout << result << std::endl;
        }
        catch (unsigned error)
        {
            std::cout << "Inner execption: " << error << std::endl;
        }
        std::cout << "Inner try-catch finished" << std::endl;	// эта строка не выполняется
    }
    catch (const char* error)
    {
        std::cout << "External execption: " << error << std::endl;
    }
    std::cout << "External try-catch finished" << std::endl;
}
```



листинг повторяет предыдущий, но внутренний блок `catch` принимает `unsigned`. для типов, не являющихся классами, требуется точное совпадение типа исключения и типа параметра `catch`. объект типа `const char*` с параметром `unsigned` не сопоставляется, поэтому внутренний обработчик пропускается. оператор после внутреннего `try-catch`, печатающий завершение внутренней конструкции, не выполняется: управление уже покинуло эту область в ходе раскрутки стека. поиск завершается во внешнем блоке `catch` с параметром `const char*`. консольный вывод:

```bash
External execption: Division by zero
External try-catch finished
```
