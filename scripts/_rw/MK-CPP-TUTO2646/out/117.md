**конструктор перемещения** (move constructor) служит альтернативой конструктору копирования там, где объект нужно передать дальше, а копировать его данные незачем. ресурс не дублируется, а забирается из источника в приёмник. источник после этого остаётся в корректном пустом состоянии и может быть уничтожен.

рассмотрим это на примере.

```cpp

#include <iostream>
 
// класс сообщения
class Message
{
public:
    // обычный конструктор
    Message(const char* data, unsigned count)
    {
        size = count;
        text = new char[size];  // выделяем память
        for(unsigned i{}; i < size; i++)    // копируем данные
        {
            text[i] = data[i];
        }

        id = ++counter;
        std::cout << "Create Message " << id << std::endl;
    }
    // конструктор копирования
    Message(const Message& copy) : Message{copy.getText(), copy.size }  // обращаемся к стандартному конструктору
    {
        std::cout << "Copy  Message " << copy.id << " to " << id << std::endl;
    }
    
    // деструктор
    ~Message()
    { 
        std::cout << "Delete Message "  << id << std::endl;
        delete[] text;	// особождаем память
    }
    char* getText() const { return text; }
    unsigned getSize() const { return size; }
    unsigned getId() const {return id;}
private:
    char* text{};  // текст сообщения
    unsigned size{};    // размер сообщения
    unsigned id{};  // номер сообщения
    static inline unsigned counter{};   // статический счетчик для генерации номера объекта
};

// класс мессенджера, который отправляет сообщение
class Messenger
{
public:
    Messenger(Message mes): message{mes}
    { }
    void sendMessage() const
    {
        std::cout << "Send message " <<  message.getId() << ": " << message.getText() << std::endl;
    }
private:
    Message message;
};
int main()
{
    Messenger telegram{Message{"Hello Word", 11}};
    telegram.sendMessage();
}
```

класс `Message` изображает сообщение. текст хранится в символьном указателе `text`, память под него выделяется динамически. чтобы на консоли был виден весь ход создания, копирования и уничтожения, в классе есть статическая переменная `counter`. она увеличивается при каждом новом объекте, и текущее значение записывается в поле `id`, номер сообщения.

```cpp

char* text{};  // текст сообщения
unsigned size{};    // размер сообщения
unsigned id{};  // номер сообщения
static inline unsigned counter{};
```

в конструкторе `Message` выделяется память под текст, переданный символьным массивом, символы копируются в этот буфер, и сообщению назначается номер. для копирования объекта определён конструктор копирования: он делегирует обычному конструктору, передавая ему текст и размер копии, так что буфер выделяется заново.

класс `Messenger` принимает сообщение в конструкторе и сохраняет его в поле `message`.

```cpp

class Messenger
{
public:
	Messenger(Message mes): message{mes}
	{ }
```

функция `sendMessage` условно отправляет сообщение: печатает его номер и текст.

в `main` создаётся объект `Messenger`, ему передаётся одно сообщение, затем вызывается `sendMessage`.

```cpp

Messenger telegram{Message{"Hello Word", 11}};
telegram.sendMessage();
```

в конструктор `Messenger` здесь передаётся объект `Message`, не связанный ни с какой переменной. это временный объект, prvalue. консольный вывод:

```bash

Create message 1
Create message 2
Copy  message 1 to 2
Delete message 1
Send message 2: Hello Word
Delete message 2
```

за время работы программы создаются два объекта `Message`, и в создании второго участвует конструктор копирования. разбор по этапам.

- выполнение строки вызывает конструктор `Message`. строка `Hello Word` копируется в поле `text`, сообщению назначается номер. этот временный объект получает номер 1. на консоль выводится

```cpp
Messenger telegram{Message{"Hello Word", 11}};
```

```bash
Create message 1
```

- созданный объект `Message` передаётся в конструктор `Messenger`. выражение `message{mes}` берёт переданный временный объект и конструктором копирования кладёт в поле `message` его копию. конструктор копирования `Message` сам обращается к обычному конструктору

```cpp
Messenger(Message mes): message{mes}
```

```cpp
Message(const Message& copy) : Message{copy.getText(), copy.size }
```

создаётся объект `Message` с номером 2. обычный конструктор выделяет для строки новый буфер. получаются две независимые копии: у каждой свой указатель на свой участок памяти. на консоль выводится

```bash

Create message 2
Copy  message 1 to 2
Delete message 1
```

теперь `Messenger` хранит второе сообщение. первое, временное, уничтожается: его деструктор освобождает свой буфер.

- затем вызывается `sendMessage`. сведения о сообщении, которое хранит мессенджер, печатаются на консоль. по завершении `main` это сообщение тоже уничтожается.

```cpp
telegram.sendMessage();
```

```bash

Send message 2: Hello Word
Delete message 2
```

с точки зрения копий и парности выделения и освобождения памяти программа корректна. буфер первого сообщения при этом ни разу не используется как результат: он выделен, скопирован в другой буфер и сразу освобождён. первое сообщение всё равно уничтожается, поэтому достаточно передать второму уже выделенный блок, а не запрашивать новый. для этого и существует конструктор перемещения.

**конструктор перемещения** принимает один параметр: rvalue-ссылку на объект того же типа.

```cpp

MyClass(MyClass&& moved) // ссылка rvalue
{
	// код конструктора перемещения
}
```

параметр `moved` обозначает перемещаемый объект. изменим программу и добавим в `Message` конструктор перемещения.

```cpp

#include <iostream>
 
// класс сообщения
class Message
{
public:
    // обычный конструктор
    Message(const char* data, unsigned count)
    {
        size = count;
        text = new char[size];  // выделяем память
        for(unsigned i{}; i < size; i++)    // копируем данные
        {
            text[i] = data[i];
        }

        id = ++counter;
        std::cout << "Create Message " << id << std::endl;
    }
    // конструктор копирования
    Message(const Message& copy) : Message{copy.getText(), copy.size }  // обращаемся к стандартному конструктору
    {
        std::cout << "Copy  Message " << copy.id << " to " << id << std::endl;
    }
    Message(Message&& moved)
    {
        id = ++counter;
        std::cout << "Create Message " << id << std::endl;

        text = moved.text;  // перемещаем текст сообщения
        size = moved.size;  // перемещаем размер сообщения
        moved.text = nullptr;
        std::cout << "Move Message " << moved.id << " to " << id << std::endl;
    }
    // деструктор
    ~Message()
    { 
        std::cout << "Delete Message "  << id << std::endl;
        delete[] text;	// особождаем память
    }
    char* getText() const { return text; }
    unsigned getSize() const { return size; }
    unsigned getId() const {return id;}
private:
    char* text{};  // текст сообщения
    unsigned size{};    // размер сообщения
    unsigned id{};  // номер сообщения
    static inline unsigned counter{};   // статический счетчик для генерации номера объекта
};

// класс мессенджера, который отправляет сообщение
class Messenger
{
public:
    Messenger(Message mes): message{std::move(mes)}
    { }
    void sendMessage() const
    {
        std::cout << "Send message " <<  message.getId() << ": " << message.getText() << std::endl;
    }
private:
    Message message;
};
int main()
{
    Messenger telegram{Message{"Hello Word", 11}};
    telegram.sendMessage();
}
```

по сравнению с предыдущим текстом сделаны два изменения. в класс `Message` добавлен конструктор перемещения.

```cpp

Message(Message&& moved)
{
    id = ++counter;
    std::cout << "Create Message " << id << std::endl;

    text = moved.text;  // перемещаем текст сообщения
    size = moved.size;  // перемещаем размер сообщения
    moved.text = nullptr;
    std::cout << "Move Message " << moved.id << " to " << id << std::endl;
}
```

параметр `moved` обозначает перемещаемый объект. обычный конструктор, в отличие от конструктора копирования, здесь не вызывается: новую память выделять не нужно. в поле `text` записывается значение указателя из `moved`, то есть адрес уже выделенного блока.

```cpp
text = moved.text
```

дополнительного выделения и посимвольного копирования нет. чтобы указатель `text` объекта `moved` больше не адресовал этот блок и деструктор `moved` его не освободил, указателю присваивается `nullptr`. вызов `delete[]` для нулевого указателя определён и ничего не делает, поэтому уничтожение источника остаётся безопасным. источник формально жив до конца своей области видимости, но ресурсом уже не владеет.

второе изменение находится в конструкторе `Messenger`. при инициализации поля используется `std::move` из стандартной библиотеки.

```cpp

class Messenger
{
public:
	Messenger(Message mes): message{std::move(mes)}
	{ }
```

`std::move` приводит переданное значение к rvalue-ссылке и само ничего не перемещает. параметр `mes` является именованным объектом, то есть lvalue, даже если инициализатор при вызове был временным. без приведения был бы выбран конструктор копирования: константная ссылка `const Message&` связывается и с rvalue. выражение `message{std::move(mes)}` выбирает конструктор перемещения и передаёт ему `mes`. результат оказывается в поле `message`. консольный вывод меняется.

```bash

Create message 1
Create Message 2
Move message 1 to 2
Delete message 1
Send message 2: Hello Word
Delete message 2
```

если конструктор перемещения не объявлен, то же выражение `message{std::move(mes)}` вызывает конструктор копирования: rvalue связывается с константной ссылкой на lvalue.

объектов по-прежнему два, но второй забирает уже выделенный буфер, и лишнего копирования символов нет. перемещают, как правило, объекты, которые дальше не нужны, как временный аргумент в этом примере.

компилятор сам генерирует конструктор перемещения по умолчанию: он перемещает все нестатические поля. генерация подавляется, если в классе объявлены деструктор, конструктор копирования или оператор присваивания с копированием либо с перемещением. в `Message` деструктор и конструктор копирования объявлены, поэтому неявного конструктора перемещения нет, и его нужно написать явно. это часть правила пяти: как только класс вручную управляет ресурсом в одной специальной функции, остальные специальные функции копирования и перемещения тоже берутся на себя.

### пример с векторами

добавление объекта в вектор показывает ту же механику. `std::vector` является динамическим массивом и для вставки в конец определяет `push_back` в двух версиях.

```cpp

void push_back(const Message &_Val)
void push_back(Message &&_Val)
```

первая принимает константную ссылку и рассчитана на передачу lvalue. вторая принимает rvalue-ссылку.

возьмём уже определённый класс `Message` и добавим в вектор один объект.

```cpp

#include <iostream> 
#include <vector>

// класс сообщения
class Message
{
    // содержимое класса Message
}
int main()
{
	std::vector<Message> messages{};
	messages.push_back(Message{"Hello world", 12});
}
```

в вектор добавляется `Message` как rvalue. внутри вектора объект сохраняется в своём буфере элементов, и для переноса данных из временного аргумента вызывается конструктор перемещения. консольный вывод:

```bash

Create Message 1
Create Message 2
Move Message 1 to 2
Delete Message 1
Delete Message 2
```

снова нет лишнего копирования символов: данные перемещаются.

если в `push_back` передать lvalue, выбирается перегрузка с константной ссылкой, и в итоге вызывается конструктор копирования. исходный объект ещё нужен вызывающему коду, забирать у него буфер нельзя.

```cpp

int main()
{
    Message mes{"Hello world", 12};
	std::vector<Message> messages{};
	messages.push_back(mes);
}
```

консольный вывод:

```bash

Create message 1
Create message 2
Copy  message 1 to 2
Delete message 2
Delete message 1
```
