отличительное свойство переменной состоит в том, что в ходе выполнения программы её значение можно изменять многократно. имя переменной обозначает объект в памяти: присваивание записывает в этот объект новое значение, тогда как тип объекта фиксируется при компиляции и далее не меняется.

```cpp
int n {7};
n = 9;
n = 5;
```

наряду с переменными в c++ определяются константы. значение константы задаётся при инициализации и в дальнейшем через это имя не изменяется. синтаксис определения совпадает с определением переменной, за исключением служебного слова `const` в начале:

```cpp
const int n {22};
// или 
// const int n = 22;
```

после определения к значению константы обращаются так же, как к значению переменной: имя входит в выражения и передаётся в операции вывода.

```cpp
#include <iostream>

int main()
{
    const int age {22};
    std::cout << "Age = " << age << "\n";
}
```

попытка присваивания после определения делает единицу трансляции некорректной: компилятор не переводит программу и выдаёт диагностику.

```cpp
const int age {22};
age = 78;
```

такой фрагмент не является допустимой программой. поскольку значение константы нельзя заменить присваиванием, объект с квалификатором `const` необходимо инициализировать, если от него требуется определённое значение. отсутствие инициализатора тоже диагностируется, и программа не компилируется:

```cpp
const int age;
```

инициализатором может служить литерал и значение, вычисляемое при выполнении, в том числе значение переменной или другой константы:

```cpp
int a {10};
const int b {7};
const int d {b};
const int x {a};
```

константой оформляют величину, которая по постановке задачи остаётся неизменной всё время работы программы. если вычисления используют число пи, это значение определяют как константу: математическая величина не меняется, и квалификатор `const` запрещает случайную запись.

```cpp
const float pi {3.14};
```

квалификатор `const` относится к типу: он запрещает модификацию через данное lvalue, и проверка выполняется статически, на этапе компиляции. в c++ объект интегрального типа с `const`, инициализированный константным выражением, сам образует константное выражение и допустим там, где требуется значение времени компиляции, например в размере массива или в метке `case`. снятие `const` приведением типа и последующая запись в объект, который был определён как константный, дают неопределённое поведение.
