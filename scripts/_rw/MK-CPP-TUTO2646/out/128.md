функция `std::sort()` из заголовочного файла `<algorithm>` сортирует диапазон элементов. первые два параметра функции являются начальным и конечным итераторами сортируемого диапазона. третий, необязательный, параметр является функцией сравнения, компаратором. если компаратор не указан, элементы сортируются по возрастанию относительно `operator<`. для строк это лексикографический порядок. алгоритм требует итераторы произвольного доступа и переставляет элементы на месте. стандарт гарантирует сложность порядка `O(N log N)` сравнений.

например, вектор строк сортируется порядком по умолчанию:

```cpp


#include <iostream>

#include <vector>

#include <string>

#include <algorithm>



int main()

{

    std::vector<std::string> people {"Tom", "Bob", "Sam", "Alice", "Kate"};  



    std::sort(begin(people), end(people)); // сортируем вектор people



    for(const auto& person: people )

    {

        std::cout << person << std::endl;

    }

}
```

сортируется весь вектор `people`, поэтому в `std::sort` передаются итераторы начала и конца вектора. результат:

```bash


Alice

Bob

Kate

Sam

Tom
```

строки упорядочены лексикографически: сравнение идёт по последовательности кодовых единиц, как в алфавитном порядке начальных букв. тот же вектор можно упорядочить компаратором, например по длине строк:

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <algorithm>



bool compare(const std::string& left, const std::string& right) 

{ 

    return left.length() < right.length(); 

}



int main()

{

    std::vector<std::string> people {"Tom", "Bob", "Sam", "Alice", "Kate"};  



    std::sort(begin(people), end(people), compare);



    for(const auto& person: people )

    {

        std::cout << person << std::endl;

    }

}
```

компаратором здесь служит функция `compare`. компаратор принимает два значения и возвращает значение типа **bool**. если первое значение должно идти раньше второго, возвращается `true`. в примере `compare` принимает две строки и возвращает `true`, если длина первой строки меньше длины второй. элементы равной длины для такого компаратора эквивалентны. `std::sort` не обязан сохранять их исходный относительный порядок: алгоритм неустойчив. устойчивую сортировку выполняет `std::stable_sort`. вывод программы:

```bash


Tom

Bob

Sam

Kate

Alice
```

строки отсортированы по длине по возрастанию.

### std::ranges::sort()

начиная со стандарта c++20 для сортировки элементов контейнера доступна `std::ranges::sort()`, которая принимает сортируемый контейнер. пара итераторов в этой перегрузке не нужна: границы алгоритм выводит из диапазона сам. требования к порядку и сложность те же, ограничения выражены концептами.

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <algorithm>

#include <ranges>		// для std::ranges



int main()

{

    std::vector<std::string> people {"Tom", "Bob", "Sam", "Alice", "Kate"};  



    std::ranges::sort(people);	// сортируем вектор people



    for(const auto& person: people )

    {

        std::cout << person << std::endl;

    }

}
```

по умолчанию данные сортируются по возрастанию. для строк это лексикографический порядок:

```bash


Alice

Bob

Kate

Sam

Tom
```

вторым параметром можно передать функцию компаратора, которая задаёт принцип сравнения значений:

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <algorithm>

#include <ranges>		// для std::ranges



bool compare(const std::string& left, const std::string& right) 

{ 

    return left.length() < right.length(); 

}



int main()

{

    std::vector<std::string> people {"Tom", "Bob", "Sam", "Alice", "Kate"};  



    std::ranges::sort(people, compare);	// сортируем вектор people с помощью компаратора compare



    for(const auto& person: people)

    {

        std::cout << person << std::endl;

    }

}
```

функция-компаратор `compare` упорядочивает элементы по возрастанию их длин:

```bash


Tom

Bob

Sam

Kate

Alice
```

### сортировка с проекцией

функция `std::ranges::sort` поддерживает проекцию данных для функции компаратора. проекция применяется к элементу до сравнения, и компаратор получает уже спроецированные значения. извлечение ключа отделено от отношения порядка.

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <algorithm>

#include <ranges>



class Person

{

public:

    Person(std::string name): name{name}{}

    std::string getName() const {return name;}

private:

    std::string name;

};



bool compare(const std::string& left, const std::string& right) 

{ 

    return left.length() < right.length(); 

}

std::string personToString(const Person& person){ return person.getName();}

int main()

{ 

    std::vector<Person> people {Person{"Tom"}, Person{"Kate"}, Person{"Bob"}, Person{"Alice"}};

    std::ranges::sort(people, compare, personToString);



    for(const auto& person: people )

    {

        std::cout << person.getName() << std::endl;

    }

}
```

сортируемый вектор содержит объекты `Person`. класс хранит имя в строковом поле `name`. для сравнения объектов `Person` можно определить отдельную функцию компаратора. здесь используется уже определённая функция компаратора для строк. третьим параметром `std::ranges::sort()` передаётся функция проекции из `Person` в `std::string`, функция `personToString`, которая возвращает имя объекта `Person`. именно эти строки передаются в компаратор при сравнении двух объектов.
