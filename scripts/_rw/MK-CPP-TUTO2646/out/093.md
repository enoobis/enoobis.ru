вектор представляет контейнер, который содержит коллекцию объектов одного типа. для работы с векторами подключают заголовок

```cpp
#include <vector>
```



простейшее объявление:

```cpp
std::vector<int> numbers;
```



в угловых скобках указывается тип объектов, которые будут храниться в векторе. вектор `numbers` хранит объекты типа `int`. сразу после такого объявления он пуст и не содержит элементов. `std::vector` является шаблоном класса: аргумент в угловых скобках задаёт специализацию, а сами элементы располагаются в непрерывном участке памяти.

инициализировать вектор можно одним из следующих способов:

```cpp
std::vector<int> v1;				// пустой вектор
std::vector<int> v2(v1);			// вектор v2 - копия вектора v1
std::vector<int> v3 = v1;			// вектор v3 - копия вектора v1
std::vector<int> v4(5);			// вектор v4 состоит из 5 чисел, каждое число равно 0
std::vector<int> v5(5, 2);		// вектор v5 состоит из 5 чисел, каждое число равно 2
std::vector<int> v6{1, 2, 4, 5};	// вектор v6 состоит из чисел 1, 2, 4, 5
std::vector<int> v7 = {1, 2, 3, 5}; // вектор v7 состоит из чисел 1, 2, 3, 5
```



круглые скобки и фигурные скобки в этих объявлениях выбирают разные конструкторы. при списковой инициализации фигурными скобками предпочтение получает конструктор от `std::initializer_list`, если он жизнеспособен. круглые скобки передают аргументы конструктору размера и заполняющего значения:

```cpp
std::vector<int> v1(5);		// вектор состоит из 5 чисел, каждое число в векторе равно 0
std::vector<int> v2{5};		// вектор состоит из одного числа, которое равно 5
std::vector<int> v3(5, 2);	// вектор состоит из 5 чисел, каждое число равно 2
std::vector<int> v4{5, 2};	// вектор состоит из двух чисел 5 и 2
```



в векторе хранятся элементы только одного типа, указанного в угловых скобках. значения других типов сохранить нельзя, как в следующем объявлении:

```cpp
std::vector<int> v{5, "hi"};
```



литерал `"hi"` имеет тип массива символов, а не `int`, поэтому список не соответствует `std::vector<int>`, и программа не компилируется.

### обращение к элементам и их перебор

для обращения к элементам вектора используют разные способы:

- `[index]`: получение элемента по индексу, как в массивах. индексация начинается с нуля

- `at(index)`: функция возвращает элемент по индексу

- `front()`: возвращает первый элемент

- `back()`: возвращает последний элемент

перебор вектора и чтение отдельных элементов:

```cpp
#include <iostream>
#include <vector>
 
int main()
{
	std::vector<int> numbers {1, 2, 3, 4, 5};
	
	int first = numbers.front();	// 1
	int last = numbers.back();		// 5
	int second = numbers[1]; 		// 2
	std::cout << "first: " << first << std::endl;
	std::cout << "second: " << second << std::endl;
	std::cout << "last: " << last << std::endl;

	numbers[0] = 6;  // изменяем значение	
	for(int n : numbers)
		std::cout << n << "\t";	// 6  2  3  4  5
	
    std::cout << std::endl;
}
```



индексация не добавляет элементов. если вектор содержит 5 элементов, обратиться к шестому как к существующему нельзя:

```cpp
std::vector<int> numbers {1, 2, 3, 4, 5};
numbers[5] = 9;
```



при таком обращении результат не определён. некоторые компиляторы диагностируют его как ошибку, некоторые продолжают компиляцию. даже в последнем случае обращение ошибочно и в любом случае не добавляет в вектор шестой элемент.

чтобы исключить такую ситуацию, используют функцию `at()`. она тоже возвращает элемент по индексу, но при обращении по недопустимому индексу генерирует исключение `std::out_of_range`:

```cpp
#include <iostream>
#include <vector>
#include <stdexcept>

int main()
{
	std::vector<int> numbers { 1, 2, 3, 4, 5};
	try
	{
		int n = numbers.at(8);
	}
	catch (std::out_of_range e)
	{
		std::cout << "Incorrect index" << std::endl;
	}
}
```



в листинге исключение перехватывается по значению, параметр имеет тип `std::out_of_range`. объект копируется в параметр обработчика. для типов-классов обычная форма параметра: константная ссылка. она связывает обработчик с существующим объектом исключения и сохраняет динамический тип.
