**множество** (`set`) задает контейнер, в котором каждое значение встречается не больше одного раза. такой контейнер выбирают для коллекции, чей инвариант запрещает дубликаты.

в стандартной библиотеке упорядоченное множество представлено шаблоном `std::set<T>` из заголовка `<set>`. параметр шаблона `T` есть тип элементов. пустое множество значений `int` создается так:

```cpp


#include <iostream>

#include <set>



int main()

{

    std::set<int> numbers;   // пустое множество чисел int

}
```

тип элементов записывается в угловых скобках после имени шаблона. в примере множество хранит числа типа `int`.

множество можно инициализировать другим множеством того же типа или списком инициализации:

```cpp


std::set<int> numbers {1, 2, 3, 4, 5};
```

конструктор от `std::initializer_list<T>` вставляет переданные элементы по одному. если ключ уже есть, вторая копия отбрасывается: инвариант `std::set` требует единственности ключа относительно компаратора.

### размер множества

`size()` возвращает число элементов. `empty()` возвращает `true`, если множество пусто, и `false` в противном случае. для `std::set` обе операции имеют постоянную сложность.

```cpp


#include <iostream>

#include <set>



int main()

{

    std::set<int> numbers{1, 2, 3};



    std::cout << "Empty: " << std::boolalpha <<  numbers.empty() << std::endl;    // Empty: false

    std::cout << "Size: " << numbers.size() << std::endl;     // Size: 3

}
```

### перебор множества

элементы перебираются циклом `for`. форма по диапазону (range-based for, ее же называют стилем for-each) обходит контейнер в порядке компаратора:

```cpp


#include <iostream>

#include <set>



int main()

{

    std::set<int> numbers{1, 2, 3, 4, 5};



    for (int n : numbers)

        std::cout << n << "\t";

    std::cout << std::endl;

}
```

компаратор по умолчанию есть `std::less<T>`. для `int` обход поэтому идет по возрастанию. стандарт требует логарифмическую сложность поиска, вставки и удаления. типичная реализация хранит узлы в красно-черном дереве, а итерация выполняет симметричный обход этого дерева.

### добавление элементов

элемент добавляется функцией `insert()`:

```cpp


#include <iostream>

#include <set>



int main()

{

    std::set<int> numbers{3, 4, 5};



    numbers.insert(1);

    numbers.insert(2);

    numbers.insert(2);

    numbers.insert(2);

    numbers.insert(6);



    for (int n : numbers)

        std::cout << n << "\t";

    std::cout << std::endl;

}
```

повторная вставка того же значения состав множества не меняет. несколько вызовов `numbers.insert(2)` оставляют число 2 в одном экземпляре. перегрузка `insert`, принимающая одно значение, возвращает `std::pair<iterator, bool>`: итератор на элемент с этим ключом и признак того, что вставка произошла. при уже существующем ключе второй член равен `false`.

элементы упорядочены. при компараторе по умолчанию порядок есть возрастание. после вставок вывод на консоль такой:

```bash
1       2       3       4       5       6
```

одна вставка занимает время, пропорциональное логарифму числа элементов: позиция нового узла определяется поиском в дереве.

### удаление элементов

элемент удаляется функцией `erase()`, в которую передается ключ:

```cpp


#include <iostream>

#include <set>





int main()

{

    std::set<int> numbers{2, 3, 4, 5};



    numbers.erase(1);

    numbers.erase(2);

    numbers.erase(3);



    for (int n : numbers)

        std::cout << n << "\t";

    std::cout << std::endl;

}
```

вызов с отсутствующим ключом, как `numbers.erase(1)`, множество не меняет. перегрузка `erase(const key_type&)` возвращает число удаленных элементов, 0 или 1, и не сигнализирует об отсутствии ключа исключением. консольный вывод:

```bash
4 5
```

### проверка наличия элемента

`count()` сообщает, есть ли значение во множестве. если значение есть, функция возвращает 1, если нет, возвращает 0. для `std::set` результат не бывает больше 1, потому что дубликаты запрещены. у `std::multiset` тот же прием дает число эквивалентных ключей.

```cpp


#include <iostream>

#include <set>





int main()

{

    std::set<int> numbers{2, 3, 4, 5};



    std::cout << "10 is in set: " << numbers.count(10) << std::endl;    // 10 is in set: 0

    std::cout << "2 is in set: " << numbers.count(2) << std::endl;      // 2 is in set: 1

}
```

начиная со стандарта c++20 ту же проверку выполняет `contains()`. функция возвращает `true`, если элемент есть, и `false`, если элемент отсутствует. условие совпадает с `count(key) != 0`.

```cpp


#include <iostream>

#include <set>





int main()

{

    std::set<int> numbers{2, 3, 4, 5};



    std::cout << "10 is in set: " << std::boolalpha << numbers.contains(10) << std::endl;    // 10 is in set: false

    std::cout << "2 is in set: " << std::boolalpha << numbers.contains(2) << std::endl;      // 2 is in set: true

}
```

### неупорядоченное множество unordered_set

`std::set<T>` держит элементы упорядоченными по критерию сравнения, по умолчанию по возрастанию. в заголовке `<unordered_set>` определен шаблон `std::unordered_set<T>`. он поддерживает тот же основной набор операций и не упорядочивает элементы. контейнер устроен как хеш-таблица: поиск, вставка и удаление в среднем занимают постоянное время, в худшем случае линейное от числа элементов. для `T` нужны хеш и предикат равенства. для `int` стандарт задает их по умолчанию.

упорядоченное множество с теми же числами:

```cpp


#include <iostream>

#include <set>



int main()

{

    std::set<int> numbers{3, 2, 5, 4};



    numbers.insert(1);

    numbers.insert(6);



    for (int n : numbers)

        std::cout << n << "\t";

    std::cout << std::endl;

}
```

элементы располагаются по возрастанию:

```bash
1       2       3       4       5       6
```

то же наполнение через неупорядоченное множество:

```cpp


#include <iostream>

#include <unordered_set>



int main()

{

    std::unordered_set<int> numbers{3, 2, 5, 4};



    numbers.insert(1);

    numbers.insert(6);



    for (int n : numbers)

        std::cout << n << "\t";

    std::cout << std::endl;

}
```

обход в этом прогоне дает последовательность ниже. она совпадает с обратным порядком добавления: в множество попали 3, 2, 5, 4, затем `insert(1)` и `insert(6)`. `insert()` в такой реализации ставит новый узел в начало списка элементов, поэтому обход начинается с последнего вставленного. стандарт этот порядок не обещает. контракт `std::unordered_set` фиксирует единственность ключа и сложность операций, а последовательность итераторов зависит от хеш-функции и от того, как библиотека раскладывает узлы по корзинам. вывод

```bash
6       1       4       5       2       3
```

характерен для библиотеки, где узлы вставлены в голову общего списка. так устроен `std::unordered_set` в microsoft visual c++. переносимый код не зависит от порядка обхода: поиск по ключу и равенство множеств определяются ключами, а не позицией при итерации.
