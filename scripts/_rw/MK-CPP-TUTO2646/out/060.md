### константные объекты

объекты классов бывают константными. константность относится ко всему объекту: после инициализации его нестатические члены без спецификатора `mutable` изменять нельзя.

```cpp


#include <iostream>

#include <string>

class Person 

{

public:

    std::string name;

    unsigned age;

    Person(std::string p_name, unsigned p_age)

    {

        name = p_name;

        age = p_age;

    }

};

int main()

{

    const Person tom{"Tom", 38};

    // мы можем получить данные константы

    std::cout << "Name: " << tom.name << "\tAge: " << tom.age << std::endl;

    // но изменить их нельзя

    // tom.name = "Tom";    // ! Ошибка

    // tom.age = 38;        // ! Ошибка

}
```

у константного объекта поля можно читать. присваивание этим полям некорректно. если раскомментировать строку

```cpp
tom.name = "Tom"; // ! Ошибка
```

компиляция остановится с ошибкой: объект `tom` константный, и модификация его нестатического члена запрещена.

### функции константного объекта

константность объекта ограничивает и вызов функций-членов. в класс `Person` добавлена `print()` для вывода полей.

```cpp


#include <iostream>

#include <string>

 

class Person 

{

private:

    std::string name;

    unsigned age;

public:

    Person(std::string p_name, unsigned p_age)

    {

        name = p_name;

        age = p_age;

    }

    void print() 

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

};

int main()

{

    const Person tom{"Tom", 38};

    tom.print();    // ! Ошибка

}
```

пример не компилируется из-за вызова `print`, хотя тело функции поля не меняет. причина в типе неявного параметра. у неконстантной функции-члена `this` имеет тип `Person*`, у константной тип `const Person*`. константный объект связывается только с `const Person*`. транслятор не исследует тело, чтобы выяснить, есть ли там запись в поля: квалификатор `const` входит в тип функции. поэтому отклоняется и функция, которая меняет состояние, и функция, которая его сохраняет, если она не объявлена константной.

для константного объекта допустимы только **константные функции**. после списка параметров ставится служебное слово **const**.

```cpp


#include <iostream>

#include <string>

 

class Person 

{

private:

    std::string name;

    unsigned age;

public:

    Person(std::string p_name, unsigned p_age)

    {

        name = p_name;

        age = p_age;

    }

    // константная функция

    void print() const  

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

};

int main()

{

    const Person tom{"Tom", 38};

    tom.print();            // Name: Tom       Age: 38

    Person bob{"Bob", 42};

    bob.print();            // Name: Bob       Age: 42

}
```

`print` объявлена константной, поэтому вызов законен и для константного `tom`, и для обычного `bob`. к неконстантному объекту константная функция применима: указатель `Person*` приводится к `const Person*` квалификационным преобразованием. внутри константной функции поля класса изменять нельзя, попытка присваивания члену в таком теле не компилируется. отдельно стоят члены со спецификатором `mutable`, о них речь ниже.

из константной функции вызывают только константные функции того же класса. неконстантная функция ожидает неконстантный `this`, а в константном теле `this` константный.

```cpp


#include <iostream>

#include <string>

 

class Person 

{

private:

    std::string name;

    unsigned age;

public:

    Person(std::string p_name, unsigned p_age)

    {

        name = p_name;

        age = p_age;

    }

    std::string getName() const

    {

        return name;

    }

    unsigned getAge() const

    {

        return age;

    }

    void print() const  

    {

        // в константной функции можно  вызывать только константные функции

        std::cout << "Name: " << getName()  << "\tAge: " << getAge() << std::endl;

    }

};

int main()

{

    const Person tom{"Tom", 38};

    tom.print();            // Name: Tom       Age: 38

    Person bob{"Bob", 42};

    bob.print();            // Name: Bob       Age: 42

}
```

дополнительно определены `getName` и `getAge`. обе константные и возвращают имя и возраст, поэтому вызов из константной `print` корректен.

#### возвращение констант

если константная функция возвращает указатель или ссылку на член, результат должен быть константным: указатель на константу или константная ссылка. иначе через возвращённое значение удалось бы изменить член константного объекта и обойти константность. возврат по значению создаёт копию и этого ограничения не несёт. в следующем примере ссылка и указатель возвращаются как константные.

```cpp


#include <iostream>

#include <string>

 

class Person 

{

private:

    std::string name;

    unsigned age;

public:

    Person(std::string p_name, unsigned p_age)

    {

        name = p_name;

        age = p_age;

    }

    // возвращаем константную ссылку

    const std::string& getName() const

    {

        return name;

    }

    // возвращаем указатель на константу

    const unsigned* getAge() const

    {

        return &age;

    }

    void print() const  

    {

        std::cout << "Name: " << name  << "\tAge: " << age << std::endl;

    }

};

int main()

{

    const Person tom{"Tom", 38};



    std::string tom_name =tom.getName();

    const unsigned* tom_age = tom.getAge();



    std::cout << "Name: " << tom_name  << "\tAge: " << *tom_age << std::endl;

}
```

константная `getName` возвращает константную ссылку на `std::string`, константная `getAge` возвращает указатель на константный `unsigned`. запись по этим результатам не компилируется, чтение допустимо.

### служебное слово mutable

отдельным членам константного объекта запись всё же бывает нужна. такой член помечают **mutable**. константность объекта его не защищает: присваивание разрешено и в константной функции, и через константный объект. обычное назначение `mutable` относится к служебным данным логически константной операции: кэш, счётчик обращений, мьютекс. в примере `mutable` для наглядности стоит у `age`, и присваивание `tom.age = 22` у константного объекта компилируется.

```cpp


#include <iostream>

#include <string>

 

class Person 

{

public:

    std::string name;

    mutable unsigned age;   // переменную age можно изменить

    Person(std::string p_name, unsigned p_age)

    {

        name = p_name;

        age = p_age;

    }

    void print() const  

    {

        std::cout << "Name: " << name  << "\tAge: " << age << std::endl;

    }

};

int main()

{

    const Person tom{"Tom", 38};

    tom.age = 22;

    tom.print();    // Name: Tom       Age: 22

}
```
