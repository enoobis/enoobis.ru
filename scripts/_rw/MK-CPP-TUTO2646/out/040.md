в предыдущих темах функция **main** определялась без параметров. ту же функцию можно определить с параметрами. переносимые формы точки входа суть `int main()` и форма с аргументами командной строки:

```cpp
int main(int argc, char* argv[])
{
	// инструкции
}
```

первый параметр, **argc**, имеет тип `int` и хранит количество аргументов командной строки. второй параметр, **argv**, имеет тип массива указателей `char*` и хранит переданные аргументы в виде строк. запись `char* argv[]` в параметре приводится к `char**`: в параметр попадает указатель на первый элемент массива указателей, который строит среда запуска. благодаря этим параметрам при запуске программы из консоли ей передаются данные. разбор строки командной строки на отдельные аргументы выполняет командный процессор. язык получает уже разделённые строки. программа получает уже готовый массив строк и их число.

ниже программа выводит полученные аргументы:

```cpp
#include <iostream>

int main(int argc, char* argv[])
{
    // выводим все переданные аргументы в цикле
    for (int i {}; i < argc; ++i)
    {
        std::cout << argv[i] << std::endl;
    }
}
```

программа выводит все аргументы командной строки. её компилируют и запускают, не передавая аргументов:

```bash
c:\cpp>g++ hello.cpp -o hello & hello
hello
```

если исходный текст расположен в файле `hello.cpp` и результат компиляции получает имя `hello`, командная строка выше сначала вызывает `g++`, затем запускает полученный файл. даже когда дополнительных аргументов нет, в `argv` есть по меньшей мере один элемент: имя файла программы в том виде, в каком его передала среда. в этом запуске массив содержит одну строку `hello`, а `argc` равен 1. стандарт дополнительно гарантирует, что элемент `argv[argc]` есть нулевой указатель. цикл в примере идёт строго до `argc` и этот элемент не читает.

программе можно передать аргументы:

```bash
c:\cpp>g++ hello.cpp -o hello & hello Tom 38
hello
Tom
38
```

при запуске передаются два значения, `"Tom"` и `"38"`. аргументы разделяются пробелом. даже если текст выглядит как число, как второй аргумент, программа получает его строкой `char*`. преобразования в `int` язык сам не делает: если нужно число, строку разбирают отдельно. в массиве `argv` теперь три элемента: имя программы, `"Tom"` и `"38"`. параметр `argc` равен 3.
