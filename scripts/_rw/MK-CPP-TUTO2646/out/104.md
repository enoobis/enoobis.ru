карта, или `std::map`, есть контейнер, в котором каждое значение связано с ключом, и по этому ключу значение читают и меняют. ключи уникальны: двум элементам нельзя иметь эквивалентные ключи. бытовой аналог такой структуры есть словарь, где слову сопоставлено толкование или перевод. отсюда второе имя этих контейнеров: словари, или ассоциативные массивы.

стандартная библиотека дает два словаря: `std::map<Key, T>` и `std::unordered_map<Key, T>`. оба шаблона параметризованы двумя типами. `Key` задает тип ключа, `T` задает тип отображаемого значения.

`std::map` определен в заголовке `<map>`. пустой словарь:

```cpp


#include <iostream>

#include <map>

#include <string>



int main()

{

    std::map<std::string, unsigned> products;

}
```

здесь словарь `products` условно хранит цены товаров. ключ имеет тип `std::string`, значение имеет тип `unsigned`: имя товара служит ключом, цена служит значением.

### обращение к элементам

чтение и запись значения выполняются оператором индексирования `[]`, по той же схеме, что у массива и у `std::vector`. в скобках стоит ключ типа `Key`, а не целочисленный индекс:

```cpp
map[ключ]=значение
```

пример заполнения и печати:

```cpp


#include <iostream>

#include <map>

#include <string>



int main()

{

    std::map<std::string, unsigned> products;

    // установка значений

    products["bread"] = 30;

    products["milk"] = 80;

    products["apple"] = 60;



    // получение значений

    std::cout << "bread\t" << products["bread"] << std::endl;

    std::cout << "milk\t" << products["milk"] << std::endl;

    std::cout << "apple\t" << products["apple"] << std::endl;

}
```

ключи в `products` имеют тип `std::string`, значения имеют тип `unsigned`. в квадратные скобки передается строка-ключ, справа записывается число:

```cpp
products["bread"] = 30;
```

ключ здесь есть название товара, значение есть его цена. элементу с ключом `"bread"` присваивается 30. пустой словарь такого ключа еще не содержит. `operator[]` ищет ключ и при отсутствии вставляет пару, у которой отображаемое значение инициализировано значением по умолчанию (`unsigned` получает 0), после чего возвращает ссылку на это значение. присваивание записывает в ссылку 30. если ключ уже есть, новая пара не создается, меняется существующее значение. чтение отсутствующего ключа через `[]` тоже выполняет вставку. когда вставка при чтении не нужна, ключ проверяют через `find` или `contains`. доступ, который при отсутствии ключа бросает `std::out_of_range`, дает функция `at()`.

то же выражение читает значение. значение имеет числовой тип, поэтому его можно сохранить в переменной:

```cpp
unsigned breadPrice = products["bread"];
```

программа выше печатает значения на консоль:

```bash


bread   30

milk    80

apple   60
```

### перебор элементов

перебор выполняет цикл `for` по диапазону:

```cpp


#include <iostream>

#include <map>

#include <string>



int main()

{

    std::map<std::string, unsigned> products;

    // установка значений

    products["bread"] = 30;

    products["milk"] = 80;

    products["apple"] = 60;



    for (const auto& [product, price] : products)

        std::cout << product << "\t" << price << std::endl;

}
```

элемент словаря имеет тип `std::pair<const Key, T>` и хранит ключ вместе со значением. для этого словаря это `std::pair<const std::string, unsigned>`. поле `first` есть ключ, поле `second` есть значение. ключ константный: позиция узла в дереве зависит от ключа, и изменение ключа разрушило бы порядок.

```cpp


for (const auto& element : products)

    std::cout << element.first << "\t" << element.second << std::endl;
```

со стандарта c++17 пару можно разобрать структурной привязкой сразу на ключ и значение:

```cpp


for (const auto& [product, price] : products)

    std::cout << product << "\t" << price << std::endl;
```

в `product` попадает ключ, в `price` попадает значение. консольный вывод:

```bash


apple   60

bread   30

milk    80
```

элементы хранятся и печатаются по возрастанию ключей. сравнение строк есть лексикографическое сравнение кодов `char` компаратором `std::less<std::string>`. для букв из набора ascii этот порядок совпадает с алфавитным. инициализация в порядке bread, milk, apple на обход не влияет: дерево перестраивает узлы по ключу.

### инициализация элементов

раз элемент есть `std::pair`, словарь можно инициализировать объектами пар:

```cpp


#include <iostream>

#include <map>

#include <string>



int main()

{

    std::map<std::string, unsigned> products

    {

        std::pair<std::string, unsigned>{"bread", 30}, std::pair{"milk", 80}, std::pair{"apple", 60}

    };

}
```

запись `std::pair{"milk", 80}` опирается на вывод аргументов шаблона класса, доступный с c++17: типы членов пары выводятся из литералов. явное `std::pair<std::string, unsigned>` задает те же типы вручную.

определение сокращается до списка пар в фигурных скобках. конструктор `std::map` от `std::initializer_list` принимает такие пары и приводит их к `value_type`:

```cpp


#include <iostream>

#include <map>

#include <string>



int main()

{

    std::map<std::string, unsigned> products

    {

        {"bread", 30}, {"milk", 80}, {"apple", 60}

    };

}
```

### удаление элементов

чтобы добавить элемент, достаточно записать значение по ключу. удаление выполняет `erase()`, которой передается ключ:

```cpp


#include <iostream>

#include <map>

#include <string>



int main()

{

    std::map<std::string, unsigned> products

    {

        {"bread", 30}, {"milk", 80}, {"apple", 60}

    };

    

    products.erase("milk");   // удаляем элемент с ключом "milk"



    for (const auto& [product, price] : products)

        std::cout << product << "\t" << price << std::endl;

	// консольный вывод

	// apple   60

	// bread   30



}
```

перегрузка по ключу возвращает число удаленных элементов, 0 или 1. отсутствующий ключ оставляет словарь без изменений.

### размер словаря

число элементов возвращает `size()`. `empty()` возвращает `true`, если словарь пуст, и `false` в противном случае.

```cpp


#include <iostream>

#include <map>

#include <string>



int main()

{

    std::map<std::string, unsigned> products

    {

        {"bread", 30}, {"milk", 80}, {"apple", 60}

    };



    std::cout << "Products count: " << products.size() << std::endl;	// Products count: 3

    std::cout << "Products is empty: " << std::boolalpha << products.empty() << std::endl; // Products is empty: false

}
```

### проверка наличия элемента

наличие ключа проверяют `count()` и `contains()`. в обе функции передается ключ. `count()` возвращает 1, если элемент есть, и 0, если его нет. больше 1 функция для `std::map` не возвращает: ключи уникальны. `contains()` появилась в c++20 и возвращает `true`, если элемент есть, и `false`, если его нет.

```cpp


#include <iostream>

#include <map>

#include <string>



int main()

{

    std::map<std::string, unsigned> products

    {

        std::pair<std::string, unsigned>{"bread", 30}, std::pair{"milk", 80}, std::pair{"apple", 60}

    }; 

    std::cout << "Apple\t" << products.count("apple")<< std::endl;     // Apple   1

    std::cout << "Orange\t" << products.count("orange")<< std::endl;   // Orange  0



    std::cout << "Apple\t" << std::boolalpha << products.contains("apple")<< std::endl;     // Apple   true

    std::cout << "Orange\t" << std::boolalpha << products.contains("orange")<< std::endl;   // Orange  false

}
```

### неупорядоченные словари

`std::map` упорядочивает элементы по ключам, по умолчанию по возрастанию. если порядок не требуется, применяют `std::unordered_map<Key, T>`. набор операций тот же, упорядочения нет. тип определен в заголовке `<unordered_map>` и реализован хеш-таблицей: средняя сложность поиска, вставки и удаления постоянная. для ключа нужны хеш и равенство. для `std::string` они заданы стандартной библиотекой.

```cpp


#include <iostream>

#include <unordered_map>

#include <string>



int main()

{

    std::unordered_map<std::string, unsigned> products

    {

        std::pair<std::string, unsigned>{"bread", 30}, std::pair{"milk", 80}, std::pair{"apple", 60}

    };

    

    for (const auto& [product, price] : products)

        std::cout << product << "\t" << price << std::endl;

}
```

консольный вывод этого прогона:

```bash


apple   60

milk    80

bread   30
```

порядок строк стандарт не фиксирует. он зависит от хеш-функции и от числа корзин. показанная последовательность есть результат конкретной библиотеки, а не часть контракта контейнера.

### итераторы

`value_type` словаря есть `std::pair<const Key, T>`, поэтому ключ через итератор не меняют. отображаемое значение через неконстантный итератор `begin()` и `end()` менять можно: доступно присваивание в `second`. константный итератор запрещает изменение и ключа, и значения. его дают `cbegin()` и `cend()`. пример только читает пары телефонной книги:

```cpp


#include <iostream>

#include <map>

#include <string>



int main()

{

    std::map<std::string, std::string> phoneBook 

    {

        {"+11111111111", "Tom"}, {"+12222222222", "Bob"}, {"+13333333333", "Sam"}

    };

    for(auto iter{phoneBook.begin()}; iter != phoneBook.end(); iter++)

    {

        std::cout << iter->first << "\t" << iter->second << std::endl;

    }

    // для получения итераторов также можно использовать функции cbegin и cend

    for(auto iter{phoneBook.cbegin()}; iter != phoneBook.cend(); iter++)

    {

        std::cout << iter->first << "\t" << iter->second << std::endl;

    }

}
```
