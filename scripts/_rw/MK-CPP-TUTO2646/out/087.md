помимо `std::exception` стандартная библиотека c++ задаёт производные типы для типичных классов ошибок:

- `runtime_error`: общий тип исключений, обнаруживаемых во время выполнения

- `range_error`: результат вычисления выходит за допустимый диапазон

- `overflow_error`: результат превышает верхнюю границу допустимого диапазона

- `underflow_error`: результат вычисления имеет недопустимое отрицательное значение и выходит за нижнюю границу

- `logic_error`: ошибка в логике программы

- `domain_error`: для переданного в функцию значения результат не определён

- `invalid_argument`: в функцию передан некорректный аргумент

- `length_error`: попытка создать объект, размер которого превышает предел, допустимый для данного типа

- `out_of_range`: попытка доступа к элементу вне допустимого диапазона

большинство этих типов разделяется на две ветви по непосредственному базовому классу: `logic_error` либо `runtime_error`. их объявления собраны в заголовочном файле `<stdexcept>`. типы ветви `logic_error` соответствуют ошибкам, которые в принципе обнаружимы до запуска программы и следуют из неверной логики: вызов функции с недопустимыми аргументами или вызов функции-члена у объекта, чьё состояние не удовлетворяет предусловию операции. вместо перехвата таких исключений допустимость аргументов и состояние объекта проверяют явно до вызова.

ветвь `runtime_error` соответствует ошибкам, которые обнаруживаются только во время выполнения. исключения, производные от `system_error`, как правило инкапсулируют сбои нижележащей операционной системы, в том числе ошибки ввода и вывода. класс `system_error` сам производен от `runtime_error` и объявлен в `<system_error>`. обращение к файлам и любое взаимодействие с оборудованием может завершиться сбоем, который нельзя предсказать по тексту программы: отказ диска, отсоединённый кабель, сбой сети.

конструкция `try-catch` может содержать несколько блоков `catch` для разных типов. при исключении выбирается обработчик, тип параметра которого совместим с типом выброшенного объекта, с учётом порядка записи блоков.

более частные обработчики помещают перед более общими:

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    Person(std::string name, unsigned age)

    {

        if(name.length() > 11)

            throw std::length_error("Name must be less than 10 chars");

        if(!age || age > 110)

            throw std::range_error("Age must be between 1 and 110");

        this->name = name;

        this->age = age;

    }

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

};

 

void testPerson(std::string name, unsigned age)

{

    try

    {

        Person person{name, age};   // создаем один объект Person

        person.print();

    }

    catch (const std::length_error& ex)

    {

        std::cout << "Length_error: " << ex.what() << std::endl;

    }

    catch (const std::range_error& ex)

    {

        std::cout << "Range_error: " << ex.what() << std::endl;

    }

    catch (const std::exception&)

    {

        std::cout << "Something wrong"<< std::endl;

    }

}

int main()

{

    testPerson("Tom", 38);  // Name: Tom       Age: 38

    testPerson("Gai Yulii Cezar", 42);  // Length_error: Name must be less than 10 chars

    testPerson("Sam", 250);  // Range_error: Age must be between 1 and 110

}
```



конструктор `Person` принимает строку имени и число возраста. передаваемые данные могут нарушать ограничения. для возраста установлен диапазон от 1 до 110, а имя не должно быть длиннее 11 символов. при нарушении конструктор генерирует разные исключения:

```cpp


Person(std::string name, unsigned age)

{

    if(name.length() > 11)

        throw std::length_error("Name must be less than 10 chars");

    if(!age || age > 110)

        throw std::range_error("Age must be between 1 and 110");

    this->name = name;

    this->age = age;

}
```



функция `testPerson` создаёт объект `Person` в блоке `try`. три блока `catch` различают типы. последний параметр имеет самый общий тип `std::exception`. второй обрабатывает `std::range_error`, производный от `std::runtime_error`. первый обрабатывает `std::length_error`, производный от `std::logic_error`. частные типы стоят раньше общего, иначе обработчик `std::exception` поглотил бы их:

```cpp


catch (const std::length_error& ex)

{

    std::cout << "Length_error: " << ex.what() << std::endl;

}

catch (const std::range_error& ex)

{

    std::cout << "Range_error: " << ex.what() << std::endl;

}

catch (const std::exception&)

{

    std::cout << "Something wrong"<< std::endl;

}
```



в обработчиках текст ошибки возвращает виртуальная функция `what()`. программа выводит:

```bash


Name: Tom       Age: 38

Length_error: Name must be less than 10 chars

Range_error: Age must be between 1 and 110
```
