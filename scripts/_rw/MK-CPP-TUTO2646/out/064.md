деструктор завершает время жизни объекта. в его теле освобождают ресурсы, которыми класс владеет напрямую, а нестатические члены уничтожаются сразу после тела. вызов автоматический и происходит, когда время жизни заканчивается. объект удаляется в следующих случаях:

- когда завершается область видимости, в которой определены автоматические объекты

- когда уничтожается контейнер (например, массив), содержащий объекты

- когда уничтожается объект, членами которого являются другие объекты

- когда к указателю на динамический объект применяют оператор `delete`

деструктор является функцией. его имя совпадает с именем класса, как у конструктора, и перед именем стоит тильда (`~`):

```cpp


~имя_класса() 

{

	// код деструктора

}
```

возвращаемого значения деструктор не имеет и параметров не принимает. второй деструктор в классе объявить нельзя: сигнатура фиксирована, перегрузки по параметрам нет.

явно деструктор пишут, когда объекту есть что освободить сверх автоматического уничтожения членов. если член сам управляет ресурсом, как `std::string` или файловый поток, его деструктор вызовется при уничтожении члена, и отдельный деструктор класса для этого ресурса не нужен. ручной деструктор нужен для ресурса, которым класс владеет непосредственно: открытый файл, память из оператора `new`, системный дескриптор. приобретение ресурса в конструкторе и освобождение в деструкторе связывает время жизни ресурса с временем жизни объекта. эту схему называют raii, resource acquisition is initialization.

простейшее определение деструктора:

```cpp


#include <iostream>

#include <string>



class Person

{

public:

	Person(std::string p_name)

	{

		name = p_name;

        std::cout << "Person " << name << " created" << std::endl;

	}

    ~Person()

    {

        std::cout << "Person " << name << " deleted" << std::endl;

    }

private:

	std::string name;

};



int main()

{

    {

        Person tom{"Tom"};

        Person bob{"Bob"};

    }   // объекты Tom и Bob уничтожаются



    Person sam{"Sam"};

}   // объект Sam уничтожается
```

деструктор `Person` сообщает об уничтожении объекта.

```cpp


~Person()

{

	std::cout << "Person " << name << " deleted" << std::endl;

}
```

в `main` создаются три объекта `Person`. два из них созданы во вложенном блоке.

```cpp


{

    Person tom{"Tom"};

    Person bob{"Bob"};

}
```

блок задаёт область видимости этих переменных. по выходе из блока время жизни заканчивается, оба объекта уничтожаются, и для каждого вызывается деструктор. автоматические объекты одной области уничтожаются в порядке, обратном созданию: сначала `bob`, затем `tom`.

затем создаётся третий объект, `sam`.

```cpp


int main()

{

    {

        Person tom{"Tom"};

        Person bob{"Bob"};

    }   // объекты Tom и Bob уничтожаются



    Person sam{"Sam"};

}   // объект Sam уничтожается
```

`sam` объявлен в области `main` и уничтожается при выходе из `main`. консольный вывод:

```bash


Person Tom created

Person Bob created

Person Bob deleted

Person Tom deleted

Person Sam created

Person Sam deleted
```

более прикладной вариант связывает деструктор со счётчиком. число объектов `Person` хранится в статической переменной. конструктор увеличивает её при создании, деструктор уменьшает при уничтожении. сам статический член вместе с объектом не уничтожается: он принадлежит классу и живёт до завершения программы.

```cpp


#include <iostream>

#include <string>



class Person

{

public:

	Person(std::string p_name)

	{

		name = p_name;

        ++count;

        std::cout << "Person " << name << " created. Count: " << count << std::endl;

	}

    ~Person()

    {

        --count;

        std::cout << "Person " << name << " deleted. Count: " << count << std::endl;

    }

private:

	std::string name;

    static inline unsigned count{}; // счетчик объектов

};



int main()

{

    {

        Person tom{"Tom"};

        Person bob{"Bob"};

    }   // объекты Tom и Bob уничтожаются

    Person sam{"Sam"};

}   // объект Sam уничтожается
```

консольный вывод программы:

```bash


Person Tom created. Count: 1

Person Bob created. Count: 2

Person Bob deleted. Count: 1

Person Tom deleted. Count: 0

Person Sam created. Count: 1

Person Sam deleted. Count: 0
```

выполнение тела деструктора ещё не освобождает память самого объекта. после тела уничтожаются нестатические члены и базовые подобъекты, и только затем освобождается хранилище. для автоматического объекта это происходит при выходе из области, для динамического при применении `delete`.

у класса без пользовательского деструктора компилятор объявляет деструктор неявно. если бы `Person` не определял деструктор, компилятор подготовил бы пустое тело, как в следующем фрагменте. члены после этого тела всё равно уничтожаются, в порядке, обратном порядку объявления.

```cpp


~Person(){}
```
