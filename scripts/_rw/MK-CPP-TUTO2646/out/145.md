объект класса может удерживать ресурс в течение всей своей жизни: динамическую память, открытый файл, сетевое соединение. в c++ время жизни такого ресурса привязывают ко времени жизни объекта идиомой `RAII` (resource acquisition is initialization). получение ресурса выполняется при инициализации объекта, освобождение выполняется в деструкторе. деструктор автоматического объекта вызывается при любом выходе из области видимости, в том числе когда область покидается из-за исключения. освобождение не поставлено в зависимость от того, дошла ли программа до явного `delete` или `close` на каждой ветке возврата.

класс `IntArray` представляет массив значений `int` и сам владеет памятью этого массива.

```cpp

#include <iostream>

class IntArray
{
public:
    IntArray(unsigned size) : data{ new int[size] } {}  // выделяем память
    ~IntArray()
    {
        if(data)
        {
            std::cout << "Freeing memory..." << std::endl;
            delete[] data;      // освобождаем память
        }
    }
    // Удаляем конструктор копирования и оператор присваивания
    IntArray(const IntArray&) = delete;
    IntArray& operator=(const IntArray&) = delete;

    // оператор индексирования для доступа к элементам
    int& operator[](unsigned index) { return data[index]; }

    // возвращаем инкапсулированный ресурс
    int* get() const { return data; }
    // передаем ресурс другогому объекту
    int* release()
    {
        int* result = data;
        data = nullptr;
        return result;
    }
private:
    int* data;
};

int main()
{   
    const unsigned count {5};   // количество элементов
    IntArray values{count};     // создаем объект, который управляет ресурсом

    // изменяем элементы динамического массива
    for (unsigned i {}; i < count; ++i)
    {
        values[i] = i;
    }
    // выводим элементы динамического массива на консоль
    for (unsigned i {}; i < count; ++i)
    {
        std::cout << values[i] << "\t";
    }
    std::cout << std::endl;
}
```

память выделяется в инициализаторе конструктора выражением `new int[size]` и освобождается в деструкторе вызовом `delete[]`. указатель лежит в закрытом поле `data`. длина массива в полях объекта не хранится: число элементов остаётся у кода, который передал `count` и сохранил эту величину. оператор `[]` границы не проверяет. выражение `new int[size]` не обнуляет элементы. скалярный `int` при такой форме `new` получает неопределённое значение, и первый цикл задаёт элементы до любого чтения. если память выделить нельзя, `new` бросает `std::bad_alloc`. конструирование тогда не завершается, деструктор этого экземпляра не вызывается, освобождать ещё нечего.

пара получения и освобождения выписана отдельно:

```cpp

IntArray(unsigned size) : data{ new int[size] } {}  // выделяем память
~IntArray()
{
    std::cout << "Freeing memory..." << std::endl;
    delete[] data;      // освобождаем память
}
```

во фрагменте деструктор всегда печатает сообщение и всегда вызывает `delete[]`. в полном определении класса перед освобождением стоит проверка `if(data)`.

динамическая память в примере частный случай ресурса и взята для наглядности. на её месте в той же схеме стояли бы файл или сетевое соединение: открытие в конструкторе, закрытие в деструкторе. для памяти ту же передачу владения выражает `std::unique_ptr<int[]>`. класс записан вручную, чтобы были видны инициализация, деструктор и явная отдача ресурса.

освобождать одну область можно только один раз. два объекта с копией одного указателя вызвали бы `delete[]` дважды, а повторное освобождение является неопределённым поведением. копирующий конструктор и копирующее присваивание удалены. попытка скопировать `IntArray` не компилируется:

```cpp

IntArray(const IntArray&) = delete;
IntArray& operator=(const IntArray&) = delete;
```

пользовательский деструктор подавляет неявное объявление перемещающего конструктора и перемещающего присваивания. объявленные копирующие операции подавляют эти же функции. перемещающие операции в классе не определены, поэтому объект нельзя ни скопировать, ни переместить. передача `IntArray` по значению, которая размножила бы указатель, отсекается ещё при компиляции.

элементы доступны через оператор `[]`. он возвращает ссылку `int&`, элемент можно читать и записывать. указатель без передачи владения даёт функция `get`. после `get` деструктор по-прежнему считает память своей и освободит её при выходе объекта из области видимости. передачу владения наружу, в том числе другому объекту, выполняет `release`. она сохраняет текущий указатель, записывает в поле `nullptr` и возвращает прежнее значение. память после этого освобождает тот код, который указатель принял:

```cpp

int* release()
{
    int* result = data;
    data = nullptr;
    return result;
}
```

вызов `delete[]` для нулевого указателя определён стандартом как пустая операция. проверка `if(data)` записывает ту же гарантию явно. после `release` деструктор видит `nullptr`, сообщение об освобождении не печатает и переданную наружу память не трогает.

в `main` создаётся один объект. число элементов равно пяти:

```cpp

int main()
{   
    const unsigned count {5};   // количество элементов
    IntArray values{count};     // создаем объект, который управляет ресурсом
```

конструктор выделяет массив из пяти `int`. первый цикл записывает в элементы индексы `0`, `1`, `2`, `3` и `4`. второй печатает их через табуляцию. при завершении `main` автоматический объект `values` выходит из области видимости, деструктор печатает сообщение и возвращает память:

```bash

0       1       2       3       4
Freeing memory...
```

числа появляются раньше сообщения: оба цикла выполняются, пока объект ещё жив. строка `Freeing memory...` печатается уже из деструктора.

тот же массив можно отдать наружу через `release` и освободить в `main`:

```cpp

int main()
{   
    const unsigned count {5};   // количество элементов
    IntArray array{count};     // создаем объект, который управляет ресурсом

    // изменяем элементы динамического массива
    for (unsigned i {}; i < count; ++i)
    {
        array[i] = i;
    }

    // получаем указатель
    int* data = array.release(); // теперь функция main обязана освободить память

    for (unsigned i {}; i < count; ++i)
    {
        std::cout << data[i] << "\t";
    }
    std::cout << std::endl;

    //освобожадем память
    delete[] data;
}
```

вызов `array.release()` копирует указатель в локальную переменную `data` и оставляет объект `array` без ресурса. обязанность вызвать `delete[]` переходит к `main` и выполняется в конце функции, после печати элементов. деструктор `array` эту память не освобождает: поле `data` уже нулевое. если убрать `delete[] data` из `main`, память утечёт. после `release` её не освободит ни деструктор `array`, ни другой объект.
