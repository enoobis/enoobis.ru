шаблон задаёт конструкцию (функцию или класс), параметризованную типами, которые на момент написания текста неизвестны и становятся известны при инстанцировании. шаблон описывает семейство конструкций, не привязанных к одному конкретному типу. подстановка аргументов и проверка тела выполняются во время компиляции.

шаблон функции (function template) задаёт функцию, тело которой не зависит от заранее фиксированных типов параметров.

потребность в шаблоне видна на функции сложения значений типов `int`, `double` и `std::string`. без шаблона для каждого типа пишут отдельную перегрузку:

```cpp


#include <iostream>

#include <string>



int add(int, int);

double add(double, double);

std::string add(std::string, std::string);



int main()

{

    std::cout << "int: " << add(4, 5) << std::endl; 

    std::cout << "double: " << add(4.4, 5.5) << std::endl;

    std::cout << "string: " << add(std::string("hel"), std::string("lo")) << std::endl;

}



int add(int x, int y)

{

    return x + y;

}

double add(double x, double y)

{

    return x + y;

}



std::string add(std::string str1, std::string str2)

{

    return str1 + str2;

}
```



перегрузки вычисляют результат, но тела совпадают: отличается лишь тип параметров и возвращаемого значения. шаблон снимает это повторение.

шаблон функции служит образцом, по которому компилятор создаёт конкретную функцию для конкретного набора аргументов шаблона:

```cpp


#include <iostream>

#include <string>



template<typename T> T add(T, T);	// прототип функции



int main()

{

    std::cout << "int: " << add(4, 5) << std::endl; 

    std::cout << "double: " << add(4.4, 5.5) << std::endl;

    std::cout << "string: " << add(std::string("hel"), std::string("lo")) << std::endl;

}

template<typename T> T add(T a, T b)

{

    return a + b;

}
```



определение начинается с ключевого слова `template`. в угловых скобках после него записывают `typename` и список параметров шаблона:

```cpp
template<typename T> T add(T a, T b)
```



после `typename` указан один параметр `T`. имя параметра шаблона произвольно. по соглашению часто берут заглавную букву, например `T`. параметр `T` обозначает тип, который определяется при компиляции конкретного вызова: `int`, `double`, `std::string` или иной тип. в теле применяется операция сложения, поэтому аргумент, подставленный вместо `T`, должен поддерживать `operator+` с результатом, приводимым к возвращаемому типу `T`. если требуемой операции нет, ошибка диагностируется на этапе компиляции, при инстанцировании этой специализации, а не при разборе самого шаблона.

при вызове `add` аргументами могут быть объекты `int`, `double` и других типов. по типам аргументов компилятор выводит аргумент шаблона, связанный с `T`, и порождает специализацию функции `add` для этого типа. вызов разрешается в эту специализацию. если для следующего вызова нужна та же специализация, используется уже созданный экземпляр.

параметры шаблона сочетаются со ссылками, указателями и массивами. в следующем варианте параметры передаются по константной ссылке, чтобы не копировать аргумент и не изменять его в теле:

```cpp


#include <iostream>

#include <string>



template<typename T> T add(const T&, const T&); 



int main()

{

    std::cout << "int: " << add(4, 5) << std::endl; 

    std::cout << "double: " << add(4.4, 5.5) << std::endl;

    std::cout << "string: " << add(std::string("hel"), std::string("lo")) << std::endl;

}

template<typename T> T add(const T& a, const T& b)

{

    return a + b;

}
```



обмен значений:

```cpp


#include <iostream> 



template<typename T> void swap(T&, T&); 



int main()

{

    int c {30};

    int d {10};

    swap(c, d);

    std::cout << "c = " << c << "\t d = " << d << std::endl;    // с = 10   d = 30

}



template <typename T> void swap(T& a, T& b)

{

    T temp = a;

    a = b;

    b = temp;

}
```



`swap` принимает два параметра одного и того же выведенного типа и обменивает их значения через временный объект типа `T`.

указатели на примере выбора наибольшего значения:

```cpp


#include <iostream> 



template<typename T> T* max(T*, T*); 



int main()

{

    int a{4}, b{5};

    std::cout << "int: " << *max(&a, &b) << std::endl; // int: 5



    double c{3.4}, d{2.3};

    std::cout << "double: " << *max(&c, &d) << std::endl;   // double: 3.4

}

template<typename T> T* max(T* a, T* b)

{

    return *a > *b? a : b;

}
```



### явный вызов реализации функции для определённого типа

в предыдущих примерах тип выводился по аргументам вызова. аргумент шаблона можно задать явно:

```cpp


#include <iostream> 



template<typename T> T add(const T&, const T&); 



int main()

{

    double d { add<double>(3.3, 2.2)};

    std::cout << "d: " << d << std::endl;   //d: 5.5

    d  = add<double>(3, 2);

    std::cout << "d: " << d << std::endl;   //d: 5

}

template<typename T> T add(const T& a, const T& b)

{

    return a + b;

}
```



явный аргумент `double` выбирает специализацию для этого типа:

```cpp
double d { add<double>(3.3, 2.2)};
```



во втором вызове аргументы являются целочисленными литералами, но явный аргумент шаблона фиксирует специализацию для `double`. преобразование аргументов к `double` выполняется уже после того, как тип `T` задан:

```cpp
d  = add<double>(3, 2);
```



### перегрузка функций и параметризация

параметризация сокращает число перегрузок: одна конструкция покрывает множество типов. отдельные версии функции по-прежнему нужны, когда различается не только тип, но и способ вычисления. перегрузку совмещают с шаблонами. ниже максимальное значение ищется либо среди двух объектов, либо среди элементов массива:

```cpp


#include <iostream>



template<typename T> const T* max(const T*, const T*); 

template <typename T> const T* max(const T[], unsigned);



int main()

{

    int a{4}, b{5};

    std::cout << *max(&a, &b) << std::endl;  // 5



    double numbers[]{3.4, 2.3, 6.1, 4.3};

    std::cout << *max(numbers, std::size(numbers)) << std::endl;   //6.1

}

template<typename T> const T* max(const T* a, const T* b)

{

    return *a > *b? a : b;

}



template <typename T>

const T* max(const T data[], unsigned size)

{

    const T* result {}; // если вектор пуст, то возвращается nullptr

    for(unsigned i{}; i < size; i++)

    {

        // если result не равен nullptr и *result меньше value

        if (!result || data[i] > *result) 

            result = &data[i];

    }

    return result;

}
```



объявлены два шаблона с одним именем `max`. первый сравнивает два объекта по адресам, полученным через указатели. второй проходит все элементы массива и выбирает наибольший. если массив пуст, возвращается `nullptr`. разрешение перегрузки различает шаблоны по списку параметров: два указателя либо массив и `unsigned`.

### использование нескольких параметров

у шаблона может быть несколько параметров типа. в примере перевода суммы между счетами тип идентификатора счёта и тип кода операции задаются независимо. для них подходят числа, строки и другие типы:

```cpp


#include <iostream>

 

template <typename T, typename K>

void transfer(T, T, K, int);

 

int main()

{

    transfer("id1234", "id5678", 2804, 5000);

}



template <typename T, typename K>

void transfer(T fromAccount, T toAccount, K code, int sum)

{

    std::cout << "From: " << fromAccount << "\nTo: " << toAccount

        << "\nSum: " << sum << "\nCode: " << code << std::endl;

}
```



в вызове `transfer("id1234", "id5678", 2804, 5000)` вместо `T` подставляется тип символьного массива строкового литерала. параметр передаётся по значению, поэтому массив вырождается в указатель и выведенный тип есть `const char*`. вместо `K` выводится `int`.

### выведение типов и decltype(auto)

тип возвращаемого значения иногда не записывают явно и поручают его вычисление компилятору. на месте возвращаемого типа тогда ставят `decltype(auto)`. спецификатор выводит тип по правилам `decltype` от выражения в операторе `return` и сохраняет ссылочность, которую обычный `auto` отбросил бы. функция среднего арифметического:

```cpp


#include <iostream> 



template <typename T> decltype(auto) average(const T (&data)[], unsigned size)

{

    T result {};

    for(unsigned i{}; i < size; i++)

    {

        result += data[i];

    }

    return result / size;

}



int main()

{

    int numbers[]{1, 3, 4, 5, 6};

    std::cout << average(numbers, std::size(numbers)) << std::endl;   // 3

}
```



### нетипизированные параметры

c++ позволяет определять шаблоны с нетипизированными параметрами, то есть с параметрами, не являющимися типами (non-type template parameter). как и у обычной функции, у шаблона могут быть параметры конкретных типов. значение такого параметра обязано быть константным выражением и подставляется во время компиляции:

```cpp


#include <iostream> 



template <typename T, unsigned N=1> void print(const T&);



int main()

{

    print<int, 4>(3);

}

// печатаем value N раз

template <typename T, unsigned N> void print(const T& value)

{

    for(unsigned i{}; i < N; i++)

    {

        std::cout << value << std::endl;

    }

}
```



шаблон `print` выводит значение типа `T` ровно `N` раз. параметр `N` имеет тип `unsigned` и по умолчанию равен 1. значение передают явным аргументом шаблона. четырежды печатается число 3:

```cpp
print<int, 4>(3);
```



тот же повтор можно получить обычным параметром функции, поэтому самостоятельный смысл нетипового параметра проявляется не в каждом шаблоне. он нужен там, где значение участвует в типе, например в границе массива. длина любого массива вычисляется так:

```cpp


#include <iostream>



template <typename T, size_t N> size_t size(const T (&data)[N]) { return N; }



int main()

{

    const int numbers1[]{1, 2, 3, 4, 5};

    const double numbers2[]{1.2, 2.3, 3.4};

    const char* people[] {"Sam", "Tom", "Bob", "Mike"};

    

    std::cout << "numbers1 size: " << size(numbers1) << std::endl;

    std::cout << "numbers2 size: " << size(numbers2) << std::endl;

    std::cout << "people size: " << size(people) << std::endl;

}
```



в более раннем листинге среднего значения размер массива передавался отдельным аргументом функции. нетиповой параметр снимает эту необходимость: граница массива входит в тип аргумента и выводится при вызове:

```cpp


#include <iostream> 



template <typename T, size_t N> T average(const T (&)[N]);



int main()

{

    int numbers1[]{1, 2, 3, 4, 5};

    std::cout << average(numbers1) << std::endl;   // 3



    double numbers2[]{1.1, 3.2, 4.3, 5.4, 6.5, 2.6};

    std::cout << average(numbers2) << std::endl;   // 3.85

}



template <typename T, size_t N> T average(const T (&data)[N])

{

    T result {};

    for(unsigned i{}; i < N; i++)

    {

        result += data[i];

    }

    return result / N;

}
```



параметр `N` имеет тип `size_t` и представляет размер массива. при вызове компилятор выводит `N` из типа аргумента, ссылки на массив известной границы `const T (&)[N]`.

### выведение типов и результата

начиная со стандарта c++20 параметры функции можно объявлять со спецификатором `auto`: тип выводится из переданного аргумента. тип результата выводится так же. для параметров и результата допустимы формы `auto*`, `auto&` и `const auto&`. запись с `auto` в списке параметров задаёт сокращённый шаблон функции: каждый такой `auto` вводит собственный параметр шаблона.

```cpp


#include <iostream>>



auto add(const auto& a, const auto& b)

{

    return a + b;

}



int main()

{

    const int n1{3};

    const int n2{4};

    std::cout << add(n1, n2) << std::endl;  // 7



    const double d1{3.3};

    const double d2{4.4};

    std::cout << add(d1, d2) << std::endl;  // 7.7

}
```
