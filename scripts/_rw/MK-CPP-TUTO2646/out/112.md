### добавление в строку

в конец строки другая строка добавляется методом `append()`. аргумент есть добавляемая строка. метод меняет левый объект и возвращает ссылку на него, поэтому вызовы можно соединить в цепочку:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string message{ "hello"};

    message.append(" ");  // добавляем пробел

    message.append("world");

	// можно добавить по цепочке

    // message.append(" ").append("world");

    std::cout << message << std::endl;    // hello world

}
```

### вставка строки

вставка одной строки в другую выполняется `insert()`. перегрузок несколько. простейшая принимает индекс вставки и вставляемую строку. символы с этого индекса и правее сдвигаются, длина приемника растет:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"insert into a text"};

    std::string str {"a string "};

    text.insert(7, str);

    std::cout << text << std::endl;  // insert a string into a text

}
```

в `text` с 7-го индекса вставляется `str`. после вызова `text` равна `insert a string into a text`.

вставляют и строковый литерал. перегрузка принимает `const char*`:

```cpp


std::string text {"Hello C++"};

text.insert(6, "C/");    // Hello C/C++
```

вставляют и фрагмент другой строки. дополнительные параметры задают индекс начала фрагмента и его длину:

```cpp


std::string text {"Langs: C++"};

std::string langs {"Java, C, C#"};

text.insert(6, langs, 5, 3);    // Langs: C, C++
```

в `text` попадает фрагмент `langs` из 3 символов, начиная с 5-го индекса. у строки `Java, C, C#` это подстрока ` C,`, и результат равен `Langs: C, C++`.

отдельная перегрузка вставляет один символ несколько раз: индекс, число повторений и сам символ.

```cpp


std::string text {"Number: 5678"};

text.insert(8, 5, '*');    // Number: *****5678
```

в `text` с 8-го индекса пять раз вставляется символ `*`.

### замена подстроки

фрагмент строки заменяется функцией `replace()`. перегрузок много. ниже те, которые встречаются чаще всего.

простая перегрузка принимает три параметра:

```cpp
std::string &std::string::replace(size_t _Off, size_t _Nx, const char *_Ptr)
```

первый параметр есть индекс, с которого начинается заменяемый фрагмент. второй есть число заменяемых символов. третий есть строка в стиле c, которая ставится на место фрагмента. длины фрагмента и замены могут различаться: строка удлиняется или укорачивается.

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Lang: Java"};

    text.replace(6, 4, "C++");    // Lang: C++

    std::cout << text << std::endl;  // Lang: C++

}
```

в `text` четыре символа с 6-го индекса заменяются на `C++`. из `Lang: Java` получается `Lang: C++`.

на место фрагмента можно поставить объект `string`, а не только литерал:

```cpp


std::string text {"Lang: Java"};

std::string lang {"C++"};

text.replace(6, 4, lang);    // Lang: C++
```

часто индекс заменяемой подстроки заранее неизвестен. его находят поиском, длину берут из найденных границ. в тексте `Hello, Tom!` подстрока `Tom` заменяется на `Alice`:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Hello, Tom!"};

    const std::string separators {" ,;:.\"!\n"}; // разделители слова

    size_t start {text.find("Tom")};            // находим позицию подстроки

    size_t end {text.find_first_of(separators, start + 1)}; // Находим конец подстроки

    if(end == std::string::npos) // если разделители слова не найдены

    {

        end = text.length();

    }

    text.replace(start, end - start, "Alice");    // заменяем подстроку



    std::cout << text << std::endl;  // Hello, Alice!

}
```

позиция первого символа `Tom` сохраняется в `start`. символ сразу после `Tom` ищется как первый разделитель из строки `separators` вызовом `find_first_of()`. если разделитель не найден, концом считается длина текста. `replace(start, end - start, "Alice")` подставляет новое имя на место найденного фрагмента.

одна и та же подстрока может встретиться несколько раз. все вхождения заменяют циклом:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Message to Tom: Hello, Tom!"};

    std::string old_str{"Tom"};  // какую подстроку заменить

    std::string new_str{"Alice"};  // на какую строку заменить

    size_t start {text.find(old_str)};            // находим позицию подстроки

    while (start != std::string::npos) // находим и заменяем все вхождения строки old_str

    {

        text.replace(start, old_str.length(), new_str); // Замена old_str на new_str

        start = text.find(old_str, start + new_str.length());

    }

    std::cout << text << std::endl;  // Message to Alice: Hello, Alice!

}
```

сначала `find` записывает в `start` индекс первого вхождения `old_str`. в цикле `replace` подставляет `new_str` вместо `old_str.length()` символов. следующий поиск начинается с `start + new_str.length()`, то есть сразу за только что записанной заменой, чтобы новое содержимое не было разобрано как очередное вхождение старой подстроки. когда вхождений больше нет, `start` получает `std::string::npos`, и цикл заканчивается.

еще одна перегрузка `replace()` заменяет фрагмент повторяющимся символом. параметры: индекс, число удаляемых символов, число повторений символа и сам символ.

```cpp


std::string text {"Phone: +12345678901"};

text.replace(9, 6, 5, '*'); // Phone: +1*****8901
```

в `text` шесть символов с 9-го индекса заменяются пятью символами `*`.

### удаление символов

удаление можно выразить через `replace()`, подставив пустую строку. удаляемый фрагмент заменяется пустым, соседние части склеиваются:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Hello Tom!"};

    const std::string empty;

    text.replace(5, 4, empty);      // Замена "Tom" на пустую строку

    std::cout << text << std::endl;  // Hello!

}
```

для удаления есть отдельная функция-член `erase()`. параметры: начальный индекс и число удаляемых символов.

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Hello Tom!"};

    text.erase(5, 4);       // удаляем 4 символа с 5-го индекса

    std::cout << text << std::endl;  // Hello!

}
```

все вхождения подстроки удаляются тем же циклом, что и при замене. на каждом шаге `erase` вырезает `to_delete.length()` символов с найденного индекса, затем поиск продолжается с этого же индекса, потому что на место удаленного фрагмента сдвинулся хвост строки:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Hello Tom! Good bye Tom..."};

    std::string to_delete{" Tom"};  // какую подстроку удалить

    size_t start {text.find(to_delete)};            // находим позицию подстроки

    while (start != std::string::npos) // находим и удаляем все вхождения to_delete

    {

        text.erase(start, to_delete.length()); 

        start = text.find(to_delete, start + to_delete.length());

    }

    std::cout << text << std::endl;  // Hello! Good bye...

}
```

перегрузка с одним индексом удаляет хвост, начиная с этого индекса, и оставляет префикс:

```cpp


std::string text {"Hello Tom"};

text.erase(5); // удаляем все кроме первых 5 символов - остается "Hello"
```

вызов без параметров удаляет все символы. строка становится пустой, емкость при этом реализация может сохранить:

```cpp


std::string text {"Hello Tom"};

text.erase(); // пустая строка
```

в c++20 добавлена свободная функция `std::erase()`. она удаляет все элементы, равные переданному значению. для `std::string` значение есть символ. это не член класса: член `erase` по символу все вхождения не удаляет. свободная функция объявлена в `<string>`.

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Hello Tom! Good bye Tom..."};

    std::erase(text, 'T');    // Удаляем символ T

    std::cout << text << std::endl;  // Hello om! Good bye om...

}
```

в примере из `text` удаляется символ `T`. регистр учитывается: `t` и `T` для этой операции различны.
