**наследование** (inheritance) связывает типы так, что производный класс получает члены базового и добавляет собственные. общее поведение задаётся в одном месте, копировать его в каждый класс не приходится.

ниже два класса: человек и сотрудник компании.

```cpp


class Person

{

public:

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

    std::string name;       //  имя

    unsigned age;           // возраст

};

class Employee

{

public:

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

    std::string name;       // имя

    unsigned age;           // возраст

    std::string company;    // компания

};
```

`Employee` повторяет `Person`: те же `name` и `age` и ту же `print`. дублирование расходится при любом изменении, править приходится оба класса. одновременно здесь выполняется отношение **is** («является»): сотрудник компании является человеком. у сотрудника есть признаки человека, имя и возраст, и собственный признак, компания. такое отношение выражают наследованием. класс `Employee` наследуют от класса `Person`.

```cpp


class Person

{

public:

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

    std::string name;       //  имя

    unsigned age;           // возраст

};

class Employee : public Person

{

public:

    std::string company;    // компания

};
```

после имени производного класса ставят двоеточие, спецификатор доступа и имя базового класса. `Person` в этом отношении базовый класс, его же называют суперклассом и родительским классом. `Employee` производный класс, его же называют подклассом и классом-наследником.

спецификатор доступа при базе определяет, как члены базового класса входят в интерфейс производного. в примере стоит **public**, и открытыми для производного класса становятся открытые члены базы:

```cpp


public:

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

    std::string name;       //  имя

    unsigned age;           // возраст
```

открытое наследование оставляет открытые члены базового класса открытыми и для клиентов производного. `name`, `age` и `print` вызываются у объекта `Employee` так же, как у объекта `Person`.

если спецификатор не указан, для `class` наследование закрытое, действует **private**. открытые члены `Person` остаются доступны внутри функций `Employee`, в открытый интерфейс `Employee` они при этом не входят. внешний код через объект `Employee` к `name`, `age` и `print` обратиться не сможет. преобразование указателя `Employee*` к `Person*` снаружи тоже закрыто, и для клиентского кода модели «сотрудник является человеком» такое наследование не даёт. для отношения **is** записывают **public**.

после введения базового класса из `Employee` убирают члены, которые уже есть в `Person`. оба класса в программе:

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

    std::string name;       //  имя

    unsigned age;           // возраст

};

class Employee : public Person

{

public:

    std::string company;    // компания

};



int main()

{

    Person tom;

    tom.name = "Tom";

    tom.age = 23;

    tom.print();    // Name: Tom       Age: 23

 

    Employee bob;

    bob.name = "Bob";

    bob.age = 31;

    bob.company = "Microsoft";

    bob.print();    // Name: Bob       Age: 31

}
```

через объект `Employee` доступны все открытые члены `Person`. производный объект содержит подобъект базового класса: члены `Person` лежат в части объекта `Employee`.

### конструкторы

данные делаем закрытыми и добавляем конструкторы. конструкторы сами по себе не наследуются: объявление конструктора `Person` в `Employee` автоматически не появляется. если у базового класса есть только конструкторы с параметрами и нет конструктора по умолчанию, производный класс в своём конструкторе явно вызывает один из них. иначе компилятор пытается вызвать отсутствующий конструктор по умолчанию базы, и программа некорректна.

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    Person(std::string name, unsigned age)

    {

        this->name = name;

        this->age = age;

    }

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

private:

    std::string name;       //  имя

    unsigned age;           // возраст

};

class Employee: public Person

{

public:

    Employee(std::string name, unsigned age, std::string company): Person(name, age)

    {

        this->company = company;

    }

private:

    std::string company;    // компания

};



int main()

{

    Person person {"Tom", 38};

    person.print();     // Name: Tom       Age: 38



    Employee employee {"Bob", 42, "Microsoft"};

    employee.print();   // Name: Bob       Age: 42

}
```

после списка параметров конструктора производного класса через двоеточие записывают вызов конструктора базы. в него передают параметры `name` и `age`.

```cpp


Employee(std::string name, unsigned age, std::string company): Person(name, age)

{

    this->company = company;

}
```

пропуск вызова конструктора базы здесь был бы ошибкой: конструктора `Person` без параметров нет, и подобъект базы нечем инициализировать.

консольный вывод программы:

```bash


Name: Tom       Age: 38

Name: Bob       Age: 42
```

в строке

```cpp
Employee employee {"Bob", 42, "Microsoft"};
```

сначала отрабатывает конструктор базового класса `Person`. он получает аргументы `"Bob"` и 42 и записывает имя и возраст в подобъект базы. затем выполняется тело конструктора `Employee` и записывает компанию. порядок фиксирован: базовый подобъект инициализируется до тела производного конструктора, потому что тело производного уже может обращаться к членам базы.

тот же конструктор записывают списком инициализации, сразу передавая аргумент в член `company`.

```cpp


Employee(std::string name, unsigned age, std::string company): Person(name, age), company(company)

{

}
```

### подключение конструктора базового класса

в примерах выше конструктор `Employee` отличается от конструктора `Person` параметром `company`, остальные параметры уходят в `Person`. если набор параметров производного класса совпадает с набором базового, отдельный конструктор можно не писать, а подключить конструкторы базы.

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    Person(std::string name, unsigned age)

    {

        this->name = name;

        this->age = age;

    }

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

private:

    std::string name;       //  имя

    unsigned age;           // возраст

};

class Employee: public Person

{

public:

    using Person::Person;   // подключаем конструктор базового класса

};

 

int main()

{

    Person person {"Tom", 38};

    person.print();     // Name: Tom       Age: 38

 

    Employee employee {"Bob", 42};

    employee.print();   // Name: Bob       Age: 42

}
```

в `Employee` конструкторы `Person` подключаются объявлением **using**.

```cpp
using Person::Person;
```

у `Employee` появляются конструкторы с теми же параметрами, что у `Person`. наследующий конструктор инициализирует базовый подобъект, а члены производного класса получают инициализацию по умолчанию. в этом примере собственных членов у `Employee` нет, поэтому двух параметров достаточно. вызов для создания объекта `Employee`:

```cpp
Employee employee {"Bob", 42};
```

### определение конструкторов копирования

конструктор копирования производного класса инициализирует и базовый подобъект. для этого в списке инициализации вызывают конструктор копирования базы. такие конструкторы добавляют в `Person` и в `Employee`.

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    // конструктор копирования класса Person

    Person(const Person& person)

    {

        name = person.name;

        age = person.age;

    }

    Person(std::string name, unsigned age)

    {

        this->name = name;

        this->age = age;

    }

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

};

class Employee: public Person

{

public:

    Employee(std::string name, unsigned age, std::string company): Person(name, age)

    {

        this->company = company;

    }

    // конструктор копирования класса Employee

    // вызываем конструктор копирования базового класса

    Employee(const Employee& employee): Person(employee)

    { 

        company=employee.company;

    }

private:

    std::string company;

};



int main()

{

    Employee tom{"Tom", 38, "Google"};

    Employee tomas{tom};    // вызываем конструктор копирования

    tomas.print();  // Name: Tom       Age: 38

}
```

в конструкторе копирования `Employee` вызывается конструктор копирования `Person`.

```cpp


Employee(const Employee& employee): Person(employee)

{ 

    company=employee.company;

}
```

в конструктор `Person` передаётся объект `employee`. ссылка `const Person&` связывается с производным объектом: при открытом наследовании `Employee` преобразуется к `Person`. конструктор базы копирует `name` и `age`. тело конструктора `Employee` копирует `company`. если вызов `Person(employee)` опустить, скопировать подобъект базы будет нечем: конструктора `Person` по умолчанию в этом классе нет, и программа не скомпилируется.

### наследование деструкторов

уничтожение объекта производного класса вызывает и деструктор производного класса, и деструктор базового. оба деструктора определены ниже.

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    Person(std::string name, unsigned age)

    {

        this->name = name;

        this->age = age;

		std::cout << "Person created" << std::endl;

    }

    ~Person()

    {

        std::cout << "Person deleted" << std::endl;

    }

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

};

class Employee: public Person

{

public:

    Employee(std::string name, unsigned age, std::string company): Person(name, age)

    {

        this->company = company;

		std::cout << "Employee created" << std::endl;

    }

    ~Employee()

    {

        std::cout << "Employee deleted" << std::endl;

    }

private:

    std::string company;

};



int main()

{

    Employee tom{"Tom", 38, "Google"};

    tom.print();

}
```

оба деструктора печатают сообщение. в `main` создаётся один объект `Employee`, а при завершении его времени жизни вызываются оба деструктора.

```bash


Person created

Employee created

Name: Tom       Age: 38

Employee deleted

Person deleted
```

порядок виден по выводу. при создании `Employee` сначала выполняется конструктор `Person`, затем конструктор `Employee`. при уничтожении порядок обратный: сначала деструктор `Employee`, затем деструктор `Person`. тело производного деструктора ещё видит живой базовый подобъект и может пользоваться его членами. освобождение памяти и других ресурсов в деструкторе базы выполняется при уничтожении любого производного объекта. отдельно вызывать деструктор базы не нужно, повторный явный вызов уничтожил бы подобъект второй раз.

### запрет наследования

наследование от класса иногда закрывают. спецификатор **final** у класса запрещает использовать его как базу.

```cpp


class Person final

{

};
```

унаследовать другой класс от `Person` после этого нельзя. объявление производного класса, как в следующем фрагменте, не компилируется: класс `Person` помечен `final` и базой быть не может.

```cpp


class Employee : public Person

{

};
```
