при определении шаблона класса компилятор генерирует по нему классы для конкретных наборов типов. то же определение можно написать вручную для фиксированного набора параметров. такое определение называется специализацией шаблона. специализация бывает полной и частичной. при сопоставлении выбирается наиболее специализированное определение, подходящее под аргументы.

### полная специализация шаблона

при полной специализации задают значения всех параметров. для этого набора аргументов компилятор использует написанную специализацию и не инстанцирует первичный шаблон.

```cpp


#include <iostream>

#include <string>

  

// шаблон класса

template <typename T>

class Person {

public:

    Person(std::string name) : name{name}

    { }

    void setId(T value) { id = value;}

    void print() const 

    {

        std::cout << "Id: " << id << "\tName: " << name << std::endl;

    }

private:

    T id;

    std::string name;

};



// полная специализация шаблона для типа unsigned

template <>

class Person<unsigned> {

public:

    Person(std::string name) : name{name}

    { 

        id = ++count;

    }

    void print() const 

    {

        std::cout << "Id: " << id << "\tName: " << name << std::endl;

    }

private:

    static inline unsigned count{};

    unsigned id;

    std::string name;

};



int main()

{

	// объекты создаются на основе полной специализации шаблона

    Person<unsigned> tom{"Tom"};

    tom.print();    // Id: 1    Name: Tom



    Person<unsigned> sam{"Sam"};

    sam.print();    // Id: 2    Name: Sam



	// объект создается на основе класса, генерируемого компилятором по шаблону

    Person<std::string> bob{"Bob"};    // T - std::string

    bob.setId("id1345");

    bob.print();    // Id: id1345  Name: Bob

}
```



сначала объявляют первичный шаблон. здесь это `Person` с одним параметром, и этот параметр задаёт тип поля `id`.

далее идёт полная специализация:

```cpp


template <>

class Person<unsigned> {

	public:

    Person(std::string name) : name{name}

    { 

        id = ++count;

    }

    void print() const 

    {

        std::cout << "Id: " << id << "\tName: " << name << std::endl;

    }

private:

    static inline unsigned count{};

    unsigned id;

    std::string name;

};
```



специализация полная: единственному параметру сопоставлено значение `unsigned`. после `template` стоят пустые угловые скобки, а список аргументов записан у имени: `Person<unsigned>`. эта специализация выбирается только когда аргумент шаблона есть `unsigned`.

члены специализации не обязаны совпадать с членами первичного шаблона. специализация может изменить, добавить или опустить члены без ограничений со стороны языка. в примере `id` имеет тип `unsigned` и в конструкторе получает значение из добавленной статической переменной `count`. спецификатор `inline` у статического члена, инициализированного внутри класса, соответствует правилу c++17 и позволяет поместить определение в заголовок. `count` увеличивается при каждом новом объекте, поэтому очередной `Person<unsigned>` получает `id` на единицу больше предыдущего. функции `setId` в специализации нет: идентификатор назначается автоматически, и отдельный установщик не требуется.

в `main` специализация используется так:

```cpp


Person<unsigned> tom{"Tom"};

tom.print();    // Id: 1    Name: Tom



Person<unsigned> sam{"Sam"};

sam.print();    // Id: 2    Name: Sam
```



аргумент шаблона `unsigned`, поэтому выбирается написанная специализация, а не инстанцирование первичного шаблона.

для остальных аргументов компилятор инстанцирует первичный шаблон:

```cpp


Person<std::string> bob{"Bob"};    // T - std::string

bob.setId("id1345");

bob.print();    // Id: id1345  Name: Bob
```



аргумент `std::string`, поле `id` имеет строковый тип, значение задаётся через `setId`, в которую передаётся строка.

### частичная специализация

при частичной специализации значения задают не для всех параметров. оставшиеся параметры по-прежнему указываются в точке использования или выводятся. частичная специализация определена для шаблонов классов. различное поведение шаблона функции при тех же целях выражают перегрузкой.

```cpp


#include <iostream> 

#include <string>

  

// шаблон класса

template <typename T, typename K>

class Person {

public:

    Person(std::string name, K phone) : name{name}, phone{phone}

    { }

    void setId(T value) { id = value;}

    void print() const 

    {

        std::cout << "Id: " << id << "\tName: " << name << "\tPhone: " << phone << std::endl;

    }

private:

    T id;

    std::string name;

    K phone;

};



// частичная специализация шаблона для типа unsigned

template <typename K>

class Person<unsigned, K> {

public:

    Person(std::string name, K phone) : name{name}, phone{phone}

    { 

        id = ++count;

    }

    void print() const 

    {

        std::cout << "Id: " << id << "\tName: " << name << "\tPhone: " << phone << std::endl;

    }

private:

    static inline unsigned count{};

    unsigned id;

    std::string name;

    K phone;

};



int main()

{

    Person<std::string, std::string> bob{"Bob", "+1234567688"};    // T - std::string

    bob.setId("13");

    bob.print();    // Id: 13  Name: Bob       Phone: +1234567688



    Person<unsigned, std::string> tom{"Tom", "+4444444444"};

    tom.print();    // Id: 1   Name: Tom       Phone: +4444444444



    Person<unsigned, std::string> sam{"Sam", "+555555555"};

    sam.print();    // Id: 2   Name: Sam       Phone: +555555555

}
```



первичный шаблон имеет два параметра, `T` и `K`:

```cpp


template <typename T, typename K>

class Person {
```



`T` задаёт тип переменной `id`, `K` задаёт тип номера телефона в поле `phone`. номер можно передать строкой или числом, то есть последовательностью цифр.

за первичным шаблоном идёт частичная специализация для типа `unsigned`:

```cpp


template <typename K>

class Person<unsigned, K> {

	// ..........

};
```



зафиксирован только `T`: он равен `unsigned`. параметр `K` остаётся неизвестным. после ключевого слова `template` перечисляют незафиксированные параметры, здесь это `K`.

угловые скобки у имени, в записи `Person<unsigned, K>`, показывают, как сопоставляются параметры первичного шаблона. длина списка совпадает с первичным шаблоном. первый аргумент специализации равен `unsigned`. второй записан тем же именем `K`, что и соответствующий параметр исходного шаблона.

если первый аргумент шаблона равен `unsigned`, для создания класса выбирается частичная специализация:

```cpp


Person<unsigned, std::string> tom{"Tom", "+4444444444"};

tom.print();    // Id: 1   Name: Tom       Phone: +4444444444



Person<unsigned, std::string> sam{"Sam", "+555555555"};

sam.print();    // Id: 2   Name: Sam       Phone: +555555555
```



если первый аргумент отличен от `unsigned`, компилятор полностью инстанцирует первичный шаблон:

```cpp


Person<std::string, std::string> bob{"Bob", "+1234567688"};    // T - std::string

bob.setId("13");

bob.print();    // Id: 13  Name: Bob       Phone: +1234567688
```
