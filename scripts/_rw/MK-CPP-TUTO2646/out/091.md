при наследовании от класса, порождённого шаблоном, аргументы базового шаблона должны быть известны в точке объявления производного класса. производный класс можно тоже объявить шаблоном и передать его параметры в базовый шаблон:

```cpp


#include <iostream> 

#include <string>

  

template <typename T>

class Person {

public:

    Person(T id, std::string name) : id{id}, name{name} { }

    void print() const 

    {

        std::cout << "Id: " << id << "\tName: " << name << std::endl;

    }

protected:

    T id;

    std::string name;

};



template <typename T>

class Employee: public Person<T> {

public:

    Employee(T id, std::string name, std::string company) : Person<T>{id, name}, company{company} { }

    void print() const 

    {

        Person<T>::print();

        std::cout << Person<T>::name << " works in " << company << std::endl;

    }

private:

    std::string company;

};



int main()

{

    Employee<unsigned> bob{123, "Bob", "Google"};

    bob.print();    // Id: 123 Name: Bob

                    // Bob works in Google

}
```



в начале определён шаблон базового класса `Person`. параметр `T` задаёт тип переменной `id`. далее определён шаблон `Employee`, который наследует `Person<T>`:

```cpp


template <typename T>

class Employee: public Person<T>
```



аргумент базового шаблона совпадает со значением, которое определяется шаблоном `Employee`.

обращение к членам базового класса записывают с квалификацией `Person<T>`, то есть с явным аргументом шаблона `Person`. базовый класс зависит от параметра `T`, и при поиске неквалифицированных имён внутри шаблона зависимые базы не просматриваются. квалификация (либо обращение через `this`) делает имя зависимым и откладывает поиск до инстанцирования:

```cpp


Person<T>{id, name}   // вызов конструктора

Person<T>::print();   // вызов функции print

Person<T>::name       // обращение к переменной name базового класса Person
```



далее объект `Employee` типизируют конкретным типом, и тот же тип применяется к функциональности базового класса:

```cpp
Employee<unsigned> bob{123, "Bob", "Google"};
```



второй вариант наследования фиксирует типы базового класса уже в точке наследования:

```cpp


#include <iostream> 

#include <string>

  

template <typename T>

class Person {

public:

    Person(T id, std::string name) : id{id}, name{name} { }

    void print() const 

    {

        std::cout << "Id: " << id << "\tName: " << name << std::endl;

    }

protected:

    T id;

    std::string name;

};



class Employee: public Person<unsigned> {

public:

    Employee(unsigned id, std::string name, std::string company) : Person{id, name}, company{company} { }

    void print() const 

    {

        Person::print();

        std::cout << name << " works in " << company << std::endl;

    }

private:

    std::string company;

};



int main()

{

    Employee bob{123, "Bob", "Google"};

    bob.print();    // Id: 123 Name: Bob

                    // Bob works in Google

}
```



`Employee` здесь обычный класс, не шаблон. он наследует `Person<unsigned>`, поэтому в базовой части параметр `T` закреплён как `unsigned`. база не зависит от параметров производного класса, и члены доступны без подстановки параметра шаблона: в листинге вызов записан как `Person::print()`, а поле `name` используется неквалифицированным именем.
