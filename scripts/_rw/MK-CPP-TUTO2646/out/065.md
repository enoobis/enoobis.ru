помимо классов собственный тип вводят **структурой**. конструкция унаследована c++ от c и в c++ является классом с другими правилами по умолчанию. структура, как и класс, описывает сущность: у неё бывают члены-данные, функции, конструкторы и деструкторы. на практике структурой оформляют набор открытых данных, а класс оставляют для типа с инвариантом и закрытым представлением.

структура вводится служебным словом **struct**. форма определения:

```cpp


struct имя_структуры

{

	компоненты_структуры

};
```

`имя_структуры` является идентификатором и подчиняется тем же правилам, что имя переменной. в фигурных скобках записывают компоненты: переменные и функции.

простейшая структура:

```cpp


#include <iostream>

#include <string>



struct person

{

	unsigned age;

	std::string name;

};



int main()

{

	person tom;

	tom.name = "Tom";

	tom.age = 34;

	std::cout << "Name: " << tom.name << "\tAge: " << tom.age << std::endl;

}
```

структура `person` содержит два члена: `name` типа `std::string` и `age` типа `unsigned`.

после определения структуру используют как тип. объект структуры является переменной этого типа. к членам обращаются операцией «точка»: читают значение или записывают новое.

```cpp
имя_переменной_структуры.имя_элемента
```

по устройству структура совпадает с классом: обе формы задают пользовательский тип. расхождение в правилах по умолчанию. член `struct` без спецификатора доступа открыт (**public**). член `class` без спецификатора закрыт (**private**). то же умолчание действует для наследования: база `struct` без спецификатора наследуется открыто, база `class` закрыто. если спецификаторы выписаны явно, `struct` и `class` дают один и тот же тип с точностью до имени.

структуру можно инициализировать списком значений.

```cpp
person tom{ 34, "Tom" };
```

инициализация агрегата устроена по тому же принципу, что инициализация массива: в фигурных скобках значения идут в порядке объявления членов. в `person` первым объявлен `age` типа `unsigned`, поэтому первое значение в скобках число, далее строка для `name`. такая инициализация законна, пока тип остаётся агрегатом. агрегатом тип перестаёт быть, когда появляются пользовательские конструкторы, закрытые или защищённые нестатические данные, виртуальные функции, а также виртуальные, закрытые или защищённые базовые классы. с появлением пользовательского конструктора объект создаётся уже им.

любой класс можно записать как структуру и наоборот, если явно расставить спецификаторы доступа. исходный класс:

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    Person(std::string name, unsigned age): name{name}, age{age}

    { }

    void print()

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

};

 

int main()

{

    Person bob{"Bob", 42};

    bob.print();

}
```

класс описывает человека и содержит закрытые данные, открытый конструктор и открытую `print`. ту же сущность задаёт структура.

```cpp


#include <iostream>

#include <string>



struct person

{

public:

    person(std::string name, unsigned age): name{name}, age{age}

    { 

    }

    void print()

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

};

 

int main()

{

    person bob{"Bob", 42};

    bob.print();

}
```

результат программы от замены `class` на `struct` не меняется: спецификаторы **public** и **private** выписаны явно, и умолчание, которым `struct` отличается от `class`, в этом тексте не участвует.

структуры применяют к данным, у которых есть только открытые атрибуты и нет инварианта, который нужно защищать функциями доступа. такова структура `person` в начале лекции. такие типы называют **агрегатными классами** (aggregate classes). для них работает агрегатная инициализация, и клиентский код обращается к членам напрямую.
