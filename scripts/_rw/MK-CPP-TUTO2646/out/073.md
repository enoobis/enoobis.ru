динамическое приведение типов выполняется во время выполнения программы. статическое приведение динамический тип на этапе выполнения не проверяет. для динамического приведения применяется функция `dynamic_cast<>()`. как и для `static_cast`, в угловых скобках указывается тип, к которому выполняется преобразование, в круглые скобки передаётся преобразуемый объект:

```cpp
dynamic_cast<тип_в_который_преобразуем>(преобразуемый_объект)
```

эту функцию можно применять только к указателям и ссылкам на полиморфные типы классов, которые содержат хотя бы одну виртуальную функцию. причина в том, что только полиморфные классы несут информацию о динамическом типе, которая необходима функции `dynamic_cast` для проверки правильности преобразования. в типичной реализации эти сведения доступны через таблицу виртуальных функций. типы, между которыми выполняется преобразование, должны быть указателями или ссылками на классы в одной иерархии классов.

есть два вида динамического приведения. первый вид представляет преобразование от указателя на базовый класс к указателю на производный класс, так называемое нисходящее преобразование, или downcast. базовые классы в иерархии помещаются вверху, а производные внизу, поэтому преобразование идёт сверху вниз. второй вид представляет преобразование между базовыми типами в одной иерархии при множественном наследовании, кросскаст (crosscast).

следующая программа показывает оба класса-источника и класс, который их объединяет:

```cpp


#include <iostream>

#include <string>



class Book      // класс книги

{

public:

    Book(std::string title, unsigned pages): title{title}, pages{pages}{}

    std::string getTitle() const {return title;}

    unsigned getPages() const {return pages;}

    virtual void print() const  

    {

        std::cout << title << ". Pages: " << pages << std::endl;

    }

private:

    std::string title;  // название книги

    unsigned pages;     // количество страниц

};

class File  // класс электронного файла

{

public:

    File(unsigned size): size{size}{}

    unsigned getSize() const {return size;}

    virtual void print() const  

    {

        std::cout << "Size: " << size << std::endl;

    }

private:

    unsigned size;     // размер в мегабайтах

};



class Ebook : public Book, public File     // класс электронной книги

{

public:

    Ebook(std::string title, unsigned pages, unsigned size): Book{title, pages}, File{size}{}

    void print() const override

    {

        std::cout << getTitle() << "\tPages: " << getPages() << "\tSize: " << getSize() << "Mb" << std::endl;

    }

};



int main()

{

    Ebook cppbook{"About C++", 350, 6};

    Book* book = &cppbook;  // указывает на объект Ebook

    // динамическое преобразование из Book в Ebook

    Ebook* ebook{dynamic_cast<Ebook*>(book)};

    ebook->print();  // About C++       Pages: 350      Size: 6Mb

}
```

класс `Book` представляет книгу с переменными `title` и `pages` для хранения названия книги и количества страниц. класс `File` представляет электронный файл, в котором для хранения размера определено поле `size`. класс электронной книги `Ebook` наследуется от обоих классов.

чтобы динамическое преобразование было возможно, базовые классы определяют виртуальную функцию `print`. наличие виртуальной функции делает `Book` и `File` полиморфными, и `dynamic_cast` может установить динамический тип объекта.

в функции `main` создаётся один объект типа `Ebook`, и его адрес передаётся указателю `book`, который представляет базовый тип `Book*`. поскольку этот указатель хранит адрес объекта `Ebook`, его можно привести к указателю на `Ebook`:

```cpp


Ebook* ebook{dynamic_cast<Ebook*>(book)};

ebook->print();  // About C++       Pages: 350      Size: 6Mb
```

далее через указатель можно обращаться к функционалу класса `Ebook`.

в этом примере динамическое преобразование не меняет результат вызова `print`: у указателя `book` можно вызвать функцию `print`, и за счёт виртуальности функции получится тот же самый результат. преобразование нужно, если необходимо обратиться к членам производного класса, которые не определены в базовом. класс `Book` не имеет функции `getSize()`, и чтобы обратиться к ней, может потребоваться преобразование к типу, где эта функция объявлена.

в примере выше было нисходящее преобразование, downcast. теперь crosscast:

```cpp


int main()

{

    Ebook cppbook{"About C++", 350, 6};

    Book* book = &cppbook;  // указывает на объект Ebook

    // динамическое преобразование из Book в File - crosscast

    File* file{dynamic_cast<File*>(book)};

    file->print();  // About C++       Pages: 350      Size: 6Mb

}
```

преобразование из указателя на `Book` в указатель на `File` является кросскастом и здесь возможно, потому что указатель `book` хранит адрес объекта `Ebook`, который также наследуется от `File`. при успехе `dynamic_cast` проверяет динамический тип и сдвигает адрес к нужному подобъекту. указатель `File*` может не совпадать с исходным `Book*`, если подобъект `File` расположен в объекте со смещением. одна функция `print` класса `Ebook` переопределяет виртуальные `print` обоих базовых классов, поэтому вызов через `File*` попадает в реализацию `Ebook`.

подобные преобразования не всегда выполняются успешно. в этом случае функция `dynamic_cast()` возвращает указатель `nullptr`, и после получения результата его можно проверить на это значение:

```cpp


int main()

{

    Book cppbook{"About C++", 350};

    Book* book = &cppbook;  // указывает на объект Book

    // динамическое преобразование из Book в File - crosscast

    File* file{dynamic_cast<File*>(book)};



    // проверяем результат

    if(file)    // если file !=nullptr

    {

        file->print();

    }

    else

    {

        std::cout << "The book is not a file" << std::endl;

    }

}
```

указатель `book` хранит адрес объекта `Book` и поэтому не может быть преобразован к типу указателя на `File`. вызов `dynamic_cast<File*>(book)` возвратит `nullptr`. после этого результат проверяется, и в зависимости от результата проверки выполняются определённые действия.

### константность

если преобразуемый указатель является указателем на константу, то тип указателя, к которому выполняется приведение, также должен представлять указатель на константу:

```cpp


int main()

{

    const Ebook cppbook{"About C++", 350, 6};

    const Book* book = &cppbook;  // указатель на константу

    // преобразование в указатель на константу

    const Ebook* file{dynamic_cast<const Ebook*>(book)};

    file->print();

}
```

`dynamic_cast` константность сохраняет. снять её этим оператором нельзя.

если необходимо выполнить приведение из указателя на константу в обычный указатель, не на константу, то сначала надо выполнить приведение к указателю того же типа, что и исходный, с помощью функции `const_cast()`:

```cpp


int main()

{

    const Ebook cppbook{"About C++", 350, 6};

    const Book* const_book = &cppbook;  // указатель на константу

    // преобразование из указателя на константу в обычный указатель того же типа

    Book* book {const_cast<Book*>(const_book)};

    // преобразуем указатели

    Ebook* file{dynamic_cast<Ebook*>(book)};

    file->print();

}
```

`const_cast` меняет квалификатор типа и динамический тип не проверяет. если объект объявлен константным, запись в него после снятия константности даёт неопределённое поведение. в примере вызывается константная функция `print`, состояние объекта не изменяется. к полученному неконстантному указателю затем применяется `dynamic_cast`.

### преобразование ссылок

функция `dynamic_cast` также может применяться к ссылкам, из ссылки на базовый тип в ссылку на производный тип:

```cpp


int main()

{

    Ebook cppbook{"About C++", 350, 6};

    Book& book {cppbook};  // ссылка на Ebook

    // преобразуем в ссылку на Ebook

    Ebook& file{dynamic_cast<Ebook&>(book)};

    file.print();

}
```

ссылка `book` в реальности ссылается на объект `Ebook`, поэтому эту ссылку можно преобразовать в ссылку `Ebook&`. если ссылка `book` не ссылается на объект `Ebook`, преобразование устроено иначе:

```cpp


int main()

{

    Book cppbook{"About C++", 350};

    Book& book {cppbook};  // ссылка на Book

    // преобразуем в ссылку на Ebook

    Ebook& file{dynamic_cast<Ebook&>(book)};  // ! Ошибка std::bad_cast

    file.print();

}
```

при преобразовании возникает ошибка, и программа завершает своё выполнение. со ссылкой результат нельзя проверить на `nullptr`: ссылка обязана обозначать объект. при неудачном `dynamic_cast` к ссылке генерируется исключение `std::bad_cast`. чтобы избежать некорректного преобразования ссылок, приведение выполняется к соответствующему типу указателя:

```cpp


int main()

{

    Book cppbook{"About C++", 350};

    Book& book {cppbook};  // ссылка на Book

    // преобразуем в ссылку на указатель на Ebook

    Ebook* file{dynamic_cast<Ebook*>(&book)};

    if(file)

        file->print();

    else

        std::cout << "Object is not a file" << std::endl;

}
```

адрес объекта передаётся в `dynamic_cast`, результатом служит указатель, и проверка на `nullptr` отделяет успешное приведение от неуспешного.

### преобразование smart-указателей

для динамического преобразования смарт-указателей `std::shared_ptr` применяется функция `std::dynamic_pointer_cast()`:

```cpp


int main()

{

    // указатель std::shared_ptr<Book> указывает на объект Ebook

    std::shared_ptr<Book> book{std::make_shared<Ebook>("About C++", 350, 6)};

    // динамическое преобразование из Book в Ebook

    std::shared_ptr<Ebook> ebook{std::dynamic_pointer_cast<Ebook>(book)};

    ebook->print();  // About C++       Pages: 350      Size: 6Mb

}
```

указатель `book`, который представляет тип `std::shared_ptr<Book>`, в реальности указывает на объект `Ebook`. поэтому его можно привести к типу указателя `std::shared_ptr<Ebook>`. при успехе новый `std::shared_ptr` разделяет владение с исходным: счётчик ссылок общий, а хранимый адрес при необходимости скорректирован к подобъекту нужного типа. если преобразование невозможно, функция возвращает пустой указатель, который сравнивается с `nullptr`:

```cpp


int main()

{

    // указатель std::shared_ptr<Book> указывает на объект Ebook

    std::shared_ptr<Book> book{std::make_shared<Book>("About Java", 280)};

    // динамическое преобразование из Book в Ebook

    std::shared_ptr<Ebook> ebook{std::dynamic_pointer_cast<Ebook>(book)};

    if(ebook)   // if (ebook != nullptr)

    {

        ebook->print();

    }

    else

    {

        std::cout << "Object is not e-book" << std::endl;

    }

}
```

указатель `book` указывает на объект `Book`. поэтому при преобразовании в указатель на объект `Ebook` функция возвратит `nullptr`.
