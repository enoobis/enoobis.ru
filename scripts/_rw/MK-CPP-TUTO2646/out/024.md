у каждого массива есть размерность. число размерностей совпадает с числом пар квадратных скобок. массив с одной парой скобок:

```cpp


int numbers[3];
```

массив `numbers` имеет одну размерность, то есть он одномерный. число элементов на размерность не влияет: и три элемента, и три тысячи остаются одним рядом значений, который представляют строкой или столбцом.

помимо одномерных массивов в c++ есть многомерные. элемент такого массива сам является массивом, и элементы этого массива тоже могут быть массивами. чаще всего встречаются двухмерные и трёхмерные массивы. двухмерный массив чисел:

```cpp


int numbers[3][2];
```

у `numbers` две размерности, две пары квадратных скобок: первая равна 3, вторая равна 2. объект состоит из трёх элементов, и каждый элемент есть массив из двух `int`. в памяти c++ хранит такой массив непрерывно, по строкам: последняя размерность меняется быстрее всего, поэтому `numbers[i][0]` и `numbers[i][1]` лежат рядом. тот же объект удобно представлять таблицей, где первая размерность задаёт число строк, а вторая задаёт число столбцов.

тем же способом объявляют массивы с большим числом размерностей, например трёхмерный. каждая следующая пара скобок добавляет ещё один уровень вложенных массивов:

```cpp


int numbers[3][2][2];
```

многомерный массив инициализируют так же, как одномерный, в том числе нулями. пустой инициализатор обнуляет все скалярные элементы:

```cpp
int numbers[3][2] {};
```

можно задать и индивидуальное значение каждого элемента. массив `numbers` состоит из трёх строк, и каждая строка есть массив из двух столбцов. вложенные фигурные скобки соответствуют этой структуре:

```cpp


int numbers[3][2] 

{ 

    {1, 2},     // первая строка

    {4, 5},     // вторая строка

    {7, 8}      // третья строка

};
```

вложенные фигурные скобки очерчивают элементы каждого подмассива. тот же массив представляется таблицей:

| 1 | 2 |
| --- | --- |
| 4 | 5 |
| 7 | 8 |

допустима инициализация только части элементов:

```cpp
int numbers[3][2] { {1, 2}, {}, {7} };
```

значения получают первые элементы соответствующих подмассивов, остальные инициализируются нулями. пустая пара скобок задаёт подмассив из нулей, а список `{7}` задаёт строку, в которой первый столбец равен 7, а второй равен 0.

для одномерного массива компилятор выводит длину из числа инициализаторов. при инициализации многомерного массива тоже можно опустить длину, но только первую размерность, то есть первые квадратные скобки. размеры внутренних массивов нужны, чтобы вычислить шаг строки: смещение элемента `[i][j]` равно `i * число_столбцов + j`, и без второй размерности этот шаг неизвестен.

```cpp


int numbers[][2] { {1, 2}, {3, 4}, {5, 6} };
```

#### обращение к элементам

для обращения к элементу многомерного массива нужен индекс по каждой размерности. у двухмерного массива указывают оба индекса. первый выбирает подмассив (строку), второй выбирает элемент внутри него (столбец):

```cpp


#include <iostream>

 

int main()

{   

    int nums[3][2] 

    { 

        {1, 2}, 

        {3, 4}, 

        {5, 6} 

    };

    // получаем значение элемента

    int n = nums[1][0];     // вторая строка, первый столбец

    std::cout << "n =" << n << std::endl;       // n = 3



    std::cout << "nums[2][1] = " << nums[2][1] << std::endl;   // nums[2][1] = 6 

    // изменяем значение элемента

    nums[2][1] = 123;       // третья строка, второй столбец

    std::cout << "nums[2][1] = " << nums[2][1] << std::endl;   // nums[2][1] = 123 

}
```

индексы массива `nums` раскладываются так:

|  | nums[0][0] | nums[0][1] |
| --- | --- | --- |
| nums[0] | 1 | 2 |
|  | nums[1][0] | nums[1][1] |
| nums[1] | 3 | 4 |
|  | nums[2][0] | nums[2][1] |
| nums[2] | 5 | 6 |

выражение `nums[1][0]` обращается к первому элементу второго подмассива, то есть к первому столбцу второй строки.

#### перебор многомерного массива

двухмерный массив перебирают вложенными циклами. внешний цикл идёт по строкам, внутренний по столбцам:

```cpp


#include <iostream>



int main()

{

	const int rows = 3, columns = 2;

	int numbers[rows][columns]  { {1, 2}, {3, 4}, {5, 6} };

	for(int i=0; i < rows; i++)

	{

		for(int j=0; j < columns; j++)

		{

			std::cout << numbers[i] [j] << "\t";

		}

		std::cout << std::endl;

	}

}
```

для перебора последовательностей подходит и другая форма цикла `for`. элемент внешнего массива сам имеет тип массива, а массив не копируется в переменную цикла, поэтому подмассив связывают ссылкой:

```cpp


#include <iostream>



int main()

{

	const int rows = 3, columns = 2;

	int numbers[rows][columns]  { {1, 2}, {3, 4}, {5, 6} };

	

	for(auto &subnumbers : numbers)

	{

		for(int number : subnumbers)

		{

			std::cout << number << "\t";

		}

		std::cout << std::endl;

	}

}
```

во внешнем цикле `for(auto &subnumbers : numbers)` имя `subnumbers` есть ссылка на очередной подмассив. во внутреннем цикле `for(int number : subnumbers)` из этого подмассива каждый элемент копируется в переменную `number` и выводится на консоль.
