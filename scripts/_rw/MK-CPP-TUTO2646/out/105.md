стандарт c++20 вводит `std::span<T>` в заголовке `<span>`. объект `span` ссылается на непрерывную последовательность значений типа `T`: на `std::vector<T>`, на `std::array<T, N>`, на встроенный массив и на другие непрерывные диапазоны. `span` хранит указатель на первый элемент и длину, собственного буфера не выделяет и временем жизни последовательности не управляет. копирование `span` копирует этот указатель и длину.

одна функция тогда обслуживает разные контейнеры. пусть нужна функция максимума по набору чисел, а набор бывает и вектором, и массивом. без `span` пришлось бы задать две перегрузки: одну от `const std::vector<int>&`, другую от указателя на `int` с отдельным размером, потому что у встроенного массива после преобразования к указателю граница типа теряется:

```cpp


int max(const std::vector<int>&);

int max(const int[], size_t);
```

`std::span` сводит обе перегрузки к одной:

```cpp


#include <iostream>

#include <vector>

#include <span> 



// int max(const std::vector<int>&);

// int max(const int[], size_t);



int max(std::span<int>);





int main()

{

    std::vector<int> nums1{1, 2, 3, 4, 5};

    std::cout << max(nums1) << std::endl;   // 5



    int nums2[]{4, 5, 6, 7, 8};

    std::cout << max(nums2) << std::endl;   // 8

}



int max(std::span<int> data) 

{

    int result {data[0]};

    for (auto value : data)

    {

        if (result < value) result = value;

    }

    return result;

}
```

в `max` можно передать и вектор, и массив. размер массива указывать не нужно. граница массива входит в его тип, конструктор `span` от встроенного массива берет длину из этой границы на этапе компиляции. у вектора длину конструктор читает из `size()` во время выполнения. шаблон `std::span<int>` имеет динамическую длину: поле размера хранится в объекте. обращение `data[0]` предполагает непустую последовательность. у пустого `span` такое обращение не определено.

у `span` есть операции, общие с другими последовательностями:

- `size()` : размер `span`

- `empty()` : возвращает `true`, если `span` пуст

- `data()` : указатель на элементы

- `front()` : первый элемент

- `back()` : последний элемент

запись через `span` меняет исходную последовательность, потому что представление указывает на ее память. в примере каждый элемент вектора умножается на 2, и измененным оказывается сам вектор:

```cpp


#include <iostream>

#include <vector>

#include <span>  



void twice(std::span<int> data);





int main()

{

    std::vector<int> nums1{1, 2, 3, 4, 5};

    twice(nums1);

    for(const auto &n : nums1)

    {

        std::cout << n << "\t";   // 2       4       6       8       10

    }

    std::cout << std::endl;

}



void twice(std::span<int> items) 

{

    for (unsigned i{}; i < items.size(); i++)

    {

        items[i] *= 2;

    }

}
```

`std::span` создают и явно, передав последовательность в конструктор:

```cpp


std::vector<int> numbers{1, 2, 3, 4, 5};

std::span<int> numSpan(numbers);
```

`std::span<int>` дает доступ к изменяемым элементам типа `int`, поэтому последовательность не может быть константной. следующий фрагмент не компилируется: конструктор не отбрасывает константность элементов.

```cpp


const std::vector<int> numbers{1, 2, 3, 4, 5};

std::span<int> numSpan(numbers);  // ! Ошибка
```

константную последовательность просматривают через `std::span<const int>`. оператор индекса тогда возвращает константную ссылку, и присваивание элементу невозможно:

```cpp


#include <iostream>

#include <vector>

#include <span>  



void print(std::span<const int>);



int main()

{

    const std::vector<int> numbers{1, 2, 3, 4, 5};

    std::span<const int> numSpan(numbers);

    print(numSpan);

}



void print(std::span<const int> items) 

{

    for(const auto &item : items)

    {

        std::cout << item << "\t";   // 2       4       6       8       10

    }

    std::cout << std::endl;

}
```

функция `print` печатает элементы представления в том виде, в каком они лежат в векторе.
