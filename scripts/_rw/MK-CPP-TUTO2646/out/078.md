оператор индексирования `[]` (subscript operator) задаёт интерпретацию объекта как массива или как контейнера других объектов и выбирает из объекта отдельный элемент. функция оператора `[]` принимает индекс, по которому в объекте-контейнере находится нужный элемент. оператор индексирования определяется только как член класса: левый операнд обязан быть объектом этого класса. простейший пример:

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    Person(std::string p_name, unsigned p_age, std::string p_company)

    {

        name = p_name;

        company = p_company;

        age = p_age;

    }

    std::string operator[](unsigned index) const

    {

        switch (index)

        {

            case 0: return name;

            case 1: return std::to_string(age);	// преобразуем в тип std::string

            case 2: return company;

            default: return "Bad Index";

        }

    }

private:

    std::string name;

    unsigned age;

    std::string company;

};



int main()

{

    Person tom{"Tom", 38, "Microsoft"};

    std::cout << tom[0] << "\n" << tom[1] << "\n" << tom[2] << std::endl;

}
```

класс `Person` определяет три закрытых поля: `name`, `age` и `company`. снаружи класса они недоступны. объект `Person` можно рассматривать как контейнер над этими полями. обращение к ним задаёт оператор индексации:

```cpp


std::string operator[](unsigned index) const

{

    switch (index)

    {

        case 0: return name;

        case 1: return std::to_string(age);

        case 2: return company;

        default: return "Bad Index";

    }

}
```

операнд оператора представляет собой числовой индекс типа `unsigned`, то есть неотрицательное целое. по значению индекса возвращается значение соответствующего поля. тип результата здесь `std::string`, поэтому поле `age` приводится к строке функцией `std::to_string`. соответствие индекса и поля условно. логичный, хотя и не обязательный, порядок совпадает с порядком объявления полей в классе. в функции `main` оператор обращается к полю по индексу:

```cpp


Person tom{"Tom", 38, "Microsoft"};

std::cout << tom[0] << "\n" << tom[1] << "\n" << tom[2] << std::endl;
```

консольный вывод:

```bash


Tom

38

Microsoft
```

индекс не обязан быть числом. его тип выбирается произвольно, например `std::string`. перегрузки `operator[]` различаются типом индекса так же, как обычные перегруженные функции.

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    Person(std::string p_name, unsigned p_age, std::string p_company)

    {

        name = p_name;

        company = p_company;

        age = p_age;

    }

    // строковый индекс

    std::string operator[](const std::string& prop) const

    {

        if(prop=="name") return name;

        else if(prop== "age") return std::to_string(age);

        else if(prop=="company") return company;

        else return "Bad Index"; 

    }

private:

    std::string name;

    unsigned age{};

    std::string company;

};



int main()

{

    Person tom{"Tom", 38, "Microsoft"};

    std::cout << tom["name"] << ": " << tom["company"] << std::endl;	// Tom: Microsoft

}
```

оператор индексации применяют и для доступа к элементу набора, который хранится в объекте. у компании есть набор сотрудников:

```cpp


#include <iostream>

#include <string>



class Company

{

public:

    std::string& operator[](unsigned index)

    {

        return employees[index];

    }

private:

    std::string employees[10]{"Tom", "Sam", "Bob"};

};



int main()

{

    Company company;

    std::cout << company[0] << std::endl;	// Tom

    company[0] = "Tomas";

    std::cout << company[0] << std::endl;	// Tomas

}
```

для простоты класс `Company` хранит сотрудников в массиве строк. функция индексации возвращает один из элементов массива `employees`. чтобы возвращённый элемент можно было изменять, оператор возвращает ссылку `std::string&`, а не временный объект `std::string`. выражение `company[0] = "Tomas"` корректно потому, что результат является левым значением: ссылка обозначает сам элемент массива, и присваивание пишет в него. возврат по значению дал бы временный объект, и присваивание в него не меняло бы массив.

главная трудность состоит в логике выбора элемента. в классе `Person` разнотипные поля приходится приводить к одному типу результата. в классе `Company` переданный индекс может не указывать на существующий элемент: выход за границы массива имеет неопределённое поведение. стратегии на этот случай различны. среди них контрольное значение, исключение и сужение контракта предусловием. при определении оператора эти ситуации учитывают заранее.
