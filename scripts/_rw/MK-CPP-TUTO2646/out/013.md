в предыдущих темах чтение и запись выполнялись через объекты `std::cout` и `std::cin`. префикс `std::` показывает, что имена `cout`, `cin` и `endl` объявлены в пространстве имён `std`. двойное двоеточие `::` является оператором разрешения области видимости: он указывает, в каком пространстве имён находится имя. без такого префикса эти имена по умолчанию не видны, потому что объявления библиотеки не попадают в глобальную область видимости.

запись с квалификатором длинна. оператор `using` вводит в текущую область видимости выбранные имена из другого пространства имён, после чего их используют без префикса.

форма директивы для одного имени:

```cpp
using пространство_имен::объект
```

исходный вариант программы обращается к именам через `std::`:

```cpp
#include <iostream>

int main()
{	
	int age;
	std::cout << "Input age: ";
	std::cin >> age;
	std::cout << "Your age: " << age << std::endl;
}
```

здесь из пространства имён `std` используются сразу три имени: `cout`, `cin` и `endl`. тот же текст с `using`:

```cpp
#include <iostream>
using std::cin;
using std::cout;
using std::endl;

int main()
{	
	int age;
	cout << "Input age: ";
	cin >> age;
	cout << "Your age: " << age << endl;
}
```

для каждого имени из `std` записывается отдельная директива `using`. семантика программы не меняется: вызовы относятся к тем же объектам, меняется только способ поиска имени. директива `using namespace std` ввела бы все имена пространства разом. для учебного кода это короче, но в заголовке и в крупном проекте такое внедрение повышает риск коллизии имён, поэтому точечная форма `using std::cout` предпочтительнее.

### определение псевдонимов

служебное слово `using` также вводит псевдоним типа. псевдоним полезен, когда имя типа длинное: короткое имя сокращает запись, не создавая отдельного типа.

```cpp
#include <iostream>

using ullong = unsigned long long;
int main()
{
    ullong n {10234};
    std::cout << n << std::endl;
}
```

для типа `unsigned long long` здесь задан псевдоним `ullong`. это объявление псевдонима: `ullong` и `unsigned long long` обозначают один и тот же тип, нового типа не появляется. псевдоним прозрачен для системы типов, перегрузки и специализаций шаблонов.

для псевдонимов в c++ сохраняется и более ранняя форма в стиле c, оператор `typedef`:

```cpp
#include <iostream>

typedef unsigned long long ullong;
int main()
{
    ullong n {10234};
    std::cout << n << std::endl;
}
```

для простого переименования `typedef` и `using` дают один и тот же результат. форма с `using` читается слева направо, от нового имени к исходному типу, и в дальнейшем распространяется на шаблонные псевдонимы, где `typedef` недостаточен.
