операторы ввода `>>` и вывода `<<` для пользовательского типа подключают его к тому же форматированному вводу-выводу, которым пользуются встроенные типы.

первый параметр оператора `>>` представляет собой ссылку на объект `istream`, с которого выполняется чтение. второй параметр представляет собой ссылку на неконстантный объект, в который нужно записать разобранные данные. результатом оператор возвращает ссылку на поток ввода из первого параметра. возврат потока оставляет выражение пригодным для следующей экстракции и для проверки в условии: после чтения поток можно испытать в булевом контексте. в фрагменте оператор задан свободной функцией, потому что левый операнд имеет тип библиотечного потока. поля `Person` закрыты, поэтому имя и возраст попадают в объект через `setName` и `setAge`.

```cpp


#include <iostream>

#include <string>



class Person 

{

public:

    Person(std::string name, unsigned age): name{name}, age{age} {}

    std::string getName() const {return name;}

    unsigned getAge() const {return age;}



    void setName(std::string personName){ name = personName;}

    void setAge(unsigned personAge){ age = personAge;}

private:

    std::string name;

    unsigned age{};

}; 

std::istream& operator >> (std::istream& in, Person& person)

{

    std::string name;

    unsigned age;

    in >> name >> age;

    person.setName(name);

    person.setAge(age);

    return in;

}

int main()

{

    Person bob{"",0};

    std::cout << "Input name and age: ";

    std::cin >> bob;

    std::cout << "Name: " << bob.getName() << "\tAge: " << bob.getAge() << std::endl;

}
```

оператор ввода по очереди считывает из потока лексемы в локальные переменные `name` и `age` и затем устанавливает ими имя и возраст объекта.

```cpp


std::istream& operator >> (std::istream& in, Person& person)

{

    std::string name;

    unsigned age;

    in >> name >> age;

    person.setName(name);

    person.setAge(age);

    return in;

}
```

извлечение в `std::string` забирает одно слово до пробельного символа, поэтому оператор рассчитан на имя из одного слова. имя из нескольких слов или имя вместе с фамилией задают отдельным разбором, обычно чтением строки целиком: для `>>` пробел является концом лексемы.

пример работы программы:

```bash


Input name and age: Bob 42

Name: Bob	Age: 42
```

если вместо числа на месте возраста введена строка, экстракция в `unsigned` выставляет у потока `failbit`. начиная со стандарта c++11 неудачный разбор числа записывает в арифметический операнд нуль. локальная переменная `age` при этом ещё не является полем объекта, и без проверки потока нуль был бы передан в `setAge`. обрабатывать такую ошибку можно по-разному. в примере ниже поля меняются только при успешном вводе. если ввод не удался, у объекта `Person` остаются те значения, которые были у него до вызова оператора.

```cpp


std::istream& operator >> (std::istream& in, Person& person)

{

    std::string name;

    unsigned age;

    in >> name >> age;

    if (in)    

	{

        person.setName(name);

        person.setAge(age);

    }

    return in;

}
```

выражение `if(in)` проверяет, удался ли ввод. поток в условии переводится в `bool`: преобразование истинно, пока не выставлены `failbit` и `badbit`. при успехе оператор записывает введённые имя и возраст. при неудаче `setName` и `setAge` не вызываются.

### чтение и запись файла

те же операторы применимы к файлу. `operator<<` принимает `ostream&`, `operator>>` принимает `istream&`. `ofstream` является `ostream`, `ifstream` является `istream`, поэтому файловый поток подставляется в уже определённый оператор. формат строки задан один раз и действует и для консоли, и для файла.

```cpp


#include <iostream>

#include <fstream>

#include <vector>

#include <string>



class Person 

{

public:

    Person(std::string name, unsigned age): name{name}, age{age} {}

    std::string getName() const {return name;}

    unsigned getAge() const {return age;}



    void setName(std::string personName){ name = personName;}

    void setAge(unsigned personAge){ age = personAge;}

private:

    std::string name;

    unsigned age{};

};

std::ostream& operator << (std::ostream &os, const Person &person)

{

    return os << person.getName() << " " << person.getAge();

}

std::istream& operator >> (std::istream& in, Person& person)

{

    std::string name;

    unsigned age;

    in >> name >> age;

    // если ввод не удался, устанавливаем некоторые значения по умолчанию

    if (in)    

	{

        person.setName(name);

        person.setAge(age);

    }

    return in;

}

int main()

{

    // начальные данные - вектор объектов Person

    std::vector<Person> people =

    {

        Person{"Tom", 23},

        Person{"Bob", 25},

        Person{"Alice", 22},

        Person{"Kate", 31}

    };

    // запись данных в файл

    std::ofstream out("people.txt");

    if (out.is_open())

    {

        for (const Person& person: people)

        {

            out << person << std::endl;

        }

    }

    out.close();

    // вектор для считываемых данных

    std::vector<Person> new_people;

    // чтение ранее записанных данных из файла

    std::ifstream in("people.txt");

    if (in.is_open())

    {

        Person person{"",0};

        while (in >> person)

        {

            new_people.push_back(person);

        }

    }

    in.close();

    // вывод считанных данных на консоль

    std::cout << "All people:" << std::endl;

    for (const Person& person: new_people)

    {

        std::cout << person << std::endl;

    }

}
```

для класса `Person` определены оператор вывода и оператор ввода. исходный вектор содержит четыре объекта: `Tom` с возрастом 23, `Bob` с возрастом 25, `Alice` с возрастом 22 и `Kate` с возрастом 31. оператор вывода пишет в поток имя, пробел и возраст. конец строки добавляет цикл записи через `std::endl`, так что каждая запись лежит в файле `people.txt` отдельной строкой. оператор ввода считывает из этого файла ту же пару лексем. условие `while (in >> person)` и извлекает очередную запись, и проверяет состояние потока. при ошибке разбора цикл останавливается. если имя уже прочитано, а возраст нет, лексема имени из потока изъята, а поля объекта сохраняют прежние значения. после закрытия файла считанные записи печатаются на консоль, каждая своим оператором вывода и с переводом строки. заголовок на консоли в коде задан литералом `All people:`.

результат работы программы:

```bash


All users:

Tom 23

Bob 25

Alice 22

Kate 31
```

листинг приводит четыре считанные строки: имя и возраст через пробел.
