### возвращение указателя

указатель, возвращаемый из функции, должен быть либо **nullptr**, либо адресом объекта, время жизни которого ещё не закончилось. возвращать адрес автоматической локальной переменной нельзя: она уничтожается при завершении функции, и возвращённый адрес становится висячим (dangling). обращение по нему есть неопределённое поведение. ниже некорректная функция, которая пытается вернуть большее из двух чисел:

```cpp


// пример некорректного возвращения значения

int* max(int a, int b)

{

    if (a > b)

        return &a;

    else

        return &b;

}
```

параметры функции устроены как локальные переменные. при вызове для них выделяется память в стеке, в кадре активации. здесь возвращается адрес этой памяти, `return &a` или `return &b`. после возврата адреса функция завершается, кадр освобождается, параметры уничтожаются, и возвращённый адрес больше не обозначает живой объект. компилятор может принять такую функцию и ограничиться предупреждением, но работать корректно она не будет: чтение по возвращённому указателю обращается к памяти, которая уже не занята этими параметрами.

из этого не следует, что функция вообще не может вернуть указатель. корректно вернуть адрес объекта, чьё время жизни контролирует вызывающий код:

```cpp


#include <iostream>



int* max(int*, int*);



int main()

{

    int n{5};

    int m{4};

    int* ptr = max(&n, &m);

    std::cout << "max: " << *ptr << std::endl; // max: 5

}

// пример корректного возвращения значения

int* max(int *a, int *b)

{

    if (*a > *b)    // разыменовываем указатели

        return a;

    else

        return b;

}
```

функция снова выбирает большее из двух чисел. в неё передаются адреса переменных `n` и `m`. возвращается один из этих адресов. объекты `n` и `m` живут в `main` и после возврата из `max` остаются действительными, поэтому возвращённый указатель можно разыменовать.

результат не обязательно сохранять в переменной или константе. к нему можно обратиться прямо в выражении. разыменование применяется к prvalue, который вернула функция:

```cpp


int main()

{

    int n{5};

    int m{4};

    std::cout << "max: " << *max(&n, &m) << std::endl; // max: 5

}
```

### возвращение ссылки

функция может возвращать и ссылку. ограничение то же, что для указателя: нельзя возвращать ссылку на локальный объект, созданный внутри функции. объекты функции уничтожаются при её завершении, их память освобождается, и возвращённая ссылка обозначала бы уже несуществующий объект.

```cpp


// пример некорректного возвращения ссылки

int& max(int a, int b)

{

    if (a > b) 

        return a;

    else

        return b;

}
```

функция возвращает ссылку на большее значение, то есть на один из параметров, переданных по значению. память этих параметров после выхода из функции освобождается. возвращённая ссылка в итоге обозначает уничтоженный объект, и использование результата есть неопределённое поведение. ссылка, в отличие от указателя, не может быть нулевой, поэтому отложить проверку нельзя: некорректная ссылка уже связана с мёртвым объектом.

чтобы ссылка оставалась действительной, значения передают по ссылке. тогда параметры сами являются именами объектов вызывающего кода, и возврат одного из них есть возврат ссылки на объект, который переживёт функцию:

```cpp


#include <iostream>



int& max(int&, int&);



int main()

{

    int n{5};

    int m{4};

    int result = max(n, m);

    std::cout << "max: " << result << std::endl; // max: 5

}

// пример корректного возвращения ссылки

int& max(int& a, int& b)

{

    if (a > b) 

        return a;

    else

        return b;

}
```

если параметры суть константные ссылки, вернуть одну из них можно только как константную ссылку. возвращаемый тип `const int&` сохраняет константность. возврат типа `int&` из константного параметра был бы отбрасыванием `const` и отвергается при компиляции: иначе через результат можно было бы изменить объект, который функция обещала не менять.

```cpp


#include <iostream>



const int& max(const int&, const int&);



int main()

{

    int n{5};

    int m{4};

    int result = max(n, m);

    std::cout << "max: " << result << std::endl; // max: 5

}

// пример корректного возвращения ссылки

const int& max(const int& a, const int& b)

{

    if (a > b) 

        return a;

    else

        return b;

}
```
