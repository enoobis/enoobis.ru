**указатель на функцию** (function pointer) хранит адрес функции. значение такого указателя есть адрес первого байта памяти, с которого начинается исполняемый код функции. в системе типов c++ это отдельный тип: сигнатура задаёт, какую функцию через него допустимо вызвать, а вызов через указатель есть косвенный вызов, адрес которого известен во время выполнения, а не зашит в инструкцию вызова на этапе компиляции.

самый обычный способ получить такой адрес даёт имя функции. имя обозначает функцию, и с его помощью функцию вызывают и получают результат. в большинстве контекстов имя функции неявно преобразуется в указатель на функцию (function-to-pointer conversion). исключение составляют операнд оператора `&` и несколько других контекстов, где требуется сама функция, а не указатель.

указатель на функцию задаётся и отдельной переменной. формальный синтаксис объявления:

```cpp
тип (*имя_указателя) (типы_параметров);
```

скобки вокруг `*имя_указателя` обязательны: они связывают `*` с именем. без них звёздочка относится к типу возвращаемого значения.

- `тип` есть тип значения, которое функция возвращает.
- `имя_указателя` есть идентификатор, выбранный по обычным правилам именования переменных.
- `параметры` задают типы параметров через запятую, если параметры есть.

указатель адресует только функцию с тем же типом возвращаемого значения и теми же типами параметров, что записаны в объявлении указателя. тип функции в c++ включает эти компоненты, а начиная с c++17 ещё и спецификацию исключений: указатель на функцию `noexcept` и указатель на функцию без `noexcept` различаются. аргументы по умолчанию в тип функции не входят и на совместимость указателя не влияют.

пример объявления:

```cpp
void (*message) ();
```

имя указателя здесь `message`. он рассчитан на функции без параметров, которые возвращают `void`, то есть не передают значение вызывающему коду.

применение:

```cpp


#include <iostream>



void hello();

void goodbye();

 

int main()

{

    void (*message)();  // определение указателя на функцию

     

    message=hello;

    message();

    message = goodbye;

    message();

}

void hello()

{

    std::cout << "Hello, World" << std::endl;

}

void goodbye()

{

    std::cout << "Good Bye, World" << std::endl;

}
```

указателю присваивается функция, совпадающая с ним по типу возвращаемого значения и по спецификации параметров:

```cpp
message=hello;
```

после этого `message` хранит адрес `hello`. вызов записывается так же, как вызов функции по имени: оператор вызова применяется к указателю, и управление передаётся по хранимому адресу.

```cpp
message();
```

равносильная форма явно разыменовывает указатель. разыменование указателя на функцию даёт обозначение функции, которое тут же снова преобразуется в указатель, поэтому обе записи вызывают одну и ту же функцию:

```cpp
(*message)();
```

позже указателю присваивается адрес другой функции той же сигнатуры. программа печатает:

```bash


Hello, World

Good Bye, World
```

в объявлении существенны скобки вокруг имени. определение

```cpp
void (*message) ();
```

не совпадает со следующим:

```cpp
void *message ();
```

во втором случае объявлен прототип функции `message`, которая возвращает указатель типа `void*`. звёздочка без скобок входит в тип результата, а `()` объявляет функцию. это обычное правило разбора деклараторов: постфиксные `()` и `[]` связываются теснее, чем префиксная `*`.

### определение и инициализация указателя

при определении указатель сразу инициализируют функцией подходящего типа:

```cpp


void (*message)() {hello}; // указывает на функцию hello

// или так

void (*message2)() =hello; // указывает на функцию hello
```

допустима инициализация значением `nullptr`. нулевой указатель на функцию вызывать нельзя: такой вызов есть неопределённое поведение.

```cpp
void (*message)() { nullptr};
```

если инициализатор есть функция, тип можно не выписывать и положиться на вывод `auto`:

```cpp


auto message { hello}; // указывает на функцию hello

auto message2 = hello; // указывает на функцию hello
```

звёздочка после `auto` подчёркивает, что переменная есть указатель:

```cpp
auto* message { hello};
```

различия типов здесь нет. имя `hello` уже преобразовано в указатель, и `auto` выводит тип этого указателя. форма `auto*` требует, чтобы инициализатор был указателем, и в этом примере условие выполнено.

при присваивании применим и оператор взятия адреса:

```cpp
auto message { &hello};
```

явное `&` даёт тот же адрес, что и неявное преобразование функции в указатель. на выведенный тип это не влияет. преобразование не выполняется, когда функция уже взята по адресу, поэтому `&hello` и `hello` в позиции инициализатора обозначают один и тот же указатель.

### указатель на функцию с параметрами

указатель может описывать функцию с параметрами. тип параметров входит в тип указателя и проверяется при присваивании и при вызове:

```cpp


#include <iostream>

 

int sum(int, int);

int subtract(int, int);

  

int main()

{

    int a{10};

    int b{5};

    int (*operation)(int, int) {sum};	// указатель operation указывает на функцию sum

    int result = operation(a, b);

    // result = (*operation)(a, b); // альтернативный вариант

    std::cout << "result = " << result << std::endl;     // result = 15

      

    operation = subtract;	// указатель operation указывает на функцию subtract

    result = operation(a, b);

    std::cout << "result = " << result << std::endl;     // result = 5

}

int sum(int x, int y)

{

    return x+y;

}

int subtract(int x, int y)

{

    return x-y;

}
```

указатель `operation` рассчитан на функцию с двумя параметрами типа `int`, возвращающую `int`. ему по очереди присваиваются `sum` и `subtract`. вызов `operation(a, b)` передаёт аргументы той функции, чей адрес сейчас хранится в указателе. выражение `(*operation)(a, b)` делает то же самое. арифметика сложения и вычитания вынесена в отдельные функции, а выбор конкретной операции отложен до выполнения и выражен присваиванием указателю.

### массивы указателей на функции

наряду с одиночным указателем объявляют массив указателей на функции. формальный синтаксис:

```cpp


тип (*имя_массива[размер]) (параметры)
```

размер массива можно опустить, если он выводится из инициализатора. пример объявления:

```cpp
double (*actions[]) (int, int)
```

`actions` есть массив указателей на функции. каждая функция принимает два параметра типа `int` и возвращает `double`. все элементы массива имеют один и тот же тип указателя, поэтому разнородные сигнатуры в один массив не помещаются.

применение:

```cpp


#include <iostream>

 

void add(int, int);

void subtract(int, int);

void multiply(int, int);

 

int main()

{

    int a {10};

    int b {5};

    void (*operations[3])(int, int) = {add, subtract, multiply};

      

    // получаем длину массива

    unsigned length = std::size(operations);

      

    for(unsigned i{}; i < length; i++)

    {

        operations[i](a, b);    // вызов функции по указателю

    }

}

void add(int x, int y)

{

    std::cout << "x + y = " << x + y << std::endl;

}

void subtract(int x, int y)

{

    std::cout << "x - y = " << x - y << std::endl;

}

void multiply(int x, int y)

{

    std::cout << "x * y = " << x * y << std::endl;

}
```

массив `operations` инициализирован тремя функциями: `add`, `subtract` и `multiply`. длина массива получается через `std::size` (c++17), которое для массива известного размера даёт число элементов на этапе компиляции. цикл перебирает массив и вызывает каждую функцию с одними и теми же аргументами `a` и `b`. индекс выбирает указатель, оператор вызова выполняет косвенный вызов. консольный вывод:

```bash


x + y = 15

x - y = 5

x * y = 50
```
