для возвращения результата из функции служит оператор **return**. у него две формы:

```cpp


return выражение;

return;
```

первая форма **return** возвращает результат. если возвращаемый тип функции отличен от **void**, функция обязана вернуть значение оператором **return**. возвращаемое значение должно совпадать с возвращаемым типом либо допускать неявное преобразование к нему. выражение в `return` инициализирует результат вызова: для классового типа это копирование или перемещение, для скалярного типа передаётся само значение. управление после `return` в функцию не возвращается, последующие операторы тела не выполняются.

единственная функция, которая возвращает значение и при этом может обойтись без оператора **return**, есть функция **main**. если выполнение `main` доходит до конца тела без `return`, это равносильно `return 0`. для любой другой функции с возвращаемым типом, отличным от `void`, выход из тела без `return` даёт неопределённое поведение.

ниже функция, которая возвращает сумму двух чисел:

```cpp


#include <iostream>



int sum(int, int);



int main()

{

    int result = sum(10, 6);    // 16

    std::cout << result << std::endl;



	std::cout << sum(10, 7) << std::endl;   // 17

    std::cout << sum(10, 8) << std::endl;   // 18

}



int sum(int n, int m)

{

    int res = n + m;

    return res;

}
```

функция `sum` принимает два значения типа `int` и возвращает значение типа `int`. прототип поэтому такой:

```cpp
int sum(int, int);
```

в теле `sum` нужен оператор **return**, после которого стоит возвращаемое значение:

```cpp


int res = n + m;

return res;
```

здесь возвращается значение переменной `res`. на месте `return` может стоять и более сложное выражение типа `int`:

```cpp


int sum(int n, int m)

{

    return n + m;

}
```

раз `sum` возвращает значение, результат можно присвоить переменной или константе. вызов в этом контексте есть prvalue, и он инициализирует объект:

```cpp


int result = sum(10, 6);    // 16

std::cout << result << std::endl;
```

результат `sum` можно использовать и напрямую, как число, например в выводе на консоль. отдельная переменная для результата не обязательна:

```cpp
std::cout << sum(10, 7) << std::endl;   // 17
```

ещё один пример возвращает результат выбранной операции:

```cpp


#include <iostream>



int calculate(int, int, char);



int main()

{

    std::cout << calculate(10, 6, '+') << std::endl;   // 16

    std::cout << calculate(10, 6, '-') << std::endl;   // 4

    std::cout << calculate(10, 6, '*') << std::endl;   // 60

    std::cout << calculate(10, 6, '/') << std::endl;   // 0

}



int calculate(int n, int m, char op)

{

    switch(op)

    {

        case '+': 

            return n + m;

        case '-':

            return n - m;

        case '*':

            return n * m;

        default: 

            return 0;

    }

}
```

функция `calculate` принимает два числа и символ, знак операции. в конструкции `switch` в зависимости от знака оператор `return` возвращает результат соответствующей операции. ветка `default` возвращает 0, поэтому у каждого пути через тело есть возвращаемое значение. отдельного общего `return` после `switch` в этом определении нет: каждая ветка завершает функцию сама.

### return без возвращения значения

другая форма оператора `return` не принимает значения. она используется в функциях, которые ничего не возвращают, то есть имеют возвращаемый тип `void`. эта форма завершает функцию до конца её тела: оставшиеся операторы не выполняются, а вызывающему коду не передаётся результат.

ниже функция принимает имя и возраст и выводит их на консоль:

```cpp


#include <iostream>

#include <string>



void print(std::string, unsigned);



int main()

{

    print("Tom", 38);       // Name: Tom       Age: 38

    print("Bob", 2500);     // Incorrect age

}



void print(std::string name, unsigned age)

{

    // если запредельный возраст

    if(age > 120)

    {

        std::cout << "Incorrect age" << std::endl;

        return; // выходим из функции

    }



    std::cout << "Name: " << name << "\tAge: " << age << std::endl;

}
```

в `print` проверяется переданный возраст. если значение недопустимо, оператор `return` выполняет выход из функции. сообщение об ошибке уже выведено, а строка с именем и возрастом не выполняется. для типа `void` форма без выражения обязательна: `return` с выражением в такой функции было бы ошибкой, как и отсутствие значения в функции с непустым возвращаемым типом.

### выведение типа результата

компилятор c++ может вывести тип возвращаемого значения, если вместо этого типа указан оператор **auto**:

```cpp


#include <iostream>



// автоматически выводится возвращаемый тип

auto sum(int a, int b)

{

    return a + b;

}



int main()

{

    std::cout << sum(3, 6) << std::endl; // 9

}
```

тип результата `sum` выводится автоматически. возвращается сумма `a + b`, и тип этого выражения есть `int`, поэтому выведенный возвращаемый тип есть `int`. определение `sum` стоит раньше вызова в `main`: при возвращаемом типе `auto` определение должно быть видно в точке вызова, одного прототипа без выведенного или явно указанного типа недостаточно. все операторы `return` одной функции должны приводить к одному и тому же выведенному типу.

в этом примере мало оснований писать **auto** вместо `int`. **auto** применяют, когда имя возвращаемого типа длинное и сложное, например вложенный шаблонный тип или тип, зависящий от выражения. запись сокращается, а тип по-прежнему фиксируется при компиляции. во время выполнения он уже не выбирается.
