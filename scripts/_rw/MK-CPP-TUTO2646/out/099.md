`std::deque` представляет двустороннюю очередь. контейнер подключается заголовочным файлом `<deque>`. по сложности он совмещает произвольный доступ за постоянное время с добавлением и удалением на обоих концах за амортизированное постоянное время. элементы не обязаны занимать один непрерывный участок памяти. типичная реализация хранит массив указателей на блоки фиксированного размера. при росте подключаются новые блоки. копирование всей последовательности в один новый массив для этого не требуется.

способы создания двусторонней очереди:

```cpp


std::deque<int> deque1;					// пустая очередь

std::deque<int> deque2(5);				// deque2 состоит из 5 чисел, каждый элемент имеет значение по умолчанию

std::deque<int> deque(5, 2);				// deque3 состоит из 5 чисел, каждое число равно 2

std::deque<int> deque4{ 1, 2, 4, 5 };		// deque4 состоит из чисел 1, 2, 4, 5

std::deque<int> deque5 = { 1, 2, 3, 5 }; 	// deque5 состоит из чисел 1, 2, 3, 5

std::deque<int> deque6({ 1, 2, 3, 4, 5 }); // deque6  состоит из чисел 1, 2, 3, 4, 5

std::deque<int> deque7(deque4);          	// deque7 - копия очереди deque4

std::deque<int> deque8 = deque7;			// deque8 - копия очереди deque7
```

конструкторы задают пустую очередь, очередь из n элементов со значением по умолчанию, очередь из n копий значения, очередь из списка инициализации и копию другой очереди.

### получение элементов очереди

чтение элемента выполняется операцией индексирования и несколькими функциями:

- `[index]`: получение элемента по индексу. проверка границы не выполняется
- `at(index)`: возвращает элемент по индексу и проверяет границу
- `front()`: возвращает первый элемент
- `back()`: возвращает последний элемент

```cpp


#include <iostream>

#include <deque>



int main()

{

	std::deque<int> numbers { 1, 2, 3, 4, 5 };



	int first = numbers.front();	// 1

	int last = numbers.back();		// 5

	int second = numbers[1];		// 2

	int third = numbers.at(2);		// 3

	std::cout << first << second << third << last << std::endl; // 1235

}
```

обращение операцией индексирования по индексу за пределами контейнера даёт неопределённое поведение:

```cpp


std::deque<int> numbers { 1, 2, 3, 4, 5 };

int eighth = numbers[7];
```

`at()` в той же ситуации позволяет перехватить ошибку индекса: при выходе за границу функция генерирует исключение `std::out_of_range`.

```cpp


#include <iostream>

#include <deque>



int main()

{

	std::deque<int> numbers { 1, 2, 3, 4, 5};

	try

	{

		int n { numbers.at(7) };

		std::cout << n << std::endl;

	}

	catch (const std::out_of_range&)

	{

		std::cout << "Incorrect index" << std::endl;

	}

}
```

элементы перебираются диапазонным циклом, циклом по индексу и итераторами. итераторы `std::deque` имеют категорию произвольного доступа, поэтому индекс и смещение итератора согласованы между собой.

```cpp


#include <iostream>

#include <deque>



int main()

{

	std::deque<int> numbers { 1, 2, 3, 4, 5 };



	for (int n : numbers)

		std::cout << n << "\t";

	std::cout << std::endl;



	for (unsigned i {}; i < numbers.size(); i++)

		std::cout << numbers[i] << "\t";

	std::cout << std::endl;



	for (auto iter = numbers.begin(); iter != numbers.end(); iter++)

		std::cout << *iter << "\t";

	std::cout << std::endl;

	

	return 0;

}
```

### размер очереди

число элементов возвращает `size()`. `empty()` сообщает, есть ли в очереди элементы: функция возвращает `true`, если очередь пуста, и `false`, если в ней есть хотя бы один элемент.

```cpp


std::deque<int> numbers { 1, 2, 3, 4, 5 };

if (numbers.empty())

{

	std::cout << "Deque is empty" << std::endl;

}

else

{

	int n {numbers.size()};

	std::cout << "Deque has " << n << " elements" << std::endl;

}
```

`resize()` меняет размер и имеет две формы:

- `resize(n)`: оставляет n первых элементов. если элементов больше n, контейнер усекается до первых n. если элементов меньше n, недостающие добавляются и инициализируются значением по умолчанию
- `resize(n, value)`: так же оставляет n первых элементов. если элементов меньше n, недостающие получают значение `value`

применение:

```cpp


std::deque<int> numbers { 1, 2, 3, 4, 5, 6 };

numbers.resize(4);	// оставляем первые четыре элемента - numbers = {1, 2, 3, 4}



numbers.resize(6, 8);	 // numbers = {1, 2, 3, 4, 8, 8}
```

вызов `resize` способен сделать недействительными итераторы, указатели и ссылки на элементы.

### изменение элементов очереди

`assign()` заменяет все элементы очереди новым набором. формы:

- `assign(il)`: заменяет содержимое элементами списка инициализации `il`
- `assign(n, value)`: заменяет содержимое n элементами со значением `value`
- `assign(begin, end)`: заменяет содержимое элементами диапазона, границы которого задают итераторы `begin` и `end`

применение:

```cpp


std::deque<int> numbers { 1, 2, 3, 4, 5 };



numbers.assign({ 21, 22, 23, 24, 25 }); // numbers = { 21, 22, 23, 24, 25 }



numbers.assign(4, 3);					// numbers = {3, 3, 3, 3}



std::deque<int> values { 6, 7, 8, 9, 10, 11 };

auto start = values.begin() + 2;	// итератор указывает на третий элемент

auto end = values.end();			// итератор указывает на последний элемент

numbers.assign(start, end); 		//  numbers = { 8, 9, 10, 11 }
```

`swap()` обменивает содержимое двух очередей:

```cpp


std::deque<int> deque1 { 1, 2, 3, 4, 5 };

std::deque<int> deque2 { 6, 7, 8, 9};

deque1.swap(deque2);	// deque1 = { 6, 7, 8, 9};
```

### добавление элементов

добавление в `std::deque` выполняется на концах и в произвольной позиции, заданной итератором:

- `push_back(val)`: добавляет значение `val` в конец очереди
- `push_front(val)`: добавляет значение `val` в начало очереди
- `emplace_back(val)`: создаёт значение из аргументов в конце очереди
- `emplace_front(val)`: создаёт значение из аргументов в начале очереди
- `emplace(pos, val)`: создаёт элемент `val` на позиции итератора `pos`. возвращает итератор на добавленный элемент
- `insert(pos, val)`: вставляет элемент `val` на позицию итератора `pos`. для готового значения результат совпадает с `emplace`. возвращает итератор на добавленный элемент
- `insert(pos, n, val)`: вставляет n элементов `val`, начиная с позиции `pos`. возвращает итератор на первый добавленный элемент. если n равно 0, возвращается итератор `pos`
- `insert(pos, begin, end)`: вставляет, начиная с `pos`, элементы другого контейнера из диапазона между итераторами `begin` и `end`. возвращает итератор на первый добавленный элемент. если между `begin` и `end` нет элементов, возвращается итератор `pos`
- `insert(pos, values)`: вставляет список значений `values`, начиная с позиции `pos`. возвращает итератор на первый добавленный элемент. если `values` не содержит элементов, возвращается итератор `pos`

функции `push_back()`, `push_front()`, `emplace_back()` и `emplace_front()`:

```cpp


std::deque<int> numbers { 1, 2, 3, 4, 5 };

numbers.push_back(6);	// { 1, 2, 3, 4, 5, 6 }

numbers.push_front(0);	// { 0, 1, 2, 3, 4, 5, 6 }

numbers.emplace_back(7);	// { 0, 1, 2, 3, 4, 5, 6, 7 }

numbers.emplace_front(-1);	// { -1, 0, 1, 2, 3, 4, 5, 6, 7 }
```

добавление в середину функцией `emplace()`:

```cpp


std::deque<int> numbers { 1, 2, 3, 4, 5 };

auto iter = ++numbers.cbegin();	// итератор указывает на второй элемент

numbers.emplace(iter, 8); // добавляем после первого элемента  numbers = { 1, 8, 2, 3, 4, 5};
```

добавление в середину функцией `insert()`:

```cpp


std::deque<int> numbers1 { 1, 2, 3, 4, 5 };

auto iter1 = numbers1.cbegin();	// итератор указывает на второй элемент

numbers1.insert(iter1 + 2, 8); // добавляем после второго элемента  

//numbers1 = { 1, 2, 8, 3, 4, 5};



std::deque<int> numbers2 { 1, 2, 3, 4, 5 };

auto iter2 = numbers2.cbegin();	// итератор указывает на первый элемент

numbers2.insert(iter2, 3, 4); // добавляем вначало три четверки  

//numbers2 = { 4, 4, 4, 1, 2, 3, 4, 5};



std::deque<int> values { 10, 20, 30, 40, 50 };

std::deque<int> numbers3 { 1, 2, 3, 4, 5 };

auto iter3 = numbers3.cbegin();	// итератор указывает на первый элемент

// добавляем в начало все элементы из values

numbers3.insert(iter3, values.begin(), values.end());

//numbers3 = { 10, 20, 30, 40, 50, 1, 2, 3, 4, 5};



std::deque<int> numbers4 { 1, 2, 3, 4, 5 };

auto iter4 = numbers4.cend();	// итератор указывает на позицию за последним элементом

// добавляем после последнего элемента список { 21, 22, 23 }

numbers4.insert(iter4, { 21, 22, 23 });

//numbers4 = { 1, 2, 3, 4, 5, 21, 22, 23};
```

в этих вызовах константный итератор либо сдвигается арифметикой произвольного доступа, либо задаёт начало или конец последовательности. `insert` перед `cend()` дописывает элементы в конец, `insert` от `cbegin()` вставляет их в начало.

при добавлении в `std::deque` итераторы становятся недействительными. вставка в начало или в конец оставляет действительными ссылки и указатели на уже размещённые элементы: блоки с этими элементами не перемещаются. вставка в середину делает недействительными итераторы, ссылки и указатели.

### удаление элементов

для удаления из `std::deque` используются следующие функции:

- `clear()`: удаляет все элементы
- `pop_back()`: удаляет последний элемент
- `pop_front()`: удаляет первый элемент
- `erase(p)`: удаляет элемент, на который указывает итератор `p`. возвращает итератор на элемент, следующий за удалённым, либо конец контейнера, если удалён последний элемент
- `erase(begin, end)`: удаляет элементы диапазона, границы которого задают итераторы `begin` и `end`. возвращает итератор на элемент, следующий за последним удалённым, либо конец контейнера, если удалён последний элемент

применение:

```cpp


std::deque<int> numbers{ 1, 2, 3, 4, 5 };

numbers.pop_front();	// numbers = { 2, 3, 4, 5 }

numbers.pop_back();		// numbers = { 2, 3, 4 }

numbers.clear();	// numbers ={}



numbers = { 1, 2, 3, 4, 5 };

auto iter = numbers.cbegin(); // указатель на первый элемент

numbers.erase(iter);	// удаляем первый элемент

// numbers = { 2, 4, 5, 6 }



numbers = { 1, 2, 3, 4, 5 };

auto begin = numbers.begin(); // указатель на первый элемент

auto end = numbers.end();		// указатель на последний элемент

numbers.erase(++begin, --end);	// удаляем со второго элемента до последнего

//numbers = {1, 5}
```

удаление из любой позиции, кроме первого и последнего элементов, делает недействительными все итераторы, указатели и ссылки на элементы `std::deque`. удаление только первого или только последнего элемента инвалидирует итераторы и ссылки удалённого элемента. ссылки на остальные элементы при этом сохраняются.

`std::deque`, как `std::vector` и `std::array`, предоставляет произвольный доступ к элементам. дополнительно поддерживается добавление в начало за амортизированное постоянное время. при изменении размера реализация не выделяет один новый массив под весь набор элементов и манипулирует указателями на блоки. соседние по индексу элементы не обязаны лежать рядом в памяти, поэтому трактовать диапазон `std::deque` как один встроенный массив нельзя. для `std::vector` такая трактовка определена непрерывностью буфера.
