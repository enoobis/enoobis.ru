язык программирования c++ представляет собой компилируемый язык общего назначения со статической типизацией. тип выражения известен на этапе трансляции, и рассогласование типов диагностируется компилятором до запуска программы. на c++ пишут приложения самого разного назначения, и язык остаётся одним из самых распространённых.

корни c++ лежат в языке c, который разработан в 1969-1973 годах в bell labs программистом деннисом ритчи (dennis ritchie). в начале 1980-х датский программист бьерн страуструп (bjarne stroustrup), в то время сотрудник bell labs, построил c++ как расширение c. сначала расширение добавляло к c средства объектно-ориентированного программирования, и сам страуструп называл его "c with classes" ("си с классами").

по мере добавления самостоятельных средств язык перестал быть надстройкой над c и стал отдельным языком программирования. название "си с классами" сменилось на c++. с этого момента оба языка развиваются независимо: общий синтаксис и близкая модель памяти сохраняются, но стандарты расходятся, и текст, корректный на одном языке, не обязан быть корректной программой на другом.

текущий черновик стандарта опубликован по ссылке [https://eel.is/c++draft/](https://eel.is/c++draft/). это рабочий документ комитета, по которому сверяют формулировки языка и стандартной библиотеки между официальными изданиями.

от c язык унаследовал прямую работу с памятью. объект занимает адресуемую область, указатель хранит адрес, время жизни динамического объекта программист задаёт явно, сборщика мусора в семантике языка нет. поэтому c++ применяют в системном программировании: при создании операционных систем, драйверов, служебных утилит, антивирусов и т.д. операционная система windows в значительной части написана на c++. системным программированием применение не ограничивается. язык используют в программах любого уровня, где существенны скорость работы и производительность: в графических приложениях, прикладных программах, играх с насыщенной визуализацией. c++ применяют и в мобильной разработке. в веб-разработке на нём создают веб-приложения и вспомогательные сервисы, которые эти приложения обслуживают. круг задач широкий: на c++ пишут практически любые виды программ.

c++ является компилируемым языком. компилятор транслирует исходный текст в исполняемый файл с набором машинных инструкций целевой архитектуры. платформы различаются системой команд, форматом исполняемого файла и двоичным интерфейсом, поэтому скомпилированную программу нельзя просто перенести на другую платформу и запустить. на уровне исходного текста программы переносимы в той мере, в какой не вызывают функции, специфичные для текущей операционной системы. компиляторы, библиотеки и инструменты разработки есть почти для всех распространённых платформ, и один и тот же исходный текст на c++ компилируется в приложения для этих платформ.

в отличие от c, c++ позволяет строить приложение в объектно-ориентированном стиле: программа представляется совокупностью взаимодействующих классов и объектов. класс задаёт устройство состояния и операции над ним, объект является экземпляром класса. такое разбиение упрощает создание крупных приложений. язык при этом не сводится к одному стилю: наряду с классами в нём остаются процедурные средства c и, в более поздних стандартах, обобщённое программирование на шаблонах.

### основные этапы развития

в 1979-1980 годах бьерн страуструп разработал расширение языка c, "си с классами". в 1983 году язык переименован в c++. операция инкремента в названии фиксирует следующий шаг относительно c.

в 1985 году вышла первая коммерческая версия c++ и первое издание книги "язык программирования c++". книга давала первое связное описание языка при отсутствии официального стандарта.

в 1989 году выпущена версия c++ 2.0. в неё вошёл ряд новых возможностей, среди которых множественное наследование, абстрактные классы, статические и константные функции-члены. после этого язык развивался сравнительно медленно вплоть до 2011 года. в 1998 году организация iso (international organization for standardization) выпустила первый стандарт. его обозначение iso/iec 14882:1998, сокращённо c++98. в 2003 году издана редакция c++03: она в основном исправляла дефекты c++98 и не меняла язык так сильно, как последующие стандарты.

в 2011 году опубликован стандарт c++11. он добавил большой набор средств языка и библиотеки: семантику перемещения, вывод типа, лямбда-выражения, модель памяти для параллельного выполнения. с тех пор вышел ещё ряд стандартов. на момент написания исходного текста последним опубликованным был c++20, он вышел в декабре 2020 года, а стандарт c++23 ожидался в 2023 году. впоследствии c++23 зафиксирован как iso/iec 14882:2024.

### компиляторы и среды разработки

для программ на c++ нужны по меньшей мере два компонента: текстовый редактор, в котором набирают исходный текст, и компилятор, который принимает файл с исходным текстом и строит исполняемый файл. редактор годится любой. для набора кода в курсе рекомендуется кроссплатформенный редактор [Visual Studio Code](https://code.visualstudio.com/download): к нему подключаются расширения для разных языков, в том числе для c++.

с редактором выбор прост, с компилятором сложнее. реализации различаются полнотой поддержки стандартов и собственными расширениями. базовый перечень компиляторов c++ собран в [википедии](https://en.wikipedia.org/wiki/List_of_compilers#C.2B.2B_compilers). степень поддержки последних стандартов приведена на странице [https://en.cppreference.com/w/cpp/compiler_support](https://en.cppreference.com/w/cpp/compiler_support). на практике имеет смысл знать по меньшей мере три основные реализации:

- g++ от проекта gnu (в составе набора компиляторов gcc)

- clang (доступен в рамках проекта llvm)

- компилятор c++ компании microsoft (используется в visual studio)

далее разбираются отдельные из этих инструментов. на протяжении всего курса основным ориентиром служит компилятор **g++** (gcc), разрабатываемый в проекте gnu. программа `g++` является драйвером: она запускает препроцессор, собственно компилятор, ассемблер и компоновщик и по умолчанию подключает стандартную библиотеку c++.

для сборки приложений используют и интегрированные среды разработки, такие как visual studio, netbeans, eclipse, qt и т.д. среда совмещает редактирование, сборку и отладку и тем самым сокращает ручные шаги при создании приложения.
