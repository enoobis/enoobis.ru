### указатели на константы

указатель может адресовать и переменную, и константу. указатель на константу сам объявляют с ключевым словом `const`. в записи `const int *` слово `const` относится к адресуемому типу: это указатель на `const int`. через него объект не изменяют, а сам указатель переназначают:

```cpp
#include <iostream>

int main()
{
	const int a {10};
    const int *pa {&a};
    std::cout << "address=" << pa << "\tvalue=" << *pa << std::endl;
}
```

указатель `pa` указывает на константу `a`. запись по адресу, который хранится в указателе, некорректна. выражение ниже отвергается при компиляции:

```cpp
*pa = 34;
```

в этом месте компилятор сообщает об ошибке, программа не строится.

указатель на константу может указывать и на обычную переменную. ограничение относится к доступу через указатель, а не к объекту самому по себе:

```cpp
#include <iostream>

int main()
{
	int a {10};
    const int *pa {&a};
    std::cout <<"value=" << *pa << std::endl;     // value=10
    a = 22;
    std::cout <<"value=" << *pa << std::endl;     // value=22
    //*pa = 34;     // так делать нельзя
}
```

переменную `a` по-прежнему изменяют напрямую, и чтение через указатель видит новое значение. изменить объект через указатель нельзя: тип `*pa` есть `const int`.

через указатель на константу не меняют значение переменной или константы. самому указателю присваивают адрес другой переменной или константы. меняется адрес в указателе, объекты по старым адресам остаются прежними:

```cpp
const int a {10};
const int *pa {&a};		// указатель указывает на константу a
const int b {45};
pa = &b;				// указатель указывает на константу b
std::cout <<"*pa = " << *pa << std::endl;     // *pa = 45
std::cout <<"a = " << a << std::endl;     // a = 10 - константа a не изменяется
```

### константный указатель

константный указатель задают другой расстановкой `const`: в записи `int *const` константен сам указатель. адрес, записанный в нём, не меняют, а значение по этому адресу меняют. такой указатель инициализируют сразу: позже присвоить ему адрес уже нельзя.

```cpp
#include <iostream>

int main()
{
	int a {10};
    int *const pa {&a};
    std::cout << "value=" << *pa << std::endl;      // value = 10
    *pa = 22;                                       // меняем значение
    std::cout << "value=" << *pa << std::endl;      // value = 22
  
    int b {45};
    // pa = &b;         так нельзя сделать
}
```

### константный указатель на константу

оба ограничения соединяются в константном указателе на константу. запись `const int *const` не позволяет менять ни хранимый адрес, ни значение по этому адресу:

```cpp
int main()
{
    int a {10};
    const int *const pa {&a};

    //*pa = 22;	 так сделать нельзя

    int b {45};
    // pa = &b;	 так сделать нельзя	
}
```
