контейнер `std::array` из одноимённого заголовочного файла `<array>` хранит последовательность фиксированной длины. длина входит в тип как параметр шаблона, не являющийся типом, поэтому размер известен при компиляции и во время выполнения не меняется. элементы лежат в непрерывном блоке, как у встроенного массива. сам `std::array` при этом является объектом класса: его можно копировать, возвращать из функции и сравнивать.

### определение и инициализация

при создании объекта в угловых скобках после имени типа передаются тип элемента и размер:

```cpp


#include <array>



int main()

{   

	std::array<int, 5> numbers;		// состоит из 5 чисел int

}
```

здесь `std::array<int, 5>` содержит пять значений типа `int`. без инициализатора элементы инициализируются по умолчанию. в приведённом объявлении объект автоматический, и для `int` такая инициализация оставляет значения неопределёнными: читать их до записи нельзя.

значения элементов задаёт инициализатор в фигурных скобках:

```cpp


std::array<int, 5> numbers {};	// состоит из 5 нулей
```

пустой инициализатор `{}` выполняет инициализацию значением. все элементы `numbers` становятся нулями.

элементам можно передать и конкретные значения:

```cpp


std::array<int, 5> numbers {2, 3, 4, 5, 6};
```

фиксированный размер ограничивает список инициализации: число значений не может превышать n. значений может быть меньше. тогда они записываются в начальные элементы, а остальные получают значение по умолчанию. для целочисленных типов это 0:

```cpp


std::array<int, 5> numbers {2, 3, 4};		// {2, 3, 4, 0, 0}
```

если значений больше, чем размер контейнера, программа не компилируется. размер входит в тип и под длину списка не подстраивается.

начиная со стандарта c++17 тип элемента и длину можно не писать явно. компилятор выводит их из списка инициализации, по правилам выведения аргументов шаблона класса:

```cpp


std::array numbers {2, 3, 4, 5, 6};
```

для такого вывода в фигурных скобках нужно хотя бы одно значение. по пустому списку нельзя установить ни тип элемента, ни параметр длины.

### доступ к элементам

к элементам `std::array` обращаются тем же синтаксисом, что и к встроенному массиву: индекс записывается в квадратных скобках. `operator[]` границу не проверяет. индекс вне диапазона `[0, size())` даёт неопределённое поведение.

```cpp


#include <array>

#include <iostream>



int main()

{   

    std::array<int, 5> numbers {2, 3, 4, 5, 6};

    // получаем значение элемента

    int n = numbers[2];

    std::cout << "n = " << n << std::endl; // n = 4

    // меняем значение элемента

    numbers[2] = 12;

    std::cout << "numbers[2] = " << numbers[2] << std::endl; // numbers[2] = 12

}
```

### перебор контейнера

`std::array` обходится обычными циклами. цикл по индексу идёт от нуля до размера. диапазонный `for` проходит от `begin()` до `end()`.

```cpp


#include <iostream>

#include <array>

#include <string>

 

int main()

{   

    const unsigned n = 5;

    std::array<std::string, n> people { "Tom", "Alice", "Kate", "Bob", "Sam" };



	// обращение через индексы

    for(int i{}; i < n; i++)

    {

        std::cout << people[i] << std::endl;

    }

    std::cout << std::endl;

	// перебор последовательности

    for (auto person : people)

    {

        std::cout << person << std::endl;

    }

}
```

### основные функции array

добавить элемент в `std::array` или удалить имеющийся нельзя: число элементов зафиксировано параметром шаблона. основные операции типа:

- `size()`: возвращает размер контейнера, он равен второму параметру шаблона
- `at(index)`: возвращает элемент по индексу `index`. индекс проверяется, при выходе за границу генерируется исключение `std::out_of_range`
- `front()`: возвращает первый элемент
- `back()`: возвращает последний элемент
- `fill(n)`: присваивает всем элементам значение n

применение:

```cpp


#include <iostream>

#include <array>

#include <string>

 

int main()

{   

    std::array<std::string, 3> people { "Tom", "Bob", "Sam" };

    std::string second = people.at(1);    // Bob

    std::string first = people.front();  // Tom

    std::string last = people.back();    // Sam

 

    std::cout << second << std::endl;   // Bob

    std::cout << first << std::endl;    // Tom

    std::cout << last << std::endl;     // Sam

 

    // присваиваем всем элементам "Undefined"

    people.fill("Undefined");  // people = { "Undefined", "Undefined", "Undefined" }

    // проверяем

    for (int i{}; i< people.size(); i++)

    {

        std::cout << people[i] << std::endl;

    }

}
```

объект `std::array` копируется и присваивается как значение. встроенному массиву другой массив целиком присвоить нельзя: имя массива не является изменяемым lvalue массива. объекту `std::array` данные другого объекта того же типа передаются обычным копированием элементов:

```cpp


std::array<int, 5> numbers1 { 1, 2, 3, 4, 5 };

std::array<int, 5> numbers2 = numbers1;		// так можно сделать



int nums1[] = { 1,2,3,4,5 };

//int nums2[] = nums1;		// так нельзя следать
```

два контейнера `std::array` сравниваются операторами отношений. сравнение идёт поэлементно, в лексикографическом порядке:

```cpp


std::array<int, 5> numbers1 { 1, 2, 3, 4, 5 };

std::array<int, 5> numbers2 { 1, 2, 3, 4, 5 }; 

 

std::cout << std::boolalpha << (numbers1 == numbers2) << std::endl;  		// true

std::cout << std::boolalpha << (numbers1 != numbers2) << std::endl;		// false

std::cout << std::boolalpha << (numbers1 > numbers2) << std::endl; 		// false

std::cout << std::boolalpha << (numbers1 < numbers2) << std::endl; 	// false
```

в этом примере `numbers1` и `numbers2` содержат одинаковые элементы в одинаковом порядке, поэтому равны, а строгие отношения порядка ложны. сравнение встроенных массивов операторами начиная со стандарта c++20 объявлено устаревшим. поэлементное сравнение `std::array` остаётся частью его интерфейса.
