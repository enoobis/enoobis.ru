синтаксис указателя на функцию читается тяжело:

```cpp
#include <iostream>
 
int sum(int, int);

int main()
{
    int (*operation)(int, int) {sum};	// указатель operation указывает на функцию sum
    std::cout << operation(3, 5) << std::endl;
}
int sum(int x, int y){  return x + y;}
```

здесь `operation` есть указатель на функцию с двумя параметрами типа `int` и результатом типа `int`:

```cpp
int (*operation)(int, int)
```

даже такая запись трудна, а длинные имена типов параметров или результата делают декларатор ещё плотнее: звёздочка, скобки и список параметров смешиваются в одной конструкции. ключевое слово `auto` сокращает определение, когда инициализатор известен:

```cpp
auto operation {sum};
```

вывод типа требует инициализации конкретной функцией: без инициализатора `auto` не знает, какой тип выводить. явный тип всё же нужен для параметра функции, для члена класса, для объявления без инициализатора. указатель на функцию есть отдельный тип, и для него вводят псевдоним через `using`:

```cpp
#include <iostream>
 
// BinaryOp представляет указатель на функцию типа int (*)(int, int)
using BinaryOp = int (*)(int, int);

int sum(int, int);
int subtract(int, int);

int main()
{
    BinaryOp operation {sum};
    std::cout << operation(8, 5) << std::endl;	// 13
	operation = subtract;
    std::cout << operation(8, 5) << std::endl;	// 3
}
int sum(int x, int y){  return x + y;}
int subtract(int x, int y){  return x - y;}
```

псевдоним `BinaryOp` обозначает указатель на функцию типа `int (*)(int, int)`, то есть функцию двух аргументов `int` с результатом `int`.

```cpp
using BinaryOp = int (*)(int, int);
```

`using` вводит синоним существующего типа, а не новый тип. тот же синоним раньше записывали через `typedef int (*BinaryOp)(int, int);`. форма с `using` читается слева направо: имя, затем тип. после объявления псевдонима указатели объявляют уже его именем:

```cpp
BinaryOp operation {sum};
```

тем же псевдонимом задают тип параметра, и сигнатура функции высшего порядка обходится без вложенного декларатора:

```cpp
#include <iostream>
 
// BinaryOp представляет указатель на функцию типа int (*)(int, int)
using BinaryOp = int (*)(int, int);

int sum(int, int);
int subtract(int, int);
void do_operation(int, int, BinaryOp);

int main()
{
    do_operation(10, 6, sum);		// 16
    do_operation(10, 6, subtract);	// 4
}
void do_operation(int a, int b, BinaryOp op)
{
	double result = op(a, b);
	std::cout << result << std::endl;
}
int sum(int x, int y){  return x + y;}
int subtract(int x, int y){  return x - y;}
```

третий параметр `do_operation` имеет тип `int (*)(int, int)`. имя `BinaryOp` и эта запись взаимозаменяемы: на этапе компиляции это один тип, и функции `sum` и `subtract` передаются в `do_operation` без приведения. внутри `do_operation` результат вызова сохраняется в `double`. преобразование из `int` в `double` здесь безопасно по значению, хотя для целого результата тип `int` был бы точнее.
