контейнер `std::list` представляет двусвязный список: каждый узел хранит элемент и указатели на предыдущий и на следующий узлы. переход к соседнему элементу выполняется за постоянное время в обе стороны. переход к элементу по номеру был бы линеен по длине пути, поэтому оператор индексации в интерфейс не входит. итераторы списка двунаправленные. для использования типа подключается заголовочный файл `<list>`.

создание списка:

```cpp


#include <list>



int main()

{

    std::list<int> list1;				// пустой список

    std::list<int> list2(5);			// список list2 состоит из 5 чисел, каждый элемент имеет значение по умолчанию

    std::list<int> list3(5, 2);			// список list3 состоит из 5 чисел, каждое число равно 2

    std::list<int> list4{ 1, 2, 4, 5 };	// список list4 состоит из чисел 1, 2, 4, 5

    std::list<int> list5 = { 1, 2, 3, 5 }; // список list5 состоит из чисел 1, 2, 4, 5

    std::list<int> list6(list4);          // список list6 - копия списка list4

    std::list<int> list7 = list4;         // список list7 - копия списка list4

}
```

конструкторы задают пустой список, список из n элементов со значением по умолчанию, список из n копий заданного значения, список из списка инициализации и копию другого списка. копирование создаёт новые узлы и копирует элементы. два списка не разделяют узлы.

### получение элементов

для `std::list` не определены ни `operator[]`, ни функция `at()`. индекс противоречил бы стоимости двусвязного списка: чтобы дойти до i-го узла, нужно пройти i ссылок.

первый и последний элементы возвращают `front()` и `back()`. обе функции требуют непустой список, иначе поведение не определено.

элементы между первым и последним достигаются обходом: циклом по диапазону или итераторами.

```cpp


#include <iostream>

#include <list>



int main()

{

    std::list<int> numbers{ 1, 2, 3, 4, 5 };

 

    int first {numbers.front() };  // 1

    int last { numbers.back() };  // 5



    std::cout << "First: " << first << std::endl;

    std::cout << "Last: " << last << std::endl;

 

    // перебор в цикле

    for (int n : numbers)

        std::cout << n << "\t";

    std::cout << std::endl;

 

    // перебор с помощью итераторов

    for (auto iter = numbers.begin(); iter != numbers.end(); iter++)

    {

        std::cout << *iter << "\t";

    }

    std::cout << std::endl;

}
```

`front()` и `back()` возвращают ссылки на соответствующие элементы. диапазонный `for` последовательно разыменовывает итераторы от `begin()` до `end()`. явный цикл делает то же самое: условие `iter != numbers.end()`, шаг `iter++`, значение читается через `*iter`.

### размер списка

размер списка возвращает `size()`:

```cpp


std::list<int> numbers{ 1, 2, 3, 4, 5 };

int size = numbers.size();	 // 5
```

`empty()` возвращает `true`, если список пуст, и `false` в противном случае:

```cpp


std::list<int> numbers{ 1, 2, 3, 4, 5 };

if (numbers.empty())

	std::cout << "The list is empty" << std::endl;

else

	std::cout << "The list is not empty" << std::endl;
```

`resize()` меняет число элементов и имеет две формы:

- `resize(n)`: оставляет n первых элементов. если элементов больше n, список усекается до первых n. если элементов меньше n, недостающие добавляются и инициализируются значением по умолчанию
- `resize(n, value)`: так же оставляет n первых элементов. если элементов меньше n, недостающие получают значение `value`

применение:

```cpp


std::list<int> numbers{ 1, 2, 3, 4, 5, 6 };

numbers.resize(4);	// оставляем первые четыре элемента - numbers = {1, 2, 3, 4}



numbers.resize(6, 8);	 // numbers = {1, 2, 3, 4, 8, 8}
```

вставка и удаление узла в известной позиции меняют указатели соседних узлов и не сдвигают остальные элементы в памяти. итераторы на сохранённые узлы остаются действительными. при усечении `resize` инвалидирует только итераторы удалённых узлов.

### изменение элементов списка

`assign()` заменяет все элементы новым набором и уничтожает прежние узлы. формы:

- `assign(il)`: заменяет содержимое элементами списка инициализации `il`
- `assign(n, value)`: заменяет содержимое n элементами со значением `value`
- `assign(begin, end)`: заменяет содержимое элементами полуоткрытого диапазона, границы которого задают итераторы `begin` и `end`

применение:

```cpp


std::list<int> numbers { 1, 2, 3, 4, 5 };



numbers.assign({ 21, 22, 23, 24, 25 }); // numbers = { 21, 22, 23, 24, 25 }



numbers.assign(4, 3);		// numbers = {3, 3, 3, 3}



std::list<int> values { 6, 7, 8, 9, 10, 11 };

auto start = ++values.begin();	// итератор указывает на второй элемент из values

auto end = values.end();

numbers.assign(start, end); //  numbers = { 7, 8, 9, 10, 11 }
```

`swap()` обменивает содержимое двух списков. обмен выполняется за постоянное время: меняются внутренние указатели на цепочку узлов, элементы не копируются. итераторы остаются действительными и продолжают указывать на те же узлы.

```cpp


std::list<int> list1{ 1, 2, 3, 4, 5 };

std::list<int> list2{ 6, 7, 8, 9};

list1.swap(list2);

// list1 = { 6, 7, 8, 9};

// list2 = { 1, 2, 3, 4, 5 };
```

### добавление элементов

добавление в `std::list` возможно на обоих концах и в любой позиции, на которую уже есть итератор. вставка при известном итераторе занимает постоянное время: создаётся узел и переписываются две связи. узлы можно перенести из другого списка функцией `splice` за постоянное время, без копирования элементов. итераторы на перенесённые узлы остаются действительными.

- `push_back(val)`: добавляет значение `val` в конец списка
- `push_front(val)`: добавляет значение `val` в начало списка
- `emplace_back(val)`: создаёт элемент из аргументов в конце списка
- `emplace_front(val)`: создаёт элемент из аргументов в начале списка
- `emplace(pos, val)`: создаёт элемент `val` на позиции итератора `pos`. возвращает итератор на добавленный элемент
- `insert(pos, val)`: вставляет элемент `val` на позицию итератора `pos`. для готового значения результат совпадает с `emplace`. возвращает итератор на добавленный элемент
- `insert(pos, n, val)`: вставляет n элементов `val`, начиная с позиции `pos`. возвращает итератор на первый добавленный элемент. если n равно 0, возвращается итератор `pos`
- `insert(pos, begin, end)`: вставляет, начиная с `pos`, элементы другого контейнера из диапазона между итераторами `begin` и `end`. возвращает итератор на первый добавленный элемент. если между `begin` и `end` нет элементов, возвращается итератор `pos`
- `insert(pos, values)`: вставляет список значений `values`, начиная с позиции `pos`. возвращает итератор на первый добавленный элемент. если `values` не содержит элементов, возвращается итератор `pos`

функции `push_back()`, `push_front()`, `emplace_back()` и `emplace_front()`:

```cpp


std::list<int> numbers{ 1, 2, 3, 4, 5 };

numbers.push_back(23);	// { 1, 2, 3, 4, 5, 23 }

numbers.push_front(15);	// { 15, 1, 2, 3, 4, 5, 23 }

numbers.emplace_back(24);	// { 15, 1, 2, 3, 4, 5, 23, 24 }

numbers.emplace_front(14);	// { 14, 15, 1, 2, 3, 4, 5, 23, 24 }
```

добавление в середину списка функцией `emplace()`:

```cpp


std::list<int> numbers{ 1, 2, 3, 4, 5 };

auto iter = ++numbers.cbegin();	// итератор указывает на второй элемент

numbers.emplace(iter, 8); // добавляем после первого элемента  numbers = { 1, 8, 2, 3, 4, 5};
```

итератор `++numbers.cbegin()` указывает на второй элемент. `emplace` вставляет перед этой позицией, поэтому новое значение оказывается сразу после первого элемента.

добавление в середину списка функцией `insert()`:

```cpp


std::list<int> numbers1{ 1, 2, 3, 4, 5 };

auto iter1 = numbers1.cbegin();	// итератор указывает на первый элемент

numbers1.insert(iter1, 0); // добавляем начало списка  

//numbers1 = { 0, 1, 2, 3, 4, 5};



std::list<int> numbers2{ 1, 2, 3, 4, 5 };

auto iter2 = numbers2.cbegin();	// итератор указывает на первый элемент

numbers2.insert(++iter2, 3, 4); // добавляем после первого элемента три четверки  

//numbers2 = { 1, 4, 4, 4, 2, 3, 4, 5};



std::list<int> values { 10, 20, 30, 40, 50 };

std::list<int> numbers3{ 1, 2, 3, 4, 5 };

auto iter3 = numbers3.cbegin();	// итератор указывает на первый элемент

// добавляем в начало все элементы из values

numbers3.insert(iter3, values.begin(), values.end());

//numbers3 = { 10, 20, 30, 40, 50, 1, 2, 3, 4, 5};



std::list<int> numbers4{ 1, 2, 3, 4, 5 };

auto iter4 = numbers4.cend();	// итератор указывает на позицию за последним элементом

// добавляем в конец список из трех элементов

numbers4.insert(iter4, { 21, 22, 23 });

//numbers4 = { 1, 2, 3, 4, 5, 21, 22, 23};
```

первый вызов вставляет перед первым элементом, то есть в начало списка. второй вставляет три копии значения 4 перед вторым элементом. третий копирует в начало весь диапазон `values`. четвёртый вставляет список инициализации перед `cend()`, то есть в конец. возвращаемый итератор указывает на первый вставленный элемент, а при пустой вставке совпадает с переданным `pos`.

### удаление элементов

для удаления из `std::list` применяются следующие функции:

- `clear()`: удаляет все элементы
- `pop_back()`: удаляет последний элемент
- `pop_front()`: удаляет первый элемент
- `erase(p)`: удаляет элемент, на который указывает итератор `p`. возвращает итератор на элемент, следующий за удалённым, либо `end()`, если удалён последний элемент
- `erase(begin, end)`: удаляет элементы полуоткрытого диапазона `[begin, end)`. возвращает итератор на элемент, следующий за последним удалённым, либо `end()`, если диапазон доходил до конца

`pop_front()` и `pop_back()` требуют непустой список. `erase` инвалидирует только итераторы удалённых элементов. остальные узлы остаются на своих местах, их итераторы действительны.

применение:

```cpp


std::list<int> numbers { 1, 2, 3, 4, 5 };

numbers.pop_front();	// numbers = { 2, 3, 4, 5 }

numbers.pop_back();		// numbers = { 2, 3, 4 }

numbers.clear();	// numbers ={}



numbers = { 1, 2, 3, 4, 5 };

auto iter = numbers.cbegin(); // указатель на первый элемент

numbers.erase(iter);	// удаляем первый элемент

// numbers = { 2, 3, 4, 5 }



numbers = { 1, 2, 3, 4, 5 };

auto begin = numbers.begin(); // указатель на первый элемент

auto end = numbers.end();		// указатель на последний элемент

numbers.erase(++begin, --end);	// удаляем со второго элемента до последнего

//numbers = {1, 5}
```

после `pop_front()` и `pop_back()` из последовательности `{1, 2, 3, 4, 5}` остаётся `{2, 3, 4}`, затем `clear()` опустошает список. далее список восстанавливается присваиванием, и `erase` по итератору начала удаляет первый элемент. в последнем фрагменте `++begin` и `--end` задают диапазон со второго элемента до последнего, не включая последний: удаляются 2, 3 и 4, остаются `{1, 5}`.
