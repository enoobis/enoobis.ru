поразрядные операции выполняются над отдельными разрядами, битами чисел. такие операции определены только для целых типов. прежде чем разбирать сами операции, нужно зафиксировать, как целое число представлено разрядами.

### двоичное представление чисел

на уровне машины данные представлены набором битов. каждый бит принимает одно из двух значений: 1, сигнал есть, и 0, сигнала нет. любые данные в памяти сводятся к последовательности нулей и единиц. 8 бит составляют 1 байт. систему счисления с двумя цифрами называют двоичной.

число 13 в двоичной системе равно `1101`. перевод получается так:

```browser


// перевод десятичного числа 13 в двоичную систему

13 / 2 = 6      // остаток 1 (13 - 6 *2 = 1)

6 / 2 = 3      // остаток 0 (6 - 3 *2 = 0)

3 / 2 = 1      // остаток 1 (3 - 1 *2 = 1)

1 / 2 = 0      // остаток 1 (1 - 0 *2 = 1)
```

общий алгоритм состоит в последовательном делении числа и всех промежуточных частных на 2 с сохранением остатков, пока частное не станет нулём. остатки выстраивают в обратном порядке, от последнего к первому, и эта последовательность и есть двоичная запись. для числа 13 шаги такие:

- число 13 делится на 2. частное равно 6, остаток равен 1, поскольку 13 - 6 * 2 = 1
- частное предыдущего шага, число 6, делится на 2. частное равно 3, остаток равен 0
- число 3 делится на 2. частное равно 1, остаток равен 1
- число 1 делится на 2. частное равно 0, остаток равен 1
- последнее частное равно 0, процесс завершается. остатки от последнего к первому образуют `1101`

обратный перевод из двоичной системы в десятичную умножает значение каждого бита, 1 или 0, на степень двойки с показателем, равным номеру бита. нумерация битов начинается с нуля у младшего разряда:

```browser


// перевод двоичного числа 1101 в десятичную систему

1(3-й бит)1(2-й бит)0(1-й бит)1(0-й бит)

1 * 2<sup>3</sup> + 1 * 2<sup>2</sup> + 0 * 2<sup>1</sup> + 1 * 2<sup>0</sup>

=

1 * 8 + 1 * 4 + 0 * 2 + 1 * 1

=

8 + 4 + 0 + 1 

=

13
```

#### представление отрицательных чисел

для знаковых целых в c++ применяется дополнительный код (two's complement). старший разряд является знаковым. если он равен 0, число неотрицательное, и его двоичная запись совпадает с записью беззнакового числа той же ширины. например, 0000 0001 в десятичной системе есть 1.

если старший разряд равен 1, число отрицательное. например, 1111 1111 при ширине 8 бит есть -1, а 1111 0011 есть -13. начиная с c++20 дополнительный код является обязательным представлением знаковых целых, а не свойством конкретной реализации.

чтобы получить из положительного числа противоположное, его биты инвертируют и к результату прибавляют единицу:

![инверсия и дополнительный код в языке программирования c++](/uploads/course-lectures/eb5463e6125e03d5e58c2adbcf429741e25b5ecc.png)

например, требуется получить -3. сначала берётся двоичное представление числа 3:

```browser


3<sub>10</sub> = 0000 0011<sub>2</sub>
```

биты инвертируются:

```browser


~0000 0011 = 1111 1100
```

к результату прибавляется 1:

```browser


1111 1100 + 1 = 1111 1101
```

число `1111 1101` и есть двоичное представление -3 в восьми битах. старший бит равен 1, поэтому значение отрицательное. обратная операция та же: инверсия и прибавление единицы возвращают исходный модуль. у дополнительного кода есть практическое следствие для процессора: сложение знаковых и беззнаковых величин одной ширины выполняется одной и той же схемой сумматора, отдельного вычитателя для знака не требуется.

сложение знакового и беззнакового представлений на примере 12 и -8:

```browser


12<sub>10</sub> = 00001100<sub>2</sub>

+

-8<sub>10</sub> = 11111000<sub>2</sub> (8 - 00001000, после инверсии - 11110111, после +1 = 11111000)

=

4<sub>10</sub> = 00000100<sub>2</sub>
```

в двоичной сумме получается `00000100`, то есть 4 в десятичной системе. единица переноса из старшего разряда отбрасывается: ширина представления ограничена.

для наглядности в c++ есть двоичный литерал. он начинается с символов `0b`. апостроф внутри литерала разделяет группы разрядов и на значение не влияет. такая запись литералов относится к c++14.

```cpp


#include <iostream>



int main()

{

    unsigned int number{0b0000'1100};   // 12

    std::cout << number << std::endl;

}
```

переменная `number` инициализирована значением `0b0000'1100`, что в десятичной системе равно 12.

### операции сдвига

каждое целое число занимает в памяти фиксированное число разрядов. операции сдвига перемещают это битовое представление вправо или влево на заданное число позиций. оба операнда должны быть целыми. операций две:

- `<<` сдвигает битовое представление числа влево на заданное число разрядов. освободившиеся младшие разряды заполняются нулями
- `>>` сдвигает битовое представление числа вправо на заданное число разрядов. для беззнакового типа освободившиеся старшие разряды заполняются нулями

применение:

```c


unsigned int a = 2 << 2;			// 10  на два разрядов влево = 1000 - 8

unsigned int b = 16 >> 3;			// 10000 на три разряда вправо = 10 - 2
```

число 2 в двоичной записи есть 10. сдвиг на два разряда влево даёт 1000, то есть 8 в десятичной системе.

число 16 в двоичной записи есть 10000. сдвиг на три разряда вправо отбрасывает три младших разряда и даёт 10, то есть 2 в десятичной системе.

сдвиг на один разряд влево совпадает с умножением на 2, сдвиг на один разряд вправо для беззнакового числа совпадает с делением на 2 нацело. в общем виде сдвиг влево на `n` разрядов аналогичен умножению на `2` в степени `n`, а сдвиг вправо на `n` разрядов аналогичен делению на `2` в степени `n`. этим пользуются вместо умножения и деления на степень двойки:

```cpp


#include <iostream>



int main()

{

    unsigned int x{3};

    unsigned int number{7};

    unsigned int result{number << x};    // 7 * 2*2*2 = 56

    std::cout << "Result: " << result << std::endl;

    number = 26;

    result = number >> x;       // 26 / (2*2*2) = 3

    std::cout << "Result: " << result << std::endl;

}
```

если величина сдвига отрицательна или не меньше ширины типа после целочисленных продвижений, поведение сдвига не определено. в примерах выше величина сдвига заведомо меньше ширины `unsigned int`.

### поразрядные операции

поразрядные логические операции тоже определены только для целых операндов и применяются к каждой паре соответственных разрядов независимо:

- `&`: поразрядная конъюнкция (операция и, поразрядное умножение). разряд результата равен 1, только если оба соответственных разряда равны 1
- `|`: поразрядная дизъюнкция (операция или, поразрядное сложение). разряд результата равен 1, если хотя бы один из соответственных разрядов равен 1
- `^`: поразрядное исключающее или. разряд результата равен 1, если ровно один из двух соответственных разрядов равен 1
- `~`: поразрядное отрицание, инверсия. унарная операция, инвертирует все разряды операнда: 1 становится 0, 0 становится 1

применение:

```c


int a = 5 | 2;			// 101 | 010 = 111  - 7

int b = 6 & 2;			// 110 & 010 = 10  - 2

int c = 5 ^ 2;			// 101 ^ 010 = 111 - 7

int d = ~9;				// -10
```

выражение `5 | 2` равно 7. число 5 в двоичной записи есть 101, число 2 есть 10, или 010 в трёх разрядах. поразрядная дизъюнкция даёт 1 в позиции, где хотя бы один разряд равен 1:

| 1 | 0 | 1 |
| --- | --- | --- |
| 0 | 1 | 0 |
| 1 | 1 | 1 |

получается 111, то есть 7.

выражение `6 & 2` считается так же по разрядам. число 6 есть 110, число 2 есть 010. конъюнкция даёт 1 только в той позиции, где оба разряда равны 1:

| 1 | 1 | 0 |
| --- | --- | --- |
| 0 | 1 | 0 |
| 0 | 1 | 0 |

получается 010, то есть 2. инверсия `~` в примере применяется к знаковому `int`: инверсия всех битов, включая знаковый, даёт значение в дополнительном коде. для `~9` комментарий в фрагменте фиксирует результат -10.

### пример практического применения операций

поразрядные операции нужны там, где данные рассматривают как набор независимых битов, а не как одну арифметическую величину. один из приёмов состоит в упаковке нескольких маленьких чисел в одно машинное слово. пусть есть три числа, каждое в диапазоне от 1 до 3:

```cpp


int value1 {3};  // 0b0000'0011

int value2 {2};  // 0b0000'0010

int value3 {1};  // 0b0000'0001
```

значения не превосходят 3, значит каждому числу достаточно двух битов: 1, 2 и 3 записываются как 01, 10 и 11. три таких поля помещаются в одно целое. упаковку выполняют сдвигом и дизъюнкцией.

```cpp


#include <iostream>



int main()

{

    int value1 {3};  // 0b0000'0011

    int value2 {2};  // 0b0000'0010

    int value3 {1};  // 0b0000'0001

    int result {0b0000'0000};

    // сохраняем в result значения из value1

    result = result | value1; // 0b0000'0011

    // сдвигаем разряды в result на 2 разряда влево

    result = result << 2;   // 0b0000'1100

    // сохраняем в result значения из value2

    result = result | value2;  // 0b0000'1110

    // сдвигаем разряды в result на 2 разряда влево

    result = result << 2;   // 0b0011'1000

    // сохраняем в result значения из value3

    result = result | value3;  // 0b0011'1001

    std::cout << result << std::endl;   // 57

}
```

разбор идёт по шагам. сначала определены сохраняемые числа `value1`, `value2`, `value3`. для результата определена переменная `result`, исходно равная 0. для наглядности ноль записан двоичным литералом:

```cpp
int result = 0b0000'0000;
```

первое число заносится в `result` поразрядной дизъюнкцией:

```cpp


result = result | value1; // 0b0000'0011
```

дизъюнкция ставит 1 в результате там, где 1 стоит хотя бы в одном операнде. при нулевом `result` это просто копирует биты `value1`:

```cpp


0b0000'0000

+

0b0000'0011

=

0b0000'0011
```

первое число уже лежит в младших разрядах `result`. числа сохраняются по порядку: сначала первое, затем второе, затем третье. перед записью следующего поля текущее содержимое сдвигается на два разряда влево, потому что каждое число занимает не более двух разрядов:

```cpp


result = result << 2;   // 0b0000'1100
```

выполняется такое перемещение битов:

```cpp


0b0000'0011 << 2 = 0b0000'1100
```

затем дизъюнкция записывает второе число в освободившиеся младшие разряды:

```cpp
result = result | value2;  // 0b0000'1110
```

что эквивалентно

```cpp


0b0000'1100

+

0b0000'0010

=

0b0000'1110
```

далее снова сдвиг на два разряда влево и запись третьего числа. в `result` оказывается двоичное значение `0b0011'1001`. в десятичной системе это 57. само десятичное число здесь не существенно: существенны позиции битов. в одно слово помещены три числа, и в `result` ещё остаются свободные старшие разряды. ширина поля не обязана равняться двум битам. два бита выбраны только потому, что исходные значения не больше 3.

восстановление идёт в обратном порядке. младшие два бита читаются маской, затем слово сдвигается вправо, и становится доступным следующее поле:

```cpp


#include <iostream>



int main()

{

    int result {0b0011'1001};

    // обратное получение данных

    int newValue3 = result & 0b000'0011;

    // сдвигаем данные на 2 разряда вправо

    result = result >> 2;

    int newValue2 = result & 0b000'0011;

    // сдвигаем данные на 2 разряда вправо

    result = result >> 2;

    int newValue1 = result & 0b000'0011;

    std::cout << newValue1 << std::endl;   // 3

    std::cout << newValue2 << std::endl;   // 2

    std::cout << newValue3 << std::endl;   // 1

}
```

числа извлекаются в порядке, обратном порядку записи. каждое сохранённое число занимает два младших разряда после очередного сдвига, поэтому достаточно взять эти два бита. маска `0b000'0011` и конъюнкция оставляют 1 только там, где и в значении, и в маске стоит 1. операция

```cpp
int newValue3 = result & 0b000'0011;
```

эквивалентна

```cpp


0b0011'1001

*

0b0000'0011

=

0b0000'0001
```

младшее поле равно `0b0000'0001`, то есть 1 в десятичной системе. это исходное `value3`, записанное последним и прочитанное первым.

если расположение полей известно, маску можно поставить сразу на нужные разряды, не сдвигая слово шаг за шагом:

```cpp


#include <iostream>



int main()

{

    int result {0b0011'1001};

    int recreatedValue1 = (result & 0b0011'0000) >> 4;

    std::cout << recreatedValue1 << std::endl;

}
```

здесь восстанавливается первое число. оно занимает биты, которые в исходной упаковке оказались третьим и четвёртым полями, считая от младшего нуля, то есть разряды с номерами 4 и 5. конъюнкция с маской `0b0011'0000` обнуляет остальные разряды, сдвиг вправо на 4 возвращает поле к младшим битам.

```cpp


0b0011'1001

*

0b0011'0000

=

0b0011'0000

>> 4

=

0b0000'0011
```

если структура слова известна заранее, поля можно сразу записать на свои места, без промежуточных сдвигов всего результата. каждое значение сдвигается на смещение своего поля и соединяется с накопителем дизъюнкцией:

```cpp


#include <iostream>



int main()

{

    int value1 {3};  // 0b0000'0011

    int value2 {2};  // 0b0000'0010

    int value3 {1};  // 0b0000'0001

    int result {0b0000'0000};

    // сохраняем в result значения из value1

    result = result | (value1 << 4);

    // сохраняем в result значения из value2

    result = result | (value2 << 2);

    // сохраняем в result значения из value3

    result = result | value3;  // 0b0011'1001

    std::cout << result << std::endl;   // 57

}
```

итоговая раскладка битов совпадает с предыдущей упаковкой: `value1` занимает разряды со смещением 4, `value2` со смещением 2, `value3` лежит в младших двух разрядах. десятичное значение снова равно 57. маска при чтении должна повторять ту же раскладку, иначе из слова будет взято соседнее поле.
