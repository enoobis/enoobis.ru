у символьного массива своя инициализация. ему передают как набор отдельных символов, так и строковый литерал:

```cpp


char hello1[] {'h', 'e', 'l', 'l', 'o'};

char hello2[] {"hello"};	// {'h', 'e', 'l', 'l', 'o', '\0'}
```

на первый взгляд набор символов один и тот же: в первом случае это отдельные символы, во втором строка. длины при этом различаются. массив `hello1` содержит пять элементов. массив `hello2` содержит не 5, а 6 элементов: при инициализации строковым литералом в символьный массив добавляется нулевой символ `'\0'`, признак конца строки в стиле c.

| hello2[0] | hello2[1] | hello2[2] | hello2[3] | hello2[4] | hello2[5] |
| --- | --- | --- | --- | --- | --- |
| h | e | l | l | o | \0 |

способ определения влияет на дальнейшую работу. при выводе оператором `<<` объект `std::cout` печатает символы до байта `'\0'`. нулевой символ в конце обязателен. если его нет, на консоль уходят символы из последующих ячеек памяти, пока не встретится нулевой байт или не произойдёт недопустимое обращение к памяти. такое чтение за границей массива есть неопределённое поведение, и конкретный вывод не фиксирован. ниже сравнивается вывод трёх символьных массивов:

```cpp


#include <iostream>

 

int main()

{   

    char hello1[]{'h', 'e', 'l', 'l', 'o'};

    char hello2[]{'h', 'e', 'l', 'l', 'o', '\0'};

    char hello3[]{"hello"};

    

    std::cout << hello1 << std::endl;

    std::cout << hello2 << std::endl;

    std::cout << hello3 << std::endl;

}
```

пример консольного вывода:

```bash


hello╨J:╕╗☻

hello

hello
```

в первом случае вывод не детерминирован, потому что символьный массив не заканчивается нулевым символом. второй и третий массивы нулевой байт содержат, и печатается строка `hello`.

### двухмерные массивы символов

строку представляют массивом символов. массив строк тогда представляют двухмерным массивом символов: первая размерность задаёт число строк, вторая задаёт вместимость каждой строки:

```cpp


#include <iostream>

 

int main()

{   

    const int max_length{50}; // максимальная длина строки (включая нулевой байт \0)

    char langs[][max_length] 

    {

        "C++", "C#",  "Python", "Java",

        "Kotlin", "Go", "Dart", "PHP"

    };

    std::cout << langs[0] << std::endl;     // C++

    std::cout << langs[1] << std::endl;     // C#

    std::cout << langs[2] << std::endl;     // Python

}
```

массив `langs` содержит 8 элементов, то есть 8 строк. максимальное число символов в каждой строке, условно число столбцов, задаёт константа `max_length`, и в этот предел входит нулевой байт. сами строки не обязаны занимать всю длину. в строке `"C++"` четыре символа: три знака и автоматически добавленный нулевой символ. остальные элементы строки получают нулевые значения. тип строки здесь есть `char[50]`, а короткая строка занимает только начало этого массива.

каждый элемент `langs` представляет строку, поэтому по индексу получают нужную строку и выводят её на консоль. выражение `langs[i]` преобразуется в указатель на первый символ i-й строки, и оператор `<<` печатает символы до нулевого байта.

### перебор двухмерных символьных массивов

вложенные массивы представляют строки, то есть массивы символов, и каждый такой массив выводят на консоль как строку:

```cpp


#include <iostream>

  

int main()

{

    char langs[][20] { "C++", "Python", "JavaScript"};

    for(auto lang : langs)

    {

        std::cout << lang << std::endl;

    }

}
```

при переборе `langs` очередной элемент, массив символов, попадает в переменную `lang`. спецификатор `auto` в копирующем объявлении выводит указатель `char*`: массив в этом контексте распадается в указатель на первый символ. дальше этот указатель выводится как строка, снова до нулевого байта.

### ввод символьных массивов и строк с консоли

метод `getline()` потока `std::cin` (член `std::istream::getline`, не свободная функция `std::getline` для типа `std::string`) считывает последовательность символов, включая пробелы. по умолчанию ввод заканчивается, когда считан символ перевода строки `'\n'`, например при нажатии клавиши enter. символ-ограничитель из потока извлекается, но в массив не записывается. у метода две версии. первая принимает два параметра: первый указывает на массив символов, куда сохраняются данные, второй задаёт максимальное число символов, которое надо сохранить. в это число входит завершающий нулевой байт `'\0'`, который добавляется в конец ввода автоматически. фактически из потока сохраняется не более `max_length - 1` символов. если ограничитель так и не встретился, поток выставляет состояние ошибки:

```cpp


#include <iostream>

 

int main()

{   

    const int max_length {100};    // максимальное количиство считываемых символов

    char text[max_length] {};       // массив для считывания строки

    std::cout << "Enter some text:" << std::endl;

    // считываем символы, включая пробелы

    std::cin.getline(text, max_length);

    std::cout << "You entered:\n" << text << std::endl;

}
```

здесь в массив `text` считывается не более 100 символов, считая нулевой байт. пример ввода:

```bash


Enter some text:

Hello enoobis.ru

You entered:

Hello enoobis.ru
```

другая форма `getline()` принимает третий параметр: символ, который служит сигналом завершения ввода.

```cpp


#include <iostream>

 

int main()

{   

    const int max_length {100};    // максимальное количиство считываемых символов

    char text[max_length] {};       // массив для считывания строки

    std::cout << "Enter some text:" << std::endl;

    // считываем символы, включая пробелы

    std::cin.getline(text, max_length, '!');

    std::cout << "You entered:\n" << text << std::endl;

}
```

здесь окончанием ввода служит восклицательный знак `!`, и при считывании он в строку не включается:

```bash


Enter some text:

Hello World!

You entered:

Hello World
```
