через параметры в функцию передаются значения. параметры перечисляются после имени функции в круглых скобках и разделяются запятыми:

```cpp
(тип_параметра1 имя_параметра1, тип_параметра2 имя_параметра2, ... тип_параметраN имя_параметраN)
```

у каждого параметра указываются тип и имя. параметр есть объект, который инициализируется аргументом при вызове. его область видимости есть тело функции, время хранения автоматическое, если он не объявлен иначе.

ниже определяется и вызывается функция, которая выводит на консоль имя и возраст:

```cpp


#include <iostream>

#include <string>

 

void print(std::string name, unsigned age)

{

    std::cout << "Name: " << name << "\tAge: " << age << std::endl;

}

 

int main()

{

    print("Tom", 38);    // Name: Tom    Age: 38

}
```

запуск программы даёт такой консольный вывод:

```bash
Name: Tom    Age: 38
```

функция `print()` принимает два параметра и выводит их значения. первый параметр называется `name` и имеет тип `std::string`. второй называется `age` и имеет тип `unsigned`, то есть `unsigned int`. при вызове каждому параметру должно быть передано значение:

```cpp
print("Tom", 38);
```

значения, которые передаются параметрам при вызове, называются аргументами. в вызове выше аргументами служат строковый и целочисленный литералы. сопоставление идёт по позиции: первый аргумент, строка `"Tom"`, инициализирует первый параметр `name`, второй аргумент, число 38, инициализирует второй параметр `age`, и далее в том же порядке. имя параметра на месте вызова не участвует: язык сопоставляет аргументы слева направо по списку параметров.

аргумент должен совпадать с параметром по типу либо допускать неявное преобразование к этому типу. строковый литерал имеет тип массива `const char`, а параметр `name` имеет тип `std::string`. литерал неявно преобразуется в `std::string` при инициализации параметра. преобразование входит в последовательность инициализации копии, потому что параметр передаётся по значению и является отдельным объектом.

тем же способом в параметры передаются не только литералы, но и значения переменных и констант:

```cpp


#include <iostream>

#include <string>

 

void print(std::string name, unsigned age)

{

    std::cout << "Name: " << name << "\tAge: " << age << std::endl;

}

 

int main()

{

    const std::string userName {"Bob"};

    unsigned userAge {42};

    print(userName, userAge);    // Name: Bob    Age: 42 

}
```

при этом вызове параметр `name` получает значение константы `userName`, а параметр `age` получает значение переменной `userAge`. константность аргумента не мешает инициализации параметра по значению: в параметр копируется значение, а сама константа остаётся неизменной.

если функция объявлена прототипом, прототип после имени в скобках содержит типы параметров. имена в прототипе не обязательны: для вызова и для проверки соответствия объявления определению достаточно типов.

```cpp


#include <iostream>

#include <string>

 

void print(std::string, unsigned);  // прототип функции print

 

int main()

{

    print("Sam", 28);    // Name: Sam    Age: 28

}



void print(std::string name, unsigned age)

{

    std::cout << "Name: " << name << "\tAge: " << age << std::endl;

}
```

имена параметров в прототипе можно указать. на тип функции они не влияют и служат пояснением для читателя объявления:

```cpp
void print(std::string name, unsigned age);  // прототип
```

### аргументы по умолчанию

у параметра может быть аргумент по умолчанию: значение, которым параметр инициализируется, если при вызове соответствующий аргумент опущен.

```cpp


#include <iostream>

#include <string>



void print(std::string name, unsigned age = 18)

{

    std::cout << "Name: " << name << "\tAge: " << age << std::endl;

}

 

int main()

{

    print("Sam");       // Name: Sam    Age: 18

    print("Tom", 22);   // Name: Tom    Age: 22

}
```

значение по умолчанию записывается как инициализатор параметра, `unsigned age = 18`. если второй аргумент не передан, параметр `age` инициализируется числом 18. выражение по умолчанию подставляется на месте вызова. внутри тела функции этого выражения нет: вызов `print("Sam")` компилируется так, будто вторым аргументом передано 18. консольный вывод программы:

```bash


Name: Sam       Age: 18

Name: Tom       Age: 22
```

прототип такой функции тоже может содержать значение по умолчанию. тогда в определении это значение не повторяют: оно берётся из объявления, которое видно в точке вызова. повторно задавать один и тот же аргумент по умолчанию в более позднем объявлении нельзя, поэтому его пишут один раз, обычно в прототипе.

```cpp


#include <iostream>

#include <string>

 

void print(std::string, unsigned = 18);  // прототип

 

int main()

{

    print("Sam");       // Name: Sam    Age: 18

    print("Tom", 23);   // Name: Tom    Age: 23

}



void print(std::string name, unsigned age)

{

    std::cout << "Name: " << name << "\tAge: " << age << std::endl;

}
```

параметры с аргументом по умолчанию ставятся после обязательных. позиционное сопоставление не позволяет пропустить средний аргумент и передать следующий, поэтому параметр без значения по умолчанию не может стоять правее параметра, у которого такое значение есть. ниже значение по умолчанию назначается и параметру `name`:

```cpp


#include <iostream>

#include <string>

 

void print(std::string = "Undefined", unsigned = 18);  // прототип

 

int main()

{

    print();            // Name: Undefined  Age: 18

    print("Sam");       // Name: Sam    Age: 18

    print("Tom", 23);   // Name: Tom    Age: 23

}



void print(std::string name, unsigned age)

{

    std::cout << "Name: " << name << "\tAge: " << age << std::endl;

}
```

раз параметр `name` необязателен, следующий за ним параметр `age` тоже должен иметь значение по умолчанию. иначе объявление некорректно: компилятор не сможет решить, к какому параметру отнести единственный переданный аргумент. при обоих значениях по умолчанию допустимы три формы вызова. `print()` берёт оба значения из объявления. `print("Sam")` задаёт имя и оставляет возраст равным 18. `print("Tom", 23)` задаёт оба аргумента явно.

### автоматическое выведение типа параметров

начиная со стандарта c++20 вместо конкретного типа параметра можно указать служебное слово **auto**. тип тогда выводится при компиляции по переданному аргументу. функция с параметром `auto` есть сокращённый шаблон функции (abbreviated function template): каждое вхождение `auto` вводит независимый параметр шаблона, и вызов порождает отдельную специализацию.

```cpp


#include <iostream>



void sum(auto, auto);   // прототип функции sum



int main()

{

    const int n1{3};

    const int n2{4};

    sum(n1, n2);  // 3 + 4 = 7



    const double d1{3.3};

    const double d2{4.4};

    sum(d1, d2);;  // 3.3 + 4.4 = 7.7

}



void sum(auto a, auto b)

{

    auto result = a + b;

    std::cout << a << " + " << b << " = " << result << std::endl;

}
```

функция `sum` вычисляет сумму двух значений. в программу передаются числа разных типов, и зависимость от одного зафиксированного типа здесь не нужна. вместо типа в параметрах записано служебное слово `auto`. вызов с двумя `int` порождает специализацию для `int`, вызов с двумя `double` порождает другую специализацию для `double`. сложение и тип результата определяются уже внутри конкретной специализации по обычным правилам языка для оператора `+`.
