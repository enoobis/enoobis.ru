все инструменты для работы с системой ввода-вывода и потоками в языке c++ определены в стандартной библиотеке. заголовочный файл `iostream` определяет следующие базовые типы для работы с потоками:

- `istream` и `wistream`: читают данные из потока

- `ostream` и `wostream`: записывают данные в поток

- `iostream` и `wiostream`: читают и записывают данные в поток

для каждого типа определён его двойник, имя которого начинается на букву `w` и который предназначен для поддержки данных типа `wchar_t`. узкие потоки оперируют типом `char`, широкие оперируют типом `wchar_t`. перевод между внешней кодировкой и типом символа выполняет локаль, связанная с потоком.

эти типы являются базовыми для других классов, управляющих потоками ввода-вывода: файловыми, строковыми и прочими.

объект типа **ostream** получает значения различных типов, преобразует их в последовательность символов и передаёт их через буфер в определённое место для вывода: консоль, файл, сетевые интерфейсы и т.д. буфер потока, `streambuf`, отделяет форматирование от устройства и накапливает символы перед фактической записью.

![поток вывода ostream в с++](/uploads/course-lectures/bb2c6c221d4e6a9983233b0a2e0e5949231fc3a5.png)

поток **istream** получает через буфер из определённого места последовательности символов (с консоли, из файла, из сети и т.д.) и преобразует эти последовательности в значения различных типов. при вводе данных, в том числе с клавиатуры в консоли, символы сначала накапливаются в буфере и только затем передаются объекту `istream`.

![поток ввода istream в с++](/uploads/course-lectures/0416c8107332ec68ee4e50013f22617ff8256a0e.png)

по умолчанию в стандартной библиотеке определены объекты этих классов: **cout**, **cin**, **cerr**. они работают с консолью. `cout` связан со стандартным выводом, `cin` со стандартным вводом, `cerr` с потоком диагностики.

### запись в поток

для записи данных в поток `ostream` применяется оператор `<<`. он принимает два операнда: левый является потоком вывода, правый является значением, которое форматируется и помещается в поток. чтение из потока `istream` выполняет оператор `>>`: левый операнд представляет поток `istream`, с которого производится считывание, а правый операнд представляет объект, в который считываются данные. оператор `>>` пропускает ведущие пробельные символы и разбирает лексему по типу правого операнда.

для чтения с консоли применяется объект **cin**, который представляет тип `istream`.

```cpp


#include <iostream>

 

int main()

{   

    int age;

    double weight;

    std::cout << "Input age: ";

    std::cin >> age;

    std::cout << "Input weight: ";

    std::cin >> weight;

    std::cout << "Your age: " << age << "\t your weight: " << weight << std::endl;

}
```

такой способ плохо подходит для чтения строк с консоли, особенно когда считываемая строка содержит пробельные символы: оператор `>>` останавливается на первом пробеле. в этом случае используется встроенная функция `getline()`, которая в качестве параметра принимает поток `istream` и переменную типа `string`, в которую нужно считать данные:

```cpp


#include <iostream>

#include <string>



int main()

{

	std::string name;

	std::cout << "Input name: ";

	getline(std::cin, name);

	//std::cin >> name;

	std::cout << "Your name: " << name <<std::endl;

}
```

пример работы программы:

```bash


Input name: Tom Smit

Your name: Tom Smit
```

по умолчанию признаком окончания ввода служит перевод на другую строку, например с помощью клавиши enter. свой признак окончания ввода задаётся дополнительным параметром функции `getline()`. для этого передаётся символ, который служит окончанием ввода:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text;

    std::cout << "Input text: " << std::endl;

    getline(std::cin, text, '*');   // окончанием ввода будет служить символ *

    std::cout << "\nYour text:" <<std::endl;

    std::cout << text <<std::endl;

}
```

ввод завершается, когда вводится символ `*`. так вводится многострочный текст, а при вводе звёздочки ввод завершается. символ-разделитель в результирующую строку не входит. пример работы программы:

```bash


Input text:

Hello World

Good bye world*



Your text:

Hello World

Good bye world
```

### вывод ошибок

для вывода сообщения об ошибке на консоль применяется объект **cerr**, который представляет объект типа `ostream`:

```cpp


#include <iostream>



int main()

{

	std::cerr << "Error occured" << std::endl;

}
```

`cerr` связан со стандартным потоком ошибок. его можно перенаправить отдельно от `cout`, и по умолчанию он сбрасывает буфер чаще, чтобы диагностика не задерживалась.

### потоки символов wchar_t

для работы с потоками данных типа `wchar_t` в стандартной библиотеке определены объекты **wcout** (тип `wostream`), **wcerr** (тип `wostream`) и **wcin** (тип `wistream`). они являются аналогами объектов `cout`, `cerr` и `cin` и работают аналогично, но над широкими символами.

```cpp


#include <iostream>



int main()

{

	int age;

	double weight;

	std::wcout << "Input age: ";

	std::wcin >> age;

	std::wcout << "Input weight: ";

	std::wcin >> weight;

	if (age <= 0 || weight <= 0)

		std::wcerr << "Invalid data" << std::endl;

	else

		std::wcout << "Your age: " << age << "\t your weight: " << weight << std::endl;

}
```
