помимо членов, которые принадлежат конкретному объекту, в c++ есть члены, принадлежащие классу как типу. их называют статическими. для объявления служит служебное слово **static**. у статического члена одно значение на весь класс. отдельной копии в каждом объекте у него нет, в представление экземпляра он не входит, и `sizeof` по объекту его не учитывает.

### статические поля

статические переменные хранят состояние, общее для всех объектов класса. статическая переменная определяется один раз, имеет статическую продолжительность хранения и существует, даже если ни один объект класса не создан. обратиться к ней можно и до первого экземпляра, если она доступна по имени класса.

показательный случай: счётчик созданных объектов. количество относится к классу и свойством отдельного человека не является.

```cpp


#include <iostream>

#include <string>



class Person

{

public:

	Person(std::string p_name, unsigned p_age)

	{

        ++count;    // при создании нового объекта увеличиваем счетчик

		name = p_name;

        age = p_age;

	}

    void print_count()

    {

        std::cout << "Created " << count << " objects" << std::endl;

    }

private:

	std::string name;

    unsigned age;

    static inline unsigned count{};  // статическое поле - счетчик объектов Person

};



int main()

{

    Person tom{"Tom", 38};

    Person bob{"Bob", 42};

    Person sam{"Sam", 25};

    tom.print_count();

    bob.print_count();

    sam.print_count();

}
```

в `Person` статическая переменная `count` объявлена со служебным словом **static**.

```cpp
static inline unsigned count{}; // инициализируем нулем
```

после **static** стоит **inline**. слово **static** задаёт классовую принадлежность и статическую продолжительность хранения. **inline** к этому смыслу не относится: оно нужно здесь, чтобы инициализатор внутри класса был определением. начиная с c++17 такое определение помещают прямо в класс, в том числе в заголовок, и правило одного определения не нарушается. без **inline** неконстантный статический член в классе только объявляется, а единственное определение с инициализатором выносят в одну единицу трансляции. в примере `count` инициализируется нулём: пустые фигурные скобки для `unsigned` дают значение 0.

при каждом создании объекта конструктор увеличивает счётчик на единицу.

```cpp


Person(std::string p_name, unsigned p_age)

{

    ++count;    // при создании нового объекта увеличиваем счетчик
```

в функциях-членах `Person` эта статическая переменная доступна по имени, объект для этого не требуется. `print_count` выводит её значение.

```cpp


void print_count()

{

    std::cout << "Created " << count << " objects" << std::endl;

}
```

в `main` создаются три объекта `Person`, и у каждого вызывается `print_count`.

```cpp


tom.print_count();

bob.print_count();

sam.print_count();
```

`count` одна на весь класс и от того, через какой объект её читают, не зависит. после трёх конструкторов во всех трёх вызовах будет выведено 3. вызов через `tom`, `bob` или `sam` читает одну и ту же переменную.

### статические функции

статическая функция-член тоже принадлежит классу и к отдельному объекту не привязана. неявного параметра `this` у неё нет, поэтому к нестатическим членам она напрямую не обращается: нестатический член существует только у объекта. обычное назначение статической функции состоит в работе со статическими переменными. `print_count` печатает `count` и к `name` и `age` не обращается, поэтому её и объявляют статической.

```cpp


#include <iostream>

#include <string>



class Person

{

public:

	Person(std::string p_name, unsigned p_age)

	{

        ++count;    // при создании нового объекта увеличиваем счетчик

		name = p_name;

        age = p_age;

	}

    // статическая функция

    static void print_count()

    {

        std::cout << "Created " << count << " objects" << std::endl;

    }

private:

	std::string name;

    unsigned age;

    static inline unsigned count{};  // статическое поле - счетчик объектов Person

};



int main()

{

    Person tom{"Tom", 38};

    Person bob{"Bob", 42};

    Person sam{"Sam", 25};

    tom.print_count();  // Created 3 objects

}
```

перед статической функцией также записывают **static**.

```cpp


static void print_count()
```

вызов по-прежнему допустим через имя любого объекта. объект здесь только называет класс, в теле функции конкретный экземпляр не используется.

```cpp


tom.print_count();
```

### обращение к статическим членам класса

статический член можно вызвать через объект. есть и вторая форма, объект в ней не участвует: имя класса, оператор `::` и имя члена.

```cpp
класс::член_класса
```

после имени класса стоит оператор разрешения области видимости `::` и имя статического члена. пример с открытым статическим полем и статической функцией:

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    static inline unsigned maxAge{120};     // статическая публичная переменная

	Person(std::string p_name, unsigned p_age)

	{

        ++count;

		name = p_name;

        if(p_age < maxAge)  // если значение не больше максимального

            age = p_age;

	}

    // статическая функция

    static void print_count()

    {

        std::cout << "Created " << count << " objects" << std::endl;

    }

private:

	std::string name;

    unsigned age{1};

    static inline unsigned count{};  // статическая приватная переменная

};



int main()

{

    Person tom{"Tom", 38};

    Person bob{"Bob", 42};

    Person sam{"Sam", 25};

    

	// обращаемся к статической функции print_count

    Person::print_count();

	// обращаемся к статической переменной maxAge

    std::cout << "Max age: " << Person::maxAge << std::endl;

	// изменяем статическую переменную maxAge

	Person::maxAge = 110;

    std::cout << "Max age: " << Person::maxAge << std::endl;

}
```

добавлено открытое статическое поле `maxAge`, верхняя граница возраста. граница от конкретного объекта не зависит и относится ко всему классу `Person`, поэтому поле статическое. конструктор сравнивает аргумент с `maxAge`. условие в коде записано как `p_age < maxAge`. если оно выполнено, `age` получает переданное значение. если нет, член остаётся равным инициализатору по умолчанию, числу 1. дальше по имени класса вызывается `print_count`, читается `maxAge`, затем `maxAge` изменяется. поле открытое и неконстантное, запись в него законна для любого кода, который видит класс.

```cpp


Person::print_count();

Person::maxAge
```

консольный вывод программы:

```bash


Created 3 objects

Max age: 120

Max age: 110
```

### статические константы

статический член может быть константой. менять `maxAge` в предыдущем примере незачем, и поле объявляют константным. присваивание такому члену не компилируется. чтение и использование в конструкторе устроены так же, как у неконстантного статического поля: доступ по имени класса или через объект, одно значение на весь класс.

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    static inline const unsigned maxAge{120};     // статическая константа

	Person(std::string p_name, unsigned p_age)

	{

        ++count;

		name = p_name;

        if(p_age < maxAge)  // если значение не больше максимального

            age = p_age;

	}

    // статическая функция

    static void print_count()

    {

        std::cout << "Created " << count << " objects" << std::endl;

    }

private:

	std::string name;

    unsigned age{1};

    static inline unsigned count{};  // статическая приватная переменная

};



int main()

{

    Person tom{"Tom", 38};

    Person bob{"Bob", 42};

    

	// обращаемся к статическим компонентам класса

    Person::print_count();

    std::cout << "Max age: " << Person::maxAge << std::endl;

}
```
