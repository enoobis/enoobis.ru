`find()` возвращает индекс первого вхождения подстроки или одного символа. тип результата есть `size_t`. поиск идет от начала строки к концу, сравнение подстроки посимвольное:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"A friend in need is a friend indeed."};

    std::cout << text.find("ed") << std::endl;      // 14

    std::cout << text.find("friend") << std::endl;  // 2

    std::cout << text.find('d') << std::endl;     // 7

    std::cout << text.find("apple") << std::endl;  // 18446744073709551615

}
```

если строка или символ не найдены, как `"apple"` в последнем вызове, возвращается константа `std::string::npos`. это наибольшее значение типа `size_t`, то есть `static_cast<size_t>(-1)`. на платформе с 64-битным `size_t` печать дает 18446744073709551615. результат `find()` сравнивают с этой константой, а не с конкретным десятичным числом: на 32-битной платформе битовая длина `size_t` другая.

```cpp


if (text.find("banana") == std::string::npos)

{

    std::cout << "Not found" << std::endl;

}
```

у `find` есть дополнительные перегрузки. второй параметр задает индекс, с которого начинается поиск. символы левее этого индекса не рассматриваются. если вхождения нет и правее, снова возвращается `npos`:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"A friend in need is a friend indeed."};

    // поиск с 10-го индекса

    std::cout << text.find("friend", 10) << std::endl;      // 22

}
```

с этой перегрузкой считают, сколько раз подстрока встречается в тексте:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"A friend in need is a friend indeed."};

    std::string word {"friend"};

    unsigned count{};       // количество вхождений

    for (unsigned i {}; i <= text.length() - word.length(); )

    {

        // получаем индекс

        size_t position = text.find(word, i);

        // если не найдено ни одного вхождения с индекса i, выходим из цикла

        if (position == std::string::npos) break;

        // если же вхождение найдено, увеличиваем счетчик вхождений

        ++count;

        // переходим к следующему индексу после position

        i = position + 1;

    }

    std::cout << "The word is found " << count << " times." << std::endl; // The word is found 2 times.

}
```

цикл идет по тексту, пока `i` не превысит `text.length() - word.length()`. `find(word, i)` возвращает индекс первого вхождения слова, начиная с `i`. если вхождения нет, `position` равен `std::string::npos`, и цикл прерывается. если индекс найден, счетчик `count` увеличивается, а `i` становится позицией сразу после найденного начала: `position + 1`. сдвиг на один символ позволяет найти и перекрывающиеся вхождения. слово `friend` в тексте встречается дважды, поэтому программа печатает:

```bash
The word is found 2 times.
```

тот же подсчет записывают циклом `while`. здесь следующий поиск начинается не на символ правее найденного начала, а на `word.length()` символов правее, то есть сразу за найденным вхождением. перекрывающееся вхождение такой сдвиг пропускает. для `friend` перекрытий нет, и счетчик совпадает с предыдущей программой:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"A friend in need is a friend indeed."};

    std::string word {"friend"};

    unsigned count{};       // количество вхождений

    size_t index{}; // начальный индекс

    while ((index = text.find(word, index)) != std::string::npos)

    {

        ++count;

        index += word.length(); // перемещаем индекс на позицию после завершения слова в тексте

    }

    std::cout << "The word is found " << count << " times." << std::endl;

}
```

третья перегрузка ищет не всю строку, а ее префикс заданной длины. третий параметр есть число символов искомой строки. эта перегрузка принимает строковый литерал или строку в стиле c, то есть `const char*` с завершающим нулевым байтом. перегрузки `find` от `std::string` с отдельным ограничением длины нет: объект `string` ищется целиком, начиная с заданной позиции.

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"A friend in need is a friend indeed."};

    std::string word {"endless"};

    // поиск с 10-го индекса 3 первых символов слова "endless", то есть "end"

    std::cout << text.find("endless", 10, 3) << std::endl;      // 25

}
```

вызов ищет с 10-го индекса три первых символа литерала `"endless"`, то есть `"end"`.

#### функция rfind. поиск в обратном порядке

`rfind()` принимает те же параметры, что и `find()`, и ищет последнее вхождение: просмотр идет от конца строки к началу. при отсутствии вхождения тоже возвращается `std::string::npos`.

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"A friend in need is a friend indeed."};

    std::cout << text.rfind("ed") << std::endl;      // 33

    std::cout << text.rfind("friend") << std::endl; // 22

    std::cout << text.rfind('d') << std::endl;     // 34

    std::cout << text.rfind("apple") << std::endl;  // 18446744073709551615

}
```

`rfind("friend")` дает 22, это начало второго слова `friend`. `rfind("ed")` и `rfind('d')` указывают на вхождения ближе к концу, чем результат `find` для тех же аргументов.

### поиск любого из набора символов

`find_first_of()` и `find_last_of()` возвращают соответственно первый и последний индекс любого символа из переданного набора:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Phone number: +23415678901"};

    std::string letters{"0123456789"};  // искомые символы

    std::cout << text.find_first_of(letters) << std::endl;      // 15

    std::cout << text.find_last_of(letters) << std::endl;      // 25

}
```

в строке `Phone number: +23415678901` ищется первая и последняя позиция любого символа из `0123456789`. так получают начало и конец записи номера.

если нужна позиция символа, которого в наборе нет, применяют `find_first_not_of()` для первой такой позиции и `find_last_not_of()` для последней:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Phone number: +23415678901"};

    std::string letters{"0123456789"};  // искомые символы

    std::cout << text.find_first_not_of(letters) << std::endl;      // 0

    std::cout << text.find_last_not_of(letters) << std::endl;      // 14

}
```

эти четыре функции комбинируют. программа ниже считает слова в строке:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"When in Rome, do as the Romans do."};    // исходный текст

    const std::string separators{ " ,;:.\"!?'*\n" }; // разделители слов

    unsigned count{};   // счетчик слов

    size_t start { text.find_first_not_of(separators) }; // начальный индекс первого слова

    while (start != std::string::npos) // если нашли слово

    {

        // увеличиваем счетчик слов

        count++;

        size_t end = text.find_first_of(separators, start + 1); // находим, где кончается слово

        if (end == std::string::npos) 

        {

            end = text.length();

        }

        start = text.find_first_not_of(separators, end + 1); // находим начальный индекс следующего слова и переустанавливаем start

    }

    // выводим количество слов

    std::cout << "Text contains " << count << " words" << std::endl;    // Text contains 8 words

}
```

текст лежит в `text`. отдельно задана строка разделителей: знаки пунктуации, пробел и перевод строки. сами разделители словами не считаются.

```cpp


const std::string separators{ " ,;:.\"!?'*\n" }; // разделители слов
```

перед циклом фиксируется индекс первого символа первого слова. `find_first_not_of()` возвращает первый индекс символа, которого нет в `separators`:

```cpp
size_t start { text.find_first_not_of(separators) };
```

цикл `while` проверяет, что индекс действителен:

```cpp
while (start != std::string::npos)
```

если в строке только символы из `separators`, `find_first_not_of()` возвращает `std::string::npos`. это означает, что непробельных и непунктуационных символов больше нет, и цикл не начинается.

пока `start` указывает на начало слова, счетчик слов увеличивается. затем ищется индекс первого разделителя строго после начала слова. этот индекс есть позиция сразу после последнего символа слова и сохраняется в `end`:

```cpp
size_t end = text.find_first_of(separators, start + 1); // находим, где закончилось слово
```

поиск конца выполняет `find_first_of()`: первая позиция любого символа из `separators`, начиная с индекса `start + 1`.

`find_first_of()` может не найти разделитель. так бывает, когда слово стоит в конце текста и после него нет ни пунктуации, ни пробела. тогда конец слова полагают равным длине текста:

```cpp


if (end == std::string::npos) // если НЕ найден ни один из символов-разделителей

    end = text.length();        // устанавливаем переменную end на конец текста
```

после того как известны начало и конец слова, `start` переносится на начало следующего слова, и цикл повторяется:

```cpp


start = text.find_first_not_of(separators, end + 1); // находим начальный индекс следующего слова и переустанавливаем start
```

по выходе из цикла печатается число найденных слов. для текста примера это 8.
