класс `std::priority_queue` представляет очередь приоритетов. тип объявлен в заголовочном файле `<queue>`, в том же заголовке, что и `std::queue`. по набору операций адаптер ближе к `std::stack`: наружу отдаются чтение вершины через `top()` и снятие вершины через `pop()`. порядок извлечения определяется приоритетом. момент вставки сам по себе положение элемента не задаёт.

внутри поддерживается куча. элемент с наивысшим приоритетом доступен на вершине за постоянное время, вставка и снятие логарифмичны по числу элементов. вложенным контейнером по умолчанию служит `std::vector`, компаратором по умолчанию служит `std::less`. при таком компараторе приоритетнее больший элемент, и `top()` возвращает максимум.

пустая очередь приоритетов:

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::priority_queue<std::string> queue;

}
```

### размер очереди

`size()` возвращает число элементов в очереди приоритетов. `empty()` возвращает `true`, если очередь пуста:

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::priority_queue<std::string> queue;

    if(queue.empty())

    {

        std::cout << "queue is empty" << std::endl;

    }

    std::cout << "queue size: " << queue.size() << std::endl; // queue size: 0

}
```

### добавление элементов

элемент добавляется функцией `push()`. после вставки куча восстанавливает инвариант: при компараторе `std::less` родитель в куче не меньше своих потомков.

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::priority_queue<std::string> queue;



    // добавляем три элемента

    queue.push("Tom");

    queue.push("Bob");

    queue.push("Sam");



	std::cout << "queue size: " << queue.size() << std::endl; // queue size: 3

}
```

### получение элементов

прочитать можно только элемент с наивысшим приоритетом. для этого служит `top()`.

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::priority_queue<std::string> queue;



    // добавляем три элемента

    queue.push("Sam");

    queue.push("Tom");

    queue.push("Bob");



	std::cout << "First: " << queue.top() << std::endl; // Top: Tom

}
```

первой в очередь попадает строка `"Sam"`, последней строка `"Bob"`, а `top()` возвращает `"Tom"`. положение задаёт компаратор. порядок вызовов `push` с этим положением не совпадает. при каждой вставке элементы сравниваются, и на вершине остаётся приоритетный.

по умолчанию первыми располагаются условно большие элементы. строка `"Tom"` больше строк `"Sam"` и `"Bob"` в лексикографическом порядке: символ `T` идёт в алфавите после `S` и `B`. очередь приоритетов при этом выглядит так:

```browser


Tom(1) - Sam (2) - Bob(3)
```

другой пример, уже для целых чисел:

```cpp


#include <iostream>

#include <queue>



int main()

{

    std::priority_queue<int> numbers;



    numbers.push(4);

    numbers.push(22);

    numbers.push(13);



	std::cout << "First: " << numbers.top() << std::endl; // Top: 22

}
```

элементы располагаются по убыванию приоритета:

```browser


22 - 13 - 4
```

максимум 22 оказывается на вершине, хотя вставлен вторым.

### удаление элементов

`pop()` снимает элемент с вершины, текущий наиболее приоритетный, и заново выстраивает кучу среди оставшихся элементов:

```cpp
queue.pop()
```

вместе `top()` и `pop()` извлекают все элементы в порядке убывания приоритета:

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::priority_queue<std::string> queue;

    queue.push("Sam");

    queue.push("Tom");

    queue.push("Bob");



    while (!queue.empty())	// пока очередь не станет пустой

    {

        std::cout << queue.top() << std::endl;

        queue.pop();	// извлекаем первый элемент

    }

}
```

пока очередь не пуста, программа печатает вершину и снимает её. консольный вывод программы:

```bash


Tom

Sam

Bob
```

порядок `"Tom"`, `"Sam"`, `"Bob"` совпадает с убыванием строк при компараторе по умолчанию. вставка шла в другом порядке: сначала `"Sam"`, затем `"Tom"`, затем `"Bob"`.
