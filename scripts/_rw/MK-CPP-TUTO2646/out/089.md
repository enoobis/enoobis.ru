шаблон класса (class template) позволяет объявить в классе члены, тип которых на момент написания кода неизвестен и задаётся аргументом шаблона при инстанцировании. прежде чем вводить синтаксис, фиксируется дублирование, которое шаблон снимает.

требуется класс пользователя с двумя полями: имя и `id`, отличающий одного пользователя от другого. имя естественно хранить строкой. тип `id` заранее не фиксирован: число, строка или иной тип, и в разных задачах выгодны разные представления. чаще всего для `id` выбирают число или строку, и без шаблона это два почти одинаковых класса:

```cpp


#include <iostream>

#include <string>



// класс Person, где id - целое число

class UintPerson {

public:

    UintPerson(unsigned id, std::string name) : id{id}, name{name}

    { }

    void print() const  

    {

        std::cout << "Id: " << id << "\tName: " << name << std::endl;

    }

private:

    unsigned id;

    std::string name;

};



// класс Person, где id - строка

class StringPerson {

public:

    StringPerson(std::string id, std::string name) : id{id}, name{name}

    { }

    void print() const  

    {

        std::cout << "Id: " << id << "\tName: " << name << std::endl;

    }

private:

    std::string id;

    std::string name;

};

 

int main()

{

    UintPerson tom{123456, "Tom"};

    tom.print();    // Id: 123456      Name: Tom

    StringPerson bob{"tvi4xhcfhr", "Bob"};

    bob.print();    // Id: tvi4xhcfhr  Name: Bob

}
```



`UintPerson` хранит `id` как целое беззнаковое (`unsigned`), `StringPerson` хранит `id` как `std::string`. в `main` создаются объекты обоих типов, и оба объекта пригодны к использованию. классы совпадают по устройству и отличаются только типом поля `id`. появление ещё одного типа идентификатора потребовало бы третьего класса. шаблон класса в c++ задаёт это семейство одним определением и тем самым уменьшает повторяемость кода.

шаблон класса записывают так:

```cpp


template <список_параметров>

class имя класса

{

	// содержимое шаблона класса

};
```



перед классом ставится ключевое слово `template` и угловые скобки со списком параметров. несколько параметров разделяют запятой.

далее шаблон, как и обычный класс, начинается с `class` (или `struct`, если определяется структура), затем имя и тело в фигурных скобках. определение заканчивается точкой с запятой. тело устроено так же, как у обычного класса, но на месте конкретных типов допускаются параметры шаблона. шаблон класса наследуется, объявляет функции, поля, конструкторы и переопределяет виртуальные функции.

перед именем параметра пишут `typename` или `class`:

```cpp


template <typename T>

// или так

template <class T>
```



здесь один параметр с именем `T`. выбор между `class` и `typename` в списке параметров шаблона на смысл не влияет: оба ключевых слова вводят параметр-тип.

классы `UintPerson` и `StringPerson` сворачиваются в один шаблон:

```cpp


#include <iostream>

#include <string>

 

template <typename T>

class Person {

public:

    Person(T id, std::string name) : id{id}, name{name}

    { }

    void print() const  

    {

        std::cout << "Id: " << id << "\tName: " << name << std::endl;

    }

private:

    T id;

    std::string name;

};

int main()

{

    Person tom{123456, "Tom"};		// T - число

    tom.print();    // Id: 123456      Name: Tom

    Person bob{"tvi4xhcfhr", "Bob"};	// T - строка

    bob.print();    // Id: tvi4xhcfhr  Name: Bob

}
```



шаблон использует один параметр `T`. конкретный тип на этапе написания кода неизвестен и определяется при создании специализации.

```cpp


template <typename T>

class Person {
```



этот параметр задаёт тип поля `id`:

```cpp
T id;
```



при создании объекта `Person` компилятор выводит аргумент шаблона по первому параметру конструктора. механизм называется выведением аргументов шаблона класса (class template argument deduction) и доступен начиная с c++17. в первом вызове:

```cpp
Person tom{123456, "Tom"};
```



в `id` передаётся литерал `123456`. целочисленный литерал без суффикса имеет тип `int`, поэтому выведенный тип поля `id` тоже `int`.

во втором вызове:

```cpp
Person bob{"tvi4xhcfhr", "Bob"};
```



в `id` передаётся строковый литерал `"tvi4xhcfhr"`. его тип есть массив `const char` фиксированной длины. параметр конструктора принимает значение по значению, массив вырождается в указатель, и поле `id` получает тип `const char*`.

компилятор порождает два определения класса, по одному на набор аргументов: для `int` и для `const char*`. объекты создаются уже по этим специализациям.

тип можно указать явно в угловых скобках после имени шаблона:

```cpp


int main()

{

    Person<unsigned> tom{123456, "Tom"};

    tom.print();    // Id: 123456      Name: Tom

    Person<std::string> bob{"tvi4xhcfhr", "Bob"};

    bob.print();    // Id: tvi4xhcfhr  Name: Bob

}
```



параметров может быть несколько. класс банковского перевода:

```cpp


#include <iostream>

#include <string>

 

template <typename T, typename V>

class Transaction

{

public:

    Transaction(T fromAcc, T toAcc, V code, unsigned sum):

        fromAccount{fromAcc}, toAccount{toAcc}, code{code}, sum{sum}

    { }

    void print() const

    {

        std::cout << "From: " << fromAccount << "\tTo: " << toAccount

            << "\tSum: " << sum << "\tCode: " << code << std::endl;

    }

private:

    T fromAccount;  // с какого счета

    T toAccount;    // на какой счет

    V code;         // код операции

    unsigned sum;   // сумма перевода

};

 

int main()

{

    // явная типизация

    Transaction<std::string, int> transaction1{"id1234", "id5678", 2804, 5000};

    transaction1.print();   // From: id1234    To: id5678      Sum: 5000       Code: 2804

    // неявная типизация

    Transaction transaction2{"id6789", "id9018", 3000, 6000};

    transaction2.print();   // From: id6789    To: id9018      Sum: 6000       Code: 3000

}
```



`Transaction` объявляет параметры `T` и `V`. `T` задаёт тип счетов, участвующих в переводе: число, строка или другой тип. `V` задаёт тип кода операции и тоже не ограничен одним типом.

при явной подстановке указывают оба типа, по позиции:

```cpp
Transaction<std::string, int> transaction1("id1234", "id5678", 2804, 5000);
```



первый аргумент, `std::string`, подставляется вместо `T`, второй, `int`, вместо `V`.

для `transaction2` типы `T` и `V` выводятся из аргументов конструктора.

### определение функций вне шаблона класса

определение функции-члена вне тела шаблона записывается иначе, чем внутри. такое определение само является шаблоном, даже если тело не употребляет параметр шаблона: член принадлежит специализации `Person<T>`, и без заголовка `template` имя `Person<T>` в точке определения не объявлено.

имя конструктора вне класса уточняется именем специализации:

```cpp


#include <iostream>

#include <string>

  

template <typename T>

class Person {

public:

    Person(T, std::string);             // обычный конструктор

    Person(const Person&);              // конструктор копирования

    ~Person();                          // деструктор

    Person& operator=(const Person&);   // оператор присваивания

    void print() const;                 // функция класса



private:

    T id;

    std::string name;

};

// определение конструктора вне шаблона класса

template <typename T>

Person<T>::Person(T id, std::string name) : id{id}, name{name} { }

// определение конструктора копирования вне шаблона класса

template <typename T>

Person<T>::Person(const Person& person) : id{person.id}, name{person.name} { }



// определение деструктора копирования вне шаблона класса

template <typename T>

Person<T>::~Person(){ std::cout << "Person deleted" << std::endl; }



// определение оператора присвоения вне шаблона класса

template <typename T>

Person<T>& Person<T>::operator=(const Person& person)

{ 

    if (&person != this)

    {

        name = person.name;

        id = person.id;

    }

    return *this;

}



// определение функции вне шаблона класса

template <typename T>

void Person<T>::print() const 

{

    std::cout << "Id: " << id << "\tName: " << name << std::endl;

}



int main()

{

    Person tom{123456, "Tom"};

    tom.print();



    Person tomas{tom};  // конструктор копирования

    tomas.print();



    Person tommy = tom; // оператор присваивания

    tommy.print();

}
```



все члены, включая конструкторы, деструктор, оператор присваивания и `print`, определены как члены шаблона `Person<T>`. конструктор копирования и `print` не упоминают `T` в теле, но остаются шаблонами, потому что принадлежат шаблону класса. то же относится к деструктору. комментарий в листинге называет его деструктором копирования, тогда как объявление `~Person()` является деструктором объекта.

квалифицированное имя `Person<T>::Person` связывает определение с шаблоном. параметр `T` в этой записи тот же, что в заголовке `template <typename T>`.

### параметры шаблонов по умолчанию

как и параметры функций, параметры шаблона могут иметь аргумент по умолчанию: тип, который подставляется, если аргумент не задан явно и не выведен из инициализатора.

```cpp


#include <iostream>

#include <string>

  

template <typename T=int>

class Person {

public:

    Person(std::string name) : name{name} { }

    void setId(T value) { id = value;}

    void print() const 

    {

        std::cout << "Id: " << id << "\tName: " << name << std::endl;

    }

private:

    T id;

    std::string name;

};

int main()

{

    Person<std::string> bob{"Bob"};    // T - std::string

    bob.setId("id1345");

    bob.print();    // Id: id1345  Name: Bob



    Person tom{"Tom"};      // T - int

    tom.setId(23456);

    tom.print();    // Id: 23456    Name: Tom

}
```



для параметра `T` типом по умолчанию указан `int`. этот параметр определяет тип поля `id`, которое задаётся функцией `setId`.

тип указывают явно в угловых скобках:

```cpp


Person<std::string> bob{"Bob"};    // T - std::string

bob.setId("id1345");
```



аргумент шаблона `std::string`, поэтому `id` является строкой.

если тип не указан, применяется умолчание `int`. конструктор `Person(std::string)` не зависит от `T`, поэтому вывести `T` из аргументов вызова нельзя, и остаётся аргумент по умолчанию:

```cpp


Person tom{"Tom"};      // T - int

tom.setId(23456);
```



здесь `id` имеет целочисленный тип.
