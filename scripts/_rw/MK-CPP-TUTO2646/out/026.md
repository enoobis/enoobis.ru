со строками в c++ работают и в стиле c: как с массивами символов, которые оканчиваются нулевым байтом `'\0'`. если такой байт не найден или удалён при обработке, дальнейшие действия со строкой дают неопределённый результат. по этой причине строки в стиле c считают небезопасными. для хранения строк в c++ используют тип `std::string` из заголовка `<string>`.

объект типа `std::string` хранит последовательность символов типа `char` и может быть пустым. длина хранится в самом объекте, отдельно от завершающего нулевого байта, который интерфейс в стиле c (`data()`, `c_str()`) поддерживает с c++11. из-за явной длины строка может содержать `'\0'` и в середине, тогда как массив в стиле c на первом же нулевом байте заканчивается. пустая строка:

```cpp
std::string message;
```

переменной типа `std::string` присваивают и конкретную строку. допустимы списковая инициализация, копирующая инициализация и прямая инициализация:

```cpp


std::string message {"Hello enoobis.ru!"};

// или так

std::string message2 = "Hello enoobis.ru!";

std::string message3("Hello enoobis.ru!");
```

переменная `message` получает копию строкового литерала `"Hello enoobis.ru!"`. во внутреннем представлении объект хранит массив символов, который тоже заканчивается нулевым байтом, однако размер известен объекту, а не вычисляется поиском этого байта. реализация `std::string` и операции этого типа делают работу безопаснее, чем ручной обход буфера. объект владеет буфером: при копировании и при уничтожении память согласуется с временем жизни строки. в распространённых реализациях короткая строка хранится внутри самого объекта, без отдельного выделения, но стандарт такой оптимизации не требует.

объект `std::string` инициализируют и другим объектом `std::string`. конструктор копирования копирует последовательность символов:

```cpp


std::string hello{"hello world"};

std::string message {hello}; // message = "hello world"

// или так

// std::string message (hello);

// std::string message = hello;
```

такую строку выводят на консоль тем же оператором `<<`, что и строку в стиле c. для `std::string` оператор выводит ровно `size()` символов:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string message {"Hello enoobis.ru!"};

    std::cout << "Message: " << message << std::endl;	// Message: Hello enoobis.ru!

}
```

### получение и изменение символов строки

как и у массива, к отдельным символам обращаются по индексу: читают их и изменяют. индекс по-прежнему начинается с нуля. оператор `[]` границ не проверяет, выход за длину строки есть неопределённое поведение. метод `at()` при выходе за границу выбрасывает исключение `std::out_of_range`:

```cpp


std::string hello {"Hello"};

char c {hello[1]};		// e

hello[0]='M';

std::cout << hello << std::endl;	// Mello
```

последовательность символов перебирают циклом `for`. ниже считается, сколько раз встречается буква `l`:

```cpp


#include <iostream>

#include <string>



int main()

{

    unsigned count{};	// счетчик, сколько раз встречается символ

    std::string message{ "Hello World"};

    for(const char c: message)

    {

        if(c == 'l')

        {

            count++;

        }

    }

    std::cout << "Count: " << count << std::endl;   // Count: 3

}
```

переменная цикла имеет тип `const char`: символ копируется, и через эту переменную строку не меняют. в `"Hello World"` буква `l` стоит три раза, что и печатает программа.

### чтение строки с консоли

для считывания введённой строки, как и для других значений, используют объект `std::cin`. оператор `>>` читает одну лексему и останавливается на пробельном символе:

```cpp


#include <iostream>

#include <string>



int main()

{	

	std::string name;

	std::cout << "Input your name: ";

	std::cin >> name;

	std::cout << "Your name: " << name << std::endl;

}
```

консольный вывод:

```bash


Input your name: Tom

Your name: Tom
```

если строка содержит подстроки, разделённые пробелом, `std::cin` вместе с оператором `>>` забирает только первую подстроку. остаток строки остаётся во входном буфере:

```bash


Input your name: Tom Smith

Your name: Tom
```

чтобы считать всю строку, включая пробелы, применяют свободную функцию `getline()`. ограничителем по умолчанию служит `'\n'`, он извлекается из потока и в строку не записывается:

```cpp


#include <iostream>

#include <string>



int main()

{	

	std::string name;

	std::cout << "Input your name: ";

	getline(std::cin, name);

	std::cout << "Your name: " << name << std::endl;

}
```

функция `getline` принимает два объекта: поток `std::cin` и переменную, в которую нужно считать строку.

консольный вывод:

```bash


Input your name: Tom Smith

Your name: Tom Smith
```
