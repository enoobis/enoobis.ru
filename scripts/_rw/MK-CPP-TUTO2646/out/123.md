объект-функция и лямбда-выражение не являются указателями на функции: у каждого свой уникальный тип класса. чтобы хранить указатель на функцию, объект-функцию и лямбду в переменной одного типа, заголовок `<functional>` определяет шаблон **std::function**. `std::function` стирает конкретный тип вызываемого объекта и оставляет фиксированную сигнатуру. внутри может оказаться указатель на функцию, функтор или лямбда-выражение, в том числе с захватом переменных.

```cpp
#include <iostream>
#include <functional>   // для std::function

class Sum
{
public:
    int operator()(int a, int b){ return a + b;}
};

int subtract(int a, int b){return a - b;}

int main()
{
    std::function<int(int,int)> operation;

    operation = Sum{};  // operation представляет объект-функцию Sum
    std::cout << operation(10, 6) << std::endl;     // 16

    operation = subtract;  // operation представляет функцию subtract
    std::cout << operation(10, 6) << std::endl;     // 4

    auto multiply = [](int a, int b){return a * b;};
    operation = multiply;  // operation представляет лямбда-выражение multiply
    std::cout << operation(10, 6) << std::endl;     // 60
}
```

для `std::function` подключается заголовочный файл `<functional>`.

```cpp
#include <functional>
```

в `main` объявляется переменная этого типа.

```cpp
std::function<int(int,int)> operation;
```

`operation` обозначает вызываемый объект с двумя параметрами типа `int` и результатом типа `int`. сигнатура записана в угловых скобках шаблона: `std::function<int(int, int)>`. пустой объект `std::function` вызывать нельзя: такой вызов бросает исключение `std::bad_function_call`. в примере перед вызовом всегда выполняется присваивание.

переменной присваивается объект-функция. временный `Sum{}` сохраняется внутри `operation` по семантике типа-обёртки.

```cpp
operation = Sum{};
```

затем присваивается обычная функция. имя `subtract` приводится к указателю на функцию, и этот указатель тоже укладывается в ту же сигнатуру.

```cpp
operation = subtract;
```

или лямбда-выражение. тип замыкания безымянный и не совпадает с типом `Sum`, но после стирания типа переменная `operation` одна и та же.

```cpp
auto multiply = [](int a, int b){return a * b;};
operation = multiply;
```

вызов во всех трёх случаях записывается одинаково: `operation` вызывается как функция, аргументы передаются её параметрам. различие целей скрыто внутри обёртки, снаружи видна только сигнатура.

```cpp
operation(10, 6)
```

другой пример.

```cpp
#include <iostream>
#include <string>
#include <functional>   // для std::function

class Console
{
public:
    void operator()(const std::string& message) 
    {
        std::cout << message << std::endl;
    }
};

void print(const std::string& message)
{
    std::cout << message << std::endl;
}

int main()
{
    std::function<void(std::string)> action;

    action = Console{};
    action("Word");

    action = print;
    action("Work");

    auto log = [](const std::string& mes){std::cout << mes << std::endl;};
    action = log;
    action("World");
}
```

здесь `action` имеет тип `std::function<void(std::string)>`: аргумент является строкой, результата нет. в эту переменную по очереди помещаются функтор `Console`, свободная функция `print` и лямбда `log`. параметр функтора и функции имеет тип `const std::string&`, а у обёртки параметр передаётся как `std::string`. это совместимо: аргумент конструируется как строка и связывается с константной ссылкой.

такая унификация нужна, когда тип вызываемого объекта нельзя сделать параметром шаблона: поле класса, элемент контейнера, нешаблонная функция. плата за единый тип состоит в косвенном вызове и, если вызываемый объект не помещается во внутренний буфер реализации, в динамическом выделении памяти. когда вызываемый объект известен на этапе компиляции и может быть параметром шаблона, шаблон обходится без этого слоя.
