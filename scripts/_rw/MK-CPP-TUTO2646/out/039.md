если параметр функции объявлен как массив, в функцию фактически передаётся указатель на первый элемент. параметр типа «массив» в объявлении функции приводится к указателю (array-to-pointer adjustment). массив при этом не копируется. как и у явного указателя, у функции есть адрес, по которому можно читать и менять элементы. два объявления ниже равносильны и задают одну и ту же функцию:

```cpp


void print(int numbers[]);

void print(int *numbers);
```

передача массива в функцию выглядит как передача его имени. имя массива в этом контексте преобразуется в указатель на нулевой элемент:

```cpp


#include <iostream>



void print(int[]);



int main()

{

    int nums[] {1, 2, 3, 4, 5};

	print(nums);

}



void print(int numbers[])

{

	std::cout << "First number: " << numbers[0] << std::endl;	// First number: 1

}
```

функция `print` выводит на консоль первый элемент массива. индексная запись `numbers[0]` для параметра-указателя есть адресация относительно полученного адреса: она равносильна `*(numbers + 0)`.

тот же параметр можно объявить указателем явно:

```cpp


#include <iostream>



void print(int*);



int main()

{

    int nums[] {1, 2, 3, 4, 5};

	print(nums);

}



void print(int *numbers)

{

	std::cout << "First number: " << *numbers << std::endl;

}
```

в функцию снова передаётся массив, но параметр сразу объявлен как указатель на первый элемент. разыменование `*numbers` читает этот элемент. вызывающий код в обоих вариантах устроен одинаково: выражение `nums` преобразуется в `int*`.

### ограничения

раз параметр, записанный как массив, рассматривается как указатель на первый элемент, длину исходного массива по нему получить нельзя. тип параметра уже не несёт границы массива.

```cpp


void print(int numbers[])

{

	int size = sizeof(numbers) / sizeof(numbers[0]);

	// или так 

	// size_t size = std::size(nums);

	std::cout << size << std::endl;

}
```

`sizeof(numbers)` здесь равен размеру указателя. размер исходного массива это выражение не даёт. деление на `sizeof(numbers[0])` даёт отношение размера указателя к размеру элемента. число элементов, выделенных в `main`, так не получить. `std::size` требует массив или диапазон с известной границей и к голому указателю не применяется. информация о длине потеряна в момент вызова.

по той же причине диапазонный цикл `for` по этому параметру невозможен. диапазонный `for` строит пару границ через массив или через `begin`/`end`. указатель границей диапазона не является:

```cpp


void print(int numbers[])

{

	for (int n : numbers)

		std::cout << n << std::endl;

}
```

### передача маркера конца массива

чтобы определять конец последовательности, перебирать элементы и обращаться к ним по индексу, нужен маркер, который сигнализирует об окончании. используются разные соглашения. все они восстанавливают границу, которую преобразование массива в указатель отбросило.

первый подход: один из элементов сам обозначает конец. массив символов может быть строкой в смысле c, то есть последовательностью символов, завершённой нулевым символом `'\0'`. нулевой символ служит признаком конца символьного массива. строковый литерал такой символ содержит, и он копируется в массив при инициализации.

```cpp


#include <iostream>



void print(char[]);



int main()

{

	char chars[] {"Hello"};

	print(chars);

}



void print(char chars[])

{

	for (unsigned i{}; chars[i] != '\0'; i++)

	{

		std::cout << chars[i];

	}

}
```

при таком соглашении массив обязан содержать признак завершения. если нулевого байта в последовательности нет, цикл продолжит чтение за границей массива. это неопределённое поведение: будут прочитаны соседние байты памяти, и останов зависит от того, встретится ли нулевой байт дальше. поэтому для массивов произвольного типа обычно передают размер отдельно:

```cpp


#include <iostream>

 

void print(int[], size_t);

 

int main()

{

    int nums[]{1, 2, 3, 4, 5};

    size_t n {std::size(nums)};

    print(nums, n);

}

 

void print(int numbers[], size_t n)

{

    for(size_t i {}; i < n; i++)

    {

        std::cout << numbers[i] << "\t";

    }

}
```

третий подход передаёт указатель на конец массива. конец можно вычислить вручную, прибавив длину к адресу начала. ту же пару границ дают библиотечные функции **std::begin()** и **std::end()**. для массива они определены так, что тип границы остаётся указателем на элемент, а длина берётся из типа массива в точке вызова, где она ещё известна:

```cpp


int nums[] { 1, 2, 3, 4, 5 };

int *begin {std::begin(nums)};		// указатель на начало массива

int *end {std::end(nums)};		// указатель на конец массива
```

`end` возвращает адрес позиции, следующей за последним элементом. диапазон полуоткрытый: начало входит в него, конец нет. длина равна разности этих указателей, а сравнение `ptr != end` корректно и тогда, когда массив пуст и оба указателя совпадают.

применение этих функций:

```cpp


#include <iostream>



void print(int*, int*);



int main()

{

	int nums[] { 1, 2, 3, 4, 5 };

	int *begin {std::begin(nums)};

	int *end {std::end(nums)};



	print(begin, end);

}



void print(int *begin, int *end)

{

	for (int *ptr {begin}; ptr != end; ptr++)

	{

		std::cout << *ptr << "\t";

	}

}
```

цикл продвигает указатель от `begin` до `end` и разыменовывает его, пока адреса не совпадут. тело не выполняется для позиции `end`, потому что по адресу за последним элементом объекта нет.

### константные массивы

вместе с указателем на первый элемент функция получает возможность менять элементы. если массив менять не нужно, параметр-массив объявляют константным. `const int*` запрещает запись по этому указателю и не запрещает чтение. константность параметра не делает константным сам массив в вызывающем коде: она ограничивает только данный путь доступа.

```cpp


#include <iostream>

 

void print(const int*, const size_t);

void twice(int*, const size_t);

 

int main()

{

    int numbers[]{1, 2, 3, 4, 5};

    size_t n = std::size(numbers);

    print(numbers, n);

    twice(numbers, n); // увеличиваем элементы массива в два раза

    print(numbers, n);

}

 

void print(const int numbers[], const size_t n)

{

    for(size_t i {}; i < n; i++)

    {

        std::cout << numbers[i] << "\t";

    }

    std::cout << std::endl;

}

void twice(int *numbers, const size_t n)

{

    for(size_t i {}; i < n; i++)

    {

        numbers[i] = numbers[i] * 2;

    }

}
```

функция `print` только выводит значения, поэтому её параметры константные. и указатель на данные, и размер помечены `const`: размер в теле не переназначается, элементы не записываются.

функция `twice` удваивает элементы, поэтому её параметр-массив неконстантный. запись `numbers[i] = numbers[i] * 2` меняет объект вызывающего кода. после `twice` массив `numbers` в `main` уже содержит удвоенные значения, и второй вызов `print` показывает новое состояние.

консольный вывод программы:

```bash


1	2	3	4	5

2	4	6	8	10
```

### передача массива по ссылке

массив можно передать и по ссылке. ссылка на массив не подвергается преобразованию в указатель: параметр обозначает сам массив. отдельная копия адреса при такой передаче не создаётся. прототип функции, которая принимает массив по ссылке, выглядит так:

```cpp


void print(int (&)[]);
```

скобки в записи `(&)` обязательны. без них объявление читалось бы иначе из-за приоритета `[]` над `&`. скобки фиксируют, что по ссылке передаётся именно массив.

```cpp


#include <iostream>

 

void print(int (&)[], size_t);



int main()

{

    int nums[] {1, 2, 3, 4, 5};

    size_t count = std::size(nums);

    print(nums, count);

}

void print(int (&numbers)[], size_t count)

{

    for(size_t i{}; i < count; i++)

    {

        std::cout << numbers[i] << "\t";

    }

}
```

тем же способом передаётся константная ссылка на массив. константность запрещает менять элементы через параметр и позволяет связать ссылку с константным массивом:

```cpp


void print(const int (&)[]);
```

на первый взгляд передача массива по ссылке мало что меняет: при передаче по значению и так уходит только адрес. преимущества тем не менее есть. во-первых, не копируется даже значение адреса: параметр есть другое имя исходного массива, и функция работает с ним непосредственно. во-вторых, ссылка на массив известной длины включает длину в тип. компилятор в точке вызова знает число элементов и отвергает массив другой длины. проверка статическая, до выполнения программы.

```cpp


#include <iostream>

 

void print(const int (&)[5]); // массив строго с 5 элементами



int main()

{

    int nums1[] {1, 2, 3, 4, 5};

    print(nums1);

}

void print(const int (&numbers)[5])

{

    for(unsigned i{}; i < 5; i++)

    {

        std::cout << numbers[i] << "\t";

    }

}
```

функция `print` принимает ссылку строго на массив из 5 элементов. длина входит в тип `const int (&)[5]`, поэтому отдельно передавать размер не нужно. граница цикла может быть константой 5, и она согласована с типом параметра.

если передать массив с другим числом элементов, программа не компилируется. типы ссылок на массивы разной длины различны, и неявного преобразования между ними нет:

```cpp


int nums2[] {1, 2, 3, 4, 5, 6};

print(nums2); // ! Ошибка - в массиве nums2 6 элементов
```

при компиляторе visual c++ от microsoft в такой ссылке обязательно указывают размер массива. ссылка на массив неизвестной границы для этого компилятора не подходит как параметр, через который вызывают функцию с конкретным массивом.

### передача многомерного массива

многомерный массив тоже передаётся как указатель на первый элемент. элемент многомерного массива сам является массивом, поэтому указатель на первый элемент есть указатель на массив: указуемый тип сам является массивом. у массива `int[n][3]` тип элемента есть `int[3]`, и после преобразования к указателю получается `int (*)[3]`.

когда параметр объявлен как указатель на массив, размер второй размерности и всех следующих размерностей должен быть задан. этот размер есть часть типа элемента. без него тип указателя не полон, и адресная арифметика по строкам не определена: шаг равен размеру строки. пример объявления:

```cpp
void print(int (*numbers)[3]);
```

передаваемый массив предполагается двумерным, и каждый его подмассив содержит 3 элемента. скобки вокруг имени параметра обязательны: они задают указатель на массив. иная расстановка скобок задаёт другой тип:

```cpp
void print(int *numbers[3])
```

здесь параметр есть массив указателей. указателем на массив такое объявление не является. тип `int *numbers[3]` есть `int*[3]`. в параметр тогда попал бы указатель на первый из трёх указателей, и разметка памяти не совпала бы с двумерным массивом `int[][3]`.

применение указателя на массив в качестве параметра:

```cpp


#include <iostream>

 

void print(const int(*)[3], const size_t);

int main()

{

    int table[][3] { {1, 2, 3}, {4, 5, 6}, {7, 8, 9} };

    // количество строк или подмассивов

    size_t rowsCount {std::size(table)};

    print(table, rowsCount);

}

 

void print(const int (*rows)[3], const size_t rowsCount)

{

    // количество столбцов или элементов в каждом подмассиве

    size_t columnsCount {std::size(*rows)};

    for(size_t i{}; i < rowsCount; i++)

    {

        for (size_t j{}; j < columnsCount; j++)

        {

            std::cout << rows[i][j] << "\t";

        }

        std::cout << std::endl;

    }

}
```

в `main` определяется двумерный массив из трёх подмассивов, по три элемента в каждом. внешняя граница в типе опущена и выводится из инициализатора, внутренняя равна 3 и совпадает с параметром `const int (*)[3]`.

в `print` вместе с массивом передаётся число строк, то есть число подмассивов. `std::size` от массива в `main` ещё видит внешнюю границу. внутри `print` число элементов подмассива получают как `std::size(*rows)`: разыменование указателя на массив даёт массив из 3 `int`, и его длина известна из типа. два цикла обходят все элементы. выражение `rows[0]` обозначает первый подмассив, выражение `rows[0][0]` обозначает первый элемент первого подмассива. меняя индексы, обходят весь двумерный массив. шаг `rows + 1` сдвигает адрес на целую строку из трёх `int`, потому что тип указуемого объекта есть `int[3]`.

консольный вывод:

```bash


1	2	3

4	5	6

7	8	9
```

ту же функцию можно объявить в нотации массивов. она читается проще нотации указателей, но вторую размерность всё равно указывают явно. запись `const int[][3]` в параметре приводится к тому же указателю на массив из трёх `int`. первая пустая граница в типе параметра не восстанавливается и заменяется отдельным аргументом `rowsCount`.

```cpp


#include <iostream>

 

void print(const int[][3], const size_t);

int main()

{

    int table[][3] { {1, 2, 3}, {4, 5, 6}, {7, 8, 9} };

    // количество строк или подмассивов

    size_t rowsCount {std::size(table)};

    print(table, rowsCount);

}

 

void print(const int rows[][3], const size_t rowsCount)

{

    // количество столбцов или элементов в каждом подмассиве

    size_t columnsCount {std::size(rows[0])};

    for( size_t i{}; i < rowsCount; i++)

    {

        for (size_t j{}; j < columnsCount; j++)

        {

            std::cout << rows[i][j] << "\t";

        }

        std::cout << std::endl;

    }

}
```
