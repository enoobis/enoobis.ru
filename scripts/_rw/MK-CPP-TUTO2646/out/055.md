помимо встроенных типов, таких как `int` и `double`, в программе определяют собственные типы, **классы**. класс есть составной тип: он собирает другие типы в один и задаёт для них операции.

класс описывает некоторый тип объектов. класс есть описание этого типа, объект есть конкретное воплощение класса, его экземпляр. представлению о человеке с именем, возрастом и прочими характеристиками соответствует класс, то есть общий шаблон. конкретные воплощения шаблона различаются: у одного человека одно имя, у другого другое. реально рассматриваемый человек есть **объект**, или **экземпляр**, этого класса. в терминах языка класс задаёт формат значения и набор операций, а экземпляр есть значение этого типа, занимающее память.

класс вводят ключевым словом `class`, за которым следует имя:

```c#


class имя_класса

{

	// компоненты класса

};
```

после имени в фигурных скобках перечисляют компоненты класса. после закрывающей скобки стоит точка с запятой. определение класса есть объявление, и точка с запятой его завершает. пропущенная точка с запятой часто заставляет компилятор принять следующее объявление за продолжение класса.

простейший класс:

```cpp


class Person { };



int main()

{



}
```

класс называется `Person`. имена классов обычно начинают с большой буквы. этот класс пуст и не содержит компонентов, но уже образует новый тип. после определения можно объявлять переменные и константы этого типа:

```cpp


class Person

{



};

int main()

{

	Person person;

}
```

пустой класс почти ничего не делает: размер пустого объекта ненулевой, в распространённых реализациях он равен 1, чтобы у разных экземпляров были разные адреса. ни состояния, ни операций у такого класса нет. класс может определять переменные и константы, в которых хранится состояние объекта, и функции, которыми задано его поведение. в `Person` добавляются и состояние, и поведение:

```cpp


#include <iostream>

#include <string>



class Person 

{

public:

    std::string name;

    unsigned age;

    void print() 

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

};

int main()

{

    Person person;

    // устанавливаем значения полей класса

    person.name = "Tom";

    person.age = 38;

    // вызываем функцию класса

    person.print();

}
```

у `Person` две переменные, `name` и `age`. они хранят имя и возраст. переменные класса называют **полями**. в стандарте это нестатические члены данных. функция `print` печатает значения полей. модификатор доступа `public:` открывает идущие за ним переменные и функции внешнему коду. у `class` члены по умолчанию закрыты (`private`), поэтому без `public:` присваивание `person.name` из `main` не компилировалось бы. спецификатор действует, пока не встретится другой спецификатор или конец класса.

в `main` создаётся один объект класса `Person`. к переменным и функциям обращаются через точку:

```cpp
объект.компонент
```

полям присваивают значения:

```cpp


person.name = "Tom";

person.age = 38;
```

функцию объекта вызывают так же, через точку. вызов `person.print()` получает неявный параметр `this`, адрес того объекта, слева от точки, и внутри `print` имена `name` и `age` обозначают поля именно этого экземпляра:

```cpp
person.print();
```

консольный вывод:

```bash


Name: Tom	Age: 38
```

тем же обращением поля читают:

```cpp


#include <iostream>

#include <string>



class Person 

{

public:

    std::string name;

    unsigned age;

    void print() 

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

};

int main()

{

    Person person;

    // устанавливаем значения полей класса

    person.name = "Bob";

    person.age = 42;

    // получаем значения полей

    std::string username = person.name;

    unsigned userage = person.age;

    // выводим полученные данные на консоль

    std::cout << "Name: " << username << "\tAge: " << userage << std::endl;

}
```

поля, как и обычные переменные, инициализируют начальными значениями прямо в определении класса:

```cpp


#include <iostream>

#include <string>



class Person 

{

public:

    std::string name{"Undefined"};

    unsigned age{18};

    void print() 

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

};

int main()

{

    Person person;

    person.print(); // Name: Undefined  Age: 18

}
```

инициализатор члена по умолчанию (c++11) используется, когда конструктор не задаёт этому члену собственное значение. в примере конструктор не объявлен, объект `person` создаётся конструктором по умолчанию, и поля получают `"Undefined"` и `18` ещё до вызова `print`.

### указатели на объекты классов

на объект класса, как и на объект другого типа, заводят указатель. через указатель обращаются к членам, переменным и функциям. для объекта в переменной разделителем служит точка, для доступа через указатель служит стрелка `->`:

```cpp


#include <iostream>

#include <string>



class Person 

{

public:

    std::string name;

    unsigned age;

    void print() 

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

};

int main()

{

    Person person;

    Person *ptr = &person;

    // обращаемся к полям и функции объекта через указатель

    ptr->name = "Tom";

    ptr->age = 22;

    ptr->print();

    // обращаемся к полям объекта

    std::cout << "Name: " << person.name << "\tAge: " << person.age << std::endl;

}
```

запись `ptr->name` равносильна `(*ptr).name`: указатель разыменовывается, затем выбирается член. скобки вокруг разыменования нужны, потому что операция `.` связывается теснее, чем `*`. изменения через `ptr` меняют объект `person`, поскольку `ptr` хранит адрес `person`, а не копию. отдельного объекта по этому указателю нет.
