над указателями определены присваивание, получение адреса самого указателя, получение значения по указателю, часть арифметических операций и операции сравнения. арифметика адресов разобрана отдельно, здесь фиксируются остальные операции и правила их типов.

### присваивание адреса

указателю присваивают адрес объекта того же типа либо значение другого указателя того же типа. адрес объекта получают оператором `&`:

```cpp


int a {10};

int *pa {&a};	// указатель pa хранит адрес переменной a
```

указатель и переменная должны иметь один и тот же тип. здесь это тип `int`: в `int*` записывают адрес объекта `int`.

### разыменование указателя

разыменование записывают как `*имя_указателя`. операция даёт объект по адресу, который хранится в указателе. результат есть lvalue, поэтому его и читают, и используют слева от присваивания:

```cpp


#include <iostream>



int main()

{

    int a {10};

    int *pa {&a};   // хранит адрес переменной a



    std::cout << "*pa = " << *pa << std::endl;  // *pa = 10

    std::cout << "a = " << a << std::endl;      // a = 10



    *pa = 25;   // меняем значение по адресу в указателе

      

    std::cout << "*pa = " << *pa << std::endl;  // *pa = 25

    std::cout << "a = " << a << std::endl;      // a = 25

}
```

через выражение `*pa` получают значение по адресу, хранящемуся в указателе `pa`. через выражение вида `*pa = значение` по этому адресу записывают новое значение.

поскольку в этом фрагменте указатель `pa` указывает на переменную `a`, изменение значения по адресу меняет и значение переменной `a`. указатель и переменная обозначают один и тот же объект.

### присвоение указателю другого указателя

присваивание указателя указателю копирует адрес, а не объект по этому адресу:

```cpp


#include <iostream>



int main()

{

	int a {10};

    int b {2};

      

    int *pa {&a};   // указатель на переменную a

    int *pb {&b};   // указатель на переменную b

      

    std::cout << "pa: address=" << pa << "\t value=" << *pa << std::endl;

    std::cout << "pb: address=" << pb << "\t value=" << *pb << std::endl;

      

    pa = pb;    // теперь указатель pa хранит адрес переменной b

    std::cout << "pa: address=" << pa << "\t value=" << *pa << std::endl;

	*pa = 125;	// меняем значение по адресу в указателе pa

    std::cout << "b value=" << b << std::endl;

}
```

когда указателю присваивается другой указатель, первый начинает указывать на тот же адрес, на который указывает второй. после `pa = pb` оба указателя адресуют `b`, и запись `*pa = 125` меняет `b`, а не `a`.

```bash


pa: address=0x56347ffc5c         value=10

pb: address=0x56347ffc58         value=2

pa: address=0x56347ffc58         value=2

b value=125
```

### нулевые указатели

нулевой указатель (null pointer) не указывает ни на какой объект. если указатель не должен хранить конкретный адрес, ему присваивают условное нулевое значение. нулевой указатель получают инициализацией нулём или константой `nullptr`:

```cpp


int *p1{nullptr};

int *p2{};
```

оба объявления задают одно и то же нулевое значение указателя. разыменование такого указателя есть неопределённое поведение, поэтому перед оператором `*` проверяют, что указатель ненулевой.

### ссылки на указатели

ссылка не является объектом, поэтому указатель на ссылку не образуют. ссылку на указатель образуют. через неё меняют значение, на которое указатель указывает, и меняют адрес, записанный в самом указателе. тип `int *&` читается как ссылка на указатель на `int`:

```cpp


#include <iostream>



int main()

{

	int a {10};

	int b {6};

	

	int *p{};			// указатель

	int *&pRef {p};		// ссылка на указатель

	pRef = &a;			// через ссылку указателю p присваивается адрес переменной a

	std::cout << "p value=" << *p << std::endl;	// 10

	*pRef = 70;			// изменяем значение по адресу, на который указывает указатель

	std::cout << "a value=" << a << std::endl;	// 70

	

	pRef = &b;			// изменяем адрес, на который указывает указатель

	std::cout << "p value=" << *p << std::endl;	// 6

}
```

имя `pRef` обозначает тот же указатель, что и `p`. присваивание `pRef = &a` записывает адрес в `p`, а `*pRef = 70` записывает число в объект по этому адресу.

### адрес указателя

указатель хранит адрес переменной, и по этому адресу получают её значение. сам указатель, как и любая переменная, имеет адрес, по которому расположен в памяти. этот адрес тоже получают оператором `&`:

```cpp


int a {10};

int *pa {&a};

std::cout << "address of pointer=" << &pa << std::endl;        // адрес указателя

std::cout << "address stored in pointer=" << pa << std::endl;  // адрес, который хранится в указателе - адрес переменной a         

std::cout << "value on pointer=" << *pa << std::endl;          // значение по адресу в указателе - значение переменной a
```

три вывода различают три разных значения: адрес ячейки, в которой лежит указатель (`&pa`), адрес, записанный в указателе (`pa`, адрес переменной `a`), и объект по этому адресу (`*pa`, значение переменной `a`).

### операции сравнения

к указателям одного типа применяют операции сравнения `>`, `>=`, `<`, `<=`, `==`, `!=`. сравнение использует номера адресов. операторы `==` и `!=` определены для произвольных указателей одного типа: они проверяют, совпадают ли адреса. операторы порядка дают определённый стандартом результат, когда оба указателя адресуют элементы одного массива или позицию сразу за его концом. сравнение указателей на независимые объекты стандарт не упорядочивает, хотя на конкретной платформе вывод часто совпадает с числовым сравнением адресов, как в примере:

```cpp


#include <iostream>



int main()

{

	int a {10};

    int b {20};

    int *pa {&a};

    int *pb {&b};

	

	if(pa > pb)

		std::cout << "pa (" << pa << ") is greater than pb ("<< pb << ")" << std::endl;

	else

		std::cout << "pa (" << pa << ") is less or equal pb ("<< pb << ")" << std::endl;

}
```

консольный вывод на одном из запусков:

```bash


pa (0xa9da5ffdac) is greater than pb (0xa9da5ffda8)
```

на этом запуске адрес в `pa` численно больше адреса в `pb`. при другом размещении автоматической памяти отношение может оказаться обратным.

### приведение типов

иногда указателю одного типа нужно присвоить значение указателя другого типа. тогда выполняют приведение. в примере использована операция в стиле c, `(тип_указателя *)`:

```cpp


#include <iostream>



int main()

{

	char c {'N'};

	char *pc {&c};			  // указатель на символ

	int *pd {(int *)pc};	  // указатель на int

	void *pv {(void*)pc};	  // указатель на void

	std::cout << "pv=" << pv << std::endl;

	std::cout << "pd=" << pd << std::endl;

}
```

перед указателем в скобках ставится тип, к которому его преобразуют. объект типа `void` создать нельзя: `void` есть неполный тип, у него нет размера. указатель типа `void*` при этом допустим. это указатель на неполный тип, способный хранить адрес любого объекта. разыменовать `void*` без приведения к конкретному типу нельзя, потому что размер и тип объекта по этому адресу неизвестны.

указатель на `char` (`char *pc {&c}`) при выводе на консоль интерпретируется как строка в стиле c: оператор `<<` печатает символы до нулевого байта, а не числовое значение адреса.

```cpp
std::cout << "pc=" << pc << std::endl;
```

чтобы вывести адрес, хранящийся в указателе типа `char*`, указатель преобразуют к другому типу, например к `void*` или к `int*`. для `void*` оператор `<<` печатает адрес.
