ограничения шаблонов, как функций, так и классов, сужают набор типов, которые допускаются в качестве параметров шаблона. добавление ограничений к параметрам шаблона решает следующие задачи:

- из заголовка шаблона сразу видно, какие аргументы шаблона разрешены, а какие нет.

- шаблон создаётся только в том случае, если аргументы шаблона удовлетворяют всем ограничениям. проверка выполняется до инстанцирования тела: при нарушении ограничения экземпляр не порождается.

- любое нарушение ограничений шаблона приводит к сообщению об ошибке, которое гораздо ближе к первопричине проблемы, а именно к попытке использовать шаблон с неверными аргументами. диагностика указывает на вызов с неверными аргументами и не уходит вглубь тела шаблона.

начиная со стандарта c++20 в язык добавлен оператор **requires**, который устанавливает ограничения для параметров шаблонов.

```cpp
template <параметры> requires ограничения
содержимое шаблона;
```

ограничения представляют условные выражения, которые возвращают значение типа **bool**. если параметр типа удовлетворяет условию, возвращается `true`. каждое ограничение предписывает одно или несколько требований для одного или нескольких параметров шаблона. выражение является константным и вычисляется во время компиляции.

например, требуется определить функцию, которая складывает числа:

```cpp
#include <iostream>

template <typename T> requires std::is_same<T, int>::value || std::is_same<T, double>::value
T sum(T a, T b){ return a + b;}

int main()
{
    std::cout << sum(3, 4) << std::endl;
    std::cout << sum(12.5, 4.3) << std::endl;
    //std::cout << sum(5l, 7l) << std::endl;
}
```

здесь определён шаблон функции `sum`, который принимает значения типа `T` и возвращает их сумму также в виде значения типа `T`. для параметра `T` после слова `requires` установлено ограничение:

```cpp
std::is_same<T, int>::value || std::is_same<T, double>::value
```

для определения ограничения применяется шаблон `std::is_same` из стандартной библиотеки c++, заголовок `<type_traits>`. этот шаблон параметризован двумя типами. вложенная константа `value` возвращает `true`, если оба типа одинаковы. выражение `std::is_same<T, int>::value` возвращает `true`, если `T` есть `int`. аналогично устанавливается ещё одно ограничение: `std::is_same<T, double>::value`. операция `||` объединяет два ограничения дизъюнкцией. тип `T` может представлять либо `int`, либо `double`. с c++17 то же условие записывают через переменную-шаблон `std::is_same_v<T, int>`.

далее в функцию `sum()` передаются значения типов, которые удовлетворяют этим ограничениям:

```cpp
std::cout << sum(3, 4) << std::endl;        // передаем int
std::cout << sum(12.5, 4.3) << std::endl;   // передаем double
```

значения других типов передать нельзя. в примере выше закомментирована строка, где в функцию `sum()` передаются значения типа `long`:

```cpp
//std::cout << sum(5l, 7l) << std::endl;  // long работать не будет
```

если её раскомментировать, компилятор не скомпилирует программу и выдаст ошибку: в функцию `sum` переданы значения некорректных типов. ограничение отклоняет аргумент на этапе проверки `requires`, до подстановки тела шаблона.
