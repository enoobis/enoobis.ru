конструкция `switch-case` сравнивает значение одного выражения с набором констант и передаёт управление соответствующей ветви. общая форма:

```c


switch(выражение)

{

	case значение_1: инструкции_1;

	case значение_2: инструкции_2;

    ...................

	case значение_N: инструкции_N;

	

	default: инструкции;

}
```

после служебного слова `switch` в скобках стоит сравниваемое выражение. его значение по очереди сопоставляется со значениями после меток `case`. при совпадении выполняется блок этой метки. сопоставление идёт по равенству значения, а не по диапазону и не по логическому условию.

сравниваемое выражение в `switch` должно иметь целочисленный или символьный тип либо быть перечислением. перечисления рассматриваются далее. метки `case` обязаны быть константными выражениями того же типа после преобразования. две метки с одним и тем же значением в одном `switch` делают программу некорректной.

в конце конструкции может стоять блок `default`. он необязателен и выполняется, если значение выражения не совпало ни с одной меткой `case`. пример:

```cpp


#include <iostream>



int main()

{

	int x {2};

     

    switch(x)

    {

        case 1: 

            std::cout << "x = 1" << "\n";

            break;

        case 2: 

            std::cout << "x = 2" << "\n";

            break;

        case 3: 

            std::cout << "x = 3" << "\n";

            break;

        default: 

            std::cout << "x is undefined" << "\n";

            break;

    }

}
```

чтобы выполнение не продолжилось в следующие блоки `case` и `default`, в конце блока ставят оператор `break`. в примере выполняется ветвь

```cpp


case 2: 

	std::cout << "x = 2" << "\n";

	break;
```

после `break` происходит выход из `switch`, остальные метки игнорируются. на консоль выводится одна строка:

```bash
x = 2
```

без `break` семантика другая: управление проваливается в следующую метку. если убрать из предыдущего примера все операторы `break`, получается такая программа:

```cpp


#include <iostream>



int main()

{

	int x {2};

     

    switch(x)

    {

        case 1: 

            std::cout << "x = 1" << "\n";

        case 2: 

            std::cout << "x = 2" << "\n";

        case 3: 

            std::cout << "x = 3" << "\n";

        default: 

            std::cout << "x is undefined" << "\n";

    }

}
```

снова выбирается метка `case 2`, потому что `x` равно 2. этот блок не завершается `break`, поэтому после него выполняются инструкции метки `case 3`, хотя `x` по-прежнему равно 2, а затем инструкции `default`. консольный вывод:

```bash


x = 2

x = 3

x is undefined
```

такой провал используют намеренно, когда у нескольких меток общий хвост действий. случайный пропуск `break` даёт ту же картину, поэтому отсутствие оператора стоит считать частью семантики ветви, а не оформлением.

#### совмещение условий

нескольким меткам `case` можно сопоставить один набор инструкций. метки записывают подряд, а инструкции и `break` ставят после последней из них:

```cpp


#include <iostream>

 

int main()

{

    int x {2};

      

    switch(x)

    {

        case 1:

        case 2: 

            std::cout << "x = 1 or 2" << "\n";

            break;

        case 3: 

        case 4:

            std::cout << "x = 3 or 4" << "\n";

            break;

        case 5:

            std::cout << "x = 5" << "\n";

            break;

    }

}
```

если `x` равно 1 или `x` равно 2, выполняется одна и та же инструкция `std::cout << "x = 1 or 2" << "\n"`. для значений 3 и 4 тоже задана общая инструкция. отдельной метки `default` здесь нет: значение вне списка 1, 2, 3, 4, 5 не приводит ни к одному выводу, и выполнение продолжается после `switch`.

#### переменные в блоках case

определение переменной внутри блока `case` встречается реже и требует отдельной области видимости. если переменная определяется в блоке `case`, инструкции этого блока помещают в фигурные скобки. для блока `default` в примере ниже это не требуется:

```cpp


#include <iostream>

 

int main()

{

    int x {2};

      

    switch(x)

    {

        case 1:

        {

            int a{10};

            std::cout << a << std::endl;

            break;

        }

        case 2:

        {

            int b{20};

            std::cout << b << std::endl;

            break;

        }

        default:

            int c{30};

            std::cout << c << std::endl;

    }

}
```

причина в правилах перехода: вход в блок по метке не должен обходить инициализацию автоматической переменной. составной оператор ограничивает время жизни имени одной ветвью, и переход на другую метку эту инициализацию не пересекает. у `default` в этом примере следующей метки нет, обхода инициализации не возникает, поэтому внутренние скобки не обязательны.

#### блок switch с инициализацией переменной

иногда для промежуточных вычислений внутри `switch` нужна переменная, видимая всем ветвям и не видимая снаружи. начиная со стандарта c++17, у конструкции есть форма с инициализатором:

```cpp


switch(инициализация; выражение) 

{

    // ..........

}
```

как и прежде, выражение после точки с запятой сравнивается с константами меток `case`. перед выражением можно определить и инициализировать переменную. пример:

```cpp


#include <iostream>

 

int main()

{

    char op = '+';

    int n = 10;

    switch(int k{2}; op)

    {

        case '+':

            std::cout << n + k << std::endl;

            break;

        case '-':

            std::cout << n - k << std::endl;

            break;

        case '*':

            std::cout << n * k << std::endl;

            break;

    }

}
```

в заголовке `switch` определена переменная `k`. она доступна только внутри этой конструкции. выражением служит значение переменной `op`, знак операции. в зависимости от знака выполняется соответствующая операция над `n` и `k`. инициализатор вычисляется один раз, до выбора метки. для `op`, равного `'+'`, выполняется ветвь сложения, и на консоль выводится `n + k`.
