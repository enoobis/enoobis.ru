в c++ существуют не только обычные указатели, которые хранят адрес объекта в памяти. есть и более специальный механизм: **указатели на члены класса**. такой указатель обозначает поле или метод внутри определения класса, а не конкретный объект.

обычный указатель хранит абсолютный адрес в памяти. указатель на член класса хранит **смещение** (offset) поля данных или адрес функции-члена относительно начала любого объекта этого класса. сами по себе они не обозначают объект. смысл появляется только при применении указателя к конкретному экземпляру класса. ниже показано, как устроены объявление, инициализация и применение.

указатели на члены класса используют нечасто, но в ряде сценариев они незаменимы. некоторые ситуации применения:

- реализация паттерна "стратегия" или "команда": объект хранит указатель на метод, который определяет его текущее поведение (стратегию)

- обработка данных по шаблону: создают массив указателей на поля и обходят его для однотипных операций (сериализация, валидация, вычисление суммы)

- диспетчеризация вызовов: в событийных системах, управляемых событиями, составляют карту, словарь (например, `std::map`), где ключом является некоторое событие, а значением является указатель на метод-обработчик этого события

указатели на поля класса и структуры представляют простейший вид указателей на члены класса. они позволяют выбрать, с каким полем объекта работать, уже во время выполнения программы. формальный синтаксис включает три компонента:

- объявление

```cpp
тип_поля Класс::*имя_указателя;
```

- инициализация

```cpp
имя_указателя = &Класс::имя_поля;
```

- использование

```cpp


объект.*имя_указателя (оператор "точка-звездочка")

указатель_на_объект->*имя_указателя (оператор "стрелка-звездочка")
```

простейший пример:

```cpp


#include <iostream>

#include <string>



struct Person{

    std::string name;

    int age;

};



int main() {

    // Объявляем указатель на член класса Person типа int

    int Person::*p_age;



    // Инициализируем указатель - указываем на поле age

    p_age = &Person::age; 



    // Используем указатель

    Person tom{"Tom", 41};  // объект для примера

    std::cout << "Person age: " << tom.*p_age << std::endl;  // Person age: 41





    // Для примера используем указатель через указатель на объект

    Person bob{"Bob", 46};

    Person* p_bob = &bob;

    std::cout << "Person age: " << p_bob->*p_age << std::endl;  // Person age: 46



    return 0;

}
```

разбор идёт по этапам. сначала объявляется указатель на член класса `Person` типа `int` с именем `p_age`:

```cpp
int Person::*p_age;
```

далее указатель инициализируется и указывает на поле `age`:

```cpp
p_age = &Person::age;
```

далее указатель применяется для обращения к полям объекта. в примере доступ показан и через объект, и через указатель на объект. фрагмент обращения через объект:

```cpp


Person tom{"Tom", 41};  // объект для примера

  std::cout << "Person age: " << tom.*p_age << std::endl;  // Person age: 41
```

использование указателя в этом примере избыточно: поле можно прочитать по имени. поэтому ниже разобраны ещё несколько примеров, где выбор поля откладывается до выполнения.

у класса `Product` два числовых поля скидки, цена рассматривается вместе с минимальной и максимальной скидкой:

```cpp


#include <iostream>

#include <string>



struct Product {

    std::string name;

    double price;

    double min_discount;

    double max_discount;



    void print_final_price(double Product::*discount) {

        // Применяем указатель на член к this

        double final_price = this->price - (this->*discount);

        std::cout << "Final price for " << this->name << " is: " << final_price << std::endl;

    }

};



int main() {

    Product phone{"Smartphone", 1000.0, 50.0, 200.0};



    // В зависимости от условия, наш указатель будет "смотреть" на разные поля

    std::cout << "Min discount:" << std::endl;

    phone.print_final_price(&Product::min_discount); // 1000 - 50 = 950



    std::cout << "Max discount:" << std::endl;

    phone.print_final_price(&Product::max_discount); // 1000 - 200 = 800





    phone.max_discount = 250; // Меняем скидку для демонстрации

    phone.print_final_price(&Product::max_discount); // 1000 - 250 = 750



    return 0;

}
```

цель состоит в том, чтобы динамически выбрать, какое из числовых полей `Product` использовать для вычисления скидки: `max_discount` или `min_discount`.

метод `print_final_price` класса `Product` принимает указатель на член:

```cpp


void print_final_price(double Product::*discount) {

    

    double final_price = this->price - (this->*discount);

    std::cout << "Final price for " << this->name << " is: " << final_price << std::endl;

}
```

параметром в функцию передаётся указатель `double Product::*discount`. он не хранит значение, а описывает, как получить доступ к полю типа `double` внутри любого объекта `Product`.

внутри метода `print_final_price` используется оператор `->*` в выражении `this->*discount`. это применяет переданный указатель к текущему объекту `this`. скобки фиксируют порядок: сначала выбирается поле, затем его значение вычитается из цены.

в функции `main` при вызове `phone.print_final_price(&Product::min_discount)` передаётся указатель на поле `min_discount`:

```cpp
phone.print_final_price(&Product::min_discount);
```

в результате метод вычисляет `price - min_discount`. если передать указатель на другое совместимое поле, расчёт будет иным.

это позволяет методу `print_final_price` оставаться общим: заранее не известно, какое именно значение нужно вычесть из цены, и имя поля приходит аргументом.

значение поля можно изменить динамически, и тогда результат вычисления изменится, но метод по-прежнему использует то же самое поле:

```cpp


phone.max_discount = 250; // Меняем скидку для демонстрации

phone.print_final_price(&Product::max_discount); // 1000 - 250 = 750
```

аналогично значение указателю присваивают динамически:

```cpp


#include <iostream>

#include <string>



struct Product {

    std::string name;

    double price;

    double min_discount;

    double max_discount;



};



int main() {

    // Объявляем указатель на член класса Product типа double

    double Product::*discount;



    Product phone{"Smartphone", 1000.0, 50.0, 200.0};



    // В зависимости от условия, наш указатель будет "смотреть" на разные поля

    if (phone.price > 500) {

        // Указываем на поле min_discount

        discount = &Product::min_discount; 

    } else {

        // Указываем на поле max_discount

        discount = &Product::max_discount;

    }

    

    // используем указатель

    std::cout << "Final discount:" << phone.*discount << std::endl;  // Final discount:50



    phone.min_discount = 80.0;  // меняем значение

    std::cout << "Final discount:" << phone.*discount << std::endl;  // Final discount:80

    return 0;

}
```

ещё один пример собирает несколько доходов в сумму через массив указателей на поля:

```cpp


#include <iostream>

#include <string>



struct Person {

    std::string name;

    int age;

    int salary;             // зарплата

    int rental_income;      // доход от недвижимости

    int other_income;       // какой-то другой доход

};



int main() {



    Person tom{"Tom", 41, 4500, 1500, 400};



    // массив указателей

    int Person::*required_fields[] = {

        &Person::salary,

        &Person::rental_income,

        &Person::other_income,

    };



    int total_income = 0;

    for (auto income : required_fields) {

        total_income += tom.*income;

    }



    std::cout << "Total income: " << total_income <<  std::endl;  // Total income: 6400

    return 0;

}
```

здесь определена структура `Person`, которая представляет человека и определяет `salary` (зарплата), `rental_income` (доход от недвижимости), `other_income` (какой-то другой доход).

в функции `main` создаётся массив указателей на члены класса `Person` с именем `required_fields`. этот массив инициализируется указателями на три поля: `salary`, `rental_income` и `other_income`. по сути создан список полей, которые нужно обработать:

```cpp


int Person::*required_fields[] = {

        &Person::salary,

        &Person::rental_income,

        &Person::other_income,

    };
```

далее в цикле вычисляется суммарный доход человека по полям из этого массива:

```cpp


int total_income = 0;

for (auto income : required_fields) {

    total_income += tom.*income;

}
```

цикл `for` перебирает каждый элемент массива `required_fields`. в каждой итерации `income` становится одним из указателей на член: сначала `&Person::salary`, затем `&Person::rental_income` и так далее. значение соответствующего поля добавляется к переменной `total_income`. тип элементов массива один, `int Person::*`, поэтому в список входят только поля типа `int`.

## указатели на функции-члены

указатели на функции позволяют динамически выбирать, какой метод объекта будет вызван. синтаксис здесь сложнее из-за необходимости указывать полную сигнатуру функции.

- объявление:

```cpp
возвращаемый_тип (Класс::*имя_указателя)(параметры);
```

- инициализация:

```cpp
имя_указателя = &Класс::имя_метода;
```

- использование:

```cpp


(объект.*имя_указателя)(аргументы);

(указатель_на_объект->*имя_указателя)(аргументы);
```

скобки вокруг `(объект.*имя_указателя)` обязательны из-за низкого приоритета операторов `.*` и `->*`. приоритет вызова `()` выше, и скобки задают применение указателя раньше вызова.

простейший пример добавляет в класс `Product` разные способы расчёта скидки.

```cpp


#include <iostream>

#include <string>



struct Product {

    std::string name;

    double price;



    double get_fixed_discount(double amount) {

        return amount;

    }



    double get_percentage_discount(double percent) {

        return price * (percent / 100.0);

    }

};



int main() {

    // Объявляем указатель на метод класса Product, который принимает double и возвращает double

    double (Product::*p_discount_calculator)(double);



    Product tv{"Big TV", 2000.0};



    bool holiday_season = true;

    if (holiday_season) {

        // Указываем на метод, считающий скидку в процентах

        p_discount_calculator = &Product::get_percentage_discount;

        double discount = (tv.*p_discount_calculator)(15.0); // Вызываем get_percentage_discount(15.0)

        std::cout << "Holiday discount: " << discount << std::endl; // 300

        std::cout << "Final price: " << tv.price - discount << std::endl; // 1700

    } else {

        // Указываем на метод с фиксированной скидкой

        p_discount_calculator = &Product::get_fixed_discount;

        double discount = (tv.*p_discount_calculator)(100.0); // Вызываем get_fixed_discount(100.0)

        std::cout << "Regular discount: " << discount << std::endl; // 100

        std::cout << "Final price: " << tv.price - discount << std::endl; // 1900

    }



    return 0;

}
```

в класс `Product` добавлены разные способы расчёта скидки:

```cpp


double get_fixed_discount(double amount) {

    return amount;

}



double get_percentage_discount(double percent) {

    return price * (percent / 100.0);

}
```

в функции `main` объявляется указатель на метод класса `Product`, который принимает `double` и возвращает `double`:

```cpp


double (Product::*p_discount_calculator)(double);
```

далее условная конструкция динамически инициализирует этот указатель и применяет его для вычисления скидки:

```cpp


if (holiday_season) {

    p_discount_calculator = &Product::get_percentage_discount;

    double discount = (tv.*p_discount_calculator)(15.0); // Вызываем get_percentage_discount(15.0)

    ..............

} else {

    p_discount_calculator = &Product::get_fixed_discount;

    double discount = (tv.*p_discount_calculator)(100.0); // Вызываем get_fixed_discount(100.0)

    ......................

}
```

оба метода имеют одну сигнатуру, поэтому один указатель типа `double (Product::*)(double)` обозначает и `get_percentage_discount`, и `get_fixed_discount`. выбор записывается в переменную до вызова. выражение `(tv.*p_discount_calculator)(15.0)` передаёт аргумент уже выбранной функции и подставляет объект `tv` в качестве `this`.
