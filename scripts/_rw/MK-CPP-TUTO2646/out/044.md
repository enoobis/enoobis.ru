рекурсия применяется к быстрой сортировке. ниже программа сортирует массив целых, разделяя его вокруг выбранного элемента и сортируя части отдельными вызовами:

```cpp


#include <iostream>

 

void sort(int[], size_t, size_t);

void swap(int[], size_t, size_t);

 

int main()

{

    int nums[] {3, 0, 6, -2, -6, 11, 3};

    sort(nums, 0, std::size(nums)-1);

    for(auto num: nums)

    {

        std::cout << num << "\t";

    }

    std::cout << std::endl;

}

 

void sort(int numbers[], size_t start, size_t end)

{

    // начальный индекс должен быть меньше конечного индекса для массива из 2 и более элементов

    if (start >= end)

        return;

    // проверяем все элементы относительно элемента с индексом start

    size_t current {start};

    for (size_t i {start + 1}; i <= end; i++)

    {

        // если i-ый элемент меньше начального

        if (numbers[i] < numbers[start]) 

        {

            swap(numbers, ++current, i); // меняем его с левым

        }

    }

    swap(numbers, start, current); // Меняем выбранный (start) и последний обмененный элементы

    if (current > start) 

	{

		sort(numbers, start, current - 1); // Сортируем элементы слева

	}

    if (end > current + 1) 

	{

		sort(numbers, current + 1, end); // Сортируем элементы справа

	}

}

void swap(int numbers[], size_t first, size_t second)

{

    auto temp{numbers[first]};

    numbers[first] = numbers[second];

    numbers[second] = temp;

}
```

для сортировки определена функция `sort`. она принимает три параметра: сортируемый массив, начальный индекс и конечный индекс сортируемой части.

```cpp
void sort(int numbers[], size_t start, size_t end)
```

при первом вызове начальный индекс `start` равен 0, а конечный индекс `end` есть индекс последнего элемента. аргумент `std::size(nums) - 1` корректен, пока массив не пуст: `size_t` беззнаковый, и вычитание единицы из нуля дало бы максимальное значение этого типа. позиции перед началом массива такое вычитание не обозначает.

сначала проверяется размер сортируемой части:

```cpp


if (start >= end)

    return;
```

если начальный индекс больше конечного или равен ему, в части меньше двух элементов, и функция сразу выходит. сортировать один элемент или пустой диапазон не нужно. в конце каждого вызова `sort()` текущая последовательность разбивается на две меньшие подпоследовательности, и для каждой снова вызывается `sort()`. рекурсия обязана дойти до подпоследовательности из одного элемента или до пустой: это базовый вариант, тот же ранний `return`. схема есть быстрая сортировка. опорным элементом берётся элемент с индексом `start`, элементы меньше него сдвигаются влево, затем опорный ставится на границу, и обе стороны сортируются отдельно. на уже упорядоченных данных такой выбор опоры даёт сильно неравные части, и глубина рекурсии становится линейной.

далее фиксируется индекс текущего элемента. он отмечает, до какого места уже собраны элементы, меньшие опорного:

```cpp


size_t current {start};
```

затем этот элемент сравнивается с остальными, стоящими после индекса `start`:

```cpp


for (size_t i {start + 1}; i <= end; i++)

{

    // если i-ый элемент меньше начального

    if (numbers[i] < numbers[start]) 

    {

        swap(numbers, ++current, i); // меняем его с тем, который слева

    }

}
```

если элемент с индексом `i` меньше выбранного начального, он меняется местами с элементом, который стоит сразу за уже собранным левым участком. индекс этого места есть `++current`: сначала `current` продвигается, затем используется как позиция обмена. в результате все элементы, которые меньше выбранного, оказываются перед элементами, которые больше его или равны ему. сравнение идёт с `numbers[start]`. опорный элемент до конца цикла остаётся на индексе `start` и сам в этих обменах не участвует, кроме случая, когда `current` всё ещё равен `start` и обмен элемента с самим собой ничего не меняет. элементы, равные опорному, условие `<` не выполняют, и они остаются справа.

когда цикл заканчивается, `current` хранит индекс последнего найденного элемента, который меньше начального элемента с индексом `start`. эти два элемента меняются местами:

```cpp
swap(numbers, start, current);
```

элемент, относительно которого сравнивались остальные, получает индекс `current` и оказывается после всех элементов, которые меньше него. слева от него лежат меньшие элементы, справа большие или равные. это и есть граница разбиения.

в конце сортируются две подпоследовательности по обе стороны от элемента с индексом `current`. для каждого подмножества вызывается `sort()`. индексы элементов, меньших выбранного, идут от начала до `current - 1`. индексы тех, которые больше или равны ему, идут от `current + 1` до конца. вычитание единицы из `current` безопасно только при `current > start`: тип `size_t` беззнаковый, и `current - 1` при нулевом `current` обошёл бы весь диапазон типа. вторая проверка `end > current + 1` не строит пустой или одноэлементный правый вызов.

```cpp


if (current > start) 

{

	sort(numbers, start, current - 1); // Сортируем элементы слева

}

if (end > current + 1) 

{

	sort(numbers, current + 1, end); // Сортируем элементы справа

}
```

при первом выполнении исходные значения такие:

```cpp


start = 0   

end = 6

current = 0
```

цикл последовательно показывает семь состояний массива. меняются они так:

```browser


после 1-итерации: 3       0       6       -2      -6      11      3

после 2-итерации: 3       0       6       -2      -6      11      3

после 3-итерации: 3       0       -2      6       -6      11      3

после 4-итерации: 3       0       -2      -6      6       11      3

после 5-итерации: 3       0       -2      -6      6       11      3

после 6-итерации: 3       0       -2      -6      6       11      3

после 7-итерации: 3       0       -2      -6      6       11      3
```

переменная `current` становится равна 3: нашлись три элемента, которые меньше выбранного элемента с индексом `start`. затем `current` и `start` меняются местами. получается:

```browser
-6      0       -2      3       6       11      3
```

затем последовательность разбивается на две подпоследовательности. слева от `current`:

```browser
-6      0       -2
```

и справа от `current`:

```browser
6       11      3
```

для каждой из этих подпоследовательностей отдельно вызывается `sort()`. левый вызов получает границы от `start` до `current - 1`, правый от `current + 1` до `end`. опорный элемент с индексом `current` в эти вызовы не входит: он уже стоит на своей окончательной позиции. те же шаги повторяются, пока очередная часть не станет короче двух элементов.
