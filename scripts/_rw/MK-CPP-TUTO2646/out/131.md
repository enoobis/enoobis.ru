### drop_view

представление **drop_view** пропускает заданное количество элементов с начала диапазона и оставляет суффикс. для создания представления применяется конструктор **std::ranges::drop_view**, в который передаются контейнер и количество пропускаемых элементов. если это количество больше длины диапазона, представление пусто.

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges>



int main()

{

    std::vector<std::string> people { "Tom", "Kate", "Bob", "Alice", "Sam" };

    // пропускаем 2 элемента

    auto view = std::ranges::drop_view{people, 2};



    for(const auto& person: view)

    {

        std::cout << person << std::endl;

    }

}
```

пропускаются два первых элемента контейнера `people`:

```cpp
auto view = std::ranges::drop_view{people, 2};
```

вывод:

```bash


Bob

Alice

Sam
```

в качестве альтернативы используется функция **std::views::drop()**, которая принимает количество пропускаемых элементов:

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges>



int main()

{

    std::vector<std::string> people { "Tom", "Kate", "Bob", "Alice", "Sam" };

    // пропускаем 2 элемента

    auto view = people | std::views::drop(2);



    for(const auto& person: view)

    {

        std::cout << person << std::endl;

    }

}
```

для создания представления используется операция `|`, которая применяется к контейнеру и к функции `std::views::drop`:

```cpp
view = people | std::views::drop(2);
```

### пропуск элементов по условию

представление **drop_while_view** пропускает первые элементы, которые соответствуют некоторому условию, и останавливается на первом элементе, для которого условие ложно. условие задаётся функцией, которая принимает элемент контейнера и возвращает `true`, если элемент соответствует условию, и `false`, если не соответствует.

для создания представления применяется конструктор **std::ranges::drop_while_view**, который принимает контейнер и функцию-условие:

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges>



int main()

{

    std::vector<std::string> people { "Tom", "Bob", "Alice", "Sam", "Kate" };

    auto condition = [](const std::string& s) {return s.length()==3; };



    auto view = std::ranges::drop_while_view{people, condition};



    for(const auto& person: view)

    {

        std::cout << person << std::endl;

    }

}
```

условие представляет функцию, которая принимает строку и возвращает `true`, если длина строки равна 3 символам:

```cpp
auto condition = [](const std::string& s) {return s.length()==3; };
```

пока условие не вернёт `false`, элементы с начала контейнера пропускаются. как только предикат вернёт `false`, оставшийся суффикс выдаётся целиком, уже без дальнейшей проверки. вывод:

```bash


Alice

Sam

Kate
```

алгоритм отбрасывает непрерывный префикс до первого элемента, для которого предикат ложен. элементы после этой границы остаются в представлении, в том числе те, которые снова удовлетворили бы предикат.

в качестве альтернативы для создания представления используется функция **std::views::drop_while()**, которая принимает функцию-условие:

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges> 



int main()

{

    std::vector<std::string> people { "Tom", "Bob", "Alice", "Sam", "Kate" };

    auto condition = [](const std::string& s) {return s.length()==3; };

     

    auto view = people | std::views::drop_while(condition);



    for(const auto& person: view)

    {

        std::cout << person << std::endl;

    }

}
```
