объект исключения в c++ может иметь любой полный тип, допускающий копирование или перемещение. стандартная библиотека описывает свои исключения типом `exception` из пространства имён `std`. класс объявлен в заголовочном файле `<exception>`, и его же используют как общий обработчик ошибок стандартной иерархии. интерфейс класса:

```cpp


namespace std

{

	class exception

	{

	public:

		exception() noexcept;

		exception(const exception&) noexcept;

		exception& operator=(const exception&) noexcept;

		virtual ~exception(); // Destructor

		virtual const char* what() const noexcept; // возвращает сообщение об исключении

	};

}
```



спецификатор `noexcept` у специальных функций и у `what()` означает, что выход через исключение из этих операций приводит к вызову `std::terminate`. это существенно при раскрутке стека: исключение из копирования объекта исключения или из деструктора во время раскрутки завершает программу.

обработка через `std::exception`:

```cpp


#include <iostream>



double divide(int, int);



int main()

{

    int x {500};

    int y{};

    try

    {

        double z = divide(x, y);

        std::cout << z << std::endl;

    }

    catch (const std::exception& err)

    {

        std::cout << "Error!!!" << std::endl;

    }

    std::cout << "The End..." << std::endl;

}

 

double divide(int a, int b)

{

    if (!b)

        throw std::exception();

    return a / b;

}
```



оператору `throw` передаётся объект `std::exception`:

```cpp
throw std::exception();
```



чтобы перехватить исключение этого типа, в `catch` объявляют параметр `std::exception`:

```cpp
catch (const std::exception& err)
```



`err` имеет тип константной ссылки на `std::exception`. если параметр в теле обработчика не используется, допустимо указать только тип:

```cpp


catch (std::exception)

{

	std::cout << "Error!!!" << std::endl;

}
```



виртуальная функция `what()` возвращает сообщение об ошибке как строку в стиле c, то есть `const char*`. у самого `std::exception` это сообщение малоинформативно: реализации обычно возвращают имя класса. в производных классах `what()` переопределяют и возвращают текст конкретной ошибки.

### создание производных классов

от `std::exception` производят собственные типы исключений.

```cpp


#include <iostream>

#include <string>



class person_error: public std::exception

{

public:

    person_error(const std::string& message): message{message}

    {}

    const char* what() const noexcept override

    {

        return message.c_str();     // получаем из std::string строку const char*

    }

private:

    std::string message;    // сообщение об ошибке

};



class Person

{

public:

    Person(std::string name, unsigned age)

    {

        if(!age || age > 110)	// если age==0 или age > 110

            throw person_error("Invalid age");

        this->name = name;

        this->age = age;

    }

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

};

 

void testPerson(std::string name, unsigned age)

{

    try

    {

        Person person{name, age};   // создаем один объект Person

        person.print();

    }

    catch (const person_error& err) // обработка ошибок, сязанных с Person

    {

        std::cout << "Person error: " << err.what() << std::endl;

    }

    catch (const std::exception&)   // обработка остальных исключений

    {

        std::cout << "Something wrong"<< std::endl;

    }

}

int main()

{

    testPerson("Tom", 38);  // Name: Tom       Age: 38

    testPerson("Sam", 250);  // Person error: Invalid age

}
```



класс `Person` представляет пользователя. конструктор принимает имя и возраст. если возраст равен нулю или превышает 110, генерируется исключение `person_error`:

```cpp


Person(std::string name, unsigned age)

{

    if(!age || age > 110)	// если age==0 или age > 110

        throw person_error("Invalid age");
```



`person_error` открыто наследует `std::exception`, принимает сообщение через конструктор и хранит его в поле `message` типа `std::string`:

```cpp


class person_error: public std::exception

{

public:

    person_error(const std::string& message): message{message}

    {}

    const char* what() const noexcept override

    {

        return message.c_str();     // получаем из std::string строку const char*

    }

private:

    std::string message;    // сообщение об ошибке

};
```



чтобы вернуть сообщение, переопределяется виртуальная функция `what()`. сигнатура базового класса возвращает `const char*`, тогда как поле хранит `std::string`. указатель на непрерывную последовательность символов даёт функция `c_str()`. указатель действителен, пока живёт объект `std::string` внутри объекта исключения, а объект исключения существует на всём протяжении обработчика:

```cpp
return message.c_str();     // получаем из std::string строку const char*
```



для проверки определена функция `testPerson`. в блоке `try` создаётся один объект `Person`. конструкция `try-catch` содержит два обработчика. первый принимает производный тип `person_error`, второй принимает базовый `std::exception` и покрывает остальные исключения этой иерархии. производный обработчик стоит раньше базового, иначе базовый перехватил бы и `person_error`:

```cpp


catch (const person_error& err) // обработка ошибок, сязанных с Person

{

    std::cout << "Person error: " << err.what() << std::endl;

}

catch (const std::exception&)   // обработка остальных исключений

{

    std::cout << "Something wrong"<< std::endl;

}
```



результат выполнения:

```bash


Name: Tom       Age: 38

Person error: Invalid age
```
