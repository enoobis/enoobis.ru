начиная со стандарта c++17 стандартная библиотека содержит заголовок `<optional>` и шаблон класса `std::optional<T>`. объект этого типа либо хранит значение типа `T`, либо находится в пустом состоянии. пустое состояние не входит в множество значений `T`, им обозначают отсутствие результата: символ не найден, параметр не задан. для `unsigned` значение располагается внутри самого объекта `optional`. отдельного размещения в динамической памяти для такого `T` нет.

поиск индекса символа в строке состоит из прохода по символам и возврата позиции. если символа в строке нет, функции нужен признак неудачи, который сам индексом не является. для знакового целого распространён возврат `-1`: отрицательное число не бывает корректной позицией, и вызывающий код отделяет неудачу от найденного индекса. у беззнакового типа запасного значения нет. любое число типа `unsigned` может оказаться настоящей позицией, в том числе в очень длинной строке. `std::optional<unsigned>` оставляет индекс в его собственном типе, а отсутствие передаёт константой `std::nullopt`. у константы тип `std::nullopt_t`, к `unsigned` она не приводится.

функция `find_index` возвращает `std::optional<unsigned>`.

```cpp

#include <iostream>
#include <string>
#include <optional>

std::optional<unsigned> find_index(const std::string&, char);
int main()
{
    const std::string text = "An apple a day keep the doctor away.";
    // находим индекс символа 'p'
    char p_char{'p'};
    const std::optional<unsigned> p_index{ find_index(text, p_char) };
    std::cout << "Index of p: " << *p_index << std::endl;
    
    // находим индекс символа 'b'
    char b_char{'b'};
    const std::optional<unsigned> b_index{ find_index(text, b_char) };
    std::cout << "Index of b: " << *b_index << std::endl;
}

std::optional<unsigned> find_index(const std::string& text, char c)
{
    // если пустая строка, возвращаем специальное значение std::nullopt
    if (text.empty())
        return std::nullopt; 
    // в цикле находим начальный индекс символа
    for(unsigned i{}; i < text.size();i++)
    {
        // если символ найден, возвращаем индекс символа
        if(text[i]==c)
        {
            return i;
        } 
    }
    // в остальных случаях возвращаем std::nullopt
    return std::nullopt;
}
```

параметр `text` принят константной ссылкой, параметр `c` это искомый символ. аргумент шаблона `unsigned` задаёт тип хранимого индекса. пустая строка сразу даёт `std::nullopt`. цикла по символам тогда нет. иначе функция перебирает индексы с нуля и возвращает наименьший `i`, на котором `text[i] == c`. если цикл закончился без совпадения, результат снова `std::nullopt`. найденный индекс хранится в `optional` как обычное значение `unsigned`.

в `main` ищутся два символа одной строки `"An apple a day keep the doctor away."`. символ `p` в ней есть, символ `b` нет. хранимое значение читается оператором `*`. объект `p_index` константный, поэтому `*p_index` имеет тип константной ссылки на `unsigned`.

```bash

Index of p: 4
Index of b: 4251975392
```

индекс `p` равен 4. это позиция первой буквы `p` в тексте. для `b` программа печатает `4251975392`. пустой `std::optional<unsigned>` не содержит объекта `unsigned`. константа `std::nullopt` большим беззнаковым числом не кодируется. оператор `*` на пустом `optional` даёт неопределённое поведение: реализация может прочитать неинициализированную память объекта, и показанное число не обязано повториться на другом компиляторе, с другой библиотекой или на следующем запуске. следующий вариант проверяет состояние до чтения.

```cpp

#include <iostream>
#include <string>
#include <optional>

std::optional<unsigned> find_index(const std::string&, char); 
void print_index(std::optional<unsigned>, char);

int main()
{
    const std::string text = "An apple a day keep the doctor away.";
    // находим индекс символа 'p'
    char p_char{'p'};
    const std::optional<unsigned> p_index{ find_index(text, p_char) };
    print_index(p_index, p_char);
    
    // находим индекс символа 'b'
    char b_char{'b'};
    const std::optional<unsigned> b_index{ find_index(text, b_char) };
    print_index(b_index, b_char);
}
// выводим индекс на консоль, если символ найден
void print_index(std::optional<unsigned> index, char c)
{
    if(index)
        std::cout << "Index of "<< c << ": " << *index << std::endl;
    else
        std::cout << "Index of "<< c << " not found" << std::endl;
}
std::optional<unsigned> find_index(const std::string& text, char c)
{
    if (text.empty())
        return std::nullopt;
    for(unsigned i{}; i < text.size();i++)
    {
        if(text[i]==c)
        {
            return i;
        } 
    }
    return std::nullopt;
}
```

поиск и печать разделены. `print_index` получает копию `optional` и сам символ, затем выводит индекс только при успехе. наличие значения записывается условием:

```cpp
if(index)
```

условие ложно, когда объект пуст, то есть когда в нём `std::nullopt`. условие истинно, когда значение есть. на результат не влияет само число: индекс `0` тоже означает успех. если бы искомый символ стоял в начале строки, проверка не приняла бы его за отсутствие. вывод программы:

```bash

Index of p: 4
Index of b not found
```

для `p` печатается индекс. для `b` печатается сообщение, что символ не найден. оператор `*` стоит только в той ветке, где `optional` уже содержит значение.

### программный интерфейс optional

те же действия записываются функциями-членами. модель от этого не меняется: объект либо пуст, либо хранит значение типа `T`.

- `has_value()` : возвращает `true`, если `optional` содержит значение, и `false`, если он пуст. проверку из `print_index` можно заменить этим вызовом. контекстное преобразование к `bool`, которым пользуется условие `if(index)`, истинно ровно при наличии значения. преобразование объявлено явным. в условии `if`, в `while` и в операнде логической операции оно выполняется без приведения. инициализация отдельного объекта типа `bool` копированием требует явного приведения

```cpp
if(index)
```

```cpp
index.has_value()
```

- `value()` : возвращает хранимое значение. перед вызовом состояние проверяют. на пустом объекте `value()` бросает исключение `std::bad_optional_access`. оператор `*` в том же состоянии исключения не бросает, обращение остаётся неопределённым поведением. проверка и чтение через `value()`:

```cpp

if(index.has_value())
    std::cout << "Index of "<< c << ": " << index.value() << std::endl;
else
    std::cout << "Index of "<< c << " not found" << std::endl;
```

- `value_or(default)` : если объект содержит значение, возвращает его. если объект пуст, возвращает аргумент `default`, приведённый к типу хранимого значения

функция `value_or` задаёт запасное значение там, где параметр разрешено не передавать.

```cpp

#include <iostream>
#include <optional>
 
double pow(double, std::optional<unsigned> = std::nullopt);
int main()
{
    double n1 = pow(4, 3);
    std::cout << n1 << std::endl;   // 64
    double n2 = pow(4);     // используем значение по умолчанию
    std::cout << n2 << std::endl;   // 16
}

double pow(double number, std::optional<unsigned> exp)
{
    unsigned a = exp.value_or(2);
    double result{1.0};
    for(unsigned i{}; i < a;i++)
    {
        result *= number;
    }
    return result;
}
```

`pow` возводит `number` в неотрицательную степень повторным умножением. второй параметр имеет тип `std::optional<unsigned>`, значение по умолчанию равно `std::nullopt`. вызов с одним аргументом оставляет степень пустой. вызов `pow(4, 3)` неявно строит `std::optional<unsigned>` со значением `3`: целое `3` преобразуется к `unsigned` и помещается внутрь объекта.

пустая степень внутри функции заменяется числом `2`, то есть основание возводится в квадрат:

```cpp
unsigned a = exp.value_or(2);
```

`value_or` объект `exp` не изменяет: вызов только выбирает возвращаемое число, хранимую степень или `2`. локальная переменная `a` задаёт число итераций. `result` начинается с `1.0` и на каждом шаге умножается на `number`. степень 3 даёт `4 * 4 * 4`, то есть 64. запасная степень 2 даёт `4 * 4`, то есть 16. оба результата печатает `main`. комментарии у вызовов фиксируют эти числа.
