к объектам `std::string` применимы операции сравнения. ими же сравнивают `string` со строковым литералом: литерал приводится к строке, либо используется перегрузка, принимающая `const char*`.

```cpp
> >= < <= == != <=>
```

операнды сравниваются посимвольно, пока не встретится пара различных символов или не кончится хотя бы одна строка. различающиеся символы упорядочиваются по своим числовым кодам. если все общие позиции совпали, а длины различаются, более короткая строка меньше более длинной. строки равны, когда длины совпадают и коды всех соответствующих символов равны. этот порядок называется лексикографическим. сравнение зависит от регистра: коды `'A'` и `'a'` различаются.

оператор `<=>` из списка выше есть трехстороннее сравнение стандарта c++20. для `std::string` он возвращает `std::strong_ordering`. результаты `<`, `>`, `<=`, `>=` и `==` согласованы с этим упорядочением.

оператор `==` возвращает `true`, если все символы обеих строк равны:

```cpp


std::string s1 {"hello"};

 

bool result {s1 == "Hello"}; // false - строки различаются по регистру

result = s1 == "hello";     // true
```

`"hello"` и `"Hello"` различаются кодом первого символа, поэтому строки не равны. то же написание в одном регистре дает равенство.

операция `>` (больше) на строках `helm` и `hello`:

`std::string s1 {"helm"};`

`std::string s2 {"hello"};`

`bool result {s1 > s2};		// true`

условие `s1 > s2` истинно: `s1` больше `s2`. первые три символа `hel` совпадают. дальше сравниваются четвертые символы, `m` и `l`. код `m` больше кода `l`, поэтому `helm` больше `hello`, хотя по числу символов `hello` длиннее `helm`.

программа ниже сортирует массив имен по возрастанию, то есть в лексикографическом порядке:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string people[] {"Tom", "Alice", "Sam", "Bob", "Kate"}; 

     // сортируем по возрастанию

    bool sorted {};

    do

    {

        sorted = true;      // остается true, если строки отсортированы

        std::string temp;   // переменная для обмена значениями

        for (unsigned i {1}; i < std::size(people); i++)

        {

            // если предыдущая строка больше последующей

            if (people[i-1] > people[i])

            { 

                // обмениваем значения

                temp = people[i];

                people[i] = people[i-1];

                people[i-1] = temp;

                sorted = false;

            }

        }

    } while (!sorted);

	// вывод строк на консоль

    for (const auto person: people) 

    {

        std::cout << person << std::endl;

    }

}
```

алгоритм есть сортировка пузырьком. она наглядна и имеет квадратичную сложность от числа строк: на каждом проходе соседние элементы сравниваются и при необходимости меняются местами. если предыдущая строка больше следующей, значения обмениваются через промежуточную переменную `temp`. флаг `sorted` сокращает работу. перед проходом он устанавливается в `true` и сбрасывается в `false` при любом обмене. внешний цикл `do-while` повторяется, пока проход не завершится без обменов. `std::size(people)` дает число элементов массива и доступна с c++17.

консольный вывод:

```bash


Alice

Bob

Kate

Sam

Tom
```

#### функция compare()

сравнение двух строк выполняет и функция `compare()`. в нее передается другая строка. функция возвращает 0, если строки равны. если текущая строка больше, возвращается число больше 0. если текущая строка меньше, возвращается число меньше 0. стандарт фиксирует знак результата. конкретные ненулевые значения выбирает реализация. в прогоне ниже это 0.

```cpp


std::string tom {"Tom"};

std::string person{"Tom"};

int result = tom.compare(person);

std::cout << result << std::endl;   // 0 - строки равны
```

здесь строки равны, поэтому результат равен 0.

второй прогон сравнивает разные имена:

```cpp


std::string tom {"Tom"};

std::string bob{"Bob"};

std::string sam {"Sam"};

    

int result = sam.compare(bob);      // 1 - первая строка (sam) больше второй (bob)

std::cout << result << std::endl;   // 1



result = sam.compare(tom);      // -1 - первая строка (sam) меньше второй (tom)

std::cout << result << std::endl;   // -1
```

`"Sam"` больше `"Bob"`, первый вызов возвращает положительное число, в этом прогоне 1. `"Sam"` меньше `"Tom"`, второй вызов возвращает отрицательное число, в этом прогоне -1.

у `compare()` несколько перегрузок. одна из них принимает три параметра:

```cpp
int compare(size_t _Off, size_t _Nx, const std::string &_Right) const
```

первый параметр есть индекс начала подстроки в текущей строке. второй есть число символов подстроки. третий есть строка, с которой эта подстрока сравнивается. сравнивается не вся текущая строка, а фрагмент `[pos, pos + count)`.

этой перегрузкой находят индекс вхождения одной строки в другую:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Hello world!"};

    std::string word {"world"};

    for (unsigned i{}; i < text.length() - word.length() + 1; i++)

    {

        if (text.compare(i, word.length(), word) == 0)

        {

            std::cout << "text contains " << word << " at index " << i << std::endl;

        }

    }

}
```

программа ищет индекс слова `world` в тексте `Hello world!`. цикл идет по индексам `text`, пока `i` не дойдет до границы `text.length() - word.length() + 1`. сравниваются `word.length()` символов, поэтому правый край окна сдвинут на длину слова. единица в формуле учитывает, что строки могут совпасть целиком, включая окно, прижатое к концу текста. на каждой итерации выполняется сравнение:

```cpp
if (text.compare(i, word.length(), word) == 0)
```

из `text` берется подстрока, которая начинается с индекса `i` и имеет длину `word.length()`, и она сравнивается со строкой `word`. нулевой результат означает равенство. первый такой индекс печатается. для данных примера консоль показывает:

```bash
text contains world at index 6
```

еще одна перегрузка сравнивает две подстроки: `compare(pos1, count1, other, pos2, count2)`. фрагмент текущей строки сопоставляется с фрагментом другой строки.

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"Hello world!"};

    std::string word {"world"};

    unsigned size {2}; // число сравниваемых символов из второй строки

    for (unsigned i{}; i < text.length() - size + 1; i++)

    {

        if (text.compare(i, size, word, 1, size) == 0)

        {

            std::cout << "text contains substring at index " << i << std::endl;

        }

    }

}
```

схема цикла прежняя. из `word`, равного `world`, берется подстрока длины `size`, начиная с индекса 1. при `size == 2` это символы `or`. они ищутся в `text`. консольный вывод:

```bash
text contains substring at index 7
```

индекс 7 соответствует вхождению `or` внутри `world` в строке `Hello world!`.
