одна из распространённых сред разработки для c++ это qt creator. qt creator кроссплатформенный: он работает на windows, linux и macos и покрывает широкий диапазон приложений, десктопные и мобильные, а также приложения для встроенных платформ. ниже создание простейшей программы на c++ в qt creator. шаблон обычного приложения на c++ при этом не обязан использовать типы библиотеки qt: в порождаемом файле достаточно стандартного потока ввода-вывода.

программу установки загружают со страницы [https://www.qt.io/download-qt-installer](https://www.qt.io/download-qt-installer)

сайт сам определяет текущую операционную систему и предлагает для неё онлайн-установщик. онлайн-установщик докачивает выбранные компоненты уже в ходе установки. загрузку начинают кнопкой `Download`:

![загрузка программы установки qt](/uploads/course-lectures/25e0705b7f1c253c2b454a00c4243c16365ac305.png)

### создание проекта c++ в qt creator

после завершения установки запускают qt creator. на стартовом экране выбирают вкладку `Projects`, по-русски «проекты», и на ней кнопку `New`, по-русски «создать»:

![первый проект в qt creator](/uploads/course-lectures/14a588fadc7419242fa431e43e3963540e5251a9.png)

в окне нового проекта в качестве шаблона выбирают `Plain C++ Application`. этот шаблон порождает консольную программу на c++ со стандартной точкой входа `main`, без класса окна из библиотеки qt:

![первый проект на языке c++ в qt creator](/uploads/course-lectures/aae590a5be83a1580d60838df39fb841e319150a.png)

дальше задают имя проекта и каталог, где он будет лежать:

![первый проект c++ в qt creator](/uploads/course-lectures/2498490e0aef980747b3394557e238f51263ed18.png)

на следующих шагах оставляют все значения по умолчанию. на последнем шаге проект создают кнопкой `Finish`:

![создание проекта plain c++ application в qt creator](/uploads/course-lectures/97c95c1e7066c8aadcbd5bc5e8da5b13d6cadad5.png)

открывается проект с содержимым по умолчанию:

![проект plain c++ application в qt creator](/uploads/course-lectures/94738a8272fb844cd1ab91b23f061db0f38d9a16.png)

у проекта один файл, `main.cpp`. в центральной части, в текстовом редакторе, открыт его код:

```cpp
#include <iostream>

using namespace std;

int main()
{
    cout << "Hello World!" << endl;
    return 0;
}
```

директива подключает заголовок стандартного потока ввода-вывода. `using namespace std` вносит имена пространства `std` в глобальную область этой единицы трансляции, поэтому `cout` и `endl` записаны без префикса `std::`. функция `main` отправляет в стандартный вывод строку и возвращает `0`, код успешного завершения процесса.

программу запускают зелёной стрелкой в нижнем левом углу qt creator. в нижней части открывается окно `Application Output` с результатами работы скомпилированной программы:

![первая программа на c++ в qt creator](/uploads/course-lectures/6f4fa726313de23e732c30b38ce77bc4e20005bc.png)
