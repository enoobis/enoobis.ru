### получение подстроки

`substr()` возвращает новую строку, копию фрагмента. исходный объект не меняется. первый параметр есть индекс начала, второй есть число копируемых символов:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string message{ "tom@localhost.com"};

    std::string submessage = message.substr(4, 9); // 9 символов начиная с 4-го 

    std::cout << submessage << std::endl;   // localhost

}
```

если запрошенная длина больше числа символов от `pos` до конца, в результат попадают все оставшиеся символы. исключения из-за слишком большой длины нет: длина обрезается до хвоста строки.

```cpp


std::string message{ "tom@localhost.com"};

std::string submessage = message.substr(4, 20); // localhost.com
```

если начальный индекс больше `size()`, позиция недействительна. `substr` бросает `std::out_of_range`, и при отсутствии обработчика программа завершается:

```cpp


std::string message{ "tom@localhost.com"};

std::string submessage = message.substr(24, 20); // ! Ошибка
```

чтобы забрать все символы от заданного индекса до конца, вызывают перегрузку с одним параметром. она эквивалентна `substr(pos, npos)`:

```cpp


std::string message{ "tom@localhost.com"};

std::string submessage = message.substr(4); // localhost.com
```

### проверка начала и завершения строки

проверить, что строка начинается с заданной подстроки, можно уже рассмотренными `compare()` и `substr()`. `compare(0, hello.length(), hello)` сравнивает префикс нужной длины с образцом. `substr(0, hello.length())` копирует префикс и сравнивает его оператором `==`:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"hello world!"};

    std::string hello {"hello"};



    // проверка, начинаяется ли text на строку hello

    // с помощью функции compare

    if (text.compare(0, hello.length(), hello) == 0)

    {

        std::cout << "The text starts with " << hello << std::endl;

    }

    // с помощью функции substr

    if (text.substr(0, hello.length()) == hello)

    {

        std::cout << "The text starts with " << hello << std::endl;

    }

}
```

со стандарта c++20 ту же проверку выполняет `starts_with()`. функция возвращает `true`, если текущая строка начинается с переданной строки. есть перегрузки для `string_view`, для `const char*` и для одного символа `char`:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"hello world!"};

    std::string hello {"hello"};



    // проверка, начинаяется ли text на строку hello

    if (text.starts_with(hello))

    {

        std::cout << "The text starts with " << hello << std::endl;

    }

}
```

окончание строки теми же средствами проверяют от индекса `length() - suffix.length()`. `compare` с этой позиции и `substr` с этой позиции сравнивают хвост с образцом:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"hello world"};

    std::string world {"world"};



    // конченый индекс

    unsigned end = text.length() - world.length();

    // проверка, заканчивается ли text на строку world

    if (text.compare(end, world.length(), world) == 0)

    {

        std::cout << "The text ends with " << world << std::endl;

    }

    // с помощью функции substr

    if (text.substr(end, world.length()) == world)

    {

        std::cout << "The text ends with " << world << std::endl;

    }

}
```

в c++20 для окончания добавлена `ends_with()`. функция возвращает `true`, если текущая строка заканчивается переданной строкой. набор перегрузок такой же, как у `starts_with()`:

```cpp


#include <iostream>

#include <string>



int main()

{

    std::string text {"hello world"};

    std::string world {"world"};



    // проверка, начинаяется ли text на строку world

    if (text.ends_with(world))

    {

        std::cout << "The text ends with " << world << std::endl;

    }

}
```
