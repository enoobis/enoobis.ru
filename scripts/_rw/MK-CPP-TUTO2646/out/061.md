служебное слово **this** обозначает указатель на объект, для которого вызвана функция-член. тип `this` в обычной функции-члене совпадает с указателем на класс, в константной функции-члене указатель константный: для класса `Point` это `Point*` и `const Point*`. через `this` доступен любой член объекта. в статической функции-члене `this` нет, такая функция к экземпляру не привязана.

```cpp


#include <iostream>



class Point

{

public:

	Point(int x, int y)

	{

		this->x = x; 

		this->y = y;

	}

	void showCoords() 

	{

		std::cout << "Point x: " << this->x << "\t y: " << y << std::endl;

	}

private:

	int x;

	int y;

};



int main()

{

	Point p1{20, 50};

	p1.showCoords();

}
```

класс `Point` задаёт точку на плоскости. координаты хранят члены `x` и `y`.

обращение к ним идёт через **this**. после `this` стоит стрелка **->**, точка здесь неприменима: `this` является указателем, и запись `this->x` равносильна `(*this).x`.

в большинстве тел имя члена видно и без `this`. указатель нужен, когда параметр или локальная переменная скрывает член: имя параметра в области функции перекрывает имя поля. конструктор как раз такой случай. запись `this->x = x` отправляет параметр в член. запись `x = x` присвоила бы параметр самому себе, член остался бы неинициализированным этой строкой.

другое применение **this**: вернуть текущий объект и продолжить вызов на нём.

```cpp


#include <iostream>



class Point

{

public:

	Point(int x, int y)

	{

		this->x = x; 

		this->y = y;

	}

	void showCoords() 

	{

		std::cout << "Coords x: " << x << "\t y: " << y << std::endl;

	}

	Point &move(int x, int y)

	{

		this->x += x;

		this->y += y;

		return *this;

	}

private:

	int x;

	int y;

};



int main()

{

    Point p1{20, 50};

    p1.showCoords();    // Point x: 20  y: 50

    p1.move(10, 5).move(10, 10);

    p1.showCoords();    // Point x: 40  y: 65

}
```

`move` через `this` сдвигает координаты и возвращает ссылку на тот же объект, тип возврата `Point&`. цепочка вызовов относится к одному экземпляру:

```cpp
p1.move(10, 5).move(10, 10);
```

возвращается ссылка на объект. строка выше по эффекту совпадает со следующим кодом.

```cpp


p1.move(10, 5);

p1.move(10, 10);
```

если `move` возвращает `Point` по значению, ссылки в типе возврата нет:

```cpp


Point move(int x, int y)

{

	this->x += x;

	this->y += y;

	return *this;

}
```

тогда вызов `p1.move(10, 5).move(10, 10)` равносилен такому коду.

```cpp


Point temp = p1.move(10, 5);

temp.move(10, 10);
```

второй `move` выполняется у временной копии, и объект `p1` этот вызов не изменяет. возврат по значению разрывает цепочку на исходном объекте: каждый следующий вызов получает уже другой экземпляр, копию.

вместо ссылки можно вернуть сам указатель **this**.

```cpp


#include <iostream>

 

class Point

{

public:

    Point(int x, int y)

    {

        this->x = x; 

        this->y = y;

    }

    void showCoords() 

    {

        std::cout << "Point x: " << this->x << "\t y: " << y << std::endl;

    }

    Point* move(int x, int y)

    {

        this->x += x;

        this->y += y;

        return this;

    }

private:

    int x;

    int y;

};

 

int main()

{

    Point p1{20, 50};

    p1.showCoords();    // Point x: 20  y: 50

    p1.move(10, 5)->move(10, 10)->move(10, 15);

    p1.showCoords();    // Point x: 50  y: 80

}
```

`move()` возвращает `this`, поэтому у результата следующий `move` вызывается операцией `->`.

```cpp
p1.move(10, 5)->move(10, 10)->move(10, 15)
```

другой пример:

```cpp


#include <iostream>



class Integer

{

public:

    Integer(int number)

    {

        value=number;

    }

    Integer& add(const Integer& obj)

    { 

        value += obj.value;

        return *this;

    }



    Integer& subtract(const Integer& obj) 

    {

        value -= obj.value;

        return *this;

    }



    Integer& multiply(const Integer& obj) 

    {

        value *= obj.value;

        return *this;

    }

    

    void print() const

    {

        std::cout << "Value: " << value << std::endl;

    }

private:

    int value;

};

int main()

{

    Integer num{10};

    num.add(Integer{30}).subtract(Integer{15}).multiply(Integer{2});

    num.print();    // Value: 50

}
```

класс `Integer` хранит целое в члене `value`. функции `add` (сложение), `subtract` (вычитание) и `multiply` (умножение) принимают другой `Integer`, выполняют операцию между текущим значением и аргументом и возвращают ссылку `Integer&` на текущий объект. возврат ссылки позволяет записать цепочку, и все три операции меняют один и тот же `num`. для начального значения 10 цепочка даёт сумму 10 и 30, то есть 40, затем разность 40 и 15, то есть 25, затем умножение на 2, то есть 50. это совпадает с выводом `Value: 50`.

```cpp


Integer num{10};

num.add(Integer{30}).subtract(Integer{15}).multiply(Integer{2});
```
