**пространство имён** группирует объявления в отдельные именованные области. пространство имён представляет собой блок объявлений с собственным именем. функции, классы и прочие компоненты, помещённые в него, получают это имя как часть своего имени. полное имя компонента состоит из имени пространства, оператора `::` (оператор разрешения области видимости, scope operator) и имени компонента. оператор `cout`, который выводит данные в стандартный поток, определён в пространстве `std`. обращение к нему записывается как `std::cout`. квалифицированное имя разделяет одинаковые неквалифицированные имена из разных пространств.

### глобальное пространство имён

если пространство имён не указано, применяется **глобальное пространство имён**. оно действует по умолчанию, когда для объявления не задано никакое пространство. имена в глобальном пространстве совпадают с тем, как они объявлены, без прикрепления имени пространства. пример:

```cpp


#include <iostream>

#include <string>



void print(const std::string&);



const std::string message{"hello"};

int main()

{

    print(message);

}



void print(const std::string& text)

{

    std::cout << text << std::endl;

}
```

здесь определены функции `print` и `main` и константа `message`, и никакое пространство имён не используется. следовательно, `print`, `main` и `message` определены в глобальном пространстве имён. для обращения к ним тоже можно применить оператор `::`, только без названия пространства. запись избыточна, но явно выбирает глобальную область:

```cpp


int main()

{

    ::print(::message);

}
```

функция `main` должна быть определена в глобальном пространстве имён. точка входа программы ищется именно там.

далее рассматривается, как определять и использовать собственные пространства имён.

### определение пространства имён

для определения пространства применяется служебное слово `namespace`, за которым идёт имя пространства:

```cpp


namespace имя_пространства_имен

{

	// код пространства имен

}
```

после имени пространства идёт блок кода. в него помещают компоненты пространства: функции, классы и другие объявления. одно и то же пространство допустимо открыть снова в другом месте единицы трансляции. повторное объявление дополняет прежнюю область, а не создаёт второе пространство с тем же именем.

например, пространство с именем `hello`:

```cpp


#include <iostream>

#include <string>



namespace hello

{

    const std::string message{"hello work"};

    void print(const std::string& text)

    {

        std::cout << text << std::endl;

    }

}



int main()

{

    hello::print(hello::message);   // hello work

}
```

в пространстве `hello` определены функция `print` и константа `message`. чтобы обратиться к этим компонентам вне пространства `hello`, используют его имя:

```cpp
hello::print(hello::message);
```

внутри пространства имён к его компонентам обращаются без имени пространства. неквалифицированный поиск находит имя в текущей области:

```cpp


namespace hello

{

    const std::string message{"hello work"};

    void print(const std::string& text)

    {

        std::cout << text << std::endl;

    }

    void print_default()

    {

        std::cout << message << std::endl;

    }

}
```

### вложенные пространства имён

одно пространство имён может содержать другие пространства:

```cpp


#include <iostream>

#include <string>



namespace console

{

    namespace messages

    {

        const std::string hello{"hello"};

        const std::string welcome{"Welcome"};

        const std::string goodbye{"Good bye"};

    }

    void print(const std::string& text)

    {

        std::cout << text << std::endl;

    }

    void print_default()

    {

        std::cout << messages::hello << std::endl;

    }

}



int main()

{

    console::print(console::messages::hello);

}
```

в пространстве `console` определено вложенное пространство `messages`, которое содержит ряд констант. для обращения к компонентам вложенного пространства тоже используют его имя:

```cpp


void print_default()

{

    std::cout << messages::hello << std::endl;

}
```

вне пространства `console` для таких констант указывают всю цепочку пространств имён:

```cpp


int main()

{

    console::print(console::messages::hello); // console { messages { hello}}

}
```

квалифицированное имя `console::messages::hello` проходит области снаружи внутрь: сначала `console`, затем `messages`, затем имя `hello`.

### директива using

директива `using` позволяет ссылаться на компонент пространства имён без использования его имени:

```cpp


#include <iostream>

#include <string>



namespace console

{

    const std::string message{"hello"};

    void print(const std::string& text)

    {

        std::cout << text << std::endl;

    }

}



using namespace console;    // подключаем все компоненты пространства console



int main()

{

    print(message); // указывать пространство имен не требуется

}
```

директива `using namespace console` записана в глобальной области и подключает все компоненты пространства `console` к неквалифицированному поиску в этой области. после неё имя пространства для обращения к его компонентам не требуется:

```cpp


using namespace console;    // подключаем все компоненты пространства console



int main()

{

    print(message); // указывать пространство имен не требуется

}
```

такое подключение приводит к нежелательным последствиям, если в глобальном пространстве имён уже определены компоненты с теми же именами, например переменная `message`. неквалифицированный поиск тогда неоднозначен. в этом случае подключают только отдельные компоненты:

```cpp


#include <iostream>

#include <string>



namespace console

{

    const std::string message{"hello"};

    void print(const std::string& text)

    {

        std::cout << text << std::endl;

    }

}



using console::print;    // подключаем только функцию print



int main()

{

    print(console::message); // надо указывать пространство для message

}
```

здесь подключена только функция `print`:

```cpp
using console::print;
```

для обращения к ней имя пространства указывать не нужно. для обращения к любым другим компонентам квалификация по-прежнему нужна.

объявление `using console::print` вводит в текущую область одно имя. директива `using namespace console` делает видимым весь набор имён пространства. первое ограничивает область возможной коллизии, второе сокращает запись ценой более широкого поиска.

### псевдонимы пространств

если название пространства длинное, для него определяют псевдоним:

```cpp
namespace псевдоним = название пространства имен;
```

пример:

```cpp


#include <iostream>

#include <string>



namespace console

{

    namespace messages

    {

        const std::string message{"hello"};

    }

    void print(const std::string& text)

    {

        std::cout << text << std::endl;

    }

}



namespace mes = console::messages;



int main()

{

    console::print(mes::message); // обращаемся к message через псевдоним mes

}
```

для пространства `console::messages` установлен псевдоним `mes`. псевдоним именует то же пространство, а не копию его объявлений: `mes::message` и `console::messages::message` обозначают одну константу.
