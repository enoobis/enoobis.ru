### take_view

представление **take_view** берёт заданное количество элементов с начала диапазона. для создания представления применяется конструктор **std::ranges::take_view**, в который передаются контейнер и число элементов префикса. это число задаёт, сколько элементов с начала представление отдаёт при обходе. если запрошено больше элементов, чем есть в диапазоне, представление отдаёт весь диапазон.

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges>



int main()

{

    std::vector<std::string> people { "Tom", "Bob", "Alice", "Sam", "Kate" };

    // берем 3 элемента

    auto view = std::ranges::take_view{people, 3};



    for(const auto& person: view)

    {

        std::cout << person << std::endl;

    }

}
```

из контейнера `people` берутся три первых элемента:

```cpp
auto view = std::ranges::take_view{people, 3};
```

вывод:

```bash


Tom

Bob

Alice
```

в качестве альтернативы используется функция **std::views::take()**, которая принимает число элементов префикса:

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges>



int main()

{

    std::vector<std::string> people { "Tom", "Bob", "Alice", "Sam", "Kate" };

    // берем 3 элемента

    auto view = people | std::views::take(3);



    for(const auto& person: view)

    {

        std::cout << person << std::endl;

    }

}
```

для создания представления используется операция `|`, которая применяется к контейнеру и к функции `std::views::take`:

```cpp
view = people | std::views::take(3);
```

### получение элементов по условию

представление **take_while_view** получает начальный отрезок элементов, которые соответствуют некоторому условию. условие задаётся функцией, которая принимает элемент контейнера и возвращает `true`, если элемент соответствует условию, и `false`, если не соответствует.

для создания представления применяется конструктор **std::ranges::take_while_view**, который принимает контейнер и функцию-условие:

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges>



int main()

{

    std::vector<std::string> people { "Tom", "Bob", "Alice", "Sam", "Kate" };

    auto condition = [](const std::string& s) {return s.length()==3; };



    auto view = std::ranges::take_while_view{people, condition};



    for(const auto& person: view)

    {

        std::cout << person << std::endl;

    }

}
```

условие представляет функцию, которая принимает строку и возвращает `true`, если длина строки равна 3 символам:

```cpp
auto condition = [](const std::string& s) {return s.length()==3; };
```

пока условие не вернёт `false`, элементы извлекаются из контейнера. вывод:

```bash


Tom

Bob
```

алгоритм отдаёт непрерывный префикс до первого элемента, для которого предикат ложен. элементы после этой границы в представление уже не входят.

в качестве альтернативы для создания представления используется функция **std::views::take_while()**, которая принимает функцию-условие:

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges> 



int main()

{

    std::vector<std::string> people { "Tom", "Bob", "Alice", "Sam", "Kate" };

    auto condition = [](const std::string& s) {return s.length()==3; };

     

    auto view = people | std::views::take_while(condition);



    for(const auto& person: view)

    {

        std::cout << person << std::endl;

    }

}
```
