### определение функции

функция определяет действия, которые выполняет программа. функция выделяет набор инструкций и назначает ему имя, после чего этот набор многократно вызывают по имени из разных мест программы. функция есть именованный блок кода. с точки зрения типов функция имеет тип, составленный из типа возвращаемого значения и типов параметров. этот тип нужен компилятору, чтобы проверить вызов.

формальное определение выглядит так:

```cpp


тип имя_функции(параметры)

{

    инструкции

}
```

первая строка есть заголовок функции. вначале указывается возвращаемый тип. если функция не возвращает значения, используют тип `void`. дохождение до конца функции типа `void` завершает её без значения. для любого другого типа выход из функции без `return` некорректен.

затем идёт имя функции, произвольный идентификатор. к именованию функции применяют те же правила, что и к именованию переменных: имя начинается с буквы или подчёркивания и далее содержит буквы, цифры и подчёркивания.

после имени в скобках перечисляются параметры. функция может не иметь параметров, тогда скобки пустые. параметры образуют локальные объекты, которые инициализируются аргументами вызова.

после заголовка в фигурных скобках стоит тело функции, последовательность выполняемых инструкций. тело есть составной оператор и задаёт область видимости локальных имён.

для возврата результата функция применяет оператор `return`. если возвращаемый тип есть любой тип, кроме `void`, функция обязана вернуть через `return` значение этого типа. значение после `return` преобразуется к возвращаемому типу, как при инициализации.

функция `main` обязана присутствовать в программе на c++ и с неё начинается выполнение. остальные функции сами по себе не стартуют:

```cpp


int main()

{

    return 0;

}
```

возвращаемый тип есть `int`, поэтому функция использует оператор `return` и возвращает значение типа `int`. возвращаемое значение ставится после оператора `return`. код возврата `main` передаётся среде исполнения как статус завершения процесса.

в функции `main` оператор `return` можно опустить. если управление доходит до конца `main` без `return`, это равносильно `return 0`. для любой другой функции с возвращаемым типом, отличным от `void`, такой пропуск некорректен:

```cpp


int main()

{



}
```

функции типа `void` возвращать значение не нужно. ниже функция только выводит текст на консоль и не содержит `return`:

```cpp


void hello()

{

	std::cout << "hello" << std::endl;

}
```

### выполнение функции

при запуске программы на c++ вызывается функция `main`. никакие другие функции, определённые в программе, автоматически не выполняются. для выполнения функцию вызывают. вызов имеет форму:

```cpp
имя_функции(аргументы);
```

после имени стоят скобки, в них перечисляются аргументы, значения для параметров функции. число и типы аргументов сверяются с объявлением. вызов есть выражение: если возвращаемый тип не `void`, его значение можно использовать дальше.

простейшая функция, определённая и вызванная дважды:

```cpp


#include <iostream>



void hello()

{

	std::cout << "hello" << std::endl;

}



int main()

{

	hello();

	hello();

}
```

функция `hello` определена в единице трансляции и вызывается из `main` два раза. в этом состоит назначение функции: общие действия выносят в отдельную функцию и вызывают из разных мест программы. программа два раза выводит строку `hello`:

```bash


hello

hello
```

### объявление функции

компилятор должен знать функцию до её вызова: имя в c++ объявляют до использования, чтобы к моменту вызова были известны возвращаемый тип и типы параметров. поэтому вызов располагают после определения, как в предыдущем примере. в части языков порядок не важен, в c++ он существенен. если функцию сначала вызвать, а потом определить, компиляция завершается ошибкой:

```cpp


#include <iostream>



int main()

{

	hello();

	hello();

}



void hello()

{

	std::cout << "hello" << std::endl;

}
```

перед вызовом функцию дополнительно объявляют. объявление функции называют прототипом. формально оно выглядит так:

```cpp
тип имя_функции(параметры);
```

фактически это заголовок функции, завершённый точкой с запятой. тела у прототипа нет: объявление вводит имя и тип в область видимости, определение дополнительно задаёт тело. определений у функции с внешней компоновкой в программе одно, согласованных объявлений может быть несколько. для функции `hello` объявление такое:

```cpp
void hello();
```

объявление ставят до вызова, определение оставляют ниже:

```cpp


#include <iostream>



void hello();



int main()

{

	hello();

	hello();

}



void hello()

{

	std::cout << "hello" << std::endl;

}
```

определение функции стоит после вызова. функция уже объявлена, поэтому компилятор знает имя `hello`, отсутствие параметров и тип `void`, и программа корректна.
