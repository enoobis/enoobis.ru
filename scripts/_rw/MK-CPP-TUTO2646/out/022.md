ссылка (reference) задаёт способ обращаться к уже существующему объекту. ссылка является альтернативным именем объекта, а не самостоятельным объектом и не хранит отдельную копию значения. для определения ссылки используется знак амперсанда `&`:

```cpp


int number {5};

int &refNumber {number};
```

здесь имя `refNumber` объявлено как ссылка на объект `number`. тип в определении ссылки совпадает с типом объекта, на который она ссылается. в примере это `int`. амперсанд входит в тип: `int&` читается как «ссылка на int».

ссылку нельзя объявить без инициализатора:

```cpp


int &refNumber;
```

она обязана быть связана с объектом в момент определения. после инициализации ссылку нельзя «переставить» на другой объект: любое присваивание через неё меняет сам объект, а не связь имени с объектом.

неконстантной ссылке нельзя присвоить литерал, например число:

```cpp


int &refNumber = 10;
```

литерал не является модифицируемым объектом. неконстантная ссылка требует lvalue, то есть выражение, обозначающее существующий объект, в который разрешена запись.

после связывания через ссылку обращаются к тому же объекту:

```cpp


#include <iostream>



int main()

{

	int number {5};

    int &refNumber {number};

	std::cout << refNumber << std::endl; // 5

	refNumber = 20;

	std::cout << number << std::endl; 	// 20

}
```

изменение по ссылке изменяет объект, на который она ссылается. в примере присваивание `refNumber = 20` записывает 20 в `number`, потому что оба имени обозначают один объект. отдельной ячейки для ссылки в модели программы нет.

ссылку определяют не только на переменную, но и на константу. сама ссылка при этом тоже должна быть константной:

```cpp


const int number{5};

const int &refNumber{number};

std::cout << refNumber << std::endl; // 5

//refNumber = 20; 		изменять значение по ссылке нельзя
```

неконстантную ссылку нельзя инициализировать константным объектом: иначе через ссылку оказалась бы возможна запись в объект, который через исходное имя изменять запрещено.

```cpp


const int number {5};

int &refNumber {number}; // ошибка
```

константная ссылка может указывать и на обычную переменную. через такую ссылку значение не изменяют, потому что тип ссылки не допускает модификацию:

```cpp


int number {5};

const int &refNumber {number};

std::cout << refNumber << std::endl; // 5



//refNumber = 20; 		изменять значение по ссылке на константу нельзя

	

// но мы можем изменить саму переменную

number = 20;

std::cout << refNumber << std::endl; 	// 20
```

напрямую записать значение через константную ссылку нельзя. сам объект при этом изменить можно, если существует другое, неконстантное имя. после `number = 20` чтение через `refNumber` тоже даёт 20: ссылка не копирует значение в момент инициализации, а продолжает именовать тот же объект.

константная ссылка, в отличие от неконстантной, может быть связана и с временным значением. время жизни временного объекта тогда продлевается до конца времени жизни ссылки.

### ссылки в цикле for

чаще всего ссылки используют в функциях, когда значение передают по ссылке. этот способ разбирается в следующих лекциях. есть и другие применения. в цикле `for`, который обходит последовательность в стиле range-for, переменная цикла по умолчанию получает копию элемента, и присваивание этой копии не меняет элемент последовательности:

```cpp


#include <iostream>



int main()

{

    int numbers[] {1, 2, 3, 4, 5};

    // меняем число на его квадрат

    for (auto n : numbers)

    {

        n = n * n;

    }

    // смотрим результат

    for (auto n : numbers)

    {

        std::cout << n << "\t";

    }

    std::cout << std::endl;

}
```

в программе два цикла. в первом каждый элемент массива копируется в переменную `n`, и этой переменной присваивается квадрат числа. меняется только локальная копия `n`, элементы массива `numbers` сохраняют прежние значения. второй цикл выводит их на консоль:

```bash
1       2       3       4       5
```

если переменная цикла объявлена ссылкой, присваивание записывается в сам элемент:

```cpp


#include <iostream>



int main()

{

    int numbers[] {1, 2, 3, 4, 5};

    // теперь n - ссылка на элемент массива

    for (auto& n : numbers)

    {

        n = n * n;

    }

    // смотрим результат

    for (auto n : numbers)

    {

        std::cout << n << "\t";

    }

    std::cout << std::endl;

}
```

в первом цикле `n` имеет тип ссылки на элемент массива. значение элемента не копируется в отдельную переменную, поэтому обход не тратит копирование, а запись `n = n * n` изменяет соответствующий элемент. второй цикл печатает уже изменённый массив:

```bash
1       4       9       16      25
```

если элементы изменять не нужно, ссылку делают константной:

```cpp


#include <iostream>



int main()

{

    int numbers[] {1, 2, 3, 4, 5};

    // n - константная ссылка

    for (const auto& n : numbers)

    {

        std::cout << n << "\t";

    }

    std::cout << std::endl;

}
```

значение элемента через `const auto&` не изменяется, но копия по-прежнему не создаётся. для `int` выигрыш мал, для крупного объекта или элемента контейнера отказ от копирования уже входит в стоимость обхода. константная ссылка одновременно фиксирует намерение: цикл только читает последовательность.
