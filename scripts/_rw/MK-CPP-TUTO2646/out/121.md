лямбда-выражение задаёт объект-функцию более короткой записью, без отдельного объявления класса. формальный синтаксис:

```cpp
[] (параметры) { действия }
```

выражение начинается с квадратных скобок: это список захвата, даже если он пуст. затем, как у обычной функции, в круглых скобках перечисляются параметры, их типы и имена. со стандарта c++14 параметрам лямбды можно задавать значения по умолчанию. после списка параметров в фигурных скобках записывается тело.

простейший пример:

```cpp
[]() { std::cout << "Hello" << std::endl; }
```

параметров нет, поэтому круглые скобки пусты. тело выводит на консоль строку `Hello`.

встретив лямбда-выражение, компилятор порождает новый тип класса, то есть объект-функцию. для примера выше порождённый класс упрощённо выглядит так.

```cpp


class __Lambda1234

{

public:

	auto operator()() const { std::cout << "Hello" << std::endl; }

};
```

имя класса произвольно, но уникально: его выбирает компилятор, и в исходном тексте его нет. два одинаковых по тексту лямбда-выражения получают разные типы. тело лямбды становится оператором `()`, а вместо явного возвращаемого типа стоит **auto**: возвращаемый тип выводит компилятор. это может быть `void` или конкретный тип выражения в `return`. оператор вызова по умолчанию константный.

для лямбды без параметров пустой список `()` можно опустить. форма `[]() {...}` сокращается до `[] {...}`.

```cpp
[]{ std::cout << "Hello" << std::endl; }
```

### вызов лямбда-выражения

лямбду можно вызвать сразу в точке определения. после тела ставятся круглые скобки с аргументами.

```cpp


#include <iostream>

 

int main()

{

    [](){std::cout << "Hello" << std::endl;} ();

    // или так

    []{std::cout << "Hello" << std::endl;} ();

}
```

параметров у этих лямбд нет, поэтому сразу после определения стоят пустые скобки.

```cpp
[](){std::cout << "Hello" << std::endl;} ();
```

выполняется тело, и на консоль выводится строка `Hello`.

### именованные лямбда-выражения

лямбда-выражение можно сохранить в переменной.

```cpp


#include <iostream>

 

int main()

{

    // переменная hello представляет лямбда-выражение 

    auto hello { [](){std::cout << "Hello" << std::endl;} };



    // через переменную вызываем лямбда-выражение

    hello();    // Hello

    hello();    // Hello

}
```

переменная `hello` хранит лямбду. тип замыкания безымянный, записать его в программе нельзя, поэтому переменная объявляется через **auto**: тип выводит компилятор.

далее по имени переменной лямбда вызывается как обычная функция. каждый вызов использует тот же объект замыкания.

```cpp
hello();
```

### параметры

лямбда с параметром:

```cpp


#include <iostream>

#include <string>

 

int main()

{

    auto print { [](const std::string& text){std::cout << text << std::endl;} };



    // вызываем лямбда-выражение

    print("Hello World!");			// Hello World!

    print("Good bye, World...");	// Good bye, World...

}
```

параметр имеет тип `const std::string&`: это строка, и она выводится на консоль. лямбда присвоена переменной `print`.

вызов `print` записывается как вызов обычной функции, аргументом передаётся строка.

```cpp


print("Hello World!");			// Hello World!

print("Good bye, World...");	// Good bye, World...
```

ту же лямбду можно вызвать сразу при определении, передав строку аргументом.

```cpp
[](const std::string& text){std::cout << text << std::endl;} ("Hell");
```

### возвращение значения

лямбда может возвращать значение. для этого, как и в обычной функции, служит оператор **return**.

```cpp


#include <iostream>

 

int main()

{

    auto sum { [](int a, int b){return a + b;} };



    // вызываем лямбда-выражение

    std::cout << sum(10, 23) << std::endl;  // 33



    // присваиваем его результат переменной

    int result { sum(1, 4)};

    std::cout << result << std::endl;       // 5

}
```

эта лямбда возвращает сумму параметров. тип суммы двух `int` есть `int`, поэтому результат можно употреблять как значение типа `int`: передать в поток вывода или сохранить в переменной.

по умолчанию возвращаемый тип выводит компилятор по выражению в `return`. его можно указать и явно, замыкающим возвращаемым типом.

```cpp


#include <iostream>

 

int main()

{

    auto sum { [](int a, int b) -> double {return a + b;} };



    // вызываем лямбда-выражение

    std::cout << sum(10, 23) << std::endl;  // 33

}
```

после списка параметров ставятся стрелка и тип результата. в этом примере результат имеет тип `double`.

```cpp
[](int a, int b) -> double {return a + b;}
```

сумма двух `int` сама по себе имеет тип `int` и при возврате преобразуется к `double`.

### лямбда-выражения как параметры функций

лямбду можно передать параметру, который является указателем на функцию.

```cpp


#include <iostream>

 

void do_operation(int a, int b, int (*op)(int, int))

{

    std::cout << op(a, b) << std::endl; 

}



int main()

{

    auto sum { [](int a, int b) {return a + b;} };

    auto subtract { [](int a, int b) {return a - b;} };



    do_operation(10, 4, sum);           // 14

    do_operation(10, 4, subtract);     // 6

}
```

функция `do_operation` принимает два числа и указатель на функцию, которая выполняет над ними операцию. на место указателя передаётся лямбда с той же сигнатурой: два параметра типа `int` и результат типа `int`. это возможно, потому что для лямбды без захвата компилятор генерирует оператор преобразования к указателю на функцию с эквивалентной сигнатурой. если лямбда обращается к внешним переменным, то есть что-то захватывает, оператор преобразования не генерируется: указатель на функцию не может нести состояние замыкания. такой случай рассматривается в следующей лекции.

лямбду можно записать прямо в аргументе. так поступают, когда больше нигде она не нужна.

```cpp
do_operation(10, 4, [](int a, int b) {return a * b;});  // 40
```

### универсальные лямбда-выражения

универсальное лямбда-выражение (generic lambda) есть лямбда, у которой хотя бы один параметр объявлен как **auto**, **auto&** или **const auto&**. параметр не привязан к одному заранее названному типу. в c++14 оператор `()` такой лямбды является шаблоном: конкретные типы выводятся при вызове, и каждая комбинация аргументов порождает свою специализацию.

```cpp


#include <iostream>

#include <string>



int main()

{

    auto add = [](auto a, auto b) {return a + b;};

    //auto print = [](const auto& value) {std::cout << value << std::endl; };



    std::cout << add(2, 3) << std::endl;        // 5 - складываем числа int

    std::cout << add(2.2, 3.4) << std::endl;    // 5.6 - складываем числа double



    std::string hello{"hello "};

    std::string world{"world"};

    std::cout << add(hello, world) << std::endl;    // hello world - складываем строки

}
```

эта лямбда принимает два параметра и возвращает их сумму. она присвоена переменной `add`.

```cpp
auto add = [](auto a, auto b) {return a + b;};
```

в точке написания типы параметров неизвестны. компилятор выводит их при вызове по переданным аргументам.

```cpp
std::cout << add(2, 3) << std::endl;
```

здесь оба аргумента имеют тип `int`, и результат является суммой этих чисел типа `int`. те же параметры принимают `double`, тогда складываются числа с плавающей точкой. для двух объектов `std::string` оператор `+` выполняет конкатенацию, и результат тоже является строкой. тип результата у каждой специализации свой: его выводит `return`.

другой пример: универсальная лямбда печатает произвольное значение. параметр `const auto&` связывается с аргументом любого типа, для которого определён вывод в поток, и копии аргумента не делает.

```cpp


#include <iostream>



int main()

{

    auto print = [](const auto& value) {std::cout << value << std::endl; };



    print("Hello");

    print(4);

    print(45.6789);

}
```
