для отдельных предметных условий в программе вводят собственные типы исключений. объект такого типа переносит структурированное состояние ошибки, а не одно значение примитивного типа. ниже это показано на проверке возраста при создании объекта `Person`.

```cpp


#include <iostream>

#include <string>



class AgeException

{

public: 

    AgeException(std::string message): message{message}{}

    std::string getMessage() const {return message;}

private:

    std::string message;

};



class Person

{

public:

    Person(std::string name, unsigned age)

    {

        if(!age||age>110)   // если возраст равен 0 или больше 110

        {

            throw AgeException{"Invalid age"};

        }

        this->name = name;

        this->age = age;

    }

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

};



int main()

{

    try

    {

        Person tom{"Tom", 38};      // Корректные данные

        tom.print();



        Person bob{"Bob", 1500};    // Некорректные данные

        bob.print();

    }

    catch (const AgeException& ex)

    {

        std::cout << ex.getMessage() << std::endl;

    }

}
```



класс `Person` принимает в конструкторе имя и возраст. возраст ограничен диапазоном от 1 до 110 включительно. если переданное значение выходит за эти пределы, конструктор генерирует исключение оператором `throw`:

```cpp
throw AgeException{"Invalid age"};
```



класс `AgeException` инкапсулирует ошибку, связанную с возрастом: хранит текст сообщения и даёт к нему доступ методом `getMessage`.

в блоке `try` создаются два объекта `Person`. первый вызов передаёт корректный возраст, второй передаёт значение вне диапазона:

```cpp
Person bob{"Bob", 1500};
```



при втором вызове конструктор выбрасывает `AgeException`, и управление переходит в блок `catch`, параметр которого имеет этот тип:

```cpp


catch (const AgeException& ex)

{

    std::cout << ex.getMessage() << std::endl;

}
```



параметр обработчика объявлен как константная ссылка `const AgeException&`. ссылка связывается с существующим объектом исключения, поэтому лишнее копирование не выполняется, а при дальнейшем наследовании сохраняется динамический тип объекта.

консольный вывод:

```bash


Name: Tom       Age: 38

Invalid age
```



### последовательность обработки исключений базовых и производных классов

при возникновении исключения блоки `catch` просматриваются в порядке их записи в коде. выбирается первый блок, параметр которого совместим с типом исключения. для исключений, тип которых не является классом, требуется точное совпадение типа объекта и типа параметра. для исключений-объектов классов при сопоставлении допускаются неявные преобразования. обработчик подходит, если выполнено одно из условий:

- параметр `catch` имеет тот же тип, что и исключение (`const` игнорируется)

- тип параметра `catch` является базовым классом типа исключения либо ссылкой на такой базовый класс (`const` игнорируется)

- и исключение, и параметр `catch` являются указателями, а объект исключения неявно преобразуется к типу параметра (`const` игнорируется)

поскольку объект производного класса неявно преобразуется к базовому, один обработчик базового типа перехватывает и базовые, и производные исключения.

```cpp


#include <iostream>

#include <string>



class AgeException

{

public: 

    AgeException(std::string message): message{message}{}

    virtual std::string getMessage() const  // виртуальная функция

    {

        return message;

    }

private:

    std::string message;

};



class MaxAgeException: public AgeException

{

public: 

    MaxAgeException(std::string message, unsigned maxAge): AgeException{message}, maxAge{maxAge}

    {}

    std::string getMessage() const override // переопределяем виртуальную функцию

    {   

        return AgeException::getMessage() + " Max age should be " + std::to_string(maxAge);

    }

private:

    unsigned maxAge;

};



class Person

{

public:

    Person(std::string name, unsigned age)

    {

        if(!age)   // если возраст равен 0

        {

            throw AgeException{"Invalid age"};

        }

        if(age>110)   // если возраст больше 110

        {

            throw MaxAgeException{"Invalid age.", 110};

        }

        this->name = name;

        this->age = age;

    }

    void print() const

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

};



int main()

{

    try

    {

        Person bob{"Bob", 1500};    // Некорректные данные

        bob.print();

    }

    catch (const AgeException& ex)

    {

        std::cout << ex.getMessage() << std::endl;

    }

}
```



для случая, когда возраст превышает максимум, введён класс `MaxAgeException`. он открыто наследует `AgeException`, сохраняет предельное значение возраста и переопределяет `getMessage`.

в конструкторе `Person` два типа исключения генерируются раздельно:

```cpp


if(!age)   // если возраст равен 0

{

    throw AgeException{"Invalid age"};

}

if(age>110)   // если возраст больше 110

{

    throw MaxAgeException{"Invalid age.", 110};

}
```



оба исключения обрабатываются одним блоком `catch` по базовому типу `AgeException`:

```cpp


catch (const AgeException& ex)

{

    std::cout << ex.getMessage() << std::endl;

}
```



`getMessage` объявлена виртуальной и переопределена в `MaxAgeException`, а параметр `catch` имеет тип ссылки. вызов идёт через динамическую диспетчеризацию: выбирается реализация фактического типа объекта. при перехвате по значению объект был бы срезан до `AgeException`, и вызывалась бы версия базового класса. на консоль выводится:

```bash


Invalid age. Max age should be 110
```



#### раздельная обработка исключений

раздельная обработка нужна, когда для производного типа требуется вызвать операции, отсутствующие в базовом классе. из-за неявного преобразования к базе обработчик производного типа размещают перед обработчиком базового. иначе базовый `catch` перехватит объект раньше, и более специфичный блок окажется недостижимым. ниже классы `Person`, `AgeException` и `MaxAgeException` обрабатываются отдельными блоками `catch`:

```cpp


void testPerson(std::string name, unsigned age)

{

    try

    {

        Person person{name, age};

        person.print();

    }

    catch (const MaxAgeException& ex)   // сначала обрабатываем исключение производного типа

    {

        std::cout << "MaxAgeException: " << ex.getMessage() << std::endl;

    }

    catch (const AgeException& ex)  // потом обрабатываем исключение базового типа

    {

        std::cout << "AgeException: " << ex.getMessage() << std::endl;

    }

}

int main()

{

    testPerson("Tom", 0);       // AgeException: Invalid age

    testPerson("Bob", 1000);    // MaxAgeException: Invalid age. Max age should be 110

}
```
