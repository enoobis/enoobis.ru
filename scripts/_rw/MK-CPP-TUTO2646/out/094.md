**итераторы** обеспечивают доступ к элементам контейнера и реализуют паттерн iterator. позиция в последовательности представлена отдельным объектом, а алгоритм обхода опирается на операции этого объекта и остаётся одним и тем же для контейнеров с разным устройством памяти. в c++ итераторы задают общий набор операций, поэтому один и тот же приём обращения к элементам применяется к контейнерам разных типов.

итераторы есть у контейнеров-последовательностей и у ассоциативных контейнеров. адаптеры контейнеров `std::stack`, `std::queue` и `std::priority_queue` итераторов не имеют: адаптер скрывает нижележащий контейнер и оставляет только операции своей дисциплины доступа (вершина стека, концы очереди, элемент с наивысшим приоритетом).

тип итератора вложен в контейнер и называется `iterator`. у каждого контейнера этот тип свой: у списка это `std::list<T>::iterator`, у вектора `std::vector<T>::iterator`. операции, через которые читается и записывается элемент, в пределах одной категории итераторов совпадают.

границы контейнера задают `begin()` и `end()`. `begin()` возвращает итератор на первый элемент, если контейнер не пуст. `end()` возвращает итератор на позицию, следующую за последним элементом: это граница конца, в которой элемента нет. диапазон обхода полуоткрытый, `[begin(), end())`. у пустого контейнера итераторы `begin()` и `end()` равны. если `begin()` не равен `end()`, в диапазоне лежит хотя бы один элемент.

обе функции возвращают итератор того контейнера, у которого вызваны:

```cpp


#include <iostream>

#include <vector>



int main()

{

    std::vector<int> numbers{ 1,2,3,4 };

    std::vector<int>::iterator iter = numbers.begin();  // получаем итератор

}
```

здесь создаётся `std::vector<int>`, инициализированный значениями `{1, 2, 3, 4}`. вызов `begin()` даёт итератор на первый элемент этого вектора.

допустимые операции зависят от категории итератора:

- `*iter`: получение элемента, на который указывает итератор
- `++iter`: перемещение вперёд, к следующему элементу
- `--iter`: перемещение назад, к предыдущему элементу. итераторы `std::forward_list` однонаправленные, декремент они не поддерживают
- `iter1 == iter2`: итераторы равны, если указывают на один и тот же элемент
- `iter1 != iter2`: итераторы не равны, если указывают на разные элементы
- `iter + n`: итератор, смещённый от `iter` на n позиций вперёд
- `iter - n`: итератор, смещённый от `iter` на n позиций назад
- `iter += n`: перемещение итератора на n позиций вперёд
- `iter -= n`: перемещение итератора на n позиций назад
- `iter1 - iter2`: число позиций между `iter1` и `iter2`
- `>`, `>=`, `<`, `<=`: отношения порядка поддерживаются только итераторами произвольного доступа, то есть итераторами `std::vector`, `std::array` и `std::deque`. к той же категории относятся арифметика `+` и `-`, составные присваивания `+=` и `-=` и разность двух итераторов

### получение и изменение элемента контейнера

разыменование итератора даёт элемент в текущей позиции. через неконстантный итератор элемент читается и записывается: семантика близка к указателю на элемент.

```cpp


#include <iostream>

#include <vector>



int main()

{

    std::vector<int> numbers{ 1,2,3,4 };

    auto iter { numbers.begin() };  // получаем итератор



    // получаем элемент, на который указывает итератор

    std::cout << *iter << std::endl;    // 1

    // изменяем элемент

    *iter = 125;

    // проверяем изменение элемента

    std::cout << numbers[0] << std::endl;    // 125

}
```

сразу после `begin()` итератор указывает на первый элемент, и выражение `*iter` возвращает именно его. присваивание `*iter = 125` меняет значение в контейнере, что подтверждает последующее чтение `numbers[0]`.

прибавление и вычитание целого смещают итератор на заданное число элементов. для `std::vector` это определено: его итераторы имеют категорию произвольного доступа, элементы лежат в непрерывном блоке памяти, и смещение на n есть адресная арифметика.

```cpp


#include <iostream>

#include <vector>



int main()

{

    std::vector<int> numbers{ 10, 20, 30, 40 };

    auto iter { numbers.begin() };  // получаем итератор



    // переходим на 1 элемент вперед ко 2-му элементу

    ++iter;

    std::cout << *iter << std::endl;    // 20



    // переходим на 2 элемента вперед к 4-му элементу

    iter +=2; 

    std::cout << *iter << std::endl;    // 40



    // переходим назад на 3 элемента к 1-му элементу

    iter = iter - 3;

    std::cout << *iter << std::endl;    // 10

}
```

категория итератора ограничивает набор операций. у `std::list` итератор двунаправленный: определены `++` и `--`, смещения на n за постоянное время нет. у `std::forward_list` нет и декремента.

### перебор контейнера

обход вектора сводится к движению от `begin()` к `end()` с разыменованием на каждом шаге:

```cpp


#include <iostream>

#include <vector>



int main()

{

    std::vector<int> numbers{ 10, 20, 30, 40 };

    auto iter { numbers.begin() };  // получаем итератор



    while(iter!=numbers.end())    // пока не дойдем до конца

    {

        std::cout << *iter << std::endl;// получаем элементы через итератор

        ++iter;             // перемещаемся вперед на один элемент

    }



    // аналогичный пример с циклом for

    for(auto start{numbers.begin()}; start !=numbers.end(); start++ )

    {

        std::cout << *start << std::endl;

    }

}
```

цикл `while` выполняется, пока итератор не стал равен `end()`. тело читает элемент через `*iter` и продвигает итератор. цикл `for` записывает ту же схему явно: инициализация итератором начала, условие `start != numbers.end()`, шаг `start++`. префиксный и постфиксный инкремент оба сдвигают позицию. если предыдущее значение итератора не нужно, достаточен префиксный `++`: постфиксная форма у итераторов классового типа возвращает копию прежнего состояния.

вставка и удаление элементов способны сделать текущие итераторы, а также ссылки и указатели на элементы недопустимыми. после такой модификации старые итераторы использовать нельзя, позицию получают заново. правила инвалидации зависят от контейнера. вставка в `std::list` не инвалидирует итераторы остальных узлов. перераспределение буфера `std::vector` инвалидирует все итераторы, ссылки и указатели на его элементы.

### константные итераторы

у константного контейнера элементы доступны только через константный итератор типа `const_iterator`. разыменование даёт ссылку на константный элемент: чтение разрешено, присваивание через `*iter` не компилируется.

```cpp


const vector<int> numbers{1, 2, 3, 4, 5};

for(auto iter {numbers.begin()}; iter != numbers.end(); ++iter)

{

	std::cout << *iter << std::endl;

	// так нельзя сделать

	//*iter = (*iter) * (*iter);

}
```

в этом фрагменте тип `iter` выводится как `std::vector<int>::const_iterator`, потому что `begin()` константного контейнера возвращает константный итератор.

константный итератор возвращают и `cbegin()` с `cend()`. контейнер при этом может быть изменяемым: запрет записи задаёт тип итератора, полученный из этих функций.

```cpp


#include <iostream>

#include <vector>



int main()

{

	std::vector<int> numbers { 1, 2, 3, 4, 5 };

	for (auto iter {numbers.cbegin()}; iter != numbers.cend(); ++iter)

	{

		std::cout << *iter << std::endl;

		// так нельзя сделать, так как итератор константный

		//*iter = (*iter) * (*iter);

	}

}
```

у `std::set` элемент константен целиком. значение узла является ключом упорядочения, и его изменение разрушило бы инвариант дерева поиска. у `std::map` через итератор меняется отображаемое значение, ключ остаётся константным: тип элемента имеет вид `std::pair<const Key, T>`. в обоих контейнерах ключ через итератор не переписывается.

### реверсивные итераторы

реверсивный итератор обходит контейнер от последнего элемента к первому. его дают `rbegin()` и `rend()`, тип называется `reverse_iterator`. `rbegin()` указывает на последний элемент, `rend()` на позицию перед первым. инкремент такого итератора сдвигает позицию к началу контейнера. диапазон снова полуоткрытый: `[rbegin(), rend())`.

```cpp


#include <iostream>

#include <vector>

 

int main()

{

    std::vector<int> numbers { 1, 2, 3, 4, 5 };

    for (auto iter {numbers.rbegin()}; iter != numbers.rend(); ++iter)

    {

        std::cout << *iter << "\t";

    }

    std::cout << std::endl;

}
```

тип итератора в этом обходе `std::vector<int>::reverse_iterator`. консольный вывод программы:

```bash


5       4       3       2       1
```

запрет записи при обратном обходе даёт константный реверсивный итератор `const_reverse_iterator`. его возвращают `crbegin()` и `crend()`.

```cpp


#include <iostream>

#include <vector>

 

int main()

{

    std::vector<int> numbers { 1, 2, 3, 4, 5 };

    for (auto iter {numbers.crbegin()}; iter != numbers.crend(); ++iter)

    {

        std::cout << *iter << std::endl;

        // так нельзя сделать, так как итератор константный

		//*iter = (*iter) * (*iter);

    }

}
```

### итераторы для массивов

для встроенного массива стандартная библиотека c++ определяет свободные функции `std::begin()` и `std::end()`. первая возвращает итератор на начало массива, вторая на позицию за последним элементом. у массива эти итераторы имеют тип указателя на элемент: память непрерывна, и указатель моделирует итератор произвольного доступа.

```cpp


int data[]{4, 5, 6, 7, 8};

// получаем итератор на начало массива 

auto iter = std::begin(data);

// получаем итератор на конец массива

auto end = std::end(data);
```

обход массива записывается так же, как обход контейнера:

```cpp


#include <iostream>

 

int main()

{

    int data[]{4, 5, 6, 7, 8};

    // перебор массива с помощью итераторов

    for(auto iter {std::begin(data)}; iter != std::end(data); iter++)

    {

        std::cout << *iter << std::endl;

    }

}
```

тот же массив обходится по индексам и через обычные указатели. итераторы нужны там, где интерфейс принимает пару границ, а индекс в этот интерфейс не входит. функция `insert()` у ряда контейнеров вставляет полуоткрытый диапазон другой последовательности. границами диапазона служат итераторы, в том числе полученные от массива. так в вектор переносится фрагмент массива:

```cpp


#include <iostream>

#include <vector>

 

int main()

{

    int data[]{4, 5, 6, 7, 8};

    std::vector<int> numbers { 1, 2, 3, 4};

    // добавляем в конец вектора numbers из массива data элементы со 2-го по предпоследний (включительно)

    numbers.insert(numbers.end(), std::begin(data) + 1, std::end(data)-1);

    for (auto iter {numbers.begin()}; iter != numbers.end(); ++iter)

    {

        std::cout << *iter << "\t";

    }

    std::cout << std::endl;

}
```

вставка задаётся вызовом

```cpp
numbers.insert(numbers.end(), std::begin(data) + 1, std::end(data)-1);
```

элементы помещаются в `numbers` с позиции `numbers.end()`, то есть в конец вектора. начало диапазона задаёт `std::begin(data) + 1`, это второй элемент массива. конец задаёт `std::end(data) - 1`, это позиция последнего элемента. диапазон полуоткрытый, поэтому последний элемент массива в вставку не входит, а предпоследний входит. из `{4, 5, 6, 7, 8}` берётся фрагмент `{5, 6, 7}`. консольный вывод:

```bash
1       2       3       4       5       6       7
```
