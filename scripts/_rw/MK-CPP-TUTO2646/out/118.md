оператор присваивания с перемещением (move assignment operator) решает ту же задачу, что и конструктор перемещения, но для уже существующего объекта слева. форма оператора:

```cpp

MyClass& operator=(MyClass&& moved)
{
	// код оператора
	return *this; // возвращаем текущий объект
}
```

параметр является rvalue-ссылкой на перемещаемый объект. оператор забирает его ресурс, приводит источник в пустое состояние и возвращает текущий объект через `*this`, чтобы присваивание можно было включать в цепочку.

определим такой оператор и применим его. рядом в том же классе остаётся обычный оператор присваивания с копированием: он нужен для lvalue.

```cpp

#include <iostream>
 
// класс сообщения
class Message
{
public:
    // обычный конструктор
    Message(const char* data, unsigned count)
    {
        size = count;
        text = new char[size];  // выделяем память
        for(unsigned i{}; i < size; i++)    // копируем данные
        {
            text[i] = data[i];
        }

        id = ++counter;
        std::cout << "Create Message " << id << std::endl;
    }
    // обычный оператор присваивания
    Message& operator=(const Message& copy)
    {
        std::cout << "Copy assign message " << copy.id << " to " << id << std::endl;
        if (&copy != this)  // избегаем самоприсваивания
        {
            delete text;        // освобождаем память текущего объекта
            // копируем данные по указателю из перемещаемого объекта в текущий
            size = copy.size;
            text = new char[size];  // выделяем память
            for(unsigned i{}; i < size; i++)    // копируем данные
            {
                text[i] = copy.text[i];
            }
        }
        return *this; // возвращаем текущий объект
    }
    // опрератор присваивания с перемещением
    Message& operator=(Message&& moved)
    {
        std::cout << "Move assign message " << moved.id << " to " << id << std::endl;
        if (&moved != this)     // избегаем самоприсваивания
        {
            delete text;        // освобождаем память текущего объекта
            text = moved.text;  // копируем указатель из перемещаемого объекта в текущий
            size = moved.size;
            moved.text = nullptr; // сбрасываем значение указателя в перемещаемом объекте
            moved.size = 0;
        }
        return *this; // возвращаем текущий объект
    }
    // деструктор
    ~Message()
    { 
        std::cout << "Delete Message "  << id << std::endl;
        delete[] text;  // освобождаем память
    }
    char* getText() const { return text; }
    unsigned getSize() const { return size; }
    unsigned getId() const {return id;}
private:
    char* text{};  // текст сообщения
    unsigned size{};    // размер сообщения
    unsigned id{};  // номер сообщения
    static inline unsigned counter{};   // статический счетчик для генерации номера объекта
};

int main()
{
    char text1[] {"Hello Word"};
    Message hello{text1, std::size(text1)};

    char text2[] {"Hi World!"};
    hello = Message{text2, std::size(text2)};   // присваивание объекта
    std::cout << "Message " <<  hello.getId() << ": " << hello.getText() << std::endl;
}
```

оператор присваивания с перемещением получает объект `Message`, освобождает ранее выделенную память текущего объекта и забирает указатель из источника. копируются не символы, а адрес блока.

```cpp

Message& operator=(Message&& moved)
{
    std::cout << "Move assign message " << moved.id << " to " << id << std::endl;
    if (&moved != this)     // избегаем самоприсваивания
    {
        delete text;        // освобождаем память текущего объекта
        text = moved.text;  // копируем указатель из перемещаемого объекта в текущий
        size = moved.size;
        moved.text = nullptr; // сбрасываем значение указателя в перемещаемом объекте
        moved.size = 0;
    }
    return *this; // возвращаем текущий объект
}
```

перед переносом проверяется, что объект не присваивается сам себе (`&moved != this`). иначе освобождение текущего буфера уничтожило бы память, которую ещё предстоит сохранить. после переноса указателю источника присваивается `nullptr`, а размер обнуляется: деструктор источника не освободит уже отданный блок. возврат `*this` отдаёт ссылку на левый операнд.

в `main` переменной `hello` присваивается объект `Message`.

```cpp

char text2[] {"Hi World!"};
hello = Message{text2, std::size(text2)};
```

как и у конструктора перемещения, правая часть является rvalue: это временный объект `Message{text2, std::size(text2)}`, который после присваивания не нужен. такой операнд и рассчитан на оператор присваивания с перемещением. консольный вывод:

```bash

Create message 1
Create message 2
Move assign message 2 to 1
Delete message 2
Message 1: Hi World!
Delete message 1
```

переменная `hello` по-прежнему обозначает объект `Message` с номером 1: присваивание не создаёт новый левый объект, оно меняет уже существующий. если в классе объявлены оба оператора, обычный и с перемещением, для rvalue выбирается перемещение, для lvalue выбирается копирование.

```cpp

Message hello{"Hello Word", 11};
Message hi{"Hi World!", 10};
hello = hi; // присвоение lvalue - обычный оператор присваивания
hello = Message{"Hi World!", 10}; // присвоение rvalue - оператор присваивания с перемещением
```

`std::move` переводит lvalue в rvalue и тем самым выбирает оператор перемещения.

```cpp

Message hello{"Hello Word", 11};
Message hi{"Hi World!", 10};
hello = std::move(hi); // преобразование lvalue в rvalue - оператор присваивания с перемещением
```

переменная `hi` приводится к rvalue, поэтому при присваивании срабатывает оператор присваивания с перемещением. после этого буфером владеет `hello`, а `hi` остаётся пустым.

компилятор генерирует оператор присваивания с перемещением по умолчанию: он перемещает все нестатические поля. генерация подавляется, если в классе объявлены деструктор, конструктор копирования, конструктор перемещения или оператор присваивания. в `Message` эти функции написаны вручную, поэтому неявного оператора нет.

### std::unique_ptr и перемещение значений

умный указатель `std::unique_ptr` единолично владеет адресом. двух объектов `std::unique_ptr`, указывающих на один и тот же блок, быть не должно: иначе оба деструктора освободили бы одну память. поэтому у `std::unique_ptr` нет конструктора копирования и нет оператора присваивания с копированием. попытка их вызвать не компилируется.

```cpp

#include <iostream> 
#include <memory>

int main()
{
	std::unique_ptr<int> one{ std::make_unique<int>(123) };
	std::unique_ptr<int> other;
	// other = one; 			// Ошибка! оператор присваивания с копированием отсутствует 
	// std::unique_ptr<int> another{ other }; // Ошибка! конструктор копированием отсутствует 
}
```

конструктор перемещения и оператор присваивания с перемещением у `std::unique_ptr` есть. ими владение переносится из одного указателя в другой.

```cpp

#include <iostream> 
#include <memory>

int main()
{
	std::unique_ptr<int> one{ std::make_unique<int>(123) };
	std::unique_ptr<int> other;
	other = std::move(one); 		// оператор копирования с перемещением
	// std::cout << *one << std::endl;  // Данные из one перемещены в other
	std::cout << *other << std::endl;	// 123
	std::unique_ptr<int> another{ std::move(other) }; // конструктор перемещения
	std::cout << *another << std::endl;	// 123
}
```

после перемещения исходный указатель пуст. прежнее значение через него получить нельзя: разыменование пустого `std::unique_ptr` не определено. в примере обращение к `one` после `std::move` поэтому закомментировано, а чтение идёт из указателя, который принял владение.
