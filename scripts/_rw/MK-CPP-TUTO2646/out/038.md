параметры функции в c++ могут иметь тип указателя. указатель передаётся по значению: функция получает копию указателя. копия хранит тот же адрес, что и исходный указатель. поэтому через параметр-указатель можно прочитать и изменить объект по этому адресу, не меняя сам указатель в вызывающем коде. копируется адрес. указуемый объект остаётся на своём месте.

ниже функция, которая увеличивает число на единицу, принимает параметр по значению:

```cpp


#include <iostream>



void increment(int);



int main()

{

    int n {10};

    increment(n);

    std::cout << "main function: " << n << std::endl;

}

void increment(int x)

{

    x++;

    std::cout << "increment function: " << x << std::endl;

}
```

переменная `n` передаётся аргументом для параметра `x`. передача идёт по значению, поэтому изменение `x` в `increment` не затрагивает `n`. это видно по выводу программы:

```bash


increment function: 11

main function: 10
```

далее `increment` переписана так, чтобы параметром был указатель:

```cpp


#include <iostream>



void increment(int*);



int main()

{

    int n {10};

    increment(&n);

    std::cout << "main function: " << n << std::endl;

}

void increment(int *x)

{

    (*x)++; // получаем значение по адресу в x и увеличиваем его на 1

    std::cout << "increment function: " << *x << std::endl;

}
```

значение по адресу меняется разыменованием с последующим инкрементом: `(*x)++`. скобки существенны. постфиксный `++` связывается теснее, чем унарная `*`, и запись `*x++` сдвинула бы указатель. объект по исходному адресу такая запись не увеличивает. `(*x)++` увеличивает на единицу объект, адрес которого хранится в `x`.

поскольку параметр теперь указатель, при вызове передаётся адрес переменной: `increment(&n)`. оператор `&` даёт указатель на `n`, и этот указатель по значению копируется в `x`.

изменение объекта через `x` видно и в переменной `n`: оба указателя, исходный адрес и его копия, обозначают один и тот же участок памяти.

```bash


increment function: 11

main function: 11
```

аргумент по-прежнему передаётся по значению, то есть функция получает копию адреса. если внутри функции изменить сам адрес, записанный в указателе-параметре, внешний указатель, переданный аргументом, не изменится. копируется значение указателя, и присваивание параметру меняет только копию.

```cpp


#include <iostream>



void increment(int*);



int main()

{

    int n {10};

    int *ptr {&n};

    increment(ptr);

    std::cout << "main function: " << *ptr << std::endl;

}

void increment(int *x)

{

	int z {6};

	x = &z;		// переустанавливаем адрес указателя x

    std::cout << "increment function: " << *x << std::endl;

}
```

в `increment` передаётся указатель `ptr`, который хранит адрес переменной `n`. функция получает копию этого указателя через параметр `x`. в теле адрес в `x` заменяется адресом локальной переменной `z`. на `ptr` это не влияет: `ptr` есть другой объект-указатель, со своим хранимым адресом. после переустановки адреса `x` и `ptr` указывают на разные объекты. кроме того, `z` автоматическая и уничтожается при выходе из `increment`, так что изменённый адрес в `x` после возврата был бы недействителен. наружу он не возвращается, и `main` читает `n` через исходный `ptr`.

результат программы:

```bash


increment function: 6

main function: 10
```

### константные параметры-указатели

параметр-указатель может быть константным.

```cpp


#include <iostream>

 

void print(const int*); // константный параметр



int main()

{

    int n {10};

    print(&n);

}

void print(const int *x)

{

    std::cout << *x << std::endl;

}
```

через константный параметр этого вида значение менять нельзя. тип `const int*` есть указатель на константу: константен указуемый объект. сам указатель при этом можно переустановить. такой параметр нужен, когда в функцию передаётся адрес константы. указатель на неконстантный `int` с адресом константного объекта не согласуется: иначе через указатель константу можно было бы изменить.

```cpp


#include <iostream>

 

void print(const int*); // константный параметр



int main()

{

    const int n {10};

    print(&n);  // передаем адрес константы

}

void print(const int *x)

{

    std::cout << *x << std::endl;

}
```

константность указуемого объекта не запрещает изменить адрес, хранимый в самом указателе:

```cpp


void print(const int *x)

{

    int z{2};

    x = &z;     // меняем адрес в указателе на адрес переменной z

    std::cout << *x << std::endl;   // 2

}
```

чтобы оставались неизменными и значение по указателю, и сам указатель, то есть хранимый адрес, указатель объявляют константным целиком. тип `const int* const` есть константный указатель на константу. первый `const` относится к объекту, второй относится к указателю.

```cpp


#include <iostream>

 

void print(const int*); // константный параметр



int main()

{

    const int n {10};

    print(&n);

}

void print(const int* const x)  // константный указатель на константу

{

    int z{2};

    //x = &z; // значение указателя нельзя изменить

    std::cout << "z = " << z << std::endl;      // z = 2

    std::cout << "*x = " << *x << std::endl;    // *x = 10

}
```

### параметры по ссылке или параметры-указатели

параметр по ссылке и параметр-указатель оба позволяют изменить объект вызывающего кода. в реализации и ссылка, и указатель представлены адресом. различие в системе типов такое: ссылка обязана быть связана с объектом и не имеет отдельного нулевого состояния, указатель может иметь значение `nullptr` и тогда не обозначает объект. если параметр может отсутствовать, используют указатель. перед разыменованием его проверяют на `nullptr`: чтение или запись по нулевому указателю есть неопределённое поведение. ссылку так проверить нельзя, потому что допустимая ссылка всегда связана с объектом.
