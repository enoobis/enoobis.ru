иногда возникает необходимость определить класс, который не предполагает создания конкретных объектов. например, класс фигуры. в реальности есть конкретные фигуры: квадрат, прямоугольник, треугольник, круг и так далее. однако абстрактной фигуры самой по себе не существует. в то же время может потребоваться определить для всех фигур какой-то общий класс, который будет содержать общую для всех функциональность. для описания подобных сущностей используются абстрактные классы.

абстрактные классы представляют собой классы, которые содержат или наследуют без переопределения хотя бы одну чистую виртуальную функцию. абстрактный класс определяет интерфейс для переопределения производными классами. объект абстрактного класса создать нельзя: компилятор отвергает определение переменной, передачу по значению и любое другое выражение, которому нужен завершённый объект этого типа. указатели и ссылки на абстрактный тип допустимы. через них вызываются виртуальные функции конкретных наследников.

чистые виртуальные функции (pure virtual functions) не имеют определения в том классе, где объявлены чистыми. цель подобных функций состоит в том, чтобы определить функционал без реализации, а реализацию определяют производные классы. чтобы определить виртуальную функцию как чистую, её объявление завершается значением `= 0`. например, абстрактный класс, который представляет геометрическую фигуру:

```cpp


class Shape

{

public:

	virtual double getSquare() const = 0;     // площадь фигуры

	virtual double getPerimeter() const = 0;  // периметр фигуры

};
```

класс `Shape` является абстрактным, потому что он содержит как минимум одну чистую виртуальную функцию. здесь таких функций две: для вычисления площади и периметра фигуры. ни одна из функций не имеет реализации в `Shape`. обе функции являются константными, но константность необязательна. любой конкретный производный класс от `Shape` должен предоставить для этих функций свою реализацию. спецификатор `= 0` делает функцию чистой и оставляет класс абстрактным, пока функцию не переопределят. стандарт допускает отдельное определение тела чистой виртуальной функции вне класса, но конкретный производный класс всё равно обязан её переопределить. если тело задано, его вызывают квалифицированным именем.

создать объект абстрактного класса нельзя:

```cpp
Shape shape{};
```

для применения абстрактного класса определяется следующая программа:

```cpp


#include <iostream>

  

class Shape

{

public:

	virtual double getSquare() const = 0;     // площадь фигуры

	virtual double getPerimeter() const = 0;  // периметр фигуры

};

class Rectangle : public Shape  // класс прямоугольника

{

public:

    Rectangle(double w, double h) : width(w), height(h)

    { }

    double getSquare() const override

    {

        return width * height;

    }

    double getPerimeter() const override

    {

        return width * 2 + height * 2;

    }

private:

    double width;   // ширина

    double height;  // высота

};

class Circle : public Shape     // круг

{

public:

    Circle(double r) : radius(r) 

    { }

    double getSquare() const override

    {

        return radius * radius * 3.14;

    }

    double getPerimeter() const override

    {

        return 2 * 3.14 * radius;

    }

private:

    double radius;  // радиус круга

};

 

int main()

{

    Rectangle rect{30, 50};

    Circle circle{30};

     

    std::cout << "Rectangle square: " << rect.getSquare() << std::endl;

    std::cout << "Rectangle perimeter: " << rect.getPerimeter() << std::endl;

    std::cout << "Circle square: " << circle.getSquare() << std::endl;

    std::cout << "Circle perimeter: " << circle.getPerimeter() << std::endl;

}
```

здесь определены два класса-наследника от абстрактного класса `Shape`: `Rectangle` (прямоугольник) и `Circle` (круг). при создании классов-наследников каждый из них должен либо определить для чистых виртуальных функций конкретную реализацию, либо повторить объявление чистой виртуальной функции. во втором случае производные классы также будут абстрактными.

`Circle` и `Rectangle` являются конкретными классами и реализуют все виртуальные функции.

консольный вывод программы:

```bash


Rectangle square: 1500

Rectangle perimeter: 160

Circle square: 2826

Circle perimeter: 188.4
```

абстрактный класс может определять и обычные функции и переменные, может иметь несколько конструкторов, но при этом нельзя создавать объекты этого абстрактного класса. например:

```cpp


#include <iostream>

  

class Shape

{

public:

    Shape(int x, int y): x{x}, y{y}

    {}

	virtual double getSquare() const = 0;     // площадь фигуры

	virtual double getPerimeter() const = 0;  // периметр фигуры

    void printCoords() const

    {

        std::cout << "X: " << x << "\tY: " << y << std::endl;

    }

private:

    int x;

    int y;

};

class Rectangle : public Shape  // класс прямоугольника

{

public:

    Rectangle(int x, int y, double w, double h) : Shape{x, y}, width(w), height(h)

    { }

    double getSquare() const override

    {

        return width * height;

    }

    double getPerimeter() const override

    {

        return width * 2 + height * 2;

    }

private:

    double width;   // ширина

    double height;  // высота

};

class Circle : public Shape     // круг

{

public:

    Circle(int x, int y, double r) : Shape{x, y}, radius(r) 

    { }

    double getSquare() const override

    {

        return radius * radius * 3.14;

    }

    double getPerimeter() const override

    {

        return 2 * 3.14 * radius;

    }

private:

    double radius;  // радиус круга

};

 

int main()

{

    Rectangle rect{0, 0, 30, 50};

    rect.printCoords();     // X: 0    Y: 0



    Circle circle{10, 20, 30};

    circle.printCoords();   // X: 10   Y: 20

}
```

класс `Shape` также имеет две переменные, конструктор, который устанавливает их значения, и невиртуальную функцию, которая выводит их значения. в производных классах также необходимо вызвать этот конструктор: подобъект абстрактной базы конструируется как часть объекта наследника, и его члены инициализирует конструктор базы. объект абстрактного класса с помощью его конструктора создать нельзя. конструктор абстрактного класса нужен именно для инициализации подобъекта внутри конкретного наследника.
