### установка clang

одним из самых распространённых компиляторов c++ является **clang**. он развивается в проекте llvm. ниже первая программа на c++ собирается clang под windows.

сначала устанавливается сам компилятор. clang входит в проект **llvm**, репозиторий которого лежит на github: [https://github.com/llvm/llvm-project](https://github.com/llvm/llvm-project). проект публикует готовый установщик под windows.

установщик для windows берётся со страницы релизов [https://github.com/llvm/llvm-project/releases/](https://github.com/llvm/llvm-project/releases/):

![загрузка установщика компилятора clang для c++ на windows](/uploads/course-lectures/20cf1b9457acc4c1ec7d1d62cd42f09aea39b3b0.png)

вверху страницы по умолчанию стоят ссылки на последний релиз. ссылка на установщик windows при этом может быть скрыта. тогда под набором ссылок нажимается **Show All assets**. среди появившихся пунктов ищется **LLVM-XX.X.X-win64.exe**, где `XX.X.X` обозначает номер версии. в примере это файл **LLVM-18.1.0-win64.exe**.

![установка компилятора clang для c++ на windows](/uploads/course-lectures/f828964bb5ee585f2608b5d2859917ff7ee3cdad.png)

это сборка для 64-битной windows. для 32-битной системы загружается файл **LLVM-18.1.0-win32.exe**.

после загрузки файл запускается.

![установка компилятора clang++ для c++ на windows](/uploads/course-lectures/76c5b000e9ebb9a5da2be8d01c1a73fee960c5f9.png)

на стартовом экране нажимается кнопка "Далее". затем принимается лицензионное соглашение.

![лицензия компилятора clang для c++ на windows](/uploads/course-lectures/9d55c9766ff7367ff6355798c2fc72a5e952013a.png)

дальше задаются параметры установки:

![добавление пути к компилятору clang для c++ в переменные среды на windows](/uploads/course-lectures/3195a8de6cb25fd6f53cef7f4d4fbc6b6cc96335.png)

чтобы при компиляции не писать полный путь к компилятору и не править переменные среды вручную, на этом шаге выбирается пункт **Add LLVM to the system PATH for current user**. установщик сам дописывает каталог `bin` в пользовательскую переменную `PATH`, и оболочка находит `clang` и `clang++` по короткому имени.

на следующем окне указывается каталог установки. можно оставить путь по умолчанию, "C:/Program Files/LLVM":

![путь к каталогу компилятора clang для c++ на windows](/uploads/course-lectures/8320191517eabe34df1f0fe543abab0937365372.png)

на остальных окнах параметры остаются по умолчанию, затем запускается установка. после успешной установки clang готов к работе.

![установка на windows компилятора clang для c++](/uploads/course-lectures/140fd8334098e94a9c1d3ed81f702b2e9a0f7dfc.png)

проверка выполняется в терминале или командной строке командой **clang --version**. должна появиться базовая информация о компиляторе: версия и параметры целевой платформы.

```bash


C:\Users\eugen>clang --version

clang version 18.1.0

Target: x86_64-pc-windows-msvc

Thread model: posix

InstalledDir: C:\Program Files\LLVM\bin
```

строка `Target: x86_64-pc-windows-msvc` означает, что эта сборка clang генерирует код под 64-разрядную windows и использует двоичный интерфейс и среду выполнения msvc. `InstalledDir` показывает каталог, из которого запущен драйвер.

### первая программа

после установки в каталоге **C:\Program Files\LLVM\bin** лежат файлы компиляторов:

![компилятор clang++ для языка c++ на windows](/uploads/course-lectures/c4aea5b1e81ceda77be775832c918b3c68f03097.png)

файл **clang.exe** компилирует программы на c, а **clang++.exe** является компилятором c++. для программ этого курса нужен clang++: драйвер `clang++` выбирает язык c++ и компонует результат со стандартной библиотекой c++. драйвер `clang`, запущенный на файле с расширением cpp, язык может распознать, но набор библиотек по умолчанию у него другой.

на диске c создаётся каталог для исходных файлов на c++. в нём создаётся текстовый файл и переименовывается в **hello.cpp**. исходный текст на c++ хранится в обычных текстовых файлах, у которых, как правило, расширение **cpp**.

![первая программа на с++](/uploads/course-lectures/9486138465d1bc14039dfd3a8d3ed484f143b7d7.png)

в примере файл hello.cpp лежит в каталоге C:\cpp.

в hello.cpp записывается минимальная программа, которая выводит строку на консоль:

```cpp


#include <iostream>        		// подключаем заголовочный файл iostream



int main()							// определяем функцию main

{									// начало функции

	std::cout << "Hello enoobis.ru!";	 // выводим строку на консоль

	return 0;						// выходим из функции

}									// конец функции
```

чтобы вывести строку, подключается интерфейс библиотеки. в начале файла стоит строка

```cpp
#include <iostream>
```

это директива препроцессора. она подключает заголовочный файл `iostream`, в котором объявлены стандартные потоки. заголовок нужен, чтобы имя `std::cout` было объявлено к моменту использования.

далее определяется функция **main**. она обязана присутствовать в программе на c++: выполнение приложения после инициализации статических объектов начинается с неё.

у функции main четыре составляющие:

- тип возвращаемого значения. здесь это тип `int`. функция должна вернуть целое число, код завершения процесса

- имя функции. функция называется `main`

- список параметров. после имени в скобках идёт список параметров. скобки пусты: эта форма `main` параметров не принимает

- тело функции. после списка параметров в фигурных скобках записываются действия функции

```cpp


{

	std::cout << "Hello enoobis.ru!";

	return 0;

}
```

в теле строка выводится на консоль. стандартный поток вывода **std::cout** связан со стандартным выводом процесса. оператор **<<** передаёт в этот поток строковый литерал "Hello enoobis.ru!". для потока вывода оператор перегружен и выполняет вставку символов. для целых тот же знак означает побитовый сдвиг.

выход из функции выполняет оператор **return**. результат имеет тип `int`, после `return` указано число 0. нуль является признаком успешного завершения программы.

после каждой инструкции в c++ ставится точка с запятой. она завершает инструкцию.

каждая строка листинга снабжена комментарием. всё, что записано после `//`, является комментарием. при компиляции комментарий не учитывается, в программу не входит и служит только пояснением к коду.

![язык программирования с++ в visual studio code](/uploads/course-lectures/47776cb1e4674fa5de3ea59cf54c7ac13aeb7f93.png)

файл компилируется из командной строки windows. команда `cd` переходит в каталог с исходным файлом:

```bash
cd C:\cpp
```

компилятору clang++ передаётся файл hello.cpp:

```bash
clang++ hello.cpp -o hello
```

необязательный параметр `-o hello` задаёт имя результата: hello.exe. если параметр опустить, файл получит имя по умолчанию, a.exe.

после команды появляется исполняемый файл. в windows он по умолчанию называется hello.exe. запуск выводит на консоль строку "Hello enoobis.ru!", как записано в программе.

![запуск компилятора clang++ на windows для компиляции программы на языке c++](/uploads/course-lectures/6161eaaa9118c6528e6602afd3d4c0907a8a47ba.png)

если вместо командной строки cmd открыта оболочка powershell, файл запускается командой "./hello".
