у каждой переменной есть тип. тип определяет, какие значения переменная может принимать, какие операции к ней применимы и сколько байт она занимает в памяти. в c++ к базовым типам относятся логический тип **bool**, целочисленные типы, типы чисел с плавающей точкой и символьные типы. ниже каждая группа разбирается отдельно. размеры, которые приводятся вместе с диапазонами, относятся к обычным платформам с байтом из 8 бит. стандарт задаёт минимумы, а не единственно возможные ширины. точные ограничения разобраны в разделе о размерах.

### логический тип

логический тип **bool** хранит одно из двух значений: **true** (истина) и **false** (ложь). пример с двумя переменными и выводом на консоль:

```cpp


#include <iostream>



int main()

{

    bool isAlive {true};

    bool isDead {false};

    std::cout << "isAlive: " << isAlive << "\n"; 

    std::cout << "isDead: " << isDead << "\n"; 

}
```

при выводе в поток значение `bool` преобразуется в 1, если это `true`, и в 0, если это `false`. поток по умолчанию печатает числовое представление, а не слова. тип используется прежде всего в условных выражениях, они разбираются дальше.

значение по умолчанию для этого типа равно `false`. так инициализируется объект со статическим временем хранения. локальная переменная без инициализатора, как и прочие объекты встроенных типов внутри функции, определённого значения не получает.

### целочисленные типы

целые числа в c++ представлены следующими типами:

- `signed char`: представляет один символ. занимает в памяти 1 байт (8 бит). хранит любое значение из диапазона от -128 до 127

- `unsigned char`: представляет один символ. занимает в памяти 1 байт (8 бит). хранит любое значение из диапазона от 0 до 255

- `char`: представляет один символ в кодировке ascii. занимает в памяти 1 байт (8 бит). хранит любое значение из диапазона от -128 до 127 либо от 0 до 255. диапазон совпадает с диапазоном `signed char`, но типы не эквивалентны. `char`, `signed char` и `unsigned char` являются тремя разными типами. `char` предназначен для числового кода символа, и в конкретной реализации его представление совпадает либо с `signed char`, либо с `unsigned char`, в зависимости от компилятора

- `short`: представляет целое число в диапазоне от -32768 до 32767. занимает в памяти 2 байта (16 бит). у типа есть псевдонимы `short int`, `signed short int`, `signed short`

- `unsigned short`: представляет целое число в диапазоне от 0 до 65535. занимает в памяти 2 байта (16 бит). синоним типа: `unsigned short int`

- `int`: представляет целое число. в зависимости от архитектуры процессора занимает 2 байта (16 бит) или 4 байта (32 бита). диапазон предельных значений тогда тоже меняется: от -32768 до 32767 при 2 байтах либо от -2 147 483 648 до 2 147 483 647 при 4 байтах. размер `int` не меньше размера `short` и не больше размера `long`. у типа есть псевдонимы `signed int` и `signed`

- `unsigned int`: представляет неотрицательное целое число. в зависимости от архитектуры занимает 2 байта (16 бит) или 4 байта (32 бита), поэтому меняется и диапазон: от 0 до 65535 для 2 байт либо от 0 до 4 294 967 295 для 4 байт. псевдоним типа: `unsigned`

- `long`: в зависимости от архитектуры занимает 4 или 8 байт и представляет целое число в диапазоне от -2 147 483 648 до 2 147 483 647 при 4 байтах либо от -9 223 372 036 854 775 808 до +9 223 372 036 854 775 807 при 8 байтах. в памяти это 4 байта (32 бита) или 8 байт (64 бита). у типа есть псевдонимы `long int`, `signed long int` и `signed long`

- `unsigned long`: представляет целое число в диапазоне от 0 до 4 294 967 295. занимает в памяти 4 байта (32 бита). синоним типа: `unsigned long int`

- `long long`: представляет целое число в диапазоне от -9 223 372 036 854 775 808 до +9 223 372 036 854 775 807. занимает в памяти 8 байт (64 бита). у типа есть псевдонимы `long long int`, `signed long long int` и `signed long long`

- `unsigned long long`: представляет целое число в диапазоне от 0 до 18 446 744 073 709 551 615. занимает в памяти, как правило, 8 байт (64 бита). псевдоним типа: `unsigned long long int`

для записи чисел используются целочисленные литералы со знаком и без знака, например -10 или 10. ниже определяется набор переменных целых типов, и их значения выводятся на консоль:

```cpp


#include <iostream>



int main()

{

    signed char num1{ -64 };

    unsigned char num2{ 64 };

    short num3{ -88 };

    unsigned short num4{ 88 };

    int num5{ -1024 };

    unsigned int num6{ 1024 };

    long num7{ -2048 };

    unsigned long num8{ 2048 };

    long long num9{ -4096 };

    unsigned long long num10{ 4096 };

    std::cout << "num1 = " << num1 << std::endl;

    std::cout << "num2 = " << num2 << std::endl;

    std::cout << "num3 = " << num3 << std::endl;

    std::cout << "num4 = " << num4 << std::endl;

    std::cout << "num5 = " << num5 << std::endl;

    std::cout << "num6 = " << num6 << std::endl;

    std::cout << "num7 = " << num7 << std::endl;

    std::cout << "num8 = " << num8 << std::endl;

    std::cout << "num9 = " << num9 << std::endl;

    std::cout << "num10 = " << num10 << std::endl;

}
```

все целочисленные литералы по умолчанию имеют тип `int`. в листинге переменным разных типов передаются числа -64, 64, 88, -88, 1024 и далее, но сами эти литералы имеют тип `int`. если значение не помещается в `int`, тип десятичного литерала выбирается как первый подходящий из последовательности `int`, `long`, `long long`. для небольших чисел, как в примере, типом остаётся `int`, а дальше выполняется преобразование к типу переменной.

литералы бывают и других типов. у литералов без знака, то есть у значений беззнаковых типов, суффикс **u** или **U**. у литералов `long` и `long long` суффиксы **L** / **l** и **LL** / **ll**:

```cpp


#include <iostream>



int main()

{

    unsigned int num6{ 1024U };         // U - unsigned int

    long num7{ -2048L };                // L - long

    unsigned long num8{ 2048UL };       // UL - unsigned long

    long long num9{ -4096LL };          // LL - long long

    unsigned long long num10{ 4096ULL };// ULL - unsigned long long

    std::cout << "num6 = " << num6 << std::endl;

    std::cout << "num7 = " << num7 << std::endl;

    std::cout << "num8 = " << num8 << std::endl;

    std::cout << "num9 = " << num9 << std::endl;

    std::cout << "num10 = " << num10 << std::endl;

}
```

суффикс входит в форму литерала и задаёт его тип до преобразования. суффиксы при этом не обязательны: компилятор, как правило, преобразует целочисленный литерал типа `int` к нужному типу переменной, если значение представимо без потери информации.

в длинном числе легко ошибиться при наборе. начиная со стандарта c++14 разряды литерала можно разделять одинарной кавычкой `'`. разделитель не меняет значение, он существует только в тексте программы:

```cpp


#include <iostream>



int main()

{

    int num{ 1'234'567'890 };

    std::cout << "num = " << num << "\n";   // num = 1234567890

}
```

#### различные системы исчисления

по умолчанию целочисленный литерал записан в десятичной системе. c++ позволяет записывать литералы и в других системах. основание задаётся префиксом, значение при этом то же, меняется только форма записи.

шестнадцатеричный литерал начинается с префикса **0x** или **0X**:

```cpp


int num1{ 0x1A};        // 26 - в десятичной

int num2{ 0xFF };       // 255 - в десятичной

int num3{ 0xFFFFFF };   //16777215 - в десятичной
```

восьмеричный литерал начинается с нуля **0**:

```cpp


int num1{ 034};        // 26 - в десятичной

int num2{ 0377 };       // 255 - в десятичной
```

ведущий нуль легко не заметить: литерал `010` равен восьми, а не десяти. цифры восьмеричной записи берутся из диапазона 0-7.

двоичный литерал начинается с префикса **0b** или **0B**. такая форма появилась в c++14:

```cpp


int num1{ 0b11010};        	// 26 - в десятичной

int num2{ 0b11111111 };		// 255 - в десятичной
```

литералы всех этих оснований принимают те же суффиксы `U` / `L` / `LL`:

```cpp


unsigned int num1{ 0b11010U};    		// 26 - в десятичной

long num2{ 0377L };             		// 255 - в десятичной

unsigned long num3{ 0xFFFFFFULL };   	//16777215 - в десятичной
```

суффикс по-прежнему задаёт тип, префикс задаёт основание. на значение, уже переведённое в тип, основание записи не влияет.

### числа с плавающей точкой

дробные числа представляются числами с плавающей точкой. в десятичной записи такое число состоит из двух частей: **мантиссы** и **показателя степени**. обе части могут быть и положительными, и отрицательными. величина числа равна мантиссе, умноженной на десять в степени показателя.

число 365 в такой записи выглядит так:

```browser
3.650000E02
```

разделителем целой и дробной частей служит точка. мантисса здесь содержит семь десятичных цифр, `3.650000`, показатель степени занимает две цифры, `02`. буква **E** обозначает экспоненту. после неё стоит степень десяти, на которую умножается мантисса 3.650000, чтобы получить исходное значение. возврат к обычной десятичной записи является такой операцией:

```browser
3.650000 × 10<sup>2</sup> = 365
```

ещё один пример, уже с небольшим числом:

```browser
-3.650000E-03
```

это число `-3.65`, умноженное на десять в степени `-3`, то есть `-0.00365`. в зависимости от показателя десятичная точка смещается. из-за этого смещения такие числа называют числами с плавающей точкой.

запись покрывает очень широкий диапазон, но не все числа этого диапазона представимы точно. представление с плавающей точкой является приближением точного числа. число 1254311179 в такой форме выглядело бы как `1.254311E09`. в десятичной записи это `1254311000`, а не `1254311179`: три младших разряда потеряны, потому что в мантиссе для них не осталось знаков.

в c++ для чисел с плавающей точкой есть три типа:

- `float`: вещественное число одинарной точности. диапазон примерно от +/- `3.4E-38` до `3.4E+38`. в памяти занимает 4 байта (32 бита)

- `double`: вещественное число двойной точности. диапазон примерно от +/- `1.7E-308` до `1.7E+308`. в памяти занимает 8 байт (64 бита)

- `long double`: вещественное число с плавающей точкой точности не ниже двойной. размер не менее 8 байт (64 бит). диапазон допустимых значений зависит от того, сколько памяти отводит типу реализация

во внутреннем двоичном представлении число с плавающей точкой состоит из бита знака, фиксированного поля показателя и поля мантиссы. у **float** 1 бит занимает знак, 8 бит занимает экспонента и 23 бита занимает мантисса, всего 32 бита. такой мантиссы хватает примерно на 7 десятичных знаков.

у **double** 1 бит знака, 11 бит экспоненты и 52 бита мантиссы, всего 64 бита. 52-разрядная мантисса даёт точность примерно до 16 десятичных знаков.

расклад **long double** зависит от компилятора и от того, как тип реализован. большинство компиляторов даёт 18-19 десятичных знаков при 64-битной мантиссе. в других реализациях, в частности в microsoft visual c++, `long double` совпадает с `double`.

литерал числа с плавающей точкой записывается дробным числом, целая и дробная части разделяются точкой:

```cpp


double num {10.45};
```

даже если переменной передаётся целое значение, точка в записи показывает, что литерал имеет плавающий тип:

```cpp


double num1{ 1 };    // 1 - целочисленный литерал

double num2{ 1. };  //1. - литерал числа с плавающей точкой
```

запись `1.` является литералом с плавающей точкой и по значению совпадает с `1.0`. точка меняет тип литерала, даже если дробных цифр после неё нет.

по умолчанию литерал с точкой имеет тип `double`. другой тип задаётся суффиксом: **f** / **F** для `float` и **l** / **L** для `long double`:

```cpp


float num1{ 10.56f };    // float

long double num2{ 10.56l };    // long double
```

ту же величину можно записать в экспоненциальной форме:

```cpp


double num1{ 5E3  };        // 5E3  = 5000.0

double num2{ 2.5e-3  };    // 2.5e-3  = 0.0025
```

буква `E` или `e` играет ту же роль, что и в примерах выше: слева мантисса, справа степень десяти.

### размеры типов данных

при перечислении типов указывался размер в памяти. стандарт фиксирует не эти размеры, а минимумы. для `int` и `short` минимум составляет 16 бит, для `long` минимум составляет 32 бита, для `long double` минимум составляет 64 разряда. размер `long` не меньше размера `int`, размер `int` не меньше размера `short`, размер `long double` не меньше размера `double`. разработчик компилятора выбирает конкретную ширину по возможностям аппаратуры. отсюда расхождение моделей данных: в модели lp64, типичной для linux и macos, `long` занимает 64 бита, в модели llp64, принятой в windows, `long` занимает 32 бита, а 64-битным целым служит `long long`.

компилятор g++ под windows отводит `long double` 16 байт. компилятор visual studio, тоже под windows, и clang++ под windows отводят `long double` 8 байт. даже на одной платформе разные компиляторы по-разному задают размеры отдельных типов. в целом же используются размеры, указанные выше при описании типов.

когда размер нужно знать точно, в c++ есть оператор **sizeof**. он возвращает размер объекта в байтах:

```cpp


#include <iostream>



int main()

{

	long double number {2};

	std::cout << "sizeof(number) =" << sizeof(number);

}
```

операндом может быть выражение или имя типа. результат имеет беззнаковый тип `size_t` и является константой времени компиляции. консольный вывод при компиляции в g++:

```consoletext
sizeof(number) = 16
```

16 байт согласуются с реализацией `long double` в g++ под windows, о которой сказано выше. тот же исходный текст, собранный компилятором с 8-байтовым `long double`, напечатает другое число. оператор как раз и нужен, чтобы не подставлять ширину типа вручную.

### символьные типы

в c++ есть следующие символьные типы:

- `char`: представляет один символ в кодировке ascii. занимает в памяти 1 байт (8 бит). хранит любое значение из диапазона от -128 до 127 либо от 0 до 255

- `wchar_t`: представляет расширенный символ. в windows занимает 2 байта (16 бит), в linux занимает 4 байта (32 бита). хранит любое значение из диапазона от 0 до 65 535 при 2 байтах либо от 0 до 4 294 967 295 при 4 байтах

- `char8_t`: представляет кодовую единицу utf-8. занимает в памяти 1 байт. хранит значение из диапазона от 0 до 255

- `char16_t`: представляет кодовую единицу utf-16. занимает в памяти 2 байта (16 бит). хранит любое значение из диапазона от 0 до 65 535

- `char32_t`: представляет код символа utf-32. занимает в памяти 4 байта (32 бита). хранит любое значение из диапазона от 0 до 4 294 967 295

#### char

переменная типа **char** хранит числовой код одного символа и занимает один байт. стандарт c++ не фиксирует кодировку для `char`, её выбирает реализация компилятора, и обычно это ascii. знаковость `char` тоже зависит от реализации: тип остаётся отдельным от `signed char` и `unsigned char`.

значением может быть один символ в одинарных кавычках либо числовой код:

```cpp


#include <iostream>



int main()

{

    char a1 {'A'};

    char a2 {65};

    std::cout << "a1: " << a1 << std::endl;

    std::cout << "a2: " << a2 << std::endl; 

}
```

переменные `a1` и `a2` получают одно и то же значение: 65 является числовым кодом символа "A" в таблице ascii. при выводе через `cout` по умолчанию печатается символ, а не его код. одинарные кавычки задают символьный литерал, его тип есть `char`. двойные кавычки задали бы строковый литерал, массив символов, это другой тип.

в c++ есть и управляющие последовательности. они начинаются с обратной косой черты и читаются особым образом. последовательность "\n" задаёт перевод строки, "\t" задаёт табуляцию. в исходном тексте это два символа, в значении литерала одна кодовая единица.

ascii достаточен для алфавитов на латинице. если нужны сразу несколько языков или алфавит за пределами английского, 256 кодов одного байта не хватает. тогда используется **unicode**.

unicode (юникод) является стандартом, который задаёт набор символов, их кодовые точки и несколько кодировок этих точек. чаще всего применяются utf-8, utf-16 и utf-32. кодировки различаются тем, как кодовая точка раскладывается по байтам. числовое значение кодовой точки одного и того же символа во всех этих кодировках совпадает. основные отличия:

- utf-8 представляет символ последовательностью переменной длины от одного до четырёх байт. набор ascii входит в utf-8 как однобайтовые коды с теми же значениями, что и в ascii. utf-8 сегодня является самой распространённой кодировкой unicode

- utf-16 представляет символы одним или двумя 16-битными значениями

- utf-32 представляет все символы 32-битными значениями

для символов unicode в c++ есть четыре типа: **wchar_t**, **char8_t**, **char16_t** и **char32_t**. типы `char16_t` и `char32_t` добавлены в c++11, тип `char8_t` добавлен в c++20.

#### wchar_t

тип **wchar_t** является основным типом для наборов символов, которые не укладываются в один байт. имя собрано из wide char: единица шире обычного однобайтового символа. значение записывается так же, как значение `char`, но перед литералом стоит префикс `L`:

```cpp
wchar_t a1 {L'A'};
```

можно передать и код символа:

```cpp
wchar_t a1 {L'\x41'};
```

в одинарных кавычках стоит шестнадцатеричный код. обратная косая черта открывает управляющую последовательность, а **x** после неё означает, что дальше идёт шестнадцатеричная запись. код `\x41` равен 65, то есть снова обозначает "A", но уже как значение `wchar_t`.

для вывода `wchar_t` на консоль нужен не `std::cout`, а поток **std::wcout**:

```cpp


#include <iostream>



int main()

{

	char h = 'H';

	wchar_t i {L'i'};

	std::wcout << h << i <<'\n';

}
```

поток `std::wcout` принимает и `char`, и `wchar_t`. поток `std::cout` для переменной `wchar_t` печатает числовой код, а не символ: у узкого потока нет вставки, которая трактовала бы это значение как глиф.

трудность `wchar_t` в том, что его размер зависит от реализации и от выбранной кодировки. кодировка обычно совпадает с предпочтительной кодировкой целевой платформы. в windows `wchar_t` обычно имеет ширину 16 бит и кодируется как utf-16. большинство других платформ задают ширину 32 бита и кодировку utf-32. такое соответствие удобно для интерфейса конкретной платформы и одновременно мешает писать код, который переносится без изменений. поэтому для переносимого текста чаще берут типы **char8_t**, **char16_t** и **char32_t**. их значения хранят единицы кодировок utf-8, utf-16 и utf-32 соответственно, а размеры этих типов одинаковы на распространённых платформах.

символы типов **char8_t**, **char16_t** и **char32_t** записываются с префиксами `u8`, `u` и `U`:

```cpp


char8_t c{ u8'l' };

char16_t d{ u'l' };

char32_t e{ U'o' };
```

префикс задаёт тип литерала так же, как суффикс задаёт тип числового литерала. для вывода значений `char8_t`, `char16_t` и `char32_t` на консоль встроенных средств уровня `std::cout` и `std::wcout` нет: стандартные потоки не определяют для этих типов вставку символа.

### спецификатор auto

тип выражения иногда трудно выписать вручную. компилятору можно поручить вывод типа объекта, для этого служит спецификатор **auto**. переменная со спецификатором `auto` обязана быть инициализирована:

```cpp


auto number = 5;        // number имеет тип int

auto sum {1234.56};    // sum имеет тип double

auto distance {267UL};  // distance имеет тип unsigned long
```

тип выводится на этапе компиляции из типа инициализатора и после этого фиксирован, как если бы он был написан явно. в листинге `number` получает тип `int`, потому что литерал 5 имеет тип `int`. `sum` получает тип `double`, потому что литерал с точкой без суффикса имеет тип `double`. `distance` получает тип `unsigned long`, потому что суффикс `UL` задаёт именно этот тип.

неинициализированная переменная со спецификатором `auto` недопустима. выводить тип не из чего:

```cpp


auto number;
```

такое определение не проходит компиляцию. инициализатор является частью объявления с `auto`, а не необязательным дополнением, как у явного типа.
