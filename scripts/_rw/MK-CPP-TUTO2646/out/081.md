**вложенный класс** (nested class) определяется внутри другого класса. вложенные классы описывают сущности, которые существуют только в рамках объекта внешнего класса, особенно когда внешний класс работает с набором объектов вложенного класса. имя вложенного класса принадлежит области внешнего, и снаружи оно квалифицируется как имя внешнего класса, затем `::`, затем имя вложенного.

учётную запись пользователя (логин и пароль) выделяют в отдельный тип:

```cpp


#include <iostream>

#include <string>



class Person

{

private:

	std::string name;



    class Account   // вложенный класс

    {

    public:

        Account(const std::string& p_email, const std::string& p_password)

        {

            email = p_email;

            password = p_password;

        }

        std::string email;

        std::string password;

    };

    Account account{"", ""};    // переменная вложенного класса Account

public:

	Person(const std::string& p_name, const std::string& p_email, const std::string& p_password)

	{

		name = p_name;

        account = Account(p_email, p_password);

	}

    void print()

    {

        std::cout<<"Name: " << name << "\n" << "Email: " << account.email << "\n"

        << "Password: " << account.password << std::endl; 

    }

};



int main()

{

    Person tom{"Tom", "tom@localhost.com", "qwerty"};

    tom.print();

}
```

класс `Person` представляет пользователя. данные его учётной записи выделены в отдельный класс `Account`. класс `Account` определён как закрытый. обратиться к этому классу можно только внутри класса `Person`.

```cpp


class Account   // вложенный класс

{

public:

    Account(std::string p_email, std::string p_password)

    {

        email = p_email;

        password = p_password;

    }

    std::string email;

    std::string password;

};
```

во вложенных классах тоже применяют спецификаторы доступа. поля `email` и `password` и конструктор определены как открытые, общедоступные, чтобы их можно было использовать в классе `Person` вне класса `Account`. поскольку класс `Account` закрытый, эти поля всё равно недоступны из кода вне `Person`. открытость члена вложенного класса не отменяет закрытость самого вложенного типа.

для хранения данных учётной записи конкретного объекта `Person` определена переменная `account`:

```cpp
Account account{"", ""};    // переменная вложенного класса Account
```

она инициализируется начальными данными: пустыми строками для `email` и пароля. инициализация нужна потому, что в конструкторе `Person` далее выполняется присваивание уже существующему члену, а не первичная инициализация.

в конструкторе класса `Person` принимаются данные для `email` и пароля, и на их основе создаётся объект `Account`:

```cpp


account = Account(p_email, p_password);
```

поля `email` и `password` открыты, поэтому в функциях класса `Person` к ним обращаются напрямую. функция `print` выводит их значения:

```cpp


void print()

{

    std::cout<<"Name: " << name << "\n" << "Email: " << account.email << "\n"

    << "Password: " << account.password << std::endl; 

}
```

в функции `main` создаётся один объект `Person`. через конструктор передаются данные, в том числе для объекта `Account`:

```cpp


Person tom{"Tom", "tom@localhost.com", "qwerty"};

tom.print();
```

консольный вывод программы:

```bash


Name: Tom

Email: tom@localhost.com

Password: qwerty
```

в примере выше объекты `Account` нельзя создавать или использовать вне класса `Person`, так как класс `Account` является закрытым. вложенный класс можно сделать общедоступным, и после этого к нему обращаются вне класса `Person`:

```cpp


#include <iostream>

#include <string>



class Person

{

public:

    class Account   // вложенный класс

    {

    public:

        Account(const std::string& p_email, const std::string& p_password)

        {

            email = p_email;

            password = p_password;

        }

        std::string email{};

        std::string password{};

    };

	Person(const std::string& p_name, const Account& p_account)

	{

		name = p_name;

        account = p_account;

	}

    void print()

    {

        std::cout<<"Name: " << name << "\n" << "Email: " << account.email << "\n"

        << "Password: " << account.password << std::endl;

        

    }

private:

	std::string name;

    Account account{"", ""};    // переменная вложенного класса Account

};



int main()

{

    Person::Account account{"bob@somemail.com", "qwerty"};

    Person bob{"Bob", account};

    bob.print();

}
```

теперь вложенный класс является открытым. объекты этого класса создают и к его переменным и функциям обращаются, используя имя внешнего класса:

```cpp
Person::Account account{"bob@somemail.com", "qwerty"};
```

функции вложенного класса могут напрямую ссылаться на статические члены внешнего класса, а также на любые другие типы, определённые во внешнем классе. эти имена не требуют экземпляра внешнего класса. доступ к другим членам внешнего класса из вложенного класса получают обычным путём: через объект класса, указатель или ссылку на объект класса. неявного указателя на объемлющий экземпляр, какой есть у внутреннего класса в java, вложенный класс c++ не имеет. при этом функции вложенного класса обращаются и к закрытым переменным и константам, которые определены во внешнем классе. вложенный класс является членом внешнего и входит в его область доступа.
