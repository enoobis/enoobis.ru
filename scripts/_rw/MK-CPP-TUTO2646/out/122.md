лямбда-выражение может захватывать переменные из окружающей области видимости. для этого служат квадратные скобки в начале выражения. захват превращает внешние имена в поля порождённого класса, то есть в состояние объекта-функции.

### получение данных по значению

если нужны все внешние автоматические переменные из области, где определена лямбда, и нужны они по значению, в квадратных скобках пишется знак равенства `=`. значения этих переменных внутри лямбды изменить нельзя.

```cpp


#include <iostream>



int main()

{

    int n{10};

    auto add = [=](int x)  { std::cout << x + n << std::endl; };

    add(4); // 14

}
```

запись `[=]` даёт лямбде внешнюю переменную `n` и позволяет прочитать её значение. копия снимается в момент создания замыкания. последующие присваивания внешней `n` на уже снятую копию не влияют.

для такой лямбды компилятор порождает класс примерно следующего вида.

```cpp


class __Lambda1c8

{

public:

	__Lambda1c8(const int& arg1) : n(arg1) {}

 	auto operator()(int x) const

 	{

 		std::cout << x + n << std::endl;

 	}

private:

	int n;

};
```

здесь существенны две детали. значение внешней переменной приходит в конструктор константной ссылкой и сохраняется в закрытом поле копией. ссылка на внешний объект в поле не хранится. оператор `()` объявлен константным, поэтому присвоить этому полю новое значение нельзя. захват по значению даёт прочитать копию и не даёт её изменить. повторные вызовы видят одну и ту же копию, пока саму лямбду не пометили `mutable`.

внешнюю переменную при таком захвате не изменить, но можно захватить по значению указатель на неё. копируется адрес. объект по этому адресу остаётся общим, и через указатель лямбда меняет исходную переменную.

```cpp


#include <iostream>



int main()

{

    int n{10};

    int* np {&n};

    auto increment = [np](){(*np)++;};

    increment(); // n = 10

    std::cout << "n = " << n << std::endl;   // n = 11

}
```

после вызова `increment` переменная `n` равна 11. копируется указатель `np`. само число остаётся в исходной ячейке, и `(*np)++` увеличивает её.

### получение данных по ссылке

если внешние переменные нужны по ссылке, в квадратных скобках пишется амперсанд `&`. тогда лямбда изменяет сами эти переменные.

```cpp


#include <iostream>



int main()

{

    int n{10};

    auto increment = [&]()  { 

        n++;    // увеличиваем значение внешней переменной n

        std::cout << "n inside lambda: " << n << std::endl; 

    };

    increment();

    std::cout << "n outside lambda: " << n << std::endl; 

}
```

запись `[&]` даёт лямбде `increment` внешнюю переменную `n` по ссылке, и присваивание меняет оригинал. в примере `n` увеличивается на единицу. по выводу видно, что имя `n` внутри лямбды и внешняя переменная `n` обозначают один и тот же объект.

```bash


n inside lambda: 11

n outside lambda: 11
```

для такой лямбды компилятор порождает класс примерно следующего вида.

```cpp


class __Lambda1c8

{

public:

	__Lambda1c8(int& arg1) : n(arg1) {}

 	auto operator()() const

 	{

		n++;

 		std::cout << "n inside lambda: " << n << std::endl; 

 	}

private:

	int& n;

};
```

оператор `()` снова константный, но поле имеет тип ссылки. константный метод запрещает менять поля замыкания, а ссылку и так нельзя перепривязать. изменение объекта, на который ссылка указывает, этим запретом не блокируется, поэтому `n++` в константном операторе корректен и затрагивает внешнюю переменную.

### mutable-параметры

в предыдущем разделе менялась сама внешняя переменная. иногда нужно менять копию, которой пользуется лямбда, и оставлять оригинал прежним. после списка параметров тогда ставится ключевое слово **mutable**. оно снимает константность с оператора `()`.

```cpp


#include <iostream>



int main()

{

    int n{10};

    auto increment = [=]() mutable  { 

        n++;    // увеличиваем значение внешней переменной n

        std::cout << "n inside lambda: " << n << std::endl; 

    };

    increment();

    std::cout << "n outside lambda: " << n << std::endl; 

}
```

внешняя `n` захвачена по значению, и саму её лямбда не изменяет. изменяется копия внутри замыкания. это показывает вывод.

```bash


n inside lambda: 11

n outside lambda: 10
```

внутри лямбды видно 11, снаружи по-прежнему 10. изменённая копия хранится в объекте лямбды и сохраняется между вызовами: следующий вызов `increment` увидел бы уже 12. внешняя переменная остаётся равной 10.

### получение определенных переменных

по умолчанию `[=]` и `[&]` захватывают все используемые автоматические переменные окружения, каждую своим способом. можно перечислить только нужные имена. захват по ссылке записывается как `[&имя_переменной]`.

```cpp


#include <iostream>



int main()

{

    int n{10};

    // получаем внешнюю переменную n по ссылке

    auto increment = [&n](){ n++;};

    increment();

    std::cout << "n: " << n << std::endl;   // n = 11

}
```

захват по значению записывается одним именем, без амперсанда.

```cpp


#include <iostream>



int main()

{

    int n{10};

    // получаем внешнюю переменную n по значению

    auto increment = [n](){ std::cout << "n: " << n << std::endl;};

    increment(); // n = 10

}
```

несколько переменных перечисляются через запятую. перед именем переменной, которая передаётся по ссылке, ставится амперсанд.

```cpp
[&k, l, &m, n]		// k и m - по ссылке, l и n - по значению
```

можно захватить всё по значению и лишь отдельные имена по ссылке.

```cpp
[=, &m, &n]		// все по значению, а m и n - по ссылке
```

или захватить всё по ссылке и лишь отдельные имена по значению.

```cpp
[&, m, n]		// все по по ссылке, а m и n - по значению
```

явная запись для имени задаёт способ захвата этого имени, остальные используемые переменные берутся способом по умолчанию. одно и то же имя дважды не захватывается.

### захват членов класса

к членам класса, и к полям, и к функциям, независимо от того, открыты они или закрыты, обращаются через захват **[this]**.

```cpp


#include <iostream>

#include <string>



void printer(auto func)

{

    std::cout << "*******************"<< std::endl;

    func();

    std::cout << "*******************"<< std::endl;

}

class Message

{

public:

    Message(const std::string& text): text{text}

    {}

    void print()

    {

        printer([this](){ std::cout << text << std::endl;});

    }

private:

    std::string text;

};



int main()

{

    Message hello{"Hello World"};

    hello.print();

}
```

в функции `print` класса `Message` на консоль выводится текст из поля `text`. для вывода вызывается внешняя функция `printer`: она печатает декоративную рамку и вызывает переданный объект. параметр `func` объявлен как `auto`, поэтому `printer` является шаблоном и принимает любой тип с оператором вызова. аргументом служит лямбда, которая читает поле `text`. захват `[this]` копирует указатель на текущий объект, и доступ к закрытому полю законен: тело лямбды находится в области члена класса и подчиняется тем же правилам доступа.

указатель `this` можно сочетать с захватом по умолчанию и с захватом отдельных переменных. такими записями будут `[=, this]`, `[this, &n]` и `[x, this, &n]`. копируется указатель на текущий объект. копия самого объекта не создаётся, поэтому лямбда не должна пережить объект: иначе обращение к полю идёт через висячий `this`. начиная с c++17 запись `[*this]` захватывает объект по значению, копией, и тогда время жизни копии совпадает с временем жизни замыкания.
