потоки для текстовых файлов представляют объекты, при открытии которых не задан режим `ios::binary`. в текстовом режиме символы конца строки могут переводиться между внутренним представлением и записью, принятой на платформе. набор байтов в файле тогда зависит от этой подстановки.

### запись в файл

запись в объект `ofstream` или `fstream` выполняет оператор вставки `<<`. им же значение передаётся в любой `ostream`, в том числе на консоль через `cout`. чтение из такого потока выполняет оператор извлечения `>>`, им же читают с консоли через `cin`.

ниже вектор структур `Point` записывается в файл `points.txt` и затем считывается оттуда в новый вектор. перед записью и перед чтением проверяется `is_open()`. по окончании оба потока закрываются через `close`.

```cpp


#include <iostream>

#include <fstream>

#include <vector>



struct Point

{

    Point(double x, double y): x{x}, y{y} {}

    double x;

    double y;

};

int main()

{

    std::vector<Point> points{ Point{0, 0}, Point{4, 5}, Point{-5, 7}};

     

    std::ofstream out("points.txt");

     

    if (out.is_open())

    {

        // записываем все объекты Point в файл

        for (const Point& point: points)

        {

            out << point.x << " " << point.y << std::endl;

        }

    }

    out.close();

 

    std::vector<Point> new_points;

    std::ifstream in("points.txt"); // окрываем файл для чтения

    if (in.is_open())

    {

        double x, y;

        while (in >> x >> y)

        {

            new_points.push_back(Point{x, y});

        }

    }

    in.close();

 

    for (const Point& point: new_points)

    {

        std::cout << "Point X: " << point.x << "\tY: " << point.y << std::endl;

    }

}
```

цикл проходит по всем элементам вектора и пишет каждый `Point` в файл.

```cpp


for (const Point& point: points)

{

    out << point.x << " " << point.y << std::endl;

}
```

при записи значения одной точки отделяются пробелом, после пары координат ставится `std::endl`: перевод строки и сброс буфера. в файле получается такой текст:

```browser


0 0

4 5

-5 7
```

оператор `>>` для числа пропускает ведущие пробельные символы и забирает одну лексему. последовательное извлечение в `x` и в `y` собирает очередную точку, и этой парой инициализируется `Point`, который помещается в вектор.

```cpp


double x, y;

while (in >> x >> y)

{

    new_points.push_back(Point{x, y});

}
```

способ ограничен правилом разделителя. при чтении поток считает пробел границей между значениями и раскладывает лексемы в переменные `x` и `y`. цикл `while (in >> x >> y)` продолжается, пока обе экстракции успешны, и заканчивается в конце файла или на первой лексеме, которая не читается как число. если записать строку, внутри которой есть пробелы, и рядом другие данные, чтение через `>>` примет пробел за границу значения. такую строку читают целиком и разбирают отдельно.
