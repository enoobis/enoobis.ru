ограничения типа применяются и к заменителям **auto**, **auto*** и **auto&**. везде, где используется `auto`, можно указать ограничение типа: при определении локальных переменных, для типа результата функции, в лямбда-выражениях и т. д. всякий раз, когда конкретный тип, который будет подставлен вместо `auto`, не удовлетворяет ограничению типа, компилятор выдаёт ошибку. вывод типа остаётся обычным, концепт лишь отвергает недопустимый результат вывода.

пример:

```cpp
#include <iostream>
#include <concepts>

template <typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

Numeric auto sum(Numeric auto a, Numeric auto b)
{
    const Numeric auto result{a + b };
    return result;
}

int main()
{
    std::cout << sum(10, 3) << std::endl;       // 13
    std::cout << sum(10.6, 3.2) << std::endl;   // 13.8
}
```

здесь определён концепт `Numeric`, который предполагает, что тип `T` представляет целое число (`std::integral<T>`) либо число с плавающей точкой (`std::floating_point<T>`). оба концепта объявлены в `<concepts>` и разделяют стандартные арифметические типы на целые и плавающие.

в определении функции `sum` рядом с заместителем типа `auto` применяется этот концепт. возможный набор используемых типов ограничивается числовыми типами. для типа результата функции это записывается так:

```cpp
Numeric auto sum
```

для типа параметров:

```cpp
(Numeric auto a, Numeric auto b)
```

для константы внутри функции:

```cpp
const Numeric auto result{a + b };
```

затем функцию `sum` вызывают, передавая в неё числа, как целые, так и с плавающей точкой:

```cpp
sum(10, 3)      // 13
sum(10.6, 3.2)  // 13.8
```

запись `numeric auto` в списке параметров задаёт аббревиатурный шаблон функции: каждый такой параметр вводит параметр шаблона со своим ограничением, и ограничения проверяются по отдельности.
