массив представляет набор однотипных данных, расположенных в памяти непрерывно. тип массива включает и тип элемента, и длину. формальное объявление выглядит так:

```cpp
тип_переменной название_массива [длина_массива]
```

после типа элемента идёт имя массива, затем в квадратных скобках размер. размер входит в тип и в стандартном c++ обязан быть преобразованным константным выражением, то есть значением, известным во время компиляции. массив из четырёх чисел:

```cpp
int numbers[4];
```

число элементов можно задать именованной константой:

```cpp


const int n = 4;

int numbers[n];		// содержит 4 элемента
```

некоторые компиляторы, в том числе g++, принимают в качестве размера и обычную переменную. массив переменной длины пришёл из c99 и в стандарт c++ не входит: это расширение реализации. программа, которая на него опирается, не переносится на компилятор без такого расширения.

объявленный массив содержит четыре объекта типа `int`, однако без инициализатора их значения неопределённы. у объекта с автоматической продолжительностью хранения, не получившего инициализатор, чтение до записи даёт неопределённое поведение. значения задают инициализатором в фигурных скобках:

```cpp
int numbers[4] {};	 //  {0, 0, 0, 0}
```

пустые фигурные скобки означают инициализацию значением. для скалярного типа `int` каждый элемент получает нуль.

конкретные значения всех элементов перечисляются в том же порядке, в каком элементы лежат в памяти:

```cpp


int numbers[4] {1, 2, 3, 4};
```

под массив выделяется непрерывный участок из четырёх ячеек. на распространённых платформах размер `int` равен 4 байтам (стандарт гарантирует не менее 16 бит), и каждая ячейка хранит один элемент:

| numbers[0] | numbers[1] | numbers[2] | numbers[3] |
| --- | --- | --- | --- |
| 1 | 2 | 3 | 4 |

если значений в инициализаторе меньше, чем элементов, перечисленные значения получают первые элементы, остальные инициализируются нулём. наличие инициализатора распространяет инициализацию на весь массив, и недостающие элементы не остаются неопределёнными:

```cpp


int numbers[4] {1, 2};	 //  {1, 2, 0, 0}
```

если значений больше, чем элементов, программа некорректна, и компиляция завершается ошибкой. избыточный инициализатор не отбрасывается:

```cpp


int numbers[4] {1, 2, 3, 4, 5, 6};	 // ! Ошибка
```

здесь длина равна 4, а в инициализаторе передаётся 6 значений.

если длина в квадратных скобках опущена, она выводится из числа инициализаторов. тип такого объекта фиксируется при компиляции:

```cpp


int numbers[] {1, 2, 3, 4, 5, 6};
```

в массиве оказывается 6 элементов, тип объекта есть `int[6]`.

одному массиву нельзя присвоить другой. у массива нет оператора присваивания: операция `=` для двух массивов в языке не определена, и элементы при необходимости копируют по отдельности.

```cpp


int nums1[] {1,2,3,4,5};

int nums2[] = nums1;	// ошибка
```

### индексы. получение и изменение элементов массива

к отдельному элементу обращаются по индексу. нумерация начинается с нуля, поэтому первый элемент имеет индекс 0, а сам индекс есть смещение от начала массива. выражение `numbers[i]` по определению языка равно `*(numbers + i)` и обозначает lvalue элемента: по нему значение читают или записывают. чтение второго элемента (индекс 1):

```cpp
int n = numbers[1];
```

запись в тот же элемент:

```cpp
numbers[1] = 123;
```

чтение и запись в одной программе:

```cpp


#include <iostream>



int main()

{

	int numbers[4]{1,2,3,4};

	int first = numbers[0];		// получаем первый элемент

	std::cout << first << std::endl;	// 1

	numbers[0] = 34;					/ изменяем значение элемента

	std::cout << numbers[0] << std::endl; // 34

}
```

индекс обязан указывать на существующий элемент. у массива из 4 элементов допустимы индексы от 0 до 3 включительно. любой другой индекс выводит обращение за границу объекта. это неопределённое поведение: компилятор диагностирует отдельные случаи, но статической проверки всех индексов язык не выполняет.

```cpp


int numbers[4]{1,2,3,4};

int forth = numbers[4];		// !Ошибка - в массиве только 4 элемента
```

### константные массивы

если элементы не должны изменяться после инициализации, массив объявляют константным с помощью ключевого слова `const`. тип элемента становится `const int`, и запись в него отвергается на этапе компиляции.

```cpp


const int numbers[4]{1,2,3,4};

// numbers[1] = 23;    // ошибка - значения элементов массива изменить нельзя
```

### длина массива

длина массива не всегда записана рядом с тем местом, где массив обрабатывают. получить её можно несколькими способами. первый, пришедший из языка c, использует оператор `sizeof`:

```cpp


#include <iostream>

 

int main()

{   

    int numbers[]{11, 12, 13, 14};

    std::cout << "Length: " << sizeof(numbers) / sizeof(numbers[0]) << std::endl;   // Length: 4

}
```

длина в элементах равна размеру всего массива, делённому на размер одного элемента. все элементы имеют один тип и занимают одинаковое число байт. выражение `sizeof(numbers)` даёт размер всего массива в байтах, выражение `sizeof(numbers[0])` даёт размер одного элемента в байтах. частное этих значений равно числу элементов. для массива фиксированной длины `sizeof` вычисляется во время компиляции и не порождает обход элементов. приём верен, пока операнд сохраняет тип массива: после преобразования имени массива в указатель `sizeof` вернёт размер указателя.

второй способ использует библиотечную функцию `std::size()`, появившуюся в c++17 и объявленную в заголовке `<iterator>`. для массива известной длины вызов является константным выражением и возвращает значение типа `std::size_t`:

```cpp


#include <iostream>

 

int main()

{   

    int numbers[]{11, 12, 13, 14};

    int count = std::size(numbers);

    std::cout << "Length: " << count << std::endl;   // Length: 4

}
```

### перебор массивов

цикл позволяет обойти весь массив и обратиться к элементам по индексам:

```cpp


#include <iostream>

 

int main()

{   

    const int n = 4;

    int numbers[n] {11, 12, 13, 14};

    for(int i=0; i < n; i++)

    {

        std::cout << numbers[i] << std::endl;

    }

}
```

для прохода нужна длина. здесь она задана константой `n`. сначала длина известна как `n`, затем цикл `for` перебирает элементы, пока счётчик `i` не станет равен длине. на консоль выводятся все элементы:

```bash


11

12

13

14
```

тем же проходом считается сумма элементов:

```cpp


#include <iostream>

 

int main()

{   

    int numbers[]{1, 2, 3, 4};

    int sum {};

    for (int i {}; i < std::size(numbers); sum += numbers[i++]);

    std::cout << "Sum: " << sum << std::endl;   // Sum: 10

}
```

длина здесь вычисляется вызовом `std::size()`. выражение итерации `sum += numbers[i++]` прибавляет текущий элемент к сумме и сдвигает индекс, тело цикла пусто, поэтому после заголовка стоит точка с запятой.

### перебор элементов в стиле for-each

для перебора последовательностей, в том числе массивов, есть отдельная форма цикла `for` (range-based for). компилятор разворачивает её в обход от начала диапазона до конца, и индекс в исходном тексте не нужен:

```cpp


#include <iostream>



int main()

{

	int numbers[4] {1,2,3,4};

	for(int n : numbers)

	{

		std::cout << n << std::endl;

	}

}
```

на каждой итерации очередной элемент копируется в переменную `n`, и это значение выводится на консоль. присваивание переменной `n` массив не изменяет. чтобы менять элементы на месте, переменную цикла объявляют ссылкой.

если тип элементов не повторяют явно, его выводит спецификатор `auto`. в примере ниже выводится тот же `int`, что и у элемента массива:

```cpp


for(auto n : numbers)

{

	std::cout << n << std::endl;

}
```

### ввод значений массива с консоли

значения элементов вводятся так же, как значения отдельных переменных. ниже пользователь вводит числа в массив:

```cpp


#include <iostream>

 

int main()

{

    const int max {6};     // максимальная длина массива - не больше 6 чисел

    int numbers[max];       // массив для ввода чисел

 

    int i{};        // счетчик введенных чисел

    std::cout << "Enter numbers" << std::endl;

    while(i < max)

    {

        std::cin >> numbers[i];    // вводим число

        i++;

    }

    // выводим массив

    for (i =0; i < max; ++i)

    {

        std::cout << numbers[i] << "\t";

    }

    std::cout << std::endl;

}
```

константа `max` ограничивает длину шестью элементами. счётчик `i` хранит, сколько чисел уже принято. цикл `while` читает очередное число в `numbers[i]`, пока `i` меньше `max`. затем цикл `for` выводит введённый массив через табуляцию. в этом фрагменте сначала вводятся шесть чисел, по одному на элемент, после чего массив печатается.
