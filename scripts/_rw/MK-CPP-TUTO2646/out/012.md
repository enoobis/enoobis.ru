в самом языке c++ нет встроенных средств консольного ввода и вывода. их предоставляет библиотека `iostream`. в ней определены два типа: `istream` и `ostream`. `istream` описывает поток ввода, `ostream` описывает поток вывода.

термин «поток» здесь обозначает последовательность символов, которую записывают на устройство ввода-вывода или считывают с него. в этой лекции таким устройством служит консоль.

для записи символов на консоль используется объект `cout` типа `ostream`. для чтения с консоли используется объект `cin` типа `istream`.

чтобы эти имена стали доступны, в начало исходного файла подключают заголовок библиотеки:

```cpp
#include <iostream>
```

### вывод на консоль

вывод на консоль выполняет оператор `<<`. левый операнд имеет тип `ostream` (для консоли это объект `cout`), правый операнд задаёт выводимое значение. оператор возвращает левый операнд, поэтому несколько выводов записывают цепочкой. ниже приведён пример того, что в результате оказывается на консоли:

```consoletext


Name: Tom

Age: 33

Weight: 81.23
```

оператор ввода `>>` тоже принимает два операнда. левый операнд имеет тип `istream` (здесь это объект `cin`), с него выполняется чтение. правый операнд задаёт объект, в который записывается считанное значение.

чтение с консоли выглядит так:

```cpp


#include <iostream>



int main()

{	

	int age;

	double weight;

	std::cout << "Input age: ";

	std::cin >> age;

	std::cout << "Input weight: ";

	std::cin >> weight;

	std::cout << "Age: " << age << "\t Weight: " << weight << std::endl;

}
```

после каждого приглашения программа ждёт ввода значения: сначала для переменной `age`, затем для переменной `weight`.

пример работы программы:

```consoletext


Input age: 32

Input weight: 67.45

Age: 32		Weight: 67.45
```

оператор ввода в первой операции записывает данные в целочисленную переменную `age` и поэтому ожидает число. для переменной `weight` он ожидает число с плавающей точкой, причём разделителем целой и дробной части служит точка. произвольный текст, в частности строка, формату не соответствует, и программа может получить некорректный результат. при неудачном разборе у потока ввода выставляется состояние ошибки, и последующие чтения до сброса этого состояния не извлекают новые символы.

оператор `>>` возвращает левый операнд, объект `cin`. из-за этого несколько значений читают одной цепочкой, передавая результат предыдущей операции следующей:

```cpp


#include <iostream>



int main()

{	

	int age;

	double weight;

	std::cout << "Input age and weight: ";

	std::cin >> age >> weight;

	std::cout << "Age: " << age << "\t Weight: " << weight << std::endl;

	return 0;

}
```

пример работы программы:

```consoletext


Input age and weight: 32 67.45

Age: 32		Weight: 67.45
```

после одного значения вводят пробельный разделитель и затем следующее значение. оператор `>>` пропускает ведущие пробельные символы и останавливает чтение числа на первом символе, который уже не входит в его запись.
