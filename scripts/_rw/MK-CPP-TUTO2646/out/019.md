условная конструкция `if-else` направляет выполнение по одному из путей в зависимости от условия. она проверяет истинность условия и при истинном условии выполняет соответствующий блок инструкций. в сокращённой форме присутствует только ветвь `if`:

```cpp


if (условие)

{

	инструкции;

}
```

в качестве условия используется условное выражение типа `bool`. если условие даёт `true`, выполняются инструкции блока `if`. если условие даёт `false`, эти инструкции пропускаются. блок заключается в фигурные скобки и образует собственную область видимости. пример:

```cpp


#include <iostream>



int main()

{

    int a {8};

    if(a == 8)

    {

        std::cout << "a == 8" << std::endl;

    }

    std::cout << "End of program" <<  std::endl;

}
```

условие здесь записано выражением `a == 8`: значение переменной `a` сравнивается с числом 8. сравнение истинно и даёт `true`, поэтому выполняется единственная инструкция блока и на консоль выводится строка `a == 8`. полный консольный вывод:

```bash


a == 8

End of program
```

инструкции, записанные после конструкции `if`, выполняются независимо от условия. в примере выше после блока стоит вывод строки `"End of program"`.

противоположная ситуация:

```cpp


#include <iostream>



int main()

{

    int a {8};

    if(a == 7)

    {

        std::cout << "a  == 7" << std::endl;

    }

    std::cout << "End of program" <<  std::endl;

}
```

условие другое: `a == 7`. переменная `a` не равна 7, сравнение ложно и даёт `false`, поэтому инструкции внутри блока `if` не выполняются. консольный вывод содержит только текст, напечатанный после конструкции:

```bash


End of program
```

если блок состоит из одной инструкции, фигурные скобки можно опустить. следующая инструкция того же уровня уже не входит в `if`:

```cpp


#include <iostream> 



int main()

{

    int a {8};

    if(a == 8)  // только одна инструкция

        std::cout << "a == 8" << std::endl;



    std::cout << "End of program" <<  std::endl;

}
```

инструкцию допускается записать и на одной строке с условием:

```cpp
if(a == 8)  std::cout << "a == 8" << std::endl;
```

пропуск скобок у одной инструкции ненадёжен: вторая строка, добавленная с тем же отступом, в блок уже не попадёт. составной оператор делает границу ветви явной.

#### if..else

полная форма включает оператор `else`:

```cpp


if(выражение_условия)

{

	инструкция_1

}

else

{

	инструкция_2

}
```

после `else` записывают инструкции, которые выполняются, если условие в `if` возвращает `false`. при истинном условии выполняется ветвь `if`, при ложном выполняется ветвь `else`. одновременно две ветви не выполняются.

```cpp


#include <iostream> 



int main()

{

    int n {21};

    if (n > 22)

    {

        std::cout << "n > 22" << std::endl;

    }

    else

    {

        std::cout << "n <= 22" << std::endl;

    }

}
```

условие `n > 22` ложно и возвращает `false`, поэтому выполняется блок `else`. на консоль выводится строка из этой ветви, в коде она задана как `"n <= 22"`.

если условие истинно, выполняется инструкция

```cpp
std::cout << "a=" << a << "; c=" << c << std::endl;
```

иначе выполняется инструкция

```cpp
std::cout << "b=" << b << "; c=" << c << std::endl;
```

в обеих ветвях доступна переменная `c`. вне конструкции `if-else` имя `c` недоступно: его область видимости ограничена этим оператором, а не всей функцией.

другой пример выясняет, делится ли одно число на другое без остатка. если остаток есть, программа выводит его на консоль:

```cpp


#include <iostream>

 

int main()

{

    int a {5};

    int b {3};

      

    if(int rem {a % b}; rem == 0)

    {

        std::cout << "a divisible by b" << std::endl;

    }

    else

    {

        std::cout << "remaining of a / b = " << rem << std::endl;

    }

}
```

в заголовке `if` определена переменная `rem`, остаток от деления `a` на `b`. такая форма, с инициализатором перед условием, существует с c++17. имя `rem` видно и в ветви `if`, и в ветви `else`, и не видно после всей конструкции. инициализатор вычисляется один раз, до проверки условия `rem == 0`.

### тернарный оператор

тернарный, или условный, оператор близок к конструкции `if-else` по выбору одной из двух альтернатив, но является выражением: он вычисляется внутри более крупного выражения и даёт значение. у него три операнда:

```cpp
операнд1? операнд2 : операнд3
```

первый операнд задаёт условие. если условие истинно и равно `true`, выбирается и вычисляется второй операнд, записанный после символа `?`. если условие ложно, выбирается и вычисляется третий операнд, записанный после двоеточия. вычисляется только выбранный операнд, второй не вычисляется. тип результата определяется общим типом второго и третьего операндов.

та же развилка, записанная через `if-else`:

```cpp


#include <iostream> 



int main()

{

    int a {5};

    int b {8};

    int c{};

    if(a > b)

    {

        c = a - b;

    }

    else

    {

        c = a + b;

    }

    std::cout << "c = " << c << std::endl;  // c = 13

}
```

если `a` больше `b`, то `c = a - b`, иначе `c = a + b`. в виде условного оператора:

```cpp


#include <iostream> 



int main()

{

    int a {5};

    int b {8};

    int c = a > b ? a - b : a + b;



    std::cout << "c = " << c << std::endl;  // c = 13

}
```

первый операнд здесь условие `a > b`. при истинном условии результатом становится второй операнд, значение выражения `a - b`. при ложном условии результатом становится третий операнд, `a + b`. полученное значение присваивается переменной `c`.

условный оператор может и не использоваться как источник значения для присваивания: выбранный операнд сам выполняет действие. пример:

```cpp


#include <iostream> 



int main()

{

    int a {5};

    int b {8};

    a > b ? std::cout << a-b : std::cout << a+b;

}
```

первый операнд снова условие. если оно истинно, выполняется второй операнд, вывод разности через `std::cout`. если оно ложно, выполняется третий операнд, вывод суммы. для значений из примера условие ложно, поэтому на консоль попадает сумма.
