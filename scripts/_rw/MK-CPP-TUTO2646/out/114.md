в качестве практики разбора строк строится небольшая программа подсчета слов. текст читается со стандартного ввода в `std::string`, слова копируются в `std::vector<std::string>`, затем печатаются число слов и сами слова. граница слова задается множеством символов-разделителей. `find_first_of` и `find_first_not_of` принимают это множество и ищут совпадение с любым его символом. порядок символов внутри множества на результат не влияет.

```cpp
#include <iostream>
#include <vector>
#include <string>

int main()
{
    std::string text; // Исходный текст
    std::cout << "Enter some text: ";
    std::getline(std::cin, text);
    const std::string separators{ " ,;:.\"!?'*\n" }; // разделители слов
    std::vector<std::string> words; // вектор для хранения слов
    size_t start { text.find_first_not_of(separators) }; // начальный индекс первого слова
    while (start != std::string::npos) // проходим, пока в строке не окажется других символов, кроме separators
    {
        size_t end = text.find_first_of(separators, start + 1); // находим, где кончается слово
        if (end == std::string::npos) // если НЕ найден ни один из символов-разделителей
            end = text.length();        // устанавливаем переменную end на конец текста
        words.push_back(text.substr(start, end - start)); // добавляем в вектор слово
        start = text.find_first_not_of(separators, end + 1); // находим начальный индекс следующего слова и переустанавливаем start
    }
    // выводим количество слов
    std::cout << "\nText contains " << words.size() << " words:" << std::endl;
    // выводим все слова на консоль
    for (const auto& word : words)
    {
        std::cout << word << std::endl;
    }
}
```

объект `text` хранит введенную строку. приглашение идет в стандартный вывод, после чего `std::getline(std::cin, text)` читает ввод до перевода строки. ограничитель в `text` не записывается. фрагмент ниже фиксирует то же начало: объявление строки, приглашение, чтение. приглашение во фрагменте записано оператором `>>`. в полной программе выше оно записано оператором `<<`.

```cpp
std::string text; // Исходный текст
std::cout >> "Enter some text: ";
std::getline(std::cin, text);
```

строка `separators` константна и содержит разделители: пробел, запятая, точка с запятой, двоеточие, точка, двойная кавычка, восклицательный знак, вопросительный знак, апостроф, звездочка и символ `\n`. символ из этого набора завершает слово и в слово не включается. дефис, скобки и цифры в набор не входят и остаются внутри слова. апостроф в набор входит, поэтому запись вроде `don't` распадается на два фрагмента.

```cpp
const std::string separators{ " ,;:.\"!?'*\n" }; // разделители слов
```

символ перевода строки добавлен в набор для демонстрации. в программе строка читается через `std::getline` с ограничителем по умолчанию, и ввод заканчивается нажатием enter. извлеченный текст символа `\n` не содержит: поток отдает строку уже без ограничителя. если ограничитель `std::getline` сменить или читать текст из файла, `\n` сохраняется в данных и отделяет слова так же, как пробел и знаки пунктуации.

число слов до разбора неизвестно, поэтому слова складываются в вектор. вектор хранит владеющие объекты `std::string` и расширяет буфер по мере `push_back`.

```cpp
std::vector<std::string> words; // вектор для хранения слов
```

перед циклом фиксируется индекс первого символа первого слова. `find_first_not_of(separators)` возвращает наименьшую позицию символа, который в множество разделителей не входит. пустая строка и строка из одних разделителей дают `std::string::npos`.

```cpp
size_t start { text.find_first_not_of(separators) }; // начальный индекс первого слова
```

цикл `while` выполняется, пока `start` обозначает найденную позицию. `std::string::npos` есть максимальное значение типа `size_t` и в строковой библиотеке означает отсутствие позиции. значение `npos` останавливает цикл: символов вне множества разделителей больше нет. для ввода из одних разделителей остановка происходит до первой итерации, вектор остается пустым.

```cpp
while (start != std::string::npos)
```

если `start` лежит на начале слова, в `end` записывается граница после последнего символа этого слова. её ищет `find_first_of(separators, start + 1)`. поиск начинается с индекса `start + 1` включительно, то есть со следующего символа, и возвращает первую позицию любого разделителя. у однобуквенного слова разделитель сразу за ним в диапазон поиска входит.

```cpp
size_t end = text.find_first_of(separators, start + 1); // находим, где закончилось слово
```

разделителя может не оказаться до конца текста. тогда `find_first_of` возвращает `std::string::npos`. так устроено последнее слово без завершающего пробела и без пунктуации. `end` устанавливается в `text.length()`, на позицию за последним символом. `substr` принимает вторым аргументом число символов, и такая граница для него корректна.

```cpp
if (end == std::string::npos) // если НЕ найден ни один из символов-разделителей
    end = text.length();        // устанавливаем переменную end на конец текста
```

когда известны начало и конец, `substr(start, end - start)` копирует полуинтервал `[start, end)` в новый `std::string`, а `push_back` кладет копию в вектор. затем `start` получает начало следующего слова: `find_first_not_of(separators, end + 1)` идет от символа после `end` и пропускает всю подряд идущую группу разделителей. если слова дальше нет, снова возвращается `npos`, и цикл на этом заканчивается. при фиксированном множестве разделителей проход линеен по длине строки: каждый символ участвует в поиске ограниченное число раз. сверх этого просмотра каждое слово отдельно копируется в собственный буфер `std::string`, а рост вектора может переместить уже накопленные объекты строк в новый буфер контейнера.

```cpp
words.push_back(text.substr(start, end - start)); // добавляем в вектор слово
start = text.find_first_not_of(separators, end + 1); // находим начальный индекс следующего слова и переустанавливаем start
```

в конце печатается размер вектора и каждое сохраненное слово с новой строки. размер равен числу слов, потому что итерация добавляет ровно один элемент.

пример работы:

```bash
Enter some text: When in Rome, do as the Romans do.

Text contains 8 words:
When
in
Rome
do
as
the
Romans
do
```

во входной строке примера восемь слов. запятая после `Rome` и заключительная точка входят в `separators` и среди слов не печатаются. оба вхождения `do` сохраняются отдельно. программа считает последовательные вхождения. множество различных слов она не строит.
