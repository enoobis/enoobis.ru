класс `std::stack` представляет стек: структуру данных с дисциплиной lifo (last-in first-out, последним вошёл, первым вышел). извлекается всегда элемент, добавленный последним. стек сопоставим со стопкой тарелок: очередная тарелка кладётся сверху, а забирается та, что лежит выше остальных и была положена последней.

`std::stack` является адаптером контейнера. собственную структуру хранения он не определяет и держит последовательность во вложенном контейнере. наружу адаптер отдаёт только операции стека. второй параметр шаблона задаёт тип вложенного контейнера, по умолчанию используется `std::deque`. итераторов у адаптера нет: обход середины не входит в дисциплину стека.

для работы со стеком подключается заголовочный файл `<stack>`. пустой стек:

```cpp


#include <iostream>

#include <stack>

#include <string>



int main()

{

    std::stack<std::string> stack;	// пустой стек строк

}
```

### размер стека

`size()` возвращает число элементов. `empty()` возвращает `true`, если стек пуст:

```cpp


#include <iostream>

#include <stack>

#include <string>



int main()

{

    std::stack<std::string> stack;

    if(stack.empty())

    {

        std::cout << "stack is empty" << std::endl;

    }

    std::cout << "stack size: " << stack.size() << std::endl; // stack size: 0

}
```

### добавление элементов

элемент помещается на вершину функцией `push()`. аргумент копируется или перемещается во вложенный контейнер. у контейнера по умолчанию это соответствует `push_back`.

```cpp


#include <iostream>

#include <stack>

#include <string>



int main()

{

    std::stack<std::string> stack;

	// добавляем три элемента

    stack.push("Tom");

    stack.push("Bob");

    stack.push("Sam");



	std::cout << "stack size: " << stack.size() << std::endl; // stack size: 3

}
```

после трёх вызовов `size()` равен 3. вершиной стека становится последняя переданная строка.

### получение элементов

прочитать можно только вершину. для этого служит `top()`. функция возвращает ссылку на верхний элемент и со стека его не снимает.

```cpp


#include <iostream>

#include <stack>

#include <string>



int main()

{

    std::stack<std::string> stack;

    stack.push("Tom");

    stack.push("Bob");

    stack.push("Sam");

    std::cout << "Top: " << stack.top() << std::endl;   // Top: Sam

}
```

после добавления трёх строк расположение стека такое: последняя добавленная строка лежит на вершине.

```browser


-------

| Sam |

-------

| Bob |

-------

| Tom |

-------
```

на вершине находится последний добавленный элемент. `top()` возвращает именно его.

### удаление элементов

элемент снимается функцией `pop()`. удаление идёт в порядке, обратном добавлению: каждый вызов убирает текущую вершину. `pop()` значение не возвращает. перед снятием оно читается через `top()`. вызов `pop()` на пустом стеке даёт неопределённое поведение.

```cpp
stack.pop()
```

вместе `top()` и `pop()` извлекают все элементы стека:

```cpp


#include <iostream>

#include <stack>

#include <string>



int main()

{

    std::stack<std::string> stack;

    stack.push("Tom");

    stack.push("Bob");

    stack.push("Sam");



    while (!stack.empty())	// пока стек не пуст

    {

        std::cout << stack.top() << std::endl;

        stack.pop();	// извлекаем верхний элемент

    }

}
```

пока `empty()` возвращает ложь, программа печатает вершину и снимает её. когда стек становится пустым, цикл заканчивается. консольный вывод программы:

```bash


Sam

Bob

Tom
```

порядок печати `"Sam"`, `"Bob"`, `"Tom"` обратен порядку вызовов `push`.

### инициализация деком

стек инициализируется другим стеком или двусторонней очередью. конструктор от контейнера принимает его как внутреннюю последовательность. вершина стека соответствует концу этой последовательности: `top()` согласован с `back()` вложенного контейнера. для `std::stack<std::string>` вложенный контейнер по умолчанию имеет тип `std::deque<std::string>`, поэтому дек строк подходит аргументом конструктора.

```cpp


#include <iostream>

#include <stack>

#include <string>



int main()

{

    std::deque<std::string> users{"Tom", "Sam", "Bob"};

    std::stack<std::string> stack {users};



    while (!stack.empty())

    {

        std::cout << stack.top() << std::endl;

        stack.pop();

    }

}
```

дек `users` содержит `"Tom"`, `"Sam"`, `"Bob"`. после построения стека на вершине оказывается последний элемент дека, строка `"Bob"`, под ней `"Sam"`, затем `"Tom"`. цикл `top` и `pop` печатает элементы в этом порядке.
