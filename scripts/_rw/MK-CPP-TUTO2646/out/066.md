перечисление задаёт собственный тип, область значений которого состоит из именованных целочисленных констант, перечислителей. форма **enum class**, ограниченное перечисление:

```cpp


enum class имя_перечисления { константа_1, константа_2, ... константа_N};
```

после служебных слов **enum class** стоит имя перечисления, затем в фигурных скобках через запятую перечислители. простейшее перечисление:

```cpp
enum class Day {Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday}
```

перечисление `Day` задаёт дни недели. каждый перечислитель является константой целого типа. по умолчанию первый получает значение 0, каждый следующий на единицу больше. `Monday` равен 0, `Tuesday` равен 1, последний перечислитель `Sunday` равен 6. базовый тип ограниченного перечисления по умолчанию `int`. сами константы находятся в области видимости перечисления, поэтому имя записывают с квалификацией, `Day::Monday`.

после определения перечисления объявляют переменную этого типа и задают ей один из перечислителей.

```cpp


Day today {Day::Thursday};

// или так

//Day today = Day::Thursday;
```

переменная `today` имеет тип `Day` и значение `Day::Thursday`. это четвёртый перечислитель при счёте с нуля: `Monday` равен 0, `Tuesday` равен 1, `Wednesday` равен 2, `Thursday` равен 3.

чтобы вывести значение, его преобразуют к целому. ограниченное перечисление к `int` неявно не приводится. перечислитель отделён от произвольного целого, и подставить `Day` туда, где ожидается число, можно только явным преобразованием.

```cpp


#include <iostream>



enum class Day {Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday};

int main()

{

    Day today {Day::Thursday};

    std::cout << "Today: " << static_cast<int>(today) << std::endl;

}
```

на консоль попадёт текст `Today: 3`, потому что `Thursday` равен 3.

значения перечислителей задают явно. если указать значение одной константы, у следующих констант без явного значения оно растёт на единицу.

```cpp
enum class Day {Monday = 1, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday};
```

здесь `Tuesday` равен 2, `Sunday` равен 7.

каждой константе можно задать своё значение и сочетать явные значения с автоматическим продолжением.

```cpp
enum class Day {Monday = 2, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday=1};
```

здесь `Saturday` равен 7, `Sunday` равен 1. двум перечислителям можно дать одно и то же значение. с точки зрения базового целого уникальность не требуется, различаются имена.

```cpp
enum class Day {Monday = 1, Mon = 1, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday };
```

`Monday` и `Mon` равны. константе можно присвоить значение уже объявленного перечислителя. выражение обязано быть константным и вычисляется во время компиляции.

```cpp
enum class Day {Monday = 1, Mon = Monday, Tuesday = Monday + 1, Wednesday, Thursday, Friday, Saturday, Sunday };
```

перечислители должны быть целочисленными константами. базовый тип можно выбрать другой, в том числе `char`. значение перечислителя тогда имеет этот тип, и в него помещается код символа.

```cpp
enum class Operation: char {Add = '+', Subtract='-', Multiply='*'};
```

чтобы вывести такие константы как символы, результат приводят к `char`. приведение к `int` показало бы код символа, приведение к `char` отдаёт сам символ.

```cpp


#include <iostream>



enum class Operation: char {Add = '+', Subtract='-', Multiply='*'};

int main()

{

    std::cout << "add: " << static_cast<char>(Operation::Add) << std::endl;

    std::cout << "subtracte: " << static_cast<char>(Operation::Subtract) << std::endl;

    std::cout << "multiply: " << static_cast<char>(Operation::Multiply) << std::endl;

}
```

### применение перечислений

перечисление уместно там, где у величины конечный набор состояний и дальнейшие действия выбираются по текущему состоянию.

```cpp


#include <iostream>



enum class Operation {Add, Subtract, Multiply};



void calculate(int n1, int n2, Operation op)

{

    switch (op)

    {

        case Operation::Add: 

            std::cout << n1 + n2 << std::endl;

            break;

        case Operation::Subtract:

            std::cout << n1 - n2 << std::endl;

            break;

        case Operation::Multiply:

            std::cout << n1 * n2 << std::endl;

            break;

    }

}

int main()

{

    calculate(10, 6, Operation::Add);           // 16

    calculate(10, 6, Operation::Subtract);      // 4

    calculate(10, 6, Operation::Multiply);      // 60

}
```

арифметические операции собраны в перечислении `Operation`. функция `calculate` по третьему параметру выбирает действие над двумя первыми. метка `case` имеет тип `Operation`, и перечислитель другого перечисления на это место не поставить: ограниченное перечисление к целому молча не приводится.

### подключение констант перечисления

по умолчанию к перечислителю обращаются по имени перечисления, например `Day::Monday`. со стандарта c++20 перечислители вводят в текущую область видимости оператором **using**.

```cpp
using enum Day;
```

дальше достаточно имени константы. имя попадает в текущую область и обходится без квалификации, пока не сталкивается с другим объявлением того же имени.

```cpp


#include <iostream>



enum class Day {Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday};

using enum Day;     // подключаем константы перечисления в текущую область видимости



int main()

{

    Day today {Thursday};	// используем только имя константы

    // или так 

    //Day today = Thursday;

    std::cout << static_cast<int>(today) << std::endl;      // 3

    // выводим значение констаты Sunday

    std::cout << static_cast<int>(Sunday) << std::endl;     // 6

}
```

в область можно ввести и один перечислитель.

```cpp


using Day::Monday;     // подключаем только Monday

........................

Day today {Monday};
```

вводится только `Day::Monday`. к остальным перечислителям по-прежнему обращаются через имя перечисления.

возможность относится к стандарту c++20. при компиляции g++ или clang++ указывают флаг `-std=c++20`. для более раннего стандарта конструкция `using enum` неизвестна и будет отвергнута.

### перечисления в c-стиле

раньше в c++ использовалась форма, пришедшая из c. она записывается без служебного слова `class`.

```cpp


#include <iostream>



enum Day {Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday};



int main()

{

    Day today = Tuesday;

    std::cout << today << std::endl;    // 1 

}
```

такие перечисления называют `unscoped`: перечислители объявляются в окружающей области видимости, в область самого перечисления они не заключены. они неявно приводятся к целому, поэтому их легко смешать с `int` и с константами другого перечисления в той же области. в старом коде эта форма встречается. в новом коде её избегают: конфликты имён и неявные преобразования дают больше ошибок, чем ограниченное перечисление `enum class`.
