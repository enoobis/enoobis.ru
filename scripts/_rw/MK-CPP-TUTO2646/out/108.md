### преобразование в строку

строку конкатенируют только со строкой. число и другие арифметические значения сначала переводят в `std::string`. для этого служит `std::to_string()`. в функцию передается преобразуемое значение. перегрузки покрывают целые типы и типы с плавающей точкой. формат плавающей точки выбирает реализация, это десятичная запись:

```cpp
#include <iostream>
#include <string>

int main()
{
    unsigned age{38};
    std::string message{ "Age: " + std::to_string(age)};
    std::cout << message << std::endl;    // Age: 38
}
```

### функции преобразования из строки в число

обратное направление, разбор строки в число, выполняют функции из `<string>`. каждая принимает строку и возвращает число своего типа:

- `stoi()` : преобразует в тип `int`

- `stol()` : в `long`

- `stoll()` : в `long long`

- `stoul()` : в `unsigned long`

- `stoull()` : в `unsigned long long`

- `stof()` : в `float`

- `stod()` : в `double`

- `stold()` : в `long double`

функции пропускают ведущие пробельные символы и разбирают необязательный знак и цифры. если разбор не прочитал ни одного символа числа, бросается `std::invalid_argument`. если значение не помещается в целевой тип, бросается `std::out_of_range`. у целочисленных вариантов есть перегрузки с указателем на индекс первого неразобранного символа и с основанием от 2 до 36.

```cpp
std::string str{ "123" };
int n{ std::stoi(str) }; // n == 123
```

### преобразование строки в указатель на символы

содержимое `string` доступно как указатель на непрерывный массив `char`. `c_str()` возвращает `const char*`. указатель адресует ту же последовательность, и за последним символом стоит нулевой байт, поэтому результат пригоден для функций в стиле c, ожидающих нуль-терминированную строку:

```cpp
#include <iostream>
#include <string>

int main()
{
    std::string message {"hello"};
    const char* message_ptr = message.c_str();  // преобразуем в указатель
    std::cout << message_ptr << std::endl;
}
```

`data()` тоже возвращает указатель на непрерывный буфер. с c++17 у неконстантного `string` есть перегрузка `data()`, возвращающая `char*`. через нее можно менять символы в пределах `size()`. константный объект дает `const char*`. до c++17 `data()` возвращала только константный указатель, а неконстантный доступ к буферу записывали через `&s[0]` у непустой строки.

```cpp
#include <iostream>
#include <string>

int main()
{
    std::string message {"hello"};
    char* message_ptr = message.data();  // преобразуем в указатель
    std::cout << message_ptr << std::endl;
}
```

указатель из `c_str()` и из `data()` теряет силу после неконстантной операции, которая меняет содержимое или емкость строки. опираться на него после `append`, `operator+=`, `insert` и подобных вызовов уже нельзя. пока строка не меняется, `c_str()` и `data()` указывают на один и тот же буфер.
