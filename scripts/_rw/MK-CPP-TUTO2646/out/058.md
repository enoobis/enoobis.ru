в c++ объявление функции и её определение можно разнести, в том числе для членов класса. определение вне класса записывают в форме `имя_класса::имя_функции(параметры) { тело_функции}`. оператор `::` разрешает область видимости класса: имя слева указывает, член какого класса определяется. для начала класс `Person`, в котором и конструктор, и `print` определены внутри класса.

```cpp


class Person 

{

private:

    std::string name;

    unsigned age;

public:

    Person(std::string p_name, unsigned p_age)

    { 

        name = p_name; 

        age = p_age;

    }

    void print() 

    {

        std::cout << "Name: " << name << "\tAge: " << age << std::endl;

    }

};
```

реализацию методов выносят наружу, в классе оставляют только объявления.

```cpp


#include <iostream>

#include <string>



class Person 

{

private:

    std::string name;

    unsigned age;

public:

    Person(std::string p_name, unsigned p_age);

    void print();

};

// конструктор

Person::Person(std::string p_name, unsigned p_age)

{ 

    name = p_name; 

    age = p_age;

}

void Person::print() 

{

    std::cout << "Name: " << name << "\tAge: " << age << std::endl;

}

int main()

{

    Person tom{"Tom", 38};

    tom.print();    // Name: Tom   Age: 22

}
```

у конструктора и у `print` внутри `Person` теперь только объявления. тела расположены вне класса и квалифицированы `Person::`. сигнатура вне класса совпадает с объявлением: имя, параметры и квалификаторы. при таком разбиении определение класса читается как интерфейс, объём тел на этот список не влияет. в программе из нескольких файлов определение класса обычно помещают в заголовок, а внеклассовые определения в отдельную единицу трансляции. клиент включает заголовок и видит интерфейс.

консольный вывод программы:

```bash


Name: Tom	Age: 38
```

разделение сокращает определение класса до списка членов и облегчает чтение интерфейса, особенно когда тела длинные.

при той же организации доступно делегирование конструкторов. один конструктор передаёт инициализацию другому конструктору того же класса, и именно целевой конструктор инициализирует члены. тело делегирующего конструктора выполняется после возврата из целевого. в списке инициализации делегирующий вызов стоит один: вместе с прямой инициализацией членов его не записывают.

```cpp


#include <iostream>

#include <string>



class Person 

{

private:

    std::string name;

    unsigned age;

public:

    Person(std::string p_name, unsigned p_age);

    Person(std::string p_name);

    void print();

};

// конструктор

Person::Person(std::string p_name, unsigned p_age)

{ 

    name = p_name; 

    age = p_age;

}

// делегирование конструктора

Person::Person(std::string p_name) : Person(p_name, 18)

{  }



void Person::print() 

{

    std::cout << "Name: " << name << "\tAge: " << age << std::endl;

}

int main()

{

    Person tom{"Tom", 39};

    tom.print();    // Name: Tom   Age: 39

    Person bob{"Bob"};

    bob.print();    // Name: Bob   Age: 18

}
```
