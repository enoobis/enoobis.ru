цикл повторяет набор инструкций, пока выполняется заданное условие. в c++ есть три вида циклов:

- `for`
- `while`
- `do...while`

различие касается момента проверки условия и того, какие части заголовка отвечают за инициализацию, проверку и шаг. ниже разобран цикл с проверкой до тела.

### цикл while

цикл `while` выполняет тело, пока условие истинно, то есть пока выражение условия даёт `true`. форма записи:

```cpp


while(условие)

{

	// выполняемые действия

}
```

после служебного слова `while` в скобках стоит условное выражение типа `bool`. в фигурных скобках записано тело. пока условие равно `true`, инструкции тела выполняются снова. когда условие становится `false`, тело больше не выполняется и управление переходит к следующей инструкции после цикла. если условие ложно уже при входе, тело не выполнится ни разу: проверка предшествует телу.

пример печатает квадраты чисел от 1 до 9:

```c


#include <iostream>



int main()

{	

	int i {1};

	while(i < 10)

	{

		std::cout << i << " * " << i << " = " << i * i << std::endl;

		i++;

	}

}
```

условие цикла записано как `i < 10`. переменная `i` инициализирована значением 1. на каждом шаге тело выводит произведение `i * i` и затем увеличивает `i` на единицу. когда `i` становится равным 10, сравнение `i < 10` даёт `false`, и цикл завершается. без инкремента `i++` условие оставалось бы истинным, и цикл не закончился бы. тело и условие работают с одним и тем же объектом `i`: условие читает его, тело изменяет.
