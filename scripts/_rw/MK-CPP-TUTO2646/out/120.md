**объект функции** (function object), или функтор, является объектом, который вызывается как функция. вызов записывается оператором **()**. простейший пример:

```cpp
#include <iostream>
#include <string>
 
class Print
{
public:
    void operator()(const std::string& message) const 
    {
        std::cout << message << std::endl;
    }   
};

int main()
{
    Print print;    // определяем объект функции
    print("Hello"); // выполняем как функцию
    print("World");
}
```

класс `Print` определяет оператор `()`. у этой перегрузки один параметр типа строки, возвращаемый тип `void`. тело выводит переданную строку на консоль.

число параметров, их типы и тип результата задаются задачей. жёсткого шаблона сигнатуры у оператора вызова нет. определить его можно только как нестатическую функцию-член класса: запись `obj(args)` по семантике языка есть вызов члена `obj`. свободная функция и статическая функция-член оператором `()` не становятся.

далее создаётся объект этого класса и вызывается с одним аргументом, как обычная функция.

```cpp
print("Hello");
```

другой пример:

```cpp
#include <iostream>

class Sum
{
public:
    int operator()(int x, int y) const  { return x + y; }   
};

int main()
{
    Sum sum;    // определяем объект функции
	int result {sum(2, 3)};		// вызываем объект функции
    std::cout << result << std::endl;    // 5
    std::cout << sum(5, 3) << std::endl;    // 8
    std::cout << sum(12, 13) << std::endl;  // 25
}
```

класс `Sum` определяет оператор `()`, который принимает два числа и возвращает их сумму. результат имеет тип `int`, поэтому его можно сохранить в переменной типа `int` и вообще употреблять везде, где ожидается `int`. каждый вызов `sum(a, b)` является обычным вызовом функции-члена и подчиняется тем же правилам перегрузки.

объект-функция может хранить состояние. этим он отличается от указателя на функцию: указатель адресует код и не несёт полей экземпляра, а функтор является обычным объектом со своей памятью. алгоритмы стандартной библиотеки принимают произвольный вызываемый объект именно поэтому.

```cpp
#include <iostream>
 
class Id
{
public:
    unsigned operator()()
    {
        return ++id;
    } 
private:
    unsigned id{};
};

int main()
{
    Id id;    // определяем объект функции
    std::cout << id() << std::endl;     // 1
    std::cout << id() << std::endl;     // 2
    std::cout << id() << std::endl;     // 3
}
```

объект `Id` при каждом вызове увеличивает закрытое поле `id` и возвращает новое значение. оператор `()` здесь не константный: он меняет состояние экземпляра. начальное значение поля нулевое, поэтому последовательные вызовы дают 1, 2, 3. у другого объекта `Id` был бы собственный счётчик.
