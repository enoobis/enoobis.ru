функция может возвращать указатель на другую функцию. это уместно, когда набор исполняемых функций ограничен и выбрать одну из них нужно внутри промежуточной функции. набор вариантов и правило выбора сосредоточены в одном месте, а вызывающий код получает уже готовый адрес и вызывает функцию единообразно.

простейший пример:

```cpp


#include <iostream>

 

void goodmorning();

void goodevening();

void(*message(unsigned))();

 

int main()

{

    void(*action)(){message(10)};    // указатель на выбранную функцию

	// выполняем полученную функцию

    action();       				// Good Morning!

    action = message(16);   		// получаем новую функцию

    action();						// Good Evening!

}

 

void(*message(unsigned hour))()

{

    if (hour > 15)

        return goodevening;

    else

        return goodmorning;

}

void goodmorning()

{

    std::cout << "Good Morning!" << std::endl;

}

void goodevening()

{

    std::cout << "Good Evening!" << std::endl;

}
```

функция `message` по переданному числу возвращает либо `goodmorning`, либо `goodevening`. объявление:

```cpp
void(*message(unsigned hour))()
```

чтение декларатора идёт от имени. `message` есть функция с одним параметром типа `unsigned` (то есть `unsigned int`). фрагмент `(*message(unsigned hour))` как раз фиксирует это имя и список параметров. тип слева, `void`, есть тип результата той функции, указатель на которую `message` возвращает: и `goodmorning`, и `goodevening` имеют результат `void`. отдельные пустые скобки справа задают параметры возвращаемой функции. обе функции параметров не принимают, поэтому скобки пусты. эквивалентная запись с замыкающим возвращаемым типом, принятая в c++11, читается проще: `auto message(unsigned hour) -> void (*)();`. смысл тот же: результат есть указатель на функцию без параметров с результатом `void`.

имя функции обозначает указатель на неё, поэтому `message` возвращает нужную функцию, поставив её имя после `return`. адрес функции имеет статическую длительность хранения в том смысле, что код функции живёт всё время программы: возвращать его из локальной функции безопасно.

указатель на полученную функцию хранится в переменной `action`:

```cpp
void(*action)();
```

переменная есть указатель на функцию без параметров с результатом `void` и потому совместима с `goodmorning` и `goodevening`.

затем `message` вызывается, и указатель попадает в `action`:

```cpp
action = message(16);
```

через `action` полученную функцию вызывают:

```cpp
action();
```

в `message` передано число 16. условие `hour > 15` истинно, возвращается указатель на `goodevening`, и на консоль печатается `Good Evening!`. при аргументе 10 условие ложно, возвращается `goodmorning`, и печатается `Good Morning!`.

более сложный пример выбирает арифметическую операцию над двумя числами:

```cpp


#include <iostream>

 

int add(int, int);

int subtract(int, int);

int multiply(int, int);

int(*select(int))(int, int);

 

int main()

{

    int(*action)(int, int) {select(1)};  // получаем указатель на функцию add

    std::cout << action(8, 5) << std::endl; // 13



    action = select(2);  // получаем указатель на функцию subtract

    std::cout << action(8, 5) << std::endl; // 3



    action = select(3);  // получаем указатель на функцию multiply

    std::cout << action(8, 5) << std::endl; // 40

}

 

int(*select(int choice))(int, int)

{

    // возвращаем нужную функцию в зависимости от choice

    switch (choice)

    {

        case 2:

            return subtract;

        case 3:

            return multiply;

        default:

            return add;

    }

}

int add(int x, int y)

{

    return x + y;

}

int subtract(int x, int y)

{

    return x - y;

}

int multiply(int x, int y)

{

    return x * y;

}
```

предполагается, что для выполнения выбирается одна из трёх функций: `add`, `subtract`, `multiply`. выбранная функция выполняет действие над числами `x` и `y`.

выбор делает `select()`. она получает условный номер функции и возвращает указатель на выбранную функцию.

все выбираемые функции имеют прототип вида:

```cpp
int add(int, int);
```

прототип `select` согласован с этим прототипом:

```cpp
int (*select(int))(int, int)
```

в начале стоит тип результата той функции, на которую указывает возвращаемый указатель, то есть `int`. затем в скобках записана сама `select` со списком параметров: `(*select(int))`. затем идёт спецификация параметров функции, на которую указывает результат. `add`, `subtract` и `multiply` принимают два значения типа `int`, поэтому спецификация есть `(int, int)`. целиком тип `select` есть «функция от `int`, возвращающая указатель на функцию `(int, int) -> int`».

выбор внутри `select` записан конструкцией `switch`:

```cpp


int(*select(int choice))(int, int)

{

    // возвращаем нужную функцию в зависимости от choice

    switch (choice)

    {

        case 2:

            return subtract;

        case 3:

            return multiply;

        default:

            return add;

    }

}
```

метки 2 и 3 возвращают `subtract` и `multiply`. любая другая метка, включая значение по умолчанию, возвращает `add`. `return` здесь возвращает адрес функции, а не результат арифметики.

в `main()` вызывается `select` с заданным числом, и результат сохраняется как указатель:

```cpp


int(*action)(int, int) {select(1)};  // получаем указатель на функцию add
```

после этого функцию вызывают через указатель. она ждёт два значения типа `int`, их и передают, а результат печатают:

```cpp
std::cout << action(8, 5) << std::endl; // 13
```

в предыдущем примере `select` при любом числе возвращает указатель на одну из функций: ветвь `default` закрывает все остальные значения. выбор можно сузить и для номера вне диапазона вернуть нулевой указатель:

```cpp


#include <iostream>

 

int add(int, int);

int subtract(int, int);

int multiply(int, int);

int(*select(int))(int, int);

 

int main()

{

    int(*action)(int, int) {select(14)};  // получаем указатель на функцию

    if(action)  // если не равно nullptr

    {

        std::cout << action(8, 5) << std::endl;

    }

    else

    {

        std::cout << "Undefined" << std::endl;

    }

}

 

int(*select(int choice))(int, int)

{

    int (*actions[])(int x, int y){ add, subtract, multiply };

    // возвращаем нужную функцию в зависимости от choice

    // возвращаем нужную функцию

    if (choice >0 && choice<4)

        return actions[choice - 1];

    else

        return nullptr;

}

int add(int x, int y){ return x + y; }

int subtract(int x, int y) {return x - y;}

int multiply(int x, int y) { return x * y; }
```

доступные функции лежат в массиве `actions`. это массив указателей на функции, локальный для данного вызова `select`. если передан номер 1, 2 или 3, из массива возвращается соответствующая функция: индекс равен `choice - 1`. если номер иной, возвращается `nullptr`:

```cpp


if (choice >0 && choice<4)

    return actions[choice - 1];

else

    return nullptr;
```

возвращаемое значение есть адрес функции (`add`, `subtract` или `multiply`), а не адрес элемента локального массива. массив после выхода из `select` уничтожается, но код функций остаётся, и возвращённый указатель остаётся действительным. `nullptr` действительного адреса не содержит.

перед вызовом указатель проверяют на `nullptr`. вызов нулевого указателя на функцию есть неопределённое поведение, поэтому ветвь с вызовом выполняется только при ненулевом значении:

```cpp


int(*action)(int, int) {select(14)};  // получаем указатель на функцию

if(action)  // если не равно nullptr

{

    std::cout << action(8, 5) << std::endl;

}

else

{

    std::cout << "Undefined" << std::endl;

}
```

при аргументе 14 условие `choice > 0 && choice < 4` ложно, `select` возвращает `nullptr`, проверка `if (action)` не проходит, и печатается `Undefined`.
