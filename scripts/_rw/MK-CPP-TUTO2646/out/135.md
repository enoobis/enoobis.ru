начиная со стандарта c++20 в язык c++ добавлены **concepts** (концепты). концепты устанавливают ограничения для параметров шаблонов, как шаблонов функций, так и шаблонов класса, и дают ограничению имя. имя участвует в перегрузке и в тексте диагностики.

концепт фактически представляет шаблон именованного набора ограничений, где каждое ограничение предписывает одно или несколько требований для одного или нескольких параметров шаблона. в общем случае он имеет следующий вид:

```cpp


template <параметры>

concept имя_концепта = ограничения;
```

список параметров концепта содержит один или несколько параметров шаблона. во время компиляции компилятор оценивает концепты, чтобы определить, удовлетворяет ли набор аргументов заданным ограничениям. результат известен до порождения кода и может управлять выбором перегрузки.

`ограничения` представляют условные выражения, которые возвращают значение типа **bool**. если параметр типа удовлетворяет условию, возвращается `true`.

простейший пример:

```cpp


template <typename T>

concept size = sizeof(T) <= sizeof(int);
```

здесь определён концепт `size`. его смысл в том, что тип, который передаётся через параметр `T`, должен удовлетворять условию `sizeof(T) <= sizeof(int)`. физический размер объектов типа `T` не должен быть больше размера значений типа `int`. `sizeof` является константным выражением, поэтому такая проверка допустима внутри концепта.

чтобы определить, соответствует ли определённый тип концепту, используется выражение концепта: имя концепта, после которого в угловых скобках указываются аргументы для параметров шаблона.

```cpp
имя_концепта<значения_для_параметров>
```

например, проверка концепта `size`:

```cpp


#include <iostream>



template <typename T>

concept size = sizeof(T) <= sizeof(int);



int main()

{

    std::cout << std::boolalpha << size<unsigned int> << std::endl;      // true

    std::cout << std::boolalpha << size<char> << std::endl;     // true

    std::cout << std::boolalpha << size<double> << std::endl;   // false 

}
```

выражения `size<unsigned int>` и `size<char>` удовлетворяют ограничению концепта: типы `unsigned int` и `char` по размеру не превосходят размер типа `int` или меньше его. эти выражения возвращают **true**. выражение `size<double>` ограничению концепта не соответствует: размер типа `double` больше размера типа `int`, поэтому выражение возвращает **false**. на распространённых платформах `double` занимает 8 байт, а `int` 4. стандарт фиксирует отношения размеров, конкретные значения `sizeof` зависят от реализации.

одни концепты могут основываться на других концептах. например:

```cpp


#include <iostream>



template <typename T>

concept small_size = sizeof(T) < sizeof(int);

template <typename T>

concept big_size = sizeof(T) > sizeof(long);



template <typename T>

concept size = small_size<T> || big_size<T>;



int main()

{

    std::cout << std::boolalpha << size<unsigned int> << std::endl; // false

    std::cout << std::boolalpha << size<char> << std::endl;         // true

    std::cout << std::boolalpha << size<double> << std::endl;       // true

}
```

вначале определяются два простейших концепта. `small_size` требует, чтобы размер типа был меньше размера типа `int`. концепт `big_size` требует, чтобы размер типа был больше размера типа `long`. с помощью стандартных логических операций **&&** и **||** ограничения объединяются. концепт `size` требует, чтобы тип `T` удовлетворял либо условию `small_size<T>`, либо условию `big_size<T>`:

```cpp
concept size = small_size<T> || big_size<T>;
```

концепты нужны как ограничения для шаблонов. именованное ограничение подставляется в объявление шаблона и проверяется при каждом обращении:

```cpp


#include <iostream>



template <typename T>

concept size = sizeof(T) <= sizeof(int);



template <typename T> requires size<T> // в качестве ограничения применяется size

T sum(T a, T b){ return a + b;}



int main()

{

    std::cout << sum(10, 3) << std::endl;       // 13

    //std::cout << sum(10.6, 3.7) << std::endl; // ! Ошибка

}
```

здесь определён концепт `size`, согласно которому размер типа `T` должен быть равен или меньше размера типа `int`.

при определении шаблона функции `sum` в качестве ограничения применяется концепт `size`:

```cpp
template <typename T> requires size<T>
```

значения, которые передаются в эту функцию, должны иметь тип, размер которого не больше размера типа `int`. вызов с аргументами типа `int` корректен:

```cpp
sum(10, 3)
```

значения типа `double` передать нельзя: эти значения занимают в памяти 8 байт, больше, чем значения типа `int`:

```cpp
sum(10.6, 3.7)
```

последняя строка в коде закомментирована. если её раскомментировать, на этапе компиляции возникнет ошибка проверки ограничения.

### сокращённый синтаксис

c++ позволяет сократить синтаксис применения концепта:

```cpp


template <size T> // в качестве ограничения применяется size

T sum(T a, T b){ return a + b;}
```

концепт указывается в угловых скобках вместо слова `typename`, перед названием параметра типа. запись `template <size T>` равносильна `template <typename T> requires size<T>`.

### встроенные концепты

приведённые концепты иллюстрируют, как концепты определяются и работают, и сами по себе прикладного смысла почти не имеют. в стандартной библиотеке c++ есть большой набор встроенных концептов для разных ситуаций. все эти концепты определены в заголовочном файле `<concepts>`.

например, встроенный концепт `std::same_as<T, K>` проверяет, представляют ли `T` и `K` один и тот же тип. ниже нужен шаблон функции, которая складывает числа `int` и `double`:

```cpp


#include <iostream>

#include <concepts>



template <typename T>

concept sum_types = std::same_as<T, int> || std::same_as<T, double>;



template <sum_types T>

T sum(T a, T b){ return a + b;}



int main()

{

    std::cout << sum(10, 3) << std::endl;       // 13

    std::cout << sum(10.6, 3.2) << std::endl;   // 13.8

}
```

здесь ограничение

```cpp
std::same_as<T, int> || std::same_as<T, double>
```

устанавливает, что тип `T` должен представлять либо `int`, либо `double`.

для той же задачи подходит и другой концепт, `std::convertible_to<K, T>`. он проверяет, можно ли преобразовать значение типа `K` в значение типа `T`. значение `int` может быть неявно преобразовано в `double`. предыдущий пример переписывается так:

```cpp


#include <iostream>

#include <concepts>



template <typename T>

concept sum_types = std::convertible_to<T, double>; // T должен поддерживать преобразование в double



template <sum_types T>

T sum(T a, T b){ return a + b;}



int main()

{

    std::cout << sum(10, 3) << std::endl;       // 13

    std::cout << sum(10.6, 3.2) << std::endl;   // 13.8

}
```

ограничение `std::convertible_to<T, double>` допускает любой тип `T`, который неявно приводится к `double`, в том числе сам `double` и целые типы. проверка концепта смотрит на допустимость преобразования в контексте копирования. совпадение типов при этом не требуется.
