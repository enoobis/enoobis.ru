идиома move-and-swap, перемещение с обменом, применяется в операторе присваивания с перемещением. она снимает дублирование кода деструктора и конструктора, который забирает ресурс: в этой идиоме ресурс забирает конструктор перемещения, а освобождает прежний ресурс деструктор временного объекта. оператор присваивания сам эти два фрагмента не расписывает заново. последовательность такая:

- для перемещаемого объекта создаётся объект конструктором перемещения
- текущий объект заменяется этим объектом. если при построении на каком-то шаге возникла ошибка, текущий объект не заменяется

общая форма `move-and-swap` выглядит так:

```cpp


MyClass& MyClass::operator=(MyClass&& rhs) noexcept

{

 	MyClass moved(std::move(rhs)); // получаем перемещаемый объект

 	swap(moved); 				  // выполняем обмен значениями

 	return *this; // возвращаем текущий объект

}
```

параметр `MyClass&&` привязывается к rvalue. имя параметра внутри функции является lvalue, даже если его тип записан как rvalue-ссылка, поэтому `std::move(rhs)` приводит `rhs` к rvalue-ссылке и тем самым выбирает конструктор перемещения. `std::move` сам данные не переносит: это приведение категории значения. `swap` затем обменивает построенный временный объект с `*this`. спецификатор `noexcept` у оператора согласован с тем, что и конструктор перемещения, и `swap` не выпускают исключений. временный объект при уничтожении освобождает ресурс, которым раньше владел `*this`. схема та же, что у копирования и замены: модификация цели откладывается до успешного построения временного объекта, а обмен объявлен непоражающим.

простейшая реализация на классе сообщения:

```cpp


#include <iostream> 

#include <string>



class Message

{

public:

	Message(std::string data) : text{new std::string(data)}	// выделяем память

	{

		id = ++counter;

		std::cout << "Create message " << id << std::endl;

	}

	// конструктор копирования

	Message(const Message& copy) : Message{copy.getText()}

	{

		std::cout << "Copy  message " << copy.id << " to " << id << std::endl;

	}

	// конструктор перемещения

	Message(Message&& moved) noexcept : text{moved.text} 

	{

		id = ++counter;

		std::cout << "Move message " << moved.id << " to " << id << std::endl;

		moved.text = nullptr;

	}

	~Message()

	{ 

		std::cout << "Delete message "  << id << std::endl;

		delete text;	// освобождаем память

	}

	// присваивание с копированием

	Message& operator=(const Message& copy)

	{

		std::cout << "Copy assign message " << copy.id << " to " << id << std::endl;

		if (&copy != this) 	// избегаем самоприсваивания

		{

			*text = copy.getText();

		}

		return *this; 

	}

	// присваивание с перемещением

	Message& operator=(Message&& moved) noexcept

	{

		std::cout << "Move assign message " << moved.id << " to " << id << std::endl;

		Message temp{std::move(moved)};	// вызываем конструктор перемещения

		swap(temp);						// обмен значениями

		return *this; // возвращаем текущий объект

	}

	// функция обмена

	void swap(Message& other) noexcept

	{

		std::swap(text, other.text);    // обмениваем два указателя

	}

	std::string& getText() const { return *text; }

	unsigned getId() const {return id;}

private:

	std::string* text;	// текст сообщения

	unsigned id{};	// номер сообщения

	static inline unsigned counter{};	// статический счетчик для генерации номера объекта

};

int main()

{

	Message mes{""};

	mes = Message{"hello"};		// присваивание с перемещением

	std::cout << "Message " << mes.getId() << ": " << mes.getText() << std::endl;

}
```

класс `Message` хранит текст в динамической памяти, доступ к строке идёт через указатель `text`. для наглядности владение выражено обычным указателем, без интеллектуального указателя: захват и отдача памяти видны в конструкторе и деструкторе. чтобы был виден весь порядок создания, копирования, перемещения и удаления, в классе есть статическая переменная `counter`. она увеличивается с каждым новым объектом, и текущее значение записывается в `id`, номер сообщения.

```cpp


std::string* text;	// текст сообщения

unsigned id{};	// номер сообщения

static inline unsigned counter{};
```

`static inline` у члена `counter` задаёт и объявление, и определение прямо в классе. это форма c++17: счётчик один на все объекты `Message`.

в конструкторе `Message` выделяется динамическая память под объект `std::string` и назначается номер:

```cpp


Message(std::string data) : text{new std::string(data)}	// выделяем память

{

	id = ++counter;

	std::cout << "Create message " << id << std::endl;

}
```

инициализатор `text{new std::string(data)}` копирует символы аргумента в новую строку в куче. если `new` выбросит `std::bad_alloc`, объект создан не будет и тело конструктора не начнётся. номер назначается уже в теле, после успешного выделения, и на консоль печатается создание.

в деструкторе память освобождается:

```cpp


~Message()

{ 

	std::cout << "Delete message "  << id << std::endl;

	delete text;	// освобождаем память

}
```

`delete text` парный к `new` выражения, которым строка создавалась. для нулевого указателя `delete` определён и ничего не делает, поэтому деструктор безопасен и после перемещения, когда в `text` записан `nullptr`. перед освобождением деструктор печатает номер уничтожаемого сообщения.

конструктор перемещения переносит в текущий объект указатель на строку из перемещаемого объекта:

```cpp


Message(Message&& moved) noexcept : text{moved.text} 

{

	id = ++counter;

	std::cout << "Move message " << moved.id << " to " << id << std::endl;

	moved.text = nullptr;

}
```

список инициализации забирает адрес `moved.text`, затем источник обнуляется. после этого у одной строки не остаётся двух живых владельцев: иначе два деструктора выполнили бы `delete` по одному адресу. новый объект получает собственный `id` через `++counter`, номер источника не копируется. спецификатор `noexcept` соответствует телу: копирование указателя и увеличение счётчика исключений не порождают. печать показывает номер источника и номер нового объекта.

в операторе присваивания с перемещением используется идиома move-and-swap:

```cpp


Message& operator=(Message&& moved) noexcept

{

	std::cout << "Move assign message " << moved.id << " to " << id << std::endl;

	Message temp{std::move(moved)};	// вызываем конструктор перемещения

	swap(temp);						// обмен значениями

	return *this; // возвращаем текущий объект

}

// функция обмена

void swap(Message& other) noexcept

{

	std::swap(text, other.text);    // обмениваем два указателя

}
```

сначала создаётся временный `Message`, в который перемещаются данные источника. имя `moved` является lvalue, поэтому без приведения был бы выбран конструктор копирования. приведение делает стандартный шаблон `std::move`, он превращает `moved` в rvalue:

```cpp
std::move(moved)
```

затем `swap` обменивает текущий объект и временный. внутри вызывается стандартная `std::swap`, и обмениваются указатели двух объектов:

```cpp
std::swap(text, other.text);
```

после обмена `*this` владеет строкой, пришедшей из источника, а временный объект владеет прежней строкой цели и освободит её в своём деструкторе. отдельного `delete` в операторе присваивания нет: освобождение остаётся в одном месте, в деструкторе. копирующее присваивание в том же классе устроено иначе. оно пишет `*text = copy.getText()` и буфер не перевыделяет. условие `&copy != this` пропускает запись при самоприсваивании. в `main` эта перегрузка не выбирается: справа стоит временный объект, и лучшим соответствием является параметр `Message&&`.

в функции `main` оператор присваивания применяется так:

```cpp


int main()

{

	Message mes{""};

	mes = Message{"hello"};		// присваивание с перемещением

	std::cout << "Message " << mes.getId() << ": " << mes.getText() << std::endl;

}
```

консольный вывод программы:

```bash


Create message 1

Create message 2

Move assign message 2 to 1

Move message 2 to 3

Delete message 3

Delete message 2

Message 1: hello

Delete message 1
```

переменная `mes` представляет объект `Message` с номером 1: его создаёт выражение `Message mes{""}`, на консоли это строка `Create message 1`. выражение `Message{"hello"}` создаёт объект с номером 2, строка `Create message 2`.

при выполнении присвоения

```cpp
mes = Message{"hello"};
```

выбирается оператор присваивания с перемещением: справа rvalue. первая печать оператора, `Move assign message 2 to 1`, показывает номер источника и номер цели до обмена. затем вызывается конструктор перемещения. он создаёт объект `Message` с номером 3 и забирает в него указатель из второго объекта:

```cpp
Message temp{std::move(moved)};
```

на консоли этому соответствует `Move message 2 to 3`. дальше указатели объектов 1 и 3 обмениваются. поле `id` в `swap` не участвует, поэтому объект 1 сохраняет номер 1, а строка `"hello"` оказывается у него. объект 3 после обмена владеет прежней пустой строкой объекта 1. локальный `temp` уничтожается при выходе из оператора, это `Delete message 3`. объект 2 к этому моменту уже содержит `text == nullptr`: ресурс забрал объект 3. временный объект полного выражения уничтожается следом, `delete` по нулевому указателю ничего не делает, на консоли это `Delete message 2`. затем печатается `Message 1: hello`: номер взят из `getId()`, текст из `getText()`. при выходе из `main` уничтожается `mes`, последняя строка вывода: `Delete message 1`.
