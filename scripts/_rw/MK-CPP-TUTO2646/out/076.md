**перегрузка операторов** (operator overloading) задаёт для объектов класса смысл встроенных операторов, в том числе `+`, `-` и `*`. для этого определяется функция, в имени которой стоят служебное слово `operator` и символ операции. функцию оператора объявляют членом класса либо свободной функцией вне класса.

перегружаются только операторы, уже существующие в c++. ввести новый символ операции нельзя. число операндов, ассоциативность и приоритет фиксированы языком и перегрузкой не меняются.

если оператор задан свободной функцией, число параметров совпадает с числом операндов. у унарного оператора один параметр, у бинарного два. первый операнд передаётся первому параметру, второй операнд второму. хотя бы один параметр должен иметь тип класса: иначе объявление не привязано к пользовательскому типу и языком не допускается. у оператора-члена неявный параметр `this` занимает место левого операнда бинарной операции и единственного операнда унарной, поэтому в списке параметров члена на один аргумент меньше, чем у свободной функции.

формальное объявление операторов как функций-членов класса:

```cpp


// бинарный оператор

ReturnType operator Op(Type right_operand);

// унарный оператор

ClassType& operator Op();
```

формальное объявление операторов как функций, которые не являются членами класса:

```cpp


// бинарный оператор

ReturnType operator Op(const ClassType& left_operand, Type right_operand);

// альтернативное определение, где класс, для которого создается оператор, представляет правый операнд

ReturnType operator Op(Type left_operand, const ClassType& right_operand);

// унарный оператор

ClassType& operator Op(ClassType& obj);
```

`ClassType` обозначает тип, для которого определяется оператор. `Type` обозначает тип другого операнда: он может совпадать с типом класса или отличаться от него. `ReturnType` обозначает тип результата и тоже может совпадать с типом операнда либо отличаться. `Op` обозначает саму операцию.

ниже класс `Counter` хранит целое число.

```cpp


#include <iostream>

 

class Counter

{

public:

    Counter(int val)

    {

        value =val;

    }

    void print() 

    {

        std::cout << "Value: " << value << std::endl;

    }

    Counter operator + (const Counter& counter) const

    {

        return Counter{value + counter.value};

    }

private:

    int value;

};



int main()

{

    Counter c1{20};

    Counter c2{10};

    Counter c3 = c1 + c2;

    c3.print();   // Value: 30

}
```

в классе `Counter` определён оператор сложения. его задача состоит в том, чтобы сложить два объекта `Counter`.

```cpp


Counter operator + (const Counter& counter) const

{

    return Counter{value + counter.value};

}
```

текущий объект, доступный через неявный параметр `this`, представляет левый операнд. объект, переданный параметром `counter`, представляет правый операнд. параметр объявлен константной ссылкой, однако константность ссылки для перегрузки не обязательна: она лишь не даёт изменить правый операнд внутри функции. функция оператора объявлена константной, и это тоже не требование языка, а обещание, что `*this` не меняется. результат оператора сложения представляет собой новый объект `Counter`, поле `value` которого равно сумме полей `value` обоих операндов. семантика операции вычислительная: исходные операнды сохраняют состояние, сумма живёт в отдельном объекте.

после определения оператора два объекта `Counter` складываются обычным выражением.

```cpp


Counter c1{20};

Counter c2{10};

Counter c3 {c1 + c2};

c3.print();   // Value: 30
```

ту же функцию можно определить вне класса.

```cpp


#include <iostream>

 

class Counter

{

public:

    Counter(int val)

    {

        value =val;

    }

    void print() 

    {

        std::cout << "Value: " << value << std::endl;

    }

    int value;	// к приватным переменным внешняя функция оператора не может обращаться

};

// определяем оператор сложения вне класса

Counter operator + (const Counter& c1, const Counter& c2) 

{

    return Counter{c1.value + c2.value};

}

 

int main()

{

    Counter c1{20};

    Counter c2{10};

    Counter c3 {c1 + c2};

    c3.print();   // Value: 30

}
```

бинарный оператор в виде свободной функции принимает два параметра. первый параметр представляет левый операнд, второй параметр правый.

по сравнению с предыдущим вариантом здесь два отличия. свободная функция не входит в область доступа класса и не читает закрытые поля, поэтому для них обычно объявляют отдельные функции доступа. в примере поле `value` сделано открытым, чтобы выражение `c1.value + c2.value` было корректно. другое решение состоит в объявлении оператора дружественной функцией: спецификатор `friend` открывает свободной функции доступ к закрытым членам и не включает поле в открытый интерфейс. второе отличие: свободная функция не бывает константной, потому что квалификатор `const` относится к `this`, которого у свободной функции нет. объявление оператора внутри класса сохраняет доступ к закрытому состоянию и позволяет пометить функцию как `const`.

возвращать объект того же класса не обязательно. тип результата выбирается по смыслу операции, и для одного символа допустимы дополнительные перегрузки.

```cpp


#include <iostream>

 

class Counter

{

public:

    Counter(int val)

    {

        value =val;

    }

    void print() 

    {

        std::cout << "Value: " << value << std::endl;

    }

    Counter operator + (const Counter& counter) const

    {

        return Counter{value + counter.value};

    }

    int operator + (int number) const

    {

        return value + number;

    }

private:

    int value;

};



 

int main()

{

    Counter counter{20};

    int number = counter + 30;

    std::cout << number << std::endl;   // 50

}
```

вторая перегрузка оператора сложения складывает объект `Counter` с числом и возвращает число. при вызове функции-члена левый операнд имеет тип `Counter`, правый операнд имеет тип `int`. выбор перегрузки выполняется по типам операндов во время компиляции, по тем же правилам, что и для обычных перегруженных функций.

форму оператора определяют правила языка и то, меняет ли операция объект. операторы присваивания, индексирования (`[]`), вызова (`()`) и доступа к члену по указателю (`->`) определяют только как функции-члены класса: стандарт требует форму члена, поскольку левый операнд обязан быть объектом этого класса. операторы, которые изменяют состояние объекта или непосредственно с ним связаны (инкремент, декремент), обычно тоже определяют как члены. операторы выделения и освобождения памяти (`new`, `new[]`, `delete`, `delete[]`) определяют свободными функциями либо статическими членами класса. вызов выполняется вне времени жизни размещаемого объекта, параметра `this` у этого объекта нет, и функция подменяет глобальную функцию распределения для выбранного типа. остальные операторы допустимо определять и членами, и свободными функциями. свободная форма уместна, когда левый операнд сам по себе не имеет типа класса и к этому типу его приводит неявное преобразование.

### операторы сравнения

результатом операторов сравнения (`==`, `!=`, `<`, `>`) обычно является значение типа `bool`. для типа `Counter` эти операторы задаются так:

```cpp


#include <iostream>

 

class Counter

{

public:

    Counter(int val)

    {

        value =val;

    }

    void print() 

    {

        std::cout << "Value: " << value << std::endl;

    }

    bool operator == (const Counter& counter) const

    {

        return value == counter.value;

    }

    bool operator != (const Counter& counter) const

    {

        return value != counter.value;

    }

    bool operator > (const Counter& counter) const

    {

        return value > counter.value;

    }

    bool operator < (const Counter& counter) const

    {

        return value < counter.value;

    }

private:

    int value;

};



 

int main()

{

    Counter c1(20);

    Counter c2(10);

    bool b1 = c1 == c2;     // false

    bool b2 = c1 > c2;   // true

 

    std::cout << "c1 == c2 = " << std::boolalpha << b1 << std::endl;    // c1 == c2 = false

    std::cout << "c1 > c2 = " << std::boolalpha << b2 << std::endl;     // c1 > c2 = true

}
```

если сравнение сводится к полям класса, для операторов `==` и `!=` достаточно реализации по умолчанию, которую запрашивают служебным словом `default`.

```cpp


#include <iostream>

 

class Counter

{

public:

    Counter(int val)

    {

        value =val;

    }

    void print() 

    {

        std::cout << "Value: " << value << std::endl;

    }

    bool operator == (const Counter& counter) const = default;

    bool operator != (const Counter& counter) const = default;

private:

    int value;

};



 

int main()

{

    Counter c1(20);

    Counter c2(10);

    bool b1 = c1 == c2;     // false

    bool b2 = c1 != c2;       // true

 

    std::cout << "c1 == c2 = " << std::boolalpha << b1 << std::endl;    // c1 == c2 = false

    std::cout << "c1 != c2 = " << std::boolalpha << b2 << std::endl;     // c1 != c2 = true

}
```

для оператора `==` объявление выглядит так:

```cpp
bool operator == (const Counter& counter) const = default;
```

по умолчанию сравниваются все поля класса, для которых определён оператор `==`. если значения всех таких полей равны, оператор возвращает `true`. механизм относится к c++20: компилятор порождает почленное сравнение в порядке объявления членов. при определённом `operator==` оператор `operator!=` можно запросить через `default`, и он вычисляется как отрицание равенства.

### операторы присвоения

оператор присвоения обычно возвращает ссылку на свой левый операнд:

```cpp


#include <iostream>

 

class Counter

{

public:

    Counter(int val)

    {

        value =val;

    }

    void print() 

    {

        std::cout << "Value: " << value << std::endl;

    }

    // оператор присвоения

    Counter& operator += (const Counter& counter)

    {

        value += counter.value;

        return *this;   // возвращаем ссылку на текущий объект

    }

private:

    int value;

};



int main()

{

    Counter c1{20};

    Counter c2{50};

    c1 += c2;

    c1.print();     // Value: 70

}
```

### унарные операции

унарные операции обычно возвращают новый объект, построенный по имеющемуся. для унарного минуса определение такое:

```cpp


#include <iostream>

 

class Counter

{

public:

    Counter(int val)

    {

        value =val;

    }

    void print() 

    {

        std::cout << "Value: " << value << std::endl;

    }

    // оператор унарного минуса

    Counter operator - () const

    {

        return Counter{-value};

    }

private:

    int value;

};



int main()

{

    Counter c1{20};

    Counter c2 = -c1;   // применяем оператор унарного минуса

    c2.print();     // Value: -20

}
```

операция унарного минуса возвращает новый объект `Counter`, в котором `value` равно значению `value` текущего объекта, умноженному на -1. константная функция-член читает состояние и строит отдельный результат, левый операнд остаётся прежним.

### операции инкремента и декремента

переопределение инкремента и декремента требует двух форм, префиксной и постфиксной. для типа `Counter` они задаются так:

```cpp


#include <iostream>

 

class Counter

{

public:

    Counter(int val)

    {

        value =val;

    }

    void print() 

    {

        std::cout << "Value: " << value << std::endl;

    }

    // префиксные операторы

    Counter& operator++ ()

    {

        value += 1;

        return *this;

    }

    Counter& operator-- ()

    {

        value -= 1;

        return *this;

    }

    // постфиксные операторы

    Counter operator++ (int)

    {

        Counter copy {*this};

        ++(*this);

        return copy;

    }

    Counter operator-- (int)

    {

        Counter copy {*this};

        --(*this);

        return copy;

    }

private:

    int value;

};



int main()

{

    Counter c1{20};

    Counter c2 = c1++;

    c2.print();       // Value: 20

    c1.print();       // Value: 21

    --c1;

    c1.print();       // Value: 20

}
```

префиксные операторы возвращают ссылку на текущий объект. сам объект доступен через указатель `this`:

```cpp


Counter& operator++ ()

{

    value += 1;

    return *this;

}
```

в теле функции записывается логика инкремента. здесь поле `value` увеличивается на 1, после чего ссылка на уже изменённый объект возвращается вызывающему коду. выражение `++c` и наблюдаемое состояние `c` после него совпадают.

постфиксные операторы возвращают значение объекта до инкремента, то есть предыдущее состояние. постфиксная форма возвращает копию, снятую до изменения:

```cpp


Counter operator++ (int)

{

    Counter copy {*this};

    ++(*this);

    return copy;

}
```

чтобы сигнатура постфиксной формы отличалась от префиксной, постфиксные версии получают дополнительный параметр типа `int`. язык использует его как различитель перегрузок, и в теле он обычно не читается. параметр остаётся доступен функции, если реализации нужно переданное значение. при вызове постфиксной формы компилятор подставляет в этот параметр 0.
