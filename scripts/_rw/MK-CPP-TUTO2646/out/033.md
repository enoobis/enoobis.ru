каждая переменная обладает **временем жизни** (lifetime) и **областью видимости** (scope). время жизни начинается в момент определения переменной и длится до её уничтожения: на этом интервале объект занимает память, и обращение к нему имеет определённую семантику. область видимости есть фрагмент текста программы, в котором имя объекта допустимо использовать. в c++ эти свойства независимы. область видимости устанавливается при компиляции и отвечает на вопрос, где имя видно. время жизни относится ко времени выполнения и отвечает на вопрос, как долго существует сам объект. обычно область видимости совпадает с блоком, заключённым в фигурные скобки. по месту определения объекты делят на глобальные и локальные. среди локальных отдельно выделяют автоматические: у них время жизни совпадает с выполнением блока.

### глобальные объекты

глобальная переменная определяется в файле программы вне любой функции и вне любого другого блока. имя с такой областью видимости доступно любой функции этого файла. по времени хранения глобальный объект относится к статическому классу памяти (static storage duration): он создаётся до входа в `main` и уничтожается только при завершении программы, после выхода из `main`.

если глобальная переменная не инициализирована явно, она получает нулевое значение. для объектов со статическим временем хранения это нулевая инициализация (zero-initialization): целые становятся нулём, указатели получают нулевой адрес, а агрегат обнуляется почленно. явный инициализатор, если он есть, применяется уже после этого шага.

ниже глобальная переменная определяется и используется из двух функций:

```cpp


#include <iostream>



int n{5};   // глобальная переменная



void print()

{

    n++;

    std::cout << "n=" << n << std::endl;

}

 

int main()

{

    print();                        // n=6

    n++;

    std::cout << "n=" << n << std::endl;   // n=7

}
```

здесь переменная `n` глобальна и доступна из любой функции единицы трансляции. любая из этих функций может изменить её значение: и `print`, и `main` обращаются к одному и тому же объекту. отдельных копий у этих вызовов нет. инкремент в `print` виден последующему инкременту в `main`, поэтому второй вывод показывает уже изменённое состояние.

### локальные объекты

объекты, которые создаются внутри блока (тело функции, тело цикла, составной оператор), называются **локальными**. имя такого объекта видно только в том блоке, где оно определено, и во вложенных в него блоках, пока его не скрыло другое объявление.

#### автоматические объекты

локальные объекты, которые существуют только на время выполнения своего блока, являются **автоматическими**. у них автоматическое время хранения (automatic storage duration). при входе в блок для такой переменной выделяется память, обычно в стековом кадре вызова, а при завершении блока память освобождается и объект уничтожается. повторный вход в блок создаёт новый объект. предыдущий к этому моменту уже уничтожен.

```cpp


#include <iostream>



void print()

{

    int n {5};  // локальная переменная, которая существует только в функции print

    std::cout << "n=" << n << std::endl;

    //так сделать нельзя, так как m определена в функции main

    // std::cout << "m=" << m << std::endl;

}

int main()

{

    int m {2};  // локальная переменная, которая существует только в функции main 

    std::cout << "m=" << m << std::endl;

    //так сделать нельзя, так как n определена в функции print

    // std::cout << "n=" << n << std::endl;

}
```

в функции `print` определена локальная переменная `n`. она автоматическая: с завершением блока `print` выделенная для неё память освобождается, и объект прекращает существование. в функции `main` определена автоматическая переменная `m`. вне своих функций эти имена недоступны. имя `n` нельзя использовать в `main`, потому что его область видимости ограничена `print`. имя `m` нельзя использовать в `print`, потому что оно ограничено `main`. попытка такого обращения есть ошибка компиляции: компилятор сообщает, что имя не найдено. до запуска такая запись не доходит.

вложенные области видимости задаются тем же способом, дополнительным блоком в фигурных скобках:

```cpp


#include <iostream>



int main()

{

    int n1 {2};  // область видимости - вся функция main 



    {

        int n2 {5};     // область видимости - блок кода

        std::cout << "n2=" << n2 << std::endl;

        n1++;   // переменная n1 доступна, т.к. определена во внешнем контексте - функции

    }   // конец блока функции - конец времени жизни переменной n2



    // так нельзя - переменная n2 из блока функции уже не существует

    // std::cout << "n2=" << n2 << std::endl;

    // переменная n1 доступна до конца функции

    std::cout << "n1=" << n1 << std::endl;

}   // конец блока функции - конец времени жизни переменной n1
```

для каждой области видимости видны объекты, определённые во внешней области, во внешнем контексте. глобальная область видимости внешняя по отношению к функции, поэтому функция может использовать глобальные переменные. функция есть внешний контекст для вложенного блока, поэтому этот блок может использовать переменную `n1`, определённую в функции вне блока. имена, введённые внутри блока, снаружи блока не видны: после закрывающей скобки имя `n2` уже не находится, хотя поиск имени идёт в окружающих областях. уничтожение `n2` происходит в конце его блока, уничтожение `n1` происходит в конце `main`. порядок уничтожения автоматических объектов обратен порядку завершения их инициализации.

### скрытие объектов

локальное объявление может скрыть (hide) объект с тем же именем, объявленный во внешнем контексте. внешний объект при этом продолжает существовать: из видимости уходит имя, а время жизни внешнего объекта продолжается. неквалифицированный поиск имени останавливается на ближайшем объявлении.

```cpp


#include <iostream>



int n {5};



int main()

{

	int n {10};

	std::cout << "n=" << n << std::endl;	// n=10

	

	{

		int n {20};

		std::cout << "n=" << n << std::endl; // n=20

	}

}
```

в программе три разных объекта с именем `n`. объявление `int n {10}` на уровне `main` скрывает глобальную переменную `n`. объявление `int n {20}` на уровне внутреннего блока скрывает переменную уровня `main`. каждый вывод читает тот объект, чьё имя найдено в текущем блоке: сначала 10, затем 20. глобальный объект со значением 5 в этих строках не участвует.

иногда нужно обратиться именно к глобальному объекту, минуя скрывающие его локальные имена. для этого перед именем ставится унарный оператор разрешения области видимости **::**. запись `::n` ищет имя в глобальном пространстве имён и не видит локальные объявления ни в `main`, ни во вложенном блоке.

```cpp


#include <iostream>



int n {5};



int main()

{

	int n {10};

	std::cout << "n=" << ::n << std::endl;	// n=5

	

	{

		int n {20};

		std::cout << "n=" << ::n << std::endl; // n=5

	}

}
```

оба вызова `::n` читают глобальный объект, поэтому оба дают значение 5. локальные объекты со значениями 10 и 20 по-прежнему существуют в своих блоках, но оператор `::` к ним не обращается.

### статические объекты

помимо автоматических, у локальных объектов есть форма со статическим временем хранения. она задаётся на уровне функции служебным словом **static**. автоматическая переменная создаётся и инициализируется при каждом входе в блок. статическая локальная переменная инициализируется один раз, когда управление впервые проходит через её объявление, а при следующих вызовах функции используется уже существующий объект с прежним значением. различие между локальной автоматической и локальной статической переменной лежит во времени жизни. область видимости у обеих одна: имя видно только внутри своего блока. автоматический объект живёт до конца выполнения блока, статический живёт до завершения программы. с c++11 инициализация локальной статической переменной защищена от гонки: если несколько потоков впервые входят в объявление одновременно, инициализацию выполняет один из них, остальные ожидают её завершения.

ниже та же функция задана с обычной автоматической переменной:

```cpp


#include <iostream>



void print()

{

    int n {1};

    std::cout << "n=" << n << std::endl;

    n++;

}

 

int main()

{

    print();

    print();

    print();

}
```

функция `print` вызывается трижды. при каждом вызове для переменной `n` снова выделяется память и снова выполняется инициализация значением 1. после выхода из `print` эта память освобождается. накопить инкремент негде: объект, который был увеличен, уже уничтожен к следующему вызову. поэтому значение при каждом входе одно и то же:

```consoletext


n=1

n=1

n=1
```

далее переменная `n` объявляется статической:

```cpp


#include <iostream>



void print()

{

    static int n {1};

    std::cout << "n=" << n << std::endl;

    n++;

}

 

int main()

{

    print();

    print();

    print();

}
```

к объявлению добавлено служебное слово `static`. по завершении `print` объект не уничтожается и занятая им память не освобождается: объект остаётся в статической памяти программы. следующий вызов видит значение, оставленное предыдущим, и инкремент накапливается. результат трёх вызовов иной:

```consoletext


n=1

n=2

n=3
```
