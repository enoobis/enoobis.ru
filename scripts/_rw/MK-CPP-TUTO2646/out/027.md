указатель есть объект, значением которого служит адрес другого объекта (переменной, константы, указателя) или функции. как и ссылка, указатель даёт косвенный доступ к объекту. в отличие от ссылки указатель можно перенаправить, можно хранить нулевое значение и можно сдвигать арифметикой адресов.

### определение указателя

в определении указывают тип объекта, на который указатель ссылается, и символ `*`:

```cpp
тип_данных* название_указателя;
```

сначала идёт тип адресуемого объекта и звёздочка, затем имя указателя. тип указателя есть `тип_данных*`, и в этот указатель записывают только адрес объекта совместимого типа.

указатель на объект типа `int`:

```cpp
int* p;
```

такой указатель хранит только адрес переменной типа `int`. пока ему не присвоен адрес, он не ссылается ни на какой объект и содержит неопределённое значение. чтение неинициализированного указателя есть неопределённое поведение. при запуске фрагмента ниже поток вывода может показать некоторый адрес в шестнадцатеричном виде, например `0x8`. шестнадцатеричная форма обычна для адресов:

```cpp


#include <iostream>



int main()

{

    int* p;

    std::cout << p << std::endl;

}
```

указатель инициализируют конкретным адресом или нулём. пустые фигурные скобки задают инициализацию значением:

```cpp


int* p{};
```

раз конкретное значение не указано, указатель получает число 0. это нулевое значение указателя, особый адрес, который ни на какой объект не указывает. то же значение задают явно константой `nullptr`. у `nullptr` тип `std::nullptr_t`, и оно преобразуется в нулевой указатель любого объектного типа:

```cpp


int* p{nullptr};
```

неинициализированный указатель язык допускает. тем не менее указатель инициализируют: либо конкретным адресом, либо нулём, как выше. нулевое значение позже позволяет проверить, что указатель ни на какой объект не ссылается. разыменование нулевого указателя тоже даёт неопределённое поведение, поэтому перед доступом по адресу нулевой указатель отличают от ненулевого.

положение звёздочки на смысл одного объявления не влияет. её ставят ближе к типу или ближе к имени, оба определения равноценны:

```cpp


int* p1{};

int *p2{};
```

звёздочка относится к одному имени, а не ко всему списку объявления. в записи `int* p, q` имя `q` имеет тип `int`, а не тип указателя.

размер значения указателя, то есть хранимого адреса, от типа адресуемого объекта не зависит. он зависит от платформы. на 32-разрядных платформах адрес занимает 4 байта, на 64-разрядных 8 байт:

```cpp


#include <iostream>



int main()

{

    int *pint{};

    double *pdouble{};

    std::cout << "*pint size: " << sizeof(pint) << std::endl;

    std::cout << "*pdouble size: " << sizeof(pdouble) << std::endl;

}
```

здесь объявлены указатели на разные типы, `int` и `double`. сами объекты этих типов имеют разный размер, обычно 4 и 8 байт. размеры значений указателей одинаковы. на 64-разрядной платформе оба указателя занимают 8 байт, на 32-разрядной занимали бы 4.

### получение адреса и оператор &

оператор `&` даёт адрес объекта, например адрес переменной. этот адрес присваивают указателю:

```cpp


int number {25};

int *pnumber {&number}; // указатель pnumber хранит адрес переменной number
```

выражение `&number` возвращает адрес переменной `number`, и переменная `pnumber` хранит именно этот адрес. тип переменной `number` есть `int`, и указатель на её адрес тоже имеет тип указателя на `int`: типы должны соответствовать. тот же указатель выводят через `auto`, тогда тип указателя выводится из инициализатора:

```cpp


int number {25};

auto *pnumber {&number}; // указатель pnumber хранит адрес переменной number
```

адрес переменной, выведенный на консоль, выглядит как шестнадцатеричное значение. конкретное число зависит от запуска: современные операционные системы сдвигают размещение автоматической памяти (aslr), поэтому от запуска к запуску адрес меняется.

```cpp


#include <iostream>



int main()

{

    int number {25};

    int *pnumber {&number}; // указатель pnumber хранит адрес переменной number

    std::cout << "number addr: " << pnumber << std::endl;

}
```

вывод программы на одном из запусков:

```bash


number addr: 0x1543bffc74
```

в каждом запуске адрес может отличаться. на показанном запуске машинный адрес переменной `number` равен `0x1543bffc74`: по этому адресу в памяти компьютера расположена переменная `number`. поскольку `number` имеет тип `int`, на большинстве архитектур она занимает следующие 4 байта (на конкретной архитектуре размер `int` может быть иным). переменная типа `int` последовательно занимает ячейки с адресами `0x1543bffc74`, `0x1543bffc75`, `0x1543bffc76`, `0x1543bffc77`.

указатель `pnumber` ссылается на адрес, по которому расположена переменная `number`, то есть на адрес `0x1543bffc74`.

сам указатель `pnumber` тоже объект и тоже имеет адрес. этот адрес получают оператором `&`, применённым уже к указателю:

```cpp


#include <iostream>



int main()

{

    int number {25};

    int *pnumber {&number}; // указатель pnumber хранит адрес переменной number

    std::cout << "number addr: " << pnumber << std::endl;

    std::cout << "pnumber addr: " << &pnumber << std::endl;

}
```

вывод программы на одном из запусков:

```bash


number addr: 0xe1f99ff7cc

pnumber addr: 0xe1f99ff7c0
```

переменная `number` расположена по адресу `0xe1f99ff7cc`, а указатель, который хранит этот адрес, расположен по адресу `0xe1f99ff7c0`. обе переменные имеют автоматическую продолжительность хранения и в этом запуске лежат в памяти рядом.

### получение значения по адресу

раз указатель хранит адрес, по этому адресу получают хранящееся там значение, то есть значение переменной `number`. для этого служит оператор `*`, оператор разыменования (indirection operator, dereference operator). результат операции есть lvalue объекта, на который указатель указывает:

```cpp


#include <iostream>



int main()

{

	int number {25};

    int *pnumber {&number};

	std::cout << "Address = " << pnumber<< std::endl;

	std::cout << "Value = " << *pnumber << std::endl;

}
```

пример консольного вывода:

```bash


Address = 0x44305ffd4c

Value = 25
```

значение, полученное разыменованием, присваивают другой переменной. выражение `*pn1` читает объект по адресу, который лежит в `pn1`:

```cpp


int n1 {25};

int *pn1 {&n1}; // указатель pn1 хранит адрес переменной n1

int n2 { *pn1}; // n2 получает значение, которое хранится по адресу в pn1

std::cout << "n2 = " << n2 << std::endl;	// n2=25
```

через указатель меняют и значение по хранимому адресу. запись `*px = 45` записывает в тот объект, на который `px` указывает:

```c


int x = 10;

int *px = &x;

*px = 45;

std::cout << "x = " << x << std::endl;	 // 45
```

по адресу, на который указывает указатель, расположена переменная `x`, поэтому меняется именно её значение.
