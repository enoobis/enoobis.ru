первая программа на c++ здесь собирается в linux, на ubuntu. компилятором служит самый распространённый вариант, g++ из набора gnu. многие дистрибутивы linux уже содержат g++, и им можно пользоваться сразу. если компилятора нет, он устанавливается из терминала:

```bash
sudo apt-get install g++
```

`apt-get` ставит пакет `g++`: драйвер c++, стандартную библиотеку libstdc++ и зависимости. команда выполняется от имени администратора через `sudo`.

наличие компилятора проверяется так:

```bash
g++ --version
```

должна отобразиться версия компилятора:

```bash
eugene@Eugene:~/Documents$ g++ --version
g++ (Ubuntu 13.2.0-4ubuntu3) 13.2.0
Copyright (C) 2023 Free Software Foundation, Inc.
This is free software; see the source for copying conditions.  There is NO

eugene@Eugene:~/Documents$
```

в файловой системе выбирается каталог для исходных текстов на c++, и в нём создаётся файл **hello.cpp** с таким кодом:

```cpp
#include <iostream>        		// подключаем заголовочный файл iostream

int main()							// определяем функцию main
{									// начало функции
	std::cout << "Hello enoobis.ru!";	// выводим строку на консоль
	return 0;						// выходим из функции
}									// конец функции
```

это тот же текст, что и в разделе про windows. на уровне исходного кода программы на c++ в значительной степени переносимы: отличия платформ проявляются в команде сборки и в формате исполняемого файла, а не в этой программе.

чтобы вывести строку, подключается интерфейс библиотеки. в начале файла стоит строка

```cpp
#include <iostream>
```

это директива препроцессора. она подключает заголовочный файл `iostream`, в котором объявлены стандартные потоки. заголовок нужен для вывода строки на консоль.

далее определяется функция **main**. она обязана присутствовать в программе на c++: выполнение приложения начинается с неё.

у функции main четыре составляющие:

- тип возвращаемого значения. здесь это тип `int`. функция должна вернуть целое число

- имя функции. функция называется `main`

- список параметров. после имени в скобках идёт список параметров. скобки пусты: эта форма `main` параметров не принимает

- тело функции. после списка параметров в фигурных скобках записываются действия функции

```cpp
{
	std::cout << "Hello enoobis.ru!\n";
	return 0;
}
```

в теле строка выводится на консоль. стандартный поток вывода **std::cout** связан со стандартным выводом процесса. оператор **<<** передаёт в этот поток строку символов, которую нужно вывести на консоль. в разборе фрагмента эта строка названа "Hello World!". в конец строки добавлена управляющая последовательность "\n": после вывода текста курсор переводится на новую строку.

выход из функции выполняет оператор **return**. результат имеет тип `int`, после `return` указано число 0. нуль является признаком успешного завершения программы.

после каждой инструкции в c++ ставится точка с запятой.

в терминале команда `cd` переходит в каталог с исходным файлом.

компиляция запускается командой:

```bash
g++ hello.cpp -o hello
```

помимо имени исходного файла компилятору передаётся параметр `-o hello`. он задаёт имя выходного файла, hello. если параметр не передать, создаётся файл с именем по умолчанию, a.out. имя a.out исторически восходит к assembler output и сохраняется как имя по умолчанию в unix-подобных системах.

после команды в каталоге с hello.cpp появляется файл **hello**. он запускается так:

```bash
./hello
```

префикс `./` нужен потому, что текущий каталог не входит в `PATH`. оболочка не запускает локальный файл по голому имени, и путь указывается явно. на консоль выводится строка "Hello enoobis.ru!".

```bash
eugene@Eugene:~/Documents$ cd cpp
eugene@Eugene:~/Documents/cpp$ g++ hello.cpp -o hello
eugene@Eugene:~/Documents/cpp$ ./hello
Hello enoobis.ru!
eugene@Eugene:~/Documents/cpp$
```
