для хранения данных в программе на c++ используются **переменные**. переменная представляет собой именованный участок памяти. у неё есть тип, имя и значение. тип определяет, какие данные переменная может хранить, какой набор операций к ней применим и как значение представлено в памяти.

перед использованием переменную определяют. синтаксис определения:

```cpp
тип_переменной имя_переменной;
```

определение одновременно вводит имя в область видимости и выделяет объект. одно лишь объявление имени без определения в этой лекции не рассматривается: для переменной с автоматическим временем хранения запись выше является определением.

### именование переменных

имя переменной является последовательностью букв, цифр и знака подчёркивания `_`. имя начинается с буквы или с подчёркивания. пробелы и знаки операций в имя не входят.

именем переменной нельзя сделать ключевое слово c++, например **for** или **if**. ключевых слов сравнительно немного, и по ходу курса становится видно, какие слова зарезервированы языком. ключевое слово не является идентификатором: транслятор разбирает его как элемент грамматики, а не как имя объекта.

не рекомендуются и такие имена:

- имена, которые начинаются с двух подчёркиваний

- имена, которые начинаются с подчёркивания, за которым идёт заглавная буква

- имена в глобальной области (вне функции main), которые начинаются с подчёркивания

стандарт резервирует эти формы для реализации. при таких именах растёт вероятность конфликта с именами, которые порождает компилятор или которые определены в подключаемых стандартных заголовках c++. поэтому имя нередко советуют вообще не начинать с символа подчёркивания: пользовательский идентификатор тогда не попадает в зарезервированный класс.

### определение переменной

в общем виде переменная определяется так:

```cpp
тип_переменной имя_переменной;
```

простейшее определение:

```cpp
int age;
```

здесь определена переменная `age` типа **int**. определение является инструкцией, после него ставится точка с запятой. тип `int` задаёт целочисленное представление. пока инициализатора нет, локальная переменная такого типа не получает определённого значения.

c++ различает регистр букв, поэтому регистр в имени существенен. в следующем фрагменте определяются две разные переменные:

```cpp


int age;

int Age;
```

переменная `Age` не обозначает тот же объект, что и переменная `age`. это разные идентификаторы, у каждого своё связывание имени с объектом.

нельзя определить в одной области видимости больше одной переменной с тем же именем:

```cpp


int age;

int age;
```

такое определение вызывает ошибку на этапе компиляции: одно имя в одной области не может обозначать два объекта. во вложенной области то же имя может скрыть внешнее, но это уже другое правило, не повторное определение.

### инициализация

после определения переменной ей можно присвоить значение. присвоение начального значения называется **инициализацией**. инициализация задаёт значение в момент создания объекта и отличается от последующего присваивания, которое меняет уже существующий объект. в c++ три вида инициализации:

- нотация присваивания (assignment notation)

- функциональная нотация (functional notation)

- инициализация в фигурных скобках (braced initialization)

ниже разбираются эти виды. функциональная нотация записывает начальное значение в круглых скобках, например `int age(20);`. с точки зрения семантики для скалярного типа это прямая инициализация: значение 20 преобразуется к типу переменной и становится её начальным значением. фигурные скобки задают инициализацию списком и запрещают сужающие преобразования. нотация присваивания разбирается первой.

#### нотация присваивания

в нотации присваивания оператор присваивания (знак `=`) передаёт переменной значение:

```cpp


int age;

age = 20;
```

переменной присваивается число 20. постоянные значения любого типа, числа, символы, строки, такие как 20, 123.456, "A" или "hello", называются **литералами**. литерал встроен в текст программы, у него нет имени, а тип выводится из формы записи. здесь переменной присваивается целочисленный литерал 20. если определение и присваивание разнесены, как в листинге, первое действие создаёт объект, второе записывает в него значение. ту же нотацию можно соединить с определением: `int age = 20;`.

пример с определением переменной и выводом её значения:

```cpp


#include <iostream>



int main()

{

	int age;

	age = 28;

	std::cout<<"Age = " << age;

}
```

переменная `age` получает 28, затем операторы `<<` по очереди отправляют в `std::cout` литерал "Age = " и текущее значение `age`.

последовательность операторов вывода в другом фрагменте лекции даёт на консоли такой текст:

```consoletext


Age1 = 23

Age2 = 24
```

теперь пример с инициализацией через фигурные скобки:

```cpp


#include <iostream>

 

int main()

{

    int age {22.5};

    std::cout<<"Age = " << age << "\n";

}
```

переменная `age` снова имеет целый тип, а в скобках записано дробное значение 22.5. инициализация списком не разрешает сужающее преобразование: при переходе от `double` к `int` отбрасывается дробная часть, и такое преобразование в фигурных скобках считается ошибкой. многие компиляторы сообщают об этом уже при компиляции. вывод g++:

```consoletext


hello.cpp: In function 'int main()':

hello.cpp:5:15: error: narrowing conversion of '2.25e+1' from 'double' to 'int' [-Wnarrowing]

    5 |     int age1 {22.5};
```

диагностика называет преобразование narrowing conversion и показывает значение `22.5` в виде `2.25e+1`. в тексте сообщения фигурирует имя `age1`, в листинге программы выше переменная названа `age`. часть компиляторов этот код всё же переводит в программу, но предупреждение выводит.

### инициализация нулем

при инициализации в фигурных скобках значение можно опустить:

```cpp
int counter {};
```

пустой список инициализации для скалярного типа означает инициализацию нулём. запись равносильна явному нулю:

```cpp
int counter {0};
```

для `int` нуль является нулевым значением типа. та же форма `{}` обнуляет и другие скаляры: `false` для `bool`, `0.0` для типов с плавающей точкой, нулевой код для `char`.

### инициализация по умолчанию

если переменную не инициализировать, происходит инициализация по умолчанию. какое значение получится, зависит от места определения, то есть от времени хранения объекта.

если переменная встроенного типа (например, `int`) определена внутри функции, она получает неопределённое значение. чтение такого значения является неопределённым поведением. если переменная встроенного типа определена вне функции, у неё статическое время хранения: объект сначала обнуляется, и для числового типа значение по умолчанию равно 0. пример:

```cpp


#include <iostream>



int x;

int main()

{

	int y;

	std::cout <<"X = " << x << "\n";

	std::cout <<"Y = " << y;

}
```

переменная `x` определена вне функции, поэтому получает значение по умолчанию, число 0.

с переменной `y`, определённой внутри `main`, дело сложнее. её значение неопределённо и зависит от компилятора и от того, что ранее лежало в стеке. вывод программы, собранной g++, может выглядеть так:

```consoletext


X = 0

Y = 0
```

нуль у `y` здесь случаен: стандарт его не гарантирует. в visual studio использование неинициализированной `y` вызывает ошибку компиляции.

перед использованием переменной ей лучше явно задать значение и не опираться на значение по умолчанию. для локальной переменной встроенного типа значение по умолчанию не является осмысленным нулём.

### изменение значения

значение переменной можно менять последующим присваиванием. имя продолжает обозначать тот же объект, меняется хранимое значение:

```cpp


#include <iostream>



int main()

{

    int age = 22;

    std::cout << "Age1 = " << age << "\n";

    age = 23;

    std::cout << "Age2 = " << age << "\n";

    age = 38;

    std::cout << "Age3 = " << age << "\n";

}
```

консольный вывод программы:

```consoletext


Age1 = 22

Age2 = 23

Age3 = 38
```

сначала объект хранит 22, после первого присваивания 23, после второго 38. каждое присваивание затирает предыдущее значение, тип объекта при этом не меняется: статическая типизация фиксирует тип в определении.
