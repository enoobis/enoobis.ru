**представление**, или view, является легковесным диапазоном, который ссылается на элементы и не владеет ими. представление обычно построено над другим диапазоном и задаёт определённый способ работы с ним, например преобразование или фильтрацию. контейнер непосредственно хранит элементы и отвечает за их время жизни, а представление ссылается на эти элементы. по стоимости построения представление эффективнее диапазона, который копирует последовательность: владения нет, копия элементов не создаётся. представление можно создать без потери производительности на копирование. обход и применение предиката при этом часто откладываются до обращения к элементам.

для создания представлений применяются адаптеры диапазонов (range adapter). есть два способа определить представление.

- применение конструктора представления `std::ranges::xxx_view`, где `xxx` обозначает название представления. первый параметр является контейнером, для которого создаётся представление, второй параметр задаёт функцию, применяемую при создании представления.

```cpp


auto view = std::ranges::xxx_view{ range, args } // конструктор представления
```

- применение операции `|` к контейнеру и функции `std::views::xxx`, где `xxx` обозначает название представления. здесь `range` также является контейнером, а функция `std::views::xxx()` принимает функцию, которая применяется для создания представления. операция `|` передаёт левый операнд, диапазон, адаптеру и возвращает новое представление. адаптеры соединяются в конвейер.

```cpp


auto view = range | std::views::xxx(args)
```

ниже это показано на фильтрации, одной из самых распространённых операций над диапазонами.

## фильтрация

для фильтрации применяется представление **std::ranges::filter_view**. вторым параметром конструктор представления принимает условие: функцию, которая принимает некоторый объект и возвращает значение типа **bool**. `true` означает, что объект соответствует условию, `false` означает, что не соответствует. представление не хранит отдельную копию отобранных элементов: при обходе оно пропускает те, для которых предикат ложен.

например, фильтрация элементов вектора:

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges>



class Person

{

public:

    Person(std::string name, unsigned age): name{name}, age{age}{}

    std::string getName() const {return name;}

    unsigned getAge() const {return age;}

    void print() const  

    {

        std::cout << name <<"\t" << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

};

bool ageMoreThan33(const Person& person) 

{ 

    return person.getAge() > 33; 

}

int main()

{

    std::vector<Person> people 

    {

        Person{"Tom", 38}, Person{"Kate", 31}, Person{"Bob", 42}, 

        Person{"Alice", 34}, Person{"Sam", 25}

    };

    auto filter_view = std::ranges::filter_view{people, ageMoreThan33};



    for(const auto& person: filter_view)

    {

        person.print();

    }

}
```

вектор хранит объекты типа `Person`, для каждого из которых задаются имя и возраст. из вектора получаются все объекты `Person`, возраст которых больше 33:

```cpp
auto filter_view = std::ranges::filter_view{people, ageMoreThan33};
```

условие вынесено в отдельную функцию `ageMoreThan33()`, которая возвращает `true`, если возраст больше 33. то же условие можно задать лямбда-выражением: замыкание с подходящей сигнатурой передаётся туда же, куда и указатель на функцию.

в результате вызова конструктора `std::ranges::filter_view` получается представление с объектами `Person`, которые соответствуют условию. полученное представление перебирается циклом `for`, и на каждой итерации доступен его элемент, здесь это объект `Person`. вывод программы:

```bash


Tom     38

Bob     42

Alice   34
```

вместо внешней функции в конструктор передаётся лямбда-выражение:

```cpp


std::vector<Person> people 

{

    Person{"Tom", 38}, Person{"Kate", 31}, Person{"Bob", 42}, 

    Person{"Alice", 34}, Person{"Sam", 25}

};

auto ageMoreThan33 = [](const Person& p){return p.getAge() > 33;};

auto filter_view = std::ranges::filter_view{people, ageMoreThan33};



for(const auto& person: filter_view)

{

    person.print();

}
```

второй способ создать представление фильтрации применяет функцию **std::views::filter()**, в которую передаётся функция фильтрации.

```cpp


#include <iostream>

#include <string>

#include <vector>

#include <ranges>



class Person

{

public:

    Person(std::string name, unsigned age): name{name}, age{age}{}

    std::string getName() const {return name;}

    unsigned getAge() const {return age;}

    void print() const  

    {

        std::cout << name <<"\t" << age << std::endl;

    }

private:

    std::string name;

    unsigned age;

}; 

int main()

{

    std::vector<Person> people 

    {

        Person{"Tom", 38}, Person{"Kate", 31}, Person{"Bob", 42}, 

        Person{"Alice", 34}, Person{"Sam", 25}

    };

    auto ageMoreThan33 = [](const Person& p){return p.getAge() > 33;};

    auto filter_view = people | std::views::filter(ageMoreThan33);



    for(const auto& person: filter_view)

    {

        person.print();

    }

}
```

для создания представления фильтрации используется операция **|**, операндами которой выступают контейнер данных и функция `std::views::filter`:

```cpp
auto filter_view = people | std::views::filter(ageMoreThan33);
```

результат совпадает с результатом конструктора представления: тот же отбор и та же отложенная проверка предиката. адаптер `std::views::filter` стыкуется с конвейером `|`.
