класс `std::queue` представляет очередь: адаптер контейнера с дисциплиной fifo (first-in first-out, первым вошёл, первым вышел). извлекается всегда элемент, добавленный первым. та же схема у обычной очереди: кто встал раньше, тот раньше и выходит.

собственную структуру хранения `std::queue` не определяет. элементы лежат во вложенном контейнере, по умолчанию в `std::deque`. адаптер показывает только концы последовательности: запись в хвост, чтение головы и хвоста, снятие с головы. итераторов нет.

для работы с очередью подключается заголовочный файл `<queue>`. пустая очередь:

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::queue<std::string> queue;  // пустая очередь

}
```

### размер очереди

`size()` возвращает число элементов. `empty()` возвращает `true`, если очередь пуста:

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::queue<std::string> queue;

    if(queue.empty())

    {

        std::cout << "queue is empty" << std::endl;

    }

    std::cout << "queue size: " << queue.size() << std::endl; // queue size: 0

}
```

### добавление элементов

элемент ставится в хвост функцией `push()`:

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::queue<std::string> queue;  // пустая очередь

    // добавляем три элемента

    queue.push("Tom");

    queue.push("Bob");

    queue.push("Sam");



    std::cout << "queue size: " << queue.size() << std::endl; // queue size: 3

}
```

три вызова `push` дают размер 3. первый вставленный элемент остаётся в голове, последний оказывается в хвосте.

### получение элементов

прочитать можно голову и хвост, произвольная позиция интерфейсом не отдаётся. голову возвращает `front()`, хвост возвращает `back()`. обе функции элемент не удаляют и требуют непустую очередь.

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::queue<std::string> queue;  // пустая очередь

    queue.push("Tom");

    queue.push("Bob");

    queue.push("Sam");



    std::cout << "First: " << queue.front() << std::endl;   // First: Tom

    std::cout << "Last: " << queue.back() << std::endl;     // Last: Sam

}
```

после последовательности `"Tom"`, `"Bob"`, `"Sam"` в голове оказывается `"Tom"`, в хвосте `"Sam"`.

### удаление элементов

элемент снимается с головы функцией `pop()`:

```cpp
queue.pop()
```

`pop()` значение не возвращает. перед снятием оно читается через `front()`. вызов на пустой очереди даёт неопределённое поведение.

вместе `front()` и `pop()` извлекают все элементы очереди:

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::queue<std::string> queue;

    queue.push("Tom");

    queue.push("Bob");

    queue.push("Sam");



    while (!queue.empty())	// пока очередь не пуста

    {

        std::cout << queue.front() << std::endl;

        queue.pop();	// извлекаем первый элемент

    }

}
```

пока очередь не пуста, программа печатает первый элемент и снимает его. консольный вывод программы:

```bash


Tom

Bob

Sam
```

порядок печати совпадает с порядком добавления: дисциплина fifo сохраняет последовательность вызовов `push`.

### инициализация деком

очередь инициализируется другой очередью или двусторонней очередью. конструктор от контейнера использует его как внутреннюю последовательность. голова очереди соответствует `front()` этого контейнера, хвост соответствует `back()`.

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::deque<std::string> people{"Tom", "Sam", "Bob"};

    std::queue<std::string> queue {people};



    while (!queue.empty())

    {

        std::cout << queue.front() << std::endl;

        queue.pop();

    }

}
```

дек `people` хранит `"Tom"`, `"Sam"`, `"Bob"`. построенная очередь отдаёт их через `front` и `pop` в том же порядке.

### обмен элементами

`swap()` меняет местами содержимое двух очередей. обмен выполняется за постоянное время: адаптер обменивает вложенные контейнеры, элементы по одному не копируются.

```cpp


#include <iostream>

#include <queue>

#include <string>



int main()

{

    std::queue<std::string> queue1 {std::deque<std::string>{"Alice", "Kate"}};



    std::queue<std::string> queue2;

    queue2.push("Tom");

    queue2.push("Bob");



    // обмен queue1 на queue2

    queue1.swap(queue2);

    // queue1 = {"Tom", "Bob"}

    // queue2 = {"Alice", "Kate"}

}
```

после вызова `queue1` содержит `"Tom"` и `"Bob"`, `queue2` содержит `"Alice"` и `"Kate"`.
