начиная со стандарта c++20 в стандартной библиотеке есть заголовок `<format>` и функция `std::format()`. она собирает строку по шаблону. первый аргумент, строка форматирования, содержит произвольный текст и любое число плейсхолдеров `{}`. в режиме автоматической нумерации каждый следующий аргумент попадает в очередной плейсхолдер: один аргумент на одну пару фигурных скобок, слева направо. результат имеет тип `std::string`. в примерах его сразу передают в `std::cout`, но сама функция от потока не зависит. строка форматирования у `std::format` должна быть константным выражением: спецификация сверяется с типами аргументов при компиляции.

подстановка трёх значений в шаблон `"{} + {} = {}"`:

```cpp

#include <iostream>
#include <format>

int main()
{
    int a {10};
    int b {7};
    std::cout << std::format("{} + {} = {}", a, b, a+b);
}
```

в строке три плейсхолдера. второй, третий и четвёртый аргументы `std::format` занимают их по порядку. `a` попадает в первую пару скобок, `b` во вторую, сумма `a + b` в третью. аргументы вычисляются до входа в функцию, поэтому в строку приходит уже готовое число. консольный вывод:

```consoletext

10 + 7 = 17
```

заголовок добавлен в стандарт поздно, и компиляторы включили его не в одном выпуске. visual studio реализует `std::format` полностью. в gcc (g++) поддержка есть начиная с версии 13.0. сборка clang может потребовать флаг `-fexperimental-library` рядом со стандартом `-std=c++20`:

```consoletext
clang++ -std=c++20 -fexperimental-library hello.cpp -o hello
```

у плейсхолдера есть необязательная спецификация. она записывается после двоеточия по грамматике:

```cpp
[[fill]align][sign][#][0][width][.precision][type]
```

квадратные скобки помечают необязательное поле. в текст плейсхолдера эти скобки не входят. порядок полей фиксирован. `fill` задаёт символ заполнения и пишется только вместе с `align`, в самом начале спецификации. `sign` управляет знаком: `+` показывает его всегда, `-` только у отрицательного числа, пробел ставит пробел перед неотрицательным числом. `#` включает альтернативную форму. у двоичной и шестнадцатеричной записи целого при этом появляется префикс основания. `0` дополняет числовое поле нулями. если одновременно задано выравнивание, этот флаг игнорируется. `width` задаёт минимальную ширину поля. `.precision` задаёт точность. `type` выбирает представление. какие поля применимы, зависит от типа аргумента. ниже разобраны точность, ширина, выравнивание и тип: в примерах вид числа и строки определяют именно они.

### спецификаторы формата

точность ограничивает число знаков у значения с плавающей точкой и число символов у строки:

```cpp
:.количество_знаков
```

после двоеточия стоит точка и количество знаков. значение `sum` равно `100.2567`. спецификатор `:.5` оставляет пять значащих цифр, считая и целую часть, и дробную:

```cpp

#include <iostream>
#include <format>

int main()
{
    double sum {100.2567}; 
    std::cout << std::format("sum = {:.5}", sum);
}
```

вывод:

```consoletext
sum = 100.26
```

пять значащих цифр числа `100.2567` заканчиваются цифрой `5`, следующая цифра равна `6`. она не меньше `5`, поэтому сохранённая `5` увеличивается на единицу. на консоль попадает `100.26`. запись `100.25` получилась бы только при отбрасывании хвоста без округления. спорной границы, где отброшенный хвост равен ровно половине единицы последнего разряда, у этого значения нет.

без буквы типа точность означает общее число значащих цифр. чтобы ограничить число знаков после десятичной точки, к спецификатору добавляют `f`:

```cpp
std::cout << std::format("sum = {:.5f}", sum);
```

снова запрошены пять знаков, теперь после точки. в дробной части `sum` четыре цифры, пятой дописывается `0`:

```consoletext
sum = 100.25670
```

та же точность для строки задаёт наибольшую длину. ширину поля эта цифра не задаёт. из `"Tom Smith"` остаются первые пять символов. пробел между словами входит в этот счёт:

```cpp
std::cout << std::format("name = {:.5}", "Tom Smith");	// name = Tom S
```

строка короче указанного предела печатается целиком. обрезка не дополняет её до этой длины. за наименьшую ширину отвечает поле `width`.

### параметр width

`width` задаёт минимальную ширину поля. когда представление короче, недостающие позиции заполняются. какой символ берётся, зависит от типа значения и от остальных полей. явный символ задаёт `fill`, и вместе с ним обязателен `align`: эта пара стоит раньше `width`. если символ заполнения не указан, используется пробел. флаг `0` непосредственно перед шириной дополняет число нулями. от символа `fill` флаг отличается положением в грамматике: он не требует `align` и теряет силу, когда выравнивание задано явно.

```cpp

#include <iostream>
#include <format>

int main()
{
    int a {2}; 
    int b {5};
    int c {-8};
    std::cout << std::format("a = {:07}", a) << std::endl;
    std::cout << std::format("b = {:7}", b) << std::endl;
    std::cout << std::format("c = {:07}", c) << std::endl;
}
```

минимальная ширина всех трёх чисел равна 7. у `a` и `c` стоит флаг `0`, у `b` заполнение остаётся пробелом:

```bash

a = 0000002
b =       5
c = -000008
```

`a` равно 2, перед цифрой стоят шесть нулей. `b` равно 5. у целого выравнивание по умолчанию правое, поэтому слева шесть пробелов. `c` отрицательно. знак записывается перед заполнением, затем идут нули, и поле имеет вид `-000008`. то же размещение знака действует, когда знак запрошен полем `sign`, значением `+` или `-`: символы заполнения стоят после знака.

### выравнивание

поле `align` выбирает сторону значения внутри ширины. `>` прижимает значение к правому краю, `<` к левому, `^` ставит его по центру. без явного `align` сторона зависит от типа: числа выравниваются вправо, строки влево.

```cpp

#include <iostream>
#include <format>

int main()
{
    std::cout << std::format("{:>7}|{:>7}|{:>7}|{:>7}|\n", 1, -.2, 3, 4);
    std::cout << std::format("{:<7}|{:<7}|{:<7}|{:<7}|\n", 1, -.2, 3, 4);
    std::cout << std::format("{:^7}|{:^7}|{:^7}|{:^7}|\n", 1, -.2, 3, 4);
}
```

вывод трёх строк:

```consoletext

      1|   -0.2|      3|      4|
1      |-0.2   |3      |4      |
   1   | -0.2  |   3   |   4   |
```

ширина каждого поля равна 7, поля разделены `|`. в первой строке значения прижаты вправо: перед `1` шесть пробелов, перед `-0.2` три. во второй строке значения прижаты влево, пробелы стоят после текста. в третьей текст окружён пробелами. знак минус и десятичная точка входят в ширину. у `-0.2` четыре символа текста, слева один пробел и справа два: при нечётном числе символов заполнения лишний символ ставится справа.

### настройка типа

поле `type` выбирает форму представления. набор букв ограничен типом аргумента.

для чисел с плавающей точкой:

- `f` : фиксированная точка. если точность не задана, после точки печатаются 6 цифр

- `g` : общее форматирование. выбирается фиксированная или экспоненциальная запись, хвостовые нули отбрасываются

- `e` : экспоненциальная запись. показатель степени десяти отделяется буквой `e`

- `a` : шестнадцатеричная мантисса. показатель после `p` является степенью двойки

для целых чисел добавляются:

- `b` : двоичная запись

- `x` : шестнадцатеричная запись в нижнем регистре. верхний регистр цифр даёт `X`

применение этих букв:

```cpp

#include <iostream>
#include <format>

int main()
{
    std::cout << std::format("{:f} \n", 34.56);     // 34.560000
    std::cout << std::format("{:g} \n", 34.56);     // 34.56
    std::cout << std::format("{:e} \n", 34.56);     // 3.456000e+01
    std::cout << std::format("{:a} \n", 34.56);     // 1.147ae147ae148p+5
    std::cout << std::format("{:b} \n", 122);       // 1111010
    std::cout << std::format("{:032b} \n", 122);    // 00000000000000000000000001111010
    std::cout << std::format("{:x} \n", 122);       // 7A
}
```

`{:f}` печатает `34.56` как `34.560000`: сработала точность по умолчанию, шесть знаков после точки. `{:g}` даёт `34.56`, хвостовые нули общему формату не нужны. `{:e}` даёт `3.456000e+01`, то есть ту же величину как мантиссу, умноженную на десять в степени 1. `{:a}` даёт `1.147ae147ae148p+5`. число `122` в двоичной записи равно `1111010`. спецификатор `{:032b}` сохраняет эту запись и дополняет её нулями слева до ширины 32. спецификатор `x` печатает шестнадцатеричные цифры в нижнем регистре, для `122` это текст `7a`. в комментарии к соответствующей строке записано `7A`. такой регистр даёт спецификатор `X`, он стоит в следующем примере.

### переопределение порядка аргументов

без номеров аргументы занимают плейсхолдеры в порядке следования. номер можно поставить внутри скобок до двоеточия. нумерация начинается с нуля и относится к аргументам после строки форматирования. двоеточие отделяет номер от спецификации. пустая спецификация `{2:}` задаёт то же представление, что и `{2}`.

```cpp

#include <iostream>
#include <format>

int main()
{
    int a{10};
    int b{20};
    int c{30};
    std::cout << std::format("{2:} {1:} {0:}", a, b, c);    // 30 20 10
}
```

первым значением в вызов передан `a`, он равен 10. строка начинается с `{2:}`, поэтому первой печатается `c`, она равна 30. затем `{1:}` берёт `b`, затем `{0:}` берёт `a`. на консоли текст `30 20 10`.

в одной строке автоматические плейсхолдеры `{}` и явные номера вместе не употребляют. либо у всех полей номеров нет, либо номер есть у каждого. смесь делает строку форматирования некорректной.

явный номер нужен, когда одно и то же значение печатается несколько раз и в разных представлениях. число 62 выводится в десятичной, двоичной и шестнадцатеричной форме:

```cpp

#include <iostream>
#include <format>

int main()
{
    int a{10};
    int b{20};
    int c{30};
    std::cout << std::format("{0:} {0:b} {0:X}", 62);    // 62 111110 3E
}
```

все три поля ссылаются на аргумент с номером 0. `{0:}` даёт `62`, `{0:b}` даёт `111110`, `{0:X}` даёт `3E`. локальные переменные `a`, `b` и `c` в эту подстановку не передаются.
