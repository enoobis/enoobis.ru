помимо отдельных динамических объектов в c++ создают динамические массивы. память под такой массив выделяет `new`, а в квадратных скобках записано, сколько объектов массив содержит:

```cpp


int *numbers {new int[4]}; // динамический массив из 4 чисел

// или так

// int *numbers = new int[4];
```

и в этой форме `new` возвращает указатель на `int`, адрес первого элемента созданного массива. тип выражения `new int[n]` есть `int*`. длина в типе указателя не сохраняется, её нужно хранить отдельно.

массив из четырёх элементов типа `int` в первой форме оставляет элементы неинициализированными: инициализация по умолчанию для `int` не задаёт значение. массив можно инициализировать явно:

```cpp


int *numbers1 {new int[4]{}};	            // массив состоит из чисел 0, 0, 0, 0

int *numbers2 {new int[4]{ 1, 2, 3, 4 }}; // массив состоит из чисел 1, 2, 3, 4

int *numbers3 {new int[4]{ 1, 2 }};       // массив состоит из чисел 1, 2, 0, 0

// аналогичные определения массивов

// int *numbers1 = new int[4]{};	         // массив состоит из чисел 0, 0, 0, 0

// int *numbers1 = new int[4]();	         // массив состоит из чисел 0, 0, 0, 0

// int *numbers2 = new int[4]{ 1, 2, 3, 4 }; // массив состоит из чисел 1, 2, 3, 4

// int *numbers3 = new int[4]{ 1, 2 };       // массив состоит из чисел 1, 2, 0, 0
```

если значений в фигурных скобках больше, чем длина массива, программа некорректна: `new` массив не создаёт. при постоянной длине это диагностируется при компиляции, а не откладывается до выполнения. если значений меньше, элементы без явного значения инициализируются значением по умолчанию. для `int` это 0, что видно по `numbers3`: заданы 1 и 2, остальные два элемента нули. пустой список `{}` или `()` инициализирует значением весь массив, и все четыре элемента равны 0.

в стандарт c++20 добавлен вывод длины массива. при этом стандарте длину можно не писать, она берётся из числа инициализаторов:

```cpp


int *numbers {new int[]{ 1, 2, 3, 4 }}; // массив состоит из чисел 1, 2, 3, 4
```

пропуск длины возможен только вместе со списком инициализации: выводить размер без него было бы не из чего.

с динамическим массивом работают через полученный указатель: элементы читают и изменяют.

```cpp


int *numbers {new int[4]{ 1, 2, 3, 4 }}; 



// получение элементов через синтаксис массивов

std::cout << numbers[0] << std::endl;       // 1

std::cout << numbers[1] << std::endl;       // 2



// получение элементов через операцию разыменования

std::cout << *numbers << std::endl;         // 1

std::cout << *(numbers+1) << std::endl;     // 2
```

элемент доступен и синтаксисом массива (`numbers[0]`), и разыменованием (`*numbers`). для указателя на первый элемент эти формы связаны тождеством: `p[i]` есть `*(p + i)`. сложение указателя со смещением сдвигает адрес на `i` элементов, а не на `i` байт. шаг равен `sizeof(int)`.

перебор записывают по-разному:

```cpp


unsigned n{ 5 };  // размер массива

int* p{ new int[n] { 1, 2, 3, 4, 5 } };



// используем индексы

for (unsigned i{}; i < n; i++)

{

    std::cout << p[i] << "\t";

}

std::cout << std::endl;



// добавляем к адресу в указателе смещение

for (unsigned i{}; i < n; i++)

{

    std::cout << *(p+i)<< "\t";

}

std::cout << std::endl;



// проходим по массиву с помощью вспомогательного указателя

for (int* q{ p }; q != p + n; q++)

{

    std::cout << *q << "\t";

}

std::cout << std::endl;
```

размер динамического массива задают обычной переменной, а не константным выражением, как у встроенного массива. тип встроенного массива включает длину, и эта длина должна быть константой времени компиляции. выражение в `new T[n]` вычисляется во время выполнения, поэтому `n` может быть значением, прочитанным из ввода или вычисленным перед выделением.

для удаления динамического массива есть отдельная форма `delete`:

```cpp


delete [] указатель_на_динамический_массив;
```

пример:

```cpp


#include <iostream>



int main()

{

	unsigned n{ 5 };  // размер массива

    int* p{ new int[n] { 1, 2, 3, 4, 5 } };



    // используем индексы

    for (unsigned i{}; i < n; i++)

    {

        std::cout << p[i] << "\t";

    }

	std::cout << std::endl;



	delete [] p;

}
```

форма `delete[]` согласована с `new[]`. она уничтожает каждый элемент (для `int` деструктор тривиален, для классового типа деструктор вызывается у каждого элемента, в порядке, обратном построению) и вызывает функцию освобождения массива. `delete` без скобок по указателю от `new[]` есть неопределённое поведение, даже если тип элемента тривиален: размер выделения и служебные данные массива известны только форме `delete[]`.

после освобождения указатель не должен хранить старый адрес. его обнуляют:

```cpp


delete [] p;

p = nullptr;	// обнуляем указатель
```

### многомерные массивы

динамический массив может быть многомерным. двумерный массив есть набор массивов, массив массивов. чтобы получить динамический двумерный массив, создают динамический массив указателей, а затем для каждого элемента создают вложенный динамический массив. общая схема:

```cpp


#include <iostream>



int main()

{

    unsigned rows = 3;       // количество строк

    unsigned columns = 2;    // количество столбцов

    int** numbers{new int*[rows]{}};  // выделяем память под двухмерный массив

	// выделяем память для вложенных массивов

    for (unsigned i{}; i < rows; i++)

    {

        numbers[i] = new int[columns]{};

    }



	// удаление массивов	

    for (unsigned i{}; i < rows; i++)

    {

        delete[] numbers[i];

    }

    delete[] numbers;

}
```

сначала выделяется память под массив указателей, условно под таблицу:

```cpp
int** numbers{new int*[rows]{}};
```

тип `int**` есть указатель на указатель. выражение `new int*[rows]` создаёт массив из `rows` указателей типа `int*` и возвращает адрес первого. инициализатор `{}` обнуляет эти указатели.

затем в цикле выделяется память каждого вложенного массива, условно строки таблицы:

```cpp
numbers[i] = new int[columns]{};
```

`numbers[i] = new int[columns]{}` записывает в i-й указатель адрес отдельного массива из `columns` нулей. строки суть отдельные выделения. они не обязаны лежать в памяти подряд, и адресная арифметика между концом одной строки и началом следующей не определена.

освобождение идёт в обратном порядке. сначала освобождается каждый вложенный массив, затем массив указателей. если удалить массив указателей раньше строк, адреса строк будут потеряны, и освободить их уже нельзя.

пример ввода и вывода двумерного динамического массива:

```cpp


#include <iostream>



int main()

{

    unsigned rows = 3;       // количество строк

    unsigned columns = 2;    // количество столбцов

    int** numbers{new int*[rows]{}};  // выделяем память под двухмерный массив

    for (unsigned i{}; i < rows; i++)

    {

        numbers[i] = new int[columns]{};

    }



    // вводим данные для таблицы rows x columns

    for (unsigned i{}; i < rows; i++)

    {

        std::cout << "Enter data for " << (i + 1) << " row" << std::endl;

        // вводим данные для столбцов i-й строки

        for (unsigned j{}; j < columns; j++)

        {

            std::cout << (j + 1) << " column: ";

            std::cin >> numbers[i][j];

        }

    }

	// вывод данных

    for (unsigned i{}; i < rows; i++)

    {

        // выводим данные столбцов i-й строки

        for (unsigned j{}; j < columns; j++)

        {

            std::cout << numbers[i][j] << "\t";

        }

        std::cout << std::endl;

    }

    

    for (unsigned i{}; i < rows; i++)

    {

        delete[] numbers[i];

    }

    delete[] numbers;

}
```

внешний цикл идёт по строкам, внутренний по столбцам. `numbers[i][j]` есть `*(*(numbers + i) + j)`: первое разыменование выбирает строку, второе элемент строки. после вывода удаления повторяют ту же обратную последовательность, что и в предыдущем фрагменте.

пример работы программы:

```bash


Enter data for 1 row

1 column: 2

2 column: 3

Enter data for 2 row

1 column: 4

2 column: 5

Enter data for 3 row

1 column: 6

2 column: 7



2       3

4       5

6       7
```

### указатель на массив

тип `int**`, указатель на указатель (pointer-to-pointer), отличается от указателя на массив (pointer to array):

```cpp


#include <iostream>

 

int main()

{

    unsigned n{3};       // количество строк



	int (*a)[2] = new int[n][2];



	int k{};

    // устанавливаем значения

    for (unsigned i{}; i < n; i++)

    {

        // устанавливаем данные для столбцов i-й строки

        for (unsigned j{}; j < 2; j++)

        {

            a[i][j] = ++k;

        }

    }



    // вывод данных

    for (unsigned i{}; i < n; i++)

    {

        // выводим данные столбцов i-й строки

        for (unsigned j{}; j < 2; j++)

        {

            std::cout << a[i][j] << "\t";

        }

        std::cout << std::endl;

    }



    // удаляем данные

    delete[] a;

	a = nullptr;

}
```

запись `int (*a)[2]` есть указатель на массив из двух элементов типа `int`. скобки вокруг `*a` нужны по той же причине, что и у указателя на функцию: без них `int *a[2]` объявил бы массив из двух указателей. с таким объектом работают как с двумерным массивом, таблицей, но число столбцов фиксировано и равно 2. это часть типа, а не значение времени выполнения. память выделяется одним выражением:

```cpp
int (*a)[2] = new int[n][2];
```

получается таблица из `n` строк и 2 столбцов. выражение `new int[n][2]` создаёт один непрерывный блок из `n * 2` объектов `int` и возвращает указатель на первую строку, то есть на массив из двух `int`. строки лежат подряд. два индекса, строка и столбец, выбирают элемент, читают или записывают его. удаление тоже одно: `delete[] a`. отдельного цикла по строкам нет, потому что не было отдельных выделений. консольный вывод:

```bash


1       2

3       4

5       6
```
