арифметические операции применяются к числам. значения, участвующие в операции, называются операндами. в c++ арифметические операции бывают бинарными, над двумя операндами, и унарными, над одним операндом. к бинарным относятся следующие.

- `+`. операция сложения возвращает сумму двух чисел. в примере результат используется как инициализатор, но тем же выражением можно задать значение и через присваивание:

```cpp


int a {10};

int b {7};

int c {a + b};  // 17

int d {4 + b};  // 11
```

присваивание записывает уже вычисленную сумму в существующий объект:

```cpp


int a {10};

int b {7};

int c = a + b;  // 17

int d = 4 + b;  // 11
```

- `-`. операция вычитания возвращает разность двух чисел:

```cpp


int a {10};

int b {7};

int c {a - b};  // 3

int d {4 - b};  // -3
```

- `*`. операция умножения возвращает произведение двух чисел:

```cpp


int a {10};

int b {7};

int c {a * b};  // 70

int d {4 * b};  // 28
```

- `/`. операция деления возвращает частное двух чисел. если оба операнда целые, дробная часть отбрасывается, даже когда результат тут же записывается в переменную типа `float` или `double`. отбрасывание происходит при самом делении, до преобразования результата к типу переменной. чтобы частное имело плавающую точку, хотя бы один операнд должен иметь плавающий тип:

```cpp


int a {26};

int b {5};

int c {a / b};      // c = 5

int d {4 / b};     // d = 0
```

в следующем фрагменте деление по-прежнему целочисленное, и в `c` и `d` попадает уже усечённое значение:

```cpp


#include <iostream>



int main()

{

    int a {26};

    int b {5};

    float c {a / b};      // c = 5

    double d {4 / b};     // d = 0

    std::cout << "c = " << c << std::endl;

    std::cout << "d = " << d << std::endl;

}
```

здесь один из операндов имеет плавающий тип, поэтому деление выполняется в плавающей арифметике:

```cpp


#include <iostream>



int main()

{

    float a {26};

    int b {5};

    float c {a / b};        // c = 5.2

    double d {4.0 / b};     // d = 0.8

    std::cout << "c = " << c << std::endl;

    std::cout << "d = " << d << std::endl;

}
```

- `%`. операция даёт остаток от целочисленного деления. оба операнда целые. для неотрицательных `a` и `b` выполняется соотношение `a == (a / b) * b + (a % b)`:

```cpp


int a {26};

int b {5};

int c {a % b};      // c = 26 % 5 = 26 - 5 * 5 = 1

int d {4 % b};     // d = 4 % 5 = 4
```

### некоторые особенности при работе с числами с плавающей точкой

при сложении и вычитании чисел с плавающей точкой, которые сильно различаются по величине, точность младшего слагаемого теряется. тип `float` в распространённой реализации, формат binary32, хранит около семи значащих десятичных цифр. сложение `1.23E-4` (это `0.000123`) и `3.65E+6` (это 3650000) математически даёт `3650000.000123`. после округления до семи значащих цифр вклад первого слагаемого исчезает:

```browser
3.650000E+06 + 1.230000E-04 = 3.650000E+06
```

соответствующий фрагмент на c++:

```cpp


#include <iostream>



int main()

{

    float num1{ 1.23E-4  };        // 0.000123

    float num2{ 3.65E+6  };        // 3650000

    float sum {num1 + num2};       // sum =3.65e+06

    std::cout << "sum =" << sum << "\n";

}
```

первое число на результат не повлияло: под значимую часть отведено лишь семь цифр, и разряды, в которых лежит `1.23E-4`, в сумму типа `float` не помещаются.

стандарт ieee 754, на который ориентируются реализации плавающей арифметики в компиляторах c++, задаёт специальные значения. если мантисса на двоичном уровне состоит только из нулей, а экспонента состоит из единиц, знак различает `+infinity` (плюс бесконечность) и `-infinity` (минус бесконечность). деление положительного числа с плавающей точкой на ноль даёт `+infinity`, деление отрицательного на ноль даёт `-infinity`. для целых типов деление на ноль этим правилом не описывается: оно остаётся неопределённым поведением.

другое специальное значение того же стандарта называется `NaN` (not a number, «не число»). его получают операции, не определённые в вещественной арифметике, например деление нуля на ноль или бесконечности на бесконечность. если хотя бы один операнд равен `NaN`, результат операции тоже равен `NaN`. сравнение `NaN` с любым значением, включая само `NaN`, даёт ложь.

демонстрационная программа:

```cpp


#include <iostream>



int main()

{

    double a{ 1.5 }, b{}, c{}, d {-1.5};

    double result { a / b };

    std::cout << a << "/" << b << " = " << result << std::endl;

    result = d / c;

    std::cout << d << "/" << c << " = " << result << std::endl;

    result = b / c;

    std::cout << b << "/" << c << " = " << result << std::endl;

    std::cout << result << " + " << a << " = " << result + a << std::endl;

}
```

в выражении `a / b` число 1.5 делится на 0, результат равен плюс бесконечности.

в выражении `d / c` число -1.5 делится на 0, результат равен минус бесконечности.

в выражении `b / c` число 0 делится на 0, результат равен `NaN`.

последнее выражение `result + a` имеет вид `NaN + 1.5`, поэтому результат тоже `NaN`.

консольный вывод программы:

```consoletext


1.5/0 = inf

-1.5/0 = -inf

0/0 = nan

nan + 1.5 = nan
```

### инкремент и декремент

есть две унарные арифметические операции над одним числом: `++` (инкремент) и `--` (декремент). у каждой две формы, префиксная и постфиксная. обе формы изменяют объект, но значение самого выражения разное. операндом должен быть модифицируемый lvalue.

- префиксный инкремент. увеличивает значение переменной на единицу, и уже новое значение служит значением выражения `++x`:

```cpp


#include <iostream>



int main()

{

    int a {8};

    int b {++a};

    std::cout << "a = " << a << std::endl;  // a = 9

    std::cout << "b = " << b << std::endl;  // b = 9

}
```

- постфиксный инкремент. тоже увеличивает переменную на единицу, но значением выражения `x++` остаётся прежнее значение, то, которое было до увеличения:

```cpp


#include <iostream>



int main()

{

    int a {8};

    int b {a++};

    std::cout << "a = " << a << std::endl;  // a = 9

    std::cout << "b = " << b << std::endl;  // b = 8

}
```

- префиксный декремент. уменьшает значение переменной на единицу, и новое значение служит значением выражения `--x`:

```cpp


#include <iostream>



int main()

{

    int a {8};

    int b {--a};

    std::cout << "a = " << a << std::endl;  // a = 7

    std::cout << "b = " << b << std::endl;  // b = 7

}
```

- постфиксный декремент. уменьшает переменную на единицу, но значением выражения `x--` остаётся значение до уменьшения:

```cpp


#include <iostream>



int main()

{

    int a {8};

    int b {a--};

    std::cout << "a = " << a << std::endl;  // a = 7

    std::cout << "b = " << b << std::endl;  // b = 8

}
```

постфиксная форма концептуально сохраняет прежнее значение, поэтому для типа класса она обычно дороже префиксной. для встроенного `int` разница в стоимости не наблюдается, различие остаётся семантическим: какое значение получает окружающее выражение.

### приоритет и ассоциативность операторов

операторы бывают левоассоциативными и правоассоциативными. левоассоциативные выполняются слева направо, правоассоциативные справа налево. большинство операторов левоассоциативны, в том числе бинарные арифметические, поэтому большинство выражений группируется слева направо. правоассоциативны унарные операторы, операторы присваивания и условный оператор.

помимо ассоциативности у операций есть приоритет: операция с более высоким приоритетом выполняется раньше. для рассмотренных операций порядок от более высокого приоритета к более низкому такой:

| ++ (инкремент), -- (декремент) |
| --- |
| * (умножение), / (деление), % (остаток от деления) |
| + (сложение), - (вычитание) |

приоритет учитывают в составном арифметическом выражении:

```cpp


int a = 8;

int b = 7;

int c = a + 5 * ++b;      // 48
```

хотя бинарные операции левоассоциативны, первой выполняется операция инкремента `++b`: у неё приоритет выше. она увеличивает `b` и возвращает новое значение. затем выполняется умножение `5 * ++b`, и только после этого сложение `a + 5 * ++b`. при `a == 8` и исходном `b == 7` получается `8 + 5 * 8`, то есть 48.

если в одном выражении одна и та же скалярная переменная несколько раз изменяется инкрементом или декрементом без промежуточной точки следования, результат не определён. многое в наблюдаемом поведении зависит от компилятора, но стандарт считает такое выражение неопределённым поведением, а не реализацией с оговорённым результатом. пример:

```cpp


int count {1};

int result = ++count * 3 + count++ * 5;
```

и g++, и clang++ компилируют этот фрагмент, и значение `result` оказывается равным 16, как подсказывает пошаговый подсчёт. clang++ при этом выдаёт предупреждение. опираться на конкретное число нельзя: другой компилятор или другая версия вправе дать иной код.

### переопределение порядка операций

скобки задают группировку явно и переопределяют приоритет. пример:

```cpp


#include <iostream>



int main()

{

    int a {8};

    int b {7};

    int c {(a + 5) * ++b};      // c = 104

    std::cout << "c = " << c << std::endl;

}
```

сложение имеет приоритет ниже умножения, но выполняется первым, потому что заключено в скобки. выражение читается как `(a + 5) * ++b`. при тех же начальных значениях `++b` даёт 8, сумма в скобках равна 13, произведение равно 104.
