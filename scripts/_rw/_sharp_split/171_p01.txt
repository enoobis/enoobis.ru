




### File




Класс `File` реализует похожую функциональность с помощью статических методов:







- Copy() : копирует файл в новое место


- Create() : создает файл


- Delete() : удаляет файл


- Move : перемещает файл в новое место


- Exists(file) : определяет, существует ли файл
