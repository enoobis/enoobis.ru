для работы с каталогами в пространстве имён `System.IO` предназначены два класса: `Directory` и `DirectoryInfo`.

### класс directory

статический класс `Directory` предоставляет методы управления каталогами. часть этих методов:

- `CreateDirectory(path)`: создаёт каталог по указанному пути `path`
- `Delete(path)`: удаляет каталог по указанному пути `path`
- `Exists(path)`: определяет, существует ли каталог по указанному пути `path`. если существует, возвращается `true`, если не существует, возвращается `false`
- `GetCurrentDirectory()`: получает путь к текущей папке. это рабочий каталог процесса, относительно которого затем разрешаются относительные пути
- `GetDirectories(path)`: получает список подкаталогов в каталоге `path`
- `GetFiles(path)`: получает список файлов в каталоге `path`
- `GetFileSystemEntries(path)`: получает список подкаталогов и файлов в каталоге `path`
- `Move(sourceDirName, destDirName)`: перемещает каталог
- `GetParent(path)`: получение родительского каталога
- `GetLastWriteTime(path)`: возвращает время последнего изменения каталога
- `GetLastAccessTime(path)`: возвращает время последнего обращения к каталогу
- `GetCreationTime(path)`: возвращает время создания каталога

каждый статический вызов заново принимает путь строкой и выполняет проверки для этого вызова. состояние между вызовами класс не хранит.

### класс directoryinfo

класс `DirectoryInfo` предоставляет операции создания, удаления, перемещения и другие операции с каталогами. по набору возможностей он близок к `Directory`, но не является статическим: экземпляр хранит путь к одному каталогу и дальше работает с ним.

основные методы класса `DirectoryInfo`:

- `Create()`: создаёт каталог
- `CreateSubdirectory(path)`: создаёт подкаталог по указанному пути `path`
- `Delete()`: удаляет каталог
- `GetDirectories()`: получает список подкаталогов папки в виде массива `DirectoryInfo`
- `GetFiles()`: получает список файлов в папке в виде массива `FileInfo`
- `MoveTo(destDirName)`: перемещает каталог

основные свойства класса `DirectoryInfo`:

- `CreationTime`: время создания каталога
- `LastAccessTime`: время последнего доступа к каталогу
- `LastWriteTime`: время последнего изменения каталога
- `Exists`: определяет, существует ли каталог
- `Parent`: получение родительского каталога
- `Root`: получение корневого каталога
- `Name`: имя каталога
- `FullName`: полный путь к каталогу

свойства времени читают метаданные файловой системы, а не содержимое каталога. `Name` содержит только последний сегмент пути, `FullName` содержит путь целиком.

### directory или directoryinfo

оба класса дают близкий набор операций. выбор зависит от числа обращений к одному и тому же каталогу. для одной или двух операций с одним каталогом достаточно класса `Directory`. для последовательности операций с одним и тем же каталогом подходит `DirectoryInfo`. методы класса `Directory` выполняют дополнительные проверки безопасности при каждом вызове. для экземпляра `DirectoryInfo` такие проверки требуются не при каждой последующей операции: путь уже связан с объектом.
