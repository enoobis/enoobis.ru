класс `File` из пакета `java.io` с потоками байтов и символов напрямую не работает. его задача это сведения о файлах и каталогах: путь, существование, длина, список содержимого. на уровне операционной системы файл и каталог различаются, а в java оба описываются одним классом `File`. объект хранит путь, а не открытый дескриптор. обращение к файловой системе происходит в момент вызова метода, и результат отражает состояние на этот момент.

какой конструктор выбрать, зависит от того, файл или каталог должен обозначать объект:

```java


File(String путь_к_каталогу)

File(String путь_к_каталогу, String имя_файла)

File(File каталог, String имя_файла)
```

первый принимает путь одной строкой. второй собирает путь из каталога и имени файла, оба заданы строками. третий берёт каталог уже готовым объектом `File` и добавляет к нему имя. разделитель между частями подставляет реализация, вручную склеивать слэши не нужно.

пример:

```java


// создаем объект File для каталога

File dir1 = new File("C://SomeDir");

// создаем объекты для файлов, которые находятся в каталоге

File file1 = new File("C://SomeDir", "Hello.txt");

File file2 = new File(dir1, "Hello2.txt");
```

`dir1` указывает на каталог `C://SomeDir`. `file1` собран из двух строк, `file2` из объекта каталога и имени `Hello2.txt`. конструктор файл не создаёт и не проверяет, что путь существует. это только значение пути.

у `File` есть методы управления файлами и каталогами. часть из них:

- `boolean createNewFile()`: создаёт новый файл по пути, который передан в конструктор. при успешном создании возвращает `true`, иначе `false`
- `boolean delete()`: удаляет каталог или файл по пути, который передан в конструктор. при успешном удалении возвращает `true`
- `boolean exists()`: проверяет, существует ли по указанному в конструкторе пути файл или каталог. если существует, возвращает `true`, иначе `false`
- `String getAbsolutePath()`: возвращает абсолютный путь для пути, переданного в конструктор
- `String getName()`: возвращает краткое имя файла или каталога
- `String getParent()`: возвращает имя родительского каталога
- `boolean isDirectory()`: возвращает `true`, если по указанному пути располагается каталог
- `boolean isFile()`: возвращает `true`, если по указанному пути находится файл
- `boolean isHidden()`: возвращает `true`, если каталог или файл являются скрытыми
- `long length()`: возвращает размер файла в байтах
- `long lastModified()`: возвращает время последнего изменения файла или каталога. значение это число миллисекунд, прошедших с начала эпохи unix
- `String[] list()`: возвращает массив файлов и подкаталогов, которые находятся в определённом каталоге
- `File[] listFiles()`: возвращает массив файлов и подкаталогов, которые находятся в определённом каталоге
- `boolean mkdir()`: создаёт новый каталог и при успешном создании возвращает `true`
- `boolean renameTo(File dest)`: переименовывает файл или каталог

`list()` отдаёт только имена, строки. `listFiles()` отдаёт те же элементы уже объектами `File`, с путём, по которому можно сразу звать `isDirectory` или `delete`. эпоха unix, от которой считается `lastModified`, это 1970-01-01 00:00:00 utc. `mkdir` создаёт один уровень каталога и не создаёт недостающих родителей: родительский путь к моменту вызова уже должен существовать. `delete` удаляет пустой каталог или файл и возвращает `false`, если удаление не выполнено. `renameTo` тоже сообщает о неудаче через `false`, а не через исключение.

### работа с каталогами

если объект `File` представляет каталог, `isDirectory()` возвращает `true`. содержимое, вложенные подкаталоги и файлы, дают `list()` и `listFiles()`. обход одного каталога:

```java


import java.io.File;



public class Program {



    public static void main(String[] args) {

        

        // определяем объект для каталога

        File dir = new File("C://SomeDir");

        // если объект представляет каталог

        if(dir.isDirectory())

        {

            // получаем все вложенные объекты в каталоге

            for(File item : dir.listFiles()){

             

                 if(item.isDirectory()){

                     

                     System.out.println(item.getName() + "  \t folder");

                 }

                 else{

                     

                     System.out.println(item.getName() + "\t file");

                 }

             }

        }

    }

}
```

`dir` указывает на `C://SomeDir`. ветка `isDirectory` отсекает случай, когда по пути лежит файл или пути нет. `listFiles()` возвращает непосредственных потомков, без рекурсии вглубь. у каждого элемента `isDirectory` отличает каталог от файла, `getName` даёт короткое имя без родительского пути. в консоль для каталога дописывается `folder`, для файла `file`.

дальше каталог создаётся, переименовывается и удаляется:

```java


import java.io.File;



public class Program {



    public static void main(String[] args) {

        

        // определяем объект для каталога

        File dir = new File("C://SomeDir//NewDir");

        boolean created = dir.mkdir();

        if(created)

            System.out.println("Folder has been created");

        // переименуем каталог

        File newDir = new File("C://SomeDir//NewDirRenamed");

        dir.renameTo(newDir);

        // удалим каталог

        boolean deleted = newDir.delete();

        if(deleted)

            System.out.println("Folder has been deleted");

    } 

}
```

`mkdir` создаёт `C://SomeDir//NewDir`. родитель `C://SomeDir` должен уже быть, иначе метод вернёт `false` и каталог не появится. при `created == true` печатается подтверждение. `renameTo` меняет путь на `C://SomeDir//NewDirRenamed`: объект `dir` после этого по-прежнему хранит старый путь, новый путь хранит `newDir`. удаление идёт уже по `newDir`. при успехе `delete` возвращает `true`, и печатается сообщение об удалении.

### работа с файлами

работа с файлами устроена так же, как с каталогом: тот же класс и те же методы пути. ниже читаются сведения об одном файле и создаётся другой:

```java


import java.io.File;

import java.io.IOException;



public class Program {



    public static void main(String[] args) {

        

        // определяем объект для каталога

        File myFile = new File("C://SomeDir//notes.txt");

        System.out.println("File name: " + myFile.getName());

        System.out.println("Parent folder: " + myFile.getParent());

        if(myFile.exists())

            System.out.println("File exists");

        else

            System.out.println("File not found");

        

        System.out.println("File size: " + myFile.length());

        if(myFile.canRead())

            System.out.println("File can be read");

        else

            System.out.println("File can not be read");

        

        if(myFile.canWrite())

            System.out.println("File can be written");

        else

            System.out.println("File can not be written");

        

        // создадим новый файл

        File newFile = new File("C://SomeDir//MyFile");

        try

        {

            boolean created = newFile.createNewFile();

            if(created)

                System.out.println("File has been created");

        }

        catch(IOException ex){

            

            System.out.println(ex.getMessage());

        }  

    } 

}
```

`myFile` указывает на `C://SomeDir//notes.txt`. печатаются краткое имя (`getName`) и родительский каталог (`getParent`). `exists` выбирает между сообщениями о наличии файла и о том, что файл не найден. `length` даёт размер в байтах. для отсутствующего файла это `0`, поэтому длину имеет смысл читать после проверки существования. `canRead` и `canWrite` сообщают, разрешены ли чтение и запись с точки зрения текущих прав. затем `newFile` указывает на `C://SomeDir//MyFile`. `createNewFile()` создаёт пустой файл. при ошибке ввода-вывода метод выбрасывает `IOException`, поэтому вызов перехватывается в `try...catch`, как в примере. если файл по этому пути уже есть, метод возвращает `false` и исключение не бросает: ветка с сообщением о создании тогда не выполняется.
