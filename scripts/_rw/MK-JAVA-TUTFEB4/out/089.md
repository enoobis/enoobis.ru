для работы с консолью в java есть класс `Console` из пакета `java.io`. отдельного устройства он не открывает: ввод и вывод идут через консоль, уже связанную с виртуальной машиной, те же `System.in` и `System.out`. класс сокращает типичные операции: приглашение, чтение строки, чтение пароля без эха, форматированный вывод.

объект консоли даёт статический метод `System.console()`:

```java
Console console = System.console();
```

если консоли у процесса нет, метод возвращает `null`, а не пустую заглушку. так бывает при перенаправлении стандартных потоков и при запуске из среды, которая подменяет консоль своей панелью.

основные методы:

- `flush()`: выводит на консоль все данные из буфера
- `format()`: выводит на консоль строку с использованием форматирования
- `printf()`: выводит на консоль строку с использованием форматирования, та же схема, что у `format`
- `String readLine()`: считывает с консоли введённую пользователем строку
- `char[] readPassword()`: считывает с консоли введённую пользователем строку, символы при этом на консоли не отображаются

`printf` вызывает `format` и возвращает тот же `PrintWriter` консоли. у `readLine` и `readPassword` есть перегрузки с форматной строкой: сначала печатается приглашение, затем читается ввод. пароль возвращается массивом `char`. массив после проверки можно затереть нулями. объект `String` неизменяем, и затереть его содержимое тем же способом нельзя.

чтение логина и пароля:

```java
import java.io.Console;

public class Program {

    public static void main(String[] args) {
        
        // получаем консоль
        Console console = System.console();
		if(console!=null){
			// считываем данные с консоли
			String login = console.readLine("Введите логин:");
			char[] password = console.readPassword("Введите пароль:");
			
			console.printf("Введенный логин: %s \n", login);
			console.printf("Введенный пароль: %s \n", new String(password));
		}
    }
}
```

сначала получается консоль. при `console != null` читаются логин и пароль. приглашения заданы аргументами `readLine` и `readPassword`. затем оба значения печатаются через `printf`. пароль для печати оборачивается в `new String(password)`: спецификатор `%s` ожидает строку, а не массив символов. в рабочей программе такой массив после использования затирают, здесь он только выводится.

доступ к консоли есть только тогда, когда программа сама запущена в консоли. при запуске в netbeans `System.console()` возвращает `null`. поэтому полученное значение проверяют на `null` до любого вызова метода. запуск из командной строки даёт живой объект, и фрагмент выше читает логин с паролем:
