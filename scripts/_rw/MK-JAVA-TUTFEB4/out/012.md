большинство операций java совпадает с операциями других си-подобных языков. унарная операция применяется к одному операнду, бинарная к двум, тернарная к трём. операнд это переменная или значение, например число, которое участвует в операции.

в арифметических операциях участвуют числа. бинарные операции берут два операнда, унарные один.

- `+` операция сложения двух чисел:

```java


int a = 10;

int b = 7;

int c = a + b;  // 17

int d = 4 + b;  // 11
```

- `-` операция вычитания двух чисел:

```java


int a = 10;

int b = 7;

int c = a - b;  // 3

int d = 4 - a;  // -6
```

- `*` операция умножения двух чисел:

```java


int a = 10;

int b = 7;

int c = a * b;  // 70

int d = b * 5;  // 35
```

- `/` операция деления двух чисел. если оба операнда целые, деление выполняется в целочисленной арифметике: дробная часть отбрасывается, результат усекается к нулю. тип переменной, которой присваивается результат, на уже выполненное деление не влияет. присваивание в `float` или `double` не восстанавливает отброшенную дробную часть. чтобы частное имело тип с плавающей точкой, хотя бы один операнд должен иметь такой тип:

```java


int a = 20;

int b = 5;

int c = a / b;  // 4

double d = 22.5 / 4.5;  // 5.0
```

```java


double k = 10 / 4;     // 2

System.out.println(k);
```

```java


double k = 10.0 / 4;     // 2.5

System.out.println(k);
```

в первом из двух последних фрагментов оба операнда целые, `10 / 4` равно 2, и только затем результат расширяется до `double`. во втором операнд `10.0` имеет тип `double`, деление идёт в плавающей арифметике и даёт `2.5`.

- `%` получение остатка от деления двух чисел:

```java


int a = 33;

int b = 5;

int c = a % b;  // 3

int d = 22 % 4; // 2 (22 - 4*5 = 2)
```

для целых остаток имеет знак делимого. выражение `a % b` связано с частным соотношением `a == (a / b) * b + (a % b)`.

есть две унарные арифметические операции над одним числом: `++` (инкремент) и `--` (декремент). у каждой две формы, префиксная и постфиксная. обе меняют переменную на единицу. значение самого выражения различно: префиксная форма возвращает уже изменённое значение, постфиксная возвращает прежнее.

- `++` (префиксный инкремент). переменная увеличивается на единицу, выражение получает новое значение. в `z=++y` сначала `y` увеличивается на 1, затем это значение присваивается `z`:

```java


int a = 8;

int b = ++a;

System.out.println(a);	// 9

System.out.println(b);	// 9
```

- `++` (постфиксный инкремент). переменная тоже увеличивается на единицу, но выражение возвращает старое значение. в `z=y++` сначала текущее значение `y` присваивается `z`, и только после этого `y` увеличивается на 1:

```java


int a = 8;

int b = a++;

System.out.println(a);	// 9

System.out.println(b);	// 8
```

- `--` (префиксный декремент). переменная уменьшается на единицу, выражение получает новое значение. в `z=--y` сначала `y` уменьшается на 1, затем это значение присваивается `z`:

```java


int a = 8;

int b = --a;

System.out.println(a);	// 7

System.out.println(b);	// 7
```

- `--` (постфиксный декремент). в `z=y--` сначала текущее значение `y` присваивается `z`, затем `y` уменьшается на 1:

```java


int a = 8;

int b = a--;

System.out.println(a);	// 7

System.out.println(b);	// 8
```

побочный эффект инкремента и декремента относится к одной переменной. если та же переменная в этом же выражении читается или меняется ещё одним оператором, порядок побочных эффектов перестаёт быть очевидным.

### приоритет арифметических операций

одни операции имеют больший приоритет, чем другие, и поэтому выполняются раньше. операции в порядке уменьшения приоритета:

`++` (постфиксный инкремент), `--` (постфиксный декремент)

`++` (префиксный инкремент), `--` (префиксный декремент)

`*` (умножение), `/` (деление), `%` (остаток от деления)

`+` (сложение), `-` (вычитание)

приоритет определяет разбор составного выражения:

```java


int a = 8;

int b = 7;

int c = a + 5 * ++b;      

System.out.println(c);	// 48
```

сначала выполняется `++b`: у префиксного инкремента приоритет выше умножения и сложения. переменная `b` увеличивается с 7 до 8, выражение возвращает 8. затем выполняется умножение `5 * ++b`, получается 40. в последнюю очередь выполняется сложение `a + 5 * ++b`. при `a = 8` результат равен 48.

скобки задают другой порядок: подвыражение в скобках вычисляется как отдельная единица.

```java


int a = 8;

int b = 7;

int c = (a + 5) * ++b;    

System.out.println(c);	// 104
```

сложение имеет более низкий приоритет, чем умножение, но в `(a + 5) * ++b` сначала вычисляется сумма, потому что она заключена в скобки. при тех же начальных значениях получается `(8 + 5) * 8`, то есть 104.

### ассоциативность операций

при одинаковом приоритете порядок вычисления задаёт ассоциативность. по ней операторы делятся на две группы:

- левоассоциативные операторы, которые выполняются слева направо
- правоассоциативные операторы, которые выполняются справа налево

умножение и деление имеют один и тот же приоритет. от разбора зависит значение выражения:

```java
int x = 10 / 5 * 2;
```

разбор `(10 / 5) * 2` даёт 4. разбор `10 / (5 * 2)` даёт 1.

все арифметические операторы, кроме префиксного инкремента и декремента, левоассоциативны, то есть выполняются слева направо. выражение `10 / 5 * 2` разбирается как `(10 / 5) * 2`, результат равен 4. префиксные `++` и `--`, а также присваивание, правоассоциативны: цепочка `a = b = c` читается как `a = (b = c)`.

### операции с числами с плавающей точкой

двоичные числа с плавающей точкой не дают точного представления большинства десятичных дробей. для финансовых расчётов и любых вычислений, где ошибка округления недопустима, тип `double` не подходит:

```java


double d = 2.0 - 1.1;

System.out.println(d);
```

ожидаемое десятичное значение 0.9 в переменной `d` не появляется. печатается `0.8999999999999999`. мантисса хранится в двоичной системе, а у числа 0.1, как и у многих других десятичных дробей, двоичная запись бесконечна. в конечную мантиссу попадает округление, и ошибка проявляется уже в вычитании. для десятичной арифметики с заданным масштабом используют класс `BigDecimal`: число хранится как немасштабированное целое и отдельный масштаб, а не как двоичная мантисса.
