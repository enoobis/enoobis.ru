иногда нужен ровно один объект некоторого типа, и имя этого типа в программе не используется. такой класс объявляют анонимным. чаще всего анонимный класс появляется там, где требуется объект интерфейса, а отдельное именованное объявление только раздувало бы единицу компиляции. компилятор порождает синтетический класс, обычно с именем вида `Внешний$1`.

общий синтаксис анонимного класса:

```java


new SuperType(аргументы для конструктора суперкласса)

{

    // поля и методы анонимного класса

}
```

`SuperType` может быть интерфейсом: тогда анонимный класс реализует этот интерфейс. `SuperType` может быть классом: тогда анонимный класс расширяет этот класс.

у анонимного класса нет конструктора. имя конструктора обязано совпадать с именем класса, а имени у класса нет. аргументы создания передаются конструктору суперкласса, если у суперкласса есть конструктор с параметрами. после этого конструктора выполняется блок инициализации экземпляра, если он записан в теле.

если `SuperType` является интерфейсом, аргументы конструктора не передаются: у интерфейса конструктора нет. после имени типа ставятся пустые скобки:

```java


new InterfaceType()

{

    // поля и методы анонимного класса

}
```

анонимный класс остаётся внутренним классом. в нестатическом контексте у него есть объемлющий экземпляр, и он захватывает эффективно финальные локальные переменные так же, как локальный класс. с java 8 однометодный интерфейс чаще закрывают лямбдой: у лямбды нет собственного состояния и собственного `this`. анонимный класс по-прежнему нужен, когда методов больше одного, когда нужны поля или когда `this` внутри тела должен указывать на сам анонимный экземпляр.

### анонимный класс вместо интерфейса

типичное место анонимного класса: там, где параметр имеет тип интерфейса, а реализация нужна один раз.

```java


public class Program{

     

	public static void main(String[] args) {



        var rectangle = new Movable(){



            public void move(int distance){

                System.out.printf("Перемещаем прямоугольник на %d пикселей\n", distance);

            }

        };

        moveObject(rectangle, 56);     // Перемещаем прямоугольник на 56 пикселей

	}

    // перемещаем объект Movable на расстояние distance

    static void moveObject(Movable obj, int distance){

        obj.move(distance);

    }

}



interface Movable{

    void move(int distance);

}
```

основные моменты:

- объявлен интерфейс `Movable` с методом `move()`

```java


interface Movable{

    void move(int distance);

}
```

- метод `moveObject()` принимает объект интерфейса `Movable` и вызывает у него `move()`

```java


static void moveObject(Movable obj, int distance){

    obj.move(distance);

}
```

- переменная `rectangle` ссылается на объект анонимного класса, который реализует `Movable`. запись похожа на обычную реализацию интерфейса, только у класса нет имени: на его месте стоит имя интерфейса, и отдельного конструктора у анонимного класса нет

```java


var rectangle = new Movable(){



    public void move(int distance){

        System.out.printf("Перемещаем прямоугольник на %d пикселей\n", distance);

    }

};
```

- затем вызывается `moveObject()`, и в него передаётся объект анонимного класса. в полном тексте выше расстояние равно 56, в отдельном фрагменте вызова записано 54:

```java
moveObject(rectangle, 54);
```

отдельную переменную под ссылку заводить не обязательно. объект анонимного класса создаётся прямо в списке аргументов:

```java


public class Program{

     

	public static void main(String[] args) {



        // передаем объект анонимного класса

        moveObject(new Movable(){

            public void move(int distance){

                System.out.printf("Человек идет на расстояние %d метров\n", distance);

            }

        }, 

        100);

	}

    static void moveObject(Movable obj, int distance){

        obj.move(distance);

    }

}



interface Movable{

    void move(int distance);

}
```

здесь в `moveObject` сразу передаётся анонимная реализация `Movable`, а вторым аргументом расстояние 100. метод печатает, что человек проходит это расстояние.

### анонимный класс вместо класса

реже анонимный класс расширяет обычный класс, а не реализует интерфейс. механизм тот же: выражение `new` создаёт экземпляр безымянного подкласса.

```java


public class Program{

     

	public static void main(String[] args) {



        printPerson(

            new Person("Tom"){



                private String company = "Yandex";



                // реализация метода print

                @Override

                void print(){

                    System.out.printf("Employee. Name: %s;  Company: %s\n", super.getName(), company);

                }

            }

        );

	}

    static void printPerson(Person person){

        person.print();

    }

}

abstract class Person{

    

    private String name;

    String getName(){ return name;}



    Person(String name){



        this.name = name;

    }



    abstract void print();

}
```

основные моменты:

- абстрактный класс `Person` представляет человека. конструктор принимает имя и сохраняет его в закрытом поле. абстрактный метод `print()` оставлен подклассам: у самого `Person` реализации нет, поэтому выражение `new Person(...)` без тела подкласса было бы незаконно

- статический метод `printPerson()` принимает объект `Person` и вызывает у него `print()`

```java


static void printPerson(Person person){

    person.print();

}
```

- при вызове `printPerson()` передаётся объект анонимного класса. конструктором абстрактного класса объект абстрактного типа не создают: такой вызов здесь означает создание экземпляра анонимного подкласса, который расширяет `Person` и передаёт в его конструктор строку `"Tom"`. в фигурных скобках записано тело анонимного класса. к состоянию добавлено поле компании, для абстрактного метода `print()` дана реализация. из этой реализации, как из любого производного класса, функциональность базового класса доступна через `super`: `super.getName()` читает имя, записанное конструктором `Person`

```java
new Person("Tom")
```

```java


{

    private String company = "Yandex";

    @Override

    void print(){

        System.out.printf("Employee. Name: %s;  Company: %s\n", super.getName(), company);

    }

}
```

### инициализаторы в анонимных классах

конструктор в анонимном классе объявить нельзя. начальное состояние, которое не сводится к аргументам суперконструктора, задаётся блоком инициализации экземпляра. этот блок выполняется после конструктора суперкласса и до того, как ссылка на объект станет видна вызывающему коду.

```java


printPerson(

    new Person("Tom"){



        private String company;



        // блок инициализатора

        {

            company = "Sber";

        }

        // реализация метода print

        @Override

        void print(){

            System.out.printf("Employee. Name: %s;  Company: %s\n", super.getName(), company);

        }

    }

);
```
