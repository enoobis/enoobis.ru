операции присваивания записывают значение в переменную. простая форма `=` кладёт в левый операнд значение правого. составные формы соединяют присваивание с другой операцией: сначала операция применяется к текущему значению переменной и правому операнду, затем результат записывается обратно.

у составной формы есть отдельное правило преобразования. результат приводится к типу левой переменной неявно, в том числе там, где обычное присваивание того же выражения потребовало бы явного приведения. для `byte b` выражение `b = b + 1` не компилируется, потому что `b + 1` имеет тип `int`, а `b += 1` компилируется: приведение к `byte` входит в семантику `+=`.

- `=` просто приравнивает одно значение другому: `c=b;`
- `+=` `c+=b;` (переменной `c` присваивается результат сложения `c` и `b`)
- `-=` `c-=b;` (переменной `c` присваивается результат вычитания `b` из `c`)
- `*=` `c*=b;` (переменной `c` присваивается результат произведения `c` и `b`)
- `/=` `c/=b;` (переменной `c` присваивается результат деления `c` на `b`)
- `%=` `c%=b;` (переменной `c` присваивается остаток от деления `c` на `b`)
- `&=` `c&=b;` (переменной `c` присваивается значение `c&b`)
- `|=` `c|=b;` (переменной `c` присваивается значение `c|b`)
- `^=` `c^=b;` (переменной `c` присваивается значение `c^b`)
- `>>=` `c>>=b;` (переменной `c` присваивается значение `c>>b`)
- `>>>=` `c>>>=b;` (переменной `c` присваивается значение `c>>>b`)

в том же ряду стоит сдвиг влево с присваиванием: `<<=` записывает в переменную результат `<<`. семантика та же, что у остальных составных форм. в примере ниже используются и `<<=`, и `>>=`.

примеры операций:

```java
int a = 5;
a += 10;        // 15
a -= 3;         // 12
a *= 2;         // 24
a /= 6;         // 4
a <<= 4;      // 64
a >>= 2;      // 16
System.out.println(a);	// 16
```

`a` начинается с 5. после `+= 10` значение равно 15, после `-= 3` равно 12, после `*= 2` равно 24, после `/= 6` равно 4. `a <<= 4` сдвигает 4 на четыре разряда влево, получается 64. `a >>= 2` сдвигает 64 на два разряда вправо, получается 16. это значение печатает `println`.

### приоритет операций

приоритет задаёт, какая операция в выражении выполняется раньше. операторы перечислены от большего приоритета к меньшему:

| `expr++` `expr--` |
| --- |
| `++expr` `--expr` `+expr` `-expr` `~` `!` |
| `*` `/` `%` |
| `+` `-` |
| `<<` `>>` `>>>` |
| `<` `>` `<=` `>=` `instanceof` |
| `==` `!=` |
| `&` |
| `^` |
| `\|` |
| `&&` |
| `\|\|` |
| `? :` (тернарный оператор) |
| `=` `+=` `-=` `*=` `/=` `%=` `&=` `^=` `\|=` `<<=` `>>=` `>>>=` (операторы присваивания) |

чем выше оператор в этой таблице, тем больше его приоритет. скобки повышают приоритет операции, заключённой в выражении: подвыражение в скобках вычисляется раньше операций снаружи. присваивание стоит в нижней строке и правоассоциативно, поэтому `a = b = 1` сначала записывает 1 в `b`, затем значение присваивания, то есть 1, записывает в `a`.
