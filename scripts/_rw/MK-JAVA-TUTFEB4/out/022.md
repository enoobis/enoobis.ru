если поля хранят состояние объекта, то методы задают его поведение. метод содержит набор операторов, которые выполняют определённые действия. действие, относящееся к классу, оформляется методом.

### определение методов

общий вид объявления метода:

```java


[модификаторы] тип_возвращаемого_значения название_метода ([параметры]){

	// тело метода

}
```

модификаторы и параметры необязательны. модификаторы задают доступ и свойства метода, параметры принимают входные значения. если параметров нет, скобки после имени остаются пустыми. в фигурных скобках записывается тело: операторы, которые выполняются при вызове.

точка входа любой программы на java оформляется методом `main`. этот метод присутствует в главном классе:

```java


class Program{



    public static void main(String[] args) {  



        System.out.println("Hello enoobis.ru!");

    }

}
```

служебные слова `public` и `static` являются модификаторами. `public` открывает метод за пределы пакета, `static` относит его к классу, а не к экземпляру: к моменту входа в программу объекта-получателя ещё нет. дальше указан тип возвращаемого значения. слово `void` означает, что метод не вырабатывает значения. вызов завершается и не передаёт результат вызывающему коду.

затем стоит имя метода, `main`, и в скобках параметры: `String[] args`. этот массив строк среда передаёт как аргументы командной строки. тело метода, все выполняемые им действия, заключено в фигурные скобки.

пример класса с собственным методом:

```java
      

class Person{ 

    String name;

    int age;



    void print(){

        System.out.printf("Name: %s	\tAge: %d\n", name, age);

    }

}



class Program{



    public static void main(String[] args) {  



    }

}
```

объявлен класс `Person` с полями `name` и `age` и методом `print`. возвращаемый тип `print` равен `void`, то есть метод не возвращает значение, и параметров у него нет. единственное действие метода состоит в выводе на консоль значений `name` и `age`. у метода экземпляра есть неявная ссылка на текущий объект, поэтому эти имена обозначают поля того экземпляра, на котором метод вызван.

чтобы метод выполнился, его вызывают.

### вызов метода

вызов записывается так:

```java


имя_метода(аргументы);
```

после имени метода стоят скобки. в них перечисляются аргументы: значения для параметров метода. число и типы аргументов согласуются с объявлением, иначе вызов не компилируется.

в классе `Program` объявлен метод `main`, и отдельно вызывать его из текста программы не нужно. среда выполнения java вызывает `main` сама. остальные методы вызываются явно. выполнение программы начинается с `main()`, поэтому прочие вызовы размещают в `main` либо в методах, которые уже были вызваны по цепочке от `main`. вызов определённого выше `print`:

```java


class Program{



    public static void main(String[] args) {  



  		// создаем объект Person

        Person tom = new Person();



  		// устанавливаем значения полей класса

        tom.name = "Tom";

        tom.age = 41;



  		// вызываем метод print

        tom.print();

    }

}



class Person{ 

    String name;

    int age;



    void print(){

        System.out.printf("Name: %s	\tAge: %d\n", name, age);

    }

}
```

для вызова служит выражение `tom.print()`. как и у поля, после имени переменной стоит точка и имя члена. параметров у `print` нет, поэтому после имени при вызове ставятся пустые скобки. точка выбирает объект `tom`: внутри метода поля `name` и `age` относятся к этому экземпляру. на консоли появляется информация о полях объекта:

```bash


Name: Tom		Age: 41
```

общее действие выносят в отдельный метод и вызывают его из разных мест программы, без копирования одних и тех же операторов:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();



        tom.name = "Tom";

        tom.age = 41;

        tom.print();



        tom.name = "Tomas";

        tom.print();



        tom.name = "Tommy";

        tom.print();

    }

}



class Person{ 

    String name;

    int age;



    void print(){

        System.out.printf("Name: %s	\tAge: %d\n", name, age);

    }

}
```

имя человека присваивается три раза, и каждый раз `print` выводит текущие поля того же объекта. меняется состояние, текст вызова метода остаётся одним и тем же. консольный вывод:

```bash


Name: Tom		Age: 41

Name: Tomas		Age: 41

Name: Tommy		Age: 41
```

возраст при этих присваиваниях не трогается, поэтому во всех трёх строках остаётся значение 41, а имя меняется так, как записано перед каждым вызовом.

### вызов методов в других методах класса

один метод класса может вызывать другие методы этого же класса:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();  // создаем объект Person



        tom.name = "Tom";

        tom.age = 41;

        tom.print();

    }

}



// класс Person

class Person{ 

    String name;

    int age;



    void printName(){

        System.out.printf("Name: %s\n", name);

    }

    void printAge(){

        System.out.printf("Age: %d\n", age);

    }

    void print(){

        printName();

        printAge();

    }

}
```

в методе `print` вызываются два других метода класса, `printName` и `printAge`. вызов без указания объекта относится к тому же экземпляру, на котором выполнен `print`: неявный получатель сохраняется, и оба метода читают поля `tom`. консольный вывод программы:

```bash


Name: Tom

Age: 41
```

разбиение на методы меняет структуру текста, а наблюдаемое поведение остаётся выводом имени и возраста. общий метод `print` собирает два более мелких действия.
