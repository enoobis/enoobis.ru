в программе допускаются методы с одним и тем же именем, но с разными типами и/или разным числом параметров. такой механизм называется **перегрузкой методов** (method overloading).

пример с тремя вариантами одного имени:

```java
class Program{

    public static void main(String[] args) {  

        Calcualtor calc = new Calcualtor();
        System.out.println(calc.sum(2, 3));          // 5
        System.out.println(calc.sum(4.5, 3.2));      // 7.7
        System.out.println(calc.sum(4, 3, 7));       // 14
    }
}

class Calcualtor{

    int sum(int x, int y){
             
        return x + y;
    }
    double sum(double x, double y){
             
        return x + y;
    }
    int sum(int x, int y, int z){
             
        return x + y + z;
    }
}
```

в классе `Calcualtor` объявлены три варианта, три перегрузки метода `sum()`. при вызове по типу и числу передаваемых аргументов выбирается та версия, которая подходит. выбор делает компилятор: он смотрит статическую сигнатуру вызова и связывает его с наиболее специфичным применимым объявлением. два аргумента типа `int` попадают в первый `sum`, два аргумента типа `double` во второй, три аргумента типа `int` в третий. это разрешение перегрузки на этапе компиляции. переопределение метода в подклассе устроено иначе: там конкретный метод экземпляра выбирается во время выполнения по классу объекта.

на перегрузку влияют число и типы параметров. одно лишь различие в типе возвращаемого значения перегрузку не создаёт. в следующем примере методы `sum` различаются только возвращаемым типом:

```java
class Program{

    public static void main(String[] args) {  

        Calcualtor calc = new Calcualtor();
        System.out.println(calc.sum(2, 3));
    }
}

class Calcualtor{

    int sum(int x, int y){
             
        return x + y;
    }
    // Ошибка - метод sum уже определен
    double sum(int x, int y){
             
        return x + y;
    }
}
```

такая пара перегрузкой не считается. программа некорректна и не компилируется: метод с тем же числом и теми же типами параметров объявлен несколько раз. сигнатура, по которой различают перегрузки, включает имя метода и типы параметров. возвращаемый тип в эту сигнатуру не входит, поэтому два объявления `sum(int, int)` для компилятора совпадают, даже когда одно обещает `int`, а другое `double`.
