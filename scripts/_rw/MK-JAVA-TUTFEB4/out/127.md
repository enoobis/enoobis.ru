модуль может зависеть от другого модуля и пользоваться его типами. за основу берётся проект из предыдущей лекции, простейший модуль:

![модули в java](/uploads/course-lectures/73aa602bb44aa11c59dc2bac0bc5bb2f767828e1.png)

модуль называется `demo` и лежит в одноимённом каталоге. в том же каталоге находится дескриптор `module-info.java`. код программы лежит в каталоге `com/enoobis/hello`, в файле `Hello.java`.

в `Hello.java` сообщение выводится в графическое окно инфраструктуры swing:
```java
package com.enoobis.hello;

import javax.swing.JOptionPane;

public class Hello{
	
	public static void main(String[] args){
		//System.out.println("Hello enoobis.ru!");
		JOptionPane.showMessageDialog(null, "Hello Demo Module!");
	}
}
```
сообщение показывает статический метод `showMessageDialog()` класса `JOptionPane` из пакета `javax.swing`. импорт в начале файла делает короткое имя видимым компилятору внутри модуля. для чужого модуля одного импорта мало: модуль-клиент должен объявить зависимость, иначе пакет `javax.swing` для `demo` нечитаем и компиляция обрывается, даже если строка `import` на месте.

модуль встроенного класса указан в документации jdk 9 и последующих версий. в начале описания класса приводится имя модуля.

![поиск модулей в java 9](/uploads/course-lectures/4f36e640b781d33833f2b56ce25b3cbf6aedd742.png)

документация помещает `JOptionPane` в модуль `java.desktop`. зависимость записывается в `module-info.java` в корневом каталоге модуля:
```java
module demo {
    requires java.desktop;
}
```
после директивы `requires` стоит имя модуля, от которого зависит текущий. несколько зависимостей записываются несколькими директивами `requires`. модуль `java.desktop` входит в состав jdk, поэтому резолвер находит его в образе среды выполнения, а `--module-path` в команде ниже по-прежнему указывает только каталог `demo`.

дальше модуль компилируется и запускается.
```bash
eugene@Eugene:/java$ javac demo/module-info.java demo/com/enoobis/hello/Hello.java
eugene@Eugene:/java$ java  --module-path demo --module demo/com.enoobis.hello.Hello
```
после запуска открывается графическое окно:
