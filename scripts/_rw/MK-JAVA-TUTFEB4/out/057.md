в java класс может быть вложенным (nested): его объявление находится внутри другого класса. вложенные классы делятся на два вида. внутренний класс (inner class) является нестатическим вложенным классом. второй вид составляет статический вложенный класс (static nested class). различие семантическое: у экземпляра внутреннего класса есть скрытая ссылка на экземпляр внешнего класса, у экземпляра статического вложенного класса такой ссылки нет.

**внутренние классы** (inner class) вводят в программу по двум причинам:

- внутренний класс можно скрыть от других классов того же пакета: без модификатора `public` тип не виден за пределами пакета, а с модификатором `private` он виден только внешнему классу.

- методам внутреннего класса доступны члены внешней области видимости, включая поля и методы внешнего класса с модификатором `private`. доступ идёт по ссылке на объемлющий экземпляр, которую компилятор передаёт конструктору внутреннего класса.

пример: класс `Person` содержит класс `Account`.

```java


public class Program{

      

    public static void main(String[] args) {

             

        Person tom = new Person("Tom", "qwerty");

        tom.print();

        tom.account.print();

    }

}

class Person{

     

    private String name;

    Account account;

 

    Person(String name, String password){

        this.name = name;

        account = new Account(password);

    }

    void print(){

        System.out.printf("Person \t Name: %s \t Password: %s \n", name, account.password);

    }

 

    public class Account{

        private String password;

         

        Account(String pass){ this.password = pass; }



        void print(){

            System.out.printf("Account Login: %s \t Password: %s \n", Person.this.name, password);

        }

    }

}
```

устройство этого текста:

- внутренний класс во всём остальном устроен как обычный класс, но его экземпляр связан с экземпляром внешнего. внутри внешнего класса объект создаётся обычным `new`. снаружи, если уровень доступа позволяет, используется форма `внешнийЭкземпляр.new ВнутреннийКласс()`. без объемлющего экземпляра объект внутреннего класса не создаётся.

- внутренний класс читает и пишет все поля внешнего класса, в том числе закрытые модификатором `private`. внешний класс точно так же обращается ко всем членам внутреннего класса, включая поля и методы с `private`. в примере `print` внешнего класса читает `account.password`, хотя поле закрыто.

- ссылку на объект внешнего класса из внутреннего получают выражением `Внешний_класс.this`, например `Person.this`. через `Person.this.name` метод `Account.print` читает закрытое поле внешнего экземпляра, а не одноимённый член внутреннего класса.

- область, где внутренний класс вообще можно упомянуть, ограничена его модификатором доступа и местом объявления. закрытый внутренний класс снаружи внешнего класса недоступен, поэтому посторонний класс пакета создать его экземпляр не может.

### локальные внутренние классы

внутренний класс объявляется не только на уровне членов, но и внутри произвольного блока: в методе, в теле цикла, в ветви условия. смысл такого класса в том, что его объекты нужны лишь в одном контексте, например в одном методе, и за пределами этого блока тип не должен существовать.

локальный класс не объявляют со спецификатором доступа (`public`, `private`, `protected`): спецификатор здесь синтаксически запрещён, а область действия и так ограничена блоком объявления. снаружи блока имени класса нет, обратиться к нему можно только из того контекста, где он определён.

```java


public class Program{

     

	public static void main(String[] args) {



        Person tom = new Person("Tom");

        tom.setTempAccount("qwerty");

	}

}





class Person{

	

	private String name;



	Person(String name){ this.name = name; }

	

	void setTempAccount (String password){

		

		class TempAccount{

			

			private void print(){

				System.out.printf("Account Login: %s \t Password: %s \n", name, password);

			}

		}

		TempAccount account = new TempAccount();

		account.print();

	}

}
```

класс `TempAccount` и его объекты существуют только внутри метода `setTempAccount`. из этого метода видны и закрытые члены локального класса: метод `print()` намеренно объявлен как `private`, и вызов `account.print()` из `setTempAccount` при этом законен, потому что вызов находится в том же блоке, где класс объявлен. локальный класс видит поля внешнего экземпляра (`name`) и локальные переменные метода (`password`). локальную переменную или параметр он захватывает только если переменная является финальной или эффективно финальной: после инициализации ей не присваивают новое значение. параметр `password` в примере не перезаписывается, поэтому захват допустим.

### статические вложенные классы

внутри класса объявляют и статические вложенные классы (static nested class). от внутреннего класса статический вложенный отличается отсутствием ссылки на экземпляр внешнего класса: объект создаётся как `Внешний.Вложенный` без экземпляра `Внешний`. статические члены внешнего класса ему доступны, в том числе закрытые. к экземплярным членам внешнего класса он обращается только через явную ссылку, которую ему передали. такой тип прячет составную структуру данных внутри внешнего класса и не привязывает её время жизни к внешнему объекту.

```java


class Math{



    public static class Factorial{

    

        private int result;

        private int key;

        

        public Factorial(int number, int x){

            

            result=number;

            key = x;

        }

        

        public int getResult(){

            return result;

        }

        

        public int getKey(){

            return key;

        }

    }

    

    public static Factorial getFactorial(int x){

    

        int result=1;

        for (int i = 1; i <= x; i++){

		

            result *= i;

        }

        return new Factorial(result, x);

    }

}
```

вложенный класс `Factorial` хранит результат вычисления факториала и исходный аргумент: пара значений возвращается одним объектом. основную работу выполняет статический метод `getFactorial`. он считает произведение `1 * 2 * ... * x` и возвращает экземпляр вложенного класса. далее класс используется в `main`:

```java


public static void main(String[] args) {

        

    Math.Factorial fact = Math.getFactorial(6);

    System.out.printf("Факториал числа %d равен %d \n", fact.getKey(), fact.getResult());

}
```
