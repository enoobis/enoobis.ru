ряд методов stream api возвращают подпотоки или объединённые потоки на основе уже имеющихся потоков.

### `takeWhile`

метод `takeWhile()` выбирает из потока элементы, пока они соответствуют условию. если попадается элемент, который условию не соответствует, метод завершает свою работу. выбранные элементы возвращаются в виде потока. метод добавлен в jdk 9.

```java


import java.util.stream.Stream;



public class Program {

 

    public static void main(String[] args) {

         

		Stream<Integer> numbers = Stream.of(-3, -2, -1, 0, 1, 2, 3, -4, -5);

		numbers.takeWhile(n -> n < 0)

			.forEach(n -> System.out.println(n));

	}

}
```

программа выбирает из потока числа, пока они меньше нуля. консольный вывод программы:

```consoletext


-3

-2

-1
```

в потоке есть и другие отрицательные числа, `-4` и `-5`, но они стоят после нуля. метод завершает работу, как только обнаружит первое число, которое не соответствует условию, и хвост не просматривает. в этом состоит отличие от метода `filter()`: `filter` проверил бы каждый элемент и оставил бы все отрицательные, в том числе стоящие после положительных.

чтобы охватить все элементы, которые меньше нуля, поток следует предварительно отсортировать. после `sorted()` отрицательные образуют префикс, и `takeWhile` забирает его целиком:

```java


Stream<Integer> numbers = Stream.of(-3, -2, -1, 0, 1, 2, 3, -4, -5);

numbers.sorted().takeWhile(n -> n < 0)

		.forEach(n -> System.out.println(n));
```

консольный вывод программы:

```consoletext


-5

-4

-3

-2

-1
```

### `dropWhile`

метод `dropWhile()` выполняет обратную задачу. он пропускает элементы потока, которые соответствуют условию, до тех пор, пока не встретит элемент, который этому условию не соответствует. найденный элемент и весь хвост возвращаются потоком. элементы хвоста предикатом уже не проверяются, даже если какой-то из них снова сделал бы предикат истинным. метод добавлен в jdk 9.

```java


Stream<Integer> numbers = Stream.of(-3, -2, -1, 0, 1, 2, 3, -4, -5);

numbers.sorted().dropWhile(n -> n < 0)

	.forEach(n -> System.out.println(n));
```

поток сначала сортируется, затем отбрасывается отрицательный префикс. консольный вывод программы:

```consoletext


0

1

2

3
```

ноль условию `n < 0` не соответствует, поэтому пропуск останавливается. в результате остаются `0`, `1`, `2` и `3`.

### `concat`

статический метод `concat()` объединяет элементы двух потоков, возвращая объединённый поток. порядок сохраняется: сначала первый поток, затем второй. повторяющиеся значения не удаляются.

```java


import java.util.stream.Stream;



public class Program {

 

    public static void main(String[] args) {

         

		Stream<String> people1 = Stream.of("Tom", "Bob", "Sam");

		Stream<String> people2 = Stream.of("Alice", "Kate", "Sam");

		

		Stream.concat(people1, people2).forEach(n -> System.out.println(n));

	}

}
```

консольный вывод:

```consoletext


Tom

Bob

Sam

Alice

Kate

Sam
```

имя `Sam` есть в обоих источниках и дважды попадает в результат. оба исходных потока при терминальной операции над результатом употребляются. один и тот же поток нельзя передать в `concat` дважды: второе потребление уже употреблённого потока недопустимо.

### `distinct`

метод `distinct()` возвращает только уникальные элементы в виде потока. уникальность определяется `equals`. у упорядоченного потока сохраняется первое вхождение, последующие такие же элементы отбрасываются.

```java


Stream<String> people = Stream.of("Tom", "Bob", "Sam", "Tom", "Alice", "Kate", "Sam");

people.distinct().forEach(p -> System.out.println(p));
```

консольный вывод:

```consoletext


Tom

Bob

Sam

Alice

Kate
```

второй `Tom` и второй `Sam` в результат не входят. порядок первых вхождений сохраняется: `Tom`, `Bob`, `Sam`, `Alice`, `Kate`.
