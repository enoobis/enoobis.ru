интерфейс `Map` сам по себе порядок ключей не задает. поверх него java дает `SortedMap` и `NavigableMap`.

### `SortedMap`

интерфейс `SortedMap` расширяет `Map` и держит ключи в полном порядке. по умолчанию это естественный порядок ключей, по возрастанию, либо порядок компаратора, переданного реализации. тот же порядок виден при обходе, в `keySet` и в `entrySet`.

методы, которые `SortedMap` добавляет к `Map`:

- `K firstKey()`: возвращает ключ первого, наименьшего, элемента

- `K lastKey()`: возвращает ключ последнего, наибольшего, элемента

- `SortedMap<K, V> headMap(K end)`: возвращает представление пар, ключи которых строго меньше end

- `SortedMap<K, V> tailMap(K start)`: возвращает представление пар, ключи которых больше либо равны start

- `SortedMap<K, V> subMap(K start, K end)`: возвращает представление пар от ключа start включительно до ключа end исключительно

границы полуинтервалов те же, что у `SortedSet`. представления связаны с исходной картой: запись через представление меняет ее, и наоборот.

### `NavigableMap`

интерфейс `NavigableMap` расширяет `SortedMap` и находит пару или ключ относительно заданного ключа. основные методы:

- `Map.Entry<K, V> ceilingEntry(K key)`: возвращает пару с наименьшим ключом k, который больше или равен key (`k >= key`). если такого ключа нет, возвращает `null`

- `Map.Entry<K, V> floorEntry(K key)`: возвращает пару с наибольшим ключом k, который меньше или равен key (`k <= key`). если такого ключа нет, возвращает `null`

- `Map.Entry<K, V> higherEntry(K key)`: возвращает пару с наименьшим ключом k, который строго больше key (`k > key`). если такого ключа нет, возвращает `null`

- `Map.Entry<K, V> lowerEntry(K key)`: возвращает пару с наибольшим ключом k, который строго меньше key (`k < key`). если такого ключа нет, возвращает `null`

- `K ceilingKey(K key)`: возвращает наименьший ключ k, который больше или равен key (`k >= key`), либо `null`

- `K floorKey(K key)`: возвращает наибольший ключ k, который меньше или равен key (`k <= key`), либо `null`

- `K higherKey(K key)`: возвращает наименьший ключ k, который строго больше key (`k > key`), либо `null`

- `K lowerKey(K key)`: возвращает наибольший ключ k, который строго меньше key (`k < key`), либо `null`

- `NavigableSet<K> descendingKeySet()`: возвращает `NavigableSet` со всеми ключами в обратном порядке

- `NavigableMap<K, V> descendingMap()`: возвращает представление `NavigableMap` со всеми парами в обратном порядке

- `NavigableSet<K> navigableKeySet()`: возвращает `NavigableSet` со всеми ключами в прямом порядке

- `NavigableMap<K, V> headMap(K upperBound, boolean incl)`: возвращает представление пар исходной карты `NavigableMap` с ключами до `upperBound`. при incl, равном `true`, пара с ключом `upperBound` входит в представление

- `NavigableMap<K, V> tailMap(K lowerBound, boolean incl)`: возвращает представление пар, начиная с ключа `lowerBound`. при incl, равном `true`, пара с ключом `lowerBound` входит в представление

- `NavigableMap<K, V> subMap(K lowerBound, boolean lowIncl, K upperBound, boolean highIncl)`: возвращает представление пар от ключа `lowerBound` до ключа `upperBound`. при значении `true` флаги `lowIncl` и `highIncl` включают соответствующую границу

к тем же операциям относятся `firstEntry`, `lastEntry`, `pollFirstEntry` и `pollLastEntry`: первые два читают наименьшую и наибольшую пары, последние два читают и одновременно удаляют их. пустая карта дает `null`.

### `TreeMap`

встроенная реализация этих интерфейсов есть класс `TreeMap`. он хранит пары в дереве и держит их отсортированными. класс наследует `AbstractMap` и реализует `NavigableMap`, а значит также `SortedMap` и `Map`. парами управляют методы `Map`. в отличие от `HashMap`, `TreeMap` при каждой вставке ставит ключ на место по возрастанию. дерево красно-черное, поэтому поиск, вставка и удаление занимают время `O(log n)`.

конструкторы:

- `TreeMap()`: создает пустую коллекцию в виде дерева с естественным порядком ключей

- `TreeMap(Map<? extends K, ? extends V> map)`: создает дерево и добавляет все пары из карты map

- `TreeMap(SortedMap<K, ? extends V> smap)`: создает дерево и добавляет все пары из сортированной карты smap. порядок берется у нее

- `TreeMap(Comparator<? super K> comparator)`: создает пустое дерево. добавляемые ключи упорядочивает компаратор

ключи должны реализовать `Comparable`, либо компаратор передается последним конструктором. при естественном порядке ключ `null` отвергается и дает `NullPointerException`. компаратор может принять `null`, только если сам его упорядочивает. порядок в `TreeMap`, явный или естественный, должен быть согласован с `equals`. если сравнение двух ключей дает ноль, `equals` тоже должен давать истину. иначе карта формально реализует `Map`, но `containsKey` и `get` расходятся с равенством: ключ, который дерево считает уже присутствующим, может не находиться сравнением `equals`, и наоборот.

создание дерева:

```java


import java.util.Map;

import java.util.TreeMap;

 

public class Program{

      

    public static void main(String[] args) {

          

        // пустое дерево

        var treeMap = new TreeMap<String,String>();

        System.out.println(treeMap);     // {}



        // дерево на основе другого словаря

        var dict = new TreeMap<String,String>(

                                Map.ofEntries( 

                                    Map.entry("+79876543210", "Tom"),

                                    Map.entry("+79666543210", "Bob"),

                                    Map.entry("+79176543210", "Sam"),

                                    Map.entry("+79276543210", "Alice")

                                ));

        System.out.println(dict);  // {blue=синий, green=зеленый, red=красный, yellow=желтый}

    }

}
```
пустое дерево печатается как `{}`. во втором дереве ключи есть телефонные номера, значения имена. комментарий к `println` и отдельный фрагмент вывода показывают другой словарь, уже с цветами:

```bash
{blue=синий, green=зеленый, red=красный, yellow=желтый}
```
в обоих случаях ключи типа `String` выстраиваются естественным порядком, лексикографически, а не в порядке вызовов `Map.entry`. `TreeMap` сравнивает ключи при вставке и кладет пару сразу на свое место.

добавление элементов:

```java


import java.util.Map;

import java.util.TreeMap;

 

public class Program{

      

    public static void main(String[] args) {

          

        // пустое дерево

        var dict = new TreeMap<String,String>();

 

        // добавляем в него элементы

        dict.put("red", "красный");

        dict.put("green", "зеленый");

        dict.put("blue", "синий");

        System.out.println(dict);   // {blue=синий, green=зеленый, red=красный}

 

        // добавляем другой словарь с данными

        var map = Map.ofEntries( 

                Map.entry("yellow", "желтый"),

                Map.entry("black", "черный") 

        );

        dict.putAll(map);



        System.out.println(dict);   // {black=черный, blue=синий, green=зеленый, red=красный, yellow=желтый}

    }

}
```
`put` добавляет пары цветов по одной, `putAll` копирует пары второй карты. совпавших ключей нет. печать идет по возрастанию ключей: `black`, `blue`, `green`, `red`, `yellow`.

получение элементов:

```java


import java.util.Map;

import java.util.Set;

import java.util.Collection;

import java.util.TreeMap;

 

public class Program{

      

    public static void main(String[] args) {

          

        // пустой словарь

        var dict = new TreeMap<String,String>(

            Map.ofEntries( 

                Map.entry("red", "красный"),

                Map.entry("green", "зеленый"),

                Map.entry("yellow", "желтый"),

                Map.entry("blue", "синий"),

                Map.entry("black", "черный") 

            )

        );



        // перебор элементов

       for(var word : dict.entrySet()){

         

           System.out.printf("%s: %s \n", word.getKey(), word.getValue());

       }



        // получим объект по ключу "red"

        String red = dict.get("red");

        System.out.println("`red` переводится как `" + red + "`");  // `red` переводится как `красный`



        // получим весь набор ключей

        Set<String> keys = dict.keySet();

        System.out.println(keys);       // [black, blue, green, red, yellow]



        // получить набор всех значений

        Collection<String> values = dict.values();

        System.out.println(values);     // [черный, синий, зеленый, красный, желтый]

            

        // получаем все объекты, которые стоят начиная с объекта с ключом "green"

        Map<String, String> afterGreen = dict.tailMap("green");

        System.out.println(afterGreen);     // {green=зеленый, red=красный, yellow=желтый}

            

        // получаем все объекты, которые стоят до объекта с ключом "green"

        Map<String, String> beforeGreen = dict.headMap("green");

        System.out.println(beforeGreen);    // {black=черный, blue=синий}

         

        // получим последний элемент дерева

        Map.Entry<String, String> lastItem = dict.lastEntry();

        System.out.println(lastItem);   // yellow=желтый

    }

}
```
обход `entrySet` идет от меньшего ключа к большему. `get("red")` возвращает значение ключа `red`. `keySet` отдает ключи в том же порядке, `values` отдает значения в порядке их ключей, а не в порядке вставки.

`tailMap("green")` начинается с границы и включает ее: `green`, `red`, `yellow`. `headMap("green")` берет ключи строго меньше `green`: `black` и `blue`. `lastEntry` возвращает пару с наибольшим ключом, `yellow`.

изменение и удаление:

```java


import java.util.Map;

import java.util.TreeMap;

 

public class Program{

      

    public static void main(String[] args) {

          

        // пустой словарь

        var dict = new TreeMap<String,String>(

            Map.ofEntries( 

                Map.entry("red", "красный"),

                Map.entry("green", "зеленый"),

                Map.entry("yellow", "желтый"),

                Map.entry("blue", "синий"),

                Map.entry("black", "черный") 

            )

        );



        // меняем по ключу "red" значение на "червонный"

        dict.replace("red", "червонный");

        System.out.println(dict);   // {black=черный, blue=синий, green=зеленый, red=червонный, yellow=желтый}

 

        // меняем по ключу "red" значение на "алый", только если значение "красный"

        dict.replace("red", "алый", "красный");

 

        // удаляем yellow

        dict.remove("yellow");

        System.out.println(dict);   // {black=черный, blue=синий, green=зеленый, red=червонный}





        // получаем с удалением первый элемент

        Map.Entry<String, String> firstWord = dict.pollFirstEntry();

        System.out.println(firstWord);      // black=черный



        // получаем с удалением последний элемент

        Map.Entry<String, String> lastWord = dict.pollLastEntry();

        System.out.println(lastWord);       // red=червонный

 

        // удаляем все элементы

        dict.clear();

        System.out.println(dict);   // {}

    }

}
```
`replace("red", "червонный")` меняет значение существующего ключа, место ключа в дереве от значения не зависит. условный `replace` записывает `алый`, только если текущее значение равно `красный`. после предыдущей замены там `червонный`, условие ложно, пара остается прежней. `remove("yellow")` удаляет пару по ключу.

`pollFirstEntry` снимает пару с наименьшим ключом, здесь `black`, и удаляет ее из дерева. `pollLastEntry` снимает пару с наибольшим из оставшихся ключей, здесь `red` со значением `червонный`. `clear` удаляет оставшиеся пары. пустое дерево снова печатается как `{}`.
