сегмент со строкой utf-8 и сегмент с массивом примитивных значений покрывают однородные данные. составное значение в языке c описывают структурой. в java ту же нативную раскладку задают своей компоновкой памяти. её строит метод `MemoryLayout.structLayout()`, а чтение и запись потом переводят значение между носителем java и байтами сегмента:

```java
static StructLayout structLayout(MemoryLayout... elements)
```

в метод передаётся набор значений типа **MemoryLayout**, по одному на поле. результат имеет тип `StructLayout`. поля укладываются в порядке аргументов. если естественное смещение следующего поля не кратно его выравниванию, перед ним вставляется зазор. размер всей структуры округляется вверх так, чтобы он был кратен выравниванию структуры. это выравнивание равно наибольшему выравниванию полей.

структуре c по имени `Point`, которая представляет точку, соответствует именованная компоновка из двух полей. определение на c:

```c


typedef struct {

    int x;

    int y;

} Point;
```

та же раскладка на java:

```c


StructLayout POINT = MemoryLayout.structLayout(

    ValueLayout.JAVA_INT.withName("x"),

    ValueLayout.JAVA_INT.withName("y")

);
```

интерфейс `MemoryLayout` даёт методы, которые не меняют исходную компоновку, а возвращают новую с тем же размером и выравниванием и с изменённым атрибутом. метод `withName(String name)` возвращает компоновку с заданным именем. имя не попадает в выделенную память: оно живёт в объекте компоновки и нужно, чтобы потом найти поле по пути.

```java
ValueLayout.JAVA_INT.withName("x")
```

это выражение задаёт компоновку значения размером 4 байта, то есть ширины типа `int` в java, и сопоставляет её с именем "x". сегмент под эти 4 байта появится отдельно, в момент выделения.

выделение сегмента под одну такую структуру:

```java


import java.lang.foreign.*;

import static java.lang.foreign.ValueLayout.*;



public class Program {



    public static void main(String[] args) {



        StructLayout POINT = MemoryLayout.structLayout(

            ValueLayout.JAVA_INT.withName("x"),

            ValueLayout.JAVA_INT.withName("y")

        );

        try (Arena arena = Arena.ofConfined()) {



            // выделяем память для 1 объекта POINT

            MemorySegment point_seg = arena.allocate(POINT);



            System.out.println(point_seg);  // MemorySegment{ kind: native, address: 0x72760c180400, byteSize: 8 }

        } 

    }

}
```

два поля `JAVA_INT` занимают 8 байт без зазора. выравнивание каждого поля равно 4, поэтому второе поле начинается ровно со смещения 4, и дополнение в конец структуры не требуется. печать сегмента показывает длину 8 байт.

при сопоставлении типа c и компоновки java длины в байтах должны совпадать. ширины примитивов java фиксированы спецификацией языка, а ширины `int` и `long` в c задаёт abi платформы. на распространённых 64-разрядных платформах c `int` совпадает с `JAVA_INT` и занимает 4 байта. беззнаковый тип c сопоставляют со знаковым носителем java той же ширины: отдельной беззнаковой константы в **ValueLayout** нет, битовая раскладка общая. при обработке такого значения в java его читают как знаковый носитель и дальше трактуют как беззнаковое самостоятельно, методами `Integer.toUnsignedLong`, `Integer.compareUnsigned` и аналогами у `Long`.

имена "x" и "y" заданы для доступа к полям по пути. через методы сегмента по этим именам поле читают и записывают:

```java


import java.lang.foreign.*;

import static java.lang.foreign.ValueLayout.*;



public class Program {



    public static void main(String[] args) {



        // определяем структуру

        StructLayout POINT = MemoryLayout.structLayout(

            ValueLayout.JAVA_INT.withName("x"),

            ValueLayout.JAVA_INT.withName("y")

        );

        try (Arena arena = Arena.ofConfined()) {



            // выделяем память для 1 объекта POINT

            MemorySegment point_seg = arena.allocate(POINT);



            // устанавливаем значения x и y

            point_seg.set(ValueLayout.JAVA_INT, POINT.byteOffset(PathElement.groupElement("x")), 20);

            point_seg.set(ValueLayout.JAVA_INT, POINT.byteOffset(PathElement.groupElement("y")), 15);



            // получаем значения x и y

            int x = point_seg.get(ValueLayout.JAVA_INT, POINT.byteOffset(PathElement.groupElement("x")));

            int y = point_seg.get(ValueLayout.JAVA_INT, POINT.byteOffset(PathElement.groupElement("y")));



            System.out.println("x: " + x);  // 20

            System.out.println("y: " + y);  // 15

        } 

    }

}
```

методы `get` и `set` обращаются к участку памяти по смещению в байтах. смещение поля считает `byteOffset()`. в него передают путь к элементу. шаг пути получают по имени: `PathElement.groupElement` выбирает поле группы, то есть поле структуры.

```java
POINT.byteOffset(PathElement.groupElement("x"))
```

вызов возвращает смещение от начала структуры до участка, сопоставленного с именем "x". в этой раскладке смещение равно 0. у поля "y" оно равно 4.

если смещение уже известно, в `get` и `set` передают само число:

```java


// поле y смещено на 4 байта относительно начала структуры

point_seg.set(ValueLayout.JAVA_INT, 4, 17);



// получаем значения  y

int y = point_seg.get(ValueLayout.JAVA_INT, POINT.byteOffset(PathElement.groupElement("y")));



System.out.println("y: " + y);  // y: 17
```

число 4 попадает в поле "y". следующее чтение по пути этого поля возвращает 17. числовое смещение не следит за зазорами выравнивания. после изменения состава структуры его пересчитывают. `byteOffset` каждый раз считает смещение по текущей компоновке, включая зазоры.

### объединения

`StructLayout` описывает расположение структуры c: поля идут последовательно, каждое со своим смещением. тип **UnionLayout** описывает объединение языка c, union. работа с **UnionLayout** близка к работе со `StructLayout`: компоновку собирают из вложенных компоновок, сегмент выделяет арена, поле находят через `byteOffset` и читают или пишут через `get` и `set`. различие в раскладке. все поля объединения начинаются со смещения 0 и занимают одну и ту же область. размер объединения равен наибольшему размеру поля, округлённому вверх до выравнивания объединения. запись в одно поле перекрывает байты остальных. компоновку объединения получают методом `MemoryLayout.unionLayout`.

### составная компоновка SequenceLayout

интерфейс **SequenceLayout** задаёт составную компоновку: однородное повторение заданной компоновки элемента, то есть последовательность. число повторений называется числом элементов последовательности. последовательность можно рассматривать как структурную компоновку, в которой один и тот же элемент повторён столько раз, сколько элементов заявлено. соседние элементы разделены постоянным шагом. шаг равен размеру элемента, округлённому вверх до его выравнивания.

компоновку этого вида строит метод `MemoryLayout.sequenceLayout()`:

```java


static SequenceLayout sequenceLayout(long elementCount, MemoryLayout elementLayout)
```

метод принимает число элементов и компоновку одного элемента в виде значения `MemoryLayout`. произведение числа элементов на шаг даёт размер всей последовательности.

массив структур задают последовательностью, элемент которой сам является структурой:

```java


// массив структур

SequenceLayout points_layout = MemoryLayout.sequenceLayout(count, 

    MemoryLayout.structLayout( 

        JAVA_INT.withName("x"),

        JAVA_INT.withName("y")

    )

);
```

обращение к полю y структуры с индексом i требует байтового смещения. путь состоит из выбора элемента последовательности и выбора поля внутри него:

```java


long offset = points_layout.byteOffset( 

    PathElement.sequenceElement(i), 

    PathElement.groupElement("y")

);
```

здесь `byteOffset` получает последовательность объектов `MemoryLayout.PathElement` и по ней находит смещение нужного компонента. `PathElement.sequenceElement(i)` задаёт i-й элемент, `PathElement.groupElement("y")` задаёт поле y этого элемента. смещение равно i, умноженному на шаг элемента, плюс смещение поля внутри элемента.

когда смещение известно и сегмент уже получен, компонент читают или записывают:

```java


MemorySegment points = Arena.global().allocate(point_layout);

int value = 6;  // значение для y

points.set(JAVA_FLOAT, offset, value, y);
```

фрагмент берёт сегмент у глобальной арены `Arena.global()` и записывает значение по вычисленному смещению. глобальная арена живёт до конца процесса и сама не закрывается. полная программа проводит те же шаги для поля `int` в арене confined:

```java


import java.lang.foreign.*;

import static java.lang.foreign.ValueLayout.*;



public class Program {



    public static void main(String[] args) {



        int count = 4;  // количество структур

        // массив структур

        SequenceLayout points_layout = MemoryLayout.sequenceLayout(count, 

            MemoryLayout.structLayout( 

                JAVA_INT.withName("x"),

                JAVA_INT.withName("y")

            )

        );

        try (Arena arena = Arena.ofConfined()) {



            // выделяем память для массива структур

            MemorySegment points = arena.allocate(points_layout);



            int index = 1;      // индекс нужной структуры в массиве



            // получаем смещение поля y для структуры с индексом index

            long offset = points_layout.byteOffset( 

                PathElement.sequenceElement(index), 

                PathElement.groupElement("y")

            );

            // устанавливаем значение y

            points.set(ValueLayout.JAVA_INT, offset, 24);



            // получаем значение y для структуры с индексом index

            int y = points.get(ValueLayout.JAVA_INT, offset);



            System.out.println("y: " + y);  // 24

        } 

    }

}
```

в программе четыре структуры. у каждой поля x и y типа `JAVA_INT`, шаг элемента равен 8 байтам. `arena.allocate` выделяет один сегмент на всю последовательность. для индекса 1 смещение поля y равно 1 * 8 + 4, то есть 12 байтам. по этому смещению записывается 24, затем то же смещение читается, и программа печатает 24. при выходе из try-with-resources арена confined закрывается, сегмент перестаёт быть доступным.
