через параметры в метод передают данные, которые участвуют в вычислениях. без параметров тело каждый раз выполняет одно и то же:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();

        tom.say();  // Hello

        tom.say();  // Hello

    }

}



class Person{ 



    void say(){

        System.out.println("Hello");

    }

}
```

в классе `Person` объявлен метод `say()`. он изображает произнесение фразы и всегда печатает одну и ту же строку. в `main` создаётся один объект класса `Person`, и у него два раза вызывается `say`. на консоли дважды появляется слово `"Hello"`:

```bash


Hello

Hello
```

сколько бы раз ни вызывался `say`, результат не меняется: внешние данные в метод не поступают. чтобы настраивать поведение снаружи, объявляют параметры. их перечисляют через запятую в скобках после имени метода:

```java


тип_метода имя_метода (тип_параметра1 параметр1, тип_параметра2 параметр2, ...)

{

    // действия метода

}
```

объявление параметра состоит из двух частей: сначала тип, затем имя. параметр является локальной переменной метода и живёт в течение одного вызова. при входе в метод он получает значение аргумента.

программа с параметром выглядит так:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();

        tom.say("Hello work");  // Hello work

        tom.say("Hello gold");  // Hello gold

    }

}



class Person{ 



    void say(String message){

        System.out.println(message);

    }

}
```

теперь `say()` принимает один параметр. его имя `message`, тип `String`. тело печатает то, что лежит в этом параметре, а не фиксированный литерал.

чтобы выполнить метод с параметрами, при вызове после имени в скобках передают значения:

```java


tom.say("Hello work");
```

параметру `message` передаётся строка `"Hello work"`. значение, которое передают параметру, называется аргументом. в этом вызове аргументом является строка `"Hello work"`. второй вызов передаёт другой аргумент, `"Hello gold"`, поэтому вторая строка на консоли другая. сам объект `tom` между вызовами не меняется: различаются только аргументы.

встречаются термины **формальные параметры** и **фактические параметры**. формальные параметры объявлены в заголовке метода, здесь это `message`. фактические параметры представляют собой значения, подставляемые на место формальных. фактические параметры и есть аргументы метода.

другой пример: метод складывает два числа.

```java


class Program{



    public static void main(String[] args) {  



        Calcualtor calc = new Calcualtor();

        calc.sum(1, 2);   // 3

        calc.sum(5, 3);   // 8

        calc.sum(5, 6);   // 11

    }

}

class Calcualtor{



    void sum(int a, int b){



        int result = a + b;

		System.out.println(result);

    }

}
```

в примере объявлен класс `Calcualtor` с одним методом `sum`. у метода два параметра, оба числа, и он выводит на консоль их сумму. тип обоих параметров `int`, поэтому на эти места передают два значения типа `int`. годятся числовые литералы и переменные типа `int`, а также значения, которые автоматически расширяются до `int`: `byte`, `short` и `char`. значение типа `long` или `double` само в `int` не переходит, для него нужно явное приведение.

значения сопоставляются параметрам по позиции. первый аргумент попадает в первый параметр, второй аргумент во второй, и так далее. при вызове `calc.sum(5, 3)` число 5 передаётся параметру `a`, число 3 параметру `b`. в параметр копируется значение аргумента. что именно копируется для примитивов и для объектов, разбирается в следующей лекции.

### параметры переменной длины

метод может принимать параметр переменной длины одного типа. нужна сумма набора чисел, а сколько чисел придёт, заранее неизвестно: 3, 4, 5 или больше. параметр переменной длины закрывает эту задачу:

```java


class Program{



    public static void main(String[] args) {  



        Calcualtor calc = new Calcualtor();

        calc.sum(1, 2, 3);			// 6

		calc.sum(1, 2, 3, 4, 5);    // 15

		calc.sum();					// 0

    }

}

class Calcualtor{



    void sum(int ...nums){

		

		int result =0;

		for(int n: nums)

			result += n;

		System.out.println(result);

	}

}
```

многоточие в записи `int ...nums` показывает, что параметр необязателен по числу аргументов и внутри метода представлен массивом. компилятор собирает переданные числа в массив `int`, и цикл `for` проходит по этому массиву. в `sum` передают одно число, несколько чисел или не передают ни одного. пустой вызов получает массив нулевой длины, а не пустую ссылку: цикл не делает ни одной итерации, `result` остаётся 0, и на консоль выводится 0. если у метода есть обычные параметры вместе с параметром переменной длины, переменный параметр записывают последним, и такой параметр в списке только один:

```java


class Program{



    public static void main(String[] args) {  



        Calcualtor calc = new Calcualtor();

        calc.sum("Sum of {1, 2, 3}: ", 1, 2, 3);    // Sum of {1, 2, 3}: 6

		calc.sum("Zero sum: ");					    // Zero sum: 0

    }

}

class Calcualtor{



    void sum(String message, int ...nums){

		

        System.out.print(message); 

		int result =0;

		for(int n: nums)

			result += n;

		System.out.println(result);

	}

}
```

здесь первый параметр, `message` типа `String`, обязателен. всё, что следует за ним и имеет тип `int`, попадает в `nums`. вызов с текстом и тремя числами печатает подпись и сумму 6. вызов `calc.sum("Zero sum: ")` передаёт только сообщение: массив чисел пуст, сумма равна 0, и строка на консоли заканчивается нулём. порядок фиксирован позицией: строку нельзя поставить после чисел, потому что переменный параметр уже занял хвост списка.
