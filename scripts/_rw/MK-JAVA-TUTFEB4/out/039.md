кроме обычных классов в java есть абстрактные классы. абстрактный класс устроен как обычный: в нём объявляют поля и методы. создать объект, то есть экземпляр абстрактного класса, нельзя. такой тип задаёт базовое состояние и поведение для классов-наследников, а конкретное воплощение дают производные классы.

при объявлении используется модификатор `abstract`:

```java


abstract class имя_класса{



  // содержимое класса

}
```

абстрактный класс обычно вводят для сущности, которая существует только как абстракция и не имеет отдельного воплощения. стандартный пример: система геометрических фигур. объекта «просто фигура» нет. есть круг, прямоугольник, квадрат. при этом круг и прямоугольник разделяют общие свойства и оба являются фигурами.

абстрактным делают и тип, который на первый взгляд выглядит конкретным, если его экземпляры в программе не создаются и класс нужен лишь как основа для наследников.

ниже абстрактный класс геометрической фигуры:

```java


abstract class Shape{

    

    int x; // x-координата точки

    int y; // y-координата точки

 

    Shape(int x, int y){

        

        this.x = x;

        this.y = y;

    }



    void print(){ System.out.println("Геометрическая фигура"); }

}
```

#### применение абстрактных классов

у геометрической фигуры обычно есть опорная точка, относительно которой задаётся положение. у прямоугольника это, как правило, координаты верхнего левого угла, у круга: центр. поля `x` и `y` хранят эти координаты. значения приходят через конструктор и записываются в состояние объекта. метод `print()` выводит сведения о фигуре.

особенность абстрактного класса: его конструктор нельзя вызвать напрямую, чтобы получить экземпляр самого абстрактного типа. оператор `new` для такого типа отвергается на этапе компиляции. тип неполон, и объект должен принадлежать конкретному подклассу.

```java


class Program{

      

    public static void main(String[] args) {



        // так нельзя

        Shape someShape = new Shape(10, 15);  // ! Ошибка: Shape is abstract; cannot be instantiated

    }

}
```

конструктор абстрактного класса вызывается только из конструкторов производных классов. ниже два таких класса:

```java


// абстрактный класс фигуры

abstract class Shape{

    

    int x; // x-координата точки

    int y; // y-координата точки

 

    Shape(int x, int y){

        

        this.x = x;

        this.y = y;

    }



    void print(){ System.out.println("Геометрическая фигура"); }

}

// производный класс прямоугольника

class Rectangle extends Shape

{

    int width;

    int height;

 

    // конструктор с обращением к конструктору класса Figure

    Rectangle(int x, int y, int width, int height){

        

        super(x,y);



        this.width = width;

        this.height = height;

    }

  

	  @Override

    void print(){ 

        System.out.printf("Пpямоугольник. Верхний левый угол: (%d, %d); Ширина: %d; Длина: %d\n", x, y, width, height);

    }

}

// производный класс круга

class Circle extends Shape

{

    int radius;

 

    // конструктор с обращением к конструктору класса Shape

    Circle(int x, int y, int radius){

        

        super(x,y);

        this.radius = radius;

    }

	

	  @Override

    void print(){ 

        System.out.printf("Круг. Центр: (%d, %d); Радиус: %d\n", x, y, radius);

    }

}
```

здесь определены класс прямоугольника и класс круга. они наследуют функционал абстрактного класса `Shape`, добавляют собственные поля (ширина и высота либо радиус) и переопределяют метод `print()`. аннотация `@Override` фиксирует намерение перекрыть метод суперкласса: при несовпадении сигнатуры компиляция останавливается. далее объекты этих классов используют как объекты типа `Shape`. статический тип ссылки: `Shape`, динамический тип: `Rectangle` или `Circle`. вызов `print()` диспетчеризуется по динамическому типу.

```java


class Program{

      

    public static void main(String[] args) {



        Shape shape1 = new Rectangle(10, 15, 200, 150);

        Shape shape2 = new Circle(50, 60, 200);



        printShape(shape1);

        printShape(shape2);

    }



    static void printShape(Shape shape){

        shape.print();

    }

}
```

консольный вывод:

```bash


Пpямоугольник. Верхний левый угол: (10, 15); Ширина: 200; Длина: 150

Круг. Центр: (50, 60); Радиус: 200
```

### абстрактные методы

наряду с абстрактными классами в java есть абстрактные методы. такой метод предваряется модификатором `abstract` и не имеет тела: реализации нет, конкретных действий метод не выполняет.

```java


abstract тип_метода имя_метода(параметры_метода);
```

производный класс обязан переопределить и реализовать все абстрактные методы базового абстрактного класса. если в классе есть хотя бы один абстрактный метод, сам класс должен быть объявлен абстрактным. иначе у создаваемого экземпляра не было бы гарантированной реализации.

в примере с фигурами метод `print()` класса `Shape` не несёт собственной нагрузки. производные классы всё равно его переопределяют и выводят свою информацию. метод можно сделать абстрактным.

```java


abstract class Shape{

    

    int x;

    int y;

 

    Shape(int x, int y){

        

        this.x = x;

        this.y = y;

    }

    // абстрактный метод

    abstract void print();

}

// прямоугольник

class Rectangle extends Shape

{

    int width;

    int height;



    Rectangle(int x, int y, int width, int height){

        

        super(x,y);

        this.width = width;

        this.height = height;

    }

	  @Override

    void print(){ 

        System.out.printf("Пpямоугольник. Верхний левый угол: (%d, %d); Ширина: %d; Длина: %d\n", x, y, width, height);

    }

}

// круг

class Circle extends Shape

{

    int radius;

 

    Circle(int x, int y, int radius){

        

        super(x,y);

        this.radius = radius;

    }

	  @Override

    void print(){ 

        System.out.printf("Круг. Центр: (%d, %d); Радиус: %d\n", x, y, radius);

    }

}
```

производные неабстрактные классы обязаны реализовать абстрактный метод. пока реализация не задана, класс остаётся абстрактным, и экземпляр создать нельзя.

абстрактными оформляют и действия, у которых нет единого конкретного воплощения: операция остаётся абстракцией и зависит от конкретного класса. у геометрической фигуры можно вычислить периметр и площадь. для прямоугольника эти величины считаются одним способом, для круга: другим. у абстрактной геометрической фигуры универсального способа нет, поэтому такие действия задают абстрактными методами. конкретные классы реализуют их по своей формуле.

```java


abstract class Shape{

    

    int x;

    int y;

 

    Shape(int x, int y){

        

        this.x = x;

        this.y = y;

    }

    // абстрактный метод для вычисления периметра

    abstract double getPerimeter();

    // абстрактный метод для вычисления площади

    abstract double getArea();

}

// прямоугольник

class Rectangle extends Shape

{

    int width;

    int height;



    Rectangle(int x, int y, int width, int height){

        

        super(x,y);

        this.width = width;

        this.height = height;

    }

	@Override

    double getPerimeter(){ return this.width * 2 + this.height * 2; }



	@Override

    double getArea(){ return this.width * this.height; }

}

// круг

class Circle extends Shape

{

    int radius;

 

    Circle(int x, int y, int radius){

        

        super(x,y);

        this.radius = radius;

    }

    

	@Override

    double getPerimeter(){ return this.radius * 3.14 * 2; }



	@Override

    double getArea(){ return this.radius * 3.14; }

}
```

в коде круга периметр считается как `radius * 3.14 * 2`, площадь как `radius * 3.14`. коэффициент `3.14` стоит на месте числа π. формула площади в примере линейна по радиусу.

применение классов:

```java


class Program{

      

    public static void main(String[] args) {



        Shape shape1 = new Rectangle(10, 15, 200, 150);

        System.out.println("Площадь прямоугольника: " + shape1.getArea());

        System.out.println("Периметер прямоугольника: " + shape1.getPerimeter());



        Shape shape2 = new Circle(50, 60, 100);

        System.out.println("Площадь круга: " + shape2.getArea());

        System.out.println("Периметер круга: " + shape2.getPerimeter());

    }

}
```

консольный вывод программы:

```bash


Площадь прямоугольника: 30000.0

Периметер прямоугольника: 700.0

Площадь круга: 314.0

Периметер круга: 628.0
```
