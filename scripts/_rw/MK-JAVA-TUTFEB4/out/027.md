кроме обычных методов класс определяет специальные методы, **конструкторы**. конструктор вызывается при создании нового объекта данного класса. обычно конструктор инициализирует объект: записывает в поля начальное состояние.

### конструктор по умолчанию

если в классе не объявлен ни один конструктор, для этого класса автоматически создаётся конструктор без параметров:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person(); // вызов конструктора по умолчанию



        tom.name = "Tom";

        tom.age = 41;



        tom.print();

    }

}



class Person{



    String name;

    int age;



    void print(){



        System.out.printf("Name: %s; Age: %d\n", name, age);

    }

}
```

класс `Person` в этом тексте не содержит ни одного конструктора. поэтому для него автоматически создаётся конструктор по умолчанию, и этим конструктором создаётся объект `Person`.

для создания объекта используется выражение `new Person()`. оператор **new** выделяет память под объект `Person`. затем вызывается конструктор по умолчанию, который не принимает параметров. после выполнения выражения в памяти выделен участок, где хранятся данные объекта `Person`. переменная `tom` получает ссылку на созданный объект.

если конструктор не инициализирует поля объекта, они сохраняют значения по умолчанию. для числовых типов это число 0, для типа `String` и других классов это значение `null`, то есть отсутствие ссылки на объект.

после создания объекта к полям `Person` обращаются через переменную `tom` и читают или записывают их, например `tom.name = "Tom"`.

на консоли в итоге видно:

```bash


Name: Tom; Age: 41
```

### создание конструкторов

если при создании объекта должна выполняться собственная логика, например поля класса должны получить определённые значения, в классе объявляют свои конструкторы. как только в классе объявлен хотя бы один конструктор, этот класс **лишается** конструктора по умолчанию: компилятор его больше не добавляет.

на уровне кода конструктор выглядит как метод с именем класса. параметры у него могут быть. возвращаемый тип не указывается. если указать тип, объявление станет обычным методом, и оператор `new` его не вызовет. простейший конструктор в классе `Person`:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person(); // вызов конструктора, который мы сами определили

        tom.print();

    }

}





class Person{



    String name;

    int age;



    // конструктор класса

    Person(){



        System.out.println("Создание объекта Person");

        name = "Tom";

        age = 41;

    }



    void print(){



        System.out.printf("Name: %s; Age: %d\n", name, age);

    }

}
```

в классе `Person` определён конструктор. он выводит на консоль сообщение и инициализирует поля класса:

```java


Person(){



    System.out.println("Создание объекта Person");

    name = "Tom";

    age = 41;

}
```

объявленный конструктор вызывается при создании объекта `Person`:

```java


Person tom = new Person();
```

выражение `Person()` в составе `new Person()` как раз вызывает конструктор, определённый в классе. это уже не автоматический конструктор по умолчанию: у класса его теперь нет. при выполнении на консоль выводится строка `"Создание объекта Person"`.

тем же способом в классе определяют и другие конструкторы:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();          // вызов 1-ого конструктора без параметров

        Person bob = new Person("Bob");     //вызов 2-ого конструктора с одним параметром

        Person sam = new Person("Sam", 25); // вызов 3-его конструктора с двумя параметрами

        

        tom.print();          // Имя: Неизвестно  Возраст: 18

        bob.print();          // Имя: Bob  Возраст: 18

        sam.print();          // Имя: Sam  Возраст: 25

    }

}



class Person{



    String name;

    int age;



    Person()

    {

        name = "Неизвестно";

        age = 18;

    }

    Person(String username)

    {

        name = username;

        age = 18;

    }

    Person(String username, int userage)

    {

        name = username;

        age = userage;

    }



    void print(){



        System.out.printf("Имя: %s; Возраст: %d\n", name, age);

    }

}
```

в классе определены три конструктора. каждый принимает своё число параметров и устанавливает значения полей класса. это перегрузка конструкторов: варианты различаются списками параметров так же, как перегруженные методы.

консольный вывод программы:

```bash


Имя: Неизвестно  Возраст: 18

Имя: Bob  Возраст: 18

Имя: Sam  Возраст: 25
```

у программы с конструкторами, по сравнению с версией без них, видны такие свойства:

- автоматическая инициализация: конструктор обеспечивает инициализацию объекта при создании и снижает вероятность ошибок из-за полей, оставшихся при значениях по умолчанию. технически 0 и `null` всё равно записываются до тела конструктора, но осмысленное для задачи состояние задаёт уже конструктор.
- краткость кода: код инициализации сосредоточен в конструкторе, основной код создания объектов короче и не повторяет одни и те же присваивания.
- объектно-ориентированное устройство: конструктор держит логику инициализации внутри самого класса, а не в каждом месте, где объект создаётся.

### ключевое слово this

служебное слово **this** представляет ссылку на текущий экземпляр класса. через него обращаются к переменным и методам объекта, а также вызывают другие конструкторы этого класса:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();          // вызов 1-ого конструктора без параметров

        Person bob = new Person("Bob");     //вызов 2-ого конструктора с одним параметром

        Person sam = new Person("Sam", 25); // вызов 3-его конструктора с двумя параметрами

        

        tom.print();          // Имя: Неизвестно  Возраст: 18

        bob.print();          // Имя: Bob  Возраст: 18

        sam.print();          // Имя: Sam  Возраст: 25

    }

}



class Person{



    String name;

    int age;



    Person()

    {

        this("Неизвестно", 18);

    }

    Person(String name)

    {

        this(name, 18);

    }

    Person(String name, int age)

    {

        this.name = name;

        this.age = age;

    }



    void print(){



        System.out.printf("Имя: %s; Возраст: %d\n", name, age);

    }

}
```

в третьем конструкторе параметры называются так же, как поля класса. имя параметра скрывает одноимённое поле. чтобы разделить поле и параметр, применяется **this**:

```java
this.name = name;
```

значение параметра `name` присваивается полю `name`. запись без `this` в этом заголовке означала бы присваивание параметра самому себе, а поле осталось бы при значении по умолчанию.

три конструктора выполняют одни и те же действия: устанавливают поля `name` и `age`. чтобы не повторять присваивания, через `this` вызывают один из конструкторов класса и передают его параметрам нужные значения:

```java


Person(String name)

{

	this(name, 18);

}
```

вызов `this(...)` обязан быть первым оператором конструктора. тогда выбранный конструктор отрабатывает до остального тела, и инициализация не раздваивается. результат программы тот же, что и в предыдущем примере: три объекта получают те же имена и возрасты.

## инициализаторы

помимо конструктора начальную инициализацию объекта проводят инициализатором экземпляра. инициализатор выполняется **до любого конструктора**. в него помещают код, общий для всех конструкторов:

```java


class Program{



    public static void main(String[] args) {  



        Person undef = new Person();          // вызов 1-ого конструктора без параметров

        undef.print();      // Имя: Неизвестно  Возраст: 18



        Person tom = new Person("Tom", 22); // вызов 2-ого конструктора с двумя параметрами

        tom.print();          // Имя: Tom  Возраст: 22

    }

}



class Person{



    String name;

    int age;



    /*начало блока инициализатора*/

    {

        name = "Неизвестно";

        age = 18;

    }

    /*конец блока инициализатора*/



    Person() { }  // пустой конструктор, ничего не делает





    Person(String name, int age)

    {

        this.name = name;

        this.age = age;

    }



    void print(){



        System.out.printf("Имя: %s; Возраст: %d\n", name, age);

    }

}
```

консольный вывод:

```bash


Имя: Неизвестно; Возраст: 18

Имя: Tom; Возраст: 22
```

пустой конструктор поля не меняет, поэтому у первого объекта остаются значения из инициализатора. второй конструктор выполняется уже после инициализатора и записывает в поля переданные аргументы, поэтому у `tom` печатаются имя `"Tom"` и возраст 22.

## порядок выполнения инициализации полей

поля инициализируются несколькими способами:

- инициализация по умолчанию, когда полю явным образом ничего не присваивается. числовое поле получает 0, логическое поле получает `false`, поле другого класса получает `null`
- явная инициализация полей: при объявлении полю явным образом присваивается значение
- инициализация в инициализаторе
- инициализация в конструкторе

порядок при создании объекта такой:

- поля получают значения, которые им присваиваются при объявлении. если при объявлении значения нет, поле уже содержит значение по умолчанию
- поля получают значения, которые им присваиваются в инициализаторе
- поля получают значения, которые им присваиваются в конструкторе

следующая программа печатает значение на каждом шаге:

```java


class Program{



    public static void main(String[] args) {  



        State state = new State();



        System.out.println("Final value: " + state.value);



    }

}



class State{ 

    String value = "Default";  // значение по умолчанию



    //  инициализатор

    {

        System.out.println("Initializator. Old value: " + value);

        value = "Initializator";

    }



    // конструктор

    State(){

        System.out.println("Constructor. Old value: " + value);

        value = "Constructor";

    }

}
```

в классе `State` есть поле `value`, которому присвоено начальное значение. в инициализаторе и в конструкторе полю присваивается новое значение, и перед записью печатается старое. консольный вывод:

```bash


Initializator. Old value: Default

Constructor. Old value: Initializator

Final value: Constructor
```

сначала полю `value` присваивается начальное значение, затем выполняется инициализатор, затем конструктор. каждый следующий шаг видит результат предыдущего.

можно поймать и самое раннее значение, если выражение инициализации поля само вызывает метод:

```java


class Program{



    public static void main(String[] args) {  



        State state = new State();



        System.out.println("Final value: " + state.value);  // 0



    }

}



class State{ 

    String value =  defaultValue();



    {

        System.out.println("Initializator. Old value: " + value);

        value = "Initializator";

    }



    State(){

        System.out.println("Constructor. Old value: " + value);

        value = "Constructor";

    }

    String defaultValue(){

        

        System.out.println("Default. Old value: " + value);

        return "Default";

    }

}
```

консольный вывод:

```bash


Default. Old value: null

Initializator. Old value: Default

Constructor. Old value: Initializator

Final value: Constructor
```

метод `defaultValue` вызывается, когда вычисляется инициализатор поля `value`. память объекта к этому моменту уже заполнена значениями по умолчанию, а присваивание строки `"Default"` ещё не выполнено, поэтому первое напечатанное значение равно `null`. затем поле получает `"Default"`, блок инициализатора записывает `"Initializator"`, конструктор записывает `"Constructor"`. инициализаторы полей и блоки инициализации выполняются в том порядке, в каком они записаны в тексте класса, и все они завершаются до тела конструктора. итоговая строка на консоли берётся уже из состояния после конструктора.
