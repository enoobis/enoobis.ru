все компоненты класса в java, то есть поля, методы и конструкторы, имеют модификаторы доступа. модификаторы доступа управляют видимостью классов, методов и переменных и тем самым определяют, из каких частей программы к компоненту класса можно обратиться. они задают, откуда разрешён доступ к конкретному классу, методу или переменной.

в java используются следующие модификаторы доступа:

- `public`: публичный, общедоступный класс или компонент класса. поля и методы, объявленные с модификатором `public`, видны другим классам из текущего пакета и из внешних пакетов, вообще в любом месте программы, откуда виден сам класс. в исходном файле может быть только один класс верхнего уровня с модификатором `public`, а количество классов с другими модификаторами или без них может быть любым. если в файле есть класс с модификатором `public`, имя файла должно совпадать с именем этого класса.

- `private`: закрытый класс или компонент класса, противоположность модификатора `public`. закрытый класс или компонент класса доступен только из кода в том же классе. у типа верхнего уровня модификаторы `private` и `protected` не применяются: их ставят на члены класса и на вложенные типы. классу верхнего уровня доступны `public` и отсутствие модификатора.

- `protected`: такой класс или компонент класса доступен из любого места в текущем классе или пакете или в производных классах, даже если они находятся в других пакетах.

- модификатор по умолчанию. отсутствие модификатора у поля или метода класса предполагает применение модификатора по умолчанию. такие поля или методы видны всем классам в текущем пакете и скрыты от классов других пакетов.

### модификаторы в рамках текущего пакета

на примере создаётся следующий класс `State`:

```java


class State{

    

    String defaultVar ="default";  // доступно в любом месте текущего пакета

    

    private String privateVar = "private";  // доступно только из текущего класса



    protected String protectedVar = "protected";  // доступно из текущего пакета и производных классов



    public String publicVar = "public";  // доступно в любом месте программы

 



    // доступен в любом месте текущего пакета

    void printDefault() { System.out.println(defaultVar); }

 

    // доступен только из текущего класса

    private void printPrivate() { System.out.println(privateVar); }

 

    // доступен из текущего пакета и производных классов

    protected void printProtected() { System.out.println(protectedVar); }

 

    // доступен в любом месте программы

    public void printPublic() { System.out.println(publicVar);} 

}
```

класс `State` не имеет явного модификатора, поэтому он доступен из любого места данного пакета и недоступен из других пакетов.

в классе `State` четыре поля, по одному на каждый уровень доступа, и четыре метода с разными модификаторами. методы выводят значения соответствующих переменных на консоль. все модификаторы разрешают использовать компоненты класса внутри самого класса, поэтому все переменные, в том числе закрытые, доступны всем его методам: обращение происходит в контексте класса `State`.

дальше показано, как переменные класса `State` используются в другом классе, расположенном в том же пакете:

```java


class Program {



    public static void main(String[] args) {

        

        State state = new State();

 

        // переменная defaultVar с модификатором по умолчанию доступна из любого места текущего пакета

        // поэтому можно получить или изменить ее значение

        System.out.println(state.defaultVar); //Ошибка, получить доступ нельзя

 

        // обратиться к переменной privateVar у нас не получится,

        // так как она имеет модификатор private и класс Program ее не видит

        System.out.println(state.privateVar); // Ошибка, получить доступ нельзя

 

        // переменная protectedVar так же доступна из любого места текущего пакета 

        // (а также в производных классах других пакетов)

        System.out.println(state.protectedVar);

 

        // переменная publicVar общедоступна везде

        System.out.println(state.publicVar);

    } 

}



class State{

    

    String defaultVar ="default";  // доступно в любом месте текущего пакета

    

    private String privateVar = "private";  // доступно только из текущего класса



    protected String protectedVar = "protected";  // доступно из текущего пакета и производных классов



    public String publicVar = "public";  // доступно в любом месте программы

 



    // доступен в любом месте текущего пакета

    void printDefault() { System.out.println(defaultVar); }

 

    // доступен только из текущего класса

    private void printPrivate() { System.out.println(privateVar); }

 

    // доступен из текущего пакета и производных классов

    protected void printProtected() { System.out.println(protectedVar); }

 

    // доступен в любом месте программы

    public void printPublic() { System.out.println(publicVar);} 

}
```

в классе `Program` удаётся обратиться к переменным `defaultVar`, `protectedVar` и `publicVar`, поскольку их модификаторы разрешают использование в этом контексте. к `privateVar` обратиться нельзя: модификатор `private` делает поле невидимым для класса `Program`. хвостовой комментарий в строке с `defaultVar` сообщает об ошибке доступа, однако правила языка и комментарии непосредственно над этой строкой доступ разрешают: поле с модификатором по умолчанию читается из любого класса текущего пакета.

аналогично дело обстоит с методами:

```java


class Program {



    public static void main(String[] args) {

        

        State state = new State();

 

        state.printDefault(); // норм



        state.printPrivate(); // Ошибка, получить доступ нельзя



        state.printProtected();  // норм



        state.printPublic();      // норм

    } 

}



class State{

    

    String defaultVar ="default";  // доступно в любом месте текущего пакета

    

    private String privateVar = "private";  // доступно только из текущего класса



    protected String protectedVar = "protected";  // доступно из текущего пакета и производных классов



    public String publicVar = "public";  // доступно в любом месте программы

 



    // доступен в любом месте текущего пакета

    void printDefault() { System.out.println(defaultVar); }

 

    // доступен только из текущего класса

    private void printPrivate() { System.out.println(privateVar); }

 

    // доступен из текущего пакета и производных классов

    protected void printProtected() { System.out.println(protectedVar); }

 

    // доступен в любом месте программы

    public void printPublic() { System.out.println(publicVar);} 

}
```

здесь доступны только три метода: `printDefault`, `printProtected` и `printPublic`. они имеют соответственно модификатор по умолчанию и модификаторы `protected` и `public`. метод `printPrivate` остаётся видимым только внутри `State`.

### модификаторы в рамках пакетов

если классы `State` и `Program` расположены в разных пакетах, набор видимых членов сужается. пусть проект имеет следующую структуру:

- файл `Program.java`

- папка `types`, файл `State.java`

файл `State.java` содержит определение аналогичного класса `State`:

```java


package types;



public class State{

    

    String defaultVar ="default";  // доступно в любом месте текущего пакета

    

    private String privateVar = "private";  // доступно только из текущего класса



    protected String protectedVar = "protected";  // доступно из текущего пакета и производных классов



    public String publicVar = "public";  // доступно в любом месте программы

 



    // доступен в любом месте текущего пакета

    void printDefault() { System.out.println(defaultVar); }

 

    // доступен только из текущего класса

    private void printPrivate() { System.out.println(privateVar); }

 

    // доступен из текущего пакета и производных классов

    protected void printProtected() { System.out.println(protectedVar); }

 

    // доступен в любом месте программы

    public void printPublic() { System.out.println(publicVar);} 

}
```

здесь только два отличия по сравнению с предыдущим определением класса `State`:

- класс `State` принадлежит пакету `types` и поэтому располагается в соответствующем каталоге

- класс `State` определён с модификатором `public`, благодаря чему он виден из других пакетов

этот класс применяется в классе `Program`:

```java


import types.State;



class Program {



    public static void main(String[] args) {

        

        State state = new State();

 

        state.printDefault(); // Ошибка



        state.printPrivate(); // Ошибка



        state.printProtected(); // Ошибка



        state.printPublic();  // норм

    } 

}
```

из другого пакета обращение компилируется только к члену с модификатором `public`. в листинге это метод `printPublic`. вызовы `printDefault`, `printPrivate` и `printProtected` отвергаются компилятором. пакетный метод не виден за пределами `types`. закрытый метод не виден нигде снаружи своего класса. метод с `protected` классу `Program` тоже недоступен: `Program` не является подклассом `State` и лежит в другом пакете. из чужого пакета подкласс обращается к защищённому члену экземпляра из своего тела, когда статическим типом ссылки является этот подкласс или его дальнейший наследник. произвольная ссылка на суперкласс такого доступа не даёт. для полей схема та же: из другого пакета виден член с `public`. исходный разбор отдельно поля после методов не расписывает, поскольку уровни доступа у полей и методов совпадают.
