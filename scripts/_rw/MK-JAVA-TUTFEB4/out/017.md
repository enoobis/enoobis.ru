условные конструкции выбирают, какая ветвь программы выполнится. выбор зависит от условия.

в java для этого есть конструкция `if..else` и тернарный оператор `?:`.

выражение `if..else` проверяет истинность условия и в зависимости от результата выполняет соответствующий код. простейшая форма состоит из блока `if`:

```java


if(условие){



    выполняемые инструкции

}
```

после ключевого слова `if` стоит условие. его тип должен быть `boolean`. это может быть значение типа `boolean`, результат операции сравнения или любое другое выражение, которое возвращает `boolean`. если условие истинно и равно `true`, выполняется код в фигурных скобках после условия. если условие равно `false`, этот код пропускается. число и ссылка условием служить не могут: неявного приведения к `boolean` в java нет.

пример:

```java


class Program {

  

    public static void main(String[] args) {

          

        int num1 = 6;

        int num2 = 4;

        if(num1 > num2){

            System.out.printf("число %d больше числа %d\n", num1, num2);

        }

    }

}
```

первое число больше второго, поэтому выражение `num1 > num2` истинно и возвращает `true`. управление переходит в блок после условия и выполняет находящиеся там инструкции, здесь это метод `System.out.printf`, который выводит строку на консоль. если первое число меньше второго или равно ему, инструкции блока `if` не выполняются.

если блок `if` содержит одну инструкцию, фигурные скобки можно опустить. телом тогда считается ровно одна следующая инструкция:

```java


class Program {

  

    public static void main(String[] args) {

          

        int num1 = 6;

        int num2 = 4;

        if(num1 > num2) 

            System.out.printf("число %d больше числа %d\n", num1, num2);

    }

}
```

### блок else

ветвь для невыполненного условия записывают блоком `else`:

```java


class Program {

  

    public static void main(String[] args) {

          

        int num1 = 6;

        int num2 = 40;

        if(num1 > num2){

            System.out.println("число num1 больше числа num2");

        }

        else{

            System.out.println("число num1 меньше или равно числу num2");

        }

    }

}
```

здесь `num1` не больше `num2`. условие `num1 > num2` не выполняется и возвращает `false`, поэтому выполняется блок инструкций после `else`.

если блок `else` содержит только одну инструкцию, фигурные скобки вокруг него тоже опускают:

```java


int num1 = 6;

int num2 = 40;

if(num1 > num2)

    System.out.println("число num1 больше числа num2");

else

    System.out.println("число num1 меньше или равно числу num2");
```

`else` относится к ближайшему `if`, у которого ещё нет своей ветви `else`. при вложенных условиях без скобок это правило определяет, какая ветвь с какой проверкой связана.

### else if

при сравнении чисел возможны три состояния: первое число больше второго, первое меньше второго, числа равны. дополнительные условия обрабатывают блоки `else if`:

```java


class Program {

  

    public static void main(String[] args) {

          

        int num1 = 6;

        int num2 = 40;

        if(num1 > num2){

            System.out.println("число num1 больше числа num2");

        }

        else if(num1 < num2){

            System.out.println("число num1 меньше числа num2");

        }

        else{

            System.out.println("числа num1 и num2 равны");

        }

    }

}
```

при необходимости выражений `else if` может быть несколько. каждое следующее условие проверяется только если все предыдущие дали `false`:

```java


class Program {

  

    public static void main(String[] args) {

          

        String name = "Eugene";



        if (name == "Tom")

            System.out.println("Вас зовут Tomas");

        else if (name == "Bob")

            System.out.println("Вас зовут Robert");

        else if (name == "Mike")

            System.out.println("Вас зовут Michael");

        else

            System.out.println("Неизвестное имя");

    }

}
```

сравнение строк оператором `==` проверяет равенство ссылок, а не посимвольное содержимое. строковые литералы с одинаковым текстом часто указывают на одну и ту же строку в пуле, и пример с `"Tom"`, `"Bob"` и `"Mike"` за счёт этого срабатывает. строка, собранная во время выполнения, может содержать тот же текст и при этом быть другим объектом. посимвольное равенство проверяет метод `equals`.

### тернарная операция

тернарная операция имеет следующий синтаксис:

```java
[первый операнд - условие] ? [второй операнд] : [третий операнд]
```

в операции три операнда. первый имеет тип `boolean` и играет роль условия. если условие равно `true`, результатом становится второй операнд. если условие равно `false`, результатом становится третий. вычисляется только выбранный операнд. второй и третий приводятся к общему типу, и этот тип получает всё выражение.

```java


int x = 3;

int y = 2;

int z = x < y ? (x+y) : (x-y);
```

результатом тернарной операции здесь является значение, которое записывается в `z`. сначала проверяется условие `x < y`. при `x = 3` и `y = 2` оно ложно, поэтому выбирается третий операнд `(x - y)`, и `z` равно 1. второй операнд `(x + y)` при ложном условии не вычисляется.
