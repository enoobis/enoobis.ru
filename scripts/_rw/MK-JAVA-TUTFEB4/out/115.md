### перебор элементов. метод `forEach`

для перебора элементов потока применяется метод `forEach()`, терминальная операция. в качестве параметра он принимает объект `Consumer<? super T>`, действие, выполняемое для каждого элемента набора.

```java


Stream<String> citiesStream = Stream.of("Париж", "Лондон", "Мадрид","Берлин", "Брюссель");

citiesStream.forEach(s->System.out.println(s));
```

по смыслу это перебор всех элементов, как в цикле for, с одним и тем же действием на каждом шаге. действие здесь: вывод строки на консоль. консоль выведет:

```consoletext


Париж

Лондон

Мадрид

Берлин

Брюссель
```

тот же `forEach` можно записать короче, передав ссылку на метод:

```java


Stream<String> citiesStream = Stream.of("Париж", "Лондон", "Мадрид","Берлин", "Брюссель");

citiesStream.forEach(System.out::println);
```

в вызов передаётся ссылка на метод, который выводит строку на консоль. форма `System.out::println` связывает метод экземпляра `println` с уже существующим объектом `System.out` типа `PrintStream`. `Consumer<String>` получает строку и вызывает на этом объекте `println`.

### фильтрация. метод `filter`

для фильтрации элементов в потоке применяется метод `filter()`, промежуточная операция. он принимает условие в виде объекта `Predicate<? super T>` и возвращает новый поток из элементов, которые этому условию удовлетворяют.

```java


Stream<String> citiesStream = Stream.of("Париж", "Лондон", "Мадрид","Берлин", "Брюссель");

citiesStream.filter(s->s.length()==6).forEach(s->System.out.println(s));
```

условие `s.length()==6` возвращает `true` для тех элементов, длина которых равна 6 символам. программа выведет:

```consoletext


Лондон

Мадрид

Берлин
```

следующий пример фильтрует более сложные данные. класс `Phone`:

```java


class Phone{

    

    private String name;

    private int price;

    

    public Phone(String name, int price){

        this.name=name;

        this.price=price;

    }

    

    public String getName() {

        return name;

    }

    

    public void setName(String name) {

        this.name = name;

    }

    

    public int getPrice() {

        return price;

    }

    

    public void setPrice(int price) {

        this.price = price;

    }

}
```

у объекта хранятся имя и цена, конструктор их задаёт, доступ идёт через геттеры и сеттеры. отфильтруем набор телефонов по цене:

```java


Stream<Phone> phoneStream = Stream.of(new Phone("iPhone 6 S", 54000), new Phone("Lumia 950", 45000),

                new Phone("Samsung Galaxy S 6", 40000));

        

phoneStream.filter(p->p.getPrice()<50000).forEach(p->System.out.println(p.getName()));
```

`filter` оставляет телефоны, у которых `getPrice()` строго меньше 50000. у `iPhone 6 S` цена 54000, он в результат не входит. `Lumia 950` и `Samsung Galaxy S 6` остаются, `forEach` печатает их имена.

### отображение. метод `map`

отображение, или маппинг, задаёт функцию преобразования одного объекта в другой: из элемента одного типа получается элемент другого типа. для отображения используется метод `map`:

```java


<R> Stream<R> map(Function<? super T, ? extends R> mapper)
```

передаваемая в `map` функция задаёт преобразование от объектов типа `T` к типу `R`. `? super T` разрешает функцию над супертипом элемента, `? extends R` разрешает вернуть подтип объявленного результата. в результате возвращается новый поток с преобразованными объектами.

возьмём класс телефонов, определённый выше, и выполним преобразование от типа `Phone` к типу `String`:

```java


Stream<Phone> phoneStream = Stream.of(new Phone("iPhone 6 S", 54000), new Phone("Lumia 950", 45000),

                new Phone("Samsung Galaxy S 6", 40000));

        

phoneStream

    .map(p-> p.getName()) // помещаем в поток только названия телефонов

    .forEach(s->System.out.println(s));
```

операция `map(p -> p.getName())` помещает в новый поток только названия телефонов. на консоли будут только названия:

```consoletext


iPhone 6 S

Lumia 950

Samsung Galaxy S 6
```

ещё одно преобразование, снова в строку. название соединяется с ценой:

```java


phoneStream

    .map(p-> "название: " + p.getName() + " цена: " + p.getPrice())

    .forEach(s->System.out.println(s));
```

результирующий поток содержит только строки. к названию каждого телефона добавлена его цена.

для преобразования объектов в типы `int`, `long` и `double` определены специальные методы `mapToInt()`, `mapToLong()` и `mapToDouble()`. они возвращают `IntStream`, `LongStream` и `DoubleStream`, без упаковки результата в `Integer`, `Long` и `Double`.

### плоское отображение. метод `flatMap`

плоское отображение выполняется тогда, когда из одного элемента нужно получить несколько. данную операцию выполняет метод `flatMap`:

```java


<R> Stream<R> flatMap(Function<? super T, ? extends Stream<? extends R>> mapper)
```

функция отображает элемент типа `T` в поток элементов типа `R`. операция склеивает эти потоки в один `Stream<R>`. `map` с такой функцией имел бы результат типа `Stream<Stream<R>>`, поток потоков. `flatMap` снимает один уровень вложенности.

в примере выше на консоль выводятся название телефона и его цена. если для каждого телефона нужны и цена со скидкой, и цена без скидки, из одного объекта `Phone` надо получить два объекта с информацией, например в виде строки. для этого применяется `flatMap`:

```java


Stream<Phone> phoneStream = Stream.of(new Phone("iPhone 6 S", 54000), new Phone("Lumia 950", 45000),

                new Phone("Samsung Galaxy S 6", 40000));

         

phoneStream

    .flatMap(p->Stream.of(

            String.format("название: %s  цена без скидки: %d", p.getName(), p.getPrice()),

            String.format("название: %s  цена со скидкой: %d", p.getName(), p.getPrice() - (int)(p.getPrice()*0.1))

	))

    .forEach(s->System.out.println(s));
```

`Stream.of` внутри лямбды строит для каждого телефона поток из двух строк. `String.format` подставляет имя и цену. скидка считается как десять процентов цены: произведение `p.getPrice()*0.1` приводится к `int`, дробная часть отбрасывается, и эта величина вычитается из цены. `flatMap` склеивает полученные потоки в один, `forEach` печатает строки.

результат работы программы:

```consoletext


название: iPhone 6 S цена без скидки: 54000

название: iPhone 6 S цена со скидкой: 48600

название: Lumia 950 цена без скидки: 45000

название: Lumia 950 цена со скидкой: 40500

название: Samsung Galaxy S 6 цена без скидки: 40000

название: Samsung Galaxy S 6 цена со скидкой: 36000
```
