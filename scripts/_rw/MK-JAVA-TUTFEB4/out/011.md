простейший канал обмена с пользователем в java это консоль: программа пишет в стандартный поток вывода и читает стандартный поток ввода. оба потока доступны через класс `System`. поле `out` связано со стандартным выводом, поле `in` со стандартным вводом, поле `err` со стандартным потоком ошибок.

### вывод на консоль

поток вывода представлен объектом `out` типа `PrintStream`. метод `println` записывает значение и затем завершает строку. курсор консоли переходит на следующую строку:

```java


class Program {

  

    public static void main(String[] args) {

          

        System.out.println("Hello world!");

		System.out.println("Bye world...");

    }

}
```

в `println` передаётся значение, обычно строка. у метода есть перегрузки для примитивных типов и для `Object`: объект приводится к строке через `String.valueOf`. программа выше печатает две строки:

```bash


Hello world!

Bye world...
```

если перевод строки не нужен, вызывают `System.out.print()`. набор перегрузок тот же, разделитель строк метод не добавляет:

```java


class Program {

  

    public static void main(String[] args) {

          

        System.out.print("Hello world!");

		System.out.print("Bye world...");

    }

}
```

консольный вывод этой программы:

```bash


Hello world!Bye world...
```

перевод строки можно вставить в сам аргумент `print`. для этого служит escape-последовательность `\n`, символ lf с кодом 10:

```java


System.out.print("Hello world \n");
```

в строку часто подставляют значения переменных. оператор `+`, у которого хотя бы один операнд имеет тип `String`, означает конкатенацию. второй операнд приводится к строке, фрагменты склеиваются слева направо:

```java


class Program {

  

    public static void main(String[] args) {

          

        int x=5;

		int y=6;

		System.out.println("x=" + x + "; y=" + y);

    }

}
```

консольный вывод программы:

```bash


x=5; y=6
```

форматированный вывод унаследован от функции `printf` языка c и доступен как `System.out.printf()`. тот же пример записывается так:

```java


int x=5;

int y=6;

System.out.printf("x=%d; y=%d \n", x, y);
```

спецификатор `%d` занимает место одного аргумента. спецификаторы сопоставляются аргументам слева направо. здесь первый `%d` получает значение `x`, второй получает значение `y`. буква `d` означает целое в десятичной записи. сам вызов `printf` возвращает тот же `PrintStream`, поэтому вызовы можно сцеплять, хотя в примерах этого нет.

кроме `%d` для других типов данных есть отдельные спецификаторы:

- `%x`: для вывода шестнадцатеричных чисел
- `%f`: для вывода чисел с плавающей точкой
- `%e`: для вывода чисел в экспоненциальной форме, например `1.3e+01`
- `%c`: для вывода одиночного символа
- `%s`: для вывода строковых значений
- `%b`: для вывода значений типа `boolean`

пример:

```java


class Program {

  

    public static void main(String[] args) {

          

        String name = "Tom";

		int age = 30;

		float height = 1.7f;

         

		System.out.printf("Name: %s  Age: %d  Height: %.2f \n", name, age, height);

    }

}
```

у `%f` можно ограничить число знаков после десятичного разделителя. в спецификаторе `%.2f` часть `.2` оставляет два знака. вывод программы:

```bash


Name: Tom  Age: 30  Height: 1,70
```

в этой строке разделитель запятая. `printf` форматирует число через `Formatter`, а тот берёт десятичный разделитель из локали по умолчанию. при локали, где разделителем принята запятая, `%f` печатает `1,70`.

### ввод с консоли

поток ввода доступен как поле `in` класса `System`. его тип `InputStream`: это поток байтов, без разбора лексем и без перевода текста в числа. поверх `System.in` обычно ставят `Scanner`, и уже он читает лексемы. небольшая программа читает целое:

```java


import java.util.Scanner;



class Program {

  

    public static void main(String[] args) {

          

        Scanner in = new Scanner(System.in);

		System.out.print("Input a number: ");

        int num = in.nextInt();

         

		System.out.printf("Your number: %d \n", num);

		in.close();

    }

}
```

класс `Scanner` расположен в пакете `java.util`, поэтому его импортируют инструкцией `import java.util.Scanner`.

конструктор `Scanner` получает `System.in`. дальше значения читают методами сканера. программа сначала печатает приглашение, затем записывает введённое целое в `num`.

целое возвращает `in.nextInt()`. метод пропускает пробельные символы и разбирает следующую лексему как значение типа `int`. если лексема не является таким числом, метод выбрасывает `InputMismatchException`.

пример работы программы:

```bash


Input a number: 5

Your number: 5
```

у `Scanner` есть отдельный метод на каждый читаемый тип:

- `next()`: считывает введённую строку до первого пробела
- `nextLine()`: считывает всю введённую строку
- `nextInt()`: считывает введённое число `int`
- `nextDouble()`: считывает введённое число `double`
- `nextBoolean()`: считывает значение `boolean`
- `nextByte()`: считывает введённое число `byte`
- `nextFloat()`: считывает введённое число `float`
- `nextShort()`: считывает введённое число `short`

для каждого примитивного типа, который сканер умеет разбирать, определён свой метод. `next()` останавливается на первом пробеле, `nextLine()` забирает остаток строки до перевода строки и сам перевод строки в результат не включает.

`nextInt`, `nextFloat` и родственные методы читают лексему и оставляют в буфере завершающий перевод строки. следующий за ними `nextLine` тогда возвращает пустую строку. в программе ниже `nextLine` вызван первым, поэтому к моменту чтения чисел перевод строки уже потреблён.

программа читает сведения о человеке:

```java


import java.util.Scanner;



class Program {

  

    public static void main(String[] args) {

          

        Scanner in = new Scanner(System.in);

        System.out.print("Input name: ");

        String name = in.nextLine();

        System.out.print("Input age: ");

        int age = in.nextInt();

		System.out.print("Input height: ");

        float height = in.nextFloat();

        System.out.printf("Name: %s  Age: %d  Height: %.2f \n", name, age, height);

		in.close();

    }

}
```

последовательно вводятся `String`, `int` и `float`, затем все три значения печатаются одной строкой. пример работы программы:

```bash


Input name: Tom

Input age: 34

Input height: 1,7

Name: Tom  Age: 34  Height: 1,70
```

для `float` и для `double` вид лексемы зависит от текущей локали. при русскоязычной, немецкой или французской локали десятичным разделителем служит запятая, и сканер ожидает запись `1,7`. лексема `1.7` с точкой в такой локали числом не считается. локаль сканера задаётся методом `useLocale`, и тогда разделитель не зависит от настроек системы.

вызов `in.close()` закрывает сканер вместе с обёрнутым потоком. поскольку этот поток здесь `System.in`, после `close()` читать стандартный ввод в том же процессе уже нельзя. в короткой программе, которая сразу завершается, это остаётся незаметным.
