циклы относятся к управляющим конструкциям. они повторяют действие, пока выполняется заданное условие. в языке java есть следующие виды циклов:

- `for`
- `while`
- `do...while`

`while` проверяет условие перед телом, поэтому при ложном условии тело не выполняется ни разу. `do...while` проверяет условие после тела, поэтому тело выполняется хотя бы один раз. ниже подробно разобран `for`: его заголовок собирает инициализацию, условие и шаг в одном месте.

### цикл for

цикл `for` имеет следующее формальное определение:

```java


for ([инициализация счетчика]; [условие]; [изменение счетчика])

{

    // действия

}
```

стандартный цикл `for`:

```java


for (int i = 1; i < 9; i++){

    System.out.printf("Квадрат числа %d равен %d \n", i, i * i);

}
```

первая часть объявления цикла, `int i = 1`, создаёт и инициализирует счётчик `i`. счётчик не обязан иметь тип `int`. подходит и другой числовой тип, например `float`. перед выполнением цикла значение счётчика равно 1. по смыслу это объявление переменной, но область видимости ограничена циклом: снаружи этого `for` имя `i` не видно.

вторая часть задаёт условие, при котором цикл продолжается. здесь тело выполняется, пока `i` не достигнет 9, то есть пока `i < 9`.

третья часть меняет счётчик. в примере это приращение на единицу. увеличивать именно на единицу не обязательно. счётчик можно уменьшать: `i--`. на месте шага допустимо и другое выражение.

тело срабатывает 8 раз. `i` проходит значения от 1 до 8, а когда значение становится равным 9, условие ложно и цикл завершается. после каждого прохода `i` увеличивается на 1.

все три части при объявлении цикла указывать не обязательно:

```java


int i = 1;

for (; ;){

    System.out.printf("Квадрат числа %d равен %d \n", i, i * i);

}
```

форма цикла та же, но все три блока в заголовке пусты: `for (; ;)`. нет инициализированной переменной-счётчика и нет условия. отсутствующее условие трактуется как истинное, поэтому цикл бесконечный. завершить его может `break`, `return` или выброс исключения внутри тела.

можно опустить только часть блоков:

```java


int i = 1;

for (; i<9;){

    System.out.printf("Квадрат числа %d равен %d \n", i, i * i);

	i++;

}
```

этот пример эквивалентен первому. счётчик есть, но создан вне цикла. условие выполнения цикла есть. приращение счётчика записано в самом теле `for`, а не в заголовке.

цикл `for` может определить сразу несколько переменных и управлять ими. переменные в одной инициализации имеют общий тип:

```java


int n = 10;

for(int i=0, j = n - 1; i < j; i++, j--){

			

	System.out.println(i * j);

}
```

здесь `i` растёт от 0, `j` убывает от `n - 1`, а тело выполняется, пока `i < j`. шаг `i++, j--` меняет обе переменные после каждого прохода.

#### вложенные циклы

циклы могут быть вложенными. внутренний цикл на каждом шаге внешнего проходит свой диапазон целиком:

```java


class Program{



    public static void main(String[] args) {  



        // внешний цикл

        for (int i = 1; i <= 9; i++) {

            // внутренний цикл

            for (int j = 1; j <= 9; j++) {

                System.out.print(i * j); 

                System.out.print('\t'); 

            }

            System.out.println(); // Перемещаемся на новую строку

        }

    }

}
```

внешний цикл задаёт `i` от 1 до 9 включительно. для каждого `i` внутренний цикл проходит `j` от 1 до 9, печатает произведение `i * j` и затем символ табуляции. после завершения внутренней строки `println` переводит вывод на новую строку. получается таблица произведений: девять строк, в каждой девять чисел.
