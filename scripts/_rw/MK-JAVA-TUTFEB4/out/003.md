предыдущая лекция собирала первую программу и запускала её из командной строки. ту же работу ускоряет ide, интегрированная среда разработки: редактор, сборка, запуск и навигация по проекту сведены в один инструмент. для java самой распространённой такой средой остаётся intellij idea компании jetbrains. ниже разобран первый проект в ней.

дистрибутив берётся с официальной страницы [https://www.jetbrains.com/idea/download](https://www.jetbrains.com/idea/download). там лежат пакеты для windows, macos и linux:

![установка intellij idea](/uploads/course-lectures/1f489af9e10187b6150fd11e4c770486d924797e.png)

на часть регионов загрузка с этого адреса может быть закрыта по географическому признаку. тогда сборка берётся из репозитория проекта на github: [https://github.com/JetBrains/intellij-community/releases](https://github.com/JetBrains/intellij-community/releases). там опубликованы готовые сборки для windows, linux и macos, для архитектур x86-64 и arm64.

![загрузка intellij idea](/uploads/course-lectures/a50381a335d9fb1a1e9ac90eeb9ff981e4a1a236.png)

на ряде дистрибутивов linux, в том числе на ubuntu, ту же среду ставит пакетный менеджер snap:

```bash
sudo snap install intellij-idea-community --classic
```

флаг `--classic` снимает изоляцию snap и даёт среде доступ к комплекту jdk и к каталогам проекта на диске. имя пакета `intellij-idea-community` указывает на открытую редакцию. коммерческая редакция ставится отдельным пакетом.

после установки intellij idea запускается, и на стартовом экране выбирается **new project**:

![создание проекта в intellij idea](/uploads/course-lectures/7276d789588c005412f416bde9fd2b2b02b9e822.png)

открывается окно создания проекта. в левой части в качестве типа снова выбирается **new project**:

![создание проекта java в intellij idea](/uploads/course-lectures/7ed49423b6bd937fd227ba6149c3bba4ff77713e.png)

в поле **name** задаётся имя проекта. в этом курсе проект называется `HelloJava`.

поле **location** задаёт путь к каталогу проекта, если путь по умолчанию не подходит.

поскольку дальше используется язык java, слева выбирается пункт **java**.

поле **jdk** указывает путь к java sdk, которым проект будет компилироваться и запускаться. обычно оно уже заполнено путём к jdk, установленному на машине. пустое поле нужно заполнить вручную: без sdk среда не знает, каким `javac` и какой стандартной библиотекой собирать проект.

после этого нажимается `Create`. среда создаёт каталог проекта и открывает его:

![первый проект на java в intellij idea](/uploads/course-lectures/29e1fcd6291176d65e54baaa0d3ce3d96ddfd8d8.png)

слева показана структура проекта. исходные файлы среда помещает в каталог **src**. сразу после создания он пуст, файлов с кодом в проекте нет. файл добавляется так: правая кнопка на каталоге **src**, в контекстном меню пункт **new -> java class**:

![добавления файла с кодом в проект на java в intellij idea](/uploads/course-lectures/aa1cf514d63cebd8f820b12e934f1829876e3817.png)

в открывшемся поле вводится имя класса. класс называется `Program`:

![добавления класса в проект на java в intellij idea](/uploads/course-lectures/5114915fa6d1c7e9905555ded7864b99bf65f531.png)

после `Enter` в каталог `src` записывается файл класса (здесь это класс `Program`), а в центре открывается его исходный текст:

![создание класса на java в intellij idea](/uploads/course-lectures/7df90935acc7058ddfc418d0d32313dac0f1c973.png)

текст класса заменяется на следующий:

```java
public class Program {

    public static void main(String[] args) {

        System.out.println("Hello enoobis.ru!");
    }
}
```

запуск выполняется зелёной стрелкой на панели инструментов или через меню **run -> run...**:

![запуск проекта на java на выполнение в intellij idea](/uploads/course-lectures/69b758340ed899cd6213d6fa5ba0e7057ddb0dc4.png)

внизу intellij idea открывается окно вывода. в нём виден результат программы, строка, которую записал `System.out.println`:

![выполнение программы на java в intellij idea](/uploads/course-lectures/3301699b1870c6132812e4c3de6f7b8d40d428db.png)
