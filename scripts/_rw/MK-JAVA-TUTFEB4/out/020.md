### конструкция switch

конструкция `switch`/`case` вычисляет выражение и сравнивает его значение с набором констант. при совпадении выполняется код соответствующей ветви. по роли `switch` близок к цепочке `if`/`else`: несколько вариантов обрабатываются в одном месте.

в показанных ниже формах селектором служит `String` или `int`. в классическом `switch` селектором также может быть `byte`, `short`, `char`, перечисление или обёртка одного из этих целых типов. типы `long`, `float`, `double` и `boolean` селектором классического `switch` не являются.

в классическом виде конструкция `switch` имеет следующее формальное определение:

```java


switch (выражение)

{

    case значение1:

        код,выполняемый если выражение имеет значение1

        break;

    case значение2:

        код,выполняемый если выражение имеет значение2

        break;

	//.............

	case значениеN:

        код, выполняемый если выражение имеет значениеN

        break;

    default:

        код, выполняемый если выражение не имеет ни одно из выше указанных значений

        break;

}
```

после ключевого слова `switch` в скобках стоит сравниваемое выражение. его значение по очереди сравнивается со значениями после `case`. при совпадении выполняется блок этой ветви. для селектора типа `String` метки сравниваются методом `equals`, по содержимому строки.

в конце блока `case` ставят один из операторов перехода: `break`, `return` или `throw`. обычно ставят `break`. он завершает `switch`, и следующие блоки `case` не выполняются. `return` завершает весь метод, `throw` выбрасывает исключение. без такого оператора выполнение проваливается в следующую ветвь: её код выполняется, даже если её метка не совпала. это проваливание (fall-through).

пример:

```java


class Program {

  

    public static void main(String[] args) {

          

        String name = "Tom";



        switch (name){



            case "Bob":

                System.out.println("Ваше имя - Bob");

                break;

            case "Tom":

                System.out.println("Ваше имя - Tom");

                break;

            case "Sam":

                System.out.println("Ваше имя - Sam");

                break;

        }

    }

}
```

конструкция `switch` последовательно сравнивает значение переменной `name` со значениями после операторов `case`. значение `name` равно строке `"Tom"`, поэтому выполняется блок

```java


case "Tom":

	System.out.println("Ваше имя - Tom");

	break;
```

на консоли появляется

```bash
Ваше имя - Tom
```

если операторы `break` убрать, после совпавшей ветви выполнение продолжается дальше:

```java


String name = "Tom";



switch (name){



    case "Bob":

        System.out.println("Ваше имя - Bob");

    case "Tom":

         System.out.println("Ваше имя - Tom");

    case "Sam":

        System.out.println("Ваше имя - Sam");

}
```

после блока

```java


case "Tom":

    System.out.println("Ваше имя - Tom");
```

выполняется и следующий блок

case "Sam":
    System.out.println("Ваше имя - Sam");

консольный вывод тогда содержит обе строки:

```bash


Ваше имя - Tom

Ваше имя - Sam
```

#### default

если значение переменной `name` не совпадает ни с одним значением после операторов `case`, ни один блок `case` не выполняется. ветвь `default` задаёт действия и для этого исхода. в операторе `switch` она необязательна: при отсутствии подходящей метки и при отсутствии `default` тело ничего не делает.

```java


string name = "Alex";



switch (name)

{

    case "Bob":

        System.out.println("Ваше имя - Bob");

        break;

    case "Tom":

        System.out.println("Ваше имя - Tom");

        break;

    case "Sam":

        System.out.println("Ваше имя - Sam");

        break;

    default:

        System.out.println("Неизвестное имя");

        break;

}
```

ни одно значение после операторов `case` не совпадает со значением переменной `name`, поэтому выполняется блок `default`:

```java


default:

	System.out.println("Неизвестное имя");

	break;
```

#### новая форма конструкции switch

в классической версии каждый блок `case`, на котором выполнение должно остановиться, завершается оператором `break`. чаще всего нужна ровно одна ветвь, а проваливание только мешает. в ходе развития языка, в java 14, добавлена форма со стрелкой. у ветви со стрелкой проваливания нет: выполняется только совпавшая ветвь.

```java


switch (выражение)

{

    case значение1 ->

        код,выполняемый если выражение имеет значение1

    case значение2 ->

        код,выполняемый если выражение имеет значение2

	//.............

	case значениеN ->

        код, выполняемый если выражение имеет значениеN

    default ->

        код, выполняемый если выражение не имеет ни одно из выше указанных значений

}
```

блок `default` в этой форме тоже необязателен. первый пример в новой форме:

```java


class Program {

  

    public static void main(String[] args) {

          

        String name = "Tom";



        switch (name){



            case "Bob" -> System.out.println("Ваше имя - Bob");

            case "Tom" -> System.out.println("Ваше имя - Tom");

            case "Sam" -> System.out.println("Ваше имя - Sam");

        }

    }

}
```

если в блок `case` нужно поместить несколько инструкций, их оформляют блоком кода:

```java


case "Tom" -> {

  System.out.println("Ваше имя - Tom");

  System.out.println("Привет, Tom");

}
```

### возвращение значения из switch

слово `switch` используется и для выражения, а не только для оператора. выражение `switch` само возвращает значение, то есть результат конструкции можно присвоить или передать дальше. в блоках оператора `switch` для немедленного выхода из метода может применяться `return`. выражение устроено иначе: каждая ветвь должна породить значение.

```java


class Program {

  

    public static void main(String[] args) {

          

        int operation = 1;  // выполняемая операция

        int a = 10, b = 6;  // числа, над которыми выполняется операция



        int result = 0;     // результат операции



        switch (operation)

        {

            case 1:

                result = a + b;

                break;

            case 2: 

                result = a - b;

                break;

            case 3: 

                result = a * b;

                break;

            default: 

                result = 0;

        }



        System.out.println(result);  // 16

    }

}
```

номер операции хранится в переменной `operation`, числа, над которыми выполняется операция, в `a` и `b`, результат в `result`. в зависимости от номера операции конструкция записывает в `result` сумму, разность, произведение или 0.

новая форма `switch` записывает то же присваивание короче. `break` не нужен, потому что стрелка не проваливается в следующую ветвь:

```java


class Program {

  

    public static void main(String[] args) {

          

        int operation = 1;  // выполняемая операция

        int a = 10, b = 6;  // числа, над которыми выполняется операция



        int result = 0;     // результат операции



        switch (operation)

        {

            case 1 -> result = a + b;

            case 2 -> result = a - b;

            case 3 -> result = a * b;

            default -> result = 0;

        }



        System.out.println(result);  // 16

    }

}
```

во всех ветвях решается одна задача: записать в `result` результат операции над числами. выражение `switch` возвращает этот результат само, и отдельное присваивание внутри ветви не требуется:

```java


class Program {

  

    public static void main(String[] args) {

          

        int operation = 1;  // выполняемая операция

        int a = 10, b = 6;  // числа, над которыми выполняется операция



        // результат операции

        int result = switch (operation)

        {

            case 1 -> a + b;

            case 2 -> a - b;

            case 3 -> a * b;

            default -> 0;

        };  // в конце обязательна точка с запятой



        System.out.println(result);  // 16

    }

}
```

переменной `result` напрямую присваивается значение, которое вычисляет выражение `switch`. вычисляемое значение стоит после стрелки в блоке `case`:

```java
case 1 -> a + b;
```

ветвь содержит выражение, а не инструкцию присваивания, поэтому запись короче.

ветки выражения `switch` должны покрывать все значения, которые допускает тип селектора. переменная `result` имеет тип `int`, селектор `operation` тоже имеет тип `int`. у типа `int` `2^32` различных значений. заводить ветвь на каждое значение не нужно: в примере существенны три номера операций. для всех остальных значений применяется `default`, и в этом примере ветвь возвращает 0. в выражении `switch` полное покрытие обязательно. без `default` или другого исчерпывающего набора меток программа не компилируется: выражение не может завершиться, не породив значение. оператор `switch` такого требования не предъявляет.

если в каждом блоке `case` нужно выполнить несколько инструкций, их оформляют отдельным блоком кода:

```java


class Program {

  

    public static void main(String[] args) {

          

        int operation = 1;  // выполняемая операция

        int a = 10, b = 6;  // числа, над которыми выполняется операция



        // результат операции

        int result = switch (operation)

        {

            case 1 -> {

                System.out.println("a + b");

                yield a + b;

            }

            case 2 -> {

                System.out.println("a - b");

                yield a - b;

            }

            case 3 -> {

                System.out.println("a * b");

                yield a * b;

            }

            default -> 0;

        }; 



        System.out.println(result);  // 16

    }

}
```

значение из блока кода возвращает оператор `yield`. после него ставится возвращаемое значение. `return` здесь не подходит: он завершил бы весь метод, а не только выражение `switch`.

```java
yield a - b;
```

есть и другая форма выражения `switch`: после `case` ставится двоеточие, а не стрелка. каждая ветвь обязана породить значение через `yield`, через выброс исключения или через заведомо незавершающийся участок. компилятор проверяет это условие.

```java


class Program {

  

    public static void main(String[] args) {

          

        int operation = 1;  // выполняемая операция

        int a = 10, b = 6;  // числа, над которыми выполняется операция



        // результат операции

        int result = switch (operation)

        {

            case 1:

                System.out.println("a + b");

                yield a + b;

            case 2:

                System.out.println("a - b");

                yield a - b;

            case 3:

                System.out.println("a * b");

                yield a * b;

            default: yield 0;

        };



        System.out.println(result);  // 16

    }

}
```

в конце блока `case` в этой форме нужен оператор `yield`: без возвращаемого значения выражение `switch` не компилируется.
