чтобы сгруппировать данные по какому-нибудь признаку, используются вместе метод `collect()` объекта `Stream` и метод `Collectors.groupingBy()`. класс, по полю которого пойдёт группировка:

```java


class Phone{

    

    private String name;

    private String company;

    private int price;

    

    public Phone(String name, String comp, int price){

        this.name=name;

        this.company=comp;

        this.price = price;

    }

    

    public String getName() { return name; }

    public int getPrice() { return price; }

    public String getCompany() { return company; }

}
```

набор объектов `Phone` группируется по компании:

```java


import java.util.List;

import java.util.Map;

import java.util.stream.Stream;

import java.util.stream.Collectors;



public class Program {

 

    public static void main(String[] args) {

         

        Stream<Phone> phoneStream = Stream.of(new Phone("iPhone X", "Apple", 600), 

            new Phone("Pixel 2", "Google", 500),

            new Phone("iPhone 8", "Apple",450),

            new Phone("Galaxy S9", "Samsung", 440),

            new Phone("Galaxy S8", "Samsung", 340));

         

        Map<String, List<Phone>> phonesByCompany = phoneStream.collect(

                Collectors.groupingBy(Phone::getCompany));

         

        for(Map.Entry<String, List<Phone>> item : phonesByCompany.entrySet()){

             

            System.out.println(item.getKey());

            for(Phone phone : item.getValue()){

                 

                System.out.println(phone.getName());

            }

            System.out.println();

        } 

    } 

}
```

для создания групп в метод `phoneStream.collect()` передаётся вызов `Collectors.groupingBy()`. выражение `Phone::getCompany` группирует объекты по компании: ссылка на метод является функцией классификации и по элементу возвращает ключ группы. в итоге создаётся объект `Map`, в котором ключами являются названия компаний, а значениями является список связанных с компаниями телефонов. без второго аргумента нижним коллектором служит `toList()`, поэтому значение имеет тип `List<Phone>`. реализация карты по умолчанию является `HashMap`, и порядок ключей при обходе спецификацией не фиксируется.

цикл печатает ключ и имена телефонов группы. консольный вывод:

```consoletext


Google

Pixel 2



Apple

iPhone X

iPhone 8



Samsung

Galaxy S9

Galaxy S8
```

### метод `Collectors.partitioningBy`

метод `Collectors.partitioningBy()` имеет похожее действие. он делит элементы на группы по принципу, соответствует ли элемент определённому условию.

```java


Map<Boolean, List<Phone>> phonesByCompany = phoneStream.collect(

                Collectors.partitioningBy(p->p.getCompany()=="Apple"));

        

for(Map.Entry<Boolean, List<Phone>> item : phonesByCompany.entrySet()){

            

    System.out.println(item.getKey());

    for(Phone phone : item.getValue()){

                

        System.out.println(phone.getName());

    }

    System.out.println();

}
```

условие `p.getCompany()=="Apple"` проверяет, принадлежит ли телефон компании `Apple`. оператор `==` сравнивает ссылки. в этом примере и поле, и литерал `"Apple"` заданы строковыми литералами, поэтому сравнение ссылок даёт тот же ответ, что и сравнение текста. содержимое строк сравнивает `equals`. если телефон принадлежит этой компании, он попадает в одну группу, если не принадлежит, то в другую. ключ `true` собирает телефоны `Apple`, ключ `false` собирает остальные.

карта разбиения содержит оба ключа, `true` и `false`, в том числе когда одна из групп пуста. `groupingBy` кладёт в карту только те ключи, которые встретились хотя бы у одного элемента.

### метод `Collectors.counting`

метод `Collectors.counting` применяется в `Collectors.groupingBy()` для вычисления количества элементов в каждой группе. тип счётчика `long`.

```java


Map<String, Long> phonesByCompany = phoneStream.collect(

        Collectors.groupingBy(Phone::getCompany, Collectors.counting()));

        

for(Map.Entry<String, Long> item : phonesByCompany.entrySet()){



    System.out.println(item.getKey() + " - " + item.getValue());

}
```

`groupingBy(Phone::getCompany, Collectors.counting())` возвращает `Map<String, Long>`. консольный вывод:

```consoletext


Google -1

Apple - 2

Samsung - 2
```

по данным потока у `Google` один телефон, у `Apple` и у `Samsung` по два.

### метод `Collectors.summing`

метод `Collectors.summing` применяется для подсчёта суммы. в зависимости от типа данных, к которым применяется метод, он имеет формы `summingInt()`, `summingLong()` и `summingDouble()`. сумма стоимости всех смартфонов по компаниям:

```java


Map<String, Integer> phonesByCompany = phoneStream.collect(

        Collectors.groupingBy(Phone::getCompany, Collectors.summingInt(Phone::getPrice)));

        

for(Map.Entry<String, Integer> item : phonesByCompany.entrySet()){



    System.out.println(item.getKey() + " - " + item.getValue());

}
```

выражение `Collectors.summingInt(Phone::getPrice)` указывает, что для каждой компании будет вычисляться совокупная цена всех её смартфонов. поскольку вычисляется сумма для значений типа `int`, в качестве типа возвращаемой коллекции используется `Map<String, Integer>`. `summingInt` копит сумму в `int`, и на переполнении действует обычное переполнение `int`. консольный вывод:

```consoletext


Google - 500

Apple - 1050

Samsung - 780
```

у `Google` сумма равна 500. у `Apple` сумма цен 600 и 450 равна 1050. у `Samsung` сумма цен 440 и 340 равна 780.

### методы `maxBy` и `minBy`

методы `maxBy` и `minBy` применяются для подсчёта максимального и минимального значения в каждой группе. в качестве параметра эти методы принимают функцию компаратора, которая нужна для сравнения значений. для каждой компании ниже находится телефон с минимальной ценой:

```java


Map<String, Optional<Phone>> phonesByCompany = phoneStream.collect(

        Collectors.groupingBy(Phone::getCompany, 

                Collectors.minBy(Comparator.comparing(Phone::getPrice))));

        

for(Map.Entry<String, Optional<Phone>> item : phonesByCompany.entrySet()){



    System.out.println(item.getKey() + " - " + item.getValue().get().getName());

}
```

`Comparator.comparing(Phone::getPrice)` строит компаратор по цене. `minBy` возвращает `Optional<Phone>`, потому что сведение минимума на пустом наборе не имело бы элемента. `groupingBy` пустых групп не создаёт, поэтому у полученного `Optional` значение есть, и `get()` в печати допустим. в качестве возвращаемого значения операции группировки используется объект `Map<String, Optional<Phone>>`. поскольку группировка идёт по компаниям, ключом выступает строка, а значением выступает объект `Optional<Phone>`.

консольный вывод:

```consoletext


Google - Pixel 2

Apple - iPhone 8

Samsung - Galaxy S8
```

у `Google` при одной модели минимум получает `Pixel 2`. у `Apple` минимум получает `iPhone 8` с ценой 450, цена `iPhone X` равна 600. у `Samsung` минимум получает `Galaxy S8` с ценой 340, цена `Galaxy S9` равна 440.

### метод `summarizing`

методы `summarizingInt()`, `summarizingLong()` и `summarizingDouble()` позволяют объединить в набор значения соответствующих типов:

```java


import java.util.IntSummaryStatistics;

//....................................



 Map<String, IntSummaryStatistics> priceSummary = phoneStream.collect(

    Collectors.groupingBy(Phone::getCompany,

        Collectors.summarizingInt(Phone::getPrice)));

        

for(Map.Entry<String, IntSummaryStatistics> item : priceSummary.entrySet()){



    System.out.println(item.getKey() + " - " + item.getValue().getAverage());

}
```

метод `Collectors.summarizingInt(Phone::getPrice)` создаёт набор, в который помещаются цены для всех телефонов каждой из групп. данный набор инкапсулируется в объекте `IntSummaryStatistics`. если применяются методы `summarizingLong()` или `summarizingDouble()`, получаются объекты `LongSummaryStatistics` или `DoubleSummaryStatistics`.

у этих объектов есть ряд методов, которые позволяют выполнить различные атомарные операции над набором:

- `getAverage()`: возвращает среднее значение, тип результата `double`

- `getCount()`: возвращает количество элементов в наборе, тип результата `long`

- `getMax()`: возвращает максимальное значение

- `getMin()`: возвращает минимальное значение

- `getSum()`: возвращает сумму элементов

- `accept()`: добавляет в набор новый элемент

в этом примере получается средняя цена смартфонов для каждой группы. консольный вывод:

```consoletext


Google - 500.0

Apple - 525.0

Samsung - 390.0
```

у `Google` одна цена 500, среднее равно 500.0. у `Apple` среднее (600 + 450) / 2 равно 525.0. у `Samsung` среднее (440 + 340) / 2 равно 390.0. среднее считается как вещественное число, даже когда все цены целые.

### метод `mapping`

метод `mapping` позволяет дополнительно обработать данные и задать функцию отображения объектов из потока на какой-нибудь другой тип данных.

```java


Map<String, List<String>> phonesByCompany = phoneStream.collect(

    Collectors.groupingBy(Phone::getCompany,

        Collectors.mapping(Phone::getName, Collectors.toList())));

        

for(Map.Entry<String, List<String>> item : phonesByCompany.entrySet()){



    System.out.println(item.getKey());

    for(String name : item.getValue()){

        System.out.println(name);

    }

}
```

выражение `Collectors.mapping(Phone::getName, Collectors.toList())` указывает, что в группу будут выделяться названия смартфонов, причём группа будет представлять объект `List`. внешний `groupingBy` по-прежнему делит элементы по компании. тип результата `Map<String, List<String>>`. цикл печатает компанию и список имён.
