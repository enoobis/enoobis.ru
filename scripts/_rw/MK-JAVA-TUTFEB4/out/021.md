java является объектно-ориентированным языком: программа строится как совокупность объектов, которые взаимодействуют через вызовы методов. класс и объект задают эту модель.

**класс** описывает тип: состав полей, набор методов и правила создания экземпляров. **объект** является экземпляром класса и получает собственный участок памяти. аналогия с человеком здесь прямая. общее представление о человеке, две руки, две ноги, голова, туловище, фиксирует признаки типа и выступает классом. конкретный человек, существующий отдельно от этого шаблона, является объектом класса.

классы уже использовались раньше. в предыдущих темах весь код приложения помещался в класс `Program`:

```java


class Program{



    public static void main(String[] args) {  



        System.out.println("Hello enoobis.ru");

    }

}
```

у класса `Program` есть метод `main`. этот метод служит точкой входа и выводит на консоль сообщение. для вывода применяется ещё один класс, `System`: выражение `System.out.println` читает статическое поле `out` и вызывает метод `println`. дальше показано, как объявлять собственные классы и создавать их объекты.

### определение классов

класс объявляется служебным словом `class`, после которого записывается имя:

```java


class имя_класса{



}
```

имя класса подчиняется тем же правилам, что и имя переменной: это идентификатор java. по соглашению имя класса начинается с прописной буквы, тогда как имена переменных и методов обычно начинают со строчной.

после имени стоят фигурные скобки. между ними расположено тело класса, то есть его компоненты: поля и методы, а при необходимости конструкторы и другие члены.

ниже объявлен класс с именем `Person`:

```java


// класс Program

class Program{



    public static void main(String[] args) {  



    }

}



// класс Person

class Person{ }
```

после имени `Person` стоят пустые фигурные скобки, поэтому у класса нет компонентов. как правило, классы верхнего уровня размещают в разных файлах. если класс помечен `public`, имя файла обязано совпадать с именем этого класса. здесь оба класса объявлены без `public`, и для краткости они помещены в один файл: компилятор такой текст принимает.

### объекты классов

класс в java вводит отдельный ссылочный тип. новый класс, даже пустой и без поведения, уже является новым типом данных. переменную этого типа объявляют так же, как переменную встроенного типа:

```java


class Program{



    public static void main(String[] args) {  



        Person tom;  // определяем переменную класса Person

    }

}



// класс Person

class Person{ }
```

в методе `main` класса `Program` объявлена переменная `tom` типа `Person`. значения у неё пока нет: локальная переменная **не инициализирована**. читать такую переменную нельзя, компилятор считает это ошибкой. прежде чем обращаться к экземпляру, его нужно создать.

объект создаётся конструктором. конструктор представляет собой специальный метод: его имя совпадает с именем класса, он вызывается при создании экземпляра и выполняет инициализацию. общий вид вызова:

```java
new конструктор_класса(параметры_конструктора);
```

сначала выполняется оператор `new`. он выделяет память под объект. затем вызывается конструктор.

#### конструктор по умолчанию

если в классе не объявлен ни один конструктор, как у пустого `Person`, компилятор добавляет конструктор по умолчанию. у этого конструктора нет параметров и пустое тело. им создаётся объект `Person`:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();  // создание объекта класса Person

    }

}



// класс Person

class Person{ }
```

в выражении `new Person()` под данные объекта `Person` выделяется участок памяти. переменная `tom` получает ссылку на созданный объект. через эту ссылку доступны поля и методы экземпляра. в переменной лежит ссылка, сам объект размещён отдельно.

функциональности у `Person` пока нет, однако java позволяет вывести объект на консоль:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();  // создание объекта класса Person

        System.out.println(tom);  // выводим объект tom на консоль

    }

}



// класс Person

class Person{ }
```

на консоль попадает текстовое представление вида `Person@1dbd16a6`. его строит унаследованный от `Object` метод `toString`: имя класса, символ `@` и шестнадцатеричная запись identity hash code. конкретный суффикс после `@` зависит от запуска.

### поля класса

у объекта две основные характеристики. состояние составляют данные, которые объект хранит. поведение составляют действия, которые объект выполняет.

состояние хранится в полях. их также называют переменными класса, точнее переменными экземпляра: у каждого объекта свой набор значений.

пустой класс `Person` выше описывает человека. у человека выделяются имя и возраст, при необходимости набор признаков расширяют. для этих признаков в класс добавляются поля:

```java


class Person{

	

	String name;		// имя

	int age;			// возраст

}
```

поле `name` хранит имя и имеет тип `String`. поле `age` хранит возраст и имеет тип `int`.

### обращение к функциональности класса

к полям, методам и другим членам обращаются точечной нотацией. после ссылки на объект ставится точка, затем имя члена:

```java


объект.поле_класса

объект.метод_класса(параметры_метода)
```

обращение к полям объекта `Person`:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();  // создание объекта класса Person



        // получаем значения полей

        System.out.println(tom.name);  // null

        System.out.println(tom.age);  // 0



        // устанавливаем новые значения полей

        tom.name = "Tom";

        tom.age = 41;



        // повторно получаем значения полей

        System.out.println(tom.name);  // Tom

        System.out.println(tom.age);  // 41

    }

}



// класс Person

class Person{ 

    String name;

    int age;

}
```

к полю `name` объекта `tom` обращаются выражением `tom.name`, к полю `age` выражением `tom.age`. сначала значения полей читаются и выводятся на консоль:

```java


System.out.println(tom.name);

System.out.println(tom.age);
```

затем полям присваиваются новые значения. полю `name` передаётся строка, поскольку его тип `String`. полю `age` передаётся число, поскольку его тип `int`. консольный вывод программы:

```bash


null

0

Tom

41
```

до присваивания печатаются значение по умолчанию ссылки и нуль числового поля. после присваивания печатаются записанные имя и возраст.

### инициализация полей

до явного присваивания поля содержат значения по умолчанию. если полю класса значение не задано в программе, оно получает нулевое значение своего типа: числовое поле получает 0, логическое поле получает `false`, ссылка на объект, в том числе строка, получает `null`. локальная переменная метода устроена иначе. её нужно инициализировать явно до чтения, иначе компиляция завершается ошибкой. поле класса при отсутствии своего инициализатора заполняется значением по умолчанию: 0, `false` или `null`. для `char` таким значением является нулевой символ.

поля можно инициализировать явно уже при объявлении:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();



        System.out.println(tom.name);  // Undefined

        System.out.println(tom.age);  // 1

    }

}



// класс Person

class Person{ 

    String name = "Undefined";

    int age = 1;

}
```

здесь инициализаторы полей выполняются при создании объекта, поэтому `tom.name` сразу равно `"Undefined"`, а `tom.age` равно 1. отдельных присваиваний в `main` для этого не требуется.

### создание нескольких объектов

объектов одного класса создают столько, сколько нужно программе:

```java




class Program{



    public static void main(String[] args) {  



        Person tom = new Person();

        Person bob = new Person(); 



        // устанавливаем новые значения полей объекта tom

        tom.name = "Tom";

        tom.age = 41;



        // устанавливаем новые значения полей объекта bob

        bob.name = "Bob";

        bob.age = 46;



        // получаем значения полей объекта tom

        System.out.println(tom.name);  // Tom

        System.out.println(tom.age);  // 41



        // получаем значения полей объекта bob

        System.out.println(bob.name);  // Bob

        System.out.println(bob.age);  // 46

    }

}



// класс Person

class Person{ 

    String name;

    int age;

}
```

здесь создаются два объекта класса `Person`: `tom` и `bob`. каждому выделяется своя область памяти, и у каждого свой набор полей `name` и `age`. запись в поле одного объекта оставляет поля другого без изменений: это разные экземпляры одного типа. одинаковые имена полей в исходном тексте класса обозначают разные ячейки, как только появляются два объекта.
