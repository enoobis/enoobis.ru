### интерфейсы в преобразованиях типов

всё, что относится к преобразованию типов классов, относится и к интерфейсам. класс реализует интерфейс, поэтому объект этого класса является и объектом реализуемого интерфейса: класс есть подтип интерфейса.

```java


public class Program{

     

	public static void main(String[] args) {

         

		  Movable tesla = new Car("Tesla");

      tesla.move();

	}

}

interface Movable{



    void move();

}



// класс машины

class Car implements Movable{ 



    private String model;



    Car(String model){ this.model = model; }



    public void move(){



        System.out.println("Едем на машине");

    }



    public void print(){



        System.out.println("Модель: " + model);

    }

}
```

класс `Car` реализует интерфейс `Movable`, поэтому переменная типа `Movable` может хранить ссылку на объект типа `Car`. это восходящее преобразование к типу интерфейса, и оно выполняется неявно.

если нужно обратиться к методам класса `Car`, которые определены не в интерфейсе `Movable`, а в самом классе `Car`, статическому типу `Movable` этих методов не видно. требуется явное нисходящее преобразование. оно законно, только если динамический тип ссылки совместим с `Car`. иначе во время выполнения возникает `ClassCastException`.

```java


public class Program{

     

	public static void main(String[] args) {

         

		  Movable tesla = new Car("Tesla");

      tesla.move();

      ((Car) tesla).print();      // Модель: Tesla



      // или через вспомогательную переменную

      Car someCar = (Car) tesla;

      someCar.print();        // Модель: Tesla

	}

}
```

### интерфейсы как параметры и результаты методов

как и классы, интерфейсы выступают типом параметров метода и типом возвращаемого значения. туда, где объявлен интерфейс, передают и оттуда возвращают объекты классов, которые этот интерфейс применяют.

```java


public class Program{

      

    public static void main(String[] args) {

        

        Car car = new Car();

        travel(car);



        Movable boing = new Aircraft();

        travel(boing);  // Летим на самолете

    }



    static void travel(Movable obj)  {



        System.out.println("Отправляемся в путешествие");

        obj.move();

    }

}



interface Movable{



    void move();

}

// класс машины

class Car implements Movable{ 



    public void move(){



        System.out.println("Едем на машине");

    }

}

class Aircraft implements Movable{ 



    public void move(){



        System.out.println("Летим на самолете");

    }

}
```

метод `travel` (условная функция путешествия на транспорте) получает параметр типа `Movable`. это может быть машина, самолёт или любой другой объект, чей класс реализует `Movable`. конкретный динамический тип внутри метода неизвестен. известно только, что объект реализует `Movable` и поэтому имеет метод `move`. вызов `obj.move()` диспетчеризуется по динамическому типу аргумента.

консольный вывод:

```bash


Отправляемся в путешествие

Едем на машине

Отправляемся в путешествие

Летим на самолете
```

пример с возвращением объекта интерфейса:

```java


public class Program{

      

    public static void main(String[] args) {

        

        Movable car = createMovable(true);

        car.move();



        Movable aircraft = createMovable(false);

        aircraft.move();

    }



    static Movable createMovable(boolean isCar)  {



        if(isCar) return new Car();

        return new Aircraft();

    }

}



interface Movable{



    void move();

}

// класс машины

class Car implements Movable{ 



    public void move(){



        System.out.println("Едем на машине");

    }

}

class Aircraft implements Movable{ 



    public void move(){



        System.out.println("Летим на самолете");

    }

}
```

метод `createMovable()` в качестве результата возвращает объект интерфейса `Movable`. параметр имеет тип `boolean` и указывает, объект какого класса будет создан: при значении `true` создаётся объект `Car`, иначе создаётся объект `Aircraft`. вызывающий код зависит от контракта `Movable`. конкретный класс выбран внутри метода.
