словари, их же называют картами и отображениями, сопоставляют ключу значение. базовый контракт словаря в java задает интерфейс `Map`. элемент карты есть пара ключ-значение. внутри одного `Map` ключи уникальны: второй `put` с тем же ключом заменяет значение, а не добавляет пару. поиск идет по ключу, то есть по идентификатору, а не по перебору всех значений.

`Map` не расширяет `Collection`. карта хранит пары, и одного типа элемента у нее нет: отдельный `add` не мог бы выбрать, что именно класть, ключ или значение. размер карты есть число пар. как коллекции наружу выходят три представления: `entrySet` дает пары, `keySet` дает ключи, `values` дает значения. изменение представления меняет карту.

методы интерфейса `Map`:

- `void clear()`: очищает коллекцию

- `boolean containsKey(Object k)`: возвращает `true`, если коллекция содержит ключ k

- `boolean containsValue(Object v)`: возвращает `true`, если коллекция содержит значение v. поиск значения линейный, в отличие от поиска ключа

- `Set<Map.Entry<K, V>> entrySet()`: возвращает набор пар. каждый элемент есть объект `Map.Entry`

- `boolean equals(Object obj)`: возвращает `true`, если аргумент тоже карта и содержит те же пары. реализация карты на равенство не влияет

- `boolean isEmpty()`: возвращает `true`, если коллекция пуста

- `V get(Object k)`: возвращает значение по ключу k. если ключа нет, возвращает `null`. тот же `null` возвращается, когда ключ есть, а значение само равно `null`. отличить эти два случая может `containsKey`

- `V getOrDefault(Object k, V defaultValue)`: возвращает значение по ключу k. если ключа нет, возвращает `defaultValue` и карту не меняет

- `V put(K k, V v)`: помещает пару с ключом k и значением v. если ключ уже был, значение перезаписывается. метод возвращает прежнее значение этого ключа, а если ключа не было, возвращает `null`. значение тоже может быть `null`, поэтому один возвращенный `null` не доказывает, что ключ был новым

- `V putIfAbsent(K k, V v)`: помещает пару с ключом k и значением v, только если ключа еще нет или текущее значение равно `null`

- `Set<K> keySet()`: возвращает набор всех ключей словаря

- `Collection<V> values()`: возвращает коллекцию всех значений словаря. значения не обязаны быть уникальными, поэтому это `Collection`, а не `Set`

- `void putAll(Map<? extends K, ? extends V> map)`: добавляет все пары из словаря map. совпавшие ключи перезаписываются

- `V remove(Object k)`: удаляет пару с ключом k и возвращает прежнее значение или `null`, если ключа не было

- `boolean remove(Object k, Object v)`: удаляет пару с ключом k, только если текущее значение равно v

- `V replace(K k, V v)`: заменяет значение для ключа k на v, только если ключ уже есть. если ключа нет, карта не меняется и метод возвращает `null`

- `boolean replace(K key, V oldValue, V newValue)`: заменяет значение ключа key на `newValue`, только если текущее значение равно `oldValue`

- `int size()`: возвращает количество пар

- `static <K, V> Map<K, V> ofEntries(Map.Entry<? extends K, ? extends V>... entries)`: возвращает неизменяемый словарь из переданных пар

положить пару можно методом `put`, прочитать значение по ключу методом `get`. реализации `Map` отдают наборы ключей и значений. `entrySet` возвращает все пары как объекты `Map.Entry`.

обобщенный интерфейс `Map.Entry<K, V>` есть одна пара: ключ типа `K` и значение типа `V`. его методы:

- `boolean equals(Object obj)`: возвращает `true`, если obj тоже `Map.Entry` и у обеих пар совпадают ключ и значение

- `K getKey()`: возвращает ключ

- `V getValue()`: возвращает значение

- `V setValue(V v)`: устанавливает для текущей пары значение v и возвращает прежнее. запись идет в ту карту, из представления которой взята пара. у немодифицируемой карты вызов завершается отказом

- `int hashCode()`: возвращает хеш-код пары. он согласован с `equals` и собирается из хеш-кодов ключа и значения

при обходе словаря ключ и значение читаются этими методами.

неизменяемый словарь:

```java


import java.util.Map;

 

public class Program{

      

    public static void main(String[] args) {

          

        Map<Integer,String> map = Map.ofEntries( 

                                        Map.entry(1, "Tom"),

                                        Map.entry(2, "Bob"),

                                        Map.entry(3, "Sam")

                                    );

        System.out.println(map);      // {3=Sam, 2=Bob, 1=Tom}

    }

}
```
ключи имеют тип `Integer`, значения тип `String`. словарь собирает `Map.ofEntries`. в него передаются объекты `Map.Entry`, которые создает `Map.entry`. первый аргумент `Map.entry` есть ключ, второй есть сопоставленное значение.

выражение

```java
Map.entry(1, "Tom")
```
создает `Map.Entry`, где ключ есть число 1, а значение строка `Tom`.

`Map.ofEntries` возвращает неизменяемый словарь. для трех пар конкретный класс этой реализации есть `java.util.ImmutableCollections$MapN`. менять такой словарь нельзя: `put`, `remove` и `setValue` завершаются `UnsupportedOperationException`. повтор ключа и нулевой ключ или значение фабрика отвергает. порядок обхода контрактом не задан, в образце печать идет не в порядке аргументов. остальные операции чтение не запрещает:

```java


import java.util.Map;

 

public class Program{

      

    public static void main(String[] args) {

          

        Map<Integer,String> map = Map.ofEntries( 

                                        Map.entry(1, "Tom"),

                                        Map.entry(2, "Bob"),

                                        Map.entry(3, "Sam")

                                    );



        // получаем размер словаряя

        System.out.println(map.size());   // 3



        // получаем все ключи

        System.out.println(map.keySet());   // [3, 2, 1]

        // получаем все значения

        System.out.println(map.values());   // [Sam, Bob, Tom]



        // получаем значение по ключу 2 из словаря

        String item2 = map.get(2);

        System.out.println("Item 2: " + item2);   // Item 2: Bob





        // перебор словаря

        for(Map.Entry<Integer,String> item : map.entrySet()){



            // получаем ключ

            Integer key = item.getKey();

            // получаем значение

            String value = item.getValue();

            System.out.printf("{ %d : %s}\n", key, value);

        }

    }

}
```
`size` возвращает 3. `keySet` и `values` отдают ключи и значения в том же неопределенном порядке. `get(2)` находит значение ключа 2, строку `Bob`. цикл по `entrySet` для каждой пары берет `getKey` и `getValue`.

### `HashMap`

общая часть реализации словарей собрана в абстрактном классе `AbstractMap`: он закрывает большую часть методов `Map`. самая распространенная реализация есть `HashMap`. класс наследует `AbstractMap` и хранит пары в хеш-таблице.

у `HashMap` четыре конструктора:

- `HashMap()`: создает пустой `HashMap` с начальной емкостью 16 и коэффициентом загрузки 0.75

- `HashMap(int initialCapacity)`: создает пустой `HashMap` с указанной начальной емкостью и коэффициентом загрузки 0.75

- `HashMap(int initialCapacity, float loadFactor)`: создает пустой `HashMap` с указанной начальной емкостью и коэффициентом загрузки

- `HashMap(Map<? extends K, ? extends V> m)`: создает новый `HashMap` и копирует в него все пары заданной карты

таблица разворачивает емкость до степени двойки. когда число пар превышает емкость, умноженную на коэффициент загрузки, емкость удваивается и пары раскладываются заново. с java 8 длинная цепочка коллизий в одной корзине заменяется сбалансированным деревом, чтобы поиск по плохому хешу не становился линейным. `HashMap` допускает один ключ `null` и любые значения `null`. порядок обхода не совпадает ни с порядком вставки, ни с порядком ключей. класс не синхронизирован: общая карта из нескольких потоков без внешней синхронизации контракт не держит.

создание `HashMap` и добавление элементов:

```java


import java.util.Map;

import java.util.HashMap;

 

public class Program{

      

    public static void main(String[] args) {

          

        // пустой словарь

        var dict = new HashMap<String,String>();



        // добавляем в него элементы

        dict.put("red", "красный");

        dict.put("green", "зеленый");

        dict.put("blue", "синий");

        System.out.println(dict);   // {red=красный, green=зеленый, blue=синий}



        Map<String,String> map = Map.ofEntries( 

                                    Map.entry("yellow", "желтый"),

                                    Map.entry("brown", "коричневый")

                                );

        // добавляем другой словарь с данными

        dict.putAll(map);

        System.out.println(dict);   // {red=красный, green=зеленый, blue=синий, yellow=желтый, brown=коричневый}

    }

}
```
и ключи, и значения здесь строки. `put` кладет три пары цветов. `putAll` копирует пары второй карты, собранной через `Map.ofEntries`. ключи не пересекаются, поэтому в словаре оказывается пять пар. порядок в печати есть порядок корзин, а не порядок вызовов.

чтение словаря:

```java


import java.util.Map;

import java.util.HashMap;

 

public class Program{

      

    public static void main(String[] args) {

          



        Map<String,String> map = Map.ofEntries( 

                                    Map.entry("red", "красный"),

                                    Map.entry("green", "зеленый"),

                                    Map.entry("blue", "синий"),

                                    Map.entry("yellow", "желтый")

                                );

        var dict = new HashMap<String,String>(map);

        System.out.println(dict);   // {red=красный, yellow=желтый, green=зеленый, blue=синий}



        // получаем размер словаряя

        System.out.println(dict.size());   // 4



        // получаем все ключи

        System.out.println(dict.keySet());   // [red, yellow, green, blue]

        // получаем все значения

        System.out.println(dict.values());   // [красный, желтый, зеленый, синий]



        // получаем значение по ключу "red" из словаря

        String red = dict.get("red");

        System.out.println("red: " + red);   // red: красный



        // проверяем наличие слова в словаре

        var hasBlack = dict.containsKey("black");

        System.out.println("black: " + (hasBlack ? dict.get("black"):" отсутствует"));   // black:  отсутствует



        // перебор словаря

        for(var word : dict.entrySet()){



            // получаем ключ 

            var source = word.getKey();

            // получаем значение

            var translation = word.getValue();

            System.out.printf("%s : %s\n", source, translation);

        }

    }

}
```
конструктор копирует четыре пары. `size` возвращает 4. `keySet` отдает ключи, `values` отдает переводы. `get("red")` возвращает значение ключа `red`. `containsKey("black")` дает `false`: ключа нет, и в сообщение подставляется текст об отсутствии, а не результат `get`. цикл по `entrySet` печатает ключ и значение каждой пары.

изменение и удаление:

```java


import java.util.Map;

import java.util.HashMap;

 

public class Program{

      

    public static void main(String[] args) {

          



        Map<String,String> map = Map.ofEntries( 

                                    Map.entry("red", "красный"),

                                    Map.entry("green", "зеленый"),

                                    Map.entry("blue", "синий"),

                                    Map.entry("yellow", "желтый")

                                );

        var dict = new HashMap<String,String>(map);

        System.out.println(dict);   // {red=красный, green=зеленый, blue=синий, yellow=желтый}



        // меняем по ключу "red" значение на "червонный"

        dict.replace("red", "червонный");

        System.out.println(dict);   // {red=червонный, green=зеленый, blue=синий, yellow=желтый}



        // меняем по ключу "red" значение на "алый", только если значение "красный"

        dict.replace("red", "алый", "красный");



        // удаляем yellow

        dict.remove("yellow");

        System.out.println(dict);   // {red=червонный, green=зеленый, blue=синий}



        // удаляем все элементы

        dict.clear();

        System.out.println(dict);   // {}

    }

}
```
`replace("red", "червонный")` меняет значение существующего ключа. следующий `replace` с тремя аргументами записывает `алый` только при текущем значении `красный`. после предыдущей замены там уже `червонный`, условие ложно, и пара не меняется. `remove("yellow")` удаляет пару по ключу. `clear` удаляет все пары, печать пустой карты есть `{}`.

добавить или заменить значение можно методом `put` или `replace`, прочитать его по ключу методом `get`. остальные методы `Map` дают перебор, набор ключей, коллекцию значений и удаление.
