статические компоненты класса и модификатор `static`

помимо обычных методов и полей класс содержит статические поля, методы, константы и инициализаторы. в формулировках рядом иногда стоят свойства и структуры: для java в этой теме имеются в виду члены класса, в том числе статические поля и методы. статические поля и методы принадлежат всему классу. чтобы обратиться к такому полю или методу, объект класса создавать не требуется.

главный класс программы на java содержит метод `main`, и этот метод является статическим:

```java


public static void main(String[] args) {

    

}
```

для объявления статических переменных, констант, методов и инициализаторов перед объявлением указывается служебное слово **static**.

### статические поля

обычное поле класса хранит состояние объекта. статическое поле хранит состояние всего класса. при создании объектов класса для каждого объекта создаётся своя копия нестатических полей. статическое поле общее для всего класса и существует в одном экземпляре.

статическое поле объявляется как обычное, только перед типом поля стоит слово `static`. статические поля на примере класса `Person`, который представляет человека:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person(41);

        tom.checkAge();     // Сколько лет осталось до пенсии: 24





        Person bob = new Person(68);

        bob.checkAge();     // Уже на пенсии



        // получение статического поля

        System.out.println(Person.retirementAge); // 65

        // изменение статического поля

        Person.retirementAge = 67;

        System.out.println(Person.retirementAge); // 67

    }

}



class Person{



    int age;        // обычное поле

    static int retirementAge = 65;  // статическое поле



    Person(int age){

        this.age = age;

	}



    void checkAge()

    {

        if (age >= retirementAge)

            System.out.println("Уже на пенсии");

        else

            System.out.printf("Сколько лет осталось до пенсии: %d\n", retirementAge - age);

    }

}
```

класс `Person` имеет два поля: `age` хранит возраст человека, `retirementAge` хранит пенсионный возраст. поле `retirementAge` является статическим. оно относится не к конкретному человеку, а ко всем людям. для упрощения здесь не учитывается, что пенсионный возраст может отличаться в зависимости от пола и профессии. поле `retirementAge` относится не к отдельному объекту и хранит не значение отдельного объекта класса `Person`. оно относится ко всему классу `Person` и хранит общее значение для всего класса.

внутри самого класса это поле используется как и любое другое. в методе `checkAge()`, который проверяет пенсионный статус человека, для проверки берётся это поле:

```java
if (age >= retirementAge)
```

вне своего класса к полю обращаются по имени класса:

```java


System.out.println(Person.retirementAge);

Person.retirementAge = 67;
```

запись `Person.retirementAge = 67` меняет единственную копию поля. следующий объект увидит уже новое значение, потому что отдельной копии у экземпляра нет.

на уровне памяти для статического поля создаётся участок, общий для всех объектов класса.

память для статических переменных выделяется и тогда, когда не создан ни один объект этого класса. участок появляется при инициализации класса, а не при выполнении `new`.

### статические инициализаторы

статический инициализатор предназначен для инициализации статических переменных и для действий, которые выполняются при подготовке класса, в том числе до создания самого первого объекта:

```java


public class Program{

     

	public static void main(String[] args) {

        

        Person tom = new Person(41);

        Person bob = new Person(68);



        tom.checkAge();     // Сколько лет осталось до пенсии: 24

        bob.checkAge();     // Уже на пенсии

	}

}



class Person{



    int age;        // обычное поле

    static int retirementAge;  // статическое поле



    static{

        retirementAge = 65;

        System.out.println("Static initializer");

    }



    Person(int age){

        this.age = age;

        System.out.println("Constructor");

	}



    void checkAge()

    {

        if (age >= retirementAge)

            System.out.println("Уже на пенсии");

        else

            System.out.printf("Сколько лет осталось до пенсии: %d\n", retirementAge - age);

    }

}
```

статический инициализатор записывается как обычный блок, только перед ним стоит служебное слово `static`. в этом блоке устанавливается начальное значение статического поля `retirementAge` и на консоль выводится сообщение.

в программе создаются два объекта класса `Person`. консольный вывод выглядит так:

```bash


Static initializer

Constructor

Constructor

Сколько лет осталось до пенсии: 24

Уже на пенсии
```

вызов статического инициализатора производится после загрузки класса, на этапе инициализации класса, фактически до создания самого первого объекта. инициализация выполняется один раз, при первом активном использовании класса. поэтому строка `"Static initializer"` печатается один раз, а `"Constructor"` печатается при каждом создании объекта, здесь дважды. затем уже работают оба вызова `checkAge`.

### статические константы

константы тоже бывают статическими. такая константа общая для всего класса:

```java


public class Program{

     

	public static void main(String[] args) {

        

        double radius = 60;

		System.out.printf("Radisu: %f \n", radius);				// 60

		System.out.printf("Area: %f \n", Math.PI * radius);		// 188,4

	}

}

class Math{

	public static final double PI = 3.14;

}
```

в примере объявлен собственный класс `Math` с полем `PI`. модификатор `public` задаёт доступ к полю, `static` относит его к классу, `final` запрещает дальнейшее присваивание. программа печатает радиус и произведение `Math.PI` на этот радиус, как записано в выражении `Math.PI * radius`.

статические константы уже активно использовались в предыдущих темах. в частности, в выражении

```java


System.out.println("hello");
```

**out** представляет статическую константу класса `System`: поле `out` объявлено как `public static final` и имеет тип `PrintStream`. обращение к нему идёт без создания объекта класса `System`.

### статические методы

статический метод задаёт общее для всех объектов поведение, которое не зависит от конкретного объекта. в любой программе на java встречается как минимум один статический метод. это метод **main**, его автоматически запускает среда выполнения. по правилам языка этот метод должен быть статическим:

```java


public class Program{

     

	// метод main должен быть статическим 

	public static void main(String[] args) {

        

        // здесь действия программы

	}

}
```

для обращения к статическим методам также применяется имя класса:

```java


public class Program{

     

	public static void main(String[] args) {

        

        Person tom = new Person(41);

        Person.checkStatus(tom); // Сколько лет осталось до пенсии: 24

	}

}



class Person{



    int age; 

    static int retirementAge = 65;



    Person(int age){

        this.age = age;

	}

    // статический метод

    static void checkStatus(Person person)

    {

        if (person.age >= retirementAge)

            System.out.println("Уже на пенсии");

        else

            System.out.printf("До пенсии осталось %d лет\n", retirementAge - person.age);

    }

}
```

в классе `Person` определён статический метод `checkStatus()`. параметром он принимает объект `Person` и проверяет его пенсионный статус: сравнивает `person.age` со статическим `retirementAge`. у статического метода нет ссылки `this` на текущий экземпляр, поэтому нужный объект передаётся явно.

статический метод обращается только к статическим членам своего класса. к нестатическим методам и полям этого же класса внутри статического метода обращаться нельзя: нет экземпляра, относительно которого их разрешать. поэтому, чтобы вызвать из `main` другие методы, объявленные в одном классе с `main`, у них тоже должен быть модификатор `static`:

```java


public class Program{

     

	public static void main(String[] args) {

        

        sum(4, 5);   // метод статический, поэтому мы можем его вызывать в методе main

        // add(4, 5);   // метод НЕстатический, поэтому мы НЕ можем его вызвать в методе main

	}



    static void sum(int a, int b){

        System.out.printf("Сумма чисел %d и %d равна %d\n", a, b, a+b);

    }



    void add(int a, int b){

        System.out.printf("Сумма чисел %d и %d равна %d\n", a, b, a+b);

    }

}
```

речь об обращении к методам и полям, которые определены в одном и том же классе. если статическому методу передана ссылка на объект, через эту ссылку он читает поля экземпляра, как `checkStatus` читает `person.age`. ограничение касается членов экземпляра, к которым пытаются обратиться без объекта.

метод определяют как статический, когда он не затрагивает состояние объекта, то есть его нестатические поля и константы, и для вызова нет смысла создавать экземпляр класса:

```java


public class Program{

     

	public static void main(String[] args) {

			

		System.out.println(Operation.sum(45, 23));			// 68

		System.out.println(Operation.subtract(45, 23));		// 22

		System.out.println(Operation.multiply(4, 23));		// 92

	}

}

class Operation{

	

	static int sum(int x, int y){

		return x + y;

	}

	static int subtract(int x, int y){

		return x - y;

	}

	static int multiply(int x, int y){

		return x * y;

	}

}
```

для методов `sum`, `subtract` и `multiply` не имеет значения, какой именно экземпляр класса `Operation` использовался бы. эти методы работают только с параметрами и не затрагивают состояние класса. поэтому их определяют как статические и вызывают через имя класса, без `new`.
