ряд методов выделения сегмента в классе `Arena` принимает компоновку **MemoryLayout**. этот интерфейс описывает размер области, выравнивание и порядок байтов. память и её интерпретация в foreign function and memory api разделены: сегмент задаёт адрес, длину и время жизни, а компоновка говорит, как читать байты. интерфейс **ValueLayout** наследует `MemoryLayout` и даёт константы встроенных компоновок для адреса и для примитивных значений java. у этих констант порядок байтов равен порядку байтов текущей платформы.

- `ADDRESS` : константа компоновки адреса. размер совпадает с размером машинного адреса, тем же, что у `size_t` в языке c. выравнивание в байтах равно `sizeof(size_t)`

- `ADDRESS_UNALIGNED` : константа компоновки адреса без выравнивания. размер по-прежнему совпадает с размером машинного адреса (`size_t`), выравнивание равно 1

- `JAVA_BOOLEAN` : константа компоновки значения `boolean`. размер совпадает с размером, который эта компоновка отводит значению `boolean`, и равен 1 байту. выравнивание равно 1

- `JAVA_BYTE` : константа компоновки значения `byte`. размер совпадает с размером типа `byte` в java и равен 1 байту, выравнивание равно 1

- `JAVA_CHAR` : константа компоновки значения `char`. размер совпадает с размером типа `char` в java и равен 2 байтам, выравнивание равно 2

- `JAVA_CHAR_UNALIGNED` : константа компоновки значения `char` без выравнивания. размер совпадает с размером типа `char` в java, выравнивание равно 1

- `JAVA_DOUBLE` : константа компоновки значения `double`. размер совпадает с размером типа `double` в java и равен 8 байтам, выравнивание равно 8

- `JAVA_DOUBLE_UNALIGNED` : константа компоновки значения `double` без выравнивания. размер совпадает с размером типа `double` в java, выравнивание равно 1

- `JAVA_FLOAT` : константа компоновки значения `float`. размер совпадает с размером типа `float` в java и равен 4 байтам, выравнивание равно 4

- `JAVA_FLOAT_UNALIGNED` : константа компоновки значения `float` без выравнивания. размер совпадает с размером типа `float` в java, выравнивание равно 1

- `JAVA_INT` : константа компоновки значения `int`. размер совпадает с размером типа `int` в java и равен 4 байтам, выравнивание равно 4

- `JAVA_INT_UNALIGNED` : константа компоновки значения `int` без выравнивания. размер совпадает с размером типа `int` в java, выравнивание равно 1

- `JAVA_LONG` : константа компоновки значения `long`. размер совпадает с размером типа `long` в java и равен 8 байтам, выравнивание равно 8

- `JAVA_LONG_UNALIGNED` : константа компоновки значения `long` без выравнивания. размер совпадает с размером типа `long` в java, выравнивание равно 1

- `JAVA_SHORT` : константа компоновки значения `short`. размер совпадает с размером типа `short` в java и равен 2 байтам, выравнивание равно 2

- `JAVA_SHORT_UNALIGNED` : константа компоновки значения `short` без выравнивания. размер совпадает с размером типа `short` в java, выравнивание равно 1

выровненная компоновка требует, чтобы смещение доступа было кратно выравниванию. обращение по некратному смещению для такой константы завершается ошибкой времени выполнения. константа с суффиксом `UNALIGNED` задаёт выравнивание 1 и принимает любое смещение. отдельная константа нужна потому, что на части архитектур невыровненное чтение либо медленнее, либо недопустимо на уровне процессора, и режим доступа выбирают явно.

массив выделяют по компоновке элемента и числу элементов. для однородного массива примитивов берут константу **ValueLayout**. массив из 16 значений `double`:

```java


import java.lang.foreign.*;



public class Program {



    public static void main(String[] args) {



        try (Arena arena = Arena.ofConfined()) {



            // выделяем память для 16 значений double

            MemorySegment double_seg = arena.allocate(ValueLayout.JAVA_DOUBLE, 16);



            System.out.println(double_seg);   // MemorySegment{ kind: native, address: 0x7477a8184cb0, byteSize: 128 }

        } 

    }

}
```

`Arena.allocate` резервирует непрерывный нативный сегмент. длина в байтах равна размеру элемента, умноженному на число элементов. у `JAVA_DOUBLE` размер элемента 8, поэтому 16 элементов занимают 128 байт: это значение `byteSize` печатает программа. выравнивание выделенной области совпадает с выравниванием компоновки. арена `Arena.ofConfined()` привязана к потоку-владельцу: сегмент, выделенный в ней, доступен этому потоку. закрытие арены в try-with-resources освобождает память, и дальнейший доступ к сегменту недопустим.

если значения уже лежат в массиве java, их переносят в нативный сегмент методом `allocateFrom()`:

```java


import java.lang.foreign.*;



public class Program {



    public static void main(String[] args) {



        try (Arena arena = Arena.ofConfined()) {



            double[] nums = {1.0, 2.0, 3.0, 4.0};

            // выделяем память для массива nums

            MemorySegment double_seg = arena.allocateFrom(ValueLayout.JAVA_DOUBLE, nums);



            System.out.println(double_seg);   // MemorySegment{ kind: native, address: 0x75f5cc1851a0, byteSize: 32 }

        } 

    }

}
```

`allocateFrom` выделяет сегмент и копирует в него элементы. четыре значения `double` занимают 32 байта, что совпадает с печатаемым `byteSize`. после копирования массив java и нативный сегмент независимы. последующая запись в сегмент оставляет исходный массив прежним.

### работа с сегментами памяти

интерфейс **MemorySegment** содержит операции над уже выделенными данными. основные формы доступа:

- `String getString(long offset)` преобразует строку utf-8, лежащую в сегменте, в строку java. чтение начинается со смещения и идёт до завершающего нулевого байта

- `type getAtIndex(ValueLayout.of type layout, long index)` считывает значение примитивного типа по индексу элемента. индекс считается в элементах: байтовое смещение равно индексу, умноженному на размер компоновки

- `void setAtIndex(ValueLayout.of type layout, long index, type value)` записывает значение примитивного типа по заданному индексу массива

- `type get(ValueLayout.of type layout, long offset)` считывает значение примитивного типа по заданному смещению в байтах

- `void set(ValueLayout.of type layout, long offset, type value)` записывает значение примитивного типа по заданному смещению в байтах

- `type [] toArray(ValueLayout.of type elementLayout)` копирует содержимое сегмента памяти в новый массив java. тип элементов задаёт компоновка `elementLayout`, число элементов определяется длиной сегмента

метод `getString()` применяют, когда байты utf-8 уже лежат в сегменте: их могла записать функция c или предыдущий вызов `allocateFrom`. чтобы получить строку java от начала сегмента, в `getString()` передают смещение 0:

```java


import java.lang.foreign.*;



public class Program {



    public static void main(String[] args) {



        try (Arena arena = Arena.ofConfined()) {



            String str = "Hello enoobis.ru";



            // преобразуем строку Java в строку UTF-8

            MemorySegment str_seg = arena.allocateFrom(str);



            System.out.println(str_seg);   // MemorySegment{ kind: native, address: 0x7aa79c1802d0, byteSize: 18 }



            // обратное преобразование в строку Java

            String java_str = str_seg.getString(0);



            System.out.println(java_str);   // Hello enoobis.ru

        } 

    }

}
```

`allocateFrom` от строки java записывает байты utf-8 и завершающий нулевой байт. без этого байта `getString` не определяет конец строки. обратное чтение `getString(0)` декодирует utf-8 в строку java. строка `Hello enoobis.ru` в примере проходит оба направления: из java в сегмент и из сегмента обратно в java.

чтение и запись по индексу массива требуют компоновку элемента и индекс:

```java


import java.lang.foreign.*;



public class Program {



    public static void main(String[] args) {



        try (Arena arena = Arena.ofConfined()) {



            double[] nums = {1.0, 2.0, 3.0, 4.0};

            // выделяем память для массива nums

            MemorySegment double_seg = arena.allocateFrom(ValueLayout.JAVA_DOUBLE, nums);



            // устанавливаем для элемента с индексом 2 значение 5.0

            int index = 2;

            double_seg.setAtIndex(ValueLayout.JAVA_DOUBLE, index, 5.0);

            // получаем один элемент double по индексу 2

            double second_double = double_seg.getAtIndex(ValueLayout.JAVA_DOUBLE, index);



            System.out.println(second_double);  // 5.0

        } 

    }

}
```

элемент с индексом 2 получает значение 5.0, затем это значение читается тем же индексом. для `JAVA_DOUBLE` индекс 2 соответствует байтовому смещению 16.

сегмент хранит базовый адрес, длину в байтах и область жизни арены. компоновку, по которой байты были записаны, он не хранит. при каждом чтении и при каждом обновлении компоновку указывают снова. в этом примере это `ValueLayout.JAVA_DOUBLE`. та же область, прочитанная с другой компоновкой, даст другое значение при тех же байтах. границы при доступе проверяются: смещение и размер читаемого значения должны лежать внутри длины сегмента, иначе выполнение завершается исключением.

все значения сегмента можно забрать в массив java одним копированием:

```java


double[] double_nums = double_seg.toArray(ValueLayout.JAVA_DOUBLE);
```

`toArray` создаёт массив примитивного типа и копирует в него байты сегмента. длина результата равна длине сегмента, делённой на размер элемента компоновки.

методы `get()` и `set()` соответствуют `getAtIndex` и `setAtIndex`. отличие в адресации: аргумент задаёт смещение в байтах от начала сегмента, а не номер элемента.

```java


import java.lang.foreign.*;



public class Program {



    public static void main(String[] args) {



        try (Arena arena = Arena.ofConfined()) {



            double[] nums = {1.0, 2.0, 3.0, 4.0};

            // выделяем память для массива nums

            MemorySegment double_seg = arena.allocateFrom(ValueLayout.JAVA_DOUBLE, nums);



            // устанавливаем значение 11 по смещению 8 байт

            double_seg.set(ValueLayout.JAVA_DOUBLE, 8, 11);

            // получаем один элемент double по смещению 16 байт

            double second_double = double_seg.get(ValueLayout.JAVA_DOUBLE, 16);



            System.out.println(second_double);  // 3.0

        } 

    }

}
```

смещение 8 байт приходится на второй элемент `double`, то есть на индекс 1. туда записывается значение 11. смещение 16 байт приходится на третий элемент, индекс 2. в исходных данных там лежит 3.0, и чтение по смещению 16 возвращает 3.0. для выровненной компоновки `JAVA_DOUBLE` смещение должно быть кратно 8. доступ с произвольным байтовым сдвигом выполняют через `JAVA_DOUBLE_UNALIGNED`.
