консольная утилита jshell реализует цикл read-evaluate-print loop, или repl: чтение, вычисление, вывод. в сеанс вводится фрагмент на java, jshell вычисляет его, печатает результат и ждёт следующий ввод. полный класс, файл и метод `main` для этого не нужны, поэтому отдельное выражение проверяется быстрее, чем сборкой программы. утилита входит в jdk начиная с java 9 (jep 222). такой фрагмент называется сниппетом: это выражение, инструкция или объявление, которое jshell принимает вне обычной единицы компиляции.

сеанс начинается командой `jshell` в консоли или в командной строке:

```bash


eugene@Eugene:~$ jshell

|  Welcome to JShell -- Version 22.0.1

|  For an introduction type: /help intro



jshell>
```

строка приглашения `jshell>` отличает ввод пользователя от ответа утилиты. первая строка называет версию jshell, в образце это 22.0.1.

дальше вводится выражение `2 + 6`, сумма двух чисел:

```bash


jshell> 2 + 6

$1 ==> 8



jshell>
```

jshell печатает результат. сумма чисел 2 и 6 равна 8:

```bash
$1 ==> 8
```

имя **$1** означает, что результат (число 8) сохранён и доступен следующим сниппетам через подстановку `$1`. это временная переменная сеанса: jshell заводит её для значения выражения, которому не задали имя. следующее выражение использует её, `5 * $1`:

```bash


jshell> 5 * $1

$2 ==> 40



jshell>
```

выражение `5 * $1` совпадает с выражением `5 * 8`, поэтому результат равен 40. это число дальше доступно через `$2`.

если значение нужно многократно, временное имя заменяют явным:

```bash


jshell> var sum = 2 + 5

sum ==> 7



jshell>
```

служебное имя `var` объявляет локальную переменную `sum` и поручает компилятору вывести её тип из инициализатора. здесь инициализатор вычисляет сумму 2 и 5, переменная хранит 7. дальше переменная используется по этому имени:

```bash


jshell> 4 * sum

$4 ==> 28



jshell>
```

произведение `4 * sum` равно 28. в протоколе сеанса результат записан под именем `$4`.

### автодополнение

дополнение по клавише `Tab` подставляет члены типа и сигнатуры методов. вводится строка `System.` (с точкой на конце) и нажимается `Tab`. членов у класса `System` много, поэтому jshell просит нажать `Tab` ещё раз. после второго нажатия печатается список имён, которые можно продолжить от `System`:

```bash


jshell> System.out.

notifyAll()    print(         printf(        println(       toString()
```

список перечисляет методы объекта `System.out`, стандартного потока вывода. чтобы напечатать строку, нужен один из методов `printf`, `print` или `println`. вводится префикс `System.out.p` (буква `p` на конце) и опять нажимается `Tab`:

```bash


jshell> System.out.p

jshell> System.out.print
```

общее начало `print` утилита подставляет сама. остаётся дописать имя метода и аргументы:

```bash


jshell> System.out.println("Hello enoobis.ru")

Hello enoobis.ru



jshell>
```

точка с запятой в этой строке протокола не стоит. jshell принимает и выражение, и инструкцию, так что для вызова в сеансе завершитель необязателен. на консоль уходит текст `Hello enoobis.ru`, затем снова печатается приглашение.

### выход из программы

сеанс завершается командой `/exit`:

```bash


jshell> /exit

|  Goodbye

eugene@Eugene:~$
```

после неё jshell печатает прощание и возвращает управление оболочке. косая черта в начале отличает команду самого jshell от кода на java.
