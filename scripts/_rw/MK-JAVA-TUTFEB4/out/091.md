### соединение строк

строки соединяет операция сложения `+`:

```java


String str1 = "Java";

String str2 = "Hello";

String str3 = str1 + " " + str2;

        

System.out.println(str3); // Hello Java
```

операнды `"Java"` и `"Hello"` склеиваются через пробел. результат это новый объект: исходные `str1` и `str2` не меняются, потому что `String` неизменяем. компилятор заменяет оператор на конкатенацию. с java 5 и до java 9 в байткоде для этого собирался `StringBuilder`, с java 9 вызывается `invokedynamic` и `StringConcatFactory`. наблюдаемый результат один и тот же.

если среди операндов сложения есть не строка, а, например, число, это значение сначала переводится в строку:

```java
String str3 = "Год " + 2015;
```

перевод делает `valueOf()` класса `String`. у метода много перегрузок, они покрывают примитивы и ссылочные типы. для объекта перегрузка `valueOf` вызывает `toString()` этого объекта. для ссылки `null` метод возвращает строку `"null"` и исключение не бросает.

другой способ соединения это `concat()`:

```java


String str1 = "Java";

String str2 = "Hello";

str2 = str2.concat(str1); // HelloJava
```

`concat()` принимает строку, с которой соединяется вызывающая строка, и возвращает новую строку. вызывающая строка остаётся прежней, поэтому результат присваивают обратно, как `str2` в примере. аргумент `null` приводит к `NullPointerException`. `valueOf` на `null` возвращает текст `"null"`. две строки здесь склеиваются без разделителя, получается `"HelloJava"`.

`join()` соединяет строки с разделителем. там, где `concat` дал одно слово `"HelloJava"`, разделитель ставит пробел между частями:

```java


String str1 = "Java";

String str2 = "Hello";

String str3 = String.join(" ", str2, str1); // Hello Java
```

`join` статический, вызывается у класса `String`, а не у экземпляра. первый параметр это разделитель, им разделяются подстроки в результате. остальные параметры через запятую передают произвольный набор подстрок. в примере их две, допустимо и больше. `null` среди подстрок снова становится текстом `"null"`, как при `valueOf`.

### проверка на пустоту

`isEmpty()` проверяет, пуста ли строка. пустая строка не содержит символов, при этом она определена и не равна `null`:

```java


String str1 = "Hello";

System.out.println(str1.isEmpty());  // false

String str2 = "  \t\n";

System.out.println(str2.isEmpty());  // false

String str3 = "";

System.out.println(str3.isEmpty());  // true
```

даже если в строке только пробелы, табуляция и переводы строки, она считается не пустой: `length()` больше нуля, и `isEmpty()` возвращает `false`.

`isBlank()` тоже проверяет пустоту, но пустой считает и строку, в которой нет ничего, кроме пробелов, табуляции и переводов строки. метод смотрит на `Character.isWhitespace`, а не только на длину:

```java


String str1 = "Hello";

System.out.println(str1.isBlank());  // false

String str2 = "  \t\n";

System.out.println(str2.isBlank());  // true

String str3 = "";

System.out.println(str3.isBlank());  // true
```

у `"Hello"` метод возвращает `false`. строка из пробела, табуляции и перевода строки для `isEmpty` была бы непустой, для `isBlank` она пустая. пустая строка `""` пустая для обоих методов. `isBlank` появился в java 11. на `null` и `isEmpty`, и `isBlank` бросают `NullPointerException`: проверяется объект, а не ссылка.

### извлечение символов и подстрок

символ по индексу возвращает `charAt(int index)`. аргумент это индекс, результат это символ `char` по этому индексу:

```java


String str = "Java";

char c = str.charAt(2);

System.out.println(c); // v
```

индексация, как у массива, начинается с нуля. у `"Java"` индекс 2 это `'v'`. индекс меньше нуля или не меньше `length()` даёт `StringIndexOutOfBoundsException`. метод возвращает кодовую единицу utf-16, а не обязательно целый юникодный скаляр.

группа символов извлекается методом `getChars(int srcBegin, int srcEnd, char[] dst, int dstBegin)`. параметры:

- `srcBegin`: индекс в строке, с которого начинается извлечение символов
- `srcEnd`: индекс в строке, до которого идёт извлечение символов
- `dst`: массив символов, в который будут извлекаться символы
- `dstBegin`: индекс в массиве `dst`, с которого надо добавлять извлечённые из строки символы

`srcBegin` включается, `srcEnd` нет. число скопированных символов равно `srcEnd - srcBegin`. массив `dst` должен быть достаточно длинным, начиная с `dstBegin`, иначе будет исключение выхода за границу.

```java


String str = "Hello world!";

int start = 6;

int end = 11;

char[] dst=new char[end - start];

str.getChars(start, end, dst, 0);

System.out.println(dst); // world
```

у `"Hello world!"` индексы 6 и 11 вырезают `"world"`: с `'w'` включительно до `'!'` не включая. массив назначения создан ровно этой длины, запись идёт с индекса 0.

### сравнение строк

строки сравнивают методами `equals()` (с учётом регистра) и `equalsIgnoreCase()` (без учёта регистра). оба принимают строку, с которой идёт сравнение:

```java


String str1 = "Hello";

String str2 = "hello";

        

System.out.println(str1.equals(str2)); // false

System.out.println(str1.equalsIgnoreCase(str2)); // true
```

`"Hello"` и `"hello"` различаются регистром, поэтому `equals` возвращает `false`, а `equalsIgnoreCase` возвращает `true`. оба метода сравнивают последовательности символов. `equals` проверяет длину и попарные кодовые единицы. `equalsIgnoreCase` сравнивает без учёта регистра и внутри вызывает `regionMatches` с флагом игнорирования регистра на всю длину строки.

для чисел и других примитивов равенство записывают знаком `==`. для строк тот же знак сравнивает идентичность ссылок: истинен, только если обе переменные указывают на один объект. совпадение текста проверяет `equals()`. две одинаковые по символам строки, собранные разными `new String`, на `==` дают `false`.

отдельные подстроки внутри двух строк сравнивает `regionMatches()`. формы метода:

```java


boolean regionMatches(int toffset, String other, int oofset, int len)

boolean regionMatches(boolean ignoreCase, int toffset, String other, int oofset, int len)
```

параметры:

- `ignoreCase`: нужно ли игнорировать регистр символов при сравнении. если значение `true`, регистр игнорируется
- `toffset`: начальный индекс в вызывающей строке, с которого начнётся сравнение
- `other`: строка, с которой сравнивается вызывающая
- `oofset`: начальный индекс в сравниваемой строке, с которого начнётся сравнение
- `len`: количество сравниваемых символов в обеих строках

имя `oofset` во второй строке записано так в показанной сигнатуре. в библиотеке параметр называется `offset`, смысл тот же: старт во второй строке.

вызов:

```java


String str1 = "Hello world";

String str2 = "I work";

boolean result = str1.regionMatches(6, str2, 2, 3);

System.out.println(result); // true
```

метод сравнивает 3 символа с 6-го индекса первой строки (`"wor"`) и 3 символа со 2-го индекса второй строки (`"wor"`). подстроки совпадают, возвращается `true`. первая перегрузка регистр учитывает. выход за длину любой из строк даёт `false`, а не исключение.

ещё пара методов, `compareTo(String str)` и `compareToIgnoreCase(String str)`, тоже сравнивает две строки и дополнительно сообщает, какая больше. значение больше 0 означает, что первая строка больше второй. значение меньше нуля означает, что больше вторая. равные строки дают 0.

порядок лексикографический, по кодовым единицам utf-16. строка `"A"` меньше строки `"B"`, потому что символ `'A'` в этом порядке стоит перед `'B'`. если первые символы равны, сравниваются следующие. когда одна строка является префиксом другой, большей считается более длинная, и модуль результата равен разнице длин.

```java


String str1 = "hello";

String str2 = "world";

String str3 = "hell";

        

System.out.println(str1.compareTo(str2)); // -15 - str1 меньше чем strt2

System.out.println(str1.compareTo(str3)); // 1 - str1 больше чем str3
```

`"hello"` против `"world"` даёт -15: первая различающаяся пара это `'h'` и `'w'`, коды 104 и 119, разность 104 - 119 = -15. отрицательный знак означает, что первая строка меньше. `"hello"` против `"hell"` даёт 1: общий префикс совпал, и у первой строки на один символ больше.

### поиск в строке

`indexOf()` находит индекс первого вхождения подстроки, `lastIndexOf()` индекс последнего. если подстрока не найдена, оба возвращают -1:

```java


String str = "Hello world";

int index1 = str.indexOf('l'); // 2

int index2 = str.indexOf("wo"); //6

int index3 = str.lastIndexOf('l'); //9
```

поиск идёт по кодовым единицам. у `"Hello world"` первое `'l'` стоит на индексе 2, последнее на индексе 9, подстрока `"wo"` начинается с индекса 6. есть перегрузки с начальным индексом: поиск тогда идёт не с нуля, а с указанной позиции.

`startsWith()` проверяет, начинается ли строка с заданной подстроки. `endsWith()` проверяет, заканчивается ли строка заданной подстрокой:

```java


String str = "myfile.exe";

boolean start = str.startsWith("my"); //true

boolean end = str.endsWith("exe"); //true
```

у `"myfile.exe"` префикс `"my"` и суффикс `"exe"` находятся на месте, оба вызова возвращают `true`. сравнение здесь точное, регистр учитывается. пустой префикс метод принимает как совпадение.

### замена в строке

`replace()` заменяет в строке одну последовательность символов на другую. заменяются все вхождения, аргумент читается как литерал, а не как регулярное выражение. для замены по регулярному выражению есть отдельный `replaceAll`.

```java


String str = "Hello world";

String replStr1 = str.replace('l', 'd'); // Heddo wordd

String replStr2 = str.replace("Hello", "Bye"); // Bye world
```

первая перегрузка меняет символ `'l'` на `'d'` во всех позициях и даёт `"Heddo wordd"`. вторая меняет подстроку `"Hello"` на `"Bye"` и даёт `"Bye world"`. исходная строка остаётся прежней, результаты лежат в новых объектах.

### удаление начальных и конечных пробелов

`strip()` удаляет начальные и конечные пробелы:

```java


String str = "   Hello enoobis.ru  ";

System.out.println(str.length());  // 22

str = str.strip(); 	// удаляем пробелы

System.out.println(str.length());  // 17
```

до вызова длина 22, после `strip` остаётся 17. сняты пробелы с обоих концов, середина строки не трогается.

в более ранних версиях java для этого служил `trim()`. он удаляет символы с кодом не выше `U+0020` и не считает пробельными ряд символов unicode, которые `Character.isWhitespace` относит к пробелам. `strip()` как раз ориентируется на `isWhitespace`. для текста с такими символами берут `strip()`.

`stripLeading()` удаляет только начальные пробелы, `stripTrailing()` только конечные:

```java


String str = "   Hello enoobis.ru  ";

System.out.println(str.length());  // 22

str = str.stripLeading();   // удаляем начальные пробелы

System.out.println(str.length());  // 19

str = str.stripTrailing();   // удаляем конечные пробелы

System.out.println(str.length());  // 17
```

после `stripLeading` длина 19: сняты ведущие пробелы, хвостовые ещё на месте. следующий `stripTrailing` доводит длину до 17.

### получение подстроки

`substring()` возвращает подстроку от заданного индекса до конца строки либо до второго индекса:

```java


String str = "Hello world";

String substr1 = str.substring(6); // world

String substr2 = str.substring(3,5); //lo
```

`substring(6)` берёт хвост `"Hello world"` с индекса 6, это `"world"`. `substring(3, 5)` берёт полуинтервал: индекс 3 включительно, индекс 5 нет, получается `"lo"`. метод возвращает новый `String`. индекс вне диапазона или конец меньше начала дают `StringIndexOutOfBoundsException`.

### изменение регистра

`toLowerCase()` переводит символы строки в нижний регистр, `toUpperCase()` в верхний:

```java


String str = "Hello World"; 

System.out.println(str.toLowerCase()); // hello world

System.out.println(str.toUpperCase()); // HELLO WORLD
```

обе версии без аргументов берут локаль по умолчанию, `Locale.getDefault()`. есть перегрузки с явной локалью: правила регистра от локали зависят, и для текста с фиксированным регистром локаль задают явно. как и остальные методы `String`, эти два возвращают новую строку.

### split

`split()` разбивает строку на подстроки по разделителю. разделитель, символ или набор символов, передаётся аргументом. аргумент это регулярное выражение, а не буквальный набор символов. точка, вертикальная черта и прочие метасимволы без экранирования означают не сами себя.

разбиение текста на слова:

```java


String text = "FIFA will never regret it";

String[] words = text.split(" ");

for(String word : words){

	System.out.println(word);

}
```

разделитель `" "` это выражение из одного пробела, поэтому строка режется по пробелам. одноаргументный `split` отбрасывает хвостовые пустые строки. консольный вывод:

```bash


FIFA

will

never

regret

it
```

каждое слово печатается отдельной строкой, в порядке слева направо.
