поразрядные операции выполняются над отдельными битами целых чисел. операндами могут быть только целые типы: `byte`, `short`, `int`, `long` и `char`. перед операцией значения уже `int` остаются как есть, более узкие целые приводятся к `int` по правилам числового продвижения.

у каждого целого есть двоичное представление. число 4 в двоичной системе записывается как `100`, число 5 как `101`.

одни и те же десятичные значения при разной ширине типа выглядят по-разному:

```java


byte b = 7;		// 0000 0111

short s = 7;	// 0000 0000 0000 0111
```

тип `byte` занимает 1 байт, или 8 бит, и представлен 8 разрядами. значение `b` в двоичном коде равно `00000111`. тип `short` занимает 2 байта, или 16 бит, поэтому то же число занимает 16 разрядов: `0000 0000 0000 0111`. старшие разряды заполнены нулями.

двоичный литерал с префиксом `0b` записывает разряды явно. символ `_` внутри числового литерала компилятор отбрасывает, он только группирует разряды:

```java


class Program{



    public static void main(String[] args) {  



        byte b = 0b0000_0111;               // 7

        short s = 0b0000_0000_0000_0111;	// 7

        System.out.println("byte b = " + b);        // byte b = 7

        System.out.println("short s = " + s);       // short s = 7

    }

}
```

целые со знаком хранятся в дополнительном коде (two's complement). старший разряд знаковый. если он равен 0, число неотрицательное, и запись совпадает с записью беззнакового числа той же ширины. `0000 0001` в десятичной системе равно 1.

![двоичное представление чисел в java](/uploads/course-lectures/eb5463e6125e03d5e58c2adbcf429741e25b5ecc.png)

если старший разряд равен 1, число отрицательное. восьмибитная запись `1111 1111` равна -1, запись `1111 0011` равна -13.

следующий литерал занимает все 32 бита `int`, и знаковый разряд в нём равен 1:

```java


class Program{



    public static void main(String[] args) {  



        int num = 0b1111_1111_1111_1111_1111_1111_1111_1110;               // -2



        System.out.println("num = " + num);        // num = -2

    }

}
```

значение `0b1111_1111_1111_1111_1111_1111_1111_1110` состоит из единиц и нуля в младшем разряде. в дополнительном коде это -2.

модуль получается по правилу дополнительного кода: инверсия всех разрядов и прибавление единицы. инверсия меняет каждую единицу на нуль и каждый нуль на единицу:

```java


// ~ - операция инверсии

~ 0b1111_1111_1111_1111_1111_1111_1111_1110

= 

  0b0000_0000_0000_0000_0000_0000_0000_0001
```

затем к результату прибавляется 1:

```java


0b0000_0000_0000_0000_0000_0000_0000_0001

+                                       

                                        1

=

0b0000_0000_0000_0000_0000_0000_0000_0010
```

двоичное число `10` в десятичной системе равно 2. так из битовой записи -2 восстанавливается положительное значение той же величины. общее соотношение для дополнительного кода: `-x = ~x + 1`, откуда `~x = -x - 1`.

### логические операции

логические операции над числами здесь поразрядные. число рассматривается как набор битов: 2 в двоичной системе равно `10` и занимает два значащих разряда, 7 равно `111` и занимает три. операция выполняется независимо в каждой позиции, недостающий старший бит более короткой записи считается нулём.

- `&` (логическое умножение). умножение идёт поразрядно. если у обоих операндов в данном разряде стоит 1, результат в этом разряде равен 1, иначе 0. у чисел 2 и 5 записи `010` и `101`. произведения разрядов `0*1`, `1*0`, `0*1` дают `000`, то есть 0. у чисел 4 и 5 записи `100` и `101`. произведения `1*1`, `0*0`, `0*1` дают `100`, то есть 4:

```java


 int a1 = 2; //010

 int b1 = 5;//101

 System.out.println(a1&b1); // результат 0

            

int a2 = 4; //100

int b2 = 5; //101

System.out.println(a2 & b2); // результат 4
```

- `|` (логическое сложение). операция тоже идёт по двоичным разрядам. в разряде возвращается 1, если хотя бы у одного числа в этом разряде стоит 1. это поразрядное «или»:

```java


int a1 = 2; //010

int b1 = 5;//101

System.out.println(a1|b1); // результат 7 - 111

int a2 = 4; //100

int b2 = 5;//101

System.out.println(a2 | b2); // результат 5 - 101
```

- `^` (логическое исключающее или). операцию называют xor. в текущем разряде возвращается 1, если биты двух чисел различны, и 0, если они совпадают. повторный xor с тем же вторым операндом возвращает исходное значение, потому что `x ^ k ^ k = x`. на этом свойстве строится простой пример шифрования. выражение `9 ^ 5` равно 12, а `12 ^ 5` снова равно 9:

```java


int number = 45; // 1001 Значение, которое надо зашифровать - в двоичной форме 101101

int key = 102; //Ключ шифрования - в двоичной системе 1100110

int encrypt = number ^ key; //Результатом будет число 1001011 или 75

System.out.println("Зашифрованное число: " +encrypt);



int decrypt = encrypt ^ key; // Результатом будет исходное число 45

System.out.println("Расшифрованное число: " + decrypt);
```

- `~` (логическое отрицание, инверсия). каждый разряд меняется на противоположный: 1 становится 0, 0 становится 1. операнд перед инверсией приводится к `int`, поэтому инвертируются все 32 бита. для `12` результат равен -13, что совпадает и с чтением младшего байта `1111 0011` как знакового `byte`:

```java


byte a = 12;                 // 0000 1100     

System.out.println(~a);		//  1111 0011   или -13
```

### операции сдвига

сдвиг тоже выполняется над разрядами. биты можно сдвинуть влево или вправо.

для типа `int` величина сдвига берётся по модулю 32, для `long` по модулю 64: в счётчике участвуют только младшие 5 или 6 бит. сдвиг `int` на 32 позиции совпадает со сдвигом на 0.

сдвиг влево записывается `<<`. освободившиеся младшие разряды заполняются нулями. при отсутствии переполнения сдвиг влево на `n` позиций совпадает с умножением на `2^n`. примеры `a << b` разобраны в программах ниже.

- `>>` сдвигает число вправо и размножает знаковый бит. это арифметический сдвиг. `16 >> 1` переводит двоичное `10000` в `1000`, то есть 16 в 8. если исходное число делится на два, сдвиг на один разряд вправо совпадает с целочисленным делением на два
- `>>>` выполняет беззнаковый, логический сдвиг вправо. число сдвигается на заданное число разрядов, а освободившиеся старшие разряды заполняются нулями, знаковый бит не копируется. выражение `-8 >>> 2` равно 1073741822: отрицательное 32-битное значение после подстановки нулей в старшие разряды становится большим положительным числом

если число делится на два, сдвиг на один разряд в соответствующую сторону совпадает с умножением или делением на два. на уровне процессора сдвиг обычно дешевле умножения и деления, поэтому для степени двойки его иногда записывают вместо арифметической операции. для отрицательных чисел правый арифметический сдвиг и целочисленное деление расходятся, когда результат не целый: деление в java усекает к нулю, а `>>` усекает к минус бесконечности. условие «число делится на степень двойки, равную величине сдвига» как раз отсекает этот случай.

операнды сдвига не обязаны нацело делиться на эту степень двойки. биты, которым после сдвига не хватает позиции, отбрасываются. сначала пример, где сдвиг на 2 для числа 16 даёт точное умножение и деление на 4:

```java


class Program{



    public static void main(String[] args) {  



        int a = 16; // в двоичной форме 10000

        int b = 2; // в двоичной форме 00010

        int c = a << b; // Сдвиг числа 10000 влево на 2 разряда, равно 1000000 или 64 в десятичной системе

        

        System.out.println("с: " + c);    // 64

        

        int d = a >> b; // Сдвиг числа 10000 вправо на 2 разряда, равно 100 или 4 в десятичной системе

        System.out.println("d: " + d);     // 4

    }

}
```

тот же сдвиг определён и для числа, которое на 4 не делится:

```java


class Program{



    public static void main(String[] args) {  



        int a = 22; // в двоичной форме 10110

        int b = 2; // в двоичной форме

        int c = a << b; // Сдвиг числа 10110 влево на 2 разряда, равно 1011000 или 88 в десятичной системе



        System.out.println("с: " + c);    // 88



        int d = a >> b; // Сдвиг числа 10110 вправо на 2 разряда, равно 101 или 5 в десятичной системе

        System.out.println("d: " + d);     // 5

    }

}
```

`22` в двоичной записи это `10110`. сдвиг влево на 2 даёт `1011000`, то есть 88. сдвиг вправо на 2 отбрасывает два младших бита и даёт `101`, то есть 5. целочисленное `22 / 4` тоже равно 5: дробная часть 0.5 уже отброшена вместе с битами.

### пример практического применения

поразрядные операции читают и записывают отдельные биты, а не только число целиком. ниже три числа, каждое в диапазоне от 0 до 3:

```java


int value1 = 3;  // 0b0000_0011

int value2 = 2;  // 0b0000_0010

int value3 = 1;  // 0b0000_0001
```

значения не превосходят 3, значит каждому числу достаточно двух бит. три таких поля укладываются в одно число: поле записывается через `|`, затем накопитель сдвигается влево и освобождает младшие биты под следующее поле.

```java


class Program{



    public static void main(String[] args) {  



        int value1 = 3;  // 0b0000_0011

        int value2 = 2;  // 0b0000_0010

        int value3 = 1;  // 0b0000_0001

        int result = 0b0000_0000;

        // сохраняем в result значения из value1

        result = result | value1; // 0b0000_0011

        // сдвигаем разряды в result на 2 разряда влево

        result = result << 2;   // 0b0000_1100

        // сохраняем в result значения из value2

        result = result | value2;  // 0b0000_1110

        // сдвигаем разряды в result на 2 разряда влево

        result = result << 2;   // 0b0011_1000

        // сохраняем в result значения из value3

        result = result | value3;  // 0b0011_1001



        System.out.println(result);  // 57

    }

}
```

разбор по шагам. сохраняемые числа это `value1`, `value2` и `value3`. результат накапливается в `result`. начальное значение 0, для наглядности оно записано двоичным литералом:

```java
int result = 0b0000_0000;
```

первое число записывается в `result` поразрядным или. если хотя бы один из двух соответствующих битов равен 1, бит результата равен 1. при нулевом `result` операция копирует младшие биты `value1`:

```java


result = result | value1; // 0b0000_0011
```

поразрядно это сложение битовых записей:

```java


0b0000_0000

+

0b0000_0011

=

0b0000_0011
```

первое число заняло младшие два бита. числа сохраняются по порядку: сначала первое, затем второе, затем третье. каждое занимает не больше двух разрядов, поэтому `result` сдвигается на два разряда влево, и младшие биты снова становятся нулями:

```java


result = result << 2;   // 0b0000_1100
```

поразрядно:

```java


0b0000_0011 << 2 =

0b0000_1100
```

второе число записывается той же операцией или:

```java
result = result | value2;  // 0b0000_1110
```

что совпадает с поразрядной записью:

```java


0b0000_1100

+

0b0000_0010

=

0b0000_1110
```

затем снова сдвиг на два разряда влево и запись третьего числа. в `result` получается `0b0011_1001`. в десятичной системе это 57. десятичная величина здесь ни для чего не нужна: имеют значение конкретные биты. после трёх полей по два бита в 32-разрядном `int` остаётся свободное место. ширина поля может быть и другой. два бита выбраны потому, что диапазон значений здесь от 0 до 3.

восстановление идёт в обратном порядке, с последнего сохранённого числа:

```java


class Program{



    public static void main(String[] args) {  



        int result = 0b0011_1001;

        // обратное получение данных

        int newValue3 = result & 0b000_0011;

        // сдвигаем данные на 2 разряда вправо

        result = result >> 2;

        int newValue2 = result & 0b000_0011;

        // сдвигаем данные на 2 разряда вправо

        result = result >> 2;

        int newValue1 = result & 0b000_0011;

        System.out.println(newValue1);    // 3

        System.out.println(newValue2);   // 2

        System.out.println(newValue3);   // 1

    }

}
```

числа читаются от последнего к первому. каждое занимает два младших разряда, поэтому нужны только эти два бита. их выделяет маска `0b000_0011` и операция `&`: в разряде остаётся 1 только если и значение, и маска содержат 1.

```java
int newValue3 = result & 0b000_0011;
```

операция эквивалентна поразрядному умножению:

```java


0b0011_1001

*

0b0000_0011

=

0b0000_0001
```

последнее число равно `0b0000_0001`, то есть 1 в десятичной системе. после сдвига `result` вправо на 2 следующее поле оказывается на месте младших битов, и та же маска читает его.

если расположение полей известно заранее, маску ставят сразу на нужные разряды, без последовательного сдвига всего числа:

```java


result = 0b0011_1001;

int recreatedValue1 = (result & 0b0011_0000) >> 4;

System.out.println(recreatedValue1);
```

первое число занимает биты 4 и 5, если нумеровать с нуля от младшего разряда. умножение на маску `0b0011_0000` обнуляет остальные биты, сдвиг вправо на 4 переносит поле в младшие разряды:

```java


0b0011_1001

*

0b0011_0000

=

0b0011_0000

>> 4

=

0b0000_0011
```

при известной раскладке поля можно записать сразу в свои позиции. сдвигается не накопитель после каждой записи, а само сохраняемое значение перед `|`:

```java


class Program{



    public static void main(String[] args) {  



        int value1 = 3;  // 0b0000_0011

        int value2 = 2;  // 0b0000_0010

        int value3 = 1;  // 0b0000_0001

        int result = 0b0000_0000;

        // сохраняем в result значения из value1

        result = result | (value1 << 4);

        // сохраняем в result значения из value2

        result = result | (value2 << 2);

        // сохраняем в result значения из value3

        result = result | value3;  // 0b0011_1001



        System.out.println(result);  // 57

    }

}
```

`value1 << 4` ставит первое поле в биты 4 и 5, `value2 << 2` ставит второе поле в биты 2 и 3, `value3` остаётся в битах 0 и 1. поразрядное или соединяет неперекрывающиеся поля, и в `result` снова получается `0b0011_1001`, десятичное 57.
