java относится к языкам со статической строгой типизацией: у каждой переменной и каждой константы тип фиксируется при компиляции и дальше не меняется. тип задаёт множество допустимых значений, набор применимых операций и размер представления в памяти. значение вне этого множества в переменную данного типа поместить нельзя. переменная целочисленного типа не хранит дробное число.

ниже разобраны восемь примитивных типов, которыми в java описывают переменные. ссылочные типы, в том числе массивы и `String`, к этой группе не относятся: переменная ссылочного типа хранит ссылку, а не само значение.

- `boolean`: хранит значение `true` или `false`

```java


boolean isActive = false;

boolean isAlive = true;
```

логический тип не является числовым. его нельзя неявно привести к `int`, и число нельзя использовать там, где требуется `boolean`. в c и c++ нулевое значение часто играет роль лжи, в java такое смешение типов запрещено.

- `byte`: хранит целое число от `-128` до `127` и занимает 1 байт

```java


byte a = 3;

byte b = 8;
```

диапазон асимметричен, потому что целые со знаком хранятся в дополнительном коде: модуль нижней границы на единицу больше верхней.

- `short`: хранит целое число от `-32768` до `32767` и занимает 2 байта

```java


short a = 3;

short b = 8;
```

- `int`: хранит целое число от `-2147483648` до `2147483647` и занимает 4 байта

```java


int a = 4;

int b = 9;
```

`int` занимает 32 бита. это тип целочисленного литерала без суффикса и тип, к которому приводятся более узкие целые в большинстве арифметических операций.

- `long`: хранит целое число от `-9223372036854775808` до `9223372036854775807` и занимает 8 байт

```java


long a = 5;

long b = 10;
```

`long` занимает 64 бита. нижняя граница снова на единицу дальше от нуля, чем верхняя: старший разряд в дополнительном коде знаковый.

- `double`: хранит число с плавающей точкой от `±4.9*10^-324` до `±1.7976931348623157*10^308` и занимает 8 байт. в дробных литералах разделителем целой и дробной части служит точка

```java


double x = 8.5;

double y = 2.7;
```

формат соответствует ieee 754 binary64: 1 знаковый бит, 11 бит порядка и 52 бита мантиссы. указанные границы относятся к конечному представимому диапазону, от наименьшего положительного субнормального значения до наибольшего конечного.

- `float`: хранит число с плавающей точкой от `-3.4*10^38` до `3.4*10^38` и занимает 4 байта

```java


float x = 8.5F;

float y = 2.7F;
```

формат соответствует ieee 754 binary32: 1 знаковый бит, 8 бит порядка и 23 бита мантиссы. точность меньше, чем у `double`, поэтому тот же десятичный литерал в этих двух типах обычно даёт разные битовые представления.

- `char`: хранит одиночный символ в кодировке utf-16 и занимает 2 байта, поэтому диапазон хранимых значений от `0` до `65535`

`char` беззнаковый. в нём лежит одна 16-битная кодовая единица utf-16, а не произвольная кодовая точка unicode. символы вне базовой плоскости записываются суррогатной парой из двух значений `char`.

### целые числа

целочисленный литерал, например 10, 4 или -5, имеет тип `int`. литерал, значение которого помещается в более узкий целый тип, можно присвоить переменной типа `byte`, `short` или `long`: компилятор выполняет преобразование присваивания константного выражения. переменную типа `int` так сузить уже нельзя, для этого нужно явное приведение.

```java


byte a = 1;

short b = 2;

long c = 2121;
```

если литерал выходит за границы `int`, компиляция останавливается, даже когда целевая переменная имеет тип `long`:

```java
long num = 2147483649;
```

число 2147483649 допустимо для `long`: верхняя граница `int` равна 2147483647. как литерал типа `int` такого значения не существует, а литерал без суффикса имеет тип `int`. суффикс `l` или `L` задаёт тип литерала `long`:

```java
long num = 2147483649L;
```

обычно целые записывают в десятичной системе. допустимы и другие основания:

```java


int num111 = 0x6F; // 16-теричная система, число 111

int num8 = 010; // 8-ричная система, число 8

int num13 = 0b1101; // 2-ичная система, число 13
```

после `0x` идёт шестнадцатеричная запись, после `0` восьмеричная, после `0b` двоичная. ведущий нуль легко не заметить: литерал `010` равен 8, а не 10.

#### числа с плавающей точкой

дробный литерал, например 3.1 или 4.5, имеет тип `double`. суффикс `f` или `F` задаёт тип `float`. суффикс `d` или `D` явно задаёт `double`, тот же тип, который у дробного литерала и без суффикса:

```java


float fl = 30.6f;

double db = 30.6;
```

обе переменные получают близкие десятичные значения, но типы различны. `float` занимает 4 байта, `double` занимает 8 байт, разрядность мантиссы у них разная. литерал `30.6` в двоичной мантиссе представляется приближённо, поэтому после расширения `float` до `double` битовые картины всё равно не совпадают.

### символы и строки

переменная типа `char` получает один символ в одинарных кавычках: `char ch='e';`. ей можно присвоить и целое от `0` до `65535`, если это константа, попадающая в диапазон. в переменной по-прежнему хранится код символа, а целое задаёт номер в таблице unicode (utf-16):

```java


char ch=102; // символ 'f'

System.out.println(ch);
```

`println` для `char` печатает символ, а не его номер. номер 102 соответствует символу `'f'`.

символ и строка устроены по-разному. `'a'` имеет тип `char` и занимает 2 байта. `"a"` имеет тип `String` и является ссылкой на объект. `String` в набор примитивных типов не входит:

```java


String hello = "Hello...";

System.out.println(hello);
```

текстовый блок в тройных кавычках тоже имеет тип `String`. такая форма строкового литерала входит в стандарт языка с java 15 и задаёт многострочный текст. компилятор сохраняет переводы строк внутри блока и снимает общее случайное смещение строк относительно закрывающих кавычек:

```java


String text = """

                Вот мысль, которой весь я предан,

                Итог всего, что ум скопил.

                Лишь тот, кем бой за жизнь изведан,

                Жизнь и свободу заслужил.

                """;

System.out.println(text);
```
