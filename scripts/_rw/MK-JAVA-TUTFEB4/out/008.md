для хранения данных в программе предназначены **переменные**. переменная обозначает именованную область памяти, в которой лежит значение определённого типа. у переменной три свойства: тип, имя и значение. тип задаёт, какие значения допустимы и какой объём память под значение отводится. имя нужно, чтобы читать и записывать эту область в тексте программы.

переменные объявляются так:

```java
тип_данных имя_переменной;
```

например, переменная с именем `x` и типом `int`:

```java
int x;
```

это объявление вводит переменную `x` типа `int`. тип `int` занимает 32 бита и хранит целое со знаком в дополнительном коде, от -2147483648 до 2147483647. значение занимает ровно 4 байта. у локальной переменной до присваивания нет значения, доступного для чтения. поле класса без явного инициализатора получает значение по умолчанию, для `int` это 0. к локальным переменным значение по умолчанию не применяется.

имя переменной выбирается свободно, пока оно удовлетворяет трём требованиям:

- имя может содержать любые алфавитно-цифровые символы и знак подчёркивания, при этом первый символ не может быть цифрой

- в имени не должно быть знаков пунктуации и пробелов

- имя не может совпадать со служебным или зарезервированным словом java. служебные слова используются в синтаксисе языка и не доступны как имена. таких слов немного: `abstract, assert, Boolean, break, byte, Case, catch, char, class, const, continue, default, do, double, else, enum, extends, final, finally, float, for, goto, if, implements, import, instanceof, interface, int, long, native, new, null, package, private, protected, Public, return, short, static, strictfp, super, Switch, synchronized, this, throw, throws, transient, try, void, volatile, while` список пополняется с новыми версиями языка

спецификация записывает служебные слова строчными буквами: `boolean`, `case`, `public`, `switch`. язык различает регистр, поэтому написания `Boolean`, `Case`, `Public` и `Switch` из перечисления выше со служебными словами `boolean`, `case`, `public`, `switch` побуквенно расходятся. `null` в спецификации относится к литералу пустой ссылки. `const` и `goto` зарезервированы и в программах не употребляются. отдельно от этого списка с java 10 работает имя `var`: оно резервируется как обозначение выводимого типа локальной переменной. спецификация идентификатора также допускает символы валют, включая `$`. в обычном тексте `$` оставляют именам, которые порождает компилятор.

при объявлении и дальнейшем использовании учитывается регистр: java различает большие и малые буквы в идентификаторах. объявления `int num;` и `int NUM;` вводят две разные переменные.

после объявления переменной ей присваивают значение:

```java
int x;		// объявление переменной
x = 10;		// присвоение значения
System.out.println(x); 	// 10
```

значение можно задать уже в объявлении. это называется **инициализацией**:

```java
int x = 10;		// объявление и инициализация переменной
System.out.println(x); 	// 10
```

если прочитать локальную переменную до присваивания, компилятор отвергает программу:

```java
int x;
System.out.println(x);
```

это следствие анализа определённого присваивания: на каждом пути к чтению локальной переменной обязана быть запись. проверка выполняется во время компиляции, до запуска.

через запятую объявляют несколько переменных одного типа:

```java
int x, y;
x = 10;
y = 25;
System.out.println(x); 	// 10
System.out.println(y); 	// 25
```

их же можно сразу инициализировать:

```java
int x = 8, y = 15;
System.out.println(x); 	// 8
System.out.println(y); 	// 15
```

значение переменной в ходе программы меняется. новое присваивание затирает прежнее:

```java
int x = 10;
System.out.println(x); 	// 10
x = 25;
System.out.println(x); 	// 25
```

имя при этом остаётся тем же, меняется содержимое области памяти.

### ключевое слово var

начиная с java 10 (jep 286) переменную можно объявить словом **var**:

```java
var x = 10;
System.out.println(x); 	// 10
```

`var` стоит на месте типа. сам тип компилятор выводит из инициализатора, и вывод происходит во время компиляции. после компиляции у переменной обычный статический тип, как если бы он был написан явно. в примере инициализатор, целое `10`, задаёт переменной `x` тип `int`. тип фиксируется при компиляции, при следующем присваивании он сохраняется.

если переменная объявлена через `var`, инициализатор обязателен. без него компилятору не из чего вывести тип, и программа не компилируется:

```java
var x;		// ! Ошибка, переменная не инициализирована
x = 10;
```

`var` в этой роли относится к локальным переменным. тип поля класса таким способом не задают: у поля нет обязательного инициализатора в той же строке, а тип поля должен быть известен по одному объявлению.

### константы

помимо переменных, данные хранят в **константах**. константе значение присваивается один раз. объявление устроено так же, как у переменной, но впереди стоит служебное слово **final**:

```java
final int LIMIT = 5;
System.out.println(LIMIT); 	// 5
// LIMIT=57; // так мы уже не можем написать, так как LIMIT - константа
```

повторное присваивание имени с `final` компилятор отвергает. для локальной переменной это одна запись за всё время жизни. по соглашению имена констант пишут в верхнем регистре. язык требует только точного написания идентификатора: `LIMIT` и `limit` для компилятора разные имена.

константа фиксирует значение, которое программа менять не должна. если число `pi` хранится в переменной и по смыслу остаётся постоянным, её объявляют с `final`: присваивание другого значения станет ошибкой компиляции. при выполнении величина уже не меняется.
