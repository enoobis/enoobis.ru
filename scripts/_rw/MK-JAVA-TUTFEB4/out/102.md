класс `Exchanger` предназначен для обмена данными между двумя потоками. класс типизирован типом тех значений, которыми потоки должны обменяться. обмен производится единственным методом `exchange()`, и этот же вызов является рандеву: поток, пришедший первым, блокируется, пока второй поток не вызовет метод со своим значением. затем значения меняются местами, и оба вызова возвращают управление.

у метода две формы:

```java
V exchange(V x) throws InterruptedException
V exchange(V x, long timeout, TimeUnit unit) throws InterruptedException, TimeoutException
```

параметр `x` представляет буфер, значение, которое текущий поток отдаёт в обмен. вторая форма дополнительно задаёт `timeout`, время ожидания, и `unit`, тип временных единиц для этого времени, значения перечисления `TimeUnit`. если за указанный срок партнёр не пришёл, метод завершается `TimeoutException`, и обмен не выполняется. `InterruptedException` возникает, когда ожидающий поток прерывают.

применение класса короткое. два потока обмениваются строками:

```java
import java.util.concurrent.Exchanger;
 
public class Program {
 
    public static void main(String[] args) {
         
        Exchanger<String> ex = new Exchanger<String>();
        new Thread(new PutThread(ex)).start();
        new Thread(new GetThread(ex)).start();
    }
}
 
class PutThread implements Runnable{
     
    Exchanger<String> exchanger;
    String message;
 
    PutThread(Exchanger<String> ex){
         
        this.exchanger=ex;
        message = "Hello Java!";
    }
    public void run(){
         
        try{
            message=exchanger.exchange(message);
            System.out.println("PutThread has received: " + message);
        }
        catch(InterruptedException ex){
            System.out.println(ex.getMessage());
        }
    }
} 
class GetThread implements Runnable{
     
    Exchanger<String> exchanger;
    String message;
 
    GetThread(Exchanger<String> ex){
         
        this.exchanger=ex;
        message = "Hello World!";
    }
    public void run(){
         
        try{
            message=exchanger.exchange(message);
            System.out.println("GetThread has received: " + message);
        }
        catch(InterruptedException ex){
            System.out.println(ex.getMessage());
        }
    }
}
```

поток `PutThread` отправляет в буфер сообщение `Hello Java!`:

```java
message=exchanger.exchange(message);
```

в ответ `exchange` возвращает данные, которые отправил в буфер другой поток. происходит обмен. сохранять ответ необязательно, вызов можно сделать только ради отправки:

```java
exchanger.exchange(message);
```

даже при отброшенном результате вызов остаётся точкой рандеву и завершается лишь после того, как второй поток тоже войдёт в `exchange`. односторонней неблокирующей отправки у класса нет.

логика `GetThread` аналогична: отправляется сообщение `Hello World!`. после обмена каждый поток печатает то, что получил от партнёра. консоль выводит:

```consoletext
PutThread has received: Hello World!
GetThread has received: Hello Java!
```

`PutThread` получает строку второго потока, `GetThread` получает строку первого. какой из двух операторов печати выполнится раньше, зависит от планировщика. сам обмен к этому моменту уже закончен: оба значения переданы до возврата из `exchange`.
