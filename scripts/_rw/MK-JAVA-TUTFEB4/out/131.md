класс `LocalDate` из пакета `java.time` хранит дату без времени суток и без часового пояса. тип неизменяем: методы сдвига возвращают новый объект и не меняют исходный. календарная система следует iso-8601. некорректная дата отвергается исключением `DateTimeException` и молча не нормализуется. средствами класса дату создают и сдвигают на дни, недели, месяцы и годы.

основные методы `LocalDate`:

- `static LocalDate now()`: возвращает объект с текущей датой. дата берётся из системных часов в часовом поясе виртуальной машины по умолчанию

- `static LocalDate of(int year, int month, int day)`: возвращает дату с заданными годом, месяцем и днём. месяц нумеруется с 1

- `int getYear()`: возвращает год

- `int getMonthValue()`: возвращает номер месяца

- `int getDayOfMonth()`: возвращает день месяца, значение от 1 до 31

- `int getDayOfYear()`: возвращает номер дня в году, от 1 до 365, а в високосном году до 366

- `DayOfWeek getDayOfWeek()`: возвращает день недели как константу перечисления `DayOfWeek`. нумерация iso: понедельник равен 1, воскресенье равно 7

- `LocalDate plusDays(int n)`: прибавляет к дате n дней

- `LocalDate plusWeeks(int n)`: прибавляет n недель

- `LocalDate plusMonths(int n)`: прибавляет n месяцев. если дня с тем же числом в целевом месяце нет, берётся последний день этого месяца

- `LocalDate plusYears(int n)`: прибавляет n лет. 29 февраля в невисокосном целевом годе переносится на 28 февраля

- `LocalDate minusDays(int n)`: вычитает n дней

- `LocalDate minusMonths(int n)`: вычитает n месяцев

- `LocalDate minusWeeks(int n)`: вычитает n недель

- `LocalDate minusYears(int n)`: вычитает n лет

текущая дата читается так:
```java
import java.time.DayOfWeek;
import java.time.LocalDate;

public class Program {
  
    public static void main(String[] args) {
        
        LocalDate date = LocalDate.now(); // получаем текущую дату
        int year = date.getYear();
        int month = date.getMonthValue();
        int dayOfMonth = date.getDayOfMonth();
        DayOfWeek dayOfWeek = date.getDayOfWeek();
        System.out.println(date);
        System.out.println(dayOfWeek);
        System.out.printf("%d.%d.%d \n", dayOfMonth, month, year);
    }
}
```
консольный вывод зависит от дня запуска. `println` для `LocalDate` печатает дату в формате iso, `yyyy-mm-dd`. константа `DayOfWeek` печатается своим именем. формат `%d.%d.%d` выводит день, месяц и год без ведущих нулей. в образце лекции это:
```bash
2025-09-17
WEDNESDAY
17.9.2025
```
произвольная дата задаётся фабрикой `of`. несуществующий день, например 31 февраля, до дальнейших вызовов не доходит: `of` бросает `DateTimeException`.
```java
LocalDate date = LocalDate.of(1914, 12, 31);
System.out.println(date);
```
сдвиг даты складывается из прибавления и вычитания. каждый вызов возвращает новый `LocalDate`, поэтому результат снова записывается в переменную. без присваивания исходный объект остался бы прежним: методы не имеют побочного эффекта по состоянию даты.
```java
LocalDate date = LocalDate.of(1914, 7, 28);
        
date = date.plusYears(4);
date = date.plusMonths(3);
date = date.plusDays(14);
System.out.println(date);   // 1918-11-11
        
date = date.minusMonths(10);
date = date.minusDays(3);
System.out.println(date);   // 1918-01-08
```
