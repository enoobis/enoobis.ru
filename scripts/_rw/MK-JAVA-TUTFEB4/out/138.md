для исследования типов помимо класса `Class` язык java даёт классы пакета `java.lang.reflect`. основные из них:

- `Field`: описывает поле класса
- `Method`: описывает метод типа
- `Constructor`: описывает конструктор класса

эти объекты получают методами класса `Class`:

- `Field[] getFields() / getDeclaredFields()`: возвращает поля класса
- `Method[] getMethods() / getDeclaredMethods()`: возвращает методы класса
- `Constructor[] getConstructors() / getDeclaredConstructors()`: возвращает конструкторы класса

`getFields()`, `getMethods()` и `getConstructors()` возвращают массивы открытых полей, методов и конструкторов, то есть членов с модификатором `public`. в эти массивы входят и открытые поля, и открытые методы, унаследованные от суперклассов. `getDeclaredFields()`, `getDeclaredMethods()` и `getDeclaredConstructors()` возвращают массивы всех полей, методов и конструкторов, объявленных непосредственно в классе, включая закрытые. члены суперклассов в эти массивы не входят.

выбор метода определяют два признака. первый признак: нужны только открытые члены или все объявленные в классе, в том числе закрытые. второй признак: нужно включить открытых предков или ограничиться членами, объявленными в самом классе. конструкторы не наследуются, поэтому у пары методов для конструкторов второй признак пуст, и методы различаются уровнем доступа.

ниже объявлен класс `Person`:

```java




class Person {

     

    private String name;

    private int age;



    public String getName() {return name;}

    public int getAge() {return age;}



    public Person(){

        this.name = "Undefined";

        this.age = 18;

    }

    public Person(String name, int age){ 



        this.name = name;

        this.age = age;

    }

 

}
```

исследование типа `Person`:

```java


import java.lang.reflect.*;



public class Program{

      

    public static void main(String[] args) {

        

        // получаем класс для класса Person

        Class personClass = Person.class;



        Field[] fields = personClass.getFields();

        Method[] methods = personClass.getMethods();

        Constructor[] ctors = personClass.getConstructors();



        System.out.println("Public Fields");

        for(Field field : fields){

            System.out.println(field);

        }

        System.out.println("\nPublic Ctors");

        for(Constructor ctor : ctors){

            System.out.println(ctor);

        }



        System.out.println("\nPublic Methods");

        for(Method method : methods){

            System.out.println(method);

        }

    }

}
```

у классов `Field`, `Method` и `Constructor` строковое представление уже собрано в виде объявления: модификаторы, тип, объявляющий класс, имя и параметры. это представление печатают на консоль напрямую. в выводе открытых полей нет: `name` и `age` объявлены как `private`, а `getFields` закрытые поля не возвращает. оба конструктора открыты, поэтому присутствуют оба. среди методов есть `getName` и `getAge` класса `Person` и открытые методы, унаследованные от `Object`: `equals`, `toString`, `hashCode`, `getClass`, `notify`, `notifyAll` и три перегрузки `wait`.

второй набор методов читает члены, объявленные в самом классе: `getDeclaredFields()`, `getDeclaredMethods()`, `getDeclaredConstructors()`:

```java


import java.lang.reflect.*;



public class Program{

      

    public static void main(String[] args) {

        

        // получаем класс для класса Person

        Class personClass = Person.class;



        Field[] fields = personClass.getDeclaredFields();

        Method[] methods = personClass.getDeclaredMethods();

        Constructor[] ctors = personClass.getDeclaredConstructors();



        System.out.println("Fields");

        for(Field field : fields){

            System.out.println(field);

        }

        System.out.println("\nCtors");

        for(Constructor ctor : ctors){

            System.out.println(ctor);

        }



        System.out.println("\nMethods");

        for(Method method : methods){

            System.out.println(method);

        }

    }

}
```

консольный вывод:

```bash

private int Person.age



Ctors

public Person(java.lang.String,int)

public Person()

```

в этом выводе видны закрытые поля `name` и `age`, оба конструктора и только два метода, объявленные в `Person`. методы `Object` в список не попадают: `getDeclaredMethods` предков не обходит.

### проверка типа

ряд методов класса `Class` проверяет вид исследуемого типа:

- `boolean isAnonymousClass()`: возвращает `true`, если тип является анонимным классом
- `boolean isArray()`: возвращает `true`, если тип представляет массив
- `boolean isPrimitive()`: возвращает `true`, если тип является примитивным
- `boolean isInterface()`: возвращает `true`, если объект представляет интерфейс
- `boolean isEnum()`: возвращает `true`, если объект представляет перечисление
- `boolean isRecord()`: возвращает `true`, если объект представляет класс record
- `boolean isInstance(Object obj)`: возвращает `true`, если объект-параметр является экземпляром этого типа
- `boolean isSealed()`: возвращает `true`, если класс определён с модификатором `sealed`
- `Class getSuperclass()`: возвращает суперкласс текущего типа

применение части этих методов:

```java


import java.lang.reflect.*;



public class Program{

      

    public static void main(String[] args) {

        

        // получаем класс для типа Person

        Class cl = Person.class;





        // получаем имя класса

        System.out.println("Name: " + cl.getName());

        // получаем суперкласс

        System.out.println("superclass: " + cl.getSuperclass());

        // проверяем, является ли тип примитивным типом

        System.out.println("primitive: " + cl.isPrimitive());

        // проверяем, является ли тип массивом

        System.out.println("array: " + cl.isArray());

        // проверяем, является ли тип классом record

        System.out.println("record: " + cl.isRecord());

        // проверяем, является ли тип интерфейсом

        System.out.println("interface: " + cl.isInterface());



        // проверям, что tom - объект класса

        Person tom = new Person("Tom", 41);

        System.out.println("tom is a Person:: " + cl.isInstance(tom));



        // проверям, что message - объект класса

        String message = "hello";

        System.out.println("message is a Person:: " + cl.isInstance(message));

    }

}

record Person(String name, int age){}
```

консольный вывод программы:

```bash


Name: Person

superclass: class java.lang.Record

primitive: false

array: false

record: true

interface: false

tom is a Person:: true

message is a Person:: false
```

`getName` печатает бинарное имя `Person`. `getSuperclass` возвращает `java.lang.Record`: любой record является подклассом этого класса. `isPrimitive`, `isArray` и `isInterface` для такого типа дают `false`, `isRecord` даёт `true`. `isInstance` выполняет ту же проверку, что оператор `instanceof`: объект `tom` является экземпляром `Person`, объект `message` типа `String` экземпляром `Person` не является.
