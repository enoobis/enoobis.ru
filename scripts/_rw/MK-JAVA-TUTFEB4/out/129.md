для математических операций в пакете `java.lang` определён класс `Math`. экземпляры этого класса не создаются: конструктор закрыт, методы и константы статические. пакет `java.lang` импортируется неявно, поэтому явный `import java.lang.Math` в примерах на смысл программы не влияет. у ряда методов есть перегрузки для других примитивных типов. ниже разобраны формы из исходной лекции, в первую очередь с аргументом `double`. реализация `Math` может подставлять аппаратные инструкции. класс `StrictMath` фиксирует побитово воспроизводимые результаты по алгоритмам fdlibm. в обычных вычислениях используется `Math`.

- `abs(double value)`: возвращает абсолютное значение аргумента value. для отрицательного аргумента знак снимается, для неотрицательного значение сохраняется
```java

import java.lang.Math;

public class Program{
     
	public static void main(String[] args) {
        double result = Math.abs(-13.5); // 13.5
        System.out.println(result); // 13.5
    }
}
```
- `acos(double value)`: возвращает арккосинус value в радианах. value обязан лежать в отрезке от -1 до 1. вне отрезка результат равен `NaN`
```java

double result = Math.acos(1); // 0.0
```
- `asin(double value)`: возвращает арксинус value в радианах. value обязан лежать в отрезке от -1 до 1

- `atan(double value)`: возвращает арктангенс value в радианах. область определения шире, чем у `asin` и `acos`: аргумент может быть любым конечным `double`

- `cbrt(double value)`: возвращает кубический корень value. в отличие от квадратного корня, корень нечётной степени определён и для отрицательного аргумента
```java

double result = Math.cbrt(27); // 3
```
- `ceil(double value)`: возвращает наименьшее целое число с плавающей точкой, которое не меньше value. округление идёт к плюс бесконечности
```java

double result = Math.ceil(2.34); // 3
```
- `clamp(double num, double a, double b)`: удерживает число num внутри границ от a до b. если num меньше a, возвращается a. если num больше b, возвращается b. иначе возвращается num. перегрузка для `double` есть в `Math` с java 21
```java

import java.lang.Math;

public class Program{
     
	public static void main(String[] args) {
        
        System.out.println(Math.clamp(-1, 0, 5)); // -1 не входит в границы дипазаона [0, 5], поэтому возвращается 0
        System.out.println(Math.clamp(6, 0, 5)); // 6 не входит в границы дипазаона [0, 5], поэтому возвращается 5
        System.out.println(Math.clamp(4, 0, 5)); // 4 входит в границы дипазаона [0, 5], поэтому возвращается 4
    }
}
```
- `cos(double d)`: возвращает косинус угла d. угол задаётся в радианах

- `cosh(double d)`: возвращает гиперболический косинус угла d

- `exp(double d)`: возвращает основание натурального логарифма, число `e`, возведённое в степень d

- `floor(double d)`: возвращает наибольшее целое число, которое не больше d. округление идёт к минус бесконечности
```java

double result = Math.floor(2.56); // 2
```
- `floorDiv(int a, int b)`: возвращает целочисленное частное a и b с округлением к минус бесконечности. оператор `/` для целых отсекает дробную часть к нулю. на положительных аргументах из примера оба варианта совпадают. на отрицательных они расходятся: `-5 / 2` равно `-2`, а `floorDiv(-5, 2)` равно `-3`
```java

System.out.println(Math.floorDiv(1, 2)); // 0
System.out.println(Math.floorDiv(7, 2)); // 3
System.out.println(Math.floorDiv(9, 2)); // 4
```
- `log(double a)`: возвращает натуральный логарифм числа a

- `log1p(double d)`: возвращает натуральный логарифм числа `(d + 1)`. для малого d отдельная функция точнее, чем `log(1 + d)`, потому что не теряет значимые разряды суммы

- `log10(double d)`: возвращает десятичный логарифм числа d

- `max(double a, double b)`: возвращает большее из двух чисел a и b

- `min(double a, double b)`: возвращает меньшее из двух чисел a и b

- `pow(double a, double b)`: возвращает a в степени b

- `random()`: возвращает псевдослучайное число от 0.0 до 1.0. по спецификации это полуинтервал: 0.0 входит, 1.0 не входит. метод делит один синхронизированный экземпляр `java.util.Random` на всю виртуальную машину. если нужно своё зерно или независимые потоки, состояние задают явно через `java.util.Random` или `ThreadLocalRandom`

- `rint(double value)`: возвращает `double`, ближайший к value целый. при равенстве расстояний выбирается чётное целое, поэтому `2.5` переходит в `2.0`, а `3.5` перешло бы в `4.0`. результат остаётся вещественным
```java

System.out.println(Math.rint(2)); // 2.0
System.out.println(Math.rint(2.3)); // 2.0
System.out.println(Math.rint(2.5)); // 2.0
System.out.println(Math.rint(2.5001)); // 3.0
System.out.println(Math.rint(2.8)); // 3.0
```
- `round(double d)`: возвращает d, округлённое до ближайшего целого, уже как целое значение. для `double` метод возвращает `long` и считается как `floor(d + 0.5)`. на границе `.5` округление уходит от нуля в положительную сторону, поэтому `2.5` становится `3`, тогда как `rint` на том же входе даёт `2.0`
```java

System.out.println(Math.round(2.3)); // 2
System.out.println(Math.round(2.5)); // 3
System.out.println(Math.round(2.5001)); // 3
System.out.println(Math.round(2.8)); // 3
```
- `scalb(double value, int factor)`: возвращает произведение value на 2 в степени factor. степень двойки вносится в порядок числа. так операция обрабатывает переполнение и потерю значимости в рамках `double` точнее, чем отдельное умножение на степень двойки
```java

System.out.println(Math.scalb(5, 3)); // 5*2*2*2 = 40
System.out.println(Math.scalb(3, 4)); // 3*2*2*2*2 = 48
```
- `signum(double value)`: возвращает `1.0`, если value положительно, и `-1.0`, если value отрицательно. если value равно 0, возвращает `0.0`, сохраняя знак нуля. для `NaN` результат тоже `NaN`
```java

System.out.println(Math.signum(2.3)); // 1
System.out.println(Math.signum(-2.3)); // -1
```
- `sin(double value)`: возвращает синус угла value. угол задаётся в радианах

- `sinh(double value)`: возвращает гиперболический синус угла value

- `sqrt(double value)`: возвращает квадратный корень value. для отрицательного аргумента результат равен `NaN`, исключения метод не бросает
```java

double result1 = Math.sqrt(16); // 4
```
- `tan(double value)`: возвращает тангенс угла value

- `tanh(double value)`: возвращает гиперболический тангенс угла value

- `toDegrees(double value)` переводит радианы в градусы, `toRadians(double value)` переводит градусы в радианы. аргумент `3.14159` лишь приближает `Math.PI`, поэтому перевод в градусы в комментарии примера записан как 180, а `toRadians(90)` даёт приближение к `pi/2`
```java

System.out.println(Math.toDegrees(3.14159)); // 180
System.out.println(Math.toRadians(90)); // 1,57079....
```
класс `Math` определяет три константы: `Math.E`, `Math.TAU` и `Math.PI`. `Math.E` есть основание натурального логарифма, `Math.PI` есть отношение длины окружности к диаметру, `Math.TAU` равно `2 * Math.PI` и присутствует в классе с java 19. площадь круга считается через `Math.PI`. усечённое десятичное приближение вроде `3.14159` в этой формуле не используется:
```java

import java.lang.Math;
import java.util.Scanner;

public class Program {
  
    public static void main(String[] args) {
          
        Scanner in = new Scanner(System.in);
        
        System.out.print("Введите радиус круга: ");
        int radius = in.nextInt();
        long area = Math.round(Math.PI * Math.pow(radius, 2));
        System.out.printf("Площадь круга с радиусом %d равна %d \n", radius, area);
    }
}
```
консольный вывод:
```bash

Введите радиус круга: 10
Площадь круга с радиусом 10 равна 314
```
