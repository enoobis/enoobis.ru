ещё одна распространённая среда для java называется netbeans. проект netbeans в значительной мере поддерживает и финансирует oracle, а разработку ведёт независимое сообщество (apache netbeans community). среда кроссплатформенная: существуют сборки под разные ос. подробности опубликованы на сайте проекта [https://netbeans.apache.org/](https://netbeans.apache.org/).

в этом материале последней считается 12-я версия. она загружается со страницы [https://netbeans.apache.org/download/nb121/nb121.html](https://netbeans.apache.org/download/nb121/nb121.html).

![загрузка apache netbeans](/uploads/course-lectures/03dfc1f06dc3736c64fc0aabd996f2d8ce992563.png)

на странице два варианта поставки: уже собранные бинарные файлы архивом (пункт `Binaries`) и установщики под конкретные операционные системы (пункт `Installers`). далее выбирается готовая сборка, пункт **binaries**.

после выбора открывается страница со ссылкой на зеркало загрузки:

![загрузка apache netbeans](/uploads/course-lectures/363cc3cb1519d1cd2cb066376d811421542b8b5d.png)

архив распаковывается в каталог, где должна лежать среда. отдельная установка не требуется: в архиве уже лежат готовые к запуску файлы. исполняемые файлы находятся в подкаталоге **bin**. на windows это `netbeans.exe` и `netbeans64.exe`.

![запуск netbeans](/uploads/course-lectures/5333fb698e64c9c09705cc03070876d1fd99f809.png)

запускается `netbeans.exe` или `netbeans64.exe`:

![netbeans](/uploads/course-lectures/d4e5658c240ae4c4398ab1e5203829efa6f70228.png)

новый проект создаётся пунктом меню **file->new project...**. открывается окно создания проекта:

![создание нового проекта в netbeans](/uploads/course-lectures/fceee7e5ecf2e2fbf9360f20fb357751a682e563.png)

в левой колонке выбирается первый пункт, **java with ant**, в правой в качестве типа проекта выбирается **java application**. затем нажимается **next >**.

ant в этом шаблоне служит сценарием сборки: среда генерирует файл сборки и вызывает его при компиляции. тип java application задаёт обычное приложение с точкой входа `main`. библиотека и веб-модуль выбираются другими пунктами того же окна.

при первом создании проекта java среда предлагает включить соответствующую поддержку:

![создание нового проекта в netbeans](/uploads/course-lectures/75256d114c11836869faded0def74c5d74e58b6d.png)

на этом шаге нажимается **activate**.

затем открывается окно параметров проекта:

![настройка проекта в netbeans](/uploads/course-lectures/dfdefcdb84c8a7a1561c1241f0ee835d02d830ae.png)

в поле **project name** задаётся имя проекта. в этом курсе проекту даётся имя `HelloApp`. остальные поля оставляют со значениями по умолчанию. последнее поле `Create Main Class` означает, что среда сама создаст класс `HelloApp` в одноимённом пакете `helloapp`. создание завершается кнопкой `Finish`. открывается новый проект:

![новый проект в netbeans](/uploads/course-lectures/7ab5e30cf623c3f787461c6a095ff34aa2cd9acf.png)

узкая панель слева показывает открытые проекты и их структуру. на этом шаге открыт один проект. широкую область справа занимает редактор: подсветка синтаксиса, дополнение кода и текст файла. редактор уже содержит заготовку:

```java
/*
 * To change this license header, choose License Headers in Project Properties.
 * To change this template file, choose Tools | Templates
 * and open the template in the editor.
 */
package helloapp;

/**
 *
 * @author Eugene
 */
public class HelloApp {

    /**
     * @param args the command line arguments
     */
    public static void main(String[] args) {
        // TODO code application logic here
    }
    
}
```

в заготовке две части, которые для первой программы не нужны, и одна, которая нужна. комментарии (блоки `/* */` и документационные `/** */`) на смысл программы не влияют, их удаляют. в начале файла директива `package helloapp;` помещает класс в пакет `helloapp`. имя пакета обязано совпадать с каталогом относительно корня исходников, поэтому файл оказывается в каталоге `helloapp`. дальше, как и в прошлой лекции, идёт класс программы `HelloApp` с методом `main`. комментарий `@author Eugene` остаётся меткой шаблона и к семантике класса отношения не имеет.

заготовка заменяется текстом, который печатает одну строку на консоль:

```java
package helloapp;

public class HelloApp {

    public static void main(String[] args) {
        
        System.out.println("Hello Java 15 from Netbeans!");
    }
    
}
```

строка `Hello Java 15 from Netbeans!` фиксирует в выводе и среду, и тот выпуск языка, на который ориентирован пример.

проект запускается зелёной стрелкой на панели netbeans, клавишей `F6` или пунктом меню `Run -> Run Project`. внизу открывается окно вывода с результатом программы:

![java в netbeans 12](/uploads/course-lectures/51f5a84418ea0b763a5792c4f931eb25706ed223.png)

это окно по роли совпадает с консолью: в него попадает стандартный поток вывода. отличия касаются оформления и того, что среда добавляет к выводу программы собственные служебные строки.
