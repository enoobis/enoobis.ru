метод может возвращать значение. в предыдущих примерах применялись методы типа `void`. метод с таким типом не возвращает значения и только выполняет действия. результат передаётся из метода оператором **return**:

```java
return возвращаемое_значение;
```

после оператора `return` указывается возвращаемое значение, результат метода. это может быть литерал, значение переменной или составное выражение. выполнение `return` сразу завершает метод, и управление возвращается в точку вызова вместе с вычисленным значением.

пример метода, который возвращает значение типа `String`:

```java


class Person{ 



    String sayHello(){

        return "Hello";

    }

}
```

метод `sayHello` имеет тип `String`, следовательно, он должен вернуть строку. в теле используется оператор **return**, после которого указана возвращаемая строка.

метод, у которого возвращаемый тип отличается от **void**, обязан на каждом пути выполнения дойти до `return` и вернуть значение. следующее определение некорректно: метод печатает текст и не возвращает строку, хотя заголовок обещает `String`:

```java


String sayHello(){



	System.out.println("Hello");

}
```

между возвращаемым типом и выражением после `return` должно быть соответствие по типам. в следующем случае возвращаемый тип равен `String`, а метод возвращает число типа `int`, поэтому определение некорректно:

```java


String sayHello(){



	return 3;	// Ошибка! Метод должен возвращать строку, а не число

}
```

компилятор проверяет, что тип выражения присваивается возвращаемому типу. число типа `int` строкой не является, и такой `return` отвергается.

результат метода, который возвращает значение, присваивают переменной или используют в другом месте программы:

```java


class Program{



    public static void main(String[] args) {  



        Person tom = new Person();

        // в метод System.out.println в качестве параметра передается результат метода tom.sayHello()

        System.out.println(tom.sayHello());  // Hello



        // присваиваем результат метода tom.sayHello() переменной

        String message = tom.sayHello();

        System.out.println(message);  // Hello

    }

}

class Person{ 



    String sayHello(){

        return "Hello";

    }

}
```

метод `sayHello()` возвращает значение типа `String`. это значение присваивается переменной типа `String`:

```java
String message = sayHello();
```

то же возвращаемое значение передаётся как аргумент другого метода:

```java


System.out.println(tom.sayHello());
```

в обоих местах вызов `tom.sayHello()` стоит там, где по контексту ожидается `String`: аргумент `println` и инициализатор переменной `message`. сам вызов вычисляется раньше, чем внешний метод получает аргумент.

после `return` записывают и составное выражение, и вызов другого метода, который возвращает свой результат. метод суммы двух чисел:

```java


class Program{



    public static void main(String[] args) {  



        Calcualtor calc = new Calcualtor();

        int result = calc.sum(10, 12);  // 22

        System.out.println(result);  // 22



        System.out.println(calc.sum(10, 15));  // 25

    }

}

class Calcualtor{



    int sum(int a, int b){

		

        return a + b;

	}

}
```

здесь выражение `a + b` вычисляется, и его результат типа `int` становится результатом `sum`. в `main` этот результат один раз сохраняется в `result`, другой раз сразу передаётся в `println`. отдельной переменной для второго вызова нет, но значение всё равно вычисляется и печатается.

в одном методе допустимо несколько операторов `return`. они возвращают разные значения в зависимости от условия, и при одном вызове выполняется только та ветка, чьё условие истинно:

```java


class Program{



    public static void main(String[] args) {  



        Time time = new Time();

        System.out.println(time.asString(7));     // Good morning

        System.out.println(time.asString(13));    // Good after noon

        System.out.println(time.asString(18));    // Good evening

        System.out.println(time.asString(2));     // Good night

    }

}

class Time{

    // метод получает текущий час

    String asString(int hour){

         

        // если значение некорретное

        if (hour >24 || hour < 0)

            return "Invalid data";

        // если от 21 часов вечера до 6 часов утра

        else if(hour > 21 || hour < 6)

            return "Good night";

        // если от 15 часов дня

        else if(hour >= 15)

            return "Good evening";

        // если от 11 часов дня

        else if(hour >= 11)

            return "Good after noon";

        // остальные случае - меньше 11часов дня

        else

            return "Good morning";

    }

}
```

метод `asString` класса `Time` принимает текущий час через параметр `hour` и возвращает значение типа `String`, то есть строку. фактически час преобразуется в строку. от значения `hour` зависит, какая ветка выполнится и какая строка вернётся. условия идут сверху вниз: срабатывает первое истинное, и соответствующий `return` завершает метод. нижние ветки при этом не выполняются.

### выход из метода

оператор `return` и возвращает значение, и завершает метод. во втором качестве он применяется в методах, которые ничего не возвращают, то есть имеют тип `void`:

```java


class Program{



    public static void main(String[] args) {  



        Time time = new Time();

        time.print(7);     // Good morning

        time.print(13);    // Good after noon

        time.print(32);    // 

        time.print(56);    // 

        time.print(2);     // Good night

    }

}

class Time{

    // метод получает текущий час

    void print(int hour){

         

        // если значение некорретное

        if (hour >24 || hour < 0)

            return;

        // если от 21 часов вечера до 6 часов утра

        else if(hour > 21 || hour < 6)

            System.out.println("Good night");

        // если от 15 часов дня

        else if(hour >= 15)

            System.out.println("Good evening");

        // если от 11 часов дня

        else if(hour >= 11)

            System.out.println("Good after noon");

        // остальные случае - меньше 11часов дня

        else

            System.out.println("Good morning");

    }

}
```

если переданное в метод `print` значение больше 24 или меньше 0, происходит выход из метода. выражение после `return` в этом случае не пишется: у `void` нет возвращаемого значения, форма оператора пустая. операторы, которые печатают приветствие, при таком входе не достигаются, поэтому для часов 32 и 56 консоль остаётся пустой. для допустимых часов печатается одна из строк, как в методе `asString`, только результат уходит на консоль, а не в возвращаемое значение.
