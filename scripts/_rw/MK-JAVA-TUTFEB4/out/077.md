работа с файлами и потоками есть в большинстве языков. в java базовые классы этой работы лежат в пакете `java.io`.

слово «поток» в программировании перегружено. им называют и поток исполнения (`Thread`), и конвейер `java.util.stream`, и канал ввода-вывода. в этой лекции поток (stream) есть абстракция чтения или записи: файла, сокета, текста консоли и других источников.

поток связывается с физическим устройством через подсистему ввода-вывода java. поток, связанный с файлом, читает этот файл или пишет в него. поток, связанный с сетевым сокетом, принимает и отправляет байты по сети. чтение и запись файлов, обмен по сети и ввод-вывод на консоли в java решаются через такие потоки.

объект, из которого данные читают, называется потоком ввода. объект, в который данные пишут, называется потоком вывода. содержимое файла читают потоком ввода, запись в файл делают потоком вывода.

все классы байтовых потоков восходят к двум абстрактным классам: `InputStream` (потоки ввода) и `OutputStream` (потоки вывода).

байтовый поток не знает о кодировке символов. для текста поверх байтов добавлены абстрактные классы `Reader` (чтение символов) и `Writer` (запись символов). они переводят между байтами источника и символами utf-16, которыми java представляет `char`, по правилам выбранной кодировки.

остальные классы потоков наследуют эти четыре абстрактных класса. часто конкретный поток оборачивает другой: буферизация, разбор примитивов и сериализация объектов устроены как надстройки над базовым потоком, а не как отдельные устройства. основные классы иерархии:

### потоки байтов

#### класс `InputStream`

`InputStream` есть база всех классов, которые читают байтовый поток. его основные методы:

- `int available()`: возвращает оценку числа байтов, которые можно прочитать без блокировки. это оценка, а не точный размер остатка: у сокета и у части файловых реализаций метод вправе вернуть 0, даже если данные еще придут

- `void close()`: закрывает поток и освобождает системный дескриптор

- `int read()`: возвращает следующий байт как целое от 0 до 255. когда байтов больше нет, возвращает -1. тип результата `int`, а не `byte`: значение 255 (все биты байта установлены) должно отличаться от признака конца потока

- `int read(byte[] buffer)`: читает байты в массив buffer, не больше его длины. возвращает число прочитанных байтов. если не прочитан ни один байт и поток исчерпан, возвращает -1

- `int read(byte[] buffer, int offset, int length)`: читает до length байтов и кладет их в buffer, начиная со смещения offset, то есть с элемента `buffer[offset]`. возвращает число успешно прочитанных байтов

- `long skip(long number)`: пропускает при чтении до number байтов и возвращает, сколько байтов удалось пропустить. фактическое число может быть меньше запрошенного

#### класс `OutputStream`

`OutputStream` есть база классов, которые пишут бинарный поток. функциональность собрана в таких методах:

- `void close()`: закрывает поток

- `void flush()`: сбрасывает буфер вывода и записывает накопленное в нижележащий приемник. у небуферизованного потока метод ничего не копит. буфер появляется у надстроек вроде `BufferedOutputStream`, и для них `flush` как раз выталкивает незаписанный хвост

- `void write(int b)`: записывает в выходной поток один байт. в поток уходят младшие 8 бит целочисленного параметра b

- `void write(byte[] buffer)`: записывает в выходной поток массив байтов buffer

- `void write(byte[] buffer, int offset, int length)`: записывает в выходной поток length байтов из массива `buffer`, начиная со смещения `offset`, то есть с элемента `buffer[offset]`

### абстрактные классы `Reader` и `Writer`

абстрактный класс `Reader` читает текст. `Reader` реализует `Readable`, поэтому среди операций есть чтение прямо в `CharBuffer`. основные методы:

- `abstract void close()`: закрывает поток ввода

- `int read()`: возвращает следующий символ как целое от 0 до 65535. если символов нет и достигнут конец потока, возвращает -1

- `int read(char[] buffer)`: читает в массив buffer символы, не больше длины массива. возвращает число успешно прочитанных символов. в конце потока возвращает -1

- `int read(CharBuffer buffer)`: читает символы в объект `CharBuffer`. возвращает число успешно прочитанных символов. в конце потока возвращает -1

- `abstract int read(char[] buffer, int offset, int count)`: читает в массив buffer, начиная со смещения offset, до count символов

- `long skip(long count)`: пропускает до count символов и возвращает число успешно пропущенных

класс `Writer` задает символьные потоки вывода. его основные методы:

- `Writer append(char c)`: добавляет в конец выходного потока символ c. возвращает сам объект `Writer`, поэтому вызовы можно соединять цепочкой

- `Writer append(CharSequence chars)`: добавляет в конец выходного потока последовательность символов chars. возвращает объект `Writer`

- `abstract void close()`: закрывает поток

- `abstract void flush()`: сбрасывает буферы потока

- `void write(int c)`: записывает в поток один символ, переданный его целочисленным кодом. в поток уходят младшие 16 бит

- `void write(char[] buffer)`: записывает в поток массив символов

- `abstract void write(char[] buffer, int off, int len)`: записывает в поток len символов из массива buffer. отбор из массива начинается с индекса off

- `void write(String str)`: записывает в поток строку

- `void write(String str, int off, int len)`: записывает в поток len символов строки. отбор начинается с индекса off

методы `Reader` и `Writer` наследуют конкретные символьные потоки. для текстовых файлов это `FileReader` и `FileWriter`: они открывают файл и кодируют символы в байты (и обратно) кодировкой по умолчанию, если конструктору не передана другая. байтовые `InputStream` и `OutputStream` той же кодировки не делают.
