метод `skip(long n)` используется для пропуска `n` элементов. этот метод возвращает новый поток, в котором пропущены первые `n` элементов в порядке встречи.

метод `limit(long n)` применяется для выборки первых `n` элементов потока. этот метод также возвращает модифицированный поток, в котором не более `n` элементов.

зачастую эта пара методов используется вместе для создания эффекта постраничной навигации. окно страницы задаётся так:

```java
Stream<String> phoneStream = Stream.of("iPhone 6 S", "Lumia 950", "Samsung Galaxy S 6", "LG G 4", "Nexus 7");
        
phoneStream.skip(1)
    .limit(2)
    .forEach(s->System.out.println(s));
```

метод `skip` пропускает один первый элемент, `iPhone 6 S`. метод `limit` выбирает два следующих элемента, `Lumia 950` и `Samsung Galaxy S 6`. консольный вывод:

```consoletext
Lumia 950
Samsung Galaxy S 6
```

метод `skip` может принять число большее, чем количество элементов в потоке, или равное ему. в этом случае будут пропущены все элементы, а в результирующем потоке будет 0 элементов.

если в метод `limit` передаётся число, большее, чем количество оставшихся элементов, выбираются все эти элементы.

постраничная навигация собирается из той же пары. номер страницы `page` при размере страницы `pageSize` означает пропуск `(page - 1) * pageSize` элементов и выбор следующих `pageSize`:

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.stream.*;
import java.util.Scanner;

public class Program {

    public static void main(String[] args) {
        
        List<String> phones = new ArrayList<String>();
        phones.addAll(Arrays.asList(new String[]
                {"iPhone 6 S", "Lumia 950", "Huawei Nexus 6P",
                "Samsung Galaxy S 6", "LG G 4", "Xiaomi MI 5",
                "ASUS Zenfone 2", "Sony Xperia Z5", "Meizu Pro 5",
                "Lenovo S 850"}));
        
        int pageSize = 3; // количество элементов на страницу
        Scanner scanner = new Scanner(System.in);
        while(true){
           
            System.out.println("Введите номер страницы: ");
            int page = scanner.nextInt();
           
            if(page<1) break; // если число меньше 1, выходим из цикла
            
            phones.stream().skip((page-1) * pageSize)
                .limit(pageSize)
                .forEach(s->System.out.println(s));
       }
    }
}
```

в наборе 10 элементов. переменная `pageSize` определяет количество элементов на странице, здесь 3. страниц получается 4: три полные и последняя, на которой только один элемент, `Lenovo S 850`.

в бесконечном цикле программа получает номер страницы из `Scanner` и выбирает только те элементы, которые находятся на указанной странице. ввод меньше 1 прерывает цикл. на каждой итерации вызывается `phones.stream()` заново: предыдущий поток после `forEach` уже употреблён, и продолжать его нельзя. `skip` сдвигает окно, `limit` обрезает его размером страницы, `forEach` печатает элементы.

номера страниц 4 и 2 дают такой вывод:

```consoletext
Введите номер страницы: 
4
Lenovo S 850
Введите номер страницы: 
2
Samsung Galaxy S 6
LG G 4
Xiaomi MI 5
```

страница 4 начинается с индекса `(4 - 1) * 3`, то есть с десятого элемента, и содержит один телефон. страница 2 начинается с индекса 3: `Samsung Galaxy S 6`, `LG G 4`, `Xiaomi MI 5`.
