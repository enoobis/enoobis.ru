литералом называется запись неизменяемого значения прямо в тексте программы. литерал передают переменной как значение, им же пользуются в выражении без предварительного объявления. по виду литералы делятся на логические, целочисленные, вещественные, символьные и строковые. отдельный литерал задаётся служебным написанием `null`.

### логические литералы

логических литералов два: **true** (истина) и **false** (ложь). оба литерала имеют тип `boolean`, самостоятельный тип с двумя значениями. программа, которая печатает оба литерала:

```java


class Program{

    public static void main(String[] args) {  



        System.out.println(true);     // true

        System.out.println(false);    // false

    }

}
```

два вызова `System.out.println()` по очереди выводят `true` и `false`. консольный вывод:

```bash


true

false
```

### целочисленные литералы

целочисленный литерал обозначает целое значение, положительное или отрицательное, например 1, 2, 3, 4, -7, -109. записывают его в десятичной, шестнадцатеричной и двоичной системах. ниже отдельно разобрана и восьмеричная запись.

десятичная запись совпадает с обычной позиционной записью числа:

```java


class Program{

    public static void main(String[] args) {  



        System.out.println(-11);

        System.out.println(5);

        System.out.println(505);

    }

}
```

двоичная запись начинается с префикса `0b`, дальше идут только цифры 0 и 1:

```java


System.out.println(0b11);        // 3

System.out.println(0b1011);      // 11

System.out.println(0b100001);    // 33
```

компилятор переводит такую запись в то же целое значение, что и десятичную с тем же числом. `0b11` равно 3, `0b1011` равно 11, `0b100001` равно 33.

шестнадцатеричная запись начинается с префикса `0x`. дальше идут цифры от 0 до 9 и буквы от `A` до `F`:

```java


System.out.println(0x0A);    // 10

System.out.println(0xFF);    // 255

System.out.println(0xA1);    // 161
```

буква `x` в префиксе и шестнадцатеричные цифры допустимы в обоих регистрах. четыре строки ниже обозначают одно и то же значение 255:

```java


System.out.println(0XFF);    // 255

System.out.println(0Xff);    // 255

System.out.println(0xFF);    // 255

System.out.println(0xff);    // 255
```

помимо десятичной, двоичной и шестнадцатеричной форм есть **восьмеричная система**. такой литерал начинается с цифры 0:

```java


class Program{

    public static void main(String[] args) {  



        System.out.println(03);        // 3

        System.out.println(013);      // 11

        System.out.println(041);    // 33

    }

}
```

ведущий нуль меняет основание системы. `03` равно 3, `013` равно 11, `041` равно 33. тот же ведущий нуль легко прочитать как десятичное оформление, поэтому восьмеричную запись применяют только там, где основание действительно нужно.

в любой из этих форм разряды можно разделять подчёркиванием. знак не входит в значение и нужен только читателю:

```java


System.out.println(123_456); 	// 123456

System.out.println(234_567__789); 	// 234567789
```

несколько подчёркиваний подряд допустимы, как во втором литерале. подчёркивание стоит между цифрами. значение `123_456` совпадает с `123456`, значение `234_567__789` совпадает с `234567789`.

десятичный литерал без суффикса `L` имеет тип `int` и обязан укладываться в диапазон `int`.

### вещественные литералы

вещественный литерал обозначает дробное число. форм две. первая форма записывает число с фиксированной запятой: дробная часть отделяется от целой знаком точки. в тексте программы стоит точка, хотя в русской терминологии говорят о запятой:

```java


3.14

100.001

-0.38
```

тот же набор значений в программе:

```java


class Program{

    public static void main(String[] args) {  



        System.out.println(3.14); 

        System.out.println(100.001); 

        System.out.println(-0.38); 

    }

}
```

литерал без суффикса имеет тип `double`, 64-битное двоичное число с плавающей запятой. суффикс `f` или `F` даёт 32-битный тип `float`.

вторая форма экспоненциальная, `MEp`. `M` обозначает мантиссу, `E` обозначает маркер порядка, `p` обозначает сам порядок. маркер означает умножение на десять в степени порядка. буквы `e` и `E` в этой роли равнозначны:

```java


System.out.println(3.2e3);	// по сути равно 3.2 * 10<sup>3</sup> = 3200

System.out.println(1.2E-1);	// равно 1.2 * 10<sup>-1</sup> = 0.12
```

`3.2e3` совпадает с 3.2, умноженным на 10 в степени 3, то есть с 3200. `1.2E-1` совпадает с 1.2, умноженным на 10 в степени -1, то есть с 0.12.

### символьные литералы

символьный литерал обозначает один символ и заключается в одинарные кавычки. такой литерал имеет тип `char`, 16-битовую единицу utf-16. первая разновидность записывает обычный символ:

```java


'2'

'A'

'T'
```

те же литералы передаются в `System.out.println`:

```java


System.out.println('2');

System.out.println('A');

System.out.println('T');
```

отдельную группу составляют **управляющие последовательности**. перед символом ставится обратная косая черта (слеш), и пара читается как один специальный символ. чаще всего используют:

- `'\n'` - перевод строки

- `'\t'` - табуляция

- `'\\'` - сам знак обратной косой черты

если в тексте встречается последовательность `\t`, компилятор читает её как один символ табуляции, длинный отступ. слеш и буква `t` по отдельности в значении не сохраняются.

символ можно записать и шестнадцатеричным кодом внутри тех же одинарных кавычек.

другая форма берёт код из таблицы [unicode](https://unicode-table.com/ru/). в одинарных кавычках пишут `\u` и следом четыре шестнадцатеричные цифры. код `\u0411` обозначает кириллическую букву `Б`, код `\u0066` обозначает букву `f`. подстановка `\u` выполняется до лексического разбора, поэтому такую запись принимают и вне кавычек, а в литерале она просто задаёт символ:

```java


System.out.println('\u0420');    // Р

System.out.println('\u0421');    // С
```

`\u0420` печатается как `Р`, `\u0421` печатается как `С`.

### строковые литералы

строковый литерал обозначает строку и заключается в двойные кавычки. значение имеет тип `String`.

```java


class Program{

    public static void main(String[] args) {  



        System.out.println("hello enoobis.ru");

        System.out.println("hello word");

        System.out.println("test");

    }

}
```

кавычка внутри строки записывается с обратной косой чертой перед ней. иначе кавычка закрыла бы литерал:

```java


System.out.println("Hello \"enoobis.ru\"");
```

в строке работают те же управляющие последовательности, что и в символьном литерале, включая `\n` и `\t`. последовательность `\n` переводит вывод на следующую строку:

```java


System.out.println("Hello\nenoobis.ru");
```

здесь `\n` служит сигналом перевода строки. при печати фрагмент `enoobis.ru` оказывается на новой строке:

```bash


Hello

enoobis.ru
```

java также поддерживает **текстовые блоки** (text blocks), многострочный текст в тройных кавычках. обычная конкатенация длинного текста выглядит так. операция `+` присоединяет к одной строке другую, и продолжение может стоять на следующей строке исходного файла. перевод строки в результате даёт последовательность `\n`. перенос строки в исходном файле сам по себе в значение строки не входит:

```java


class Program{

    public static void main(String[] args) {  



        System.out.println("Вот мысль, которой весь я предан,\n"+

                "Итог всего, что ум скопил.\n"+

                "Лишь тот, кем бой за жизнь изведан,\n"+

                "Жизнь и свободу заслужил.");

    }

}
```

результат этого кода:

```bash


Вот мысль, которой весь я предан,

Итог всего, что ум скопил.

Лишь тот, кем бой за жизнь изведан,

Жизнь и свободу заслужил.
```

**текстовые блоки** записывают тот же многострочный текст без конкатенации и без явных `\n`. средство вошло в язык как стандартное в java 15:

```java


class Program{

    public static void main(String[] args) {  



        System.out.println("""

                Вот мысль, которой весь я предан,

                Итог всего, что ум скопил.

                Лишь тот, кем бой за жизнь изведан,

                Жизнь и свободу заслужил.""");

    }

}
```

весь блок обёрнут в тройные кавычки. открывающие `"""` заканчивают строку, текст занимает следующие строки, закрывающие `"""` стоят после него. компилятор снимает случайный отступ: общий пробельный префикс, который задаётся положением закрывающего ограничителя, в значение строки не входит. поэтому строки стихотворения в исходном тексте сдвинуты вместе с кодом метода, а в выводе прижаты к левому краю. результат совпадает с программой, где строки соединялись через `+` и `\n`.

### null

**null** обозначает ссылку, которая не указывает ни на какой объект, то есть отсутствие значения. литерал имеет специальный пустой тип и присваивается любому ссылочному типу. присваивание `null` числовому или другому примитивному типу недопустимо. вызов метода или чтение поля через такую ссылку во время выполнения завершается исключением `NullPointerException`.
