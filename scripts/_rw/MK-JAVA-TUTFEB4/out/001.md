для разработки программ на java требуется комплект jdk (java development kit). в него входят компилятор, средство запуска, стандартная библиотека и утилиты, которыми программу компилируют, запускают и сопровождают.

сборки oracle jdk для windows (x64), linux (x64, arm64) и macos (x64, arm64) опубликованы по адресу [https://www.oracle.com/java/technologies/downloads/](https://www.oracle.com/java/technologies/downloads/)

сборки openjdk для windows (x64), linux (x64, arm64) и macos (x64, arm64) опубликованы по адресу [https://jdk.java.net/27/](https://jdk.java.net/27/)

openjdk распространяется архивами. oracle дополнительно публикует установочные пакеты. ниже разобрана установка на разные системы. номера выпусков на приведённых страницах не совпадают между собой: страница windows указывает jdk 27, страницы linux и macos, а также документация api указывают выпуск 26, пример проверки версии показывает сборку 25. для установки берётся та ссылка и тот файл, которые указаны в соответствующем шаге.

### установка на windows

#### установка с помощью установщика

обычный путь на windows: установщик с сайта oracle. страница загрузки: [https://www.oracle.com/java/technologies/downloads/#jdk27-windows](https://www.oracle.com/java/technologies/downloads/#jdk27-windows)

для windows предложены три варианта: установщик exe (x64 installer), установщик msi (x64 msi installer) и архив, который не требует установки. между пунктами x64 installer и x64 msi installer существенной разницы нет. далее выбран пункт x64 installer. после загрузки запускается программа установки:

![установка java development kit](/uploads/course-lectures/06c496bdc841c3b9d844cf7ba2edd807dfbf7033.png)

на первом экране нажимается `Next`. следующий экран задаёт каталог установки:

![установка компонентов java development kit](/uploads/course-lectures/411e556ffb5934560277d1e7135ee5a5e2124422.png)

каталог оставляют по умолчанию и снова нажимают `Next`. установщик копирует файлы комплекта.

по завершении появляется окно:

![завершение установки jdk](/uploads/course-lectures/59b2cf6e5b93efb573ab5a8d6d56525ca047954d.png)

по умолчанию файлы помещаются в каталог `C:\Program Files\Java\jdk-[номер_версии]`, если путь при установке не меняли. в подкаталоге `bin` лежат утилиты запуска и трансляции. для первых программ нужны компилятор **javac** и средство запуска **java.exe**. `javac` переводит исходный текст в файл байт-кода, бинарный файл класса. машинный код процессора на этом шаге ещё не строится: его позже может породить уже jvm. `java.exe` передаёт файл класса виртуальной машине:

![компилятор javac в java](/uploads/course-lectures/e2c0243a124a9521f38a74be390971404918aa4b.png)

#### установка через пакетный менеджер

openjdk от microsoft ставится и через пакетный менеджер winget. в командной строке или в powershell выполняется:

```bash
winget install Microsoft.OpenJDK.26
```

команда ставит 26-ю версию jdk. идентификатор пакета `Microsoft.OpenJDK.26` фиксирует и поставщика, и номер выпуска.

### установка на linux

для jdk от oracle на linux доступно несколько форматов поставки. страница загрузки: [https://www.oracle.com/java/technologies/downloads/#jdk26-linux](https://www.oracle.com/java/technologies/downloads/#jdk26-linux)

![установка jdk на linux](/uploads/course-lectures/ccac2939cf918fd1269aad55964f6c8fbd89706a.png)

- arm64 compressed archive: архив для систем на архитектуре arm64

- arm64 rpm package: rpm-пакет для систем на архитектуре arm64, где пакеты ставятся через rpm (fedora, suse и другие)

- x64 compressed archive: архив для систем на архитектуре intel x86-64

- x64 debian package: пакет debian для систем на архитектуре intel x86-64 (ubuntu, debian и другие)

- x64 rpm package: rpm-пакет для систем на архитектуре intel x86-64, где пакеты ставятся через rpm (fedora, suse и другие)

на ubuntu для intel x86-64 выбирается пункт x64 debian package. в описании такой загрузки фигурирует файл `jdk-25_linux-x64_bin.deb`. установка выполняется командой, в которой указан пакет 26-го выпуска:

```bash
sudo dpkg -i jdk-26_linux-x64_bin.deb
```

`dpkg -i` ставит локальный deb-файл. `sudo` выполняет команду от имени администратора: каталоги, куда пакеты записывают файлы, обычному пользователю недоступны для записи.

если система ведёт пакеты через rpm (fedora, suse и другие) и работает на intel x86-64, выбирается пункт x64 rpm package. загруженный пакет ставится командой:

```bash
sudo rpm -ivh jdk-26_linux-x64_bin.rpm
```

`rpm -ivh` ставит новый пакет (`-i`), выводит ход установки (`-v`) и показывает индикатор (`-h`).

та же схема на arm64, для fedora, suse и других систем с rpm: пункт arm64 rpm package и команда

```bash
sudo rpm -ivh jdk-26_linux-aarch64_bin.rpm
```

имя `aarch64` в файле пакета принято в linux как обозначение архитектуры arm64.

в репозиториях дистрибутивов часто есть и собственные пакеты jdk. установка через snap:

```bash
sudo snap install openjdk
```

установка через apt:

```bash
sudo apt install default-jdk
```

пакет `default-jdk` в debian и ubuntu является метапакетом: он тянет ту версию компилятора и среды выполнения, которую дистрибутив считает основной.

установка конкретного выпуска через apt:

```bash
sudo apt install openjdk-26-jdk-headless
```

суффикс `headless` означает сборку без графических библиотек. для компиляции и консольных программ её достаточно. номер `26` в имени пакета задаёт выпуск платформы.

установка из архива на основных системах linux устроена одинаково. архив распаковывается в выбранный каталог, после чего путь к его подкаталогу `bin` добавляется в переменные среды, чтобы оболочка находила `javac` и `java` без полного пути.

### проверка установки

после установки в командной строке или в терминале запрашивается версия:

```bash
java -version
```

в ответ ожидается номер только что установленного выпуска. образец вывода для 25-й версии:

```bash


java version "25" 2025-09-16 LTS

Java(TM) SE Runtime Environment (build 25+37-LTS-3491)

Java HotSpot(TM) 64-Bit Server VM (build 25+37-LTS-3491, mixed mode, sharing)
```

строка `java version "25"` называет выпуск платформы, дата `2025-09-16` и пометка `LTS` относятся к этой сборке: lts (long term support) означает ветку с длительным сопровождением. `Java(TM) SE Runtime Environment` называет среду выполнения java se, `Java HotSpot(TM) 64-Bit Server VM` называет серверную виртуальную машину hotspot в 64-разрядном режиме. `mixed mode` означает, что vm совмещает интерпретацию байт-кода и jit-компиляцию. `sharing` означает совместное использование архива классов между процессами.

документация спецификации api нужна при любой нетривиальной работе с библиотекой. документация java se опубликована на сайте oracle: [https://docs.oracle.com/en/java/javase/26/docs/api/index.html](https://docs.oracle.com/en/java/javase/26/docs/api/index.html). адрес приведён для 26-го выпуска. для другого выпуска номер в пути заменяется на соответствующий.

та же документация загружается архивом и читается без сети, со страницы [https://www.oracle.com/java/technologies/javase-jdk26-doc-downloads.html](https://www.oracle.com/java/technologies/javase-jdk26-doc-downloads.html) (снова для 26-го выпуска).
