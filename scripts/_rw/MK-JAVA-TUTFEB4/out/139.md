за работу с полями класса в пакете `java.lang.reflect` отвечает класс `Field`. объект `Field` описывает одно поле так, как оно записано в файле класса: имя, объявленный тип, модификаторы и операции чтения и записи значения во время выполнения. ниже основные методы этого класса:

- `String getName()`: возвращает имя поля

- `Class getType()`: возвращает объявленный тип поля в виде объекта `Class`. для примитива это объект вроде `int.class`, который представляет сам примитивный тип

- `int getModifiers()`: возвращает целое число, в котором отдельные биты соответствуют модификаторам. установленный бит означает, что модификатор есть в объявлении

- `Set<AccessFlag> accessFlags()`: возвращает набор флагов доступа этого поля. начиная с java 20 тот же набор сведений, что даёт битовая маска `getModifiers()`, доступен как множество значений перечисления `AccessFlag`, и разбирать биты вручную уже не требуется

- `Object get(Object obj)`: возвращает текущее значение поля у объекта `obj`. значение примитивного поля приходит упакованным в соответствующий ссылочный тип

- `void set(Object obj, Object value)`: записывает в поле объекта `obj` новое значение `value`. результата у метода нет

### получение полей

чтение и запись начинаются с получения объекта `Field`. у класса `Class` для этого есть несколько методов. они различаются областью поиска и тем, учитывается ли модификатор доступа:

- `Field[] getFields()`: возвращает массив объектов `Field` для открытых полей (с модификатором `public`) данного класса и его суперклассов. закрытые и пакетные поля в этот массив не входят

- `Field[] getDeclaredFields()`: возвращает массив объектов `Field` для всех полей, объявленных именно в данном классе, без полей суперклассов. если таких полей нет, а также если объект `Class` представляет примитивный тип, `void` или массив, метод возвращает массив нулевой длины. у массива при этом есть публичное поле `length`, и его отдаёт `getFields()`, а `getDeclaredFields()` для массива остаётся пустым

- `Field getField(String name)`: возвращает объект `Field` для публичного поля, имя которого передано параметром. поиск идёт и по полям суперклассов. если такого публичного поля нет, метод генерирует исключение `NoSuchFieldException`

- `Field getDeclaredField(String name)`: возвращает объект `Field` для поля данного класса с указанным именем при любом модификаторе доступа. поля суперклассов метод не просматривает: чтобы дойти до поля суперкласса, берут `getSuperclass()` и уже у него вызывают `getDeclaredField`. если поля с таким именем нет, метод генерирует исключение `NoSuchFieldException`

имя сравнивается как строка, поэтому регистр символов входит в тождество поля. строка `"Name"` не совпадает с полем `name`.

пример получает все объявленные поля класса `Person`:

```java


import java.lang.reflect.*;



public class Program{

      

    public static void main(String[] args) {

        

        // получаем класс для типа Person

        Class cl = Person.class;



        // получаем поля 

        Field[] fields = cl.getDeclaredFields();

        for(Field f : fields){



            // получаем тип и имя поля

            System.out.printf("%s %s;\n", f.getType().getName(), f.getName());

        }

    }

}



class Person {

     

    private String name;

    private int age;



    public Person(String name, int age){ 



        this.name = name;

        this.age = age;

    }

    

    void print(){

        System.out.printf("Person. Name: %s;  Age: %d\n", name, age);

    }

}
```

консольный вывод:

```bash


java.lang.String name;

int age;
```

`getType().getName()` для ссылочного типа печатает двоичное имя класса, здесь `java.lang.String`, а для примитива `int` оставляет имя `int`. рядом `getName()` печатает простое имя поля. порядок элементов `getDeclaredFields()` спецификация не фиксирует: на него нельзя опираться как на порядок объявлений в исходном тексте, хотя виртуальная машина часто возвращает поля именно в этом порядке.

то же поле можно запросить по имени:

```java


import java.lang.reflect.*;



public class Program{

      

    public static void main(String[] args) {

        

        // получаем класс для типа Person

        Class cl = Person.class;



        try{

            // получаем поля name и age

            Field nameField = cl.getDeclaredField("name");

            Field ageField = cl.getDeclaredField("age");



            System.out.println(nameField);

            System.out.println(ageField);

        }

        catch(NoSuchFieldException ex){

            System.out.println(ex);

        }

    }

}



class Person {

     

    private String name;

    private int age;



    public Person(String name, int age){ 



        this.name = name;

        this.age = age;

    }

    

    void print(){

        System.out.printf("Person. Name: %s;  Age: %d\n", name, age);

    }

}
```

`getDeclaredField()` здесь вызывается для полей `name` и `age` класса `Person`. регистр в строке имени учитывается. метод `toString()` у `Field` собирает модификаторы, тип и квалифицированное имя. на консоль выводится:

```bash


private java.lang.String Person.name

private int Person.age
```

дальше с уже полученным полем обычно делают одно из двух: читают значение или записывают новое. для этого у `Field` есть `get()` и `set()`.

### обращение к приватным полям

по умолчанию рефлексия соблюдает контроль доступа java. поля `name` и `age` объявлены как `private`, поэтому `get()` и `set()` без дополнительной подготовки выбрасывают `IllegalAccessException`, исключение недопустимого доступа. пока проверка включена, `get` и `set` применимы только к тем полям, которые доступны вызывающему коду по обычным правилам языка. механизм безопасности позволяет узнать, какие поля есть у объекта, и при этом не позволяет читать и записывать значения этих полей без соответствующего разрешения.

проверку доступа снимают методом `setAccessible()` у объекта `Field`, передав значение `true`:

```java


field.setAccessible(true);
```

если доступ не предоставлен, сам вызов `setAccessible` завершается исключением. с модулями java 9 пакет может быть закрыт для глубокой рефлексии: тогда возникает `InaccessibleObjectException`. чужой модуль читается так только если пакет открыт (`opens`) вызывающему модулю или если виртуальная машина запущена с разрешением вроде `--add-opens`. метод `trySetAccessible()` с java 9 делает ту же попытку и возвращает `false`, если открыть доступ нельзя. в примерах ниже классы лежат в одном неименованном модуле, и для приватного поля своего класса `setAccessible(true)` выполняется.

### получение значения поля

значение поля читает метод `get()`:

```java


public Object get(Object obj) throws IllegalArgumentException, IllegalAccessException
```

параметр метода задаёт объект, у которого читается поле. для поля экземпляра это должен быть объект совместимого типа, иначе возникает `IllegalArgumentException`. для статического поля ссылка на экземпляр игнорируется и может быть `null`. пример читает поля объекта `Person`:

```java


import java.lang.reflect.*;



public class Program{

      

    public static void main(String[] args) {

        

        // Исследуемый объект

        Person tom = new Person("Tom", 41);

        // получаем класс для типа Person

        Class cl = tom.getClass();



        try{

            // получаем поля name и age

            Field nameField = cl.getDeclaredField("name");

            Field ageField = cl.getDeclaredField("age");



            // делаем поля доступными для доступа

            nameField.setAccessible(true);

            ageField.setAccessible(true);



            // получаем значения полей

            Object name = nameField.get(tom);  // Tom

            Object age = ageField.get(tom);     // 41



            System.out.println("Name: " + name);

            System.out.println("Age: " + age);  

        }

        catch(Exception ex){

            System.out.println(ex);

        }

    }

}



class Person {

     

    private String name;

    private int age;



    public Person(String name, int age){ 



        this.name = name;

        this.age = age;

    }

    

    void print(){

        System.out.printf("Person. Name: %s;  Age: %d\n", name, age);

    }

}
```

после `setAccessible(true)` чтение `name` даёт строку `Tom`, чтение `age` даёт упакованное значение `41`. статический тип обоих результатов есть `Object`: примитив `int` рефлексия возвращает как `Integer`.

### изменение поля

значение поля меняет метод `set()`:

```java


public void set(Object obj, Object value) throws IllegalArgumentException, IllegalAccessException
```

первый параметр (`obj`) задаёт объект, поле которого меняется, второй параметр (`value`) задаёт новое значение. для примитивного поля ссылочный аргумент распаковывается. несовместимый тип значения приводит к `IllegalArgumentException`. обращение к закрытому полю без `setAccessible` приводит к `IllegalAccessException`. пример записывает новые значения и печатает объект:

```java


import java.lang.reflect.*;



public class Program{

      

    public static void main(String[] args) {

        

        // Исследуемый объект

        Person tom = new Person("Tom", 41);

        // получаем класс для типа Person

        Class cl = tom.getClass();



        try{

            // получаем поля name и age

            Field nameField = cl.getDeclaredField("name");

            Field ageField = cl.getDeclaredField("age");



            // делаем поля доступными для доступа

            nameField.setAccessible(true);

            ageField.setAccessible(true);



            // изменяем значения полей

            nameField.set(tom, "Bob");

            ageField.set(tom, 22);



            tom.print();    // Person. Name: Bob;  Age: 22

        }

        catch(Exception ex){

            System.out.println(ex);

        }

    }

}



class Person {

     

    private String name;

    private int age;



    public Person(String name, int age){ 



        this.name = name;

        this.age = age;

    }

    

    void print(){

        System.out.printf("Person. Name: %s;  Age: %d\n", name, age);

    }

}
```

после записи поле `name` содержит `Bob`, поле `age` содержит `22`, что и показывает `print()`. при разрешённом `setAccessible(true)` модификатор `private` эту запись не останавливает: рефлексия меняет поле напрямую. сеттер класса при этом не вызывается, и проверки, которые автор мог поместить в метод изменения, на записанное значение не накладываются.
