часто нужно запустить несколько задач одновременно и получить результат первой успешно завершившейся либо собрать результаты всех. для этого у `ExecutorService` есть два метода: `invokeAll()` и `invokeAny()`.

### invokeall. ожидание завершения всей группы задач

метод `invokeAll()` отправляет на выполнение все задачи из коллекции объектов `Callable`, блокирует вызывающий поток до завершения всех задач и возвращает список объектов `Future` с результатами. порядок списка совпадает с порядком отправки. порядок завершения на этот список не влияет. по индексу задача сопоставляется со своим `Future`.

в ряде ситуаций ожидание всей группы оказывается избыточным: метод не возвращает управление, даже если часть задач уже завершилась с ошибкой. сбой одной задачи не отменяет остальные и не выбрасывается из `invokeAll`. исключение сохраняется в соответствующем `Future`. наружу `invokeAll` бросает `InterruptedException`, если прерван поток, который ждёт группу.

у метода две перегрузки:

```java


<T> List<Future<T>> invokeAll(Collection<? extends Callable<T>> tasks)

<T> List<Future<T>> invokeAll(Collection<? extends Callable<T>> tasks, long timeout, TimeUnit unit)
```

первая принимает коллекцию задач и возвращает список `Future` со статусом и результатом каждой.

вторая дополнительно принимает тайм-аут, интервал, до истечения которого ожидается завершение задач. по контракту java по истечении интервала незавершённые задачи отменяются, а метод возвращает список. `TimeoutException` эта перегрузка не выбрасывает. у каждого элемента возвращённого списка `isDone()` истинен. `InterruptedException` по-прежнему возможен, если прерван ожидающий поток.

пример считает несколько факториалов:

```java


import java.util.concurrent.*;

import java.util.List;

import java.util.ArrayList;



record FactorialResult(int number, int factorial){}



class FactorialTask implements Callable<FactorialResult>{



    private int number;

    FactorialTask(int number) {  this.number = number; }



    public FactorialResult call() throws Exception{



        if(number < 1) throw new Exception("Incorrect number: " + number + ". Number must be greater than 0");



        int result = 1;

        int n = number;

        while(n > 0)  result *= n--; 



        return new FactorialResult(number, result);  // возвращаем результат задачи

    };

}



class Program{



    public static void main(String[] args) {

         

        System.out.println("Main thread started...");





        try (ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor()) {



            List<Callable<FactorialResult>> tasks = new ArrayList<Callable<FactorialResult>>();

            // добавляем несколько задач

            for(int i = -1; i < 4; i++) tasks.add(new FactorialTask(i));



            // вызываем и ждем завершения всех задач

            List<Future<FactorialResult>> results = executor.invokeAll(tasks);



            // получаем результаты

            for (Future<FactorialResult> result : results) {

                if (result.state() == Future.State.SUCCESS){

                    FactorialResult factorialResult =  result.resultNow();

                    System.out.printf("Factorial of %d:  %d\n", 

                            factorialResult.number(), factorialResult.factorial());

                }

                else{

                    var ex = result.exceptionNow();

                    System.out.println("Factorial exception: " + ex.getMessage());

                }

            }



        } // здесь вызывается метод executor.close() 

        catch(Exception ex){

            System.out.println(ex.getMessage());

        }

        System.out.println("Main thread finished...");

    }

}
```

для результата задачи объявлен тип `FactorialResult`:

```java
record FactorialResult(int number, int factorial){}
```

`record` здесь несёт два компонента: `number`, число, для которого считается факториал, и `factorial`, сам факториал. доступ к компонентам идёт методами `number()` и `factorial()`.

задача представлена классом `FactorialTask`. он реализует `Callable`. метод `call` считает факториал числа, полученного через конструктор, и возвращает `FactorialResult`.

```java


public FactorialResult call() throws Exception{



    if(number < 1) throw new Exception("Incorrect number: " + number + ". Number must be greater than 0");



    int result = 1;

    int n = number;

    while(n > 0)  result *= n--; 



    return new FactorialResult(number, result);  // возвращаем результат задачи

};
```

если `number < 1`, выбрасывается проверяемое `Exception`. иначе произведение накапливается так же, как в одиночной задаче факториала, и упаковывается в запись вместе с исходным числом. факториал нуля по определению равен 1, но условие примера отвергает и нуль.

в пример входят числа от -1 включительно до 4 невключительно, то есть -1, 0, 1, 2 и 3. среди них есть заведомо недопустимые для этой задачи. создаётся `ExecutorService`, исполняющий задачи на виртуальных потоках, и список `Callable`:

```java


try (ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor()) {



    List<Callable<FactorialResult>> tasks = new ArrayList<Callable<FactorialResult>>();

    // добавляем несколько задач

    for(int i = -1; i < 4; i++) tasks.add(new FactorialTask(i));
```

затем все задачи запускаются методом `executor.invokeAll()`, и вызывающий поток ждёт их завершения:

```java
List<Future<FactorialResult>> results = executor.invokeAll(tasks);
```

на этой строке `main` приостанавливается, пока не завершится вся группа. когда результаты доступны, цикл проходит по списку в порядке отправки и обрабатывает каждый исход:

```java


for (Future<FactorialResult> result : results) {

    if (result.state() == Future.State.SUCCESS){

        FactorialResult factorialResult =  result.resultNow();

        System.out.printf("Factorial of %d:  %d\n", 

        factorialResult.number(), factorialResult.factorial());

    }

    else{

        var ex = result.exceptionNow();

        System.out.println("Factorial exception: " + ex.getMessage());

    }

}
```

каждый элемент является `Future`. метод `state()` показывает состояние. при `Future.State.SUCCESS` метод `resultNow()` возвращает сам результат, объект `FactorialResult`. при неуспехе `exceptionNow()` возвращает возникшее исключение, и на консоль выводится его сообщение. ветка `else` в примере рассчитана на `FAILED`: у отменённой задачи `exceptionNow()` выбрасывает `IllegalStateException`, потому что отмена не сохраняет исключение тела задачи. в этом запуске отмены нет, задачи либо успешны, либо завершились исключением из `call()`. сообщение `exceptionNow()` совпадает с текстом конструктора `Exception`, без дополнительной обёртки `ExecutionException`, поскольку `invokeAll` наружу это исключение не пробрасывает.

консольный вывод программы:

```bash


Main thread started...

Factorial exception: Incorrect number: -1. Number must be greater than 0

Factorial exception: Incorrect number: 0. Number must be greater than 0

Factorial of 1:  1

Factorial of 2:  2

Factorial of 3:  6

Main thread finished...
```

числа -1 и 0 отвергнуты условием `number < 1`. факториалы 1, 2 и 3 равны 1, 2 и 6. порядок строк совпадает с порядком задач в списке.

### invokeany. ожидание завершения одной задачи из группы

метод `invokeAny()` отправляет на выполнение все задачи из коллекции объектов `Callable` и блокирует вызывающий поток, пока одна из них не завершится успешно и не вернёт свой результат. у метода две перегрузки.

### invokeany. ожидание завершения одной задачи из группы

метод `invokeAny()` отправляет на выполнение все задачи из коллекции объектов `Callable` и блокирует вызывающий поток, пока одна из них не завершится успешно и не вернёт свой результат. у метода две перегрузки.

```java


<T> T invokeAny(Collection<? extends Callable<T>> tasks)

<T> T invokeAny(Collection<? extends Callable<T>> tasks, long timeout, TimeUnit unit)
```

первая перегрузка принимает коллекцию, из которой нужно дождаться одного успешного завершения. результат метода есть результат одной успешно завершившейся задачи. какая именно из успешных задач победит, контракт не фиксирует.

вторая перегрузка дополнительно принимает тайм-аут, время, до истечения которого должна успешно завершиться хотя бы одна задача. если за это время успеха нет, выбрасывается `TimeoutException`.

незавершённые к моменту возврата задачи отменяются. если ни одна задача не завершилась успешно, выбрасывается `ExecutionException`. причина внутри него является одним из исключений задач. пустая коллекция отвергается с `IllegalArgumentException`.

предыдущий пример меняется так, чтобы было достаточно одного успешно посчитанного факториала:

```java


import java.util.concurrent.*;

import java.util.List;

import java.util.ArrayList;



record FactorialResult(int number, int factorial){}

class FactorialTask implements Callable<FactorialResult>{



    private int number;

    FactorialTask(int number) {  this.number = number; }



    public FactorialResult call() throws Exception{



        if(number < 1) throw new Exception("Incorrect number: " + number + ". Number must be greater than 0");



        int result = 1;

        int n = number;

        while(n > 0)  result *= n--; 



        return new FactorialResult(number, result);  // возвращаем результат задачи

    };

}



class Program{



    public static void main(String[] args) {

         

        System.out.println("Main thread started...");





        try (ExecutorService executor = Executors.newVirtualThreadPerTaskExecutor()) {

            List<Callable<FactorialResult>> tasks = new ArrayList<Callable<FactorialResult>>();

            // добавляем несколько задач

            for(int i = -1; i < 4; i++) tasks.add(new FactorialTask(i));



            // вызываем задачи и ждем, пока хотя бы одна из них не завершенится

            FactorialResult factorialResult = executor.invokeAny(tasks);

            System.out.printf("Factorial of %d:  %d\n", 

                    factorialResult.number(), factorialResult.factorial());



        }

        catch(Exception ex){

            System.out.println(ex.getMessage());

        }

        System.out.println("Main thread finished...");

    }

}
```

большая часть логики совпадает с предыдущим примером. отличие в ожидании одной задачи через `invokeAny()`:

```java


FactorialResult factorialResult = executor.invokeAny(tasks);

System.out.printf("Factorial of %d:  %d\n",  factorialResult.number(), factorialResult.factorial());
```

вывод не детерминирован. одна из возможных трасс:

```bash


Main thread started...

Factorial of 3:  6

Main thread finished...
```

в списке есть успешные задачи для чисел 1, 2 и 3, поэтому любая из них может дать возвращённое значение. исключения задач с аргументами -1 и 0 сами по себе `invokeAny` не завершают, пока есть шанс другого успеха.

если успешно не завершилась ни одна задача, исключение обрабатывается в `catch`. для набора, в котором успеха нет, вывод выглядит так:

```bash


Main thread started...

java.lang.Exception: Incorrect number: -1. Number must be greater than 0

Main thread finished...
```

текст `java.lang.Exception: Incorrect number: -1. Number must be greater than 0` приходит из `ExecutionException`: в сообщении оказывается `toString()` причины. в показанном запуске причиной стало исключение задачи с числом -1. для списка из примера, где присутствуют 1, 2 и 3, такая трасса не возникает.
