ещё одна распространённая среда для приложений на java называется **eclipse**. изначально среду создала и развивала ibm, затем разработка была выделена в отдельный проект eclipse foundation. среда распространяется свободно и покрывает разные виды приложений на java: от консольной программы до корпоративного и веб-проекта.

последняя на момент исходного текста версия публиковалась на странице [https://www.eclipse.org/downloads/](https://www.eclipse.org/downloads/). там рядом с именем текущего выпуска (в том тексте это версия `Oxygen`) стоит кнопка `Download`.

![eclipse ide](/uploads/course-lectures/be495c78e3747a3d9edbe8d57b7114ce89b0121d.png)

после нажатия открывается страница самой загрузки, и пакет установщика забирается повторным нажатием `Download`:

![загрузка eclipse ide](/uploads/course-lectures/f12e2c17c9906021f65cc65fe1c1267d7bbdcdef.png)

загруженный пакет запускается:

![eclipse ide for java ee](/uploads/course-lectures/73fdb53776c0a6a0ab5c67e009c09f2b87c4586c.png)

eclipse объединяет несколько сред под разные задачи и языки, и установщик предлагает выбрать одну из конфигураций. для работы с java в этом курсе существенны две:

`Eclipse IDE for Java Developers`

`Eclipse IDE for Enterprise Java and Web Developers`

первая даёт базовые средства java: проект, компилятор, запуск. вторая добавляет к ним средства веб-приложений и сервисов и включает возможности первой. далее выбирается `Eclipse IDE for Enterprise Java and Web Developers`.

затем указывается каталог установки (или оставляется каталог по умолчанию), указывается путь к jdk и нажимается `Install`:

![создание первого проекта в eclipse ide](/uploads/course-lectures/792884240e0748937fea5596adcc2568065bf4ec.png)

следующий шаг принимает лицензионное соглашение:

![установка лицензии для eclipse ide](/uploads/course-lectures/90c5c8d8350a25a8196032fb00ee4f60da7e9fd4.png)

после принятия соглашения начинается установка. по её окончании eclipse запускается. сначала среда запрашивает каталог для проектов (workspace): в нём будут лежать файлы проектов. значение оставляют по умолчанию и нажимают `Launch`:

![delete eclipse ide in windows 10](/uploads/course-lectures/dd8ea7321112cd1dde737d5bfdf548854eb88dcc.png)

дальше выбирается пункт меню **file -> new -> project**:

![создание первого проекта на java в eclipse ide](/uploads/course-lectures/74e8621e3fca4a58e8931fb46a0429c79d1e266f.png)

открывается окно выбора шаблона. выбирается **java project**, затем `Next`:

![java project in eclipse ide](/uploads/course-lectures/b641f8b5610ade0de57acd96802244c02f608394.png)

следующее окно задаёт параметры проекта. в поле **project name** вводится имя. в этом курсе проекту даётся имя helloapp:

![настройка проекта java в eclipse ide](/uploads/course-lectures/10408bae5f5a00c728725e0550f26f3780c314f8.png)

поле **jre** задаёт среду выполнения, то есть ту версию java, которой проект будет компилироваться и запускаться. можно оставить версию по умолчанию или выбрать другую, если нужен конкретный выпуск jdk или jre.

внизу окна находится поле **create module-info.java file**. файл `module-info.java` служит дескриптором модуля системы модулей java (jpms): он объявляет имя модуля и его зависимости. для первого проекта этот файл не требуется. чтобы не добавлять его в каталог, отметку с поля снимают.

остальные параметры оставляют по умолчанию и нажимают `Finish`.

следующее окно спрашивает, открывать ли перспективу проекта. перспективой в eclipse называется сохранённый набор панелей под определённый вид работы:

![](/uploads/course-lectures/2cf7321f223f4d297a0f191b40d15dacf8929c8d.png)

для дальнейших шагов выбор перспективы на результат не влияет. нажимается **open perspective**.

после создания проект открыт в eclipse. если среда не показывает проект сама, нажимается `Restore`:

![restore project in eclipse ide](/uploads/course-lectures/e84c07dae84f3e4a1700626811d45848b6d249fd.png)

сразу после создания проект пуст.

![](/uploads/course-lectures/b07a6fb8ed957775904318c2ce6148b3543e6ff9.png)

исходные файлы java среда помещает в каталог **src**. правая кнопка на этом каталоге открывает контекстное меню, в нём выбирается **new -> class**:

![добавление класса java в eclipse ide](/uploads/course-lectures/a861559b0c96a9edfa3744fd82b98cbf80752401.png)

в окне настройки класса поле `Name` задаёт имя. в этом курсе класс называется `Program`. остальные параметры оставляют по умолчанию:

![создание программы на java в eclipse](/uploads/course-lectures/4f76c9ada6460c14dd9822e98b4189882790a200.png)

в проект добавляется файл `Program.java`, в центре eclipse открывается его текст. текст заменяется на следующий:

```java
package helloapp;

public class Program {

	public static void main(String[] args) {
		System.out.println("Hello Eclipse!");
	}
}
```

![первая программа на java в eclipse](/uploads/course-lectures/2abb43656744b996f769444abc30b8ed5772cc35.png)

директива `package helloapp;` помещает класс в пакет, совпадающий с именем проекта. метод `main` остаётся точкой входа, как и в программах, собранных вручную.

проект запускается зелёной стрелкой на панели или пунктом меню **run -> run**. внизу, в панели `Console`, появляется результат: тот же поток, который программа пишет в стандартный вывод.
