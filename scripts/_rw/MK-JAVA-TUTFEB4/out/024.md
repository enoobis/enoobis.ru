объекты классов, как и значения примитивных типов, передаются в методы. в обоих случаях аргумент передаётся по значению. для примитива в параметр копируется само значение. для объекта в параметр копируется ссылка на область памяти, где расположен экземпляр, а поля объекта при этой передаче не копируются.

сначала подробно рассматривается передача параметров примитивных типов: числовых, таких как `int` и `double`, а также `char` и `boolean`.

```java


class Program{



    public static void main(String[] args) {  



        int num = 22;

        Calcualtor calc = new Calcualtor();

        calc.twice(num);

        System.out.printf("num in main (after twice): %d\n", num);

    }

}

class Calcualtor{



    void twice(int n){

		

        n = n + n;

        System.out.printf("n in twice: %d\n", n);

	}

}
```

в методе `main` значение переменной `num` передаётся в метод `calc.twice()` параметру `n`:

```java


calc.twice(num);
```

в `calc.twice()` значение параметра `n`, которому передано значение `num`, увеличивается в два раза:

```java


void twice(int n){

		

    n = n + n;

    System.out.printf("n in twice: %d\n", n);

}
```

после возврата из `calc.twice()` переменная `num` сохраняет прежнее значение. консольный вывод программы показывает обе величины:

```bash


n in twice: 44

num in main (after twice): 22
```

параметр `n` в методе `twice` увеличился вдвое, как и записано в теле. переменная `num` после выполнения `twice` осталась равной 22. при вызове `calc.twice()` параметр `n` получает **копию значения** переменной `num`, то есть число 22:

![передача параметров по значению в java](/uploads/course-lectures/3940ffe362f77c9f209edd2c020c95b4f8784c6a.png)

когда вызывается `calc.twice()`, в участок памяти параметра `n` копируется значение переменной `num`, число 22. после этого `n` и `num` не связаны: у них разные участки памяти, и изменение одного не затрагивает другое. присваивание параметру `n` оставляет переменную `num` прежней. так устроена передача по значению для примитива: вызывающий код и параметр расходятся сразу после копирования.

у переменных остальных типов в переменной хранится ссылка на область памяти объекта. небольшой пример с полем объекта:

```java


class Program{



    public static void main(String[] args) {  



        Person bob = new Person();

        bob.age = 22;

        System.out.printf("bob.age in main (before twice): %d\n", bob.age);



        Calcualtor calc = new Calcualtor();

        calc.twice(bob);



        System.out.printf("bob.age in main (after twice): %d\n", bob.age);

    }

}

class Person{ 



    int age;

}



class Calcualtor{



    void twice(Person p){

		

        p.age = p.age + p.age;

        System.out.printf("p.age in twice: %d\n", p.age);

	}

}
```

метод `twice` класса `Calcualtor` теперь принимает объект типа `Person`. у этого типа есть целочисленное поле `age`. в `twice` поле увеличивается в два раза тем же приёмом, сложением значения с самим собой:

```java


 void twice(Person p){

		

    p.age = p.age + p.age;

    System.out.printf("p.age in twice: %d\n", p.age);

}
```

в методе `main` объявляется переменная `bob` типа `Person`, полю `age` записывается 22, и значение переменной передаётся в `twice`:

```java


Person bob = new Person();

.......................

calc.twice(bob);
```

консольный вывод программы:

```bash


bob.age in main (before twice): 22

p.age in twice: 44

bob.age in main (after twice): 44
```

поле `age` у объекта, на который указывает `bob`, изменилось. в `twice` передаётся копия ссылки на область памяти, где находится объект `Person`. переменная `bob` и параметр `p` метода `twice` указывают на один и тот же объект:

![передача объектов в метод в java](/uploads/course-lectures/af5ffd81f9fc34498341254d6fd4cd8e997fb917.png)

после выполнения метода у объекта, ссылку на который хранит `bob` и который передан в метод, значение `age` меняется с 22 на 44. скопирована была ссылка. участок с полями остался общим, поэтому запись `p.age = ...` видна и через `bob`.

от этого случая отделяют другой: параметр перенаправляют на новый объект.

```java


class Program{



    public static void main(String[] args) {  



        Person bob = new Person();

        bob.age = 22;

        System.out.printf("bob.age in main (before twice): %d\n", bob.age);



        Calcualtor calc = new Calcualtor();

        calc.twice(bob);



        System.out.printf("bob.age in main (after twice): %d\n", bob.age);

    }

}

class Person{ 



    int age;

}



class Calcualtor{



    void twice(Person p){

		

        p = new Person();      // создаем новый объект

        p.age = 44;

        System.out.printf("p.age in twice: %d\n", p.age);

	}

}
```

в метод `twice` снова передаётся копия ссылки на объект `Person`. внутри метода меняются уже не отдельные поля исходного объекта. объект создаётся заново конструктором и оператором `new`. в памяти выделяется новое место под новый объект `Person`, и ссылка на него присваивается параметру `p`:

```java


void twice(Person p){

		

    p = new Person();      // создаем новый объект

    p.age = 44;

    System.out.printf("p.age in twice: %d\n", p.age);

}
```

после создания нового объекта `Person` параметр `p` и переменная `bob` в `main` хранят ссылки на разные объекты. переменная `bob`, которая передавалась в метод, сохраняет ссылку на прежний объект в памяти. значение его поля не меняется, что и показывает консольный вывод:

```bash


bob.age in main (before twice): 22

p.age in twice: 44

bob.age in main (after twice): 22
```

присваивание `p = new Person()` подменяет локальную копию ссылки. переменная вызывающего кода указывает туда же, куда указывала до вызова. поля исходного объекта меняются только тогда, когда через переданную ссылку записывают сами поля, как в предыдущем примере с `p.age`.
