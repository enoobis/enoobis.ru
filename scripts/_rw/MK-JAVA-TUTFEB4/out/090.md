строка это последовательность символов. в java за неё отвечает класс `String`: создание, длина, сравнение, поиск, замена. объект `String` ссылается на область памяти, где лежат символы. с java 9 эта область устроена как массив `byte[]` и признак кодировки. если все символы помещаются в latin-1, на символ уходит один байт, иначе массив хранит utf-16. снаружи строка по-прежнему последовательность кодовых единиц utf-16. `length()` считает эти единицы, а не байты массива и не число юникодных скаляров: суррогатная пара занимает две единицы и даёт длину 2.

новую строку получают конструктором `String` или литералом в двойных кавычках:

```java
public static void main(String[] args) {
        
    String str1 = "Java";
    String str2 = new String(); // пустая строка
    String str3 = new String(new char[] {'h', 'e', 'l', 'l', 'o'});
    String str4 = new String(new char[]{'w', 'e', 'l', 'c', 'o', 'm', 'e'}, 3, 4);//3 -начальный индекс, 4 -кол-во символов
        
    System.out.println(str1); // Java
    System.out.println(str2); //
    System.out.println(str3); // hello
    System.out.println(str4); // come
}
```

`str1` это литерал `"Java"`. литералы с одинаковым содержимым могут указывать на один объект из пула строк. `str2` построен конструктором без аргументов и пуст: объект есть, символов в нём нет. `str3` копирует массив `{'h', 'e', 'l', 'l', 'o'}` целиком и даёт `"hello"`. `str4` берёт конструктор `String(char[], int, int)`: начальный индекс 3 и число символов 4. из `"welcome"` это символы с индекса 3, четыре штуки, строка `"come"`. `new String(...)` создаёт новый объект даже если такая последовательность уже есть в пуле. литерал пул может переиспользовать.

`String` неизменяем. операция, которая по смыслу меняет строку, возвращает новый объект. прежний объект остаётся с тем же содержимым и той же идентичностью. из-за этого строку можно безопасно публиковать между потоками без дополнительной синхронизации её символов, а хэш-код разрешено кэшировать: он не устареет.

### длина строк. пустые строки и null

строка рассматривается как набор символов, поэтому длина это число этих символов. её даёт `length()`:

```java
String str1 = "Java";
System.out.println(str1.length()); // 4
```

у `"Java"` длина 4. обратное преобразование в массив символов делает `toCharArray()`. метод копирует кодовые единицы в новый `char[]`, изменения массива строку не затрагивают:

```java
String str1 = new String(new char[] {'h', 'e', 'l', 'l', 'o'});
char[] helloArray = str1.toCharArray();
```

строка бывает пустой. ей присваивают пустые кавычки, либо получают строку, из которой удалены все символы:

```java
String s = "";   // пустая строка
if(s.length() == 0) System.out.println("String is empty");
```

длина, которую возвращает `length()`, в этом случае равна 0.

отдельный метод `isEmpty()` проверяет пустоту напрямую. для пустой строки он возвращает `true`:

```java
String s = "";   // пустая строка
if(s.isEmpty()) System.out.println("String is empty");
```

`isEmpty()` истинен ровно тогда, когда `length()` равен 0. это проверка длины, а не проверка ссылки.

переменная типа `String` может не ссылаться ни на какой объект и иметь значение `null`:

```java
String s = null;   // строка не указывает на объект
if(s == null) System.out.println("String is null");
```

`null` и пустая строка не одно и то же. пустая строка это объект длины 0, `null` это отсутствие объекта. вызов метода у `null` завершается ошибкой времени выполнения, `NullPointerException`:

```java
String s = null;   // строка не указывает на объект
if(s.length()==0) System.out.println("String is empty");	// ! Ошибка
```

ссылки на объект `String` нет, поэтому ни `length()`, ни другой метод экземпляра вызвать нельзя. перед обращением ссылку проверяют на `null`. оператор `||` вычисляет правую часть только если левая ложна, поэтому `length()` при `s == null` не вызывается:

```java
String s = null;   // строка не указывает на объект
if(s==null || s.length()==0) System.out.println("String is empty");
```

### основные методы класса `String`

операции над строкой собраны в методах `String`. из них выделяются:

- `concat()`: объединяет строки
- `valueOf()`: преобразует объект в строковый вид
- `join()`: соединяет строки с учётом разделителя
- `compareTo()`: сравнивает две строки
- `charAt()`: возвращает символ строки по индексу
- `getChars()`: возвращает группу символов
- `equals()`: сравнивает строки с учётом регистра
- `equalsIgnoreCase()`: сравнивает строки без учёта регистра
- `regionMatches()`: сравнивает подстроки в строках
- `indexOf()`: находит индекс первого вхождения подстроки в строку
- `lastIndexOf()`: находит индекс последнего вхождения подстроки в строку
- `startsWith()`: определяет, начинается ли строка с подстроки
- `endsWith()`: определяет, заканчивается ли строка на определённую подстроку
- `replace()`: заменяет в строке одну подстроку на другую
- `strip()`: удаляет начальные и конечные пробелы
- `substring()`: возвращает подстроку, начиная с определённого индекса до конца или до определённого индекса
- `toLowerCase()`: переводит все символы строки в нижний регистр
- `toUpperCase()`: переводит все символы строки в верхний регистр

работа этих методов разбирается далее.
