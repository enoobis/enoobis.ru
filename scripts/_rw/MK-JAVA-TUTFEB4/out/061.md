с версии java 21 доступен **record pattern**, шаблон записи (jep 440). шаблон проверяет, что значение является экземпляром класса `record`, и сразу разбирает его компоненты. если ссылка равна `null` или динамический тип не совпал, шаблон не сопоставляется. тот же шаблон пишется и в операторе `instanceof`, и в конструкции `switch`. безымянный шаблон `_` на месте ненужного компонента в java 21 является preview, с java 22 входит в язык постоянно.

### instanceof

пример шаблона записи с оператором `instanceof`:

```java


public class Program{

      

    public static void main(String[] args) {

             

        Person tom = new Person("Tom", 22);



        if(tom instanceof Person(var pName, var pAge)){

            System.out.printf("Person. Name: %s;  Age: %d\n", pName, pAge);

        }

    }

}

record Person(String name, int age){}
```

выражение `tom instanceof Person(var pName, var pAge)` проверяет, что `tom` имеет тип `Person` и не равен `null`, и связывает компоненты записи с переменными шаблона. компонент `name` попадает в `pName`, компонент `age` в `pAge`. порядок компонентов совпадает с порядком в каноническом конструкторе записи. внутри блока `if` эти переменные используются как обычные локальные переменные. `var` выводит тип компонента. тип можно записать и явно, связывание от этого не меняется:

```java


if(tom instanceof Person(String pName, int pAge)){

    System.out.printf("Person. Name: %s;  Age: %d\n", pName, pAge);

}
```

если компонент не нужен, на его месте ставят прочерк `_`, безымянный шаблон. ниже остаётся только возраст:

```java


if(tom instanceof Person(_, int pAge)){

    System.out.printf("Person Age: %d\n", pAge);

}
```

имя отбрасывается, в `pAge` связывается `age`, и печать использует только его.

### switch

конструкции и выражения `switch` принимают тот же шаблон. селектором выступает сам объект записи:

```java


Person tom = new Person("Tom", 22);



switch(tom){



    case Person(var pName, var pAge) ->

        System.out.printf("Person. Name: %s;  Age: %d\n", pName, pAge);



    case null -> System.out.printf("Undefined");

}
```

ветвь `case Person(var pName, var pAge)` разбирает запись так же, как `instanceof` выше. отдельная ветвь `case null` нужна потому, что шаблон записи с `null` не совпадает, а switch по ссылке без метки `null` при нулевом селекторе завершается исключением `NullPointerException`.

### константы и защитные условия guards

в позиции компонента шаблона записи константа не ставится. компонент принимает вложенный шаблон, шаблон типа или безымянный шаблон `_`, а строковый литерал шаблоном компонента не является. отдельно поймать имя `"Tom"` прямой записью литерала нельзя:

```java


if(tom instanceof Person("Tom", _)){  // Ошибка: "Tom" - константа

    System.out.printf("Person Tom");

}
```

сравнение с константой переносится в защитное условие. переменная шаблона сопоставляется с нужным значением уже после успешного разбора записи:

```java


public class Program{

      

    public static void main(String[] args) {

             

        Person tom = new Person("Tom", 22);

        Person bob = new Person("Bob", 46);



        printPerson(tom);       // Hello Tom

        printPerson(bob);       // Hello

    }



    static void printPerson(Person person){



        if(person instanceof Person(var pName, _) && pName == "Tom"){

             System.out.println("Hello Tom");

        }

        else if(person instanceof Person(_, _) ){

             System.out.println("Hello");

        }

    }

}
```

если имя равно `"Tom"`, выполняется блок `if`:

```java


if(person instanceof Person(var pName, _) && pName == "Tom"){

    System.out.println("Hello Tom");

}
```

условие `pName == "Tom"` является охраной шаблона. оператор `==` сравнивает ссылки. для литерала `"Tom"`, которым в примере заполнены и запись, и правая часть, сравнение ссылок даёт ожидаемый результат. если имя другое, выполняется блок `else if`:

```java


else if(person instanceof Person(_, _) ){

    System.out.println("Hello");

}
```

шаблон `Person(_, _)` совпадает с любой записью `Person`, компоненты отбрасываются, и печатается общее приветствие. для `bob` с именем `"Bob"` срабатывает эта ветвь.

в `switch` охрана вводится оператором `when`, после которого записывается условие:

```java


public class Program{

      

    public static void main(String[] args) {

             

        Person tom = new Person("Tom", 22);

        Person bob = new Person("Bob", 46);



        printPerson(tom);       // Hello Tom

        printPerson(bob);       // Hello

    }



    static void printPerson(Person person){



        switch(person){



            case Person(var pName, _)  when pName == "Tom" -> // только для тех Person, где name = "Tom"

                System.out.println("Hello Tom");



            case Person(_, _) ->                // для всех остальных Person

                System.out.println("Hello");



            case null -> {}   // если null, ничего не выводим

        }

    }

}
```

ветвь с `when pName == "Tom"` выбирается только для тех `Person`, у которых компонент `name` равен `"Tom"`. следующая ветвь `Person(_, _)` покрывает остальные записи. метка `case null` покрывает нулевую ссылку и ничего не печатает: пустой блок оставляют, чтобы селектор `null` не приводил к `NullPointerException`.

### вложенные шаблоны

шаблоны вкладываются друг в друга. компонент составного типа разбирается своим шаблоном прямо в шаблоне внешней записи:

```java


public class Program{

      

    public static void main(String[] args) {

             

        Person tom = new Person("Tom", 41);

        Company mycorp = new Company("MyCorp", tom);



        if(mycorp instanceof Company(_, Person(var name, _))){

            System.out.println("CEO: " + name);

        }

    }

}

record Person(String name, int age){}

record Company(String name, Person ceo){}
```

второе поле записи `Company` имеет тип `Person`. выражение `mycorp instanceof Company(_, Person(var name, _))` отбрасывает имя компании, требует, чтобы директор был записью `Person`, и связывает компонент `name` этой записи с переменной `name`. возраст директора безымянным шаблоном отбрасывается. если поле `ceo` равно `null`, вложенный шаблон `Person(...)` не совпадает, и тело `if` не выполняется.

тот же разбор в `switch`:

```java


public class Program{

      

    public static void main(String[] args) {

             

        Person tom = new Person("Tom", 41);

        Company mycorp = new Company("MyCorp", tom);



        switch(mycorp){



            case Company(_, Person(var name, _)) ->

                System.out.println("CEO: " + name);



            case null -> {}

            default -> {}

        }

    }

}

record Person(String name, int age){}

record Company(String name, Person ceo){}
```

последние две метки закрывают значения, которые первая ветвь не принимает:

```java


case null -> {}

default -> {}
```

варианты конструкции должны быть исчерпывающими (exhaustive): набор ветвей покрывает все значения типа селектора. для ссылочного селектора в это множество входит и `null`. компания может быть нулевой ссылкой:

```java
Company mycorp = null;
```

этот вариант принимает отдельная метка:

```java


case null -> {}
```

остаётся случай, когда сама компания существует, а вложенный `Person` равен `null`:

```java


Company mycorp = new Company("MyCorp", null);
```

шаблон `Company(_, Person(var name, _))` здесь не совпадает, потому что вложенный шаблон записи требует ненулевой `Person`. такой селектор, как и любой другой ещё не покрытый вариант, принимает ветвь `default`:

```java


default -> {}
```
