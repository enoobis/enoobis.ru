рефлексия даёт программе во время выполнения доступ к структуре типов: к полям, методам, конструкторам, суперклассу и модификаторам. по этим данным строят плагины, анализаторы и другие программы, которым состав типов становится известен только при запуске, в том числе для типов, чей исходник закрыт.

тип, через который читают эту структуру, называется `Class` и лежит в `java.lang`. один объект `Class` соответствует одному загруженному типу в данном загрузчике классов. основные методы:

- `Field[] getFields()`: возвращает массив объектов `Field` для открытых полей данного класса и его суперклассов, включая открытые поля суперинтерфейсов. если таких полей нет, а также если объект `Class` представляет примитивный тип или массив, метод возвращает массив нулевой длины
- `Field[] getDeclaredFields()`: возвращает массив объектов `Field` для полей, объявленных в данном классе. если таких полей нет, а также если объект представляет примитивный тип или массив, метод возвращает массив нулевой длины
- `Method[] getMethods()`: возвращает открытые методы в виде объектов `Method`, включая методы, унаследованные от суперклассов и суперинтерфейсов
- `Method[] getDeclaredMethods()`: возвращает все методы данного класса или интерфейса и не включает унаследованные методы
- `Constructor[] getConstructors()`: возвращает массив объектов `Constructor` для всех открытых конструкторов
- `Constructor[] getDeclaredConstructors()`: возвращает массив объектов `Constructor` для всех конструкторов, объявленных непосредственно в этом классе
- `boolean isAnonymousClass()`: возвращает `true`, если тип является анонимным классом
- `boolean isArray()`: возвращает `true`, если тип представляет массив
- `boolean isPrimitive()`: возвращает `true`, если тип является примитивным
- `boolean isInterface()`: возвращает `true`, если объект представляет интерфейс
- `boolean isEnum()`: возвращает `true`, если объект представляет перечисление
- `boolean isRecord()`: возвращает `true`, если объект представляет класс record. такие классы входят в язык с java 16
- `boolean isInstance(Object obj)`: возвращает `true`, если объект-параметр является экземпляром этого типа. проверка совпадает по смыслу с оператором `instanceof`, для ссылки `null` результат `false`
- `boolean isSealed()`: возвращает `true`, если класс объявлен с модификатором `sealed`. запечатанные классы входят в язык с java 17
- `Class getSuperclass()`: возвращает суперкласс текущего типа. для `Object`, для интерфейса, для примитива и для `void` метод возвращает `null`
- `RecordComponent[] getRecordComponents()`: возвращает массив объектов `RecordComponent`, которые описывают компоненты record, или `null`, если объект не представляет класс record
- `String getPackageName()`: возвращает имя пакета, в котором лежит тип. если тип является массивом, возвращается пакет типа элемента. если тип примитивный, возвращается `java.lang`

конструкторы в java не наследуются. поэтому `getConstructors` и `getDeclaredConstructors` различаются модификатором доступа, а состав объявлений берётся из одного и того же класса. у полей и методов пара `get*` и `getDeclared*` различается ещё и наследованием: первый набор включает открытых предков, второй ограничен объявлениями самого класса и сохраняет закрытые члены.

## получение класса

исследование типа начинается с объекта `Class`, который этому типу соответствует. получить его можно тремя способами:

- метод `getClass()` класса `Object`, а вместе с ним и у остальных ссылочных типов, возвращает объект `Class` для динамического типа экземпляра
- статический метод `Class.forName()` принимает бинарное имя типа с учётом пакета и возвращает объект `Class`, который представляет этот тип
- литерал класса, запись `.class` у имени типа, возвращает объект `Class` и не требует экземпляра

### метод getclass

прямой способ при уже созданном экземпляре: метод `getClass()`. он объявлен в `Object` и есть у всех ссылочных типов java:

```java


public class Program{

      

    public static void main(String[] args) {

             

        Person tom = new Person();

        Class personClass = tom.getClass();

        System.out.println(personClass);    // class Person

    }

}

class Person{ }
```

у экземпляра `Person` берётся объект `Class`. консоль печатает строку `class Person`: метод `toString` у `Class` ставит перед бинарным именем слово `class` для класса и слово `interface` для интерфейса.

если тип расположен в пакете, печатается полное бинарное имя. для строки:

```java


public class Program{

      

    public static void main(String[] args) {



        String text = "";

        System.out.println(text.getClass());    // class java.lang.String

    }

}
```

у объекта `String` полное имя класса `java.lang.String`.

`getClass` возвращает класс самого объекта, то есть динамический тип. статический тип переменной, через которую на объект ссылаются, на результат не влияет. в примерах выше оба типа совпадают: переменная и экземпляр имеют один класс.

### метод forname

статический метод `Class.forName()` принимает бинарное имя типа с учётом пакета и возвращает объект `Class` этого типа. у класса из безымянного пакета бинарное имя совпадает с простым. у класса из пакета сегменты разделяются точками:

```java


public class Program{

      

    public static void main(String[] args) {

        

        try{



            Class personClass = Class.forName("Person");

            System.out.println(personClass);    // class Person



            Class strClass = Class.forName("java.lang.String");

            System.out.println(strClass);    // class java.lang.String

        }

        catch(ClassNotFoundException ex){



            System.out.println("Class not found");

        }

    }

}

class Person{ }
```

если виртуальная машина не находит класс по переданному имени, метод выбрасывает проверяемое исключение `ClassNotFoundException`. вызов поэтому помещают в обработчик этого исключения. одноаргументная форма `forName` загружает класс определяющим загрузчиком вызывающего класса и инициализирует загруженный класс: выполняются статические инициализаторы. литерал `.class` тоже разрешает тип, но инициализацию класса сам по себе не запускает.

### литерал class

литерал `.class` пишется у имени типа и возвращает объект `Class` этого типа. это конструкция языка, экземпляр для неё не нужен. тот же литерал есть у примитивных типов, например `int.class`, и у типа `void`:

```java


public class Program{

      

    public static void main(String[] args) {

        

        Class personClass = Person.class;

        System.out.println(personClass);    // class Person



        Class strClass = String.class;

        System.out.println(strClass);    // class java.lang.String

    }

}

class Person{ }
```

в примере литерал даёт объект `Class` и для `Person`, и для `String`, с тем же текстовым видом, что и `getClass` с `forName`. различие трёх способов в моменте получения: `getClass` требует экземпляр и сообщает динамический тип, `forName` загружает класс по строке во время выполнения и может не найти его, литерал `.class` связывается с типом, имя которого записано в исходнике.
