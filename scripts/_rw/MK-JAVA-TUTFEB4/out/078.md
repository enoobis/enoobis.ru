### запись файлов и класс `FileOutputStream`

класс `FileOutputStream` пишет байты в файл. он наследует `OutputStream` и поэтому получает все его операции записи, сброса и закрытия.

файл для записи задается конструктором. у класса несколько конструкторов:

```java


FileOutputStream(String filePath)

FileOutputStream(File fileObj)

FileOutputStream(String filePath, boolean append)

FileOutputStream(File fileObj, boolean append)
```
файл передается либо строковым путем, либо объектом `File`. второй параметр append выбирает режим. при `true` новые байты дописываются в конец, прежнее содержимое сохраняется. при `false` файл усекается до нуля и запись идет с начала. конструкторы с одним аргументом соответствуют append, равному `false`.

если файла по этому пути нет, он создается при открытии. если нет каталога, в котором файл должен лежать, конструктор выбрасывает `FileNotFoundException`.

запись строки в файл:

```java


import java.io.*;



public class Program {

 

    public static void main(String[] args) {

         

        String text = "Hello world!"; // строка для записи

        try(FileOutputStream fos=new FileOutputStream("notes.txt"))

        {

            // перевод строки в байты

            byte[] buffer = text.getBytes();

             

            fos.write(buffer, 0, buffer.length);

			System.out.println("The file has been written");

        }

        catch(IOException ex){

             

            System.out.println(ex.getMessage());

        }

    }

}
```
конструктор получает путь `notes.txt`. строки в байтовом потоке сами по себе нет, поэтому текст сначала переводится в массив байтов методом `getBytes` без явной кодировки: берется кодировка платформы по умолчанию. для строки `Hello world!` все символы лежат в ascii, и байты совпадают с их кодами при любой распространенной кодировке. `write(buffer, 0, buffer.length)` записывает массив целиком.

закрытие файла и освобождение дескриптора здесь не вызываются вручную. объект создается в заголовке `try`: это try-with-resources. при выходе из блока, в том числе из-за исключения, у ресурса вызывается `close`. ветка `catch` обрабатывает `IOException`, в том числе `FileNotFoundException`, который из нее наследует.

весь массив писать не обязательно. перегрузка `write(int)` записывает один байт, младшие 8 бит аргумента:

```java


fos.write(buffer[0]); // запись первого байта
```
### чтение файлов и класс `FileInputStream`

чтение из файла делает класс `FileInputStream`. он наследует `InputStream` и реализует его методы чтения, пропуска и закрытия.

объект создается одним из конструкторов. чаще всего достаточно варианта, который принимает путь к файлу:

```java


FileInputStream(String fileName) throws FileNotFoundException
```
если файл открыть нельзя, например по указанному пути его нет, конструктор выбрасывает `FileNotFoundException`.

чтение ранее записанного файла и вывод на консоль:

```java


import java.io.*;



public class Program {

 

    public static void main(String[] args) {



		try(FileInputStream fin=new FileInputStream("notes.txt"))

        {    

            int i;

            while((i=fin.read())!=-1){

             

                System.out.print((char)i);

            }   

        }

        catch(IOException ex){

             

            System.out.println(ex.getMessage());

        } 

    }

}
```
каждый байт читается в переменную `i`:

```java
while((i=fin.read())!=-1){
```
когда данных больше нет, `read` возвращает -1, и цикл останавливается. переменная имеет тип `int`, поэтому признак конца не путается с байтом 255.

прочитанный байт приводится к `char` и печатается. для `Hello world!` коды лежат в диапазоне ascii, и приведение дает те же символы. для байта вне этого диапазона `(char)` не декодирует utf-8: он просто берет число байта как код символа. текст с другой кодировкой этим циклом не разбирается, для текста предназначены `Reader` и `Writer`.

тот же файл можно читать порциями в массив байтов:

```java


import java.io.*;

 

public class Program {

  

    public static void main(String[] args) {

 

        try(FileInputStream fin=new FileInputStream("notes.txt"))

        {

            byte[] buffer = new byte[256];

            System.out.println("File data:");

            

            int count;

            while((count=fin.read(buffer))!=-1){

              

                for(int i=0; i<count;i++){

            

                    System.out.print((char)buffer[i]);

                }

            }   

        }

        catch(IOException ex){

              

            System.out.println(ex.getMessage());

        } 

    }

}
```
`read(byte[])` заполняет массив buffer длиной 256 и возвращает, сколько байтов реально прочитано. файл может быть длиннее 256 байтов, поэтому чтение стоит в цикле и идет до конца потока. когда в этом файле больше нет байтов, метод возвращает -1.

```java
while((count=fin.read(buffer))!=-1){
```
последняя порция часто короче 256 байтов, и хвост массива тогда содержит мусор от прошлой итерации или нули. фактическое число сохраняется в `count`, и на консоль выводится только этот префикс:

```java


for(int i=0; i<count;i++){

            

    System.out.print((char)buffer[i]);

}
```
оба класса вместе копируют один файл в другой:

```java


import java.io.*;

 

public class Program {

 

    public static void main(String[] args) {

         

        try(FileInputStream fin=new FileInputStream("notes.txt");

                FileOutputStream fos=new FileOutputStream("notes_new.txt"))

        {

            byte[] buffer = new byte[256];

            

            int count;

            // считываем буфер

            while((count=fin.read(buffer))!=-1){

              

                // записываем из буфера в файл

                fos.write(buffer, 0, count);

            }

            System.out.println("File has been written");

        }

        catch(IOException ex){

             

            System.out.println(ex.getMessage());

        } 

    } 

}
```
в одном try-with-resources открыты `notes.txt` на чтение и `notes_new.txt` на запись. ресурсы закрываются в порядке, обратном объявлению: сначала поток записи, затем поток чтения. цикл читает до 256 байтов и пишет в выход ровно `count` байтов, с начала буфера. запись всего массива на последней порции дописала бы в копию лишние байты.

`FileInputStream` и `FileOutputStream` предназначены для двоичных данных, то есть для байтов. текстовый файл ими тоже открывают, но кодировку, перевод строки и символы, которые не умещаются в один байт, они не разбирают. для текста подходят классы символьных потоков.
