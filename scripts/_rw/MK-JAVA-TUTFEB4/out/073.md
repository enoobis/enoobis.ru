### `SortedSet`

интерфейс `SortedSet` задает набор, элементы которого хранятся в порядке возрастания. он расширяет `Set`, поэтому элементы по-прежнему уникальны: равные по `equals` и по порядку сортировки не дублируются. методы интерфейса:

- `E first()`: возвращает первый элемент набора, наименьший в текущем порядке

- `E last()`: возвращает последний элемент набора, наибольший в текущем порядке

- `SortedSet<E> headSet(E end)`: возвращает представление с элементами первичного набора, строго меньшими end

- `SortedSet<E> subSet(E start, E end)`: возвращает представление с элементами от start включительно до end исключительно

- `SortedSet<E> tailSet(E start)`: возвращает представление с элементами первичного набора, начиная со start, то есть большими либо равными start

эти методы возвращают представления, а не копии. изменение представления меняет исходный набор, и изменение исходного набора видно через представление.

### `NavigableSet`

интерфейс `NavigableSet` расширяет `SortedSet` и ищет элементы относительно заданного значения. его методы:

- `E ceiling(E obj)`: ищет наименьший элемент e, который больше либо равен obj (`e >= obj`). если такой элемент есть, возвращает его, иначе `null`

- `E floor(E obj)`: ищет наибольший элемент e, который меньше либо равен obj (`e <= obj`). если такой элемент есть, возвращает его, иначе `null`

- `E higher(E obj)`: ищет наименьший элемент e, который строго больше obj (`e > obj`). если такой элемент есть, возвращает его, иначе `null`

- `E lower(E obj)`: ищет наибольший элемент e, который строго меньше obj (`e < obj`). если такой элемент есть, возвращает его, иначе `null`

- `NavigableSet<E> descendingSet()`: возвращает представление того же набора в обратном порядке

- `NavigableSet<E> headSet(E upperBound, boolean incl)`: возвращает представление элементов первичного набора до `upperBound`. при `incl`, равном `true`, элемент `upperBound` входит в представление, иначе граница строгая

- `NavigableSet<E> tailSet(E lowerBound, boolean incl)`: возвращает представление элементов, начиная с `lowerBound`. при `incl`, равном `true`, сам `lowerBound` входит в представление

- `NavigableSet<E> subSet(E lowerBound, boolean lowerIncl, E upperBound, boolean highIncl)`: возвращает представление элементов от `lowerBound` до `upperBound`. флаги `lowerIncl` и `highIncl` включают соответствующую границу при значении `true`

`ceiling` и `floor` замыкают границу, `higher` и `lower` оставляют ее строгой. представления снова смотрят на тот же набор.

### `TreeSet`

обобщенный класс `TreeSet` хранит объекты в дереве в порядке возрастания. он наследует `AbstractSet` и реализует `NavigableSet`, а через него и `SortedSet`. реализация опирается на красно-черное дерево `TreeMap`: элементы набора становятся ключами этого дерева. красно-черное дерево держит высоту логарифмической, поэтому основные операции ограничены `O(log n)`.

вставка в дерево медленнее вставки в хеш-таблицу `HashSet`: у хеш-таблицы среднее время `O(1)`, у дерева всегда порядка `log2(n)` сравнений. зато поиск места для нового элемента все же намного быстрее линейной проверки дубликатов в массиве или в связном списке, где сравнение идет с каждым элементом. если в дереве уже n элементов, для позиции нового элемента нужно в среднем `log2(n)` сравнений. при 1000 элементах это около 10 сравнений, потому что `log2(1000)` близок к 10.

при добавлении `TreeSet` сравнивает объекты. они должны реализовать интерфейс `Comparable`, либо в конструктор передается `Comparator`. если нет ни естественного порядка, ни компаратора, вставка завершается `ClassCastException`. порядок должен быть согласован с `equals`: когда сравнение дает ноль, `equals` тоже должен давать истину. иначе набор нарушает контракт `Set`.

конструкторы `TreeSet`:

- `TreeSet()`: создает пустое дерево с естественным порядком элементов

- `TreeSet(Collection<? extends E> col)`: создает дерево и добавляет все элементы коллекции col

- `TreeSet(SortedSet<E> set)`: создает дерево и добавляет все элементы сортированного набора set. порядок берется у этого набора

- `TreeSet(Comparator<? super E> comparator)`: создает пустое дерево, в котором добавляемые элементы упорядочивает переданный компаратор

`TreeSet` поддерживает обычные операции вставки и удаления и методы навигации:

- `boolean add(E e)`: добавляет указанный элемент в этот набор, если его еще нет

- `boolean addAll(Collection<? extends E> c)`: добавляет все элементы указанной коллекции в этот набор

- `E ceiling(E e)`: возвращает наименьший элемент этого набора, больший или равный заданному, или `null`, если такого элемента нет

- `void clear()`: удаляет все элементы из этого набора

- `Object clone()`: возвращает поверхностную копию данного экземпляра `TreeSet`. элементы не клонируются

- `Comparator<? super E> comparator()`: возвращает компаратор, которым упорядочены элементы, или `null`, если набор использует естественный порядок

- `boolean contains(Object o)`: возвращает `true`, если набор содержит указанный элемент

- `Iterator<E> descendingIterator()`: возвращает итератор по элементам в порядке убывания

- `NavigableSet<E> descendingSet()`: возвращает обратный порядок элементов набора

- `E first()`: возвращает первый, наименьший, элемент набора

- `E floor(E e)`: возвращает наибольший элемент, меньший или равный заданному, или `null`, если такого элемента нет

- `SortedSet<E> headSet(E toElement)`: возвращает представление части набора, элементы которой строго меньше `toElement`

- `NavigableSet<E> headSet(E toElement, boolean inclusive)`: возвращает представление части множества, элементы которой меньше `toElement`, а при inclusive, равном `true`, еще и равны ему

- `E higher(E e)`: возвращает наименьший элемент множества, строго больший заданного, или `null`, если такого элемента нет

- `boolean isEmpty()`: возвращает `true`, если в данном множестве нет элементов

- `Iterator<E> iterator()`: возвращает итератор по элементам в порядке возрастания

- `E last()`: возвращает последний, наибольший, элемент множества

- `E lower(E e)`: возвращает наибольший элемент, строго меньший заданного, или `null`, если такого элемента нет

- `E pollFirst()`: извлекает и удаляет первый, наименьший, элемент или возвращает `null`, если множество пусто

- `E pollLast()`: извлекает и удаляет последний, наибольший, элемент или возвращает `null`, если набор пуст

- `boolean remove(Object o)`: удаляет указанный элемент из набора, если он присутствует

- `int size()`: возвращает количество элементов в дереве

- `NavigableSet<E> subSet(E fromElement, boolean fromInclusive, E toElement, boolean toInclusive)`: возвращает представление части набора в диапазоне от `fromElement` до `toElement`. включение границ задают флаги

- `SortedSet<E> subSet(E fromElement, E toElement)`: возвращает представление части набора от `fromElement` включительно до `toElement` исключительно

- `SortedSet<E> tailSet(E fromElement)`: возвращает представление части набора, элементы которой больше или равны `fromElement`

- `NavigableSet<E> tailSet(E fromElement, boolean inclusive)`: возвращает представление части набора, элементы которой больше `fromElement`, а при inclusive, равном `true`, еще и равны ему

```java


import java.util.TreeSet;

 

public class Program{

      

    public static void main(String[] args) {

          

        TreeSet<String> langs = new TreeSet<String>();

          

        // добавим в список ряд элементов

        langs.add("Java");

        langs.add("JavaScript");

        langs.add("Python");

        langs.add("C++");

        

        System.out.printf("langs size: %d \n", langs.size());



        System.out.println(langs);  // [C++, Java, JavaScript, Python]

         

        // удаление элемента

        langs.remove("JavaScript");

        System.out.println(langs);  // [C++, Java, Python]

    }

}
```
объекты сравниваются при вставке и сразу занимают место по возрастанию. `String` реализует `Comparable`, его естественный порядок лексикографический, по кодам utf-16. поэтому печать дает отсортированный набор, а не порядок вызовов `add`:

```bash


langs size: 4 

[C++, Java, JavaScript, Python]

[C++, Java, Python]
```
`C++` оказывается раньше `Java`, потому что код символа `C` меньше кода `J`. `Java` короче `JavaScript` и совпадает с его префиксом, поэтому идет раньше. удаление `JavaScript` сохраняет порядок оставшихся элементов.

`TreeSet` реализует `NavigableSet` и через него `SortedSet`, так что к дереву применимы методы взятия концов, диапазонов и соседей:

```java


import java.util.TreeSet;

import java.util.SortedSet;

import java.util.NavigableSet;

 

public class Program{

      

    public static void main(String[] args) {

          

        TreeSet<String> langs = new TreeSet<String>();

          

        // добавим в список ряд элементов

        langs.add("Java");

        langs.add("JavaScript");

        langs.add("Python");

        langs.add("C#");

        langs.add("C++");

        langs.add("Go");

        

        // сначала выводим все

        System.out.println(langs);      // [C#, C++, Go, Java, JavaScript, Python]



        // получим первый - самый меньший элемент

        System.out.println(langs.first());      // C#



        // получим последний - самый больший элемент

        System.out.println(langs.last());       // Python



        // получим поднабор от одного элемента до другого

        SortedSet<String> set = langs.subSet("Go", "Python");

        System.out.println(set);                // [Go, Java, JavaScript]



        // элемент из набора, который идет перед JavaScript ("больше" JavaScript)

        String greater = langs.higher("JavaScript");    // Python

        System.out.println(greater);



        // элемент из набора, который идет перед Go ("меньше" Go)

        String lower = langs.lower("Go");

        System.out.println(lower);          // C++



        // возвращаем набор элементов, которые идут перед Go

        SortedSet<String> goHead=langs.headSet("Go");

        System.out.println(goHead);       // [C#, C++]



        // возвращаем набор элементов, которые идут начиная с JavaScript

        SortedSet<String> jsTail =langs.tailSet("JavaScript");  

        System.out.println(jsTail);     // [JavaScript, Python]



        // возвращаем набор в обратном порядке

        NavigableSet<String> reversedSet = langs.descendingSet();

        System.out.println(reversedSet);     // [Python, JavaScript, Java, Go, C++, C#]

    }

}
```
`first` возвращает наименьший элемент. в этом наборе это `C#`. момент вставки на результат не влияет. `last` возвращает наибольший, `Python`. символ `#` имеет меньший код, чем `+`, поэтому `C#` стоит перед `C++`.

`subSet("Go", "Python")` берет полуинтервал: `Go` входит, `Python` нет. в представлении остаются `Go`, `Java`, `JavaScript`.

`higher("JavaScript")` дает ближайший строго больший элемент, `Python`. `lower("Go")` дает ближайший строго меньший, `C++`.

`headSet("Go")` включает все, что строго меньше `Go`: `C#` и `C++`. `tailSet("JavaScript")` начинается с самой границы и идет до конца: `JavaScript`, `Python`.

`descendingSet` есть представление в обратном порядке: от `Python` к `C#`. это не копия, а тот же набор, просматриваемый с другого конца.
