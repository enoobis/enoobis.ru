классы `DataOutputStream` и `DataInputStream` записывают и читают значения примитивных типов в двоичном виде. раскладка фиксирована протоколом `DataOutput`: многобайтовые числа идут от старшего байта к младшему, big-endian, одинаково на любой платформе. текстового представления чисел в этом потоке нет.

### запись данных и `DataOutputStream`

`DataOutputStream` представляет поток вывода для примитивных типов: `int`, `double` и остальных. каждому типу соответствует свой метод. класс принимает в конструкторе любой `OutputStream` и дописывает к нему кодирование значений, само открытие файла или сокета остаётся на вложенном потоке.

- `writeBoolean(boolean v)`: записывает в поток однобайтовое значение `boolean`
- `writeByte(int v)`: записывает в поток 1 байт, младшие 8 бит целочисленного значения
- `writeChar(int v)`: записывает 2-байтовое значение `char`
- `writeDouble(double v)`: записывает в поток 8-байтовое значение `double`
- `writeFloat(float v)`: записывает в поток 4-байтовое значение `float`
- `writeInt(int v)`: записывает в поток целочисленное значение `int`, 4 байта
- `writeLong(long v)`: записывает в поток значение `long`, 8 байт
- `writeShort(int v)`: записывает в поток значение `short`, 2 байта
- `writeUTF(String str)`: записывает в поток строку в кодировке utf-8

у `writeUTF` кодировка модифицированная. сначала в поток пишутся два байта беззнаковой длины, тем же способом, что и `writeShort`, затем байты символов. длина считается в байтах представления, а не в числе символов `String`. сырой последовательности utf-8 без префикса длины метод не пишет, и парный `readUTF` длину из этих двух байтов и читает.

### считывание данных и `DataInputStream`

`DataInputStream` выполняет обратное действие: читает из потока значения примитивных типов. для каждого типа есть свой метод чтения. порядок и ширина чтения обязаны совпасть с порядком и шириной записи, потому что в потоке нет имён полей и меток типов. сдвиг на один байт делает все последующие значения нечитаемыми в исходном смысле.

- `boolean readBoolean()`: считывает из потока однобайтовое значение `boolean`
- `byte readByte()`: считывает из потока 1 байт
- `char readChar()`: считывает из потока значение `char`
- `double readDouble()`: считывает из потока 8-байтовое значение `double`
- `float readFloat()`: считывает из потока 4-байтовое значение `float`
- `int readInt()`: считывает из потока целочисленное значение `int`
- `long readLong()`: считывает из потока значение `long`
- `short readShort()`: считывает значение `short`
- `String readUTF()`: считывает из потока строку в кодировке utf-8
- `int skipBytes(int n)`: пропускает при чтении из потока `n` байтов

`skipBytes` может пропустить меньше запрошенного, если поток кончился раньше. возвращаемое значение это число реально пропущенных байтов. для `DataInputStream` поверх файла конец потока наступает вместе с концом файла.

применение обоих классов:

```java


import java.io.*;



public class Program {

 

    public static void main(String[] args) {

         

        Person tom = new Person("Tom", 34, 1.68, false);

		// запись в файл

        try(DataOutputStream dos = new DataOutputStream(new FileOutputStream("data.bin")))

        {

           // записываем значения

            dos.writeUTF(tom.name);

            dos.writeInt(tom.age);

            dos.writeDouble(tom.height);

            dos.writeBoolean(tom.married);

            System.out.println("File has been written");

        }

        catch(IOException ex){

             

            System.out.println(ex.getMessage());

        }  

         

        // обратное считывание из файла

        try(DataInputStream dos = new DataInputStream(new FileInputStream("data.bin")))

        {

           // записываем значения

            String name = dos.readUTF();

            int age = dos.readInt();

            double height = dos.readDouble();

            boolean married = dos.readBoolean();

            System.out.printf("Name: %s  Age: %d  Height: %f  Married: %b", 

                    name, age, height, married);

        }

        catch(IOException ex){

             

            System.out.println(ex.getMessage());

        }  

    } 

}

 

class Person

{

    public String name;

    public int age;

    public double height;

    public boolean married;

     

    public Person(String n, int a, double h, boolean m)

    {

        this.name=n;

        this.height=h;

        this.age=a;

        this.married=m;

    }

}
```

в файл последовательно записываются поля объекта `Person`: имя, возраст, рост, признак `married`. формат файла задан этим порядком вызовов, а не механизмом сериализации объектов. класс `Person` здесь обычный, с публичными полями, интерфейс `Serializable` ему не нужен.

конструктор `DataOutputStream` принимает поток вывода, сигнатура `DataOutputStream(OutputStream out)`. в примере это `FileOutputStream`, поэтому байты уходят в файл `data.bin`. методы вида `writeUTF()` раскладывают значения в этот бинарный файл. `writeUTF` пишет имя, `writeInt` возраст, `writeDouble` рост, `writeBoolean` флаг. сообщение `File has been written` печатается на консоль и в файл не входит.

затем ранее записанные данные читаются обратно. конструктор `DataInputStream` принимает поток чтения, сигнатура `DataInputStream(InputStream in)`. здесь это `FileInputStream` на тот же `data.bin`. `readUTF`, `readInt`, `readDouble` и `readBoolean` идут в том же порядке, в каком шла запись. `printf` собирает прочитанные значения в одну строку консоли: имя, возраст, рост и флаг.
