основная синтаксическая единица программы на java называется **инструкцией** (statement). инструкция задаёт действие: вызов метода, объявление переменной, присваивание. после инструкции ставится точка с запятой (`;`). этот знак сообщает компилятору, что инструкция закончена. точка с запятой завершает инструкцию.

```java


System.out.println("Hello enoobis.ru!");
```

эта строка вызывает метод `System.out.println`, и тот выводит на консоль строку `Hello enoobis.ru!`. вызов метода сам по себе является инструкцией, поэтому строка заканчивается точкой с запятой.

помимо отдельных инструкций употребляется блок. блок собирает несколько инструкций в одну синтаксическую единицу. он ограничен фигурными скобками, инструкции стоят между открывающей и закрывающей:

```java


{

	System.out.println("Hello!");

	System.out.println("Welcome to Java!");

}
```

в этом блоке две инструкции, каждая печатает свою строку. блок задаёт область видимости: локальная переменная, объявленная внутри скобок, снаружи блока не видна.

### выполнение программы. метод main

java является объектно-ориентированным языком, поэтому программу можно представить как набор классов и объектов, которые вызывают друг друга. в первой главе первое приложение было записано так:

```java


public class Program{ 

     

    public static void main (String args[]){

         

		System.out.println("Hello enoobis.ru!");

    }

}
```

основу программы составляет класс `Program`. объявление начинается с модификатора доступа **public**: тип доступен за пределами пакета, и его можно запустить из командной строки. дальше стоит служебное слово **class** и имя класса. после имени идёт блок, тело класса.

точкой входа программы на java служит метод **main** в классе `Program`. выполнение начинается с него. в приложении, которое запускают как программу, этот метод обязателен. заголовок в той форме, которая использована выше, выглядит так:

```java
public static void main (String args[])
```

при запуске виртуальная машина ищет в главном классе метод `main` с таким заголовком и, найдя его, вызывает. равносильная запись параметра выглядит как `String[] args`: скобки массива могут стоять и у типа, и у имени. средство запуска также принимает вариант с переменным числом аргументов `String... args`. все эти формы обозначают один параметр, массив строк.

в начале заголовка стоит модификатор `public`: метод доступен снаружи класса, в том числе коду запуска, который находится вне пользовательского пакета. `static` означает, что метод принадлежит классу, и машина вызывает его, не создавая объект. `void` означает, что метод не возвращает значение. в скобках записан параметр `String args[]`: массив `args` со значениями типа `String`, то есть строками. через этот массив при запуске в программу передают данные командной строки. элемент `args[0]` содержит первый аргумент после имени класса. в c на месте нулевого аргумента `argv[0]` стоит имя программы.

после заголовка идёт блок метода: набор инструкций, которые выполняются при вызове.

### сокращённые файлы кода и методы main в jdk 25

с jdk 21 в платформе появилась экспериментальная возможность упростить текст программы. в jdk 25 она перестала быть экспериментальной и вошла в язык как обычное средство. имя этой возможности: сокращённые исходные файлы и методы `main` экземпляра (compact source files and instance main methods). суть в том, что код можно записать без объявления класса и с короткой формой `main`. файл `Program.java` с таким текстом:

```java


void main() {

    System.out.println("Hello enoobis.ru!");

}
```

фрагмент короче предыдущего. нет модификатора `public`, нет `static`, нет параметра, нет объявления класса. компилятор помещает метод в неявный класс безымянного пакета, а средство запуска само создаёт экземпляр и вызывает метод. выпуски jdk 21, 22, 23 и 24 принимали такую форму `main` только как предварительную, и при компиляции нужны были дополнительные флаги. для jdk 22 команда выглядела так:

```bash
javac --release 22 --enable-preview Program.java
```

число `22` задаёт номер выпуска и заменяется на `21`, `23` или `24`, если компилируется соответствующим jdk. флаг `--release` фиксирует версию языка, флаг `--enable-preview` включает предварительные средства именно этого выпуска. для запуска тоже требовался `--enable-preview`:

```bash
java --enable-preview Program
```

начиная с jdk 25 дополнительные флаги не нужны ни при компиляции, ни при запуске:

```bash


eugene@Eugene:/workspace/java$ javac Program.java

eugene@Eugene:/workspace/java$ java Program

Hello enoobis.ru!

eugene@Eugene:/workspace/java$
```

метод `main` можно по-прежнему вложить в явный класс. метод при этом остаётся методом экземпляра: модификатора `static` у него нет.

```java


class Program{

    void main() {

        System.out.println("Hello enoobis.ru");

    }

}
```

### комментарии

в тексте программы допустимы комментарии. комментарий объясняет, что делает соседний фрагмент. компилятор комментарии отбрасывает: они не меняют семантику программы и не увеличивают размер файла класса, потому что в байт-код не попадают.

в java два вида комментариев, которые разбираются здесь. однострочный занимает хвост строки после `//`. многострочный заключается между `/*` и `*/` и может занимать несколько строк. документационный комментарий `/** */` устроен так же, как многострочный, но его дополнительно читает утилита javadoc.

```java


/*

	многострочный комментарий

	Объявление нового класса,

	который содержит код программы

*/

public class Program{ 	// начало объявления класса Program

     

	// определение метода main

	public static void main (String args[]){ 	// объявление нового метода

         

		 System.out.println("Hello enoobis.ru!"); 	// вывод строки на консоль

    } 	// конец объявления нового метода

} // конец объявления класса Program
```

в этом файле многострочный комментарий описывает класс целиком, однострочные помечают начало и конец объявлений и смысл вызова `println`. на поток выполнения ни одна из этих пометок не влияет.
