кроме отдельных примитивных типов и классов в java есть тип `enum`, перечисление. перечисление задаёт набор логически связанных констант. объявление начинается со служебного слова `enum`, за которым идёт имя перечисления:

```java


enum имя_перечисления{



    константа_1,

    константа_2,

    ........................

    константа_N,

}
```

после имени в фигурных скобках через запятую перечисляют элементы. пример:

```java


enum DayTime{



    MORNING,

    AFTERNOON,

    EVENING,

    NIGHT

}
```

перечисление `DayTime` имеет четыре значения: `MORNING`, `AFTERNOON`, `EVENING`, `NIGHT`. имена констант произвольны. в java их часто записывают в верхнем регистре. это соглашение именования. компилятор регистр имени не ограничивает.

перечисление вводит новый тип, поэтому переменную этого типа объявляют и используют как переменную класса. каждая константа есть единственный экземпляр этого типа, созданный самим перечислением. перечисление является классом и наследует `java.lang.Enum`.

```java


class Program{

      

    public static void main(String[] args) {



        DayTime current = DayTime.MORNING;

		System.out.println(current);	// MORNING

    }

}

enum DayTime{



    MORNING,

    AFTERNOON,

    EVENING,

    NIGHT

}
```

при использовании константы указывают полное имя с именем перечисления. простое имя константы вне перечисления не видно: константы находятся в области видимости типа `DayTime`.

```java
DayTime current = DayTime.MORNING;
```

при выводе на консоль константа преобразуется в строку. эта строка совпадает с именем константы. для `DayTime.MORNING` получается `"MORNING"`. преобразование выполняет `toString()`, который по умолчанию возвращает то же имя, что и метод `name()`.

### перечисления в конструкциях и выражениях switch

перечисления сочетаются с конструкциями и выражениями `switch`. при сопоставлении с константой имя перечисления не пишут: оно уже зафиксировано типом селектора. компилятор знает полный набор констант. выражение `switch` в примере обязано покрыть все константы, иначе код не компилируется. ветка по умолчанию поэтому не нужна, пока набор разобран целиком.

```java


class Program{

      

    public static void main(String[] args) {



        DayTime current = DayTime.MORNING;

        String message = getMessage(current);

		System.out.println(message);	// Доброе утро



        message = getMessage(DayTime.EVENING);

        System.out.println(message);	// Добрый вечер

    }



    static String getMessage(DayTime dt){



        return switch(dt){

            case MORNING -> "Доброе утро";

            case AFTERNOON -> "Добрый день";

            case EVENING -> "Добрый вечер";

            case NIGHT -> "Доброй ночи";

        };

    }

}

enum DayTime{



    MORNING,

    AFTERNOON,

    EVENING,

    NIGHT

}
```

### перечисления для хранения состояния

перечисление используют в классе как тип состояния. вместо произвольного целого или строки поле хранит одно значение из замкнутого набора, и постороннее состояние в это поле не записать.

```java


class Program{

      

    public static void main(String[] args) {



        Operation sum = new Operation(OpType.ADD, 5, 4);

        System.out.println(sum.execute());	// 9



        Operation sub = new Operation(OpType.SUBTRACT, 5, 4);

        System.out.println(sub.execute());	// 1



        Operation mul = new Operation(OpType.MULTIPLY, 5, 4);

        System.out.println(mul.execute());	// 20

    }

}

enum OpType{



    ADD,

    SUBTRACT,

    MULTIPLY

}

class Operation{

    

    private OpType type;

    private int op1;

    private int op2;



    Operation(OpType type, int op1, int op2){

        this.type = type;

        this.op1 = op1;

        this.op2 = op2;

    }



    int execute(){

        return switch(type){



            case ADD -> op1 + op2;

            case SUBTRACT -> op1 - op2;

            case MULTIPLY -> op1 * op2;

        };

    }

}
```

перечисление `OpType` представляет тип операции. класс `Operation` представляет арифметическую операцию. конструктор устанавливает её тип и два операнда. метод `execute` в зависимости от типа операции выполняет сложение, вычитание или умножение. выбор ветви снова делает выражение `switch` по замкнутому набору констант.

### методы перечислений

у каждого перечисления есть статический метод `values()`. он возвращает массив всех констант перечисления в порядке объявления. метод синтетический: его порождает компилятор, в исходнике перечисления его нет. возвращается копия массива, поэтому перестановка элементов у вызывающего кода не меняет набор констант самого типа.

```java


class Program{

      

    public static void main(String[] args) {



        DayTime[] dts = DayTime.values();

        for(DayTime dt: dts){

            System.out.println(dt);    

        }

    }

}

enum DayTime{



    MORNING,

    AFTERNOON,

    EVENING,

    NIGHT

}
```

консольный вывод:

```bash


MORNING

AFTERNOON

EVENING

NIGHT
```

метод `ordinal()` возвращает порядковый номер константы. нумерация начинается с 0 и совпадает с позицией в объявлении.

```java


class Program{

      

    public static void main(String[] args) {



        var current = DayTime.MORNING;

        System.out.println(current.ordinal());  // 0



        System.out.println(DayTime.AFTERNOON.ordinal());  // 1

    }

}
```

номер из `ordinal()` используют как индекс в таблице сопоставления: константе соответствует элемент массива с тем же порядком.

```java


class Program{

      

    static String[] messages = {"Доброе утро", "Добрый день", "Добрый вечер", "Доброй ночи"};



    public static void main(String[] args) {



        var current = DayTime.EVENING;

        System.out.println(messages[current.ordinal()]);  // Добрый вечер

    }

}

enum DayTime{



    MORNING,

    AFTERNOON,

    EVENING,

    NIGHT

}
```

индекс равен позиции константы в исходнике. если в перечисление вставить новую константу, номера следующих констант сдвинутся, и таблица, завязанная на `ordinal()`, разъедется с именами.

перечисления, как обычные классы, могут определять конструкторы, поля и методы:

```java


class Program{



    public static void main(String[] args) {



        var current = DayTime.EVENING;

        System.out.println(current.getMessage());  // Добрый вечер

    }

}

enum DayTime{



    MORNING ("Доброе утро"), AFTERNOON("Добрый день"), EVENING("Добрый вечер"), NIGHT("Доброй ночи");



    private String message;

	DayTime(String message){

		this.message = message;

	}

	public String getMessage(){ return message;}

}
```

перечисление `DayTime` определяет приватное поле `message` для сообщения, связанного со значением, и возвращает его методом `getMessage`. значение поля передаётся через конструктор в момент объявления константы. объявление константы здесь содержит вызов конструктора со строковым аргументом.

конструктор перечисления по умолчанию имеет модификатор `private`. любой другой модификатор доступа считается ошибкой. создать константу вызовом конструктора можно только внутри самого перечисления. снаружи `new DayTime(...)` запрещён: набор экземпляров замкнут списком констант.

#### определение методов

методы можно определять и для отдельных констант. константа с собственным телом образует анонимный подкласс перечисления и перекрывает его методы. если в перечислении объявлен абстрактный метод, каждая константа обязана дать свою реализацию.

```java


class Program{

      

    public static void main(String[] args) {

          

        Operation op = Operation.SUM;

        System.out.println(op.action(10, 4));   // 14

        op = Operation.MULTIPLY;

        System.out.println(op.action(6, 4));    // 24

    }

}

enum Operation{

    SUM{

        int action(int x, int y){ return x + y;}

    },

    SUBTRACT{

        int action(int x, int y){ return x - y;}

    },

    MULTIPLY{

        int action(int x, int y){ return x * y;}

    };

    abstract int action(int x, int y);

}
```
