В прошлой теме мы рассмотрели, как создавать первую программу с последующим ее запуском в командной строке. Для упрощения разработки мы также можем использовать такие инструменты как IDE или интегрированные среды разработки, которые упрощают и ускоряют написание кода и создание приложений. На данный момент наиболее популярной средой разработки для Java является IntelliJ IDEA от компании JetBrains. Рассмотрим, как использовать данную среду.

Прежде всего загрузим установочный дистрибутив с официального сайта [https://www.jetbrains.com/idea/download](https://www.jetbrains.com/idea/download). По этому адресу можно найти пакеты для Windows, MacOS, Linux:

![установка intellij idea](/uploads/course-lectures/1f489af9e10187b6150fd11e4c770486d924797e.png)

Однако на некоторые регионы может действовать блокировка по географическому принципу. И в этом случае можно загрузить данную среду разработки с репозитория компании на github по адресу [https://github.com/JetBrains/intellij-community/releases](https://github.com/JetBrains/intellij-community/releases). Здесь можно найти готовые сборки под все распространенные системы - Windows, Linux, MacOS и под разные архитектуры - как под x86-64, так и под ARM64

![загрузка intellij idea](/uploads/course-lectures/a50381a335d9fb1a1e9ac90eeb9ff981e4a1a236.png)

На ряде ОС на Linux, например, на Ubuntu, для установки можно использовать пакетный менеджер snap и установить среду с помощью команды:

```bash
sudo snap install intellij-idea-community --classic
```

После установки запустим IntelliJ IDEA и создадим первый проект. Для этого на стартовом экране выберем **New Project**:

![создание проекта в intellij idea](/uploads/course-lectures/7276d789588c005412f416bde9fd2b2b02b9e822.png)

Далее откроется окно создания проекта. В левой части в качестве типа проекта выберем **New Project**.

![создание проекта java в intellij idea](/uploads/course-lectures/7ed49423b6bd937fd227ba6149c3bba4ff77713e.png)

В поле **Name** укажем имя проекта. В моем случае проект будет называться HelloJava.

В поле **Location** можно указать путь к проекту, если не устраивает путь по умолчанию.

Поскольку мы будем работать с языком Java, слева выберем пункт язык **Java**

Кроме того, в поле **JDK** можно указать путь к Java SDK, который будет использоваться в проекте. Как правило, это поле по умолчанию уже содержит путь к JDK, который установлен на локальном компьютере. Если это поле пусто, то его надо установить.

После этого нажмем на кнопку Create. После этого среда создаст и откроет проект.

![первый проект на java в intellij idea](/uploads/course-lectures/29e1fcd6291176d65e54baaa0d3ce3d96ddfd8d8.png)

В левой части мы можем увидеть структуру проекта. Все файлы с исходным кодом помещаются в папку **src**. По умолчанию эта папка пуста, никаких файлов кода у нас в проекте пока нет. Поэтому добавим файл с исходным кодом. Для этого нажмем на папку **src** правой кнопкой мыши и в контекстном меню выберем пункт **New -> Java Class**:

![добавления файла с кодом в проект на java в intellij idea](/uploads/course-lectures/aa1cf514d63cebd8f820b12e934f1829876e3817.png)

После этого нам откроется небольшое окошко, в которое надо ввести имя класса. Пусть класс будет называться **Program**:

![добавления класса в проект на java в intellij idea](/uploads/course-lectures/5114915fa6d1c7e9905555ded7864b99bf65f531.png)

После нажатия на клавишу Enter в папку src будет добавлен новый файл с классом java (в случае выше класс Program). А в центральной части откроется его содержимое - собственно исходный код:

![создание класса на java в intellij idea](/uploads/course-lectures/7df90935acc7058ddfc418d0d32313dac0f1c973.png)

Изменим код класса следующим образом:

```java
public class Program {

    public static void main(String[] args) {

        System.out.println("Hello enoobis.ru!");
    }
}
```

С помощью зеленой стрелки на панели инструментов или через меню **Run -> Run...** запустим проект.

![запуск проекта на java на выполнение в intellij idea](/uploads/course-lectures/69b758340ed899cd6213d6fa5ba0e7057ddb0dc4.png)

И внизу IntelliJ IDEA отобразится окно вывода, где мы можем увидеть результат работы нашей программы.

![выполнение программы на java в intellij idea](/uploads/course-lectures/3301699b1870c6132812e4c3de6f7b8d40d428db.png)
