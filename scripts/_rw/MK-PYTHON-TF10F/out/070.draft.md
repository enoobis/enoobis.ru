бинарные файлы, в отличие от текстовых, хранят информацию как набор байтов и не проходят декодирование в символы. при открытии бинарного файла на чтение или на запись к режиму добавляют флаг `"b"`: вместе с записью (`"w"`) это режим `"wb"`, вместе с чтением (`"r"`) это режим `"rb"`. в текстовом режиме байты перевода строки могут подменяться по правилам платформы, поэтому для копии изображения, архива или другого формата с жёсткой раскладкой байтов нужен именно двоичный режим.

### модуль pickle

для бинарных файлов python предоставляет встроенный модуль `pickle`, который сводит сериализацию объекта к записи и чтению потока байтов. у модуля две основные операции:

- `dump(obj, file)` : записывает объект obj в бинарный файл file

- `load(file)` : считывает данные из бинарного файла в объект

поток `pickle` рассчитан на чтение тем же языком. если аргумент протокола не задан, `dump` использует `pickle.DEFAULT_PROTOCOL`. `load()` исполняет содержимое потока при восстановлении объекта, поэтому данные из недоверенного источника этим модулем не загружают: подделанный поток может запустить произвольный код.
