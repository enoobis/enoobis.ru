функция задаёт блок кода, который выполняет определённую задачу и может вызываться из разных мест программы. в предыдущих лекциях уже встречались функции, в том числе `print()`, выводящая значение на консоль. python предоставляет набор встроенных функций и позволяет определять собственные. формальное определение:

```python
def имя_функции ([параметры]):
    инструкции
```

определение начинается с инструкции `def`: имя функции, круглые скобки с параметрами и двоеточие. параметры в скобках необязательны. со следующей строки идёт тело, то есть инструкции, которые функция выполняет. все они имеют отступ от начала строки.

инструкция `def` исполняется в момент, когда до неё доходит интерпретатор, и связывает имя с объектом функции. это не объявление времени компиляции, как прототип в c: до выполнения `def` имени ещё нет.

простейшая функция:

```python
def say_hello():
    print("Hello")
```

функция называется `say_hello`. параметров у неё нет, тело состоит из одной инструкции и выводит на консоль строку `Hello`.

инструкции тела обязаны иметь отступ от начала определения. пример, где следующая инструкция в функцию уже не входит:

```python
def say_hello():
    print("Hello")


print("Bye")
```

инструкция `print("Bye")` отступа от начала `say_hello` не имеет и в эту функцию не входит. между определением функции верхнего уровня и дальнейшим кодом обычно оставляют две пустые строки. это соглашение оформления, синтаксис его не требует.

вызов записывается именем функции; в скобках передаются значения всех параметров:

```python
имя_функции ([параметры])
```

определение и вызов:

```python
def say_hello():    # определение функции say_hello
    print("Hello")


say_hello()         # вызов функции say_hello
say_hello()
say_hello()
```

функция `say_hello` вызывается три раза подряд. консольный вывод:

```bash
Hello
Hello
Hello
```

сначала выполняется определение, и только потом вызов. если вызвать имя до выполнения соответствующего `def`, поиск имени завершится ошибкой `NameError`.

если тело состоит из одной инструкции, его можно записать на той же строке, что и заголовок:

```python
def say_hello(): print("Hello")

say_hello()
```

так же определяются и вызываются другие функции. несколько функций в одной программе:

```python
def say_hello():
    print("Hello")


def say_goodbye():
    print("Good Bye")


say_hello()
say_goodbye()
```

консольный вывод:

```bash
Hello
Good Bye
```

### локальные функции

одну функцию можно определить внутри другой. вложенную функцию называют локальной: её имя существует только в области видимости той функции, где она определена. пример:

```python
def print_messages():
    # определение локальных функций
    def say_hello(): print("Hello")
    def say_goodbye(): print("Good Bye")
    # вызов локальных функций
    say_hello()
    say_goodbye()

# Вызов функции print_messages
print_messages()

#say_hello() # вне функции print_messages функция say_hello не доступна
```

функции `say_hello()` и `say_goodbye()` определены внутри `print_messages()` и по отношению к ней локальны. вызывать их можно только из `print_messages()`. имя локальной функции живёт в локальном пространстве имён объемлющей функции и в глобальную область не попадает. раскомментированный вызов `say_hello()` вне `print_messages()` завершился бы ошибкой `NameError`.

### организация программы и функция main

в программе может быть много функций. один из способов упорядочить их: собрать вызовы в отдельной функции, обычно с именем `main`, а остальные функции определять рядом. вызов `main` ставится после всех нужных определений:

```python
def main():
    say_hello()
    say_goodbye()

def say_hello():
    print("Hello")

def say_goodbye():
    print("Good Bye")

# Вызов функции main
main()
```
