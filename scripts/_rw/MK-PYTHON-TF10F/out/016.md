функция может принимать параметры. через параметры в функцию передают данные. встроенная `print()` получает выводимое значение именно так.

собственная функция с параметром:

```python
def say_hello(name):
    print(f"Hello, {name}")

say_hello("Tom")
say_hello("Bob")
say_hello("Alice")
```

у `say_hello` есть параметр `name`. при вызове этому параметру передаётся значение. внутри функции параметр используется как обычная локальная переменная: его можно, например, вывести через `print`. в вызове

```python
say_hello("Tom")
```

строка `Tom` связывается с параметром `name`. при выполнении программа печатает:

```bash
Hello, Tom
Hello, Bob
Hello, Alice
```

при вызове значения связываются с параметрами по позиции: первый аргумент попадает в первый параметр, второй во второй. формальный параметр это имя в определении функции, фактический аргумент это значение в точке вызова. функция с несколькими параметрами:

```python
def print_person(name, age):
    print(f"Name: {name}")
    print(f"Age: {age}")


print_person("Tom", 37)
```

функция `print_person` принимает два параметра: `name` и `age`. вызов:

```python
print_person("Tom", 37)
```

первое значение, строка `Tom`, передаётся первому параметру `name`. второе значение, число 37, передаётся второму параметру `age`. внутри функции значения параметров выводятся на консоль:

```bash
Name: Tom
Age: 37
```

### значения по умолчанию

часть параметров можно сделать необязательными, указав при определении значение по умолчанию. выражение такого значения вычисляется один раз, в момент выполнения `def`, и затем переиспользуется в тех вызовах, где аргумент опущен. пример:

```python
def say_hello(name="Tom"):
    print(f"Hello, {name}")


say_hello()         # здесь параметр name будет иметь значение "Tom"
say_hello("Bob")    # здесь name = "Bob"
```

параметр `name` необязателен. если при вызове значение для него не передано, берётся значение по умолчанию, строка `Tom`. консольный вывод:

```bash
Hello, Tom
Hello, Bob
```

если параметров несколько, параметры со значением по умолчанию записывают после параметров без него. иначе вызов по позиции не смог бы однозначно решить, какой аргумент какому параметру соответствует. пример:

```python
def print_person(name, age = 18):
    print(f"Name: {name}  Age: {age}")


print_person("Bob")
print_person("Tom", 37)
```

параметр `age` необязателен и по умолчанию равен 18. перед ним стоит обязательный параметр `name`. при вызове значение `age` можно не передавать, а значение `name` передать необходимо.

все параметры функции могут быть необязательными:

```python
def print_person(name = "Tom", age = 18):
    print(f"Name: {name}  Age: {age}")


print_person()              # Name: Tom  Age: 18
print_person("Bob")         # Name: Bob  Age: 18
print_person("Sam", 37)     # Name: Sam  Age: 37
```

### передача значений параметрам по имени. именованные параметры

в примерах выше аргументы связываются с параметрами по позиции. то же значение можно передать по имени: в вызове указывается имя параметра и ему присваивается аргумент. позиционные аргументы при этом записывают раньше именованных. форма вызова:

```python
def print_person(name, age):
    print(f"Name: {name}  Age: {age}")


print_person(age = 22, name = "Tom")
```

здесь значения параметров `age` и `name` передаются по имени. параметр `name` стоит в определении первым, но вызов `print_person(age = 22, name = "Tom")` всё равно передаёт число 22 параметру `age`, а строку `Tom` параметру `name`. порядок именованных аргументов на связывание не влияет.

символ `*` в списке параметров отделяет параметры, которым значение передаётся только по имени. все параметры справа от `*` получают аргументы только по имени. попытка передать их позицией завершается ошибкой `TypeError`:

```python
def print_person(name, *,  age, company):
    print(f"Name: {name}  Age: {age}  Company: {company}")


print_person("Bob", age = 41, company ="Microsoft")    # Name: Bob  Age: 41  company: Microsoft
```

параметры `age` и `company` здесь только именованные. если поставить `*` перед всем списком, только именованными становятся все параметры:

```python
def print_person(*,  name, age, company):
    print(f"Name: {name}  Age: {age}  Company: {company}")
```

параметры, которым значение передаётся только по позиции, то есть позиционные параметры, отмечаются символом `/`. все параметры слева от `/` получают аргументы только по позиции. передача такого параметра по имени завершается ошибкой `TypeError`. конструкция `/` входит в язык начиная с python 3.8:

```python
def print_person(name, /, age, company="Microsoft"):
    print(f"Name: {name}  Age: {age}  Company: {company}")


print_person("Tom", company="JetBrains", age = 24)     # Name: Tom  Age: 24  company: JetBrains
print_person("Bob", 41)                 # Name: Bob  Age: 41  company: Microsoft
```

параметр `name` здесь позиционный. в одной функции можно сочетать позиционные и только именованные параметры:

```python
def print_person(name, /,  age = 18, *, company):
    print(f"Name: {name}  Age: {age}  Company: {company}")


print_person("Sam", company ="Google")               # Name: Sam  Age: 18  company: Google
print_person("Tom", 37, company ="JetBrains")        # Name: Tom  Age: 37  company: JetBrains
print_person("Bob", company ="Microsoft", age = 42)  # Name: Bob  Age: 42  company: Microsoft
```

параметр `name` стоит слева от `/`, поэтому он позиционный и обязательный: значение ему передаётся только по позиции. параметр `company` стоит справа от `*` и потому только именованный. параметр `age` расположен между `/` и `*` и принимает значение и по имени, и по позиции. `company` обязателен, хотя записан после параметра со значением по умолчанию: только именованный параметр позицией не заполняется, поэтому наличие у `age` значения по умолчанию его обязательности не снимает.

### неопределенное количество параметров

звёздочка перед именем параметра собирает заранее неизвестное число позиционных аргументов. это нужно, когда функция должна принять несколько значений, а их количество в точке определения неизвестно. функция суммы:

```python
def sum(*numbers):
    result = 0
    for n in numbers:
        result += n
    print(f"sum = {result}")


sum(1, 2, 3, 4, 5)		# sum = 15
sum(3, 4, 5, 6)			# sum = 18
```

функция `sum` объявляет один параметр `*numbers`. звёздочка означает, что на это место можно передать сколько угодно позиционных значений. внутри функции имя `numbers` ссылается на кортеж этих значений. цикл `for` перебирает кортеж, каждое значение попадает в переменную `n`, и с ним выполняется нужное действие. здесь накапливается сумма. вызов `sum(1, 2, 3, 4, 5)` печатает 15, вызов `sum(3, 4, 5, 6)` печатает 18. имя `sum` в этой области перекрывает встроенную функцию с тем же именем.
