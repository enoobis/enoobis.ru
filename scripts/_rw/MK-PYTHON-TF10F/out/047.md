встроенный модуль `secrets` генерирует криптографически стойкие случайные числа для секретов: токенов аутентификации, токенов безопасности, паролей и других чувствительных данных.

для обычных случайных чисел в python есть модуль `random`. у `secrets` выше криптографическая стойкость: числа берутся из более надёжного источника, энтропии операционной системы (`os.urandom`). у модуля есть отдельные операции для секретов. для паролей, токенов и вообще для случайных строк и чисел, когда нужна криптографическая стойкость, используется именно `secrets`.

функциональность делится на несколько групп: генерация случайных чисел, генерация токенов и смежные операции. ниже разобраны эти группы.

### генерация случайных чисел

для генерации случайных чисел модуль даёт такие функции.

- `secrets.choice(seq)`: возвращает случайно выбранный элемент из непустой последовательности
- `secrets.randbelow(exclusive_upper_bound)`: возвращает случайное целое в полуоткрытом диапазоне `[0, exclusive_upper_bound)`
- `secrets.randbits(k)`: возвращает неотрицательное целое с `k` случайными битами

`secrets.choice()` подходит для пароля из алфавитно-цифровых символов. ниже пароль собирается из 8 таких символов. `string.ascii_letters` задаёт буквы, `string.digits` задаёт цифры, каждый символ выбирается независимо.

```python
import secrets
import string

characters = string.ascii_letters + string.digits
password = "".join(secrets.choice(characters) for i in range(8))

print(password)
```

один из возможных выводов:

```bash
EZg7Xbou
```

более жёсткое требование: восьмизначный пароль содержит как минимум одну строчную букву, как минимум одну заглавную букву, как минимум одну цифру и один знак пунктуации. цикл отвергает заготовки, в которых какого-то из этих классов нет, и возвращает первую подходящую. алфавит здесь включает `string.punctuation`.

```python
import secrets
import string

def generate_password(length=8):
    characters = string.ascii_letters + string.digits + string.punctuation
    while True:
        password = "".join(secrets.choice(characters) for _ in range(length))
        # Гарантируем наличие разных типов символов
        if (any(c.islower() for c in password)
                and any(c.isupper() for c in password)
                and any(c.isdigit() for c in password)
                and any(c in string.punctuation for c in password)):
            return password

print(generate_password())
```

один из возможных выводов:

```bash
y-4!v?SR
```

другой вариант: восьмизначный буквенно-цифровой пароль содержит как минимум одну строчную букву, как минимум одну заглавную букву и как минимум три цифры. пунктуации в алфавите нет, число цифр считается суммой по строке.

```python
import secrets
import string

def generate_password(length=8):
    characters = string.ascii_letters + string.digits
    while True:
        password = "".join(secrets.choice(characters) for _ in range(length))
        # Гарантируем наличие разных типов символов
        if (any(c.islower() for c in password)          # строчная буква
            and any(c.isupper() for c in password)      # заглавная буква
            and sum(c.isdigit() for c in password) >= 3):  # 3 цифры
                return password

print(generate_password())
```

один из возможных выводов:

```bash
X9Y88vdi
```

`secrets.randbelow()` ограничивает целое сверху. граница в диапазон не входит: вызов с аргументом 100 даёт число от 0 до 99.

```python
import secrets

# Генерация случайного числа в диапазоне
secure_number = secrets.randbelow(100)  # от 0 до 99
print(secure_number)
```

`secrets.randbits()` строит число заданной ширины в битах. семь бит дают значение от 0 до 127.

```python
import secrets

number = secrets.randbits(7)    # из 7 битов
print(number)
```

один из возможных выводов:

```bash
115
```

### генерация токенов

для защищённых токенов, которые подходят для сброса пароля, трудноугадываемых адресов url и сходных задач, модуль даёт следующие функции.

- `secrets.token_bytes([nbytes=None])`: возвращает случайную строку байтов из `nbytes` байтов. если `nbytes` равно `None` или аргумент не указан, берётся значение по умолчанию
- `secrets.token_hex([nbytes=None])`: возвращает случайную текстовую строку в шестнадцатеричном виде. в ней `nbytes` случайных байтов, и каждый байт записан двумя шестнадцатеричными цифрами. если `nbytes` равно `None` или аргумент не указан, берётся значение по умолчанию
- `secrets.token_urlsafe([nbytes=None])`: возвращает случайную текстовую строку, пригодную для url, из `nbytes` случайных байтов. текст кодируется в base64, поэтому на один байт в среднем приходится около 1,3 символа. если `nbytes` равно `None` или аргумент не указан, берётся значение по умолчанию

если длина не задана, в текущей стандартной библиотеке по умолчанию берётся 32 байта.

применение функций:

```python
import secrets

# генерацию случайной строки байтов, содержащей nbytes количество байтов. 
token = secrets.token_bytes()
print(token)

#Если значение не указано, используется разумное значение по умолчанию
token = secrets.token_bytes(10)
print(token)

# Создание 16-байтового токена в шестнадцатеричном формате
token = secrets.token_hex(16)
print(token)

# Создание URL-безопасного токена
url_token = secrets.token_urlsafe(16)
print(url_token)
```

первый вызов `token_bytes()` не передаёт длину и получает значение по умолчанию. второй явно запрашивает 10 байтов. `token_hex(16)` строит шестнадцатеричную запись 16 байтов, то есть 32 шестнадцатеричные цифры. `token_urlsafe(16)` строит url-пригодную строку из 16 случайных байтов.
