наследование строит новый класс на основе уже существующего. подкласс получает публичные атрибуты и методы суперкласса и может добавить собственные. вместе с инкапсуляцией наследование составляет основание объектно-ориентированного программирования.

в этом отношении различают подкласс и суперкласс. подкласс наследует у суперкласса все публичные атрибуты и методы. суперкласс называют также базовым классом (base class) или родительским (parent class), подкласс называют производным (derived class) или дочерним (child class).

синтаксис наследования выглядит так:

```python


class подкласс (суперкласс):

	методы_подкласса
```

после имени класса в скобках указан суперкласс. в теле записываются методы подкласса.

класс `Person` представляет человека:

```python


class Person:



    def __init__(self, name):

        self.__name = name   # имя человека



    @property

    def name(self):

        return self.__name

    

    def display_info(self):

        print(f"Name: {self.__name} ")
```

конструктор сохраняет имя в закрытом атрибуте `__name`. снаружи имя читается через свойство `name`. метод `display_info` печатает это имя.

класс работника, который работает на предприятии, можно описать заново, отдельно от `Person`. таким классом будет `Employee`:

```python


class Employee:



    def __init__(self, name):

        self.__name = name  # имя работника



    @property

    def name(self):

        return self.__name



    def display_info(self):

        print(f"Name: {self.__name} ")



    def work(self):

        print(f"{self.name} works")
```

у `Employee` те же атрибуты и методы, что и у `Person`: работник является человеком. к повторённому коду добавляется только метод `work`, остальной текст повторяет `Person`. чтобы одна и та же реализация не копировалась во второй класс, здесь применяется наследование. общая часть остаётся в `Person`, а `Employee` описывает только добавленный метод.

класс `Employee` наследуется от класса `Person`:

```python


class Person:



    def __init__(self, name):

        self.__name = name   # имя человека



    @property

    def name(self):

        return self.__name



    def display_info(self):

        print(f"Name: {self.__name} ")





class Employee(Person):



    def work(self):

        print(f"{self.name} works")





tom = Employee("Tom")

print(tom.name)     # Tom

tom.display_info()  # Name: Tom 

tom.work()          # Tom works
```

`Employee` полностью перенимает поведение `Person` и добавляет метод `work()`. при создании экземпляра `Employee` используется конструктор, унаследованный от `Person`: собственный `__init__` подкласс не объявляет.

```python
tom = Employee("Tom")
```

вызов `Employee("Tom")` находит `Person.__init__` по порядку разрешения методов и передаёт ему имя. далее доступны унаследованные атрибуты, свойства и методы:

```python


print(tom.name)     # Tom

tom.display_info()  # Name: Tom
```

закрытые атрибуты базового класса, в том числе `__name`, для `Employee` под исходным именем недоступны. в методе `work` обращение к приватному атрибуту `self.__name` завершается ошибкой:

```python


def work(self):

    print(f"{self.__name} works")   # ! Ошибка
```

причина в подстановке имён. идентификатор с двумя подчёркиваниями в начале переписывается по классу, в теле которого он записан. в теле `Employee` имя `__name` становится `_Employee__name`. атрибут, созданный в `Person`, хранится как `_Person__name`. это разные имена, поэтому чтение `self.__name` внутри `Employee` до атрибута базового класса не доходит. публичное свойство `name` при этом вызывается: оно объявлено в `Person` под именем без подстановки, и поиск метода идёт по этому имени.

### множественное наследование

python поддерживает множественное наследование: один класс может наследоваться от нескольких классов сразу.

```python


#  класс работника

class Employee:

    def work(self):

        print("Employee works")





#  класс студента

class Student:

    def study(self):

        print("Student studies")





class WorkingStudent(Employee, Student):        # Наследование от классов Employee и Student

    pass





# класс работающего студента

tom = WorkingStudent()

tom.work()      # Employee works

tom.study()     # Student studies
```

класс `Employee` представляет сотрудника фирмы, класс `Student` представляет студента. класс `WorkingStudent` представляет работающего студента и никакого собственного поведения не задаёт, поэтому в теле стоит оператор `pass`. `WorkingStudent` наследует методы двух классов, `Employee` и `Student`. у экземпляра этого класса вызываются методы обоих базовых классов.

базовые классы могут быть сложнее и содержать собственное состояние:

```python


class Employee:



    def __init__(self, name):

        self.__name = name



    @property

    def name(self):

        return self.__name



    def work(self):

        print(f"{self.name} works")





class Student:



    def __init__(self, name):

        self.__name = name



    @property

    def name(self):

        return self.__name



    def study(self):

        print(f"{self.name} studies")





class WorkingStudent(Employee, Student):

    pass





tom = WorkingStudent("Tom")

tom.work()      # Tom works

tom.study()     # Tom studies
```

у `Employee` и у `Student` есть конструктор с параметром `name`, свойство `name` и метод действия. экземпляр создаётся вызовом `WorkingStudent("Tom")`. своего `__init__` у `WorkingStudent` нет, поэтому исполняется конструктор того базового класса, который встречается раньше в порядке разрешения методов. в заголовке раньше указан `Employee`, его конструктор записывает имя, и вызовы `work` и `study` печатают `Tom`.

если оба базовых класса содержат методы или атрибуты с одинаковыми именами, выбор реализации определяется порядком базовых классов.

```python


class Employee:

    def do(self):

        print("Employee works")

 

class Student:

    def do(self):

        print("Student studies")

 

 

# class WorkingStudent(Student,Employee):

class WorkingStudent(Employee, Student):

    pass



tom = WorkingStudent()

tom.do()     # ?
```

оба базовых класса, `Employee` и `Student`, определяют метод `do`, и каждый печатает свою строку. список базовых классов в заголовке задаёт реализацию, которую получит наследник `WorkingStudent`. первым в этом списке стоит `Employee`:

```python
class WorkingStudent(Employee, Student)
```

поиск метода `do` идёт по порядку разрешения: сам класс, затем базовые слева направо. первым среди базовых стоит `Employee`, поэтому берётся его реализация `do`.

если очередность классов поменять:

```python
class WorkingStudent(Student,Employee)
```

используется реализация класса `Student`: теперь он стоит в списке базовых раньше `Employee`.

порядок применения поведения базовых классов можно прочитать у самого класса. для этого есть атрибут `__mro__` и метод `mro()`:

```python


print(WorkingStudent.__mro__)

print(WorkingStudent.mro())
```

`mro` означает method resolution order, порядок разрешения методов. атрибут `__mro__` хранит кортеж классов, метод `mro()` возвращает тот же порядок списком. для `WorkingStudent`, объявленного от `Employee` и `Student`, последовательность начинается с `WorkingStudent`, затем идут `Employee`, `Student` и в конце `object`. python строит этот порядок алгоритмом c3: сохраняется очерёдность базовых классов в заголовке и очерёдность внутри mro каждого из них. атрибут ищется по кортежу слева направо, и срабатывает первое найденное определение.
