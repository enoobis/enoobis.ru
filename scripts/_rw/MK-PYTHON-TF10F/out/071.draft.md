для работы с бинарными файлами в python применяется ещё один модуль, `shelve`. он сохраняет объект в файл под определённым ключом и по этому ключу извлекает ранее сохранённый объект. работа с данными через `shelve` устроена как работа со словарём: ключ служит именем при сохранении и при извлечении. под этой оболочкой значения сериализует `pickle`, а сами ключи лежат в базе `dbm`. ограничения `pickle` сохраняются, в том числе запрет на загрузку файла из недоверенного источника.

параметр `flag` принимает значения:

- `c` : файл открывается для чтения и записи (значение по умолчанию). если файл не существует, он создаётся.

- `r` : файл открывается только для чтения.

- `w` : файл открывается для записи. по контракту модуля этот флаг открывает уже существующую базу и для чтения, и для записи.

- `n` : файл открывается для записи. если файл не существует, он создаётся. если он существует, он перезаписывается.

параметр `protocol` передаётся в `pickle`. значение `None` оставляет протокол по умолчанию. параметр `writeback` разобран ниже, рядом с обновлением изменяемых значений.
