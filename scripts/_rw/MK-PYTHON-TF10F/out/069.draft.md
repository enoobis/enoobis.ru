одним из распространённых файловых форматов, в которых информацию хранят по полям, является формат **csv**. каждая строка файла csv представляет отдельную запись и состоит из столбцов, разделённых запятыми. отсюда имя формата: comma separated values. формат остаётся текстовым, однако для разбора кавычек, запятых внутри поля и перевода строки внутри кавычек в python есть встроенный модуль `csv`. простое деление строки по символу запятой этих правил не выполняет.

в файл записывается двумерный список, то есть таблица. каждая вложенная строка описывает одного пользователя. у пользователя два поля: имя и возраст. сначала в таблице три строки и два столбца, затем отдельным вызовом добавляется четвёртая запись.

при открытии файла на запись третьим аргументом передаётся `newline=""`. пустая строка отключает перевод конца строки силами самого текстового потока и позволяет корректно читать и писать строки независимо от операционной системы. модуль `csv` подставляет собственный разделитель строк (в диалекте excel, который принят по умолчанию, это `\r\n`). если трансляцию конца строки не отключить, на платформах с окончанием `\r\n` к уже записанному разделителю добавляется лишний `\r`.

для записи нужен объект **writer**. его возвращает функция `csv.writer(file)`, куда передаётся открытый файл. сама запись набора строк выполняется методом `writer.writerows(users)`. метод принимает набор строк, в этом примере двумерный список. значение поля, которое не является строкой, при сериализации приводится к строке.

если нужно добавить одну запись в виде одномерного списка, например `["Sam", 31]`, вызывается метод `writer.writerow(user)`.
