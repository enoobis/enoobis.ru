**zip** является широко используемым форматом архивации и сжатия файлов. в python для него есть встроенный модуль `zipfile`. модуль создаёт, читает и записывает zip-файлы, получает их содержимое и добавляет в архив новые файлы. чтение архива, закрытого традиционным шифром zipcrypto, поддерживается: пароль задаётся методом `setpassword()` либо аргументом `pwd` при извлечении и чтении. записать зашифрованный архив модуль не может.

zip-файл в модуле представлен классом `ZipFile`. конструктор:

```python


ZipFile(file, mode='r', compression=ZIP_STORED, allowZip64=True, compresslevel=None, *, strict_timestamps=True, metadata_encoding=None)
```

параметры:

- `file` : путь к zip-файлу

- `mode` : режим открытия файла. принимает следующие значения: `r` применяется для чтения существующего файла

- `w` : применяется для записи нового файла

- `a` : применяется для добавления в файл

- `compression` : тип сжатия файла при записи. принимает значения: `ZIP_STORED` означает архивацию без сжатия (значение по умолчанию)

- `ZIP_DEFLATED` : стандартный тип сжатия при архивации в zip, алгоритм deflate

- `ZIP_BZIP2` : сжатие способом bzip2

- `ZIP_LZMA` : сжатие способом lzma

- `allowZip64` : если равно `True`, zip-файл может быть больше 4 гб. формат zip изначально хранит размеры в 32-битных полях, и без расширения zip64 архив упирается в этот предел

- `compresslevel` : уровень сжатия при записи файла. для типов сжатия `ZIP_STORED` и `ZIP_LZMA` не применяется. для типа `ZIP_DEFLATED` допустимые значения от 0 до 9, а для типа `ZIP_BZIP2` допустимые значения от 1 до 9

- `strict_timestamps` : при значении `False` позволяет работать с zip-файлами, созданными ранее 01.01.1980 и позже 31.12.2107. эти границы задаёт формат времени dos, в котором zip хранит отметку времени

- `metadata_encoding` : применяется для декодирования метаданных zip-файла, например комментариев и имён, если у записи не выставлен признак кодировки utf-8

для работы с файлами класс предоставляет методы:

- `close()` : закрывает zip-файл

- `getinfo()` : возвращает информацию об одном файле из архива в виде объекта `ZipInfo`

- `namelist()` : возвращает список файлов архива

- `infolist()` : возвращает информацию обо всех файлах из архива в виде списка объектов `ZipInfo`

- `open()` : предоставляет доступ к одному из файлов в архиве

- `read()` : считывает файл из архива в набор байтов

- `extract()` : извлекает из архива один файл

- `extractall()` : извлекает все элементы из архива

- `setpassword()` : устанавливает пароль для zip-файла

- `printdir()` : выводит на консоль содержимое архива

### создание и закрытие файла

для создания архивного файла в конструктор `ZipFile` передаётся режим `"w"` или `"a"`:

```python


from zipfile import ZipFile



myzip = ZipFile("enoobis.zip", "w")
```

после выполнения кода в текущей папке создаётся пустой архивный файл `enoobis.zip`. режим `"w"` создаёт архив заново: если файл с таким именем уже был, прежнее содержимое стирается в момент открытия.

после окончания работы с архивом его закрывает метод `close()`:

```python


from zipfile import ZipFile



myzip = ZipFile("enoobis.zip", "w")

myzip.close()
```

`ZipFile` является менеджером контекста и поддерживает выражение `with`. выражение задаёт контекст и автоматически закрывает файл по завершении контекста, в том числе при исключении внутри блока:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "w") as myzip:

    pass
```

### запись файлов в архив

для записи файлов в архив применяется метод `write()`:

```python
write(filename, arcname=None, compress_type=None, compresslevel=None)
```

первый параметр является файлом, который записывается в архив. второй параметр `arcname` задаёт произвольное имя файла внутри архива. по умолчанию берётся само имя файла. третий параметр `compress_type` задаёт тип сжатия, параметр `compresslevel` задаёт уровень сжатия. значения, переданные в `write()`, относятся к одной записи и перекрывают тип сжатия, выбранный в конструкторе, только для этой записи.

запись в архив `enoobis.zip` файла `hello.txt`, который, как предполагается, лежит в той же папке, что и текущий скрипт python:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "w") as myzip:

    myzip.write("hello.txt")
```

при открытии файла в режиме `"w"` архив создаётся заново, поэтому прежнее содержимое к моменту последующих записей уже стёрто. если нужно добавить файлы к существующему архиву, zip-файл открывают в режиме `"a"`:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "a") as myzip:

    myzip.write("hello2.txt")

    myzip.write("forest.jpg")
```

по умолчанию сжатие не применяется, то есть действует `ZIP_STORED`. при необходимости задают способ сжатия и уровень сжатия:

```python


from zipfile import ZipFile, ZIP_DEFLATED



with ZipFile("enoobis.zip", "w", compression=ZIP_DEFLATED, compresslevel=3) as myzip:

    myzip.write("hello.txt")
```

если в архив добавляются файлы с уже занятыми именами, консоль выводит предупреждение. чтобы в архиве не оказалось записей с повторяющимися именами, вторым параметром метода `write` им явно задают уникальное имя внутри архива:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "a") as myzip:

    myzip.write("hello.txt", "hello1.txt")

    myzip.write("hello.txt", "hello2.txt")

    myzip.write("hello.txt", "hello3.txt")
```

один и тот же файл на диске при этом попадает в архив под тремя разными внутренними именами.

### получение информации о файлах в архиве

метод `infolist()` возвращает информацию о файлах в архиве в виде списка. каждый файл представлен объектом `ZipInfo`:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "a") as myzip:

    print(myzip.infolist())
```

класс `ZipInfo` хранит сведения о файле в атрибутах. основные из них:

- `filename` : название файла

- `date_time` : дата и время последнего изменения файла в виде кортежа в формате `(год, месяц, день, час, минута, секунда)`

- `compress_type` : тип сжатия

- `compress_size` : размер после сжатия

- `file_size` : оригинальный размер файла до сжатия

эти данные по каждому файлу в архиве:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "r") as myzip:

    for item in myzip.infolist():

        print(f"File Name: {item.filename} Date: {item.date_time} Size: {item.file_size}")
```

примерный консольный вывод:

```consoletext


File Name: hello.txt  Date: (2022, 11, 23, 20, 21, 34)  Size: 18

File Name: forest.jpg  Date: (2022, 11, 19, 20, 46, 52)  Size: 103956

File Name: hello1.txt  Date: (2022, 11, 23, 20, 21, 34)  Size: 18

File Name: hello2.txt  Date: (2022, 11, 23, 20, 21, 34)  Size: 18

File Name: hello3.txt  Date: (2022, 11, 23, 20, 21, 34)  Size: 18
```

метод `is_dir()` проверяет, является ли элемент в архиве папкой. в zip каталог часто представлен отдельной записью с именем, заканчивающимся на `/`.

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "r") as myzip:

    for item in myzip.infolist():

        if(item.is_dir()):  

            print(f"Папка: {item.filename}")

        else:  

            print(f"Файл: {item.filename}")
```

если нужен только список имён файлов, входящих в архив, применяется метод `namelist()`:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "r") as myzip:

    for item in myzip.namelist():

        print(item)
```

консольный вывод:

```consoletext


hello.txt

forest.jpg

hello1.txt

hello2.txt

hello3.txt
```

метод `getinfo()` возвращает данные по одному архивированному файлу. в метод передаётся имя файла в архиве. результат является объектом `ZipInfo`:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "r") as myzip:

    try:

        hello_file = myzip.getinfo("hello.txt")

        print(hello_file.file_size)

    except KeyError:

        print("Указанный файл отсутствует")
```

если в архиве нет элемента с указанным именем, метод генерирует ошибку `KeyError`.

### извлечение файлов из архива

для извлечения всех файлов из архива применяется метод `extractall()`:

```python
extractall(path=None, members=None, pwd=None)
```

первый параметр задаёт каталог для извлечения. по умолчанию извлечение идёт в текущий каталог. параметр `members` является списком строк, то есть списком названий файлов, которые надо извлечь из архива. третий параметр `pwd` является паролем, если архив закрыт паролем. пароль передаётся байтами.

извлечение всех файлов из архива:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "r") as myzip:

    myzip.extractall()
```

извлечение в определённую папку:

```python
myzip.extractall(path="enoobis")
```

извлечение части файлов:

```python


# извлекаем файлы  "hello.txt", "forest.jpg" в папку "enoobis2"

myzip.extractall(path="enoobis2", members=["hello.txt", "forest.jpg"])
```

для извлечения одного файла применяется метод `extract()`. обязательным параметром в него передаётся имя извлекаемого файла:

```python
myzip.extract("hello.txt")
```

### считывание файла

метод `read()` считывает содержимое файла из архива в набор байтов, не создавая отдельный файл на диске:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "r") as myzip:

    content = myzip.read("hello5.txt")

    print(content)
```

возвращённое значение имеет тип `bytes`. если записи с таким именем нет, возникает `KeyError`, как и у `getinfo()`.

### открытие файла

метод `open()` открывает отдельный файл из архива без извлечения его в каталог на диске:

```python


open(name, mode='r', pwd=None, *, force_zip64=False)
```

первый обязательный параметр является именем файла внутри архива. второй параметр `mode` задаёт режим открытия. параметр `pwd` задаёт пароль, если файл защищён паролем. параметр `force_zip64` при значении `True` позволяет открывать файлы больше 4 гб.

полученный объект удобен и для чтения содержимого, и для записи в член архива. ниже файл открывается и в него записывается содержимое. архив при этом открыт в режиме `"a"`, иначе запись нового члена недоступна:

```python


from zipfile import ZipFile



with ZipFile("enoobis.zip", "a") as myzip:

    # записываем в архив новый файл "hello5.txt"

    with myzip.open("hello5.txt", "w") as hello_file:

        encoded_str = bytes("Python...", "UTF-8")

        hello_file.write(encoded_str)
```

строка перед записью кодируется в байты кодировкой `UTF-8`, потому что поток члена архива в режиме `"w"` принимает байты, а не `str`.
