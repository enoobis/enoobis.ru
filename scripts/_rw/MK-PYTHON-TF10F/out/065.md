guard, или ограничение шаблона, задаёт дополнительное условие, которому должно соответствовать выражение. ограничение пишут сразу после шаблона служебным словом `if`, дальше идёт само условие.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age


def enter(person):
    match person:
        case Person(name=name, age=age) if age < 18:
            print(f"{name}, доступ запрещен")
        case Person(name=name):
            print(f"{name}, добро пожаловать!")


enter(Person("Tom", 37))        # Tom, добро пожаловать!
enter(Person("Sam", 12))        # Sam, доступ запрещен
```

первый шаблон:

```python
case Person(name=name, age=age) if age < 18:
    print(f"{name}, доступ запрещен")
```

соответствует любому объекту `Person`, у которого атрибут `age` меньше 18. часть `if age < 18` и есть ограничение. шаблон сначала сопоставляется как обычно. guard вычисляется только при успехе сопоставления, и в этом выражении уже видны имена, связанные шаблоном. если guard даёт ложь, ветвь пропускается и `match` переходит к следующему `case`. при возрасте меньше 18 печатается отказ в доступе. при возрасте 18 и больше первая ветвь не берётся, выполняется вторая, где атрибут `age` уже не проверяется, и печатается приветствие.

дополнительные ограничения вводят так же. каждое следующее условие стоит в своей ветви, и до неё доходят только те субъекты, которые не взяты предыдущими ветвями.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age


def enter(person):
    match person:
        case Person(name=name, age=age) if age < 18:
            print(f"{name}, доступ запрещен")
        case Person(name=name, age=age) if age < 22:
            print(f"{name}, доступ  ограничен")
        case Person(name=name):
            print(f"{name}, у вас полноценный доступ!")


enter(Person("Tom", 37))        # Tom, у вас полноценный доступ!
enter(Person("Bob", 20))        # Bob, доступ  ограничен
enter(Person("Sam", 12))        # Sam, доступ запрещен
```

возраст меньше 18 попадает в первую ветвь. возраст от 18 до 21 включительно попадает во вторую: условие `age < 22` проверяется после того, как `age < 18` уже дало ложь. возраст 22 и больше доходит до последней ветви, где остаётся проверка типа и связывание `name`. границы задаёт порядок ветвей: более узкое условие стоит выше.

условие ограничения может быть сложным и составным по структуре.

```python
def check_data(data):
    match data:
        case name, age if name == "admin" or age not in range(1, 101):
            print("Некорректные значения")
        case name, age:
            print(f"Данные проверены. Name: {name}  Age: {age}")


check_data(("admin", -45))      # Некорректные значения
check_data(("Tom", 37))         # Данные проверены. Name: Tom  Age: 37
```

функция получает кортеж `data`. оба шаблона в конструкции `match` соответствуют последовательности из двух элементов. скобки у такого шаблона можно опустить, запятая сама делает его шаблоном последовательности. первый шаблон дополнительно применяет ограничение `name == "admin" or age not in range(1, 101)`. по этому условию ветвь берётся, когда первый элемент кортежа имеет значение `"admin"` либо второй элемент находится вне `range(1, 101)`. диапазон содержит целые от 1 до 100 включительно и не включает правый конец, поэтому 101 и отрицательные значения ограничение выполняют. для целого числа проверка вхождения в `range` выполняется за константное время. субъект `("admin", -45)` попадает в первую ветвь по имени. субъект `("Tom", 37)` ограничение не выполняет и попадает во вторую ветвь, где печатаются проверенные имя и возраст.
