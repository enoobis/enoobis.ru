для работы с бинарными файлами в python применяется ещё один модуль, `shelve`. он сохраняет объект в файл под определённым ключом и по этому ключу извлекает ранее сохранённый объект. работа с данными через `shelve` устроена как работа со словарём: ключ служит именем при сохранении и при извлечении. под этой оболочкой значения сериализует `pickle`, а сами ключи лежат в базе `dbm`. ограничения `pickle` сохраняются, в том числе запрет на загрузку файла из недоверенного источника.

для открытия файла модуль `shelve` использует функцию `open()`:

```python
open(путь_к_файлу[, flag="c"[, protocol=None[, writeback=False]]])
```

параметр `flag` принимает значения:

- `c` : файл открывается для чтения и записи (значение по умолчанию). если файл не существует, он создаётся.

- `r` : файл открывается только для чтения.

- `w` : файл открывается для записи. по контракту модуля этот флаг открывает уже существующую базу и для чтения, и для записи.

- `n` : файл открывается для записи. если файл не существует, он создаётся. если он существует, он перезаписывается.

параметр `protocol` передаётся в `pickle`. значение `None` оставляет протокол по умолчанию. параметр `writeback` разобран ниже, рядом с обновлением изменяемых значений.

для закрытия подключения к файлу вызывается метод `close()`:

```python
import shelve
d = shelve.open(filename)
d.close()
```

либо файл открывают оператором `with`. менеджер контекста сам вызывает `close()` при выходе из блока. ниже в файл сохраняются и затем читаются несколько объектов:

```python
import shelve

FILENAME = "states2"
with shelve.open(FILENAME) as states:
    states["London"] = "Great Britain"
    states["Paris"] = "France"
    states["Berlin"] = "Germany"
    states["Madrid"] = "Spain"

with shelve.open(FILENAME) as states:
    print(states["London"])
    print(states["Madrid"])
```

запись данных состоит в установке значения для определённого ключа:

```python
states["London"] = "Great Britain"
```

чтение из файла эквивалентно получению значения по ключу:

```python
print(states["London"])
```

в качестве ключей используются строковые значения. значение иного типа модуль сохраняет через `pickle`. строка `FILENAME` задаёт имя базы, а реальные файлы на диске зависят от выбранной реализации `dbm` (`dbm.gnu`, `dbm.ndbm` или запасной `dbm.dumb`): рядом с именем могут появиться файлы с суффиксами `.dat`, `.dir`, `.bak`. консольный вывод программы:

```bash
Great Britain
Spain
```

### чтение данных

при чтении, если запрашиваемый ключ отсутствует, генерируется исключение `KeyError`. перед получением наличие ключа проверяют оператором `in`:

```python
with shelve.open(FILENAME) as states:
    key = "Brussels"
    if key in states:
        print(states[key])
```

доступен и метод `get()`. первый параметр метода является ключом, по которому следует получить значение, второй является значением по умолчанию и возвращается, если ключ не найден.

```python
with shelve.open(FILENAME) as states:
    state = states.get("Brussels", "Undefined")
    print(state)
```

цикл `for` перебирает все ключи файла. значение по текущему ключу читается отдельным обращением:

```python
with shelve.open(FILENAME) as states:
    for key in states:
        print(key," - ", states[key])
```

метод `keys()` возвращает все ключи из файла, метод `values()` возвращает все значения:

```python
with shelve.open(FILENAME) as states:

    for city in states.keys():
        print(city, end=" ")        # London Paris Berlin Madrid 
    print()
    for country in states.values():
        print(country, end=" ")     # Great Britain France Germany Spain
```

метод `items()` возвращает набор кортежей. каждый кортеж содержит ключ и значение.

```python
with shelve.open(FILENAME) as states:

    for state in states.items():
        print(state)
```

консольный вывод:

```bash
("London", "Great Britain")
("Paris", "France")
("Berlin", "Germany")
("Madrid", "Spain")
```

### обновление данных

для изменения данных по ключу присваивают новое значение. для добавления данных определяют новый ключ:

```python
import shelve

FILENAME = "states2"
with shelve.open(FILENAME) as states:
    states["London"] = "Great Britain"
    states["Paris"] = "France"
    states["Berlin"] = "Germany"
    states["Madrid"] = "Spain"

with shelve.open(FILENAME) as states:

    states["London"] = "United Kingdom"
    states["Brussels"] = "Belgium"
    for key in states:
        print(key, " - ", states[key])
```

если значение является изменяемым объектом, правка его полей на месте в базу сама не попадает. без повторного присваивания по тому же ключу `shelve` не замечает мутацию. параметр `writeback=True` при открытии включает кэш: изменённые объекты записываются обратно при `sync()` или при `close()`.

### удаление данных

для удаления с одновременным получением значения используется метод `pop()`. в него передаётся ключ элемента и значение по умолчанию, если ключ не найден:

```python
with shelve.open(FILENAME) as states:

    state = states.pop("London", "NotFound")
    print(state)
```

для удаления применяется и оператор `del`:

```python
with shelve.open(FILENAME) as states:

    del states["Madrid"] 	# удаляем объект с ключом Madrid
```

для удаления всех элементов используется метод `clear()`:

```python
with shelve.open(FILENAME) as states:

    states.clear()
```
