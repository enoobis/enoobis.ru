### атрибуты класса

кроме атрибутов объектов в классе можно определять атрибуты классов. такие атрибуты задаются переменными уровня класса, в теле класса на одном уровне с методами.

```python
class Person:
     type = "Person"
     description = "Describes a person"


print(Person.type)          # Person
print(Person.description)   # Describes a person

Person.type = "Class Person"
print(Person.type)          # Class Person
```

в классе `Person` определены два атрибута: `type`, который хранит имя класса, и `description`, который хранит описание класса.

для обращения к атрибутам класса используется имя класса, например `Person.type`. как и атрибуты объекта, их можно читать и изменять. присваивание `Person.type` меняет значение в словаре класса, и следующее чтение через имя класса показывает уже новую строку.

подобные атрибуты общие для всех объектов класса:

```python
class Person:
     type = "Person"
     def __init__(self, name):
         self.name = name


tom = Person("Tom")
bob = Person("Bob")
print(tom.type)     # Person
print(bob.type)     # Person

# изменим атрибут класса
Person.type = "Class Person"
print(tom.type)     # Class Person
print(bob.type)     # Class Person
```

чтение `tom.type` не находит атрибут `type` у экземпляра и продолжает поиск в классе `Person`. поэтому `tom` и `bob` получают одно и то же значение. после присваивания `Person.type = "Class Person"` и `tom.type`, и `bob.type` печатают новую строку: атрибут экземпляра не создавался, поиск по-прежнему доходит до класса.

атрибуты класса применяют там, где для всех объектов нужны общие данные.

```python
class Person:
    default_name = "Undefined"

    def __init__(self, name):
        if name:
            self.name = name
        else:
            self.name = Person.default_name


tom = Person("Tom")
bob = Person("")
print(tom.name)  # Tom
print(bob.name)  # Undefined
```

атрибут `default_name` хранит имя по умолчанию. если в конструктор передана пустая строка, условие `if name` ложно, и атрибуту `name` передаётся значение атрибута класса `default_name`. для обращения к атрибуту класса внутри методов применяется имя класса:

```python
self.name = Person.default_name
```

запись `Person.default_name` читает атрибут класса напрямую, даже когда у экземпляра позже появится одноимённый атрибут. чтение через `self` дошло бы до класса только до тех пор, пока экземпляр своего атрибута с этим именем не получил.

#### атрибут класса

атрибут класса и атрибут объекта могут совпадать по имени. если атрибуту объекта значение не задано, при чтении используется значение атрибута класса:

```python
class Person:
    name = "Undefined"

    def print_name(self):
        print(self.name)


tom = Person()
bob = Person()
tom.print_name()    # Undefined
bob.print_name()    # Undefined

bob.name = "Bob"
bob.print_name()    # Bob
tom.print_name()    # Undefined
```

метод `print_name` использует атрибут `name`, обращаясь к нему через `self`. нигде в коде этот атрибут экземпляру не присваивается. на уровне класса атрибут `name` задан, поэтому при первом обращении к `print_name` используется значение атрибута класса:

```python
tom = Person()
bob = Person()
tom.print_name()    # Undefined
bob.print_name()    # Undefined
```

далее атрибут объекта можно установить присваиванием:

```python
bob.name = "Bob"
bob.print_name()    # Bob
tom.print_name()    # Undefined
```

присваивание `bob.name = "Bob"` создаёт атрибут в словаре экземпляра `bob`. поиск имени начинается с экземпляра, поэтому `bob.print_name()` печатает значение объекта и до класса не доходит. второй объект, `tom`, продолжает использовать атрибут класса. если изменить атрибут класса, изменится и значение `tom.name`:

```python
tom = Person()
bob = Person()
tom.print_name()    # Undefined
bob.print_name()    # Undefined

Person.name = "Some Person"     # меняем значение атрибута класса
bob.name = "Bob"                # устанавливаем атрибут объекта
bob.print_name()    # Bob
tom.print_name()    # Some Person
```

присваивание `Person.name = "Some Person"` меняет атрибут класса. у `bob` к этому моменту уже есть собственный атрибут `name`, поэтому печать даёт `Bob`. у `tom` собственного атрибута нет, и `tom.print_name()` даёт новое значение класса, `Some Person`. так устроен поиск атрибута: сначала словарь экземпляра, затем класс объекта, затем базовые классы в порядке mro.

### статические методы

кроме обычных методов класс может определять статические методы. такие методы предваряются аннотацией `@staticmethod` и относятся к классу в целом. статические методы определяют поведение, которое не зависит от конкретного объекта: параметр экземпляра в них не передаётся.

```python
class Person:
    __type = "Person"

    @staticmethod
    def print_type():
        print(Person.__type)


Person.print_type()     # Person - обращение к статическому методу через имя класса

tom = Person()
tom.print_type()     # Person - обращение к статическому методу через имя объекта
```

в классе `Person` определён атрибут класса `__type`, который хранит значение, общее для всего класса: название класса. название атрибута предваряется двумя подчёркиваниями, поэтому атрибут закрытый и защищён от изменения снаружи. внутри тела `Person` имя подменяется на `_Person__type`, и запись по буквальному имени `__type` этот атрибут не затрагивает.

в классе `Person` также определён статический метод `print_type`, который выводит на консоль значение атрибута `__type`. действие этого метода не зависит от конкретного объекта и относится ко всему классу: вне зависимости от объекта на консоль выводится одно и то же значение атрибута `__type`. поэтому метод сделан статическим. обращение `Person.print_type()` идёт через имя класса, обращение `tom.print_type()` идёт через имя объекта. оба вызова выполняют одну и ту же функцию. при вызове через экземпляр объект в аргументы не подставляется: `@staticmethod` оставляет функцию без связывания `self`.
