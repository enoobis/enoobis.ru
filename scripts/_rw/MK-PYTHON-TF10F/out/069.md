одним из распространённых файловых форматов, в которых информацию хранят по полям, является формат **csv**. каждая строка файла csv представляет отдельную запись и состоит из столбцов, разделённых запятыми. отсюда имя формата: comma separated values. формат остаётся текстовым, однако для разбора кавычек, запятых внутри поля и перевода строки внутри кавычек в python есть встроенный модуль `csv`. простое деление строки по символу запятой этих правил не выполняет.

работа модуля на примере:

```python
import csv

FILENAME = "users.csv"

users = [
    ["Tom", 28],
    ["Alice", 23],
    ["Bob", 34]
]

with open(FILENAME, "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerows(users)
	

with open(FILENAME, "a", newline="") as file:
	user = ["Sam", 31]
    writer = csv.writer(file)
    writer.writerow(user)
```

в файл записывается двумерный список, то есть таблица. каждая вложенная строка описывает одного пользователя. у пользователя два поля: имя и возраст. сначала в таблице три строки и два столбца, затем отдельным вызовом добавляется четвёртая запись.

при открытии файла на запись третьим аргументом передаётся `newline=""`. пустая строка отключает перевод конца строки силами самого текстового потока и позволяет корректно читать и писать строки независимо от операционной системы. модуль `csv` подставляет собственный разделитель строк (в диалекте excel, который принят по умолчанию, это `\r\n`). если трансляцию конца строки не отключить, на платформах с окончанием `\r\n` к уже записанному разделителю добавляется лишний `\r`.

для записи нужен объект **writer**. его возвращает функция `csv.writer(file)`, куда передаётся открытый файл. сама запись набора строк выполняется методом `writer.writerows(users)`. метод принимает набор строк, в этом примере двумерный список. значение поля, которое не является строкой, при сериализации приводится к строке.

если нужно добавить одну запись в виде одномерного списка, например `["Sam", 31]`, вызывается метод `writer.writerow(user)`.

после выполнения скрипта в том же каталоге оказывается файл `users.csv` со следующим содержимым:

```python
Tom,28
Alice,23
Bob,34
Sam,31
```

для чтения создаётся объект **reader**:

```python
import csv

FILENAME = "users.csv"

with open(FILENAME, "r", newline="") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row[0], " - ", row[1])
```

полученный reader перебирается в цикле по строкам. элемент строки после разбора всегда имеет тип `str`, даже если в исходном списке на запись лежало число.

```bash
Tom  -  28
Alice  -  23
Bob  -  34
Sam - 31
```

### работа со словарями

в примере выше каждая запись, то есть строка, была отдельным списком, например `["Sam", 31]`. модуль `csv` дополнительно умеет работать со словарями. функция `csv.DictWriter()` возвращает объект writer для записи в файл, функция `csv.DictReader()` возвращает объект reader для чтения. пример:

```python
import csv

FILENAME = "users2.csv"

users = [
    {"name": "Tom", "age": 28},
    {"name": "Alice", "age": 23},
    {"name": "Bob", "age": 34}
]

with open(FILENAME, "w", newline="") as file:
    columns = ["name", "age"]
    writer = csv.DictWriter(file, fieldnames=columns)
    writer.writeheader()
	
    # запись нескольких строк
    writer.writerows(users)
    
    user = {"name" : "Sam", "age": 41}
    # запись одной строки
    writer.writerow(user)

with open(FILENAME, "r", newline="") as file:
    reader = csv.DictReader(file)
    for row in reader:
        print(row["name"], "-", row["age"])
```

запись строк по-прежнему выполняется методами `writerow()` и `writerows()`. теперь каждая строка является отдельным словарём. помимо данных в файл пишутся заголовки столбцов: это делает метод `writeheader()`. набор имён столбцов передаётся в `csv.DictWriter` вторым параметром `fieldnames`. при чтении к полю внутри строки обращаются по имени столбца, например `row["name"]`. если `DictReader` создан без явного списка имён, первую строку файла он принимает за заголовок и дальше отдаёт словари с этими ключами.
