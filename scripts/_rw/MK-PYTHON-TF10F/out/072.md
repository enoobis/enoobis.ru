ряд операций над каталогами и файлами даёт встроенный модуль `os`. в нём много функций, ниже разобраны основные:

- `mkdir()` : создаёт новую папку

- `rmdir()` : удаляет папку

- `rename()` : переименовывает файл

- `remove()` : удаляет файл

### создание и удаление папки

для создания папки применяется функция `mkdir()`. в неё передаётся путь к создаваемой папке. путь может быть относительным, от текущего рабочего каталога процесса, или абсолютным. `mkdir()` создаёт один уровень каталога: промежуточные каталоги в пути уже должны существовать, поэтому в примере сначала создаётся `c://somedir`, и только затем вложенная папка.

```python
import os

# путь относительно текущего скрипта
os.mkdir("hello")
# абсолютный путь
os.mkdir("c://somedir")
os.mkdir("c://somedir/hello")
```

для удаления папки используется функция `rmdir()`. в неё передаётся путь к удаляемой папке. удаляется только пустой каталог: если внутри остаются файлы или вложенные папки, вызов завершается ошибкой операционной системы.

```python
import os

# путь относительно текущего скрипта
os.rmdir("hello")
# абсолютный путь
os.rmdir("c://somedir/hello")
```

### переименование файла

переименование выполняет функция `rename(source, target)`. первый параметр является путём к исходному файлу, второй является новым именем. в обоих параметрах допустимы и абсолютные, и относительные пути. пусть в папке `C://SomeDir/` лежит файл `somefile.txt`. его переименовывают в `hello.txt`:

```python
import os

os.rename("C://SomeDir/somefile.txt", "C://SomeDir/hello.txt")
```

вызов меняет путь в каталоге файловой системы. если целевой путь указывает на другой каталог на том же томе, файл оказывается перенесённым, а не только переименованным в исходной папке.

### удаление файла

удаление файла выполняет функция `remove()`. в неё передаётся путь к файлу. для каталогов эта функция не предназначена, каталог снимают через `rmdir()`.

```python
import os

os.remove("C://SomeDir/hello.txt")
```

### существование файла

попытка открыть файл, которого нет, приводит к исключению `FileNotFoundError`. исключение перехватывают конструкцией `try`...`except`. до открытия наличие пути можно проверить методом `os.path.exists(path)`. в метод передаётся проверяемый путь. проверка и последующее открытие разделены по времени: между ними путь может исчезнуть или появиться, поэтому для самой операции открытия исключение всё равно обрабатывают. в фрагменте ниже используется `os.path`, и модуль `os` импортируют так же, как в предыдущих фрагментах.

```python
filename = input("Введите путь к файлу: ")
if os.path.exists(filename):
    print("Указанный файл существует") 
else:
    print("Файл не существует")
```
