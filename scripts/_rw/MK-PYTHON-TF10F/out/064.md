в pattern matching шаблоном может быть объект класса. шаблон класса проверяет тип уже существующего экземпляра и читает его атрибуты. конструктор при сопоставлении не вызывается, новый экземпляр не создаётся.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age


def print_person(person):
    match person:
        case Person(name="Tom", age=37):
            print("Default Person")
        case Person(name=name, age=37):
            print(f"Name: {name}")
        case Person(name="Tom", age=age):
            print(f"Age: {age}")
        case Person(name=name, age=age):
            print(f"Name: {name}  Age: {age}")


print_person(Person("Tom", 37))  # Default person
print_person(Person("Tom", 22))  # Age: 22
print_person(Person("Sam", 37))  # Name: Sam
print_person(Person("Bob", 41))  # Name: Bob  Age: 41
```

класс `Person` в конструкторе принимает значения атрибутов `self.name` и `self.age`.

функция `print_person` принимает объект, который в успешных вызовах является экземпляром `Person`. `match` сравнивает его с шаблонами. каждый шаблон называет класс и сопоставляет атрибуты с вложенными шаблонами. первый шаблон фиксирует оба атрибута литералами:

```python
case Person(name="Tom", age=37):
    print("Default Person")
```

шаблон подходит экземпляру `Person`, у которого атрибут `name` равен `"Tom"`, а атрибут `age` равен `37`. проверка типа идёт через `isinstance`, поэтому экземпляр подкласса тоже подходит. литералы вложенных шаблонов сравниваются по равенству, а `None`, `True` и `False` по тождеству. отсутствующий атрибут отвергает шаблон, исключение `AttributeError` из сопоставления наружу не выходит.

второй шаблон фиксирует только `age`:

```python
case Person(name=name, age=37):
    print(f"Name: {name}")
```

для успеха `age` должен быть равен `37`. атрибут `name` может быть любым, его значение связывается с именем `name`. запись `name=name` читается как «атрибут слева, шаблон справа». в `print(f"Name: {name}")` печатается уже связанное имя. совпадение двух имён необязательно, справа можно поставить другой идентификатор:

```python
case Person(name=person_name, age=37):      # переменной person_name передается значение атрибута name
    print(f"Name: {person_name}")
```

третий шаблон принимает экземпляр `Person`, у которого `name` равен `"Tom"`. значение `age` связывается с именем `age`:

```python
case Person(name="Tom", age=age):
    print(f"Age: {age}")
```

в последнем шаблоне оба атрибута произвольны и связываются с одноимёнными именами:

```python
case Person(name=name, age=age):
    print(f"Name: {name}  Age: {age}")
```

перечислять все атрибуты не требуется. неназванный атрибут не проверяется. маска `_` закрывает субъекты, которые не подошли к шаблонам класса, в том числе значения чужого типа.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age


def print_person(person):
    match person:
        case Person(name="Tom"):
            print("Default Person")
        case Person(name=person_name):         # получаем только атрибут name
            print(f"Name: {person_name}")
        case _:
            print("Not a Person")


print_person(Person("Tom", 37))  # Default person
print_person(Person("Sam", 37))  # Name: Sam
print_person("Tom")              # Not a Person
```

второй шаблон `Person(name=person_name)` принимает любой экземпляр `Person` и связывает атрибут `name` с именем `person_name`. последняя ветвь обрабатывает значение, которое экземпляром `Person` не является, в примере это строка `"Tom"`.

### передача набора значений

вертикальная черта задаёт набор значений одного атрибута:

```python
def print_person(person):
    match person:
        case Person(name="Tom" | "Tomas" | "Tommy"):
            print("Default Person")
        case Person(name=person_name):         # получаем только атрибут name
            print(f"Name: {person_name}")
        case _:
            print("Not a Person")


print_person(Person("Tom", 37))     # Default person
print_person(Person("Tomas", 37))   # Default person
```

первый шаблон принимает экземпляр `Person`, у которого `name` равен `"Tom"`, `"Tomas"` или `"Tommy"`. атрибут `age` этой ветвью не проверяется.

тем же знаком соединяют целые шаблоны, в том числе шаблоны разных классов:

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age


class Student:
    def __init__(self, name):
        self.name = name


def print_person(person):
    match person:
        case Person(name="Tom") | Student(name="Tomas"):
            print("Default Person/Student")
        case Person(name=name) | Student(name=name):    # получаем только атрибут name
            print(f"Name: {name}")
        case _:
            print("Not a Person or Student")


print_person(Person("Tom", 37))     # Default Person/Student
print_person(Student("Tomas"))      # Default Person/Student


print_person(Person("Bob", 41))     # Name: Bob
print_person(Student("Mike"))       # Name: Mike

print_person("Tom")                 # Not a Person or Student
```

первый шаблон:

```python
case Person(name="Tom") | Student(name="Tomas")
```

принимает экземпляр `Person` с `name`, равным `"Tom"`, и экземпляр `Student` с `name`, равным `"Tomas"`.

второй шаблон `Person(name=name) | Student(name=name)` принимает любой экземпляр `Person` и любой экземпляр `Student`. в обеих альтернативах связано одно и то же имя `name`: у или-шаблона набор захваченных имён во всех альтернативах обязан совпадать.

### позиционные параметры

выше атрибуты названы по имени: `Person(name="Tom", age=37)`. при большом числе однотипных шаблонов повтор имён удлиняет запись. python допускает позиционную форму, если класс задаёт порядок атрибутов.

```python
class Person:
    __match_args__ = ("name", "age")
    def __init__(self, name, age):
        self.name = name
        self.age = age


def print_person(person):
    match person:
        case Person("Tom", 37):
            print("Default Person")
        case Person(person_name, 37):
            print(f"Name: {person_name}")
        case Person("Tom", person_age):
            print(f"Age: {person_age}")
        case Person(person_name, person_age):
            print(f"Name: {person_name}  Age: {person_age}")


print_person(Person("Tom", 37))  # Default person
print_person(Person("Tom", 22))  # Age: 22
print_person(Person("Sam", 37))  # Name: Sam
print_person(Person("Bob", 41))  # Name: Bob  Age: 41
```

в классе `Person` задан атрибут класса:

```python
__match_args__ = ("name", "age")
```

кортеж `__match_args__` сообщает, что в позиционном шаблоне первый вложенный шаблон читает атрибут `name`, второй атрибут `age`. поэтому в `Person("Tom", 37)` имена атрибутов можно не писать: позиция определяет атрибут. без `__match_args__` позиционные вложенные шаблоны поднимают `TypeError`. именованные шаблоны от этого атрибута не зависят. у классов данных кортеж `__match_args__` строится по полям автоматически.

позиционная форма в примере повторяет те же четыре случая, что и именованная: оба значения фиксированы, фиксирован только возраст, фиксировано только имя, оба значения захватываются.
