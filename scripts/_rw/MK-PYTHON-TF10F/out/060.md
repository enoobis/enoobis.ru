начиная с версии 3.10 в языке python есть сопоставление с образцом, pattern matching. pattern matching это применение конструкции `match`: выражение сопоставляется с шаблоном, и если выражение соответствует шаблону, выполняются определённые действия. в этом смысле конструкция `match` близка к конструкции `if`/`elif`/`else`, которая выполняет действия в зависимости от условия. помимо ветвления по условию шаблон извлекает данные из составных типов и применяет действия к различным частям объекта. `match` и `case` являются мягкими ключевыми словами. вне этой конструкции те же имена остаются обычными переменными.

конструкция `match` имеет следующее формальное определение:

```python
match выражение:
    case шаблон_1:
        действие_1
    case шаблон_2:
        действие_2
    ................
    case шаблон_N:
        действие_N
    case _:
        действие_по_умолчанию
```

после ключевого слова `match` идёт сравниваемое выражение, субъект сопоставления. оно вычисляется один раз. затем после двоеточия на последующих строках располагаются ветки `case`. после каждого `case` указывается шаблон, с которым сравнивается выражение из `match`. после шаблона через двоеточие указывается набор выполняемых действий блока `case`.

конструкция `match` последовательно сравнивает выражение с шаблонами из блоков `case`. если шаблон какого-нибудь блока `case` соответствует выражению из `match`, выполняются инструкции этого блока. первая успешная ветка завершает выбор: следующие блоки `case` уже не проверяются и не выполняются.

в качестве шаблонов, с которыми сравниваются выражения, применяются и данные примитивных типов, и последовательности элементов, и объекты классов. ниже в качестве шаблона выступают литералы примитивных типов. в зависимости от языка печатается приветственное сообщение.

```python
def print_hello(language):
    match language:
        case "russian":
            print("Привет")
        case "english":
            print("Hello")
        case "german":
            print("Hallo")


print_hello("english")      # Hello
print_hello("german")       # Hallo
print_hello("russian")      # Привет
```

функция `print_hello` принимает параметр `language`, через который передаётся выбранный язык. в самой функции конструкция `match` сравнивает значение переменной `language`. в блоках `case` определены шаблоны, строки, с которыми сопоставляется переменная `language`.

при вызове `print_hello("english")` параметр `language` равен `english`, поэтому конструкция `match` выбирает следующий блок `case`:

```python
case "english":
    print("Hello")
```

блоки `case` имеют отступы от начала конструкции `match`. инструкции каждого блока `case` имеют отступы от начала данного блока `case`. это то же правило отступов, что и у остальных составных инструкций python. если блок `case` имеет одну инструкцию, её можно поместить на той же строке, что и оператор `case`.

```python
def print_hello(language):
    match language:
        case "russian": print("Привет")
        case "english": print("Hello")
        case "german": print("Hallo")


print_hello("english")      # Hello
print_hello("german")       # Hallo
print_hello("russian")      # Привет
```

если выражение из `match` не соответствует ни одному из шаблонов `case`, ни один из этих блоков `case` не выполняется. если при несовпадении, когда ни один шаблон `case` не соответствует выражению `match`, нужны действия по умолчанию, применяется шаблон `_`, прочерк. шаблон успешен для любого значения и имя не связывает. ветка с таким шаблоном неопровержима. неопровержимая ветка в `match` стоит последней, иначе текст отвергается при компиляции с `SyntaxError`.

```python
def print_hello(language):
    match language:
        case "russian":
            print("Привет")
        case "english":
            print("Hello")
        case "german":
            print("Hallo")
        case _:
            print("Undefined")


print_hello("english")      # Hello
print_hello("spanish")      # Undefined
```

если ни один из шаблонов `case` не соответствует значению `language`, выполняется блок:

```python
case _: 
    print("Undefined")
```

вызов `print_hello("spanish")` не совпадает со строками `russian`, `english` и `german`, поэтому печатается `Undefined`.

блок `case` может сравнивать сразу с несколькими значениями. в этом случае значения разделяются вертикальной чертой `|`. это или-шаблон: ветка соответствует субъекту, если совпала хотя бы одна альтернатива. альтернативы проверяются слева направо.

```python
def print_hello(language):
    match language:
        case "russian":
            print("Привет")
        case "american english" | "british english" | "english":
            print("Hello")
        case _:
            print("Undefined")


print_hello("english")              # Hello
print_hello("american english")     # Hello
print_hello("spanish")              # Undefined
```

шаблон `case "american english" | "british english" | "english"` соответствует сразу трём значениям. вызовы с `english` и с `american english` печатают `Hello`. вызов с `spanish` попадает в ветку `_` и печатает `Undefined`.

подобным образом сравниваются выражения с данными других типов. литерал в шаблоне сопоставляется через равенство `==`. для `None`, `True` и `False` сравнение идёт через идентичность `is`.

```python
def operation(a, b, code):
    match code:
        case 1:
            return a + b
        case 2:
            return a - b
        case 3:
            return a * b
        case _:
            return 0


print(operation(10, 5, 1))      # 15
print(operation(10, 5, 2))      # 5
print(operation(10, 5, 3))      # 50
print(operation(10, 5, 4))      # 0
```

функция `operation` принимает два числа и код операции. конструкция `match` сравнивает код операции с конкретными значениями и в зависимости от значения выполняет над числами определённую операцию. если `code` равен 1, выполняется ветка:

```python
case 1:
    return a + b
```

`return` в этой ветке завершает функцию `operation` и возвращает сумму чисел `a` и `b`. инструкция `match` сама значение не производит, результат функции отдаёт `return`. если `code` равен 2, возвращается разность. если `code` равен 3, возвращается произведение чисел. во всех остальных случаях, ветка `_`, возвращается 0.
