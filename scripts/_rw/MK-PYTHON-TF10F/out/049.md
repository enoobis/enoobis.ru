при преобразовании числа в текст python по умолчанию использует англосаксонскую запись: группы разрядов целой части отделяются запятыми, а дробная часть отделяется от целой точкой. в континентальной европе распространена другая запись: группы разрядов разделяются точкой, а дробная и целая части разделяются запятой. синтаксис числовых литералов самого языка от культуры не зависит: в исходном тексте десятичный разделитель всегда точка. культура влияет на функции, которые читают локаль процесса и уже по ней собирают строку.

```python
# англосаксонская система
1,234.567
# европейская система
1.234,567
```

за преобразование под выбранную культуру отвечает модуль стандартной библиотеки `locale`. это обёртка над локалью языка c: функция `setlocale` библиотеки libc хранит категорию в состоянии процесса, и к ней обращаются те операции форматирования, которые написаны с учётом локали.

культура устанавливается функцией `setlocale()`. у неё два параметра:

```python
setlocale(category, locale)
```

первый параметр задаёт категорию: только числа, только валюты или сразу несколько категорий. в аргумент передаётся одна из констант модуля:

- `LC_ALL`: локализация всех категорий, то есть форматирование чисел, валют, дат и остальных групп, которые знает libc

- `LC_NUMERIC`: локализация чисел

- `LC_MONETARY`: локализация валют

- `LC_TIME`: локализация дат и времени

- `LC_CTYPE`: классификация символов и перевод между верхним и нижним регистром

- `LC_COLLATE`: правила сравнения и упорядочивания строк

второй параметр выбирает саму культуру. допустимые строки определяет библиотека c конкретной операционной системы, общего для всех платформ списка имён нет. на windows в примере лекции используется двухбуквенный код страны по iso: `"us"` для сша, `"de"` для германии, `"ru"` для россии. на той же платформе c runtime часто принимает и длинные имена вида `German_Germany`. на macos и в posix-системах нужна пара из кода языка и кода страны: `"en_US"` для английского в сша, `"de_DE"` для немецкого в германии, `"ru_RU"` для русского в россии. вызов меняет локаль всего процесса и не потокобезопасен: потоки разделяют одно глобальное состояние libc.

до первого вызова `setlocale` процесс находится в локали `C`. для чисел она даёт точку в качестве десятичного разделителя, ту же запись, которую исходный текст лекции называет культурой по умолчанию `"en_US"`.

для чисел и валют модуль даёт две функции:

- `currency(num)`: форматирует сумму по правилам категории `LC_MONETARY`, с символом валюты и с числом знаков, принятым у этой валюты

- `format_string(format, num)`: подставляет число num в строку format вместо плейсхолдера. плейсхолдеры те же, что в формате printf. `d` обозначает целое

- `f`: число с плавающей точкой

- `e`: экспоненциальная запись

перед плейсхолдером ставится знак процента, например:

```python
"%d"
```

у дробного спецификатора после точки указывается число знаков дробной части. лишние знаки округляются:

```python
%.2f		# два знака в дробной части
```

ниже локаль чисел и валют переключается на немецкую культуру:

```python
import locale

locale.setlocale(locale.LC_ALL, "de")        # для  Windows
# locale.setlocale(locale.LC_ALL, "de_DE")   # для MacOS

number = 12345.6789
formatted = locale.format_string("%f", number)
print(formatted)    # 12345,678900

formatted = locale.format_string("%.2f", number)
print(formatted)    # 12345,68

formatted = locale.format_string("%d", number)
print(formatted)    # 12345

formatted = locale.format_string("%e", number)
print(formatted)    # 1,234568e+04

money = 234.678
formatted = locale.currency(money)
print(formatted)    # 234,68 €
```

в немецкой записи десятичный разделитель - запятая. значение `12345.6789` в формате `%f` печатается как `12345,678900`, спецификатор `%.2f` оставляет два знака и даёт `12345,68`. спецификатор `%d` отбрасывает дробную часть. `currency` добавляет знак валюты культуры: для германии это евро, и сумма `234.678` выводится как `234,68 €` с округлением до цента.

если вторым аргументом передать пустую строку, `setlocale` берёт культуру текущей рабочей машины, то есть локаль пользователя. `getlocale()` возвращает действующую локаль парой из имени и кодировки:

```python
import locale

locale.setlocale(locale.LC_ALL, "")

number = 12345.6789
formatted = locale.format_string("%.02f", number)
print(formatted)    # 12345,68
print(locale.getlocale())   
# ('Russian_Russia', '1251') - Windows
# ('ru_RU', 'UTF-8')  - MacOS
```

конкретная пара зависит от системы. комментарии фрагмента фиксируют типичный результат: на windows `('Russian_Russia', '1251')`, на macos `('ru_RU', 'UTF-8')`. вызов `getlocale()` без аргумента читает категорию `LC_CTYPE`.
