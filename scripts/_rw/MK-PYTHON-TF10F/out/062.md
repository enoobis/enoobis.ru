шаблоном последовательности служит и запись в квадратных скобках. конспект разбирает её на списках и называет субъект массивом. скобки, как и круглые в шаблоне кортежа, тип не фиксируют: обе формы принимают любую последовательность, кроме `str`, `bytes` и `bytearray`. внутри шаблона стоят литералы, имена, которым передаются элементы, или маска `_`, если элемент не нужен.

```python
def print_people(people):
    match people:
        case ["Tom", "Sam", "Bob"]:
            print("default people")
        case ["Tom", second, _]:
            print(f"Second Person: {second}")
        case [first, second, third]:
            print(f"{first}, {second}, {third}")


print_people(["Tom", "Sam", "Bob"])         # default people
print_people(["Tom", "Mike", "Bob"])        # Second Person: Mike
print_people(["Alice", "Bill", "Kate"])     # Alice, Bill, Kate
print_people(["Tom", "Kate"])               # несоответствует ни одному из шаблонов
```

функция `print_people` рассчитана на список из трёх элементов. субъект иной длины в этом первом примере ни одной ветви не соответствует, что и показывает вызов с двумя элементами: подходящего шаблона нет, и `match` ничего не выполняет.

первый шаблон требует конкретные значения всех трёх элементов.

```python
case ["Tom", "Sam", "Bob"]:
    print("default people")
```

первый элемент должен быть строкой `"Tom"`, второй строкой `"Sam"`, третий строкой `"Bob"`.

второй шаблон требует равенства первого элемента строке `"Tom"`. остальные два элемента произвольны.

```python
case ["Tom", second, _]:
    print(f"Second Person: {second}")
```

второй элемент связывается с именем `second`. третий не используется, на его месте маска.

третий шаблон принимает любую последовательность из трёх элементов и связывает их с именами `first`, `second` и `third`.

```python
case [first, second, third]:
    print(f"{first}, {second}, {third}")
```

выше длина была фиксирована тремя элементами. отдельные шаблоны задают и другие длины. маска на каждом месте проверяет только длину:

```python
def print_people(people):
    match people:
        case [_]:
            print("Массив из одного элемента")
        case [_, _]:
            print("Массив из двух элементов")
        case [_, _, _]:
            print("Массив из трех элементов")
        case _:
            print("Непонятно")


print_people(["Tom"])                   # Массив из одного элемента
print_people(["Tom", "Sam"])            # Массив из двух элементов
print_people(["Tom", "Sam", "Bob"])     # Массив из трех элементов
print_people("Tom")                     # Непонятно
```

вызов `print_people("Tom")` печатает сообщение ветви `_`. строка является субъектом, но шаблоны `[...]` её как последовательность символов не принимают, поэтому срабатывает исчерпывающая маска. пустой список тоже не имеет длины 1, 2 или 3 и попадает в ту же ветвь.

### массивы неопределённой длины

если длина заранее неизвестна, обязательные элементы записывают явно, а хвост обозначают звёздочкой. имя после звёздочки получает список оставшихся элементов.

```python
def print_people(people):
    match people:
        case [first, *other]:
            print(f"First: {first}  Other: {other}")


print_people(["Tom"])                   # First: Tom  Other: []
print_people(["Tom", "Sam"])            # First: Tom  Other: ["Sam"]
print_people(["Tom", "Sam", "Bob"])     # First: Tom  Other: ["Sam", "Bob"]
```

параметр `*other` собирает хвост. шаблон `[first, *other]` принимает любую последовательность, в которой есть хотя бы один элемент: этот элемент попадает в `first`, остальные в `other`. у списка из одного элемента `other` пуст. пустая последовательность этому шаблону не соответствует. и для списка, и для кортежа захваченный хвост имеет тип `list`.

если хвост нужен только как допуск любой длины от одного элемента, а значение хвоста не нужно, пишут `*_`:

```python
def print_people(people):
    match people:
        case [first, *_]:
            print(f"First: {first}")


print_people(["Tom"])                   # First: Tom
print_people(["Sam", "Tom"])            # First: Sam
print_people(["Bob", "Sam", "Tom"])     # First: Bob
```

### альтернативные значения

набор допустимых значений одного элемента перечисляют через вертикальную черту:

```python
def print_people(people):
    match people:
        case ["Tom" | "Tomas" | "Tommy", "Sam", "Bob"]:
            print("default people")
        case [first, second, third]:
            print(f"{first}, {second}, {third}")


print_people(["Tom", "Sam", "Bob"])         # default people
print_people(["Tomas", "Sam", "Bob"])       # default people
print_people(["Alice", "Bill", "Kate"])     # Alice, Bill, Kate
```

первый шаблон принимает последовательность из трёх элементов, где первый равен `"Tom"`, `"Tomas"` или `"Tommy"`, а второй и третий равны `"Sam"` и `"Bob"`.

или-шаблон соединяет и целые последовательности:

```python
def print_people(people):
    match people:
        case ["Tom", "Sam", "Bob"] | ["Tomas", "Sam", "Bob"]:
            print("Tom/Tomas, Sam, Bob")
        case [first, second, third]:
            print(f"{first}, {second}, {third}")


print_people(["Tom", "Sam", "Bob"])         # Tom/Tomas, Sam, Bob
print_people(["Tomas", "Sam", "Bob"])       # Tom/Tomas, Sam, Bob
print_people(["Alice", "Bill", "Kate"])     # Alice, Bill, Kate
```

первый шаблон принимает два списка: `["Tom", "Sam", "Bob"]` и `["Tomas", "Sam", "Bob"]`. тот же шаблон примет и кортеж с теми же элементами, потому что форма скобок длину и значения проверяет, а тип последовательности не ограничивает.
