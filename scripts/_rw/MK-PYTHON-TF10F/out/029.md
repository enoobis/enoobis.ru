начиная с версии 3 в языке python все классы неявно имеют один общий суперкласс `object`, и все классы по умолчанию наследуют его методы. класс, у которого в заголовке базовые классы не указаны, всё равно получает `object` в конце порядка разрешения методов.

одним из наиболее используемых методов класса `object` является метод `__str__()`. когда нужно получить строковое представление объекта или вывести объект в виде строки, python вызывает этот метод. его ищут `print` и встроенная функция `str()`. при определении класса метод переопределяют, чтобы строка отражала состояние экземпляра.

класс `Person` и вывод его строкового представления:

```python
class Person:
    def __init__(self, name, age):
        self.name = name  # устанавливаем имя
        self.age = age  # устанавливаем возраст

    def display_info(self):
        print(f"Name: {self.name}  Age: {self.age}")


tom = Person("Tom", 23)
print(tom)
```

при запуске программа выведет строку такого вида:

```consoletext
<__main__.Person object at 0x10a63dc00>
```

собственный `__str__` в `Person` не определён, поэтому вызывается реализация `object`. она делегирует в `__repr__` и возвращает имя типа вместе с идентификатором объекта. по этой строке состояние экземпляра не восстановить. данные объекта можно вывести отдельным методом: в примере выше это метод `display_info`.

другой выход: определить в классе `Person` метод `__str__()` (по два подчёркивания с каждой стороны):

```python
class Person:
    def __init__(self, name, age):
        self.name = name  # устанавливаем имя
        self.age = age  # устанавливаем возраст

    def display_info(self):
        print(self)
        # print(self.__str__())     # или так

    def __str__(self):
        return f"Name: {self.name}  Age: {self.age}"


tom = Person("Tom", 23)
print(tom)      # Name: Tom  Age: 23
tom.display_info()  # Name: Tom  Age: 23
```

метод `__str__` должен возвращать строку. здесь возвращается основная информация о человеке: имя и возраст. если эта информация нужна в других методах класса, используется выражение `self.__str__()`. в `display_info` стоит `print(self)`, и печать экземпляра снова вызывает `__str__`. комментарий рядом показывает прямой вызов `self.__str__()`. теперь консольный вывод такой:

```bash
Name: Tom  Age: 23
Name: Tom  Age: 23
```

имя `__str__` подстановке закрытых имён не подвергается. подстановка затрагивает имена с двумя подчёркиваниями в начале и не больше чем с одним подчёркиванием в конце. у `__str__` два подчёркивания стоят и в конце, поэтому интерпретатор ищет метод по записанному имени.
