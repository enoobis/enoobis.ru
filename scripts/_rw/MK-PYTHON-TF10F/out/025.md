по умолчанию атрибуты класса общедоступны: из любого места программы атрибут объекта можно прочитать и изменить. пример:

```python
class Person:
    def __init__(self, name, age):
        self.name = name    # устанавливаем имя
        self.age = age     	# устанавливаем возраст
				
    def print_person(self):
        print(f"Имя: {self.name}\tВозраст: {self.age}")
		

tom = Person("Tom", 39)
tom.name = "Человек-паук"       # изменяем атрибут name
tom.age = -129           		# изменяем атрибут age
tom.print_person()				# Имя: Человек-паук 	Возраст: -129
```

возрасту или имени можно присвоить заведомо некорректное значение, например отрицательный возраст. такое состояние объекта нежелательно, и доступ к атрибутам приходится контролировать.

с этой задачей связана инкапсуляция. инкапсуляция, одна из базовых идей объектно-ориентированного программирования, скрывает реализацию и не оставляет внешнему коду прямого доступа к ней.

в python атрибут делают закрытым, начиная его имя с двух подчёркиваний, `__name`. оба атрибута, имя и возраст, ниже закрыты:

```python
class Person:
    def __init__(self, name, age):
        self.__name = name    # устанавливаем имя
        self.__age = age       # устанавливаем возраст
                 
    def print_person(self):
        print(f"Имя: {self.__name}\tВозраст: {self.__age}")
         
 
tom = Person("Tom", 39)
tom.__name = "Человек-паук"     # пытаемся изменить атрибут __name
tom.__age = -129                # пытаемся изменить атрибут __
tom.print_person()              # Имя: Tom        Возраст: 39
```

снаружи по-прежнему можно написать присваивание атрибутам `__name` и `__age`:

```python
tom.__name = "Человек-паук"     # пытаемся изменить атрибут __name
tom.__age = -129                # пытаемся изменить атрибут __
```

вывод `print_person` показывает, что атрибуты объекта сохранили прежние значения:

```python
tom.print_person()       # Имя: Tom        Возраст: 39
```

подстановка имён устроена так. если в теле класса идентификатор начинается с двух подчёркиваний и имеет не больше одного подчёркивания в конце, компилятор переписывает его по шаблону `_ClassName__attribute`. имя `__attribute` становится `_ClassName__attribute`. в примере создаются атрибуты `_Person__name` и `_Person__age`. подстановка выполняется при компиляции тела класса и снаружи этого тела не действует. поэтому обращение к закрытому атрибуту из методов того же класса доходит до замещённого имени, а запись с исходным именем вне класса до него не доходит. имена вроде `__init__`, с двумя подчёркиваниями и в начале и в конце, подстановке не подвергаются. одно подчёркивание в начале имени её тоже не включает.

присваивание вне класса не меняет замещённый атрибут:

```python
tom.__age = 43
```

такая запись динамически создаёт у экземпляра новый атрибут с буквальным именем `__age`. к `self.__age`, то есть к `self._Person__age`, он отношения не имеет. чтение `tom.__age` до подобного присваивания завершается ошибкой `AttributeError`: атрибута с буквальным именем `__age` у объекта нет:

```python
print(tom.__age)
```

закрытость здесь относительна. полное замещённое имя доступно и из внешнего кода:

```python
class Person:
    def __init__(self, name, age):
        self.__name = name    # устанавливаем имя
        self.__age = age       # устанавливаем возраст
                 
    def print_person(self):
        print(f"Имя: {self.__name}\tВозраст: {self.__age}")
         
 
tom = Person("Tom", 39)
tom._Person__name = "Человек-паук"     # изменяем атрибут __name
tom.print_person()              # Имя: Человек-паук        Возраст: 39
```

автору внешнего кода для этого нужно знать и имя класса, и правило подстановки. сама подстановка нужна прежде всего затем, чтобы имя класса не сталкивалось с таким же именем в подклассе. границей безопасности она не является.

### методы доступа. геттеры и сеттеры

к закрытому атрибуту обращаются через методы доступа. геттер читает значение, сеттер записывает его. тот же класс с методами доступа:

```python
class Person:
    def __init__(self, name, age):
        self.__name = name    # устанавливаем имя
        self.__age = age       # устанавливаем возраст

    # сеттер для установки возраста
    def set_age(self, age):
        if 0 < age < 110:
            self.__age = age
        else:
            print("Недопустимый возраст")

    # геттер для получения возраста
    def get_age(self):
        return self.__age

    # геттер для получения имени
    def get_name(self):
        return self.__name
    
    def print_person(self):
        print(f"Имя: {self.__name}\tВозраст: {self.__age}")
         
 
tom = Person("Tom", 39)
tom.print_person()  # Имя: Tom 	Возраст: 39
tom.set_age(-3486)  # Недопустимый возраст
tom.set_age(25)
tom.print_person()  # Имя: Tom 	Возраст: 25
```

возраст читает метод `get_age`:

```python
def get_age(self):
    return self.__age
```

возраст изменяет метод `set_age`:

```python
def set_age(self, age):
    if 0 < age < 110:
        self.__age = age
    else:
        print("Недопустимый возраст")
```

доступ через метод позволяет добавить логику. по переданному возрасту метод решает, записывать ли его: значение может быть некорректным. условие `0 < age < 110` пропускает целые от 1 до 109 включительно. иначе печатается `Недопустимый возраст`, и прежнее значение `__age` сохраняется.

пара методов нужна не каждому закрытому атрибуту. имя в примере задаётся только в конструкторе, а для чтения определён `get_name`.

### аннотации свойств

методы доступа можно заменить свойством. запись строится на аннотациях, которые начинаются с символа `@`. это те же декораторы, что применяются к функциям: аннотация получает метод и возвращает объект свойства.

геттер помечают аннотацией `@property`. сеттер помечают аннотацией `имя_свойства_геттера.setter`.

класс `Person` на аннотациях:

```python
class Person:
    def __init__(self, name, age):
        self.__name = name    # устанавливаем имя
        self.__age = age       # устанавливаем возраст

    # свойство-геттер
    @property
    def age(self):
        return self.__age
    # свойство-сеттер
    @age.setter
    def age(self, age):
        if 0 < age < 110:
            self.__age = age
        else:
            print("Недопустимый возраст")

    @property
    def name(self):
        return self.__name
    
    def print_person(self):
        print(f"Имя: {self.__name}\tВозраст: {self.__age}")
         
 
tom = Person("Tom", 39)
tom.print_person()  # Имя: Tom 	Возраст: 39
tom.age = -3486     # Недопустимый возраст  (Обращение к сеттеру)
print(tom.age)      # 39 (Обращение к геттеру)
tom.age = 25        # (Обращение к сеттеру)
tom.print_person()  # Имя: Tom 	Возраст: 25
```

сеттер определяют после геттера: аннотация `@age.setter` ищет уже созданное свойство с именем `age`. геттер и сеттер называются одинаково, `age`, и над сеттером стоит `@age.setter`.

и чтение, и запись идут через выражение `tom.age`. `@property` превращает метод в дескриптор, поэтому обращение диспетчеризуется в геттер или сеттер, а не ищет обычный атрибут экземпляра. присваивание `tom.age = -3486` вызывает сеттер и оставляет прежний возраст, `print(tom.age)` вызывает геттер и печатает 39, следующее присваивание 25 проходит проверку.

свойство может состоять из одного геттера, как `name`. записать его нельзя, прочитать можно. присваивание свойству без сеттера завершается ошибкой `AttributeError`.
