pattern matching проверяет наличие в словаре заданных ключей и значений. шаблон отображения сопоставляется с объектом протокола `Mapping`. перечисленные ключи должны присутствовать, а их значения должны подойти вложенным шаблонам. лишние ключи совпадению не мешают: шаблон не требует, чтобы других ключей не было. отсутствующий ключ отвергает шаблон и не поднимает `KeyError`.

```python
def look(words):
    match words:
        case {"red": "красный", "blue": "синий"}:  # если в словаре words слова red и blue
            print("Слова red и blue есть в словаре")
        case {"red": "красный"}:        # если в словаре words есть слово red
            print("Слово red есть в словаре, а слово blue отсутствует")
        case {"blue": "синий"}:        # если в словаре words есть слово blue
            print("Слово blue есть в словаре, а слово red отсутствует")
        case {}:
            print("Слова red и blue в словаре отсутствует")
        case _:
            print("Это не словарь")


look({"red": "красный", "blue": "синий", "green": "зеленый"})   # Слова red и blue есть в словаре
look({"red": "красный", "green": "зеленый"})        # Слово red есть в словаре, а слово blue отсутствует
look({"blue": "синий", "green": "зеленый"})         # Слово blue есть в словаре, а слово red отсутствует
look({"green": "зеленый"})                          # Слова red и blue в словаре отсутствует
look("yelllow")                                     # Это не словарь
```

в функцию `look` передаётся словарь. первый шаблон:

```python
case {"red": "красный", "blue": "синий"}:  # если в словаре words слова red и blue
    print("Слова red и blue есть в словаре")
```

он принимает словарь, в котором есть пара `"red": "красный"` и пара `"blue": "синий"`. прочие пары, в примере ключ `"green"`, на успех не влияют. порядок ветвей существенен. словарь с обоими ключами подошёл бы и к более короткому шаблону, но короткие ветви стоят ниже и до них выполнение не доходит.

второй шаблон `{"red": "красный"}` принимает любой словарь с парой `"red": "красный"`. третий шаблон `{"blue": "синий"}` принимает любой словарь с парой `"blue": "синий"`.

четвёртый шаблон `{}` не называет ни одного ключа. из-за правила лишних ключей он принимает всякое отображение, в том числе непустое. поэтому словарь только с ключом `"green"` попадает сюда. до ветви маски выполнение не доходит.

последний шаблон `_` принимает любое значение. в примере туда попадает строка `"yelllow"`: строка отображением не является.

### передача набора значений

вертикальная черта задаёт альтернативные значения вложенного шаблона:

```python
def look(words):
    match words:
        case {"red": "красный" | "алый" | "червонный"}:  # если значение "красный", "алый" или "червонный"
            print("Слово red есть в словаре")
        case {}:
            print("Слово red в словаре отсутствует или имеет некорректное значение")


look({"red": "красный", "green": "зеленый"})        # Слово red есть в словаре
look({"red": "алый", "green": "зеленый"})           # Слово red есть в словаре
look({"green": "зеленый"})    # Слово red в словаре отсутствует или имеет некорректное значение
```

шаблон `{"red": "красный" | "алый" | "червонный"}` принимает словарь с ключом `"red"`, если значение равно `"красный"`, `"алый"` или `"червонный"`. другой ключ рядом не мешает. неверное значение или отсутствие ключа отвергают ветвь, и срабатывает `{}`.

альтернативой может быть и весь шаблон отображения:

```python
def look(words):
    match words:
        case {"red": "красный"} | {"blue": "синий"} :
            print("либо red, либо blue есть в словаре")
        case {}:
            print("надо проверить слова red и blue")


look({"red": "красный", "green": "зеленый"})    # либо red, либо blue есть в словаре
look({"blue": "синий", "green": "зеленый"})     # либо red, либо blue есть в словаре
look({"green": "зеленый"})                      # надо проверить слова red и blue
```

шаблон `{"red": "красный"} | {"blue": "синий"}` принимает словарь, в котором есть пара `"red": "красный"`, или пара `"blue": "синий"`, или обе. набор имён, связанных в альтернативах, должен совпадать.

если нужны сами ключи, а значения безразличны, на место значения ставят маску `_`:

```python
def look(words):
    match words:
        case {"red": _, "blue": _}:
            print("Слова red и blue есть в словаре")
        case {}:
            print("red и/или blue отсутствуют в словаре")


look({"red": "красный", "blue": "синий"})       # Слова red и blue есть в словаре
look({"red": "алый", "blue": "синий"})          # Слова red и blue есть в словаре
look({"red": "красный", "green": "зеленый"})    # red и/или blue отсутствуют в словаре
```

здесь проверяется только присутствие ключей `"red"` и `"blue"`. любые их значения подходят. словарь без одного из этих ключей доходит до `{}`.

### получение значений по ключам

значение по ключу связывают с именем. вид вложенного поля:

```python
{ключ: переменная}
```

имя справа от двоеточия служит шаблоном захвата: с ним связывается значение ключа.

```python
def look(words):
    match words:
        case {"red": red, "blue": blue}:
            print(f"red: {red}  blue: {blue}")
        case {}:
            print("надо проверить слова red и blue")


look({"red": "красный", "blue": "синий"})    # red: красный  blue: синий
look({"red": "алый", "blue": "синий"})    # red: алый  blue: синий
```

в первой ветви значение ключа `"red"` попадает в имя `red`, значение ключа `"blue"` в имя `blue`. совпадение имени ключа и имени захвата необязательно: справа может стоять любой допустимый идентификатор.

### получение всех значений

двойная звёздочка захватывает остальные пары словаря:

```python
def look(words):
    match words:
        case {"red": red, **rest}:
            print(f"red: {red}")
            for key in rest:        # rest - тоже словарь
                print(f"{key}: {rest[key]}")


look({"red": "красный", "blue": "синий", "green": "зеленый"})
# red: красный
# blue: синий
# green: зеленый
```

шаблон `{"red": red, **rest}` принимает любой словарь с ключом `"red"`. значение этого ключа связывается с `red`. прочие пары попадают в `rest`, и `rest` само является словарём, уже без ключа `"red"`. двойная звёздочка в одном шаблоне отображения допустима один раз.
