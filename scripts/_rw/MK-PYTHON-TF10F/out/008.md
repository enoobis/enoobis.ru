### переменные

переменные предназначены для хранения данных. имя переменной в python начинается с буквы или со знака подчёркивания и далее может содержать буквы, цифры и знак подчёркивания. буквы здесь понимаются широко: в идентификаторе допустимы буквы юникода, не только латиница. имя при этом не должно совпадать со служебным словом языка. служебных слов немного, их список обозрим: ```python


False      await      else       import     pass

None       break      except     in         raise

True       class      finally    is         return

and        continue   for        lambda     try

as         def        from       nonlocal   while

assert     del        global     not        with

async      elif       if         or         yield
``` имя из этого списка использовать как переменную нельзя, такая запись является синтаксической ошибкой. помимо жёстких служебных слов, с версии 3.10 есть мягкие: `match` и `case` зарезервированы в конструкции сопоставления и вне её остаются допустимыми именами.

пример переменной:

```python


name = "Tom"
```

здесь определена переменная `name`, которая хранит строку `Tom`. точнее, имя `name` связано с объектом строки. тип принадлежит объекту, а не ячейке имени.

в python применяют два способа записи составных имён: **camel case** и **underscore notation**.

**camel case** означает, что каждое новое подслово в имени начинается с большой буквы:

```python


userName = "Tom"
```

**underscore notation** означает, что подслова разделяются знаком подчёркивания:

```python


user_name = "Tom"
```

для функций и переменных руководство по стилю рекомендует второй способ, а запись с больших букв внутри слова оставляет классам. язык принимает оба варианта: это соглашение, а не правило грамматики.

учитывается и регистр, поэтому переменные `name` и `Name` представляют разные объекты:

```python


# две разные переменные

name = "Tom"

Name = "Tom"
```

после определения имя можно использовать в программе, например вывести его значение на консоль встроенной функцией `print`:

```python


name = "Tom"  # определение переменной name

print(name)   # вывод значения переменной name на консоль
```

отличительная особенность переменной в том, что значение можно менять в течение работы программы. присваивание связывает имя с другим объектом, прежний объект при этом не переписывается:

```python


name = "Tom"  # переменной name равна "Tom"

print(name)   # выводит: Tom

name = "Bob"  # меняем значение на "Bob"

print(name)   # выводит: Bob
```

### типы данных

переменная хранит данные одного из типов. в python типов много. ниже разбираются базовые: **bool**, **int**, **float**, **complex** и **str**.

### логические значения

тип **bool** представляет два логических значения: `True` (верно, истина) и `False` (неверно, ложь). значение `True` показывает, что утверждение истинно. значение `False` показывает, что утверждение ложно. пример переменных этого типа:

```python


isMarried = False

print(isMarried)    # False



isAlive = True

print(isAlive)      # True
```

`bool` является подтипом `int`: численно `True` равно 1, а `False` равно 0. логическое значение поэтому допустимо там, где ожидается целое, хотя по смыслу это значение истинности, а не количество.

### целые числа

тип **int** представляет целое число, например 1, 4, 8, 50. точность произвольная: величина ограничена памятью, а не шириной машинного слова, в отличие от фиксированных целых в c и java. пример:

```python


age = 21

print("Возраст:", age)    # Возраст: 21



count = 15

print("Количество:", count) # Количество: 15
```

по умолчанию числовые литералы без префикса читаются как десятичные. python также поддерживает двоичную, восьмеричную и шестнадцатеричную запись. префикс задаёт систему при разборе литерала. на объект, который получится после разбора, префикс не влияет: это всё тот же `int`.

для двоичной системы перед числом ставится префикс **0b**:

```python


a = 0b11

b = 0b1011

c = 0b100001

print(a)    # 3 в десятичной системе

print(b)    # 11 в десятичной системе

print(c)    # 33 в десятичной системе
```

для восьмеричной системы перед числом ставится префикс **0o**:

```python


a = 0o7

b = 0o11

c = 0o17

print(a)    # 7 в десятичной системе

print(b)    # 9 в десятичной системе

print(c)    # 15 в десятичной системе
```

для шестнадцатеричной системы перед числом ставится префикс **0x**:

```python


a = 0x0A

b = 0xFF

c = 0xA1

print(a)    # 10 в десятичной системе

print(b)    # 255 в десятичной системе

print(c)    # 161 в десятичной системе
```

в какой бы системе литерал ни был записан, `print` по умолчанию выводит десятичное представление. преобразование в строку для целого десятичное. другие основания получают отдельным форматом или функциями представления, к двоичному выводу курс вернётся при поразрядных операциях.

### дробные числа

тип **float** представляет число с плавающей точкой, например 1.2 или 34.76. в качестве разделителя целой и дробной частей используется точка. завершающая точка без дробных цифр, как в литерале `68.`, тоже задаёт `float`, а не `int`:

```python


height = 1.68

pi = 3.14

weight = 68.

print(height)   # 1.68

print(pi)       # 3.14

print(weight)   # 68.0
```

в cpython значение `float` хранится в двоичном формате двойной точности `IEEE 754`. гарантированное число значащих десятичных цифр у этого формата около пятнадцати, поэтому десятичная дробь в общем случае представлена приближённо. к следствиям приближения курс вернётся в теме арифметики и функции `round`.

число с плавающей точкой можно записать в экспоненциальной форме:

```python


x = 3.9e3

print(x)  # 3900.0



x = 3.9e-3

print(x)  # 0.0039
```

мантисса и порядок разделяются буквой `e`. число после `e` задаёт степень десяти, на которую умножается мантисса. в литерале `3.9e3` используются два знака мантиссы, 3.9, а порядок 3 даёт 3900.0. форма `3.9e-3` даёт 0.0039. если число слишком велико или слишком мало, экспоненциальная запись короче полной десятичной: пишется короткая мантисса и степень десяти.

### комплексные числа

тип **complex** представляет комплексные числа в формате `вещественная_часть+мнимая_часть**j**`. после мнимой части указывается суффикс **j**. в математической записи мнимую единицу часто обозначают как i, в python принят суффикс `j`, как в инженерной традиции. объект хранит вещественную и мнимую части как два значения `float`:

```python


complexNumber = 1+2j

print(complexNumber)   # (1+2j)
```

### строки

тип **str** представляет строки. строка представляет последовательность символов, заключённую в одинарные или двойные кавычки, например `hello` и `'hello'`. в python 3.x строки представляют набор символов в кодировке unicode: объект `str` хранит последовательность кодовых точек, а не байты. выбор одинарных или двойных кавычек на тип и на значение не влияет, он позволяет вложить кавычку другого вида без экранирования:

```python


message = "Hello World!"

print(message)  # Hello World!



name = 'Tom'

print(name)  # Tom
```

если строка содержит много символов, её можно разбить на части и разместить эти части на разных строках кода. тогда вся строка заключается в круглые скобки, а отдельные части в кавычки:

```python


text = ("Laudate omnes gentes laudate "

        "Magnificat in secula ")

print(text)
```

соседние строковые литералы внутри скобок склеиваются ещё при компиляции в один объект `str`. скобки нужны, чтобы литерал мог занять несколько физических строк без символа продолжения строки.

если нужно определить многострочный текст, такой текст заключается в тройные двойные или одинарные кавычки:

```python


'''

Это комментарий

'''

text = '''Laudate omnes gentes laudate

Magnificat in secula

Et anima mea laudate

Magnificat in secula 

'''

print(text)
```

при использовании тройных одинарных кавычек их не путают с комментариями: если текст в тройных одинарных кавычках присваивается переменной, это строка, а не комментарий. литерал без присваивания остаётся выражением. присваивание связывает с именем значение, включая внутренние переводы строк.

#### управляющие последовательности в строке

строка может содержать специальные символы, управляющие последовательности. некоторые из них:

- `\\` позволяет добавить внутрь строки слеш

- `\'` позволяет добавить внутрь строки одинарную кавычку

- `\"` позволяет добавить внутрь строки двойную кавычку

- `\n` осуществляет переход на новую строку

- `\t` добавляет табуляцию

`\t` вставляет один символ табуляции, а не несколько пробелов. сколько колонок он займёт на экране, зависит от табуляции терминала. в пояснении к этой последовательности табуляцию иногда оценивают как четыре отступа, но это ширина отображения, а не правило языка.

несколько последовательностей в одной строке:

```python


text = "Message:\n\"Hello World\""

print(text)
```

консольный вывод программы:

```consoletext


Message:

"Hello World"
```

такие последовательности позволяют поместить в строку кавычку, табуляцию или перевод на другую строку. они же мешают, когда обратный слеш нужен как обычный символ. пример пути к файлу:

```python


path = "C:\python\name.txt"

print(path)
```

переменная `path` содержит путь к файлу. внутри строки встречается фрагмент `\n`, и он читается как управляющая последовательность перевода строки, а не как два символа пути. консольный вывод получается таким:

```consoletext


C:\python

ame.txt
```

чтобы избежать этой подстановки, перед строкой ставится символ **r**. префикс сырой строки отключает разбор управляющих последовательностей, и `\n` остаётся двумя символами, обратным слешем и буквой:

```python


path = r"C:\python\name.txt"

print(path)
```

#### вставка значений в строку

python позволяет вставлять в строку значения других переменных. внутри строки переменные размещаются в фигурных скобках `{}`, а перед всей строкой ставится символ **f**:

```python


userName = "Tom"

userAge = 37

user = f"name: {userName}  age: {userAge}"

print(user)   # name: Tom  age: 37
```

на место `{userName}` вставляется значение переменной `userName`. на место `{userAge}` вставляется значение переменной `userAge`. это форматированный строковый литерал: выражения в скобках вычисляются при выполнении, и их значения подставляются в результат. литерал с префиксом `f` не является обычной склейкой кусков текста в момент компиляции.

### динамическая типизация

python является языком с динамической типизацией. переменная не привязана жёстко к определённому типу.

тип определяется значением, которое присвоено имени. при присвоении строки в двойных или одинарных кавычках объект имеет тип **str**. при присвоении целого числа python определяет тип объекта как **int**. чтобы получить объект `float`, имени присваивают дробное число, в котором разделителем целой и дробной части является точка.

в ходе выполнения тип связанного с именем объекта можно сменить, присвоив значение другого типа. имя при этом перепривязывается. прежний объект своего типа не меняет:

```python


userId = "abc"  # тип str

print(userId)



userId = 234  # тип int

print(userId)
```

встроенная функция **type()** во время выполнения возвращает текущий тип объекта, на который указывает имя:

```python


userId = "abc"  	# тип str

print(type(userId)) # <class 'str'>



userId = 234  		# тип int

print(type(userId)) # <class 'int'>
```
