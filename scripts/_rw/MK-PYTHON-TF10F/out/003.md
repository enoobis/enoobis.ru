### установка

для создания программ на python нужен интерпретатор. в части дистрибутивов linux, в том числе в ubuntu, python уже установлен. версию в терминале проверяют командой:

```bash
python3 --version
```

![версия интерпретатора python в linux](/uploads/course-lectures/a2b155a921792593b4d76700ba857ba2b0db6d12.png)

если интерпретатор установлен, команда печатает номер версии.

даже при наличии интерпретатора установленная версия может отставать от последней опубликованной. последнюю версию, доступную в репозитории дистрибутива, ставят командой:

```bash
sudo apt-get update && sudo apt-get install python3
```

`apt-get update` обновляет список пакетов, `apt-get install python3` ставит пакет `python3`. это пакет дистрибутива, а не произвольная сборка с сайта языка: номер версии привязан к выпуску дистрибутива и может быть старше текущей линии cpython.

если нужна не эта доступная версия, а конкретная линия, в имени пакета указывают подверсию. установка python 3.10:

```bash
sudo apt-get install python3.10
```

установка python 3.11:

```bash
sudo apt-get install python3.11
```

пакеты `python3.10` и `python3.11` ставят версионированные интерпретаторы рядом друг с другом. имя `python3` при этом может по-прежнему указывать на другую линию. как сменить линию по умолчанию, разбирается в теме про несколько версий.

### запуск интерпретатора

после установки интерпретатора можно выполнять программы. первую программу вводят в интерактивный сеанс. его открывают командой:

```bash
python3
```

в запущенный интерпретатор вводят строку:

```python
print("hello enoobis.ru")
```

консоль выводит текст `hello enoobis.ru`:

![первая программа на python в linux](/uploads/course-lectures/553b64a4c91621639e95a3f8d4e4a990b97af8bd.png)

в этой программе использована встроенная функция `print()`. она записывает переданную строку в стандартный вывод, и консоль показывает этот текст.

### создание файла программы

обычно программа хранится во внешнем файле-скрипте, и уже файл передаётся интерпретатору. для скриптов создают каталог `python`, а в нём текстовый файл `hello.py`. для исходного текста на python принято расширение `py`.

![создание скрипта на языке python на linux](/uploads/course-lectures/0ed0aea1cf5c35c27414f461ad4ca6b3b7182e7b.png)

файл открывают в любом текстовом редакторе и помещают в него следующий код:

```python
name = input("Введите имя: ")
print("Привет,", name)
```

![python в visual studio code](/uploads/course-lectures/1fe86ea64b2ed8ccab9dee9e9afa57fba714fdc7.png)

скрипт состоит из двух инструкций. первая вызывает `input()` и ждёт, пока пользователь введёт имя. введённая строка связывается с именем `name`.

вторая инструкция вызывает `print()` и выводит приветствие вместе с введённым именем.

далее открывают терминал и командой `cd` переходят в каталог, где лежит `hello.py`. в примере это каталог `enoobis/python` в домашнем каталоге текущего пользователя. код из `hello.py` выполняют командой:

```consoletext
python3 hello.py
```

программа печатает приглашение к вводу имени, затем печатает приветствие.
