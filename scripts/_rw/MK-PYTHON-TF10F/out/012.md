ряд операций представляют условные выражения. операции сравнения, а также `and`, `or` и `in`, принимают два операнда. результат сравнения и результат `not` имеют логический тип **bool**. логических значений ровно два: `True` (выражение истинно) и `False` (выражение ложно). у `and` и `or` возвращаемое значение устроено иначе: это один из операндов, и его тип не обязан быть `bool`.

### операции сравнения

простейшие условные выражения представляют операции сравнения. они сопоставляют два значения. python поддерживает следующие операции сравнения:

- `==` возвращает `True`, если оба операнда равны. иначе возвращает `False`.

- `!=` возвращает `True`, если оба операнда не равны. иначе возвращает `False`.

- `>` (больше чем) возвращает `True`, если первый операнд больше второго.

- `<` (меньше чем) возвращает `True`, если первый операнд меньше второго.

- `>=` (больше или равно) возвращает `True`, если первый операнд больше второго или равен ему.

- `<=` (меньше или равно) возвращает `True`, если первый операнд меньше второго или равен ему.

сравнения можно выстроить в цепочку. запись `a < b < c` эквивалентна `a < b and b < c`, причём средний операнд вычисляется один раз.

логические связки применяются к результатам сравнений и к любым другим объектам. истинность объекта не сводится к константам `True` и `False`: число 0 и пустая строка `""` рассматриваются как ложь, остальные числа и непустые строки эквивалентны истине. ложны также `None`, `False`, нулевые числа других числовых типов и пустые контейнеры. объект может задать собственную истинность, но для примеров ниже достаточно чисел и строк.

- `and` (логическое умножение) применяется к двум операндам:

```python
x and y
```

сначала вычисляется левый операнд. если его значение ложно, возвращается именно оно, правый операнд не вычисляется. если левый истинен, возвращается значение правого операнда. когда оба сравнения истинны, связка `and` тоже даёт истину. формально при двух истинных операндах возвращается значение последнего операнда, а не обязательно константа `True`. пример с двумя сравнениями:

```python
age = 22
weight = 58
result = age > 21 and weight == 58
print(result)  # True
```

операндами `and` не обязаны быть значения `True` и `False`. это могут быть любые значения:

```python
result = 4 and "w"
print(result)  # w, так как 4 равно True, поэтому возвращается значение последнего операнда

result = 0 and "w"
print(result)  # 0, так как 0 эквивалентно False
```

здесь число 0 ложно, поэтому второй вызов возвращает 0 и до строки не доходит. число 4 истинно, поэтому возвращается последний операнд, строка `w`.

- `or` (логическое сложение) также применяется к двум операндам:

```python
x or y
```

сначала оператор `or` вычисляет выражение `x`. если оно истинно, возвращается его значение. если оно ложно, вычисляется второй операнд `y` и возвращается значение `y`:

```python
age = 22
isMarried = False
result = age > 21 or isMarried
print(result)  # True, так как выражение age > 21 равно True
```

оператор `or` тоже применяется к любым значениям, не только к `True` и `False`:

```python
result = 4 or "w"
print(result)  # 4, так как 4 эквивалентно True, поэтому возвращается значение первого операнда

result = 0 or "w"
print(result)  # w, так как 0 эквивалентно False, поэтому возвращается значение последнего операнда
```

- `not` (логическое отрицание) принимает один операнд. оно возвращает `True`, если выражение ложно, и `False`, если выражение истинно. в отличие от `and` и `or`, результат всегда имеет тип `bool`:

```python
age = 22
isMarried = False
print(not age > 21)  # False
print(not isMarried)  # True
print(not 4)  # False
print(not 0)  # True
```

### оператор in

оператор **in** возвращает `True`, если в некотором наборе значений есть определённое значение. форма оператора:

```python
значение in набор_значений
```

строка представляет набор символов. оператором `in` проверяют, есть ли в ней подстрока. для типа `str` левый операнд ищется как подстрока, а не только как один символ. для списка и других коллекций тот же оператор проверяет вхождение элемента, а не куска текста:

```python
message = "hello world!"
hello = "hello"
print(hello in message)  # True - подстрока hello есть в строке "hello world!"

gold = "gold"
print(gold in message)  # False - подстроки "gold" нет в строке "hello world!"
```

если нужно проверить обратное, что в наборе значений нет искомого, используют модификацию оператора, **not in**. она возвращает `True`, если в наборе значений нет определённого значения:

```python
message = "hello world!"
hello = "hello"
print(hello not in message)  # False

gold = "gold"
print(gold not in message)  # True
```
