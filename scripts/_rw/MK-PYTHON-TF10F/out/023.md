декоратор в python это функция, которая получает функцию аргументом и возвращает функцию. возвращаемая функция подменяет исходную: можно изменить ход вызова, значения параметров и результат, не правя тело исходной функции.

простейший пример:

```python
# определение функции декоратора
def select(input_func):    
    def output_func():      # определяем функцию, которая будет выполняться вместо оригинальной
        print("*****************")  # перед выводом оригинальной функции выводим всякую звездочки
        input_func()                # вызов оригинальной функции
        print("*****************")  # после вывода оригинальной функции выводим всякую звездочки
    return output_func     # возвращаем новую функцию

# определение оригинальной функции
@select         # применение декоратора select
def hello():
    print("Hello enoobis.ru")

# вызов оригинальной функции
hello()
```

сначала определяется сам декоратор. здесь он называется `select()`. параметром он получает функцию, к которой его применяют. в этом тексте параметр называется `input_func`:

```python
def select(input_func):    
    def output_func():      # определяем функцию, которая будет выполняться вместо оригинальной
        print("*****************")  # перед выводом оригинальной функции выводим всякую звездочки
        input_func()                # вызов оригинальной функции
        print("*****************")  # после вывода оригинальной функции выводим всякую звездочки
    return output_func     # возвращаем новую функцию
```

результатом декоратора служит локальная функция `output_func`. она вызывает входную функцию `input_func`. до вызова и после него печатается строка из символов `*`. `output_func` замыкается на `input_func` и сохраняет ссылку на исходную функцию.

далее определяется функция, к которой декоратор применяется. здесь это `hello`, она печатает строку:

```python
@select         # применение декоратора select
def hello():
    print("Hello enoobis.ru")
```

перед определением функции ставят символ `@` и имя декоратора. к `hello()` применяется `select()`. запись `@select` над `def` равносильна присваиванию `hello = select(hello)` сразу после определения: имя `hello` связывается с результатом декоратора в момент выполнения `def`, а не при каждом вызове.

затем функцию вызывают обычным образом:

```python
hello()
```

поскольку к функции применён `select`, объект `hello` передан в `select()` как `input_func`. декоратор вернул новую функцию `output_func`, и вызов по имени `hello` выполняет именно её: печать звёзд, вызов исходной функции, снова печать звёзд. консольный вывод:

```consoletext
*****************
Hello enoobis.ru
*****************
```

### получение параметров функции в декораторе

декоратор может перехватить аргументы, переданные в функцию:

```python
# определение функции декоратора
def check(input_func):    
    def output_func(*args):      # через *args получаем значения параметров оригинальной функции
        input_func(*args)                # вызов оригинальной функции
    return output_func     # возвращаем новую функцию

# определение оригинальной функции
@check
def print_person(name, age):
    print(f"Name: {name}  Age: {age}")

# вызов оригинальной функции
print_person("Tom", 38)
```

функция `print_person()` принимает два параметра: `name` (имя) и `age` (возраст). к ней применён декоратор `check()`.

декоратор `check` возвращает локальную функцию `output_func()`. её параметр `*args` собирает позиционные аргументы исходной функции в кортеж. в этом вызове кортеж содержит значения `name` и `age`:

```python
def check(input_func):    
    def output_func(*args):      # через *args получаем значения параметров функции input_func
```

эти значения передаются в исходную функцию распаковкой:

```python
input_func(*args)
```

консольный вывод:

```bash
Name: Tom  Age: 38
```

если в `print_person` попадает недопустимое значение, например отрицательный возраст, декоратор может проверить аргументы и подменить их до вызова исходной функции:

```python
# определение функции декоратора
def check(input_func):    
    def output_func(*args):
        name = args[0]
        age = args[1]           # получаем значение второго параметра
        if age < 0: age = 1     # если возраст отрицательный, изменяем его значение на 1
        input_func(name, age)   # передаем функции значения для параметров
    return output_func

# определение оригинальной функции
@check
def print_person(name, age):
    print(f"Name: {name}  Age: {age}")

# вызов оригинальной функции
print_person("Tom", 38)
print_person("Bob", -5)
```

`args` это набор значений. по индексу из него читается аргумент нужной позиции. если возраст меньше 0, вместо него подставляется 1, и уже эти значения передаются в вызов. вывод:

```bash
Name: Tom  Age: 38
Name: Bob  Age: 1
```

### получение результата функции

тем же приёмом читают результат функции и при необходимости заменяют его:

```python
# определение функции декоратора
def check(input_func):    
    def output_func(*args):
        result = input_func(*args)   # передаем функции значения для параметров
        if result < 0: result = 0   # если результат функции меньше нуля, то возвращаем 0
        return result
    return output_func

# определение оригинальной функции
@check
def sum(a, b):
    return a + b

# вызов оригинальной функции
result1 = sum(10, 20)
print(result1)          # 30

result2 = sum(10, -20)
print(result2)          # 0
```

функция `sum()` возвращает сумму чисел. декоратор `check` смотрит на этот результат и, если он меньше нуля, возвращает 0. вызов `sum(10, -20)` без декоратора дал бы -10. консольный вывод:

```bash
30
0
```
