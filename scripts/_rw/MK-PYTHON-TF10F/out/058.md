методы строки, которые применяются к значениям `str` в прикладном коде, не меняют объект вызова. строка неизменяема, поэтому методы, строящие текст, возвращают новый объект `str`. предикаты возвращают `True` или `False`.

- `isalpha()`: возвращает `True`, если строка не пуста и состоит только из алфавитных символов
- `islower()`: возвращает `True`, если строка состоит только из символов в нижнем регистре. по контракту метода все символы, у которых есть регистр, должны быть строчными, и хотя бы один такой символ обязателен. цифры и прочие символы без регистра условие не нарушают. пустая строка и строка из одних цифр дают `False`
- `isupper()`: возвращает `True`, если все символы строки, у которых есть регистр, записаны в верхнем регистре и хотя бы один такой символ есть
- `isdigit()`: возвращает `True`, если строка не пуста и все символы строки являются цифрами
- `isnumeric()`: возвращает `True`, если строка не пуста и представляет собой число в смысле unicode: у каждого символа есть числовое значение. десятичная цифра, надстрочная цифра и числовая дробь сюда входят. знак, пробел и десятичная точка не входят
- `startswith(str)`: возвращает `True`, если строка начинается с подстроки `str`
- `endswith(str)`: возвращает `True`, если строка заканчивается на подстроку `str`
- `lower()`: переводит строку в нижний регистр
- `upper()`: переводит строку в верхний регистр
- `title()`: начальные символы всех слов в строке переводятся в верхний регистр
- `capitalize()`: переводит в верхний регистр первую букву только самого первого слова строки, остальные символы с регистром переводит в нижний
- `lstrip()`: удаляет начальные пробелы из строки
- `rstrip()`: удаляет конечные пробелы из строки
- `strip()`: удаляет начальные и конечные пробелы из строки
- `ljust(width)`: если длина строки меньше параметра `width`, справа от строки добавляются пробелы, чтобы дополнить значение `width`, а сама строка выравнивается по левому краю. если строка уже не короче `width`, дополнения нет
- `rjust(width)`: если длина строки меньше параметра `width`, слева от строки добавляются пробелы, чтобы дополнить значение `width`, а сама строка выравнивается по правому краю
- `center(width)`: если длина строки меньше параметра `width`, слева и справа от строки равномерно добавляются пробелы, чтобы дополнить значение `width`, а сама строка выравнивается по центру
- `find(str[, start [, end])`: возвращает индекс подстроки в строке. если подстрока не найдена, возвращается число `-1`
- `replace(old, new[, num])`: заменяет в строке одну подстроку на другую
- `split([delimeter[, num]])`: разбивает строку на подстроки в зависимости от разделителя
- `partition(delimeter)`: разбивает строку по разделителю на три подстроки и возвращает кортеж из трёх элементов: подстрока до разделителя, разделитель и подстрока после разделителя
- `join(strs)`: объединяет строки в одну строку, вставляя между ними определённый разделитель

у `isalpha()`, `isdigit()` и `isnumeric()` пустая строка даёт `False`. `isdecimal()` принимает только десятичные цифры, `isdigit()` ещё и прочие цифры, `isnumeric()` любые символы с числовым значением. `lstrip`, `rstrip` и `strip` без аргумента снимают пробельные символы. переданная строка задаёт набор символов: с каждого края снимаются символы из этого набора, пока край остаётся внутри набора. `startswith` и `endswith` принимают и кортеж строк: результат `True`, если совпала хотя бы одна.

если с клавиатуры ожидается число, перед преобразованием введённой строки в число проверяют методом `isnumeric()`, введено ли в действительности число. при результате `True` выполняется преобразование.

```python
string = input("Введите число: ")
if string.isnumeric():
    number = int(string)
    print(number)
```

множества строк у `isnumeric()` и у `int()` различаются. `isnumeric()` возвращает `True` для надстрочных цифр и числовых дробей unicode, а `int()` на них поднимает `ValueError`. строку со знаком и с пробелами по краям `isnumeric()` отклоняет. `int()` читает необязательный знак и допускает пробелы в начале и в конце целого. проверка отсекает буквенный ввод. разбор целого у `int()` задаётся отдельно от этого предиката.

проверка, начинается или оканчивается строка на определённую подстроку:

```python
file_name = "hello.py"

starts_with_hello = file_name.startswith("hello")   # True
ends_with_exe = file_name.endswith("exe")           # False
```

имя `hello.py` начинается с `hello`, поэтому `startswith` возвращает `True`. окончание `exe` с суффиксом `.py` не совпадает, `endswith` возвращает `False`.

удаление пробелов в начале и в конце строки:

```python
string = "   hello  world!  "
string = string.strip()
print(string)           # hello  world!
```

`strip()` снимает пробелы только по краям. пробел внутри `hello  world!` сохраняется, что и показывает вывод.

дополнение строки пробелами и выравнивание:

```python
print("iPhone 7:", "52000".rjust(10))
print("Huawei P10:", "36000".rjust(10))
```

консольный вывод:

```bash
iPhone 7:      52000
Huawei P10:    36000
```

подписи имеют разную длину. `rjust(10)` помещает каждую цену в поле шириной 10 и добавляет пробелы слева, поэтому в выводе числа стоят в одном правом столбце.

### поиск в строке

для поиска подстроки в строке применяется метод `find()`. он возвращает индекс первого вхождения подстроки в строку и имеет три формы:

- `find(str)`: поиск подстроки `str` ведётся с начала строки до её конца
- `find(str, start)`: параметр `start` задаёт начальный индекс, с которого будет производиться поиск
- `find(str, start, end)`: параметр `end` задаёт конечный индекс, до которого будет идти поиск. этот индекс в просматриваемый отрезок не входит, по тому же правилу, что конечная граница среза

если подстрока не найдена, метод возвращает `-1`. метод `index()` ищет так же, а при отсутствии подстроки поднимает `ValueError`.

```python
welcome = "Hello world! Goodbye world!"
index = welcome.find("wor")
print(index)       # 6

# поиск с 10-го индекса
index = welcome.find("wor",10)
print(index)       # 21

# поиск с 10 по 15 индекс
index = welcome.find("wor",10,15)
print(index)       # -1
```

в строке `Hello world! Goodbye world!` первое `wor` стоит на индексе 6. поиск с 10-го индекса находит второе вхождение на индексе 21. поиск с 10 по 15 индекс этого вхождения не покрывает, результат `-1`.

### замена в строке

для замены в строке одной подстроки на другую применяется метод `replace()`:

- `replace(old, new)`: заменяет подстроку `old` на `new`
- `replace(old, new, num)`: параметр `num` указывает, сколько вхождений подстроки `old` надо заменить на `new`. по умолчанию `num` равно `-1`, что соответствует первой форме метода и приводит к замене всех вхождений

```python
phone = "+1-234-567-89-10"

# замена дефисов на пробел
edited_phone = phone.replace("-", " ")
print(edited_phone)     # +1 234 567 89 10

# удаление дефисов
edited_phone = phone.replace("-", "")
print(edited_phone)     # +12345678910

# замена только первого дефиса
edited_phone = phone.replace("-", "", 1)
print(edited_phone)     # +1234-567-89-10
```

первый вызов заменяет дефисы на пробел. второй удаляет дефисы: новая подстрока пустая. третий передаёт `num` равный 1 и заменяет только первый дефис, остальные дефисы в результате остаются. имя `phone` по-прежнему ссылается на исходную строку, результаты связаны с `edited_phone`.

### разделение на подстроки

метод `split()` разбивает строку на список подстрок в зависимости от разделителя. в качестве разделителя может выступать любой символ или последовательность символов. метод имеет следующие формы:

- `split()`: в качестве разделителя используется пробел. без аргумента строка делится по любым пробельным символам, подряд идущие пробелы схлопываются, пустые фрагменты в список не попадают
- `split(delimeter)`: в качестве разделителя используется `delimeter`. в сигнатуре языка этот параметр называется `sep`. явный разделитель делит строку только по себе и пустые фрагменты между соседними вхождениями сохраняет
- `split(delimeter, num)`: параметр `num` указывает, сколько вхождений `delimeter` используется для разделения. в сигнатуре это `maxsplit`. оставшаяся часть строки добавляется в список без разделения на подстроки

```python
text = "Это был огромный, в два обхвата дуб, с обломанными ветвями и с обломанной корой"
# разделение по пробелам
splitted_text = text.split()
print(splitted_text)
print(splitted_text[6])     # дуб,

# разбиение по запятым
splitted_text = text.split(",")
print(splitted_text)
print(splitted_text[1])     # в два обхвата дуб

# разбиение по первым пяти пробелам
splitted_text = text.split(" ", 5)
print(splitted_text)        
print(splitted_text[5])     # обхвата дуб, с обломанными ветвями и с обломанной корой
```

разделение по пробелам даёт список слов примера. элемент с индексом 6 равен `дуб,`, запятая остаётся при слове. разбиение по запятым даёт части между запятыми. элемент с индексом 1 это `в два обхвата дуб` с пробелом после удалённой запятой. разбиение по первым пяти пробелам оставляет хвост одним элементом. элемент с индексом 5 равен `обхвата дуб, с обломанными ветвями и с обломанной корой`.

ещё один метод, `partition()`, разбивает строку по разделителю на три подстроки и возвращает кортеж из трёх элементов: подстрока до разделителя, разделитель и подстрока после разделителя. в сигнатуре разделитель называется `sep`. находится первое вхождение.

```python
text = "Это был огромный, в два обхвата дуб, с обломанными ветвями и с обломанной корой"
text_parts = text.partition("дуб")
print(text_parts)
# ('Это был огромный, в два обхвата ', 'дуб', ', с обломанными ветвями и с обломанной корой')
```

если разделитель в строке не найден, кортеж по-прежнему состоит из трёх элементов: исходная строка, пустой разделитель и пустой хвост, то есть `(исходная строка, '', '')`.

### соединение строк

при рассмотрении простейших операций со строками объединение записывается операцией сложения. другую возможность для соединения строк представляет метод `join()`: он объединяет список строк. текущая строка, у которой вызывается данный метод, используется в качестве разделителя.

```python
words = ["Let", "me", "speak", "from", "my", "heart", "in", "English"]

# разделитель - пробел
sentence = " ".join(words)
print(sentence)  # Let me speak from my heart in English

# разделитель - вертикальная черта
sentence = " | ".join(words)
print(sentence)  # Let | me | speak | from | my | heart | in | English
```

вместо списка в метод `join` можно передать простую строку, тогда разделитель будет вставляться между символами этой строки. вообще аргументом годится любой итерируемый объект из строк. элемент другого типа приводит к `TypeError`: `join` строки сам не приводит элементы к `str`.

```python
word = "hello"
joined_word = "|".join(word)
print(joined_word)      # h|e|l|l|o
```
