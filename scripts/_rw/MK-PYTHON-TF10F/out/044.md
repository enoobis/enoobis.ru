модуль в python представляет отдельный файл с кодом, который повторно используется в других программах. при импорте интерпретатор выполняет тело файла и связывает имя модуля с объектом модуля, то есть с отдельным пространством имён.

для создания модуля создаётся файл с расширением `.py`. имя файла без расширения становится именем модуля. в файле определяют одну или несколько функций.

пусть главный файл программы называется `main.py`, и к нему подключаются внешние модули.

новый модуль определяется в той же папке, где лежит `main.py`: файл называется `message.py`. интерпретатор ищет модули по ряду стандартных путей из `sys.path`. один из этих путей указывает на папку главного запускаемого скрипта. оба файла помещают в один проект, чтобы интерпретатор нашёл `message.py` без дополнительной настройки путей.

![модули в python](/uploads/course-lectures/c69edac96d2ac8288dbf997d450126253b2fe80a.png)

модуль называется `message`. в нём записывается следующий код.

```python


hello = "Hello all"





def print_message(text):

    print(f"Message: {text}")
```

здесь определены переменная `hello` и функция `print_message`. функция получает текст параметром и выводит его на консоль.

в основном файле программы, `main.py`, модуль используется так.

```python


import message      # подключаем модуль message



# выводим значение переменной hello

print(message.hello)        # Hello all

# обращаемся к функции print_message

message.print_message("Hello work")  # Message: Hello work
```

для использования модуля его импортируют оператором `import`. после оператора указывается имя модуля: `import message`.

обращение к содержимому модуля идёт через его пространство имён. по умолчанию пространство имён совпадает с именем модуля и в этом примере тоже называется `message`.

получив пространство имён, к функции обращаются по схеме пространство_имен.функция.

обращение к `print_message()` из модуля `message`:

```python
message.print_message("Hello work")
```

после этого запускается главный скрипт `main.py`, и он задействует `message.py`. консольный вывод получается таким.

```bash


Hello all

Message: Hello work
```

### подключение функциональности модуля в глобальное пространство имен

другой вариант связывает функциональность модуля сразу с глобальным пространством имён текущего модуля. для этого служит служебное слово `from`.

```python


from message import print_message



# обращаемся к функии print_message из модуля message

print_message("Hello work")  # Message: Hello work



# переменная hello из модуля message не доступна, так как она не импортирована

# print(message.hello)   

# print(hello)
```

из модуля `message` в глобальное пространство имён импортируется функция `print_message()`. её вызывают без указания пространства имён модуля, как функцию, определённую в этом же файле.

остальные функции и переменные модуля при этом недоступны. в примере выше недоступна переменная `hello`: комментарии показывают оба отвергнутых обращения, через имя модуля и без него. нужные имена подключаются по отдельности.

```python


from message import print_message

from message import hello



# обращаемся к функции print_message из модуля message

print_message("Hello work")  # Message: Hello work



# обращаемся к переменной hello из модуля message

print(hello)    # Hello all
```

если в глобальное пространство имён нужно импортировать весь публичный функционал, вместо имён отдельных функций и переменных ставится символ `*`.

```python


from message import *



# обращаемся к функции print_message из модуля message

print_message("Hello work")  # Message: Hello work



# обращаемся к переменной hello из модуля message

print(hello)    # Hello all
```

импорт в глобальное пространство имён ведёт к коллизиям имён функций. если в том же файле определена функция с тем же именем, вызывается та, которая связана с именем на момент вызова. определение, выполненное позже, перезаписывает имя: до оператора `def` вызов находит функцию из модуля `message`, после `def` то же имя указывает на функцию текущего файла.

```python


from message import *

 

print_message("Hello work")  # Message: Hello work - применяется функция из модуля message



def print_message(some_text):

    print(f"Text: {some_text}")

 

print_message("Hello work")  # Text: Hello work - применяется функция из текущего файла
```

одноимённая функция текущего файла закрывает функцию из подключённого модуля.

звёздочный импорт забирает публичные имена. имя, которое начинается с подчёркивания, в этот набор не входит, пока модуль сам не перечислит его в списке `__all__`. если список `__all__` задан, импортируются только перечисленные в нём имена.

### установка псевдонимов

при импорте модуля и его функциональности им задают псевдонимы. после служебного слова `as` записывается псевдоним. псевдоним модуля задаётся так.

```python


import message as mes  # модуль message проецируется на псевдоним mes



# выводим значение переменной hello

print(mes.hello)        # Hello all

# обращаемся к функии print_message

mes.print_message("Hello work")  # Message: Hello work
```

пространство имён здесь называется `mes`, и через этот псевдоним доступна функциональность модуля. имя `message` в текущее пространство имён не вводится.

так же задаются псевдонимы отдельной функциональности модуля.

```python


from message import print_message as display

from message import hello as welcome



print(welcome)          # Hello all - переменная hello из модуля message

display("Hello work")   # Message: Hello work - функция print_message из модуля message
```

для функции `print_message` из модуля `message` установлен псевдоним `display`, для переменной `hello` установлен псевдоним `welcome`. обращения идут через эти псевдонимы.

псевдоним используется, когда исходные имена функций и переменных не устраивают: они слишком длинные, и их сокращают, либо им дают более точные имена. псевдоним используется и тогда, когда в текущем файле уже есть функциональность с теми же именами. разные имена связываются с разными объектами, и конфликта нет.

```python


from message import print_message as display



def print_message(some_text):

    print(f"Text: {some_text}")



# функция print_message из модуля message

display("Hello work")       # Message: Hello work



# функция print_message из текущего файла

print_message("Hello work")  # Text: Hello work
```

### имя модуля

в примере выше модуль `main.py`, главный, использует модуль `message.py`. при запуске `main.py` программа выполняет всю необходимую работу. если запустить отдельно сам `message.py`, на консоли ничего не будет. модуль `message` только определяет функцию и переменную и не выполняет других действий. модуль можно собрать так, чтобы `message.py` и запускался сам по себе, и подключался в другие модули.

при выполнении модуля среда определяет его имя и присваивает его глобальной переменной `__name__`. с обеих сторон стоят по два подчёркивания. если модуль является запускаемым, его имя равно `__main__`, тоже по два подчёркивания с каждой стороны. если модуль используется в другом модуле, на время выполнения его имя совпадает с названием файла без расширения `py`. это различие и проверяется ниже. содержимое файла `message.py` меняется так.

```python


hello = "Hello all"





def print_message(text):

    print(f"Message: {text}")





def main():

    print_message(hello)





if __name__ == "__main__": 

    main()
```

в `message.py` для тестирования функциональности модуля добавлена функция `main`. файл `message.py` запускается отдельно от остальных, и код модуля проверяется этим запуском.

вызов функции `main` записан так.

```python


if __name__ == "__main__":

    main()
```

переменная `__name__` указывает на имя модуля. у главного модуля, который запускается непосредственно, эта переменная всегда имеет значение `__main__`, независимо от имени файла.

если скрипт `message.py` запускают отдельно, сам по себе, python присваивает `__name__` значение `__main__`. условие в `if` истинно, и вызывается функция `main` из этого же файла.

если запускают другой скрипт, а `message.py` подключают как вспомогательный, для `message.py` переменная `__name__` имеет значение `message`. функция `main` в файле `message.py` не выполняется. тело модуля при импорте всё же выполняется: присваивание `hello` и определения функций происходят в момент загрузки. условный вызов при этом пропускается. повторный импорт того же модуля тело заново не выполняет: интерпретатор возвращает уже загруженный объект модуля.

проверка имени модуля предпочтительнее безусловного вызова `main`. вызов на верхнем уровне сработал бы и при импорте, а проверка отделяет запуск как программы от загрузки как библиотеки.

в файле `main.py` можно поставить ту же проверку, является ли модуль главным. для главного файла она не обязательна.

```python


import message





def main(): 

    message.print_message("Hello work")  # Message: Hello work





if __name__ == "__main__":

    main()
```
