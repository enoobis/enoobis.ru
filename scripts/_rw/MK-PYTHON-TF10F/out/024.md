у python есть встроенные типы, среди них `int` и `str`. ими пользуются непосредственно. собственные типы задают классами. класс описывает сущность: набор атрибутов состояния и методов поведения. объект есть экземпляр класса, конкретный носитель этого состояния.

представление о человеке с именем, возрастом и действиями вроде ходьбы или счёта задаёт класс. отдельный человек с собственным именем есть объект этого класса. экземпляры разделяют определение и различаются состоянием.

класс вводится словом `class`:

```python


class название_класса:

    атрибуты_класса

    методы_класса
```

внутри класса определяют атрибуты, которые хранят характеристики, и методы, то есть функции класса.

простейший класс:

```python


class Person:

    pass
```

класс `Person` условно представляет человека. методов и атрибутов в нём нет. тело класса синтаксически обязано содержать хотя бы одну инструкцию, поэтому стоит пустой оператор `pass`. его ставят там, где грамматика требует тело, а действий по задаче нет.

после класса создают объекты:

```python


class Person:

    pass



tom = Person()      # определение объекта tom

bob = Person()      # определение объекта bob
```

после определения `Person` создаются два объекта этого класса, `tom` и `bob`. объект создаёт конструктор: вызываемая сущность с именем класса, которая возвращает экземпляр. вызов `Person()` есть вызов конструктора. если собственный инициализатор не задан, у класса есть конструктор без параметров:

```python
tom = Person()      # Person() - вызов конструктора, который возвращает объект класса Person
```

### конструкторы

объект класса создаётся конструктором. выше объекты `Person` создавались конструктором по умолчанию: он не принимает параметров и имеется у класса, пока не определён собственный `__init__`. явный конструктор задают методом `__init__()` (по два символа подчёркивания с каждой стороны):

```python


class Person:

    # конструктор

    def __init__(self):

        print("Создание объекта Person")



tom = Person()      # Создание объекта Person
```

в классе `Person` конструктор это функция `__init__`. она принимает как минимум один параметр, ссылку на текущий экземпляр, по соглашению называемую `self`. в конструкторе обычно помещают действия, которые нужны при создании объекта.

создание объекта:

```python


tom = Person()
```

выполняет `__init__()` класса `Person` и печатает строку `Создание объекта Person`.

`__init__` это обычная функция, но в точке вызова пишут имя класса, а не `__init__`. вызывающий код аргумент `self` не передаёт: объект выделяется до входа в `__init__`, а `__init__` инициализирует уже созданный экземпляр. интерпретатор подставляет этот экземпляр первым аргументом.

### атрибуты объекта

атрибуты хранят состояние объекта. внутри класса их устанавливают через `self`. класс с именем и возрастом:

```python


class Person:



    def __init__(self, name, age):

        self.name = name    # имя человека

        self.age = age        # возраст человека





tom = Person("Tom", 22)



# обращение к атрибутам

# получение значений

print(tom.name)     # Tom

print(tom.age)      # 22

# изменение значения

tom.age = 37

print(tom.age)      # 37
```

конструктор `Person` принимает ещё два параметра, `name` и `age`. через них в объект передаются имя и возраст создаваемого человека.

внутри конструктора устанавливаются атрибуты `name` и `age`:

```python


def __init__(self, name, age):

    self.name = name

    self.age = age
```

атрибуту `self.name` присваивается значение параметра `name`. атрибут `age` получает значение параметра `age`. имя атрибута не обязано совпадать с именем параметра: оба имени просто стоят по разные стороны присваивания.

если у `__init__` есть параметры кроме `self`, при вызове конструктора им передают значения:

```python


tom = Person("Tom", 22)
```

параметру `name` передаётся строка `Tom`, параметру `age` число 22.

по имени объекта читают и изменяют его атрибуты:

```python


print(tom.name)     # получение значения атрибута name

tom.age = 37        # изменение значения атрибута age
```

так создают разные объекты `Person` с разным состоянием атрибутов:

```python


class Person:



    def __init__(self, name, age):

        self.name = name    # имя человека

        self.age = age        # возраст человека





tom = Person("Tom", 22)

bob = Person("Bob", 43)



print(tom.name)         # Tom

print(bob.name)         # Bob
```

создаются два объекта класса `Person`, `tom` и `bob`. оба соответствуют одному определению и имеют один набор атрибутов, но состояние у них разное. при каждом вызове интерпретатор заново связывает `self` с создаваемым экземпляром. в вызове

```python


tom = Person("Tom", 22)
```

`self` это объект `tom`. в вызове

```python
bob = Person("Bob", 43)
```

`self` это объект `bob`.

атрибуты не обязательно перечислять в теле класса. python позволяет добавить атрибут экземпляру динамически, присваиванием вне класса:

```python


class Person:



    def __init__(self, name, age):

        self.name = name        # имя человека

        self.age = age          # возраст человека





tom = Person("Tom", 22)



tom.company = "Microsoft"

print(tom.company)  # Microsoft
```

здесь экземпляру назначается атрибут `company`, место работы. после присваивания его читают так же, как `name` и `age`. обращение к атрибуту до присваивания завершается ошибкой: у объекта нет такого имени в его пространстве атрибутов:

```python


tom = Person("Tom", 22)

print(tom.company)  # ! Ошибка - AttributeError: Person object has no attribute company
```

### методы классов

методы класса это функции, определённые в теле класса. они задают поведение объектов. класс с одним методом:

```python


class Person:       # определение класса Person

     def say_hello(self):

        print("Hello")



tom = Person()

tom.say_hello()    # Hello
```

метод `say_hello()` условно выполняет приветствие и печатает строку. у любого метода, как и у конструктора, первый параметр это ссылка на текущий экземпляр. по соглашению его называют `self`, хотя это не служебное слово, а обычное имя параметра. через него метод обращается к состоянию и другим методам этого экземпляра. в записи вызова этот аргумент не указывают: при обращении через объект интерпретатор подставляет экземпляр сам.

вызов метода записывают точечной нотацией: после имени объекта ставится точка и имя метода:

```python
объект.метод([параметры метода])
```

обращение к `say_hello()` для печати приветствия:

```python
tom.say_hello()    # Hello
```

программа выводит на консоль строку `Hello`.

если методу нужны другие параметры, их записывают после `self`. при вызове для них передают значения:

```python


class Person:       # определение класса Person

    def say(self, message):     # метод 

        print(message)



tom = Person()

tom.say("Hello enoobis.ru")    # Hello enoobis.ru
```

метод `say()` принимает два параметра: `self` и `message`. для `message` при вызове передают значение.

к атрибутам и методам объекта внутри класса обращаются через `self`:

```python


self.атрибут    # обращение к атрибуту

self.метод      # обращение к методу
```

класс `Person` с выводом сведений об объекте:

```python


class Person:



    def __init__(self, name, age):

        self.name = name        # имя человека

        self.age = age          # возраст человека

    

    def display_info(self):

        print(f"Name: {self.name}  Age: {self.age}")





tom = Person("Tom", 22)

tom.display_info()      # Name: Tom  Age: 22



bob = Person("Bob", 43)

bob.display_info()      # Name: Bob  Age: 43
```

метод `display_info()` печатает информацию. к атрибутам внутри метода он обращается как `self.name` и `self.age`. консольный вывод:

```bash


Name: Tom  Age: 22

Name: Bob  Age: 43
```

### деструкторы

кроме конструктора класс может определить деструктор, специальный метод, который вызывается при уничтожении объекта. это метод `__del__(self)`. в него, как и в конструктор, передаётся ссылка на текущий объект. в деструкторе помещают действия на момент уничтожения, например освобождение ресурсов, которые объект занимал.

деструктор вызывает интерпретатор. явно его не вызывают. простейший пример:

```python


class Person:

 

    def __init__(self, name):

        self.name = name

        print("Создан человек с именем", self.name)

    

    def __del__(self):

        print("Удален человек с именем", self.name)

 

tom = Person("Tom")
```

деструктор печатает уведомление об удалении объекта `Person`. программа создаёт один объект и хранит ссылку на него в переменной `tom`. создание выполняет конструктор. ссылка живёт до завершения программы, и при завершении для `tom` выполняется деструктор. вывод:

```bash


Создан человек с именем Tom

Удален человек с именем Tom
```

другой пример:

```python


class Person:

 

    def __init__(self, name):

        self.name = name

        print("Создан человек с именем", self.name)

    

    def __del__(self):

        print("Удален человек с именем", self.name)

 



def create_person():

    tom = Person("Tom")

    

create_person()

print("Конец программы")
```

объект `Person` создаётся и используется внутри `create_person`, поэтому время его жизни ограничено этой функцией. когда функция завершается, локальная ссылка исчезает. в стандартной реализации объект уничтожается, когда ссылок на него не остаётся, и деструктор наблюдается сразу после выхода из функции, раньше печати строки завершения. вывод:

```bash


Создан человек с именем Tom

Удален человек с именем Tom

Конец программы
```
