модуль `dataclasses` даёт декоратор `dataclass`. декоратор собирает data-класс: тип, чьё назначение - хранить состояние. по аннотациям полей он генерирует шаблонные специальные методы, и писать их вручную не требуется. обычно у такого класса нет собственного поведения в виде методов, хотя определение методов язык допускает.

то же состояние можно описать обычным классом с явным конструктором:

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

tom = Person("Tom", 38)
print(f"Name: {tom.name}  Age: {tom.age}")      # Name: Tom  Age: 38
```

у класса `Person` в `__init__` два атрибута экземпляра, `name` и `age`. дальше создаётся один экземпляр, и значения атрибутов печатаются. поля записываются присваиванием в теле конструктора. равенство и строковое представление у такого класса остаются стандартными: без `__eq__` оператор `==` сравнивает идентичность объектов.

тот же класс в виде data-класса:

```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int

tom = Person("Tom", 38)
print(f"Name: {tom.name}  Age: {tom.age}")      # Name: Tom  Age: 38
```

декоратор импортируется из `dataclasses` и применяется к `Person`. метод `__init__` в теле не пишется. поля объявляются аннотациями. аннотация описывает поле для декоратора и для статической проверки. во время выполнения python остаётся языком с динамической типизацией и эти аннотации при присваивании не проверяет. сгенерированный `__init__` принимает значения полей в порядке объявления.

объявление сводится к списку полей. одним `__init__` декоратор не ограничивается. data-класс

```python
@dataclass
class Person:
    name: str
    age: int
```

по составу сгенерированных методов соответствует такому определению:

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"Person(name={self.name!r}, age={self.age!r}"
    
    def __eq__(self, other):
        if other.__class__ is self.__class__:
            return (self.name, self.age) == (other.name, other.age)
        return NotImplemented
```

кроме `__init__` появляются `__repr__`, строковое представление для отладки, и `__eq__`, сравнение двух объектов по значениям полей. если класс правого операнда другой, `__eq__` возвращает `NotImplemented`: сравнение передаётся встречному методу. проверка идёт по тождеству `__class__`, поэтому экземпляр подкласса с теми же полями равным не считается. в развёрнутом фрагменте у f-строки `__repr__` нет закрывающей скобки. фактический текст, который печатает декоратор, скобку содержит. вызов сгенерированных методов:

```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int


tom = Person("Tom", 38)
bob = Person("Bob", 42)
tomas = Person("Tom", 38) 
print(tom == tomas)     # True
print(tom == bob)       # False
print(tom)              # Person(name="Tom", age=38)
```

два разных объекта с одинаковыми полями равны по `==`. объект с другими полями не равен. `print` выводит результат `__repr__`.

### параметры декоратора dataclass

параметры декоратора выбирают, какие специальные методы генерировать:

```python
def dataclass(cls=None, /, *, init=True, repr=True, eq=True, order=False,
              unsafe_hash=False, frozen=False, match_args=True,
              kw_only=False, slots=False)
```

базовые параметры:

- `init`: при `True` генерируется `__init__()`. по умолчанию `True`

- `repr`: при `True` генерируется `__repr__()`, строковое представление объекта. по умолчанию `True`

- `eq`: при `True` генерируется `__eq__()`, сравнение двух объектов по полям. по умолчанию `True`

- `order`: при `True` генерируются методы упорядочивания `__lt__` (`<`), `__le__` (`<=`), `__gt__` (`>`), `__ge__` (`>=`). по умолчанию `False`. сравнение лексикографическое, в порядке объявления полей. при `order=True` параметр `eq` остаётся `True`, иначе декоратор поднимает `ValueError`: порядок без равенства был бы несогласован

- `unsafe_hash`: при `True` генерируется `__hash__()`. по умолчанию `False`. хеш не строится, когда объект сравнивается по значению и остаётся изменяемым. равные объекты обязаны иметь равный хеш, а запись в поле после помещения в множество или словарь этот инвариант ломает. флаг включает хеш принудительно, отсюда имя unsafe

в той же сигнатуре есть `frozen`, `match_args`, `kw_only` и `slots`. `frozen=True` запрещает присваивание полям после создания экземпляра. `match_args` по умолчанию равен `True` и порождает `__match_args__` для структурного сопоставления с образцом. `kw_only=True` делает поля аргументами только по имени. `slots=True` кладёт поля в `__slots__`, и у экземпляра нет `__dict__`.

метод, который декоратор построил бы сам, можно задать в теле класса. явная реализация заменяет генерацию одноимённого метода.

применение параметров:

```python
from dataclasses import dataclass

@dataclass(unsafe_hash=True, order=True)
class Person:
    name: str
    age: int
    def __repr__(self):
        return f"Person. Name: {self.name}  Age: {self.age}"


tom = Person("Tom", 38)
print(tom.__hash__())   # -421667297069596717
print(tom)              # Person. Name: Tom  Age: 38
```

здесь включены хеш и методы упорядочивания, а `__repr__` задан в теле класса. строковое представление берётся из этого метода, шаблон декоратора для `__repr__` не используется.

### значения по умолчанию

полю можно задать значение по умолчанию. оно подставляется, когда соответствующий аргумент конструктора опущен. как и у параметров функции, поля со значением по умолчанию идут после полей без него:

```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int = 18


tom = Person("Tom", 38)
print(tom)              # Person(name="Tom", age=38)

bob = Person("Bob")
print(bob)              # Person(name="Bob", age=18)
```

### добавление дополнительного функционала

data-класс хранит данные, и в теле можно определить обычные методы. декоратор такие методы не заменяет:

```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int

    def say_hello(self):
        print(f"{self.name} says hello")


tom = Person("Tom", 38)
tom.say_hello()     # Tom says hello
```
