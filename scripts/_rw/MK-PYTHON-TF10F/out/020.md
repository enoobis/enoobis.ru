в операциях над данными участвуют значения разных типов. например, складываются число типа `int` и число типа `float`:

```python
a = 2       # число int
b = 2.5     # число float
c = a + b
print(c)    # 4.5
```

ошибки здесь нет: результат равен 4.5 и имеет тип `float`. автоматическое приведение python выполняет только внутри числовой иерархии. для остальных сочетаний типов действуют отдельные правила.

### неявные преобразования

операнды одной арифметической операции приводятся к общему числовому типу. если исходные типы различаются, выбор идёт по иерархии `complex`, затем `float`, затем `int`:

- если один операнд имеет тип `complex`, второй приводится к `complex`.
- иначе, если один операнд имеет тип `float`, второй приводится к `float`. так значение переменной `a` в примере выше преобразовано из `int` в `float`.
- иначе оба операнда имеют тип `int`, и преобразование не требуется.

`bool` является подклассом `int`, поэтому логические значения участвуют в арифметике как целые.

### явные преобразования

вне этой иерархии интерпретатор типы сам не смешивает, и преобразование записывают вызовом встроенной функции. следующий код выглядит как сложение двойки и тройки:

```python
a = "2"
b = 3
c = a + b
```

ожидание, что `"2" + 3` даст 5, не выполняется. первый операнд имеет тип `str`, и операция завершается исключением. при запуске появляется трасса такого вида:

```consoletext
Traceback (most recent call last):
  File "/Users/eugene/PycharmProjects/HelloApp/main.py", line 3, in <module>
    c = a + b
TypeError: can only concatenate str (not "int") to str
```

для явных преобразований python предоставляет встроенные функции:

- `int()`: преобразует значение в целое число
- `float()`: преобразует значение в число с плавающей точкой
- `str()`: преобразует значение в строку

#### int

в предыдущем примере строка приводится к числу функцией `int()`:

```python
a = "2"
b = 3
c = int(a) + b
print(c)    # 5
```

примеры преобразований через `int()`:

```python
a = int(15)     # a = 15
b = int(3.7)    # b = 3
c = int("4")    # c = 4
e = int(False)    # e = 0
f = int(True)     # f = 1
```

если значение не разбирается как целое, `int` завершается ошибкой `ValueError: invalid literal for int() with base 10`:

```python
b = int("a1c")    # Ошибка
c = int("4.7")    # Ошибка
```

#### float

функция `float()` преобразует значение в число с плавающей точкой и устроена аналогично `int()`:

```python
a = "2.7"
b = 3
c = float(a) + b
print(c) # 5.7
```

примеры преобразований через `float()`:

```python
a = float(15)       # a = 15.0
b = float(3.7)      # b = 3.7
c = float("4.7")    # c = 4.7
d = float("5")      # d = 5.0
e = float(False)    # e = 0.0
f = float(True)     # f = 1.0
```

в `float` преобразуются тоже не любые значения. в следующем вызове python порождает ошибку `ValueError`:

```python
d = float("abc")  # Ошибка
```

#### str

функция `str()` преобразует значение в строку:

```python
a = str(False)      # a = "False"
b = str(True)       # b = "True"
c = str(5)         # c = "5"
d = str(5.7)       # d = "5.7"
```

`str()` нужна, в частности, когда к строке добавляют значение другого типа. следующий код завершается ошибкой:

```python
age = 22
message = "Age: " + age     # Ошибка
print(message)
```

сложение числа с числом это арифметическое сложение. сложение строки со строкой это конкатенация. для пары `str` и `int` у оператора `+` реализации нет: каждый тип определяет `+` только для своего операнда, и смешение даёт `TypeError`. чтобы выполнить конкатенацию, число сначала переводят в строку функцией `str()`:

```python
age = 22
message = "Age: " + str(age)   # Age: 22
print(message)
```
