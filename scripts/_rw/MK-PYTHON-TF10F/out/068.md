### запись в текстовый файл

текстовый файл в python открывается встроенной функцией `open()`. режим **w** перезаписывает файл, режим **a** дописывает данные в конец, режимы **r+** и **w+** открывают файл одновременно для чтения и для записи. собственно запись выполняет метод `write(str)`: в него передаётся записываемая строка. метод принимает именно строку. числа и значения других типов предварительно преобразуются в строку, потому что текстовый поток оперирует символами, а не внутренним представлением объекта.

в режиме **w** отсутствующий файл создаётся, а существующий обнуляется уже в момент открытия, до первого вызова `write()`. в режиме **a** после открытия указатель позиции стоит за последним байтом, и очередная запись присоединяется к уже лежащему в файле тексту.

запись строки в файл `hello.txt`:

```python


with open("hello.txt", "w") as file:

    file.write("hello world")



print("Файл записан")
```

оператор `with` связывает файловый объект с блоком и вызывает `close()` при выходе из блока, в том числе если внутри блока возникло исключение. после выполнения скрипта в каталоге текущего скрипта python появляется файл `hello.txt`. его можно открыть в любом текстовом редакторе и при необходимости изменить.

дозапись в тот же файл ещё одной строки:

```python


with open("hello.txt", "a") as file:

    file.write("\nhello work")



print("Файл изменен")
```

дозапись присоединяет символы к последнему символу файла. чтобы новая порция началась с отдельной строки, в записываемый текст включают эскейп-последовательность `\n`. в итоге файл `hello.txt` содержит:

```python


hello world

hello work
```

список строк записывает метод `writelines()`. параметром он принимает последовательность строк:

```python


lines = ["Hello Word\n", "Hello Work\n", "Hello World\n"]

with open("hello2.txt", "a") as file:

    file.writelines(lines)

    

print("Список строк записан в файл")
```

`writelines()` не добавляет разделители между элементами. если каждая строка списка должна лежать в файле на своей строке, элемент списка заканчивается символом `\n`.

ещё один способ записи даёт встроенная функция `print()`, которой обычно выводят данные на консоль. аргумент `file` направляет тот же вывод в открытый файл:

```python


with open("hello.txt", "a") as myfile:

    print("\nhello enoobis.ru", file=myfile)
```

первый аргумент `print()` является записываемой строкой. файл передаётся не позицией, а именованным параметром `file`: в сигнатуре `print()` этот параметр стоит после `*` и вызывается только по имени. по умолчанию `print()` дописывает перевод строки, поэтому явный `\n` в тексте нужен тогда, когда требуется дополнительный разрыв сверх стандартного `end`.

### чтение файла

для чтения файл открывают в режиме **r** (read). содержимое затем забирают разными методами:

- `readline()` : считывает одну строку из файла

- `read()` : считывает всё содержимое файла в одну строку

- `readlines()` : считывает все строки файла в список

построчное чтение записанного выше файла:

```python


with open("hello.txt", "r") as file:

    for line in file:

        print(line)
```

явного вызова `readline()` в этом цикле нет, однако при итерации файлового объекта каждая новая строка получается именно через `readline()`. вызывать метод ещё раз вручную внутри цикла не нужно: итератор уже возвращает очередную строку вместе с завершающим `\n`, если перевод строки был записан в файле. консольный вывод:

```bash


hello world



hello work



hello enoobis.ru
```

функция `print()` неявно добавляет к каждой порции вывода перевод строки `\n`, а строки записанного файла тоже разделены символом `\n`. в результате каждая выведенная строка заканчивается двойным `\n`. лишний перенос убирается передачей в `print()` значения `end=""`.

```python


with open("hello.txt", "r") as file:

    for line in file:

        print(line, end="")
```

отдельные строки можно прочитать и явным вызовом `readline()`:

```python


with open("hello.txt", "r") as file:

    str1 = file.readline()      # считываем первую строку

    print(str1, end="")

    str2 = file.readline()      # считываем вторую строку

    print(str2)
```

консольный вывод:

```bash


hello world

hello work
```

`readline()` применим и к построчному чтению в цикле `while`. в конце файла метод возвращает пустую строку `""`, а пустая строка в условии цикла ложна, поэтому цикл останавливается. строка файла, в которой нет ничего, кроме перевода строки, равна `"\n"` и условие не прерывает: пустые строки файла сохраняются.

```python


with open("hello.txt", "r") as file:

    line = file.readline()

    while line:

        print(line, end="")

        line = file.readline()
```

если файл небольшой и целиком помещается в память, его читают одним вызовом `read()`:

```python


with open("hello.txt", "r") as file:

    content = file.read()

    print(content)
```

`readlines()` считывает весь файл в список строк. к отдельной строке затем обращаются по индексу:

```python


with open("hello.txt", "r") as file:

    contents = file.readlines()

    str1 = contents[0]

    str2 = contents[1]

    print(str1, end="")

    print(str2)
```

если кодировка файла отличается от ascii, её задают параметром **encoding**. без этого аргумента текстовый режим декодирует байты кодировкой, которую возвращает локаль. имя кодека `utf8` совпадает с `utf-8`.

```python


filename = "hello.txt"

with open(filename, encoding="utf8") as file:

    text = file.read()
```

### чтение и запись

чтобы открыть файл сразу и для чтения, и для записи, в режим передают один из флагов:

- `r+` : если файл не найден, генерируется исключение `FileNotFoundError`

- `w+` : если файл не существует, он создаётся. если файл существует, он перезаписывается

запись с последующим чтением того же потока:

```python


with open("hello.txt", "w+") as file:

    file.write("Hello world\nHello work\n")  # сначала записываем данные

    file.seek(0)        # перемещаемся к первому байту в файле

    content = file.read()   # считываем данные

    print(content)
```

### перемещение по файлу

после открытия позицию в файле меняет метод `seek()`. в него передаётся индекс байта, на который нужно установить указатель. после записи указатель автоматически стоит в конце файла, а чтение идёт с той позиции, где указатель находится в данный момент. сдвиг в самое начало выполняется вызовом

```python
file.seek(0)
```

тем же способом указатель переносят на нужную позицию. ниже данные читаются со смещения, которое пояснение называет 5-м символом, а аргумент `seek` задаёт как 6-й байт:

```python


with open("hello.txt", "w+") as file:

    file.write("Hello world\n")  # сначала записываем данные

    file.seek(6)                # перемещаемся к шестому байту в файле

    content = file.read()       # считываем данные

    print(content)      # world
```

аргумент `seek()` нумеруется с нуля. в текстовом режиме переносимы только смещение 0 и значения, ранее возвращённые методом `tell()`: произвольный байтовый индекс определён для двоичного режима. в ascii-строке `Hello world` смещение 6 указывает на символ `w`, и дальнейшее чтение возвращает хвост `world`, что и фиксирует комментарий примера.

### пример работы с файлами

следующий скрипт записывает введённый с консоли массив строк и считывает его обратно из файла на консоль. имя файла хранится в `FILENAME`. функция `write()` читает строку через `input()` и дописывает её в конец файла вместе с `\n`. функция `read()` печатает строки файла с `end=""`, затем выводит дополнительный перевод строки, чтобы отделить меню от прочитанного текста. цикл `while` повторяет меню, пока не будет выбран выход. оператор `match` сопоставляет введённый номер с образцами: такая форма доступна начиная с python 3.10. образец `_` принимает любое значение, не совпавшее с предыдущими ветками.

```python


# имя файла

FILENAME = "messages.txt"



# запись строки в файл

def write():

    message = input("Введите строку: ")

    with open(FILENAME, "a") as file:

        file.write(message + "\n")



# чтение файла файл

def read():

    with open(FILENAME, "r") as file:

        for message in file:

            print(message, end="")

    print() # перевод строки для разделения меню и вывода

            

while(True):

    selection = int(input("1.Запись в файл\t\t2.Чтение файла\t\t3.Выход\nВыберите действие: "))

    match selection:

        case 1: write()

        case 2: read()

        case 3: break

        case _: print("Некорректный ввод")

    

print("Программа завершена")
```

пример работы программы:

```bash

Выберите действие: 1

Введите строку: Hello World



1.Запись в файл         2.Чтение файла          3.Выход

Выберите действие: 1

Введите строку: Hello enoobis.ru



1.Запись в файл         2.Чтение файла          3.Выход

Выберите действие: 2

Hello World

Hello enoobis.ru



1.Запись в файл         2.Чтение файла          3.Выход

Выберите действие: 3

Программа завершена
```
