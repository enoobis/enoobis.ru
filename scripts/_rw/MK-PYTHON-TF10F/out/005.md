в предыдущей теме простейший скрипт на python набирался в текстовом редакторе. для набора текста редактора достаточно. другой способ состоит в том, чтобы создавать программу в интегрированной среде разработки, ide.

ide предоставляет текстовый редактор и сверх него подсветку синтаксиса, автодополнение, запуск только что написанного скрипта из того же окна и средства навигации по коду. для python таких сред несколько. одна из наиболее распространённых называется pycharm, её выпускает компания jetbrains. среда продолжает развиваться, регулярно обновляется и доступна для windows, macos и linux. дистрибутив загружают со страницы https://www.jetbrains.com/pycharm/download/ .

![ide pycharm](/uploads/course-lectures/44b3318ad3bdf268e879620cab57e2d78b50625c.png)

на часть регионов страница загрузки закрыта по географическому признаку. тогда сборку берут из репозитория компании на github по адресу https://github.com/JetBrains/intellij-community/releases . там находятся готовые сборки для windows, linux и macos и для архитектур `x86-64` и `ARM64`.

![загрузка pycharm ide](/uploads/course-lectures/1a5c8a5dda12dbcf4f7a01f9b3634f32d79d96cd.png)

после загрузки дистрибутив устанавливают.

![установка pycharm](/uploads/course-lectures/02b4a6ba2c543fe6b0df7a39b095ff2d841248f6.png)

по окончании установки программу запускают. первый запуск открывает начальное окно:

![первая программа в pycharm](/uploads/course-lectures/113b12180112eb9c2b3e35dbdd7182a1cb6a1917.png)

проект создают пунктом `New -> New Project`.

далее открывается окно настройки проекта. в поле `Location` указывают путь к проекту. в примере проект помещается в папку `HelloApp`. имя папки и является именем проекта.

![настройка проекта в pycharm](/uploads/course-lectures/e4af1a4129f966e8b27b8afdfc560db71b1aeb64.png)

кроме пути к проекту остальные настройки оставляют по умолчанию и нажимают кнопку `Create`. после этого создаётся пустой проект:

![первый проект в pycharm](/uploads/course-lectures/2d8056dff84e784154cb9640e11d62abb96a4d41.png)

в центре среды открыт файл `main.py` с тем содержимым, которое среда поместила в него при создании проекта.

простейшую программу получают правкой файла `main.py`:

```python
name = input("Введите ваше имя: ")
print("Привет,", name)
```

скрипт запускают зелёной стрелкой на панели инструментов:

![запуск программы в pycharm](/uploads/course-lectures/12b96393ccf20ad228f9e7c650cb7af603c94793.png)

тот же запуск выполняется через меню `Run`, пункт `Run 'main'`.

после запуска внизу ide открывается окно вывода. в него вводят имя, и там же после ввода появляется приветствие:

![запуск программы python в pycharm](/uploads/course-lectures/42a9f4b6e6b8463a2335a9648d64bd36e1daf538.png)
