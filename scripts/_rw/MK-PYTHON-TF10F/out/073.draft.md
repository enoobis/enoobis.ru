в функции `get_words()` текст сегментируется на слова. файл читается целиком в кодировке `utf8`. переводы строки заменяются пробелами, затем из текста удаляются знаки пунктуации: запятая, точка, вопросительный и восклицательный знаки. остальные символы, в том числе кавычки и дефис, эта цепочка `replace` не трогает, так что границей слова они не становятся. после `lower()` регистр не различает вхождения одного слова. `split()` без аргументов режет строку по любому пробельному символу и отбрасывает пустые фрагменты: разделителем по умолчанию служит пробел и соседние с ним переводы строки и табуляции, уже свёрнутые предыдущей заменой. `sort()` сортирует список на месте, в лексикографическом порядке уже приведённых к нижнему регистру строк. функция возвращает этот список.

функция `get_words_dict()` строит словарь. ключ является уникальным словом, значение является числом вхождений этого слова в тексте. если слово уже есть в словаре, счётчик увеличивается на единицу, иначе ключ создаётся со значением 1. поскольку список перед подсчётом отсортирован, первое появление каждого ключа идёт в порядке сортировки. словарь в python, начиная с версии 3.7, хранит порядок вставки, поэтому дальнейший обход словаря печатает слова в том же порядке.

в функции `main()` вводится путь к файлу, вызываются обе функции и печатается статистика. если `os.path.exists()` возвращает ложь, выводится сообщение об отсутствии файла и подсчёт не начинается. иначе печатаются общее число слов `len(words)`, число уникальных слов `len(words_dict)` и полный перечень: `ljust(20)` дополняет слово пробелами справа до ширины 20, затем печатается счётчик. условие `if __name__ == "__main__"` вызывает `main()` только когда файл запущен как программа, а не импортирован как модуль.
