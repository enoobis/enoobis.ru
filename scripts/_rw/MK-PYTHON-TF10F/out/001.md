### установка

для создания программ на python нужен интерпретатор. его устанавливают со страницы https://www.python.org/downloads/ , где находится ссылка на загрузку последней версии языка:

![установка python](/uploads/course-lectures/968d87027d8984a7c61a623d3fbb438545ca9d84.png)

по нажатию кнопки загружается установщик той операционной системы, на которой открыта страница. windows 7 и более ранние версии windows этим установщиком не поддерживаются.

на windows запуск инсталлятора открывает окно мастера установки:

![установка дистрибутива python 3.12 на windows](/uploads/course-lectures/9ad24999a6bc413d53268d34a5ec677e64ff051a.png)

в этом окне задаётся каталог установки интерпретатора. в разбираемом примере путь оставляют по умолчанию, то есть `C:\Users\[имя_пользователя]\AppData\Local\Programs\Python\Python312\`.

кроме каталога, внизу окна отмечают флажок `Add Python 3.12 to PATH`. флажок дописывает каталог интерпретатора в переменную среды `PATH`. командная оболочка ищет исполняемый файл по каталогам из `PATH` слева направо, поэтому после такой установки имя `python` разрешается без полного пути к `python.exe`.

установку и номер версии затем проверяют в командной строке или в терминале командой `python --version`:

```bash
C:\Users\eugen>python --version
Python 3.12.1

C:\Users\eugen>
```

### запуск интерпретатора

после установки интерпретатора можно выполнять первые программы. если каталог при установке не меняли, на windows интерпретатор лежит по пути `C:\Users\[имя_пользователя]\AppData\Local\Programs\Python\Python[номер_версии]\` и является файлом `python.exe`.

![интерпретатор python](/uploads/course-lectures/e985c60b6063461f8d146755e4fbaccdb4a1f9e4.png)

запуск этого файла открывает интерактивный сеанс. сеанс устроен как цикл read-eval-print: введённая строка компилируется, выполняется, и значение выражения показывается в консоли. в сеанс вводят строку:

```python
print("hello enoobis.ru")
```

консоль выводит текст `hello enoobis.ru`:

```bash
Python 3.12.0 (tags/v3.12.0:0fb18b0, Oct  2 2023, 13:03:39) [MSC v.1935 64 bit (AMD64)] on win32
Type "help", "copyright", "credits" or "license" for more information.
>>> print("hello enoobis.ru")
hello enoobis.ru
>>>
```

в этой программе вызвана встроенная функция `print()`. она записывает переданные аргументы в стандартный поток вывода. в консоли это выглядит как строка текста.

### создание файла программы

в обычной работе программа хранится во внешнем файле-скрипте, и уже файл передаётся интерпретатору. для скриптов создают каталог, в примере он назван `python` и расположен на диске c, хотя каталог может лежать и в другом месте файловой системы. в каталоге создают текстовый файл `hello.py`. для исходного текста на python принято расширение `py`.

![создание скрипта на языке python](/uploads/course-lectures/c55879602d710262b8e9d3044a67cf90c8444b32.png)

файл открывают в любом текстовом редакторе и помещают в него следующий код:

```python
name = input("Введите имя: ")
print("Привет,", name)
```

![python в visual studio code](/uploads/course-lectures/1fe86ea64b2ed8ccab9dee9e9afa57fba714fdc7.png)

скрипт состоит из двух инструкций. первая вызывает `input()` и ждёт, пока пользователь введёт имя. функция читает строку из стандартного ввода до перевода строки и возвращает её как значение типа `str`, уже без завершающего перевода строки. это значение связывается с именем `name`.

вторая инструкция вызывает `print()` и выводит приветствие вместе с введённым именем. несколько аргументов выводятся через пробел.

далее открывают командную строку или терминал и командой `cd` переходят в каталог, где лежит `hello.py`. в примере это каталог `C:\python`:

```bash
cd c:\python
```

затем указывают полный путь к интерпретатору и имя файла скрипта. в примере строка запуска такая:

```bash
C:\Users\eugen\AppData\Local\Programs\Python\Python312\python.exe hello.py
```

если при установке был отмечен флажок `Add Python 3.12 to PATH` и каталог интерпретатора попал в переменные среды, полный путь к `python.exe` не нужен. достаточно имени команды:

```bash
python hello.py
```

на windows есть и более короткая форма через лаунчер `py`. лаунчер сам выбирает установленный интерпретатор и передаёт ему скрипт:

```bash
py hello.py
```

имя `python` берётся из `PATH`, а `py` является отдельной программой выбора интерпретатора. различие становится заметным, когда на машине стоят несколько версий: лаунчер умеет выбрать линию явно. этот случай разбирается в теме про несколько установленных версий.

сеанс с обоими способами запуска выглядит так:

```bash
Microsoft Windows [Version 10.0.22621.2361]
(c) Корпорация Майкрософт (Microsoft Corporation). Все права защищены.

C:\Users\eugen>cd c:\python

c:\python>C:\Users\eugen\AppData\Local\Programs\Python\Python312\python.exe hello.py
Введите имя: Eugene
Привет, Eugene

c:\python>python hello.py
Введите имя: Tom
Привет, Tom

c:\python>py hello.py
Введите имя: Bob
Привет, Bob

c:\python>
```

программа печатает приглашение к вводу имени, после ввода печатает приветствие.
