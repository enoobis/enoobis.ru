циклы повторяют блок инструкций, пока выполняется заданное условие. в python определены два вида циклов:

- while
- for

### цикл while

цикл `while` относится к циклам с предусловием: условие вычисляется перед каждой итерацией, и тело выполняется только при истинном значении. если условие ложно уже при входе, тело не выполняется ни разу. формальное определение:

```python


while условное_выражение:

   инструкции
```

после слова `while` записывается условное выражение. пока оно даёт значение `True`, выполняется следующий блок инструкций. как только выражение становится ложным, управление переходит к первой инструкции после цикла.

все инструкции тела располагаются на последующих строках и имеют отступ от начала строки со словом `while`. в python границы блока задаёт отступ: анализатор порождает служебные признаки увеличения и уменьшения отступа, и по ним тело относится к составному оператору. в c и java ту же роль играют фигурные скобки.

```python


number = 1



while number < 5:

    print(f"number = {number}")

    number += 1

print("Работа программы завершена")
```

цикл выполняется, пока переменная `number` меньше 5. начальное значение равно 1, поэтому тело выполняется несколько раз, а затем условие становится ложным.

тело цикла состоит из двух инструкций:

```python


print(f"number = {number}")

number += 1
```

обе инструкции имеют отступ от начала оператора `while`. по этому отступу интерпретатор относит их к циклу. на каждой итерации сначала выводится текущее значение `number`, затем переменной присваивается значение на единицу больше. без этого присваивания условие оставалось бы истинным, и цикл не завершился бы.

инструкция `print("Работа программы завершена")` отступа от начала строки не имеет, поэтому в тело `while` не входит. она выполняется один раз после выхода из цикла.

ход выполнения разбирается по шагам:

- сначала проверяется, меньше ли `number` пяти. в начале переменная равна 1, условие возвращает `True`, и выполняются инструкции тела. на консоль выводится строка `number = 1`, после чего `number` увеличивается на единицу и становится равной 2. однократное выполнение тела называется итерацией. так завершается первая итерация.
- снова проверяется условие для `number`. показанный далее фрагмент фиксирует первые напечатанные строки:

```consoletext


number = 1

number = 2
```

оператор `continue` передаёт управление к следующей проверке условия и не завершает цикл. оператор `break` завершает цикл сразу, и оставшиеся итерации не выполняются. ниже тот же каркас цикла записан с `continue` вместо `break`:

```python


number = 0

while number < 5:

    number += 1

    if number == 3 :    # если number = 3, переходим к новой итерации цикла

        continue

    print(f"number = {number}")
```

если `number` равно 3, инструкции после `continue` на этой итерации не выполняются. счётчик увеличивается до проверки, поэтому пропуск `print` не мешает условию когда-нибудь стать ложным. по шагам: начальное значение 0; на входе в тело оно становится 1 и печатается; затем 2 печатается; значение 3 пропускает печать; 4 и 5 печатаются; следующая проверка `number < 5` уже ложна. на консоли оказываются 1, 2, 4 и 5:

```consoletext


number = 1

number = 2

number = 4

number = 5
```
