тип `float` в python хранит число в двоичном формате ieee 754. у большинства десятичных дробей, включая `0.1`, нет конечной двоичной записи, поэтому уже короткая сумма показывает накопленную ошибку округления:

```python
number = 0.1 + 0.1 + 0.1
print(number)       # 0.30000000000000004
```

встроенная `round()` округляет уже полученный двоичный результат до заданного числа десятичных знаков и удобна на выводе. модель представления она не меняет: промежуточные значения остаются двоичными `float`. десятичную плавающую точку даёт модуль `decimal`. он следует спецификации ibm general decimal arithmetic, той же модели, что десятичный формат ieee 754-2008: число хранится как целый коэффициент и десятичный показатель степени, и дробь `0.1` представима точно.

рабочий тип модуля - класс `Decimal`. экземпляр строится конструктором. в конструктор передаётся строка с десятичной записью числа:

```python
from decimal import Decimal

number = Decimal("0.1")
```

строка нужна по семантике конструктора. вызов от значения `float` сохранил бы уже округлённое двоичное приближение, и десятичный объект унаследовал бы ту ошибку, из-за которой модуль вообще используют. готовый объект участвует в арифметике. сумма трёх десятых равна ровно `0.3`:

```python
from decimal import Decimal

number = Decimal("0.1")
number = number + number + number
print(number)       # 0.3
```

в одной операции с `Decimal` допустим тип `int`. целые в python имеют неограниченную точность и переводятся в десятичное значение без округления:

```python
number = Decimal("0.1")
number = number + 2
```

операция между `Decimal` и `float` завершается ошибкой. интерпретатор не приводит двоичное значение к десятичному молча, иначе точность расчёта снова стала бы случайной:

```python
number = Decimal("0.1")
number = number + 0.1	# здесь возникнет ошибка
```

нули в конце строкового литерала задают масштаб: число знаков после десятичной точки, то есть отрицательный показатель степени. младший разряд сохраняется, даже когда он равен нулю:

```python
number = Decimal("0.10")
number = 3 * number
print(number)       # 0.30
```

строка `"0.10"` задаёт два знака после точки, строка `"0.100"` задаёт три. умножение на целое `3` в этом фрагменте сохраняет масштаб и печатает `0.30`.

### округление чисел

метод `quantize()` округляет `Decimal` до показателя степени другого экземпляра `Decimal`. этот экземпляр передаётся первым аргументом и задаёт шаг округления, а не слагаемое:

```python
from decimal import Decimal

number = Decimal("0.444")
number = number.quantize(Decimal("1.00"))
print(number)       # 0.44

number = Decimal("0.555678")
print(number.quantize(Decimal("1.00")))       # 0.56

number = Decimal("0.999")
print(number.quantize(Decimal("1.00")))       # 1.00
```

строка `"1.00"` означает два знака после точки: показатель степени у `Decimal("1.00")` равен `-2`. значение `0.444` переходит в `0.44`, `0.555678` в `0.56`, `0.999` в `1.00`.

режим по умолчанию - константа `ROUND_HALF_EVEN`, банковское округление. если отбрасываемая часть лежит ровно посередине между двумя соседними представимыми значениями, сохраняется вариант с чётной последней цифрой. при сложении многих таких полуокруглений систематического сдвига в одну сторону нет: половина случаев уходит вверх, половина вниз.

```python
from decimal import Decimal, ROUND_HALF_EVEN


number = Decimal("10.025")      # 2 - ближайшее четное число
print(number.quantize(Decimal("1.00"), ROUND_HALF_EVEN))       # 10.02

number = Decimal("10.035")      # 4 - ближайшее четное число
print(number.quantize(Decimal("1.00"), ROUND_HALF_EVEN))       # 10.04
```

режим передаётся вторым аргументом `quantize`. строка `"1.00"` по-прежнему держит два знака после точки. у `10.025` сохраняемая цифра - `2`, она чётная, а следующая цифра `5` ставит значение ровно на середину интервала, поэтому цифра не растёт и результат равен `10.02`. у `10.035` сохраняемая цифра - `3`, нечётная, ближайшая чётная - `4`, поэтому хвост `35` переходит в `40` этого разряда и результат равен `10.04`.

другой режим подставляется константой того же модуля. импорт устроен так же, как импорт `ROUND_HALF_EVEN` во фрагменте выше.

- `ROUND_HALF_UP`: к ближайшему значению, а при точной половине - от нуля. для положительного числа это рост сохраняемой цифры, когда следующая цифра равна `5` или больше

- `ROUND_HALF_DOWN`: к ближайшему значению, а при точной половине - к нулю. сохраняемая цифра положительного числа растёт, только если хвост строго больше `5`

```python
number = Decimal("10.026")
print(number.quantize(Decimal("1.00"), ROUND_HALF_DOWN))       # 10.03

number = Decimal("10.025")
print(number.quantize(Decimal("1.00"), ROUND_HALF_DOWN))       # 10.02
```

у `10.026` хвост больше половины разряда, результат `10.03`. у `10.025` хвост равен ровно половине, и `ROUND_HALF_DOWN` оставляет `10.02`.

- `ROUND_05UP`: если округление к нулю оставило бы в последнем разряде цифру `0` или `5` и при этом остаток ненулевой, значение уходит от нуля. в примере лекции это переход нуля в единицу следующего разряда, когда дальше стоит `5` или больше

```python
number = Decimal("10.005")
print(number.quantize(Decimal("1.00"), ROUND_05UP))       # 10.01

number = Decimal("10.025")
print(number.quantize(Decimal("1.00"), ROUND_05UP))       # 10.02
```

у `10.005` округление к нулю дало бы `10.00`, последняя цифра `0`, остаток ненулевой, поэтому результат `10.01`. у `10.025` округление к нулю даёт `10.02`, последняя цифра `2`, условие на `0` и `5` не выполняется, результат остаётся `10.02`.

- `ROUND_CEILING`: в сторону плюс бесконечности при любом ненулевом хвосте

```python
number = Decimal("10.021")
print(number.quantize(Decimal("1.00"), ROUND_CEILING))       # 10.03

number = Decimal("10.025")
print(number.quantize(Decimal("1.00"), ROUND_CEILING))       # 10.03
```

оба положительных значения, `10.021` и `10.025`, переходят в `10.03`. для отрицательного числа тот же режим двигает значение к нулю и дальше, к плюс бесконечности.

- `ROUND_FLOOR`: в сторону минус бесконечности. у положительного числа ненулевой хвост отбрасывается, и сохраняемая цифра не растёт

```python
number = Decimal("10.021")
print(number.quantize(Decimal("1.00"), ROUND_FLOOR))       # 10.02

number = Decimal("10.025")
print(number.quantize(Decimal("1.00"), ROUND_FLOOR))       # 10.02
```

`10.021` и `10.025` оба остаются `10.02`. для отрицательного числа тот же режим увеличивает модуль.

константа режима по умолчанию лежит в контексте десятичной арифметики, `decimal.getcontext().rounding`. аргумент `quantize` перекрывает её на один вызов и контекст процесса не меняет.
