программа на python состоит из набора инструкций. каждая инструкция помещается на новую строку:

```python
print(2 + 3) 
print("Hello")
```

отступы входят в синтаксис языка. неверно поставленный отступ является ошибкой, а не особенностью оформления. следующий фрагмент почти совпадает с предыдущим, однако вторая инструкция сдвинута, и такой текст не выполняется:

```python
print(2 + 3) 
	print("Hello")
```

новую инструкцию верхнего уровня помещают с начала строки. в этом python отличается от c# и java: там отступ не меняет структуру программы, а границы блока задают скобки. здесь принадлежность строки блоку определяется столбцом, в котором она начинается.

часть конструкций занимает несколько строк. такова условная конструкция `if`:

```python
if 1 < 2:
    print("Hello")
```

если 1 меньше 2, выполняется инструкция, печатающая `Hello`. отступ у `print("Hello")` обязателен: инструкция используется не сама по себе, а как часть условной конструкции `if`. она входит в сюиту (suite) этого оператора, то есть в подчинённый блок. согласно [руководству по оформлению кода](https://www.python.org/dev/peps/pep-0008/) отступ желательно делать из числа пробелов, кратного 4: 4, 8, 16 и далее. если отступ равен не 4, а 5 пробелам, программа тоже выполняется: язык требует одинакового отступа у строк одной сюиты, а не конкретной ширины. смешивать в одном блоке пробелы и символы табуляции нельзя.

таких составных конструкций немного, поэтому вопрос, где отступ обязателен, остаётся обозримым. сюиту открывают, в частности, `if`, `for`, `while`, `try`, `with`, `def` и `class`. заголовок каждой из них заканчивается двоеточием, тело сдвинуто относительно заголовка.

### регистрозависимость

python различает регистр в именах, поэтому выражения `print`, `Print` и `PRINT` являются разными именами. `print` имя встроенной функции вывода на консоль. если вместо него написать `Print`, соответствия встроенной функции не будет:

```python
Print("Hello World")
```

такой вызов не выполняется: имя `Print` не связано с функцией вывода.

### комментарии

чтобы отметить, что делает тот или иной участок кода, применяют комментарии. при трансляции и выполнении интерпретатор комментарии игнорирует, на работу программы они не влияют. комментарии в python в изложении курса бывают блочные и строчные.

строчные комментарии предваряются знаком решётки `#`. они могут располагаться на отдельной строке:

```python
# Вывод на консоль 
# сообщения Hello World
print("Hello World")
```

любой набор символов после знака `#` представляет комментарий. в примере выше первые две строки кода являются комментариями.

строчный комментарий может стоять и на той же строке, что и инструкция, после неё:

```python
print("Hello World")  # Вывод сообщения на консоль
```

в блочных комментариях до и после текста ставятся три одинарные кавычки: `'''текст комментария'''`. пример:

```python
''' 
    Вывод на консоль
    сообщения Hello World
'''
print("Hello World")
```

на уровне грамматики три одинарные кавычки задают строковый литерал, а не отдельный вид комментария. если литерал стоит отдельной инструкцией и ни к какому имени не привязан, значение вычисляется и отбрасывается, поэтому запись похожа на комментарий. от знака `#` она отличается тем, что лексер комментарий удаляет из текста, а строковый литерал остаётся в синтаксической структуре. если такой литерал является первой инструкцией модуля, класса или функции, он сохраняется как строка документации в атрибуте `__doc__`.

### основные функции

python предоставляет ряд встроенных функций. некоторые из них используются очень часто, особенно на начальных этапах изучения языка.

основной функцией вывода информации на консоль является `print()`. в качестве аргумента в неё передаётся строка, которую нужно вывести:

```python
print("Hello Python")
```

если на консоль нужно вывести несколько значений, их передают в `print` через запятую:

```python
print("Full name:", "Tom", "Smith")
```

все переданные значения склеиваются через пробелы в одну строку. пробел является разделителем по умолчанию, это параметр `sep`, а не часть самих значений:

```bash
Full name: Tom Smith
```

если `print` отвечает за вывод, то функция `input` отвечает за ввод информации. в качестве необязательного параметра она принимает приглашение к вводу и возвращает введённую строку. возвращаемое значение можно сохранить в переменной:

```python
name = input("Введите имя: ")
print("Привет", name)
```

`input` читает стандартный ввод до перевода строки и возвращает текст типа `str` без этого перевода строки. консольный вывод примера:

```bash
Введите имя: Евгений
Привет Евгений
```
