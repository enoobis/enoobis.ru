основной функционал для работы с датами и временем сосредоточен в модуле `datetime`, в классах:

- `date`

- `time`

- `datetime`

объекты этих классов в конструкторах ниже создаются без часового пояса: это наивные дата и время, в них нет поля `tzinfo`.

### класс date

для дат используется класс `date` из модуля `datetime`. объект создаётся конструктором, который последовательно принимает три параметра: год, месяц и день.

```python
date(year, month, day)
```

создание даты:

```python
import datetime

yesterday = datetime.date(2017,5, 2)
print(yesterday)      # 2017-05-02
```

несуществующий день или месяц конструктор отвергает исключением `ValueError`: поля проходят проверку диапазона при создании, а не при последующем выводе. строковое представление имеет вид `гггг-мм-дд`.

текущую дату возвращает метод `today()`. это местная календарная дата машины, на которой выполняется интерпретатор.

```python
from datetime import date

today = date.today()
print(today)      # 2017-05-03
print("{}.{}.{}".format(today.day, today.month, today.year))      # 2.5.2017
```

свойства `day`, `month` и `year` дают соответственно день, месяц и год.

### класс time

за время суток отвечает класс `time`. объект времени создаётся его конструктором:

```python
time([hour] [, min] [, sec] [, microsec])
```

конструктор последовательно принимает часы, минуты, секунды и микросекунды. все параметры необязательные. параметр, который не передан, инициализируется нулём.

```python
from datetime import time

current_time = time()
print(current_time)     # 00:00:00

current_time = time(16, 25)
print(current_time)     # 16:25:00

current_time = time(16, 25, 45)
print(current_time)     # 16:25:45
```

### класс datetime

класс `datetime` из одноимённого модуля соединяет дату и время в одном объекте. конструктор:

```python
datetime(year, month, day [, hour] [, min] [, sec] [, microsec])
```

первые три параметра, год, месяц и день, обязательны. остальные необязательны и при отсутствии значения инициализируются нулём.

```python
from datetime import datetime

deadline = datetime(2017, 5, 10)
print(deadline)     # 2017-05-10 00:00:00

deadline = datetime(2017, 5, 10, 4, 30)
print(deadline)     # 2017-05-10 04:30:00
```

текущие дату и время возвращает метод `now()`: местное время машины, по-прежнему без привязки к часовому поясу внутри объекта.

```python
from datetime import datetime

now = datetime.now()
print(now)     # 2017-05-03 11:18:56.239443

print("{}.{}.{}  {}:{}".format(now.day, now.month, now.year, now.hour, now.minute))  # 3.5.2017  11:21

print(now.date())
print(now.time())
```

свойства `day`, `month`, `year`, `hour`, `minute`, `second` дают отдельные компоненты даты и времени. методы `date()` и `time()` возвращают отдельно дату и отдельно время, уже как объекты классов `date` и `time`.

### преобразование из строки в дату

у класса `datetime` есть метод `strptime()`, который разбирает строку и строит из неё дату. метод принимает два параметра:

```python
strptime(str, format)
```

первый параметр `str` является строковым представлением даты и времени. второй параметр является форматом и описывает, как части даты и времени расположены в этой строке. если строка не совпадает с форматом, метод поднимает `ValueError`.

коды формата:

- `%d` : день месяца в виде числа

- `%m` : порядковый номер месяца

- `%y` : год в виде 2-х чисел

- `%Y` : год в виде 4-х чисел

- `%H` : час в 24-х часовом формате

- `%M` : минута

- `%S` : секунда

разные форматы одной и той же календарной даты:

```python
from datetime import datetime
deadline = datetime.strptime("22/05/2017", "%d/%m/%Y")
print(deadline)     # 2017-05-22 00:00:00

deadline = datetime.strptime("22/05/2017 12:30", "%d/%m/%Y %H:%M")
print(deadline)     # 2017-05-22 12:30:00

deadline = datetime.strptime("05-22-2017 12:30", "%m-%d-%Y %H:%M")
print(deadline)     # 2017-05-22 12:30:00
```
