модуль `random` управляет генерацией случайных чисел. генератор псевдослучайный: последовательность определяется внутренним состоянием и не предназначена для криптографических задач. основные функции модуля:

- `random()`: число с плавающей точкой от 0.0 до 1.0
- `randint()`: случайное целое из заданного диапазона
- `randrange()`: случайное целое из заданного набора чисел
- `shuffle()`: перемешивает список
- `choice()`: возвращает случайный элемент списка

`random()` возвращает число с плавающей точкой в полуоткрытом интервале от 0.0 включительно до 1.0 не включая. значение из более широкого интервала получается масштабированием. умножение на 100 переносит результат в интервал от 0.0 до 100.0 с тем же исключением правого конца.

```python
import random

number = random.random()  # значение от 0.0 до 1.0
print(number)
number = random.random() * 100  # значение от 0.0 до 100.0
print(number)
```

`randint(min, max)` возвращает случайное целое между двумя границами. обе границы входят в диапазон: результат не меньше `min` и не больше `max`.

```python
import random

number = random.randint(20, 35)  # значение от 20 до 35
print(number)
```

`randrange()` возвращает случайное целое из набора, устроенного как диапазон `range`. у функции три формы.

- `randrange(stop)`: набор от 0 до `stop`, не включая `stop`
- `randrange(start, stop)`: набор от `start` до `stop`, не включая `stop`
- `randrange(start, stop, step)`: набор от `start` до `stop`, не включая `stop`, где соседние значения отличаются на `step`

правая граница в набор не входит, как и у `range`. комментарии в примере перечисляют допустимые значения каждого вызова.

```python
import random

number = random.randrange(10)  # значение от 0 до 10 не включая
print(number)
number = random.randrange(2, 10)  # значение в диапазоне 2, 3, 4, 5, 6, 7, 8, 9
print(number)
number = random.randrange(2, 10, 2)  # значение в диапазоне 2, 4, 6, 8
print(number)
```

### работа со списком

для списков в модуле определены две функции. `shuffle()` переставляет элементы списка на месте: меняется сам переданный список, новый список не создаётся. `choice()` возвращает один элемент непустой последовательности, выбранный равновероятно. вызовы ниже относятся к уже импортированному модулю `random`.

```python
numbers = [1, 2, 3, 4, 5, 6, 7, 8]
random.shuffle(numbers)
print(numbers)  
random_number = random.choice(numbers)
print(random_number)
```
