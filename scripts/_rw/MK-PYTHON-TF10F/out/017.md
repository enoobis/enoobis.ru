### возвращение результата

функция может возвращать результат. для этого служит оператор `return`, после которого записывается возвращаемое значение:

```python
def имя_функции ([параметры]):
    инструкции
    return возвращаемое_значение
```

простейшая функция, возвращающая значение:

```python
def get_message():
    return "Hello enoobis.ru"
```

после `return` стоит строка `"Hello enoobis.ru"`. её и возвращает `get_message()`. результат вызова можно присвоить переменной или подставить туда, где ожидается значение:

```python
def get_message():
    return "Hello enoobis.ru"


message = get_message()  # получаем результат функции get_message в переменную message
print(message)          # Hello enoobis.ru

# можно напрямую передать результат функции get_message
print(get_message())    # Hello enoobis.ru
```

после `return` допустимо и составное выражение: из функции возвращается его значение. функция, удваивающая число:

```python
def double(number):
    return 2 * number
```

функция `double` возвращает значение выражения `2 * number`:

```python
def double(number):
    return 2 * number

result1 = double(4)     # result1 = 8
result2 = double(5)     # result2 = 10
print(f"result1 = {result1}")   # result1 = 8
print(f"result2 = {result2}")   # result2 = 10
```

другой пример, сумма двух чисел:

```python
def sum(a, b):
    return a + b


result = sum(4, 6)                  # result = 0
print(f"sum(4, 6) = {result}")      # sum(4, 6) = 10
print(f"sum(3, 5) = {sum(3, 5)}")   # sum(3, 5) = 8
```

### выход из функции

оператор `return` одновременно возвращает значение и завершает выполнение функции. инструкции, текстуально расположенные после него в том же блоке, недостижимы, поэтому `return` ставят после тех действий, которые ещё должны выполниться. пример:

```python
def get_message():
    return "Hello enoobis.ru"
    print("End of the function")

print(get_message())
```

синтаксически функция корректна, но инструкция `print("End of the function")` недостижима: `return` уже вернул значение и передал управление вызывающему коду.

`return` без выражения применяют и в функциях, которые не вычисляют отдельный результат. результатом такого вызова становится `None`, то же значение, которое функция получает при обычном завершении без `return`. типичный приём: по условию выйти из функции раньше:

```python
def print_person(name, age):
    if age > 120 or age < 1:
        print("Invalid age")
        return
    print(f"Name: {name}  Age: {age}")


print_person("Tom", 22)
print_person("Bob", -102)
```

функция `print_person` принимает имя и возраст. сначала проверяется диапазон: если возраст больше 120 или меньше 1, печатается `Invalid age` и `return` завершает функцию. допустимыми остаются значения от 1 до 120 включительно. при корректном возрасте на консоль выводится информация о человеке. вывод программы:

```bash
Name: Tom  Age: 22
Invalid age
```
