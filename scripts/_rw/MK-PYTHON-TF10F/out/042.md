упаковка и распаковка постоянно встречаются в параметрах функций. в определениях часто стоят параметры `*args` и `**kwargs`.

имена `args` и `kwargs` являются соглашением языка python. на их месте допустимы любые идентификаторы. смысл задаёт число звёзд перед именем. выбранный идентификатор на упаковку не влияет. `*args` собирает аргументы, переданные по позиции. `**kwargs` собирает аргументы, переданные по имени.

оператор `*` применяется к любому итерируемому объекту: к кортежу, к списку, к строке. оператор `**` применяется к словарям.

### *args

оператор `*` позволяет передать в функцию несколько значений. все они упаковываются в один кортеж, и этот кортеж связывается с параметром.

```python
def fun(*args):
    # обращаемся к первому элементу кортежа
    print(args[0])
 
    # выводим весь кортеж
    print(args)
 
fun("Python", "C++", "Java", "C#")
```

функция `fun` принимает кортеж значений. при вызове ей передаётся любое число позиционных аргументов. четыре строки из примера становятся одним кортежем. тело читает элемент с индексом 0 и печатает кортеж целиком. консольный вывод:

```bash
Python
('Python', 'C++', 'Java', 'C#')
```

за счёт этого функция принимает переменное число значений. в `sum` аккумулятор начинается с нуля, цикл прибавляет каждый элемент кортежа, и функция возвращает сумму. три вызова отличаются только числом аргументов.

```python
def sum(*args):
	result = 0 
	for arg in args: 
		result += arg
	return result
 
print(sum(1, 2, 3))			# 6
print(sum(1, 2, 3, 4))		# 10
print(sum(1, 2, 3, 4, 5))	# 15
```

### оператор **

оператор `**` упаковывает аргументы, переданные по имени, в словарь. имена параметров становятся ключами, значения аргументов становятся значениями словаря.

```python
def fun(**kwargs):
    print(kwargs)	# выводим словарь на консоль
 
fun(name="Tom", age="38", company="Google")
fun(language="Python", version="3.11")
```

два вызова передают разные наборы имён, и напечатанные словари содержат именно эти пары. консольный вывод:

```bash
{'name': 'Tom', 'age': '38', 'company': 'Google'}
{'language': 'Python', 'version': '3.11'}
```

поскольку внутри функции аргументы доступны как словарь, их значения читаются по ключам. цикл перебирает ключи и печатает пару «имя = значение».

```python
def fun(**kwargs):
    for key in kwargs:
        print(f"{key} = {kwargs[key]}")
 
fun(name="Tom", age="38", company="Google")
```

консольный вывод:

```bash
name = Tom
age = 38
company = Google
```

### распаковка аргументов

те же операторы `*` и `**` не только упаковывают аргументы в кортеж и словарь, но и распаковывают уже собранную коллекцию в вызове.

#### оператор * и распаковка

ситуация, в которой распаковка необходима, видна на передаче кортежа в функцию с параметром `*args`.

```python
def sum(*args):
  result = 0
  for arg in args:
    result += arg
  return result
 
numbers = (1, 2, 3, 4, 5)
print(sum(numbers))
```

в вызов `sum` передаётся кортеж `numbers`. параметр `*args` тоже связан с кортежем, и по внешнему виду вызов кажется согласованным. выполнение завершается ошибкой.

```bash
TypeError: unsupported operand type(s) for +=: 'int' and 'tuple'
```

кортеж `numbers` попадает в `*args` как один элемент. на первой итерации к целому `result` прибавляется этот кортеж, и операция `+=` для такой пары типов не определена.

чтобы элементы кортежа попали в `*args` по отдельности, кортеж распаковывают в точке вызова.

```python
def sum(*args):
  result = 0
  for arg in args:
    result += arg
  return result
 
numbers = (1, 2, 3, 4, 5)
# применяем распаковку - *numbers
print(sum(*numbers))     # 15
```

запись `*numbers` раскладывает кортеж на отдельные позиционные аргументы. `sum` получает пять чисел и возвращает их сумму.

другой случай: у функции несколько обычных параметров, а данные уже лежат в одном кортеже или списке.

```python
def print_person(name, age, company):
  print(f"Name:{name}, Age: {age}, Company: {company}")
 
person =("Tom", 38, "Google")
# выполняем распаковку кортежа person
print_person(*person)	# Name:Tom, Age: 38, Company: Google
```

выражение `*person` раскладывает кортеж на отдельные значения. они связываются с параметрами `name`, `age` и `company` по позиции.

#### оператор ** и распаковка

оператор `**` распаковывает словарь в именованные аргументы.

```python
def print_person(name, age, company):
  print(f"Name:{name}, Age: {age}, Company: {company}")
 
tom ={"name":"Tom", "age":38, "company":"Google"}
# выполняем распаковку словаря tom
print_person(**tom)	# Name:Tom, Age: 38, Company: Google
```

выражение `**tom` раскладывает словарь на пары. значение попадает в параметр, имя которого совпадает с ключом. `name`, `age` и `company` заполняются по названиям ключей. порядок пар в литерале на это связывание не влияет.

### сочетание параметров

`*args` и `**kwargs` стоят в одном определении вместе с обычными параметрами. имена по-прежнему выбираются свободно. в примере первые два позиционных аргумента связываются с `num1` и `num2`, а все позиционные аргументы сверх этих двух собираются в кортеж `nums`.

```python
def sum(num1, num2, *nums):
    result=num1+num2
    for n in nums:
        result += n
    return result

print(sum(1,2,3))		# 6
print(sum(1,2,3,4))		# 10
```
