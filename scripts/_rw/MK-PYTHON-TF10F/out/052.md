модуль `timeit` измеряет длительность коротких фрагментов кода. основная функция модуля, `timeit()`, возвращает суммарное время заданного числа выполнений действия. единица результата - секунда:

```python
timeit.timeit(stmt='pass', setup='pass', timer=<default timer>, number=1000000, globals=None)
```

параметры функции:

- `stmt`: измеряемое действие. это строка с кодом или вызываемый объект без аргументов. по умолчанию строка `pass`

- `setup`: код, который выполняется один раз до серии измерений. по умолчанию тоже `pass`. сюда помещают импорт модулей, нужных измеряемому фрагменту. длительность setup в результат не входит

- `timer`: функция отметки времени без аргументов. значение по умолчанию выбирается под платформу и совпадает с `timeit.default_timer`. параметр обычно оставляют как есть

- `number`: сколько раз выполнить stmt. по умолчанию 1000000. повтор нужен, чтобы шум планировщика и шаг системных часов не преобладали над коротким фрагментом

- `globals`: пространство имён для кода, заданного строкой. словарь глобальных переменных вызывающего кода делает видимыми его функции и имена

возвращается сумма длительностей всех повторов, число с плавающей точкой, а не среднее. среднее равно этой сумме, делённой на `number`.

на время измерения функция по умолчанию отключает сборщик мусора. соседние прогоны тогда меньше расходятся из-за случайного цикла gc. если сборка мусора входит в стоимость измеряемого кода, отключение сдвигает оценку.

пример:

```python
import timeit  # модуль для работы с таймерами

# тестируемая функция - вычисляет сумму чисел от 1 до 10000
def sum():
    result = 0
    for i in range(10000): 
        result +=i
    return result

# Функция timeit.timeit возвращает время выполнения функции в секундах
# Первый параметр представляет выполняемую функцию
# Параметр number указывает на число выполнений. По умолчанию равен 1000000
# В нашем случае выполняем функцию sum 100 раз
execution_time = timeit.timeit(lambda: sum(), number=100)

print("Время выполнения функции sum:", execution_time)
```

измеряемое действие - лямбда, которая вызывает функцию `sum`. тело функции складывает целые из `range(10000)`, то есть числа от 0 до 9999 включительно. комментарий фрагмента формулирует тот же диапазон как сумму от 1 до 10000. параметр `number` равен 100: в замер входят сто вызовов. имя `sum` в этом фрагменте перекрывает встроенную функцию с тем же именем. результат попадает в `execution_time` и печатается. типичный вывод:

```bash
eugene@Eugene:$ python3 app.py
Время выполнения функции sum: 0.01668926700222073
```

конкретное число зависит от машины, нагрузки и версии интерпретатора. строка вывода - образец одного прогона, а не норматив.

### установка действия

в первом примере действие задано лямбдой, которая вызывает функцию из текста программы. то же действие можно передать строкой:

```python
import timeit 

# код, выполнение которого измеряем
action = "10+12"

print(timeit.timeit(action))
```

измеряется код `"10+12"`. параметр `number` опущен, поэтому строка выполняется 1000000 раз.

несколько инструкций в одной строке разделяются точкой с запятой:

```python
import timeit 

action = "a=10; b=12; a+b"

print(timeit.timeit(action))
```

когда инструкций больше и среди них есть ветвления или циклы, фрагмент записывают в тройных кавычках:

```python
import timeit 

action = ''' 
def sum():
    result = 0
    for n in range(100): 
        result += n
    return result
'''

print(timeit.timeit(action))
```

строка этого фрагмента содержит определение функции `sum` и не содержит её вызова. в замер входит повторное выполнение оператора `def`: создание объекта функции и привязка имени. тело цикла при таком stmt не исполняется. чтобы измерить сам цикл, в строку включают вызов либо передают вызываемый объект, как в первом примере лекции.

### настройка

функцию из другого модуля импортируют в параметре `setup`. импорт выполняется до цикла измерений и в длительность не входит. пусть в модуле `test` определена функция `sum_test()`. запуск выглядит так:

```python
import timeit

my_action = "sum_test()"
my_setup = "from test import sum_test"
print(timeit.timeit(my_action, setup=my_setup))
```

### применение таймеров

отметки времени для `timeit()` даёт таймер. класс, которым модуль это оформляет:

```python
class timeit.Timer(stmt='pass', setup='pass', timer=<default timer>, number=1000000, globals=None)
```

`timeit.Timer` хранит измеряемый оператор, код подготовки, функцию таймера и пространство имён. число повторений принимает метод `Timer.timeit` и одноимённая функция модуля. в приведённой строке конструктора `number` стоит рядом с остальными параметрами. отметку времени текущей платформы возвращает `timeit.default_timer()`: монотонные часы высокого разрешения, на большинстве платформ это `time.perf_counter`. ручной замер одного прогона без серии повторов:

```python
import timeit 

def sum():
    result = 0
    for n in range(100): 
        result += n
    return result

start = timeit.default_timer()
print("Start time:", start)
sum()
print("Execution time:", timeit.default_timer() - start)
```

`default_timer()` читается до вызова `sum` и после него. разность равна прошедшему времени одного выполнения. в один прогон входит шум операционной системы, поэтому для короткого фрагмента берут многократный замер через `timeit()`.
