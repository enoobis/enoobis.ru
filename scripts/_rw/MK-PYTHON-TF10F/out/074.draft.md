**zip** является широко используемым форматом архивации и сжатия файлов. в python для него есть встроенный модуль `zipfile`. модуль создаёт, читает и записывает zip-файлы, получает их содержимое и добавляет в архив новые файлы. чтение архива, закрытого традиционным шифром zipcrypto, поддерживается: пароль задаётся методом `setpassword()` либо аргументом `pwd` при извлечении и чтении. записать зашифрованный архив модуль не может.

параметры:

- `file` : путь к zip-файлу

- `mode` : режим открытия файла. принимает следующие значения: `r` применяется для чтения существующего файла

- `w` : применяется для записи нового файла

- `a` : применяется для добавления в файл

- `compression` : тип сжатия файла при записи. принимает значения: `ZIP_STORED` означает архивацию без сжатия (значение по умолчанию)

- `ZIP_DEFLATED` : стандартный тип сжатия при архивации в zip, алгоритм deflate

- `ZIP_BZIP2` : сжатие способом bzip2

- `ZIP_LZMA` : сжатие способом lzma

- `allowZip64` : если равно `True`, zip-файл может быть больше 4 гб. формат zip изначально хранит размеры в 32-битных полях, и без расширения zip64 архив упирается в этот предел

- `compresslevel` : уровень сжатия при записи файла. для типов сжатия `ZIP_STORED` и `ZIP_LZMA` не применяется. для типа `ZIP_DEFLATED` допустимые значения от 0 до 9, а для типа `ZIP_BZIP2` допустимые значения от 1 до 9

- `strict_timestamps` : при значении `False` позволяет работать с zip-файлами, созданными ранее 01.01.1980 и позже 31.12.2107. эти границы задаёт формат времени dos, в котором zip хранит отметку времени

- `metadata_encoding` : применяется для декодирования метаданных zip-файла, например комментариев и имён, если у записи не выставлен признак кодировки utf-8

для работы с файлами класс предоставляет методы:

- `close()` : закрывает zip-файл

- `getinfo()` : возвращает информацию об одном файле из архива в виде объекта `ZipInfo`

- `namelist()` : возвращает список файлов архива

- `infolist()` : возвращает информацию обо всех файлах из архива в виде списка объектов `ZipInfo`

- `open()` : предоставляет доступ к одному из файлов в архиве

- `read()` : считывает файл из архива в набор байтов

- `extract()` : извлекает из архива один файл

- `extractall()` : извлекает все элементы из архива

- `setpassword()` : устанавливает пароль для zip-файла

- `printdir()` : выводит на консоль содержимое архива
