### генерация исключений и оператор raise

иногда исключение нужно сгенерировать явно. для этого служит оператор `raise`:

```python
try:
    age = int(input("Введите возраст: "))
    if age > 110 or age < 1:
        raise Exception("Некорректный возраст")
    print("Ваш возраст:", age)
except ValueError:
    print("Введены некорректные данные")
except Exception as e:
    print(e)
print("Завершение программы")
```

оператору `raise` передаётся объект `BaseException`. в примере это объект `Exception`. в конструктор типа можно передать сообщение, которое затем видит пользователь. если `age` больше 110 или меньше 1, выполняется `raise`, и управление переходит к блоку `except`, обрабатывающему исключения типа `Exception`:

```bash
Введите возраст: 100500
Некорректный возраст
Завершение программы
```

порядок ветвей здесь такой же, как при разборе нескольких типов. `ValueError` является подклассом `Exception`, поэтому ветвь `except ValueError` стоит раньше ветви `except Exception`. она забирает ошибку преобразования `int`. ветвь `Exception` получает уже собственно вызванный `raise`, а также любой другой наследник `Exception`, не пойманный выше. если бы обработчик `Exception` стоял первым, до ветви `ValueError` выполнение бы не доходило.

### создание своих типов исключений

python не ограничивается встроенными типами исключений. собственные типы создают наследованием. исходный класс `Person`:

```python
class Person:
    def __init__(self, name, age):
        self.__name = name  # устанавливаем имя
        self.__age = age   # устанавливаем возраст

    def display_info(self):
        print(f"Имя: {self.__name}  Возраст: {self.__age}")
```

конструктор `Person` получает имя и возраст и присваивает их приватным атрибутам `__name` и `__age`. при создании объекта в конструктор можно передать значение, некорректное с точки зрения предметной логики, например отрицательное число. один из способов остановить такое создание состоит в генерации исключения при передаче некорректных значений.

текст программы:

```python
class PersonAgeException(Exception):
    def __init__(self, age, minage, maxage):
        self.age = age
        self.minage = minage
        self.maxage = maxage

    def __str__(self):
        return f"Недопустимое значение: {self.age}. " \
               f"Возраст должен быть в диапазоне от {self.minage} до {self.maxage}"


class Person:
    def __init__(self, name, age):
        self.__name = name  # устанавливаем имя
        minage, maxage = 1, 110
        if minage < age < maxage:   # устанавливаем возраст, если передано корректное значение
            self.__age = age
        else:                       # иначе генерируем исключение
            raise PersonAgeException(age, minage, maxage)

    def display_info(self):
        print(f"Имя: {self.__name}  Возраст: {self.__age}")

try:
    tom = Person("Tom", 37)
    tom.display_info()  # Имя: Tom 	Возраст: 37

    bob = Person("Bob", -23)
    bob.display_info()
except PersonAgeException as e:
    print(e)    # Недопустимое значение: -23. Возраст должен быть в диапазоне от 1 до 110
```

в начале определён класс `PersonAgeException`, наследник `Exception`. собственные классы исключений наследуют `Exception`, чтобы попадать в обычный перехват ошибок приложения и не смешиваться с `SystemExit` и `KeyboardInterrupt`, которые наследуют `BaseException` напрямую. `PersonAgeException` предназначен для исключений, связанных с возрастом.

конструктор `PersonAgeException` получает три значения: некорректный возраст, из-за которого возникло исключение, а также минимальное и максимальное значения возраста.

```python
class PersonAgeException(Exception):
    def __init__(self, age, minage, maxage):
        self.age = age
        self.minage = minage
        self.maxage = maxage

    def __str__(self):
        return f"Недопустимое значение: {self.age}. " \
               f"Возраст должен быть в диапазоне от {self.minage} до {self.maxage}"
```

в методе `__str__` задано текстовое представление класса, по сути сообщение об ошибке. `print` исключения вызывает именно `__str__`. конструктор не передаёт строку в `Exception.__init__`, поэтому кортеж `args` базового класса остаётся пустым, а текст сообщения целиком формирует переопределённый `__str__`.

в конструкторе класса `Person` проверяется переданное значение возраста. если значение не попадает в заданный диапазон, генерируется исключение `PersonAgeException`:

```python
raise PersonAgeException(age, minage, maxage)
```

условие записано цепочкой сравнений `minage < age < maxage`, то есть возраст должен быть строго больше нижней границы и строго меньше верхней. значения 1 и 110 в этот интервал не входят и тоже приводят к `raise`.

при использовании класса `Person` учитывают, что конструктор может сгенерировать исключение на некорректном значении. создание объектов оборачивают в `try`/`except`:

```python
try:
    tom = Person("Tom", 37)
    tom.display_info()  # Имя: Tom 	Возраст: 37

    bob = Person("Bob", -23)  # генерируется исключение типа PersonAgeException
    bob.display_info()
except PersonAgeException as e:
    print(e)    # Недопустимое значение: -23. Возраст должен быть в диапазоне от 1 до 110
```

вызов `raise` внутри `__init__` означает, что конструктор не возвращает экземпляр: имя справа от присваивания не связывается. в примере объект `tom` создаётся успешно, и `display_info` для него выполняется. создание `bob` выбрасывает `PersonAgeException`, остаток блока `try`, включая `bob.display_info`, не выполняется, и управление переходит к `except`. этот блок обрабатывает `PersonAgeException` и выводит сведения об исключении на консоль. более общие ветви `except Exception` это исключение тоже поймали бы, потому что `PersonAgeException` является подклассом `Exception`. отдельная ветвь позволяет отличить ошибку возраста от прочих сбоев.
