выполнение скрипта на python в общем случае делится на две стадии.

- файл с кодом, то есть файл с расширением `.py`, компилируется в промежуточный байткод
- далее байткод интерпретируется, и на этой стадии программа собственно выполняется

явно порождать байткод не требуется. интерпретатор создаёт его сам, когда скрипт запускают. если программа импортирует внешние модули или библиотеки и этот импорт происходит впервые, скомпилированный байткод сохраняется в файле с расширением `.pyc` и кэшируется в каталоге `__pycache__` рядом с исходным файлом. когда исходный файл библиотеки меняется, python перекомпилирует байткод. когда изменений нет, загружается уже скомпилированный байткод из файла `.pyc`. повторная компиляция пропускается, и запуск выполняется быстрее.

байткод основного скрипта, того файла, который передают интерпретатору python как программу, в `.pyc` не сохраняется. этот файл компилируется заново при каждом запуске.

пусть в папке проекта лежит `user.py` с функцией двух параметров. функция печатает оба значения.

```python
def printUser(username, userage):
    print(f"Name: {username}  Age:{userage}")
```

этот файл подключается в главном модуле `app.py`.

```python
import user
username = "Tom"
userage = 39

user.printUser(username, userage)
```

при выполнении `app.py` в папке проекта, там, где лежит `user.py`, создаётся каталог `__pycache__`. в нём появляется файл байткода вида `user.cpython-версия.pyc`. на месте версии стоит номер используемого интерпретатора, например `311` для python 3.11. файл `.pyc` бинарный, открывать его в текстовом редакторе бессмысленно: в нём лежит байткод и служебный заголовок.

### ручная компиляция байткода

файл байткода создаётся автоматически, но его можно породить и вручную. для этого есть два способа: компиляция скриптом `py_compile` и компиляция модулем `compileall`.

`py_compile` компилирует отдельные файлы. произвольный скрипт `user.py` компилируется такой программой.

```python
import py_compile

py_compile.compile("user.py")   # передаем путь к скрипту
```

в `compile()` передаётся путь к скрипту. после выполнения в текущей папке снова появляется каталог `__pycache__`, а в нём файл `user.cpython-311.pyc`.

модуль `compileall` компилирует все файлы python по указанным путям. каталог `C:/python/files` целиком компилируется командой ниже.

```bash
python -m compileall c:\python\files
```

по умолчанию компилируются и файлы во вложенных каталогах. если нужны только файлы, которые лежат непосредственно в указанной папке, добавляется опция `-l`. обход подкаталогов тогда не выполняется.

```bash
python -m compileall c:\python\files -l
```
