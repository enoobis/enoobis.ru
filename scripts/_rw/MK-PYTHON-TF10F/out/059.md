в прошлых темах в строку вставляются значения с помощью символа `f` перед литералом. выражения стоят в фигурных скобках и вычисляются при выполнении.

```python
first_name="Tom"
text = f"Hello, {first_name}."
print(text)     # Hello, Tom.

name="Bob"
age=23
info = f"Name: {name}\t Age: {age}"
print(info)     # Name: Bob	 Age: 23
```

альтернативу даёт метод `format()`. этот метод форматирует строку, вставляя на место плейсхолдеров переданные значения. для вставки используются параметры, которые обрамляются фигурными скобками `{}`.

### именованные параметры

в форматируемой строке параметры задаются именами. в методе `format()` для этих параметров передаются значения под теми же именами.

```python
text = "Hello, {first_name}.".format(first_name="Tom")
print(text)     # Hello, Tom.

info = "Name: {name}\t Age: {age}".format(name="Bob", age=23)
print(info)     # Name: Bob	 Age: 23
```

аргументы метода `format` определяются с тем же именем, что и параметры в строке. если параметр называется `first_name`, как в первом случае, то и аргумент, которому присваивается значение, называется `first_name`. отсутствующее имя поднимает `KeyError`. лишний именованный аргумент в подстановку не входит.

### параметры по позиции

в метод `format` можно последовательно передать набор аргументов, а в форматируемой строке вставить эти аргументы, указывая в фигурных скобках их номер. нумерация начинается с нуля.

```python
info = "Name: {0}\t Age: {1}".format("Bob", 23)
print(info)     # Name: Bob	 Age: 23
```

один и тот же аргумент можно вставить в строку множество раз: номер в скобках повторяется.

```python
text = "Hello, {0} {0} {0}.".format("Tom")
```

здесь имя `text` получает строку, в которой единственный аргумент `Tom` подставлен на каждое место `{0}`.

### подстановки

ещё один способ передать форматируемые значения это подстановки, специальные плейсхолдеры. на их место вставляются значения, а код внутри скобок задаёт, как значение показать. для форматирования используются следующие плейсхолдеры:

- `s`: для вставки строк
- `d`: для вставки целых чисел
- `f`: для вставки дробных чисел. для этого типа также можно определить через точку количество знаков в дробной части
- `%`: умножает значение на 100 и добавляет знак процента
- `e`: выводит число в экспоненциальной записи

код согласован с типом значения. `s` применяется к строке, `d` к целому. код `s` для объекта типа `int` поднимает `ValueError`.

общий синтаксис плейсхолдера следующий:

```python
{:плейсхолдер}
```

в зависимости от плейсхолдера можно добавлять дополнительные параметры. для форматирования чисел `float` используются следующие параметры:

```python
{:[количество_символов][запятая][.число_знаков_в_дробной_части] плейсхолдер}
```

при вызове метода `format` в него в качестве аргументов передаются значения, которые вставляются на место плейсхолдеров. если номер и имя не указаны, аргументы занимают плейсхолдеры по порядку.

```python
welcome = "Hello {:s}"
name = "Tom"
formatted_welcome = welcome.format(name)
print(formatted_welcome)		# Hello Tom
```

в качестве результата метод `format()` возвращает новую отформатированную строку. строка, у которой метод вызван, остаётся прежней: тип `str` неизменяем.

форматирование целых чисел:

```python
source = "{:d} символов"
number = 5
target = source.format(number)
print(target)   # 5 символов
```

если форматируемое число больше 999, в определении плейсхолдера можно указать запятую в качестве разделителя разрядов. эта запятая принадлежит спецификации формата и не зависит от локали процесса.

```python
source = "{:,d} символов"
print(source.format(5000))   # 5,000 символов
```

плейсхолдеры можно использовать и в f-строках. спецификация пишется после выражения, через двоеточие.

```python
n = 5000
source = f"{n:,d} символов"
print(source)   # 5,000 символов
```

для дробных чисел, то есть таких, которые представляют тип `float`, перед кодом плейсхолдера после точки можно указать, сколько знаков в дробной части вывести. число знаков фиксировано: лишние разряды округляются, недостающие дописываются нулями, как в спецификации `{:.4f}`.

```python
number = 23.8589578
print("{:.2f}".format(number))   # 23.86
print("{:.3f}".format(number))   # 23.859
print("{:.4f}".format(number))   # 23.8590
print("{:,.2f}".format(10001.23554))    # 10,001.24
```

ещё один параметр устанавливает минимальную ширину форматируемого значения в символах. если текст короче поля, недостающие позиции заполняются пробелами. для чисел выравнивание по умолчанию правое, поэтому пробелы оказываются слева. `{:.2f}` для `23.8589578` даёт `23.86`, и в поле шириной 10 слева остаются пробелы. `{:8d}` для `25` занимает восемь позиций.

```python
print("{:10.2f}".format(23.8589578))    #     23.86
print("{:8d}".format(25))               #      25
```

аналогичный пример с f-строками даёт тот же текст: спецификация после двоеточия у f-строки и у `format()` одна и та же.

```python
n1 = 23.8589578
print(f"{n1:10.2f}")    #     23.86
n2 = 25
print(f"{n2:8d}")       #      25
```

для вывода процентов используется код `%`. значение умножается на 100, затем добавляется знак процента. число знаков после точки задаётся так же, как у дробного формата. `{:%}` для `.12345` показывает шесть знаков дробной части, `{:.0%}` оставляет `12%`, `{:.1%}` оставляет один знак.

```python
number = .12345
print("{:%}".format(number))        # 12.345000%
print("{:.0%}".format(number))      # 12%
print("{:.1%}".format(number))      # 12.3%

print(f"{number:%}")        # 12.345000%
print(f"{number:.0%}")      # 12%
print(f"{number:.1%}")      # 12.3%
```

для вывода числа в экспоненциальной записи применяется плейсхолдер `e`. точность по умолчанию у `e`, как и у `f`, равна шести знакам после точки, поэтому `12345.6789` получает вид `1.234568e+04`. `{:.0e}` оставляет одну цифру мантиссы, `{:.1e}` одну цифру после точки.

```python
number = 12345.6789
print("{:e}".format(number))        # 1.234568e+04
print("{:.0e}".format(number))      # 1e+04
print("{:.1e}".format(number))      # 1.2e+04

print(f"{number:e}")        # 1.234568e+04
print(f"{number:.0e}")      # 1e+04
print(f"{number:.1e}")      # 1.2e+04
```

### форматирование без метода format

существует ещё один способ форматирования, со следующим синтаксисом:

```python
строка%(параметр1, параметр2,..параметрN)
```

в начале идёт строка, которая содержит те же плейсхолдеры, которые были рассмотрены выше, за исключением плейсхолдера `%`. после строки ставится знак процента `%`, а затем список значений, которые вставляются в строку. знак процента здесь представляет операцию: у строки оператор `%` строит новую строку. рядом с плейсхолдером указывается знак процента, получаются коды `%s`, `%d`, `%f`, `%e`. в отличие от метода `format` фигурные скобки не требуются. при нескольких значениях справа стоит кортеж, и его элементы сопоставляются плейсхолдерам слева направо.

```python
info = "Имя: %s \t Возраст: %d" % ("Tom", 35)Hello World     !
print(info)   # Имя: Tom 	 Возраст: 35
```

после кортежа в той же строке исходного примера сразу записан текст `Hello World`. подстановка берёт значения из кортежа. комментарий к `print` показывает ожидаемую строку: имя `Tom` и возраст `35`.

способы форматирования чисел здесь также применяются. точность и экспоненциальная запись задаются между знаком `%` и кодом типа.

```python
number = 23.8589578
print("%0.2f  - %e" % (number, number))   # 23.86  - 2.385896e+01
```

### установка длины строки

с помощью специальных символов можно задать длину строки при форматировании:

- `N`: выравнивает строку по правому краю и дополняет её пробелами с левой стороны до длины `N`. в примере это записано знаком `>` перед шириной, `{str:>16}`
- `^N`: выравнивает строку по центру и дополняет её пробелами с левой и правой стороны до длины `N`
- `.N`: задаёт точную длину строки. если в ней больше `N` символов, то она усекается

например:

```python
str = "Hello World"
print(f"{str:>16}!")     
print(f"{str:<16}!")   
print(f"{str:^16}!")
print(f"{str:.16}!") 
print(f"{str:.5}!")
```

присваивание имени `str` скрывает встроенную функцию `str` в этой области видимости. спецификации в примере читают уже связанное со строкой `Hello World` имя.

результат:

```bash
    Hello World!
Hello World    !
  Hello World  !
Hello World!
Hello!
```

в строке `Hello World` 11 символов. спецификация `>16` выравнивает её по правому краю поля шириной 16, пробелы стоят слева. `<16` выравнивает по левому краю, пробелы стоят справа. `^16` выравнивает по центру и дополняет пробелами с обеих сторон. `.16` строку не усекает: длина 11 меньше 16, выводится `Hello World`. `.5` оставляет первые пять символов, `Hello`. восклицательный знак в литерале стоит после поля и в ширину спецификации не входит.
