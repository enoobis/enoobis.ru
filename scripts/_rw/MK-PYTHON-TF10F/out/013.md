условные конструкции используют условные выражения и в зависимости от их значения направляют выполнение программы по одному из путей. одна из таких конструкций, конструкция **if**, имеет следующее формальное определение:

```python
if логическое_выражение:
	инструкции
[elif логическое выражение:
	инструкции]
[else: 
	инструкции]
```

квадратные скобки в этой схеме обозначают необязательные ветви `elif` и `else`. в текст программы скобки не переносятся.

в самом простом виде после служебного слова **if** идёт логическое выражение. если это выражение возвращает `True`, выполняется последующий блок инструкций. каждая инструкция блока начинается с новой строки и имеет отступ от начала выражения `if`. отступ желательно делать в 4 пробела или в другое количество пробелов, кратное 4. строки одной сюиты обязаны иметь одинаковый отступ: по нему определяется, какие инструкции входят в блок.

```python
language = "english"
if language == "english":
    print("Hello")
print("End")
```

значение переменной `language` равно `english`, поэтому выполняется блок `if`. в нём одна инструкция, `print("Hello")`. консоль выводит следующие строки:

```bash
Hello
End
```

последняя строка кода, которая выводит сообщение `End`, не имеет отступа от начала строки. она не принадлежит блоку `if` и выполняется в любом случае, даже если выражение в конструкции `if` возвратит `False`.

если у этой строки поставить отступ, она тоже принадлежит конструкции `if`:

```python
language = "english"
if language == "english":
    print("Hello")
    print("End")
```

### блок else

если нужно определить альтернативу на тот случай, когда выражение в **if** возвратит `False`, используют блок **else**:

```python
language = "russian"
if language == "english":
    print("Hello")
else:
    print("Привет")
print("End")
```

если выражение `language == "english"` возвращает `True`, выполняется блок `if`, иначе выполняется блок `else`. в этом примере условие `language == "english"` возвращает `False`, поэтому выполняются инструкции из блока `else`.

инструкции блока **else** тоже должны иметь отступ от начала строки. в примере выше `print("End")` отступа не имеет, поэтому не входит в блок `else` и выполняется вне зависимости от того, чему равно условие `language == "english"`. консоль выводит следующие строки:

```bash
Привет
End
```

блок `else` может содержать несколько инструкций. у каждой из них один и тот же отступ от начала строки:

```python
language = "russian"
if language == "english":
    print("Hello")
    print("World")
else:
    print("Привет")
    print("мир")
```

### elif

если нужно ввести несколько альтернативных условий, используют дополнительные блоки **elif**. после условия идёт блок инструкций.

```python
language = "german"
if language == "english":
    print("Hello")
    print("World")
elif language == "german":
    print("Hallo")
    print("Welt")
else:
    print("Привет")
    print("мир")
```

сначала python проверяет выражение `if`. если оно равно `True`, выполняются инструкции из блока `if`. если это условие возвращает `False`, python проверяет выражение из `elif`.

если выражение после `elif` равно `True`, выполняются инструкции из блока `elif`. если оно равно `False`, выполняются инструкции из блока `else`. ветви проверяются по порядку, и срабатывает первая истинная. остальные условия после неё уже не вычисляются.

при необходимости определяют несколько блоков `elif` для разных условий:

```python
language = "german"
if language == "english":
    print("Hello")
elif language == "german":
    print("Hallo")
elif language == "french":
    print("Salut")
else:
    print("Привет")
```

### вложенные конструкции if

конструкция `if` сама может содержать вложенные конструкции `if`:

```python
language = "english"
daytime = "morning"
if language == "english":
	print("English")
    if daytime == "morning":
        print("Good morning")
    else:
        print("Good evening")
```

здесь конструкция `if` содержит вложенную конструкцию `if`/`else`. если переменная `language` равна `english`, вложенная конструкция дополнительно проверяет значение переменной `daytime`: равна ли она строке `morning`. в этом примере консольный вывод такой:

```bash
English
Good morning
```

вложенные выражения `if` тоже начинаются с отступа, а инструкции во вложенных конструкциях имеют свой, более глубокий отступ. отступы, расставленные иначе, меняют логику программы: сюита определяется столбцом, а не близостью строк на экране. предыдущий пример не совпадает со следующим:

```python
language = "english"
daytime = "morning"
if language == "english":
    print("English")
if daytime == "morning":
    print("Good morning")
else:
     print("Good evening")
```

во втором тексте второй `if` записан с тем же отступом, что и первый, поэтому не входит в его сюиту. ветвь `else` относится ко второму `if` и зависит только от `daytime`. проверка языка и проверка времени суток здесь независимы.

тем же способом вложенные конструкции `if`/`elif`/`else` размещают в блоках `elif` и `else`:

```python
language = "russian"
daytime = "morning"
if language == "english":
    if daytime == "morning":
        print("Good morning")
    else:
        print("Good evening")
else:
    if daytime == "morning":
        print("Доброе утро")
    else:
        print("Добрый вечер")
```

внешняя развилка выбирает язык, внутренняя в каждой ветви выбирает время суток. отступ показывает, какая инструкция к какой развилке относится.
