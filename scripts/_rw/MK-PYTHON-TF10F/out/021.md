область видимости (scope) задаёт участок программы, в котором имя переменной можно использовать. в python у имени есть два основных контекста: глобальный и локальный. поиск имени идёт по лексическим областям: локальная область функции, области объемлющих функций, глобальная область модуля и затем встроенные имена.

### глобальный контекст

глобальное имя определено вне всякой функции и доступно любой функции модуля. пример:

```python
name = "Tom"


def say_hi():
    print("Hello", name)


def say_bye():
    print("Good bye", name)

say_hi()
say_bye()
```

переменная `name` глобальна. обе функции читают её из глобальной области.

### локальный контекст

локальная переменная создаётся внутри функции и доступна только из этой функции:

```python
def say_hi():
    name = "Sam"
    surname = "Johnson"
    print("Hello", name, surname)


def say_bye():
    name = "Tom"
    print("Good bye", name)

say_hi()
say_bye()
```

в каждой из двух функций есть локальная переменная `name`. совпадение идентификаторов не делает их одной переменной: у каждой функции своё локальное пространство имён. в `say_hi()` есть ещё локальная `surname`. в `say_bye()` этого имени нет, и обращение к нему там завершилось бы ошибкой `NameError`.

### скрытие переменных

локальное имя скрывает глобальное имя с тем же идентификатором:

```python
name = "Tom"


def say_hi():
    name = "Bob"        # скрываем значение глобальной переменной
    print("Hello", name)


def say_bye():
    print("Good bye", name)


say_hi()    # Hello Bob
say_bye()   # Good bye Tom
```

глобальная переменная называется `name`. в `say_hi` определена локальная переменная с тем же именем, и присваивание создаёт именно её: любое присваивание имени внутри функции делает это имя локальным для всей функции. `say_bye` присваивания не содержит и читает глобальную `name`. поэтому первый вызов печатает `Hello Bob`, а второй `Good bye Tom`.

чтобы присваивание меняло глобальную переменную, а не создавало локальную, имя объявляют словом `global`:

```python
name = "Tom"


def say_hi():
    global  name
    name = "Bob"        # изменяем значение глобальной переменной
    print("Hello", name)


def say_bye():
    print("Good bye", name)


say_hi()    # Hello Bob
say_bye()   # Good bye Bob
```

### nonlocal

объявление `nonlocal` связывает имя с переменной ближайшей объемлющей функции. глобальная область в этот поиск не входит: до неё `nonlocal` не доходит. обычно `nonlocal` пишут во вложенной функции, когда имя должно указывать на переменную или параметр внешней функции.

вложенная функция может только читать внешнее имя:

```python
def outer():  # внешняя функция
    n = 5

    def inner():    # вложенная функция
        print(n)

    inner()     # 5
    print(n)


outer()     # 5
```

локальная функция `inner()` печатает переменную `n`, определённую во внешней `outer()`. затем `outer()` вызывает `inner()`. при вызове `outer()` на консоли дважды появляется 5: вложенная функция читает уже существующее имя и не присваивает ему.

если во вложенной функции есть присваивание, семантика другая:

```python
def outer():  # внешняя функция
    n = 5

    def inner():    # вложенная функция
        n = 25
        print(n)

    inner()     # 25
    print(n)


outer()     # 5 
# 25    - inner
# 5     - outer
```

присваивание `n = 25` создаёт новую локальную переменную `n`, которая скрывает `n` внешней функции `outer`. компилятор помечает имя локальным на всю функцию, если в ней есть хотя бы одно присваивание этому имени. чтение такого имени до присваивания даёт `UnboundLocalError`. в примере печать внутри `inner` показывает 25, а печать во `outer` по-прежнему показывает 5.

чтобы присваивание во вложенной функции попадало в переменную объемлющей функции, имя объявляют как `nonlocal`:

```python
def outer():  # внешняя функция
    n = 5

    def inner():    # вложенная функция
        nonlocal n  # указываем, что n - это переменная из окружающей функции
        n = 25
        print(n)

    inner()     # 25
    print(n)


outer()          # 25
```
