### функция как тип

в python функция является объектом: у неё есть тип, её можно хранить в переменной и передавать как значение. имя функции это ссылка на такой объект. присваивание копирует ссылку, а вызов переменной выполняет тот объект, на который она указывает в этот момент. пример:

```python
def say_hello(): print("Hello")
def say_goodbye(): print("Good Bye")

message = say_hello
message()       # Hello
message = say_goodbye
message()       # Good Bye
```

переменной `message` присваивается одна из функций. сначала это `say_hello`:

```python
message = say_hello
```

после присваивания `message` указывает на `say_hello` и вызывает её как обычную функцию:

```python
message()       # Hello
```

вызов выполняет `say_hello`, и на консоль выводится строка `Hello`. затем той же переменной присваивается другая функция, и следующий вызов выполняет уже её.

через переменную так же вызывается функция с параметрами, и так же получается её результат:

```python
def sum(a, b): return a + b
def multiply(a, b): return a * b

operation = sum
result = operation(5, 6)
print(result)   # 11

operation = multiply
print(operation(5, 6))      # 30
```

### функция как параметр функции

раз функция является значением наряду со строкой или числом, её можно передать параметром в другую функцию. функция, которая печатает результат некоторой операции:

```python
def do_operation(a, b, operation):
    result = operation(a, b)
    print(f"result = {result}")

def sum(a, b): return a + b
def multiply(a, b): return a * b

do_operation(5, 4, sum)         # result = 9
do_operation(5, 4, multiply)   # result = 20
```

у `do_operation` три параметра. третий, по соглашению о вызове, должен быть функцией двух параметров, возвращающей результат. в момент определения `do_operation` конкретная операция ещё неизвестна: зафиксированы только число параметров и то, что результат будет напечатан. такая функция называется функцией высшего порядка.

при вызове третьим аргументом передаётся другая функция, например `sum`:

```python
do_operation(5, 4, sum)
```

параметр `operation` указывает на `sum` и возвращает сумму двух чисел.

тем же параметром передаётся другая функция, `multiply`, и выполняется умножение:

```python
do_operation(5, 4, multiply)   # result = 20
```

подстановка операции через параметр оставляет `do_operation` неизменной, а конкретное действие задаётся в точке вызова.

### функция как результат функции

функция может возвращать другую функцию. ниже функция выбирает операцию по значению параметра:

```python
def sum(a, b): return a + b
def subtract(a, b): return a - b
def multiply(a, b): return a * b


def select_operation(choice):
    if choice == 1:
        return sum
    elif choice == 2:
        return subtract
    else:
        return multiply


operation = select_operation(1)     # operation = sum
print(operation(10, 6))             # 16

operation = select_operation(2)     # operation = subtract
print(operation(10, 6))             # 4

operation = select_operation(3)     # operation = multiply
print(operation(10, 6))             # 60
```

`select_operation` по значению `choice` возвращает одну из трёх функций: `sum`, `subtract` или `multiply`. любая ветка, кроме `choice == 1` и `choice == 2`, возвращает `multiply`. результат `select_operation` сохраняется в переменную `operation`:

```python
operation = select_operation(1)
```

в `select_operation` передано число 1, поэтому возвращён объект `sum`. переменная `operation` указывает на `sum`, то есть на сложение двух чисел:

```python
print(operation(10, 6))             # 16 - фактически равно sum(10, 6)
```

вызов `print(operation(10, 6))` совпадает с `sum(10, 6)` и печатает 16. тем же способом получают и выполняют остальные функции: при `choice` равном 2 печатается 4, при значении 3 печатается 60.
