одной из сред, в которых ведут программы на python, является visual studio. по сравнению с pycharm у этой ide есть практическое отличие. в бесплатной редакции visual studio community доступен ряд средств, которые в pycharm входят только в платную редакцию professional edition. к таким средствам относится веб-разработка, в том числе с помощью фреймворков. при этом средства разработки на python в visual studio пока доступны только в версии для windows.

установочный файл visual studio community загружают по ссылке https://visualstudio.microsoft.com/ru/vs/community/ . после запуска установщика среди устанавливаемых компонентов выбирают пункт `Разработка на Python`:

![установка python в visual studio](/uploads/course-lectures/608a6dd4b61a7ec66eab064ed149b58243d7b04d.png)

после установки visual studio запускают и в окне программы выбирают `Create a new project`:

![создание проекта для python в visual studio](/uploads/course-lectures/a9954e6be193a1dade8b1b23d6283c9f92d120a1.png)

в окне создания проекта выбирают шаблон `Python Application`:

![первый проект python в visual studio](/uploads/course-lectures/64574114fded516ab7b6e3c722f4579c08dd4b35.png)

на следующем окне указывают название и путь к проекту. в примере проект называется `HelloApp`:

![первый проект python в visual studio](/uploads/course-lectures/300b7e9b8ab07b0ad90426de117be208559ebf2c.png)

кнопка `Create` создаёт новый проект:

![первый проект на python в visual studio](/uploads/course-lectures/bbb66ae67e704067d7da2d4dbbf155e40bb1daed.png)

справа окно `Solution Explorer` (обозреватель решений) показывает структуру проекта. по умолчанию в нём видны следующие элементы:

- `Python Environments`: используемые среды и, в частности, версия python, которой пользуется проект

- `References`: внешние зависимости, подключённые к текущему проекту

- `Search Paths`: пути поиска модулей python. интерпретатор просматривает эти каталоги, когда импортируемый модуль не найден в стандартных местах

- `HelloApp.py`: файл исходного текста на python

по умолчанию файл `HelloApp.py` уже открыт, но пуст. в него добавляют строку:

```python
print("Hello Python from Visual Studio!")
```

затем на панели инструментов нажимают зелёную стрелку запуска:

![запуск скрипта python в visual studio](/uploads/course-lectures/91ca3a0ac49413b5d601755fff832dccfdfe56cc.png)

после запуска открывается консоль и выводит заданную строку:

![первое приложение на python в visual studio](/uploads/course-lectures/88471856f4565498902bd4e840e6f8a7a4d17b0f.png)
