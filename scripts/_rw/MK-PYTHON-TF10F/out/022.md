замыкание (closure) это функция вместе с лексическим окружением, в котором она создана. окружение сохраняется и тогда, когда функцию вызывают вне области, где она была определена.

технически замыкание складывается из трёх компонентов:

- внешняя функция, которая задаёт область видимости и определяет в ней переменные и параметры, то есть лексическое окружение
- сами эти переменные и параметры
- вложенная функция, которая эти переменные и параметры использует

замыкания в python получают из локальных функций:

```python
def outer():        # внешняя функция
    n = 5           # лексическое окружение - локальная переменная

    def inner():      # локальная функция
        nonlocal n
        n += 1        # операции с лексическим окружением
        print(n)

    return inner


fn = outer()   # fn = inner, так как функция outer возвращает функцию inner
# вызываем внутреннюю функцию inner
fn()    # 6
fn()    # 7
fn()    # 8
```

функция `outer` определяет локальную переменную `n`. это лексическое окружение внутренней функции.

внутри `outer` определена локальная функция `inner`. она обращается к `n`, увеличивает её на единицу и печатает значение:

```python
def inner():      # локальная функция
    nonlocal n
    n += 1        # операции с лексическим окружением
    print(n)
```

эту локальную функцию `outer` возвращает:

```python
return inner
```

вызов `outer` даёт в переменную `fn` локальную функцию `inner`:

```python
fn = outer()
```

`fn` и есть замыкание: объект функции и окружение, в котором функция создана. свободная переменная `n` хранится в ячейке объемлющей области, а вложенная функция сохраняет ссылку на эту ячейку. поэтому после выхода из `outer` вызов `fn` по-прежнему читает и изменяет ту же `n`. каждый новый вызов `outer` создаёт собственную ячейку. последовательные вызовы одного замыкания дают 6, 7 и 8:

```python
fn()    # 6
fn()    # 7
fn()    # 8
```

### применение параметров

к лексическому окружению относятся и параметры окружающей функции:

```python
def multiply(n):
    def inner(m): return n * m

    return inner


fn = multiply(5)
print(fn(5))        # 25
print(fn(6))        # 30
print(fn(7))        # 35
```

внешняя функция `multiply` возвращает функцию, которая принимает число и возвращает число. вызов `multiply()` возвращает локальную функцию `inner`:

```python
def inner(m): return n * m
```

`inner` запоминает окружение создания, в том числе значение параметра `n`, сама принимает параметр `m` и возвращает произведение `n` и `m`. вызов `multiply` связывает имя `fn` с этой функцией и с захваченным `n`:

```python
fn = multiply(5)
```

здесь параметр `n` равен 5. вызов локальной функции, например

```python
print(fn(6))        # 30
```

передаёт число 6 параметру `m`. функция возвращает произведение `n` и `m`, то есть `5 * 6`, равное 30.

тот же захват параметра записывается лямбдой. семантика вызовов совпадает с предыдущим вариантом:

```python
def multiply(n): return lambda m: n * m


fn = multiply(5)
print(fn(5))        # 25
print(fn(6))        # 30
print(fn(7))        # 35
```
