строка в python 3 представляет собой последовательность кодовых позиций unicode, записанную в кавычках. одинарные и двойные кавычки для литерала равноправны: выбор влияет на то, какую кавычку можно вставить внутрь без экранирования, и не меняет тип значения. тип такого значения `str`.

```python


message = "Hello World!"

print(message)  # Hello World!



name = 'Tom'

print(name)  # Tom
```

длинный литерал можно разбить на части и разместить их на разных строках. вся запись заключается в круглые скобки, каждая часть остаётся в своих кавычках. соседние строковые литералы склеиваются при компиляции в один объект `str`, до начала выполнения. скобки позволяют перенести части на следующие строки. запятой между частями нет, кортеж из них не собирается.

```python


text = ("Laudate omnes gentes laudate "

        "Magnificat in secula ")

print(text)
```

многострочный текст заключается в тройные двойные или тройные одинарные кавычки. перевод строки, попавший внутрь такого литерала, входит в значение строки.

```python


'''

Это комментарий

'''

text = '''Laudate omnes gentes laudate

Magnificat in secula

Et anima mea laudate

Magnificat in secula 

'''

print(text)
```

тройные одинарные кавычки комментарием не становятся. комментарий задаётся символом `#` и до конца строки в значение не входит. если текст в тройных одинарных кавычках присваивается переменной, получается значение типа `str`. неприсвоенный литерал из примера выше тоже является строковым выражением: интерпретатор его вычисляет. когда такой литерал оказывается первым оператором модуля, функции или класса, он сохраняется в `__doc__` как строка документации.

#### управляющие последовательности в строке

литерал без префикса `r` читает обратную косую черту как начало управляющей последовательности, иначе escape-последовательности. из этого набора в лекции используются такие:

- `\\`: вставляет внутрь строки символ обратной косой черты, слеш
- `\'`: вставляет внутрь строки одинарную кавычку
- `\"`: вставляет внутрь строки двойную кавычку
- `\n`: выполняет переход на новую строку
- `\t`: вставляет табуляцию. в описании последовательности её ширина указана как 4 отступа: так табуляцию часто показывает консоль. в значении строки при этом не четыре пробела, а один символ табуляции

ниже в одном литерале стоят перевод строки и экранированные двойные кавычки.

```python


text = "Message:\n\"Hello World\""

print(text)
```

консольный вывод программы:

```bash


Message:

"Hello World"
```

эти последовательности помещают в строку кавычку, табуляцию и перенос на другую строку. та же обработка мешает, когда обратная косая черта нужна как обычный символ пути.

```python


path = "C:\python\name.txt"

print(path)
```

переменная `path` содержит путь к файлу. внутри литерала встречается `\n`. без сырого префикса эта пара интерпретируется как управляющая последовательность, перевод строки, а не как косая черта и буква n. буква p после косой отдельной последовательности не образует, косая перед p в выводе сохраняется. консольный вывод:

```bash


C:\python

ame.txt
```

чтобы избежать такой подстановки, перед строкой ставится символ `r`. тот же смысл у префикса `R`. в сыром литерале обратная косая черта остаётся обычным символом, и `\n` в значении пути не превращается в перевод строки. синтаксическое ограничение: сырой литерал нельзя закончить нечётным числом обратных косых, последняя косая экранировала бы закрывающую кавычку.

```python


path = r"C:\python\name.txt"

print(path)
```

### вставка значений в строку

python позволяет вставлять в строку значения других переменных. внутри строки выражения размещаются в фигурных скобках `{}`, перед всей строкой ставится символ `f`. тот же смысл у префикса `F`. выражения в скобках вычисляются при выполнении, результат форматируется и собирается в новую строку.

```python


userName = "Tom"

userAge = 37

user = f"name: {userName}  age: {userAge}"

print(user)   # name: Tom  age: 37
```

на место `{userName}` вставляется значение переменной `userName`. на место `{userAge}` вставляется значение переменной `userAge`. в примере это `Tom` и `37`, вывод: `name: Tom  age: 37`.

### обращение к символам строки

к отдельному символу строки обращаются по индексу в квадратных скобках. единица индексации `str` это кодовая позиция unicode. графема, собранная из нескольких кодовых позиций, занимает несколько индексов. байты к этой индексации не относятся, для них есть тип `bytes`.

```python


string = "hello world"

c0 = string[0]  # h

print(c0)

c6 = string[6]  # w

print(c6)



c11 = string[11]  # ошибка IndexError: string index out of range

print(c11)
```

индексация начинается с нуля, первый символ строки имеет индекс 0. обращение к индексу, которого в строке нет, поднимает исключение `IndexError`. в примере длина строки `hello world` равна 11 символам, допустимые индексы идут от 0 до 10. индекс 11 лежит вне этого диапазона, последнее обращение в примере как раз его и запрашивает.

доступ к символам с конца строки дают отрицательные индексы. индекс `-1` представляет последний символ, `-2` предпоследний, и так далее к началу. отрицательный индекс считается как длина плюс этот индекс и тоже проверяется на границы. в примере `-1` это `d`, `-5` это `w`.

```python


string = "hello world"

c1 = string[-1]  # d

print(c1)

c5 = string[-5]  # w

print(c5)
```

строка является неизменяемым типом (immutable). присваивание отдельному символу завершается ошибкой, для такой операции это `TypeError`.

```python


string = "hello world"

string[1] = "R"
```

целиком значение строки можно переустановить, связав имя с другим объектом `str`. прежний объект присваиванием по индексу не изменяется.

### перебор строки

цикл `for` перебирает все символы строки слева направо. на каждой итерации имя цикла связано с очередной кодовой позицией. в примере каждая позиция печатается своей строкой вывода.

```python


string = "hello world"

for char in string:

    print(char)
```

### получение подстроки

из строки можно получить не только отдельные символы, но и подстроку. для среза используется следующий синтаксис. срез задаёт полуинтервал: начальный индекс входит, конечный не входит.

- `string[:end]`: извлекается последовательность символов начиная с 0-го индекса по индекс `end`, не включая `end`
- `string[start:end]`: извлекается последовательность символов начиная с индекса `start` по индекс `end`, не включая `end`
- `string[start:end:step]`: извлекается последовательность символов начиная с индекса `start` по индекс `end`, не включая `end`, через шаг `step`

при положительном шаге опущенный `start` означает 0, опущенный `end` означает длину строки. слишком большой `end` у среза исключение `IndexError` не вызывает: граница обрезается по длине. результат среза это новый объект `str`.

используются все варианты получения подстроки:

```python


string = "hello world"



# с 0 до 5 индекса

sub_string1 = string[:5]

print(sub_string1)      # hello



# со 2 до 5 индекса

sub_string2 = string[2:5]

print(sub_string2)      # llo



# с 2 по 9 индекса через один символ

sub_string3 = string[2:9:2]

print(sub_string3)      # lowr
```

третий срез идёт с шагом 2 и берёт индексы 2, 4, 6 и 8. пробел в `hello world` стоит на индексе 5 и в этот срез не попадает, поэтому значение равно `lowr`.

### объединение строк

одна из самых распространённых операций со строками это их объединение, конкатенация. для объединения применяется операция сложения. оба операнда должны иметь тип `str`, результат является новым объектом. соединение двух строк в примере даёт `Tom Smith`.

```python


name = "Tom"

surname = "Smith"

fullname = name + " " + surname

print(fullname)  # Tom Smith
```

сложение строки и числа для `str` не определено и поднимает `TypeError`. число приводят к строке функцией `str()`, после этого операнды складываются как строки. в примере возраст 33 попадает в текст как символы `33`, вывод: `Name: Tom Age: 33`.

```python


name = "Tom"

age = 33

info = "Name: " + name + " Age: " + str(age)

print(info)  # Name: Tom Age: 33
```

### повторение строки

для повторения строки определённое количество раз применяется операция умножения на целое. при положительном множителе длина результата равна длине строки, умноженной на этот множитель. нулевой и отрицательный множитель дают пустую строку.

```python


print("a" * 3)  # aaa

print("he" * 4)  # hehehehe
```

### сравнение строк

сравнение строк производится в лексикографическом порядке: по кодовым позициям unicode, слева направо. принимаются во внимание и символы, и их регистр. у базовой латиницы кодовая позиция цифры меньше кодовой позиции любой буквы, а кодовая позиция буквы верхнего регистра меньше кодовой позиции буквы нижнего регистра. отсюда сравнения примера.

```python


str1 = "1a"

str2 = "aa"

str3 = "Aa"

print(str1 > str2)  # False, так как первый символ в str1 - цифра

print(str2 > str3)  # True, так как первый символ в str2 - в нижнем регистре
```

строка `1a` условно меньше, чем строка `aa`: сравнение идёт по первому символу, и цифра меньше буквы. если начальные символы обоих строк представляют цифры, меньшей считается меньшая цифра, например `1a` меньше, чем `2a`. если начальные символы представляют алфавитные символы в одном и том же регистре, порядок берётся по алфавиту. так, `aa` меньше, чем `ba`, а `ba` меньше, чем `ca`. если первые символы одинаковые, в расчёт берутся вторые символы при их наличии. когда общее начало совпало и у одной строки символы закончились раньше, более короткая строка меньше.

зависимость от регистра не всегда желательна: строки различаются только регистром и по тексту должны считаться совпадающими. перед сравнением обе строки приводят к одному регистру. функция `lower()` приводит строку к нижнему регистру, функция `upper()` к верхнему. оба метода возвращают новую строку.

```python


str1 = "Tom"

str2 = "tom"

print(str1 == str2)  # False - строки не равны



print(str1.lower() == str2.lower())  # True
```

### функции `ord` и `len`

строка содержит символы unicode, поэтому функция `ord()` получает числовое значение символа в кодировке unicode, номер его кодовой позиции. для `A` это 65: unicode сохраняет номера ascii в начале таблицы.

```python
print(ord("A"))     # 65
```

для получения длины строки используется функция `len()`. длина считается в кодовых позициях, не в байтах utf-8 и не в графемах.

```python


string = "hello world"

length = len(string)

print(length)	# 11
```

### поиск в строке

выражение `term in string` ищет подстроку `term` в строке `string`. если подстрока найдена, выражение возвращает `True`, иначе возвращается `False`. поиск идёт по последовательности кодовых позиций и не делит строку на слова.

```python


text = "hello world"

exist = "hello" in text

print(exist)    # True



exist = "sword" in text

print(exist)    # False
```

оператор `not in` проверяет отсутствие подстроки в строке. для `hello` в `hello world` результат `False`, потому что подстрока есть. для `sword` результат `True`.

```python


text = "hello world"

print("hello" not in text)    # False

print("sword" not in text)    # True
```
