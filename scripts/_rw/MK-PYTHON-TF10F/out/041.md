### распаковка

распаковка (`unpacking`), её же называют деструктуризацией, раскладывает коллекцию (кортеж, список и другие последовательности) на отдельные значения.

python поддерживает множественное присваивание, как и ряд других языков.

```python
x, y = 1, 2
print(x)    # 1
print(y)    # 2
```

значения связываются сразу с двумя переменными. присваивание идёт по позиции: `x` получает `1`, `y` получает `2`.

этот пример уже является деструктуризацией. запись `1, 2` представляет собой кортеж: кортеж задаёт запятая между значениями. скобки лишь группируют ту же запись. та же распаковка записывается со скобками.

```python
x, y = (1, 2)
print(x)    # 1
print(y)    # 2
```

в обоих вариантах первый элемент кортежа передаётся первой переменной, второй элемент второй переменной, и далее по позиции.

так же раскладываются и другие кортежи.

```python
name, age, company = ("Tom", 38, "Google")
print(name)         # Tom
print(age)          # 38
print(company)      # Google
```

распаковка не ограничена кортежами. тем же позиционным правилом раскладываются списки.

```python
people = ["Tom", "Bob", "Sam"]
first, second, third = people
print(first)      # Tom
print(second)     # Bob
print(third)      # Sam
```

при разложении словаря переменные получают ключи. порядок ключей совпадает с порядком вставки. значение по ключу читается отдельным обращением к словарю.

```python
dictionary = {"red": "красный", "blue": "синий", "green": "зеленый"}
r, b, g = dictionary
print(r)    # red
print(b)    # blue
print(g)    # green
# получаем значение по ключу
print(dictionary[g])    # зеленый
```

### деструктуризация в циклах

цикл может раскладывать коллекции на составляющие прямо в заголовке. если элемент итерируемого объекта сам является последовательностью, его поля связываются с переменными заголовка по позиции.

```python
people = [
	("Tom", 38, "Google"),
	("Bob", 42, "Microsoft"),
	("Sam", 29, "JetBrains")
]

for name, age, company in people:
	print(f"Name: {name}, Age: {age}, Company: {company}")
```

здесь перебирается список кортежей `people`. каждый кортеж состоит из трёх элементов, и на итерации они связываются с `name`, `age` и `company`.

функция `enumerate()` принимает коллекцию и для каждого элемента строит кортеж. кортеж содержит индекс и сам элемент. индекс начинается с нуля и увеличивается на единицу с каждой итерацией. цикл сразу раскладывает эту пару.

```python
people = ["Tom", "Bob", "Sam"]
for index, name in enumerate(people):
    print(f"{index}.{name}")

# результат
# 0.Tom
# 1.Bob
# 2.Sam
```

### игнорирование значений

если элемент коллекции не нужен, для него обычно берут имя `_`. так помечают неиспользуемое значение. для языка `_` остаётся обычным идентификатором.

```python
person =("Tom", 38, "Google")
name, _, company = person
print(name)     # Tom
print(company)  # Google
```

второй элемент кортежа в этом разложении не используется дальше по смыслу примера, поэтому он связывается с `_`. при этом `_` является обычным именем, таким же, как `name` и `company`, и связанное значение можно прочитать.

```python
name, _, company = person
print(_)     # 38
```

### упаковка значений и оператор *

оператор `*` упаковывает значения в коллекцию.

```python
num1=1
num2=2
num3=3
*numbers,=num1,num2,num3
print(numbers)  #[1, 2, 3]
```

значения кортежа `(num1, num2, num3)` собираются в список `numbers`. запятая после `numbers` обязательна: слева должен стоять список целей присваивания, и единственная цель в нём звёздная. запись без этой запятой синтаксически не является присваиванием со звёздной целью. звёздная цель всегда получает список, даже если справа стоит кортеж.

обычно упаковка собирает то, что осталось после присваивания остальных позиций.

```python
head, *tail = [1, 2, 3, 4, 5]

print(head)  # 1
print(tail)  # [2, 3, 4, 5]
```

`head` по позиции получает первый элемент списка. все остальные элементы передаются в `tail`. `tail` оказывается списком оставшихся элементов.

так же забирается всё, кроме последнего элемента.

```python
*head, tail = [1, 2, 3, 4, 5]

print(head)  # [1, 2, 3, 4]
print(tail)  # 5
```

или забирается середина, без первого и без последнего.

```python
head, *middle, tail = [1, 2, 3, 4, 5]

print(head)    # 1
print(middle)  # [2, 3, 4]
print(tail)    # 5
```

или забирается всё, кроме первого и второго.

```python
first, second, *other = [1, 2, 3, 4, 5]

print(first)    # 1
print(second)   # 2
print(other)    # [3, 4, 5]
```

таким разложением получают разные комбинации элементов. источник при этом может быть не только списком, но и кортежем, словарём и другой коллекцией. в левой части допускается только одна звёздная цель.

если нужны первый, третий и последний элементы, а остальные не нужны, формально под каждый элемент коллекции требуется своя цель. при длине 100 объявлять сто имён не требуется: лишние позиции поглощает звёздная цель, а отдельные пропуски по-прежнему записываются именем `_`.

```python
first, _, third, *_, last = [1, 2, 3, 4, 5, 6, 7, 8]

print(first)   # 1
print(third)   # 3
print(last)    # 8
```

тем же приёмом читаются ключи словаря. звёздная цель снова получает список, уже список ключей между первым и последним.

```python
red, *other, green = {"red":"красный", "blue":"синий", "yellow":"желтый", "green":"зеленый"}

print(red)    		# red
print(green)  		# green
print(other)    	# ['blue', 'yellow']
```

### распаковка и операторы * и **

операторы `*` и `**` применяются и в другую сторону: они распаковывают уже готовую коллекцию внутри литерала или вызова. `*` распаковывает кортежи, списки, строки и множества. `**` распаковывает словари. это используется, когда одна коллекция собирается из других.

```python
nums1 = [1, 2, 3]
nums2 = (4, 5, 6)

# распаковываем список nums1 и кортеж nums2
nums3 = [*nums1, *nums2] 
print(nums3)		# [1, 2, 3, 4, 5, 6]
```

здесь значения списка `nums1` и кортежа `nums2` распаковываются и помещаются в список `nums3` в порядке записи.

словари раскладываются так же, но оператором `**`.

```python
dictionary1 = {"red":"красный", "blue":"синий"}
dictionary2 = {"green":"зеленый", "yellow":"желтый"}

# распаковываем словари
dictionary3 = {**dictionary1, **dictionary2}
print(dictionary3)  # {'red': 'красный', 'blue': 'синий', 'green': 'зеленый', 'yellow': 'желтый'}
```

пары обоих словарей попадают в новый словарь. при совпадении ключей остаётся значение из того словаря, который распакован правее.
