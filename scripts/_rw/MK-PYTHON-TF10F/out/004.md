на одной рабочей машине может быть установлено несколько версий python одновременно. так поступают, когда внешние библиотеки поддерживают разные линии языка, и в других случаях, где нужны разные версии. на момент написания исходного материала последней актуальной версией была python **3.11**, и рядом с ней требовалась версия **3.10**. ниже показано, как поставить эти версии рядом и как выбрать, какая из них запускается.

### windows

на странице загрузок https://www.python.org/downloads/ находится ссылка на нужную версию:

![управление несколькими версиями python](/uploads/course-lectures/87f5d164a8a4866876bf1a2c7ad29b84ddb5e5b2.png)

эту версию загружают и устанавливают отдельно от уже стоящей:

![установка разных версий python на windows](/uploads/course-lectures/b2ad5f652dda58b5a03e40a16b03c377fce68ff2.png)

чтобы при вызове интерпретатора не писать полный путь, при установке его каталог добавляют в переменные среды. в `PATH` тогда оказывается несколько путей к разным интерпретаторам:

![установка разных версий python на windows в переменные среды](/uploads/course-lectures/d5d3b4c61045c733af78a4278dffb8edc53bd448.png)

оболочка ищет исполняемый файл по `PATH` сверху вниз и берёт первое совпадение. та версия, чей каталог стоит выше, становится версией по умолчанию. кнопкой `Вверх` нужную запись перемещают в начало списка. в примере версией по умолчанию делают 3.11. команды `python --version` и `py --version` тогда печатают 3.11:

```consoletext
python --version</div>
<p>или</p>
<div class="console"><pre class="consoletext">py --version</div>
<p>то консоль отобразит версию 3.11:</p>
<div class="console"><pre class="consoletext">
C:\python>python --version
Python 3.11.0
```

к версии 3.10 и к остальным установленным линиям обращаются через лаунчер `py`, явно указывая номер линии:

```consoletext
C:\python>py -3.10 --version
Python 3.10.9
```

тем же способом скрипт `hello.py` запускают именно версией 3.10:

```consoletext
py -3.10 hello.py
```

остальные версии вызываются так же: суффикс вида `-3.10` выбирает линию, а лаунчер находит соответствующий интерпретатор.

### macos

на macos разные версии ставят отдельно. один из способов состоит в том, чтобы загрузить с официального сайта пакет установщика нужной версии.

к конкретной версии обращаются командой вида `python3.[номер_подверсии]`. если установлена линия 3.10, её номер проверяют так:

```consoletext
python3.10 --version
```

обращение к линии `python3.9`, при условии что она установлена:

```consoletext
python3.9 --version
```

скрипт `hello.py` версией python 3.10 запускают так:

```consoletext
python3.10 hello.py
```

### linux

на linux несколько версий тоже ставят одновременно. установка линий 3.10 и 3.11:

```consoletext
sudo apt-get install python3.10
sudo apt-get install python3.11
```

одна из линий является версией по умолчанию. к ней достаточно обратиться именем `python3`. проверка версии по умолчанию:

```consoletext
python3 --version
```

к остальным линиям обращаются с номером подверсии:

```consoletext
python3.10 --version
python3.11 --version
```

скрипт `hello.py` версией python 3.10:

```consoletext
python3.10 hello.py
```

версия по умолчанию может потребовать замены. на debian и производных, где пакеты ставят через apt, для этого применяют `update-alternatives`: имя `python3` связывают с конкретным файлом интерпретатора. чтобы версией по умолчанию стал python 3.11, последовательно выполняют:

```consoletext
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.10 1
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.11 2
```

числа справа задают приоритет, в формулировке исходного описания это приоритет и состояние альтернативы. у версии 3.11 приоритет больше, поэтому обращение к `python3` разрешается в 3.11. в примере это python 3.11.0rc1: суффикс rc обозначает выпуск-кандидат, то есть сборку до финального релиза той же линии.

![управление версиями python в linux](/uploads/course-lectures/208fb3f10eeeb101ffa14579d12aea6f4aafada3.png)

команда

```consoletext
sudo update-alternatives --config python3
```

открывает выбор версии по умолчанию: перечисляются зарегистрированные альтернативы, и активной отмечается нужная.

![установка версии python по умолчанию в linux](/uploads/course-lectures/298616f00bc919a8b6fbfeae9cbc3675f24c1465.png)
