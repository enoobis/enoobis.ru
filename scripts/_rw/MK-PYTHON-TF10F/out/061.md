шаблоном в pattern matching может быть последовательность, записанная круглыми скобками. в примерах этой лекции субъектом служит кортеж. такие шаблоны называют шаблонами кортежа. скобки здесь относятся к синтаксису шаблона и тип субъекта не фиксируют: и круглые, и квадратные скобки сопоставляются с любой последовательностью, кроме `str`, `bytes` и `bytearray`. строка по кодовым точкам таким шаблоном не разбирается, иначе любой текст случайно совпадал бы с последовательностью символов. длина субъекта должна совпасть с числом элементов шаблона, если в шаблоне нет звёздочки.

```python
def print_data(user):
    match user:
        case ("Tom", 37):
            print("default user")
        case ("Tom", age):
            print(f"Age: {age}")
        case (name, 22):
            print(f"Name: {name}")
        case (name, age):
            print(f"Name: {name}  Age: {age}")


print_data(("Tom", 37))     # default user
print_data(("Tom", 28))     # Age: 28
print_data(("Sam", 22))     # Name: Sam
print_data(("Bob", 41))     # Name: Bob  Age: 41
print_data(("Tom", 33, "Google"))    # не соответствует ни одному из шаблонов
```

функция принимает параметр `user`. в вызовах это кортеж из двух элементов, последний вызов передаёт кортеж из трёх элементов и ни одному шаблону не соответствует: длина другая, и ветви по умолчанию нет, поэтому `match` ничего не выполняет. ветви проверяются по порядку, срабатывает первая успешная, поэтому более узкий шаблон стоит выше более широкого.

первый шаблон требует точного совпадения обоих элементов: первый равен `"Tom"`, второй равен `37`.

```python
case ("Tom", 37):
    print("default user")
```

при таком субъекте на консоль выводится `default user`.

второй шаблон принимает любой двухэлементный субъект, у которого первый элемент равен `"Tom"`. второй элемент связывается с именем `age`.

```python
case ("Tom", age):
    print(f"Age: {age}")
```

если первый элемент равен `"Tom"`, а второй не равен `37`, успевает именно эта ветвь: предыдущая уже отвергнута. значение второго элемента попадает в `age` и доступно в теле ветви. константный шаблон `("Tom", 37)` обязан стоять выше, иначе имя `age` захватило бы и значение `37`, и первая ветвь стала бы недостижимой.

третий шаблон устроен симметрично. жёстко задан второй элемент, он равен `22`, первый связывается с именем `name`.

```python
case (name, 22):
    print(f"Name: {name}")
```

двухэлементный субъект, не подошедший к первым трём шаблонам, попадает в четвёртый. конкретные значения здесь не фиксируются, оба элемента связываются с именами `name` и `age`.

```python
case (name, age):
    print(f"Name: {name}  Age: {age}")
```

имя, связанное шаблоном, получает сопоставленное значение и доступно в теле этой ветви. литерал сравнивается по равенству, кроме `None`, `True` и `False`, для которых используется тождество, как и в лекции про литеральные шаблоны.

### альтернативные значения

если элемент должен совпасть с одним из нескольких значений, их перечисляют через вертикальную черту:

```python
def print_data(user):
    match user:
        case ("Tom" | "Tomas" | "Tommy", 37):
            print("default user")
        case ("Tom", age):
            print(f"Age: {age}")
        case (name, 22):
            print(f"Name: {name}")
        case (name, age):
            print(f"Name: {name}  Age: {age}")


print_data(("Tom", 37))     # default user
print_data(("Tomas", 37))   # default user
print_data(("Tom", 28))     # Age: 28
print_data(("Sam", 37))     # Name: Sam  Age: 37
```

первый шаблон принимает двухэлементную последовательность, где первый элемент равен `"Tom"`, `"Tomas"` или `"Tommy"`, а второй равен `37`. субъект `("Sam", 37)` этому шаблону не подходит и доходит до последней ветви.

или-шаблон применим не только к одному элементу, но и к целым последовательностям:

```python
def print_data(user):
    match user:
        case ("Tom", 37) | ("Sam", 22):
            print("default user")
        case (name, age):
            print(f"Name: {name}  Age: {age}")


print_data(("Tom", 37))     # default user
print_data(("Sam", 22))     # default user
print_data(("Mike", 28))    # Name: Mike  Age: 28
```

первый шаблон принимает два кортежа: `("Tom", 37)` и `("Sam", 22)`. в альтернативах одного или-шаблона набор связываемых имён обязан совпадать, иначе конструкция синтаксически отвергается.

### пропуск элементов

если элемент не нужен ни как константа, ни как имя, на его место ставят шаблон `_`. маска сопоставляется с чем угодно и имя не связывает.

```python
def print_data(user):
    match user:
        case ("Tom", 37):
            print("default user")
        case (name, _):     # второй элемент не важен
            print(f"Name: {name}")


print_data(("Tom", 37))     # default user
print_data(("Sam", 25))     # Name: Sam
print_data(("Bob", 41))     # Name: Bob
```

маской можно закрыть все элементы. значения тогда не используются, но число элементов по-прежнему проверяется:

```python
def print_data(user):
    match user:
        case ("Tom", 37):
            print("default user")
        case ("Sam", _):
            print("Name: Sam")
        case (_, _):
            print("Undefined user")


print_data(("Tom", 37))     # default user
print_data(("Sam", 25))     # Name: Sam
print_data(("Bob", 41))     # Undefined user
```

шаблон `(_, _)` принимает только последовательность из двух элементов. последовательность другой длины, строка, число к нему не подходят.

шаблоны разной длины можно держать в одном `match`. субъект попадёт не больше чем в одну из этих ветвей, потому что длины различны.

```python
def print_data(user):
    match user:
        case (name, age):
            print(f"Name: {name}  Age: {age}")
        case (name, age, company):
            print(f"Name: {name}  Age: {age}  Company: {company}")
        case (name, age, company, lang):
            print(f"Name: {name}  Age: {age}  Company: {company} Language: {lang}")


print_data(("Tom", 37))                     # Name: Tom  Age: 37
print_data(("Sam", 22, "Microsoft"))        # Name: Sam  Age: 22  Company: Microsoft
print_data(("Bob", 41, "Google", "english"))    
# Name: Bob  Age: 41  Company: Google Language: english
```

### кортеж с неопределённым количеством элементов

хвост неизвестной длины записывают звёздочкой. имя после звёздочки получает оставшиеся элементы списком, даже если сам субъект был кортежем.

```python
def print_data(user):
    match user:
        case ("Tom", 37, *rest):
            print(f"Rest: {rest}")
        case (name, age, *rest):
            print(f"{name} ({age}): {rest}")


print_data(("Tom", 37))               # Rest: []
print_data(("Tom", 37, "Google"))     # Rest: ["Google"]
print_data(("Bob", 41, "Microsoft", "english"))     # Bob (41): ["Microsoft", "english"]
```

параметр `*rest` собирает все элементы после явно записанных. шаблоны `("Tom", 37, *rest)` и `(name, age, *rest)` принимают любую последовательность длины 2 и больше. элементы начиная с третьего попадают в `rest`. при длине ровно 2 список `rest` пуст. `print_data(("Tom", 37))` поэтому печатает пустой список: ветвь срабатывает, хвост пуст.

если хвост должен допускаться, но его значение не нужно, пишут `*_`:

```python
def print_data(user):
    match user:
        case ("Tom", 37, *_):
            print("Default user")
        case (name, age, *_):
            print(f"{name} ({age})")


print_data(("Tom", 37))               # Default user
print_data(("Tom", 37, "Google"))     # Default user
print_data(("Bob", 41, "Microsoft", "english"))     # Bob (41)
```
