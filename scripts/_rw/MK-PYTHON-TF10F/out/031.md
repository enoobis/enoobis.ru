обычно классы отражают объекты окружающей действительности. иногда приходится описывать сущности без конкретного воплощения. сущность «животное» не совпадает ни с кошкой, ни с собакой: конкретные животные существуют, а животное как таковое экземпляра не имеет. сущность «геометрическая фигура» точно так же не совпадает с прямоугольником, квадратом, кругом или треугольником. для описания таких сущностей применяют **абстрактные классы**.

все средства создания абстрактных классов собраны в модуле `abc`, который подключают отдельно:

```python
import abc
```

основу модуля составляют класс `ABC` и декоратор `@abstractmethod`. класс `ABC` задаёт метакласс `ABCMeta`, и абстрактные классы наследуют `ABC`. декоратор `@abstractmethod` помечает метод как абстрактный: у функции устанавливается признак `__isabstractmethod__`.

абстрактный класс объявляется как обычный класс и при этом наследуется от `ABC`:

```python
import abc
class Shape(abc.ABC):
    pass
```

как правило, абстрактный класс объявляет общий протокол наследников. часть этого протокола может не иметь реализации: её обязаны задать производные классы. такой протокол оформляют абстрактными методами. у геометрической фигуры могут быть методы периметра, площади и другие. общей формулы площади для всех фигур нет, у каждой фигуры свой принцип вычисления. поэтому метод площади в классе фигуры объявляют абстрактным. для этого ставят `@abstractmethod` из модуля `abc`:

```python
import abc
class Shape(abc.ABC):
    @abc.abstractmethod 
    def area (self): pass       # площадь фигуры
```

метод `area` определён как абстрактный. конкретной реализации у него нет, тело состоит из оператора `pass`.

экземпляр класса, у которого остались нереализованные абстрактные методы, создать нельзя. интерпретатор собирает такие имена в множество `__abstractmethods__` и при вызове конструктора поднимает `TypeError`, пока множество не пусто:

```python
import abc
class Shape(abc.ABC):
    @abc.abstractmethod 
    def area (self): pass       # площадь фигуры

shape = Shape()     # ! Ошибка - так нельзя
print(shape)
```

класс, унаследованный от `ABC` и не содержащий абстрактных методов, создаётся обычным образом. запрет срабатывает при непустом `__abstractmethods__`.

классы-наследники реализуют все абстрактные методы абстрактного класса. класс прямоугольника:

```python
import abc
class Shape(abc.ABC):
    @abc.abstractmethod 
    def area (self): pass       # площадь фигуры

# класс прямоугольника 
class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    def area (self): return self.width * self.height
    
rect = Rectangle(30, 50)
print("Rectangle area:", rect.area())   # Rectangle area: 1500
```

`Rectangle` принимает через конструктор ширину и высоту и использует их в `area`: площадь равна произведению сторон. после реализации `area` множество абстрактных методов пустеет, и экземпляр создаётся. если наследник оставит `area` нереализованным, он сам останется абстрактным, и вызов его конструктора завершится той же ошибкой.

тем же способом определяют другие фигуры. класс круга считает площадь как квадрат радиуса, умноженный на `3.14`:

```python
import abc
class Shape(abc.ABC):
    @abc.abstractmethod 
    def area (self): pass       # площадь фигуры

# класс прямоугольника 
class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    def area (self): return self.width * self.height
    
# класс круга 
class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    def area (self): return self.radius * self.radius * 3.14
    

def print_area(shape):
    print("Area:", shape.area())
    

rect = Rectangle(30, 50)
circle = Circle(30)
print_area(rect)        # Area: 1500
print_area(circle)      # Area: 2826.0
```

для вывода площади определена функция `print_area`, которая принимает любую фигуру. параметр аннотирован только использованием: функции достаточно объекта с методом `area`. вызов `shape.area()` диспетчеризуется по классу экземпляра, поэтому для прямоугольника выполняется `Rectangle.area`, а для круга `Circle.area`. общий тип `Shape` фиксирует наличие метода, конкретный класс поставляет формулу.

абстрактный класс может также определять конструктор, атрибуты и неабстрактные методы. наследники их используют:

```python
import abc
class Shape(abc.ABC):
    def __init__(self, x, y):
        self.x = x
        self.y = y 
        
    @abc.abstractmethod     
    def area (self): pass       # абстрактны метод
    
    def print_point(self):          # неабстрактный метод
        print("X:", self.x, "\tY:", self.y)

# класс прямоугольника 
class Rectangle(Shape):
    def __init__(self, x, y, width, height):
        super().__init__(x, y)
        self.width = width
        self.height = height
    def area (self): return self.width * self.height
    

rect = Rectangle(10, 20, 100, 100)
rect.print_point()      # X: 10   Y: 20
```

`Shape` через конструктор принимает координаты `x` и `y` точки, относительно которой строится фигура. для прямоугольника это может быть верхний левый угол, для круга центр. неабстрактный метод `print_point` выводит координаты точки на консоль. `Rectangle` в своём `__init__` вызывает `super().__init__(x, y)` и затем записывает ширину и высоту. метод `print_point` наследник не переопределяет: поиск по порядку разрешения методов находит реализацию в `Shape`.
