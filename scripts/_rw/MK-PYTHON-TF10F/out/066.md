оператор `as` задаёт псевдоним для значения шаблона или для всего шаблона. имя после `as` связывается с тем субъектом, который сопоставила эта часть. отдельный объект при связывании не создаётся.

```python
def print_person(person):
    match person:
        case "Tom" | "Tomas" | "Tommy" as name:
            print(f"Name: {name}")
        case _:
            print("Undefined")


print_person("Tom")     # Name: Tom
print_person("Tomas")   # Name: Tomas
print_person("Bob")     # Undefined
```

первый шаблон соответствует трём строкам: `"Tom"`, `"Tomas"` и `"Tommy"`. после набора значений стоит оператор `as`, затем указывается псевдоним. оператор `|` связывает теснее, чем `as`, поэтому `"Tom" | "Tomas" | "Tommy" as name` читается как `("Tom" | "Tomas" | "Tommy") as name`. какая бы из трёх строк ни была передана, она оказывается в переменной `name`. маска `_` закрывает остальные значения.

псевдоним применяют и для отдельного значения шаблона, и для всего шаблона.

```python
def print_person(person):
    match person:
        case ("Tom" | "Tomas" as name, 37 | 38 as age):   # псевдонимы для отдельных значений
            print(f"Tom| Name: {name}  Age: {age}")
        case ("Bob" | "Robert", 41 | 42) as bob:          # псевдоним для всего шаблона
            print(f"Bob| Name: {bob[0]}  Age: {bob[1]}")
        case _:
            print("Undefined")


print_person(("Tomas", 38))     # Tom| Name: Tomas  Age: 38
print_person(("Robert", 41))    # Bob| Name: Robert  Age: 41
```

в первой ветви `("Tom" | "Tomas" as name, 37 | 38 as age)` псевдонимы стоят у отдельных значений. из-за того, что `|` связывает теснее, `as` охватывает или-шаблон целиком: `name` получает и `"Tom"`, и `"Tomas"`, `age` получает и `37`, и `38`. чтобы связать только одну альтернативу, её заключают в скобки. вторая ветвь `("Bob" | "Robert", 41 | 42) as bob` задаёт псевдоним для всего шаблона. в `bob` оказывается сама последовательность, то есть кортеж, и элементы читаются по индексам `bob[0]` и `bob[1]`.

псевдонимы обычно нужнее на данных более сложной структуры.

```python
class Person:
    __match_args__ = ("name", "age")
    def __init__(self, name, age):
        self.name = name
        self.age = age


def print_family(family):
    match family:
        case (Person() as husband, Person() as wife):
            print(f"Husband. Name: {husband.name}  Age: {husband.age}")
            print(f"Wife. Name: {wife.name}  Age: {wife.age}")
        case _:
            print("Undefined")


print_family((Person("Tom", 37), Person("Alice", 33)))
# Husband. Name: Tom  Age: 37
# Wife. Name: Alice  Age: 33

print_family((Person("Sam", 28), Person("Kate", 25)))
# Husband. Name: Sam  Age: 28
# Wife. Name: Kate  Age: 25
```

функция `print_family` принимает кортеж, который должен состоять из двух элементов `Person`. атрибут `__match_args__` задаёт порядок позиционных подшаблонов класса. шаблон `Person()` пуст, позиционные подшаблоны не заданы, поэтому проверяется только тип: подходит любой экземпляр `Person`, в том числе экземпляр подкласса, атрибуты не ограничиваются. для первого элемента определён псевдоним `husband`, для второго псевдоним `wife`. по этим псевдонимам затем читаются атрибуты `name` и `age`. субъект иной формы попадает в ветвь `_`.
