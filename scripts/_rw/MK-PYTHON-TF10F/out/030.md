для пользовательского класса интерпретатор вызывает специальный метод экземпляра. выражение `a + b` приводит к вызову `a.__add__(b)`, если метод определён и вернул значение, отличное от `NotImplemented`. функции модуля `operator` являются обёртками над тем же синтаксисом: `operator.add(a, b)` эквивалентно `a + b`, а имена вида `__add__` в модуле служат псевдонимами этих функций. часть имён таблицы принадлежит функциям модуля `operator` и отдельного протокола модели данных не задаёт. конкатенация последовательностей идёт через `__add__`. логическое `not` проверяет истинность объекта через `__bool__` или, при его отсутствии, через `__len__`. составное присваивание, например `a += b`, вызывает `__iadd__`, если он есть. если метода нет, интерпретатор выполняет `a = a + b` и заново связывает имя.

чтобы определить оператор для класса, класс реализует соответствующий метод. оператор сложения задаётся методом `__add__`:

```python


class Counter:

    def __init__(self, value):

        self.value = value

    # переопределение оператора сложения

    def __add__(self, other):

        return Counter(self.value + other.value)

    

counter1 = Counter(5)

counter2 = Counter(15)

counter3 = counter1 + counter2

print(counter3.value)       # 20
```

класс `Counter` хранит атрибут `value`, условное числовое значение. метод `__add__` определяет для типа `Counter` оператор сложения. один объект `Counter` складывается с другим объектом `Counter`, поэтому второй параметр представляет другой объект `Counter`:

```python


def __add__(self, other):

    return Counter(self.value + other.value)
```

метод возвращает новый объект `Counter`, в который помещается сумма атрибутов `value` обоих операндов. исходные объекты не изменяются: результат операции есть отдельный экземпляр.

после этого два объекта `Counter` складываются, и результатом является новый объект `Counter`.

приведённая реализация описывает один из возможных смыслов сложения. второй параметр может иметь любой тип. если `Counter` нужно складывать с числом, оператор определяется так:

```python


class Counter:

    def __init__(self, value):

        self.value = value

        

    def __add__(self, other):

        return Counter(self.value + other)

    

counter1 = Counter(5)

counter3 = counter1 + 6

print(counter3.value)       # 11
```

оператор по-прежнему возвращает объект `Counter`, но второй параметр теперь представляет обычное число: выражение `self.value + other` использует сложение числа с числом.

возвращаемый тип ряда операторов языком жёстко не фиксируется. тот же метод может вернуть обычное число:

```python


class Counter:

    def __init__(self, value):

        self.value = value

        

    def __add__(self, other):

        return self.value + other

    

counter1 = Counter(5)

result = counter1 + 7

print(result)       # 12
```

методы ниже разбирают ещё несколько операторов. если метод левого операнда возвращает `NotImplemented` или отсутствует, интерпретатор пробует отражённый метод правого операнда (`__radd__` для сложения и аналоги для других арифметических операций). примеры этой лекции реализуют случай, когда `Counter` стоит слева от оператора.

### истинность объекта

метод `__bool__` задаёт истинность объекта и тем самым правило преобразования к `True` или `False`:

```python


class Counter:

    def __init__(self, value):

        self.value = value

    def __bool__(self):

        return self.value > 0

    

def test(counter):

    if counter: print("Counter = True")

    else: print("Counter = False")

    

counter1 = Counter(3)

test(counter1)              # Counter = True



counter2 = Counter(-3)

test(counter2)              # Counter = False
```

предикат в примере: объект `Counter` истинен, когда `value > 0`, и ложен при нуле и при отрицательных значениях. благодаря этому объект `Counter` используется в условных и циклических конструкциях. функция `test` в конструкции `if`/`else` проверяет значение объекта и печатает одно из двух сообщений.

если `__bool__` не определён, python обращается к `__len__`: ненулевая длина считается истиной. если нет ни `__bool__`, ни `__len__`, экземпляр считается истинным. явный `__bool__` заменяет оба этих правила.

объект `Counter` может служить условием цикла `while`:

```python


class Counter:

    def __init__(self, value):

        self.value = value

    def __bool__(self):

        return self.value > 0

    

counter1 = Counter(3)



while(counter1):

    print("Counter1: ", counter1.value)

    counter1.value -=1
```

цикл выполняется, пока `counter1` соответствует `True`, то есть пока `value` больше нуля. на каждой итерации `value` уменьшается на единицу. когда значение становится нулём, `__bool__` возвращает ложь, и цикл завершается.

### операторы, которые возвращают значение bool

ряд операций по контракту возвращает логическое значение `True` или `False`. к ним относятся операции сравнения:

```python


class Counter:

    def __init__(self, value):

        self.value = value

        

    def __gt__(self, other):

        return self.value > other.value

    def __lt__(self, other):

        return self.value < other.value



    

counter1 = Counter(1)

counter2 = Counter(2)

    

if counter1 > counter2: 

    print("counter1 больше чем counter2")

elif counter1 < counter2:

    print("counter1 меньше чем counter2")

else: 

    print("counter1 и counter2 равны")
```

в классе `Counter` определены операторы «больше» и «меньше», методы `__gt__` и `__lt__`. сравнение идёт с другим объектом `Counter` и сводится к сравнению атрибутов `value`:

```python


def __gt__(self, other):

    return self.value > other.value

def __lt__(self, other):

    return self.value < other.value
```

после этого соответствующие операции применяются к двум объектам `Counter`:

```python
if counter1 > counter2:
```

ветвь `else` выполняется, когда ложны и `>`, и `<`. для двух объектов с равным `value` оба метода возвращают `False`, и печатается сообщение о равенстве. отдельный `__eq__` в этом фрагменте не задан: равенство здесь выводится как отсутствие строгого порядка.

### операции обращения по индексу

ряд операторов обращается к объекту по индексу, в квадратных скобках:

```python
obj[index]
```

обычно такие операции применяют к коллекциям, которые разбираются в следующих лекциях: по индексу получают или изменяют элемент набора значений. те же операции применимы к любому объекту, а индекс может быть значением произвольного типа. ниже разбор получения значения по индексу:

```python


class Person:

    def __init__(self, name, age):

        self.__name = name

        self.__age = age

        

    def __getitem__(self, prop):

        if prop == "name": return self.__name

        elif prop == "age": return self.__age

        return None

    

tom = Person("Tom", 39)



print("Name:", tom["name"])     # Name: Tom

print("Age:", tom["age"])       # Age: 39

print("Id:", tom["id"])         # Id: None
```

класс `Person` содержит два приватных атрибута, `__name` и `__age`. получение данных по индексу реализует метод `__getitem__`. второй параметр этой функции есть значение, которое играет роль индекса. здесь индексом служит название атрибута. в зависимости от переданной строки метод возвращает либо `__name`, либо `__age`. при имени, которому не соответствует атрибут, метод возвращает `None`.

значение по индексу получают, передавая название атрибута в квадратных скобках:

```python
tom["name"]
```

вызов подписки транслируется в `__getitem__`. если в квадратных скобках записан срез, в метод приходит объект `slice`, что в таблице соответствует строке получения диапазона.

### проверка наличия свойства

оператор `in` проверяет наличие значения в последовательности, то есть в некотором наборе значений:

```python
значение in последовательность
```

если значение присутствует в последовательности, возвращается `True`, иначе `False`. тем же оператором проверяют наличие свойства в объекте:

```python


class Person:

    def __init__(self, name, age):

        self.name = name

        self.age = age

        

    def __contains__(self, prop):

        if prop == "name" or prop == "age": return True 

        return False

    

tom = Person("Tom", 39)

print("name" in tom)        # True

print("id" in tom)          # False
```

реализацию оператора `in` даёт метод `__contains__`. первый параметр, как и у других методов экземпляра, есть текущий объект: тот, что стоит справа от `in`. второй параметр есть проверяемое значение, оно стоит слева от `in`. если второй параметр равен `"name"` или `"age"`, метод возвращает `True`, что означает наличие такого атрибута у объекта.

выражение `"name" in tom` возвращает `True`, выражение `"id" in tom` возвращает `False`.

если `__contains__` не определён, python перебирает объект через итератор и сравнивает элементы оператором `==`. собственный `__contains__` заменяет этот перебор постоянной по времени проверкой имени.

### реализация операторов парами

операторы сравнения удобно реализовать парами. вместе с оператором `==` сразу определяют оператор `!=`. чтобы не записывать одну и ту же логику дважды, один оператор выражают через другой:

```python


class Counter:

    def __init__(self, value):

        self.value = value

    

    def __eq__(self, other): return self.value == other.value

    def __ne__(self, other): return not (self == other)

    

    def __gt__(self, other): return self.value > other.value

    def __le__(self, other): return not (self > other)

    

    def __lt__(self, other): return self.value < other.value

    def __ge__(self, other): return not (self < other)

        

c1 = Counter(1)

c2 = Counter(2)



print(c1 == c2)     # False

print(c1 != c2)     # True



print(c1 < c2)      # True

print(c1 >= c2)     # False
```

оператор `!=` возвращает инверсию результата оператора `==`, определённого выше:

```python


def __eq__(self, other): return self.value == other.value

def __ne__(self, other): return not (self == other)
```

аналогично оператор `<=` определён как инверсия `>`, а оператор `>=` как инверсия `<`. выражение `self == other` внутри `__ne__` снова вызывает `__eq__`, а `self > other` внутри `__le__` вызывает `__gt__`, поэтому формула сравнения атрибутов остаётся в одном методе.

начиная с python 3, если `__ne__` не определён, операция `!=` сама инвертирует результат `__eq__`, кроме случая, когда тот вернул `NotImplemented`. явная пара в примере делает эту зависимость видимой в коде класса. декоратор `functools.total_ordering` умеет достроить недостающие операции порядка из `__eq__` и одного из методов сравнения. пример записывает пары вручную.
