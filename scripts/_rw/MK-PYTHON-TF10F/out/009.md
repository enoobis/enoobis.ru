### вывод на консоль

для вывода информации на консоль предназначена встроенная функция **print()**. при вызове ей в скобках передаётся выводимое значение:

```python
print("Hello enoobis.ru")
```

этот код выводит на консоль строку `Hello enoobis.ru`.

отличительная особенность функции в том, что по умолчанию значение печатается на отдельной строке:

```python
print("Hello World")
print("Hello enoobis.ru")
print("Hello Python")
```

три вызова `print()` выводят три сообщения. при выводе на консоль каждое сообщение размещается на отдельной строке:

```bash
Hello World
Hello enoobis.ru
Hello Python
```

такое поведение не всегда соответствует задаче. если все значения нужны на одной строке, поведение функции настраивают параметром **end**. этот параметр задаёт символы, которые добавляются в конце к выводимой строке. при применении параметра **end** вызов `print()` выглядит так:

```python
print(значение, end = конечные_символы)
```

по умолчанию `end` равен символу `"\n"`, который задаёт перевод на следующую строку. поэтому `print` по умолчанию выводит переданное значение так, что следующее обращение к выводу начинается с новой строки.

чтобы функция не переводила строку, а продолжала вывод на той же строке, в `end` передают другой текст, в примере пробел:

```python
print("Hello World", end=" ")
print("Hello enoobis.ru", end=" ")
print("Hello Python")
```

выводимые значения разделяются пробелом:

```bash
Hello World Hello enoobis.ru Hello Python
```

в `end` может стоять не один символ, а набор символов:

```python
print("Hello World", end=" and ")
print("Hello enoobis.ru", end=" and ")
print("Hello Python")
```

выводимые сообщения отделяются символами `" and "`:

```bash
Hello World and Hello enoobis.ru and Hello Python
```

параметр `end` дописывается после всех значений данного вызова. разделение самих аргументов одного вызова задаёт другой параметр, `sep`, по умолчанию он равен пробелу. поток, куда пишет функция, по умолчанию является стандартным выводом.

### консольный ввод

наряду с выводом на консоль программа получает ввод пользователя и вводимые данные. для этого в python определена функция **input()**. в функцию передаётся приглашение к вводу. результат ввода сохраняют в переменной. пример ввода имени:

```python
name = input("Введите свое имя: ")
print(f"Ваше имя: {name}")
```

в функцию `input()` передаётся приглашение в виде строки `Введите свое имя: `. результат функции, то есть результат ввода пользователя, передаётся в переменную `name`. значение этой переменной затем выводится на консоль функцией `print()`. пример работы кода:

```bash
Введите свое имя: Eugene
Ваше имя: Eugene
```

ещё пример с вводом нескольких значений:

```python
name = input("Your name: ")
age = input("Your age: ")
print(f"Name: {name}  Age: {age}")
```

пример работы программы:

```bash
Your name: Tom
Your age: 37
Name: Tom  Age: 37
```

все введённые значения рассматриваются как значения типа **str**, то есть строки. даже если вводится число, как во втором примере выше, python рассматривает введённое значение как строку, а не как число. числовая интерпретация требует явного преобразования, например вызовом `int`. сама функция `input` разбора числа не выполняет: она возвращает текст до перевода строки, без этого перевода.
