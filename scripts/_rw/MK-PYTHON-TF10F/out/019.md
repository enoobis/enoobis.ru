лямбда-выражение в python задаёт небольшую анонимную функцию. его записывают оператором `lambda`. форма:

```python
lambda [параметры] : инструкция
```

простейшее лямбда-выражение:

```python
message = lambda: print("hello")

message()   # hello
```

выражение присваивается переменной `message`. параметров у него нет. тело состоит из вызова `print("hello")`: на консоль выводится строка `hello`, а значением самого вызова `print` является `None`, его лямбда и возвращает. через `message` выражение вызывается как обычная функция. та же семантика у функции с именем:

```python
def message(): 
    print("hello")
```

параметры лямбда-выражения записывают после слова `lambda`. значение, которое выражение возвращает, записывают после двоеточия: тело лямбды это одно выражение, и его значение становится результатом вызова. отдельный `return` не пишется. квадрат числа:

```python
square = lambda n: n * n

print(square(4))    # 16
print(square(5))    # 25
```

лямбда принимает один параметр `n`. справа от двоеточия стоит возвращаемое значение `n * n`. эквивалентная функция:

```python
def square2(n): return n * n
```

так же записывается лямбда с несколькими параметрами:

```python
sum = lambda a, b: a + b

print(sum(4, 5))    # 9
print(sum(5, 6))    # 11
```

лямбда-выражение короче отдельного `def`, но тело ограничено одним выражением: присваивания, циклы и другие операторы в него не входят. выражение уместно там, где функцию нужно передать параметром или вернуть из другой функции и отдельное имя не требуется. передача лямбды параметром:

```python
def do_operation(a, b, operation):
    result = operation(a, b)
    print(f"result = {result}")

do_operation(5, 4, lambda a, b: a + b)  # result = 9
do_operation(5, 4, lambda a, b: a * b)  # result = 20
```

именованные функции для передачи в `do_operation`, как в предыдущей лекции, здесь не нужны: аргументом служит само выражение. вызов со сложением печатает 9, вызов с умножением печатает 20.

лямбда точно так же возвращается из функции. при выборе 1 возвращается сложение, при выборе 2 вычитание, при любом другом значении, в том числе при 3, умножение. следующие вызовы печатают 16, 4 и 60:

```python
def select_operation(choice):
    if choice == 1:
        return lambda a, b: a + b
    elif choice == 2:
        return lambda a, b: a - b
    else:
        return lambda a, b: a * b


operation = select_operation(1)  # operation = sum
print(operation(10, 6))  # 16

operation = select_operation(2)  # operation = subtract
print(operation(10, 6))  # 4

operation = select_operation(3)  # operation = multiply
print(operation(10, 6))  # 60
```
