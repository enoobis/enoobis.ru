встроенный модуль `math` стандартной библиотеки python собирает функции элементарной математики: степени и корни, округление, факториал, перевод углов, тригонометрию и логарифмы. большая часть модуля реализована на c и считает в двоичной плавающей точке ieee 754. операции, которые по определению заданы на целых, например факториал, работают с типом `int`. основные функции:

- `pow(num, power)`: возведение числа num в степень power. результат всегда имеет тип `float`. инфиксный оператор `**` для двух целых операндов сохраняет целый тип, поэтому при той же математической величине тип результата у оператора и у `math.pow` различен

- `sqrt(num)`: квадратный корень числа num, значение типа `float`

- `ceil(num)`: округление к ближайшему целому в сторону плюс бесконечности. для аргумента типа `float` в python 3 функция возвращает `int`

- `floor(num)`: округление к ближайшему целому в сторону минус бесконечности, для `float` результат тоже `int`

- `factorial(num)`: факториал неотрицательного целого num

- `degrees(rad)`: перевод величины угла из радиан в градусы

- `radians(grad)`: перевод величины угла из градусов в радианы

- `cos(rad)`: косинус угла, аргумент в радианах

- `sin(rad)`: синус угла, аргумент в радианах

- `tan(rad)`: тангенс угла, аргумент в радианах

- `acos(num)`: арккосинус. аргумент лежит на отрезке от -1 до 1, результат - угол в радианах

- `asin(num)`: арксинус, результат в радианах

- `atan(num)`: арктангенс, результат в радианах

- `log(n, base)`: логарифм числа n по основанию base. если основание не передано, вычисляется натуральный логарифм

- `log10(n)`: десятичный логарифм числа n

пример применения части этих функций:

```python
import math

# возведение числа 2 в степень 3
n1 = math.pow(2, 3)
print(n1)  # 8

# ту же самую операцию можно выполнить так
n2 = 2**3
print(n2)

# квадратный корень числа
print(math.sqrt(9))  # 3

# ближайшее наибольшее целое число
print(math.ceil(4.56))  # 5

# ближайшее наименьшее целое число
print(math.floor(4.56))  # 4

# перевод из радиан в градусы
print(math.degrees(3.14159))  # 180

# перевод из градусов в радианы
print(math.radians(180))   # 3.1415.....
# косинус
print(math.cos(math.radians(60)))  # 0.5
# cинус
print(math.sin(math.radians(90)))   # 1.0
# тангенс
print(math.tan(math.radians(0)))    # 0.0

print(math.log(8,2))    # 3.0
print(math.log10(100))    # 2.0
```

возведение в степень во фрагменте записано двумя способами: вызовом `math.pow` и оператором `**`. тригонометрические функции принимают радианы, поэтому градусная мера сначала переводится через `math.radians`: косинус 60 градусов равен 0.5, синус 90 градусов равен 1.0, тангенс нуля равен 0.0. `math.log(8, 2)` даёт 3.0, `math.log10(100)` даёт 2.0.

модуль `math` также задаёт константы. для курса достаточны `math.pi` (отношение длины окружности к диаметру) и `math.e` (основание натурального логарифма). в исходной формулировке лекции они названы pi и e:

```python
import math
radius = 30
# площадь круга с радиусом 30
area = math.pi * math.pow(radius, 2)
print(area)

# натуральный логарифм числа 10
number = math.log(10, math.e)
print(number)
```

площадь круга здесь считается как `pi * r^2`. натуральный логарифм получен как логарифм по основанию `math.e`: вызов `math.log` с одним аргументом делает то же самое.

### дополнительные математические функции

в python есть встроенные функции для числовых расчётов, которые в модуль `math` не входят. среди них:

- `abs`: абсолютное значение числа, то есть модуль

- `min`: наименьшее значение среди элементов списка или другого набора сравнимых объектов

- `max`: наибольшее значение среди таких элементов

расстояние между двумя числами как абсолютная разность без учёта знака:

```python
num1 = 3
num2 = 8
diff = abs(num1-num2)  # 5
print(diff)   # 5
```

`abs` определена для чисел и для объектов, у которых есть метод `__abs__`.

наименьшее и наибольшее число в списке:

```python
numbers = [54, 23, 1, 4, 657, 2, -3, 56, 24]

min_number = min(numbers)  # -3
max_number = max(numbers)  # 657
print("min:", min_number) 
print("max:", max_number)
```

`min` и `max` принимают любой итерируемый объект с элементами, упорядоченными отношением `<`, а также несколько отдельных аргументов. в примере аргумент один, и это список.
