особый класс операций представляют поразрядные операции. они выполняются над отдельными разрядами чисел типа `int`. чтобы видеть, что именно делает такая операция, нужно двоичное представление числа. у `int` точность произвольная, и отрицательные значения хранятся в дополнительном коде с бесконечным распространением знакового бита. примеры ниже неотрицательные, на них видна конечная запись без знака.

### двоичное представление чисел

в двоичной системе каждый разряд числа принимает только два значения, 0 и 1. 0 в десятичной системе равен 0 в двоичной, 1 соответствует 1. следующее десятичное число, 2, в двоичной системе записывается как 10: когда к 1 прибавляют 1, результат равен 10. дальше разряды заполняются по тому же правилу.

число 5 в двоичном представлении равно 101 и занимает три разряда. для вывода десятичного числа в двоичной системе применяют спецификатор `0b`:

```python
number = 5 # в двоичной форме 101
print(f"number = {number:0b}")  # number = 101
```

спецификатор `0b` в фигурных скобках f-строки задаёт формат вывода. это не префикс литерала. без спецификатора функция `print()` выводит число в десятичной системе. преобразование целого в строку по умолчанию десятичное.

python позволяет сразу задать число в двоичной форме. двоичная запись ставится после префикса **0b**:

```python
number = 0b101	# определяем число в двоичной форме
print(f"number = {number:0b}")  # number = 101
print(f"number = {number}")  # number = 5 - в десятичной системе
```

префикс `0b` меняет разбор литерала. объект после разбора остаётся обычным `int`, поэтому десятичный вывод показывает 5.

ещё несколько соответствий двоичной и десятичной систем:

```python
number1 = 1 # в двоичной системе 0b1
number2 = 2 # в двоичной системе 0b10
number3 = 3 # в двоичной системе 0b11
number4 = 4 # в двоичной системе 0b100
number5 = 5 # в двоичной системе 0b101
number6 = 6 # в двоичной системе 0b110
```

### операции над отдельными разрядами

в python есть следующие операции над отдельными разрядами чисел. их называют и поразрядными, и логическими: операция сопоставляет биты двух операндов по позициям.

- `&` (логическое умножение). умножение производится поразрядно. если у обоих операндов значение разряда равно 1, операция возвращает 1, иначе возвращается 0. в первом случае числа равны 2 и 5. 2 в двоичном виде это 010, 5 это 101. поразрядное умножение даёт 0*1, 1*0, 0*1, итог 000. во втором случае вместо двойки стоит 4. у 4 в старшем из этих трёх разрядов стоит 1, как и у 5, поэтому результат равен 1*1, 0*0, 0*1, то есть 100, число 4 в десятичной записи:

```python
x1 = 2  # 010
y1 = 5  # 101
z1 = x1 & y1
print(f"z1 = {z1}")   # z1 = 0

x2 = 4  # 100
y2 = 5  # 101
z2 = x2 & y2
print(f"z2 = {z2}")   # z2 = 4
print(f"z2 = {z2:0b}")  # z2 = 100
```

- `|` (логическое сложение). операция тоже идёт по двоичным разрядам, но возвращает единицу, если хотя бы у одного числа в данном разряде есть единица:

```python
x1 = 2      # 010
y1 = 5      # 101
z1 = x1|y1  # 111

print(f"z1 = {z1}")     # z1 = 7
print(f"z1 = {z1:0b}")  # z1 = 111

x2 = 4          # 100
y2 = 5          # 101
z2 = x2 | y2    # 101
print(f"z2 = {z2}")     # z2 = 5
print(f"z2 = {z2:0b}")  # z2 = 101
```

- `^` (логическое исключающее или). если значения текущего разряда у обоих чисел разные, возвращается 1, иначе возвращается 0. эту операцию также называют xor. число 9 в двоичной форме равно 1001, число 5 равно 0101. xor по этим разрядам даёт 1^0, 0^1, 0^0, 1^1. первые два разряда в этой записи содержат разные значения и получают 1. последние два содержат одинаковые значения и получают 0. результат равен 1100, или 12 в десятичной системе:

```python
x = 9       #  1001
y = 5       #  0101
z = x ^ y   #  1100
print(f"z = {z}")       # z = 12
print(f"z = {z:0b}")   # z = 1100
```

ту же операцию применяют для простого шифрования. xor обратен сам себе: повторное применение того же ключа возвращает исходное число, потому что `(x ^ key) ^ key` равно `x`:

```python
x = 45       # Значение, которое надо зашифровать - в двоичной форме 101101
key = 102    # Пусть это будет ключ - в двоичной форме 1100110

encrypt = x ^ key    # Результатом будет число 1001011 или 75
print(f"Зашифрованное число: {encrypt}")

decrypt = encrypt ^ key    # Результатом будет исходное число 45
print(f"Расшифрованное число: {decrypt}")
```

той же операцией меняют местами значения двух чисел без отдельной временной переменной. после трёх присваиваний имена указывают на бывшие значения друг друга:

```python
x = 9       #  1001
y = 5       #  0101
x = x ^ y
y = x ^ y
x = x ^ y 

print(f"x = {x}")       # x = 5
print(f"y = {y}")       # y = 9
```

ход обмена на тех же битах таков. сначала `x` становится `9 ^ 5`, то есть 1100. затем `y` становится `1100 ^ 0101`, то есть прежним значением `x`, 1001. затем `x` становится `1100 ^ 1001`, то есть прежним значением `y`, 0101.

- `~` (инверсия). операция инвертирует число. выражение `~x` фактически аналогично `-(x+1)`. равенство является определением операции для `int`, а не оценкой: каждый бит меняется на противоположный, и из-за дополнительного кода это совпадает с арифметическим `-(x+1)`. пример:

```python
x = 5
y = ~x;
print(f"y: {y}")  # -6
```

для `x`, равного 5, результат равен -6.

### операции сдвига

операции сдвига тоже производятся над разрядами чисел. сдвиг может идти вправо и влево.

- `x >> y` сдвигает число `x` вправо на `y` разрядов. например, `16 >> 1` сдвигает число 16, в двоичном представлении 10000, на один разряд вправо. получается 1000, или число 8 в десятичном представлении. младшие разряды при правом сдвиге отбрасываются.

- `x << y` сдвигает число `x` влево на `y` разрядов. младшие разряды, которые появляются слева от старой записи, заполняются нулями.

если исходное неотрицательное число, которое сдвигают в ту или другую сторону, делится на два, сдвиг на один разряд совпадает с умножением или делением на два. в общем виде сдвиг влево на `y` разрядов умножает неотрицательное целое на `2 ** y`, сдвиг вправо делит его нацело на `2 ** y`. поэтому сдвиг используют вместо непосредственного умножения или деления на степень двойки. пример сдвига на два разряда:

```python
a = 16 # в двоичной форме 10000
b = 2  
c = a << b  # Сдвиг числа 10000 влево на 2 разряда, равно 1000000 или 64 в десятичной системе
print(c)   #64

d = a >> b  #Сдвиг числа  10000  вправо на 2 разряда, равно 100 или 4 в десятичной системе
print(d)   #4
```

числа, которые участвуют в операциях, не обязаны быть степенью двойки и не обязаны быть кратны 2. операция определена для целого вообще. во втором примере взято 22. правый сдвиг отбрасывает младшие биты, левый дописывает нули:

```python
a = 22 # в двоичной форме 10110
b = 2
c = a << b  # Сдвиг числа 10110 влево на 2 разряда, равно 1011000 или 88 в десятичной системе
print(c)   # 88

d = a >> b  # Сдвиг числа 10110 вправо на 2 разряда, равно 101 или 5 в десятичной системе
print(d)   # 5
```
