### установка

для создания программ на python нужен интерпретатор. его устанавливают со страницы https://www.python.org/downloads/ , где находится ссылка на загрузку последней версии языка:

![установка python на macos](/uploads/course-lectures/17c6466330ebffdf27effe5cfdae2e46422769ff.png)

если текущая система mac os, по адресу https://www.python.org/downloads/ предлагается графический установщик для macos. установщик загружают, запускают и проходят пошаговую установку:

![установка python на macos](/uploads/course-lectures/eb671b20486c31eb5dc48d5fc71dbcd5242f8262.png)

к интерпретатору на macos обращаются командой `python3`. исторически имя `python` на этой системе указывало на python 2, который поставляла apple и позднее убрала из состава системы, поэтому официальный установщик регистрирует команду `python3`. после установки версию проверяют этой командой:

```consoletext
python3 --version
```

![проверка установки python на macos](/uploads/course-lectures/2a06bc713f503c0fc2410c4f1735c1091108812d.png)

### первая программа

где-нибудь на диске создают каталог `python` для скриптов. в каталоге создают текстовый файл `hello.py`. для исходного текста на python принято расширение `py`.

файл открывают в любом текстовом редакторе и помещают в него следующий код:

```python
name = input("Your name: ")
print("Hello, ", name)
```

![python в visual studio code mac os](/uploads/course-lectures/b4d4b7ae6b7189b4b59dd08f620388779763b164.png)

скрипт состоит из двух инструкций. первая вызывает `input()` и ждёт, пока пользователь введёт имя. введённая строка связывается с именем `name`. функция возвращает значение типа `str` без завершающего перевода строки.

вторая инструкция вызывает `print()` и выводит приветствие вместе с введённым именем.

далее открывают терминал и командой `cd` переходят в каталог, где лежит `hello.py`. в примере это каталог `/Users/eugene/Documents/python`:

```consoletext
cd /Users/eugene/Documents/python
```

для выполнения скрипт передают интерпретатору `python3`:

```consoletext
python3 hello.py
```

программа печатает приглашение к вводу имени, затем печатает приветствие.
