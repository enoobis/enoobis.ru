python поддерживает все распространённые арифметические операции:

- `+` сложение двух чисел:

```python
print(6 + 2)  # 8
```

- `-` вычитание двух чисел:

```python
print(6 - 2)  # 4
```

- `*` умножение двух чисел:

```python
print(6 * 2)  # 12
```

- `/` деление двух чисел:

```python
print(6 / 2)  # 3.0
```

оператор `/` в python 3 выполняет вещественное деление. результат имеет тип `float`, даже если оба операнда имеют тип `int`. этим `/` отличается от целочисленного деления.

- `//` целочисленное деление двух чисел. операция возвращает целочисленный результат деления, отбрасывая дробную часть:

```python
print(7 / 2)  # 3.5
print(7 // 2)  # 3
```

отбрасывание устроено как округление вниз, к минус бесконечности, а не к нулю. для положительных операндов из примера это совпадает с отсечением дробной части. для отрицательных результат может отличаться от деления в c: частное не приближается к нулю, а уходит к меньшему целому.

- `**` возведение в степень:

```python
print(6 ** 2)  # Возводим число 6 в степень 2. Результат - 36
```

- `%` получение остатка от деления. ближайшее число к 7, которое делится на 2 без остатка, это 6. остаток от деления равен 7 - 6 = 1:

```python
print(7 % 2)  # Получение остатка от деления числа 7 на 2. Результат - 1
```

для целых остаток согласован с целочисленным частным: `a % b` равно `a - (a // b) * b`.

при последовательном использовании нескольких арифметических операций их выполнение идёт по приоритету. раньше выполняются операции с большим приоритетом. приоритеты в порядке убывания приведены в таблице. столбец направления задаёт ассоциативность, то есть порядок при равном приоритете.

| операции | направление |
| --- | --- |
| ** | справа налево |
| * / // % | слева направо |
| + - | слева направо |

возведение в степень правоассоциативно: при нескольких `**` подряд сначала выполняется правая пара. умножение, деление и сложение левоассоциативны.

следующее выражение вычисляется по этой таблице:

```python
number = 3 + 4 * 5 ** 2 + 7
print(number)  # 110
```

сначала выполняется возведение в степень `5 ** 2` как операция с большим приоритетом, далее результат умножается на 4 (`25 * 4`), затем выполняется сложение `3 + 100`, затем сложение `103 + 7`. итог равен 110.

чтобы переопределить порядок операций, используют скобки. выражение в скобках вычисляется раньше окружающих операций того же текста:

```python
number = (3 + 4) * (5 ** 2 + 7)
print(number)  # 224
```

в арифметических операциях участвуют и целые, и дробные числа. если в одной операции участвует целое число (`int`) и число с плавающей точкой (`float`), целое приводится к типу `float`. результат смешанной операции имеет тип `float`.

### арифметические операции с присвоением

ряд операций сразу присваивает результат первому операнду:

- `+=` присвоение результата сложения

- `-=` присвоение результата вычитания

- `*=` присвоение результата умножения

- `/=` присвоение результата от деления

- `//=` присвоение результата целочисленного деления

- `**=` присвоение степени числа

- `%=` присвоение остатка от деления

для чисел `int` и `float` такая операция вычисляет результат и заново связывает имя с этим результатом. числовой объект сам по себе не изменяется: у этих типов нет изменяемого состояния.

примеры операций:

```python
number = 10
number += 5
print(number)  # 15

number -= 3
print(number)  # 12

number *= 4
print(number)  # 48
```

### округление и функция round

при операциях с числами типа `float` результат может быть неточным:

```python
first_number = 2.0001
second_number = 5
third_number = first_number / second_number
print(third_number)	# 0.40002000000000004
```

ожидаемое частное равно 0.40002, однако в конце после ряда нулей появляется лишняя цифра. то же видно на сложении:

```python
print(2.0001 + 0.1)  # 2.1001000000000003
```

причина в представлении. `float` хранится в двоичном формате `IEEE 754`, и многие десятичные дроби, включая 0.1 и 0.0001, не имеют конечной записи в двоичной системе. в объект попадает ближайшее представимое число, и уже с ним выполняется операция. десятичная печать показывает это накопленное отклонение.

для округления результата используется встроенная функция **round()**:

```python
first_number = 2.0001
second_number = 0.1
third_number = first_number + second_number
print(round(third_number))  # 2
```

в функцию `round()` передаётся число, которое нужно округлить. если передано одно число, как в примере выше, оно округляется до целого.

функция `round()` принимает и второй аргумент. он указывает, сколько знаков после запятой должно содержать получаемое число:

```python
first_number = 2.0001
second_number = 0.1
third_number = first_number + second_number
print(round(third_number, 4))  # 2.1001
```

число `third_number` округляется до 4 знаков после запятой.

если в функцию передано только округляемое число, оно округляется до ближайшего целого.

примеры округлений:

```python
# округление до целого числа
print(round(2.49))  # 2 - округление до ближайшего целого 2
print(round(2.51))  # 3
```

если округляемая часть одинаково удалена от двух целых чисел, округление идёт к ближайшему чётному:

```python
print(round(2.5))   # 2 - ближайшее четное
print(round(3.5))   # 4 - ближайшее четное
```

это правило банковского округления, round half to even. при равенстве расстояний выбирается чётное значение, а не всегда большее по модулю.

округление производится до ближайшего кратного 10 в степени минус число оставляемых знаков:

```python
# округление до двух знаков после запятой
print(round(2.554, 2))      # 2.55
print(round(2.5551, 2))      # 2.56
print(round(2.554999, 2))   # 2.55
print(round(2.499, 2))      # 2.5
```

функция `round()` не снимает ограничение двоичного формата. выше при округлении до целых применяется правило: если округляемая часть одинаково удалена от двух значений, выбирается ближайшее чётное. в python десятичная дробь не всегда точно представима значением `float`, и перед округлением число уже может быть чуть больше или чуть меньше десятичной середины. отсюда результаты, которые не совпадают с ожиданием по десятичной записи:

```python
# округление до двух знаков после запятой
print(round(2.545, 2))   # 2.54
print(round(2.555, 2))   # 2.56 - округление до четного
print(round(2.565, 2))   # 2.56
print(round(2.575, 2))   # 2.58

print(round(2.655, 2))   # 2.65 - округление не до четного
print(round(2.665, 2))   # 2.67
print(round(2.675, 2))   # 2.67
```
