### создание объекта исключения

при обработке исключения учитывают, что при передаче объекта оператору `throw` блок `catch` получает копию этого объекта. копия существует только в пределах блока `catch`. оператор `throw` копирует (или перемещает) операнд в объект исключения, которым управляет механизм обработки. параметр `catch`, принятый по значению, копирует этот объект ещё раз.
