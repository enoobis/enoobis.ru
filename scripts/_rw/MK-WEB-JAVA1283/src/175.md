Долгое время работа с датами и временем в JavaScript основывалась на встроенном объекте `Date`, который предоставляет API для управления датами и временем. Однако объект Date обладает рядом критических недостатков: - Мутабельность : объекты можно изменять напрямую, что может привести к трудноотловимым багам - Сложность с часовыми поясами : встроенная поддержка временных зон крайне ограничена - Неудобная арифметика : для прибавления пары дней часто приходится писать громоздкие конструкции - Ошибки/неоднозначные решения в API : например, месяцы в Date начинаются с 0, а дни - с 1 И для решения проблем с объектом `Date` в язык JavaScript внедряется Temporal API . На момент написания текущей статьи ожидается, что этот API и войдет в стандарт ES2026, тем не менее он уже доступен в большинстве распространенных браузеров - в Chrome, Firefox, Edge. По сути Temporal API - это современный стандарт, который меняет подход к обработке времени и дат. Его основные преимущества:





- Иммутабельность : объекты Temporal неизменяемы. Любая операция (добавление времени, смена пояса) создает новый объект.

- Разделение сущностей : вместо одного универсального объекта `Date` (который хранит и дату, и время одновременно), Temporal предлагает специализированные типы: `Temporal.PlainDate` (только дата), `Temporal.PlainTime` (только время), `Temporal.ZonedDateTime` (дата и время с учетом конкретного часового пояса).


- Простая арифметика : методы вроде `add()` и `subtract()` позволяют легко манипулировать датами без ручных вычислений.

- Безопасная работа с DST : API автоматически учитывает переходы на летнее и зимнее время при расчетах.



### Основные типы Temporal API



Ключевая функциональность Temporal API сосредоточена в нескольких типах, которые можно разделить следующим образом в зависимости от их назначения:





- Instant : точная точка во времени (timestamp) в наносекундах с 1 января 1970 года. Не привязана к календарю или временной зоне (всегда UTC).

- ZonedDateTime : cамый полный тип. Это "дата + время + временная зона + календарь". Используется, когда важно учитывать переход на летнее время и локальные правила региона. Некоторое подобие стандартного объекта `Date`

- PlainDateTime : комбинация даты и времени. Но не учитывает смещение UTC.

- PlainDate : только дата (год, месяц, день)

- PlainTime : только время (часы, минуты, секунды)

- PlainYearMonth : только год и месяц

- PlainMonthDay : только месяц и день

- Duration : отрезок времени (например, "2 часа 30 минут"). Используется для арифметики (прибавить к дате) и сравнения разницы между двумя событиями.




### Свойство Now. Получение текущих даты и времени



Для получения текущих даты и времени в Temporal API определено свойство **Temporal.Now**, которое содержит статические методы для получения текущего времени в различных форматах:





- `instant()` : возвращает текущее время в виде объекта Temporal.Instant.

- `plainDateISO(timeZone)` : возвращает текущую дату в виде объекта Temporal.PlainDate в указанном часовом поясе (необязательный параметр timeZone).

- `plainDateTimeISO(timeZone)` : возвращает текущую дату и время в виде объекта Temporal.PlainDateTime в указанном часовом поясе (необязательный параметр timeZone)

- `plainTimeISO(timeZone)` : возвращает текущее время в виде объекта Temporal.PlainTime в указанном часовом поясе (необязательный параметр timeZone)

- `timeZoneId()` : возвращает идентификатор часового пояса, представляющий текущий часовой пояс системы.

- `zonedDateTimeISO(timeZone)` : возвращает текущую дату и время в виде объекта Temporal.ZonedDateTime в указанной временной зоне (необязательный параметр timeZone)



Часть этих методов принимают идентификатор временной зоны. Поэтому вначале расмотрим, что они представляют.



Наиболее полный список всех идентификаторов временных зон можно найти на специализированных сайтах. В частности, по адресу [https://www.iana.org/time-zones](https://www.iana.org/time-zones). Однако их поддержка может отличаться. Чтобы посмотреть, какие идентификаторы временных зон поддерживаются в текущем браузере на текущий момент, можно использовать следующий код:



Пример получения



```javascript

const timeZones = Intl.supportedValuesOf("timeZone");
console.log(timeZones);
```



В итоге мы получим массив идентфикаторов, разбитых по группам. Каждый идентификатор представляет строку типа "Europe/Belgrade", где вначале идет обычно название континента и через слеш название города, ключевого для временной зоны. Например, идентфиикатор `"Europe/Belgrade"` представляет временную зону столицы Сербии - Белграда. Аналогично "Europe/Moscow" представляет временную зону Москвы, а, скажем, "Europe/Volgograd" - временную зону Волгограда. При этом важно не путать временную зону с часовым поясом. Так, в данном случае Моска и Волгоград условно представляют разные временные зоны, но тем в реальности часовой пояс у них один и тот же.




С помощью метода `Temporal.Now.timeZoneId()` можно получить текущую временную зону:



```javascript
console.log(Temporal.Now.timeZoneId()); // например, "Europe/Volgograd"
```



Примеры получения текущих времени и даты с учетом временной зоны и без:



```javascript

const instant = Temporal.Now.instant();
console.log(instant.toString()); // 2026-03-16T13:27:26.567Z

// текущая дата во временной зоне текущей системы
const date = Temporal.Now.plainDateISO();
console.log(date.toString()); // 2026-03-16

// текущая дата во временной зоне "Europe/Belgrade"
const dateInBelgrade = Temporal.Now.plainDateISO("Europe/Belgrade");
console.log(dateInBelgrade.toString()); // 2026-03-16

// текущие дата и время во временной зоне текущей системы
const dateTime = Temporal.Now.plainDateTimeISO();
console.log(dateTime.toString()); // 2026-03-16T16:27:26.568

// текущие дата и время во временной зоне "Europe/Belgrade"
const dateTimeInBelgrade = Temporal.Now.plainDateTimeISO("Europe/Belgrade");
console.log(dateTimeInBelgrade.toString()); // 2026-03-14T16:27:26.568

// текущиее время во временной зоне текущей системы
const time = Temporal.Now.plainTimeISO();
console.log(time.toString()); // 16:27:26.568

// текущиее время во временной зоне "Europe/Belgrade"
const timeInBelgrade = Temporal.Now.plainTimeISO("Europe/Belgrade");
console.log(timeInBelgrade.toString()); // 14:27:26.568

// текущие дата и время во временной зоне текущей системы
const zoneDateTime = Temporal.Now.zonedDateTimeISO();
console.log(zoneDateTime.toString()); // 2026-03-16T16:27:26.568+03:00[Europe/Moscow]

// текущие дата и время во временной зоне "Europe/Belgrade"
const zoneDateTimeInBelgrade = Temporal.Now.zonedDateTimeISO("Europe/Belgrade");
console.log(zoneDateTimeInBelgrade.toString()); // 2026-03-16T14:27:26.568+01:00[Europe/Belgrade]
```



Стоит отметить, что все основные типы в Temporal API поддерживают метод **toLocaleString()**, который в отличие от метода `toString()`, позволяет вывести дату/время в соответствии с текущей локалью (языковыми настройками) системы. Что может представить дату/время, возможно, в более предпочтительном формате для вывода. Например, вывод для англоязычной локали:



```javascript

const instant = Temporal.Now.instant();
console.log(instant.toLocaleString()); // 3/19/2026, 10:52:12 PM

// текущая дата во временной зоне текущей системы
const date = Temporal.Now.plainDateISO();
console.log(date.toLocaleString()); // 3/19/2026

// текущая дата во временной зоне "Europe/Belgrade"
const dateInBelgrade = Temporal.Now.plainDateISO("Europe/Belgrade");
console.log(dateInBelgrade.toLocaleString()); // 3/19/2026

// текущие дата и время во временной зоне текущей системы
const dateTime = Temporal.Now.plainDateTimeISO();
console.log(dateTime.toLocaleString()); // 3/19/2026, 10:52:12 PM

// текущие дата и время во временной зоне "Europe/Belgrade"
const dateTimeInBelgrade = Temporal.Now.plainDateTimeISO("Europe/Belgrade");
console.log(dateTimeInBelgrade.toLocaleString()); // 3/19/2026, 8:52:12 PM

// текущиее время во временной зоне текущей системы
const time = Temporal.Now.plainTimeISO();
console.log(time.toLocaleString()); // 10:52:12 PM

// текущиее время во временной зоне "Europe/Belgrade"
const timeInBelgrade = Temporal.Now.plainTimeISO("Europe/Belgrade");
console.log(timeInBelgrade.toLocaleString()); // 8:52:12 PM

// текущие дата и время во временной зоне текущей системы
const zoneDateTime = Temporal.Now.zonedDateTimeISO();
console.log(zoneDateTime.toLocaleString()); // 3/19/2026, 10:52:12 PM GMT+3

// текущие дата и время во временной зоне "Europe/Belgrade"
const zoneDateTimeInBelgrade = Temporal.Now.zonedDateTimeISO("Europe/Belgrade");
console.log(zoneDateTimeInBelgrade.toLocaleString()); // 3/19/2026, 8:52:12 PM GMT+1
```
