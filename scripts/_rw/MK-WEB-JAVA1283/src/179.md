Объект Temporal.PlainDateTime по сути представляет собой комбинацию объектов `Temporal.PlainDate` и `Temporal.PlainTime`. `PlainDateTime` применяется для представления даты и времени, которые могут отличаться в разных часовых поясах.



### Создание PlainDateTime



Для создания/получения объекта `PlainDateTime` можно использовать три способа:





- Конструкторы

- Статический метод `Temporal.Now.plainDateTimeISO()` , который возвращает текущую дату и время

- Статический метод `Temporal.PlainDateTime.from()` , который создает объект PlainDateTime из другого объекта или строки



#### Конструкторы



Для создания `PlainDateTime` прежде всего можно использовать соответствующие функции-конструкторы



```javascript

new Temporal.PlainDateTime(year, month, day)
new Temporal.PlainDateTime(year, month, day, hour)
new Temporal.PlainDateTime(year, month, day, hour, minute)
new Temporal.PlainDateTime(year, month, day, hour, minute, second)
new Temporal.PlainDateTime(year, month, day, hour, minute, second, millisecond)
new Temporal.PlainDateTime(year, month, day, hour, minute, second, millisecond, microsecond)
new Temporal.PlainDateTime(year, month, day, hour, minute, second, millisecond, microsecond, nanosecond)
new Temporal.PlainDateTime(year, month, day, hour, minute, second, millisecond, microsecond, nanosecond, calendar)
```



Параметры конструкторов:





- `year` : год

- `month` : месяц

- `day` : день месяца

- `hour` (необязательный): час

- `minute` (необязательный): минуты

- `second` (необязательный): секунды

- `millisecond` (необязательный): миллисекунды.

- `microsecond` (необязательный): микросекунды

- `nanosecond` (необязательный): наносекунды

- `calendar` (необязательный): cтрока, обозначающая используемый календарь (по умолчанию `"iso8601"` ). Но независимо от выбранного календаря значения года, месяца и дня должны соответствовать календарной системе ISO 8601. Для получения всех доступных календарей можно использовать выражение `Intl.supportedValuesOf("calendar")`



Пример определения объекта `PlainDateTime`:



```javascript

const dt1 = new Temporal.PlainDateTime(2026, 3, 16);
console.log(dt1.toString()); // 2026-03-16T00:00:00

const dt2 = new Temporal.PlainDateTime(2026, 3, 16, 0, 0, 0, 0, 0, 0, "persian");
console.log(dt2.toString()); // 2026-03-16T00:00:00[u-ca=persian]
```



#### Получение текущих даты и времени



Для получения текущих значений даты и времени в виде объекта `PlainDateTime` применяется статический метод `Temporal.Now.plainDateTimeISO()`:



```javascript

const dateTime = Temporal.Now.plainDateTimeISO();
console.log(dateTime.toString());   // 2026-03-16T22:25:28.634090088
```



#### Temporal.PlainDateTime.from()



Статический метод `Temporal.PlainDateTime.from()` создает новый объект `PlainDateTime` из другого объекта `PlainDateTime`, объекта со свойствами даты и времени или строки RFC 9557.



```javascript

Temporal.PlainDateTime.from(info)
Temporal.PlainDateTime.from(info, options)
```



Здесь параметр `info` представляет либо экземпляр `PlainDateTime`, на основе которого создается новый объект, либо строку в формате RFC 9557 с датой (дополнительно, но необязательно может содержать время и календарь), либо это объект с такими свойствами-компонентами дат и времени.



Второй и необязательный параметр `options` представляет объект со свойством `overflow`. Это свойство определяет поведение компонента даты в параметре `info`, которая выходит за пределы допустимого диапазона. Это свойство может принимать два значения: "constrain" (компонент даты ограничивается допустимым диапазоном, значение по умолчанию) и "reject" (генерируется исключение RangeError).



Рассмотрим несколько примеров. Создание на основе другого `PlainDateTime`:



```javascript

const dateTime = Temporal.PlainDateTime.from(new Temporal.PlainDateTime(2026, 3, 17));
console.log(dateTime.toString()); // 2026-03-17T00:00:00
```



Этот способ может быть полезен, когда необходимо создать на объект на основе уже существующего с изменением некоторых отдельных компонентов.



При создании на основе произвольного объекта, в метод передается обычный объект JS, у которого названия свойств в целом соответствуют названиям параметров конструктора (`calendar, era, eraYear, year, month, monthCode, day, hour, minute, second, millisecond, microsecond, nanosecond`). Из этих параметров обызательно можно указать только три: год (свойство year или era с eraYear), месяц (month или monthCode) и день (day):



```javascript

const dt = Temporal.PlainDateTime.from({
  year: 2026,
  month: 3,
  day: 17,
  hour: 7,
  minute: 40
});
console.log(dt.toString()); // 2026-03-17T07:40:00
```



Третий способ - передача строки в формате RFC 9557 - `YYYY-MM-DD T HH:mm:ss.sssssssss [u-ca=calendar_id]`, где обязательными являются только три первых компонента (YYYY год, MM - месяц, DD - день):



```javascript

const dt = Temporal.PlainDateTime.from("2026-03-06T07:40:56");
console.log(dt.toString()); // 2026-03-06T07:40:56
```



### Свойства и получение компонентов даты



Для хранения различных компонентов даты и времени объект определяет ряд свойств:





- `calendarId` : строка, которая представляет календарь

- `day` : день месяца (обычно начинается с 1)

- `dayOfWeek` : день недели (начиная с 1). Дни недели нумеруются последовательно от 1 до daysInWeek и зависят от календаря. 1 обычно обозначает понедельник в календаре, даже если в локалях, использующих этот календарь, первым днем ​​недели может считаться другой день

- `dayOfYear` : номер дня в году, начиная с 1. Первый день этого года - 1, а последний день - daysInYear. Зависит от календаря.

- `daysInMonth` : количество дней в месяце

- `daysInWeek` : количество дней в неделе

- `daysInYear` : количество дней в году. Зависит от календаря. Для календаря ISO 8601 это 365, или 366 в високосном году.

- `era` : эра этой даты, или undefined, если календарь не использует эры (например, ISO 8601)

- `eraYear` : год в рамках эры, или undefined, если календарь не использует эры. Индекс года обычно начинается с 1 (более распространенный) или 0, а годы в эре могут уменьшаться со временем (например, григорианский до н.э.)

- `hour` : час (целое число от 0 до 23)

- `inLeapYear` : логическое значение, которое указывает, находится ли эта дата в високосном году

- `microsecond` : микросекунды даты (число от 0 до 999)

- `millisecond` : миллисекунды даты (число от 0 до 999)

- `minute` : минуты (число от 0 до 59)

- `month` : индекс месяца в году. Первый месяц этого года равен 1, а последний месяц - monthsInYear

- `monthCode` : строка, которая представляет месяц этой даты. Зависит от календаря. Обычно это M плюс двузначный номер месяца

- `monthsInYear` : количество месяцев в году этой даты. Зависит от календаря. Для календаря ISO 8601 это всегда 12, но в других календарных системах это может отличаться.

- `nanosecond` : наносекунды даты (число от 0 до 999)

- `second` : секунды даты (число от 0 до 59)

- `weekOfYear` : Виндекс недели (начиная с 1) в yearOfWeek для этой даты, или undefined, если календарь не имеет четко определенной системы недель. Первая неделя года равна 1. Зависит от календаря

- `year` : количество лет этой даты

- `yearOfWeek` : год, который будет сопоставлен с weekOfYear этой даты, или undefined, если календарь не имеет четко определенной системы недель



Например, получим некоторые компоненты текущей даты:



```javascript

const dateTime = Temporal.Now.plainDateTimeISO();
console.log(dateTime.toString());   // 2026-03-16T22:25:28.634090088
console.log(dateTime.day);          // 16
console.log(dateTime.month);        // 3
console.log(dateTime.year);         // 2026
console.log(dateTime.hour);         // 22
console.log(dateTime.minute);       // 25
```



### Управление датами и временем



Для управления датами и временем объект `PlainDateTime` определяет ряд методов:





- `equals()` : возвращает true, если эта дата и время эквивалентны по значению другой дате и времени (с учетом календарей), и false в противном случае.

- `compare(dateTime1, dateTime2)` (статический метод): возвращает возвращает -1, если dateTime1 предшествует dateTime2, 0, если они совпадают, и 1, если dateTime1 следует за dateTime2. Сравнение производится по исходным значениям даты и времени, без учета календарей.


- `add()` : сдвигает дату/время вперед на заданную длительность (прибавляет) и результат возвращает в виде нового объекта `PlainDateTime`

- `subtract()` : сдвигает дату/время на заданную длительность назад (вычитает) и результат возвращает в виде нового объекта `PlainDateTime`


- `since()` : возвращает новый объект `Temporal.Duration` , который представляет продолжительность от другой даты до текущей. Продолжительность положительна, если другая дата и время предшествует текущей, и отрицательна, если идет после.

- `until()` : возвращает новый объект `Temporal.Duration` , который представляет продолжительность от текущей даты до другой. Продолжительность положительна, если другая дата позже текущей, и отрицательна, если идет раньше.


- `round()` : возвращает объект `PlainDateTime` , представляющий эту дату и время, округленную до заданной единицы.


- `with()` : возвращает объект `PlainDateTime` , в котором некоторые поля текущего объекта заменены новыми значениями.

- `withCalendar()` : возвращает объект `PlainDateTime` , в котором применяется новая календарная система

- `withPlainTime()` : возвращает объект `PlainDateTime` , в котором часть времени текущего объекта полностью заменена новым временем

- `toLocaleString()` : возвращает строку с представлением даты и времени с учетом языка.

- `toPlainDate()` : возвращает новый объект Temporal.PlainDate, представляющий часть даты (год, месяц, день) этой даты и времени в той же календарной системе.

- `toPlainTime()` : возвращает новый объект Temporal.PlainTime, представляющий часть времени (час, минута, секунда и доля секунды).

- `toZonedDateTime()` : возвращает новый экземпляр Temporal.ZonedDateTime, представляющий ту же дату и время, но в указанной временной зоне.



Рассмотрим базовые операции с датами и временем.



### Сравнение даты и времени



Метод `equals()` позволяет сравнить два объекта PlainDateTime на равенство: он возвращают `true`, если два объекта эквивалентны с учетом календарей, и `false` в противном случае:



```javascript

const dt1 = new Temporal.PlainDateTime(2026, 3, 16, 0, 0, 0, 0, 0, 0);
const dt2 = new Temporal.PlainDateTime(2026, 3, 16, 0, 0, 0, 0, 0, 0);
const dt3 = new Temporal.PlainDateTime(2026, 3, 16, 0, 0, 0, 0, 0, 0, "persian");

console.log(dt1.equals(dt2));       // true
console.log(dt1.equals(dt3));       // false - календари разные
```



Статический метод `compare()` позволяет определить, предшествует ли одна дата другой или наоборот - следует за ней. Он возвращает возвращает -1, если первая дата предшествует второй, и 1, если первая дата следует за второй. При равестве двух дат возвращается 0, при этом в отличие от `equals()` календари не учитываются:



```javascript

const dt1 = new Temporal.PlainDateTime(2026, 3, 16);
const dt2 = new Temporal.PlainDateTime(2026, 3, 16, 0, 0, 0, 0, 0, 0, "persian");

const dt3 = new Temporal.PlainDateTime(2026, 3, 17);
const dt4 = new Temporal.PlainDateTime(2026, 3, 15);

console.log(Temporal.PlainDateTime.compare(dt1, dt2));  // 0  - даты равны
console.log(Temporal.PlainDateTime.compare(dt1, dt3));  // -1 - дата dt1 идет перед dt3
console.log(Temporal.PlainDateTime.compare(dt1, dt4));  // 1  - дата dt1 идет после dt4
```



### Сдвиг дат/времени



Методы `add()` и `subtract()` сдвигают дату/время соответственно вперед и назад. В качестве параметра они принимают объект **Temporal.Duration** или объект со свойствами `years, months, weeks, days, hours, minutes, seconds, milliseconds, microseconds, nanoseconds`, которые представляют продолжительность для добавления или вычитания из текущей даты:



```javascript

// исходный объект
const dateTime = new Temporal.PlainDateTime(2026, 3, 16);

const tomorrow = dateTime.add({days:1});    // добавляем один день
console.log(tomorrow.toString());           // 2026-03-17T00:00:00

const yesterday = dateTime.subtract({days:1});  // вычитаем один день
console.log(yesterday.toString());              // 2026-03-15T00:00:00
```



### Продолжительность между двумя датами



Метод `since()` позволяет узнать, сколько времени пройдет от другой даты до текущей, а метод `until()` - сколько пройдет времени от текущей даты до другой. Оба метода возвращают результат в виде объекта `Temporal.Duration`, который представляет продолжительность между двумя датами:



```javascript

const date1 = new Temporal.PlainDateTime(2026, 3, 15);
const date2 = new Temporal.PlainDateTime(2026, 3, 25);

const current = new Temporal.PlainDateTime(2026, 3, 18);

// сколько времени от даты date1 до current
const since_date1 = current.since(date1);
console.log(since_date1.toString());        // P3D - 3 дня

// сколько времени от даты current до date2
const until_date2 = current.until(date2);
console.log(until_date2.toString());        // P7D - 7 дней
```



### with



Метод `with()` позволяет определить новый объект `PlainDateTime` на основе текущего, у которого заменены отдельные поля. Это полезно, когда нам надо создать один объект на основе другого, заменив лишь пару свойств. В метод передается объект, свойства которого соответствуют свойствам `PlainDateTime`:



```javascript

const current = new Temporal.PlainDateTime(2026, 3, 18, 22, 5); // 

const new_date = current.with({day: 24, month:4});   // меняем день и месяц

console.log(current.toString());      // 2026-03-18T22:05:00
console.log(new_date.toString());     // 2026-04-24T22:05:00
```
