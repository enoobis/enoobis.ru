В прошлых статьях был реализован простой функционал для отправки запросов к модели в рамках Prompt API. Однако было бы неплохо, если запросы к модели могли отправляться в рамках некоторого контекста - истории предыдущего взаимодействия с моделью, как в стандартных ИИ чат-ботах.



Для того чтобы модель помнила контекст, сессию `LanguageModel` необходимо создавать один раз при загрузке страницы, а не пересоздавать при каждом новом запросе. Метод завершения сессии - `session.destroy()` в таком случае вызывается только при закрытии или перезагрузке страницы.



При использовании `promptStreaming()` в рамках одной сессии Chrome автоматически сохраняет историю диалога. Однако, чтобы пользователь тоже видел историю, нам нужно добавлять сообщения в виде чата, а не перезаписывать один общий блок. Например:



```xml

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="utf-8" />
    <title>enoobis.ru</title>
    <style>
        body { font-family: sans-serif; max-width: 600px; margin: 20px auto; padding: 0 10px; }
        textarea { width: 100%; height: 80px; margin-bottom: 10px; padding: 8px; box-sizing: border-box; }
        button { padding: 10px 20px; cursor: pointer; }
        
        /* Стили для окон чата */
        #chat-container { margin-top: 20px; max-height: 400px; overflow-y: auto; border: 1px solid #ddd; border-radius: 5px; padding: 10px; background: #fafafa; }
        .message { margin: 10px 0; padding: 10px; border-radius: 5px; white-space: pre-wrap; }
        .user-message { background: #e3f2fd; align-self: flex-end; margin-left: 20px; }
        .ai-message { background: #f5f5f5; margin-right: 20px; }
    </style>
</head>
<body>
<h2>Тест Prompt API (Чат с контекстом)</h2>
    
<textarea id="promptInput" placeholder="Введите ваш запрос к модели..."></textarea>
<button id="sendBtn" disabled>Инициализация ИИ...</button>

<h3>История диалога:</h3>
<div id="chat-container"></div>

<script>
// Получаем элементы интерфейса
const promptInput = document.getElementById("promptInput");
const sendBtn = document.getElementById("sendBtn");
const chatContainer = document.getElementById("chat-container");

// Глобальная переменная для хранения единой сессии
let chatSession = null;

// Функция для добавления блоков сообщений в HTML
function appendMessage(sender, text) {
        
    const messageDiv = document.createElement("div");
    messageDiv.classList.add("message");
    messageDiv.classList.add(sender === "user" ? "user-message" : "ai-message");
    messageDiv.textContent = text;
    chatContainer.appendChild(messageDiv);
    chatContainer.scrollTop = chatContainer.scrollHeight; // Скролл вниз
    return messageDiv; // Возвращаем элемент для последующего обновления текста
}

async function start(){
    
    // проверяем доступность Prompt API
    if (typeof LanguageModel === "undefined") {
        output.textContent = "Ошибка: Prompt API не поддерживается вашим браузером.";
        return;
    }

    // проверяем доступность модели для выбранных языков
    const availability = await LanguageModel.availability({ languages: ["en", "ru"] });
    if (availability === "unavailable") {
        output.textContent = "Ошибка: Модель для Prompt API не доступна.";
        return;
    }

    // Создаем ОДНУ постоянную сессию для сохранения контекста
    chatSession = await LanguageModel.create();
    sendBtn.textContent = "Отправить запрос";
    sendBtn.disabled = false; // кнопка доступна - можно отправлять запросы

    // Устанавливаем обработчик клика на кнопку
    sendBtn.addEventListener("click", async () => {

        const text = promptInput.value.trim(); // получаем введенный текст
        // если текста нет и сессия не создана, выход
        if (!text || !chatSession) return;

        // Отображаем сообщение пользователя в чате и очищаем поле ввода
        appendMessage("user", text);
        promptInput.value = "";
        sendBtn.disabled = true;    // на время получения ответа блокируем кнопку

        // Создаем пустой блок для будущего ответа ИИ
        const aiMessageElement = appendMessage("ai", "Думаю...");

        // Вызываем стриминг в рамках существующей сессии
        const stream = chatSession.promptStreaming(text);
            
        // Очищаем поле перед выводом
        aiMessageElement.textContent = ""; 

        // Читаем поток частями в реальном времени
        for await (const chunk of stream) {
            // добавляем текст ответа 
            aiMessageElement.textContent += chunk; 
        }

        // после получения ответа делаем кнопку доступной
        sendBtn.disabled = false;
    });

    // Уничтожаем сессию при закрытии или обновлении вкладки пользователем
    window.addEventListener("beforeunload", () => {
        if (chatSession) {
            chatSession.destroy();
        }
    });
}

start();
</script>
</body>
</html>
```



Для управления сессией она определена как глобальная переменная и теперь создается один раз при вызове функции `start()`.



Вместо перезаписи одного div, определена вспомогательная функция `appendMessage()`, которая создает новые элементы для отображения запроса пользователя и ответа модели и добавляет их в элемент chatContainer



Удаление сессии через session.destroy() из finally: В отличие от кода прошлой статьи сессия больше не уничтожается после каждого запроса, благодаря чему модель помнит предыдущие реплики. Очистка ресурсов происходит в обработчике события `beforeunload()`: метод `destroy()` теперь срабатывает только тогда, когда пользователь закрывает страницу или обновляет ее.



Таким образом, мы сможем общаться с моделью в рамках чата.

### Очистка контекста



Хотя пример выше хорошо работает, но что, если мы захотим в некоторый момент времени очистить историю чата и начать диалог с моделью заново, чтобы модель не помнила содержание предыдущих запросов? Добавим для этой цели в предыдущий пример кнопку очистки истории чата:



```xml

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="utf-8" />
    <title>enoobis.ru</title>
    <style>
        body { font-family: sans-serif; max-width: 600px; margin: 20px auto; padding: 0 10px; }
        textarea { width: 100%; height: 80px; margin-bottom: 10px; padding: 8px; box-sizing: border-box; }
        .controls { display: flex; gap: 10px; margin-bottom: 10px; }
        button { padding: 10px 20px; cursor: pointer; }

        #clearBtn { background-color: #f44336; color: white; border: none; border-radius: 4px; }
        #clearBtn:disabled { background-color: #e0e0e0; color: #a6a6a6; cursor: not-allowed; }
        #sendBtn { background-color: #4CAF50; color: white; border: none; border-radius: 4px; }
        #sendBtn:disabled { background-color: #e0e0e0; color: #a6a6a6; cursor: not-allowed; }
        
        /* Стили для окон чата */
        #chat-container { margin-top: 20px; max-height: 400px; overflow-y: auto; border: 1px solid #ddd; border-radius: 5px; padding: 10px; background: #fafafa; }
        .message { margin: 10px 0; padding: 10px; border-radius: 5px; white-space: pre-wrap; }
        .user-message { background: #e3f2fd; align-self: flex-end; margin-left: 20px; }
        .ai-message { background: #f5f5f5; margin-right: 20px; }
        .system-message { background: #fff3cd; color: #856404; align-self: center; text-align: center; font-size: 0.9em; width: 100%; box-sizing: border-box; }
    </style>
</head>
<body>
<h2>Тест Prompt API (Чат с контекстом)</h2>
    
<textarea id="promptInput" placeholder="Введите ваш запрос к модели..."></textarea>
    <div class="controls">
        <button id="sendBtn" disabled>Инициализация ИИ...</button>
        <button id="clearBtn" disabled>Очистить историю чата</button>
    </div>

<h3>История диалога:</h3>
<div id="chat-container"></div>

<script>
// Получаем элементы интерфейса
const promptInput = document.getElementById("promptInput");
const sendBtn = document.getElementById("sendBtn");
const clearBtn = document.getElementById("clearBtn");
const chatContainer = document.getElementById("chat-container");

// Глобальная переменная для хранения единой сессии
let chatSession = null;

// Функция инициализации или перезапуска сессии
async function initSession(isReset = false) {
    sendBtn.disabled = true;
    clearBtn.disabled = true;
        
    if (isReset) {
        sendBtn.textContent = "Перезапуск ИИ...";
    }

    // проверяем доступность Prompt API
    if (typeof LanguageModel === "undefined") {
        appendMessage("system", "Ошибка: Prompt API не поддерживается вашим браузером.");
        return;
    }

    // проверяем доступность модели для выбранных языков
    const availability = await LanguageModel.availability({ languages: ["en", "ru"] });
    if (availability === "unavailable") {
        appendMessage("system", "Ошибка: Модель для Prompt API не доступна.");
        return;
    }
    // Если старая сессия существует, уничтожаем ее
    if (chatSession) {
        chatSession.destroy();
        chatSession = null;
    }

    // Создаем новую чистую сессию
    chatSession = await LanguageModel.create();
            
    sendBtn.textContent = "Отправить запрос";
    sendBtn.disabled = false;
    clearBtn.disabled = false;

    if (isReset) {
        appendMessage("system", "История чата очищена");
    }
}


// Функция для добавления блоков сообщений в HTML
function appendMessage(sender, text) {
        
    const messageDiv = document.createElement("div");
    messageDiv.classList.add("message");

    // на основе отправителя добавляем класс
    if (sender === "system") {
        messageDiv.classList.add("system-message");
    } else {
        messageDiv.classList.add(sender === "user" ? "user-message" : "ai-message");
    }
    
    messageDiv.textContent = text;
    chatContainer.appendChild(messageDiv);
    chatContainer.scrollTop = chatContainer.scrollHeight; // Скролл вниз
    return messageDiv; // Возвращаем элемент для последующего обновления текста
}

async function start(){
    
    // Первоначальный запуск при загрузке страницы
    await initSession();

    // Устанавливаем обработчик клика на кнопку
    sendBtn.addEventListener("click", async () => {

        const text = promptInput.value.trim(); // получаем введенный текст
        // если текста нет и сессия не создана, выход
        if (!text || !chatSession) return;

        // Отображаем сообщение пользователя в чате и очищаем поле ввода
        appendMessage("user", text);
        promptInput.value = "";
        sendBtn.disabled = true;    // на время получения ответа блокируем кнопку
        clearBtn.disabled = true; // Блокируем очистку во время генерации ответа

        // Создаем пустой блок для будущего ответа ИИ
        const aiMessageElement = appendMessage("ai", "Думаю...");

        // Вызываем стриминг в рамках существующей сессии
        const stream = chatSession.promptStreaming(text);
            
        // Очищаем поле перед выводом
        aiMessageElement.textContent = ""; 

        // Читаем поток частями в реальном времени
        for await (const chunk of stream) {
            // добавляем текст ответа 
            aiMessageElement.textContent += chunk; 
        }

        // после получения ответа делаем кнопки доступными
        sendBtn.disabled = false;
        clearBtn.disabled = false;
    });

    // Обработчик клика для кнопки очистки истории
    clearBtn.addEventListener("click", async () => {
        // Визуально очищаем окно чата
        chatContainer.innerHTML = "";
        // Перезапускаем сессию ИИ
        await initSession(true);
    });

    // Уничтожаем сессию при закрытии или обновлении вкладки пользователем
    window.addEventListener("beforeunload", () => {
        if (chatSession) {
            chatSession.destroy();
        }
    });
}

start();
</script>
</body>
</html>
```



В данном случае мы добавили кнопку очистки истории чата (`clearBtn`), которая сбрасывает текущую сессию ИИ, блокирует интерфейс на время создания новой сессии и визуально очищает историю сообщений в окне чата.



В плане кода изменились следующие моменты:





- Логика создания сессии вынесена в отдельную асинхронную функцию - initSession(). Это позволяет вызывать ее повторно при клике на сброс.

- Безопасное пересоздание: перед созданием новой сессии скрипт проверяет наличие старой ( `if (chatSession)` ) и корректно освобождает память под нее через `destroy()` .

- Блокировка кнопок: во время сброса сессии и во время генерации ответа обе кнопки блокируются ( `disabled = true` ), чтобы избежать конфликтов и повторных запросов в один и тот же момент времени.

- Визуальные системные уведомления: добавлен новый класс стилей .system-message. При успешном сбросе в чате выводится желтое сервисное уведомление о том, что контекст очищен.



Таким образом, теперь в произвольный момент времени мы сможем нажать на кнопку сброса, очистить историю чата и начать диалог заново:
