Объект Temporal.PlainDate представляет календарную дату (дату без времени). По сути, это календарная дата в формате ISO 8601 с полями года, месяца и дня, а также связанной календарной системой.



### Определение PlainTime



Для определения объекта `PlainDateTime` можно выделить три основных способа:





- Конструкторы

- Статический метод `Temporal.Now.plainDateISO()` , который возвращает текущую дату и время

- Статический метод `Temporal.PlainDate.from()` , который создает объект PlainDateTime из другого объекта или строки



#### Конструкторы



Для создания `PlainDateTime` можно использовать две функции конструкторов



```javascript

new Temporal.PlainDate(year, month, day)
new Temporal.PlainDate(year, month, day, calendar)
```



Через параметры конструкторов устанавливаются одноименные свойства объекта:





- `year` : год

- `month` : месяц

- `day` : день месяца

- `calendar` (необязательный): cтрока, обозначающая используемый календарь (по умолчанию `"iso8601"` ). Но независимо от выбранного календаря значения года, месяца и дня должны соответствовать календарной системе ISO 8601. Для получения всех доступных календарей можно использовать выражение `Intl.supportedValuesOf("calendar")`



Пример определения объекта `PlainDate`:



```javascript

const date1 = new Temporal.PlainDate(2026, 3, 18);
console.log(date1.toString()); // 2026-03-18

const date2 = new Temporal.PlainDate(2026, 3, 18, "persian");
console.log(date2.toString()); // 2026-03-18[u-ca=persian]
```




#### Получение текущей даты



Для получения текущей даты в виде объекта `PlainDate` применяется статический метод `Temporal.Now.plainDateISO()`:



```javascript

const dateTime = Temporal.Now.plainDateISO();
console.log(dateTime.toString());           // 2026-03-18
console.log(dateTime.toLocaleString());     // 18/3/2026
```



#### Temporal.PlainDate.from()



Статический метод `Temporal.PlainDate.from()` создает новый объект `PlainDate` из другого объекта `PlainDate`, объекта со свойствами даты и времени или строки RFC 9557.



```javascript

Temporal.PlainDate.from(info)
Temporal.PlainDate.from(info, options)
```



Здесь параметр `info` представляет либо экземпляр `PlainDate`, на основе которого создается новый объект, либо строку в формате RFC 9557 с датой (дополнительно, но необязательно может содержать календарь), либо это объект с такими свойствами-компонентами дат и времени.



Второй и необязательный параметр `options` представляет объект со свойством `overflow`. Это свойство определяет поведение компонента даты в параметре `info`, которая выходит за пределы допустимого диапазона. Это свойство может принимать два значения: "constrain" (компонент даты ограничивается допустимым диапазоном, значение по умолчанию) и "reject" (генерируется исключение RangeError).



Рассмотрим несколько примеров. Создание на основе другого `PlainDate`:



```javascript

const date1 = Temporal.PlainDate.from(new Temporal.PlainDate(2026, 3, 18));
console.log(date1.toString()); // 2026-03-18
```



При создании на основе произвольного объекта, в метод передается обычный объект JS, у которого названия свойств в целом соответствуют названиям параметров конструктора (`calendar, era, eraYear, year, month, monthCode, day`). Из этих параметров обязательно можно указать только три: год (свойство year или era с eraYear), месяц (month или monthCode) и день (day):



```javascript

const date1 = Temporal.PlainDate.from({
  year: 2026,
  month: 3,
  day: 18
});
console.log(date1.toString()); // 2026-03-18
```



Третий способ - передача строки в формате RFC 9557 - `YYYY-MM-DD [u-ca=calendar_id]`, где обязательными являются три первых компонента (YYYY год, MM - месяц, DD - день):



```javascript

const date1 = Temporal.PlainDate.from("2026-03-20");
console.log(date1.toString()); // 2026-03-20
```




### Свойства и получение компонентов даты



Для хранения различных компонентов даты и времени объект `PlainDate` определяет ряд свойств:





- `calendarId` : строка, которая представляет календарь

- `day` : день месяца (обычно начинается с 1)

- `dayOfWeek` : день недели (начиная с 1). Дни недели нумеруются последовательно от 1 до daysInWeek и зависят от календаря. 1 обычно обозначает понедельник в календаре, даже если в локалях, использующих этот календарь, первым днем ​​недели может считаться другой день

- `dayOfYear` : номер дня в году, начиная с 1. Первый день этого года - 1, а последний день - daysInYear. Зависит от календаря.

- `daysInMonth` : количество дней в месяце

- `daysInWeek` : количество дней в неделе

- `daysInYear` : количество дней в году. Зависит от календаря. Для календаря ISO 8601 это 365, или 366 в високосном году.

- `era` : эра этой даты, или undefined, если календарь не использует эры (например, ISO 8601)

- `eraYear` : год в рамках эры, или undefined, если календарь не использует эры. Индекс года обычно начинается с 1 (более распространенный) или 0, а годы в эре могут уменьшаться со временем (например, григорианский до н.э.)

- `inLeapYear` : логическое значение, которое указывает, находится ли эта дата в високосном году

- `month` : индекс месяца в году. Первый месяц этого года равен 1, а последний месяц - monthsInYear

- `monthCode` : строка, которая представляет месяц этой даты. Зависит от календаря. Обычно это M плюс двузначный номер месяца

- `monthsInYear` : количество месяцев в году этой даты. Зависит от календаря. Для календаря ISO 8601 это всегда 12, но в других календарных системах это может отличаться.

- `weekOfYear` : Виндекс недели (начиная с 1) в yearOfWeek для этой даты, или undefined, если календарь не имеет четко определенной системы недель. Первая неделя года равна 1. Зависит от календаря

- `year` : количество лет этой даты

- `yearOfWeek` : год, который будет сопоставлен с weekOfYear этой даты, или undefined, если календарь не имеет четко определенной системы недель



Например, получим некоторые компоненты текущей даты:



```javascript

const today = Temporal.Now.plainDateISO();
console.log(today.toString());   // 2026-03-19
console.log(today.day);          // 19
console.log(today.month);        // 3
console.log(today.year);         // 2026
```



### Управление датами и временем



Для управления датами и временем объект `PlainDate` предоставляет ряд методов:





- `equals()` : возвращает true, если эта дата эквивалентна по значению другой дате (с учетом календарей), и false в противном случае.

- `compare(date1, date2)` (статический метод): возвращает возвращает -1, если date1 предшествует date2, 0, если они совпадают, и 1, если date1 следует за date2. Сравнение производится по исходным значениям даты без учета календарей.


- `add()` : сдвигает дату вперед на заданную длительность (прибавляет) и результат возвращает в виде нового объекта `PlainDate`

- `subtract()` : сдвигает дату на заданную длительность назад (вычитает) и результат возвращает в виде нового объекта `PlainDate`


- `since()` : возвращает новый объект `Temporal.Duration` , который представляет продолжительность от другой даты до текущей. Продолжительность положительна, если другая дата и время предшествует текущей, и отрицательна, если идет после.

- `until()` : возвращает новый объект `Temporal.Duration` , который представляет продолжительность от текущей даты до другой. Продолжительность положительна, если другая дата позже текущей, и отрицательна, если идет раньше.


- `with()` : возвращает объект `PlainDate` , в котором некоторые поля текущего объекта заменены новыми значениями.

- `withCalendar()` : возвращает объект `PlainDate` , в котором применяется новая календарная система

- `toLocaleString()` : возвращает строку с представлением даты и времени с учетом языка.

- `toPlainDateTime()` : возвращает объект `Temporal.PlainDateTime` , который представляет текущую дату

- `toPlainMonthDay()` : возвращает объект `Temporal.PlainMonthDay` , который представляет текущую дату (по сути исключает год, оставляя месяц и день)

- `toPlainYearMonth()` : возвращает объект `Temporal.PlainYearMonth` , который представляет текущую дату (по сути исключает день, оставляя год и месяц)

- `toZonedDateTime()` : возвращает новый экземпляр Temporal.ZonedDateTime, представляющий ту же дату и время, но в указанной временной зоне.



Рассмотрим основные операции с датами.



### Сравнение даты и времени



Метод `equals()` возвращает `true`, если два объекта эквивалентны с учетом календарей, и `false`, если объекты не эквивалентны:



```javascript

const date1 = new Temporal.PlainDate(2026, 3, 19);
const date2 = new Temporal.PlainDate(2026, 3, 19);
const date3 = new Temporal.PlainDate(2026, 3, 19, "persian");

console.log(date1.equals(date2));       // true
console.log(date1.equals(date3));       // false - календари разные
```



Статический метод `compare()` позволяет определить, предшествует ли одна дата другой или наоборот - следует за ней. Он возвращает возвращает -1, если первая дата предшествует второй, и 1, если первая дата следует за второй. При равестве двух дат возвращается 0, при этом в отличие от `equals()` календари не учитываются:



```javascript

const date1 = new Temporal.PlainDate(2026, 3, 19);
const date2 = new Temporal.PlainDate(2026, 3, 19, "persian");

const date3 = new Temporal.PlainDate(2026, 3, 20);
const date4 = new Temporal.PlainDate(2026, 3, 16);

console.log(Temporal.PlainDate.compare(date1, date2));  // 0  - даты равны
console.log(Temporal.PlainDate.compare(date1, date3));  // -1 - дата date1 идет перед date3
console.log(Temporal.PlainDate.compare(date1, date4));  // 1  - дата date1 идет после date4
```



#### Арифметика с датами



Методы `add()` и `subtract()` позволяют прибавить к дате некоторую продолжительность в виде объекта **Temporal.Duration** или JS-объектF со свойствами `years, months, weeks, days, hours`, которые задают продолжительность:



```javascript

// исходный объект
const dateTime = new Temporal.PlainDate(2026, 3, 19);

const tomorrow = dateTime.add({days:1});    // добавляем один день
console.log(tomorrow.toString());           // 2026-03-20

const yesterday = dateTime.subtract({days:2});  // вычитаем 2 дня
console.log(yesterday.toString());              // 2026-03-18
```



### Продолжительность между двумя датами



Метод `since()` позволяет узнать, сколько времени пройдет от другой даты до текущей, а метод `until()` - сколько пройдет времени от текущей даты до другой. Оба метода возвращают результат в виде объекта `Temporal.Duration`, который представляет продолжительность между двумя датами:



```javascript

const date1 = new Temporal.PlainDate(2026, 3, 15);
const date2 = new Temporal.PlainDate(2026, 3, 25);

const current = new Temporal.PlainDate(2026, 3, 18);

// сколько времени от даты date1 до current
const since_date1 = current.since(date1);
console.log(since_date1.toString());        // P3D - 3 дня

// сколько времени от даты current до date2
const until_date2 = current.until(date2);
console.log(until_date2.toString());        // P7D - 7 дней
```



### with



Метод `with()` позволяет определить новый объект `PlainDate` на основе текущего, у которого изменены отдельные поля. Это может быть полезно, когда нам надо создать один объект на основе другого с заменой лишь некоторых свойств. В метод передается объект, свойства которого соответствуют свойствам `PlainDate`:



```javascript

const today = new Temporal.PlainDate(2026, 3, 19); // 

const new_date = today.with({day: 25, month:4});   // меняем день и месяц

console.log(today.toString());          // 2026-03-19
console.log(new_date.toString());       // 2026-04-25
```
