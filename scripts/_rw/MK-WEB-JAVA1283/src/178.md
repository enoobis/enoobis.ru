Для представления времени в Temporal API предназначен тип Temporal.PlainTime , который представляет время без даты, например, повторяющееся событие, происходящее в одно и то же время каждый день. По сути, он представляет комбинацию часов, минут, секунд, миллисекунд, микросекунд и наносекунд.



### Определение PlainTime



Для создания/получения объекта `PlainTime` можно использовать три способа:





- Функции-конструкторы

- Статический метод `Temporal.Now.PlainTimeISO()` , который возвращает текущее время

- Статический метод `Temporal.PlainTime.from()` , который создает объект `PlainTime` из другого объекта или строки



#### Конструкторы



Для типа `PlainTime` определен ряд функций-конструкторов



```javascript

new Temporal.PlainTime()
new Temporal.PlainTime(hour)
new Temporal.PlainTime(hour, minute)
new Temporal.PlainTime(hour, minute, second)
new Temporal.PlainTime(hour, minute, second, millisecond)
new Temporal.PlainTime(hour, minute, second, millisecond, microsecond)
new Temporal.PlainTime(hour, minute, second, millisecond, microsecond, nanosecond)
```



Параметры конструкторов:





- `hour` : час

- `minute` : минуты

- `second` : секунды

- `millisecond` : миллисекунды.

- `microsecond` : микросекунды

- `nanosecond` : наносекунды



Пример определения объекта `PlainTime`:



```javascript

const time1 = new Temporal.PlainTime(22, 5);
console.log(time1.toString()); // 22:05:00

const time2 = new Temporal.PlainTime(22, 7, 40);
console.log(time2.toString()); // 22:07:40
```



#### Получение текущего времени



Для получения текущего времени в виде объекта `PlainTime` применяется статический метод `Temporal.Now.plainTimeISO()`:



```javascript

const now = Temporal.Now.plainTimeISO();
console.log(now.toString());   // 15:43:40.45698999
```



#### Temporal.PlainTime.from()



Статический метод `Temporal.PlainTime.from()` создает новый объект `PlainTime` из другого объекта `PlainTime`, объекта со свойствами времени или строки RFC 9557.



```javascript

Temporal.PlainTime.from(info)
Temporal.PlainTime.from(info, options)
```



Здесь параметр `info` представляет либо экземпляр `PlainTime`, на основе которого создается новый объект, либо строку в формате RFC 9557 с временем, либо это объект с такими свойствами-компонентами времени.



Второй и необязательный параметр `options` представляет объект со свойством `overflow`. Это свойство определяет поведение компонента времени в параметре `info`, которая выходит за пределы допустимого диапазона. Это свойство может принимать два значения: "constrain" (компонент времени ограничивается допустимым диапазоном, значение по умолчанию) и "reject" (генерируется исключение RangeError).



Рассмотрим различные сценарии. Создание на основе другого `PlainTime`:



```javascript

const someTime = Temporal.PlainTime.from(new Temporal.PlainTime(22, 5));
console.log(someTime.toString()); // 22:05:00
```



При создании на основе произвольного объекта, в метод передается обычный javascript-объект, у которого названия свойств в целом соответствуют названиям параметров конструктора (`hour, minute, second, millisecond, microsecond, nanosecond`):



```javascript

const time = Temporal.PlainTime.from({
  hour: 5,
  minute: 22
});
console.log(time.toString()); // 05:22:00
```



Третий способ - передача строки в формате RFC 9557 - `HH:mm:ss.sssssssss`, где определяются три компонента:





- `HH` : час - двузначное число от 00 до 23

- `mm` (необязательно): минуты - двузначное число от 00 до 59. По умолчанию - 00.

- `ss.sssssssss` (необязательно): секунды - двузначное число от 00 до 59. Может дополнительно сопровождаться точкой или запятой и одной-девятью цифрами. По умолчанию - 00. Компоненты HH, mm и ss могут быть разделены двоеточием или пустым символом. Можно опустить только ss или оба символа — ss и mm, поэтому время может быть в одном из трех форматов: `HH, HH:mm` или `HH:mm:ss.sssssssss`



Пример определения времени по строке:



```javascript

const time = Temporal.PlainTime.from("00:40:56");
console.log(time.toString());   // 00:40:56
```



### Свойства и получение компонентов времени



Для хранения различных компонентов времени объект `PlainTime` определяет ряд свойств:





- `hour` : час (целое число от 0 до 23)

- `microsecond` : микросекунды даты (число от 0 до 999)

- `millisecond` : миллисекунды даты (число от 0 до 999)

- `minute` : минуты (число от 0 до 59)

- `nanosecond` : наносекунды даты (число от 0 до 999)

- `second` : секунды даты (число от 0 до 59)



Например, получим все компоненты текущего времени:



```javascript

const now = Temporal.Now.plainTimeISO();
console.log(now.toString());    // 16:19:44.564225098
console.log(now.hour);          // 16
console.log(now.minute);        // 19
console.log(now.second);        // 44
console.log(now.millisecond);   // 564
console.log(now.microsecond);   // 225
console.log(now.nanosecond);    // 98
```



### Управление временем



Для управления временем объект `PlainTime` предоставляет ряд методов:





- `equals()` : возвращает true, если текущий объект времени эквивалентен по значению другому объекту, и false в противном случае.

- `compare(time1, time2)` (статический метод): возвращает возвращает -1, если time1 предшествует time2, 0, если они совпадают, и 1, если time1 следует за time2.


- `add()` : добавляет к времени заданную длительность и результат возвращает в виде нового объекта `PlainTime`

- `subtract()` : вычитает из времени заданную длительность и результат возвращает в виде нового объекта `PlainTime`


- `since()` : возвращает объект `Temporal.Duration` , который представляет продолжительность от другой временной точкой до текущей. Продолжительность положительна, если вторая временная точка предшествует текущей, и отрицательна, если идет после.

- `until()` : возвращает объект `Temporal.Duration` , который представляет продолжительность от временной точки до другой. Продолжительность положительна, если вторая временная точка позже текущей, и отрицательна, если идет раньше.


- `round()` : возвращает объект `PlainTime` , представляющий текущее значение времени, округленное до заданной единицы.


- `with()` : возвращает объект `PlainTime` , в котором некоторые поля текущего объекта заменены новыми значениями.


- `toLocaleString()` : возвращает строку с представлением времени с учетом языка.



Рассмотрим базовые операции со временем.



### Сравнение временных точек



Для сравнения двух временных точек на равенство можно применять метод `equals()`, который возвращает `true`, если два объекта `PlainTime` эквивалентны, и `false`, если не эквивалентны:



```javascript

const time1 = new Temporal.PlainTime(10, 5);
const time2 = new Temporal.PlainTime(10, 5, 0);
const time3 = new Temporal.PlainTime(10, 5, 0, 0, 1);

console.log(time1.equals(time2));       // true
console.log(time1.equals(time3));       // false
```



Статический метод `compare()` позволяет определить, предшествует ли одна временная точка другой или наоборот - следует за ней. Он возвращает возвращает -1, если первая дата предшествует второй, и 1, если первая временная точка следует за второй. При равенстве двух временных точек возвращается 0:



```javascript

const time1 = new Temporal.PlainTime(11, 25);
const time2 = new Temporal.PlainTime(11, 25, 0, 0, 0);

const time3 = new Temporal.PlainTime(11, 35);
const time4 = new Temporal.PlainTime(11, 15);

console.log(Temporal.PlainTime.compare(time1, time2));  // 0  - значения времени равны
console.log(Temporal.PlainTime.compare(time1, time3));  // -1 - time1 идет перед time3
console.log(Temporal.PlainTime.compare(time1, time4));  // 1  - time1 идет после time4
```



### Арифметические операции со временем



Метод `add()` прибавляет к значениям времени некоторую продолжительность, а метод `subtract()`, наоборот, вычитает некоторое время. В качестве параметра методы принимают объект **Temporal.Duration** или объект со свойствами `hours, minutes, seconds, milliseconds, microseconds, nanoseconds`, которые представляют продолжительность для добавления или вычитания:



```javascript

// исходный объект
const current = new Temporal.PlainTime(10, 30);

const later= current.add({hours:1});    // добавляем один час
console.log(later.toString());          // 11:30:00

const earlier = current.subtract({hours:2, minutes: 10});  // вычитаем 2 часа и 10 минут
console.log(earlier.toString());              // 08:20:00
```



### Продолжительность между двумя датами



Метод `since()` позволяет узнать, сколько времени пройдет от второй временной точки до текущей, а метод `until()` - сколько пройдет времени от текущей временной точки до второй. Оба метода возвращают результат в виде объекта `Temporal.Duration`, который представляет продолжительность между двумя временными точками:



```javascript

const current = new Temporal.PlainTime(10, 30);

const time1 = new Temporal.PlainTime(10, 10);
const time2 = new Temporal.PlainTime(12, 10);

// сколько времени от даты time1 до current
const since_time1 = current.since(time1);
console.log(since_time1.toString());        // PT20M - 20 минут

// сколько времени от даты current до time2
const until_time2 = current.until(time2);
console.log(until_time2.toString());        // PT1H40M - 1 час 40 минут
```



### with



Метод `with()` позволяет определить новый объект `PlainTime` на основе текущего, у которого заменены отдельные поля. Это полезно, когда нам надо создать один объект на основе другого, заменив лишь пару свойств. В метод передается объект, свойства которого соответствуют свойствам `PlainTime`:



```javascript

const current_time = new Temporal.PlainTime(22, 12, 45); // 22:12:45

const new_time = current_time.with({minute: 14});   // меняем минуты

console.log(current_time.toString());       // 22:12:45
console.log(new_time.toString());           // 22:14:45
```




### Округление



Метод `round()` позволяет округлить время до определенной единицы измерения и возвращает результат округления в виде нового объекта `Temporal.PlainTime`. Распространенная версия метода принимает строку, которая указыванет на минимальный тип единиц измерения (smallestUnit), до которой надо произвести откругление. Это может быть одна из следующих строк - "hour", "minute", "second", "millisecond", "microsecond", "nanosecond" или их аналоги во множественном числе (с прибавлением окончания "s"). Пример округления:



```javascript

const time = Temporal.PlainTime.from({hour: 3, minute: 58, second: 45});
// округление до часов
const hours = time.round("hours");
console.log(hours.toString());             // 04:00:00

// округление до минут
const minutes = time.round("minutes");
console.log(minutes.toString());           // 03:59:00

// округление до секунд
const seconds = time.round("seconds");
console.log(seconds.toString());           // 03:58:45
```
