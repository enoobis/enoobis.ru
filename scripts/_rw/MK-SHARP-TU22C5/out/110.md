значительная часть прикладных задач сводится к обработке текста: разбор веб-страниц, поиск по тексту, извлечение полей для аналитики. в языке c# текстовые значения имеют тип **string**. вся функциональность этого типа сосредоточена в классе **System.String**. слово `string` является псевдонимом System.String, это один и тот же тип. объект хранит текст как последовательность символов unicode в кодировке utf-16. единица хранения совпадает с `char` и занимает два байта. свойство Length считает кодовые единицы utf-16. одна графема может занимать несколько таких единиц: символ вне базовой многоязычной плоскости записывается суррогатной парой и увеличивает Length на два. максимальный размер объекта String в памяти составляет около 2 гб, что соответствует примерно одному миллиарду символов. предел вытекает из ограничения размера объекта в среде .net, заголовок объекта эту оценку ещё немного уменьшает.

строка неизменяема. любой метод, который по смыслу правит текст, возвращает новый объект, прежний буфер остаётся прежним. поэтому индексатор строки доступен только для чтения.

### создание строк

строка создаётся либо присваиванием литерала переменной типа string, либо одним из конструкторов класса String:

```c#


string s1 = "hello";

string s2 = new String('a', 6); // результатом будет строка "aaaaaa"

string s3 = new String(new char[] { 'w', 'o', 'r', 'l', 'd' });

string s4 = new String(new char[] { 'w', 'o', 'r', 'l', 'd' }, 1, 3); // orl



Console.WriteLine(s1);  // hello

Console.WriteLine(s2);  // aaaaaaa

Console.WriteLine(s3);  // world

Console.WriteLine(s4);  // orl
```

у конструктора String несколько версий. вызов

```c#
new String('a', 6)
```

повторяет символ из первого параметра указанное число раз и создаёт строку "aaaaaa" из шести символов.

другой конструктор принимает массив символов и собирает из него строку:

```c#
string s3 = new String(new char[] { 'w', 'o', 'r', 'l', 'd' });
```

третья использованная версия берёт из массива только участок. второй параметр задаёт начальный индекс, третий задаёт число символов:

```c#
string s4 = new String(new char[] { 'w', 'o', 'r', 'l', 'd' }, 1, 3); // orl
```

из массива `{'w', 'o', 'r', 'l', 'd'}` берутся три символа, начиная с индекса 1, и получается строка "orl". литерал и результат конструктора с тем же содержимым равны по значению. одинаковые литералы среда обычно помещает в пул интернирования, так что у них может совпасть и ссылка. конструктор каждый раз выделяет новый объект и в пул его сам не кладёт.

### строка как набор символов

для доступа к отдельным кодовым единицам у строки есть индексатор:

```c#


public char this[int index] {get;}
```

аксессор только для чтения: присваивание символа по индексу противоречило бы неизменяемости и не компилируется. через индексатор строка читается как массив символов:

```c#


string message = "hello";

// получаем символ

char firstChar = message[1]; // символ 'e'

Console.WriteLine(firstChar);   //e



Console.WriteLine(message.Length);  // длина строки
```

у строки "hello" индекс 1 содержит символ 'e'. индекс 0 содержал бы 'h'. свойство **Length** возвращает длину в кодовых единицах, для этого литерала она равна 5. индекс вне диапазона `[0, Length)` приводит к `IndexOutOfRangeException`.

### перебор строк

класс String реализует `IEnumerable<char>`, поэтому строка перебирается циклом foreach как последовательность значений char. тот же обход записывается циклом for через индексатор:

```c#


string message = "hello";



for(var i =0; i < message.Length; i++)

{

    Console.WriteLine(message[i]);

}

foreach(var ch in message)

{

    Console.WriteLine(ch);

}
```

оба цикла печатают символы по одному, от начала строки к концу. порядок обхода совпадает с порядком кодовых единиц в буфере.

### сравнение строк

оператор `==` для типа string сравнивает последовательности символов:

```c#


string message1 = "hello";

string message2 = "hello";



Console.WriteLine(message1 == message2);    // true
```

для двух литералов "hello" результат true. оператор перегружен и смотрит на содержимое буферов, посимвольно и без учёта культуры. ссылочное равенство задаётся отдельно, через `Object.ReferenceEquals`: у интернированных литералов ссылки часто совпадают, у строк, собранных конструктором или конкатенацией, при том же тексте ссылки различаются. культурно-зависимое упорядочивание выполняет не оператор `==`, а методы `Compare` и `CompareOrdinal`, они разобраны среди операций над строками.

### многострочные строки

начиная с c# 11 литерал, открытый и закрытый не менее чем тремя символами `"`, задаёт многострочный текст. внутри него кавычки и переводы строк пишутся как есть, без экранирования. литерал сочетается с интерполяцией:

```c#


Print();

PrintValue("hello");



void Print()

{

    string text = """

              <element attr="content">

                <body>

                </body>

              </element>

              """;

    Console.WriteLine(text);

}



void PrintValue(string val)

{

    string text = $"""

              <element attr="content">

                <body>

                {val}

                </body>

              </element>

              """;

    //// или так 

    //string text =  $$"""

    //          <element attr="content">

    //            <body>

    //            {{val}}

    //            </body>

    //          </element>

    //          """;

    Console.WriteLine(text);

}
```

содержимое такого литерала может занимать несколько строк. общий ведущий отступ снимается по позиции закрывающих кавычек, относительные отступы внутри текста сохраняются. один знак `$` перед кавычками включает интерполяцию: `{val}` подставляет значение, а удвоенная скобка обозначает буквальную скобку. форма с `$$`, показанная в комментарии, сдвигает границу интерполяции: подстановка записывается как `{{val}}`, а одиночные скобки остаются символами текста. так записывают разметку, в которой скобки встречаются часто. пример как раз собирает фрагмент с тегами и подставляет аргумент `val` внутрь элемента body.

### основные методы строк

основная функциональность класса String раскрывается методами. среди них выделяются следующие:

- `Compare`: сравнивает две строки с учётом текущей культуры, то есть локали пользователя

- `CompareOrdinal`: сравнивает две строки по кодовым единицам, без учёта локали

- `Contains`: определяет, содержится ли подстрока в строке

- `Concat`: соединяет строки

- `CopyTo`: копирует часть строки, начиная с определённого индекса, в массив символов

- `EndsWith`: определяет, совпадает ли конец строки с подстрокой

- `Format`: форматирует строку по шаблону с нумерованными подстановками

- `IndexOf`: находит индекс первого вхождения символа или подстроки

- `Insert`: вставляет в строку подстроку и возвращает новую строку

- `Join`: соединяет элементы массива строк через разделитель

- `LastIndexOf`: находит индекс последнего вхождения символа или подстроки

- `Replace`: замещает в строке символ или подстроку другим символом или подстрокой

- `Split`: разделяет строку на массив строк

- `Substring`: извлекает из строки подстроку, начиная с указанной позиции

- `ToLower`: переводит символы строки в нижний регистр

- `ToUpper`: переводит символы строки в верхний регистр

- `Trim`: удаляет начальные и конечные пробельные символы

каждый из этих методов, кроме тех, что только читают буфер и возвращают число или логическое значение, порождает новый объект string либо заполняет переданный массив. исходная строка при этом не меняется. работа методов продолжается в следующих разделах.
