как и во многих языках программирования, в c# есть своя система типов данных, которая используется для создания переменных. тип данных определяет внутреннее представление данных, множество значений, которое может принимать объект, а также допустимые действия, которые можно применять к объекту. проверка того, что операция допустима для типа, в c# выполняется во время компиляции, за исключением явных операций приведения и позднего связывания.

в языке c# есть следующие базовые типы данных:

- bool : хранит значение `true` или `false` (логические литералы). представлен системным типом `System.Boolean`

```c#


bool alive = true;

bool isDead = false;
```

- byte : хранит целое число от `0` до `255` и занимает 1 байт. представлен системным типом `System.Byte`

```c#


byte bit1 = 1;

byte bit2 = 102;
```

- sbyte : хранит целое число от `-128` до `127` и занимает 1 байт. представлен системным типом `System.SByte`

```c#


sbyte bit1 = -101;

sbyte bit2 = 102;
```

- short : хранит целое число от `-32768` до `32767` и занимает 2 байта. представлен системным типом `System.Int16`

```c#


short n1 = 1;

short n2 = 102;
```

- ushort : хранит целое число от `0` до `65535` и занимает 2 байта. представлен системным типом `System.UInt16`

```c#


ushort n1 = 1;

ushort n2 = 102;
```

- int : хранит целое число от `-2147483648` до `2147483647` и занимает 4 байта. представлен системным типом `System.Int32`. все целочисленные литералы по умолчанию представляют значения типа int:

```c#


int a = 10;

int b = 0b101;  // бинарная форма b =5

int c = 0xFF;   // шестнадцатеричная форма c = 255
```

- uint : хранит целое число от `0` до `4294967295` и занимает 4 байта. представлен системным типом `System.UInt32`

```c#


uint a = 10;

uint b = 0b101;

uint c = 0xFF;
```

- long : хранит целое число от `-9 223 372 036 854 775 808` до `9 223 372 036 854 775 807` и занимает 8 байт. представлен системным типом `System.Int64`

```c#


long a = -10;

long b = 0b101;

long c = 0xFF;
```

- ulong : хранит целое число от `0` до `18 446 744 073 709 551 615` и занимает 8 байт. представлен системным типом `System.UInt64`

```c#


ulong a = 10;

ulong b = 0b101;

ulong c = 0xFF;
```

- float : хранит число с плавающей точкой от `-3.4*10^38` до `3.4*10^38` и занимает 4 байта. представлен системным типом `System.Single`

- double : хранит число с плавающей точкой от `±5.0*10^-324` до `±1.7*10^308` и занимает 8 байт. представлен системным типом `System.Double`

- decimal : хранит десятичное дробное число. если употребляется без десятичной запятой, имеет значение от `±1.0*10^-28` до `±7.9228*10^28`, может хранить 28 знаков после запятой и занимает 16 байт. представлен системным типом `System.Decimal`

- char : хранит одиночный символ в кодировке unicode и занимает 2 байта. представлен системным типом `System.Char`. этому типу соответствуют символьные литералы:

```c#


char a = 'A';

char b = '\x5A';

char c = '\u0420';
```

- string : хранит набор символов unicode. представлен системным типом `System.String`. этому типу соответствуют строковые литералы.

```c#


string hello = "Hello";

string word = "world";
```

- object : может хранить значение любого типа данных и занимает 4 байта на 32-разрядной платформе и 8 байт на 64-разрядной платформе. представлен системным типом `System.Object`, который является базовым для всех других типов и классов .net.

```c#


object a = 22;

object b = 3.14;

object c = "hello code";
```

имена вроде `int` и `bool` являются псевдонимами структур из пространства `System`. целочисленные типы и `char`, `float`, `double`, `decimal`, `bool` относятся к значимым типам: значение хранится непосредственно, а указанные размеры суть размеры этого значения. границы знаковых целых совпадают с диапазоном дополнительного кода соответствующей разрядности. `string` является ссылочным типом: переменная хранит ссылку на неизменяемый объект строки. размер, указанный для `object`, является размером ссылки, равным размеру указателя на данной платформе. само значение, помещённое в переменную типа `object`, при необходимости упаковывается в отдельный объект кучи.

например, определяются несколько переменных разных типов, и их значения выводятся на консоль:

```c#


string name = "Tom";

int age = 33;

bool isEmployed = false;

double weight = 78.65;



Console.WriteLine($"Имя: {name}");

Console.WriteLine($"Возраст: {age}");

Console.WriteLine($"Вес: {weight}");

Console.WriteLine($"Работает: {isEmployed}");
```

для вывода данных на консоль здесь применяется интерполяция: перед строкой ставится знак $, и после этого в строку в фигурных скобках вводятся значения переменных. консольный вывод программы:

```bash


Имя: Tom

Возраст: 33

Вес: 78,65

Работает: False
```

культура вывода может заменить точку в вещественном литерале на запятую: значение `78.65` в исходном тексте и `78,65` в консоли относятся к одному числу `double`, а различается только десятичный разделитель.

### использование суффиксов

при присвоении значений учитывается следующая особенность: все вещественные литералы (дробные числа) рассматриваются как значения типа **double**. чтобы указать, что дробное число представляет тип **float** или тип **decimal**, к литералу добавляется суффикс: `F`/`f` для float и `M`/`m` для decimal.

```c#


float a = 3.14F;

float b = 30.6f;



decimal c = 1005.8M;

decimal d = 334.8m;
```

без суффикса литерал `3.14` имеет тип `double`, и присваивание его в `float` без приведения не проходит проверку типов: преобразование из `double` в `float` может потерять точность и не является неявным.

подобным образом все целочисленные литералы рассматриваются как значения типа **int**. чтобы явным образом указать, что целочисленный литерал представляет значение типа uint, используется суффикс **U/u**, для типа **long** суффикс **L/l**, а для типа **ulong** суффикс **UL/ul**:

```c#


uint a = 10U;

long b = 20L;

ulong c = 30UL;
```

суффикс меняет тип литерала ещё до проверки присваивания. для `ulong` годятся сочетания `UL`, `Ul`, `uL`, `ul`, `LU` и остальные комбинации регистра. регистр суффикса на значение не влияет.

### использование системных типов

выше при перечислении всех базовых типов данных для каждого упоминался системный тип. название встроенного типа по сути представляет собой сокращённое обозначение системного типа. например, следующие переменные эквивалентны по типу:

```c#


int a = 4;

System.Int32 b = 4;
```

после компиляции оба объявления ссылаются на одну и ту же структуру `System.Int32`. псевдоним существует только в языке, в метаданных сборки остаётся системный тип.

### неявная типизация

ранее тип переменных указывался явно, например `int x;`. компилятор при компиляции уже знал, что x хранит целочисленное значение.

можно использовать и модель неявной типизации:

```c#


var hello = "Hell to World";

var c = 20;
```

для неявной типизации вместо названия типа данных используется ключевое слово `var`. затем уже при компиляции компилятор сам выводит тип данных исходя из присвоенного значения. так как по умолчанию все целочисленные значения рассматриваются как значения типа `int`, переменная c будет иметь тип `int`. аналогично переменной `hello` присваивается строка, поэтому эта переменная будет иметь тип `string`. вывод типа происходит целиком во время компиляции. `var` не вводит динамическую типизацию: после вывода тип фиксирован, и присвоить значение другого типа нельзя.

эти переменные подобны обычным, однако они имеют некоторые ограничения.

во-первых, нельзя сначала объявить неявно типизируемую переменную, а затем инициализировать:

```c#


// этот код работает

int a;

a = 20;



// этот код не работает

var c;

c= 20;
```

типу неоткуда взяться, пока нет выражения-инициализатора, по которому выполняется вывод.

во-вторых, нельзя указать в качестве значения неявно типизируемой переменной `null`:

```c#


// этот код не работает

var c=null;
```

поскольку значение `null`, компилятор не сможет вывести тип данных. у литерала `null` нет собственного типа, тип ему придаёт контекст присваивания, а при `var` этот контекст как раз и должен быть выведен из литерала.
