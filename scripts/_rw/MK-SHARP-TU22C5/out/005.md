для хранения данных в программе применяются **переменные**. переменная представляет именованную область памяти, в которой хранится значение определённого типа. переменная имеет тип, имя и значение. тип определяет, какого рода информацию может хранить переменная, и одновременно задаёт множество допустимых операций над этим значением. имя является идентификатором, через который программа обращается к этой области. для ссылочного типа в переменной хранится ссылка на объект, а не сам объект целиком.

перед использованием любую переменную надо определить. синтаксис определения переменной выглядит следующим образом:

```c#
тип имя_переменной;
```

вначале идёт тип переменной, потом её имя. объявление вводит имя в текущую область видимости и связывает его с типом. в качестве имени переменной может выступать любое произвольное название, которое удовлетворяет следующим требованиям:

- имя может содержать любые цифры, буквы и символ подчёркивания, при этом первый символ в имени должен быть буквой или символом подчёркивания

- в имени не должно быть знаков пунктуации и пробелов

- имя не может быть ключевым словом языка c#. таких слов не так много, и при работе в visual studio среда разработки подсвечивает ключевые слова синим цветом.

хотя имя переменной может быть любым, переменным дают описательные имена, которые говорят об их предназначении. компилятор проверяет только формальные ограничения идентификатора, смысловая нагрузка имени на семантику не влияет.

например, определяется простейшая переменная:

```c#


string name;
```

здесь определена переменная name, которая имеет тип **string**, то есть переменная представляет строку. поскольку определение переменной представляет собой инструкцию, после него ставится точка с запятой. до присваивания локальная переменная считается определённо не присвоенной: чтение из неё до записи является ошибкой компиляции, а не чтением случайного содержимого памяти.

при этом учитывается, что c# является регистрозависимым языком, поэтому следующие два определения переменных представляют две разные переменные:

```c#


string name;

string Name;
```

сравнение имён идёт по точным символам, поэтому `name` и `Name` занимают разные ячейки связывания в таблице имён области видимости.

после определения переменной можно присвоить некоторое значение:

```c#


string name;

name = "Tom";
```

так как переменная name представляет тип string, то есть строку, ей присваивается строка в двойных кавычках. переменной можно присвоить только то значение, которое соответствует её типу. проверка соответствия выполняется во время компиляции: правая часть должна неявно приводиться к типу левой части.

в дальнейшем с помощью имени переменной программа обращается к той области памяти, в которой хранится её значение.

можно сразу при определении присвоить переменной значение. этот приём называется инициализацией:

```c#
string name = "Tom";
```

инициализация совмещает объявление и первое присваивание в одной инструкции, поэтому переменная становится определённо присвоенной сразу.

отличительная черта переменных состоит в том, что в программе можно многократно менять их значение. например, ниже определяется переменная, меняется её значение и выводится на консоль:

```c#


string name = "Tom";  // определяем переменную и инициализируем ее

 

Console.WriteLine(name);    // Tom

 

name = "Bob";       // меняем значение переменной

Console.WriteLine(name);    // Bob
```

консольный вывод программы:

```consoletext


Tom

Bob
```

повторное присваивание не создаёт новую переменную: имя остаётся тем же, меняется хранимое значение.

### константы

отличительная особенность переменных состоит в том, что их значение можно изменить в процессе работы программы. кроме того, в c# есть константы. **константа** должна быть обязательно инициализирована при определении, и после определения значение константы не может быть изменено.

константы предназначены для описания таких значений, которые не должны изменяться в программе. для определения констант используется ключевое слово **const**, которое указывается перед типом константы:

```c#


const string NAME = "Tom";  // определяем константу
```

здесь определена константа `NAME`, которая хранит строку "Tom". нередко для названия констант используется верхний регистр, но это не более чем условность. компилятор регистр имени не навязывает.

при использовании констант нужно помнить, что объявить их можно только один раз и что к моменту компиляции они должны быть определены. значение `const` обязано быть константным выражением, которое компилятор вычисляет во время компиляции, а не во время выполнения. в следующем случае возникает ошибка, так как константе не присвоено начальное значение:

```c#


const string NAME;  // ! Ошибка - константа NAME не инициализирована
```

кроме того, константу нельзя изменить в процессе работы программы:

```c#


const string NAME = "Tom";  // определяем константу

NAME = "Bob";   // !Ошибка - у констаты нельзя изменить значение
```

если в программе нужно хранить данные, которые не следует изменять, они определяются в виде констант. если их можно изменять, они определяются в виде переменных. подстановка константы происходит при компиляции, поэтому отдельной ячейки, которую программа могла бы перезаписать, у локальной константы такого вида нет.
