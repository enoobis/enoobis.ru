все массивы в c# построены на классе **Array** из пространства имён System. конкретный тип вроде `string[]` или `int[,]` является производным от Array. собственный наследник Array объявить нельзя: экземпляры массивов порождает среда выполнения. класс задаёт общие свойства и статические методы для любого ранга и типа элементов. основные из них:

- свойство Length возвращает общее число элементов массива

- свойство Rank возвращает размерность массива, то есть число его измерений

- `int BinarySearch(Array array, object? value)` выполняет бинарный поиск в отсортированном массиве и возвращает индекс найденного элемента

- `void Clear(Array array)` очищает массив, записывая во все элементы значение по умолчанию для их типа

- `void Copy(Array sourceArray, int sourceIndex, Array destinationArray, int destinationIndex, int length)` копирует из массива sourceArray, начиная с индекса sourceIndex, length элементов в массив destinationArray, начиная с индекса destinationIndex

- `bool Exists<T>(T[] array, Predicate<T> match)` проверяет, содержит ли массив array элементы, которые удовлетворяют условию делегата match

- `void Fill<T>(T[] array, T value)` заполняет массив array значением value

- `T? Find<T>(T[] array, Predicate<T> match)` находит первый элемент, который удовлетворяет условию делегата match. если элемент не найден, возвращается null

- `T? FindLast<T>(T[] array, Predicate<T> match)` находит последний элемент, который удовлетворяет условию делегата match. если элемент не найден, возвращается null

- `int FindIndex<T>(T[] array, Predicate<T> match)` возвращает индекс первого вхождения элемента, который удовлетворяет условию делегата match

- `int FindLastIndex<T>(T[] array, Predicate<T> match)` возвращает индекс последнего вхождения элемента, который удовлетворяет условию

- `T[] FindAll<T>(T[] array, Predicate<T> match)` возвращает новый массив из всех элементов, которые удовлетворяют условию делегата match

- `int IndexOf(Array array, object? value)` возвращает индекс первого вхождения элемента в массив

- `int LastIndexOf(Array array, object? value)` возвращает индекс последнего вхождения элемента в массив

- `void Resize<T>(ref T[]? array, int newSize)` изменяет размер одномерного массива

- `void Reverse(Array array)` располагает элементы массива в обратном порядке

- `void Sort(Array array)` сортирует элементы одномерного массива

ниже разобраны наиболее часто используемые методы. часть перегрузок принимает участок массива парой (индекс, длина), часть принимает делегат `Predicate<T>` или компаратор.

### сортировка массива

метод **Sort()** упорядочивает одномерный массив на месте:

```c#


string[] people =  { "Tom", "Sam", "Bob", "Kate", "Tom", "Alice" };



Array.Sort(people);



foreach (var person in people) 

    Console.Write($"{person} ");

	

// Alice Bob Kate Sam Tom Tom
```

сравнение строк по умолчанию идёт через компаратор текущего типа элементов. для `string` это культурно-зависимое сравнение. алгоритм, описанный для `Array.Sort`, является интроспективной сортировкой: на коротких участках используется сортировка вставками, при вырождении быстрой сортировки выполняется переход к пирамидальной, в остальных разбиениях работает быстрая сортировка. оценка числа сравнений в среднем и в худшем случае остаётся порядка n log n. сортировка неустойчива: взаимный порядок равных элементов не сохраняется. в примере две строки Tom после сортировки просто оказываются рядом, и по выводу их прежний порядок не восстановить.

у метода много перегрузок. одна из них упорядочивает только участок массива:

```c#


string[] people =  { "Tom", "Sam", "Bob", "Kate", "Tom", "Alice" };



// сортируем с 1 индекса 3 элемента

Array.Sort(people, 1, 3);



foreach (var person in people) 

    Console.Write($"{person} ");

	

// Tom Bob Kate Sam Tom Alice
```

вызов `Array.Sort(people, 1, 3)` затрагивает три элемента, начиная с индекса 1: Sam, Bob, Kate. после упорядочивания этого участка массив становится Tom, Bob, Kate, Sam, Tom, Alice. элементы вне окна, индексы 0, 4 и 5, остаются на своих местах.

### поиск индекса элемента

```c#


string[] people = { "Tom", "Sam", "Bob", "Kate", "Tom", "Alice" };



// находим индекс первого элемента "Tom"

int tomFirstIndex = Array.IndexOf(people, "Tom");

// находим индекс последнего элемента "Tom"

int tomLastIndex = Array.LastIndexOf(people, "Tom");

// находим индекс первого элемента, у которого длина строки больше 3

int lengthFirstIndex = Array.FindIndex(people, person => person.Length > 3);

// находим индекс последнего элемента, у которого длина строки больше 3

int lengthLastIndex = Array.FindLastIndex(people, person => person.Length > 3);



Console.WriteLine($"tomFirstIndex: {tomFirstIndex}");		// 0

Console.WriteLine($"tomLastIndex: {tomLastIndex}");			// 4

Console.WriteLine($"lengthFirstIndex: {lengthFirstIndex}");	// 3

Console.WriteLine($"lengthLastIndex: {lengthLastIndex}");	// 5





// находим индекс элемента "Bob"

// для бинарного поиска коллекцию нужно отсортировать

Array.Sort(people); // Alice Bob Kate Sam Tom Tom

int bobIndex = Array.BinarySearch(people, "Bob");

Console.WriteLine($"bobIndex: {bobIndex}");					// 1
```

`IndexOf` возвращает индекс первого вхождения значения, `LastIndexOf` возвращает индекс последнего. обе операции линейны по длине массива. `FindIndex` и `FindLastIndex` делают то же самое для произвольного предиката: здесь условие `person.Length > 3` выделяет строки длиннее трёх символов. первый такой элемент Kate стоит на индексе 3, последний Alice стоит на индексе 5.

`BinarySearch` ищет уже в упорядоченном массиве и требует, чтобы порядок совпадал с отношением сравнения. перед вызовом массив сортируется, после чего Bob оказывается на индексе 1. бинарный поиск делит оставшийся отрезок пополам и за счёт этого выполняет порядка log n сравнений. если элемент не найден, `IndexOf`, `LastIndexOf`, `FindIndex` и `FindLastIndex` возвращают -1. `BinarySearch` в этом случае возвращает отрицательное число: побитовое дополнение индекса, куда значение можно вставить, сохранив порядок. неотрицательный результат является индексом найденного элемента, отрицательный кодирует точку вставки.

### поиск элемента по условию

```c#


string[] people =  { "Tom", "Sam", "Bob", "Kate", "Tom", "Alice" };



// находим первый и последний элементы

// где длина строки больше 3 символов

string? first = Array.Find(people, person => person.Length > 3);

Console.WriteLine(first); // Kate

string? last = Array.FindLast(people, person => person.Length > 3);

Console.WriteLine(last); // Alice



// находим элементы, у которых длина строки равна 3

string[] group = Array.FindAll(people, person => person.Length == 3);

foreach (var person in group) Console.WriteLine(person);

// Tom Sam Bob Tom
```

`Find` возвращает первый элемент, для которого предикат истинен, `FindLast` возвращает последний. при длине строки больше трёх это Kate и Alice. если подходящего элемента нет, для данной сигнатуры результат равен null. `FindAll` собирает все совпадения в новый массив: строки длины 3, то есть Tom, Sam, Bob и повторный Tom. исходный массив эти методы не изменяют. `Exists` сообщает, есть ли хотя бы одно совпадение, и массив совпадений не строит.

### изменение порядка элементов массива

`Reverse` переставляет элементы участка в обратном порядке на месте:

```c#


string[] people =  { "Tom", "Sam", "Bob", "Kate", "Tom", "Alice" };



Array.Reverse(people);



foreach (var person in people) 

    Console.Write($"{person} ");

// "Alice", "Tom", "Kate", "Bob", "Sam", "Tom"
```

весь массив разворачивается: первым становится бывший последний элемент Alice, последним становится бывший первый Tom.

та же операция применяется к участку:

```c#


string[] people =  { "Tom", "Sam", "Bob", "Kate", "Tom", "Alice" };



// изменяем порядок 3 элементов начиная c индекса 1  

Array.Reverse(people, 1, 3);



foreach (var person in people) 

    Console.Write($"{person} ");

// "Tom", "Kate", "Bob", "Sam", "Tom", "Alice"
```

здесь обратный порядок получают только три элемента, начиная с индекса 1. участок Sam, Bob, Kate превращается в Kate, Bob, Sam, а элементы вне окна сохраняются. в результате массив печатается как Tom, Kate, Bob, Sam, Tom, Alice.

### изменение размера массива

длина массива задаётся при создании и полем объекта не меняется. метод Resize выделяет новый одномерный массив запрошенного размера, копирует в него общую часть элементов и записывает новую ссылку в переменную. первый параметр поэтому передаётся по ссылке `ref`: внутри метода в переменную вызывающего записывается ссылка на новый массив. изменение ячеек прежнего массива оставило бы в переменной people прежнюю ссылку. второй параметр задаёт новое число элементов. если оно меньше прежней длины, хвост отбрасывается. если оно больше, дополнительные ячейки получают значение по умолчанию для типа элементов: null для ссылок, 0 для чисел.

```c#


string[] people =  { "Tom", "Sam", "Bob", "Kate", "Tom", "Alice" };



// уменьшим массив до 4 элементов

Array.Resize(ref people, 4);



foreach (var person in people) 

    Console.Write($"{person} ");

// "Tom", "Sam", "Bob", "Kate"
```

после `Array.Resize(ref people, 4)` в переменной people лежит новый массив из четырёх строк: Tom, Sam, Bob, Kate. прежний массив из шести элементов остаётся прежним объектом, но ссылка на него из people уже не указывает, и при отсутствии других ссылок он становится доступен сборщику мусора.

### копирование массива

метод **Copy** копирует участок одного массива в другой. для ссылочных типов копируются ссылки, сами объекты не клонируются. строки при этом остаются теми же объектами, что и в источнике.

```c#


string[] people =  { "Tom", "Sam", "Bob", "Kate", "Tom", "Alice" };



var employees = new string[3];



// копируем 3 элемента из массива people c индекса 1  

// и вставляем их в массив employees начиная с индекса 0

Array.Copy(people,1, employees,0, 3);



foreach (var person in employees) 

    Console.Write($"{person} ");

// Sam Bob Kate
```

из массива people копируются три элемента, начиная с индекса 1, и записываются в массив employees, начиная с индекса 0. в employees оказываются Sam, Bob и Kate. длины массивов заранее согласованы с окном копирования: приёмник должен вмещать length элементов, начиная с destinationIndex, иначе метод завершится исключением. перекрывающиеся участки одного и того же массива копируются так, чтобы исходные значения участка были прочитаны до их затирания.
