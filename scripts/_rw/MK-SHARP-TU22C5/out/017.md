после циклов, переменных, условных конструкций и массивов ниже разобраны три задачи: подсчет положительных элементов, инверсия на месте и квадратичная сортировка обменами.

### количество положительных чисел

число положительных элементов массива получают одним проходом:

```c#


int[] numbers = { -4, -3, -2, -1, 0, 1, 2, 3, 4 };

int result = 0;

foreach(int number in numbers)

{

	if(number > 0)

	{

		result++;

	}

}

Console.WriteLine($"Число элементов больше нуля: {result}");
```

переменная `result` хранит накопленное количество и начинает с 0. `foreach` читает элементы по порядку. если элемент строго больше нуля, к `result` прибавляется единица. ноль и отрицательные числа счетчик не меняют. после цикла `result` равен числу положительных элементов. время линейно по длине массива, дополнительная память постоянна.

### инверсия массива

инверсия разворачивает массив на месте, в обратном порядке:

```c#


int[] numbers = { -4, -3, -2, -1,0, 1, 2, 3, 4 };

            

int n = numbers.Length; // длина массива

int k = n / 2;          // середина массива

int temp;               // вспомогательный элемент для обмена значениями

for(int i=0; i < k; i++)

{

	temp = numbers[i];

	numbers[i] = numbers[n - i - 1];

	numbers[n - i - 1] = temp;

}

foreach(int i in numbers)

{

	Console.Write($"{i} \t");

}
```

элементы нужно менять, поэтому подходит `for`, а не `foreach`. `n` хранит длину, `k` равно `n / 2` и задает середину: целочисленное деление отбрасывает дробную часть, при нечетной длине средний элемент остается на месте. на шаге `i` меняются местами элементы с индексами `i` и `n - i - 1`. индекс `n - i - 1` симметричен `i` относительно концов массива. обмен идет через временную переменную `temp`, иначе одно из значений было бы потеряно. цикл останавливается на середине, поэтому каждая пара меняется один раз. время линейно по `n`, дополнительная память ограничена одной переменной `temp`.

### программа сортировки массива

следующий фрагмент сортирует массив по возрастанию обменами. каждый элемент сравнивается со всеми последующими:

```c#


int[] nums = { 54, 7, -41, 2, 4, 2, 89, 33, -5, 12 };



// сортировка

int temp;

for (int i = 0; i < nums.Length - 1; i++)

{

    for (int j = i + 1; j < nums.Length; j++)

    {

        if (nums[i] > nums[j])

        {

            temp = nums[i];

            nums[i] = nums[j];

            nums[j] = temp;

        }

    }

}



// вывод

Console.WriteLine("Вывод отсортированного массива");

for (int i = 0; i < nums.Length; i++)

{

    Console.WriteLine(nums[i]);

}
```

алгоритм делает проходы по массиву и сравнивает пары. каждый элемент сравнивается с каждым другим, сравнение элемента с самим собой исключено, поэтому внутренний цикл начинается со следующего индекса. число сравнений квадратично по длине.

во внешнем цикле выбирается элемент, который сравнивают с хвостом массива. граница `nums.Length - 1` достаточна: у последнего элемента хвоста уже нет.

```c#
for (int i = 0; i < nums.Length - 1; i++)
```

внутренний цикл начинается с `i + 1` и доходит до конца массива. из него берутся элементы, с которыми сравнивается `nums[i]`:

```c#
for (int j = i + 1; j < nums.Length; j++)
```

если элемент с меньшим индексом больше элемента с большим индексом, их меняют местами. после обмена меньшее значение оказывается левее. равные элементы не меняются, потому что условие строгое:

```c#


if (nums[i] > nums[j])

{

	temp = nums[i];

	nums[i] = nums[j];

	nums[j] = temp;

}
```

после всех пар массив упорядочен по возрастанию, и цикл вывода печатает элементы по одному на строку. сортировка работает на месте: отдельный выходной массив не выделяется.
