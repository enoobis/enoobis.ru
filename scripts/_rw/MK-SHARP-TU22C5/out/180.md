xpath является языком запросов к xml. запрос выбирает узлы, которые удовлетворяют селектору, и вычисляется относительно контекстного узла.

ниже селекторы, которые дальше используются в примерах.

`.`

текущий узел.

`..`

родительский узел.

`*`

все дочерние элементы текущего узла. проверка узла `*` сопоставляется с элементами любого имени и не захватывает текстовые узлы и комментарии.

`person`

все дочерние узлы с заданным именем, здесь с именем person.

`@name`

атрибут текущего узла. после знака `@` стоит имя атрибута, здесь name.

`@*`

все атрибуты текущего узла.

`element[3]`

дочерний узел по позиции, здесь третий. нумерация позиций в xpath начинается с 1, поэтому предикат `[3]` означает `position()=3`, а не элемент с индексом 3 в смысле массива c#.

`//person`

все узлы документа с именем person. две косые черты запускают поиск по оси потомков, а не только среди прямых детей контекстного узла.

`person[@name='Tom']`

элементы person с заданным значением атрибута. здесь выбираются все элементы person, у которых атрибут name равен tom.

`person[company='Microsoft']`

элементы с заданным значением вложенного элемента. здесь выбираются все элементы person, у которых дочерний элемент company имеет значение microsoft.

`//person/company`

все узлы документа с именем company, которые лежат в элементах person. шаг `person/company` идёт по оси ребёнка, а префикс `//` позволяет начать этот шаг от любого person в документе.

имя без косой черты отсчитывается от текущего узла по оси ребёнка, `@` переходит на ось атрибутов.

запросы xpath в этой модели выполняются двумя методами. в лекции они отнесены к `XmlElement`. объявлены они у `XmlNode` и доступны элементу как наследнику:

- `SelectSingleNode()` выбирает один узел. если запросу соответствует несколько узлов, возвращается первый. если не соответствует ни один, результат пуст

- `SelectNodes()` возвращает выборку коллекции узлов объектом `XmlNodeList`

документ для запросов тот же, что и в прошлых темах:

```xml


<?xml version="1.0" encoding="utf-8" ?>

<people>

  <person name="Tom">

    <company>Microsoft</company>

    <age>37</age>

  </person>

  <person name="Bob">

    <company>Google</company>

    <age>41</age>

  </person>

</people>
```

первый запрос выбирает все дочерние узлы корня, то есть все элементы person:

```c#


using System.Xml;



XmlDocument xDoc = new XmlDocument();

xDoc.Load("people.xml");

XmlElement? xRoot = xDoc.DocumentElement;



// выбор всех дочерних узлов

XmlNodeList? nodes = xRoot?.SelectNodes("*");

if (nodes is not null)

{

    foreach (XmlNode node in nodes)

        Console.WriteLine(node.OuterXml);

}
```

консольный вывод. печатается `OuterXml`, разметка самого узла вместе с его потомками:

```consoletext


<person name="Tom"><company>Microsoft</company><age>37</age></person>

<person name="Bob"><company>Google</company><age>41</age></person>
```

тот же набор можно запросить по имени. выбираются все узлы `<person>`:

```c#


XmlNodeList? personNodes = xRoot?.SelectNodes("person");
```

значения атрибутов name у элементов person выводятся так:

```c#


using System.Xml;



XmlDocument xDoc = new XmlDocument();

xDoc.Load("people.xml");

XmlElement? xRoot = xDoc.DocumentElement;

XmlNodeList? personNodes = xRoot?.SelectNodes("person");

if(personNodes is not null)

{

    foreach (XmlNode node in personNodes)

        Console.WriteLine(node.SelectSingleNode("@name")?.Value);

}
```

результат выполнения:

```bash


Tom

Bob
```

узел, у которого атрибут name имеет значение tom, выбирается отдельным предикатом. `SelectSingleNode` здесь достаточен: такому предикату в документе соответствует один элемент, и на консоль снова идет его `OuterXml`.

```c#


XmlNode? tomNode = xRoot?.SelectSingleNode("person[@name='Tom']");

Console.WriteLine(tomNode?.OuterXml);
```

чтобы получить только компании, выборка спускается вниз по иерархии: от любого person к его дочернему company. `InnerText` возвращает текст элемента без окружающей разметки.

```c#


using System.Xml;



XmlDocument xDoc = new XmlDocument();

xDoc.Load("people.xml");

XmlElement? xRoot = xDoc.DocumentElement;



XmlNodeList? companyNodes = xRoot?.SelectNodes("//person/company");

if(companyNodes is not null)

{

    foreach (XmlNode node in companyNodes)

        Console.WriteLine(node.InnerText);

}
```
