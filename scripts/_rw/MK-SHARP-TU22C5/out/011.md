операция присваивания записывает значение в модифицируемое именованное выражение. левый операнд обязан допускать запись: это переменная, поле, элемент массива, свойство или индексатор. правый операнд вычисляется и дает записываемое значение. у операции два операнда.

базовая форма в c#, как и в большинстве императивных языков, обозначается `=`. значение правого операнда записывается в объект, обозначенный левым:

```c#


int number = 23;
```

переменной `number` присваивается число 23. имя `number` стоит слева и принимает значение правого операнда.

одно и то же значение можно записать сразу в несколько переменных. присваивание правоассоциативно, поэтому цепочка без скобок читается справа налево. тип выражения присваивания совпадает с типом левого операнда, а значение выражения равно записанному значению, поэтому результат одной операции может стать правым операндом следующей:

```c#


int a, b, c;

a = b = c = 34;
```

приоритет присваивания ниже приоритета арифметических операций. сначала целиком вычисляется правый операнд, и только после этого результат записывается влево:

```c#


int a, b, c;

a = b = c = 34 * 2 / 4; // 17
```

сначала вычисляется `34 * 2 / 4`. оба оператора целочисленные и выполняются слева направо: `34 * 2` дает 68, затем `68 / 4` дает 17. число 17 записывается в `c`, затем в `b`, затем в `a`.

помимо простого присваивания в c# есть составные операции. для предопределенных операторов запись `A += B` дает тот же результат, что `A = A + B`, но левый операнд вычисляется один раз. различие проявляется, когда слева стоит индексатор или свойство с побочным эффектом при чтении.

- `+=` : присваивание после сложения. левому операнду присваивается сумма левого и правого операндов: `A += B` равнозначно `A = A + B`
- `-=` : присваивание после вычитания. левому операнду присваивается разность левого и правого операндов: `A -= B` эквивалентно `A = A - B`
- `*=` : присваивание после умножения. левому операнду присваивается произведение левого и правого операндов: `A *= B` эквивалентно `A = A * B`
- `/=` : присваивание после деления. левому операнду присваивается частное левого и правого операндов: `A /= B` эквивалентно `A = A / B`
- `%=` : присваивание после деления по модулю. левому операнду присваивается остаток от целочисленного деления левого операнда на правый: `A %= B` эквивалентно `A = A % B`
- `&=` : присваивание после поразрядной конъюнкции. левому операнду присваивается результат поразрядного и его битового представления с битовым представлением правого операнда: `A &= B` эквивалентно `A = A & B`
- `|=` : присваивание после поразрядной дизъюнкции. левому операнду присваивается результат поразрядного или его битового представления с битовым представлением правого операнда: `A |= B` эквивалентно `A = A | B`
- `^=` : присваивание после исключающего или. левому операнду присваивается результат поразрядного исключающего или его битового представления с битовым представлением правого операнда: `A ^= B` эквивалентно `A = A ^ B`
- `<<=` : присваивание после сдвига разрядов влево. левому операнду присваивается результат сдвига его битового представления влево на число разрядов, равное значению правого операнда: `A <<= B` эквивалентно `A = A << B`
- `>>=` : присваивание после сдвига разрядов вправо. левому операнду присваивается результат сдвига его битового представления вправо на число разрядов, равное значению правого операнда: `A >>= B` эквивалентно `A = A >> B`

применение составных операций. комментарии показывают значение `a` после каждой строки:

```c#


int a = 10;

a += 10;        // 20

a -= 4;         // 16

a *= 2;         // 32

a /= 8;         // 4

a <<= 4;      // 64

a >>= 2;      // 16
```

составные присваивания тоже правоассоциативны и выполняются справа налево:

```c#


int a = 8;

int b = 6;

int c = a += b -= 5;	// 9
```

разбор выражения идет от правого присваивания к левому:

- `b -= 5` вычисляет `6 - 5` и записывает в `b` значение 1
- `a += (b -= 5)` вычисляет `8 + 1` и записывает в `a` значение 9
- `c = (a += (b -= 5))` записывает в `c` значение 9
