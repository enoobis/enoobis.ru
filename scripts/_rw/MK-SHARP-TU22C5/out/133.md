класс **Parallel** входит в tpl и описывает параллельное исполнение набора делегатов и итераций цикла. методы класса делят работу между потоками пула. вызывающий поток тоже исполняет часть работы. вызов возвращает управление, когда все части завершились, нормально или с исключением.

метод `Invoke` запускает сразу несколько действий:

```c#


// метод Parallel.Invoke выполняет три метода

Parallel.Invoke(

    Print,

    () =>

    {

        Console.WriteLine($"Выполняется задача {Task.CurrentId}");

        Thread.Sleep(3000);

    },

    () => Square(5)

);



void Print()

{

    Console.WriteLine($"Выполняется задача {Task.CurrentId}");

    Thread.Sleep(3000);

}

// вычисляем квадрат числа

void Square(int n)

{

    Console.WriteLine($"Выполняется задача {Task.CurrentId}");

    Thread.Sleep(3000);

    Console.WriteLine($"Результат {n * n}");

}
```

`Parallel.Invoke` принимает массив `Action`, то есть делегатов без параметров и без результата. число элементов произвольное. в примере их три: группа методов `Print`, лямбда с печатью идентификатора и паузой, лямбда с вызовом `Square(5)`. как и у конструктора `Task`, аргументом бывает и имя метода, и лямбда-выражение.

при нескольких доступных ядрах эти делегаты исполняются параллельно. вызывающий поток забирает один из них себе. степень параллелизма по умолчанию соотносится с числом процессоров и не обязана равняться числу делегатов: лишние действия ждут свободного работника. пример вывода:

```consoletext


Выполняется задача 1

Выполняется задача 3

Выполняется задача 2

Результат 25
```

порядок строк не фиксирован. `Результат 25` печатает только `Square`, поэтому эта строка идёт после строки той же задачи, а относительно двух других задач встаёт в любое место.

### Parallel.For

метод `Parallel.For` выполняет итерации цикла параллельно. одна из перегрузок:

```c#
For(int, int, Action<int>)
```

первый аргумент задаёт начальный индекс и входит в диапазон. второй задаёт конечный индекс и в диапазон не входит. третий аргумент, делегат `Action<int>`, вызывается один раз на итерацию и получает текущий индекс:

```c#


Parallel.For(1, 5, Square);



// вычисляем квадрат числа

void Square(int n)

{

    Console.WriteLine($"Выполняется задача {Task.CurrentId}");

    Console.WriteLine($"Квадрат числа {n} равен {n * n}");

    Thread.Sleep(2000);

}
```

границы 1 и 5 задают полуинтервал от 1 до 5, не включая 5: индексы 1, 2, 3 и 4. тело `Square` принимает `int`, что совпадает с типом `Action<int>`. аргумент `n` и есть счётчик итерации. `Square` вызывается четыре раза. пример вывода:

```consoletext


Выполняется задача 1

Выполняется задача 2

Квадрат числа 4 равен 16

Выполняется задача 4

Квадрат числа 1 равен 1

Выполняется задача 3

Квадрат числа 3 равен 9

Квадрат числа 2 равен 4
```

итерации планируются независимо. порядок индексов в выводе не повторяет последовательность 1, 2, 3, 4. две печати одной итерации тоже не атомарны: между ними поток может быть вытеснен, и вклинивается строка другой итерации.

### Parallel.ForEach

метод **Parallel.ForEach** перебирает коллекцию с интерфейсом `IEnumerable<T>` по той же схеме, что цикл `foreach`, и распределяет элементы по рабочим потокам. одна из перегрузок:

```c#
ParallelLoopResult ForEach<TSource>(IEnumerable<TSource> source,Action<TSource> body)
```

первый параметр является источником элементов, второй является телом и вызывается один раз на элемент. метод возвращает структуру `ParallelLoopResult` с итогом прохода:

```c#


ParallelLoopResult result = Parallel.ForEach<int>(

       new List<int>() { 1, 3, 5, 8 },

       Square

);



// вычисляем квадрат числа

void Square(int n)

{

    Console.WriteLine($"Выполняется задача {Task.CurrentId}");

    Console.WriteLine($"Квадрат числа {n} равен {n * n}");

    Thread.Sleep(2000);

}
```

источник содержит значения `int`, поэтому второй аргумент, тело, тоже принимает `int`. пример вывода:

```consoletext


Выполняется задача 1

Выполняется задача 3

Квадрат числа 8 равен 64

Выполняется задача 4

Квадрат числа 3 равен 9

Выполняется задача 2

Квадрат числа 5 равен 25

Квадрат числа 1 равен 1
```

порядок элементов в выводе задаёт планировщик. порядок исходного списка не сохраняется.

### выход из цикла

в обычных циклах `for` и `foreach` досрочный выход записывается оператором `break`. у `Parallel.For` и `Parallel.ForEach` одновременно живы несколько итераций, и один оператор `break` чужие потоки не останавливает. досрочный выход передаётся объектом состояния итерации:

```c#


ParallelLoopResult result = Parallel.For(1, 10, Square);

if (!result.IsCompleted)

    Console.WriteLine($"Выполнение цикла завершено на итерации {result.LowestBreakIteration}");



// вычисляем квадрат числа

void Square(int n, ParallelLoopState pls)

{

    if (n == 5) pls.Break();    // если передано 5, выходим из цикла



    Console.WriteLine($"Квадрат числа {n} равен {n * n}");

    Thread.Sleep(2000);

}
```

тело `Square` принимает дополнительный параметр **ParallelLoopState**. когда индекс равен 5, вызывается `Break`. вызов сообщает циклу, что итерации с большим индексом уже не нужны. итерации с меньшим индексом доводятся до конца: уже разрешённая работа с меньшим номером не отменяется. планировщик завершает `Parallel.For` в ближайшей точке, где это можно сделать без обрыва таких итераций.

`Parallel.For` и `Parallel.ForEach` возвращают **ParallelLoopResult**. для этого примера существенны два свойства:

- `IsCompleted` : `true`, только если цикл прошёл весь диапазон и не останавливался через `Break` или `Stop`.

- `LowestBreakIteration` : наименьший индекс, на котором вызвали `Break`. если `Break` не вызывался, значения нет.

в примере `Break` срабатывает на индексе 5, поэтому `IsCompleted` равно `false`, а `LowestBreakIteration` равно 5.
