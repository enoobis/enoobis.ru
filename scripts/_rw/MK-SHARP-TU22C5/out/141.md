проекция позволяет преобразовать объект одного типа в объект другого типа. для проекции используется оператор **select**. пусть имеется набор объектов следующего класса, представляющего пользователя:

```c#

record class Person(string Name, int Age);
```
в результирующую выборку берётся только свойство `Name`:

```c#

var people = new List<Person>
{
    new Person ("Tom", 23),
    new Person ("Bob", 27),
    new Person ("Sam", 29),
    new Person ("Alice", 24)
};

var names = from p in people select p.Name;

foreach (string n in names)
     Console.WriteLine(n);
```
результат выражения linq представляет набор строк, поскольку выражение `select p.Name` выбирает в результирующую выборку только значения свойства `Name`.

```bash

Tom
Bob
Sam
Alice
```
в качестве альтернативы используется метод расширения **Select()**:

```c#
Select(Func<TSource,TResult> selector)
```
этот метод принимает функцию преобразования в виде делегата `Func<TSource, TResult>`. функция преобразования получает каждый объект выборки типа `TSource` и с его помощью создаёт объект `TResult`. метод `Select` возвращает коллекцию преобразованных объектов. в linq to objects проекция отложена: лямбда вызывается при перечислении, а не в момент построения запроса.

предыдущий пример с применением метода `Select`:

```c#

var people = new List<Person>
{
    new Person ("Tom", 23),
    new Person ("Bob", 27),
    new Person ("Sam", 29),
    new Person ("Alice", 24)
};
var names = people.Select(u => u.Name);

foreach (string n in names)
     Console.WriteLine(n);
```
аналогично можно создать объекты другого типа, в том числе анонимного:

```c#

var people = new List<Person>
{
    new Person ("Tom", 23),
    new Person ("Bob", 27)
};

var personel = from p in people
            select new
            {
                FirstName = p.Name,
                Year = DateTime.Now.Year - p.Age
            };

foreach (var p in personel)
    Console.WriteLine($"{p.FirstName} - {p.Year}");


record class Person(string Name, int Age);
```
здесь оператор `select` создаёт объект анонимного типа, используя текущий объект `Person`. результат содержит набор объектов данного анонимного типа, в котором определены два свойства: `FirstName` и `Year` (год рождения). для анонимного типа компилятор порождает закрытый класс с этими свойствами, с конструктором и с равенством по значениям свойств. консольный вывод программы:

```bash

Tom - 1999
Bob - 1995
```
в качестве альтернативы используется метод расширения **Select()**:

```c#

// проекция на объекты анонимного типа
var personel = people.Select(p => new 
{ 
    FirstName = p.Name, 
    Year = DateTime.Now.Year - p.Age 
});
```
### переменные в запросах и оператор let

иногда в запросах linq нужны дополнительные промежуточные вычисления. для этих целей в запросах задают свои переменные с помощью оператора **let**:

```c#

var people = new List<Person>
{
    new Person ("Tom", 23),
    new Person ("Bob", 27)
};

var personnel = from p in people
               let name = $"Mr. {p.Name}"
               let year = DateTime.Now.Year - p.Age
               select new
            {
                Name = name,
                Year = year
            };

foreach (var p in personnel)
    Console.WriteLine($"{p.Name} - {p.Year}");

record class Person(string Name, int Age);
```
здесь создаются две переменные. переменная `name`, значение которой равно `$"Mr. {p.Name}"`. переменная `year` хранит разность текущего года и возраста. оператор `let` вводит имя в область запроса, и дальше оно доступно в `where` и `select`. при переводе запроса в методы компилятор превращает `let` в промежуточный `Select`, который запоминает вычисленное значение рядом с исходным элементом. у методов расширения отдельного оператора для такого имени нет: промежуточный результат либо вычисляют внутри лямбды, либо сохраняют в локальной переменной до цепочки.

возможность определять переменные внутри запроса отличает операторы linq от цепочки методов расширения.

### выборка из нескольких источников

в linq можно выбирать объекты не только из одного, но и из большего количества источников. например, классы:

```c#

record class Course(string Title);  // учебный курс
record class Student(string Name);  // студент
```
класс `Course` представляет учебный курс и хранит его название. класс `Student` представляет студента и хранит его имя.

из списка курсов и списка студентов получается набор пар студент-курс, то есть сущность, которая представляет учёбу студента на данном курсе:

```c#

var courses = new List<Course> { new Course("C#"), new Course("Java") };
var students = new List<Student> { new Student("Tom"), new Student("Bob") };

var enrollments = from course in courses    //  выбираем по одному курсу
             from student in students       //  выбираем по одному студенту
             select new { Student = student.Name, Course = course.Title};   // соединяем каждого студента с каждым курсом

foreach (var enrollment in enrollments)
    Console.WriteLine($"{enrollment.Student} - {enrollment.Course}");

record class Course(string Title);  // учебный курс
record class Student(string Name);  // студент
```
консольный вывод:

```consoletext

Tom - C#
Bob - C#
Tom - Java
Bob - Java
```
при выборке из двух источников каждый элемент из первого источника сопоставляется с каждым элементом из второго источника. получается 4 пары. такая запись задаёт декартово произведение источников. второй оператор `from` компилятор переводит в вызов `SelectMany`.

### SelectMany и сведение объектов

метод **SelectMany** позволяет свести набор коллекций в одну коллекцию. у него ряд перегруженных версий. две из них:

```c#

SelectMany(Func<TSource, IEnumerable<TResult>> selector);
SelectMany(Func<TSource, IEnumerable<TCollection>> collectionSelector, Func<TSource,TCollection,TResult> resultSelector);
```
первая версия метода принимает функцию преобразования в виде делегата `Func<TSource, IEnumerable<TResult>>`. функция преобразования получает каждый объект выборки типа `TSource` и с его помощью создаёт набор объектов `TResult`. метод `SelectMany` возвращает одну плоскую коллекцию преобразованных объектов: вложенность последовательностей снимается.

вторая версия принимает функцию преобразования в виде делегата `Func<TSource, IEnumerable<TCollection>>`. функция преобразования получает каждый объект выборки типа `TSource` и возвращает некоторую промежуточную коллекцию типа `TCollection`. второй параметр - та же функция преобразования в виде делегата `Func<TSource, TCollection, TResult>`, которая получает два параметра: каждый элемент текущей выборки и каждый элемент промежуточной коллекции, и на их основе создаёт некоторый объект типа `TResult`.

следующий пример сводит сотрудников всех компаний в один список:

```c#

var companies = new List<Company>
{
    new Company("Microsoft", new List<Person> {new Person("Tom"), new Person("Bob")}),
    new Company("Google", new List<Person> {new Person("Sam"), new Person("Mike")}),
};
var employees = companies.SelectMany(c => c.Staff);

foreach (var emp in employees)
    Console.WriteLine($"{emp.Name}");

record class Company(string Name, List<Person> Staff);
record class Person(string Name);
```
здесь дан список компаний, и в каждой компании имеется набор сотрудников в виде списка объектов `Person`. на выходе получается список сотрудников всех компаний, то есть коллекция объектов `Person`. консольный вывод:

```consoletext

Tom
Bob
Sam
Mike
```
аналогичный пример с помощью операторов linq:

```c#

var companies = new List<Company>
{
    new Company("Microsoft", new List<Person> {new Person("Tom"), new Person("Bob")}),
    new Company("Google", new List<Person> {new Person("Sam"), new Person("Mike")}),
};
var employees = from c in companies
                from emp in c.Staff
                select emp;

foreach (var emp in employees)
    Console.WriteLine($"{emp.Name}");

record class Company(string Name, List<Person> Staff);
record class Person(string Name);
```
теперь к сотрудникам добавляется их компания:

```c#

var companies = new List<Company>
{
    new Company("Microsoft", new List<Person> {new Person("Tom"), new Person("Bob")}),
    new Company("Google", new List<Person> {new Person("Sam"), new Person("Mike")}),
};

var employees = companies.SelectMany(c => c.Staff,
                                    (c, emp)=> new { Name = emp.Name, Company = c.Name });

foreach (var emp in employees)
    Console.WriteLine($"{emp.Name} - {emp.Company}");

record class Company(string Name, List<Person> Staff);
record class Person(string Name);
```
здесь применяется другая версия метода `SelectMany`. первый делегат в виде `c => c.Staff` создаёт промежуточную коллекцию: фактически возвращается набор сотрудников каждой компании. второй делегат `(c, emp)=> new { Name = emp.Name, Company = c.Name }` получает каждую компанию и каждый элемент промежуточной коллекции, объект `Person`, и на их основе создаёт анонимный объект с двумя свойствами `Name` и `Company`. консольный вывод программы:

```consoletext

Tom - Microsoft
Bob - Microsoft
Sam - Google
Mike - Google
```
аналогичный пример с помощью операторов запросов:

```c#

var companies = new List<Company>
{
    new Company("Microsoft", new List<Person> {new Person("Tom"), new Person("Bob")}),
    new Company("Google", new List<Person> {new Person("Sam"), new Person("Mike")}),
};
var employees = from c in companies
             from emp in c.Staff
             select new { Name = emp.Name, Company = c.Name };

foreach (var emp in employees)
    Console.WriteLine($"{emp.Name} - {emp.Company}");

record class Company(string Name, List<Person> Staff);
record class Person(string Name);
```
