шаблон кортежа сравнивает значение кортежа по позициям. в выражение `switch` передаётся кортеж из языка и времени суток, и по этой паре выбирается текст приветствия:

```c#


string GetWelcome(string lang, string daytime) => (lang, daytime) switch

{

	("english", "morning") => "Good morning",

	("english", "evening") => "Good evening",

	("german", "morning") => "Guten Morgen",

	("german", "evening") => "Guten Abend",

	_ => "Здрасьть"

};
```

в метод приходят два значения, из которых строится кортеж. кортеж можно передать и готовым, тогда параметр уже имеет тип кортежа. в ветвях круглые скобки задают значения позиций. ветвь `("english", "morning")` совпадает только когда `lang` равен `"english"` и `daytime` равен `"morning"`. остальные пары заданы так же. шаблон `_` принимает любую пару, не совпавшую раньше. сравнение идёт по всем позициям сразу: несовпадение одной позиции отклоняет всю ветвь.

применение:

```c#


string message = GetWelcome("english", "evening");

Console.WriteLine(message);  // Good evening



message = GetWelcome("french", "morning");

Console.WriteLine(message);  // Здрасьть
```

сравнивать можно не все позиции. элемент, который в ветви не участвует, заменяется прочерком `_`. это шаблон отбрасывания: позиция обязана существовать, но её значение не проверяется и не связывается.

```c#


string GetWelcome(string lang, string daytime, string status) => (lang, daytime, status) switch

{

	("english", "morning", _) => "Good morning",

	("english", "evening", _) => "Good evening",

	("german", "morning", _) => "Guten Morgen",

	("german", "evening", _) => "Guten Abend",

	(_, _, "admin") => "Hello, Admin",

	_ => "Здрасьть"

};
```

кортеж теперь состоит из трёх элементов: язык, время суток и статус. первые четыре ветви статус не используют, поэтому на третьей позиции стоит `_`, как в `("english", "morning", _)`. в предпоследней ветви проверяется только третий элемент, язык и время в ней не участвуют: `(_, _, "admin")`. для каждой позиции при этом указано либо конкретное значение, либо прочерк. пропуск позиции недопустим: число позиций шаблона совпадает с числом элементов кортежа.

применение:

```c#


string message = GetWelcome("english", "evening", "user");

Console.WriteLine(message);  // Good evening



message = GetWelcome("french", "morning", "admin");

Console.WriteLine(message);  // Hello, Admin
```

порядок ветвей существенен. пара с языком `"english"` и временем `"evening"` совпадает со второй ветвью даже при статусе `"admin"`, потому что более ранние ветви уже покрывают эту комбинацию языка и времени, а статус в них отброшен. до ветви администратора доходит значение, не совпавшее с четырьмя первыми шаблонами, например язык `"french"` при статусе `"admin"`.
