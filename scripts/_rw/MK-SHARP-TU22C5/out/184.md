сохранение и восстановление объектов в файлах xml выполняет класс `XmlSerializer` из пространства имён `System.Xml.Serialization`. он сопоставляет открытый граф объектов разметке xml и обратно, без ручной сборки узлов, как это делалось через `XmlDocument` и linq to xml.

у `XmlSerializer` несколько конструкторов, и почти все они требуют тип данных, которые будут сериализоваться и десериализоваться:

```c#


XmlSerializer xmlSerializer = new XmlSerializer(typeof(Person));



//[Serializable]

class Person { }
```

такой экземпляр сериализатора работает с объектами класса `Person`. атрибут `[Serializable]` в листинге закомментирован. для `XmlSerializer` он не нужен: атрибут относится к бинарной сериализации и на отображение в xml не влияет.

у `XmlSerializer` есть жёсткие ограничения контракта. класс, подлежащий сериализации, должен быть открытым, с модификатором `public`, и должен иметь открытый конструктор без параметров. сериализуются только открытые члены. поля и свойства с модификатором `private` при сериализации игнорируются. у свойств должны быть открытые аксессоры чтения и записи: десериализатор создаёт объект пустым конструктором и затем записывает свойства, поэтому свойство только с геттером он заполнить не может.

### сериализация

сохранение объекта в xml выполняет метод `Serialize()`. у метода несколько перегрузок. простейшая из них:

```c#
void Serialize (Stream stream, object? o);
```

первый параметр имеет тип `Stream`, например `FileStream`, и задаёт поток, в который пишется xml. второй параметр является тем объектом, который сохраняется. применение к одному экземпляру `Person`:

```c#


using System.Xml.Serialization;



// объект для сериализации

Person person = new Person("Tom", 37);



// передаем в конструктор тип класса Person

XmlSerializer xmlSerializer = new XmlSerializer(typeof(Person));



// получаем поток, куда будем записывать сериализованный объект

using (FileStream fs = new FileStream("person.xml", FileMode.OpenOrCreate))

{

    xmlSerializer.Serialize(fs, person);



    Console.WriteLine("Object has been serialized");

}



//[Serializable]

public class Person

{

    public string Name { get; set; } = "Undefined";

    public int Age { get; set; } = 1;



    public Person() { }

    public Person(string name, int age)

    {

        Name = name;

        Age = age;

    }

}
```

класс `Person` открытый, его свойства открыты и доступны для чтения и записи, конструктор без параметров есть, поэтому экземпляры этого класса сериализуются. в конструктор `XmlSerializer` передаётся тип `Person`, полученный через `typeof`. параметризованный конструктор `Person(string, int)` здесь вызывается самой программой при создании объекта. при чтении xml он не используется: десериализатор вызывает конструктор без параметров.

в `Serialize` передаются файловый поток, открытый на файл `person.xml` в режиме `OpenOrCreate`, и сохраняемый объект `Person`. после завершения программы файл `person.xml` содержит состояние объекта:

```xml


<?xml version="1.0"?>

<Person xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns:xsd="http://www.w3.org/2001/XMLSchema">

  <Name>Tom</Name>

  <Age>37</Age>

</Person>
```

корневой элемент получает имя класса, `Person`. сериализатор добавляет объявления пространств имён `xsi` и `xsd` для xml schema instance и xml schema. свойства становятся одноимёнными дочерними элементами, `Name` и `Age`.

### десериализация

восстановление объекта c# из xml выполняет метод `Deserialize()`. одна из его перегрузок:

```c#
object? Deserialize (Stream stream);
```

параметром передаётся `Stream` с данными xml. метод возвращает десериализованный объект как `object`, и вызывающий код приводит его к ожидаемому типу.

чтение того же файла `person.xml`:

```c#


using System.Xml.Serialization;



XmlSerializer xmlSerializer = new XmlSerializer(typeof(Person));



// десериализуем объект

using (FileStream fs = new FileStream("person.xml", FileMode.OpenOrCreate))

{

    Person? person = xmlSerializer.Deserialize(fs) as Person;

    Console.WriteLine($"Name: {person?.Name}  Age: {person?.Age}");

}



public class Person

{

    public string Name { get; set; } = "Undefined";

    public int Age { get; set; } = 1;



    public Person() { }

    public Person(string name, int age)

    {

        Name = name;

        Age = age;

    }

}
```

оператор `as` даёт `null`, если фактический тип результата не совместим с `Person`, и тогда оператор `?.` не обращается к свойствам. при успешном чтении на консоль выводятся имя и возраст, записанные при сериализации.

### сериализация и десериализация коллекций

тем же сериализатором сохраняется массив или другая коллекция объектов. в конструктор передаётся уже не тип элемента, а тип массива:

```c#


using System.Xml.Serialization;



Person[] people = new Person[]

{

    new Person("Tom", 37),

    new Person("Bob", 41)

};



XmlSerializer formatter = new XmlSerializer(typeof(Person[]));

// сохранение массива в файл

using (FileStream fs = new FileStream("people.xml", FileMode.OpenOrCreate))

{

    formatter.Serialize(fs, people);

}

// восстановление массива из файла

using (FileStream fs = new FileStream("people.xml", FileMode.OpenOrCreate))

{

    Person[]? newpeople = formatter.Deserialize(fs) as Person[];



    if(newpeople != null)

    {

        foreach (Person person in newpeople)

        {

            Console.WriteLine($"Name: {person.Name} --- Age: {person.Age}");

        }

    }

}



public class Person

{

    public string Name { get; set; } = "Undefined";

    public int Age { get; set; } = 1;



    public Person() { }

    public Person(string name, int age)

    {

        Name = name;

        Age = age;

    }

}
```

сначала массив из двух объектов `Person` записывается в `people.xml`, затем читается обратно. результат `Deserialize` приводится к `Person[]`. если приведение не удалось и `newpeople` равно `null`, цикл не выполняется.

консольный вывод:

```bash


Name: Tom --- Age: 37

Name: Bob --- Age: 41
```

для более сложного по составу объекта схема та же. свойство ссылочного типа сериализуется вложенным элементом, если тип этого свойства сам удовлетворяет контракту `XmlSerializer`:

```c#


using System.Xml.Serialization;



var microsoft = new Company("Microsoft");

var google = new Company("Google");



Person[] people = new Person[]

{

    new Person("Tom", 37, microsoft),

    new Person("Bob", 41, google)

};



XmlSerializer formatter = new XmlSerializer(typeof(Person[]));



using (FileStream fs = new FileStream("people.xml", FileMode.OpenOrCreate))

{

    formatter.Serialize(fs, people);

}



using (FileStream fs = new FileStream("people.xml", FileMode.OpenOrCreate))

{

    Person[]? newpeople = formatter.Deserialize(fs) as Person[];



    if(newpeople != null)

    {

        foreach (Person person in newpeople)

        {

            Console.WriteLine($"Name: {person.Name}");

            Console.WriteLine($"Age: {person.Age}");

            Console.WriteLine($"Company: {person.Company.Name}");

        }

    }

}



public class Company

{

    public string Name { get; set; } = "Undefined";



    // стандартный конструктор без параметров

    public Company() { }



    public Company(string name) => Name = name;

}

public class Person

{

    public string Name { get; set; } = "Undefined";

    public int Age { get; set; } = 1;

    public Company Company { get; set; } = new Company();



    public Person() { }

    public Person(string name, int age, Company company)

    {

        Name = name;

        Age = age;

        Company = company;

    }

}
```

у `Person` есть свойство `Company`, и оно хранит объект класса `Company`. члены `Company` объявлены как `public`, и у класса есть конструктор без параметров, поэтому вложенный объект входит в граф сериализации. инициализатор `= new Company()` задаёт значение по умолчанию для того случая, когда свойство ещё не заполнено программой. после сериализации получается такой xml-документ:

```xml


<?xml version="1.0"?>

<ArrayOfPerson xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns:xsd="http://www.w3.org/2001/XMLSchema">

  <Person>

    <Name>Tom</Name>

    <Age>37</Age>

    <Company>

      <Name>Microsoft</Name>

    </Company>

  </Person>

  <Person>

    <Name>Bob</Name>

    <Age>41</Age>

    <Company>

      <Name>Google</Name>

    </Company>

  </Person>

</ArrayOfPerson>
```

для массива корневой элемент по соглашению сериализатора называется `ArrayOfPerson`: префикс `ArrayOf` и имя типа элемента. каждый элемент массива становится элементом `Person`, а вложенный `Company` становится одноимённым дочерним элементом со своим `Name`.
