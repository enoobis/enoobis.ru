конструкция `switch` вычисляет выражение и сравнивает его значение с набором констант. при совпадении выполняется соответствующая ветвь.

формальная схема:

```c#


switch (выражение)

{

    case значение1:

        код,выполняемый если выражение имеет значение1

        break;

    case значение2:

        код,выполняемый если выражение имеет значение2

        break;

	//.............

	case значениеN:

        код, выполняемый если выражение имеет значениеN

        break;

    default:

        код, выполняемый если выражение не имеет ни одно из выше указанных значений

        break;

}
```

после `switch` в скобках стоит дискриминант. его значение последовательно сравнивается со значениями после `case`. при первом совпадении выполняется тело этой ветви.

в конце каждой ветви `case` обязателен оператор перехода: `break`, `goto case`, `return` или `throw`. обычно ставят `break`. после него остальные ветви `case` не выполняются. неявного провала в следующую ветвь, как в c, здесь нет: без оператора перехода код не компилируется. это устраняет класс ошибок, когда пропущенный `break` молча присоединяет соседнюю ветвь.

пример:

```c#




string name = "Tom";



switch (name)

{

    case "Bob":

        Console.WriteLine("Ваше имя - Bob");

        break;

    case "Tom":

        Console.WriteLine("Ваше имя - Tom");

        break;

    case "Sam":

        Console.WriteLine("Ваше имя - Sam");

        break;

}
```

`switch` сравнивает значение `name` со строками после `case`. значение `name` равно `"Tom"`, поэтому выполняется ветвь

```c#


case "Tom":

	Console.WriteLine("Ваше имя - Tom");

	break;
```

на консоль выводится

```bash
Ваше имя - Tom
```

если `name` не совпадает ни с одним значением после `case`, ни одна ветвь не выполняется. чтобы в этой ситуации всё же выполнить действие, в `switch` добавляют необязательную ветвь `default`.

```c#


string name = "Alex";



switch (name)

{

    case "Bob":

        Console.WriteLine("Ваше имя - Bob");

        break;

    case "Tom":

        Console.WriteLine("Ваше имя - Tom");

        break;

    case "Sam":

        Console.WriteLine("Ваше имя - Sam");

        break;

    default:

        Console.WriteLine("Неизвестное имя");

        break;

}
```

ни одна константа после `case` не равна значению `name`, поэтому выполняется `default`:

```c#


default:

	Console.WriteLine("Неизвестное имя");

	break;
```

если после текущей ветви нужно выполнить другую, вместо `break` записывают `goto case`:

```c#


int number = 1;

switch (number)

{

    case 1:

        Console.WriteLine("case 1");

        goto case 5; // переход к case 5

    case 3:

        Console.WriteLine("case 3");

        break;

    case 5:

        Console.WriteLine("case 5");

        break;

	default:

        Console.WriteLine("default");

        break;

}
```

при `number`, равном 1, печатается текст первой ветви, затем управление переходит к ветви `case 5`, и печатается её текст. ветвь `case 3` при этом не выполняется: переход адресный, а не последовательный провал.

### возвращение значения из switch

`switch` может завершать метод и возвращать значение. в ветвях `case` для этого ставится `return`. метод:

```c#


int DoOperation(int op, int a, int b)

{

	switch (op)

	{

		case 1: return a + b;

		case 2: return a - b;

		case 3: return a * b;

		default: return 0;

	}

}
```

в `DoOperation` передаётся числовой код операции и два операнда. по коду над операндами выполняется сложение, вычитание или умножение, и результат возвращается из метода. если код не равен 1, 2 или 3, ветвь `default` возвращает 0. каждая ветвь обязана передать управление наружу, здесь это делает `return`, поэтому отдельный `break` не нужен.

вызов метода:

```c#


int DoOperation(int op, int a, int b)

{

	switch (op)

	{

		case 1: return a + b;

		case 2: return a - b;

		case 3: return a * b;

		default: return 0;

	}

}



int result1 = DoOperation(1, 10, 5); // 15

Console.WriteLine(result1);         // 15



int result2 = DoOperation(3, 10, 5); // 50

Console.WriteLine(result2);         // 50
```

### получение результата из switch

тот же выбор можно записать выражением `switch`, которое само является значением, а не оператором.

```c#


int DoOperation(int op, int a, int b)

{

	int result = op switch {

		1 => a + b,

		2 => a - b,

		3 => a * b,

		_ => 0

	};

	return result;

}
```

метки `case` в этой форме не пишутся. после сравниваемого значения стоит стрелка `=>`. выражение справа от стрелки и есть результат ветви. вместо `default` используется шаблон отбрасывания `_`: он сопоставляется с любым ещё не покрытым значением. результат всего выражения присваивается переменной `result`.

результат выражения можно сразу вернуть из метода, без промежуточной переменной:

```c#


int DoOperation(int op, int a, int b)

{

	return op switch

	{

		1 => a + b,

		2 => a - b,

		3 => a * b,

		_ => 0

	};

}
```

ещё более короткая запись выносит выражение в тело, заданное стрелкой:

```c#


int DoOperation(int op, int a, int b) => op switch

{

	1 => a + b,

	2 => a - b,

	3 => a * b,

	_ => 0

};
```

такое сокращение относится только к тем конструкциям `switch`, которые возвращают значение. оператор `switch`, который лишь выполняет действия и ничего не возвращает, в выражение со стрелками сам по себе не превращается.

при возврате значения из метода значение должно получаться при любом входе. следующая версия не компилируется:

```c#


int DoOperation(int op, int a, int b)

{

	return op switch

	{

		1 => a + b,

		2 => a - b,

		3 => a * b

	};

}
```

метод возвращает значение, если код операции равен 1, 2 или 3. для любого другого кода, например 4, ветви нет. выражение `switch` обязано быть исчерпывающим: компилятор проверяет, что каждая возможная величина дискриминанта сопоставлена какой-то ветви. для `int` перечислить все значения невозможно, поэтому нужна ветвь по умолчанию. её роль выполняет `_` или, в операторе `switch`, ветвь `default`, и тогда возврат определён для всех остальных кодов.
