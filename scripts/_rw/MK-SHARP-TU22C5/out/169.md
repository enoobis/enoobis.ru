большая часть задач программирования затрагивает файловую систему. программе нужно прочитать текст, записать данные, удалить один файл или целый каталог, а в более крупной задаче, например в текстовом редакторе, такие операции составляют саму работу программы. платформа .net собирает средства файлового ввода-вывода в пространстве имён `System.IO`. типы этого пространства, в том числе `Stream`, `StreamWriter` и `FileStream`, задают чтение и запись байтов и символов.

обзор начинается с верхнего уровня иерархии, с логических дисков. логический диск описывает класс `DriveInfo` из `System.IO`. экземпляр соответствует тому, который операционная система показывает программе: разделу диска, съёмному носителю или сетевому ресурсу.

статический метод `GetDrives()` возвращает массив `DriveInfo`, по одному экземпляру на каждый логический диск машины. имя диска лежит в свойстве этого экземпляра. остальные сведения читаются оттуда же:

- `AvailableFreeSpace`: объём свободного места, доступного текущему пользователю, в байтах. если на томе действует квота, величина меньше полного свободного места
- `DriveFormat`: имя файловой системы тома
- `DriveType`: тип диска. значение одноимённого перечисления: фиксированный диск, съёмный, сетевой и другие виды
- `IsReady`: готов ли носитель. у dvd-привода значение ложно, пока диск не вставлен, и тогда размер и метка недоступны
- `Name`: имя диска
- `RootDirectory`: корневой каталог диска, объект `DirectoryInfo`
- `TotalFreeSpace`: общий объём свободного места на диске в байтах, без вычета пользовательской квоты
- `TotalSize`: общий размер диска в байтах
- `VolumeLabel`: метка тома. свойство доступно и для чтения, и для записи

следующий фрагмент обходит все логические диски и печатает имя и тип. объём, свободное место и метка читаются только при истинном `IsReady`: у неготового носителя этих данных нет, и обращение к ним завершается исключением. метод `GetDrives()` возвращает и неготовые диски, поэтому проверка стоит внутри цикла, а не до него.

```c#


DriveInfo[] drives = DriveInfo.GetDrives();



foreach (DriveInfo drive in drives)

{

    Console.WriteLine($"Название: {drive.Name}");

    Console.WriteLine($"Тип: {drive.DriveType}");

    if (drive.IsReady)

    {

        Console.WriteLine($"Объем диска: {drive.TotalSize}");

        Console.WriteLine($"Свободное пространство: {drive.TotalFreeSpace}");

        Console.WriteLine($"Метка диска: {drive.VolumeLabel}");

    }

    Console.WriteLine();

}
```

числа в выводе суть размеры в байтах на той машине, где выполнялся фрагмент. набор дисков, типы и метки зависят от конфигурации системы.
