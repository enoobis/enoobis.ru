текст поверх байтового потока читают и пишут отдельные классы пространства `System.IO`: `StreamWriter` и `StreamReader`. они держат кодировку и переводят между символами и байтами. `FileStream` под ними остаётся потоком байтов.

### запись в файл и `StreamWriter`

для записи текста служит `StreamWriter`. экземпляр создаётся одним из конструкторов:

- `StreamWriter(string path)`: аргумент `path` задаёт файл, с которым связывается поток
- `StreamWriter(string path, bool append)`: аргумент `append` выбирает режим. при `true` новые данные дописываются в конец файла. при `false` файл записывается заново
- `StreamWriter(string path, bool append, System.Text.Encoding encoding)`: аргумент `encoding` задаёт кодировку записи

запись идёт такими методами:

- `Close()`: закрывает файл и освобождает ресурсы. метод не возвращает значение и, как у `FileStream`, внутри вызывает `Dispose`
- `void Flush()`: записывает в файл данные, ещё лежащие в буфере, и очищает буфер. без сброса хвост текста может остаться в памяти процесса
- `Task FlushAsync()`: асинхронная версия `Flush`
- `void Write(string value)`: записывает значение. есть перегрузки для элементарных типов, в том числе `Write(char value)`, `Write(int value)`, `Write(double value)`. число при этом форматируется в десятичный текст. двоичное представление `BinaryWriter` этот вызов не использует
- `Task WriteAsync(string value)`: асинхронная версия `Write`. асинхронные перегрузки есть не у всех вариантов `Write`
- `void WriteLine(string value)`: записывает данные и после них символ конца строки
- `Task WriteLineAsync(string value)`: асинхронная версия `WriteLine`

пример записи:

```c#


string path = "note1.txt";

string text = "Hello World\nHello  enoobis.COM";



// полная перезапись файла 

using (StreamWriter writer = new StreamWriter(path, false))

{

    await writer.WriteLineAsync(text);

}

// добавление в файл

using (StreamWriter writer = new StreamWriter(path, true))

{

    await writer.WriteLineAsync("Addition");

    await writer.WriteAsync("4,5");

}
```

фрагмент создаёт `StreamWriter` дважды. первый конструктор получает `append` равный `false`: существующий файл перезаписывается, отсутствующий создаётся, и в него уходит текст из переменной `text`. внутри этого текста уже есть `\n`, а `WriteLineAsync` добавляет ещё один конец строки после всего значения. второй конструктор получает `true` и открывает файл для дописывания. `WriteLineAsync` записывает строку `Addition` и конец строки, `WriteAsync` записывает символы `4,5` без дополнительного конца строки. в файл попадают четыре символа. двоичное представление числа этот вызов не пишет.

по завершении в текущем каталоге процесса лежит файл `note1.txt`. его строки:

```consoletext


Hello World

Hello  enoobis.COM

Addition

4,5
```

конструктор без явной кодировки пишет в utf-8. кодировку можно передать третьим аргументом. во фрагменте это `System.Text.Encoding.Default`, которое в текущей .net тоже обозначает utf-8, а сам параметр показывает, куда подставляется другая кодировка, если она нужна:

```c#


using (StreamWriter writer = new StreamWriter(path, true, System.Text.Encoding.Default))

{

    // операции с writer

}
```

### чтение из файла и `StreamReader`

`StreamReader` читает из текстового файла весь текст или отдельные строки. часть конструкторов:

- `StreamReader(string path)`: аргумент `path` задаёт читаемый файл
- `StreamReader(string path, System.Text.Encoding encoding)`: аргумент `encoding` задаёт кодировку, которой байты файла переводятся в символы. она должна совпадать с кодировкой записи, иначе коды символов разойдутся

часть методов:

- `void Close()`: закрывает файл и освобождает ресурсы
- `int Peek()`: возвращает следующий доступный символ и не сдвигает позицию. если символов больше нет, возвращает -1
- `int Read()`: читает следующий символ и возвращает его код. есть перегрузка `Read(char[] array, int index, int count)`, где `array` принимает прочитанные символы, `index` задаёт индекс в `array`, с которого они записываются, а `count` ограничивает число символов
- `Task ReadAsync()`: асинхронная версия `Read`
- `string ReadLine()`: читает одну строку. символы перевода строки в результат не входят
- `string ReadLineAsync()`: асинхронная версия `ReadLine`
- `string ReadToEnd()`: читает весь оставшийся текст файла
- `string ReadToEndAsync()`: асинхронная версия `ReadToEnd`

чтение всего ранее записанного файла:

```c#


string path = "note1.txt";

// асинхронное чтение

using (StreamReader reader = new StreamReader(path))

{

    string text = await reader.ReadToEndAsync();

    Console.WriteLine(text);

}
```

`ReadToEndAsync` забирает текст от текущей позиции до конца одной строкой, вместе с переводами строк.

построчное чтение:

```c#


string path = "/Users/eugene/Documents/app/note1.txt";



// асинхронное чтение

using (StreamReader reader = new StreamReader(path))

{

	string? line;

	while ((line = await reader.ReadLineAsync()) != null)

	{

		Console.WriteLine(line);

	}

}
```

цикл `while ((line = await reader.ReadLineAsync()) != null)` устроен так. сначала переменной `line` присваивается результат `reader.ReadLineAsync()`, затем результат сравнивается с `null`. когда `reader` доходит до конца файла и строк больше нет, `ReadLineAsync` возвращает `null`, и цикл останавливается. тело цикла печатает уже прочитанную строку.
