для форматирования вывода дат и времени применяются стандартные строки формата и настраиваемые описатели. стандартный описатель состоит из одного символа. регистр различает полный и краткий вариант: `D` и `d` задают разные форматы. названия, порядок компонентов и разделители берутся из `CultureInfo.CurrentCulture`. часть описателей дополнительно зависит от часового пояса и от `DateTimeKind`.

| описатель | описание |
| --- | --- |
| `D` | полный формат даты. например, 17 июля 2015 г. |
| `d` | краткий формат даты. например, 17.07.2015 |
| `F` | полный формат даты и времени. например, 17 июля 2015 г. 17:04:43 |
| `f` | полный формат даты и краткий формат времени. например, 17 июля 2015 г. 17:04 |
| `G` | краткий формат даты и полный формат времени. например, 17.07.2015 17:04:43 |
| `g` | краткий формат даты и времени. например, 17.07.2015 17:04 |
| `M`, `m` | формат дня и месяца. например, 17 июля |
| `O`, `o` | формат обратного преобразования даты и времени. вывод по стандарту iso 8601 шаблоном `yyyy'-'MM'-'dd'T'HH':'mm':'ss'.'fffffffzzz`. например, `2015-07-17T17:04:43.4092892+03:00` |
| `R`, `r` | время по гринвичу, форма rfc 1123. например, `Fri, 17 Jul 2015 17:04:43 GMT` |
| `s` | сортируемый формат даты и времени. например, `2015-07-17T17:04:43` |
| `T` | полный формат времени. например, 17:04:43 |
| `t` | краткий формат времени. например, 17:04 |
| `U` | полный универсальный формат даты и времени. например, 17 июля 2015 г. 17:04:43 |
| `u` | краткий универсальный формат даты и времени. например, `2015-07-17 17:04:43Z` |
| `Y`, `y` | формат месяца и года. например, `Июль 2015` |

текущие дата и время выводятся во всех перечисленных форматах. стандартный описатель передаётся в `ToString` либо записывается после двоеточия в интерполяции: `$"{now:f}"` вызывает тот же формат, что и `now.ToString("f")`.

```c#


DateTime now = DateTime.Now;



Console.WriteLine($"D: {now.ToString("D")}");

Console.WriteLine($"d: {now.ToString("d")}");

Console.WriteLine($"F: {now.ToString("F")}");

Console.WriteLine($"f: {now:f}");

Console.WriteLine($"G: {now:G}");

Console.WriteLine($"g: {now:g}");

Console.WriteLine($"M: {now:M}");

Console.WriteLine($"O: {now:O}");

Console.WriteLine($"o: {now:o}");

Console.WriteLine($"R: {now:R}");

Console.WriteLine($"s: {now:s}");

Console.WriteLine($"T: {now:T}");

Console.WriteLine($"t: {now:t}");

Console.WriteLine($"U: {now:U}");

Console.WriteLine($"u: {now:u}");

Console.WriteLine($"Y: {now:Y}");
```

консольный вывод ниже получен в культуре ru-ru. момент и смещение взяты из исходного примера, пояс utc+4:

```consoletext


D: 6 января 2022 г.

d: 06.01.2022

F: 6 января 2022 г. 14:45:20

f: 6 января 2022 г. 14:45

G: 06.01.2022 14:45:20

g: 06.01.2022 14:45

M: 6 января

O: 2022-01-06T14:45:20.3942344+04:00

o: 2022-01-06T14:45:20.3942344+04:00

R: Thu, 06 Jan 2022 14:45:20 GMT

s: 2022-01-06T14:45:20

T: 14:45:20

t: 14:45

U: 6 января 2022 г. 10:45:20

u: 2022-01-06 14:45:20Z

Y: январь 2022 г.
```

строка `U` показывает 10:45:20 при локальном времени 14:45:20 и смещении +04:00: перед форматированием значение переводится в utc, затем применяется полный формат текущей культуры. описатели `O` и `o` совпадают. они сохраняют доли секунды и смещение, и строка разбирается обратно в то же значение. описатель `u` дописывает суффикс `Z` к компонентам исходного значения и сам смещение не пересчитывает: в выводе остаётся 14:45:20, хотя суффикс выглядит как метка utc. описатель `s` тоже сортируемый и тоже не переводит значение в utc. у него нет ни смещения, ни суффикса `Z`.

### настройка формата времени и даты

встроенный формат не всегда совпадает с требуемой записью. собственный вид `DateTime` собирается из настраиваемых описателей. в такой строке символ является описателем, и регистр снова значим: `d`, `M` и `m` обозначают разные компоненты. литерал, который не должен читаться как описатель, экранируется кавычками или обратной косой чертой.

| описатель | описание |
| --- | --- |
| `d` | день месяца от 1 до 31. одноразрядное число выводится без начального нуля |
| `dd` | день месяца от 1 до 31. одноразрядное число дополняется начальным нулём |
| `ddd` | сокращённое название дня недели |
| `dddd` | полное название дня недели |
| `f` / `fffffff` | доли секунды. в исходном описании этот ряд назван миллисекундами: число символов `f` задаёт число разрядов. допустимо от одного до семи знаков. семь знаков `f` совпадают с точностью `DateTime`, один тик равен 100 наносекундам |
| `g` | период или эра (например, "н. э.") |
| `h` | часы от 1 до 12. одноразрядное значение не дополняется нулём |
| `hh` | часы от 01 до 12. одноразрядное значение дополняется нулём |
| `H` | часы от 0 до 23. одноразрядное значение не дополняется нулём |
| `HH` | часы от 0 до 23. одноразрядное значение дополняется нулём |
| `K` | часовой пояс. для `Local` выводится смещение, для `Utc` выводится `Z`, для `Unspecified` выводится пустая строка |
| `m` | минуты от 0 до 59. одноразрядное значение не дополняется начальным нулём |
| `mm` | минуты от 0 до 59. одноразрядное значение дополняется начальным нулём |
| `M` | месяц от 1 до 12 |
| `MM` | месяц от 1 до 12. одноразрядный месяц дополняется начальным нулём |
| `MMM` | сокращённое название месяца |
| `MMMM` | полное название месяца |
| `s` | секунды от 0 до 59. одноразрядное значение не дополняется начальным нулём |
| `ss` | секунды от 0 до 59. одноразрядное значение дополняется начальным нулём |
| `t` | первый символ обозначений `AM` и `PM` |
| `tt` | `AM` или `PM` |
| `y` | год одной или двумя цифрами. если в годе больше двух цифр, выводятся две младшие |
| `yy` | год одной или двумя цифрами. если в годе больше двух цифр, выводятся две младшие. если цифра одна, она дополняется начальным нулём |
| `yyy` | год из трёх цифр |
| `yyyy` | год из четырёх цифр |
| `yyyyy` | год из пяти цифр. если цифр меньше пяти, значение дополняется начальными нулями |
| `z` | смещение в часах относительно utc |
| `zz` | смещение в часах относительно utc. одноразрядное смещение дополняется начальным нулём |

два собственных формата: время `hh:mm:ss` и дата `dd.MM.yyyy`.

```c#


DateTime now = DateTime.Now;

Console.WriteLine(now.ToString("hh:mm:ss"));

Console.WriteLine(now.ToString("dd.MM.yyyy"));
```

консольный вывод:

```consoletext


02:46:38

06.01.2022
```

`hh` печатает час в диапазоне 01-12. суточный диапазон 0-23 задаёт описатель `HH`.
