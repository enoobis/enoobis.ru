цикл повторно выполняет тело, пока выполняется условие. в c# четыре формы цикла:

- `for`
- `foreach`
- `while`
- `do...while`

`while` проверяет условие до тела и может не выполнить тело ни разу. `do...while` проверяет условие после тела и выполняет тело хотя бы один раз. `foreach` перебирает элементы коллекции. ниже подробно разобран `for`, затем операторы досрочного выхода и вложенные циклы.

### цикл for

формальное определение цикла `for`:

```c#


for ([действия_до_выполнения_цикла]; [условие]; [действия_после_выполнения])

{

    // действия

}
```

объявление `for` состоит из трех частей, разделенных точкой с запятой.

первая часть выполняется один раз до цикла. обычно здесь объявляют и инициализируют переменные счетчика. переменная, объявленная в этой части, видна в условии, в третьей части и в теле, и не видна после цикла: ее область видимости совпадает с оператором `for`.

вторая часть задает условие продолжения. тело выполняется, пока условие равно `true`. пустое условие трактуется как истинное, и цикл становится бесконечным, пока его не прервет `break` или `return`.

третья часть выполняется после каждой итерации тела, до следующей проверки условия. обычно здесь меняют счетчик.

после заголовка в фигурных скобках стоит тело. одна инструкция может стоять и без скобок.

стандартный цикл `for`:

```c#


for (int i = 1; i < 4; i++)

{

    Console.WriteLine(i);

}
```

первая часть, `int i = 1`, создает переменную `i` и инициализирует ее единицей.

вторая часть, условие `i < 4`, допускает тело, пока счетчик меньше 4. третья часть `i++` увеличивает счетчик после каждой итерации. при `i`, равном 1, 2 и 3, на консоль выводится текущее значение. когда `i` становится равным 4, условие ложно, и цикл завершается.

вывод ниже получен перебором строки `"Tom"` циклом `foreach`: каждый элемент печатается отдельной строкой.

```consoletext


T

o

m
```

переменная, объявленная в `foreach`, должна иметь тип элемента коллекции. элементы строки имеют тип `char`, это символы utf-16, поэтому переменная `c` имеет тип `char`. если тип элемента по тексту коллекции неочевиден, переменную объявляют через `var`: компилятор выводит тип элемента из типа свойства `Current` у перечислителя.

```c#


foreach(var c in "Tom")

{

    Console.WriteLine(c);

}
```

коллекции платформы .net и то, какие из них допускают `foreach`, разбираются отдельно. для `foreach` тип должен предоставлять метод `GetEnumerator`, а перечислитель методы `MoveNext` и `Current`. массив и строка этому правилу удовлетворяют.

### операторы continue и break

`break` завершает ближайший охватывающий цикл, не дожидаясь ложного условия:

```c#


for (int i = 0; i < 9; i++)

{

    if (i == 5)

        break;

    Console.WriteLine(i);

}
```

по условию заголовка цикл продолжался бы, пока `i` не достигнет 9. на итерации со значением 5 выполняется `break`, и цикл завершается. тело успевает выполниться пять раз, для значений 0, 1, 2, 3 и 4. инструкция после `break` в этой итерации не достигается, третья часть заголовка тоже не выполняется:

```consoletext


0

1

2

3

4
```

`continue` не завершает цикл, а пропускает остаток текущей итерации. управление переходит к третьей части `for`, затем снова проверяется условие:

```c#


for (int i = 0; i < 9; i++)

{

    if (i == 5)

        continue;

    Console.WriteLine(i);

}
```

когда счетчик равен 5, `continue` пропускает `Console.WriteLine`, увеличивает `i` и переходит к следующей итерации. число 5 на консоль не попадает:

```consoletext


0

1

2

3

4

6

7

8
```

`break` и `continue` применимы в `for`, `foreach`, `while` и `do...while`. каждый из них относится к ближайшему охватывающему циклу, а не к внешнему.

### вложенные циклы

тело цикла может само содержать цикл:

```c#


for (int i = 1; i < 10; i++)

{

    for (int j = 1; j < 10; j++)

    {

        Console.Write($"{i * j} \t");

    }

    Console.WriteLine();

}
```

внешний цикл `for (int i = 1; i < 10; i++)` задает первый множитель от 1 до 9 включительно. внутренний перебирает второй множитель `j` в том же диапазоне и печатает произведение `i * j` и табуляцию. после внутреннего цикла `Console.WriteLine()` завершает строку. получается таблица умножения: девять строк, в каждой девять произведений.
