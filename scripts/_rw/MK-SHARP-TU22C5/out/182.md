linq to xml позволяет выбирать элементы документа запросом, составленным из оси дерева и операторов linq. исходный файл `people.xml` построен в прошлой теме:

```xml


<?xml version="1.0" encoding="utf-8"?>

<people>

  <person name="Tom">

    <company>Microsoft</company>

    <age>37</age>

  </person>

  <person name="Bob">

    <company>Google</company>

    <age>41</age>

  </person>

</people>
```

обход его элементов печатает значения на консоль:

```c#


using System.Xml.Linq;



XDocument xdoc = XDocument.Load("people.xml");

// получаем корневой узел

XElement? people = xdoc.Element("people");

if (people is not null)

{

    // проходим по всем элементам person

    foreach (XElement person in people.Elements("person"))

    {



        XAttribute? name = person.Attribute("name");

        XElement? company = person.Element("company");

        XElement? age = person.Element("age");



        Console.WriteLine($"Person: {name?.Value}");

        Console.WriteLine($"Company: {company?.Value}");

        Console.WriteLine($"Age: {age?.Value}");



        Console.WriteLine(); //  для разделения при выводе на консоль

    }

}
```

вывод программы:

```consoletext


Person: Tom

Company: Microsoft

Age: 37



Person: Bob

Company: Google

Age: 41
```

работа с уже существующим файлом начинается с загрузки. статический метод `XDocument.Load()` принимает путь к файлу:

```c#
XDocument xdoc = XDocument.Load("people.xml");
```

xml хранит элементы иерархически, поэтому доступ тоже идёт сверху вниз. чтобы получить элементы person, сначала берётся корневой элемент, и уже у него запрашиваются person:

```c#


// получаем корневой узел

XElement? people = xdoc.Element("people");

if (people is not null)

{

    // проходим по всем элементам person

    foreach (XElement person in people.Elements("person"))

    {
```

метод `Element("имя_элемента")` возвращает первый найденный дочерний элемент с таким именем либо `null`, если его нет. метод `Elements("имя_элемента")` возвращает коллекцию одноимённых дочерних элементов. здесь коллекция состоит из элементов person, и её можно перебрать циклом. фрагмент выше обрывается на открытии цикла: это начало того же обхода, который полностью записан в предыдущей программе.

дальше по иерархии читаются атрибуты и вложенные элементы. элемент company у текущего person получается так:

```c#
XElement? company = person.Element("company");
```

значение простого элемента, который содержит только текст, читается свойством `Value`:

```c#
string? companyValue = person.Element("company")?.Value;
```

оператор `?.` оставляет результат пустым, если промежуточный `Element` вернул `null`, и тогда к `Value` обращения нет.

операторы linq вместе с linq to xml записывают выборку и проекцию одним выражением:

```c#


using System.Xml.Linq;



XDocument xdoc = XDocument.Load("people.xml");



var microsoft = xdoc.Element("people")?   // получаем корневой узел people

    .Elements("person")             // получаем все элементы person

    // получаем все person, у которого company = Microsoft

    .Where(p => p.Element("company")?.Value == "Microsoft")    

    .Select(p => new        // для каждого объекта создаем анонимный объект

    {

      name = p.Attribute("name")?.Value,

      age = p.Element("age")?.Value,

      company = p.Element("company")?.Value

  });



if (microsoft is not null)

{

    foreach (var person in microsoft)

    {

        Console.WriteLine($"Name: {person.name}  Age: {person.age}");

    }

}
```

здесь выбираются все элементы person, у которых вложенный элемент company равен microsoft. по этой выборке строится последовательность анонимных объектов с тремя свойствами: name, age и company. для той же проекции вместо анонимного типа подошли бы отдельный класс или структура. цепочка начинается с `Element("people")?`, поэтому при отсутствии корня всё выражение равно `null`, и цикл печати не выполняется. в печати участвуют имя и возраст.

другой запрос выбирает элемент person, у которого атрибут name равен tom:

```c#


using System.Xml.Linq;



XDocument xdoc = XDocument.Load("people.xml");



var tom = xdoc.Element("people")?   // получаем корневой узел people

    .Elements("person")             // получаем все элементы person

    .FirstOrDefault(p => p.Attribute("name")?.Value == "Tom");



var name = tom?.Attribute("name")?.Value;

var age = tom?.Element("age")?.Value;

var company = tom?.Element("company")?.Value;



Console.WriteLine($"Name: {name}  Age: {age}  Company: {company}");
```

`FirstOrDefault` возвращает первый подходящий элемент либо значение по умолчанию, для ссылочного `XElement` это `null`. дальше имя, возраст и компания читаются через `?.`, так что отсутствие узла tom даёт пустые значения в выводе, а не исключение.
