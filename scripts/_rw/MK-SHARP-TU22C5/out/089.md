анонимный тип создаёт объект с набором свойств без отдельного объявления класса. в исходном тексте он записывается ключевым словом **var** и инициализатором объекта:

```c#

var user = new { Name = "Tom", Age = 34 };
Console.WriteLine(user.Name);
```

`user` является объектом анонимного типа с двумя свойствами, `Name` и `Age`. свойства читаются так же, как у обычного объекта класса. записать их после создания нельзя: свойства анонимного типа доступны только для чтения.

имя типа выбирает компилятор. в программе его записать нельзя, поэтому переменная объявляется через `var`. часто такое имя выглядит как `<>f__AnonymousType0'2`. число после апострофа равно числу свойств: здесь их два. для clr анонимный тип является ссылочным, как и класс. компилятор порождает запечатанный класс, свойства читаются через get-аксессоры, а `Equals` и `GetHashCode` сравнивают объекты по значениям этих свойств.

если несколько анонимных объектов имеют один и тот же набор свойств, совпадают имена, типы и порядок, компилятор использует одно определение типа:

```c#

var user = new { Name = "Tom", Age = 34 };
var student = new { Name = "Alice", Age = 21 };
var manager = new { Name = "Bob", Age = 26, Company = "Microsoft" };

Console.WriteLine(user.GetType().Name); // <>f__AnonymousType0'2
Console.WriteLine(student.GetType().Name); // <>f__AnonymousType0'2
Console.WriteLine(manager.GetType().Name); // <>f__AnonymousType1'3
```

у `user` и `student` одно определение. у `manager` набор другой: добавлено свойство `Company`, и компилятор порождает отдельный тип, что видно по имени `<>f__AnonymousType1'3`. к классу с похожим набором свойств такой объект не приводится. совпадение имён свойств отношения подтипов не создаёт.

значения свойств задаются только в инициализаторе. за его пределами присваивание не компилируется:

```c#

var student = new { Name = "Alice", Age = 21 };
student.Age = 32;   // ! Ошибка
```

помимо инициализатора, в котором каждому свойству явно сопоставлено значение, есть **инициализаторы с проекцией** (projection initializers). в них передаются идентификаторы, и имена этих идентификаторов становятся именами свойств:

```c#

Person tom = new Person("Tom"); 
int age = 34;
var student = new { tom.Name, age }; // инициализатор с проекцией
Console.WriteLine(student.Name);
Console.WriteLine(student.age);

class Person
{
    public string Name { get; set; }
    public Person(string name) => Name = name;
}
```

такое определение совпадает со следующей записью:

```c#
var student = new { Name = tom.Name, age = age};
```

имена `Name` и `age` становятся именами свойств. для простого идентификатора берётся его собственное имя, для доступа к члену берётся имя члена, поэтому `tom.Name` даёт свойство `Name`, а переменная `age` даёт свойство `age`.

массив объектов анонимного типа записывается так же, через `var` и общий инициализатор. все элементы обязаны иметь один и тот же анонимный тип:

```c#

var people = new[]
{
	new {Name="Tom"},
	new {Name="Bob"}
};
foreach(var p in people)
{
	Console.WriteLine(p.Name);
}
```

анонимный тип используют там, где форма нужна в одном узком контексте или однократно. отдельный класс для такой формы избыточен: свойство добавляется прямо в инициализаторе, и другое объявление менять не приходится. обычный повод: результат выборки из базы данных. объекты живут внутри запроса и дальше по программе часто не передаются, так что именованный класс для них ничего не добавляет. анонимный объект хранит такую временную выборку.
