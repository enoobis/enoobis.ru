### константы класса

помимо полей класс может хранить данные в константах. значение константы задаётся один раз, прямо в объявлении, и впоследствии не меняется. константа описывает тип в целом и не привязана к отдельному экземпляру: обращение идёт через имя класса, а имя объекта для этого не используется.

```c#


Person tom = new Person();

tom.name = "Tom";

tom.Print();    // Person: Tom



Console.WriteLine(Person.type); // Person

// Person.type = "User"; 	// !Ошибка: изменить константу нельзя



class Person

{

    public const string type = "Person";

    public string name = "Undefined";

    public void Print() => Console.WriteLine($"{type}: {name}");

}
```

в классе `Person` объявлена константа `type`. в ней записано название класса:

```c#
public const string type = "Person";
```

название класса не зависит от объекта. сколько бы экземпляров `Person` ни было создано, это название остаётся общим для всех них и меняться не должно. поэтому его сохраняют в константе.

константе необходимо присвоить значение уже в определении. константа вычисляется во время компиляции, и компилятор принимает только константное выражение: литералы встроенных числовых типов, `bool`, `char`, `string`, значение перечисления. выражения, которое станет известно лишь во время выполнения, в константе быть не может.

внутри класса к константе обращаются так же, как к полю. в методе `Print` значение `type` выводится на консоль вместе с именем объекта.

вне класса для обращения требуется имя типа:

```c#
Console.WriteLine(Person.type); // Person
```

константа неявно статическая: отдельного значения на каждый экземпляр у неё нет, и модификатор `static` указывать нельзя. если нужны данные, которые относятся ко всему классу и известны до запуска программы, для них используется константа. компилятор подставляет значение в каждое место использования, поэтому изменение константы в уже собранной библиотеке увидят только те сборки, которые перекомпилированы против новой версии.

### поля для чтения и модификатор readonly

поле для чтения является полем класса или структуры, значение которого после инициализации не меняют. присвоить его можно при объявлении либо в конструкторе. в остальных местах программы допустимо только чтение.

такое поле объявляется модификатором `readonly`:

```c#


Person tom = new Person("Tom");

Console.WriteLine(tom.name);



//tom.name = "Sam"; // !Ошибка: нельзя изменить

class Person

{

    public readonly string name = "Undefined"; // можно так инициализировать

    public Person(string name)

    {

        this.name = name; // в конструкторе также можно присвоить значение полю для чтения

    }

    public void ChangeName(string otherName)

    {

        //this.name = otherName;    // так нельзя 

    }

}
```

поле `name` хранит имя пользователя и объявлено для чтения. значение можно задать прямо в объявлении:

```c#
public readonly string name = "Undefined";
```

либо присвоить его в конструкторе:

```c#


public Person(string name)

{

	this.name = name;

}
```

в любом другом месте, в том числе в методах самого класса `Person`, присваивание полю для чтения запрещено. инициализация происходит во время выполнения: конструктор вправе записать значение, которого не существовало при компиляции. если поле не помечено `static`, у каждого экземпляра хранится собственное значение.

### сравнение констант

- константа определяется во время компиляции, поле для чтения может быть определено во время выполнения. значение константы задаётся только при её определении. поле для чтения инициализируется либо при определении, либо в конструкторе класса

- константа не может использовать модификатор `static`, поскольку уже неявно является статической. поле для чтения может быть как статическим, так и нестатическим

### структуры для чтения

помимо полей для чтения в c# определяются структуры для чтения. объявление предваряется модификатором `readonly`:

```c#


readonly struct Person { }
```

все поля такой структуры тоже обязаны быть полями для чтения:

```c#


readonly struct Person

{

	public readonly string name;

	public Person(string name)

	{

		this.name = name;

	}

}
```

то же требование относится к свойствам: они доступны только для чтения.

```c#


readonly struct Person

{

	public readonly string Name { get; } // указывать readonly необязательно

	public int Age { get; } // свойство только для чтения

	public Person(string name, int age)

	{

		Name = name;

		Age = age;

	}

}
```

`readonly struct` задаёт инвариант неизменяемости: после завершения конструктора состояние экземпляра не меняется. компилятор считает `this` в экземплярных членах доступным только для чтения. благодаря этому при вызове членов структуры из readonly-контекста можно обойтись без защитной копии. модификатор `readonly` у автосвойства внутри такой структуры необязателен. отсутствие сеттера уже делает свойство неизменяемым, что видно по объявлению `Age` рядом с `Name`.
