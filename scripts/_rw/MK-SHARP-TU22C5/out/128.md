класс **Mutex**, мьютекс, задаёт взаимное исключение потоков и расположен в пространстве имён `System.Threading`. неименованный экземпляр виден внутри одного процесса. конструктор с именем публикует объект ядра под этим именем, и тогда тот же мьютекс открывают другие процессы. у мьютекса есть поток-владелец: `ReleaseMutex` обязан вызвать тот поток, который получил владение через `WaitOne`. если владелец завершается, не освободив мьютекс, следующий ожидающий получает `AbandonedMutexException` и вместе с ним само владение, чтобы инвариант общего ресурса можно было восстановить.

пример с оператором `lock` из предыдущей темы:

```c#


int x = 0;

object locker = new();  // объект-заглушка

// запускаем пять потоков

for (int i = 1; i < 6; i++)

{

    Thread myThread = new(Print);

    myThread.Name = $"Поток {i}";

    myThread.Start();

}





void Print()

{

    lock (locker)

    {

        x = 1;

        for (int i = 1; i < 6; i++)

        {

            Console.WriteLine($"{Thread.CurrentThread.Name}: {x}");

            x++;

            Thread.Sleep(100);

        }

    }

}
```

тот же протокол на мьютексе:

```c#


int x = 0;

Mutex mutexObj = new();



// запускаем пять потоков

for (int i = 1; i < 6; i++)

{

    Thread myThread = new(Print);

    myThread.Name = $"Поток {i}";

    myThread.Start(); 

}



void Print()

{

    mutexObj.WaitOne();     // приостанавливаем поток до получения мьютекса

    x = 1;

    for (int i = 1; i < 6; i++)

    {

        Console.WriteLine($"{Thread.CurrentThread.Name}: {x}");

        x++;

        Thread.Sleep(100);

    }

    mutexObj.ReleaseMutex();    // освобождаем мьютекс

}
```

объект создаётся конструктором без параметров, то есть свободным и без имени:

```c#
Mutex mutexObj = new Mutex()
```

основную работу выполняют `WaitOne()` и `ReleaseMutex()`. вызов `mutexObj.WaitOne()` приостанавливает поток, пока мьютекс `mutexObj` не будет получен. свободный мьютекс отдаётся вызывающему потоку сразу, и этот поток становится владельцем. занятый мьютекс оставляет поток в очереди ожидания.

изначально мьютекс свободен, поэтому его забирает один из пяти потоков.

когда работа с общим `x` закончена, поток отдаёт владение через `mutexObj.ReleaseMutex()`. мьютекс переходит к одному из ожидающих. вызов `ReleaseMutex` из потока, который владельцем не является, завершается исключением `ApplicationException`.

на строке `mutexObj.WaitOne()` поток ждёт освобождения и только после получения владения выполняет присваивание и цикл. участок от `WaitOne` до `ReleaseMutex` является критической секцией: одновременно его исполняет не больше одного потока. повторный `WaitOne` того же владельца увеличивает счётчик владения, и столько же раз требуется `ReleaseMutex`, прежде чем мьютекс станет доступен другим. оператор `lock` такого раздельного ожидания и освобождения из другого места программы не выражает: `Enter` и `Exit` связаны одним блоком.
