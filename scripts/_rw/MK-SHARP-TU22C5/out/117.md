для дат без времени суток и для времени суток без календарной даты в .net 6 добавлены структуры `DateOnly` и `TimeOnly`. они снимают с `DateTime` роль контейнера, в котором одна из частей всегда фиктивна: полночь у чистой даты или дата-заглушка у чистого времени. обе структуры неизменяемы, как и `DateTime`: операции возвращают новое значение.

### dateonly

структура `DateOnly` представляет дату. экземпляр создаётся одной из перегрузок конструктора.

```c#


DateOnly()

DateOnly(int year, int month, int day)

DateOnly(int year, int month, int day, System.Globalization.Calendar calendar)
```

конструктор без параметров инициализирует структуру датой 01.01.0001, то есть минимальной датой григорианского диапазона .net:

```c#


DateOnly someDate = new DateOnly();

Console.WriteLine(someDate); // 01.01.0001
```

вторая перегрузка принимает год, месяц и день:

```c#


DateOnly someDate = new DateOnly(2022,1,6); // 6 января 2022 года

Console.WriteLine(someDate); // 06.01.2022
```

третья перегрузка кроме года, месяца и дня принимает календарь: объект `System.Globalization.Calendar`, в системе которого интерпретируются эти три числа. класс `Calendar` абстрактный. .net предоставляет готовые наследники для разных календарных систем. дата относительно юлианского календаря задаётся так:

```c#


using System.Globalization;



DateOnly julianDate = new DateOnly(2022,1,6, new JulianCalendar());

Console.WriteLine(julianDate); // 19.01.2022
```

компоненты 2022, 1 и 6 здесь читаются как дата юлианского календаря. `DateOnly` хранит номер дня в пролептическом григорианском календаре, поэтому при выводе получается тот же день в григорианской записи. в xx и xxi веках разница юлианского и григорианского календарей составляет 13 суток, и 6 января 2022 года по юлианскому календарю приходится на 19 января 2022 года по григорианскому. отсюда вывод `19.01.2022`.

#### свойства dateonly

свойства выделяют компоненты даты:

- `Day`: день месяца
- `DayNumber`: число суток, прошедших с 1 января 0001 года по григорианскому календарю. это внутреннее представление значения, по нему даты сравниваются и вычитаются как целые
- `DayOfWeek`: день недели
- `DayOfYear`: день года, от 1 до 365 или 366
- `MaxValue`: максимально возможная дата. статическое свойство
- `MinValue`: самая ранняя возможная дата. статическое свойство
- `Month`: месяц
- `Year`: год

применение свойств:

```c#


DateOnly now = new DateOnly(2022,1,6);

Console.WriteLine(now.Day);         // 6

Console.WriteLine(now.DayNumber);   // 738160

Console.WriteLine(now.DayOfWeek);   // Thursday

Console.WriteLine(now.DayOfYear);   // 6

Console.WriteLine(now.Month);       // 1

Console.WriteLine(now.Year);        // 2022
```

#### методы dateonly

методы выполняют арифметику дат и преобразование в строку и в `DateTime`. часть из них:

- `AddDays(int days)`: добавляет к дате указанное число дней. отрицательный аргумент сдвигает дату назад
- `AddMonths(int months)`: добавляет месяцы
- `AddYears(int years)`: добавляет годы
- `ToDateTime(TimeOnly)`: возвращает `DateTime`, у которого календарная дата берётся из текущего `DateOnly`, а время суток из аргумента `TimeOnly`
- `ToLongDateString()`: подробная запись даты по шаблону длинной даты текущей культуры
- `ToShortDateString()`: сжатая запись даты по шаблону короткой даты текущей культуры

у структуры есть и статические методы. часть из них:

- `FromDateTime(DateTime dateTime)`: по значению `DateTime` создаёт `DateOnly`, время суток отбрасывается
- `FromDayNumber(int days)`: по числу суток с 1 января 0001 года создаёт `DateOnly`. операция, обратная свойству `DayNumber`
- `Parse(string date)`: разбирает строковое представление даты в `DateOnly` по правилам текущей культуры
- `ParseExact(string date, string format)`: разбирает строку в `DateOnly` по явно заданному формату
- `TryParse(String, DateOnly)`: разбирает строку в `DateOnly`. при успехе возвращает `true`, а выходной параметр получает созданную дату. при неудаче исключения нет, метод возвращает `false`
- `TryParseExact(String, String, DateOnly)`: то же с явным форматом. при успехе возвращает `true`, а параметр типа `DateOnly` получает созданную дату

пример нескольких операций. разбор строки зависит от локали: комментарий в коде относит формат "06.01.2022" к русскоязычной операционной системе, где короткий шаблон даты использует такой порядок и точку в качестве разделителя.

```c#


DateOnly now = DateOnly.Parse("06.01.2022");    // на русскоязычной локализованной ОС

Console.WriteLine(now); // 06.01.2022

now = now.AddDays(1);   // 07.01.2022

now = now.AddMonths(4); // 07.05.2022

now = now.AddYears(-1); // 07.05.2021

Console.WriteLine(now.ToShortDateString());  // 07.05.2021

Console.WriteLine(now.ToLongDateString());   // 7 мая 2021 г.
```

### timeonly

структура `TimeOnly` представляет время суток в диапазоне от 00:00:00 до 23:59:59.9999999. верхняя граница совпадает с максимальной точностью тика внутри суток. экземпляр создаётся одной из перегрузок конструктора.

```c#


TimeOnly()

TimeOnly(long ticks)

TimeOnly(int hour, int minute)

TimeOnly(int hour, int minute, int second)

TimeOnly(int hour, int minute, int second, int millisecond)
```

конструктор без параметров инициализирует структуру временем 0:00, то есть полуночью:

```c#


TimeOnly time = new TimeOnly();

Console.WriteLine(time); // 0:00
```

остальные перегрузки задают часы и минуты, а при необходимости ещё секунды и миллисекунды. перегрузка с аргументом `long` задаёт время числом тиков от полуночи.

```c#


TimeOnly time1 = new TimeOnly(4, 30);

Console.WriteLine(time1);   // 4: 30



TimeOnly time2 = new TimeOnly(14, 23, 30);

Console.WriteLine(time2);   // 14: 23
```

#### свойства timeonly

свойства выделяют компоненты времени:

- `Hour`: часы
- `Minute`: минуты
- `Second`: секунды
- `Millisecond`: миллисекунды
- `Ticks`: число тиков от полуночи
- `MaxValue`: максимально возможное время. статическое свойство
- `MinValue`: минимально возможное время, полночь. статическое свойство

применение свойств:

```c#


TimeOnly time = new TimeOnly(14, 23, 30);

Console.WriteLine(time.Hour);       // 14

Console.WriteLine(time.Minute);     // 23

Console.WriteLine(time.Second);     // 30
```

#### методы timeonly

методы сдвигают время и форматируют его. часть из них:

- `AddHours(double hours)`: добавляет часы. дробная часть переводится в минуты и более мелкие единицы. переход через полночь оставляет результат внутри одних суток
- `AddMinutes(double minutes)`: добавляет минуты
- `Add(TimeSpan value)`: добавляет интервал из `TimeSpan`
- `ToLongTimeString()`: подробная запись времени по шаблону длинного времени текущей культуры
- `ToShortTimeString()`: сжатая запись времени по шаблону короткого времени текущей культуры

статические методы, часть перечня:

- `FromDateTime(DateTime dateTime)`: по значению `DateTime` создаёт `TimeOnly`, календарная дата отбрасывается
- `FromTimeSpan(TimeSpan value)`: по `TimeSpan` создаёт `TimeOnly`
- `Parse(string time)`: разбирает строковое представление времени в `TimeOnly`
- `ParseExact(string, string)`: разбирает строку в `TimeOnly` по заданному формату
- `TryParse(string time, TimeOnly result)`: разбирает строку в `TimeOnly`. при успехе возвращает `true`, а параметр `result` получает разобранное время
- `TryParseExact(string time, string format, TimeOnly result)`: то же с явным форматом. при успехе возвращает `true`, а параметр типа `TimeOnly` получает разобранное время

пример нескольких операций:

```c#


TimeOnly time = TimeOnly.Parse("06:33:22");

Console.WriteLine(time);        // 6:33

time = time.AddHours(1);        // 7:33

time = time.AddMinutes(-23);   // 7:10



Console.WriteLine(time.ToShortTimeString());  // 7:10

Console.WriteLine(time.ToLongTimeString());   // 7:10:22
```
