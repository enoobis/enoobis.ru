отдельная группа операций дает условные выражения. результат имеет тип `bool`: `true`, если условие выполняется, и `false` в противном случае. в c# число не преобразуется в `bool` неявно, поэтому условие всегда строится сравнением или логической операцией. сюда входят операции сравнения и логические операции.

### операции сравнения

операция сравнения сопоставляет два операнда и возвращает `bool`: `true`, если отношение выполняется, и `false`, если не выполняется.

- `==` сравнивает два операнда на равенство. при равенстве возвращается `true`, иначе `false`:

```c#


int a = 10;

int b = 4;

bool c = a == b; // false
```

- `!=` сравнивает два операнда и возвращает `true`, если они не равны, и `false`, если равны:

```c#


int a = 10;

int b = 4;

bool c = a != b; 	// true

bool d = a!=10;		// false
```

- `>` операция "больше чем". возвращает `true`, если первый операнд больше второго, иначе `false`:

```c#


int a = 10;

int b = 4;

bool c = a > b;     // true

bool d = a > 25;    // false
```

- `>=` операция "больше или равно". возвращает `true`, если первый операнд больше второго или равен ему, иначе `false`:

```c#


int a = 10;

int b = 4;

bool c = a >= b;     // true

bool d = a >= 25;    // false
```

операции `<`, `>`, `<=` и `>=` имеют приоритет выше, чем `==` и `!=`. отношение вычисляется раньше проверки равенства.

### логические операции

логические операторы тоже возвращают `bool` и принимают операнды типа `bool`. обычно их ставят между отношениями и собирают из нескольких сравнений одно условие.

приоритет среди операторов этой лекции, от высокого к низкому: унарное `!`, затем отношения `<`, `>`, `<=`, `>=`, затем равенство `==` и `!=`, затем `&`, затем `^`, затем `|`, затем `&&`, затем `||`.

- `|` логическое сложение, логическое или. возвращает `true`, если хотя бы один операнд равен `true`. вычисляются оба операнда:

```c#


bool x1 = (5 > 6) | (4 < 6); // 5 > 6 - false, 4 < 6 - true, поэтому возвращается true

bool x2 = (5 > 6) | (4 > 6); // 5 > 6 - false, 4 > 6 - false, поэтому возвращается false
```

- `&` логическое умножение, логическое и. возвращает `true`, только если оба операнда одновременно равны `true`. вычисляются оба операнда:

```c#


bool x1 = (5 > 6) & (4 < 6); // 5 > 6 - false, 4 < 6 - true, поэтому возвращается false

bool x2 = (5 < 6) & (4 < 6); // 5 < 6 - true, 4 < 6 - true, поэтому возвращается true
```

- `||` условное логическое или. возвращает `true`, если хотя бы один операнд равен `true`:

```c#


bool x1 = (5 > 6) || (4 < 6); // 5 > 6 - false, 4 < 6 - true, поэтому возвращается true

bool x2 = (5 > 6) || (4 > 6); // 5 > 6 - false, 4 > 6 - false, поэтому возвращается false
```

- `&&` условное логическое и. возвращает `true`, если оба операнда одновременно равны `true`:

```c#


bool x1 = (5 > 6) && (4 < 6); // 5 > 6 - false, 4 < 6 - true, поэтому возвращается false

bool x2 = (5 < 6) && (4 < 6); // 5 < 6 - true, 4 < 6 - true, поэтому возвращается true
```

- `!` логическое отрицание. операция унарная: возвращает `true`, если операнд равен `false`, и `false`, если операнд равен `true`:

```c#


bool a = true;

bool b = !a;    // false
```

- `^` исключающее или. возвращает `true`, если ровно один из двух операндов равен `true`. если оба равны `true` или оба равны `false`, результат `false`. вычисляются оба операнда:

```c#


bool x5 = (5 > 6) ^ (4 < 6); // 5 > 6 - false, 4 < 6 - true, поэтому возвращается true

bool x6 = (50 > 6) ^ (4 / 2 < 3); // 50 > 6 - true, 4/2 < 3 - true, поэтому возвращается false
```

пары `|` и `||`, а также `&` и `&&`, дают одинаковый булев результат на чистых операндах и различаются семантикой вычисления.

в выражении `z=x|y;` вычисляются и `x`, и `y`.

в выражении `z=x||y;` сначала вычисляется `x`. если `x` равно `true`, результат уже определен: дизъюнкция истинна, и `y` не вычисляется. `y` вычисляется только при `x`, равном `false`.

та же развилка у пары `&` и `&&`. в выражении `z=x&y;` вычисляются оба операнда.

в выражении `z=x&&y;` сначала вычисляется `x`. если `x` равно `false`, конъюнкция ложна, и `y` не вычисляется. `y` вычисляется только при `x`, равном `true`.

`||` и `&&` называют сокращенными, или условными, операторами: второй операнд пропускается, когда первый уже фиксирует результат. вместе с ним пропускаются его побочные эффекты, вызов метода и возможное исключение. `|` и `&` над `bool` всегда выполняют оба операнда. те же лексемы над целыми выполняют поразрядные операции и тоже всегда вычисляют оба операнда.
