исходный файл снова `people.xml` из прошлых тем:

```xml


<?xml version="1.0" encoding="utf-8"?>

<people>

  <person name="Tom">

    <company>Microsoft</company>

    <age>37</age>

  </person>

  <person name="Bob">

    <company>Google</company>

    <age>41</age>

  </person>

</people>
```

### добавление данных

добавление в документ xml выполняется методом `Add()` у объекта `XElement`. аргументом передаётся добавляемый узел, здесь целое поддерево person, собранное конструкторами:

```c#


using System.Xml.Linq;



XDocument xdoc = XDocument.Load("people.xml");

XElement? root = xdoc.Element("people");



if(root != null)

{

    // добавляем новый элемент

    root.Add(new XElement("person",

                new XAttribute("name", "Sam"),

                new XElement("company", "JetBrains"),

                new XElement("age", 28)));



    xdoc.Save("people.xml");

}



// выводим xml-документ на консоль

Console.WriteLine(xdoc);
```

в результате формируется и записывается на диск новый документ. `Console.WriteLine(xdoc)` печатает текущее дерево:

```consoletext


<people>

  <person name="Tom">

    <company>Microsoft</company>

    <age>37</age>

  </person>

  <person name="Bob">

    <company>Google</company>

    <age>41</age>

  </person>

  <person name="Sam">

    <company>JetBrains</company>

    <age>28</age>

  </person>

</people>
```

к двум прежним элементам person добавлен элемент с атрибутом name равным sam, компанией jetbrains и возрастом 28. `Save` вызывается только если корневой элемент people найден.

### изменение данных

чтобы изменить данные, сначала находится нужный элемент, затем правятся его атрибуты или вложенные элементы. ниже меняется элемент person, у которого атрибут name равен tom:

```c#


using System.Xml.Linq;



XDocument xdoc = XDocument.Load("people.xml");



// получим элемент person с name = "Tom"

var tom = xdoc.Element("people")?

    .Elements("person")

    .FirstOrDefault(p => p.Attribute("name")?.Value == "Tom");



if(tom != null)

{

    //  меняем атрибут name

    var name = tom.Attribute("name");

    if (name != null) name.Value = "Tomas";





    //  меняем вложенный элемент age

    var age = tom.Element("age");

    if (age != null) age.Value = "22";



    xdoc.Save("people.xml");

}



// выводим xml-документ на консоль

Console.WriteLine(xdoc);
```

снова формируется и записывается документ:

```consoletext


<people>

  <person name="Tomas">

    <company>Microsoft</company>

    <age>22</age>

  </person>

  <person name="Bob">

    <company>Google</company>

    <age>41</age>

  </person>

  <person name="Sam">

    <company>JetBrains</company>

    <age>28</age>

  </person>

</people>
```

атрибут name у найденного узла получает значение tomas, вложенный элемент age получает текст 22. компания этого узла не меняется. элемент sam, добавленный предыдущим шагом, в дереве остаётся: правка идёт по тому же файлу. если атрибут или элемент age отсутствует, соответствующая проверка на `null` пропускает присваивание. `Save` выполняется только когда сам элемент tom найден.

### удаление данных

удаление узла xml выполняется методом `Remove()` у того объекта `XElement`, который нужно убрать из дерева. ниже удаляется элемент person, у которого атрибут name равен bob:

```c#


using System.Xml.Linq;



XDocument xdoc = XDocument.Load("people.xml");

XElement? root = xdoc.Element("people");



if (root != null)

{

    // получим элемент person с name = "Bob"

    var bob = root.Elements("person")

        .FirstOrDefault(p => p.Attribute("name")?.Value == "Bob");

    // и удалим его

    if (bob != null)

    {

        bob.Remove();

        xdoc.Save("people.xml");

    }

}



// выводим xml-документ на консоль

Console.WriteLine(xdoc);
```

документ после удаления снова записывается и печатается:

```consoletext


<people>

  <person name="Tomas">

    <company>Microsoft</company>

    <age>22</age>

  </person>

  <person name="Sam">

    <company>JetBrains</company>

    <age>28</age>

  </person>

</people>
```

`Remove` отсоединяет элемент от родителя. в оставшемся дереве есть tomas и sam, узла bob нет. запись на диск происходит только если bob действительно найден.

если удалять нужно атрибут, метод `Remove` вызывается у соответствующего объекта `XAttribute`. от родительского элемента тогда отсоединяется атрибут, а сам элемент остаётся.
