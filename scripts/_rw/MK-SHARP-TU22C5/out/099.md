в c# массив хранит набор объектов одного типа, но длина массива фиксируется при создании. если число элементов заранее неизвестно или меняется по ходу работы, применяют коллекции. часть коллекций прямо задаёт стандартные структуры данных: стек, очередь, словарь. эти структуры закрывают отдельные задачи доступа, которые массивом выражаются только вручную. большая часть классов коллекций расположена в пространстве имён `System.Collections.Generic`.

класс `List<T>` из этого пространства имён задаёт список объектов одного типа. параметр типа определяет, значения какого типа хранятся в списке. по назначению это простейший список однотипных объектов, по устройству динамический массив: элементы лежат в непрерывном буфере, доступ по индексу занимает постоянное время, а вставка и удаление в середине сдвигают хвост и линейны по числу сдвигаемых элементов.

пустой список создаётся конструктором без элементов:

```c#
List<string> people = new List<string>();
```

здесь параметр типа равен `string`, поэтому хранить в списке можно только строки.

начальные элементы передаются сразу, в фигурных скобках после вызова конструктора. это инициализатор коллекции: перечисленные значения добавляются по порядку.

```c#
List<string> people = new List<string>() { "Tom", "Bob", "Sam" };
```

в список попадают три строки.

конструктор, принимающий `IEnumerable<T>`, копирует элементы другой коллекции, например другого списка:

```c#


var people = new List<string>() { "Tom", "Bob", "Sam" };

var employees = new List<string>(people);
```

оба способа соединяются. элементы источника копирует конструктор, элементы инициализатора добавляются следом:

```c#


var people = new List<string>() { "Tom", "Bob", "Sam" };

var employees = new List<string>(people){"Mike"};
```

в `employees` четыре элемента, `{ "Tom", "Bob", "Sam", "Mike" }`. три приходят из `people`, четвёртый задан при инициализации.

начиная с c# 12 список можно собрать выражением коллекции. элементы заключаются в квадратные скобки, а целевой тип выражения, здесь `List<string>`, определяет, какая коллекция строится. пустые скобки задают пустой список. те же скобки в позиции шаблона, внутри `is` или `switch`, задают списочный шаблон. в позиции выражения они список создают.

```c#


List<string> people = ["Tom", "Bob", "Sam"];

List<string> employees = [];// пустой список
```

так же строятся списки других типов элементов:

```c#


List<Person> people = new List<Person>() 

{ 

    new Person("Tom"),

    new Person("Bob"), 

    new Person("Sam") 

};



class Person

{

    public string Name { get;}

    public Person(string name) => Name = name;

}
```

### установка начальной емкости списка

ещё один конструктор `List<T>` принимает начальную ёмкость:

```c#
List<string> people = new List<string>(16);
```

ёмкость, свойство `Capacity`, задаёт размер внутреннего буфера, а не число уже хранимых элементов. число элементов даёт свойство `Count`. если при добавлении `Count` превышает ёмкость, реализация выделяет новый буфер большего размера и копирует в него старые элементы. когда верхняя граница размера известна, передача её в конструктор убирает эти копирования, пока `Count` не превысит заданную ёмкость. то же значение можно записать позже в свойство `Capacity`.

### обращение к элементам списка

как и массив, список поддерживает индексатор. по индексу элемент читают и заменяют. индекс считается от нуля. обращение вне диапазона индексов порождает исключение:

```c#


var people = new List<string>() { "Tom", "Bob", "Sam" };



string firstPerson = people[0];	// получаем первый элемент

Console.WriteLine(firstPerson); // Tom

people[0] = "Mike";		// изменяем первый элемент

Console.WriteLine(people[0]); // Mike
```

### длина списка

свойство `Count` возвращает число элементов:

```c#


var people = new List<string>() { "Tom", "Bob", "Sam" };

Console.WriteLine(people.Count);    // 3
```

`Count` и `Capacity` расходятся. после трёх добавлений в список без заранее заданной ёмкости `Count` равен 3, а буфер может быть больше.

### перебор списка

список перебирается циклом `foreach`. цикл получает перечислитель и читает элементы по порядку от начала к концу:

```c#


var people = new List<string>() { "Tom", "Bob", "Sam" };



foreach (var person in people)

{

    Console.WriteLine(person);

}

// Вывод программы:

// Tom

// Bob

// Sam
```

допустимы и другие циклы. вместе с индексом список перебирают циклом `for`, пока индекс меньше `Count`:

```c#


var people = new List<string>() { "Tom", "Bob", "Sam" };



for (int i = 0; i < people.Count; i++)

{

    Console.WriteLine(people[i]);

}
```

перечислитель `List<T>` следит за версией коллекции. изменение списка внутри `foreach` делает перечислитель недействительным, и следующее движение по нему завершается исключением `InvalidOperationException`. цикл `for` по индексам такой проверки не выполняет. при удалении элементов внутри этого цикла границы нужно пересчитывать отдельно.

### методы списка

для дальнейших примеров нужны такие члены `List<T>`:

- `void Add(T item)`: добавление нового элемента в конец списка

- `void AddRange(IEnumerable<T> collection)`: добавление в список коллекции или массива

- `int BinarySearch(T item)`: двоичный поиск элемента. если элемент найден, метод возвращает его индекс. список к этому моменту должен быть отсортирован, иначе возвращаемый индекс не соответствует поиску. если элемента нет, возвращается отрицательное число: его побитовое дополнение задаёт позицию, куда элемент встал бы при вставке с сохранением порядка

- `void CopyTo(T[] array)`: копирует список в массив `array`

- `void CopyTo(int index, T[] array, int arrayIndex, int count)`: копирует из списка, начиная с индекса `index`, `count` элементов и записывает их в массив `array`, начиная с индекса `arrayIndex`

- `bool Contains(T item)`: возвращает `true`, если элемент `item` есть в списке

- `void Clear()`: удаляет из списка все элементы

- `bool Exists(Predicate<T> match)`: возвращает `true`, если в списке есть элемент, который соответствует предикату `match`

- `T? Find(Predicate<T> match)`: возвращает первый элемент, который соответствует предикату `match`. если элемент не найден, возвращается `null`

- `T? FindLast(Predicate<T> match)`: возвращает последний элемент, который соответствует предикату `match`. если элемент не найден, возвращается `null`

- `List<T> FindAll(Predicate<T> match)`: возвращает список элементов, которые соответствуют предикату `match`

- `int IndexOf(T item)`: возвращает индекс первого вхождения элемента в списке. если элемента нет, возвращается -1

- `int LastIndexOf(T item)`: возвращает индекс последнего вхождения элемента в списке. если элемента нет, возвращается -1

- `List<T> GetRange(int index, int count)`: возвращает список элементов, число которых равно `count`, начиная с индекса `index`

- `void Insert(int index, T item)`: вставляет элемент `item` в список по индексу `index`. если такого индекса в списке нет, генерируется исключение

- `void InsertRange(int index, IEnumerable<T> collection)`: вставляет коллекцию `collection` в текущий список, начиная с индекса `index`. если такого индекса в списке нет, генерируется исключение

- `bool Remove(T item)`: удаляет элемент `item` из списка и при успешном удалении возвращает `true`. если одинаковых элементов несколько, удаляется первое вхождение

- `void RemoveAt(int index)`: удаляет элемент по индексу `index`. если такого индекса в списке нет, генерируется исключение

- `void RemoveRange(int index, int count)`: параметр `index` задаёт индекс, с которого удаляются элементы, а параметр `count` задаёт число удаляемых элементов

- `int RemoveAll(Predicate<T> match)`: удаляет все элементы, которые соответствуют предикату `match`. возвращает число удалённых элементов

- `void Reverse()`: меняет порядок элементов на обратный

- `void Reverse(int index, int count)`: меняет порядок на обратный у элементов, число которых равно `count`, начиная с индекса `index`

- `void Sort()`: сортировка списка

- `void Sort(IComparer<T>? comparer)`: сортировка списка объектом `comparer`. значение `null` означает компаратор по умолчанию для типа `T`

`Predicate<T>` в этих сигнатурах является делегатом от элемента к `bool`: предикат получает элемент и сообщает, подходит ли он.

### добавление в список

```c#


List<string> people = new List<string> () { "Tom" };



people.Add("Bob"); // добавление элемента

// people = { "Tom", "Bob" };



people.AddRange(new[] { "Sam", "Alice" });   // добавляем массив

// people = { "Tom", "Bob", "Sam", "Alice" };

// также можно было бы добавить другой список

// people.AddRange(new List<string>(){ "Sam", "Alice" });



people.Insert(0, "Eugene"); // вставляем на первое место

// people = { "Eugene", "Tom", "Bob", "Sam", "Alice" };



people.InsertRange(1, new string[] {"Mike", "Kate"}); // вставляем массив с индекса 1

// people = { "Eugene", "Mike", "Kate", "Tom", "Bob", "Sam", "Alice" };



// также можно было бы добавить другой список

// people.InsertRange(1, new List<string>(){ "Mike", "Kate" });
```

`Add` дописывает элемент в конец. `AddRange` дописывает последовательность. в примере это массив, на то же место годится и другой `List<string>`. `Insert` сдвигает существующие элементы вправо и ставит новый элемент в указанную позицию, здесь в начало, по индексу 0. `InsertRange` вставляет последовательность, начиная с индекса 1. комментарии в коде фиксируют состав списка после каждой операции.

### удаление из списка

```c#


var people = new List<string> () { "Eugene", "Mike", "Kate", "Tom", "Bob", "Sam", "Tom", "Alice" };



people.RemoveAt(1); //  удаляем второй элемент

// people = { "Eugene", "Kate", "Tom", "Bob", "Sam", "Tom", "Alice" };



people.Remove("Tom"); //  удаляем элемент "Tom"

// people = { "Eugene", "Kate", "Bob", "Sam", "Tom", "Alice" };



// удаляем из списка все элементы, длина строки которых равна 3

people.RemoveAll(person => person.Length == 3);

// people = { "Eugene", "Kate", "Alice" };



// удаляем из списка 2 элемента начиная с индекса 1

people.RemoveRange(1, 2);

// people = { "Eugene"};



// полностью очищаем список

people.Clear();

// people = {  };
```

`RemoveAt(1)` удаляет второй элемент: индексация начинается с нуля. `Remove("Tom")` удаляет первое вхождение строки `"Tom"` и оставляет второе. `RemoveAll` с предикатом `person => person.Length == 3` удаляет все строки длины 3. `RemoveRange(1, 2)` удаляет два элемента, начиная с индекса 1. `Clear` очищает список целиком. после него `Count` равен 0. ёмкость буфера этот метод не обнуляет: освобождаются элементы, размер выделенного массива сохраняется.

### поиск и проверка элемента

```c#


var people = new List<string> () { "Eugene", "Mike", "Kate", "Tom", "Bob", "Sam" };



var containsBob = people.Contains("Bob");     //  true

var containsBill = people.Contains("Bill");    // false



// проверяем, есть ли в списке строки с длиной 3 символа

var existsLength3 = people.Exists(p => p.Length == 3);  // true



// проверяем, есть ли в списке строки с длиной 7 символов

var existsLength7 = people.Exists(p => p.Length == 7);  // false



// получаем первый элемент с длиной в 3 символа

var firstWithLength3 = people.Find(p => p.Length == 3); // Tom



// получаем последний элемент с длиной в 3 символа

var lastWithLength3 = people.FindLast(p => p.Length == 3);  // Sam



// получаем все элементы с длиной в 3 символа в виде списка

List<string> peopleWithLength3 = people.FindAll(p => p.Length == 3);

// peopleWithLength3 { "Tom", "Bob", "Sam"}
```

`Contains` проверяет наличие элемента сравнением на равенство. строка `"Bob"` в списке есть, строки `"Bill"` нет. `Exists` отвечает на вопрос, есть ли хотя бы один элемент, для которого предикат истинен. строки длины 3 в списке есть, строки длины 7 нет. `Find` возвращает первый подходящий элемент, здесь `"Tom"`. `FindLast` возвращает последний, здесь `"Sam"`. `FindAll` собирает все подходящие элементы в новый `List<string>`: `"Tom"`, `"Bob"`, `"Sam"`.

### получение диапазона и копирование в массив

```c#


List<string> people = new List<string>() {"Eugene", "Tom", "Mike", "Sam", "Bob" };



// получаем диапазон со второго по четвертый элемент

var range = people.GetRange(1, 3);

// range = { "Tom", "Mike", "Sam"};



// копируем в массив первые три элемента

string[] partOfPeople = new string[3];

people.CopyTo(0, partOfPeople, 0, 3);

// partOfPeople = { "Eugene", "Tom", "Mike"};
```

`GetRange(1, 3)` возвращает новый список из трёх элементов, начиная со второго: `"Tom"`, `"Mike"`, `"Sam"`. исходный список при этом не меняется. `CopyTo` копирует элементы в уже выделенный массив. вызов `CopyTo(0, partOfPeople, 0, 3)` читает три элемента списка с индекса 0 и пишет их в `partOfPeople` с индекса 0. в массиве оказываются `"Eugene"`, `"Tom"`, `"Mike"`.

### расположение элементов в обратном порядке

```c#


var people = new List<string> () { "Eugene", "Tom", "Mike", "Sam", "Bob" };



// переворачиваем весь список

people.Reverse();

// people = { "Bob","Sam", "Mike", "Tom", "Eugene"};



var people2 = new List<string>() { "Eugene", "Tom", "Mike", "Sam", "Bob" };

// переворачиваем часть только 3 элемента с индекса 1

people2.Reverse(1, 3);

// people2 = { "Eugene","Sam", "Mike", "Tom", "Bob" };
```

`Reverse` без аргументов переставляет все элементы списка. порядок становится обратным исходному. перегрузка `Reverse(1, 3)` переставляет только три элемента, начиная с индекса 1, и не трогает элементы вне этого отрезка. оба метода меняют сам список, а не возвращают новую последовательность.
