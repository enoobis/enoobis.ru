у полей, методов и остальных членов класса есть модификаторы доступа. модификатор задаёт допустимую область видимости члена: контекст, в котором имя переменной или метода разрешается. проверка выполняется при компиляции. сборка, в которой объявлен тип, и отношение наследования являются двумя независимыми осями этой проверки.

в c# используются такие модификаторы доступа.

- `private`: закрытый член класса или структуры. он доступен только внутри своего класса или своей структуры.

- `private protected`: член класса доступен в своём классе и в производных классах, объявленных в той же сборке. имя видно там, где одновременно выполнены два условия: обращение идёт из иерархии наследования и оба типа принадлежат одной сборке.

- `file`: добавлен в c# 11 и применяется к типам, например к классам и структурам. тип с этим модификатором доступен только из текущего файла кода.

- `protected`: член класса доступен в своём классе и в производных классах. производные классы могут находиться в других сборках.

- `internal`: член класса или структуры доступен из любого кода той же сборки и недоступен другим программам и сборкам.

- `protected internal`: объединяет `protected` и `internal`. член доступен из любого места текущей сборки и из производных классов, в том числе расположенных в других сборках. это объединение двух условий, а не их пересечение: достаточно одного из них. пересечению соответствует `private protected`.

- `public`: открытый член класса или структуры. он доступен из любого кода, включая другие программы и сборки.

те же модификаторы применяются к членам структуры, кроме `private protected`, `protected` и `protected internal`. структура не может быть базовым типом: она неявно герметизирована, производных структур не существует, и модификаторы, смысл которых завязан на наследников, для неё не определены.

классы и структуры, объявленные непосредственно вне других типов, могут иметь только модификаторы `public`, `file` или `internal`.

модификатор можно записать явно или опустить.

```c#


public class Person

{

	string name;

	public Person(string name) 

	{

		this.name = name;

	}

	public void Print() => Console.WriteLine($"Name: {name}");

}
```

если у члена модификатор не указан, применяется `private`. в примере поле `name` неявно закрыто.

классы и структуры без модификатора, расположенные вне других типов, по умолчанию имеют доступ `internal`. вложенные классы и структуры, как и прочие члены, по умолчанию имеют `private`.

```c#


class Phone

{

    struct Camera

    {



    }

}
```

класс `Phone` не вложен ни в какой другой тип, поэтому неявно помечен `internal`. структура `Camera` вложена и, как остальные члены класса, неявно помечена `private`.

### модификаторы в рамках текущего проекта

рассмотрим класс `State`.

```c#


class State

{

    // все равно, что private string defaultVar;

    string defaultVar ="default";

    // поле доступно только из текущего класса

    private string privateVar = "private";

    // доступно из текущего класса и производных классов, которые определены в этом же проекте

    protected private string protectedPrivateVar = "protected private";

    // доступно из текущего класса и производных классов

    protected string protectedVar = "protected";

    // доступно в любом месте текущего проекта

    internal string internalVar = "internal";

    // доступно в любом месте текущего проекта и из классов-наследников в других проектах

    protected internal string protectedInternalVar = "protected internal";

    // доступно в любом месте программы, а также для других программ и сборок

    public string publicVar = "public";



    // по умолчанию имеет модификатор private

    void Print() => Console.WriteLine(defaultVar);



    // метод доступен только из текущего класса

    private void PrintPrivate() => Console.WriteLine(privateVar);



    // доступен из текущего класса и производных классов, которые определены в этом же проекте

    protected private void PrintProtectedPrivate() => Console.WriteLine(protectedPrivateVar);



    // доступен из текущего класса и производных классов

    protected void PrintProtected() => Console.WriteLine(protectedVar);



    // доступен в любом месте текущего проекта

    internal void PrintInternal() => Console.WriteLine(internalVar);



    // доступен в любом месте текущего проекта и из классов-наследников в других проектах

    protected internal void PrintProtectedInternal() => Console.WriteLine(protectedInternalVar);



    // доступен в любом месте программы, а также для других программ и сборок

    public void PrintPublic() => Console.WriteLine(publicVar);

}
```

у класса `State` нет явного модификатора, поэтому действует `internal`: тип доступен в любом месте данного проекта и недоступен из других программ и сборок.

в классе шесть полей, по одному на каждый уровень доступа, и ещё переменная без модификатора. она закрыта, то есть фактически имеет `private`. семь методов с теми же модификаторами выводят значения соответствующих переменных. любой модификатор разрешает использование члена внутри самого класса, поэтому все поля, включая закрытые, видны всем методам `State`: они находятся в одной области класса.

запись `protected private` в примере обозначает тот же модификатор, что и `private protected`. компилятор принимает оба порядка служебных слов.

использование полей `State` из другого класса того же проекта, `StateConsumer`, выглядит так.

```c#


class StateConsumer

{

    public void PrintState()

    {

        State state = new State();



        // обратиться к переменной defaultVar у нас не получится,

        // так как она имеет модификатор private и класс StateConsumer ее не видит

        Console.WriteLine(state.defaultVar); //Ошибка, получить доступ нельзя



        // то же самое относится и к переменной privateVar

        Console.WriteLine(state.privateVar); // Ошибка, получить доступ нельзя



        // обратиться к переменной protectedPrivateVar не получится,

        // так как класс StateConsumer не является классом-наследником класса State

        Console.WriteLine(state.protectedPrivateVar); // Ошибка, получить доступ нельзя



        // обратиться к переменной protectedVar тоже не получится,

        // так как класс StateConsumer не является классом-наследником класса State

        Console.WriteLine(state.protectedVar); // Ошибка, получить доступ нельзя



        // переменная internalVar с модификатором internal доступна из любого места текущего проекта

        // поэтому можно получить или изменить ее значение

        Console.WriteLine(state.internalVar);



        // переменная protectedInternalVar так же доступна из любого места текущего проекта

        Console.WriteLine(state.protectedInternalVar);



        // переменная publicVar общедоступна

        Console.WriteLine(state.publicVar);

    }

}
```

из `StateConsumer` доступны только `internalVar`, `protectedInternalVar` и `publicVar`: их модификаторы разрешают обращение в этом контексте. `defaultVar` и `privateVar` закрыты, а `StateConsumer` не является тем же классом. `protectedPrivateVar` и `protectedVar` требуют наследника `State`, которым `StateConsumer` не является. `internal` и `protected internal` в той же сборке наследника не требуют. `public` открыт без дополнительных условий.

с методами ситуация та же.

```c#


class StateConsumer

{

    public void PrintState()

    {

        State state = new State();



        state.Print(); //Ошибка, получить доступ нельзя



        state.PrintPrivate(); // Ошибка, получить доступ нельзя



        state.PrintProtectedPrivate(); // Ошибка, получить доступ нельзя



        state.PrintProtected(); // Ошибка, получить доступ нельзя



        state.PrintInternal();    // норм



        state.PrintProtectedInternal();  // норм



        state.PrintPublic();      // норм

    }

}
```

доступны три метода: `PrintInternal`, `PrintProtectedInternal` и `PrintPublic`, с модификаторами `internal`, `protected internal` и `public`. закрытые методы и методы с `protected` из `StateConsumer` не вызываются.

### модификаторы в рамках сборок

пусть проект и соответствующая сборка `MyLib` содержат три класса.

```c#


namespace MyLib;

// класс доступен из других сборок

public class PublicState

{

    internal void PrintInternal() => Console.WriteLine("internal");

    protected internal void PrintProtectedInternal() => Console.WriteLine("protected internal");

    public void PrintPublic() => Console.WriteLine("public");



}



// класс доступен только в текущей сборке - по умолчанию internal

class DefaultState { }

// класс доступен только в текущей сборке

internal class InternalState{  }
```

`DefaultState` и `InternalState` имеют модификатор `internal`, поэтому доступны только в текущем проекте. у `DefaultState` модификатор опущен, и для типа верхнего уровня это то же самое, что явный `internal`.

класс `PublicState` с модификатором `public` доступен из других проектов. его метод `PrintInternal` доступен только в текущем проекте. вне текущего проекта доступны `PrintPublic` и `PrintProtectedInternal`, причём второй в другом проекте виден только классам-наследникам.

сборку `MyLib` подключают к другому проекту, где объявлен `StateConsumer`.

```c#


using MyLib;

class StateConsumer

{

    public void PrintState()

    {

        // Ошибка DefaultState - по умолчанию internal, поэтому нет доступа

        DefaultState defaultState = new DefaultState();

        // Ошибка InternalState - internal, поэтому нет доступа

        InternalState internalState = new InternalState();



        // норм, PublicState - public, доступен из других программ

        PublicState publicState = new PublicState();

        // Ошибка, нет доступа - метод доступен только в свой сборке

        publicState.PrintInternal();

        // Ошибка, нет доступа - StateConsumer НЕ является классом-наследником от класса PublicState,

        // поэтому метод не доступен

        publicState.PrintProtectedInternal();  // нет доступа

        // норм - общедоступный метод

        publicState.PrintPublic();      // норм

    }

}
```

у `StateConsumer` есть доступ только к классу `PublicState` и его методу `PrintPublic`, потому что оба помечены `public`. `DefaultState` и `InternalState` из другой сборки не конструируются. `PrintInternal` остаётся внутри сборки `MyLib`. `PrintProtectedInternal` в чужой сборке открыт наследникам `PublicState`, а `StateConsumer` наследником не является, поэтому вызов не компилируется.

такая система скрывает детали реализации класса от остальных частей программы: закрытые и внутренние члены не входят в контракт, который видит код за пределами разрешённой области.

### файл как область видимости

в c# 11 добавлен модификатор видимости `file`. он применяется к классам, структурам, делегатам, перечислениям и интерфейсам. тип с этим модификатором используется только внутри текущего файла.

```c#


file class Person

{

}
```

модификатор `file` не сочетается с другими модификаторами доступа. компилятор даёт такому типу уникальное имя в метаданных сборки, чтобы одноимённые файловые типы из разных файлов не столкнулись. для остальных файлов проекта этого имени нет: простое имя `Person` из примера разрешается только в том файле, где стоит `file`.
