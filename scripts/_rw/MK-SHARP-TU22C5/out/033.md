объявляемые классы и прочие типы в .net обычно помещают в пространства имён. пространство имён группирует код в логические блоки: оно собирает функциональность, связанную общей задачей, и отделяет её от остального текста программы. для компилятора пространство имён является механизмом квалификации имён. во время выполнения clr видит полное имя типа, в которое сегменты пространства имён уже входят. отдельного объекта "пространство имён" в модели выполнения нет.

пространство имён объявляют служебным словом `namespace`, после которого записывают имя:

```c#


namespace имя_пространства_имен

{

	// содержимое пространства имен

}
```

в файле `Program.cs` можно объявить пространство имён `Base`.

```c#


namespace Base

{

    class Person

    {

        string name;

        public Person(string name) => this.name = name;

        public void Print() => Console.WriteLine($"Имя: {name}");

    }

}
```

это пространство содержит класс `Person` с одним полем `name`, конструктором и методом `Print`.

![пространства имен в языке программирования c# и .net](/uploads/course-lectures/0356d894b6d5b8c1a3eee1e7f36a68bc2fa81fe5.png)

простое имя `Person` снаружи пространства `Base` не разрешается.

```c#


Person tom = new Person("Tom"); // Ошибка - Visual Studio не видит класс Person

tom.Print();



namespace Base

{

    class Person

    {

        string name;

        public Person(string name) => this.name = name;

        public void Print() => Console.WriteLine($"Имя: {name}");

    }

}
```

компилятор не связывает простое имя `Person` с классом из `Base`, и visual studio сообщает об ошибке. чтобы обратиться к классу, нужно полное имя с учётом пространства имён.

```c#


Base.Person tom = new("Tom");

tom.Print();          // Имя: Tom



namespace Base

{

    class Person

    {

        string name;

        public Person(string name) => this.name = name;

        public void Print() => Console.WriteLine($"Имя: {name}");

    }

}
```

класс расположен в `Base`, поэтому его полное имя записывается как `Base.Person`. по этому имени к классу обращаются вне его пространства имён.

### подключение пространства имён

полное имя с квалификатором удлиняет текст, особенно если из пространства берётся много типов. директива `using` подключает пространство имён к текущей единице компиляции, и простые имена его типов начинают разрешаться без префикса.

```c#


using Base; // подключение пространства имен Base



Person tom = new("Tom");

tom.Print();     // Имя: Tom



namespace Base

{

    class Person

    {

        string name;

        public Person(string name) => this.name = name;

        public void Print() => Console.WriteLine($"Имя: {name}");

    }

}
```

![подключение пространства имен и using в языке программирования c# и .net](/uploads/course-lectures/f1e83a1e9a8d23426604f6ccb5ef45625b148169.png)

директива `using` импортирует типы указанного пространства и не импортирует вложенные пространства. `using Base` не делает видимыми типы из `Base.PersonTypes`. для вложенного пространства нужна отдельная директива либо полная квалификация.

### вложенные пространства имён

пространство имён может содержать другие пространства имён.

```c#


namespace Base

{

    namespace PersonTypes

    {

        class Person

        {

            string name;

            OrganisationTypes.Company company;

            public Person(string name, OrganisationTypes.Company company) 

            { 

                this.name = name; 

                this.company = company; 

            }

            public void Print()

            {

                Console.WriteLine($"Имя: {name} ");

                company.Print();

            }

        }

    }

    namespace OrganisationTypes

    {

        class Company

        {

            string title;

            public Company(string title) => this.title = title;

            public void Print() => Console.WriteLine($"Название компании: {title}");

        }

    }

}
```

классы `Person` и `Company` лежат в разных вложенных пространствах. чтобы в `Person` использовать `Company`, имя записывают с пространством: `OrganisationTypes.Company`. оба класса в итоге находятся в общем пространстве `Base`, поэтому префикс `Base` в этом имени можно опустить. второй путь состоит в том, чтобы подключить пространство `Company` директивой `using`.

вне `Base` нужна вся цепочка пространств имён.

```c#


using Base.PersonTypes; // подключение пространства имен Base.PersonTypes для класса Person



Base.OrganisationTypes.Company microsoft = new("Microsoft");

Person tom = new("Tom", microsoft);

tom.Print();     // Имя: Tom   Название компании: Microsoft



namespace Base

{

    namespace PersonTypes

    {

        class Person

        {

            string name;

            OrganisationTypes.Company company;

            public Person(string name, OrganisationTypes.Company company) 

            { 

                this.name = name; 

                this.company = company; 

            }

            public void Print()

            {

                Console.WriteLine($"Имя: {name} ");

                company.Print();

            }

        }

    }

    namespace OrganisationTypes

    {

        class Company

        {

            string title;

            public Company(string title) => this.title = title;

            public void Print() => Console.WriteLine($"Название компании: {title}");

        }

    }

}
```

здесь `using Base.PersonTypes` даёт простое имя `Person`, а `Company` по-прежнему записывается полным именем `Base.OrganisationTypes.Company`. вложенная запись `namespace Base { namespace PersonTypes { ... } }` по смыслу совпадает с формой `namespace Base.PersonTypes`, которая сразу задаёт составное имя.

### пространства имён уровня файла

начиная с .net 6 и c# 10 пространство имён можно объявить на уровне файла. в visual studio новый файл добавляют так: правая кнопка по имени проекта, в меню пункт `Add -> New Item...`.

![добавление нового пространства имен c# в visual studio](/uploads/course-lectures/a7d219f70c773505e30a9ea4f3360c87e10245cb.png)

в окне добавления элемента выбирают пункт `Class`, а в поле `Name` указывают имя файла `Base.cs`.

![пространства имен уровня файла c# в visual studio](/uploads/course-lectures/95b1e382f773ac3ad38be7276a41961821b403ea.png)

в проект попадает файл `Base.cs`. содержимое по умолчанию удаляют и записывают следующий код.

```c#


namespace Base;



class Person

{

    string name;

    public Person(string name) => this.name = name;

    public void Print() => Console.WriteLine($"Имя: {name} ");

}
```

директива `namespace Base;` в начале файла означает, что всё дальнейшее содержимое файла принадлежит пространству `Base`. фигурные скобки для этого пространства не пишут: область директивы простирается до конца файла, и второй директивы пространства имён в том же файле уже не ставят.

это пространство подключают в `Program.cs`.

```c#


using Base; // подключение пространства имен Base



Person tom = new("Tom");

tom.Print();
```
