ранее разобраны блоки расширений. они появились в c# 14 и добавляют поведение уже существующему типу без правки его исходного кода и без наследования. обобщённый блок расширений устроен так же, но типизирован одним или несколькими параметрами типа, по тем же правилам, что обобщённый тип и обобщённый метод. обычный повод для такой записи: операторы, которые должны работать с целым семейством типов.

простейший пример ниже показывает форму объявления. практической работы он не делает:

```c#

string text = "Hello";
text >>= null;

static class Operators{

    extension<T>(T self) where T: class?{

        public void operator >>= (T _) => Console.WriteLine(self);
    }
}
```

для произвольного ссылочного типа задан оператор `>>=`, сдвиг вправо с присваиванием. сама реализация сдвиг не выполняет.

блок расширения выглядит так:

```c#

extension<T>(T self) where T: class?{
```

параметр типа `T` стоит на месте конкретного типа. ограничение записывается тем же словом `where`, что у обобщённого типа и обобщённого метода. ограничение `where T: class?` требует ссылочный тип и допускает отсутствие значения: на месте `T` может быть класс, и значение этого типа может быть `null`.

блок нестатический: в скобках указан получатель `self`. составной оператор присваивания начиная с c# 14 объявляется методом экземпляра. тело оператора выводит левый операнд на консоль:

```c#
public void operator >>= (T _) => Console.WriteLine(self);
```

оператор бинарный, поэтому правый операнд приходит параметром. в этом примере он не читается, и имя параметра заменено на `_`. конкретный тип правого операнда здесь не используется.

применение:

```c#

string text = "Hello";
text >>= null;
```

`text` имеет ссылочный тип `string`, и к нему применяется `>>=`. правый операнд обязан иметь тот же тип `T`, что и левый, либо быть равным `null`. здесь справа стоит `null`. на его месте могла бы стоять и строка:

```c#

string text = "Hello";
text >>= "world";
```

в обоих вызовах тело оператора только печатает левый операнд. сдвига значения нет, и новое значение переменной не записывается.

следующий пример использует ту же форму как применение действия к значению:

```c#

string text = "Hello METANIT.COM";

text >>= Console.WriteLine;
text >>= FramePrint;
text >>= mes => Console.WriteLine($"<{mes}>");

void FramePrint(string message) => Console.WriteLine($"***** {message} *****");

static class Operators{

    extension<T>(T self) where T: class{

        public void operator >>= (Action<T> op) => op(self);
    }
}
```

параметр оператора имеет тип `Action<T>`: делегат с одним аргументом типа `T`, то есть типа, к которому применяется оператор. тело вызывает этот делегат и передаёт ему получатель `self`.

под такой делегат подходит `Console.WriteLine`, когда `T` выводится как `string`:

```c#
text >>= Console.WriteLine;
```

правым операндом может быть и собственный метод, и лямбда-выражение:

```c#

text >>= FramePrint;
text >>= mes => Console.WriteLine($"<{mes}>");

void FramePrint(string message) => Console.WriteLine($"***** {message} *****");
```

`FramePrint` печатает сообщение между рядами звёздочек. лямбда печатает текст в угловых скобках. консольный вывод программы:

```bash

Hello METANIT.COM
***** Hello METANIT.COM *****
<Hello METANIT.COM>
```

блок обобщённый, поэтому тот же оператор применим к любому ссылочному типу, в том числе к собственному:

```c#

Person person = new("Bob", 44);
person >>= Console.WriteLine;     // Bob (44)

person >>= (p) => p.Age = 25;
person >>= Console.WriteLine;     // Bob (25)

person >>= SetDefault;
person >>= Console.WriteLine;     // Tom (41)

void SetDefault(Person p)
{
    p.Age = 41;
    p.Name = "Tom";
}

class Person{

    public string Name {get;set;}
    public int Age {get;set;}

    public Person(string name, int age)
    {

        Name = name;
        Age = age;
    }

    public override string ToString() => $"{Name} ({Age})";
}

static class Operators{

    extension<T>(T self) where T: class{

        public void operator >>= (Action<T> op) => op(self);
    }
}
```

левый операнд имеет тип `Person`. тип ссылочный, поэтому делегат справа меняет его свойства и доступные поля в исходном объекте. копия при вызове не создаётся. комментарии фиксируют три состояния: `Bob (44)`, затем `Bob (25)` после смены возраста, затем `Tom (41)` после `SetDefault`.

#### значимые типы

в предыдущих блоках ограничение было ссылочным: `where T: class`. для значимого типа ограничение меняется на `where T: struct`, а получатель расширения помечается модификатором `ref`:

```c#

int n = 123;

n >>= Console.WriteLine;

static class Operators{

    extension<T>(ref T self) where T: struct{

        public void operator >>= (Action<T> op) => op(self);
    }
}
```

значимый тип при передаче без `ref` копируется. модификатор `ref` связывает блок с исходной переменной, поэтому оператор видит ту же ячейку, что и вызывающий код. в примере `n` равно 123, и `>>=` передаёт это значение в `Console.WriteLine`.

параметров типа у блока может быть несколько: один для левого операнда, другой для правого, либо один операнд зависит сразу от нескольких параметров. ниже это показано на статическом блоке. цепочка читает строку, подставляет значение по умолчанию, разбирает число и возводит его в квадрат:

```c#

// проверяем строку и устанавливаем значение по умолчанию, если ввод отсутствует
var checkNum = (string? val) => val?.Length > 0 ? val : "11";

Console.Write("Введите число: ");

int num =  
    Console.ReadLine()  // считываем число в виде строки
    | checkNum          // проверяем введенную строку   (string -> string)
    | Int32.Parse       // парсим строку в число        (string -> int)
    | Square            // возводим в квадрат           (int -> int)
    ;

num >>= Console.WriteLine;

int Square(int n) => n * n;

static class Operators{

    extension<T1, T2>(T1) {

        public static T2 operator | (T1 self, Func<T1, T2> op) => op(self);
    }
    extension<T>(ref T self) where T: struct{

        public void operator >>= (Action<T> op) => op(self);
    }
}
```

у блока два параметра типа, `T1` и `T2`:

```c#

extension<T1, T2>(T1) {

    public static T2 operator | (T1 self, Func<T1, T2> op) => op(self);
}
```

формально блок объявлен для типа `T1`. получателя в скобках нет, блок статический. оператор `|` принимает левый операнд типа `T1` и правый операнд типа `Func<T1, T2>`: делегат получает `T1` и возвращает `T2`. результат делегата становится результатом оператора. `T1` и `T2` могут совпадать, а могут быть разными типами. оператор `|` левоассоциативен, поэтому цепочка группируется слева направо, и тип результата каждого шага становится типом левого операнда следующего шага.

применение оператора:

```c#

int num =  
    Console.ReadLine()  // считываем число в виде строки
    | checkNum          // проверяем введенную строку   (string -> string)
    | Int32.Parse       // парсим строку в число        (string -> int)
    | Square            // возводим в квадрат           (int -> int)
    ;
```

порядок выполнения такой:

- `Console.ReadLine()` считывает число в виде строки

- `| checkNum` передаёт оператору `|` ранее введённую строку слева. справа стоит лямбда `checkNum`. она проверяет строку и, если строка равна `null` или не содержит символов, возвращает значение по умолчанию `"11"`

- `| Int32.Parse` передаёт оператору `|` слева строку, результат `checkNum`. справа стоит метод `Int32.Parse`, который принимает строку и преобразует её в целое число. оператор возвращает значение типа `int`. если введённая строка не преобразуется в число, пример этого не проверяет. такую проверку добавляют по той же схеме, что и `checkNum`

- `| Square` передаёт оператору `|` слева целое число, полученное от `Int32.Parse`. справа стоит метод `Square`, который возводит переданное число в квадрат

примеры запуска:

```bash

eugene@Eugene:/dotnet/c#/testapp$ dotnet run
Введите число: 15
225
eugene@Eugene:/dotnet/c#/testapp$ dotnet run
Введите число: -3
9
eugene@Eugene:/dotnet/c#/testapp$ dotnet run
Введите число: 
121
eugene@Eugene:/dotnet/c#/testapp$ dotnet run
```

ввод `15` даёт 225, ввод `-3` даёт 9. пустая строка проходит через значение по умолчанию `"11"` и даёт 121.
