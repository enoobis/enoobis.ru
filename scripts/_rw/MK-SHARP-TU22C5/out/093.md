сопоставление с образцом (pattern matching) проверяет, удовлетворяет ли значение заданному шаблону. при успешном сопоставлении выполняется соответствующая ветвь. язык c# встраивает шаблоны в оператор `is`, в оператор `switch` и в выражение `switch` и различает несколько видов сопоставления. ниже разобраны типовой и константный шаблоны и их запись в `switch`.

типовой шаблон (type pattern) проверяет динамический тип значения и при успехе связывает это значение с переменной целевого типа:

```c#
значение is тип переменная_типа
```

если динамический тип выражения совместим с указанным типом, проверка истинна, а переменная получает то же значение, уже рассматриваемое как этот тип. отдельное приведение не пишется: к членам целевого типа компилятор допускает обращение на той ветви, где шаблон совпал.

для разбора достаточно двух классов:

```c#


class Employee

{

    public virtual void Work() => Console.WriteLine("Employee works");

}



class Manager : Employee

{

    public override void Work() => Console.WriteLine("Manager works");

    public bool IsOnVacation { get; set; }

}
```

класс `Employee` задаёт работника и виртуальный метод `Work`. класс `Manager` наследует `Employee`, переопределяет `Work` и добавляет свойство `IsOnVacation`. статически переменная типа `Employee` может ссылаться и на экземпляр базового класса, и на экземпляр `Manager`. эти случаи различаются динамическим типом.

проверка, является ли объект `Employee` экземпляром `Manager`:

```c#


Employee tom = new Manager();

UseEmployee(tom);	// Manager works



void UseEmployee(Employee emp)

{

    if (emp is Manager manager && manager.IsOnVacation == false)

    {

        manager.Work();

    }

    else

    {

        Console.WriteLine("Преобразование не допустимо");

    }

}
```

в методе `UseEmployee` значение `emp` сопоставляется с типом `Manager`. шаблоном выступает тип `Manager`. если динамический тип совместим с `Manager`, переменная `manager` обозначает это значение, и через неё доступны члены `Manager`, включая `IsOnVacation` и `Work`. конъюнкция `&& manager.IsOnVacation == false` вычисляется только после успешного связывания: при неудачном шаблоне правый операнд не читается. если значение не является `Manager` либо менеджер в отпуске, выполняется ветвь с сообщением о недопустимом преобразовании.

константный шаблон (constant pattern) сравнивает значение с константой. для строки сравнение идёт по значению:

```c#


var message = "hello";



// проверяем, соответствует ли значение message строке "hello"

if (message is "hello")

{

   Console.WriteLine("hello");

}
```

тем же видом шаблона проверяют ссылку на `null`. форма `is not null` соединяет константный шаблон `null` с логическим шаблоном `not`:

```c#


Employee? bob = new Employee();

Employee? tom = null;



UseEmployee(bob);

UseEmployee(tom);



void UseEmployee(Employee? emp)

{

    if (emp is not null)

        emp.Work();

}
```

после успешной проверки `emp is not null` анализ потока управления считает ссылку ненулевой, поэтому вызов `emp.Work()` не требует отдельной проверки на `null`.

помимо оператора `if`, шаблоны входят в оператор `switch`. ветви проверяются сверху вниз, выполняется первая совпавшая:

```c#


Employee bob = new Employee();

Employee tom = new Manager();

UseEmployee(tom);   // Manager works

UseEmployee(bob);   // Object is not manager



void UseEmployee(Employee? emp)

{

    switch (emp)

    {

        case Manager manager:

            manager.Work();

            break;

        case null:

            Console.WriteLine("Object is null");

            break;

        default:

            Console.WriteLine("Object is not manager");

            break;

    }

}
```

ветвь `case Manager manager` совпадает, когда динамический тип является `Manager`, и связывает значение с `manager`. ветвь `case null` является константным шаблоном и принимает пустую ссылку. ветвь `default` принимает остальные значения, в том числе экземпляр `Employee`, динамический тип которого не является `Manager`.

дополнительное условие к уже совпавшему шаблону задаёт охрана `when`. она вычисляется только после успешного сопоставления и сама по себе значение не связывает:

```c#


Employee bob = new Manager() { IsOnVacation = true };

Employee tom = new Manager() { IsOnVacation = false };

UseEmployee(tom);   // Manager works

UseEmployee(bob);   // Employee does not work



void UseEmployee(Employee? emp)

{

    switch (emp)

    {

        case Manager manager when !manager.IsOnVacation:

            manager.Work();

            break;

        case null:

            Console.WriteLine("Employee is null");

            break;

        default:

            Console.WriteLine("Employee does not work");

            break;

    }

}
```

шаблон снова требует динамический тип `Manager`. только при удачном сопоставлении читается `IsOnVacation`. тело ветви выполняется, если это свойство ложно. менеджер в отпуске типовому шаблону удовлетворяет, охрану `!manager.IsOnVacation` не проходит и попадает в `default`.
