метод может вернуть результат вызывающему коду. ранее рассматривались методы с типом `void`: такой метод не производит значения и ограничивается действиями.

чтобы вернуть значение, в теле ставят оператор `return` и после него выражение результата:

```c#
return возвращаемое значение;
```

метод, возвращающий `string`:

```c#


string GetMessage()

{

	return "Hello";

}
```

тип `GetMessage` указан как `string`, поэтому результат обязан быть строкой. `return` передает эту строку в точку вызова и завершает выполнение метода.

у метода с любым возвращаемым типом, кроме `void`, каждая ветвь, которая может завершить метод, должна выполнить `return` с совместимым значением. определение без `return` некорректно:

```c#


string GetMessage()

{

	Console.WriteLine("Hello");

}
```

тип выражения после `return` должен соответствовать возвращаемому типу или неявно приводиться к нему. в следующем определении возвращаемый тип равен `string`, а выражение имеет тип `int`. неявного преобразования `int` в `string` нет, и определение некорректно:

```c#


string GetMessage()

{

	return 3;	// Ошибка! Метод должен возвращать строку, а не число

}
```

результат можно записать в переменную или использовать в другом выражении:

```c#


string GetMessage()

{

	return "Hello";

}



string message = GetMessage();	// получаем результат метода в переменную message

Console.WriteLine(message);		// Hello
```

`GetMessage()` возвращает `string`, поэтому результат присваивается переменной того же типа: `string message = GetMessage();`.

результат одного метода может сразу стать аргументом другого. аргументы вычисляются до входа в вызываемый метод:

```c#


string GetMessage()

{

	return "Hello";

}

void PrintMessage(string message)

{

	Console.WriteLine(message);

}

PrintMessage(GetMessage());
```

в вызове `PrintMessage(GetMessage())` сначала выполняется `GetMessage()`, и его результат передается параметру `message` метода `PrintMessage`.

после `return` допустимо любое выражение нужного типа, в том числе вызов другого метода. метод суммы:

```c#


int Sum(int x, int y)

{

    return x + y;

}



int result = Sum(10, 15);   // 25

Console.WriteLine(result);   // 25



Console.WriteLine(Sum(5, 6));   // 11
```

тип `Sum()` равен `int`, поэтому метод возвращает целое число. `return` отдает сумму `x` и `y`. вызов можно присвоить переменной или сразу передать в `Console.WriteLine`: выражение вызова имеет тип возвращаемого значения метода.

### сокращенная версия методов с результатом

метод, который только возвращает значение, тоже записывают телом-выражением. блок

```c#


string GetMessage()

{

	return "hello";

}
```

задает тот же метод, что и

```c#


string GetMessage() => "hello";
```

аналогично блок

```c#


int Sum(int x, int y)

{

    return x + y;

}
```

задает тот же метод, что и

```c#
int Sum(int x, int y) => x + y;
```

после `=>` стоит выражение результата. отдельный `return` не пишется: значение выражения и есть возвращаемое значение. для `void` после `=>` стояла бы инструкция, для остальных типов стоит выражение.

### выход из метода

`return` одновременно отдает значение и покидает метод. инструкции, текстуально расположенные после `return` на том же пути, не выполняются:

```c#


string GetHello()

{

	return "Hello";

	Console.WriteLine("After return");

}
```

синтаксически определение допустимо. инструкция `Console.WriteLine("After return")` недостижима: `return` уже вернул значение и вышел из метода. компилятор сообщает о недостижимом коде.

`return` без выражения допустим в методе типа `void`. значения после него нет, потому что метод ничего не возвращает. так выходят из метода раньше последней инструкции, когда дальнейшая работа не нужна:

```c#


void PrintPerson(string name, int age)

{

    if(age > 120 || age < 1)

    {

        Console.WriteLine("Недопустимый возраст");

        return;

    }

    Console.WriteLine($"Имя: {name}  Возраст: {age}");

}



PrintPerson("Tom", 37);         // Имя: Tom  Возраст: 37

PrintPerson("Dunkan", 1234);    // Недопустимый возраст
```

`PrintPerson()` принимает имя и возраст. сначала возраст проверяется на допустимый диапазон. условие `age > 120 || age < 1` истинно вне отрезка от 1 до 120 включительно. тогда метод пишет сообщение о недопустимом возрасте и по `return` завершается. инструкции после этого `return` в том же вызове не выполняются.

если возраст лежит в допустимом диапазоне, метод пишет имя и возраст на консоль. вывод программы:

```consoletext


Имя: Tom  Возраст: 37

Недопустимый возраст
```
