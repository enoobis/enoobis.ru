### объединение строк

конкатенация, то есть соединение строк, записывается операцией `+` и статическим методом **Concat**:

```c#


string s1 = "hello";

string s2 = "world";

string s3 = s1 + " " + s2; // результат: строка "hello world"

string s4 = string.Concat(s3, "!!!"); // результат: строка "hello world!!!"



Console.WriteLine(s4);
```

`Concat` является статическим методом класса string. показанная перегрузка принимает две строки. есть перегрузки с другим числом аргументов и перегрузка, принимающая последовательность строк. операция `+` для нескольких операндов в одном выражении сводится компилятором к такому соединению, без промежуточной строки на каждый знак плюс. каждое соединение всё равно выделяет новый объект: строка неизменяема, и дописать символы в уже созданный буфер нельзя.

для соединения элементов коллекции через разделитель используется статический метод **Join**:

```c#


string s5 = "apple";

string s6 = "a day";

string s7 = "keeps";

string s8 = "a doctor";

string s9 = "away";

string[] values = new string[] { s5, s6, s7, s8, s9 };



string s10 = string.Join(" ", values);

Console.WriteLine(s10); // apple a day keeps a doctor away
```

показанная версия `Join` принимает строку-разделитель и массив строк. элементы values склеиваются в порядке массива, между соседними элементами вставляется один разделитель. в примере разделитель является пробелом, поэтому результат читается как apple a day keeps a doctor away. пустой разделитель склеил бы элементы вплотную. разделитель из нескольких символов копировался бы между элементами целиком.

### сравнение строк

статический метод **Compare** задаёт порядок двух строк:

```c#


string s1 = "hello";

string s2 = "world";



int result = string.Compare(s1, s2);

if (result<0)

{

    Console.WriteLine("Строка s1 перед строкой s2");

}

else if (result > 0)

{

    Console.WriteLine("Строка s1 стоит после строки s2");

}

else

{

    Console.WriteLine("Строки s1 и s2 идентичны");

}

// результатом будет "Строка s1 перед строкой s2"
```

эта версия `Compare` принимает две строки и возвращает целое число. если первая строка стоит в порядке раньше второй, результат меньше нуля. если первая стоит позже, результат больше нуля. если строки совпадают по правилу сравнения, результат равен 0. показанная перегрузка учитывает текущую культуру. для букв h и w и в культурном, и в порядковом сравнении h предшествует w, поэтому "hello" оказывается перед "world", и программа печатает, что строка s1 стоит перед строкой s2. там, где нужен порядок кодов вне локали, применяется `CompareOrdinal`: он сравнивает кодовые единицы utf-16 и от культуры не зависит.

### поиск в строке

метод **IndexOf** возвращает индекс первого вхождения символа или подстроки. нумерация начинается с нуля. если вхождение не найдено, результат равен -1.

```c#


string s1 = "hello world";

char ch = 'o';

int indexOfChar = s1.IndexOf(ch); // равно 4

Console.WriteLine(indexOfChar);



string substring = "wor";

int indexOfSubstring = s1.IndexOf(substring); // равно 6

Console.WriteLine(indexOfSubstring);
```

в строке "hello world" символ 'o' впервые стоит на индексе 4. подстрока "wor" начинается на индексе 6. метод **LastIndexOf** решает ту же задачу для последнего вхождения: он просматривает строку с конца и возвращает наибольший подходящий индекс либо -1.

отдельная пара методов проверяет границу строки целиком. **StartsWith** истинен, когда строка начинается с заданной подстроки, **EndsWith** истинен, когда строка этой подстрокой заканчивается. в примере в массиве лежат имена файлов, и печатаются только имена с окончанием exe:

```c#


var files = new string[]

{

    "myapp.exe",

    "forest.jpg",

    "main.exe",

    "book.pdf",

    "river.png"

};



for (int i = 0; i < files.Length; i++)

{

    if (files[i].EndsWith(".exe"))

        Console.WriteLine(files[i]);

}
```

перегрузка `EndsWith` с одним строковым аргументом сравнивает окончание с учётом текущей культуры. для суффикса ".exe" из латиницы результат совпадает с порядковым сравнением. цикл оставляет myapp.exe и main.exe и пропускает остальные имена.

### разделение строк

метод **Split** делит строку на массив подстрок. параметром служит набор разделителей: массив символов или массив строк.

```c#


string text = "И поэтому все так произошло";



string[] words = text.Split(new char[] { ' ' });



foreach (string s in words)

{

    Console.WriteLine(s);

}
```

здесь разделитель один, это пробел. каждое вхождение пробела является границей, и слова текста попадают в массив по отдельности. подряд идущие разделители порождают между собой пустые элементы. если во входной строке окажется несколько пробелов подряд, в массив попадут пустые строки. для текста, где такие пропуски возможны, подходит перегрузка с параметром `StringSplitOptions`:

```c#


string[] words = text.Split(new char[] { ' ' }, StringSplitOptions.RemoveEmptyEntries);
```

значение `StringSplitOptions.RemoveEmptyEntries` отбрасывает пустые подстроки. соседние разделители тогда не оставляют пустых ячеек, и в массиве остаются только непустые фрагменты.

### обрезка строки

начальные и конечные символы снимает метод **Trim**:

```c#


string text = " hello world ";



text = text.Trim(); // результат "hello world"

text = text.Trim(new char[] { 'd', 'h' }); // результат "ello worl"
```

`Trim` без параметров удаляет начальные и конечные пробельные символы, не только пробел, но и перевод строки, табуляцию и прочие символы, для которых истинно `char.IsWhiteSpace`, и возвращает новую строку. перегрузка с массивом символов снимает с обоих концов все идущие подряд символы из этого набора. в примере после первого вызова остаётся "hello world". второй вызов снимает ведущую 'h' и завершающую 'd', получается "ello worl". символы в середине строки эта операция не трогает.

частичные варианты делят ту же работу по краям. **TrimStart** снимает символы только в начале, **TrimEnd** снимает символы только в конце. набор символов задаётся так же, как у `Trim`.

участок не с краёв, а по позиции и длине, выделяет метод **Substring**:

```c#


string text = "Хороший день";

// обрезаем начиная с третьего символа

text = text.Substring(2);

// результат "роший день"

Console.WriteLine(text);

// обрезаем сначала до последних двух символов

text = text.Substring(0, text.Length - 2);

// результат "роший де"

 Console.WriteLine(text);
```

`Substring` возвращает новую строку. первая перегрузка принимает индекс начала и забирает хвост до конца исходной строки. с индекса 2 строка `"Хороший день"` даёт `"роший день"`. вторая перегрузка принимает индекс начала и длину вырезаемого участка. вызов `Substring(0, text.Length - 2)` оставляет префикс без двух последних символов и даёт "роший де". индекс или длина за пределами строки завершают метод исключением `ArgumentOutOfRangeException`.

### вставка

метод **Insert** возвращает новую строку, в которую вложена подстрока:

```c#


string text = "Хороший день";

string substring = "замечательный ";



text = text.Insert(8, substring);

Console.WriteLine(text);	// Хороший замечательный день
```

первый параметр является индексом вставки, второй является самой подстрокой. индекс 8 в строке `"Хороший день"` приходится на границу перед словом "день", поэтому результат читается как `"Хороший замечательный день"`. символы исходной строки, начиная с индекса 8, сдвигаются вправо на длину вставки. вставка в индекс 0 ставит подстроку в начало, вставка в индекс `Length` дописывает её в конец.

### удаление строк

участок удаляет метод **Remove**, снова с выделением новой строки:

```c#


string text = "Хороший день";

// индекс последнего символа

int ind = text.Length - 1;

// вырезаем последний символ

text = text.Remove(ind); 

Console.WriteLine(text);    // Хороший ден



// вырезаем первые два символа

text = text.Remove(0, 2);

Console.WriteLine(text);    // роший ден
```

первая перегрузка принимает индекс и удаляет все символы, начиная с него и до конца. индекс последнего символа равен `Length - 1`, поэтому вызов снимает последнюю букву и оставляет `"Хороший ден"`. вторая перегрузка принимает ещё и число удаляемых символов. `Remove(0, 2)` выбрасывает два символа от начала и оставляет `"роший ден"`. и индекс, и сумма индекса с длиной должны лежать в пределах строки.

### замена

метод **Replace** заменяет все вхождения символа или подстроки:

```c#


string text = "хороший день";



text = text.Replace("хороший", "плохой");

Console.WriteLine(text);	// плохой день



text = text.Replace("о", "");

Console.WriteLine(text);	// плхй день
```

первое применение меняет подстроку "хороший" на "плохой". второе меняет каждый символ "о" на пустую строку, то есть удаляет эти символы из текста, и остаётся "плхй день". заменяются все вхождения, не только первое. если образца в строке нет, возвращается строка с тем же содержимым. как и остальные операции этого раздела, `Replace` не пишет в исходный буфер.

### смена регистра

перевод в верхний и нижний регистр выполняют **ToUpper()** и **ToLower()**:

```c#


string hello = "Hello world!";



Console.WriteLine(hello.ToLower()); // hello world!

Console.WriteLine(hello.ToUpper()); // HELLO WORLD!
```

обе перегрузки без параметров учитывают текущую культуру: соответствие верхнего и нижнего регистра для части букв зависит от локали. для латинской строки `"Hello world!"` метод `ToLower` даёт `"hello world!"`, `ToUpper` даёт `"HELLO WORLD!"`. варианты `ToUpperInvariant` и `ToLowerInvariant` применяют инвариантные правила и от локали пользователя не зависят. исходная строка hello остаётся прежней, результаты печатаются как новые строки.
