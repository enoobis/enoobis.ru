начиная с версии c# 8.0 в язык добавлены **асинхронные стримы**, которые упрощают работу с потоками данных в асинхронном режиме. асинхронность в c# существует давно, однако асинхронные методы до этого возвращали один объект, когда асинхронная операция была готова предоставить результат. для возвращения нескольких значений в c# применяются итераторы, но они синхронны: вызов `MoveNext` блокирует вызывающий поток, и такой итератор нельзя ожидать в асинхронном контексте. асинхронные стримы обходят это ограничение и позволяют получать множество значений, возвращая их по мере готовности в асинхронном режиме.

асинхронный стрим представляет собой метод, который обладает тремя характеристиками:

- метод имеет модификатор `async`

- метод возвращает объект `IAsyncEnumerable<T>`. интерфейс `IAsyncEnumerable<T>` определяет метод `GetAsyncEnumerator`, который возвращает `IAsyncEnumerator<T>`:

```c#

public interface IAsyncEnumerable<out T>
{
	IAsyncEnumerator<T> GetAsyncEnumerator(CancellationToken cancellationToken = default);
}

public interface IAsyncEnumerator<out T> : IAsyncDisposable
{
	T Current { get; }
	ValueTask<bool> MoveNextAsync();
}
public interface IAsyncDisposable
{
    ValueTask DisposeAsync();
}
```
- метод содержит выражения `yield return` для последовательного получения элементов из асинхронного стрима

фактически асинхронный стрим объединяет асинхронность и итераторы. простейший пример:

```c#

await foreach (var number in GetNumbersAsync())
{
    Console.WriteLine(number);
}

async IAsyncEnumerable<int> GetNumbersAsync()
{
    for (int i = 0; i < 10; i++)
    {
        await Task.Delay(100);
        yield return i;
    }
}
```
метод `GetNumbersAsync()` и представляет асинхронный стрим. этот метод является асинхронным. его возвращаемый тип - `IAsyncEnumerable<int>`. суть метода в том, что с помощью `yield return` он каждые 100 миллисекунд возвращает очередное число. метод должен вернуть 10 чисел от 0 до 9 с промежутком в 100 миллисекунд. тело такого метода выполняется не в момент вызова, а по ходу `MoveNextAsync`: компилятор строит автомат, и каждый `yield return` завершает очередной шаг перечисления.

для получения данных из стрима используется цикл `foreach`:

```c#
await foreach (var number in GetNumbersAsync())
```
цикл предваряется оператором **await**. каждый раз, когда асинхронный стрим возвращает очередное число, цикл получает его и выводит на консоль. `await foreach` на каждой итерации ожидает `MoveNextAsync`, не блокируя поток. после завершения перечисления вызывается `DisposeAsync` из интерфейса `IAsyncDisposable`, поэтому стрим может освободить асинхронно удерживаемые ресурсы.

асинхронные стримы применяются для получения данных из внешнего хранилища, где элементы приходят по мере готовности операции ввода-вывода. пусть имеется следующий класс хранилища:

```c#

class Repository
{
	string[] data = { "Tom", "Sam", "Kate", "Alice", "Bob" };
	public async IAsyncEnumerable<string> GetDataAsync()
	{
		for (int i = 0; i < data.Length; i++)
		{
			Console.WriteLine($"Получаем {i + 1} элемент");
			await Task.Delay(500);
			yield return data[i];
		}
	}
}
```
для упрощения примера данные здесь представлены в виде простого внутреннего массива строк. для имитации задержки в получении применяется метод `Task.Delay`.

получение этих данных в программе:

```c#

Repository repo = new Repository();
IAsyncEnumerable<string> data = repo.GetDataAsync();
await foreach (var name in data)
{
    Console.WriteLine(name);
}

class Repository
{
    string[] data = { "Tom", "Sam", "Kate", "Alice", "Bob" };
    public async IAsyncEnumerable<string> GetDataAsync()
    {
        for (int i = 0; i < data.Length; i++)
        {
            Console.WriteLine($"Получаем {i + 1} элемент");
            await Task.Delay(500);
            yield return data[i];
        }
    }
}
```
