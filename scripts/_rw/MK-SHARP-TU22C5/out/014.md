условные конструкции направляют выполнение программы по одной из ветвей в зависимости от условия. в c# одна из таких конструкций имеет вид `if..else`.

конструкция `if`/`else` проверяет условие типа `bool` и выполняет соответствующий фрагмент. целое значение условием не является: в отличие от c, неявного преобразования числа в `bool` нет.

простейшая форма состоит из блока `if`:

```c#


if(условие)

{

	выполняемые инструкции

}
```

после служебного слова `if` стоит условие. его тип обязан быть `bool`: литерал `bool`, отношение или любое другое выражение с результатом `bool`. при значении `true` выполняется код в фигурных скобках, составляющих вложенную инструкцию. при значении `false` этот блок пропускается.

пример:

```c#


int num1 = 8;

int num2 = 6;

if(num1 > num2)

{

	Console.WriteLine($"Число {num1} больше числа {num2}");

}
```

первое число больше второго, поэтому отношение `num1 > num2` имеет значение `true`, и управление переходит к инструкции `Console.WriteLine($"Число {num1} больше числа {num2}")`.

если ветвь `if` содержит ровно одну инструкцию, фигурные скобки можно опустить. грамматика принимает одну вложенную инструкцию, а блок в скобках сам является такой инструкцией:

```c#


int num1 = 8;

int num2 = 6;

if (num1 > num2)

    Console.WriteLine($"Число {num1} больше числа {num2}");



// или так

if (num1 > num2) Console.WriteLine($"Число {num1} больше числа {num2}");
```

несколько отношений соединяются логическими операторами. `&&` вычисляет правый операнд только при истинном левом:

```c#


int num1 = 8;

int num2 = 6;

if(num1 > num2 && num1==8)

{

	Console.WriteLine($"Число {num1} больше числа {num2}");

}
```

ветвь `if` выполняется, когда `num1 > num2` равно `true` и `num1==8` равно `true`.

#### выражение else

ветвь для ложного условия записывается блоком `else`:

```c#


int num1 = 8;

int num2 = 6;

if(num1 > num2)

{

	Console.WriteLine($"Число {num1} больше числа {num2}");

}

else

{

	Console.WriteLine($"Число {num1} меньше или равно числу {num2}");

}
```

блок `else` выполняется, когда условие после `if` равно `false`. одна инструкция в `else` тоже записывается без фигурных скобок:

```c#


int num1 = 8;

int num2 = 6;

if(num1 > num2)

	Console.WriteLine($"Число {num1} больше числа {num2}");

else

	Console.WriteLine($"Число {num1} меньше или равно числу {num2}");
```

#### else if

сравнение двух чисел дает три исхода: первое больше второго, первое меньше второго, числа равны. конструкция `else if` добавляет очередное условие и проверяется только если предыдущие условия ложны:

```c#


int num1 = 8;

int num2 = 6;

if(num1 > num2)

{

	Console.WriteLine($"Число {num1} больше числа {num2}");

}

else if (num1 < num2)

{

    Console.WriteLine($"Число {num1} меньше числа {num2}");

}

else

{

    Console.WriteLine("Число num1 равно числу num2");

}
```

цепочку `else if` можно продолжить. условия проверяются сверху вниз, выполняется первая истинная ветвь, остальные пропускаются:

```c#


string name = "Alex";



if (name == "Tom")

    Console.WriteLine("Вас зовут Tomas");

else if (name == "Bob")

    Console.WriteLine("Вас зовут Robert");

else if (name == "Mike")

    Console.WriteLine("Вас зовут Michael");

else

    Console.WriteLine("Неизвестное имя");
```

### тернарная операция

условная операция, ее также называют тернарной, проверяет условие и дает значение. это выражение, а не инструкция: у него есть результат, который можно записать в переменную или передать дальше. синтаксис:

```c#
[первый операнд - условие] ? [второй операнд] : [третий операнд]
```

у операции три операнда. при условии `true` результатом становится второй операнд, при условии `false` третий. вычисляется только выбранный операнд. оба ветвящихся операнда должны приводиться к общему типу, иначе выражение не компилируется.

```c#


int x=3;

int y=2;



int z = x < y ? (x+y) : (x-y);

Console.WriteLine(z);	// 1
```

первый операнд, условие, представлен выражением `x < y`. при `x`, равном 3, и `y`, равном 2, отношение ложно, поэтому выбирается третий операнд `(x-y)`. разность равна 1, и это значение получает `z`. второй операнд `(x+y)` не вычисляется.
