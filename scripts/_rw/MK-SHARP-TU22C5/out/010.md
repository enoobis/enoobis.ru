особый класс операций представляют поразрядные операции. они выполняются над отдельными разрядами числа. числа рассматриваются в двоичном представлении: например, 2 в двоичном представлении равно 10 и имеет два разряда, число 7 равно 111 и имеет три разряда. каждый разряд является битом со значением 0 или 1, и операция задаёт таблицу, по которой из битов операндов получается бит результата. целое в c# занимает фиксированное число разрядов (32 для `int`), поэтому старшие нули в короткой записи ниже опущены только для краткости.

### логические операции

- & (логическое умножение). умножение производится поразрядно, и если у обоих операндов значения разрядов равны 1, операция возвращает 1, иначе возвращается 0. например, в первом случае два числа, 2 и 5. 2 в двоичном виде представляет число 010, а 5 представляет 101. поразрядное умножение (0*1, 1*0, 0*1) даёт 000. во втором случае вместо двойки число 4, у которого в соответствующем разряде 1, так же как и у числа 5, поэтому получается (1*1, 0*0, 0*1) = 100, то есть число 4 в десятичном формате.

```c#


 int x1 = 2; //010

 int y1 = 5;//101

 Console.WriteLine(x1&y1); // выведет 0

            

int x2 = 4; //100

int y2 = 5; //101

Console.WriteLine(x2 & y2); // выведет 4
```

операция `&` на целых не имеет отношения к условному вычислению: оба операнда вычисляются, и результат строится по битам. имя "логическое умножение" здесь историческое: таблица бита совпадает с конъюнкцией.

- | (логическое сложение). операция похожа на логическое умножение и тоже производится по двоичным разрядам, но теперь возвращается единица, если хотя бы у одного числа в данном разряде имеется единица. например:

```c#


int x1 = 2; //010

int y1 = 5;//101

Console.WriteLine(x1|y1); // выведет 7 - 111

int x2 = 4; //100

int y2 = 5;//101

Console.WriteLine(x2 | y2); // выведет 5 - 101
```

для 2 и 5 поразрядная дизъюнкция 010 и 101 даёт 111, то есть 7. для 4 и 5 дизъюнкция 100 и 101 даёт 101, то есть 5.

- ^ (логическое исключающее или). эту операцию также называют xor, нередко её применяют для простого шифрования. здесь опять производятся поразрядные операции. если значения текущего разряда у обоих чисел разные, возвращается 1, иначе возвращается 0. из 45 ^ 102 в качестве результата получается число 75. чтобы расшифровать число, та же операция применяется к результату. xor является обратной самой себе: `(x ^ key) ^ key` восстанавливает `x`, потому что `key ^ key` даёт ноль, а `x ^ 0` равно `x`. подобным образом можно обменять два положительных числа без использования дополнительной переменной. та же цепочка верна для любой пары значений `int`, не только для положительных: она опирается на битовую обратимость xor, а не на знак.

```c#


int x = 45; // Значение, которое надо зашифровать - в двоичной форме 101101

int key = 102; //Пусть это будет ключ - в двоичной форме 1100110



int encrypt = x ^ key; //Результатом будет число 1001011 или 75

Console.WriteLine($"Зашифрованное число: {encrypt}") ;



int decrypt = encrypt ^ key; // Результатом будет исходное число 45

Console.WriteLine($"Расшифрованное число: {decrypt}");
```

```c#


45 ^ 102 = 

0101101

^

1100110

=

1001011

= 75
```

```c#


int a = 9;  // 1001 

int b = 5;  // 0101

 

a = a ^ b;  // a = 1001 ^ 0101 = 1100 = 12

b = a ^ b;  // b = 12 ^ 5 = 1100 ^ 0101 = 1001 = 9

a = a ^ b;  // a = 12 ^ 9 = 1100 ^ 1001 = 0101 = 5



Console.WriteLine($"a: {a}") ;  // 5

Console.WriteLine($"b: {b}") ;  // 9
```

обмен устроен так. после `a = a ^ b` в `a` лежит разность битов исходных значений. `b = a ^ b` восстанавливает прежнее `a`, потому что повторный xor с `b` снимает `b`. затем `a = a ^ b` снимает уже восстановленное исходное `a` и оставляет прежнее `b`. дополнительная переменная не нужна, потому что промежуточное значение хранит информацию об обоих числах.

- ~ (логическое отрицание, или инверсия). ещё одна поразрядная операция, которая инвертирует все разряды: если значение разряда равно 1, оно становится равным нулю, и наоборот.

```c#


int x = 12; 				// 00001100

Console.WriteLine(~x);		// 11110011   или -13
```

для `int` инверсия затрагивает все 32 разряда, включая знак. отсюда соотношение `~x = -x - 1`: инверсия 12 даёт -13, что и печатает вызов.

### представление отрицательных чисел

для записи чисел со знаком в c# применяется **дополнительный код** (two's complement), при котором старший разряд является знаковым. если его значение равно 0, число положительное, и его двоичное представление не отличается от представления беззнакового числа. например, 0000 0001 в десятичной системе равно 1.

если старший разряд равен 1, перед нами отрицательное число. например, 1111 1111 в десятичной системе представляет -1. соответственно, 1111 0011 представляет -13.

чтобы получить из положительного числа отрицательное, его нужно инвертировать и прибавить единицу:

```c#


int x = 12;

int y = ~x;

y += 1;

Console.WriteLine(y);	// -12
```

прибавление единицы к инверсии как раз и даёт арифметическое отрицание: `-x = ~x + 1`. в дополнительном коде сложение и вычитание выполняются теми же битовыми схемами, что и для беззнаковых чисел, а знак оказывается следствием интерпретации старшего разряда.

### операции сдвига

операции сдвига также производятся над разрядами чисел. сдвиг может происходить вправо и влево.

- `x>>y` сдвигает число x вправо на y разрядов. например, `16>>1` сдвигает число 16 (которое в двоичном представлении 10000) на один разряд вправо, то есть в итоге получается 1000, или число 8 в десятичном представлении. противоположный оператор `x<<y` сдвигает биты влево, заполняя освободившиеся младшие разряды нулями.

если исходное число, которое надо сдвинуть в ту или другую сторону, делится на два, то фактически получается умножение или деление на два. поэтому подобную операцию можно использовать вместо непосредственного умножения или деления на два. для неотрицательных значений сдвиг влево на 1 умножает на 2, сдвиг вправо на 1 делит на 2 с отбрасыванием остатка. у знакового `int` сдвиг вправо арифметический: освободившийся старший разряд заполняется прежним знаковым битом, а не нулём. в примерах ниже числа положительные, и этот бит равен нулю. например:

```c#


int a = 16; // в двоичной форме 10000

int b = 2; // в двоичной форме

int c = a << b; // Сдвиг числа 10000 влево на 2 разряда, равно 1000000 или 64 в десятичной системе



Console.WriteLine($"Зашифрованное число: {c}") ;    // 64



int d = a >> b; // Сдвиг числа 10000 вправо на 2 разряда, равно 100 или 4 в десятичной системе

Console.WriteLine($"Зашифрованное число: {d}");     // 4
```

числа, которые участвуют в операциях, необязательно должны быть кратны 2:

```c#


int a = 22; // в двоичной форме 10110

int b = 2; // в двоичной форме

int c = a << b; // Сдвиг числа 10110 влево на 2 разряда, равно 1011000 или 88 в десятичной системе



Console.WriteLine($"Зашифрованное число: {c}") ;    // 88



int d = a >> b; // Сдвиг числа 10110 вправо на 2 разряда, равно 101 или 5 в десятичной системе

Console.WriteLine($"Зашифрованное число: {d}");     // 5
```

биты, ушедшие за границу разрядности, теряются. поэтому сдвиг заменяет умножение или деление на степень двойки только в пределах диапазона типа и только пока вытесненные биты не несут нужной информации.

### пример практического применения операций

поразрядные операции нередко недооценивают, и не всегда видно, для чего они нужны. тем не менее они помогают в решении ряда задач. прежде всего они позволяют манипулировать данными на уровне отдельных битов. один из примеров. есть три числа, которые находятся в диапазоне от 0 до 3:

```c#


int value1 = 3;  // 0b0000_0011

int value2 = 2;  // 0b0000_0010

int value3 = 1;  // 0b0000_0001
```

значения этих чисел не будут больше 3, и эти данные нужно максимально сжать. три числа можно сохранить в одно число. в этом помогают поразрядные операции.

```c#


int value1 = 3;  // 0b0000_0011

int value2 = 2;  // 0b0000_0010

int value3 = 1;  // 0b0000_0001

int result = 0b0000_0000;

// сохраняем в result значения из value1

result = result | value1; // 0b0000_0011

// сдвигаем разряды в result на 2 разряда влево

result = result << 2;   // 0b0000_1100

// сохраняем в result значения из value2

result = result | value2;  // 0b0000_1110

// сдвигаем разряды в result на 2 разряда влево

result = result << 2;   // 0b0011_1000

// сохраняем в result значения из value3

result = result | value3;  // 0b0011_1001



Console.WriteLine(result);  // 57
```

разбор этого кода начинается с определения сохраняемых чисел value1, value2, value3. для хранения результата определена переменная result, которая по умолчанию равна 0. для наглядности ей присвоено значение в бинарном формате:

```c#
int result = 0b0000_0000;
```

подчёркивание в бинарном литерале является разделителем разрядов и на значение не влияет. компилятор его отбрасывает.

первое число сохраняется в result:

```c#


result = result | value1; // 0b0000_0011
```

здесь логическая операция поразрядного сложения: если один из соответствующих разрядов равен 1, результирующий разряд тоже будет равен 1. фактически

```c#


0b0000_0000

+

0b0000_0011

=

0b0000_0011
```

первое число сохранено в result. числа сохраняются по порядку. сначала в result идёт первое число, затем второе и далее третье. поэтому число result сдвигается на два разряда влево (эти числа занимают в памяти не более двух разрядов):

```c#


result = result << 2;   // 0b0000_1100
```

фактически

```c#


0b0000_0011 << 2 =

0b0000_1100
```

сдвиг освобождает два младших бита, не теряя уже записанное значение: оно уезжает в более старшие разряды.

далее повторяется логическая операция сложения, сохраняется второе число:

```c#
result = result | value2;  // 0b0000_1110
```

что эквивалентно

```c#


0b0000_1100

+

0b0000_0010

=

0b0000_1110
```

дизъюнкция с нулевыми младшими битами записывает туда биты второго числа и не портит уже сдвинутые биты первого.

далее повторяется сдвиг на два разряда влево, и сохраняется третье число. в итоге получается двоичное представление `0b0011_1001`. в десятичной системе это число равно 57. само десятичное значение здесь не важно, потому что важны конкретные биты числа. в одно число сохранены три числа, и в переменной result ещё есть свободное место. в реальности не важно, сколько именно битов надо сохранить. в этом примере сохраняются лишь два бита.

для восстановления данных применяется обратный порядок:

```c#


result = 0b0011_1001

// обратное получение данных

int newValue3 = result & 0b000_0011;

// сдвигаем данные на 2 разряда вправо

result = result >> 2;

int newValue2 = result & 0b000_0011;

// сдвигаем данные на 2 разряда вправо

result = result >> 2;

int newValue1 = result & 0b000_0011;

Console.WriteLine(newValue1);    // 3

Console.WriteLine(newValue2);   // 2

Console.WriteLine(newValue3);   // 1
```

числа получаются в порядке, обратном тому, в котором они были сохранены. поскольку каждое сохранённое число занимает лишь два разряда, нужны лишь последние два бита. для этого применяется битовая маска `0b000_0011` и операция логического умножения, которая возвращает 1, если каждый из двух соответствующих разрядов равен 1. операция

```c#
int newValue3 = result & 0b000_0011;
```

эквивалентна

```c#


0b0011_1001

*

0b0000_0011

=

0b0000_0001
```

последнее число равно `0b0000_0001`, или 1 в десятичной системе. маска обнуляет все разряды, кроме выбранных, поэтому соседние упакованные значения в результат не попадают.

если структура данных известна точно, битовая маска составляется так, чтобы получить нужное число:

```c#


result = 0b0011_1001;

int recreatedValue1 = (result & 0b0011_0000) >> 4;

Console.WriteLine(recreatedValue1);
```

здесь получается первое число, которое занимает в числе биты 4 и 5. для этого применяется умножение на битовую маску `0b0011_0000`. затем число сдвигается на 4 разряда вправо.

```c#


0b0011_1001

*

0b0011_0000

=

0b0011_0000

>> 4

=

0b0000_0011
```

маска вырезает нужные биты на их исходных позициях, а сдвиг прижимает их к младшим разрядам, чтобы значение снова лежало в диапазоне 0..3.

если структура, по которой сохраняются данные, известна точно, данные можно сразу записать в нужное место числа result:

```c#


int value1 = 3;  // 0b0000_0011

int value2 = 2;  // 0b0000_0010

int value3 = 1;  // 0b0000_0001

int result = 0b0000_0000;

// сохраняем в result значения из value1

result = result | (value1 << 4);

// сохраняем в result значения из value2

result = result | (value2 << 2);

// сохраняем в result значения из value3

result = result | value3;  // 0b0011_1001



Console.WriteLine(result);  // 57
```

сдвиг перед записью ставит каждое значение в свою пару битов, а дизъюнкция объединяет непересекающиеся группы. результат совпадает с последовательной упаковкой, но промежуточные сдвиги всего регистра не нужны: позиция каждого поля задаётся явно.
