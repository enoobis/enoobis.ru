у многих методов расширения linq параметр имеет тип делегата, чаще всего некоторой специализации `Func<T, TResult>`. у `Where` предикат имеет тип `Func<TSource, bool>`:

```c#


public static IEnumerable<TSource> Where<TSource>(

	this IEnumerable<TSource> source,

	Func<TSource, bool> predicate

)
```

в такой параметр обычно передают лямбда-выражение. туда же подставляется группа методов или локальная функция: компилятор выполняет преобразование группы методов в экземпляр делегата, если сигнатура совместима с `Func<TSource, bool>`. число параметров, их типы и тип результата должны совпасть. лишний параметр или другой возвращаемый тип делают преобразование невозможным.

```c#


string[] people = { "Tom", "Bob", "Kate", "Tim", "Mike", "Sam" };



var result = people.Where(LenghtIs3);



foreach (var person in result)

    Console.WriteLine(person);



bool LenghtIs3(string name) => name.Length == 3;
```

локальная функция `LenghtIs3` проверяет, равна ли длина строки 3 символам. набор, к которому применяется `Where`, содержит объекты `string`, поэтому параметр метода имеет этот тип. возвращаемый тип представлен типом `bool`. значение `true` означает, что объект `string` удовлетворяет условию и попадает в выходную последовательность, значение `false` отбрасывает элемент. сам вызов `Where` отложен: `LenghtIs3` вызывается позже, по одному разу на каждый элемент, когда результат перечисляют.

другой пример. метод `Select()` применяется к коллекции целых чисел и преобразует каждое отобранное число в его квадрат:

```c#


int[] numbers = { -2, -1, 0, 1, 2, 3, 4, 5, 6, 7 };



var result = numbers.Where(i => i > 0).Select(Square);



foreach (int i in result)

    Console.WriteLine(i);



int Square(int n) => n * n;
```

`Select` принимает делегат `Func<TSource, TResult>`. набор состоит из объектов `int`, поэтому входной параметр делегата тоже имеет тип `int`. выходной параметр тоже `int`: квадрат числа в этой арифметике остаётся целочисленным значением, и `Square` возвращает `int`. `Where` перед `Select` оставляет только положительные числа, `Select` отображает каждое из них функцией `n * n`. отрицательные значения и ноль до `Square` не доходят. оба метода остаются отложенными, пока результат не перечисляет цикл `foreach`.
