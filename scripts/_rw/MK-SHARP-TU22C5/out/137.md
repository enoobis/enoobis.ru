асинхронный метод может содержать несколько выражений `await`. когда выполнение доходит до оператора `await`, метод приостанавливается, пока не завершится ожидаемая задача. после завершения управление переходит к следующему оператору `await`, и так далее. так асинхронные задачи вызываются последовательно, в том порядке, в котором записаны. приостановка не блокирует поток: компилятор превращает метод с модификатором `async` в автомат состояний, а продолжение ставится в очередь после завершения задачи.

```c#


await PrintAsync("Hello C#");

await PrintAsync("Hello World");

await PrintAsync("Hello  enoobis.COM");



async Task PrintAsync(string message)

{

    await Task.Delay(2000);     // имитация продолжительной операции

    Console.WriteLine(message);

}
```
консольный вывод этой программы:

```consoletext


Hello C#

Hello World

Hello  enoobis.COM
```
вызовы `PrintAsync` выполняются последовательно, в том порядке, в котором определены в коде. каждая задача выполняется как минимум 2 секунды, поэтому общее время трёх задач составляет как минимум 6 секунд. вывод строго детерминирован: строки появляются в том же порядке, в каком стоят операторы `await`.

такая последовательность нужна, когда одна задача зависит от результатов другой.

последовательное ожидание требуется не всегда. если зависимости между задачами нет, все задачи запускают сразу, а оператор `await` ставят там, где нужно гарантировать завершение, например в конце программы.

```c#


// определяем и запускаем задачи

var task1 = PrintAsync("Hello C#");

var task2 = PrintAsync("Hello World");

var task3 = PrintAsync("Hello  enoobis.COM");



// ожидаем завершения задач

await task1;

await task2;

await task3;



async Task PrintAsync(string message)

{

    await Task.Delay(2000);     // имитация продолжительной операции

    Console.WriteLine(message);

}
```
в этом случае все задачи запускаются и выполняются параллельно, общее время меньше 6 секунд, а консольный вывод не детерминирован. один из возможных вариантов:

```consoletext


Hello  enoobis.COM

Hello C#

Hello World
```
`Task.Delay` регистрирует таймер и возвращает незавершённую задачу, не занимая поток на время ожидания. три такие задачи перекрываются по времени, поэтому общая длительность меньше суммы отдельных задержек.

ожидание набора задач в .net сводится к методу **Task.WhenAll**. метод принимает набор асинхронных задач и ожидает завершения всех этих задач. это аналог статического метода `Task.WaitAll()`, но предназначен непосредственно для асинхронных методов и позволяет применить оператор `await`. `WaitAll` блокирует вызывающий поток. `Task.WhenAll` возвращает новую задачу, и вызывающий поток остаётся свободным.

```c#


// определяем и запускаем задачи

var task1 = PrintAsync("Hello C#");

var task2 = PrintAsync("Hello World");

var task3 = PrintAsync("Hello  enoobis.COM");



// ожидаем завершения всех задач

await Task.WhenAll(task1, task2, task3);



async Task PrintAsync(string message)

{

    await Task.Delay(2000);     // имитация продолжительной операции

    Console.WriteLine(message);

}
```
сначала запускаются три задачи. затем `Task.WhenAll` создаёт новую задачу, которая завершается после завершения всех предоставленных задач, то есть задач `task1`, `task2`, `task3`. оператор `await` ожидает её завершения. если хотя бы одна из задач завершилась с ошибкой, составная задача тоже завершается с ошибкой, но лишь после завершения остальных.

если нужно дождаться, когда будет выполнена хотя бы одна задача из некоторого набора, применяется метод **Task.WhenAny()**. это аналог метода `Task.WaitAny()`: выполнение завершается, когда завершается хотя бы одна задача. для ожидания к `Task.WhenAny()` применяется оператор `await`. метод возвращает ту задачу, которая завершилась первой. остальные продолжают выполняться.

```c#


// определяем и запускаем задачи

var task1 = PrintAsync("Hello C#");

var task2 = PrintAsync("Hello World");

var task3 = PrintAsync("Hello  enoobis.COM");



// ожидаем завершения хотя бы одной задачи

await Task.WhenAny(task1, task2, task3);



async Task PrintAsync(string message)

{   

    await Task.Delay(new Random().Next(1000, 2000));     // имитация продолжительной операции

    Console.WriteLine(message);

}
```
### получение результата

задачи, передаваемые в `Task.WhenAll` и `Task.WhenAny`, могут возвращать некоторое значение. тогда из `Task.WhenAll` можно получить массив, который содержит результаты задач. для набора задач типа `Task<TResult>` результат `await` имеет тип массива `TResult`. порядок элементов в этом массиве совпадает с порядком аргументов. момент завершения отдельной задачи на позицию результата не влияет.

```c#


// определяем и запускаем задачи

var task1 = SquareAsync(4);

var task2 = SquareAsync(5);

var task3 = SquareAsync(6);



// ожидаем завершения всех задач

int[] results = await Task.WhenAll(task1, task2, task3);

// получаем результаты:

foreach (int result in results)

    Console.WriteLine(result);



async Task<int> SquareAsync(int n)

{

    await Task.Delay(1000);

    return n * n;

}
```
метод `SquareAsync` возвращает число `int`, квадрат передаваемого в метод числа. переменная `results` содержит результат вызова `Task.WhenAll`, то есть результаты всех трёх запущенных задач. поскольку все передаваемые в `Task.WhenAll` задачи возвращают `int`, результат `Task.WhenAll` представляет собой массив значений `int`.

после завершения задачи её результат можно получить стандартным образом через свойство `Result`:

```c#


// определяем и запускаем задачи

var task1 = SquareAsync(4);

var task2 = SquareAsync(5);

var task3 = SquareAsync(6);



await Task.WhenAll(task1, task2, task3);

// получаем результат задачи task2

Console.WriteLine($"task2 result: {task2.Result}"); // task2 result: 25



async Task<int> SquareAsync(int n)

{

    await Task.Delay(1000);

    return n * n;

}
```
к свойству `Result` обращаются после `await`, когда задача уже завершена и значение сохранено в ней. чтение `Result` до завершения блокирует вызывающий поток до конца операции.
