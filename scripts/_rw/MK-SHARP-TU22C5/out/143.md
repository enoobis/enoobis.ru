### оператор orderby и метод OrderBy

для сортировки набора данных в linq применяется оператор **orderby**:

```c#

int[] numbers = { 3, 12, 4, 10};
var orderedNumbers = from i in numbers
                     orderby i
                     select i;
foreach (int i in orderedNumbers)
    Console.WriteLine(i);
```
оператор `orderby` принимает критерий сортировки. здесь в качестве критерия выступает само число. результат работы программы:

```consoletext

3
4
10
12
```
числа сортируются в обычном математическом порядке. строки сортируются исходя из алфавитного порядка. без явного компаратора для строк используется сравнение текущей культуры:

```c#

string[] people = { "Tom", "Bob", "Sam" };
var orderedPeople = from p in people orderby p select p;
foreach (var p in orderedPeople)
    Console.WriteLine(p);       // Bob Sam Tom
```
вместо оператора `orderby` можно применять метод расширения **OrderBy()**:

```c#

OrderBy (Func<TSource,TKey> keySelector)
OrderBy (Func<TSource,TKey> keySelector, IComparer<TKey>? comparer);
```
первая версия метода получает делегат, который через параметр получает элемент коллекции и который возвращает значение, применяемое для сортировки, то есть ключ. вторая версия позволяет также задать принцип сортировки через реализацию интерфейса `IComparer<TKey>`. оператор `orderby` для последовательности в памяти транслируется в вызов `OrderBy`.

предыдущие два примера с помощью метода `OrderBy`:

```c#

int[] numbers = { 3, 12, 4, 10 };
var orderedNumbers = numbers.OrderBy(n=>n);
foreach (int i in orderedNumbers)
    Console.WriteLine(i);

string[] people = { "Tom", "Bob", "Sam" };
var orderedPeople = people.OrderBy(p=>p);
foreach (var p in orderedPeople)
    Console.WriteLine(p);
```
### сортировка сложных объектов

для выборки сложных объектов критерием сортировки указывают свойство класса объекта:

```c#

var people = new List<Person>
{
    new Person("Tom", 37),
    new Person("Sam", 28),
    new Person("Tom", 22),
    new Person("Bob", 41),
};
// с помощью оператора orderby
var sortedPeople1 = from p in people
                  orderby p.Name
                  select p;

foreach (var p in sortedPeople1)
    Console.WriteLine($"{p.Name} - {p.Age}");

// с помощью метода OrderBy
var sortedPeople2 = people.OrderBy(p => p.Name);

foreach (var p in sortedPeople2)
    Console.WriteLine($"{p.Name} - {p.Age}");

record class Person(string Name, int Age);
```
### сортировка по возрастанию и убыванию

по умолчанию оператор `orderby` и метод `OrderBy` производят сортировку по возрастанию. с помощью ключевых слов **ascending** (сортировка по возрастанию) и **descending** (сортировка по убыванию) для оператора `orderby` можно явным образом указать направление сортировки. например, массив чисел сортируется по убыванию:

```c#

int[] numbers = { 3, 12, 4, 10 };
var orderedNumbers = from i in numbers
                     orderby i descending
                     select i;
foreach (int i in orderedNumbers)
    Console.WriteLine(i);   // 12 10 4 3
```
для сортировки по убыванию применяется метод **OrderByDescending()**, который работает аналогично `OrderBy` за исключением направления сортировки:

```c#

int[] numbers = { 3, 12, 4, 10 };
var orderedNumbers = numbers.OrderByDescending(n => n);
foreach (int i in orderedNumbers)
    Console.WriteLine(i);   // 12 10 4 3
```
### множественные критерии сортировки

в наборах сложных объектов сортировку иногда задают сразу по нескольким полям. для этого в запросе linq все критерии указываются в порядке приоритета через запятую:

```c#

var people = new List<Person>
{
    new Person("Tom", 37),
    new Person("Sam", 28),
    new Person("Tom", 22),
    new Person("Bob", 41),
};
// с помощью оператора orderby
var sortedPeople1 = from p in people
                  orderby p.Name, p.Age
                  select p;

foreach (var p in sortedPeople1)
    Console.WriteLine($"{p.Name} - {p.Age}");
```
результат программы:

```consoletext

Bob - 41
Sam - 28
Tom - 22
Tom - 37
```
для разных критериев сортировки можно установить направление:

```c#

// с помощью оператора orderby
var sortedPeople1 = from p in people
                  orderby p.Name, p.Age descending  // сортировка по возрасту по убыванию
                  select p;
```
с помощью методов расширения то же самое делается через метод **ThenBy()** (для сортировки по возрастанию) и **ThenByDescending()** (для сортировки по убыванию):

```c#

var sortedPeople2 = people.OrderBy(p => p.Name).ThenByDescending(p=>p.Age);
```
`OrderBy` фиксирует первичный ключ. `ThenBy` и `ThenByDescending` добавляют последующие ключи и вызываются на уже упорядоченной последовательности. результат будет аналогичен предыдущему: имя по возрастанию, а при равных именах возраст по убыванию.

### переопределение критерия сортировки

с помощью реализации `IComparer<T>` переопределяют критерии сортировки, если стандартное сравнение не годится. строки по умолчанию сортируются в алфавитном порядке. сортировка строк по их длине задаётся собственным компаратором:

```c#

string[] people = new[]{"Kate", "Tom", "Sam", "Mike", "Alice"};
var sortedPeople = people.OrderBy(p => p, new CustomStringComparer());

foreach (var p in sortedPeople)
    Console.WriteLine(p);

// сравнение по длине строки
class CustomStringComparer : IComparer<String>
{
    public int Compare(string? x, string? y)
    {
        int xLength = x?.Length ?? 0; // если x равно null, то длина 0
        int yLength = y?.Length ?? 0;
        return xLength - yLength;
    }
}
```
интерфейс `IComparer<T>` типизируется типом сортируемых данных (здесь типом `String`). для реализации этого интерфейса необходимо определить метод `Compare`. он возвращает число: если первый параметр больше второго, то число больше 0, если меньше, то число меньше 0. если оба параметра равны, то возвращается 0. тот же контракт используют `Comparer<T>.Default` и методы сортировки массивов.

если параметр равен `null`, длина строки считается равной 0. с помощью разницы длин строк из обоих параметров определяется, какой из них больше.

результат программы:

```consoletext

Tom
Sam
Kate
Mike
Alice
```
сортировка `OrderBy` в linq to objects устойчива: элементы с равным ключом сохраняют исходный относительный порядок. длины `"Tom"` и `"Sam"` равны, длины `"Kate"` и `"Mike"` равны, и внутри одной длины строки идут в том порядке, в каком стояли в массиве.
