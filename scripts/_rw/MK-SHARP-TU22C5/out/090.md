кортеж группирует набор значений. синтаксис появился в c# 7.0. под ним лежит структура `System.ValueTuple`, значимый тип с открытыми изменяемыми полями. класс `System.Tuple` из более ранних версий .net устроен иначе: он ссылочный и неизменяемый. имена элементов в синтаксисе c# 7 существуют на этапе компиляции и сохраняются в метаданных атрибутом. во время выполнения поля называются `Item1`, `Item2` и далее по порядку.

кортеж записывается как список значений в круглых скобках:

```c#

var tuple = (5, 10);
```

у `tuple` два значения, 5 и 10. к каждому обращаются через поле с именем:

```c#
Item[порядковый_номер_поля_в_кортеже]
```

например:

```c#

var tuple = (5, 10);
Console.WriteLine(tuple.Item1); // 5
Console.WriteLine(tuple.Item2); // 10
tuple.Item1 += 26;
Console.WriteLine(tuple.Item1); // 31
```

тип здесь выведен. его можно указать и явно. число элементов типа совпадает с числом элементов кортежа:

```c#
(int, int) tuple = (5, 10);
```

два элемента имеют тип `int`, поэтому в типе переменной стоят два `int`. другой состав:

```c#
(string, int, double) person = ("Tom", 25, 81.23);
```

первый элемент имеет тип `string`, второй `int`, третий `double`.

полям можно дать собственные имена:

```c#

var tuple = (count:5, sum:10);
Console.WriteLine(tuple.count); // 5
Console.WriteLine(tuple.sum); // 10
```

после этого к полям обращаются по именам `count` и `sum`. имена `Item1` и `Item2` обозначают те же ячейки.

кортеж разбирается на отдельные переменные. такая запись называется декомпозицией:

```c#

var (name, age) = ("Tom", 23);
Console.WriteLine(name);    // Tom
Console.WriteLine(age);     // 23
```

той же записью меняются местами значения двух переменных:

```c#

string main = "Java";
string second = "C#";
(main, second) = (second, main);
Console.WriteLine(main);    // C#
Console.WriteLine(second);  // Java
```

справа строится новый кортеж из текущих значений, слева они раскладываются обратно. отдельная временная переменная в исходном тексте не нужна. тот же приём используется в сортировке массива: пара элементов меняется местами, если левый больше правого.

```c#

int[] nums = { 54, 7, -41, 2, 4, 2, 89, 33, -5, 12 };

// сортировка
for (int i = 0; i < nums.Length - 1; i++)
{
    for (int j = i + 1; j < nums.Length; j++)
    {
        if (nums[i] > nums[j])
            (nums[i], nums[j]) =(nums[j], nums[i]);
    }
}

// вывод
Console.WriteLine("Вывод отсортированного массива");
for (int i = 0; i < nums.Length; i++)
{
    Console.WriteLine(nums[i]);
}
```

### кортеж как результат метода

метод возвращает одно значение. когда результатов несколько, их собирают в кортеж, и возвращаемым значением становится он:

```c#

var tuple = GetValues();
Console.WriteLine(tuple.Item1); // 1
Console.WriteLine(tuple.Item2); // 3

(int, int) GetValues()
{
    var result = (1, 3);
    return result;
}
```

`GetValues()` возвращает кортеж из двух значений типа `int`. метод отдаёт два числа одним значением. кортеж по-прежнему записывается списком в круглых скобках.

второй пример считает сумму и число элементов массива:

```c#

var tuple = GetValuesData(new int[] { 1, 2, 3, 4, 5, 6, 7 });
Console.WriteLine(tuple.count);
Console.WriteLine(tuple.sum);

(int sum, int count) GetValuesData(int[] numbers)
{
    var result = (sum: 0, count: numbers.Length);
    foreach(var n in numbers)
    {
        result.sum += n;
    }
    return result;
}
```

возвращаемый тип назван `(int sum, int count)`. внутри сумма накапливается в `result.sum`, а `count` сразу равен длине массива. вызывающий код читает оба поля по этим именам.

### кортеж как параметр метода

кортеж передаётся в метод как один аргумент:

```c#

PrintPerson(("Tom", 37));   // Tom - 37
PrintPerson(("Bob", 41));   // Bob - 41


void PrintPerson((string name, int age) person)
{
    Console.WriteLine($"{person.name} - {person.age}");
}
```

`PrintPerson` принимает кортеж из двух элементов. первый имеет тип `string` и имя `name`, второй имеет тип `int` и имя `age`. метод печатает имя и возраст.
