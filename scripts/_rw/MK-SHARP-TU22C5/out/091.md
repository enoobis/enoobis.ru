records появились в c# 9 и по умолчанию являются ссылочным типом. тип record может быть неизменяемым и уже при объявлении получает члены, которые для класса и структуры пришлось бы писать вручную: сравнение по значению, копию с изменением отдельных свойств и текстовое представление состояния.

неизменяемый тип нужен там, где требуется гарантия, что данные объекта после создания не изменятся. в .net такие типы уже есть. классический пример: `string`. содержимое строки после создания не меняется, операция, которая выглядит как изменение, возвращает новый экземпляр.

с версии c# 10 ту же форму можно придать структуре. отсюда два вида: record-класс и record-структура.

тип объявляется ключевым словом **record**. у record-класса слово `class` можно опустить:

```c#

public record Person
{
    public string Name { get; set; }
    public Person(string name) => Name = name;
}
```

та же запись со словом `class`:

```c#

public record class Person
{
    public string Name { get; set; }
    public Person(string name) => Name = name;
}
```

у record-структуры слово **struct** обязательно:

```c#

public record struct Person
{
    public string Name { get; set; }
    public Person(string name) => Name = name;
}
```

одно слово **record** неизменяемости не даёт. объект record неизменяем только при дополнительных условиях. со свойством, у которого обычный сеттер, значение меняется после создания:

```c#

var person = new Person("Tom");
person.Name = "Bob";
Console.WriteLine(person.Name); // Bob - данные изменились

public record Person
{
    public string Name { get; set; }
    public Person(string name) => Name = name;
}
```

ошибки здесь нет, свойство `Name` перезаписывается. чтобы объект был неизменяемым, вместо обычного сеттера у свойства ставится модификатор **init**:

```c#

var person = new Person("Tom");
person.Name = "Bob";    // ! ошибка - свойство изменить нельзя

public record Person
{
    public string Name { get; init; }
    public Person(string name) => Name = name;
}
```

присвоить `Name` после конструктора уже нельзя. аксессор `init` принимает значение в конструкторе и в инициализаторе объекта. дальнейшая запись в свойство не компилируется.

во многом record-класс устроен как обычный класс, record-структура как обычная структура. record-класс может быть абстрактным, может наследовать другой record-класс и может закрывать наследование модификатором `sealed`. отличия от класса и структуры разобраны ниже.

### сравнение на равенство

для record компилятор порождает метод **Equals()** и согласованный с ним `GetHashCode`. два record сравниваются по значениям членов:

```c#

var person1 = new Person("Tom");
var person2 = new Person("Tom");
Console.WriteLine(person1.Equals(person2)); // true

var user1 = new User("Tom");
var user2 = new User("Tom");
Console.WriteLine(user1.Equals(user2));     // false

public record Person
{
    public string Name { get; init; }

    public Person(string name) => Name = name;
}
public class User
{
    public string Name { get; init; }
    public User(string name) => Name = name;
}
```

два объекта `Person` равны, потому что равны значения `Name`. два объекта класса `User` с тем же `Name` не равны: у класса `Equals` по умолчанию сравнивает ссылки, и это разные экземпляры. сравнение record идёт по значению.

для record также сразу определены операторы **==** и **!=**. они тоже сравнивают значения:

```c#

var person1 = new Person("Tom");
var person2 = new Person("Tom");
Console.WriteLine(person1 == person2); // true

var user1 = new User("Tom");
var user2 = new User("Tom");
Console.WriteLine(user1 == user2);     // false
```

у класса `User` оператор `==` остаётся ссылочным, поэтому два разных экземпляра дают `false`.

### оператор with

record поддерживает инициализацию оператором **with**. у обычного класса этого оператора нет. `with` строит одну record по другой:

```c#

var tom = new Person("Tom", 37);
var sam = tom with { Name = "Sam" };
Console.WriteLine($"{sam.Name} - {sam.Age}"); // Sam - 37

public record Person
{
    public string Name { get; init; }
    public int Age { get; init; }
    public Person(string name, int age)
    {
        Name = name; Age = age;
    }
}
```

после исходной record стоит **with**, а в фигурных скобках перечислены свойства, которые в копии получают другие значения. компилятор порождает конструктор копирования. `with` вызывает его и затем записывает указанные свойства. у `sam` свойство `Age` взято у `tom` и равно 37, свойство `Name` заменено на `Sam`. запись короче ручного копирования каждого поля, когда свойств много, а меняются одно или два.

если копируются все свойства, фигурные скобки оставляют пустыми:

```c#

var person1 = new Person("Tom", 37);
var person2 = person1 with { };
```

### позиционные records

данные свойств можно принять прямо параметрами конструктора и сократить объявление. полная запись `Person` выглядит так:

```c#

public record Person
{
    public string Name { get; init; }
    public int Age { get; init; }
    public Person(string name, int age)
    {
        Name = name; Age = age;
    }
    public void Deconstruct(out string name, out int age) => (name, age) = (Name, Age);
}
```

кроме конструктора здесь есть деконструктор `Deconstruct`. он раскладывает объект `Person` на кортеж значений. применение:

```c#

var person = new Person ("Tom", 37);
Console.WriteLine(person.Name); // Tom

var (personName, personAge) = person;

Console.WriteLine(personAge);     // 37
Console.WriteLine(personName);    // Tom
```

эту запись сокращают до позиционного record:

```c#

public record Person(string Name, int Age);
```

этим объявление типа исчерпывается. для `Person` компилятор создаёт конструктор с двумя параметрами, свойства `Name` и `Age`, в которые эти параметры записываются, и деконструктор. использование совпадает с полной формой:

```c#

var person = new Person("Tom", 37);
Console.WriteLine(person); // Tom

var (personName, personAge) = person;

Console.WriteLine(personAge);     // 37
Console.WriteLine(personName);    // Tom

public record Person(string Name, int Age);
```

позиционные параметры можно совместить с обычными свойствами:

```c#

var person = new Person("Tom", 37) { Company = "Google"};
Console.WriteLine(person.Company); // Google
person.Company = "Microsoft";
Console.WriteLine(person.Company); // Microsoft

public record Person(string Name, int Age)
{
    public string Company { get; set; } = "";
}
```

`Name` и `Age` приходят из позиционного конструктора. `Company` объявлено отдельно и имеет обычный сеттер, поэтому его задают инициализатором и затем меняют. пустая строка в объявлении свойства является начальным значением, если инициализатор его не задал.

### позиционные структуры для чтения

у позиционного record-класса свойства, заданные параметрами конструктора, по умолчанию получают модификатор **init**. после конструктора их уже не изменить:

```c#

var person = new Person("Tom", 37);
person.Name = "Bob";	// ! Ошибка - значение нельзя изменить

public record Person(string Name, int Age);
```

правило относится только к свойствам, которые пришли из позиционного конструктора. отдельно объявленное свойство с обычным сеттером, как `Company` выше, менять можно.

у позиционной record-структуры те же свойства получают обычные сеттеры:

```c#

var person = new Person("Tom", 37);
person.Name = "Bob";
Console.WriteLine(person.Name); // Bob - значение изменилось
// структура record
public record struct Person(string Name, int Age);
```

чтобы у свойств структуры вместо сеттера стоял **init**, структуру помечают словом **readonly**:

```c#

var person = new Person("Tom", 37);
person.Name = "Bob";	// ! Ошибка - значение свойства нельзя изменить

// структура record доступна только для чтения
public readonly record struct Person(string Name, int Age);
```

### метод ToString

для record компилятор также порождает метод **ToString()**. он печатает состояние объекта в виде имени типа и значений свойств:

```c#

var person = new Person("Tom", 37);
Console.WriteLine(person); // Person {Name = Tom, Age = 37}

public record Person(string Name, int Age);
```

### наследование

record-класс наследуется по тем же правилам, что обычный класс. record-структура, как и прочая структура, в наследовании классов не участвует.

```c#

var tom = new Person("Tom", 37);
var bob = new Employee("Bob", 41, "Microsoft");
Console.WriteLine(tom); // Person {Name = Tom, Age = 37}
Console.WriteLine(bob); // Person {Name = Bob, Age = 41, Company = Microsoft}

public record Person(string Name, int Age);
public record Employee(string Name, int Age, string Company) : Person(Name, Age);
```

`Employee` наследует `Person`. позиционный конструктор наследника принимает `Name`, `Age` и `Company` и передаёт имя и возраст конструктору базового record. комментарии к выводу фиксируют текст синтезированного `ToString` для обоих объектов: состояние `tom` и состояние `bob` с добавленным `Company`.
