перегрузка операторов преобразования типов стоит рядом с перегрузкой обычных операторов. в обоих случаях для пользовательского типа задаётся операция, которую язык для встроенных типов уже умеет применять сам: здесь это преобразование значения одного типа в значение другого.

раньше рассматривались явные и неявные преобразования примитивных типов. например:

```c#

int x = 50;
byte y = (byte)x; // явное преобразование от int к byte
int z = y;  // неявное преобразование от byte к int
```

`int` сужается к `byte` только явной операцией приведения: часть значения может не поместиться в меньший тип. обратное направление, от `byte` к `int`, язык выполняет неявно: всякое значение `byte` представимо как `int`.

ту же границу между явной и неявной формой можно провести для собственных типов и описать, как именно значение одного типа получается из значения другого. описание оформляется перегрузкой оператора преобразования:

```c#

public static implicit|explicit operator Тип_в_который_надо_преобразовать(исходный_тип param)
{
	// логика преобразования
}
```

после модификаторов **public static** стоит **explicit**, если преобразование явное и в точке использования нужна операция приведения, либо **implicit**, если преобразование неявное и приведение не пишется. затем идёт ключевое слово **operator**, тип результата и единственный параметр: значение, которое преобразуется. оператор статичен, не привязан к конкретному экземпляру и выбирается компилятором при разрешении преобразований на этапе компиляции.

ниже тип `Counter` хранит число секунд в свойстве `Seconds` и задаёт оба направления между `Counter` и `int`:

```c#

class Counter
{
	public int Seconds { get; set; }

	public static implicit operator Counter(int x)
	{
		return new Counter { Seconds = x };
	}
	public static explicit operator int(Counter counter)
	{
		return counter.Seconds;
	}
}
```

первый оператор неявно строит `Counter` из `int`: создаётся новый экземпляр, и переданное число записывается в `Seconds`. второй оператор явно извлекает из `Counter` число: результатом становится текущее значение `Seconds`.

применение этих операторов:

```c#

Counter counter1 = new Counter { Seconds = 23 };

int x = (int)counter1;
Console.WriteLine(x);   // 23

Counter counter2 = x;
Console.WriteLine(counter2.Seconds);  // 23
```

направление из `Counter` в `int` объявлено как **explicit**, поэтому без операции приведения выражение не компилируется:

```c#
int x = (int)counter1;
```

направление из `int` в `Counter` объявлено как **implicit**, поэтому присваивание `Counter counter2 = x` записывается без приведения. какое направление сделать явным, а какое неявным, решает автор типа. по руководствам языка неявным оставляют преобразование, которое не теряет информацию и не завершается исключением; явным помечают сужение, возможную потерю или преобразование, о котором вызывающий код должен сказать прямо. для пары `Counter` и `int` оба варианта язык принимает, и выбор фиксирует автор типа.

оператор преобразования, объявленный в некотором типе, обязан преобразовывать из этого типа или в этот тип. оператор внутри `Counter` либо принимает `Counter`, либо возвращает `Counter`. компилятор ищет пользовательское преобразование только в типе источника и в типе приёмника. в одной цепочке преобразований участвует не больше одного пользовательского оператора: до него и после него могут стоять стандартные преобразования, но два пользовательских оператора подряд не соединяются.

дальше то же правило применяется к двум составным типам. рядом с `Counter` объявлен `Timer`:

```c#

class Timer
{
	public int Hours { get; set; }
	public int Minutes { get; set; }	
	public int Seconds { get; set; }
}
class Counter
{
	public int Seconds { get; set; }

	public static implicit operator Counter(int x)
	{
		return new Counter { Seconds = x };
	}
	public static explicit operator int(Counter counter)
	{
		return counter.Seconds;
	}
	public static explicit operator Counter(Timer timer)
	{
		int h = timer.Hours * 3600;
		int m = timer.Minutes * 60;
		return new Counter { Seconds = h + m + timer.Seconds };
	}
	public static implicit operator Timer(Counter counter)
	{
		int h = counter.Seconds / 3600;
		int m = (counter.Seconds % 3600) / 60;
		int s = counter.Seconds % 60;
		return new Timer { Hours = h, Minutes = m, Seconds = s };
	}
}
```

`Timer` хранит часы, минуты и секунды. `Counter` хранит одну величину, суммарные секунды. преобразование из `Timer` в `Counter` объявлено явным: часы переводятся в секунды умножением на 3600, минуты на 60, и три слагаемых складываются. обратное преобразование неявное: из суммарных секунд целочисленным делением получаются часы, из остатка от деления на 3600 получаются минуты, последним остатком от деления на 60 получаются секунды. так 3675 секунд дают 1 час, 1 минуту и 15 секунд: 3675 = 1 * 3600 + 1 * 60 + 15.

применение этих преобразований:

```c#

Counter counter1 = new Counter { Seconds = 115 };

Timer timer = counter1;
Console.WriteLine($"{timer.Hours}:{timer.Minutes}:{timer.Seconds}"); // 0:1:55

Counter counter2 = (Counter)timer;
Console.WriteLine(counter2.Seconds);  //115
```

115 секунд неявно становятся таймером 0 часов, 1 минута и 55 секунд. обратный шаг записан явным приведением и снова даёт 115.
