для работы с каталогами в пространстве имён `System.IO` предусмотрены два класса: `Directory` и `DirectoryInfo`.

### класс `Directory`

`Directory` является статическим классом: экземпляр не создаётся, и каждая операция получает путь отдельным аргументом. часть методов:

- `CreateDirectory(path)`: создаёт каталог по пути `path`. недостающие промежуточные каталоги создаются вместе с конечным
- `Delete(path)`: удаляет каталог по пути `path`
- `Exists(path)`: проверяет, есть ли каталог по пути `path`. если есть, возвращается `true`, если нет, возвращается `false`
- `GetCurrentDirectory()`: возвращает путь текущего каталога процесса
- `GetDirectories(path)`: возвращает пути подкаталогов каталога `path`
- `GetFiles(path)`: возвращает пути файлов в каталоге `path`
- `GetFileSystemEntries(path)`: возвращает пути и подкаталогов, и файлов каталога `path`
- `Move(sourceDirName, destDirName)`: перемещает каталог из `sourceDirName` в `destDirName`
- `GetParent(path)`: возвращает родительский каталог
- `GetLastWriteTime(path)`: возвращает время последнего изменения каталога
- `GetLastAccessTime(path)`: возвращает время последнего обращения к каталогу
- `GetCreationTime(path)`: возвращает время создания каталога

время в трёх последних методах относится к метаданным файловой системы, а не к содержимому файлов внутри каталога.

### класс `DirectoryInfo`

`DirectoryInfo` покрывает создание, удаление, перемещение и чтение сведений о каталоге. по набору операций класс близок к `Directory`, но не является статическим: экземпляр хранит путь, переданный конструктору.

```c#
public DirectoryInfo (string path);
```

методы класса `DirectoryInfo`:

- `Create()`: создаёт каталог по пути экземпляра
- `CreateSubdirectory(path)`: создаёт подкаталог по пути `path`, относительному к каталогу экземпляра. промежуточные части `path` создаются тоже
- `Delete()`: удаляет каталог
- `GetDirectories()`: возвращает подкаталоги массивом `DirectoryInfo`
- `GetFiles()`: возвращает файлы массивом `FileInfo`
- `MoveTo(destDirName)`: перемещает каталог в `destDirName`

свойства класса `DirectoryInfo`:

- `CreationTime`: время создания каталога
- `LastAccessTime`: время последнего доступа к каталогу
- `LastWriteTime`: время последнего изменения каталога
- `Exists`: существует ли каталог на момент вызова. это снимок, а не подписка на изменения файловой системы
- `Parent`: родительский каталог
- `Root`: корневой каталог
- `Name`: имя каталога, то есть последняя компонента пути
- `FullName`: полный путь к каталогу

### `Directory` или `DirectoryInfo`

возможности двух классов совпадают по существу, и выбор зависит от того, сколько операций выполняется над одним каталогом. одна или две операции проще выражаются статическими методами `Directory`: путь каждый раз передаётся строкой. последовательность операций над одним и тем же каталогом выражается экземпляром `DirectoryInfo`. причина в устройстве вызовов. методы `Directory` при каждом обращении заново проверяют путь, в документации базовой библиотеки эта проверка названа проверкой безопасности. у `DirectoryInfo` путь уже связан с экземпляром, и повторять такую проверку на каждой операции не обязательно.

### получение списка файлов и подкаталогов

```c#
string dirName = "C:\\";
// если папка существует
if (Directory.Exists(dirName))
{
    Console.WriteLine("Подкаталоги:");
    string[] dirs = Directory.GetDirectories(dirName);
    foreach (string s in dirs)
    {
        Console.WriteLine(s);
    }
    Console.WriteLine();
    Console.WriteLine("Файлы:");
    string[] files = Directory.GetFiles(dirName);
    foreach (string s in files)
    {
        Console.WriteLine(s);
    }
}
```

в обычном строковом литерале обратная косая черта начинает escape-последовательность, поэтому в пути её пишут дважды: `"C:\\"`. в дословном литерале перед строкой стоит `@`, и черта пишется один раз: `@"C:\Program Files"`. оба литерала обозначают один и тот же путь. статические методы возвращают полные пути строками.

тот же обход через экземпляр даёт не строки, а объекты `DirectoryInfo` и `FileInfo`. полный путь читается из `FullName`:

```c#
string dirName = "C:\";

var directory = new DirectoryInfo(dirName);

if (directory.Exists)
{
    Console.WriteLine("Подкаталоги:");
    DirectoryInfo[] dirs = directory.GetDirectories();
    foreach (DirectoryInfo dir in dirs)
    {
        Console.WriteLine(dir.FullName);
    }
    Console.WriteLine();
    Console.WriteLine("Файлы:");
    FileInfo[] files = directory.GetFiles();
    foreach (FileInfo file in files)
    {
        Console.WriteLine(file.FullName);
    }
}
```

литерал пути в этом фрагменте записан с одной обратной чертой внутри обычных кавычек. в c# такая запись не компилируется: черта экранирует закрывающую кавычку. для корня диска c работают формы `"C:\\"` и `@"C:\"`.

### фильтрация папок и файлов

методы перечисления принимают второй аргумент, шаблон имени. в шаблоне два метасимвола. `*` соответствует любой последовательности символов, в том числе пустой. `?` соответствует ровно одному символу. шаблон сравнивается с именем внутри каталога, а не с полным путём.

каталоги, имя которых начинается с `books` и дальше содержит точку, отбирает шаблон `books*.`:

```c#
// класс Directory
string[] dirs = Directory.GetDirectories(dirName, "books*.");

// класс DirectoryInfo
var directory = new DirectoryInfo(dirName);
DirectoryInfo[] dirs = directory.GetDirectories("books*.");
```

файлы с расширением `.exe` отбирает шаблон `*.exe`:

```c#
// класс Directory
string[] files = Directory.GetFiles(dirName, "*.exe");

// класс DirectoryInfo
var directory = new DirectoryInfo(dirName);
FileInfo[] files = directory.GetFiles("*.exe");
```

сопоставление шаблона следует правилам файловой системы. в windows регистр в именах не различается, в linux различается.

### создание каталога

вариант на `DirectoryInfo`:

```c#
string path = @"C:\SomeDir";
string subpath = @"program\avalon";
DirectoryInfo dirInfo = new DirectoryInfo(path);
if (!dirInfo.Exists)
{
    dirInfo.Create();
}
dirInfo.CreateSubdirectory(subpath);
```

сначала читается `Exists`. если каталога нет, его создаёт `Create`. затем `CreateSubdirectory` строит относительный путь `program\avalon`. в итоге появляется каталог `C:\SomeDir\program\avalon`.

статические методы дают тот же каталог. `CreateDirectory` сам создаёт недостающие промежуточные компоненты, поэтому второй вызов получает уже составной путь:

```c#
string path = @"C:\SomeDir";
string subpath = @"program\avalon";
if (!Directory.Exists(path))
{
    Directory.CreateDirectory(path);
}
Directory.CreateDirectory($"{path}/{subpath}");
```

во втором вызове части пути соединены символом `/`. для api пространства `System.IO` на windows эта черта допустима наравне с обратной.

### получение информации о каталоге

```c#
string dirName = "C:\\Program Files";

DirectoryInfo dirInfo = new DirectoryInfo(dirName);

Console.WriteLine($"Название каталога: {dirInfo.Name}");
Console.WriteLine($"Полное название каталога: {dirInfo.FullName}");
Console.WriteLine($"Время создания каталога: {dirInfo.CreationTime}");
Console.WriteLine($"Корневой каталог: {dirInfo.Root}");
```

фрагмент строит `DirectoryInfo` для `C:\Program Files` и печатает четыре свойства: имя (`Name`), полный путь (`FullName`), время создания (`CreationTime`) и корень (`Root`).

### удаление каталога

вызов `Delete` без дополнительного аргумента для непустого каталога завершается исключением: внутри остаются файлы или подкаталоги. рекурсивное удаление передаёт в `Delete` аргумент типа `bool` со значением `true`, и тогда удаляется каталог вместе с содержимым. перед удалением проверяется наличие каталога. если пути нет, вызов тоже выбрасывает исключение. проверка `Exists` и последующий `Delete` не атомарны: каталог может исчезнуть между двумя вызовами, и исключение всё равно возникнет.

```c#
string dirName = @"C:\SomeDir";

DirectoryInfo dirInfo = new DirectoryInfo(dirName);
if (dirInfo.Exists)
{
    dirInfo.Delete(true);
    Console.WriteLine("Каталог удален");
}
else
{
    Console.WriteLine("Каталог не существует");
}
```

тот же порядок у статического метода. признак рекурсии передаётся вторым аргументом `Directory.Delete`:

```c#
string dirName = @"C:\SomeDir";
if (Directory.Exists(dirName))
{
    Directory.Delete(dirName, true);
    Console.WriteLine("Каталог удален");
}
else
{
    Console.WriteLine("Каталог не существует");
}
```

### перемещение каталога

каталог назначения не должен существовать в момент вызова. в него переносится содержимое исходного каталога, и существующий путь назначения вызов не перезаписывает: операция завершается исключением.

```c#
string oldPath = @"C:\SomeFolder";
string newPath = @"C:\SomeDir";
DirectoryInfo dirInfo = new DirectoryInfo(oldPath);
if (dirInfo.Exists && !Directory.Exists(newPath))
{
    dirInfo.MoveTo(newPath);
	// или так
    // Directory.Move(oldPath, newPath);
}
```

перемещение в пределах одного родительского каталога, как в фрагменте выше, совпадает с переименованием: меняется последняя компонента пути, дерево содержимого сохраняется. источник и назначение должны лежать на одном томе, иначе возникает `IOException`.
