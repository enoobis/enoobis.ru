в c# 8.0 появились индексы и диапазоны. они задают позицию и полуинтервал в последовательности и сокращают код, который раньше вручную вычислял границы подмассива. для этого в библиотеке есть два типа: **System.Index** и **System.Range**. оба являются структурами и копируются по значению. Index обозначает одну позицию, Range обозначает пару границ.

### индексы

индекс хранит целое смещение. при создании ему передаётся это смещение, в том числе неявным преобразованием из int:

```c#


Index myIndex = 2;
```

значение 2 указывает на третий элемент последовательности, потому что нумерация начинается с нуля.

оператор **^** строит индекс от конца последовательности:

```c#


Index myIndex = ^2;
```

`^2` указывает на второй элемент с конца, то есть на предпоследний. для последовательности длины n индекс `^k` соответствует обычному смещению `n - k`. `^1` всегда обозначает последний элемент, `^0` обозначает позицию сразу за последним элементом и как одиночный индекс чтения не используется, зато служит естественной верхней границей диапазона.

чтение массива через оба вида индекса:

```c#


Index myIndex1 = 2;		// третий элемент

Index myIndex2 = ^2;	// предпоследний элемент



string[] people = { "Tom", "Bob", "Sam", "Kate", "Alice" };

string selected1 = people[myIndex1];    // Sam

string selected2 = people[myIndex2];    // Kate

Console.WriteLine(selected1);   

Console.WriteLine(selected2);
```

`people[2]` и `people[myIndex1]` дают Sam, третий элемент. `people[^2]` и `people[myIndex2]` дают Kate, предпоследний элемент массива из пяти строк.

ту же выборку делают обычные целочисленные индексы:

```c#


string[] people = { "Tom", "Bob", "Sam", "Kate", "Alice" };

string selected1 = people[2];    // Sam

string selected2 = people[people.Length - 2];    // Kate

Console.WriteLine(selected1);   

Console.WriteLine(selected2);
```

отдельный тип Index для такого чтения обязателен не везде: выражение `people[people.Length - 2]` вычисляет то же смещение, что и `^2`. смысл Index в том, что запись `people[^2]` короче и прямо показывает отсчёт от конца, тогда как вычитание из `Length` каждый раз восстанавливает это соглашение вручную.

### диапазон

диапазон задаёт часть последовательности двумя индексами. начальный индекс в диапазон входит, конечный индекс в диапазон не входит. это полуинтервал `[start, end)`. оператор **..** строит значение типа Range:

```c#
Range myRange1 = 1..4; // по 1-го индекса включая по 4-й индекс не включая
```

диапазон myRange1 покрывает элементы с индекса 1 включительно до индекса 4 не включая. элемент с индексом 4 в диапазон не попадает. границы имеют тип Index. число в записи диапазона неявно приводится к Index. следующие два определения задают один и тот же полуинтервал:

```c#


Index start = 1;

Index end = 4;

Range myRange1 = start..end;

			

Range myRange2 = 1..4;
```

на массиве диапазон применяется как индекс и даёт подмассив. со второго по четвёртый элемент, если считать с единицы, это индексы 1, 2 и 3:

```c#


string[] people = { "Tom", "Bob", "Sam", "Kate", "Alice" };

string[] peopleRange = people[1..4]; // получаем 2, 3 и 4-й элементы из массива

foreach(var person in peopleRange)

{

	Console.WriteLine(person);

}
```

результат выражения `people[1..4]` является новым массивом из элементов с индексами 1, 2 и 3 включительно: Bob, Sam, Kate. консольный вывод:

```bash


Bob

Sam

Kate
```

для массива такая операция выделяет новый массив и копирует в него выбранные элементы. длина копии равна числу позиций в полуинтервале.

верхнюю границу можно указать одну. пропущенная нижняя граница равна индексу 0:

```c#


string[] people = { "Tom", "Bob", "Sam", "Kate", "Alice" };

string[] peopleRange = people[..4];     // Tom, Bob, Sam, Kate
```

`people[..4]` копирует элементы `[0, 4)`: Tom, Bob, Sam, Kate.

нижнюю границу тоже можно указать одну. пропущенная верхняя граница равна концу последовательности, то есть индексу `^0`:

```c#


string[] people = { "Tom", "Bob", "Sam", "Kate", "Alice" };

string[] peopleRange = people[1..];     // Bob, Sam, Kate, Alice
```

`people[1..]` копирует хвост, начиная с индекса 1: Bob, Sam, Kate, Alice.

индексы от конца задают окно относительно текущей длины последовательности:

```c#


string[] people = { "Tom", "Bob", "Sam", "Kate", "Alice" };

string[] peopleRange1 = people[^2..];     	// два последних - Kate, Alice

string[] peopleRange2 = people[..^1];   	// начиная с предпоследнего - Tom, Bob, Sam, Kate

string[] peopleRange3 = people[^3..^1];   	// два начиная с предпоследнего - Sam, Kate
```

`people[^2..]` содержит два последних элемента, Kate и Alice. `people[..^1]` содержит все элементы, кроме последнего: Tom, Bob, Sam, Kate. `people[^3..^1]` начинается с третьего элемента от конца включительно и заканчивается перед последним элементом. для этого массива это Sam и Kate.

индексы и диапазоны определены и для Span и ReadOnlySpan. у массива индексатор диапазона копирует элементы в новый массив. у span тот же синтаксис вызывает срез и новый буфер под элементы не выделяет:

```c#


string[] people = { "Tom", "Bob", "Sam", "Kate", "Alice" };

Span<string> peopleSpan = people;

Span<string> selectedPeopleSpan = peopleSpan[1..4];

foreach (var person in selectedPeopleSpan)

{

	Console.WriteLine(person);

}
```

`peopleSpan[1..4]` является значением `Span<string>` на те же три строки Bob, Sam, Kate внутри исходного массива. изменение ячейки через этот span изменит и people, и peopleSpan. это то различие выделений, которое разбиралось для метода `Slice`.
