в c# используется большинство операций, которые применяются и в других языках программирования. операции представляют определённые действия над операндами, участниками операции. в качестве операнда может выступать переменная или какое-либо значение, например число. операции бывают унарными (выполняются над одним операндом), бинарными (над двумя операндами) и тернарными (выполняются над тремя операндами). ниже перечислены виды арифметических операций и правила, по которым выражение из нескольких операций получает значение. приоритет и ассоциативность задают дерево выражения ещё во время компиляции: скобки и порядок операторов определяют, какие подвыражения станут операндами.

бинарные арифметические операции:

- + операция сложения двух чисел:

```c#


int x = 10;

int z = x + 12; // 22
```

- - операция вычитания двух чисел:

```c#


int x = 10;

int z = x - 6; // 4
```

- * операция умножения двух чисел:

```c#


int x = 10;

int z = x * 5; // 50
```

- / операция деления двух чисел. при делении учитывается, что если оба операнда представляют целые числа, то результат тоже будет целым: дробная часть отбрасывается, усечение идёт к нулю, а не к ближайшему целому. несмотря на то, что результат операции в итоге помещается в переменную типа double, которая позволяет сохранить дробную часть, в самой операции участвуют два литерала, которые по умолчанию рассматриваются как значения типа int, то есть целые числа, и результат тоже будет целочисленным. тип операции определяется типами операндов, а не типом переменной, в которую результат затем записывается. для выхода из этой ситуации литералы или переменные, участвующие в операции, определяются именно как типы double или float:

```c#


int x = 10;

int z = x / 5; // 2



double a = 10;

double b = 3;

double c = a / b; // 3.33333333
```

```c#
double z = 10 /  4; //результат равен 2
```

```c#
double z = 10.0 /  4.0; //результат равен 2.5
```

во фрагменте с `10 / 4` оба литерала имеют тип `int`, частное равно 2, и только потом это целое преобразуется в `double`. во фрагменте с `10.0 / 4.0` деление уже вещественное, и дробная часть сохраняется.

- % операция получения остатка от деления двух чисел:

```c#


double x = 10.0;

double z = x % 4.0; //результат равен 2
```

операция `%` возвращает остаток, а не частное. для положительных операндов из примера остаток равен 2, потому что 10 = 4 * 2 + 2.

есть ряд унарных операций, в которых принимает участие один операнд:

- ++ операция инкремента. инкремент бывает префиксным: `++x`. сначала значение переменной x увеличивается на 1, а потом её значение возвращается в качестве результата операции.

есть и постфиксный инкремент: `x++`. сначала значение переменной x возвращается в качестве результата операции, а затем к нему прибавляется 1.

```c#


int x1 = 5;

int z1 = ++x1; // z1=6; x1=6

Console.WriteLine($"{x1} - {z1}");



int x2 = 5;

int z2 = x2++; // z2=5; x2=6

Console.WriteLine($"{x2} - {z2}");
```

различие префикса и постфикса относится к значению выражения, а не к конечному состоянию переменной. в обоих случаях переменная в итоге увеличена на единицу. побочный эффект и чтение старого или нового значения упорядочены относительно друг друга именно формой оператора.

- -- операция декремента, или уменьшения значения на единицу. существует префиксная форма декремента (`--x`) и постфиксная (`x--`).

```c#


int x1 = 5;

int z1 = --x1; // z1=4; x1=4

Console.WriteLine($"{x1} - {z1}");



int x2 = 5;

int z2 = x2--; // z2=5; x2=4

Console.WriteLine($"{x2} - {z2}");
```

при выполнении сразу нескольких арифметических операций учитывается порядок их выполнения. приоритет операций от наивысшего к низшему:

- инкремент, декремент

- умножение, деление, получение остатка

- сложение, вычитание

для изменения порядка следования операций применяются скобки. скобки задают корень поддерева явно и отменяют приоритет, заданный грамматикой.

набор операций:

```c#


int a = 3;

int b = 5;

int c = 40;

int d = c---b*a;    // a=3  b=5  c=39  d=25

Console.WriteLine($"a={a}  b={b}  c={c}  d={d}");
```

здесь три операции: декремент, вычитание и умножение. запись `c---` разбирается как постфиксный декремент `c--` и следующий за ним знак минус: лексер забирает более длинный оператор `--`, а не два отдельных минуса. сначала выполняется декремент переменной c, затем умножение `b*a`, и в конце вычитание. фактически набор операций выглядел так:

```c#
int d = (c--)-(b*a);
```

постфиксный декремент возвращает старое значение c, равное 40, и лишь затем уменьшает c до 39. умножение 5 * 3 даёт 15. разность 40 - 15 даёт 25, что совпадает с комментарием к `d`.

с помощью скобок порядок операций меняется, например следующим образом:

```c#


int a = 3;

int b = 5;

int c = 40;

int d = (c-(--b))*a;    // a=3  b=4  c=40  d=108

Console.WriteLine($"a={a}  b={b}  c={c}  d={d}");
```

здесь префиксный декремент применяется к b до вычитания, c не изменяется, и умножение на a выполняется последним, потому что оно стоит вне скобок.

### ассоциативность операторов

как показано выше, операции умножения и деления имеют один и тот же приоритет. выражение

```c#


int x = 10 / 5 * 2;
```

допускает два разбора: `(10 / 5) * 2` либо `10 / (5 * 2)`. от разбора зависят разные результаты.

когда операции имеют один и тот же приоритет, порядок вычисления определяется ассоциативностью операторов. в зависимости от ассоциативности есть два типа операторов:

- левоассоциативные операторы, которые выполняются слева направо

- правоассоциативные операторы, которые выполняются справа налево

все арифметические операторы являются левоассоциативными, то есть выполняются слева направо. поэтому выражение `10 / 5 * 2` трактуется как `(10 / 5) * 2`, и результатом будет 4. ассоциативность не меняет приоритет относительно других групп: умножение и деление по-прежнему выполняются раньше сложения, а между собой группируются слева.
