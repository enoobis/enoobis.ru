### частичные классы

класс может быть частичным: у одного и того же типа несколько объявлений, часто в разных файлах, а компилятор собирает их в один тип. для среды выполнения частичности уже нет. в метаданных остаётся один класс.

имена файлов роли не играют. пусть один файл называется `PersonMove.cs`, другой `PersonEat.cs`. в **PersonMove.cs** объявлен такой класс:

```c#

public partial class Person
{
	public void Move() => Console.WriteLine("Человек идет");
}
```

в **PersonEat.cs** объявлен другой фрагмент того же типа:

```c#

public partial class Person
{
	public void Eat() => Console.WriteLine("Человек ест");
}
```

оба файла содержат части одного класса `Person` с разными методами. признак частичности: ключевое слово **partial** у каждого объявления. после объединения типу доступны все методы:

```c#

var tom = new Person();
tom.Move();
tom.Eat();
```

консольный вывод:

```bash

Человек идет
Человек ест
```

несколько объявлений частичного класса сливаются в одно. размещать их по разным файлам не обязательно. они могут лежать в одном файле и даже рядом:

```c#

var tom = new Person();
tom.Move();
tom.Eat();
// Console.WriteLine(tom.Name);

public partial class Person
{
	public void Eat() => Console.WriteLine("Человек ест");
}
public partial class Person
{
	public void Move() => Console.WriteLine("Человек идет");
}
```

смысл частичного класса в разделении знания. автор одной части может не знать, что делает другая часть. так устроена автогенерация кода. типичный случай: описание пользовательского интерфейса. программист пишет логику взаимодействия с пользователем, а генератор дописывает другую часть класса, которая рисует элементы управления и вычисляет их положение.

### частичные методы

частичный класс может содержать частичные методы. они тоже помечаются словом **partial**. объявление без тела лежит в одной части класса, реализация в другой. схема близка к разделению функции на прототип и реализацию в языках c и c++.

объявление метода `Say`:

```c#

// объявление частичного класса
public partial class Person
{
	public partial void Say(string message);  // объявление частичного метода
}
```

у `Say` нет тела, это только объявление. компилятор фиксирует сигнатуру: метод принимает строку и не возвращает значение. что именно метод будет делать, в этой части класса ещё не задано. сигнатура уже известна, и метод можно вызывать.

реализация находится во второй части:

```c#

// реализация частичного класса
public partial class Person
{
    // реализация частичного метода
	public partial void Say(string message)
    {
        Console.WriteLine(message);
    }
}
```

здесь у `Say()` есть тело: метод печатает переданную строку. вызов `Say` выполняет эту реализацию.

к частичному методу по умолчанию применяется набор ограничений:

- у него нет модификаторов доступа

- его тип результата: `void`

- у него нет out-параметров

- у него нет модификаторов `virtual, override, sealed, new` или `extern`

классический частичный метод без реализации компилятор удаляет вместе с вызовами. вызывающему коду тогда не на что опереться, поэтому у такого метода нет результата и нет out-параметра. если объявление выходит за эти ограничения, реализация обязательна. в предыдущем примере у метода стоит модификатор `public`, и тело поэтому должно быть предоставлено.

### частичные свойства и индексаторы

частичные методы в c# существуют давно. с версии c# 13 то же разделение на объявление и реализацию доступно свойствам и индексаторам. сигнатура объявления и сигнатура реализации совпадают. частичное автосвойство объявлять нельзя. если свойство помечено словом `partial` и реализации у него нет, компилятор читает его как объявление свойства.

пример частичного свойства:

```c#

var tom = new Person("Tom");

Console.WriteLine(tom.Name);

// объявление класса
partial class Person{
    public partial string Name { get; set; }  // объявление частичного свойства
}

// реализация класса
partial class Person{
    private string name; // поле для хранения значения свойства

    public Person(string name) => this.name = name;

    public partial string Name    // реализация частичного свойства
    {
        get => name;
        set => name = value;
    }
}
```

сначала идёт только объявление класса `Person`:

```c#

partial class Person{
    public partial string Name { get; set; }  // объявление частичного свойства
}
```

в нём объявлено частичное свойство `Name`. запись похожа на автоматическое свойство, но модификатор `partial` делает её объявлением: частичное автосвойство язык не принимает, аксессоры появляются в реализации.

```c#

partial class Person{
    private string name; // поле для хранения значения свойства

    public Person(string name) => this.name = name;

    public partial string Name    // реализация частичного свойства
    {
        get => name;
        set => name = value;
    }
}
```

в примере объявление и реализация стоят рядом. их можно разнести по разным файлам, и для компилятора это то же слияние, что и у частичного метода.

частичный индексатор:

```c#

var buffer = new Buffer();

// некоторые действия с индексатором
for(var i=0; i < Buffer.COUNT; ++i){
    buffer[i] = i * i;
}

for(var i=0; i < Buffer.COUNT; ++i){
    Console.WriteLine(buffer[i]);
}
// объявление класса
partial class Buffer{
    public partial int this[int index]  { get; set; }  // объявление свойства-индексатора
}

// реализация класса
partial class Buffer{
    public const int COUNT = 6;
    private int[] data = new int[COUNT];
    public partial int this[int index]    // реализация свойства-индексатора
    {
        get => data[index];
        set => data[index] = value;
    }
}
```

индексатор объявлен в частичном классе `Buffer`. он надстроен над массивом `data`: чтение и запись по индексу идут в этот массив. константа `COUNT` задаёт длину 6, цикл заполняет ячейки квадратами индексов и затем печатает их.
