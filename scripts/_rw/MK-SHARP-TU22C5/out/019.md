в предыдущей теме метод `SayHello` писал на консоль одно и то же сообщение:

```c#


void SayHello()

{

    Console.WriteLine("Hello");

}



SayHello(); // Hello
```

текст сообщения зафиксирован в теле, и вызывающий код его не выбирает. входные данные передают через параметры.

параметры задают входные данные метода. их перечисляют через запятую в скобках после имени. у каждого параметра сначала указан тип, затем имя:

```c#


тип_метода имя_метода (тип_параметра1 параметр1, тип_параметра2 параметр2, ...)

{

	// действия метода

}
```

определение параметра состоит из типа и имени. тип задает, какие значения можно передать, имя обозначает это значение внутри тела.

метод `PrintMessage` принимает выводимое сообщение снаружи:

```c#


void PrintMessage(string message)

{

    Console.WriteLine(message);

}



PrintMessage("Hello work");           // Hello work

PrintMessage("Hello METANIT.COM");    // Hello METANIT.COM

PrintMessage("Hello C#");             // Hello C#
```

у `PrintMessage()` один параметр `message` типа `string`.

вызов передает аргументы в скобках после имени, по одному на каждый параметр:

```c#
PrintMessage("Hello work");
```

параметр `message` получает строку `"Hello work"`. значение, подставленное в вызове, называется аргументом. строка `"Hello work"` в этом вызове является аргументом.

в описаниях методов различают формальные и фактические параметры. формальные параметры объявлены в заголовке метода. здесь это `message`. фактические параметры являются значениями, которые подставляют на место формальных. фактический параметр и аргумент обозначают одно и то же.

метод сложения двух чисел:

```c#


void Sum(int x, int y)

{

    int result = x + y;

    Console.WriteLine($"{x} + {y} = {result}");

}



Sum(10, 15);	// 10 + 15 = 25
```

у `Sum` два параметра, `x` и `y`, оба типа `int`. вызов обязан передать два целых числа. внутри метода сумма вычисляется и пишется на консоль.

аргументы сопоставляются параметрам по позиции, слева направо. в вызове `Sum(10, 15)` число 10 получает `x`, число 15 получает `y`.

параметры допустимы и в теле-выражении:

```c#


void Sum(int x, int y) => Console.WriteLine($"{x} + {y} = { x + y }");



Sum(10, 15);    // 10 + 15 = 25
```

аргументом может быть значение переменной или результат выражения, у которого есть значение совместимого типа:

```c#


void Sum(int x, int y) => Console.WriteLine($"{x} + {y} = { x + y }");



int a = 10, b = 15, c = 6;

Sum(a, b);                  // 10 + 15 = 25

Sum(3, c);                  // 3 + 6 = 9

Sum(14, 4 + c);             // 14 + 10 = 24
```

если аргумент является локальной переменной, эта переменная должна быть определенно присвоена до вызова. чтение неинициализированной локальной переменной в c# запрещено, и следующий фрагмент не компилируется:

```c#


void Sum(int x, int y)

{

    Console.WriteLine($"{x} + {y} = { x + y }");

}



int a;

int b = 15;

Sum(a, b);  // ! Ошибка
```

### соответствие параметров и аргументов по типу данных

между аргументом и параметром должно быть соответствие по типу: тип аргумента совпадает с типом параметра или неявно приводится к нему.

```c#


void PrintPerson(string name, int age)

{

    Console.WriteLine($"Name: {name}  Age: {age}");

}



PrintPerson("Tom", 24); // Name: Tom  Age: 24
```

первый параметр `PrintPerson()` имеет тип `string`, поэтому первый аргумент обязан быть строкой. второй параметр имеет тип `int`, поэтому второй аргумент обязан быть целым числом, совместимым с `int`.

```c#


PrintPerson("Tom", 24);
```

аргументом может быть и значение типа, который неявно преобразуется к типу параметра:

```c#


void PrintPerson(string name, int age)

{

    Console.WriteLine($"Name: {name}  Age: {age}");

}



byte b = 37;

PrintPerson("Tom", b); // Name: Tom  Age: 37
```

параметр типа `int` получает значение типа `byte`. компилятор вставляет неявное расширяющее преобразование `byte` к `int`, и ошибки нет. набор таких преобразований разобран в теме о преобразованиях базовых типов данных.

значение несовместимого типа передать нельзя. следующий вызов не компилируется: `int` не приводится неявно к `string`, а `string` не приводится неявно к `int`, поэтому ни перестановка аргументов, ни их типы заголовку не подходят.

```c#
PrintPerson(45, "Bob"); // Ошибка! несоответствие значений типам параметров
```

### необязательные параметры

по умолчанию вызов предоставляет аргумент для каждого параметра. необязательный параметр объявляют со значением по умолчанию. после первого необязательного параметра все следующие тоже должны быть необязательными: обязательный параметр не может стоять правее необязательного.

```c#


void PrintPerson(string name, int age = 1, string company = "Undefined")

{

    Console.WriteLine($"Name: {name}  Age: {age}  Company: {company}");

}
```

у `age` и `company` есть значения по умолчанию, поэтому эти параметры необязательны. вызов может их опустить. опущенный аргумент заменяется значением по умолчанию. компилятор подставляет это значение на месте вызова, в код вызывающего:

```c#


void PrintPerson(string name, int age = 1, string company = "Undefined")

{

    Console.WriteLine($"Name: {name}  Age: {age}  Company: {company}");

}



PrintPerson("Tom", 37, "Microsoft");  // Name: Tom  Age: 37  Company: Microsoft

PrintPerson("Tom", 37);               // Name: Tom  Age: 37  Company: Undefined

PrintPerson("Tom");                   // Name: Tom  Age: 1   Company: Undefined
```

консольный вывод программы:

```consoletext


Name: Tom  Age: 37  Company: Microsoft

Name: Tom  Age: 37  Company: Undefined

Name: Tom  Age: 1   Company: Undefined
```

### именованные параметры

в предыдущих вызовах аргументы шли в порядке параметров. это передача по позиции. именованный аргумент указывает имя параметра и снимает этот порядок:

```c#


void PrintPerson(string name, int age = 1, string company = "Undefined")

{

    Console.WriteLine($"Name: {name}  Age: {age}  Company: {company}");

}



PrintPerson("Tom", company:"Microsoft", age: 37);  // Name: Tom  Age: 37  Company: Microsoft

PrintPerson(age:41, name: "Bob");          // Name: Bob  Age: 41  Company: Undefined

PrintPerson(company:"Google", name:"Sam"); // Name: Sam  Age: 1   Company: Google
```

в именованном аргументе пишут имя параметра и через двоеточие значение: `name:"Tom"`. позиционные аргументы, если они есть, стоят левее именованных. имя должно совпадать с формальным параметром. так вызывают метод, пропуская необязательный параметр в середине списка или меняя порядок аргументов.

консольный вывод программы:

```consoletext


Name: Tom  Age: 37  Company: Microsoft

Name: Bob  Age: 41  Company: Undefined

Name: Sam  Age: 1   Company: Google
```
