для файлов в `System.IO` есть пара классов `File` и `FileInfo`, устроенная так же, как пара `Directory` и `DirectoryInfo`. через них файл создаётся, удаляется и перемещается, у него читаются свойства.

### `FileInfo`

часть методов и свойств класса `FileInfo`:

- `CopyTo(path)`: копирует файл по новому пути `path`
- `Create()`: создаёт файл. метод возвращает открытый `FileStream`, и пока этот поток не закрыт, файл занят
- `Delete()`: удаляет файл
- `MoveTo(destFileName)`: перемещает файл по пути `destFileName`
- свойство `Directory`: родительский каталог в виде `DirectoryInfo`
- свойство `DirectoryName`: полный путь родительского каталога
- свойство `Exists`: существует ли файл на момент чтения свойства
- свойство `Length`: размер файла в байтах
- свойство `Extension`: расширение файла, включая точку
- свойство `Name`: имя файла без каталога
- свойство `FullName`: полное имя файла

экземпляр строится конструктором, аргумент которого есть путь к файлу:

```c#


FileInfo fileInf = new FileInfo(@"C:\app\content.txt");
```

как и у `DirectoryInfo`, путь хранится в экземпляре. серия операций над одним файлом идёт через этот экземпляр, одиночный вызов чаще остаётся статическим методом `File`.

### `File`

класс `File` даёт ту же группу операций статическими методами:

- `Copy()`: копирует файл в новое место
- `Create()`: создаёт файл и возвращает открытый поток
- `Delete()`: удаляет файл
- `Move`: перемещает файл в новое место
- `Exists(file)`: определяет, существует ли файл

### пути к файлам

путь бывает абсолютным и относительным. абсолютный путь начинается от корня: в windows это буква диска, в macos и linux это `/`. относительный путь отсчитывается от текущего каталога процесса. форма разделителя в литерале зависит от того, обычная это строка или дословная: в обычной строке обратная черта удваивается, в дословной пишется как есть. прямая черта в путях windows для этих api тоже допустима.

```c#


// абсолютные пути

string path1 = @"C:\Users\eugene\Documents\content.txt";  // для Windows

string path2 = "C:\\Users\\eugene\\Documents\\content.txt";  // для Windows

string path3 = "/Users/eugene/Documents/content.txt";  // для MacOS/Linux



// относительные пути

string path4 = "MyDir\\content.txt";  // для Windows

string path5 = "MyDir/content.txt";  // для MacOS/Linux
```

### получение информации о файле

```c#


string path = @"C:\Users\eugene\Documents\content.txt";

// string path = "/Users/eugene/Documents/content.txt";  // для MacOS/Linux

FileInfo fileInfo = new FileInfo(path);

if (fileInfo.Exists)

{

    Console.WriteLine($"Имя файла: {fileInfo.Name}");

    Console.WriteLine($"Время создания: {fileInfo.CreationTime}");

    Console.WriteLine($"Размер: {fileInfo.Length}");

}
```

при истинном `Exists` печатаются имя (`Name`), время создания (`CreationTime`) и размер в байтах (`Length`). время создания есть свойство файловой системы, его наследует и `FileInfo`.

### удаление файла

```c#


string path = @"C:\app\content.txt";

FileInfo fileInf = new FileInfo(path);

if (fileInf.Exists)

{

   fileInf.Delete();

   // альтернатива с помощью класса File

   // File.Delete(path);

}
```

`Delete` вызывается только если `Exists` истинно. альтернатива в комментарии фрагмента, `File.Delete(path)`, выполняет ту же операцию статическим методом.

### перемещение файла

```c#


string path =  @"C:\OldDir\content.txt";

string newPath = @"C:\NewDir\index.txt";

FileInfo fileInf = new FileInfo(path);

if (fileInf.Exists)

{

   fileInf.MoveTo(newPath);       

   // альтернатива с помощью класса File

   // File.Move(path, newPath);

}
```

если по новому пути файл уже есть, перегрузка с дополнительным аргументом типа `bool` задаёт, заменять ли его. значение `true` означает замену.

```c#


string path =  @"C:\OldDir\content.txt";

string newPath = @"C:\NewDir\index.txt";

FileInfo fileInf = new FileInfo(path);

if (fileInf.Exists)

{

   fileInf.MoveTo(newPath, true);       

   // альтернатива с помощью класса File

   // File.Move(path, newPath, true);

}
```

при значении `false` существующий файл назначения не заменяется, и вызов завершается исключением. те же два аргумента пути и признак замены принимает `File.Move`.

### копирование файла

```c#


string path =  @"C:\OldDir\content.txt";

string newPath = @"C:\NewDir\index2.txt";

FileInfo fileInf = new FileInfo(path);

if (fileInf.Exists)

{

   fileInf.CopyTo(newPath, true);      

   // альтернатива с помощью класса File

   // File.Copy(path, newPath, true);

}
```

`CopyTo` у `FileInfo` принимает путь копии и значение `bool`: нужно ли при копировании заменять уже существующий файл. во фрагменте передано `true`, поэтому существующий файл по пути назначения перезаписывается. значение `false` при уже существующем файле приводит к исключению.

`Copy` у `File` принимает три аргумента: путь исходного файла, путь копии и значение `bool`, которое задаёт замену существующего файла. смысл третьего аргумента тот же, что у второго аргумента `CopyTo`.

копирование оставляет исходный файл на месте. перемещение забирает его с исходного пути. в обоих случаях при замене содержимое файла назначения теряется.

### чтение и запись файлов

помимо операций над самим файлом класс `File` содержит методы, которые целиком читают или записывают текстовый либо двоичный файл. у каждого синхронного метода есть асинхронный двойник с суффиксом `Async`. асинхронная версия возвращает `Task` и принимает `CancellationToken`, через который ожидание отменяется. синхронная версия занимает вызывающий поток на всё время операции.

- `AppendAllLines(String, IEnumerable<string>)` / `AppendAllLinesAsync(String, IEnumerable<string>, CancellationToken)` дописывают в файл набор строк. если файла нет, он создаётся
- `AppendAllText(String, String)` / `AppendAllTextAsync(String, String, CancellationToken)` дописывают в файл одну строку. если файла нет, он создаётся
- `byte[] ReadAllBytes(string path)` / `Task<byte[]> ReadAllBytesAsync(string path, CancellationToken cancellationToken)` считывают содержимое файла в массив байтов
- `string[] ReadAllLines(string path)` / `Task<string[]> ReadAllLinesAsync(string path, CancellationToken cancellationToken)` считывают текстовый файл в массив строк. массив строится сразу на всё содержимое
- `string ReadAllText(string path)` / `Task<string> ReadAllTextAsync(string path, CancellationToken cancellationToken)` считывают текстовый файл в одну строку
- `IEnumerable<string> ReadLines(string path)` читает текстовый файл как последовательность строк. перечисление отложенное: очередная строка запрашивается по мере обхода, память на весь файл сразу не занимается
- `void WriteAllBytes(string path, byte[] bytes)` / `Task WriteAllBytesAsync(string path, byte[] bytes, CancellationToken cancellationToken)` записывают массив байтов. если файла нет, он создаётся. если файл есть, прежнее содержимое заменяется
- `void WriteAllLines(string path, string[] contents)` / `Task WriteAllLinesAsync(string path, IEnumerable<string> contents, CancellationToken cancellationToken)` записывают набор строк в текстовый файл. если файла нет, он создаётся. если файл есть, прежнее содержимое заменяется
- `WriteAllText(string path, string? contents)` / `Task WriteAllTextAsync(string path, string? contents, CancellationToken cancellationToken)` записывают строку в текстовый файл. если файла нет, он создаётся. если файл есть, прежнее содержимое заменяется

методы `Write*` заменяют файл целиком, методы `Append*` дописывают в конец. вместе они закрывают обычные сценарии: текст целиком, текст по строкам, сырые байты, синхронно и асинхронно.

запись строки и обратное чтение выглядят так:

```c#


string path = @"c:\app\content.txt";



string originalText = "Hello  enoobis.com";

// запись строки

await File.WriteAllTextAsync(path, originalText);

// дозапись в конец файла

await File.AppendAllTextAsync(path, "\nHello work");



// чтение файла

string fileText = await File.ReadAllTextAsync(path);

Console.WriteLine(fileText);
```

вывод программы:

```consoletext


Hello  enoobis.com

Hello work
```

вторая запись добавляет в строку последовательность `\n`. это символ перевода строки, u+000a. из-за него дописанный текст начинается в файле с новой строки. метод записывает ровно переданные символы и сам не подменяет `\n` на пару `\r\n`, принятую как перевод строки в windows.

если каждая переданная строка должна занять в файле отдельную строку, для записи берётся `WriteAllLines` или `WriteAllLinesAsync`, для дописывания `AppendAllLines` или `AppendAllLinesAsync`. эти методы сами завершают каждую строку переводом строки:

```c#
await File.WriteAllLinesAsync(path, new[] { "Hello  enoobis.com", "Hello work" });
```

при чтении то же различие. `ReadAllText` и `ReadAllTextAsync` возвращают весь текст одной строкой. `ReadAllLines` и `ReadAllLinesAsync` возвращают каждую строку файла отдельно, уже без символов перевода строки.

### кодировка

методы чтения и записи текста принимают дополнительный аргумент кодировки, объект `System.Text.Encoding`. одна и та же кодировка нужна и при записи, и при чтении: байты файла суть коды выбранной кодировки, и другая кодировка декодирует их в другие символы.

```c#


using System.Text;



string path = "/Users/eugene/Documents/app/content.txt";



string originalText = "Привет  enoobis.com";

// запись строки

await File.WriteAllTextAsync(path, originalText, Encoding.Unicode);

// дозапись в конец файла

await File.AppendAllTextAsync(path, "\nПривет мир", Encoding.Unicode);



// чтение файла

string fileText = await File.ReadAllTextAsync(path, Encoding.Unicode);

Console.WriteLine(fileText);
```

здесь кодировка задана готовым значением `Encoding.Unicode`. это utf-16 с порядком байтов little-endian. кириллица в этой кодировке представима, потому что utf-16 покрывает всю базовую многоязычную плоскость.

кодировку можно указать и по имени. имя должно быть известно среде выполнения, иначе `GetEncoding` выбрасывает исключение:

```c#


using System.Text;



string path = @"c:\app\content.txt";



string originalText = "Hello  enoobis.com";

// запись строки

await File.WriteAllTextAsync(path, originalText, Encoding.GetEncoding("iso-8859-1"));

// дозапись в конец файла

await File.AppendAllTextAsync(path, "\nHello code", Encoding.GetEncoding("iso-8859-1"));



// чтение файла

string fileText = await File.ReadAllTextAsync(path, Encoding.GetEncoding("iso-8859-1"));

Console.WriteLine(fileText);
```

имя `iso-8859-1` обозначает latin-1, однобайтовую кодировку западноевропейского набора. символы вне этого набора, в том числе кириллица, в ней не представимы, поэтому фрагмент пишет латинский текст.
