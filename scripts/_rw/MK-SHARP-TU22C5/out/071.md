**замыкание** (closure) есть объект функции, который хранит своё лексическое окружение и после того, как вызов ушёл из области видимости, где функция была создана.

технически замыкание собирается из трёх компонентов:

- внешняя функция, которая задаёт область видимости и в которой объявлены переменные и параметры, то есть лексическое окружение

- переменные и параметры (лексическое окружение), объявленные во внешней функции

- вложенная функция, которая использует переменные и параметры внешней функции

в c# замыкание получают локальной функцией или лямбда-выражением. компилятор выносит захваченные переменные в поля служебного класса, поэтому время жизни переменной определяется временем жизни делегата: переменная переживает кадр стека внешней функции. каждый вызов внешней функции создаёт свой экземпляр этого класса: у разных замыканий окружения независимы.

замыкание на локальной функции:

```c#


var fn = Outer();   // fn = Inner, так как метод Outer возвращает функцию Inner

// вызываем внутреннюю функцию Inner

fn();   // 6

fn();   // 7

fn();   // 8



Action Outer()	// метод или внешняя функция

{

    int x = 5;	// лексическое окружение - локальная переменная

    void Inner()	// локальная функция

    {

        x++;		// операции с лексическим окружением

        Console.WriteLine(x);

    }

    return Inner;	// возвращаем локальную функцию

}
```

метод `Outer` возвращает тип `Action`: функцию, которая не принимает параметров и имеет результат `void`.

```c#
Action Outer()
```

внутри `Outer` объявлена переменная `x`. это лексическое окружение внутренней функции:

```c#
int x = 5;
```

там же объявлена локальная функция `Inner`. она обращается к своему лексическому окружению, переменной `x`, увеличивает её на единицу и выводит значение на консоль:

```c#


void Inner()

{

	x++;

	Console.WriteLine(x);

}
```

эту локальную функцию возвращает метод `Outer`:

```c#
return Inner;
```

вызов `Outer` помещает локальную функцию `Inner` в переменную `fn`:

```c#
var fn = Outer();
```

переменная `fn` и есть замыкание: вместе хранятся функция и окружение, в котором она создана. вызов происходит вне метода, где функция объявлена, но лексическое окружение сохранено, к нему можно обращаться и его можно изменять. это видно по консольному выводу:

```c#


fn();   // 6

fn();   // 7

fn();   // 8
```

### реализация с помощью лямбда-выражений

лямбда-выражение записывает то же замыкание короче. семантика захвата прежняя: `x` живёт в объекте замыкания и не копируется значением в момент создания лямбды.

```c#


var outerFn = () =>

{

    int x = 10;

    var innerFn = () => Console.WriteLine(++x);

    return innerFn;

};



var fn = outerFn();   // fn = innerFn, так как outerFn возвращает innerFn

// вызываем innerFn

fn();   // 11

fn();   // 12

fn();   // 13
```

### применение параметров

к лексическому окружению, помимо локальных переменных, относятся параметры охватывающего метода.

```c#


var fn = Multiply(5);  



Console.WriteLine(fn(5));   // 25

Console.WriteLine(fn(6));   // 30

Console.WriteLine(fn(7));   // 35



Operation Multiply(int n)

{

    int Inner(int m)

    {

        return n * m;

    }

    return Inner;

}

delegate int Operation(int n);
```

внешняя функция, метод `Multiply`, возвращает функцию, которая принимает число `int` и возвращает число `int`. для этого объявлен делегат `Operation`, он и задаёт возвращаемый тип:

```c#
delegate int Operation(int n);
```

на том же месте используют встроенный делегат `Func<int, int>`: сигнатура совпадает с `Operation`.

вызов `Multiply()` возвращает локальную функцию, которая соответствует сигнатуре делегата `Operation`:

```c#


int Inner(int m)

{

	return n * m;

}
```

эта функция запоминает окружение, в котором была создана, в частности значение параметра `n`. помимо этого она принимает собственный параметр и возвращает произведение `n` и `m`.

при вызове `Multiply` переменная `fn` получает локальную функцию `Inner` и её лексическое окружение, значение параметра `n`:

```c#
var fn = Multiply(5);
```

в этом вызове параметр `n` равен 5. вызов локальной функции:

```c#
Console.WriteLine(fn(6));   // 30
```

число 6 передаётся в параметр `m`. функция возвращает произведение `n` и `m`, то есть 5 * 6 = 30.

тот же код сокращается вложенными лямбдами: внешняя получает `n` и возвращает функцию от `m`.

```c#


var multiply = (int n) => (int m) => n * m; 



var fn = multiply(5);  



Console.WriteLine(fn(5));   // 25

Console.WriteLine(fn(6));   // 30

Console.WriteLine(fn(7));   // 35
```
