**индексаторы** задают доступ к данным объекта по индексу. снаружи обращение выглядит так же, как индексация массива. по устройству индексатор близок к свойству: у него есть блоки `get` и `set`, которые читают и записывают значение. для среды выполнения это параметризованное свойство. компилятор порождает методы доступа, по умолчанию с именем `Item`.

формальное объявление:

```c#

возвращаемый_тип this [Тип параметр1, ...]
{
	get { ... }
	set { ... }
}
```

имени у индексатора нет. на его месте стоит ключевое слово **this**, а в квадратных скобках перечисляются параметры. параметр обязателен хотя бы один: без него член был бы обычным свойством.

далее класс `Person` представляет человека, класс `Company` представляет организацию, в которой эти люди работают. индексатор определён у `Company`:

```c#

class Person
{
    public string Name { get;}
    public Person(string name) => Name=name;
}
class Company
{
    Person[] personal;
    public Company(Person[] people) => personal = people;
    // индексатор
    public Person this[int index]
    {
        get => personal[index];
        set => personal[index] = value;
    }
}
```

персонал хранится в массиве `personal` из объектов `Person`. доступ к элементам идёт через индексатор:

```c#
public Person this[int index]
```

индексатор похож на свойство в двух отношениях. во-первых, у него есть тип результата. здесь это `Person`: именно объекты этого типа индексатор принимает и возвращает. во-вторых, у него есть параметр `int index`, по которому выбирается элемент внутри `Company`.

чтение задаёт блок **get**:

```c#

get => personal[index];
```

тип индексатора равен `Person`, поэтому блок `get` возвращает значение этого типа. логика внутри может быть любой. здесь это прямое чтение элемента `personal`. запись устроена как у свойства: параметр **value** содержит переданный `Person`, и он сохраняется в массив по индексу.

```c#

set => personal[index] = value;
```

после этого экземпляр `Company` индексируется как набор `Person`:

```c#

var microsoft = new Company(new[]
{
    new Person("Tom"), new Person("Bob"), new Person("Sam"), new Person("Alice")
});
// получаем объект из индексатора
Person firstPerson = microsoft[0];
Console.WriteLine(firstPerson.Name);  // Tom
// переустанавливаем объект
microsoft[0] = new Person("Mike");
Console.WriteLine(microsoft[0].Name);  // Mike
```

если переданный индекс отсутствует в массиве `personal`, возникает исключение, как и при прямом обращении к элементу массива. эту реакцию можно заменить собственной проверкой:

```c#

class Company
{
    Person[] personal;
    public Company(Person[] people) => personal = people;
    // индексатор
    public Person this[int index]
    {
        get
        {
			// если индекс имеется в массиве
            if (index >= 0 && index < personal.Length)
                return personal[index];	// то возвращаем объект Person по индексу
            else
                throw new ArgumentOutOfRangeException(); // иначе генерируем исключение
        }
        set
        {
			// если индекс есть в массиве
            if (index >= 0 && index < personal.Length)
                personal[index] = value;	// переустанавливаем значение по индексу
        }
    }
}
```

в блоке `get` индекс из допустимого диапазона даёт объект `Person`, прочий индекс приводит к `ArgumentOutOfRangeException`. в блоке `set` значение записывается только при индексе внутри массива. при выходе за границу запись пропускается. исключение в этом варианте порождает только чтение.

### индексы

индексатор получает индексы своими параметрами. тип индекса не обязан быть `int`, а хранилище не обязано быть массивом. объект можно рассматривать как набор атрибутов и передавать имя атрибута строкой:

```c#

User tom = new User();
// устанавливаем значения
tom["name"] = "Tom";
tom["email"] = "tom@gmail.ru";
tom["phone"] = "+1234556767";

// получаем значение
Console.WriteLine(tom["name"]); // Tom

class User
{
    string name = "";
    string email = "";
    string phone = "";
    public string this[string propname]
    {
        get
        {
            switch (propname)
            {
                case "name": return name;
                case "email": return email;
                case "phone": return phone;
                default: throw new Exception("Unknown Property Name");
            }
        }
        set
        {
            switch (propname)
            {
                case "name":
                    name = value;
                    break;
                case "email":
                    email = value;
                    break;
                case "phone":
                    phone = value;
                    break;
            }
        }
    }
}
```

индексатор `User` принимает строку с именем атрибута, которое совпадает с именем поля. блок **get** по этой строке возвращает `name`, `email` или `phone`. неизвестное имя приводит к исключению `Exception` с текстом `Unknown Property Name`. блок **set** по той же строке выбирает поле и записывает в него `value`. неизвестное имя при записи не меняет ни одного поля: ветки `default` у записи нет.

### применение нескольких параметров

параметров может быть несколько. в классе ниже хранилище задано двумерным массивом, то есть матрицей:

```c#

class Matrix
{
    int[,] numbers = new int[,] { { 1, 2, 4 }, { 2, 3, 6 }, { 3, 4, 8 } };
    public int this[int i, int j]
    {
        get => numbers[i, j];
        set => numbers[i, j] = value;
    }
}
```

у индексатора два индекса, `i` и `j`. обращение к объекту обязано передавать оба:

```c#

Matrix matrix = new Matrix();
Console.WriteLine(matrix[0, 0]);
matrix[0, 0] = 111;
Console.WriteLine(matrix[0, 0]);
```

индексатор не бывает статическим и применяется только к экземпляру. при этом он может быть виртуальным или абстрактным и переопределяться в производном классе. виртуальность здесь та же, что у свойства: вызов `get` или `set` диспетчеризуется по динамическому типу экземпляра.

### блоки get и set

как и у свойства, блок `get` или блок `set` можно опустить, если соответствующая операция не нужна. без `set` индексатор доступен только для чтения:

```c#

class Matrix
{
    int[,] numbers = new int[,] { { 1, 2, 4 }, { 2, 3, 6 }, { 3, 4, 8 } };
    public int this[int i, int j]
    {
        get => numbers[i, j];
    }
}
```

доступ к блокам ограничивается модификаторами. блок `set` ниже закрыт модификатором `private`: прочитать элемент можно из любого кода, а записать его могут только члены самого `Matrix`.

```c#

class Matrix
{
    int[,] numbers = new int[,] { { 1, 2, 4 }, { 2, 3, 6 }, { 3, 4, 8 } };
    public int this[int i, int j]
    {
        get => numbers[i, j];
        private set => numbers[i, j] = value;
    }
}
```

### перегрузка индексаторов

индексаторы перегружаются по тем же правилам, что и методы: версии различаются числом, типом или порядком параметров.

```c#

var microsoft = new Company(new Person[] { new("Tom"), new("Bob"), new("Sam") });

Console.WriteLine(microsoft[0].Name);      // Tom
Console.WriteLine(microsoft["Bob"].Name);  // Bob
class Person
{
    public string Name { get;}
    public Person(string name) => Name=name;
}
class Company
{
    Person[] personal;
    public Company(Person[] people) => personal = people;
    // индексатор
    public Person this[int index]
    {
        get => personal[index];
        set => personal[index] = value;
    }

    public Person this[string name]
    {
        get
        {
            foreach (var person in personal)
            {
                if (person.Name == name) return person;
            }
            throw new Exception("Unknown name");
        }
    }
}
```

у `Company` две версии. первая по индексу `int` и читает, и записывает `Person`. вторая только читает `Person` по имени: обходит `personal` и возвращает первый объект с совпавшим `Name`, а если имени нет, выбрасывает `Exception` с текстом `Unknown name`.
