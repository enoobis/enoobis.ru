ещё один распространённый вид коллекции составляет словарь. словарь хранит объекты, каждый из которых является парой ключ-значение. класс `Dictionary<TKey, TValue>` типизируется двумя параметрами. параметр `TKey` задаёт тип ключей, параметр `TValue` задаёт тип значений. в перечне методов ниже те же роли иногда обозначены буквами `K` и `V`. словарь реализован хеш-таблицей. поиск, вставка и удаление по ключу занимают в среднем постоянное время, если хеш-коды ключей распределены равномерно. корзину ключа определяют `GetHashCode` и `Equals`. ключи в одном словаре уникальны.

### создание и инициализация словаря

класс предоставляет несколько конструкторов. пустой словарь:

```c#


Dictionary<int, string> people = new Dictionary<int, string>();
```

у словаря `people` ключи имеют тип `int`, значения являются строками.

при определении словарь можно сразу инициализировать значениями:

```c#


var people = new Dictionary<int, string>()

{

    { 5, "Tom"},

    { 3, "Sam"},

    { 11, "Bob"}

};
```

инициализатор коллекции передаёт объекту начальные данные в фигурных скобках после вызова конструктора. для словаря каждый элемент тоже заключается в фигурные скобки:

```c#
{ 5, "Tom"}
```

каждый элемент несёт два значения. первое является ключом, второе является значением элемента. поскольку для ключей указан тип `int`, а для значений тип `string`, в элементе сначала стоит число, затем строка. у элемента выше ключ равен 5, значение равно `"Tom"`. по этому ключу значение затем читается из словаря.

вторая форма инициализации записывает ключ в квадратных скобках и присваивает ему значение:

```c#


var people = new Dictionary<int, string>()

{

    [5] = "Tom",

    [6] = "Sam",

    [7] = "Bob"

};
```

при такой записи вызывается индексатор. если ключа ещё нет, элемент добавляется. для начального заполнения обе формы дают один и тот же набор пар.

### структура `KeyValuePair<TKey, TValue>`

каждый элемент словаря представлен структурой `KeyValuePair<TKey, TValue>`. параметр `TKey` задаёт тип ключа, параметр `TValue` задаёт тип значения. свойства `Key` и `Value` возвращают ключ и значение элемента. структура является значимым типом: при перечислении в переменную попадает копия пары. одна из версий конструктора `Dictionary<TKey, TValue>` инициализирует словарь коллекцией таких объектов:

```c#


var mike = new KeyValuePair<int, string>(56, "Mike"); 

var employees = new List<KeyValuePair<int, string>>() { mike};

var people = new Dictionary<int, string>(employees);
```

конструктор `KeyValuePair<int, string>` принимает два параметра: ключ элемента и его значение. здесь создаётся одна пара `mike` с ключом 56 и значением `"Mike"`. эта пара добавляется в список `employees`, которым затем инициализируется словарь.

оба способа инициализации соединяются. конструктор копирует готовые пары, инициализатор добавляет остальные:

```c#


var mike = new KeyValuePair<int, string>(56, "Mike");

var employees = new List<KeyValuePair<int, string>>() { mike };

var people = new Dictionary<int, string>(employees)

{

    [5] = "Tom",

    [6] = "Sam",

    [7] = "Bob",

};
```

в словаре `people` после этого четыре элемента.

### перебор словаря

для перебора применяется цикл `foreach`:

```c#


var people = new Dictionary<int, string>()

{

    [5] = "Tom",

    [6] = "Sam",

    [7] = "Bob"

};

foreach(var person in people)

{

    Console.WriteLine($"key: {person.Key}  value: {person.Value}");

}
```

при переборе каждый элемент попадает в переменную типа `KeyValuePair<int, string>`. свойства `Key` и `Value` дают ключ и значение. консольный вывод этого прогона:

```bash


key: 5  value: Tom

key: 6  value: Sam

key: 7  value: Bob
```

контракт `Dictionary<TKey, TValue>` порядок перечисления не фиксирует. совпадение вывода с порядком вставки в одном прогоне не задаёт порядок следующего.

тип `KeyValuePair<TKey, TValue>` допускает деконструкцию, поэтому при переборе пару можно сразу разложить на ключ и значение:

```c#


var people = new Dictionary<int, string>()

{

    [5] = "Tom",

    [6] = "Sam",

    [7] = "Bob"

};

foreach (var (key, val) in people)  // раскладываем объект на свойства

{

    Console.WriteLine($"key: {key}  value: {val}");

}
```

### получение элементов

для обращения к элементу применяется его ключ. ключ передаётся индексатору в квадратных скобках:

```c#
словарь[ключ]
```

тем же индексатором элемент читают и изменяют:

```c#


var people = new Dictionary<int, string>()

{

    [5] = "Tom",

    [6] = "Sam",

    [7] = "Bob",

};

// получаем элемент по ключу 6

string sam = people[6];  // Sam

Console.WriteLine(sam);  // Sam

// переустанавливаем значение по ключу 6

people[6] = "Mike";

Console.WriteLine(people[6]);  // Mike



// добавляем новый элемент по ключу 22

people[22] = "Eugene";

Console.WriteLine(people[22]);  // Eugene
```

чтение `people[6]` возвращает значение по существующему ключу. присваивание `people[6] = "Mike"` заменяет значение, ключ остаётся прежним. присваивание по ключу, которого в словаре нет, добавляет новый элемент: так появляется пара с ключом 22 и значением `"Eugene"`. чтение отсутствующего ключа через индексатор завершается исключением `KeyNotFoundException`. если при записи ключ уже есть, значение переустанавливается. если такого ключа нет, элемент добавляется.

### методы и свойства `Dictionary<TKey, TValue>`

из методов класса дальше используются следующие:

- `void Add(K key, V value)`: добавляет новый элемент в словарь. если ключ уже есть, метод завершается исключением и прежнее значение не перезаписывает

- `void Clear()`: очищает словарь

- `bool ContainsKey(K key)`: проверяет наличие элемента с заданным ключом и возвращает `true`, если ключ есть в словаре

- `bool ContainsValue(V value)`: проверяет наличие элемента с заданным значением и возвращает `true`, если такое значение есть. поиск идёт по значениям, а не по хешу ключа, и линеен по числу элементов

- `bool Remove(K key)`: удаляет элемент по ключу и возвращает признак того, что элемент был в словаре. другая версия метода передаёт удалённый элемент в выходной параметр: `bool Remove(K key, out V value)`

- `bool TryGetValue(K key, out V value)`: получает из словаря элемент по ключу `key`. при успешном получении передаёт значение элемента в выходной параметр `value` и возвращает `true`. если ключа нет, возвращает `false`, а в `value` оказывается значение по умолчанию для типа `V`

- `bool TryAdd(K key, V value)`: добавляет в словарь элемент с ключом `key` и значением `value`. при успешном добавлении возвращает `true`. если ключ уже занят, словарь не меняется и метод возвращает `false`

из свойств отмечается `Count`: оно возвращает число элементов в словаре.

применение методов на телефонной книге. ключом служит номер телефона, значением служит имя абонента:

```c#


// условная телефонная книга

var phoneBook = new Dictionary<string, string>();



// добавляем элемент: ключ - номер телефона, значение - имя абонента

phoneBook.Add("+123456", "Tom");

// альтернативное добавление

// phoneBook["+123456"] = "Tom";



// Проверка наличия

var phoneExists1 = phoneBook.ContainsKey("+123456");    // true

Console.WriteLine($"+123456: {phoneExists1}");

var phoneExists2 = phoneBook.ContainsKey("+567456");    // false

Console.WriteLine($"+567456: {phoneExists2}");

var abonentExists1 = phoneBook.ContainsValue("Tom");      // true

Console.WriteLine($"Tom: {abonentExists1}");

var abonentExists2 = phoneBook.ContainsValue("Bob");      // false

Console.WriteLine($"Bob: {abonentExists2}");



// удаление элемента

phoneBook.Remove("+123456");



// проверяем количество элементов после удаления

Console.WriteLine($"Count: {phoneBook.Count}"); // Count: 0
```

`Add` вставляет пару с ключом `"+123456"` и значением `"Tom"`. индексатор, записанный в комментарии, для нового ключа выполняет ту же вставку. `ContainsKey` различает номер, который в книге есть, и номер, которого нет. `ContainsValue` так же проверяет имя абонента. `Remove` удаляет элемент по ключу. после удаления `Count` равен 0.
