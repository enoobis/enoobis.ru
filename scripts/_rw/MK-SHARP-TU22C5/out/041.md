помимо обычных полей, методов и свойств у класса и структуры бывают статические поля, методы и свойства. статический член относится ко всему типу, а не к отдельному экземпляру. для обращения к нему экземпляр создавать не обязательно: имя разрешается через имя типа.

### статические поля

статическое поле хранит состояние всего класса или всей структуры. его объявляют как обычное поле, но перед типом ставят служебное слово `static`. класс `Person` ниже представляет человека.

```c#


Person bob = new(68);

bob.СheckAge();     // Уже на пенсии



Person tom = new(37);

tom.СheckAge();     // Сколько лет осталось до пенсии: 28



// получение статического поля

Console.WriteLine(Person.retirementAge); // 65

// изменение статического поля

Person.retirementAge = 67;



class Person

{

    int age;

    public static int retirementAge = 65;

    public Person(int age)

    {

        this.age = age;

    }

    public void СheckAge()

    {

        if (age >= retirementAge)

			Console.WriteLine("Уже на пенсии");

        else

			Console.WriteLine($"Сколько лет осталось до пенсии: {retirementAge - age}");

    }

}
```

у `Person` два поля: `age` хранит возраст конкретного человека, `retirementAge` хранит пенсионный возраст. поле `retirementAge` статическое. оно относится ко всем людям, а не к одному объекту. в примере для простоты не учитывается, что пенсионный возраст может зависеть от пола и профессии. поле `retirementAge` не является состоянием отдельного объекта класса `Person`. оно принадлежит типу `Person` и хранит общее значение для всего класса.

внутри класса статическое поле используется так же, как остальные члены. метод `СheckAge` проверяет пенсионный статус и читает это поле.

```c#
if (age >= retirementAge)
```

вне класса к полю обращаются по имени класса.

```c#


Console.WriteLine(Person.retirementAge);

Person.retirementAge = 67;
```

для статического поля выделяется один участок памяти, общий для всех объектов класса. хранилище связано с объектом типа, а не с экземпляром, поэтому присваивание `Person.retirementAge = 67` видно через любой экземпляр.

![статические методы класса в c#](/uploads/course-lectures/b50131ed426eb67b4a0f9a6b3825c8278108ed04.png)

память под статические переменные выделяется и в том случае, когда не создано ни одного объекта этого класса. инициализация типа происходит при первом обращении к статическому члену или при первом создании экземпляра, если у типа есть статический конструктор. до этого момента статические поля ещё не получили свои значения, но после инициализации типа они существуют независимо от числа экземпляров.

### статические свойства

статические свойства объявляют и используют по тому же правилу.

```c#


Person bob = new(68);

bob.СheckAge();



Console.WriteLine(Person.RetirementAge); // 65



class Person

{

    int age;

    static int retirementAge = 65;

    public static int RetirementAge

    {

        get { return retirementAge; }

        set { if (value > 1 && value < 100) retirementAge = value; }

    }

    public Person(int age)

    {

        this.age = age;

    }

    public void СheckAge()

    {

        if (age >= retirementAge)

            Console.WriteLine("Уже на пенсии");

        else

            Console.WriteLine($"Сколько лет осталось до пенсии: {retirementAge - age}") ;

    }

}
```

доступ к статической переменной `retirementAge` идёт через статическое свойство `RetirementAge`. свойство принадлежит типу: его читают как `Person.RetirementAge`. сеттер отбрасывает значение вне интервала от 1 до 100, поэтому общее состояние класса меняется только при допустимом возрасте.

переменные и свойства, которые хранят состояние, общее для всех объектов класса или структуры, объявляют статическими.

статические поля и свойства часто служат счётчиками. счётчик ниже показывает, сколько объектов `Person` создано.

```c#


var tom = new Person();

var bob = new Person();

var sam = new Person();

Console.WriteLine(Person.Counter);  // 3



class Person

{

    static int counter = 0;

    public static int Counter => counter;

    public Person()

    {

        counter++;

    }

}
```

счётчик хранится в закрытой переменной `counter`. конструктор увеличивает её на единицу при каждом создании объекта. статическое свойство `Counter` доступно только для чтения и отдаёт текущее значение. инкремент обычным оператором не атомарен: при одновременном создании объектов из нескольких потоков часть увеличений может потеряться. атомарную замену даёт `System.Threading.Interlocked.Increment`.

### статические методы

статический метод задаёт поведение, общее для всех объектов и не зависящее от конкретного экземпляра. вызов идёт через имя класса или структуры.

```c#


Person bob = new(68);

Person.CheckRetirementStatus(bob);



class Person

{

    public int Age { get; set; }

    static int retirementAge = 65;

    public Person(int age) => Age = age;

    public static void CheckRetirementStatus(Person person)

    {

        if (person.Age >= retirementAge)

            Console.WriteLine("Уже на пенсии");

        else

            Console.WriteLine($"Сколько лет осталось до пенсии: {retirementAge - person.Age}") ;

    }

}
```

статический метод `CheckRetirementStatus` принимает объект `Person` и проверяет его пенсионный статус.

статический метод обращается только к статическим членам класса. к нестатическим методам, полям и свойствам из статического метода обратиться нельзя: у статического метода нет ссылки `this`, и экземплярного состояния в его области видимости нет. экземпляр, с которым метод работает, передают параметром, как `person` в этом примере.

### статический конструктор

кроме обычных конструкторов у класса бывает статический конструктор. у него такие отличия.

- статический конструктор не имеет модификатора доступа и не принимает параметров

- как и в статическом методе, в статическом конструкторе нельзя использовать `this` для ссылки на текущий объект, и обращаться можно только к статическим членам класса

- статический конструктор нельзя вызвать из программы вручную. он выполняется автоматически при первом создании объекта данного класса или при первом обращении к его статическим членам, если они есть

статический конструктор обычно инициализирует статические данные либо выполняет действие, которое требуется ровно один раз. наличие статического конструктора отключает у типа отложенную инициализацию `beforefieldinit`: среда выполнения запускает его непосредственно перед первым использованием, а не в произвольный более ранний момент. среда гарантирует однократный запуск, в том числе при одновременном обращении из нескольких потоков.

статический конструктор можно определить так.

```c#


Console.WriteLine(Person.RetirementAge);



class Person

{

    static int retirementAge;

    public static int RetirementAge => retirementAge;

    static Person()

    {

        if (DateTime.Now.Year == 2022)

            retirementAge = 65;

        else

            retirementAge = 67;

    }

}
```

встроенная структура `DateTime` даёт текущий год через свойство `DateTime.Now.Year`. если год равен 2022, пенсионный возраст устанавливается в 65. при любом другом годе устанавливается 67. чтение `Person.RetirementAge` в первой строке программы является обращением к статическому члену и потому запускает статический конструктор до того, как свойство вернёт значение.

### статические классы

статический класс объявляют с модификатором `static`. он содержит только статические поля, свойства и методы. класс ниже выполняет несколько арифметических операций.

```c#


Console.WriteLine(Operations.Add(5, 4));         // 9

Console.WriteLine(Operations.Subtract(5, 4));    // 1

Console.WriteLine(Operations.Multiply(5, 4));    // 20



static class Operations

{

    public static int Add(int x, int y) => x + y;

    public static int Subtract(int x, int y) => x - y;

    public static int Multiply(int x, int y) => x * y;

}
```

экземпляр `Operations` создать нельзя: у статического класса нет конструктора экземпляра, доступного вызывающему коду. такой класс не используется как базовый тип. все вызовы идут через имя типа, как `Operations.Add`.
