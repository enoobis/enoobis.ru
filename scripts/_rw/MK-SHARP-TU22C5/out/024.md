локальная функция объявляется внутри другого метода. её область видимости ограничена объемлющим методом: имя локальной функции не входит в область видимости типа и недоступно снаружи. обычно в неё выносят действие, которое нужно только этому методу.

метод, сравнивающий суммы элементов двух массивов:

```c#


void Compare(int[] numbers1, int[] numbers2)

{

    int numbers1Sum = 0;

    int numbers2Sum = 0;



    foreach(int number in numbers1) 

        numbers1Sum += number; 



    foreach (int number in numbers2)

        numbers2Sum += number;



    if (numbers1Sum > numbers2Sum)

        Console.WriteLine("сумма чисел из массива numbers1 больше");

    else if (numbers1Sum < numbers2Sum)

        Console.WriteLine("сумма чисел из массива numbers2 больше");

    else

        Console.WriteLine("суммы чисел обоих массивов равны");

}



int[] numbers1 = { 1, 2, 3 };

int[] numbers2 = { 3, 4, 5, 6, 7 };



Compare(numbers1, numbers2);
```

метод `Compare` принимает два массива и по очереди суммирует их элементы, чтобы выяснить, в каком массиве сумма больше. вычисление работает, но одно и то же действие записано дважды:

```c#


int numbers1Sum = 0;



foreach(int number in numbers1) 

	numbers1Sum += number;
```

если потребуется суммировать только положительные или только чётные элементы либо иначе изменить критерий, правку придётся внести в оба цикла. повторяющееся действие логично вынести в отдельный метод. когда оно не вызывается больше нигде в программе и используется только внутри одного метода, его объявляют локальной функцией. метод `Compare` тогда принимает вид:

```c#


void Compare(int[] numbers1, int[] numbers2)

{

    int numbers1Sum = Sum(numbers1);

    int numbers2Sum = Sum(numbers2);



    if (numbers1Sum > numbers2Sum)

        Console.WriteLine("сумма чисел из массива numbers1 больше");

    else if (numbers1Sum < numbers2Sum)

        Console.WriteLine("сумма чисел из массива numbers2 больше");

    else

        Console.WriteLine("суммы чисел обоих массивов равны");



    int Sum(int[] numbers)

    {

        int result = 0;

        foreach (int number in numbers)

            result += number;

        return result;

    }

}



int[] numbers1 = { 1, 2, 3 };

int[] numbers2 = { 3, 4, 5, 6, 7 };



Compare(numbers1, numbers2);
```

сумма вынесена в локальную функцию `Sum`: она принимает массив и возвращает сумму элементов. внутри `Compare` она вызывается для обоих массивов. локальную функцию можно вызывать и до её объявления в тексте метода: имя локальной функции находится в области видимости всего тела, а не только текста ниже объявления. вне метода `Compare` имя `Sum` не видно.

компилятор оформляет локальную функцию как метод объемлющего типа. если она захватывает локальные переменные или параметры внешнего метода, для этих переменных строится замыкание: объект, который переживает кадр стека и хранит захваченное состояние. если захвата нет, отдельный объект не нужен.

### статические локальные функции

локальная функция может быть статической. её объявляют с модификатором `static`. такая функция не обращается к переменным окружения, то есть к локальным переменным и параметрам метода, в котором она объявлена. отсутствие захвата означает, что замыкание не создаётся.

сначала локальная функция, которой окружение доступно:

```c#


int Sum(int[] numbers)

{

    int limit = 0;

    int result = 0;

    foreach (int number in numbers)

    {

        if (IsPassed(number)) result += number;

    }

    return result;



    bool IsPassed(int number)

    {

        return number > limit;

    }

}



int[] numbers1 = { -3, -2, -1, 0, 1, 2, 3 };

int[] numbers2 = { 3, -4, 5, -6, 7 };



Console.WriteLine(Sum(numbers1));

Console.WriteLine(Sum(numbers2));
```

функция `Sum` суммирует те элементы массива, которые проходят проверку локальной функции `IsPassed`. `IsPassed` сравнивает переданное число с переменной `limit`, объявленной в `Sum`. локальная функция читает состояние объемлющей функции: `limit` захвачена. при `limit`, равном 0, в сумму входят только положительные элементы.

та же функция, объявленная статической:

```c#


int Sum(int[] numbers)

{

    int result = 0;

    int limit = 0;

    foreach (int number in numbers)

    {

        if (IsPassed(number, limit)) result += number;

    }

    return result;



    static bool IsPassed(int number, int lim)

    {

        //return number > limit; // Ошибка: метод IsPassed не имеет доступа к переменной limit

        return number > lim;

    }

}
```

модификатор `static` ставится перед типом результата локальной функции. `IsPassed` больше не видит `limit`. значение нужно либо передать параметром, как здесь через `lim`, либо завести собственную локальную переменную внутри `IsPassed`. обращение к `limit` из статической локальной функции является ошибкой компиляции: статический контекст не связан с кадром объемлющего метода.
