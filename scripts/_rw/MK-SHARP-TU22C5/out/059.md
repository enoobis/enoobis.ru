### определение блока catch

за обработку исключения отвечает блок **catch**. у него есть следующие формы.

- обрабатывает любое исключение, которое возникло в блоке `try`. пример такого блока уже был показан выше.

```c#


catch

{

	// выполняемые инструкции

}
```

такая форма не называет тип. в неё попадает любое исключение, дошедшее до этого кадра стека, если более ранний `catch` его не забрал.

- обрабатывает только те исключения, которые соответствуют типу, указанному в скобках после оператора `catch`. так обрабатываются только исключения типа `DivideByZeroException`. если в блоке `try` возникнут исключения других типов, отличных от `DivideByZeroException`, они обработаны не будут.

```c#


catch (тип_исключения)

{

	// выполняемые инструкции

}
```

```c#


try

{

	int x = 5;

	int y = x / 0;

	Console.WriteLine($"Результат: {y}");

}

catch(DivideByZeroException)

{

	Console.WriteLine("Возникло исключение DivideByZeroException");

}
```

типизированный `catch` совместим с указанным типом и с его подтипами: обработчик выбирается по отношению наследования, а не по точному равенству типа. поиск идёт сверху вниз по тексту метода, срабатывает первый подходящий блок.

- обрабатывает только те исключения, которые соответствуют типу, указанному в скобках после оператора `catch`. вся информация об исключении помещается в переменную данного типа. по правилу отбора типа эта форма совпадает с предыдущей и добавляет переменную. в переменную `ex` типа `DivideByZeroException` помещается информация о возникшем исключении. свойство `Message` даёт сообщение об ошибке. если информация об исключении не нужна, переменную можно не объявлять, как в предыдущей форме.

```c#


catch (тип_исключения имя_переменной)

{

	// выполняемые инструкции

}
```

```c#


try

{

	int x = 5;

	int y = x / 0;

	Console.WriteLine($"Результат: {y}");

}

catch(DivideByZeroException ex)

{

	Console.WriteLine($"Возникло исключение {ex.Message}");

}
```

переменная обработчика есть ссылка на тот объект исключения, который был создан при генерации. через неё доступны сообщение, стек и остальные свойства базового типа `Exception`.

### фильтры исключений

фильтры исключений позволяют обрабатывать исключения в зависимости от определённых условий. после выражения `catch` идёт выражение **when**, после которого в скобках указывается условие:

```c#


catch when(условие)

{

	

}
```

обработка исключения в блоке `catch` производится только в том случае, если условие в выражении `when` истинно. пример:

```c#


int x = 1;

int y = 0;



try

{

    int result1 = x / y;

    int result2 = y / x;

}

catch (DivideByZeroException) when (y == 0)

{

    Console.WriteLine("y не должен быть равен 0");

}

catch(DivideByZeroException ex)

{

    Console.WriteLine(ex.Message);

}
```

здесь выбрасывается исключение, так как `y` равен 0. блоков `catch` два, и оба обрабатывают исключения типа `DivideByZeroException`, то есть все исключения, генерируемые при делении на ноль. для первого блока указано условие **y == 0**, поэтому обрабатывает исключение именно этот блок: условие после оператора **when** возвращает `true`.

фильтр выполняется на первой фазе поиска обработчика, до раскрутки стека. если условие ложно, блок не считается подходящим, его `catch` не выполняется, и среда продолжает поиск. локальные `finally` этого кадра к моменту фильтра ещё не отработали.

противоположная ситуация:

```c#


int x = 0;

int y = 1;



try

{

    int result1 = x / y;

    int result2 = y / x;

}

catch (DivideByZeroException) when (y == 0)

{

    Console.WriteLine("y не должен быть равен 0");

}

catch(DivideByZeroException ex)

{

    Console.WriteLine(ex.Message);

}
```

здесь выбрасывается исключение, так как `x` равен 0. условие первого блока `catch`, **y == 0**, теперь возвращает `false`. clr ищет соответствующие блоки `catch` дальше и для обработки исключения выбирает второй блок `catch`. если второй блок `catch` убрать, исключение вообще не будет обрабатываться: фильтр, вернувший `false`, обработчиком не является.
