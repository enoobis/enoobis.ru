пространство имён **System.Dynamic** дополняет dlr готовыми типами динамических объектов. основной из них для прикладного кода называется `ExpandoObject`. он строит объект, набор членов которого задаётся при выполнении, по той же схеме, что и объект в javascript:

```c#


// определяем объект, который будет хранять ряд значений

dynamic person = new System.Dynamic.ExpandoObject();

person.Name = "Tom";

person.Age = 46;

person.Languages = new List<string> { "english", "german", "french" };



Console.WriteLine($"{person.Name} - {person.Age}");

foreach (var lang in person.Languages)

    Console.WriteLine(lang);



// объявляем метод

person.IncrementAge = (Action<int>)(x => person.Age += x);

person.IncrementAge(6); // увеличиваем возраст на 6 лет

Console.WriteLine($"{person.Name} - {person.Age}");
```

консольный вывод:

```bash


Tom - 46

english

german

french

Tom - 52
```

у экземпляра `ExpandoObject` объявляются произвольные свойства. в примере это `Name`, `Age` и `Languages`. тип значения у каждого свойства свой: строка, целое число, список строк. метод задаётся так же, как свойство, только в значение записывается делегат. присваивание `person.IncrementAge` сохраняет лямбду типа `Action<int>`, а вызов `person.IncrementAge(6)` исполняет её и увеличивает `Age` на `6`.

члены `ExpandoObject` хранятся как словарь имя-значение. присваивание неизвестного имени добавляет запись, чтение отсутствующего имени завершается ошибкой связывания. отдельных статических членов и собственной семантики операций у этого класса нет: он покрывает случай, когда объекту достаточно набора свойств и делегатов.

### dynamicobject

класс **DynamicObject** решает ту же задачу, но оставляет программе саму семантику операций. он нужен там, где придётся определить, как объект реагирует на чтение, запись, вызов, индексацию и арифметику. `ExpandoObject` для таких случаев не рассчитан: у него нельзя подменить отдельные операции и нельзя добавить статические члены.

чтобы пользоваться **DynamicObject**, объявляют собственный класс, наследуют его от `DynamicObject` и переопределяют нужные методы. конструктор `DynamicObject` защищённый, поэтому экземпляр самого базового класса из внешнего кода не создаётся. переопределяемые методы такие:

- `TryBinaryOperation()` : выполняет бинарную операцию между двумя объектами. по смыслу совпадает со стандартными бинарными операциями, например со сложением `x + y`

- `TryConvert()` : выполняет преобразование к заданному типу. по смыслу совпадает с преобразованием в c#, например `(SomeType) obj`

- `TryCreateInstance()` : создаёт экземпляр объекта

- `TryDeleteIndex()` : удаляет индексатор

- `TryDeleteMember()` : удаляет свойство или метод

- `TryGetIndex()` : читает элемент по индексу через индексатор. в c# тому же соответствует выражение `int x = collection[i]`

- `TryGetMember()` : читает значение свойства. по смыслу совпадает с обращением к свойству, например `string n = person.Name`

- `TryInvoke()` : вызывает сам объект как делегат

- `TryInvokeMember()` : вызывает метод

- `TrySetIndex()` : записывает элемент по индексу через индексатор. в c# тому же соответствует выражение `collection[i] = x;`

- `TrySetMember()` : записывает свойство. по смыслу совпадает с присваиванием свойству, например `person.Name = "Tom"`

- `TryUnaryOperation()` : выполняет унарную операцию, как унарные операции в c#: `x++`

у всех этих методов одна схема. каждый возвращает `bool`: `true` означает, что операция выполнена, `false` передаёт её обратно связывателю, и вызывающий код получает отказ в связывании. первый параметр всегда является связывателем, binder. он несёт имя члена и сведения о сигнатуре, которые компилятор собрал в точке вызова. если операция соответствует индексатору или методу с аргументами, вторым параметром идёт массив `object[]`: в нём лежат аргументы, переданные в метод или индексатор.

почти все операции, кроме установки и удаления свойств и индексаторов, возвращают значение. для него предусмотрен третий параметр вида `out object`: через него метод отдаёт результат наружу. в конкретных сигнатурах тип этого параметра записывается как `out object?`.

сигнатура `TryInvokeMember()` выглядит так:

```c#


public virtual bool TryInvokeMember (InvokeMemberBinder binder, object?[]? args, out object? result)
```

параметр `InvokeMemberBinder binder` является связывателем и даёт имя вызываемого метода. `object?[]? args` хранит переданные аргументы. `out object? result` предназначен для выходного результата.

пример динамического объекта:

```c#


using System.Dynamic;



class PersonObject : DynamicObject

{

    // словарь для хранения всех свойств

    Dictionary<string, object> members = new Dictionary<string, object>();



    // установка свойства

    public override bool TrySetMember(SetMemberBinder binder, object? value)

    {

        if(value is not null)

        {

            members[binder.Name] = value;

            return true;

        }

        return false;

    }

    // получение свойства

    public override bool TryGetMember(GetMemberBinder binder, out object? result)

    {

        result = null;

        if (members.ContainsKey(binder.Name))

        {

            result = members[binder.Name];

            return true;

        }

        return false;

    }

    // вызов метода

    public override bool TryInvokeMember(InvokeMemberBinder binder, object?[]? args, out object? result)

    {

        result = null;

        if(args?[0] is int number)

        {

            // получаем метод по имен

            dynamic method = members[binder.Name];

            // вызываем метод, передавая его параметру значение args?[0]

            result = method(number);

        }

        // если result не равен null, то вызов метода прошел успешно

        return result != null;

    }

}
```

класс наследует `DynamicObject`. непосредственно создавать объекты `DynamicObject` нельзя, поэтому вся семантика живёт в наследнике. здесь переопределены три метода: запись свойства, чтение свойства и вызов метода.

все члены, и свойства, и методы, лежат в словаре `Dictionary<string, object> members`. ключ является именем свойства или метода, значение является содержимым этого члена. для метода содержимым служит делегат.

запись свойства выполняет `TrySetMember()`:

```c#


bool TrySetMember(SetMemberBinder binder, object? value)
```

параметр `binder` хранит имя устанавливаемого свойства в `binder.Name`, параметр `value` хранит присваиваемое значение. если значение не равно `null`, оно записывается в словарь под этим именем, и метод возвращает `true`. значение `null` метод отвергает и возвращает `false`: в словаре, как он объявлен в примере, пустая ссылка не сохраняется.

чтение свойства выполняет `TryGetMember`:

```c#


bool TryGetMember(GetMemberBinder binder, out object? result)
```

`binder` снова содержит имя свойства. параметр `result` получает значение. перед поиском `result` обнуляется. если ключ в словаре есть, в `result` копируется хранимое значение и метод возвращает `true`. если ключа нет, метод возвращает `false`, а `result` остаётся `null`.

вызов метода выполняет `TryInvokeMember`:

```c#


public override bool TryInvokeMember(InvokeMemberBinder binder, object?[]? args, out object? result)

{

    result = null;

    if(args?[0] is int number)

    {

        // получаем метод по имен

        dynamic method = members[binder.Name];

        // вызываем метод, передавая его параметру значение args?[0]

        result = method(number);

    }

    // если result не равен null, то вызов метода прошел успешно

    return result != null;

}
```

сначала `result` устанавливается в `null`. затем проверяется первый аргумент: образец `args?[0] is int number` истинен, только если массив аргументов не пуст и нулевой элемент имеет тип `int`. дальше по имени из `binder.Name` из словаря достаётся делегат, вызывается с этим целым, и результат вызова записывается в `result`. реализация рассчитана на метод с одним параметром типа `int` и с возвращаемым значением. если `result` после вызова не равен `null`, метод метаобъекта возвращает `true`, и вызов считается успешным. если аргумент не является `int`, ветка не выполняется, `result` остаётся `null`, и наружу уходит `false`. обращение к отсутствующему имени в словаре эта реализация не перехватывает: индексатор словаря в таком случае выбрасывает исключение до возврата из `TryInvokeMember`.

применение класса:

```c#


using System.Dynamic;



// создаем объект

dynamic person = new PersonObject();

// устанавливаем ряд свойств

person.Name = "Tom";

person.Age = 23;

// определяем метод для изменения свойства Age

Func<int, int> increment = (int n) => { person.Age += n; return person.Age; };

person.IncrementAge = increment;



Console.WriteLine($"{person.Name} - {person.Age}"); // Tom - 23

person.IncrementAge(4); // применяем метод

Console.WriteLine($"{person.Name} - {person.Age}"); // Tom - 27
```

выражение `person.Name = "Tom"` вызывает `TrySetMember`. вторым аргументом в него приходит строка `"Tom"`, а имя члена связыватель передаёт как `Name`. выражение `person.Age = 23` устроено так же.

выражение `return person.Age` внутри лямбды вызывает `TryGetMember` и получает значение, ранее записанное в словарь.

метод `IncrementAge` задаётся лямбдой `(int n) => { person.Age += n; return person.Age; }`. лямбда принимает число `n`, увеличивает на него свойство `Age` и возвращает новое значение `person.Age`. делегат сохраняется в словаре под именем `IncrementAge`. вызов `person.IncrementAge(4)` попадает в `TryInvokeMember`: связыватель передаёт имя `IncrementAge`, массив аргументов содержит `4`, делегат исполняется, и свойство `person.Age` увеличивается. первый вывод печатает `Tom - 23`, второй, после приращения на `4`, печатает `Tom - 27`.
