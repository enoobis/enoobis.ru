класс `LinkedList<T>` представляет двусвязный список: каждый узел хранит ссылку на следующий узел и ссылку на предыдущий. в отличие от `List<T>` элементы не лежат непрерывным блоком. поиск узла по позиции или по значению линеен. вставка и удаление рядом с уже известным узлом меняют только соседние ссылки и остальные элементы не сдвигают.

### создание связанного списка

для создания списка применяется один из конструкторов. пустой список:

```c#


LinkedList<string> people = new LinkedList<string>();
```

список `people` предназначен для хранения строк.

в конструктор можно передать коллекцию элементов, например `List<string>`. по ней строится связный список, узлы идут в порядке перечисления источника:

```c#


var employees = new List<string> { "Tom", "Sam", "Bob" };



LinkedList<string> people = new LinkedList<string>(employees);

foreach (string person in people)

{

    Console.WriteLine(person);

}
```

### узел `LinkedListNode<T>`

в `List<T>` каждый элемент представлен значением типа `T`. в `LinkedList<T>` каждый узел является объектом класса `LinkedListNode<T>`, а значение типа `T` хранится внутри узла. сами узлы являются ссылочными объектами и размещаются в куче.

свойства `LinkedListNode<T>`:

- `Value`: возвращает или устанавливает значение узла, представленное типом `T`

- `Next`: возвращает ссылку на следующий элемент типа `LinkedListNode<T>` в списке. если следующий элемент отсутствует, свойство имеет значение `null`

- `Previous`: возвращает ссылку на предыдущий элемент типа `LinkedListNode<T>` в списке. если предыдущий элемент отсутствует, свойство имеет значение `null`

### свойства `LinkedList<T>`

класс `LinkedList<T>` определяет следующие свойства:

- `Count`: число элементов в связанном списке

- `First`: первый узел в списке в виде объекта `LinkedListNode<T>`. у пустого списка свойство равно `null`

- `Last`: последний узел в списке в виде объекта `LinkedListNode<T>`. у пустого списка свойство равно `null`

применение этих свойств:

```c#


var employees = new List<string> { "Tom", "Sam", "Bob" };



LinkedList<string> people = new LinkedList<string>(employees);

Console.WriteLine(people.Count);            // 3

Console.WriteLine(people.First?.Value);    // Tom

Console.WriteLine(people.Last?.Value);    // Bob
```

оператор `?.` у `First` и `Last` нужен потому, что у пустого списка этих узлов нет. через свойства списка и узла выполняется проход по всем элементам в прямом или обратном порядке. индексатора у `LinkedList<T>` нет, поэтому доступ по номеру позиции сводится к такому проходу:

```c#


LinkedList<string> people = new LinkedList<string>(new[] { "Tom", "Sam", "Bob" });



// от начала до конца списка

var currentNode = people.First;

while(currentNode != null)

{

    Console.WriteLine(currentNode.Value);

    currentNode = currentNode.Next;

}



// с конца до начала списка

currentNode = people.Last;

while (currentNode != null)

{

    Console.WriteLine(currentNode.Value);

    currentNode = currentNode.Previous;

}
```

прямой проход начинается с `First` и движется по `Next`, пока ссылка не станет равной `null`. обратный проход начинается с `Last` и движется по `Previous`. значение элемента читается из `Value`.

### методы `LinkedList<T>`

методы класса обращаются к элементам и в конце списка, и в начале, и рядом с известным узлом:

- `AddAfter(LinkedListNode<T> node, LinkedListNode<T> newNode)`: вставляет узел `newNode` в список после узла `node`

- `AddAfter(LinkedListNode<T> node, T value)`: вставляет в список новый узел со значением `value` после узла `node`

- `AddBefore(LinkedListNode<T> node, LinkedListNode<T> newNode)`: вставляет в список узел `newNode` перед узлом `node`

- `AddBefore(LinkedListNode<T> node, T value)`: вставляет в список новый узел со значением `value` перед узлом `node`

- `AddFirst(LinkedListNode<T> node)`: вставляет узел в начало списка

- `AddFirst(T value)`: вставляет новый узел со значением `value` в начало списка

- `AddLast(LinkedListNode<T> node)`: вставляет узел в конец списка

- `AddLast(T value)`: вставляет новый узел со значением `value` в конец списка

- `RemoveFirst()`: удаляет первый узел из списка. после этого новым первым узлом становится узел, следующий за удалённым

- `RemoveLast()`: удаляет последний узел из списка

узел, который передаётся в `AddAfter`, `AddBefore` и в перегрузки с готовым `LinkedListNode<T>`, должен принадлежать этому списку. иначе операция завершается исключением. один и тот же узел не входит сразу в два списка.

применение части методов:

```c#


var people = new LinkedList<string>();

people.AddLast("Tom"); // вставляем узел со значением Tom на последнее место

                        //так как в списке нет узлов, то последнее будет также и первым

people.AddFirst("Bob"); // вставляем узел со значением Bob на первое место



// вставляем после первого узла новый узел со значением Mike

if (people.First != null) people.AddAfter(people.First, "Mike");



// теперь у нас список имеет следующую последовательность: Bob Mike Tom

foreach (var person in people) Console.WriteLine(person);
```

`AddLast("Tom")` ставит узел со значением `"Tom"` на последнее место. список в этот момент пуст, поэтому последнее место совпадает с первым. `AddFirst("Bob")` ставит узел со значением `"Bob"` на первое место. `AddAfter(people.First, "Mike")` вставляет после первого узла новый узел со значением `"Mike"`. проверка `people.First != null` отсекает пустой список: вставка относительно отсутствующего узла не выполняется. порядок обхода после этих операций: `Bob`, `Mike`, `Tom`.

так же строится список другого типа элемента:

```c#


var company = new LinkedList<Person>();



company.AddLast(new Person("Tom"));

company.AddLast(new Person("Sam"));

company.AddFirst(new Person("Bill"));



foreach (var person in company) Console.WriteLine(person.Name);



class Person

{

    public string Name { get; }

    public Person(string name) => Name = name;

}
```

здесь значение узла имеет тип `Person`, а при обходе печатается свойство `Name`. два вызова `AddLast` дописывают в хвост `"Tom"` и `"Sam"`, `AddFirst` ставит `"Bill"` в голову.
