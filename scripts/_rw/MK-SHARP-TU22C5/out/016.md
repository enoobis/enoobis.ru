массив хранит последовательность элементов одного типа. объявление похоже на объявление переменной: после типа ставятся квадратные скобки. массив в c# является ссылочным типом: переменная хранит ссылку на объект в куче, а длина объекта фиксируется при создании.

```c#
тип_переменной[] название_массива;
```

массив целых чисел объявляется так:

```c#
int[] numbers;
```

после объявления переменной ей присваивают созданный массив:

```c#
int[] nums = new int[4];
```

переменная `nums` ссылается на массив элементов `int`. операция `new` выделяет память на 4 элемента: `new int[4]`. это число называется длиной массива. каждый элемент получает значение по умолчанию своего типа. для `int` это 0. для ссылочного типа элемента значением по умолчанию был бы `null`.

элементы можно инициализировать сразу. четыре формы ниже задают один и тот же массив длины 4. `new[]` выводит тип элемента из списка инициализации, а форма без `new` допустима только в объявлении с явным типом слева:

```c#


int[] nums2 = new int[4] { 1, 2, 3, 5 };



int[] nums3 = new int[] { 1, 2, 3, 5 };



int[] nums4 = new[] { 1, 2, 3, 5 };



int[] nums5 = { 1, 2, 3, 5 };
```

все четыре определения равноценны: получается массив `int` из элементов 1, 2, 3 и 5.

так же объявляют массивы других типов, например `string`:

```c#
string[] people = { "Tom", "Sam", "Bob" };
```

начиная с c# 12 массив можно задать выражением коллекции: элементы стоят в квадратных скобках. тип берется из левой части. пустое выражение `[]` дает массив длины 0, если слева указан тип массива:

```c#


int[] nums1 = [ 1, 2, 3, 5 ];

int[] nums2 = [];   // пустой массив
```

### индексы и получение элементов массива

доступ к элементу идет по индексу. индекс нумерует элемент с нуля, поэтому у первого элемента индекс 0, у четвертого индекс 3. чтение и запись по индексу выполняются за постоянное время. проверка границы выполняется во время выполнения.

чтение элемента:

```c#


int[] numbers = { 1, 2, 3, 5 };



// получение элемента массива

Console.WriteLine(numbers[3]);  // 5



// получение элемента массива в переменную

var n = numbers[1]; 	// 2

Console.WriteLine(n);  // 2
```

запись в элемент по индексу:

```c#


int[] numbers = { 1, 2, 3, 5 };



// изменим второй элемент массива

numbers[1] = 505;



Console.WriteLine(numbers[1]);  // 505
```

массив создан на 4 элемента, индексы 0, 1, 2 и 3. обращение к шестому элементу, то есть к индексу 6, выходит за границу. компилятор такое обращение не отвергает: индекс в общем случае становится известен только при выполнении. во время выполнения выбрасывается `IndexOutOfRangeException`:

```c#


int[] numbers = { 1, 2, 3, 5 };



Console.WriteLine(numbers[6]);  // ! Ошибка - в массиве только 4 элемента
```

### свойство length и длина массива

у каждого массива есть свойство `Length`. оно хранит число элементов. для одномерного массива это и есть длина единственного измерения:

```c#


int[] numbers = { 1, 2, 3, 5 };



Console.WriteLine(numbers.Length);  // 4
```

свойство указывается через точку после имени: `numbers.Length`.

### получение элементов с конца массива

индекс последнего элемента равен длине минус 1. при длине 4 последний индекс равен 3. через `Length` читают элементы с конца:

```c#


int[] numbers = { 1, 2, 3, 5};



Console.WriteLine(numbers[numbers.Length - 1]);  // 5 - первый с конца или последний элемент

Console.WriteLine(numbers[numbers.Length - 2]);  // 3 - второй с конца или предпоследний элемент

Console.WriteLine(numbers[numbers.Length - 3]);  // 2 - третий элемент с конца
```

выражение вида `numbers.Length - 1` каждый раз заново кодирует смещение от конца. начиная с c# 8.0 для этого есть оператор `^`: индекс от конца. `numbers[^k]` обозначает тот же элемент, что `numbers[numbers.Length - k]`. `^1` указывает на последний элемент, `^0` совпадает с длиной и в границы не входит.

тот же пример через `^`:

```c#


int[] numbers = { 1, 2, 3, 5};



Console.WriteLine(numbers[^1]);  // 5 - первый с конца или последний элемент

Console.WriteLine(numbers[^2]);  // 3 - второй с конца или предпоследний элемент

Console.WriteLine(numbers[^3]);  // 2 - третий элемент с конца
```

### перебор массивов

массив перебирают разными циклами. `foreach` последовательно читает элементы:

```c#


int[] numbers = { 1, 2, 3, 4, 5 };

foreach (int i in numbers)

{

    Console.WriteLine(i);

}
```

контейнер имеет тип `int[]`, элемент имеет тип `int`, поэтому переменная цикла объявлена как `int`. для типа-значения в переменную попадает копия элемента.

тот же обход записывают циклом `for`. индекс идет от 0 до `Length - 1`:

```c#


int[] numbers = { 1, 2, 3, 4, 5 };

for (int i = 0; i < numbers.Length; i++)

{

    Console.WriteLine(numbers[i]);

}
```

`for` гибче `foreach`. `foreach` идет по элементам подряд и служит для чтения. в `for` шаг счетчика можно увеличить больше чем на единицу и пропустить элементы, а по индексу можно записать новое значение:

```c#


int[] numbers = { 1, 2, 3, 4, 5 };

for (int i = 0; i < numbers.Length; i++)

{

	numbers[i] = numbers[i] * 2;

    Console.WriteLine(numbers[i]);

}
```

тот же последовательный обход записывают циклом `while`. счетчик меняют в теле, условие сравнивает его с `Length`:

```c


int[] numbers = { 1, 2, 3, 4, 5 };

int i = 0;

while(i < numbers.Length)

{

    Console.WriteLine(numbers[i]);

	i++;

}
```

### многомерные массивы

ранг массива равен числу измерений. у одномерного массива ранг 1, его можно представить строкой или столбцом. у многомерного массива ранг больше 1. такой массив прямоугольный: длина каждого измерения фиксирована и одинакова для всех позиций по другим измерениям.

массив ранга 2 называют двухмерным. ниже одномерный и двухмерный массивы содержат одни и те же числа:

```c#


int[] nums1 = new int[] { 0, 1, 2, 3, 4, 5 };



int[,] nums2 = { { 0, 1, 2 }, { 3, 4, 5 } };
```

визуально оба массива выглядят так.

одномерный массив `nums1`

| 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |

двухмерный массив `nums2`

| 0 | 1 | 2 |
| --- | --- | --- |
| 3 | 4 | 5 |

`nums2` представляет таблицу из двух строк и трех столбцов. элементы лежат в одном объекте, обход по умолчанию идет по строкам. способы объявления двухмерного массива:

```c#


int[,] nums1;

int[,] nums2 = new int[2, 3];

int[,] nums3 = new int[2, 3] { { 0, 1, 2 }, { 3, 4, 5 } };

int[,] nums4 = new int[,] { { 0, 1, 2 }, { 3, 4, 5 } };

int[,] nums5 = new [,]{ { 0, 1, 2 }, { 3, 4, 5 } };

int[,] nums6 = { { 0, 1, 2 }, { 3, 4, 5 } };
```

ранг может быть и больше двух. трехмерный массив объявляют тремя запятыми в скобках. размеры измерений задают отдельно:

```c#


int[,,] nums3 = new int[2, 3, 4];
```

возможны и четырехмерные массивы, и массивы большего ранга. на практике обычно хватает ранга 1 и 2: с ростом ранга адресация `a[i, j, k, ...]` быстро теряет наглядность.

при переборе многомерного массива учитывают, что `Length` равен общему числу элементов, а не числу строк:

```c#


int[,] numbers = { { 1, 2, 3 }, { 4, 5, 6 }};

foreach (int i in numbers)

	Console.Write($"{i} ");
```

у массива `numbers` длина 6: две строки по три элемента. `foreach` обходит элементы по строкам и печатает их в одну строку:

```consoletext
1 2 3 4 5 6
```

чтобы обойти таблицу по строкам отдельно, нужна длина каждого измерения. метод `GetUpperBound(номер_размерности)` возвращает индекс последнего элемента в этом измерении. для массива, созданного через `new`, нижняя граница равна 0, поэтому число элементов измерения равно `GetUpperBound(d) + 1`. у двухмерного массива измерение 0 соответствует строкам. выражение

```c#
numbers.GetUpperBound(0) + 1
```

дает число строк. выражение

```c#
numbers.Length / количество_строк
```

дает число элементов в каждой строке, то есть число столбцов. тот же размер столбцов равен `GetUpperBound(1) + 1`, как в комментарии примера. вложенные циклы печатают таблицу:

```c#


int[,] numbers = { { 1, 2, 3 }, { 4, 5, 6 }};



int rows = numbers.GetUpperBound(0) + 1;	// количество строк

int columns = numbers.Length / rows;		// количество столбцов

// или так

// int columns = numbers.GetUpperBound(1) + 1;



for (int i = 0; i < rows; i++)

{

	for (int j = 0; j < columns; j++)

	{

		Console.Write($"{numbers[i, j]} \t");

	}

	Console.WriteLine();

}
```

вывод сохраняет строки таблицы:

```consoletext


1	2	3

4	5	6
```

### массив массивов

прямоугольный многомерный массив отличается от массива массивов, его также называют зубчатым. у зубчатого массива ранг равен 1: элемент сам является массивом, и длины внутренних массивов могут различаться. каждая строка является отдельным объектом.

```c#


int[][] nums = new int[3][];

nums[0] = new int[2] { 1, 2 };			// выделяем память для первого подмассива

nums[1] = new int[3] { 1, 2, 3 };		// выделяем память для второго подмассива

nums[2] = new int[5] { 1, 2, 3, 4, 5 };	// выделяем память для третьего подмассива
```

две группы квадратных скобок означают массив массивов. длина задается только в первых скобках, следующие остаются пустыми: `new int[3][]`. массив `nums` содержит три массива, их длины 2, 3 и 5 и совпадать не обязаны. пока внутренняя ссылка не инициализирована, она равна `null`, и чтение строки без присваивания дает `NullReferenceException`.

альтернативное определение сразу строит внутренние массивы:

```c#


int[][] numbers = { 

    new int[] { 1, 2 }, 

    new int[] { 1, 2, 3 }, 

    new int[] { 1, 2, 3, 4, 5 } 

};
```

зубчатый массив `nums`

| 1 | 2 |  |  |  |
| --- | --- | --- | --- | --- |
| 1 | 2 | 3 |  |  |
| 1 | 2 | 3 | 4 | 5 |

зубчатый массив перебирают вложенными циклами. внешний цикл получает строку типа `int[]`, внутренний читает ее элементы. длина строки берется из `Length` этой строки, а не из общей длины:

```c#


int[][] numbers = new int[3][];

numbers[0] = new int[] { 1, 2 };

numbers[1] = new int[] { 1, 2, 3 };

numbers[2] = new int[] { 1, 2, 3, 4, 5 };

foreach(int[] row in numbers)

{

	foreach(int number in row)

    {

		Console.Write($"{number} \t");

    }

	Console.WriteLine();

}



// перебор с помощью цикла for

for (int i = 0; i<numbers.Length;i++)

{

	for (int j =0; j<numbers[i].Length; j++)

    {

		Console.Write($"{numbers[i][j]} \t");

	}

	Console.WriteLine();

}
```

### основные понятия массивов

три величины описывают форму массива:

- ранг (rank): количество измерений массива
- длина измерения (dimension length): длина отдельного измерения
- длина массива (array length): количество всех элементов массива

пример:

```c#
int[,] numbers = new int[3, 4];
```

массив `numbers` двухмерный, у него два измерения, ранг равен 2. длина первого измерения равна 3, длина второго равна 4. длина массива, то есть общее число элементов, равна `3 * 4`, это 12.
