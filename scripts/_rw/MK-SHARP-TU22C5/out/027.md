c# является объектно-ориентированным языком: программу можно представить как совокупность объектов, которые хранят состояние и взаимодействуют через операции. описание объекта задаёт класс, объект является экземпляром этого класса.

у класса и экземпляра разные роли. представление о человеке с именем, возрастом и прочими характеристиками есть общий шаблон. этот шаблон и есть класс. конкретные воплощения шаблона различаются: у одного человека одно имя, у другого другое. реально существующий человек, то есть экземпляр, является объектом класса.

классы в курсе уже встречались. тип `string`, представляющий строку, является классом. класс `Console` предоставляет метод `WriteLine()`, который выводит на консоль переданную информацию. дальше разбирается, как объявлять собственные классы.

класс есть тип, определяемый в программе. его объявляют ключевым словом `class`:

```c#


class название_класса

{

	// содержимое класса

}
```

после `class` стоит имя класса, в фигурных скобках располагается тело. в файле `Program.cs` класс `Person`, представляющий человека, объявляется так:

```c#


class Person

{

 

}
```

![классы и объекты в языке программирования c# и .net](/uploads/course-lectures/31efb7e6f5778eca14c377892606f6eba3f9aa8a.png)

начиная с c# 12 пустое объявление класса можно записать без фигурных скобок:

```c#


class Person;
```

такой класс не показывает ни состояния, ни поведения, поэтому дальше в него добавляется функциональность. пустая запись полезна как заготовка типа: имя уже введено, тело можно нарастить позже.

### поля и методы класса

класс хранит данные в полях. поле класса есть переменная, объявленная на уровне класса, а не внутри метода. время жизни поля совпадает со временем жизни экземпляра: поле входит в состояние объекта.

поведение класса задаётся методами.

в класс `Person` добавляются поля и метод:

```c#


class Person 

{

    public string name = "Undefined";	// имя

    public int age;						// возраст



    public void Print()

    {

        Console.WriteLine($"Имя: {name}  Возраст: {age}");

    }

}
```

в `Person` объявлены поле `name` для имени и поле `age` для возраста. в отличие от локальных переменных метода, поля могут иметь модификаторы доступа. модификатор пишется перед полем. чтобы поля были доступны вне `Person`, им указан `public`. член без расширяющего доступ модификатора в классе закрыт: к нему нельзя обратиться из другого типа.

при объявлении полю можно сразу присвоить значение, как полю `name` выше. неинициализированное поле получает значение по умолчанию. для числовых типов это 0. для ссылочных полей значение по умолчанию есть `null`: ссылка ещё ни на какой объект не указывает. инициализатор поля выполняется при создании экземпляра, до тела конструктора.

в `Person` объявлен метод `Print()`. метод класса имеет доступ к полям этого экземпляра. `Print` читает `name` и `age` и выводит их на консоль. чтобы метод был виден вне класса, он тоже объявлен с `public`.

### создание объекта класса

после объявления класса создают его объекты. для создания служат конструкторы. конструктор есть специальный метод: его имя совпадает с именем класса, он вызывается при создании нового объекта и инициализирует экземпляр. возвращаемый тип у конструктора не указывается, потому что результат вызова есть сам новый объект, а не значение, которое конструктор мог бы вернуть отдельно. общий вид вызова:

```c#
new конструктор_класса(параметры_конструктора);
```

сначала идёт оператор `new`, который выделяет память под объект, затем вызывается конструктор.

#### конструктор по умолчанию

если в классе не объявлен ни один конструктор, как в `Person` выше, компилятор создаёт пустой конструктор без параметров. его называют конструктором по умолчанию. как только в классе появится хотя бы один собственный конструктор, этот автоматический конструктор больше не генерируется.

объект класса `Person`:

```c#


Person tom = new Person();  // создание объекта класса Person



// определение класса Person

class Person 

{

    public string name = "Undefined";

    public int age;



    public void Print()

    {

        Console.WriteLine($"Имя: {name}  Возраст: {age}");

    }

}
```

![создание классов в языке программирования c# и .net](/uploads/course-lectures/9b49168dd3ecda4e243700c6eea91f8987bad43b.png)

объект создаётся выражением `new Person()`. после его выполнения в памяти выделен участок, где лежат данные объекта `Person`. класс является ссылочным типом, поэтому сам объект размещается в куче, а переменная `tom` получает ссылку на него. через эту ссылку доступны поля и методы экземпляра. пока ссылка жива, объект достижим. когда достижимых ссылок не остаётся, память может забрать сборщик мусора.

### обращение к функциональности класса

к полям, методам и прочим членам обращаются точечной записью: после выражения, обозначающего объект, ставится точка и имя члена.

```c#


объект.поле_класса

объект.метод_класса(параметры_метода)
```

обращение к полям и методу объекта `Person`:

```c#


Person tom = new Person();  // создание объекта класса Person



// Получаем значение полей в переменные

string personName = tom.name;

int personAge = tom.age;

Console.WriteLine($"Имя: {personName}  Возраст {personAge}");   // Имя: Undefined  Возраст: 0



// устанавливаем новые значения полей

tom.name = "Tom";

tom.age = 37;



// обращаемся к методу Print

tom.Print();    // Имя: Tom  Возраст: 37



class Person 

{

    public string name = "Undefined";

    public int age;



    public void Print()

    {

        Console.WriteLine($"Имя: {name}  Возраст: {age}");

    }

}
```

сначала поля читаются в локальные переменные. `name` ещё хранит инициализатор `"Undefined"`, `age` хранит значение по умолчанию 0. затем полям присваиваются новые значения, и `Print` выводит уже их. присваивание полю меняет состояние того объекта, на который ссылается `tom`, а не переменную `tom` как ссылку.

консольный вывод программы:

```consoletext


Имя: Undefined	Возраст: 0

Имя: Tom	Возраст: 37
```

### добавление класса

обычно классы размещают в отдельных файлах. часто одному классу соответствует один файл. если проект собирается вне visual studio, средствами .net cli, достаточно добавить файл в папку проекта. новый файл `Person.cs`:

```c#


class Person

{

    public string name = "Undefined";

    public void Print()

    {

        Console.WriteLine($"Person {name}");

    }

}
```

в файле объявлен класс `Person` с полем `name` и методом `Print`.

основной файл программы `Program.cs` использует этот класс:

```c#


Person tom = new Person();

tom.name = "Tom";

tom.Print();    // Person Tom
```

![использование классов в проекте в visual studio в языке программирования c#](/uploads/course-lectures/f64b67b8a9dd1df35b9c3de3fc346cfbd48cf2e1.png)

visual studio содержит встроенные шаблоны для добавления класса. чтобы добавить класс, в visual studio нажимают правой кнопкой мыши на название проекта:

![добавление класса в visual studio в c#](/uploads/course-lectures/54804de67e51689a7431771478a81f44dd74d6d5.png)

в контекстном меню выбирают пункт `Add -> New Item...` либо `Add -> Class...`.

в окне добавления элемента в центральной части, среди шаблонов, должен быть выбран пункт `Class`. внизу окна в поле `Name` вводят имя класса. пусть класс называется `Person`:

![добавление нового класса в visual studio в c#](/uploads/course-lectures/79406b4bf2b7392b79e1d5eca5aa2c1b31a8e139.png)

в качестве имени допустимо и `Person`, и `Person.cs`. после нажатия кнопки добавления в проект попадает новый класс. в нём записывают тот же код и используют класс в `Program.cs`.

классы, объявленные в отдельных файлах одной сборки, видны друг другу без дополнительной регистрации: компилятор собирает все файлы проекта в одну единицу компиляции. отсюда обычная структура: тип лежит в собственном файле, а точка входа в `Program.cs` только создаёт объекты и вызывает их методы.
