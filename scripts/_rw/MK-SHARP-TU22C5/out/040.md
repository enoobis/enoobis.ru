иногда один и тот же метод нужен с разным набором параметров, и по фактическим аргументам вызывается определённая версия. эту возможность называют перегрузкой методов (method overloading).

в c# класс может содержать несколько методов с одним именем и разной сигнатурой. сигнатура складывается из следующих частей.

- имя метода

- количество параметров

- типы параметров

- порядок параметров

- модификаторы параметров

имена параметров в сигнатуру не входят. для метода

```c#


public int Sum(int x, int y) 

{ 

	return x + y;

}
```

сигнатура записывается как `Sum(int, int)`.

перегрузка состоит в том, что методы имеют разную сигнатуру, в которой совпадает только имя. методы должны различаться хотя бы по одному из признаков:

- количество параметров

- тип параметров

- порядок параметров

- модификаторы параметров

разрешение перегрузки выполняется во время компиляции. компилятор выбирает единственный наилучший применимый кандидат. это статическая диспетчеризация: реализация фиксируется по тексту вызова. виртуальный вызов, в отличие от перегрузки, выбирает реализацию во время выполнения по типу объекта. если два кандидата одинаково хороши, вызов признаётся неоднозначным и отклоняется.

пусть есть класс

```c#


class Calculator

{

	public void Add(int a, int b)

    {

		int result = a + b;

        Console.WriteLine($"Result is {result}");

	}

    public void Add(int a, int b, int c)

    {

		int result = a + b + c;

        Console.WriteLine($"Result is {result}");

    }

    public int Add(int a, int b, int c, int d)

    {

		int result = a + b + c + d;

        Console.WriteLine($"Result is {result}");

        return result;

	}

	public void Add(double a, double b)

	{

		double result = a + b;

        Console.WriteLine($"Result is {result}");

	}

}
```

здесь четыре версии метода `Add`, четыре перегрузки.

первые три версии различаются количеством параметров. четвёртая совпадает с первой по количеству, но различается типом параметров. достаточно, чтобы хотя бы один параметр имел другой тип, поэтому четвёртая версия тоже является допустимой перегрузкой `Add`.

сигнатуры этих методов:

```c#


Add(int, int)

Add(int, int, int)

Add(int, int, int, int)

Add(double, double)
```

после объявления перегруженные версии вызывают так.

```c#


Calculator calc = new Calculator();

calc.Add(1, 2); // 3

calc.Add(1, 2, 3); // 6

calc.Add(1, 2, 3, 4); // 10

calc.Add(1.4, 2.5); // 3.9
```

консольный вывод:

```consoletext


Result is 3

Result is 6

Result is 10

Result is 3.9
```

перегружаемые методы могут различаться модификаторами параметров.

```c#


void Increment(ref int val)

{

	val++;

	Console.WriteLine(val);

}



void Increment(int val)

{

	val++;

	Console.WriteLine(val);

}
```

обе версии `Increment` имеют один параметр одного типа, но в первой параметр помечен `ref`. модификатор `ref` входит в сигнатуру, поэтому обе версии являются корректными перегрузками. на месте вызова их различает форма аргумента: `Increment(ref x)` связывает вызов с первой версией, `Increment(x)` со второй. первая меняет переменную вызывающего, потому что `ref` передаёт саму переменную. вторая получает копию значения.

различие по возвращаемому типу или по имени параметров не создаёт перегрузку. набор методов

```c#


int Sum(int x, int y)

{

	return x + y;

}

int Sum(int number1, int number2)

{

	return number1 + number2;

}

void Sum(int x, int y)

{

	Console.WriteLine(x + y);

}
```

имеет одну и ту же сигнатуру

```c#


Sum(int, int)
```

этот набор не является корректными перегрузками `Sum` и не компилируется. имена `x` и `number1` для компилятора неразличимы, а смена `int` на `void` в возвращаемом типе сигнатуру не меняет. возвращаемый тип в c# в сигнатуру метода не входит.
