расширение типа добавляет ему методы, свойства и операторы без нового производного типа, без перекомпиляции исходного типа и без правки его исходного текста. исходный код при этом может быть вовсе недоступен. в языке две синтаксические формы: методы расширения и блоки расширений.

метод расширения (extension method) добавляет метод к уже существующему типу без производного класса. форма нужна, когда тип, класс или структуру, изменить нельзя, потому что исходного кода нет, и когда не подходит наследование. последнее относится, в частности, к типам с модификатором `sealed`: от них нельзя объявить наследника.

ниже к типу `string` добавляется метод, которого в самом типе нет:

```c#

string s = "Привет мир";
char c = 'и';
int i = s.CharCount(c);
Console.WriteLine(i); 

public static class StringExtension
{
    public static int CharCount(this string str, char c)
    {
        int counter = 0;
        for (int i = 0; i < str.Length; i++)
        {
            if (str[i] == c)
                counter++;
        }
        return counter;
    }
}
```

метод расширения размещается в статическом классе. здесь это `StringExtension`. сам метод тоже статический. он считает, сколько раз символ встречается в строке.

от обычного статического метода его отличает первый параметр вида `this имя_типа название_параметра`. в примере это `this string str`. тип параметра задаёт тип, к которому метод будет относиться, поэтому здесь стоит `string`.

вызов записывается как вызов метода экземпляра, и первый параметр в точке вызова не передаётся. его подставляет компилятор: `s.CharCount(c)` превращается в вызов `StringExtension.CharCount(s, c)`. остальные аргументы идут в прежнем порядке.

```c#
int i = s.CharCount(c);
```

разрешение метода расширения статическое и происходит во время компиляции. если у самого типа уже есть метод с той же сигнатурой, вызывается он, а метод расширения не рассматривается. поиск идёт в области пространства имён. метод виден там, где его пространство имён подключено директивой `using`. в другом пространстве имён те же строки этот метод не получают, пока `using` не откроет пространство, в котором лежит статический класс.

## блоки расширений

с версии c# 14 новые члены существующего типа можно описывать блоком `extension`. дальше такой блок называется **блоком расширений**.

блок расширения задаёт методы, свойства и операторы. расширений два вида:

- расширения экземпляров: добавляют члены экземпляру типа

- статические расширения: добавляют члены самому типу

синтаксически блок расширений предваряется словом `extension`:

```c#

extension (тип получатель | тип){

    // определения
    // методов
    // свойств 
    // операторов
}
```

в круглых скобках после `extension` указан расширяемый тип. у расширения экземпляра следом за типом стоит получатель: переменная этого типа, через которую тело блока обращается к объекту. в фигурных скобках помещаются методы, свойства и операторы, которые добавляются типу.

блок расширения располагается в статическом классе. этот класс не является обобщённым и не вложен в другой класс.

`extension` не зарезервировано как ключевое слово на все контексты. это контекстное слово, и вне объявления блока то же написание годится как имя переменной:

```c#

var extension = "ext";
Console.WriteLine(extension);
```

### расширения экземпляров

расширение экземпляра применяется к конкретному значению типа. тот же подсчёт символов, что и выше, записывается блоком расширения так:

```c#

static class StringExtension
{
    extension(string str)
    {
        public int CharCount(char c)
        {
            int counter = 0;
            for (int i = 0; i < str.Length; i++)
            {
                if (str[i] == c) counter++;
            }
            return counter;
        }
    }
}
```

блок объявлен для `string`, получатель назван `str`. через `str` тело ссылается на строку, к которой применён метод. внутри блока один метод `CharCount`: он принимает символ и считает его вхождения.

вызов:

```c#

string s = "Привет мир";
char c = 'и';
int i = s.CharCount(c);
Console.WriteLine(i);   // 2
 
static class StringExtension
{
    extension(string str)
    {
        public int CharCount(char c)
        {
            int counter = 0;
            for (int i = 0; i < str.Length; i++)
            {
                if (str[i] == c) counter++;
            }
            return counter;
        }
    }
}
```

в строке `Привет мир` символ `и` встречается два раза, что и печатает программа.

свойство добавляется так же. ниже у строки появляется `IsNumber`: истина, если строку можно прочитать как последовательность десятичных цифр.

```c#

string str1 = "Hello world";
Console.WriteLine(str1.IsNumber);   // false

string str2 = "1234567";
Console.WriteLine(str2.IsNumber);   // true

string str3 = "123456yyy678";
Console.WriteLine(str3.IsNumber);   // false
 
static class StringExtension
{
    extension(string str)
    {
        public bool IsNumber
        {
            get
            {
                for (int i = 0; i < str.Length; i++)
                {
                    if (str[i] < '0' || str[i] > '9') return false;
                }
                return true;
            }
        }
    }
}
```

`IsNumber` проходит по символам. если символ меньше `'0'` или больше `'9'`, свойство возвращает `false`, и строка не считается целым числом. если такой символ не встретился, возвращается `true`.

### статические расширения

статическое расширение относится к типу в целом. отдельный экземпляр ему не нужен. его методы и свойства помечаются модификатором `static`.

```c#

Console.WriteLine(string.Default);

static class StringExtension
{
    extension(string)   // для статических расширений указываем только тип
    {
        public static string Default => "Hello World";
    }
}
```

у `string` объявлено свойство `Default`, которое возвращает фиксированную строку. скобки расширения содержат только тип, без получателя: получатель нужен экземпляру, а у статического члена его нет. обращение идёт через имя типа: `string.Default`.

частый повод для статического расширения: операторы. они и в обычном типе объявляются статическими. ниже строки сравниваются по длине:

```c#

Console.WriteLine("hello" > "ello");  // true
Console.WriteLine("hello" < "ello");  // false

static class StringExtension
{
    extension(string)
    {

        public static bool operator >(string str1, string str2) => str1.Length > str2.Length;
        public static bool operator <(string str1, string str2) => str1.Length < str2.Length;

        public static string Default => "Hello World";
    }
}
```

`>` истинно, когда длина левой строки больше длины правой. у `"hello"` длина 5, у `"ello"` длина 4, поэтому первое сравнение даёт `true`, второе `false`.

сложение массивов тем же способом закрывает отсутствие операции в языке. напрямую выражение не компилируется:

```c#

int[] nums1 = [1, 2, 3, 4];
int[] nums2 = [6, 7, 8];
int[] nums3 = nums1 + nums2;  // ! ошибка
```

у `int[]` оператор `+` не определён, компилятор сообщает об ошибке. статическое расширение задаёт этот оператор:

```c#

int[] nums1 = [1, 2, 3, 4];
int[] nums2 = [6, 7, 8];
int[] nums3 = nums1 + nums2;
foreach(int i in nums3)
{
    Console.Write(i);  
    Console.Write(" "); // пробел - разделитель между числами
}
Console.WriteLine();

static class ArrayExtension
{
    extension(int[])
    {   
        public static int[] operator +(int[] numbers, int[] other)
        {
            // возвращаемый массив, который объединяет оба исходных
            int[] new_numbers = new int[numbers.Length + other.Length];
            int j = 0;  // индекс итогового массива

            // добавляем элементы из первого массива
            for(int i = 0; i < numbers.Length; i++, j++)
            {
                new_numbers[j] = numbers[i];
            }

            // добавляем элементы из второго массива
            for(int i = 0; i < other.Length; i++, j++)
            {
                new_numbers[j] = other[i];
            }
            return new_numbers;
        }
    }
}
```

блок статический, поэтому тип указан без получателя:

```c#
extension(int[])
```

внутри объявлен только оператор сложения, и он статический, как и всякий бинарный оператор пользовательского типа. реализация выделяет новый массив длины, равной сумме длин операндов, копирует в него первый массив, затем второй и возвращает результат. два исходных массива при этом не меняются.

после этого сложение двух массивов компилируется. консольный вывод программы:

```bash
1 2 3 4 6 7 8
```

в одном статическом классе можно держать и расширение экземпляра, и статическое расширение:

```c#

int[] nums1 = [1, 2, 3, 4];
int[] nums2 = [6, 7, 8];
int[] nums3 = nums1 + nums2;

nums3.Print();

static class ArrayExtension
{
    // расширение экземпляра
    extension(int[] numbers)
    {
        public void Print()
        {
            foreach(int i in numbers)
            {
                Console.Write(i);  
                Console.Write(" ");
            }
            Console.WriteLine();
        }
    }
    // статическое расширение
    extension(int[])
    {   
        public static int[] operator +(int[] numbers, int[] other)
        {
            int[] new_numbers = new int[numbers.Length + other.Length];
            int j = 0;
            for(int i = 0; i < numbers.Length; i++, j++)
            {
                new_numbers[j] = numbers[i];
            }
            for(int i = 0; i < other.Length; i++, j++)
            {
                new_numbers[j] = other[i];
            }
            return new_numbers;
        }
    }
}
```

экземплярное расширение добавляет `Print`, статическое по-прежнему задаёт `+`. выражение `nums1 + nums2` строит новый массив, а `nums3.Print()` печатает его элементы через экземплярный метод.
