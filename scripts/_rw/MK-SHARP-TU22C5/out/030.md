наряду с классами структуры дают ещё один способ объявлять собственные типы в c#. многие примитивные типы, в том числе `int` и `double`, сами являются структурами: за именем в языке стоит значимый тип вроде `System.Int32` и `System.Double`.

### определение структуры

структуру объявляют ключевым словом `struct`:

```c#


struct имя_структуры

{

	// элементы структуры

}
```

после `struct` стоит имя, в фигурных скобках располагаются элементы: поля, методы и другие члены.

структура `Person`, представляющая человека:

```c#


struct Person

{

}
```

начиная с c# 12 пустое объявление структуры, без полей, свойств и методов, можно записать без фигурных скобок:

```c#


struct Person;
```

как и класс, структура хранит состояние в полях и задаёт поведение методами. в `Person` добавляются два поля и метод:

```c#


struct Person

{

    public string name;

    public int age;



    public void Print()

    {

        Console.WriteLine($"Имя: {name}  Возраст: {age}");

    }

}
```

поля `name` и `age` хранят имя и возраст, метод `Print` выводит эти данные на консоль.

к полям, методам и прочим членам структуры обращаются точечной записью: после значения структуры ставится точка и имя члена.

```c#


объект.поле_структуры

объект.метод_структуры(параметры_метода)
```

### создание объекта структуры

#### инициализация с помощью конструктора

перед использованием структуру инициализируют. для создания значения, как и у класса, вызывают конструктор через `new`. даже если в тексте структуры нет ни одного конструктора, у неё есть хотя бы один: конструктор по умолчанию, который генерирует компилятор. он не принимает параметров и создаёт значение со значениями полей по умолчанию.

```c#
new название_структуры();
```

объект структуры `Person` через конструктор по умолчанию:

```c#


Person tom = new Person();	// вызов конструктора

// или так 

// Person tom = new();



tom.name = "Tom";	// изменяем значение по умолчанию в поле name



tom.Print();    // Имя: Tom  Возраст: 0



struct Person

{

    public string name;

    public int age;



    public void Print()

    {

        Console.WriteLine($"Имя: {name}  Возраст: {age}");

    }

}
```

создаётся значение `tom`. конструктор по умолчанию записывает в поля значения по умолчанию. для чисел это 0, поэтому `age` равен 0. для строк это `null`, то есть отсутствие ссылки на строку. если поля доступны, а при модификаторе `public` они доступны, их можно изменить после создания. полю `name` присваивается строка `"Tom"`. вызов `Print()` даёт такой консольный вывод:

```consoletext
Имя: Tom  Возраст: 0
```

структура есть значимый тип. переменная `tom` хранит само значение, а не ссылку на него. вызов `new` в этом случае инициализирует локальную переменную, а не выделяет отдельный объект в куче так, как это происходит для класса.

#### непосредственная инициализация полей

если все поля доступны, как поля `Person` с модификатором `public`, структуру можно инициализировать без вызова конструктора. тогда всем полям нужно присвоить значения до того, как поля читают или вызывают методы структуры.

```c#


Person tom;			// не вызываем конструктор

// инициализация полей

tom.name = "Sam";

tom.age = 37;



tom.Print();    // Имя: Sam  Возраст: 37



struct Person

{

    public string name;

    public int age;



    public void Print()

    {

        Console.WriteLine($"Имя: {name}  Возраст: {age}");

    }

}
```

локальная переменная `tom` объявлена без `new`. правила определённого присваивания требуют, чтобы перед чтением значения и перед вызовом `Print` были записаны и `name`, и `age`. пока хотя бы одно поле не записано, значение структуры считается неинициализированным, и компилятор вызов метода не пропустит.

### инициализация полей по умолчанию

начиная с c# 10 поля структуры можно инициализировать прямо в объявлении. до c# 10 такой записи не было:

```c#


Person tom = new Person();

tom.Print();    // Имя:Tom  Возраст: 1



struct Person

{

	// инициализация полей значениями по умолчанию - доступна с C#10

    public string name = "Tom";

    public int age = 1;

    public Person() { }

    public void Print() =>Console.WriteLine($"Имя: {name}  Возраст: {age}");

}
```

даже при таких начальных значениях, чтобы они применились, конструктор нужно объявить явно и вызвать его. неявный конструктор по умолчанию обнуляет память и не выполняет инициализаторы полей. в примере объявлен пустой `Person()`, и именно его вызов запускает инициализаторы: `name` получает `"Tom"`, `age` получает 1. вывод `Print` показывает эти значения, а не нули.

### конструкторы структуры

как и класс, структура может объявлять конструкторы. в `Person` добавляется конструктор:

```c#


Person tom = new();

Person bob = new("Bob");

Person sam = new("Sam", 25);



tom.Print();    // !!!! Имя:   Возраст: 0

bob.Print();    // Имя: Bob  Возраст: 1 

sam.Print();    // Имя: Sam  Возраст: 25



struct Person

{

    public string name;

    public int age;



    public Person(string name = "Tom", int age = 1)

    {

        this.name = name;

        this.age = age;

    }

    public void Print() => Console.WriteLine($"Имя: {name}  Возраст: {age}");

}
```

в структуре объявлен конструктор с двумя параметрами, и для обоих заданы значения по умолчанию. создание первого значения устроено иначе, чем двух остальных:

```c#


Person tom = new();	// по прежнему используется конструктор без параметров по умолчанию

tom.Print();    // !!!! Имя:   Возраст: 0
```

здесь по-прежнему вызывается конструктор по умолчанию без параметров. конструктор с необязательными параметрами не является конструктором без параметров: у него два параметра, просто при вызове их можно опустить. вызов `new()` без аргументов связывается с неявным конструктором, который обнуляет поля. поэтому имя пустое, а возраст равен 0. инициализатор `"Tom"` и значение 1 из списка параметров не применяются. при создании `bob` и `sam` аргументы есть, и вызывается уже объявленный конструктор.

начиная с c# 10 можно объявить собственный конструктор без параметров:

```c#


Person tom = new();



tom.Print();    // Имя: Tom  Возраст: 37



struct Person

{

    public string name;

    public int age;



    public Person()

    {

        name = "Tom";

        age = 37;

    }

    public void Print() => Console.WriteLine($"Имя: {name}  Возраст: {age}");

}
```

теперь `new()` вызывает этот конструктор, и поля получают `"Tom"` и 37. неявное обнуление в этот вызов не подставляется.

до c# 11 в конструкторе структуры требовалось инициализировать все поля. начиная с c# 11 это необязательно: поле, которому в конструкторе ничего не присвоили, получает значение по умолчанию.

если нужны конструкторы с разным числом параметров, их, как у классов, связывают в цепочку:

```c#


Person tom = new();

Person bob = new("Bob");

Person sam = new("Sam", 25);



tom.Print();    // Имя: Tom  Возраст: 1

bob.Print();    // Имя: Bob  Возраст: 1 

sam.Print();    // Имя: Sam  Возраст: 25



struct Person

{

    public string name;

    public int age;



    public Person() : this("Tom")

    { }

    public Person(string name) : this(name, 1)

    { }

    public Person(string name, int age)

    {

        this.name = name;

        this.age = age;

    }

    public void Print() => Console.WriteLine($"Имя: {name}  Возраст: {age}");

}
```

консольный вывод программы:

```bash


Имя: Tom  Возраст: 1

Имя: Bob  Возраст: 1 

Имя: Sam  Возраст: 25
```

первый конструктор вызывает конструктор с одним параметром и передаёт `"Tom"`. тот вызывает конструктор с двумя параметрами и добавляет возраст 1. тело, которое пишет поля, одно. `new()`, `new("Bob")` и `new("Sam", 25)` попадают в разные точки цепочки, но все заканчивают в конструкторе с двумя параметрами.

начиная с c# 12 у структур, как и у классов, бывают первичные конструкторы. параметры добавляются к объявлению типа и используются в его теле:

```c#


var tom = new Person("Tom", 38);

tom.Print();



public struct Person(string name, int age)

{

    public Person(string name) : this(name, 18) { }

    public void Print() => Console.WriteLine($"name: {name}, age: {age}");

}
```

у структуры `Person` первичный конструктор принимает `name` и `age`. для параметра, который читается в теле, компилятор создаёт закрытое поле и хранит в нём значение. поэтому параметры видны в `Print`.

помимо первичного конструктора можно объявить дополнительные, как в примере. дополнительный конструктор обязан вызвать первичный:

```c#
public Person(string name) : this(name, 18) { }
```

### инициализатор структуры

для структуры, как и для класса, допустим инициализатор:

```c#


Person tom = new Person { name = "Tom", age = 22 };



tom.Print();    // Имя: Tom  Возраст: 22



struct Person

{

    public string name;

    public int age;

    public void Print() => Console.WriteLine($"Имя: {name}  Возраст: {age}");

}
```

сначала вызывается конструктор без параметров. если свой конструктор без параметров не объявлен, вызывается конструктор по умолчанию. затем полям присваиваются значения из фигурных скобок. присваивания инициализатора идут после конструктора и заменяют то, что конструктор записал в те же поля.

### копирование структуры с помощью with

если нужно получить копию значения и изменить в копии только часть полей, используют оператор `with`:

```c#


Person tom = new Person { name = "Tom", age = 22 };

Person bob = tom with { name = "Bob" };

bob.Print();    // Имя: Bob  Возраст: 22
```

`bob` получает все значения `tom`, затем в фигурных скобках после `with` перечисляются поля, которые в копии нужно заменить. исходное значение `tom` не меняется: `with` строит новое значение структуры. для значимого типа это покомпонентное копирование с последующими присваиваниями, а не общая ссылка на один объект.
