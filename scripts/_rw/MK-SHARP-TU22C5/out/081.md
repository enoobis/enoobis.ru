наряду с методами в классах и структурах определяют операторы. класс `Counter`:

```c#


class Counter

{

	public int Value { get; set; }

}
```

этот класс представляет счётчик, значение которого хранится в свойстве `Value`.

два объекта класса `Counter`, два счётчика, нужно сравнивать или складывать на основании свойства `Value`, используя стандартные операции сравнения и сложения:

```c#


Counter counter1 = new Counter { Value = 23 };

Counter counter2 = new Counter { Value = 45 };



bool result = counter1 > counter2;

Counter c3 = counter1 + counter2;
```

ни операция сравнения, ни операция сложения для объектов `Counter` пока не доступны. эти операции определены для ряда примитивных типов: числовые значения по умолчанию можно складывать. правило сложения объектов классов и структур компилятор сам не выводит. для этого перегружают нужные операторы.

определение оператора есть определение в классе, для объектов которого оператор вводится, специального метода:

```c#


public static возвращаемый_тип operator оператор(параметры)

{  }
```

этот метод должен иметь модификаторы **public static**, поскольку перегружаемый оператор используется для всех объектов данного класса. к одному экземпляру операция не привязана. далее идёт имя возвращаемого типа. возвращаемый тип есть тот тип, объекты которого операция должна получить. в результате сложения двух объектов `Counter` ожидается новый объект `Counter`. в результате сравнения двух объектов ожидается значение типа `bool`, которое указывает, истинно условное выражение или ложно. в зависимости от задачи возвращаемые типы могут быть любыми.

затем вместо названия метода идёт служебное слово **operator** и сам оператор. дальше в скобках перечисляются параметры. бинарные операторы принимают два параметра, унарные один. в любом случае один из параметров должен представлять тот тип, класс или структуру, в котором определяется оператор.

перегрузка нескольких операторов для класса `Counter`:

```c#


class Counter

{

	public int Value { get; set; }

        

	public static Counter operator +(Counter counter1, Counter counter2)

    {

		return new Counter { Value = counter1.Value + counter2.Value };

	}

	public static bool operator >(Counter counter1, Counter counter2)

	{

		return counter1.Value > counter2.Value;

	}

	public static bool operator <(Counter counter1, Counter counter2)

	{

		return counter1.Value < counter2.Value;

	}

}
```

все определённые операторы бинарные, то есть выполняются над двумя объектами, поэтому у каждой перегрузки по два параметра.

операция сложения должна сложить два объекта класса `Counter`, поэтому оператор принимает два объекта этого класса. в результате сложения нужен новый объект `Counter`, поэтому тот же класс указан как возвращаемый тип. действия оператора сводятся к созданию нового объекта, свойство `Value` которого объединяет значения свойства `Value` обоих параметров:

```c#


public static Counter operator +(Counter counter1, Counter counter2)

{

	return new Counter { Value = counter1.Value + counter2.Value };

}
```

определены и две операции сравнения. если определяется одна из этих операций, нужно определить и вторую: пара `<` и `>` объявляется вместе. операторы сравнения сравнивают значения свойств `Value` и в зависимости от результата возвращают либо `true`, либо `false`.

перегруженные операторы в программе:

```c#


Counter counter1 = new Counter { Value = 23 };

Counter counter2 = new Counter { Value = 45 };

bool result = counter1 > counter2;

Console.WriteLine(result); // false



Counter counter3 = counter1 + counter2;

Console.WriteLine(counter3.Value);  // 23 + 45 = 68
```

определение оператора по сути представляет собой метод, поэтому метод можно перегрузить, то есть создать для него ещё одну версию. в класс `Counter` добавляется ещё один оператор:

```c#


public static int operator +(Counter counter1, int val)

{

	return counter1.Value + val;

}
```

этот метод складывает значение свойства `Value` и некоторое число и возвращает их сумму. применение этого оператора:

```c#


Counter counter1 = new Counter { Value = 23 };

int result = counter1 + 27; // 50

Console.WriteLine(result);
```

определить можно не все операторы. логику задают для следующих операторов:

- унарные операторы `+x`, `-x`, `!x`, `~x`, `++`, `--`, `true`, `false`

- бинарные операторы `+`, `-`, `*`, `/`, `%`

- операции сравнения `==`, `!=`, `<`, `>`, `<=`, `>=`

- поразрядные операторы `&`, `|`, `^`, `<<`, `>>`, `>>>`

- логические операторы `&&`, `||`

операторы `&&` и `||` не объявляются отдельным методом `operator`. они вычисляются для типа, если определены `true`, `false` и соответствующие `&` или `|`. выражение `x && y` компилятор раскрывает через оператор `false` и оператор `&`, выражение `x || y` через оператор `true` и оператор `|`.

кроме того, несколько операторов определяют только парами:

- `==` и `!=`

- `<` и `>`

- `<=` и `>=`

есть и операторы, которые нельзя перегрузить, например операцию равенства `=` или тернарный оператор `?:`, а также ряд других. полный список перегружаемых операторов приведён в [документации msdn](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/operator-overloading#overloadable-operators).

### определение инкремента и декремента

в коде оператора не должны изменяться те объекты, которые передаются в оператор через параметры. для класса `Counter` оператор инкремента можно определить так:

```c#


public static Counter operator ++(Counter counter1)

{

	counter1.Value += 10;

	return counter1;

}
```

оператор унарный и принимает только один параметр, объект того класса, в котором оператор определён. это **неправильное** определение инкремента: оператор не должен менять значения своих параметров. `Counter` есть класс, то есть ссылочный тип. если метод увеличивает `Value` и возвращает тот же экземпляр, временная ссылка постфиксной формы указывает на уже изменённый объект, и различие префикса и постфикса пропадает.

более корректное определение оператора инкремента:

```c#


public static Counter operator ++(Counter counter1)

{

	return new Counter { Value = counter1.Value + 10 };

}
```

возвращается новый объект, который содержит в свойстве `Value` инкрементированное значение. исходный аргумент метод не изменяет. отдельно операторы для префиксного и для постфиксного инкремента (а также декремента) определять не нужно: одна реализация работает в обоих случаях, а форму выбирает компилятор.

```c#


Counter counter1 = new Counter() { Value = 10 };

Counter counter2 = counter1++;

Console.WriteLine(counter1.Value);      // 20

Console.WriteLine(counter2.Value);      // 10



Counter counter3 = ++counter1;

Console.WriteLine(counter1.Value);      // 30

Console.WriteLine(counter3.Value);      // 30
```

при постфиксном инкременте (`counter1++`) компилятор сначала создаёт временную переменную и сохраняет в неё текущий объект. затем текущий объект замещается значением, полученным из функции оператора. результатом операции возвращается значение временной переменной. при префиксном инкременте (`++counter1`) компилятор возвращает новое значение, полученное из функции оператора. шаг в примере равен 10, поэтому числа отличаются от привычного увеличения на единицу, но порядок сохранения старого значения и записи нового тот же.

### определение операций true и false

отдельно определяют операторы **true** и **false**. их объявляют парой. эти операторы нужны, когда объект типа используют в качестве условия. для класса `Counter`:

```c#


class Counter

{

	public int Value { get; set; }

	

	public static bool operator true(Counter counter1)

    {

		return counter1.Value != 0;

    }

	public static bool operator false(Counter counter1)

    {

		return counter1.Value == 0;

    }

}
```

проверка условия:

```c#


Counter counter = new Counter() { Value = 0 };

if (counter)

	Console.WriteLine(true);

else

	Console.WriteLine(false);
```

если нужна операция отрицания, как в `if (!counter)`, для типа определяют и операцию **!**:

```c#


Counter counter = new Counter() { Value = 2 };

if (!counter)

    Console.WriteLine(true);

else

    Console.WriteLine(false);



class Counter

{

    public int Value { get; set; }



    public static bool operator !(Counter counter1)

    {

        return counter1.Value == 0;

    }



    public static bool operator true(Counter counter1)

    {

        return counter1.Value != 0;

    }

    public static bool operator false(Counter counter1)

    {

        return counter1.Value == 0;

    }

}
```

условие в операции отрицания здесь совпадает с условием операции `false`: истина при `Value == 0`. оператор `false` парный к `true` и участвует в логических условиях, оператор `!` задаёт унарное отрицание.
