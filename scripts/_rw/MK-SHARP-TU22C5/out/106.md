**итератор** представляет собой блок кода, который перебирает набор значений оператором **yield**. таким блоком может быть тело метода, тело оператора или аксессор get свойства. компилятор превращает этот блок в конечный автомат: локальные переменные поднимаются в поля сгенерированного класса, а каждое вхождение `yield` становится точкой, в которой исполнение приостанавливается и затем возобновляется.

у итератора две специальные инструкции:

- `yield return`: определяет возвращаемый элемент и запоминает место, с которого выполнение продолжится

- `yield break`: сообщает, что последовательность больше не содержит элементов, и завершает перечислитель

небольшой пример порождает квадраты целых чисел:

```c#


Numbers numbers = new Numbers();

foreach (int n in numbers)

{

    Console.WriteLine(n);

}



class Numbers

{

    public IEnumerator<int> GetEnumerator()

    {

        for (int i = 0; i < 6; i++)

        {

            yield return i * i;

        }

    }

}
```

в классе Numbers метод **GetEnumerator()** и есть итератор. оператор **yield return** отдаёт очередное значение, здесь это квадрат числа, и сохраняет состояние цикла. тело метода при вызове `GetEnumerator` ещё не пробегает последовательность. продвижение происходит внутри `MoveNext`, который цикл foreach вызывает на каждой итерации. очередной `yield return` записывает элемент в `Current`, возвращает из `MoveNext` значение true и оставляет автомат на следующей инструкции. когда цикл `for` заканчивается, `MoveNext` возвращает false.

поэтому объект Numbers перебирается в `foreach` как обычная коллекция. каждый шаг цикла возобновляет итератор ровно с сохранённой позиции, получает один элемент и снова приостанавливает метод. промежуточной коллекции из шести квадратов при этом не строится: значения вычисляются по требованию.

тот же приём позволяет перебирать само число в цикле foreach. для этого `GetEnumerator` определяется как метод расширения типа int, то есть `System.Int32`:

```c#


foreach(var n in 5) Console.WriteLine(n);

foreach (var n in -5) Console.WriteLine(n);



static class Int32Extension

{

    public static IEnumerator<int> GetEnumerator(this int number)

    {

        int k = (number > 0)? number: 0;

        for (int i = number - k; i <= k; i++) yield return i;

    }

}
```

метод возвращает целые точки от границы, вычисленной по знаку аргумента, до другой границы включительно. если number больше нуля, k совпадает с number, цикл начинается с `number - k`, то есть с нуля, и идёт до number. если number не положителен, k равен 0, цикл начинается с самого number и идёт до нуля. консольный вывод показывает обе ветви, для 5 и для -5:

```consoletext


0

1

2

3

4

5

-5

-4

-3

-2

-1

0
```

поиск `GetEnumerator` циклом foreach идёт по образцу и видит метод расширения, поэтому запись `foreach (var n in 5)` корректна. собственного перечислителя у `System.Int32` нет, метод приходит из расширения.

следующий пример применяет `yield` к предметной коллекции. класс Company хранит штат в массиве personnel, элементами которого служат объекты Person:

```c#


class Person

{

    public string Name { get; }

    public Person(string name) =>Name = name;

}

class Company

{

    Person[] personnel;

    public Company(Person[] personnel) => this.personnel = personnel;

    public int Length => personnel.Length;

    public IEnumerator<Person> GetEnumerator()

    {

        for (int i = 0; i < personnel.Length; i++)

        {

            yield return personnel[i];

        }

    }

}
```

метод `GetEnumerator()` является итератором. при переборе объекта Company цикл foreach обращается к оператору `yield return personnel[i]`. в момент этого оператора сохраняется текущее местоположение, включая значение i. когда foreach запрашивает следующий объект, итератор продолжает выполнение с сохранённого места. вход в метод заново, с первой строки, при этом не выполняется. свойство `Length` отдаёт длину массива и к протоколу перебора не относится.

в основной программе перебор выполняет сам цикл foreach, опираясь на эту реализацию:

```c#


var people = new Person[] 

{ 

    new Person("Tom"), 

    new Person("Bob"), 

    new Person("Sam") 

};

var microsoft = new Company(people);



foreach(Person employee in microsoft)

{

    Console.WriteLine(employee.Name);

}
```

массив people из трёх объектов Person передаётся в конструктор Company. цикл печатает Name каждого сотрудника в порядке массива: Tom, Bob, Sam.

перебор массива циклом for внутри итератора необязателен. последовательность может быть собрана из нескольких отдельных операторов `yield return`:

```c#


public IEnumerator<Person> GetEnumerator()

{

    yield return personnel[0];

    yield return personnel[1];

    yield return personnel[2];

}
```

каждый такой оператор тоже сохраняет местоположение. первый вызов `MoveNext` останавливается на первом `yield return` и отдаёт `personnel[0]`, второй возобновляет метод со следующей строки и отдаёт `personnel[1]`, третий отдаёт `personnel[2]`. индексы здесь зафиксированы, поэтому длина массива должна быть не меньше трёх, иначе чтение по индексу завершится `IndexOutOfRangeException`.

сгенерированный автомат реализует перечислитель и `IDisposable`. если в итераторе есть блок `finally`, он выполняется при `Dispose`, в том числе когда `foreach` выходит из цикла досрочно. в примерах этого раздела таких блоков нет, и освобождение ничего не делает.

### именованный итератор

в примерах выше итератором служил метод `GetEnumerator`. оператор `yield` допустим и в любом другом методе, если тип возврата этого метода является интерфейсом `IEnumerable` или его обобщённой формой. такие методы называют **именованными итераторами**. вызов именованного итератора возвращает объект последовательности, а сам обход начинается позже, когда у этого объекта запрашивают перечислитель.

именованный итератор в классе Company ограничивает число возвращаемых сотрудников:

```c#


class Person

{

    public string Name { get; }

    public Person(string name) =>Name = name;

}

class Company

{

    Person[] personnel;

    public Company(Person[] personnel) => this.personnel = personnel;

    public int Length => personnel.Length;

    public IEnumerable<Person> GetPersonnel(int max)

    {

        for (int i = 0; i < max; i++)

        {

            if (i == personnel.Length)

            {

                yield break;

            }

            else

            {

                yield return personnel[i];

            }

        }

    }

}
```

метод `GetPersonnel` имеет сигнатуру с результатом `IEnumerable<Person>` и принимает количество выводимых объектов max. во время выполнения max может оказаться больше длины массива personnel. обращение к `personnel[i]` за границей массива выбросило бы исключение, поэтому при `i == personnel.Length` выполняется оператор **yield break**. он прекращает работу итератора: текущий перечислитель завершается, и следующий `MoveNext` возвращает false. пока i меньше и max, и длины массива, оператор `yield return` отдаёт очередного сотрудника.

применение итератора:

```c#


var people = new Person[]

{

    new Person("Tom"), 

    new Person("Bob"),

    new Person("Sam")

};

var microsoft = new Company(people);



foreach(Person employee in microsoft.GetPersonnel(5))

{

    Console.WriteLine(employee.Name);

}
```

вызов `microsoft.GetPersonnel(5)` возвращает последовательность не более чем из пяти объектов Person. сотрудников в массиве три, поэтому после трёх операций `yield return` условие `i == personnel.Length` запускает `yield break`. цикл печатает Tom, Bob и Sam и на четвёртый элемент не выходит. если вызвать `GetPersonnel` с max меньше длины, цикл `for` закончится сам, без `yield break`, и вернёт ровно max первых элементов. каждый вызов метода создаёт независимый объект последовательности, так что два цикла по одному и тому же результату или два отдельных вызова не делят между собой позицию обхода.
