помимо примитивных типов в c# есть тип `enum`, перечисление. перечисление задаёт набор логически связанных именованных констант и само является отдельным значимым типом: переменная хранит одно из этих значений, а не произвольное число.

объявление строится ключевым словом `enum`:

```c#


enum название_перечисления

{

	// значения перечисления

	значение1,

	значение2,

	.......

	значениеN

}
```

после `enum` стоит имя типа, затем в фигурных скобках через запятую перечисляются константы.

простейшее перечисление:

```c#


enum DayTime

{

    Morning,

    Afternoon,

    Evening,

    Night

}
```

тип `DayTime` имеет четыре константы: `Morning`, `Afternoon`, `Evening` и `Night`.

перечисление вводит новый тип. им, как и любым другим типом, объявляют переменные, константы и параметры методов. значением такой переменной, константы или параметра может быть только константа этого перечисления:

```c#
const DayTime dayTime = DayTime.Morning;
```

дальше эти переменные, константы и параметры используются наравне с прочими значениями:

```c#


DayTime dayTime = DayTime.Morning;



if(dayTime == DayTime.Morning)  

    Console.WriteLine("Доброе утро");

else

    Console.WriteLine("Привет");



enum DayTime

{

    Morning,

    Afternoon,

    Evening,

    Night

}
```

сравнение `dayTime == DayTime.Morning` проверяет, какое именно именованное значение хранится в переменной. имена констант принадлежат типу: записать `Morning` без квалификации `DayTime` в этом контексте нельзя.

### хранение состояния

переменная перечисления часто хранит состояние, от которого зависит дальнейшее действие.

```c#


DayTime now = DayTime.Evening;



PrintMessage(now);					 // Добрый вечер

PrintMessage(DayTime.Afternoon);	// Добрый день

PrintMessage(DayTime.Night);		// Доброй ночи



void PrintMessage(DayTime dayTime)

{

    switch (dayTime)

    {

        case DayTime.Morning:

            Console.WriteLine("Доброе утро");

            break;

        case DayTime.Afternoon:

            Console.WriteLine("Добрый день");

            break;

        case DayTime.Evening:

            Console.WriteLine("Добрый вечер");

            break;

        case DayTime.Night:

            Console.WriteLine("Доброй ночи");

            break;

    }

}

enum DayTime

{

    Morning,

    Afternoon,

    Evening,

    Night

}
```

метод `PrintMessage` принимает значение типа `DayTime` и по нему выбирает приветствие. каждая константа соответствует своей ветви `switch`. дискриминант имеет тип перечисления, поэтому ветви сравниваются не с произвольными числами, а с константами того же типа.

другой пример:

```c#


DoOperation(10, 5, Operation.Add);          // 15

DoOperation(10, 5, Operation.Subtract);     // 5

DoOperation(10, 5, Operation.Multiply);     // 50

DoOperation(10, 5, Operation.Divide);       // 2



void DoOperation(double x, double y, Operation op)

{

    double result = op switch

    {

        Operation.Add => x + y,

        Operation.Subtract => x - y,

        Operation.Multiply => x * y,

        Operation.Divide => x / y

    };

    Console.WriteLine(result);

}

enum Operation

{

    Add,

    Subtract,

    Multiply,

    Divide

}
```

перечисление `Operation` именует арифметические операции. каждая операция представлена отдельной константой. метод `DoOperation` принимает два числа и константу операции, а выражение `switch` по этой константе вычисляет результат. добавление новой константы в перечисление сделает выражение неполным, и код перестанет компилироваться, пока для новой операции не появится ветвь. в этом отличие перечисления от голого `int`: набор допустимых значений виден в типе.

### тип и значения констант перечисления

у констант перечисления есть базовый целочисленный тип. он указывается после имени перечисления через двоеточие:

```c#


enum Time : byte

{

    Morning,

    Afternoon,

    Evening,

    Night

}
```

базовый тип обязан быть целочисленным: `byte`, `sbyte`, `short`, `ushort`, `int`, `uint`, `long` или `ulong`. если тип не указан, используется `int`. выбор базового типа задаёт диапазон и размер значения. `byte` занимает один байт и достаточен для небольшого набора констант. сам по себе перечисление остаётся отдельным типом: значение `Time` не является `byte` до явного приведения.

от базового типа зависит, какие числа можно сопоставить константам. по умолчанию каждой константе присваивается целое число: первая получает 0, вторая 1 и далее по порядку. для `DayTime` выше:

```c#


DayTime now = DayTime.Morning;



Console.WriteLine((int) now);  // 0

Console.WriteLine((int) DayTime.Night);  // 3



enum DayTime

{

    Morning,

    Afternoon,

    Evening,

    Night

}
```

целочисленное значение константы получают явным приведением:

```c#
(int) DayTime.Night	// 3
```

`DayTime.Night` стоит в списке четвёртым, поэтому его код равен 3, если нумерация начата с нуля у `Morning`.

хотя каждой константе сопоставлено число, число само по себе константе перечисления не присваивается:

```c#


DayTime now = 2;	// ! Ошибка
```

присваивание литерала 2 отвергается компилятором: типы различны, и неявного преобразования из произвольного целого в перечисление нет. исключение спецификации одно: константа 0 неявно преобразуется к любому перечислению, поэтому присваивание нуля компилируется. любое другое число требует явного приведения, например `(DayTime)2`, и тогда в переменную попадает значение с этим кодом, даже если среди констант такого имени нет.

значения можно задать явно, начав с первой константы:

```c#


enum DayTime

{

    Morning = 3,	// каждый следующий элемент по умолчанию увеличивается на единицу

    Afternoon,		// этот элемент равен 4

    Evening,		// 5

    Night			// 6

}
```

если указано значение только у `Morning`, каждая следующая константа получает число на единицу больше: `Afternoon` равно 4, `Evening` равно 5, `Night` равно 6.

можно задать число у каждой константы:

```c#


enum DayTime

{

    Morning = 2,

    Afternoon = 4,

    Evening = 8,

    Night = 16

}
```

константы одного перечисления могут совпадать по числу. одной константе можно присвоить значение другой:

```c#


enum DayTime

{

    Morning = 1,

    Afternoon = Morning,

    Evening = 2,

    Night = 2

}
```

здесь `Afternoon` равен `Morning`, то есть 1, а `Evening` и `Night` оба равны 2. с точки зрения базового целого это одно и то же значение, поэтому различать такие константы сравнением уже нельзя: сравниваются коды, а не позиции в объявлении.
