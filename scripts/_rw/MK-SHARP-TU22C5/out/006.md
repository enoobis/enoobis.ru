литералы представляют неизменяемые значения (иногда их ещё называют константами). литералы можно передавать переменным в качестве значения. литерал отличается от константы `const`: литерал является записью значения в исходном тексте, а `const` является именем, связанным с таким значением. литералы бывают логическими, целочисленными, вещественными, символьными и строковыми. отдельный литерал представляет ключевое слово `null`.

### логические литералы

есть две логических константы: **true** (истина) и **false** (ложь):

```c#


Console.WriteLine(true);

Console.WriteLine(false);
```

тип этих литералов выводится как `bool`. других логических литералов в языке нет: истина и ложь не записываются числами 1 и 0.

### целочисленные литералы

целочисленные литералы представляют положительные и отрицательные целые числа, например 1, 2, 3, 4, -7, -109. целочисленные литералы могут быть выражены в десятичной, шестнадцатеричной и двоичной форме. основание меняет только запись в исходном тексте. значение, которое получает переменная, от системы счисления записи не зависит.

с целыми числами в десятичной форме всё должно быть понятно, так как они используются в повседневной жизни:

```c#


Console.WriteLine(-11);

Console.WriteLine(5);

Console.WriteLine(505);
```

числа в двоичной форме предваряются символами 0b, после которых идёт набор из нулей и единиц:

```c#


Console.WriteLine(0b11);        // 3

Console.WriteLine(0b1011);      // 11

Console.WriteLine(0b100001);    // 33
```

для записи числа в шестнадцатеричной форме применяются символы 0x, после которых идёт набор символов от 0 до 9 и от a до f, которые представляют число:

```c#


Console.WriteLine(0x0A);    // 10

Console.WriteLine(0xFF);    // 255

Console.WriteLine(0xA1);    // 161
```

префикс `0b` и префикс `0x` являются частью лексики литерала. регистр букв a-f и самого префикса для значения не существенен: `0xFF` и `0xff` обозначают одно и то же число.

### вещественные литералы

вещественные литералы представляют дробные числа. этот тип литералов имеет две формы. первая форма: вещественные числа с фиксированной запятой, при которой дробная часть отделяется от целой части точкой. например:

```c#


3.14

100.001

-0.38
```

вещественные литералы могут определяться и в экспоненциальной форме `MEp`, где `M` обозначает мантиссу, `E` обозначает экспоненту, которая фактически означает "*10^" (умножить на десять в степени), а `p` обозначает порядок. например:

```c#


Console.WriteLine(3.2e3);	// по сути равно 3.2 * 10<sup>3</sup> = 3200

Console.WriteLine(1.2E-1);	// равно 1.2 * 10<sup>-1</sup> = 0.12
```

по умолчанию вещественный литерал имеет тип `double`. суффикс, который выбирает другой вещественный тип, рассматривается вместе с системой типов.

### символьные литералы

символьные литералы представляют одиночные символы. символы заключаются в одинарные кавычки. символьные литералы бывают нескольких видов. прежде всего это обычные символы:

```c#


'2'

'A'

'T'
```

их можно вывести на консоль с помощью `Console.WriteLine`:

```c#


Console.WriteLine('2');

Console.WriteLine('A');

Console.WriteLine('T');
```

специальную группу представляют **управляющие последовательности**. управляющая последовательность представляет символ, перед которым ставится слеш. данная последовательность интерпретируется определённым образом. наиболее часто используемые последовательности:

- `'\n'` - перевод строки

- `'\t'` - табуляция

- `'\\'` - слеш

если компилятор встретит в тексте последовательность \t, он будет воспринимать эту последовательность не как слеш и букву t, а как табуляцию, то есть длинный отступ. распознавание происходит на лексическом уровне: в значение литерала попадает один символ, а не два знака исходного текста.

символы могут определяться в виде шестнадцатеричных кодов, также заключённых в одинарные кавычки.

ещё один способ определения символов представляет использование шестнадцатеричных кодов ascii. для этого в одинарных кавычках указываются символы '\x', после которых идёт шестнадцатеричный код символа из таблицы ascii. коды символов из таблицы ascii можно посмотреть [здесь](http://www.asciitable.com/).

например, литерал '\x78' представляет символ "x":

```c#


Console.WriteLine('\x78');    // x

Console.WriteLine('\x5A');    // Z
```

последний способ определения символьных литералов представляет применение кодов из таблицы символов [unicode](https://unicode-table.com/ru/). для этого в одинарных кавычках указываются символы '\u', после которых идёт шестнадцатеричный код unicode. например, код `'\u0411'` представляет кириллический символ `'Б'`:

```c#


Console.WriteLine('\u0420');    // Р

Console.WriteLine('\u0421');    // С
```

тип символьного литерала, `char`, хранит кодовую единицу utf-16. для символов базовой многоязычной плоскости один литерал совпадает с одним юникодным скаляром. escape `\u` задаёт эту кодовую единицу напрямую, минуя ввод самого символа с клавиатуры.

### строковые литералы

строковые литералы представляют строки. строки заключаются в двойные кавычки:

```c#


Console.WriteLine("hello");

Console.WriteLine("фыва");

Console.WriteLine("hello word");
```

если внутри строки необходимо вывести двойную кавычку, такая внутренняя кавычка предваряется обратным слешем:

```c#


Console.WriteLine("Компания \"Рога и копыта\"");
```

в строках можно использовать управляющие последовательности. например, последовательность '\n' осуществляет перевод на новую строку:

```c#


Console.WriteLine("Привет \nмир");
```

при выводе на консоль слово "мир" будет перенесено на новую строку:

```consoletext


Привет

мир
```

строковый литерал имеет тип `string` и ссылается на неизменяемую последовательность символов. управляющие последовательности внутри него обрабатываются так же, как в символьном литерале, но результат является строкой, а не одним `char`.

### null

**null** представляет ссылку, которая не указывает ни на какой объект. то есть по сути отсутствие значения. у `null` нет отдельного объекта в куче: это особое ссылочное значение, которое можно присвоить переменной ссылочного типа и которое нельзя разыменовать как экземпляр.
