классы представляют ссылочные типы, и это ограничивает копирование. присваивание копирует ссылку. сам объект при этом остаётся прежним.

```c#


class Person

{

    public string Name { get; set; }

    public int Age { get; set; }

    public Person(string name, int age)

    {

        Name = name;

        Age = age;

    }

}
```

один объект `Person` и попытка скопировать его данные в другой объект `Person` присваиванием:

```c#


var tom = new Person("Tom", 23);

var bob = tom;

bob.Name = "Bob";

Console.WriteLine(tom.Name); // Bob
```

переменные `tom` и `bob` указывают на один и тот же объект в памяти, поэтому изменение свойств через `bob` затрагивает и `tom`.

чтобы `bob` указывала на новый объект, но хранила значения из `tom`, применяют клонирование через интерфейс **ICloneable**:

```c#


public interface ICloneable

{

    object Clone();

}
```

### поверхностное копирование

реализация интерфейса в классе `Person`:

```c#


class Person : ICloneable

{

    public string Name { get; set; }

    public int Age { get; set; }

    public Person(string name, int age)

    {

        Name = name;

        Age = age;

    }

    public object Clone()

    {

        return new Person(Name, Age);

    }

}
```

использование:

```c#


var tom = new Person("Tom", 23);

var bob = (Person)tom.Clone();

bob.Name = "Bob";

Console.WriteLine(tom.Name); // Tom
```

`Clone` создаёт новый объект, поэтому изменения свойств переменной `bob` не сказываются на свойствах переменной `tom`. результат `ICloneable.Clone` имеет тип `object`, и перед использованием копию приводят к `Person`: необобщённый контракт не сохраняет статический тип клона.

код копирования сокращает метод **MemberwiseClone()**, объявленный в `object` как защищённый. он возвращает копию объекта:

```c#


class Person : ICloneable

{

    public string Name { get; set; }

    public int Age { get; set; }

    public Person(string name, int age)

    {

        Name = name;

        Age = age;

    }

    public object Clone()

    {

        return MemberwiseClone();

    }

}
```

этот метод реализует **поверхностное (неглубокое) копирование**. поля значимых типов копируются по значению, поля ссылочных типов копируются как ссылки. такого копирования может быть недостаточно. пусть класс `Person` содержит ссылку на объект класса `Company`:

```c#


class Person : ICloneable

{

    public string Name { get; set; }

    public int Age { get; set; }

    public Company Work { get; set; }

    public Person(string name, int age, Company company)

    {

        Name = name;

        Age = age;

        Work = company;

    }

    public object Clone() => MemberwiseClone();

}

class Company

{

    public string Name { get; set; }

    public Company(string name) => Name = name;

}
```

при копировании новая копия указывает на тот же объект `Company`:

```c#


var tom = new Person("Tom", 23, new Company("Microsoft"));

var bob = (Person)tom.Clone();

bob.Work.Name = "Google";

Console.WriteLine(tom.Work.Name); // Google - а должно быть Microsoft
```

### глубокое копирование

поверхностное копирование работает для свойств примитивных типов и не работает для сложных объектов. для них применяют **глубокое копирование**:

```c#


class Person : ICloneable

{

    public string Name { get; set; }

    public int Age { get; set; }

    public Company Work { get; set; }

    public Person(string name, int age, Company company)

    {

        Name = name;

        Age = age;

        Work = company;

    }

    public object Clone() => new Person(Name, Age, new Company(Work.Name));

}

class Company

{

    public string Name { get; set; }

    public Company(string name) => Name = name;

}
```

`Clone` создаёт и новый `Person`, и новый `Company`, копируя имя компании. после этого `Work` у копии и у оригинала ссылаются на разные объекты. если бы у `Company` были собственные изменяемые ссылочные поля, их пришлось бы копировать отдельно: глубокая копия обходит весь граф объектов, который должен стать независимым.
