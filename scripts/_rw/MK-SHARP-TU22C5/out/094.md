паттерн свойств (property pattern) сравнивает значение со значениями отдельных свойств объекта. для дальнейших примеров достаточно такого класса:

```c#


class Person

{

    public string Name { get; set; } = "";        // имя пользователя

    public string Status { get; set; } = "";     // статус пользователя

    public string Language { get; set; } = "";   // язык пользователя

}
```

класс `Person` хранит три строки: `Name`, `Status` и `Language`. сопоставление ниже смотрит на эти свойства и выбирает текст приветствия.

```c#


Person tom = new Person { Language = "english", Status = "user", Name = "Tom" };

Person pierre = new Person { Language = "french", Status = "user", Name = "Pierre" };



SayHello(tom);		// Hello

SayHello(pierre);	// Salut



void SayHello(Person person)

{

    if(person is Person { Language: "french" })

    {

        Console.WriteLine("Salut");

    }

    else

    {

        Console.WriteLine("Hello");

    }

}
```

метод `SayHello` принимает `Person` и сопоставляет аргумент с шаблоном `Person { Language: "french" }`. шаблон истинен, когда динамический тип совместим с `Person` и свойство `Language` равно `"french"`. для `pierre` печатается `Salut`, для `tom` ветвь `else` печатает `Hello`.

в одном шаблоне можно потребовать несколько свойств сразу. к языку добавляется проверка `Status`:

```c#


Person tom = new Person { Language = "english", Status = "user", Name = "Tom" };

Person pierre = new Person { Language = "french", Status = "user", Name = "Pierre" };

Person admin = new Person { Language = "english", Status = "admin", Name = "Admin" };



SayHello(admin);    // Hello, admin

SayHello(tom);      // Hello

SayHello(pierre);   // Salut



void SayHello(Person person)

{

    if(person is Person { Language: "english", Status: "admin" })

    {

        Console.WriteLine("Hello, admin");

    }

    else if (person is Person { Language: "french"})

    {

        Console.WriteLine("Salut");

    }

    else

    {

        Console.WriteLine("Hello");

    }

}
```

первая ветвь истинна, только если `person` является `Person`, `Language` равно `"english"` и `Status` равно `"admin"`. свойства, не перечисленные в шаблоне, на результат не влияют: имя администратора может быть любым. вторая ветвь проверяет одно свойство `Language` со значением `"french"`. остальные объекты попадают в последнюю ветвь и получают `Hello`.

тот же шаблон записывается ветвями выражения `switch`. выражение возвращает значение первой совпавшей ветви:

```c#


string GetMessage(Person? p) => p switch

{

    { Language: "english" } => "Hello!",

    { Language: "german", Status: "admin" } => "Hallo, admin!",

    { Language: "french" } => "Salut!",

    { } => "undefined",

    null => "null"       // если Person p = null

};
```

внутри фигурных скобок свойство и требуемое значение разделяются двоеточием: `{ свойство: значение }`. значение свойства объекта сравнивается с константой в шаблоне. несколько пар перечисляются через запятую, `{ Language: "german", Status: "admin" }`, и объект должен удовлетворить каждой из них. пустые скобки `{}` условий на свойства не накладывают.

ветви проверяются по порядку, выполняется первая совпавшая. если у объекта `Person` свойство `Language` равно `"english"`, результат равен `"Hello!"`. если одновременно `Language` равно `"german"` и `Status` равно `"admin"`, результат равен `"Hallo, admin!"`. объект с английским языком до второй ветви не доходит, даже когда его статус равен `"admin"`: его уже приняла первая ветвь. если `Language` равно `"french"`, результат равен `"Salut!"`.

если объект не совпал с предыдущими ветвями, он сопоставляется с пустыми скобками `{}`, и результат равен `"undefined"`. пустой шаблон свойства истинен для любого ненулевого значения. сюда попадает и объект, у которого нужные свойства не заданы или равны `null`: константа предыдущих ветвей с `null` не совпадает, и выполнение доходит до `{}`.

последняя ветвь проверяет саму ссылку на `null` и возвращает `"null"`. она стоит после `{}`, потому что пустой шаблон свойства значение `null` не принимает.

применение выражения:

```c#


Person pierre = new Person { Language = "french", Status = "user", Name = "Pierre" };

string message = GetMessage(pierre);

Console.WriteLine(message);     // Salut!



Person tomas = new Person { Language = "german", Status = "admin", Name = "Tomas" };

Console.WriteLine(GetMessage(tomas));     // Hallo, admin!



Person pablo = new Person { Language = "spanish", Status = "user", Name = "Pablo" };

Console.WriteLine(GetMessage(pablo));     // undefined



Console.WriteLine(GetMessage(null));     // null
```

в шаблоне свойства можно связать значение свойства с переменной и подставить её в результат ветви:

```c#


string GetMessage(Person? p) => p switch

{

	{ Language: "german", Status: "admin" } => "Hallo, admin!",

	{ Language: "french", Name: var name } => $"Salut, {name}!",

	{ Language: var lang} => $"Unknown language: {lang}",

	null => "null"

};
```

подшаблон `Name: var name` всегда совпадает и передаёт значение свойства `Name` в переменную `name`. эта переменная затем входит в интерполированную строку результата, `$"Salut, {name}!"`. подшаблон `Language: var lang` так же сохраняет фактический язык, когда ни одна более конкретная ветвь не совпала. константный подшаблон требует равенства, шаблон `var` только связывает значение.

применение:

```c#


Person pierre = new Person { Language = "french", Status = "user", Name = "Pierre" };

string message = GetMessage(pierre);

Console.WriteLine(message);             // Salut, Pierre!



Person tomas = new Person { Language = "german", Status = "admin", Name = "Tomas" };

Console.WriteLine(GetMessage(tomas));     // Hallo, admin!



Person pablo = new Person { Language = "spanish", Status = "user", Name = "Pablo" };

Console.WriteLine(GetMessage(pablo));     // Unknown language: spanish



Person? bob = null;

Console.WriteLine(GetMessage(bob));         // null
```

начиная с c# 10 сопоставление допускает расширенный доступ к свойству вложенного объекта, без отдельной пары скобок на каждый уровень. классы примера:

```c#


class Employee

{

    public string Name { get;}

    public Company Company { get; set; }

    public Employee(string name, Company company)

    {

        Name = name;

        Company = company;

    }



}

class Company

{

    public string Title { get;}

    public Company(string title) => Title = title;

}
```

класс `Company` хранит название в свойстве `Title`. класс `Employee` хранит сотрудника и в свойстве `Company` ссылку на компанию. шаблон свойства спускается во вложенный объект:

```c#


var microsoft = new Company("Microsoft");

var google = new Company("Google");

var tom = new Employee("Tom", microsoft);

var bob = new Employee("Bob", google);



PrintCompany(tom);    // 

PrintCompany(bob);    // 



void PrintCompany(Employee employee)

{

    if (employee is Employee { Company:{Title: "Microsoft" } })

    {

        Console.WriteLine($"{employee.Name} works in Microsoft");

    }

    else

    {

        Console.WriteLine($"{employee.Name} works someware");

    }

}
```

в методе `PrintCompany` объект `employee` сопоставляется с шаблоном `Employee { Company: { Title: "Microsoft" } }`. для совпадения значение должно быть `Employee`, а название компании через свойство `Company` должно быть равно `"Microsoft"`. если ссылка `Company` равна `null`, вложенный шаблон не совпадает: чтение `Title` у пустой ссылки шаблон не выполняет.

тот же спуск начиная с c# 10 записывается расширенным шаблоном свойства, где члены соединяются точкой:

```c#


void PrintCompany(Employee employee)

{

    if (employee is Employee { Company.Title: "Microsoft" })

    {

        Console.WriteLine($"{employee.Name} works in Microsoft");

    }

    else

    {

        Console.WriteLine($"{employee.Name} works someware");

    }

}
```

запись `Company.Title: "Microsoft"` обозначает свойство `Title` вложенного объекта `Company`. обе формы отделяют сотрудника с этим названием компании от остальных, для которых выполняется ветвь `else`.
