обычно система сама генерирует исключения в определённых ситуациях, например при делении числа на ноль. язык c# позволяет генерировать исключения и вручную, оператором **throw**. этим оператором исключение создаётся и вызывается в процессе выполнения.

в программе выполняется ввод имени пользователя. если длина имени меньше 2 символов, должно возникнуть исключение:

```c#


try

{

    Console.Write("Введите имя: ");

    string? name = Console.ReadLine();

    if (name== null || name.Length < 2)

    {

        throw new Exception("Длина имени меньше 2 символов");

    }

    else

    {

        Console.WriteLine($"Ваше имя: {name}");

    }

}

catch (Exception e)

{

    Console.WriteLine($"Ошибка: {e.Message}");

}
```

после оператора **throw** указывается объект исключения. через его конструктор передаётся сообщение об ошибке. вместо типа `Exception` используется и объект любого другого типа исключений: в c# оператор `throw` принимает только объект класса `Exception` или производного от него класса. произвольный объект, как в c++, этим оператором не передаётся.

затем в блоке `catch` сгенерированное исключение обрабатывается. объект исключения создаётся в управляемой куче, и дальше среда ищет обработчик так же, как для исключения, порождённого самой средой выполнения.

тем же способом исключения генерируются в любом месте программы. существует и другая форма оператора `throw`, когда после него объект исключения не указывается. в таком виде оператор `throw` используется только в блоке `catch`:

```c#


try

{

    try

    {

        Console.Write("Введите имя: ");

        string? name = Console.ReadLine();

        if (name == null || name.Length < 2)

        {

            throw new Exception("Длина имени меньше 2 символов");

        }

        else

        {

            Console.WriteLine($"Ваше имя: {name}");

        }

    }

    catch (Exception e)

    {

        Console.WriteLine($"Ошибка: {e.Message}");

        throw;

    }

}

catch (Exception ex)

{

    Console.WriteLine(ex.Message);

}
```

при вводе имени длиной меньше 2 символов возникает исключение, и его обрабатывает внутренний блок `catch`. поскольку в этом блоке используется оператор `throw`, исключение передаётся дальше внешнему блоку `catch`. внешний блок получает то же самое исключение и выводит то же самое сообщение на консоль.

форма `throw` без выражения отличается от повторной генерации `throw e`. голый `throw` пробрасывает текущее исключение и сохраняет исходную трассировку стека, то есть место, где исключение было создано. запись `throw e` создаёт новую точку генерации и подменяет стек местом повторного броска. во внутреннем блоке примера записан именно голый `throw`, поэтому внешний обработчик видит исходное исключение, а не новое.
