класс `Queue<T>` представляет очередь, которая работает по алгоритму fifo (first in, first out): первый вошёл, первый вышел. в .net очередь хранится кольцевым буфером на массиве. постановка пишет в хвост, извлечение читает голову. обе операции занимают в среднем постоянное время, пока буфер не приходится расширять.

### создание очереди

для создания очереди применяется один из трёх конструкторов. пустая очередь:

```c#


Queue<string> people = new Queue<string>();
```

при создании пустой очереди можно указать ёмкость:

```c#


Queue<string> people = new Queue<string>(16);
```

ёмкость резервирует буфер под указанное число элементов и не означает, что они уже стоят в очереди. третий конструктор инициализирует очередь элементами другой коллекции или массива. порядок перечисления источника становится порядком очереди: первый перечисленный элемент оказывается в голове.

```c#


var employees = new List<string> { "Tom", "Sam", "Bob" };

Queue<string> people = new Queue<string>(employees);

foreach (var person in people) Console.WriteLine(person);



Console.WriteLine(people.Count); // 3
```

для перебора очереди применяется цикл `foreach`. обход идёт от головы к хвосту и элементы не удаляет. число элементов даёт свойство `Count`. в примере источник содержит `"Tom"`, `"Sam"`, `"Bob"`, в том же порядке они печатаются, а `Count` равен 3.

### методы `Queue<T>`

у класса выделяются следующие методы:

- `void Clear()`: очищает очередь

- `bool Contains(T item)`: возвращает `true`, если элемент `item` имеется в очереди

- `T Dequeue()`: извлекает и возвращает первый элемент очереди, то есть голову

- `void Enqueue(T item)`: добавляет элемент в конец очереди, то есть в хвост

- `T Peek()`: возвращает первый элемент из начала очереди без его удаления

применение очереди:

```c#


var people = new Queue<string>();



// добавляем элементы

people.Enqueue("Tom");  // people = { Tom }

people.Enqueue("Bob");  // people = { Tom, Bob }

people.Enqueue("Sam");  // people = { Tom, Bob, Sam }



// получаем элемент из самого начала очереди 

var firstPerson = people.Peek();

Console.WriteLine(firstPerson); // Tom



// удаляем элементы

var person1 = people.Dequeue();  // people = { Bob, Sam  }

Console.WriteLine(person1); // Tom

var person2 = people.Dequeue();  // people = { Sam  }

Console.WriteLine(person2); // Bob

var person3 = people.Dequeue();  // people = {  }

Console.WriteLine(person3); // Sam
```

`Enqueue` трижды добавляет элементы в хвост. голова при этом остаётся `"Tom"`. `Peek` читает голову, состав очереди не меняется. каждый `Dequeue` снимает текущую голову: сначала `"Tom"`, затем `"Bob"`, затем `"Sam"`. после третьего извлечения очередь пуста.

если `Peek` или `Dequeue` вызываются у пустой очереди, программа завершает вызов исключением. перед получением элемента проверяют число элементов:

```c#


if(people.Count > 0)

{

    var person = people.Peek();

    people.Dequeue();

}
```

ту же пару действий без исключения на пустой очереди дают два метода:

- `bool TryDequeue(out T result)`: передаёт в переменную `result` первый элемент очереди и удаляет его из очереди. возвращает `true`, если очередь не пуста и элемент успешно получен

- `bool TryPeek(out T result)`: передаёт в переменную `result` первый элемент очереди без его извлечения. возвращает `true`, если очередь не пуста и элемент успешно получен

применение методов:

```c#


var people = new Queue<string>();



// добавляем элементы

people.Enqueue("Tom");  // people = { Tom }



// удаляем элементы

var success1 = people.TryDequeue(out var person1);  // success1 = true

if (success1) Console.WriteLine(person1); // Tom



var success2 = people.TryPeek(out var person2);  // success2 = false

if (success2) Console.WriteLine(person2);
```

после одного `Enqueue` вызов `TryDequeue` успешен и выводит `"Tom"`. очередь после этого пуста, поэтому `TryPeek` возвращает `false`, и ветвь вывода не выполняется.

очередь прямо соответствует ожиданию обслуживания, например очереди пациентов на приём к врачу. врач забирает пациентов по одному, пока очередь не опустеет:

```c#


var patients = new Queue<Person>();

patients.Enqueue(new Person("Tom"));

patients.Enqueue(new Person("Bob"));

patients.Enqueue(new Person("Sam"));



var practitioner = new Doctor();

practitioner.TakePatients(patients);



class Person

{

    public string Name { get; }

    public Person(string name) => Name = name;

}



class Doctor

{

    public void TakePatients(Queue<Person> patients)

    {

        while(patients.Count > 0)

        {

            var patient = patients.Dequeue();

            Console.WriteLine($"Осмотр пациента {patient.Name}");

        }

        Console.WriteLine("Доктор закончил осматривать пациентов");

    }

}
```

класс врача `Doctor` в методе `TakePatients` принимает очередь пациентов в виде объектов `Person`. пока в очереди есть объекты, метод извлекает их по одному через `Dequeue`. когда очередь пуста, печатается сообщение о конце осмотра. консольный вывод:

```c#


Осмотр пациента Tom

Осмотр пациента Bob

Осмотр пациента Sam

Доктор закончил осматривать пациентов
```
