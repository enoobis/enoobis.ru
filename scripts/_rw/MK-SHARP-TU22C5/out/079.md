большинство встроенных в .net классов коллекций и массивы поддерживают сортировку. одним методом, который, как правило, называется `Sort()`, набор данных упорядочивают по возрастанию:

```c#


int[] numbers = new int[] { 97, 45, 32, 65, 83, 23, 15 };

Array.Sort(numbers);

foreach (int n in numbers)

    Console.WriteLine(n);

// 15 23 32 45 65 83 97
```

метод `Sort` по умолчанию работает для наборов примитивных типов, таких как `int` или `string`. для сортировки наборов сложных объектов применяют интерфейс **IComparable**. в нём один метод:

```c#


public interface IComparable

{

    int CompareTo(object? o);

}
```

метод `CompareTo` сравнивает текущий объект с объектом, который передаётся параметром `object? o`. на выходе целое число одного из трёх видов:

- меньше нуля: текущий объект должен находиться перед объектом, который передаётся в качестве параметра

- равен нулю: оба объекта равны

- больше нуля: текущий объект должен находиться после объекта, передаваемого в качестве параметра

эти три исхода задают порядок для сортировки сравнением. класс `Person`:

```c#


class Person : IComparable

{

    public string Name { get;}

    public int Age { get; set; }

    public Person(string name, int age)

    {

        Name = name; Age = age;

    }

    public int CompareTo(object? o)

    {

        if(o is Person person) return Name.CompareTo(person.Name);

        else throw new ArgumentException("Некорректное значение параметра");

    }

}
```

критерием сравнения выбрано свойство `Name` объекта `Person`. фактически сравнивается `Name` текущего объекта и `Name` объекта, переданного параметром. если объект не приводится к типу `Person`, выбрасывается исключение: контракт не обещает сравнение с произвольным `object`.

применение:

```c#


var tom = new Person("Tom", 37);

var bob = new Person("Bob", 41);

var sam = new Person("Sam", 25);



Person[] people = { tom, bob, sam};

Array.Sort(people);



foreach (Person person in people)

{

    Console.WriteLine($"{person.Name} - {person.Age}");

}
```

консольный вывод:

```consoletext


Bob - 41

Sam - 25

Tom - 37
```

интерфейс `IComparable` имеет обобщённую версию. она сокращает применение в классе `Person` и убирает приведение из `object`:

```c#


class Person : IComparable<Person>

{

    public string Name { get;}

    public int Age { get; set; }

    public Person(string name, int age)

    {

        Name = name; Age = age;

    }

    public int CompareTo(Person? person)

    {

        if(person is null) throw new ArgumentException("Некорректное значение параметра");

        return Name.CompareTo(person.Name);

    }

}
```

аналогично задают сравнение по возрасту:

```c#


class Person : IComparable<Person>

{

    public string Name { get;}

    public int Age { get; set; }

    public Person(string name, int age)

    {

        Name = name; Age = age;

    }

    public int CompareTo(Person? person)

    {

        if(person is null) throw new ArgumentException("Некорректное значение параметра");

        return Age - person.Age;

    }

}
```

разность `Age - person.Age` сохраняет нужный знак, пока вычитание не переполняет `int`. у границ диапазона знак ломается, поэтому для порядка надёжнее `Age.CompareTo(person.Age)`.

### применение компаратора

кроме интерфейса `IComparable` платформа .net предоставляет интерфейс `IComparer`:

```c#


public interface IComparer<in T>

{

	int Compare(T? x, T? y);

}
```

метод `Compare` предназначен для сравнения двух объектов и тоже возвращает три значения. если первый объект больше второго, возвращается число больше 0. если меньше, возвращается число меньше нуля. если оба объекта равны, возвращается ноль. параметр `T` помечен `in`: интерфейс контравариантен.

компаратор объектов `Person` может сравнивать их по длине строки, то есть по длине значения свойства `Name`:

```c#


class PeopleComparer : IComparer<Person>

{

    public int Compare(Person? p1, Person? p2)

    {

        if(p1 is null || p2 is null) 

            throw new ArgumentException("Некорректное значение параметра");

        return p1.Name.Length - p2.Name.Length;

    }

}



class Person

{

    public string Name { get;}

    public int Age { get; set; }

    public Person(string name, int age)

    {

        Name = name; Age = age;

    }

}
```

здесь используется обобщённая версия интерфейса `IComparer`, чтобы не делать лишних преобразований типов. применение компаратора:

```c#


var alice = new Person("Alice", 41);

var tom = new Person("Tom", 37);

var kate = new Person("Kate", 25);



Person[] people = { alice, tom, kate};

Array.Sort(people, new PeopleComparer());



foreach (Person person in people)

{

    Console.WriteLine($"{person.Name} - {person.Age}");

}
```

объект компаратора указывают вторым параметром метода `Array.Sort()`. при этом не важно, реализует ли класс `Person` интерфейс `IComparable`: правила сортировки, установленные компаратором, имеют больший приоритет. в начале идут объекты `Person`, у которых имена короче, в конце те, у которых имена длиннее:

```consoletext


Tom - 37

Kate - 25

Alice - 41
```
