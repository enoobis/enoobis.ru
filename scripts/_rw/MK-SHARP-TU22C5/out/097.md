в c# 9.0 к шаблонам добавлены реляционный шаблон (relational pattern) и логический шаблон (logical pattern).

реляционный шаблон сравнивает входное значение с константой операциями порядка: `<`, `>`, `<=`, `>=`. ветви проверяются сверху вниз, поэтому более узкое условие ставят раньше более широкого. проценты по вкладу зависят от суммы:

```c#


decimal Calculate(decimal sum)

{

	return sum switch {

		<= 0 => 0,              // если sum меньше или равно 0, возвращаем 0

		< 50000 => sum * 0.05m, // если sum меньше 50000, возвращаем sum * 0.05m

		< 100000 => sum * 0.1m, // если sum меньше 100000, возвращаем sum * 0.1m

		_ => sum * 0.2m        // в остальных случаях возвращаем sum * 0.2m

	};

}
```

при сумме `<= 0` результат равен 0. при сумме меньше 50000, если первая ветвь уже не совпала, результат равен `sum * 0.05m`. суффикс `m` задаёт литерал типа `decimal`, и умножение остаётся в десятичной арифметике. при сумме меньше 100000 результат равен `sum * 0.1m`. шаблон `_` принимает остальные суммы, включая 100000 и выше, и возвращает `sum * 0.2m`. границы не пересекаются при исполнении, потому что срабатывает первая подходящая ветвь. значение 10000 меньше и 50000, и 100000, но останавливается на ветви `< 50000`.

применение:

```c#


Console.WriteLine(Calculate(-200));     // 0

Console.WriteLine(Calculate(0));        // 0 

Console.WriteLine(Calculate(10000));    // 500

Console.WriteLine(Calculate(60000));    // 6000

Console.WriteLine(Calculate(200000));   // 40000
```

логический шаблон соединяет шаблоны операторами `and` и `or`. `and` истинен, когда истинны оба операнда. `or` истинен, когда истинен хотя бы один. по возрасту выбирается сообщение о доступе:

```c#


string CheckAge(int age)

{

	return age switch

	{

		<1 or >110 => "Недействительный возраст",   // если age больше 110 и меньше 1

		>=1 and <18 => "Доступ запрещен",           // если age равно или больше 1 и меньше 18

		_ => "Доступ разрешен"                      // в остальных случаях

	};

}
```

ветвь `< 1 or > 110` совпадает, если возраст меньше 1 или больше 110, и возвращает сообщение о недействительном возрасте. ветвь `>= 1 and < 18` совпадает, если возраст не меньше 1 и при этом меньше 18, и возвращает сообщение о запрете доступа. шаблон `_` возвращает сообщение о разрешённом доступе для остальных значений, включая 18. приоритет `and` выше приоритета `or`, по той же схеме, что у операторов `&&` и `||`, поэтому в этих ветвях скобки не обязательны.

применение:

```c#


Console.WriteLine(CheckAge(200));     // Недействительный возраст

Console.WriteLine(CheckAge(0));      // Недействительный возраст 

Console.WriteLine(CheckAge(17));    // Доступ запрещен

Console.WriteLine(CheckAge(18));   // Доступ разрешен
```

третий логический оператор шаблонов, `not`, отрицает вложенный шаблон. ветвь совпадает, когда вложенный шаблон не совпадает:

```c#


string CheckAge(int age) => age switch

{

	not 33 => "Обычный возраст",   // если age НЕ равен 33

	_ => "Вам 33 года"             // в остальных случаях, то есть если age = 33

};
```

ветвь `not 33` совпадает при любом возрасте, отличном от 33, и возвращает сообщение об обычном возрасте. ветвь `_` остаётся для значения, которое предыдущая ветвь не приняла, то есть для возраста 33, и возвращает сообщение о том, что возраст равен 33. `not` здесь является комбинатором шаблонов. отрицается совпадение шаблона, а не заранее вычисленный `bool`, как у оператора `!`.
