### псевдонимы

для классов и структур можно ввести псевдоним. далее в программе вместо названия типа пишется этот псевдоним. для вывода строки на экран применяется метод `Console.WriteLine()`. классу `Console` задаётся псевдоним:

```c#


using printer = System.Console;



printer.WriteLine("Laudate omnes gentes laudate");

printer.WriteLine("Magnificat in secula");
```

выражение `using printer = System.Console` объявляет, что псевдонимом класса `System.Console` будет имя `printer`. с директивой подключения пространства имён в начале файла это выражение не совпадает, хотя используется тот же оператор `using`. псевдоним связывает имя с уже существующим типом и требует полного имени класса, включая пространство имён, в котором класс определён. нового типа псевдоним не создаёт: подстановка выполняется во время компиляции, в метаданных сборки отдельного типа `printer` нет. чтобы вывести строку, вызывается `printer.WriteLine("Laudate omnes gentes laudate")`.

псевдоним используют, когда имена классов и структур длинные и их сокращают, либо когда типу хотят дать более выразительное имя.

ещё один пример. объявляются класс и псевдоним для него:

```c#


using printer = System.Console;

using User = Person;



User tom = new User("Tom");

printer.WriteLine(tom.Name);    // Tom



class Person

{

    public string Name { get; set; }

    public Person(string name) => Name = name;

}
```

класс называется `Person`, а в программе для него используется псевдоним `User`. `User` и `Person` обозначают один и тот же тип: объект, созданный как `new User`, является экземпляром `Person`, и приведение между этими именами не требуется.

### статический импорт

в c# можно импортировать статическую функциональность класса. ниже импортируются члены класса `Console`:

```c#


using static System.Console;



WriteLine("Hello from C# 8.0");
```

выражение `using static` подключает все статические методы и свойства, а также константы указанного типа. после этого при вызове метода имя класса можно не писать: имя ищется среди импортированных статических членов. если одно и то же имя приходит из нескольких статических импортов, неквалифицированный вызов становится неоднозначным, и компилятор требует указать тип явно.

так же объявляются и импортируются собственные классы:

```c#


using static System.Console;

using static Operation;



WriteLine(Sum(5, 4));       // 9

WriteLine(Subtract(5, 4));  // 1

WriteLine(Multiply(5, 4)); // 20



static class Operation

{

    public static int Sum(int a, int b) => a + b;

    public static int Subtract(int a, int b) => a - b;

    public static int Multiply(int a, int b) => a * b;

}
```
