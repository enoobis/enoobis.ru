изменение xml-документа, то есть правка, добавление и удаление элементов, выполняется методами `XmlNode`:

- `AppendChild` добавляет новый дочерний узел в конец текущего узла

- `InsertAfter` добавляет новый узел после заданного узла

- `InsertBefore` добавляет новый узел перед заданным узлом

- `RemoveAll` удаляет все дочерние узлы текущего узла

- `RemoveChild` удаляет у текущего узла один дочерний узел и возвращает его

`XmlDocument` добавляет фабрики новых узлов. узел обязан быть создан тем документом, которому он будет принадлежать: конструкторы конкретных узлов снаружи сборки недоступны, поэтому новый узел получается только через документ-владелец и лишь затем присоединяется к дереву.

- `CreateNode` создаёт узел заданного типа `XmlNodeType`

- `CreateElement` создаёт элемент и возвращает `XmlElement`. в исходном перечне метод сопоставлен с типом `XmlDocument`, по контракту возвращается именно элемент

- `CreateAttribute` создаёт узел типа `XmlAttribute`

- `CreateTextNode` создаёт текстовый узел. тип результата называется `XmlText`, имени `XmlTextNode` в библиотеке нет

- `CreateComment` создаёт комментарий

исходный документ снова берётся из `people.xml` прошлой темы:

```xml


<?xml version="1.0" encoding="utf-8" ?>

<people>

  <person name="Tom">

    <company>Microsoft</company>

    <age>37</age>

  </person>

  <person name="Bob">

    <company>Google</company>

    <age>41</age>

  </person>

</people>
```

в этот документ добавляется новый элемент `person`:

```c#


using System.Xml;



XmlDocument xDoc = new XmlDocument();

xDoc.Load("people.xml");

XmlElement? xRoot = xDoc.DocumentElement;



// создаем новый элемент person

XmlElement personElem = xDoc.CreateElement("person");



// создаем атрибут name

XmlAttribute nameAttr = xDoc.CreateAttribute("name");



// создаем элементы company и age

XmlElement companyElem = xDoc.CreateElement("company");

XmlElement ageElem = xDoc.CreateElement("age");



// создаем текстовые значения для элементов и атрибута

XmlText nameText = xDoc.CreateTextNode("Mark");

XmlText companyText = xDoc.CreateTextNode("Facebook");

XmlText ageText = xDoc.CreateTextNode("30");



//добавляем узлы

nameAttr.AppendChild(nameText);

companyElem.AppendChild(companyText);

ageElem.AppendChild(ageText);



// добавляем атрибут name

personElem.Attributes.Append(nameAttr);

// добавляем элементы company и age

personElem.AppendChild(companyElem);

personElem.AppendChild(ageElem);

// добавляем в корневой элемент новый элемент person

xRoot?.AppendChild(personElem);

// сохраняем изменения xml-документа в файл

xDoc.Save("people.xml");
```

добавление идёт по одной схеме. сначала создаётся элемент, `xDoc.CreateElement("person")`. если элемент составной и содержит другие элементы, создаются и они. если элемент простой и хранит текст, создаётся текстовый узел, `XmlText companyText = xDoc.CreateTextNode("Facebook");`.

текст присоединяется к своему элементу или атрибуту через `AppendChild`. атрибут `name` добавляется в коллекцию `Attributes`, элементы `company` и `age` добавляются в `person`, а сам `person` добавляется в корень, `xRoot.AppendChild(personElem);`. оператор `?.` перед `AppendChild` пропускает вставку, если корневого элемента нет.

изменённое дерево записывается на диск методом `Save`: `xDoc.Save("people.xml")`.

код строит элемент с именем person, атрибутом `name` со значением mark и вложенными `company` и `age`. в тексте, который лекция показывает после записи, у добавленного узла стоит имя people: листинг и аргумент `CreateElement("person")` расходятся.

```xml


<?xml version="1.0" encoding="utf-8"?>

<people>

  <person name="Tom">

    <company>Microsoft</company>

    <age>37</age>

  </person>

  <person name="Bob">

    <company>Google</company>

    <age>41</age>

  </person>

  <people name="Mark">

    <company>Facebook</company>

    <age>30</age>

  </people>

</people>
```

### удаление узлов

удаление первого узла документа:

```c#


using System.Xml;



XmlDocument xDoc = new XmlDocument();

xDoc.Load("people.xml");

XmlElement? xRoot = xDoc.DocumentElement;

XmlNode? firstNode = xRoot?.FirstChild;

if(firstNode is not null) xRoot?.RemoveChild(firstNode);

xDoc.Save("people.xml");
```

`FirstChild` корня при стандартной загрузке указывает на первый элемент `person`. `RemoveChild` отсоединяет этот узел и возвращает его, после чего `Save` снова записывает файл. проверка `is not null` оставляет дерево без изменений, если дочернего узла нет.
