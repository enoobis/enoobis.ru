лямбда-выражение представляет собой сокращённую запись анонимного метода. слева от оператора `=>` задаётся список параметров, справа выражение или блок операторов, которые эти параметры используют. с точки зрения типа лямбда в этих примерах является делегатом: компилятор преобразует её в экземпляр делегата с совместимой сигнатурой. тот же синтаксис может быть преобразован в дерево выражений, если целевой тип этого требует. ниже целевой тип всегда делегат, и лямбда вызывается как метод.

общая форма:

```c#
(список_параметров) => выражение
```

простейшее лямбда-выражение не принимает параметров и не возвращает значения:

```c#

Message hello = () => Console.WriteLine("Hello");
hello();       // Hello
hello();       // Hello
hello();       // Hello

delegate void Message();
```

переменная hello имеет тип делегата Message: действие без параметров и без результата. справа от `=>` стоит выражение `Console.WriteLine("Hello")`. слева список параметров пуст, что совпадает с Message. каждый вызов hello выполняет это выражение. дальше переменная используется как метод.

если действий несколько, они заключаются в фигурные скобки. такой блок является телом оператора, а не одним выражением:

```c#

Message hello = () =>
{
    Console.Write("Hello ");
    Console.WriteLine("World");
};
hello();       // Hello World
```

выше тип hello задан явно, именем делегата Message. начиная с **c# 10** переменную с лямбдой можно объявить через **var**. у лямбды тогда должен быть выводимый естественный тип:

```c#

var hello = () => Console.WriteLine("Hello");
hello();       // Hello
hello();       // Hello
hello();       // Hello
```

при неявной типизации компилятор сопоставляет лямбду с известным типом делегата по её форме. лямбда без параметров и без возвращаемого значения получает естественный тип встроенного делегата **Action**. Action как раз не принимает параметров и не возвращает значения, поэтому hello в этом фрагменте имеет тип Action, и вызов hello() законен.

### параметры лямбды

если целевой тип делегата известен, типы параметров лямбды можно не повторять. они выводятся из сигнатуры делегата:

```c#

Operation sum = (x, y) => Console.WriteLine($"{x} + {y} = {x + y}");
sum(1, 2);       // 1 + 2 = 3
sum(22, 14);    // 22 + 14 = 36

delegate void Operation(int x, int y);
```

лямбда sum приводится к типу Operation, у которого оба параметра имеют тип `int`. параметры x и y получают этот тип, и отдельная аннотация в списке не нужна.

при неявной типизации целевого типа нет, и вывести тип делегата из одних только имён параметров компилятор не может. следующий фрагмент не компилируется:

```c#
var sum = (x, y) => Console.WriteLine($"{x} + {y} = {x + y}");	// ! Ошибка
```

тип параметров тогда указывают явно. по аннотациям компилятор уже может построить тип делегата:

```c#

var sum = (int x, int y) => Console.WriteLine($"{x} + {y} = {x + y}");
sum(1, 2);       // 1 + 2 = 3
sum(22, 14);    // 22 + 14 = 36
```

если параметр один и его тип не аннотируется, скобки вокруг списка опускаются:

```c#

PrintHandler print = message => Console.WriteLine(message);
print("Hello");         // Hello
print("Welcome");       // Welcome

delegate void PrintHandler(string message);
```

начиная с c# 12 параметру лямбды можно задать значение по умолчанию. при вызове без аргумента используется это значение, при вызове с аргументом подставляется переданное:

```c#

var welcome = (string message = "hello")=> Console.WriteLine(message);

welcome("hello world"); // hello world
welcome();              // hello
```

### возвращение результата

лямбда может возвращать значение. если справа от `=>` стоит одно выражение без фигурных скобок, его значение и есть результат. тип результата должен совпадать с возвращаемым типом делегата либо выводиться из самого выражения, когда делегат объявлен через **var**:

```c#

var sum = (int x, int y) => x + y;
int sumResult = sum(4, 5);                  // 9
Console.WriteLine(sumResult);               // 9

Operation multiply = (x, y) => x * y;
int multiplyResult = multiply(4, 5);        // 20
Console.WriteLine(multiplyResult);          // 20

delegate int Operation(int x, int y);
```

в первой лямбде тип делегата выводится из аннотаций `int` и из выражения `x + y`, результат имеет тип int. во второй целевой тип задан делегатом Operation, параметры выводятся из него, а выражение `x * y` даёт возвращаемый тип int.

если тело состоит из нескольких операторов или из одного оператора в фигурных скобках, результат передаётся оператором **return**, как в обычном методе. одно выражение в скобках уже не считается автоматически результатом:

```c#

var subtract = (int x, int y) =>
{
    if (x > y) return x - y;
    else return y - x;
};
int result1 = subtract(10, 6);  // 4 
Console.WriteLine(result1);     // 4

int result2 = subtract(-10, 6);  // 16
Console.WriteLine(result2);      // 16
```

обе ветви возвращают неотрицательную разность. при x > y возвращается x - y, иначе y - x. вызовы с парами (10, 6) и (-10, 6) дают 4 и 16.

### добавление и удаление действий в лямбда-выражении

переменная, которой присвоена лямбда, имеет тип делегата, поэтому к ней применяются те же операции над списком вызова. в список можно добавить другую лямбду или метод, а затем удалить их. порядок вызова совпадает с порядком добавления, удаление снимает соответствующее вхождение:

```c#

var hello = () => Console.WriteLine("METANIT.COM");

var message = () => Console.Write("Hello ");
message += () => Console.WriteLine("World"); // добавляем анонимное лямбда-выражение
message += hello;   // добавляем лямбда-выражение из переменной hello
message += Print;   // добавляем метод

message();
Console.WriteLine("--------------"); // для разделения вывода

message -= Print;   // удаляем метод
message -= hello;   // удаляем лямбда-выражение из переменной hello

message?.Invoke();  // на случай, если в message больше нет действий

void Print() => Console.WriteLine("Welcome to C#");
```

сначала message ссылается на лямбду, которая печатает "Hello " без перевода строки. к ней добавляется лямбда с "World" и переводом строки, затем лямбда из переменной hello ("METANIT.COM") и метод Print ("Welcome to C#"). первый вызов message выполняет все четыре действия. после разделительной строки из списка снимаются Print и hello. вызов через `message?.Invoke()` выполняет оставшиеся две лямбды. оператор `?.` оставлен на случай, если список вызова опустеет: при значении null вызов просто не производится.

консольный вывод:

```consoletext

Hello World
METANIT.COM
Welcome to C#
--------------
Hello World
```

### лямбда-выражение как аргумент метода

лямбду можно передать в параметр типа делегата. метод задаёт момент вызова и аргументы, а лямбда задаёт само действие. в следующем фрагменте действие является предикатом: делегат возвращает bool и тем самым решает, участвует ли элемент в сумме.

```c#

int[] integers = { 1, 2, 3, 4, 5, 6, 7, 8, 9 };

// найдем сумму чисел больше 5
int result1 = Sum(integers, x => x > 5);
Console.WriteLine(result1); // 30

// найдем сумму четных чисел
int result2 = Sum(integers, x => x % 2 == 0);
Console.WriteLine(result2);  //20

int Sum(int[] numbers, IsEqual func)
{
    int result = 0;
    foreach (int i in numbers)
    {
        if (func(i))
            result += i;
    }
    return result;
}

delegate bool IsEqual(int x);
```

метод Sum принимает массив чисел и делегат IsEqual, а возвращает сумму типа int. цикл перебирает массив и накапливает только те элементы, для которых `IsEqual func` возвращает true. на момент написания Sum конкретное условие неизвестно. известна только сигнатура: по числу типа int метод должен получить bool.

при вызове в Sum передаются массив и лямбда:

```c#

int result1 = Sum(integers, x => x > 5);
```

параметр x этой лямбды получает число, которое Sum передаёт в делегат:

```c#

if (func(i))
```

выражение `x > 5` задаёт условие. если оно истинно, лямбда возвращает true, и число входит в сумму. для массива от 1 до 9 это числа 6, 7, 8 и 9, их сумма равна 30.

второй вызов устроен так же, но условие другое: в сумму входят чётные числа, то есть те, остаток от деления которых на 2 равен нулю.

```c#

int result2 = Sum(integers, x => x % 2 == 0);
```

числа 2, 4, 6 и 8 дают сумму 20.

### лямбда-выражение как результат метода

метод может вернуть лямбду. возвращаемый тип метода тогда является типом делегата, с которым эта лямбда совместима. конкретное тело выбирается по аргументу и становится значением делегата:

```c#

Operation operation = SelectOperation(OperationType.Add);
Console.WriteLine(operation(10, 4));    // 14

operation = SelectOperation(OperationType.Subtract);
Console.WriteLine(operation(10, 4));    // 6

operation = SelectOperation(OperationType.Multiply);
Console.WriteLine(operation(10, 4));    // 40

Operation SelectOperation(OperationType opType)
{
    switch (opType)
    {
        case OperationType.Add: return (x, y) => x + y;
        case OperationType.Subtract: return (x, y) => x - y;
        default: return (x, y) => x * y;
    }
}
enum OperationType
{
    Add, Subtract, Multiply
}
delegate int Operation(int x, int y);
```

метод SelectOperation принимает перечисление OperationType. в перечислении три константы, по одной на арифметическую операцию. по значению параметра метод возвращает лямбду: сложение, вычитание или умножение. ветвь default возвращает умножение, поэтому константа Multiply и любое неразобранное значение дают произведение. возвращаемый тип Operation требует два параметра типа int и результат типа int. каждая из трёх лямбд эту сигнатуру выполняет, типы параметров выводятся из Operation, и отдельная аннотация в списке не нужна. вызов полученного делегата с аргументами 10 и 4 даёт 14, 6 и 40 соответственно.
