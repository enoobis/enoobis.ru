начиная с c# 14 для собственного типа можно отдельно задать составные операторы присваивания: цель присваивания изменяется на месте.

в более ранних версиях c# составное присваивание для такого типа тоже существовало, но только как следствие бинарного оператора. если определён оператор сложения, выражение с `+=` компилируется без отдельного объявления. тип `Counter` ниже складывает свой экземпляр с числом и возвращает новый `Counter`:

```c#

Counter counter1 = new Counter { Value = 23 };
Counter counter2 = counter1 + 45;
Console.WriteLine(counter2.Value);  // 23 + 45 = 68

class Counter
{
    static int count;
    public int Id {get;}
    public int Value { get; set; }

    public Counter()
    {
        Id = ++count;
    }
    public static Counter operator +(Counter c, int n)
    {
        return new Counter { Value = c.Value + n };
    }
}
```

оператор `+` создаёт новый экземпляр и записывает в него сумму `Value`. тот же оператор подставляется в составное присваивание, поэтому следующая запись законна, хотя `+=` явно не объявлялся:

```c#

Counter counter1 = new Counter { Value = 23 };
counter1 += 45;
Console.WriteLine($"counter1.Value: {counter1.Value}");  // 68
```

вызов `+=` компилируется благодаря оператору `+`. вывод на консоль показывает, что арифметика сходится: 23 + 45 даёт 68. так же устроены остальные пары. достаточно объявить `-`, и становится доступна операция `-=`.

у этой подстановки есть цена. инструкция

```c#
counter1 += 45;
```

совпадает по результату с присваиванием

```c#
counter1 = counter1 + 45;
```

бинарный `+` возвращает новый `Counter`, и переменная начинает указывать на него. свойство `Id` делает эту подмену наблюдаемой: идентификатор выдаёт конструктор, поэтому смена `Id` означает новый экземпляр.

```c#

Counter counter1 = new Counter { Value = 23 };

Console.WriteLine($"counter1.Id: {counter1.Id}"); // counter1.Id: 1

counter1 += 45;  // Здесь создается новый объект Counter
Console.WriteLine($"counter1.Value: {counter1.Value}");  // 68

Console.WriteLine($"counter1.Id: {counter1.Id}");   // counter1.Id: 2
```

консольный вывод:

```bash

counter1.Id: 1
counter1.Value: 68
counter1.Id: 2
```

у `counter1` сменился `Id`, конструктор отработал дважды. серия таких операций повторяет создание:

```c#

Counter counter1 = new Counter { Value = 0 };
counter1 += 1;  // 2-й вызов конструктора
counter1 += 1;  // 3-й вызов конструктора
counter1 += 1;  // 4-й вызов конструктора
Console.WriteLine($"counter1.Value: {counter1.Value}");  // 3
```

каждое `+=` вызывает конструктор заново. для типа, у которого сложение означает увеличение величины этого объекта, лишние экземпляры не нужны. в c# 14 (.net 10) составное присваивание можно объявить отдельно: метод изменяет текущий объект и ничего не выделяет взамен.

такой оператор является методом экземпляра. он возвращает `void`, принимает один параметр и называется так же, как сам оператор. к объявлению применяются четыре правила:

- объявление не содержит модификатор `static`

- оператор принимает один параметр

- возвращаемый тип оператора: `void`

- имя совпадает с обозначением оператора: `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `|=`, `^=`, `<<=`, `>>=` или `>>>=`

оператор `+=` для `Counter`, который меняет поле на месте:

```c#

Counter counter1 = new Counter { Value = 0 };

Console.WriteLine($"counter1.Id: {counter1.Id}"); // counter1.Id: 1

counter1 += 1;
counter1 += 1;
counter1 += 1;

Console.WriteLine($"counter1.Value: {counter1.Value}");  // 3

Console.WriteLine($"counter1.Id: {counter1.Id}");   // counter1.Id: 1

class Counter
{
    static int count;
    public int Id {get;}
    public int Value { get; set; }

    public Counter()
    {
        Id = ++count;
    }
    public void operator +=(int n)
    {
        Value += n;
    }
}
```

консольный вывод подтверждает, что конструктор при `+=` не вызывается и новый объект не создаётся. меняется `Value` уже существующего экземпляра, `Id` остаётся прежним:

```bash

counter1.Id: 1
counter1.Value: 3
counter1.Id: 1
```

одноимённые составные операторы перегружаются по типу параметра, как обычные методы:

```c#

Counter counter1 = new Counter { Value = 0 };

counter1 += 1;
counter1 += new Counter { Value = 5 };

counter1 += 2;

Console.WriteLine(counter1.Value);  // 8

class Counter
{
    public int Value { get; set; }

    public void operator +=(int n)
    {
        Value += n;
    }

    public void operator +=(Counter c)
    {
        Value += c.Value;
    }
}
```

здесь одна форма прибавляет `int`, другая прибавляет `Value` второго `Counter`. три операции дают 0 + 1 + 5 + 2 = 8.

инкремент и декремент по смыслу близки к `+=` и `-=`, и их задают той же экземплярной формой:

```c#

Counter counter1 = new Counter { Value = 1 };

counter1++;
Console.WriteLine(counter1.Value);  // 2
++counter1;
Console.WriteLine(counter1.Value);  // 3

class Counter
{
    public int Value { get; set; }

    public void operator ++() => ++Value;
}
```

префиксная и постфиксная запись в виде отдельной инструкции обе вызывают этот метод и увеличивают `Value`. у формы есть ограничение: она возвращает `void`, поэтому её результат нельзя присвоить. следующие выражения не компилируются:

```c#

Counter counter2 = ++counter1;
// или так
Counter counter2 = counter1++;
```

чтобы инкремент одновременно менял текущий объект и давал значение в выражении, рядом ставят два объявления: статическое и экземплярное.

```c#

Counter counter1 = new Counter { Value = 1 };

Counter counter2 = ++counter1;
Console.WriteLine(counter1.Value);  // 2
Console.WriteLine(counter2.Value);  // 2


class Counter
{
    public int Value { get; set; }

    // два определения оператора
    public static Counter operator ++(Counter c) => new Counter{Value = c.Value++};
    public void operator ++() => ++Value;
}
```

статическая форма возвращает `Counter` и тем самым делает `++` выражением. экземплярная форма по-прежнему меняет объект на месте. комментарии к выводу фиксируют у обеих переменных `Value`, равный 2.

## операторы и наследование

производный класс может переопределить оператор присваивания базового класса. экземплярная форма участвует в виртуальной диспетчеризации. статический оператор прежних версий виртуальным не бывает:

```c#

var dc = new DoubleCounter { Value = 0 };

dc += 3;
Console.WriteLine(dc.Value);  // 6


class Counter
{
    public int Value { get; set; }
    public virtual void operator +=(int n) => Value += n;
}
class DoubleCounter : Counter
{
    public new int Value { get; set; }
    // переопределяем оператор
    public override void operator +=(int n) => Value += 2*n;
}
```

в `Counter` оператор `+=` объявлен как `virtual`. `DoubleCounter` подменяет его через `override` и прибавляет удвоенное число. свойство `Value` в производном классе объявлено с `new`, то есть это отдельное свойство, которое скрывает базовое. переопределённый оператор пишет именно в него. вызов `dc += 3` попадает в `DoubleCounter` и даёт 6.
