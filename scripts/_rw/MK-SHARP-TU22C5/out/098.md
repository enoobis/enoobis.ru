шаблоны списков (list pattern) сопоставляют выражение с последовательностью элементов массива или списка. шаблон доступен начиная с c# 11. он требует тип, у которого есть длина (`Length` или `Count`) и индексатор. массив и `List<T>` этому условию удовлетворяют. подшаблоны элементов проверяются по позициям, а длина шаблона без среза должна совпасть с длиной значения.

полное совпадение с массивом задаётся перечислением всех элементов:

```c#


Console.WriteLine(GetNumber(new[] { 1, 2, 3, 4, 5 }));  // 1

Console.WriteLine(GetNumber(new[] { 1, 2}));            // 3

Console.WriteLine(GetNumber(new int[] {}));             // 4

Console.WriteLine(GetNumber(new[] { 1, 2, 5 }));        // 5



int GetNumber(int[] values)=> values switch

{

        [1, 2, 3, 4, 5] => 1,

        [1, 2, 3] => 2,

        [1, 2] => 3,

        [] => 4,

        _ => 5

};
```

ветвь `[1, 2, 3, 4, 5]` совпадает только с массивом этой длины и с этими элементами по порядку. ветви `[1, 2, 3]`, `[1, 2]` и пустой шаблон `[]` устроены так же. шаблон `_` вне скобок отбрасывает всё значение и принимает любой массив, не совпавший с предыдущими ветвями, в том числе массив другой длины. отсюда результаты примера. пять элементов `1, 2, 3, 4, 5` дают 1. массив из `1, 2` даёт 3. пустой массив даёт 4. массив `1, 2, 5` не равен ни одному списку констант и даёт 5.

тот же набор ветвей применим к списку `List<int>`:

```c#


List<int> numbers = new List<int>{1, 2, 3};



Console.WriteLine(GetNumber(numbers));  // 2



int GetNumber(List<int> values) => values switch

{

    [1, 2, 3, 4, 5] => 1,

    [1, 2, 3] => 2,

    [1, 2] => 3,

    [] => 4,

    _ => 5

};
```

список из трёх элементов `1, 2, 3` совпадает со второй ветвью и даёт 2.

шаблон списка допустим и в операторе `if`:

```c#


int[] numbers = { 1, 2, 3, 4, 5 };

if(numbers is [1, 2, 3, 4, 5])

{

    Console.WriteLine("[1, 2, 3, 4, 5]");

}
```

#### подстановка _

шаблон `_` на месте элемента принимает один элемент с любым значением и эту позицию из длины не выбрасывает. шаблон `[2, _, 5]` совпадает с массивом ровно из трёх элементов, у которого первый равен 2, третий равен 5, а средний произволен. шаблон `[_, _]` совпадает с любым массивом ровно из двух элементов.

```c#


Console.WriteLine(GetNumber(new[] { 2, 3, 5}));       // 1

Console.WriteLine(GetNumber(new[] { 2, 4, 6 }));      // 2

Console.WriteLine(GetNumber(new[] { 1, 2, 5 }));      // 3

Console.WriteLine(GetNumber(new[] { 1, 2, 3}));      // 4

Console.WriteLine(GetNumber(new int[] { }));         // 5



int GetNumber(int[] values) => values switch

{

    [2, _, 5] => 1,

    [2, _, _] => 2,

    [_, _, 5] => 3,

    [_, _, _] => 4,

    _ => 5

};
```

массив `{ 2, 3, 5 }` совпадает с `[2, _, 5]`. массив `{ 2, 4, 6 }` не имеет 5 на третьей позиции и подходит под `[2, _, _]`. массив `{ 1, 2, 5 }` подходит под `[_, _, 5]`. массив `{ 1, 2, 3 }` имеет длину 3 и раньше не совпал, поэтому попадает в `[_, _, _]`. пустой массив трёх позиций не имеет и уходит в `_`.

#### slice-паттерн

срез (slice pattern), записываемый как `..`, принимает последовательность произвольной длины, в том числе пустую. в одном шаблоне списка такой срез допускается один раз. шаблон `[1, 2, .., 5]` требует, чтобы массив начинался с 1, следующим элементом была 2, а последним была 5. между 2 и 5 может стоять сколько угодно целых чисел, и промежуток может быть пустым. под этот шаблон подходят, в частности, три массива:

```c#


int[] arr1 = {  1, 2, 3, 4, 5 };

int[] arr2 = { 1, 2, 5 };

int[] arr3 = { 1, 2, 66, 77, 88, 5 };
```

тем же срезом задаётся произвольный хвост, произвольная голова или весь массив. `[2, ..]` совпадает с непустым массивом, который начинается с 2. `[.., 5]` совпадает с массивом, который заканчивается на 5. `[..]` совпадает с массивом любой длины, включая пустой.

```c#


Console.WriteLine(GetNumber(new[] { 2, 5 }));           // 1

Console.WriteLine(GetNumber(new[] { 2, 3, 4, 5 }));     // 1



Console.WriteLine(GetNumber(new[] { 2}));               // 2

Console.WriteLine(GetNumber(new[] { 2, 3, 4}));         // 2



Console.WriteLine(GetNumber(new[] {3, 4, 5}));          // 3

Console.WriteLine(GetNumber(new[] { 5 }));              // 3



Console.WriteLine(GetNumber(new int[] {  }));           // 4

Console.WriteLine(GetNumber(new[] { 1 }));              // 4

Console.WriteLine(GetNumber(new[] { 1, 2, 3 }));        // 4



int GetNumber(int[] values)=> values switch

{

    [2, .., 5] => 1,    // если первый элемент - 2, а последний - 5

    [2,..] => 2,        // если первый элемент - 2

    [.., 5] => 3,       // если последний элемент - 5

    [..] => 4          // произвольное количество элементов

};
```

комментарии ветвей фиксируют те же условия. первая ветвь принимает и `{ 2, 5 }`, где срез пуст, и `{ 2, 3, 4, 5 }`, где срез содержит 3 и 4. массив, который начинается с 2 и не заканчивается на 5, попадает во вторую ветвь. массив, который заканчивается на 5 и не начинается с 2, попадает в третью. все прочие значения, включая пустой массив, `{ 1 }` и `{ 1, 2, 3 }`, принимает `[..]`.

срез сочетается с подстановкой `_`:

```c#


int GetNumber(int[] values) => values switch

{

    [_, .., _] => 1,

    [..] => 2

};
```

шаблон `[_, .., _]` требует хотя бы два элемента. первый и последний занимают позиции `_`, а `..` принимает всё между ними, в том числе пустую последовательность. массив короче двух элементов до этой ветви не доходит и совпадает с `[..]`.

```c#


Console.WriteLine(GetNumber(new[] { 1, 2, 3, 4}));   // 1

Console.WriteLine(GetNumber(new[] { 1, 2, 3}));     // 1

Console.WriteLine(GetNumber(new[] { 1, 2}));        // 1

Console.WriteLine(GetNumber(new[] { 1 }));          // 2

Console.WriteLine(GetNumber(new int[] { }));       // 2



int GetNumber(int[] values) => values switch

{

    [_, .., _] => 1,

    [..] => 2

};
```

массивы длины 4, 3 и 2 попадают в первую ветвь. массив из одного элемента и пустой массив попадают во вторую.

### получение элементов в переменные

отдельные элементы можно связать с переменными. позиция `var` всегда совпадает и сохраняет элемент:

```c#


int[] numbers = { 2, 3, 5 };

if(numbers is [var first, var second, .., var last])

{

    Console.WriteLine($"first: {first}, second: {second}  last: {last}");

}
```

первый элемент попадает в `first`, второй в `second`, последний в `last`. срез `..` поглощает середину и в этом фрагменте никуда не записывается.

тот же разбор для нескольких массивов:

```c#


Console.WriteLine(GetData(new[] { 1, 2, 3 }));        // First: 1  Second: 2  Last: 3

Console.WriteLine(GetData(new[] { 2, 4, 6, 8 }));    // First: 2  Second: 4  Last: 8

Console.WriteLine(GetData(new[] { 1, 2 }));          // Array has less than 3 elements



string GetData(int[] values) => values switch

{

    [var first, var second, .., var last] => $"First: {first}  Second: {second}  Last: {last}",

    [..] => "Array has less than 3 elements"

};
```

если длина меньше трёх, позиций для `first`, `second` и `last` не хватает, и значение совпадает с `[..]`. текст результата тогда сообщает, что в массиве меньше трёх элементов. при достаточной длине в строку входят первый, второй и последний элементы, без промежуточных.

элементы, пришедшиеся на срез, тоже можно записать в переменную. в шаблоне `[2, .. var middle, 5]` подпоследовательность среза попадает в `middle`:

```c#


Console.WriteLine(GetSlice(new[] { 2, 3, 4, 5}));       // Middle: 3, 4

Console.WriteLine(GetSlice(new[] { 2, 4, 6, 8 }));      // End: 4, 6, 8

Console.WriteLine(GetSlice(new[] { 1, 2, 3, 5 }));      // Start: 1, 2, 3

Console.WriteLine(GetSlice(new[] { 1, 2, 3, 4 }));      // All: 1, 2, 3, 4

Console.WriteLine(GetSlice(new int[] { }));             // All: 



string GetSlice(int[] values) => values switch

{

    [2, .. var middle, 5] => $"Middle: {string.Join(", ", middle)}",

    [2, .. var end] => $"End: {string.Join(", ", end)}",

    [.. var start, 5] => $"Start: {string.Join(", ", start)}",

    [.. var all] => $"All: {string.Join(", ", all)}"

};
```

ветви идут по порядку. массив, который начинается с 2 и заканчивается на 5, отдаёт середину в `middle`, и `string.Join` печатает её через запятую. массив, который начинается с 2 и не заканчивается на 5, отдаёт хвост после первой двойки в `end`. массив, который заканчивается на 5 и не попал в предыдущие ветви, отдаёт голову без последней пятёрки в `start`. любой оставшийся массив, включая пустой, целиком попадает в `all`.

### свойства коллекций

массивы и списки являются обычными классами c# и имеют свойства, поэтому к ним применим и шаблон свойства. конъюнкция `and` соединяет его со списочным шаблоном. если массив из трёх элементов нужно разложить по трём переменным, длину можно назвать явно:

```c#


int[] numbers = { 2, 3, 5 };

if(numbers is { Length:3} and [var first, var second, var third])

{

    Console.WriteLine($"first: {first}, second: {second}  third: {third}");

}
```

шаблон `{ Length: 3 }` проверяет свойство `Length`. шаблон `[var first, var second, var third]` связывает три позиции. `and` требует оба совпадения. для массива длины 3 списочный шаблон уже подразумевает эту длину, а свойство `Length` делает то же условие явным и показывает, что оба вида шаблонов применяются к одному значению.
