если встроенные типы исключений не подходят, создаются собственные типы. базовым классом для всех исключений является класс `Exception`, и для собственного типа наследуется он.

в программе действует ограничение по возрасту:

```c#


try

{

    Person person = new Person { Name = "Tom", Age = 17 };

}

catch (Exception ex)

{

    Console.WriteLine($"Ошибка: {ex.Message}");

}



class Person

{

    private int age;

    public string Name { get; set; } = "";

    public int Age

    {

        get => age;

        set

        {

            if (value < 18)

                throw new Exception("Лицам до 18 регистрация запрещена");

            else

                age = value;

        }

    }

}
```

в классе `Person` при установке возраста выполняется проверка. если возраст меньше 18, выбрасывается исключение. класс `Exception` принимает в конструкторе строку, которая затем передаётся в его свойство `Message`.

иногда удобнее собственные классы исключений. в отдельной ситуации требуется особым образом обработать только те исключения, которые относятся к классу `Person`. для этого вводится специальный класс `PersonException`:

```c#


class PersonException : Exception

{

    public PersonException(string message)

        : base(message) { }

}
```

своих полей и методов у класса нет. конструктор только обращается к конструктору базового класса `Exception` и передаёт ему строку `message`. класс `Person` после этого выбрасывает исключение именно этого типа, а основная программа обрабатывает его отдельным блоком `catch`:

```c#


try

{

    Person person = new Person { Name = "Tom", Age = 17 };

}

catch (PersonException ex)

{

    Console.WriteLine($"Ошибка: {ex.Message}");

}



class Person

{

    private int age;

    public string Name { get; set; } = "";

    public int Age

    {

        get => age;

        set

        {

            if (value < 18)

                throw new PersonException("Лицам до 18 регистрация запрещена");

            else

                age = value;

        }

    }

}
```

обработчик выбирается по типу объекта исключения. отдельный класс нужен затем, чтобы `catch (PersonException)` срабатывал только на эту ситуацию и не перехватывал остальные `Exception`. имя с суффиксом `Exception` соответствует обычному соглашению библиотеки .net. в библиотечном коде у такого типа, как правило, есть ещё конструктор с внутренним исключением `InnerException`, чтобы сохранять цепочку причин. для примера достаточен один конструктор со строкой сообщения.

наследовать собственный класс исключений именно от типа `Exception` не обязательно. берётся и другой производный тип. тип `ArgumentException` представляет исключение, генерируемое из-за передачи аргументу некорректного значения:

```c#


class PersonException : ArgumentException

{

	public PersonException(string message)

		: base(message)

	{ }

}
```

для возраста это основание подходит: в сеттер свойства приходит недопустимое значение аргумента `value`. `ArgumentException` уже несёт смысл «некорректный аргумент», а `PersonException` уточняет, что аргумент относится к объекту `Person`.

каждый тип исключений может определять свои свойства. в классе можно определить свойство для хранения устанавливаемого значения:

```c#


class PersonException : ArgumentException

{

	public int Value { get;}

	public PersonException(string message, int val)

		: base(message)

	{

		Value = val;

	}

}
```

в конструкторе класса это свойство устанавливается. при обработке исключения его значение читается:

```c#


try

{

    Person person = new Person { Name = "Tom", Age = 17 };

}

catch (PersonException ex)

{

    Console.WriteLine($"Ошибка: {ex.Message}");

    Console.WriteLine($"Некорректное значение: {ex.Value}");

}



class Person

{

    private int age;

    public string Name { get; set; } = "";

    public int Age

    {

        get => age;

        set

        {

            if (value < 18)

                throw new PersonException("Лицам до 18 регистрация запрещена", value);

            else

                age = value;

        }

    }

}
```

консольный вывод:

```consoletext


Ошибка: Лицам до 18 регистрация запрещена

Некорректное значение: 17
```

свойство `Value` хранит отклонённое значение рядом с текстом `Message`. обработчику не нужно разбирать строку сообщения, чтобы узнать, какое именно число было отвергнуто: оно лежит в типизированном поле исключения.
