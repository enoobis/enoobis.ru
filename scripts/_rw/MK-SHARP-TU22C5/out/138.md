обработка ошибок в асинхронных методах, использующих ключевые слова `async` и `await`, имеет свои особенности. исключение, выброшенное из тела `async`-метода, сохраняется в возвращаемой задаче и заново возбуждается в точке `await`.

для обработки ошибок выражение **await** помещается в блок `try`:

```c#

try
{
    await PrintAsync("Hello  enoobis.COM");
    await PrintAsync("Hi");
}
catch (Exception ex)
{
    Console.WriteLine(ex.Message);
}

async Task PrintAsync(string message)
{
    // если длина строки меньше 3 символов, генерируем исключение
    if (message.Length < 3)
        throw new ArgumentException($"Invalid string length: {message.Length}");
    await Task.Delay(100);     // имитация продолжительной операции
    Console.WriteLine(message);
}
```
асинхронный метод `PrintAsync` генерирует исключение `ArgumentException`, если методу передаётся строка длиной меньше 3 символов.

для обработки исключения выражение `await` помещено в блок `try`. при выполнении вызова `await PrintAsync("Hi")` генерируется исключение, и оно выбрасывается в точке ожидания. программа не останавливает аварийно свою работу: исключение обрабатывается, и выполнение продолжается.

консольный вывод программы:

```consoletext

Hello  enoobis.COM
Invalid string length: 2
```
если асинхронный метод имеет тип `void`, исключение вовне не передаётся. объекта `Task`, в котором можно было бы сохранить ошибку, метод не возвращает, и обработать исключение при вызове нельзя.

```c#

try
{
    PrintAsync("Hello  enoobis.COM");
    PrintAsync("Hi");       // здесь программа сгенерирует исключение и аварийно остановится
    await Task.Delay(1000); // ждем завершения задач
}
catch (Exception ex)    // исключение НЕ будет обработано
{
    Console.WriteLine(ex.Message);
}

async void PrintAsync(string message)
{
    // если длина строки меньше 3 символов, генерируем исключение
    if (message.Length < 3)
        throw new ArgumentException($"Invalid string length: {message.Length}");
    await Task.Delay(100);     // имитация продолжительной операции
    Console.WriteLine(message);
}
```
несмотря на то, что асинхронные методы вызываются в блоке `try`, исключение не будет перехвачено и обработано. в этом ограничение асинхронных `void`-методов: исключение уходит в текущий контекст синхронизации, а при его отсутствии в пул потоков, и необработанное исключение аварийно завершает процесс. обработку исключения тогда определяют в самом асинхронном методе:

```c#

PrintAsync("Hello  enoobis.COM");
PrintAsync("Hi");
await Task.Delay(1000); // ждем завершения задач

async void PrintAsync(string message)
{
    try
    {
        // если длина строки меньше 3 символов, генерируем исключение
        if (message.Length < 3)
            throw new ArgumentException($"Invalid string length: {message.Length}");
        await Task.Delay(100);     // имитация продолжительной операции
        Console.WriteLine(message);
    }
    catch (Exception ex)
    {
        Console.WriteLine(ex.Message);
    }

}
```
### исследование исключения

при возникновении ошибки у объекта `Task`, представляющего асинхронную задачу, в которой произошла ошибка, свойство **IsFaulted** имеет значение `true`. кроме того, свойство `Exception` объекта `Task` содержит всю информацию об ошибке. ниже это свойство проверяется явно:

```c#

var task = PrintAsync("Hi");
try
{
    await task;
}
catch
{
    Console.WriteLine(task.Exception?.InnerException?.Message); // Invalid string length: 2
    Console.WriteLine($"IsFaulted: {task.IsFaulted}");  // IsFaulted: True
    Console.WriteLine($"Status: {task.Status}");        // Status: Faulted
}

async Task PrintAsync(string message)
{
    // если длина строки меньше 3 символов, генерируем исключение
    if (message.Length < 3)
        throw new ArgumentException($"Invalid string length: {message.Length}");
    await Task.Delay(1000);     // имитация продолжительной операции
    Console.WriteLine(message);
}
```
если в метод передана строка длиной меньше 3 символов, `task.IsFaulted` равно `true`. статус такой задачи, `TaskStatus.Faulted`, виден через свойство `Status`. свойство `Exception` имеет тип `AggregateException`: инфраструктура задач оборачивает исходное исключение, и оно доступно через `InnerException`.

### обработка нескольких исключений. whenall

если ожидается выполнение сразу нескольких задач, например с помощью `Task.WhenAll`, можно получить сразу несколько исключений, по одному на каждую упавшую задачу. все исключения читаются из свойства `Exception.InnerExceptions`:

```c#

// определяем и запускаем задачи
var task1 = PrintAsync("H");
var task2 = PrintAsync("Hi");
var allTasks = Task.WhenAll(task1, task2);
try
{
    await allTasks;
}
catch (Exception ex)
{
    Console.WriteLine($"Exception: {ex.Message}");
    Console.WriteLine($"IsFaulted: {allTasks.IsFaulted}");
    if(allTasks.Exception is not null)
    {
        foreach (var exception in allTasks.Exception.InnerExceptions)
        {
            Console.WriteLine($"InnerException: {exception.Message}");
        }
    }
}

async Task PrintAsync(string message)
{
    // если длина строки меньше 3 символов, генерируем исключение
    if (message.Length < 3)
        throw new ArgumentException($"Invalid string: {message}");
    await Task.Delay(1000);     // имитация продолжительной операции
    Console.WriteLine(message);
}
```
здесь в два вызова метода `PrintAsync` передаются заведомо некорректные значения. при обоих вызовах будет сгенерирована ошибка.

блок `catch` через переменную `Exception ex` получает одно перехваченное исключение: оператор `await` разворачивает `AggregateException` и пробрасывает одно внутреннее исключение. в выводе программы это сообщение первой задачи. коллекция `Exception.InnerExceptions` содержит информацию обо всех возникших исключениях.

при выполнении этого фрагмента консольный вывод такой:

```consoletext

Exception: Invalid string: H
IsFaulted: True
InnerException: Invalid string: H
InnerException: Invalid string: Hi
```
