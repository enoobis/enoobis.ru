интерфейс есть ссылочный тип, который объявляет функциональность: набор методов и свойств без обязательной реализации. эту функциональность затем реализуют классы и структуры, применяющие интерфейс.

### определение интерфейса

интерфейс вводят служебным словом **interface**. по соглашению имена интерфейсов в c# начинаются с заглавной **I**, например `IComparable`, `IEnumerable` (так называемая венгерская нотация). язык такой префикс не требует: это соглашение о стиле библиотек .net.

интерфейс может объявлять:

- методы

- свойства

- индексаторы

- события

- статические поля и константы (начиная с версии c# 8.0)

нестатические переменные интерфейсу запрещены: экземплярного состояния у него нет. простейший интерфейс, в котором собраны перечисленные виды членов:

```c#


interface IMovable

{

	// константа

	const int minSpeed = 0;     // минимальная скорость

	// статическая переменная

	static int maxSpeed = 60;   // максимальная скорость

	// метод

	void Move();                // движение

	// свойство

	string Name { get; set; }  	// название

	

	delegate void MoveHandler(string message);  // определение делегата для события

	// событие

	event MoveHandler MoveEvent;    // событие движения

}
```

здесь определён интерфейс `IMovable`, который представляет движущийся объект. члены описывают возможности такого объекта: интерфейс задаёт функциональность, которая у движущегося объекта должна быть.

методы и свойства без реализации близки к абстрактным методам и свойствам абстрактных классов. метод `Move` обозначает передвижение: тела нет, параметров нет, результат не возвращается.

свойство `Name` на первый взгляд похоже на автоматическое свойство. в интерфейсе это объявление свойства без реализации. скрытого поля, которое появилось бы у автосвойства класса, здесь нет.

### модификаторы доступа

если у методов и свойств интерфейса модификатор доступа не указан, фактически действует **public**: задача интерфейса в том, чтобы опубликовать функциональность для реализации классом. то же верно для констант и статических переменных. в классах и структурах поле без модификатора получает `private`, в интерфейсе оно получает `public`. к константе `minSpeed` и переменной `maxSpeed` интерфейса `IMovable` обращаются по имени интерфейса:

```c#


Console.WriteLine(IMovable.maxSpeed);	// 60

Console.WriteLine(IMovable.minSpeed);	// 0
```

начиная с версии c# 8.0 модификаторы доступа у компонентов интерфейса можно указывать явно:

```c#


interface IMovable

{

	public const int minSpeed = 0;     // минимальная скорость

	private static int maxSpeed = 60;   // максимальная скорость

	public void Move();

	protected internal string Name { get; set; }  	// название

	public delegate void MoveHandler(string message);  // определение делегата для события

	public event MoveHandler MoveEvent;    // событие движения

}
```

как и классы, интерфейс верхнего уровня по умолчанию имеет уровень доступа **internal**: такой интерфейс доступен только в рамках текущего проекта. модификатор `public` делает интерфейс общедоступным:

```c#


public interface IMovable

{

	void Move();

}
```

### реализация по умолчанию

начиная с версии c# 8.0 интерфейсы поддерживают реализацию методов и свойств по умолчанию. в интерфейсе можно определить полноценные методы и свойства с телом, как в обычных классах и структурах. реализация метода `Move` по умолчанию:

```c#


interface IMovable

{

	// реализация метода по умолчанию

	void Move()

	{

		Console.WriteLine("Walking");

	}

}
```

со свойствами по умолчанию дело сложнее. нестатические переменные в интерфейсе запрещены, поэтому свойство интерфейса не может хранить состояние объекта. вычисляемую реализацию по умолчанию для свойства задать можно:

```c#


interface IMovable

{

	// реализация метода по умолчанию

    void Move() => Console.WriteLine("Walking");

	// реализация свойства по умолчанию

	// свойство только для чтения

	int MaxSpeed { get { return 0; } }

}
```

если у интерфейса есть приватные методы и свойства (модификатор `private`), они обязаны иметь реализацию по умолчанию: снаружи такой член всё равно не реализуют. то же относится к статическим методам, не обязательно приватным: статический член принадлежит самому интерфейсу, и класс его не реализует.

```c#


Console.WriteLine(IMovable.MaxSpeed);   // 60

IMovable.MaxSpeed = 65;

Console.WriteLine(IMovable.MaxSpeed);   // 65

double time = IMovable.GetTime(500, 10);

Console.WriteLine(time);    // 50



interface IMovable

{

    public const int minSpeed = 0;     // минимальная скорость

    private static int maxSpeed = 60;   // максимальная скорость

    // находим время, за которое надо пройти расстояние distance со скоростью speed

    static double GetTime(double distance, double speed) => distance / speed;

    static int MaxSpeed

    {

        get => maxSpeed;

        set

        {

            if (value > 0) maxSpeed = value;

        }

    }

}
```
