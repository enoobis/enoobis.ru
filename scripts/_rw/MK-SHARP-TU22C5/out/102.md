класс `Stack<T>` представляет коллекцию с алгоритмом lifo (last in, first out): последний вошёл, первый вышел. каждый следующий добавленный элемент помещается поверх предыдущего. извлечение идёт в обратном порядке: снимается элемент, который находится выше остальных. в .net стек хранится массивом, вершина расположена в конце занятой части. постановка и снятие вершины занимают в среднем постоянное время.

стек как дисциплина доступа встречается и вне программ. стопка книг или тарелок устроена так же: очередную книгу или тарелку кладут поверх предыдущей, а забирают сначала верхнюю. тот же порядок у одежды. на улицу в зимнюю погоду выходят, сначала надев майку, потом рубашку, затем свитер и в конце куртку. снимают одежду в обратном порядке: сначала куртку, потом свитер и далее.

### создание стека

для создания стека применяется один из трёх конструкторов. пустой стек:

```c#


Stack<string> people = new Stack<string>();
```

при создании пустого стека можно указать ёмкость:

```c#


Stack<string> people = new Stack<string>(16);
```

ёмкость задаёт размер буфера и не помещает в стек элементы. третий конструктор инициализирует стек элементами другой коллекции или массива. перечисление источника кладёт элементы по очереди, поэтому последний перечисленный оказывается на вершине:

```c#


var employees = new List<string> { "Tom", "Sam", "Bob" };

Stack<string> people = new Stack<string>(employees);

foreach (var person in people) Console.WriteLine(person);



Console.WriteLine(people.Count); // 3
```

для перебора стека применяется цикл `foreach`. порядок обхода совпадает с порядком lifo и идёт от вершины ко дну. обход элементы не удаляет. консольный вывод для построенного выше стека:

```consoletext


Bob

Sam

Tom

3
```

число элементов стека даёт свойство `Count`. в выводе оно равно 3 и печатается после цикла: перечислитель стек не разбирает.

### методы `Stack<T>`

в классе выделяются следующие методы:

- `Clear`: очищает стек

- `Contains`: проверяет наличие элемента в стеке и возвращает `true` при его наличии

- `Push`: добавляет элемент на вершину стека

- `Pop`: извлекает и возвращает первый элемент стека, то есть вершину

- `Peek`: возвращает первый элемент стека без его удаления

применение:

```c#


var people = new Stack<string>();

people.Push("Tom");

// people = { Tom }

people.Push("Sam");

// people = { Sam, Tom }

people.Push("Bob");

// people = { Bob, Sam, Tom }



// получаем первый элемент стека без его удаления 

string headPerson = people.Peek();

Console.WriteLine(headPerson);  // Bob



string person1 = people.Pop();

// people = { Sam, Tom }

Console.WriteLine(person1);  // Bob



string person2 = people.Pop();

// people = { Tom }

Console.WriteLine(person2);  // Sam



string person3 = people.Pop();

// people = { }

Console.WriteLine(person3);  // Tom
```

три вызова `Push` кладут на стек `"Tom"`, затем `"Sam"`, затем `"Bob"`. вершина после этого равна `"Bob"`. `Peek` читает её и стек не меняет. каждый `Pop` снимает текущую вершину: `"Bob"`, затем `"Sam"`, затем `"Tom"`.

если `Peek` или `Pop` вызываются у пустого стека, программа завершает вызов исключением. перед получением элемента проверяют число элементов:

```c#


if(people.Count > 0)

{

    var person = people.Peek();

    people.Pop();

}
```

ту же пару действий без исключения на пустом стеке дают два метода:

- `bool TryPop(out T result)`: удаляет из стека первый элемент и передаёт его в переменную `result`. возвращает `true`, если стек не пуст и элемент успешно получен

- `bool TryPeek(out T result)`: передаёт в переменную `result` первый элемент стека без его извлечения. возвращает `true`, если элемент успешно получен

применение методов:

```c#


var people = new Stack<string>();

people.Push("Tom");

// people = { Tom }



// удаляем элементы

var success1 = people.TryPop(out var person1);  // success1 = true

if (success1) Console.WriteLine(person1); // Tom



var success2 = people.TryPeek(out var person2);  // success2 = false

if (success2) Console.WriteLine(person2);
```

`Push` кладёт `"Tom"`. `TryPop` снимает вершину и возвращает `true`, после чего стек пуст. следующий `TryPeek` возвращает `false`, и вывод `person2` не выполняется.
