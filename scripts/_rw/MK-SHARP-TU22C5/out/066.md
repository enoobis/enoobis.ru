с делегатами непосредственно связаны анонимные методы. анонимный метод задаёт тело функции в точке создания экземпляра делегата и не получает отдельного имени в исходном тексте. синтаксис появился в c# 2.0. лямбда-выражения, которые разбираются дальше, связываются с делегатом по тем же правилам соответствия сигнатуре, но записываются короче.

определение начинается со служебного слова **delegate**. далее в скобках идёт список параметров, а тело метода заключается в фигурные скобки:

```c#

delegate(параметры)
{
	// инструкции
}
```

пример связывания с переменной делегата:

```c#

MessageHandler handler = delegate (string mes)
{
    Console.WriteLine(mes);
};
handler("hello world!");

delegate void MessageHandler(string message);
```

анонимный метод не образует самостоятельного члена типа. он существует как тело экземпляра делегата. переменная handler хранит этот экземпляр, и вызов handler передаёт управление в тело анонимного метода.

тот же приём используется, когда анонимный метод передаётся в параметр типа делегата. отдельная именованная переменная тогда не нужна:

```c#

ShowMessage("hello!", delegate (string mes)
{
    Console.WriteLine(mes);
});

static void ShowMessage(string message, MessageHandler handler)
{
    handler(message);
}

delegate void MessageHandler(string message);
```

если список параметров у анонимного метода указан, он обязан совпадать со списком параметров делегата: число, типы и модификаторы передачи. если параметры телу не нужны, скобки со списком опускаются целиком. опустить список можно и тогда, когда делегат принимает несколько параметров: тело просто не именует аргументы и не обращается к ним.

```c#

MessageHandler handler = delegate
{
    Console.WriteLine("анонимный метод");
};
handler("hello world!");    // анонимный метод

delegate void MessageHandler(string message);
```

отсюда два допустимых варианта. указанный список параметров должен совпадать с параметрами делегата. полностью опущенный список делает анонимный метод совместимым с любым делегатом того же возвращаемого типа, у которого нет параметров с модификатором **out**.

опустить параметры нельзя, если хотя бы один параметр делегата объявлен с модификатором **out**. параметр out обязан получить значение в теле метода. при опущенном списке параметр out остаётся без присваивания, и преобразование в делегат отклоняется.

анонимный метод, как и обычный метод, может возвращать значение. тип результата должен совпадать с возвращаемым типом делегата:

```c#

Operation operation = delegate (int x, int y)
{
    return x + y;
};
int result = operation(4, 5);
Console.WriteLine(result);       // 9

delegate int Operation(int x, int y);
```

тело анонимного метода видит переменные объемлющего кода. в следующем фрагменте результат складывается не только из параметров x и y, но и из внешней локальной переменной z:

```c#

int z = 8;
Operation operation = delegate (int x, int y)
{
    return x + y + z;
};
int result = operation(4, 5);
Console.WriteLine(result);       // 17

delegate int Operation(int x, int y);
```

такой захват относится к переменной, а не к копии её значения на момент создания делегата. чтение z происходит при вызове. если между созданием делегата и вызовом переменная изменится, тело увидит уже новое значение. когда время жизни делегата может превысить время жизни кадра, компилятор переносит захваченную переменную в объект замыкания, размещаемый в куче.

анонимный метод уместен там, где действие нужно один раз, тело короткое и отдельно именовать его незачем. типичный случай такой подстановки: обработчик события. события разбираются дальше.
