### форматирование строк

при выводе в консоль метод Console.WriteLine умеет подставлять значения в шаблон. такая подстановка заменяет ручную конкатенацию, когда в фиксированный текст нужно вложить несколько величин:

```c#


string name = "Tom";

int age = 23;



Console.WriteLine("Имя: {0}  Возраст: {1}", name, age);

// консольный вывод

// Имя: Tom  Возраст: 23
```

в шаблоне `"Имя: {0}  Возраст: {1}"` элементы `{0}` и `{1}` являются полями подстановки. на их место по порядку ставятся значения аргументов `name` и `age`. номер в скобках является индексом аргумента. с позицией поля внутри шаблона этот номер прямо не связан, поэтому один и тот же индекс можно использовать несколько раз.

то же составное форматирование доступно в любом месте программы через статический метод **string.Format**:

```c#


string name = "Tom";

int age = 23;

string output = string.Format("Имя: {0}  Возраст: {1}", name, age);

Console.WriteLine(output);
```

`Format` принимает шаблон с полями `{0}`, `{1}` и далее, а затем набор аргументов. метод возвращает новую строку, в которой поля заменены текстовым представлением аргументов. общий вид поля: `{индекс,выравнивание:формат}`. индекс обязателен. выравнивание и формат необязательны. выравнивание задаёт минимальную ширину поля, формат выбирает правило перевода значения в текст.

### спецификаторы форматирования

в форматной части поля допустимы стандартные и настраиваемые описатели. стандартные числовые описатели таковы:

| C / c | задаёт формат денежной единицы и указывает количество десятичных разрядов после запятой |
| --- | --- |
| D / d | целочисленный формат, указывает минимальное количество цифр |
| E / e | экспоненциальное представление числа, указывает количество десятичных разрядов после запятой |
| F / f | формат дробных чисел с фиксированной точкой, указывает количество десятичных разрядов после запятой |
| G / g | задаёт более короткий из двух форматов: F или E |
| N / n | тоже формат дробных чисел с фиксированной точкой, задаёт количество разрядов после запятой и выводит разделители групп |
| P / p | задаёт отображение знака процентов рядом с числом, указывает количество десятичных разрядов после запятой |
| X / x | шестнадцатеричный формат числа |

регистр буквы описателя для большинства числовых форматов на вид числа не влияет. у `X` и `x` регистр различен: `X` печатает шестнадцатеричные цифры в верхнем регистре, `x` в нижнем. число после описателя задаёт точность, и смысл точности зависит от самого описателя.

#### форматирование валюты

для денежной величины используется описатель "C":

```c#


double number = 23.7;

string result = string.Format("{0:C0}", number);

Console.WriteLine(result); // 24 р.

string result2 = string.Format("{0:C2}", number);

Console.WriteLine(result2); // 23,70 р.
```

число после описателя задаёт, сколько знаков стоит после разделителя целой и дробной части. к тексту добавляется знак денежной единицы текущей культуры. и знак, и разделитель, и позиция символа валюты берутся из `CultureInfo.CurrentCulture`, поэтому на разных локалях строка различается. комментарии примера соответствуют культуре, где валюта выводится как «р.», а дробная часть отделяется запятой. точность участвует в округлении: значение 23.7 при нуле знаков после разделителя печатается как 24. при точности 2 дробная часть дополняется до двух знаков и выглядит как 23,70 в той же культуре.

#### форматирование целых чисел

для целых значений применяется описатель "d":

```c#


int number = 23;

string result = string.Format("{0:d}", number);

Console.WriteLine(result); // 23

string result2 = string.Format("{0:d4}", number);

Console.WriteLine(result2); // 0023
```

число после описателя задаёт минимальное количество цифр. если в исходном значении цифр меньше, слева дописываются нули. 23 при формате `d4` превращается в 0023. если цифр больше, чем запрошенная ширина, значение печатается целиком и не обрезается. описатель `d` применяется к целым типам. без числа точности выводится обычная десятичная запись без ведущих нулей.

#### форматирование дробных чисел

описатель F задаёт запись с фиксированной точкой. число после него указывает, сколько знаков стоит после разделителя целой и дробной части. у целого значения дописываются разделитель и нули.

```c#


int number = 23;

string result = string.Format("{0:f}", number);

Console.WriteLine(result); // 23,00



double number2 = 45.08;

string result2 = string.Format("{0:f4}", number2);

Console.WriteLine(result2); // 45,0800



double number3 = 25.07;

string result3 = string.Format("{0:f1}", number3);

Console.WriteLine(result3); // 25,1
```

формат `f` без точности использует точность по умолчанию, для этого описателя это два знака, поэтому 23 печатается как 23,00 в культуре с десятичной запятой. `f4` дополняет 45.08 нулями до четырёх знаков: 45,0800. `f1` оставляет один знак и округляет 25.07 до 25,1. разделитель снова берётся из текущей культуры. описатель `N` относится к той же группе фиксированной точки и дополнительно вставляет разделители групп разрядов, например пробел или запятую тысяч.

#### формат процентов

описатель "P" показывает число как долю и дописывает знак процента. точность задаёт число знаков после запятой уже у процентной записи:

```c#


decimal number = 0.15345m;

Console.WriteLine("{0:P1}", number);// 15,3%
```

перед выводом значение умножается на 100. 0.15345 при точности 1 становится 15,3%. знак процента и разделитель определяются текущей культурой.

#### настраиваемые форматы

символ `#` в форматной строке является позицией необязательной цифры. остальные символы шаблона, если они не являются специальными, копируются в результат как есть. так собирается телефонный номер вида +х (ххх)ххх-хх-хх:

```c#


long number = 19876543210;

string result = string.Format("{0:+# (###) ###-##-##}", number);

Console.WriteLine(result); // +1 (987) 654-32-10
```

шаблон `+# (###) ###-##-##` раскладывает одиннадцать цифр числа 19876543210 по позициям `#` справа налево по группам шаблона и оставляет литералы `+`, пробелы, скобки и дефисы на своих местах. результат: +1 (987) 654-32-10. если цифр меньше, чем знаков `#`, лишние позиции `#` остаются пустыми и не печатают нуль. обязательную цифру с ведущим нулём задавал бы знак `0`, в этом шаблоне он не используется.

### метод ToString

метод `ToString()` возвращает текстовое представление объекта и принимает те же описатели, что и `Format`. числовые типы реализуют разбор форматной строки напрямую:

```c#


long number = 19876543210;

Console.WriteLine(number.ToString("+# (###) ###-##-##"));// +1 (987) 654-32-10



double money = 24.8;

Console.WriteLine(money.ToString("C2")); // 24,80 р.
```

первый вызов применяет настраиваемый телефонный шаблон, второй применяет денежный описатель `C2` и печатает 24,80 с валютой текущей культуры. `string.Format("{0:C2}", money)` и `money.ToString("C2")` используют один и тот же механизм форматов. у `ToString` нет индекса аргумента: формат относится к самому значению, у которого метод вызван.

### интерполяция строк

интерполяция строк является записью того же форматирования внутри литерала. пример с именем и возрастом выглядит так:

```c#


string name = "Tom";

int age = 23;



Console.WriteLine($"Имя: {name}  Возраст: {age}");

// консольный вывод

// Имя: Tom  Возраст: 23
```

знак `$` перед кавычками включает интерполяцию. внутри строки остаются поля `{...}`, но вместо индекса в них записывается выражение. компилятор вычисляет выражения в порядке вхождения и строит результирующую строку. для приведённых вызовов это тот же результат, что у составного формата с `{0}` и `{1}`.

внутри скобок допустимо любое выражение языка c#, в том числе арифметика:

```c#


int x = 8;

int y = 7;

string result = $"{x} + {y} = {x + y}";

Console.WriteLine(result); // 8 + 7 = 15
```

выражение `x + y` вычисляется при построении строки, в текст попадает уже число 15.

в поле можно вызвать метод:

```c#


int x = 8;

int y = 7;

string result = $"{x} * {y} = {Multiply(x, y)}";

Console.WriteLine(result); // 8 * 7 = 56



int Multiply(int a, int b) => a * b;
```

`Multiply` вызывается в момент интерполяции, возвращает 56, и это значение вкладывается в строку. аргументы выражения берутся из окружающей области видимости.

внутри того же поля ставится и описатель формата. набор описателей совпадает с методом `Format`. телефонный номер в виде +x xxx-xxx-xx-xx:

```c#


long number = 19876543210;

Console.WriteLine($"{number:+# ### ### ## ##}"); // +1 987 654 32 10
```

после двоеточия стоит тот же настраиваемый шаблон, что передавался бы в `ToString` или в поле `{0:...}` метода `Format`.

ширина поля задаётся целым числом после запятой. отрицательная ширина выравнивает текст по левому краю и дополняет пробелами справа, положительная выравнивает по правому краю и дополняет пробелами слева:

```c#


string name = "Tom";

int age = 23;



Console.WriteLine($"Имя: {name, -5} Возраст: {age}"); // пробелы после

Console.WriteLine($"Имя: {name, 5} Возраст: {age}"); // пробелы до
```

минимальная ширина для `name` равна 5. значение "Tom" короче, поэтому к нему добавляются два пробела: после текста при ширине -5 и перед текстом при ширине 5. если текст длиннее запрошенной ширины, он печатается целиком, ширина его не обрезает. вывод примера:

```bash


Имя: Том        Возраст: 23

Имя: Том        Возраст: 23
```
