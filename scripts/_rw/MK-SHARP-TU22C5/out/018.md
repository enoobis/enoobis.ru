переменная хранит значение. метод хранит именованную последовательность инструкций и выполняет ее при вызове. с точки зрения выполнения метод является единицей вызова: у него есть точка входа, собственный кадр стека и, при необходимости, возвращаемое значение.

общее определение:

```c#


[модификаторы] тип_возвращаемого_значения название_метода ([параметры])

{

	// тело метода

}
```

модификаторы и параметры необязательны. возвращаемый тип обязателен: если значение не возвращается, на его месте пишут `void`.

ранее уже использовался по меньшей мере один метод, `Console.WriteLine()`. он пишет строку в стандартный вывод. дальше разбирается, как объявлять собственные методы.

### определение метода

пример метода:

```c#


void SayHello()

{

    Console.WriteLine("Hello");

}
```

метод `SayHello` пишет сообщение на консоль. к имени метода предъявляются те же требования, что и к имени переменной: имя является идентификатором. по соглашению имена методов начинают с заглавной буквы.

перед именем стоит возвращаемый тип. `void` означает, что метод не возвращает значение и ограничивается побочным эффектом.

после имени в круглых скобках перечисляют параметры. пустые скобки означают, что параметров нет.

далее идет тело: блок инструкций. у `SayHello` тело состоит из одной инструкции вывода:

```c#
Console.WriteLine("Hello");
```

одного определения недостаточно, чтобы тело выполнилось. метод нужно вызвать. до вызова инструкции тела не исполняются.

### вызов методов

вызов состоит из имени и списка аргументов в скобках. если параметры есть, на их места подставляют аргументы:

```c#


название_метода (значения_для_параметров_метода);
```

вызов `SayHello` выглядит так:

```c#
SayHello();
```

параметров нет, поэтому после имени стоят пустые скобки. скобки обязательны: без них имя обозначает группу методов, а не вызов.

определение и вызовы в одном фрагменте:

```c#


void SayHello()

{

    Console.WriteLine("Hello");

}



SayHello(); // Hello

SayHello(); // Hello
```

консольный вывод программы:

```consoletext


Hello

Hello
```

метод можно вызывать повторно из разных мест программы. в примере `SayHello` вызывается дважды, и тело выполняется дважды. каждый вызов независим: локальные переменные предыдущего вызова к следующему не переходят.

текстовый порядок определения и вызова внутри одной области видимости не важен. член типа виден во всем теле типа, локальная функция видна во всем блоке, где она объявлена. поэтому вызов может стоять в тексте выше определения:

```c#


SayHello(); // Hello

SayHello(); // Hello



void SayHello()

{

    Console.WriteLine("Hello");

}
```

еще три метода. каждый пишет приветствие и ничего не принимает:

```c#


void SayHelloRu()

{

    Console.WriteLine("Привет");

}

void SayHelloEn()

{

    Console.WriteLine("Hello");

}

void SayHelloFr()

{

    Console.WriteLine("Salut");

}





string language = "en";



switch (language)

{

    case "en": 

        SayHelloEn();

        break;

    case "ru":

        SayHelloRu();

        break;

    case "fr":

        SayHelloFr();

        break;

}
```

`SayHelloRu()`, `SayHelloEn()` и `SayHelloFr()` имеют тип `void`, параметров не принимают и пишут строку на консоль. каждый соответствует одному языку приветствия.

инструкция `switch` сравнивает `language` со строковыми константами. переменная условно хранит код языка, и от ее значения выбирается метод. ветвь `case` не проваливается в следующую: `break` завершает ветвь. при значении `"en"` на консоль выводится

```consoletext
Hello
```

### сокращенная запись методов

если тело состоит из одной инструкции, блок можно заменить телом-выражением. исходный вид:

```c#


void SayHello()

{

	Console.WriteLine("Hello");

}
```

сокращенный вид:

```c#
void SayHello() => Console.WriteLine("Hello");
```

после списка параметров стоит `=>`, затем единственная инструкция. так записывают тело именованного метода: имя, возвращаемый тип и параметры остаются в заголовке.
