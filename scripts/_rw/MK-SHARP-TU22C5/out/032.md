каждая переменная в c# связана с областью видимости: участком текста, в котором имя разрешается в конкретное объявление. за пределами этого участка имя не связано с переменной, а для локальной переменной заканчивается и хранение значения. область видимости и время жизни полезно разделять. область видимости описывает, где компилятор видит имя. время жизни описывает, как долго существует значение. локальная переменная живёт в пределах активации метода. поле экземпляра живёт вместе с объектом.

в языке различают несколько контекстов объявления.

- контекст класса. переменная, объявленная на уровне класса, является полем и доступна в любом методе этого класса. такие переменные называют полями, в учебном тексте встречается и название глобальные переменные класса. поле экземпляра хранит состояние конкретного объекта. статическое поле хранит состояние, общее для типа. имя поля входит в область видимости всего тела класса.

- контекст метода. переменная, объявленная в методе, локальна и доступна только в этом методе. в других методах то же имя с этим объявлением не связано.

- контекст блока кода. переменная, объявленная в блоке, тоже локальна и доступна только внутри блока. вне блока она недоступна.

ниже программа объявляет четыре переменные: `type`, `name`, `shortName` и `surname`. у каждой своя область.

```c#


Person tom = new();

tom.PrintName();

tom.PrintSurname();



class Person                            // начало контекста класса

{

    string type = "Person";             // переменная уровня класса

    public void PrintName()             // начало контекста метода PrintName

    {

        string name = "Tom";            // переменная уровня метода



        {                               // начало контекста блока кода

            string shortName = "Tomas"; // переменная уровня блока кода

            Console.WriteLine(type);    // в блоке доступна переменная класса

            Console.WriteLine(name);    // в блоке доступна переменная окружающего метода

            Console.WriteLine(shortName);// в блоке доступна переменная этого же блока

        }                               // конец контекста блока кода, переменная shortName уничтожается



        Console.WriteLine(type);        // в методе доступна переменная класса

        Console.WriteLine(name);        // в методе доступна переменная этого же метода

        //Console.WriteLine(shortName); //так нельзя, переменная c определена в блоке кода

        //Console.WriteLine(surname);     //так нельзя, переменная surname определена в другом методе



    }       // конец контекста метода PrintName, переменная name уничтожается



    public void PrintSurname()      // начало контекста метода PrintSurname

    {

        string surname = "Smith";   // переменная уровня метода



        Console.WriteLine(type);        // в методе доступна переменная класса

        Console.WriteLine(surname);     // в методе доступна переменная этого же метода 

    }       // конец конекста метода PrintSurname, переменная surname уничтожается



}   // конец контекста класса, переменная type уничтожается
```

поле `type` объявлено в классе `Person` и входит в область видимости методов `PrintName` и `PrintSurname`. вложенный блок видит `type` вместе с именами охватывающего метода: вложенная область получает имена внешней.

переменная `name` существует только в рамках `PrintName`. переменная `surname` существует только в рамках `PrintSurname`. из `PrintName` обратиться к `surname` нельзя: объявление находится в другой области, и компилятор это имя там не разрешает.

`shortName` существует только в блоке, границами которого служат открывающая и закрывающая фигурные скобки. после закрывающей скобки имя уничтожается для последующего кода метода, обращение к нему не компилируется. в комментариях примера отмечены два запрещённых обращения: к `shortName` за пределами её блока и к `surname`, объявленной в другом методе.

границы этих контекстов совпадают с фигурными скобками, которые задают блок, тело метода и тело класса. область видимости в c# лексическая: она определяется текстом программы, а не тем, какая функция вызвала текущую во время выполнения.

локальная переменная метода или блока скрывает поле класса, если имена совпадают. скрытие не удаляет поле. простое имя внутри метода связывается с локальной переменной, а поле по-прежнему читается как `this.name`.

```c#


class Person 

{

    string name = "Tom";             // переменная уровня класса

    public void PrintName() 

    {

        string name = "Tomas";      // переменная уровня метода скрывает переменную уровня класса



        Console.WriteLine(name);    // Tomas

    } 

}
```

в `PrintName` простое имя `name` обозначает локальную строку `"Tomas"`. поле класса со значением `"Tom"` этим простым именем уже не читается.

в одном контексте нельзя объявить несколько переменных с одним и тем же именем. для локальных имён правило в c# жёстче, чем в c++ и java: локальное имя занимает весь охватывающий блок, включая вложенные блоки. вложенный блок не может заново объявить имя, которое уже использовано для локальной переменной или параметра снаружи. поле класса при этом скрывать можно: поля и локальные переменные лежат в разных пространствах объявлений, что и показывает пример со скрытием `name`.
