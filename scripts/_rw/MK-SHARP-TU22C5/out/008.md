### консольный вывод

для вывода информации на консоль уже использовался встроенный метод **Console.WriteLine**. если нужно вывести некоторую информацию на консоль, она передаётся в метод `Console.WriteLine`:

```c#


string hello = "Привет мир";

Console.WriteLine(hello);

Console.WriteLine("Добро пожаловать в C#!");

Console.WriteLine("Пока мир...");

Console.WriteLine(24.5);
```

консольный вывод:

```consoletext


Привет мир!

Добро пожаловать в C#!

Пока мир...

24,5
```

`Console.WriteLine` перегружен: аргументом может быть строка, число или значение другого типа. число приводится к строке по правилам текущей культуры, поэтому дробная часть в выводе может отделяться запятой.

нередко возникает необходимость вывести на консоль в одной строке значения сразу нескольких переменных. в этом случае используется приём, который называется интерполяцией:

```c#


string name = "Tom";

int age = 34;

double height = 1.7;

Console.WriteLine($"Имя: {name}  Возраст: {age}  Рост: {height}м");
```

для встраивания отдельных значений в выводимую на консоль строку используются фигурные скобки, в которые заключается встраиваемое значение. это может быть значение переменной (`{name}`) или более сложное выражение (например, операция сложения `{4 + 7}`). перед всей строкой ставится знак доллара $.

при выводе на консоль вместо помещённых в фигурные скобки выражений выводятся их значения:

```consoletext


Имя: Tom  Возраст: 34  Рост: 1,7м
```

интерполяция вычисляет выражения во время выполнения и вставляет их текстовое представление. сам знак `$` в исходном тексте выбирает эту форму литерала на этапе компиляции.

есть другой способ вывода на консоль сразу нескольких значений:

```c#


string name = "Tom";

int age = 34;

double height = 1.7;

Console.WriteLine("Имя: {0}  Возраст: {2}  Рост: {1}м", name, height, age);
```

строка в `Console.WriteLine` содержит числа в фигурных скобках: {0}, {1}, {2}. это плейсхолдеры, вместо которых при выводе строки на консоль подставляются значения. подставляемые значения указываются после строки через запятую. такой вызов использует составное форматирование: строка формата и список аргументов передаются отдельно, а номер в скобках является индексом аргумента.

при этом важен порядок подобных плейсхолдеров. в этом фрагменте после строки первой указана переменная name, потом height и потом age. поэтому значение переменной name вставляется вместо первого плейсхолдера {0} (нумерация начинается с нуля), height вместо {1}, а age вместо {2}. поэтому при выводе на консоль строка

```c#
"Имя: {0}  Возраст: {2}  Рост: {1}м"
```

будет заменена на

```c#
"Имя: Tom  Возраст: 34  Рост: 1,7м"
```

индекс в плейсхолдере не обязан расти слева направо. он выбирает аргумент по позиции в списке, а не по порядку появления скобок в тексте.

#### Console.Write

кроме `Console.WriteLine()` можно использовать метод **Console.Write()**. он работает так же, за тем исключением, что не добавляет переход на следующую строку, то есть последующий консольный вывод будет выводиться на той же строке.

```c#


string name = "Tom";

int age = 34;

double height = 1.7;

Console.Write($"Имя: {name}  Возраст: {age}  Рост: {height}м");
```

различие методов только в завершающем переводе строки. `WriteLine` добавляет его после вывода, `Write` оставляет курсор на текущей строке.

### консольный ввод

кроме вывода информации на консоль можно получать информацию с консоли. для этого предназначен метод **Console.ReadLine()**. он позволяет получить введённую строку.

```c#


Console.Write("Введите свое имя: ");

string? name = Console.ReadLine();

Console.WriteLine($"Привет {name}");
```

здесь всё, что вводит пользователь, с помощью метода `Console.ReadLine()` передаётся в переменную name. пример работы программы:

```bash


Введите свое имя: Том

Привет Том
```

особенность метода `Console.ReadLine()` состоит в том, что он может считать информацию с консоли только в виде строки. кроме того, возможна ситуация, когда для метода `Console.ReadLine` не окажется доступных для считывания строк, то есть когда ему нечего считывать. тогда он возвращает значение **null**, то есть фактически отсутствие значения. чтобы отразить эту ситуацию, переменная `name`, в которую поступает ввод с консоли, определяется как переменная типа **string?**. здесь `string` указывает, что переменная может хранить значения типа string, то есть строки. знак вопроса **?** указывает, что переменная также может хранить значение **null**, то есть по сути не иметь никакого значения. далее `null` и работа с ним разбираются подробнее. аннотация `?` относится к статике обнуляемых ссылок: компилятор считает `null` допустимым значением этого типа и требует учитывать такую возможность в местах, где ссылка разыменовывается.

если нужно ввести возраст в переменную типа int или другую информацию в переменные типа double или decimal, платформа .net по умолчанию предоставляет ряд методов, которые позволяют преобразовать различные значения к типам int, double и так далее. некоторые из этих методов:

- `Convert.ToInt32()` (преобразует к типу int)

- `Convert.ToDouble()` (преобразует к типу double)

- `Convert.ToDecimal()` (преобразует к типу decimal)

пример ввода значений:

```c#


Console.Write("Введите имя: ");

string? name = Console.ReadLine();



Console.Write("Введите возраст: ");

int age = Convert.ToInt32(Console.ReadLine());



Console.Write("Введите рост: ");

double height = Convert.ToDouble(Console.ReadLine());



Console.Write("Введите размер зарплаты: ");

decimal salary = Convert.ToDecimal(Console.ReadLine());



Console.WriteLine($"Имя: {name}  Возраст: {age}  Рост: {height}м  Зарплата: {salary}$");
```

эти методы разбирают строку по правилам текущей культуры и возвращают значение целевого значимого типа. при неразборной строке разбор завершается исключением, то есть ошибка формата обнаруживается во время выполнения, а не во время компиляции.

при вводе важно учитывать текущую операционную систему и её культуру. в одних культурах разделителем между целой и дробной частью является точка (сша, великобритания), в других запятая (россия, германия). например, если текущая ос русскоязычная, дробные числа вводятся с разделителем-запятой. если локализация англоязычная, разделителем целой и дробной части при вводе будет точка.

пример работы программы:

```bash


Введите имя: Том

Введите возраст: 25

Введите рост: 1,75

Введите размер зарплаты: 300,67

Имя: Том  Возраст: 25  Рост: 1,75м  Зарплата: 300,67$
```
