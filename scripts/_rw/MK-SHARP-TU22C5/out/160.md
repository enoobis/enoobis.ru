атрибуты в .net встраивают в сборку дополнительные метаданные. атрибут можно назначить всему типу: классу, интерфейсу, структуре, перечислению, делегату. его же можно назначить отдельному члену: методу, свойству, полю, событию, конструктору. базовый класс всех атрибутов называется `System.Attribute`. в библиотеке .net уже есть большой набор производных атрибутов. помимо них объявляют собственные классы атрибутов: они описывают метаданные других типов и сами по себе код этих типов не исполняют. чтение атрибута выполняется позже, через отражение.

в следующем примере нужно проверять объект пользователя на порог возраста. для порога объявляется собственный атрибут:

```c#


class AgeValidationAttribute : Attribute

{

	public int Age { get;}

    public AgeValidationAttribute() { }

	public AgeValidationAttribute(int age) => Age = age;

}
```

это обычный класс, наследник `System.Attribute`. в нём два конструктора: без параметров и с параметром. второй принимает пороговый возраст и записывает его в свойство `Age`. свойство доступно только для чтения: значение задаётся в конструкторе и дальше не меняется.

атрибут назначается классу:

```c#


[AgeValidation(18)]

public class Person

{

    public string Name { get;}

    public int Age { get; set; }

    public Person(string name, int age)

    {

        Name = name;

        Age = age;

    }

}
```

класс `Person` помечен атрибутом. имя атрибута ставится в квадратных скобках непосредственно перед объявлением класса. суффикс `Attribute` в этом месте можно опустить. записи `[AgeValidation(18)]` и `[AgeValidationAttribute(18)]` обозначают один и тот же атрибут: компилятор ищет тип по обоим именам.

если у атрибута есть конструктор с параметрами (`public AgeValidationAttribute(int age)`), после имени атрибута передаются аргументы этого конструктора. здесь в параметр `age` уходит значение `18`. тем самым у экземпляра `AgeValidationAttribute`, который компилятор поместит в метаданные `Person`, свойство `Age` будет равно `18`. такие аргументы называются позиционными: они сопоставляются параметрам конструктора по порядку.

для свойств атрибута существует и вторая форма, именованные аргументы. она рассчитана на конструктор без параметров: `[AgeValidation(Age = 18)]`. именованный аргумент сопоставляется открытому полю или свойству, у которого есть сеттер. в классе выше у `Age` объявлен только геттер, поэтому именованная форма требует сеттера у `Age` либо открытого поля, куда компилятор сможет записать значение после вызова беспараметрического конструктора.

дальше атрибут читается у типа `Person` и применяется к проверке объектов:

```c#


Person tom = new Person("Tom", 35);

Person bob = new Person("Bob", 16);

bool tomIsValid = ValidateUser(tom);    // true

bool bobIsValid = ValidateUser(bob);    // false



Console.WriteLine($"Результат валидации Тома: {tomIsValid}");

Console.WriteLine($"Результат валидации Боба: {bobIsValid}");



bool ValidateUser(Person person)

{

    Type type = typeof(Person);

    // получаем все атрибуты класса Person

    object[] attributes = type.GetCustomAttributes(false);



    // проходим по всем атрибутам

    foreach (Attribute attr in attributes)

    {

        // если атрибут представляет тип AgeValidationAttribute

        if (attr is AgeValidationAttribute ageAttribute)

            // возвращаем результат проверки по возрасту

            return person.Age >= ageAttribute.Age;

    }

    return true;

}



class AgeValidationAttribute : Attribute

{

	public int Age { get;}

    public AgeValidationAttribute() { }

    public AgeValidationAttribute(int age) => Age = age;

}



[AgeValidation(18)]

public class Person

{

    public string Name { get;}

    public int Age { get; set; }

    public Person(string name, int age)

    {

        Name = name;

        Age = age;

    }

}
```

создаются два объекта: `tom` с возрастом `35` и `bob` с возрастом `16`. `ValidateUser` для первого возвращает `true`, для второго `false`.

метод `ValidateUser` получает объект `Person`. выражение `typeof(Person)` даёт объект `Type`, описывающий класс. `GetCustomAttributes(false)` возвращает атрибуты этого типа. аргумент `false` отключает просмотр базовых классов: в массив попадают только атрибуты, назначенные самому `Person`. далее цикл ищет среди них `AgeValidationAttribute`. если атрибут есть, метод сравнивает `person.Age` с порогом `ageAttribute.Age` и возвращает результат сравнения. пользователь проходит проверку, когда его возраст не меньше порога. если атрибут классу не назначен, метод возвращает `true`: ограничения в метаданных нет, и проверка по возрасту не выполняется.

### ограничение применения атрибута

атрибут `AttributeUsage` ограничивает цели, к которым допускается применять пользовательский атрибут. если `AgeValidationAttribute` должен ставиться только на классы, объявление выглядит так:

```c#


[AttributeUsage(AttributeTargets.Class)]

class AgeValidationAttribute : Attribute

{

//....................................

}
```

допустимые цели задаёт перечисление **AttributeTargets**. у него есть и другие значения:

- `All` : атрибут допускается на всех целях

- `Assembly` : атрибут применяется к сборке

- `Constructor` : атрибут применяется к конструктору

- `Delegate` : атрибут применяется к делегату

- `Enum` : атрибут применяется к перечислению

- `Event` : атрибут применяется к событию

- `Field` : атрибут применяется к полю типа

- `Interface` : атрибут применяется к интерфейсу

- `Method` : атрибут применяется к методу

- `Property` : атрибут применяется к свойству

- `Struct` : атрибут применяется к структуре

значения объединяются побитовым или. атрибут, допустимый и на классах, и на структурах, объявляется так: `[AttributeUsage(AttributeTargets.Class | AttributeTargets.Struct)]`. у `AttributeUsage` есть ещё два свойства. `AllowMultiple` по умолчанию равно `false`: одну и ту же цель нельзя пометить этим атрибутом дважды. `Inherited` по умолчанию равно `true`: атрибут переходит к наследникам цели, если цель это допускает.
