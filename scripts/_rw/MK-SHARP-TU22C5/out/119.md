математические функции стандартной библиотеки .net собраны в классе `Math`. класс статический: экземпляр не создаётся, все методы и константы статические. аргументы тригонометрических методов задаются в радианах, возвращаемые углы обратных функций тоже в радианах. перегрузки есть для нескольких числовых типов. ниже перечислены основные методы в той форме, в которой они обычно вызываются для `double`.

- `Abs(double value)`: абсолютное значение аргумента `value`. есть перегрузки и для остальных числовых типов

```c#


double result = Math.Abs(-12.4); // 12.4
```

- `Acos(double value)`: арккосинус `value` в радианах. область определения: `value` от -1 до 1 включительно. вне этого отрезка результат `NaN`

```c#


double result = Math.Acos(1); // 0
```

- `Asin(double value)`: арксинус `value` в радианах. область определения та же: от -1 до 1
- `Atan(double value)`: арктангенс `value` в радианах
- `BigMul(int x, int y)`: произведение `x * y` в типе `long`. произведение двух `int` может не помещаться в `int`, 64-битный результат сохраняет его без переполнения. в примере результат присваивается `double`: преобразование из `long` в `double` для этого значения точное

```c#


double result = Math.BigMul(100, 9340); // 934000
```

- `Ceiling(double value)`: наименьшее целое с плавающей точкой, которое не меньше `value`. результат остаётся `double` (или `decimal` у соответствующей перегрузки) и направлен от минус бесконечности к плюс бесконечности: `Ceiling(-2.3)` равно `-2`

```c#


double result = Math.Ceiling(2.34); // 3
```

- `Cos(double d)`: косинус угла `d` в радианах
- `Cosh(double d)`: гиперболический косинус угла `d`
- `DivRem(int a, int b, out int result)`: частное от деления `a / b`. остаток записывается в параметр `result`. частное усекается к нулю, как у оператора `/` для целых

```c#


int result;

int div = Math.DivRem(14, 5, out result);

//result = 4

// div = 2
```

- `Exp(double d)`: основание натурального логарифма `e`, возведённое в степень `d`, то есть `e^d`
- `Floor(decimal d)`: наибольшее целое, которое не больше `d`. направление к минус бесконечности. есть перегрузка и для `double`, её вызывает пример ниже. для отрицательных `Floor` и `Truncate` расходятся: `Floor(-2.3)` равно `-3`

```c#


double result = Math.Floor(2.56); // 2
```

- `IEEERemainder(double a, double b)`: остаток от деления `a` на `b` по стандарту ieee 754. частное округляется до ближайшего целого, связь на середине округляется к чётному. оператор `%` усекает частное к нулю. для 26 и 4 оба правила дают 2, потому что 26 равен `4 * 6 + 2` и 6.5 до ближайшего чётного даёт 6

```c#


double result = Math.IEEERemainder(26, 4); // 2 = 26-24
```

- `Log(double d)`: натуральный логарифм числа `d`
- `Log(double a, double newBase)`: логарифм числа `a` по основанию `newBase`
- `Log10(double d)`: десятичный логарифм числа `d`
- `Max(double a, double b)`: большее из `a` и `b`
- `Min(double a, double b)`: меньшее из `a` и `b`
- `Pow(double a, double b)`: число `a`, возведённое в степень `b`
- `Round(double d)`: число `d`, округлённое до ближайшего целого. на середине, когда дробная часть ровно `0.5`, режим по умолчанию `MidpointRounding.ToEven`: выбирается чётное целое. примеры ниже на середину не попадают

```c#


double result1 = Math.Round(20.56); // 21

double result2 = Math.Round(20.46); //20
```

- `Round(double a, int b)`: число `a`, округлённое до `b` знаков после запятой. то же правило середины действует в десятичном разряде, до которого идёт округление

```c#


double result1 = Math.Round(20.567, 2); // 20,57

double result2 = Math.Round(20.463, 1); //20,5
```

- `Sign(double value)`: 1, если `value` положительно, -1, если `value` отрицательно, и 0, если `value` равно 0

```c#


int result1 = Math.Sign(15); // 1

int result2 = Math.Sign(-5); //-1
```

- `Sin(double value)`: синус угла `value` в радианах
- `Sinh(double value)`: гиперболический синус угла `value`
- `Sqrt(double value)`: квадратный корень числа `value`. для отрицательного аргумента результат `NaN`

```c#


double result1 = Math.Sqrt(16); // 4
```

- `Tan(double value)`: тангенс угла `value` в радианах
- `Tanh(double value)`: гиперболический тангенс угла `value`
- `Truncate(double value)`: отбрасывает дробную часть `value` и возвращает целую часть. усечение идёт к нулю, поэтому знак сохраняется и `Truncate(-16.89)` равно `-16`

```c#


double result = Math.Truncate(16.89); // 16
```

класс `Math` определяет две константы: `Math.E`, основание натурального логарифма, и `Math.PI`. площадь круга через них:

```c#


double radius = 50;

double area = Math.PI * Math.Pow(radius, 2);

Console.WriteLine($"Площадь круга с радиусом {radius} равна {Math.Round(area,2)}");

Площадь круга с радиусом 50 равна 7853,98
```
