в предыдущих примерах число параметров метода фиксировалось в объявлении. модификатор `params` задаёт параметр переменной арности: формальный параметр имеет тип одномерного массива, а при вызове на его место допускается произвольное число аргументов.

```c#


void Sum(params int[]  numbers)

{

    int result = 0;

    foreach (var n in numbers)

    {

        result += n;

    }

    Console.WriteLine(result);

}



int[] nums = { 1, 2, 3, 4, 5};

Sum(nums);

Sum(1, 2, 3, 4);

Sum(1, 2, 3);

Sum();
```

параметр с модификатором `params` обязан быть одномерным массивом того типа, значения которого передаются в метод. на его место при вызове можно поставить отдельные значения, готовый массив того же типа элементов либо не передавать аргументы вовсе. число значений заранее не фиксировано, но каждое из них должно быть совместимо с типом элемента. семантика вызова такова: компилятор собирает перечисленные аргументы в новый массив. если аргумент уже является массивом нужного типа, новый массив не создаётся и передаётся та же ссылка. пустой список аргументов соответствует массиву нулевой длины, а не отсутствию параметра.

если у метода есть и обычные параметры, их помещают до параметра с модификатором `params`.

```c#


void Sum(int initialValue, params int[]  numbers)

{

    int result = initialValue;

    foreach (var n in numbers)

    {

        result += n;

    }

    Console.WriteLine(result);

}



int[] nums = { 1, 2, 3, 4, 5};

Sum(10, nums);	// число 10 - передается параметру initialValue

Sum(1, 2, 3, 4);

Sum(1, 2, 3);

Sum(20);
```

у метода `Sum` параметр `initialValue` обязателен, поэтому при каждом вызове для него передаётся значение. первое значение в списке аргументов связывается с `initialValue`, остальные попадают в массив `numbers`. вызов `Sum(20)` передаёт 20 в `initialValue` и пустой массив в параметр `params`. вызов `Sum(10, nums)` передаёт 10 в `initialValue`, а массив `nums` целиком в `numbers`.

после параметра с модификатором `params` другие параметры недопустимы. массив переменной длины замыкает список параметров: иначе сопоставление позиционных аргументов с формальными параметрами было бы неоднозначным. следующее объявление компилятор отвергает.

```c#


//Так НЕ работает

void Sum(params int[] numbers, int initialValue)

{}
```

### массив в качестве параметра

передачу через `params` следует отличать от обычного параметра-массива.

```c#


void Sum(int[] numbers, int initialValue)

{

    int result = initialValue;

    foreach (var n in numbers)

    {

        result += n;

    }

    Console.WriteLine(result);

}



int[] nums = { 1, 2, 3, 4, 5};

Sum(nums, 10);



// Sum(1, 2, 3, 4);     // так нельзя - нам надо передать массив
```

метод `Sum` принимает массив без модификатора `params`, поэтому первый аргумент при вызове обязан быть массивом. отдельными числами такой вызов записать нельзя: без `params` компилятор не собирает аргументы в массив. в отличие от параметра `params`, после параметра-массива могут стоять другие параметры. здесь это `initialValue`, и значение 10 передаётся ему вторым аргументом.
