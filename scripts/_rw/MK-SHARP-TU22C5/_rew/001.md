первая программа на c# собирается из двух частей: текста и компилятора. текст можно набрать в любом редакторе, в том числе в блокноте, который входит в windows. в этой лекции редактором служит visual studio code. он ставится на windows, macos и linux, дистрибутив лежит на странице [загрузить visual studio code](https://code.visualstudio.com/Download).

![c# в visual studio code](/uploads/course-lectures/2db6096eea5aa4235f9b9892b11d9d06702a2f0c.png)

вторая часть, без которой текст не становится программой, это компилятор и сопутствующие утилиты. microsoft поставляет их пакетом **.net sdk**. пакет кроссплатформенный: отдельные сборки есть для основных операционных систем и для основных архитектур процессора. sdk шире одного компилятора. в него входят компилятор c#, среда исполнения, целевые библиотеки и интерфейс командной строки `dotnet`. одной только среды исполнения, без sdk, хватает, чтобы запустить уже собранную программу, но собрать ее из исходников таким набором нельзя.

установщики под windows, macos и linux лежат на официальной странице [https://dotnet.microsoft.com/en-us/download](https://dotnet.microsoft.com/en-us/download).

![загрузка sdk .net](/uploads/course-lectures/f657e611f7bd19bfbaac005ad9b4c4d616a04659.png)

страница сама подставляет варианты sdk под операционную систему, с которой ее открыли. на момент лекции там предлагается 10-я версия .net sdk. для учебы берется самая новая версия, сейчас это .net 10: в ней собраны последние возможности языка и библиотеки. при необходимости рядом ставят и более ранние версии. на той же странице [https://dotnet.microsoft.com/en-us/download](https://dotnet.microsoft.com/en-us/download) собраны sdk под разные архитектуры и системы.
