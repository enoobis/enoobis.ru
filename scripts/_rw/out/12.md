циклы позволяют многократно выполнять некоторое действие, пока выполняется заданное условие. в dart есть следующие виды циклов:

- for

- while

- do...while

- for-each

### цикл for

формальное определение цикла for:

```dart
for (инициализатор; условие; действие)
{
    // тело цикла
}
```

- инициализатор выполняется один раз перед началом цикла и задаёт начальное состояние. как правило, здесь объявляются и инициализируются счётчики, то есть переменные, через которые контролируется выполнение цикла. их область видимости ограничена самим циклом.

- условие определяет, продолжается ли цикл. обычно это операция сравнения. условие проверяется перед каждой итерацией и должно иметь тип `bool`: в отличие от c, ненулевое число истинным здесь не считается. если условие истинно, выполняется тело цикла, а затем `действие`.

- действие выполняется после каждого прохода тела цикла и изменяет параметры цикла, обычно увеличивает счётчик.

стандартный цикл for:

```dart
for (int i = 1; i < 9; i++){
    print("$i * $i = ${i *i} \n");
}
```

первая часть объявления, `int i = 1`, создаёт счётчик i и инициализирует его, так что перед выполнением цикла он равен 1. по сути это обычное объявление переменной.

вторая часть задаёт условие продолжения: цикл выполняется, пока i меньше 9.

третья часть увеличивает счётчик на единицу. шаг может быть любым: счётчик можно уменьшать, `i--`, или изменять иначе.

в итоге тело цикла выполнится 8 раз, пока i не станет равно 9. каждый такой проход называется **итерацией**, и после каждой итерации значение i увеличивается на 1. в dart каждая итерация получает собственную копию переменной цикла, поэтому замыкание, созданное в теле, захватывает значение i именно этой итерации, а не общую переменную, как это было в javascript до появления `let`.

на консоль выводятся квадраты чисел от 1 до 8:

```bash
1 * 1 = 1
2 * 2 = 4
3 * 3 = 9
4 * 4 = 16
5 * 5 = 25
6 * 6 = 36
7 * 7 = 49
8 * 8 = 64
```

указывать все три части заголовка не обязательно, любые из них можно опустить:

```dart
void main (){
    int i = 1;
    for (; i<9;){
        print("$i * $i = ${i *i} \n");
        i++;
    }
}
```

этот пример эквивалентен первому: счётчик по-прежнему есть, но объявлен вне цикла и потому виден и после него, условие выполнения сохраняется, а приращение счётчика перенесено в тело цикла. если опустить и условие, цикл станет бесконечным, и выйти из него можно будет только через `break`, `return` или исключение.

цикл for может объявлять сразу несколько переменных и управлять ими:

```dart
void main (){
      
    for(int i=1, j = 1; i < 10 && j < 10; i++, j++){
			
	    print(i * j);
    }
}
```

здесь объявляются две переменные, i и j. условием служит выражение `i < 10 && j < 10`, а в части действия через запятую перечислены приращения обеих переменных.
