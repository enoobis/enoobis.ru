средства работы с файловой системой и вообще с подсистемой ввода-вывода в dart сосредоточены в библиотеке **dart:io**. для каталогов в ней определён класс **Directory**, который вместе с `File` и `Link` является подтипом абстрактного класса `FileSystemEntity`.

экземпляр Directory создаётся фабричным конструктором, которому передаётся путь к каталогу:

```dart
var myDir = Directory("temp");
```

конструктор лишь связывает объект с путём и не обращается к файловой системе: каталог по этому пути может и не существовать. среди свойств класса Directory прежде всего нужно свойство **path**, возвращающее путь к каталогу.

```dart
import 'dart:io';

void main() {
  var myDir = Directory("temp");
  print(myDir.path);  // temp
}
```

здесь указан относительный путь "temp". он разрешается относительно текущего рабочего каталога процесса, поэтому при запуске из папки проекта каталог temp будет искаться именно в ней. допускается и абсолютный путь:

```dart
import 'dart:io';

void main() {
  var myDir = Directory("D:\hello");
  print(myDir.path);  // D:\hello
}
```

при записи путей windows в обычных строковых литералах нужно помнить, что обратная косая черта начинает escape-последовательность. надёжнее удваивать её (`"D:\\hello"`) или использовать raw-строку (`r"D:\hello"`), в которой экранирование не действует.

статическое свойство **current** даёт текущий рабочий каталог, а статическое свойство **systemTemp** возвращает каталог временных файлов операционной системы (в windows это папка temp пользователя):

```dart
import 'dart:io';

void main() {
  print(Directory.current);
  print(Directory.systemTemp);
}
```

### создание каталога

каталог создаётся методом **create()**:

```dart
Future<Directory> create({bool recursive = false})
```

например, так создаётся папка "hello" в текущем каталоге:

```dart
import 'dart:io';

void main() {
  var myDir = Directory("hello");
  myDir.create();
  print("Folder has been created");
}
```

метод асинхронный и возвращает `Future`, поэтому в этом примере сообщение выводится до фактического завершения операции. если результат нужен дальше по ходу программы, вызов следует предварять `await` или использовать синхронный вариант `createSync()`.

для создания вложенного каталога в метод передаётся параметр `recursive` со значением `true`:

```dart
import 'dart:io';

void main() {
  var myDir = Directory("hello1/temp");
  myDir.create(recursive: true);
  print("Folder has been created");
}
```

здесь создаётся каталог "hello1/temp", причём промежуточный каталог hello1 может отсутствовать: он будет создан автоматически.

### получение содержимого

метод **list()** возвращает содержимое каталога, то есть вложенные каталоги и файлы:

```dart
Stream<FileSystemEntity> list({bool recursive = false, bool followLinks = true})
```

каждый элемент каталога, будь то файл, папка или ссылка, представлен типом **FileSystemEntity**. метод возвращает поток (`Stream`) таких объектов, которые поступают по мере чтения каталога. при `recursive: true` обходится всё поддерево, а `followLinks` определяет, следовать ли символическим ссылкам. пример ниже выводит все папки и файлы в корне диска c:

```dart
import 'dart:io';

void main() async {
  var myDir = Directory("C:\\");
  try{
    await for (var entity in myDir.list()) {
      print(entity.path);
    }
  }
  catch(ex){ print(ex);}
}
```

поток перебирается циклом `await for`. поскольку `list()` возвращает асинхронную последовательность `Stream`, а не `Iterable`, перед for указывается **await**, и сама функция main должна быть помечена как `async`. ошибки доступа, возникающие при чтении каталога, пробрасываются в теле цикла и перехватываются блоком `try-catch`.

свойство `path` объекта FileSystemEntity возвращает полный путь к элементу. результат выполнения на одной из машин выглядит так:

### проверка существования папки

метод **exists()** возвращает `true`, если каталог существует:

```dart
Future<bool> exists()
```

проверка существования нескольких каталогов:

```dart
import 'dart:io';

void main() async {
  print(await Directory("C:\").exists());
  print(await Directory("somefolder").exists());
}
```

в литерале `"C:\"` обратная косая черта экранирует закрывающую кавычку, так что для компиляции этот путь следует записать как `"C:\\"` или `r"C:\"`. кроме того, результат `exists()` отражает состояние файловой системы лишь на момент вызова: между проверкой и последующей операцией каталог может быть создан или удалён другим процессом.

### переименование

каталог переименовывается методом **rename()**:

```dart
Future<Directory> rename(String newPath);
```

параметром служит новый путь, а результатом является новый объект Directory, указывающий на переименованный каталог. исходный объект по-прежнему хранит старый путь, поскольку экземпляры FileSystemEntity неизменяемы и лишь ссылаются на путь. в примере папка "hello" переименовывается в "work":

```dart
import 'dart:io';

void main() async {
  // создаем папку "hello"
  var dir = await Directory("hello").create();
  // переименовываем ее в "work"
  var new_dir = await dir.rename("work");
  print(new_dir.path);  // work
}
```

### удаление

каталог удаляется методом **delete()**:

```dart
Future<FileSystemEntity> delete({bool recursive = false})
```

параметр `recursive` определяет поведение при наличии содержимого. при `true` удаляются и все вложенные файлы и папки. при `false`, что является значением по умолчанию, каталог должен быть пуст, иначе генерируется исключение `FileSystemException`. например, удаление папки "work":

```dart
import 'dart:io';

void main() async {
  var dir = Directory("work");
  await dir.delete();
  print("${dir.path} deleted");  
}
```

### получение статистики по папке

сведения о каталоге возвращает метод **stat()**:

```dart
Future<FileStat> stat()
```

статистика представлена классом **FileStat** со следующими свойствами:

- accessed : время последнего доступа (объект DateTime)

- changed : время последнего изменения данных папки/файла или их метаданных (объект DateTime); в windows это свойство содержит время создания

- modified : время последнего изменения данных папки/файла (объект DateTime)

- size : размер в байтах

- mode : режим файла, то есть биты прав доступа в стиле posix

получение статистики:

```dart
import 'dart:io';

void main() async {
  var dir = Directory.current;
  var stat = await dir.stat();
  print(dir.path); 
  print("Accessed datetime: ${stat.accessed}");  
  print("Modified datetime: ${stat.modified}");  
  print("Size: ${stat.size}");  
}
```
