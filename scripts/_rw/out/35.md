dart позволяет задать поведение ряда встроенных операторов для пользовательских классов, что даёт дополнительные средства работы с объектами. пусть имеется класс Counter:

```dart
class Counter{
	
	int value;
	Counter(this.value);
}
```

класс описывает счётчик, значение которого хранится в поле value.

пусть есть два объекта Counter, два счётчика, которые требуется сравнивать и складывать по значению поля value с помощью стандартных операций сравнения и сложения:

```dart
Counter counter1 = Counter(5);
Counter counter2 = Counter(15);
Counter counter3 = counter1 + counter2;

bool isFirstGreater = counter1 > counter2;
```

по умолчанию ни сравнение, ни сложение для объектов Counter недоступны, и такой код не компилируется. эти операции определены, например, для int, но как складывать объекты классов, введённых разработчиком, dart не знает. для этого соответствующие операторы нужно переопределить в классе.

в dart оператор представляет собой обычный экземплярный метод со специальным именем. переопределение оператора сводится к объявлению в классе, для объектов которого он нужен, метода следующего вида:

```dart
возвращаемый_тип operator оператор(параметр) {  }
```

возвращаемый тип определяет, объект какого типа получится в результате операции. так, при сложении двух объектов Counter естественно ожидать новый объект Counter, а при сравнении двух объектов значение типа bool, показывающее, истинно ли условие. в зависимости от задачи возвращаемый тип может быть любым. вместо имени метода записывается ключевое слово **operator** и сам знак оператора, затем в скобках указывается параметр. левым операндом служит объект, у которого вызывается метод (this), правым операндом служит параметр.

перегрузим оператор сложения для класса Counter:

```dart
void main (){
     
    Counter counter1 = Counter(5);
	Counter counter2 = Counter(15);
	Counter counter3 = counter1 + counter2;
	print(counter3.value);	// 20
}

class Counter{
	
	int value;
	Counter(this.value);
	
	Counter operator +(Counter otherCounter){
		
		return Counter(this.value + otherCounter.value);
	}
}
```

складываются два объекта Counter, поэтому оператор принимает параметр этого же класса. результатом сложения должен быть новый объект Counter, поэтому тот же класс указан и как возвращаемый тип. вся работа оператора сводится к созданию нового объекта, поле value которого равно сумме полей value обоих операндов.

переопределить можно не все операторы dart, а лишь следующие: `<`, `>`, `<=`, `>=`, `==`, `+`, `-`, `*`, `/`, `~/`, `%`, `|`, `&`, `^`, `~`, `<<`, `>>`, `>>>`, `[]` и `[]=`. оператор `!=` отдельно не определяется: выражение `a != b` всегда вычисляется как отрицание `a == b`. составные присваивания вроде `+=` тоже выводятся из соответствующего бинарного оператора. переопределяя `==`, следует согласованно переопределять и геттер hashCode, иначе объекты будут некорректно работать в Set и в качестве ключей Map.

аналогично для класса Counter можно переопределить операторы > и <. операции сравнения возвращают значение типа bool, поэтому и при определении этих операторов возвращаемый тип bool, а фактическое действие оператора сводится к сравнению полей value обоих объектов.

в примерах выше параметр имел тот же тип Counter, но это не обязательно: в зависимости от задачи параметр может иметь любой тип. изменим код следующим образом:

```dart
void main (){
     
    Counter counter1 = Counter(15);
	
	Counter counter2 = counter1 + 25;
	print(counter2.value);	// 40
	
	int diff = counter1 - 7;
	print(diff);	// 8
}

class Counter{
	
	int value;
	Counter(this.value);
	
	Counter operator +(int number){
		
		return Counter(this.value + number);
	}
	
	int operator -(int number){
		
		return this.value - number;
	}
}
```

теперь оператор сложения складывает объект Counter с обычным числом и возвращает новый объект Counter. оператор вычитания вычитает из Counter число и возвращает значение другого типа: разность поля value и вычитаемого. поскольку оператор есть метод левого операнда, выбор реализации определяется только его типом, поэтому запись `25 + counter1` не скомпилируется: у int нет оператора +, принимающего Counter. кроме того, в одном классе нельзя объявить два оператора + с разными типами параметра, так как перегрузки методов по сигнатуре в dart нет.
