функция может принимать параметры. они перечисляются в скобках после имени функции, и каждый параметр объявляется так:

```dart
тип название_параметра
```

ранее уже использовалась функция с параметром, `print()`. через параметр она получает значение и выводит его на консоль, а благодаря параметру одной и той же функции можно передавать разные значения.

```dart

void main() {
	
	print("Hello");
	print(22);
	print("enoobis.ru");
}
```

определим собственную функцию с параметрами, которая складывает два числа:

```dart

void main() {
	
	sum(2, 5);	// 7
}
void sum(int a, int b){
	int c = a + b;
	print(c);
}
```

функция sum принимает два параметра с именами a и b типа `int`. в функции main вызывается sum, и ей передаются два аргумента. аргументы представляют собой значения, которые получают параметры функции. здесь они передаются по позиции: первый аргумент связывается с первым параметром, второй со вторым и так далее. параметр a получает значение 2, параметр b значение 5. передача в dart всегда выполняется по значению, причём для объектов значением является ссылка, поэтому присваивание параметру внутри функции не влияет на переменную вызывающего кода.

число аргументов должно соответствовать числу параметров, а тип каждого аргумента должен быть подтипом типа соответствующего параметра. оба требования проверяются статически, на этапе компиляции. например, определим ещё одну функцию:

```dart

void main() {
	
	printPerson("Tom", 35);
	printPerson("Alice", 29);
}
void printPerson(String name, int age){
	print("Name: $name");
	print("Age: $age \n");
}
```

функция printPerson принимает два параметра: первый типа String, второй типа int. поэтому при вызове сначала передаётся значение типа String, то есть строка, а затем значение типа int, то есть целое число.

тип параметров при определении функции можно не указывать:

```dart

void main() {
	
	printPerson("Tom", 35);
	printPerson(29, "Alice");
}
void printPerson(name, age){
	print("Name: $name");
	print("Age: $age \n");
}
```

в этом случае тип параметров name и age не выводится из передаваемых аргументов: им неявно назначается тип **dynamic**. предыдущее определение функции printPerson равносильно следующему:

```dart

void printPerson(dynamic name, dynamic age){
	print("Name: $name");
	print("Age: $age \n");
}
```

поэтому во втором вызове, `printPerson(29, "Alice")`, параметр name получит значение типа int, а параметр age строку. статически оба параметра имеют тип dynamic, и компилятор не проверяет их использование, а фактический тип значения известен только во время выполнения. за гибкость здесь приходится платить тем, что ошибки типов обнаруживаются лишь при выполнении программы.

### необязательные параметры

часть параметров можно сделать необязательными, то есть допускающими вызов без соответствующих аргументов. такие позиционные параметры заключаются в квадратные скобки. если тип параметра не допускает null, для него нужно указать значение по умолчанию, которое используется, когда аргумент не передан. значение по умолчанию должно быть константным выражением:

```dart

void main() {
	
	printPerson("Tom", 35);
	printPerson("Alice");
}
void printPerson(String name, [int age = 22]){
	print("Name: $name");
	print("Age: $age \n");
}
```

здесь параметр age необязательный. если значение для него не передано, он получает значение 22. консольный вывод:

```bash

Name: Tom
Age: 35

Name: Alice
Age: 22
```

необязательные позиционные параметры должны следовать за обязательными. в примере выше необязательный параметр age идёт после обязательного параметра name.

необязательных параметров может быть несколько, и все они помещаются в одни квадратные скобки:

```dart

void main() {
	
	printPerson("Tom");
}
void printPerson(String name, [int age = 22, String company = "Undefined"]){
	print("Name: $name");
	print("Age: $age");
	print("Company: $company \n");
}
```

здесь два необязательных параметра, age и company. поскольку они позиционные, передать company, не передав age, нельзя.

если необязательный параметр имеет nullable-тип, то есть может принимать значение null, значение по умолчанию можно не указывать: тогда им будет **null**.

```dart

void main() {
	
	printPerson("Tom", 35);
	printPerson("Alice");
}
void printPerson(String name, [int? age]){
	print("Name: $name");
	if(age!=null){
		print("Age: $age \n");
	}
}
```

внутри проверки `age!=null` компилятор сужает тип age с `int?` до `int` (type promotion), поэтому значение можно использовать без дополнительного приведения.

консольный вывод:

```bash

Name: Tom
Age: 35

Name: Alice
```

### именованные параметры

dart поддерживает передачу аргументов по имени. например:

```dart

void main() {
	
	printPerson(name: "Tom", age: 35);
	printPerson(age: 29, name: "Alice");
	printPerson(name: "Kate");
}
void printPerson({String name = "undefined", int age=0}){
	print("Name: $name");
	print("Age: $age \n");
}
```

в определении функции именованные параметры заключаются в фигурные скобки. если тип параметра не допускает значение null, для него указывается значение по умолчанию.

при вызове указывается имя параметра и через двоеточие его значение (`name: "Tom"`), а порядок именованных аргументов произволен. так, во втором вызове сначала передаётся значение для age, а затем для name (`printPerson(age: 29, name: "Alice")`). параметр можно и вовсе не передавать, тогда он получит значение по умолчанию, как параметр age в третьем вызове (`printPerson(name: "Kate")`).

консольный вывод:

```bash

Name: Tom
Age: 35

Name: Alice
Age:29

Name: Kate
Age: 0
```

если параметр имеет nullable-тип, то есть допускает значение null, значение по умолчанию можно не указывать, и тогда им будет null:

```dart

void main() {
     
    printPerson(age: 35);
    printPerson(age: 29, name: "Alice");
    printPerson(name: "Kate");
}
void printPerson({String? name = "undefined", int? age}){
    print("Name: $name");
	if(age != null){
		print("Age: $age \n");
	}
}
```

консольный вывод программы:

```bash

Name: undefined
Age: 35

Name: Alice
Age: 29

Name: Kate
```

### обязательные параметры

именованные параметры по умолчанию необязательны: для них можно задать значение по умолчанию и не передавать их при вызове. иногда же нужно, чтобы параметр был одновременно именованным и обязательным. для этого перед параметром указывается модификатор **required**. например, сделаем обязательным параметр name:

```dart

void main() {
     
    printPerson(age: 29, name: "Alice");
    printPerson(name: "Kate");
    // printPerson(age: 35);   // ! Ошибка - для name надо указать значение
}
void printPerson({required String name, int age = 22}){
    print("Name: $name");
    print("Age: $age\n");
}
```

теперь значение для параметра name обязательно, но передаётся оно по-прежнему по имени. отсутствие обязательного аргумента обнаруживается на этапе компиляции. позиционные и именованные необязательные параметры в одной функции сочетать нельзя: допускается либо список в квадратных скобках, либо в фигурных.

### константы в функциях

через параметры значения передаются локальным переменным функции. их можно передавать и локальным **final**-константам, поскольку значение final определяется во время выполнения и фиксируется при первом присваивании. **const**-константам передать значение параметра нельзя, так как значение const должно быть известно уже во время компиляции. поэтому при разных вызовах функции **final**-константы могут получать разные значения:

```dart

void main() {
	
	printPerson("Tom", 35);
	printPerson("Alice", 22);
}
void printPerson(String userName, int userAge){
	// const int initialAge = userAge; - так нельзя, константа должна определяться на этапе компиляции
	final String name = userName;
	final int age = userAge;
	print("Name: $name   Age: $age \n");
}
```

консольный вывод программы:

```bash

Name: Tom  Age: 35

Name: Alice  Age: 22
```
