в предыдущей теме показано, что интерфейсы позволяют обойти запрет множественного наследования и объединить в одном классе контракты нескольких классов. другой механизм для той же задачи в dart составляют **миксины** (mixins). сначала рассмотрим ситуацию, в которой миксины оказываются предпочтительнее интерфейсов:

```dart
class Worker{
    String company = "";
    void work()=>print("works in $company");
}
class Student{
    String university = "";
    void study() =>print("studies in $university");
}
class WorkingStudent implements Worker, Student{
    
    String name ="";
    @override
    String company = "";
    @override
    String university;
    WorkingStudent(this.name, this.university, this.company);
    @override
    void study() =>print("studies in $university");
    @override
    void work()=>print("works in $company");
}
```

класс WorkingStudent, описывающий работающего студента, реализует два интерфейса: Worker (работающий) и Student (студент). следовательно, он обязан определить все поля и методы, объявленные в Worker и Student. при этом WorkingStudent ничего нового не вносит и лишь повторяет код чужих полей и методов, поскольку implements передаёт только сигнатуры, но не реализацию. миксины решают именно эту проблему: они позволяют повторно использовать реализацию в нескольких иерархиях классов без множественного наследования.

по форме объявления миксин похож на обычный класс, но вводится ключевым словом **mixin**. миксин не может содержать генеративный конструктор. кроме того, миксин не может применять другие миксины и не может наследовать другие классы.

возможны два варианта объявления. если миксин должен также использоваться как обычный класс, он объявляется словами **mixin class**. если требуется **чистый миксин**, используется только **mixin**.

миксины подключаются к классу ключевым словом **with**, после которого перечисляются применяемые миксины:

```dart
mixin class A{}     // класс-миксин
mixin B{}           // чистый миксин
class С with A, B {}    // применение миксинов
```

семантически запись `with A, B` означает линеаризацию: поверх суперкласса последовательно накладывается сначала A, затем B, и каждое такое применение порождает промежуточный анонимный класс. поэтому порядок перечисления существенен: при совпадении имён члены миксина, указанного правее, перекрывают члены указанных левее.

перепишем предыдущий пример с использованием миксинов:

```dart
mixin class Worker{
    String company = "Microsoft";
    void work()=>print("works in $company");
}
mixin Student{
    String university = "Stanford";
    void study() =>print("studies in $university");
}
class WorkingStudent with Worker, Student{
     
    String name;
    WorkingStudent(this.name, String school, String job){
        university = school;
        company = job;
    }
}
void main (){
 
    WorkingStudent tom = WorkingStudent("Tom", "MIT", "Google");
    tom.work();      // works in Google
    tom.study();     // studies in MIT
}
```

Worker и Student выступают здесь в роли миксинов, причём Worker является классом-миксином, а Student чистым миксином. при определении класса WorkingStudent они подключаются оператором **with**:

```dart
class WorkingStudent with Worker, Student{
```

после этого класс WorkingStudent получает поля и методы Worker и Student вместе с их реализацией. WorkingStudent становится также подтипом Worker и Student, и его экземпляр можно передавать туда, где ожидается любой из этих типов.

поскольку Worker объявлен как класс-миксин, его можно использовать и самостоятельно: создавать экземпляры, изменять поля, вызывать методы и т.д., например:

```dart
mixin class Worker{
    String company = "Microsoft";
    void work()=>print("works in $company");
}
void main (){

    Worker bob = Worker();
    bob.work();     // works in Microsoft
    bob.company = "Apple";
    bob.work();     // works in Apple
}
```

для создания объекта Worker вызывается конструктор без параметров. у класса-миксина нет явно объявленных конструкторов, и компилятор предоставляет неявный конструктор по умолчанию.

миксин Student, напротив, объявлен как чистый миксин и может использоваться только через with. попытка создать его экземпляр приводит к ошибке компиляции:

```dart
mixin Student{
    String university = "Stanford";
    void study() =>print("studies in $university");
}

void main (){
 
    Student sam = Student();    // ! Ошибка: Couldn't find constructor 'Student'.
    sam.study();
}
```

### переопределение миксинов

если функциональность, полученная от миксинов, не подходит, её можно переопределить в самом классе:

```dart
mixin class Worker{
    String company = "Microsoft";
    void work()=>print("works in $company");
}
mixin Student{
    String university = "Stanford";
    void study() =>print("studies in $university");
}
class WorkingStudent with Worker, Student{
     
    String name;
    WorkingStudent(this.name, String univer, String job){
        university = univer;
        company = job;
    }
    // переопределяем методы миксинов
    @override
    void work()=>print("$name works in $company");
    @override
    void study() =>print("$name studies in $university");
}
void main (){
 
    WorkingStudent tom = WorkingStudent("Tom", "MIT", "Google");
    tom.work();      // Tom works in Google
    tom.study();     // Tom studies in MIT
}
```

в линеаризованной цепочке тело класса WorkingStudent располагается последним, над всеми применёнными миксинами, поэтому его методы перекрывают методы миксинов.

### сочетание миксинов с наследованием

миксины можно комбинировать с наследованием:

```dart
mixin class Worker{
    String company = "Microsoft";
    void work()=>print("works in $company");
}
class Student{
    String university;
    Student(this.university);
    void study() =>print("studies in $university");
}
class WorkingStudent extends Student with Worker{
     
    String name;
    WorkingStudent(this.name, super.university, String job){
        company = job;
    }
    @override
    void work()=>print("$name works in $company");
    @override
    void study() =>print("$name studies in $university");
}
void main (){
 
    WorkingStudent tom = WorkingStudent("Tom", "MIT", "Google");
    tom.work();      // Tom works in Google
    tom.study();     // Tom studies in MIT
}
```

здесь для примера сущность Student определена как обычный класс, который можно наследовать. суперклассом WorkingStudent служит Student, поверх него применяется миксин Worker, а конструктор WorkingStudent через super-параметр передаёт university в конструктор Student.
