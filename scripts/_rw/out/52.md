для работы с файлами библиотека **dart:io** определяет класс **File**, а для работы с каталогами класс **Directory**. оба являются подтипами `FileSystemEntity`.

экземпляр File создаётся фабричным конструктором, который принимает путь к файлу:

```dart
File(String path)
```

сам `File` объявлен как абстрактный интерфейс, и фабричный конструктор возвращает экземпляр внутренней реализации, специфичной для платформы. определение файла:

```dart
import 'dart:io';		// для работы  с File

void main () {
  File file = File("hello.txt");
	print(file.path);         // hello.txt
}
```

прежде всего для работы с файлами подключается библиотека "dart:io":

```dart
import 'dart:io';
```

в функции main определяется объект File, связанный с файлом "hello.txt".

```dart
File file = File("hello.txt");
```

путь относительный, поэтому он разрешается относительно текущего рабочего каталога: обычно это корневой каталог проекта или, при запуске отдельного скрипта dart, папка, из которой он запущен. существование файла на этом этапе значения не имеет, так как конструктор к файловой системе не обращается, а сам файл будет создан ниже.

из свойств, описывающих файл, в первую очередь используется **path**, возвращающее путь к файлу.

абсолютный путь даёт свойство **absolute**, которое возвращает новый объект File с абсолютным путём:

```dart
import 'dart:io';

void main () {
  File file = File("hello.txt");
	print(file.path);           // hello.txt
  print(file.absolute.path);  // c:\dart\hello.txt
}
```

### создание файла

файл создаётся методом **create()**:

```dart
Future<File> create({bool recursive = false, bool exclusive = false});
```

первый параметр определяет поведение при создании файла в подкаталогах. если `recursive` равен `false`, файл создаётся только при условии, что все каталоги из пути к нему уже существуют. если `recursive` равен `true`, любой отсутствующий каталог из пути создаётся автоматически.

второй параметр задаёт поведение для уже существующего файла. при значении `false` (по умолчанию) существующий файл остаётся нетронутым и ничего не происходит. при значении `true` и существующем файле генерируется исключение FileSystemException, что даёт атомарную проверку отсутствия файла вместе с его созданием.

создание файла "hello.txt" в текущем каталоге:

```dart
import 'dart:io';

void main () async{
  File file = File("hello.txt");
  await file.create();
	print("File has been created");
}
```

если файл создаётся во вложенном каталоге, существование которого заранее неизвестно, в метод следует передать `recursive` со значением `true`:

```dart
import 'dart:io';

void main async() {
  File file = File("somefolder/hello.txt");
  await file.create(recursive:true);
	print("File has been created");
}
```

синтаксически корректная сигнатура асинхронной точки входа записывается как `void main() async`: модификатор `async` ставится после списка параметров.

### копирование файла

копирование выполняет метод **copy()**, которому передаётся путь, по которому будет располагаться копия:

```dart
Future<File> copy(String newPath);
```

результатом является объект File, соответствующий скопированному файлу.

копирование файла "hello.txt" в "work.txt":

```dart
import 'dart:io';

void main () async{
  // сначала создаем файл "hello.txt"
  File file = await File("hello.txt").create();
  // затем копируем его в "work.txt"
  File fileCopy = await file.copy("work.txt");

	print("File ${file.path} has been copied to ${fileCopy.path}");
}
```

### проверка существования файла

метод **exists()** возвращает `true`, если файл существует:

```dart
Future<bool> exists()
```

проверка существования нескольких файлов:

```dart
import 'dart:io';

void main () async{

  print(await File("hello.txt").exists());
  print(await File("somefile.dat").exists());
}
```

### переименование

файл переименовывается методом **rename()**:

```dart
Future<FileSystemEntity> rename(String newPath);
```

параметром служит новый путь. в `FileSystemEntity` метод объявлен с типом `Future<FileSystemEntity>`, а класс File переопределяет его с ковариантным возвращаемым типом `Future<File>`, поэтому результатом является новый объект File. в примере файл "hello.txt" переименовывается в "hello12345.txt":

```dart
import 'dart:io';

void main() async {
  // создаем файл "hello.txt"
  var file = await File("hello.txt").create();
  // переименовываем его в "hello12345.txt"
  var new_file = await file.rename("hello12345.txt");
  print("File ${file.path} renamed to ${new_file.path}");
}
```

исходный объект `file` сохраняет прежний путь, что и видно в выводе.

### удаление

файл удаляется методом **delete()**:

```dart
Future<FileSystemEntity> delete({bool recursive = false})
```

результатом является удалённый файл. для отсутствующего файла генерируется исключение, поэтому перед удалением наличие файла обычно проверяют. проверка и удаление при этом не атомарны, и в конкурентной среде надёжнее перехватывать `FileSystemException`. удаление файла "work.txt":

```dart
import 'dart:io';

void main() async {
  var file = File("work.txt");
  // если файл существует
  if(await file.exists()){
    await file.delete();
    print("${file.path} deleted");
  }  
}
```

### получение статистики по файлу

сведения о файле возвращает метод **stat()**:

```dart
Future<FileStat> stat()
```

статистика представлена классом **FileStat** со следующими свойствами:

- accessed : время последнего доступа (объект DateTime)

- changed : время последнего изменения данных папки/файла или их метаданных (объект DateTime); в windows это свойство содержит время создания

- modified : время последнего изменения данных папки/файла (объект DateTime)

- size : размер в байтах

- mode : режим файла, то есть биты прав доступа в стиле posix

получение статистики:

```dart
import 'dart:io';

void main() async {
  final file = await File("hello.txt").create();
  final stat = await file.stat();
  print(file.path); 
  print("Accessed datetime: ${stat.accessed}");  
  print("Modified datetime: ${stat.modified}");  
  print("Size: ${stat.size}");  
}
```

кроме того, класс `File` предоставляет отдельные методы для получения тех же данных:

- lastAccessed() : возвращает время последнего доступа к файлу в виде объекта `DateTime`

- lastModified() : возвращает время последнего изменения файла в виде объекта `DateTime`

- length() : возвращает размер файла в байтах

применение методов:

```dart
import 'dart:io';

void main() async {
  final file = await File("hello.txt").create();

  print(file.path); 

  final lastAccessed = await file.lastAccessed();
  final lastModified = await file.lastModified();
  final length = await file.length();

  print("Accessed datetime: $lastAccessed");  
  print("Modified datetime: $lastModified");  
  print("Size: $length");  
}
```

каждый из этих методов выполняет отдельный системный вызов, поэтому при необходимости нескольких характеристик сразу один вызов `stat()` дешевле.
