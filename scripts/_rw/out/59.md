при получении каждого очередного запроса от клиента сервер создаёт для него объект типа **HttpRequest**. этот класс реализует интерфейс **Stream**, поэтому экземпляр запроса является потоком для чтения: тело запроса поступает из него асинхронно, порциями байтов.

помимо тела, HttpRequest предоставляет метаданные запроса через ряд свойств:

- `contentLength` : длина тела запроса

- `cookies` : куки, отправленные клиентом, в виде объекта `List<Cookie>`

- `headers` : заголовки запроса (объект HttpHeaders)

- `method` : метод запроса, например, GET, POST, PUT и т.д.

- `requestedUri` : запрошенный адрес в виде объекта Uri

- `response` : объект HttpResponse, ассоциированный с данным запросом и используемый для отправки ответа

- `uri` : запрошенный путь в виде объекта Uri

различие между `uri` и `requestedUri` в полноте адреса: `uri` содержит адрес в том виде, в каком он указан в строке запроса, обычно только путь и строку запроса, а `requestedUri` восстанавливает полный адрес со схемой и хостом. эти сведения используются при обработке запросов. например, в зависимости от запрошенного пути клиенту отправляется тот или иной ответ:

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
  print("Сервер запущен...");
  await server.forEach((HttpRequest request) {

    var responseText = "Page Not Found";
    switch (request.uri.path) {
      case "/":               // если обращение к главной странице
        responseText = "Index Page";
      case "/about":               // если обращение по пути "/about"
        responseText = "About Page";
      case "/contact":               // если обращение по пути "/contacts"
        responseText = "Contacts Page";
    }
    final response = request.response;
    response.write(responseText);
    response.close(); 
  });
}
```

класс `Uri` имеет свойство **path**, хранящее запрошенный путь. в примере выше проверяется именно оно:

```dart
switch (request.uri.path)
```

в зависимости от значения пути выбирается текст, отправляемый клиенту. отдельные значения заданы для путей "/" (главная страница), "/about" и "/contact". при запросе по любому другому пути отправляется текст по умолчанию. в dart 3 непустая ветвь `case` не переходит в следующую, поэтому оператор `break` в конце ветвей не требуется. по сути, это простейшая форма маршрутизации: отображение пути запроса на обработчик.
