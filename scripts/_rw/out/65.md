### паттерн словарей

паттерн словарей сопоставляет словарь (`Map`) с шаблоном, который задаёт шаблоны для значений отдельных ключей. например:

```dart
void main() {
    
    var admin = {"name": "admin",  "email": "admin@hmail.com"};
    var tom = {"name": "Tom",  "email": "tom@hmail.com"};
    var bob = {"email": "bob@hmail.com"};

    print(createMessage(admin));    // Hello Admin!
    print(createMessage(tom));     // Hi Tom
    print(createMessage(bob));     //  Hello World
}

String createMessage(Map data)
{
    return switch(data)
    {
        {"name": "admin"} => "Hello Admin!",   // если name = "admin"
        {"name": var name} => "Hi $name",    // если есть ключ name
        _ => "Hello World"          // в остальных случаях
    };
}
```

функция createMessage получает словарь data и передаёт его в конструкцию switch, которая сопоставляет словарь с рядом шаблонов. первый шаблон требует, чтобы в словаре был ключ "name" со значением "admin":

```dart
{"name": "admin"} => "Hello Admin!",   // если name = "admin"
```

второй шаблон требует только наличия ключа "name", его значение может быть любым. это значение связывается с переменной name, которая затем используется при формировании строки:

```dart
{"name": var name} => "Hi $name",    // если есть ключ name
```

третий шаблон применяется во всех остальных случаях, например когда в словаре нет ключа "name".

в отличие от шаблона списка, шаблон словаря не требует полного совпадения: проверяются только перечисленные в нём ключи, а остальные элементы словаря, например "email", игнорируются. ключи в шаблоне должны быть константами.

### паттерн объектов

паттерн объектов сопоставляет свойства объекта с вложенными шаблонами. например:

```dart
void main() {
    
    var tom = Person("Tom", 38);
    var tomas = Person("Tom", 17);
    var bob = Person("Bob", 42);

    print(createMessage(tom));      // Hello Tom
    print(createMessage(tomas));    // Hello Tomas
    print(createMessage(bob));      //  Hi Bob
}

String createMessage(Person person)
{
    return switch(person)
    {
        Person(name:"Tom", age: >18) => "Hello Tom",   // name = "Tom" и age > 18
        Person(name:"Tom") => "Hello Tomas",           // name = "Tom" и age <= 18
        Person(name: var pname) => "Hi $pname"        // в остальных случаях
    };
}

class Person{
   
    String name;
    int age;
    Person(this.name, this.age);
}
```

в функции createMessage объект класса Person, имеющий два свойства, name и age, сопоставляется с рядом шаблонов. первый шаблон требует, чтобы свойство "name" было равно "Tom", а свойство age было больше 18:

```dart
Person(name:"Tom", age: >18) => "Hello Tom"
```

паттерн объектов, по сути, применяет к свойствам объекта другие паттерны: к свойству name здесь применяется паттерн констант, а к свойству age реляционный паттерн. сначала проверяется, что значение имеет тип Person, затем для каждого указанного свойства вызывается геттер и его результат сопоставляется с вложенным шаблоном. шаблоны произвольно вкладываются друг в друга, что и делает систему паттернов композиционной.

второй шаблон более общий и применяется, если свойство name равно "Tom" (при любом значении age):

```dart
Person(name:"Tom") => "Hello Tomas",
```

третий шаблон применяется во всех остальных случаях: он лишь извлекает значение свойства name в переменную pname. поскольку шаблон `Person(name: var pname)` совпадает с любым экземпляром Person, switch-выражение исчерпывающее и ветвь `_` не нужна.

```dart
Person(name: var pname) => "Hi $pname"
```

подобным образом можно сопоставлять любые доступные свойства объектов, в том числе объектов встроенных классов. например, проверим длину строки:

```dart
void main() {

  print(checkPassword("hello"));        // Invalid password
  print(checkPassword("hello wo"));       // Weak password
  print(checkPassword("hello world"));  // Strong password
}

String checkPassword(String password){
  return switch(password){

    String(length:>10) => "Strong password",
    String(length:>6) => "Weak password",
    _ => "Invalid password"
  };
}
```

здесь проверяется, превышает ли длина строки заданное значение, и в зависимости от результата возвращается то или иное сообщение. свойство `length` класса String является обычным геттером, поэтому для объектного шаблона оно ничем не отличается от свойств пользовательского класса.
