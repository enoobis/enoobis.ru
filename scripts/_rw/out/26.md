### константы классов

помимо обычных полей-переменных класс может определять поля-константы. константное поле экземпляра объявляется с ключевым словом **final**. значение такого поля должно быть установлено до начала выполнения тела конструктора: к этому моменту экземпляр уже считается созданным, и dart гарантирует, что все final-поля к нему инициализированы.

первый способ установить значение константы: присвоить его при объявлении.

```dart
class Person{

	final String name = "Tom";  // константа
	int age = 0;
	
    Person(int age) {
		
        this.age = age;
	}
	
    void display(){
        print("Name: $name \tAge: $age");
    }
}

void main() {

    Person tom = Person(38);  
    tom.display();      // Name: Tom    Age: 38
}
```

здесь поле name, которое представляет имя, объявлено как константа, и при объявлении ему присвоено значение:

```dart
final String name = "Tom";
```

такой способ подходит для значений, известных уже на момент определения класса. для имени он неуместен: разные объекты Person должны иметь разные значения поля name, и требуется лишь, чтобы после инициализации эти значения нельзя было изменить. в примере выше у всех объектов Person поле name одинаково. поэтому используется другой способ: установка константы через список инициализации.

```dart
class Person{

	final String name;  // константа
	int age = 0;
	
    Person(String name, int age) : this.name = name {
		
        this.age = age;
	}
    void display() =>print("Name: $name \tAge: $age");
}

void main() {

    Person tom = Person("Tom", 38);  
    tom.display();      // Name: Tom    Age: 38
    Person bob = Person("Bob", 42);  
    bob.display();      // Name: Bob    Age: 42
}
```

теперь имя, как и возраст, передаётся через конструктор, но устанавливается в списке инициализации, который выполняется **до вызова тела конструктора**

```dart
Person(String name, int age) : this.name = name {
```

благодаря этому можно создавать объекты Person с разными именами.

третий способ: инициализировать константу непосредственно через формальный параметр конструктора.

```dart
class Person{

	final String name;  // константа
	int age = 0;
	
    Person(this.name, int age){
		
        this.age = age;
	}
    void display() => print("Name: $name \tAge: $age");
}

void main() {

    Person tom = Person("Tom", 38);  
    tom.display();      // Name: Tom    Age: 38
    Person bob = Person("Bob", 42);  
    bob.display();      // Name: Bob    Age: 42
}
```

параметр вида `this.name` (initializing formal) автоматически связывает первый аргумент с константой name. семантически это то же присваивание в списке инициализации, только в сокращённой записи:

```dart
Person(this.name, int age){
```

### константные объекты

объекты классов сами могут выступать константами. ключевое слово `final` определяет константы времени выполнения:

```dart
class Person{

	final String name;  // константа
	int age;
	
    Person(this.name, this.age){}
	
    void display() => print("Name: $name \tAge: $age");
}

void main() {

    final Person tom = Person("Tom", 38);  
    // tom = Person("Tomas", 18);  // так нельзя
    tom.age = 22;       // так можно
    tom.display();      // Name: Tom    Age: 22
}
```

здесь `tom` объявлена как константа с помощью ключевого слова **final**

```dart
final Person tom = Person("Tom", 38);
```

final относится к переменной, а не к объекту: неизменяемой становится ссылка. поэтому переменную нельзя связать с другим объектом:

```dart
tom = Person("Tomas", 18);  // так нельзя
```

при этом состояние самого объекта остаётся изменяемым, и поля, не являющиеся константами, например age, можно менять. это то же поведение, что у `final` в java или `readonly` для ссылочного поля в c#:

```dart
tom.age = 22;       // так можно
tom.display();      // Name: Tom    Age: 22
```

### константные конструкторы

класс может содержать константные конструкторы. они предназначены для создания объектов, которые не должны изменяться, и объявляются с ключевым словом **const**. класс с таким конструктором не может содержать изменяемых полей экземпляра, все его поля должны быть final. кроме того, константный конструктор не имеет тела:

```dart
class Person{

	final String name;  // константа
	final int age;      // константа
	
    const Person(this.name, this.age);  // константный конструктор
    void display() => print("Name: $name \tAge: $age");
}

void main() {

    const Person tom = Person("Tom", 38);
    tom.display();      // Name: Tom    Age: 38
}
```

здесь и name, и age объявлены как константы, а единственный конструктор является константным и устанавливает их значения. в программе константный объект определяется с помощью ключевого слова **const**:

```dart
const Person tom = Person("Tom", 38);
```

так создаётся константа времени компиляции. все аргументы константного конструктора в этом случае сами должны быть константными выражениями, а результат вычисляется компилятором. константы канонизируются: два константных выражения с одинаковыми аргументами дают один и тот же экземпляр, поэтому `identical(const Person("Tom", 38), const Person("Tom", 38))` возвращает true. в ряде сценариев это повышает производительность программы. например, фреймворк flutter широко использует константные виджеты (элементы управления) в пользовательском интерфейсе. поскольку flutter знает, что такие виджеты неизменяемы, он может не перестраивать их при повторной сборке дерева и не тратить время на пересчёт и отрисовку соответствующей части макета.
