для хранения данных в dart, как и в других языках программирования, используются переменные. переменная объявляется следующим образом:

```dart
Тип_данных имя_переменной;
```

тип данных задаётся одним из встроенных типов либо типом, определённым программистом. имя переменной представляет собой произвольный идентификатор, который может содержать буквенно-цифровые символы и символ подчёркивания (а также знак $), не может начинаться с цифры и не должен совпадать с ключевыми словами языка: `abstract, else, import, super, as, enum, in, switch, assert, export, interface, sync, async, extends, is, this, await, extension, library, throw, break, external, mixin, true, case, factory, new, try, catch, false, null, typedef, class, final, on, var, const, finally, operator, void, continue, for, part, while, covariant, Function, rethrow, with, default, get, return, yield, deferred, hide, set, do, if, show, dynamic, implements, static`

строго говоря, в этом перечне смешаны несколько категорий. зарезервированные слова (например, `class`, `if`, `var`, `null`) нельзя использовать в качестве идентификатора нигде. встроенные идентификаторы (например, `abstract`, `dynamic`, `static`, `import`) запрещены лишь как имена типов и префиксы импорта, а контекстные ключевые слова (`async`, `sync`, `on`, `show`, `hide`) имеют особый смысл только в определённых синтаксических позициях. тем не менее использовать любые из них как имена переменных не рекомендуется.

например, объявление переменной name типа String:

```dart
String name;
```

для имён переменных принят стиль lowerCamelCase: имя начинается со строчной буквы, а если оно состоит из нескольких слов, первое пишется со строчной, а каждое последующее с прописной буквы, например userAge или oldUserAge.

### значение переменной

операция присваивания связывает с переменной значение, соответствующее её типу. например, тип `String` представляет строки, поэтому переменной этого типа можно присвоить строку:

```dart
void main() {
	String name = "Tom";
	print(name);
	name = "Bob";
	print(name);
}
```

консольный вывод:

```bash
Tom
Bob
```

### var

переменную можно объявить и с помощью ключевого слова **var**:

```dart
var name = "Tom";
```

в этом случае тип переменной выводится компилятором из типа инициализирующего выражения. вывод происходит на этапе компиляции: переменная name получает статический тип String ровно так же, как при явном указании типа. по смыслу это аналог `var` в java и c# или `val`/`var` с выводом типа в kotlin.

ещё один способ объявления переменной состоит в использовании типа **dynamic**.

```dart
dynamic name = "Tom";
```

как и при `var`, переменная получает значение, но в отличие от var, тип dynamic позволяет присваивать ей значения других типов. причина в том, что `dynamic` отключает статическую проверку типов для этой переменной: компилятор не выводит её тип из значения, а допускает любые присваивания и обращения к членам, перенося проверку на время выполнения. например, следующая программа не скомпилируется:

```dart
void main() {
	var name = "Tom";
	print(name);
	name =  45;		// Ошибка!!! name представляет строки, а не целые числа
	print(name);
}
```

здесь по начальному значению переменной name (строка "Tom") для неё выводится тип String, представляющий строки. затем переменной присваивается число 45. это значение не является строкой, то есть не входит в множество допустимых значений типа String, статического типа переменной name, поэтому компилятор сообщает об ошибке ещё до запуска программы. чтобы тип хранимого значения мог меняться динамически, применяется тип **dynamic**. следующая программа выполнится без ошибок:

```dart
void main() {
	dynamic name = "Tom";
	print(name);
	name =  45;
	print(name);
}
```

плата за такую гибкость состоит в потере статических гарантий: ошибки, которые при обычной типизации обнаружил бы компилятор, при dynamic проявятся только во время выполнения.

### const и final

характерное свойство переменной состоит в том, что её значение можно менять сколько угодно раз в ходе выполнения программы:

```dart
void main() {
	var name = "Tom";
	print(name);	// Tom
	name =  "Bob";
	print(name);	// Bob
	name =  "Sam";
	print(name);	// Sam
}
```

если значение менять не требуется или это нежелательно, вместо обычных переменных используются константы. они объявляются с модификаторами **const** и **final**:

```dart
void main (){
	
	const name = "Tom";
	print(name);	// Tom
	//name =  "Bob";	// Ошибка - значение константы нельзя изменять!
}
```

попытка изменить значение константы приводит к ошибке компиляции.

модификатор **final** используется аналогично:

```dart
void main (){
	
	final name = "Tom";
	print(name);	// Tom
	//name =  "Bob";	// Ошибка - значение константы нельзя изменять!
}
```

основное различие между **const** и **final** состоит в том, что значение **const** должно быть известно на этапе компиляции, а значение **final** вычисляется во время выполнения. переменная final допускает ровно одно присваивание, но инициализирующее выражение может быть произвольным. const, напротив, требует константного выражения, то есть такого, которое компилятор способен вычислить сам. разницу хорошо иллюстрирует вывод текущих даты и времени. они получаются выражением `DateTime.now()`. сохраним их в константу и выведем на консоль:

```dart
void main() {
    final today = DateTime.now();
    print(today);
}
```

дата и время сохраняются в константу today, объявленную с ключевым словом `final`, поскольку при каждом запуске программы текущее время разное. иначе говоря, значение определяется **во время выполнения программы**.

если в этом примере заменить `final` на `const`, программа не скомпилируется и не запустится, так как вызов `DateTime.now()` не является константным выражением:

```dart
void main() {
    const today = DateTime.now();	// ! Ошибка
    print(today);
}
```

следует учитывать, что final запрещает лишь повторное присваивание самой переменной: если она ссылается на изменяемый объект, состояние этого объекта менять можно. значение const, напротив, глубоко неизменяемо и канонизируется: одинаковые константные выражения дают один и тот же экземпляр.

при объявлении констант тип можно не указывать, он выводится из значения:

```dart
void main (){
	
	const a = 5;
	print(a);

	final b = 9;
	print(b);
}
```
