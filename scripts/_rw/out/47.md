основной класс для написания асинхронного кода в dart: Future. в этой лекции рассматриваются средства, которые он предоставляет для работы с результатом отложенной операции.

### получение значения из Future и метод then

в момент создания объект Future находится в незавершённом состоянии, а соответствующая операция будет выполнена позднее. чтобы отреагировать на момент перехода Future в завершённое состояние, у класса Future определён метод **then**. метод принимает функцию обратного вызова, которая вызывается при успешном завершении Future. единственным параметром функция получает значение, которым завершился Future.

пример:

```dart


void main() {

    Future<String> future = Future.delayed(

     Duration(seconds: 1),

     () {

        print("Выполнение Future");

        return "Hello Future";  // возвращаем строку

    });

     

    future.then((value){

        print("Из Future получено значение: $value");

    });

   

  print("Завершение функции main");

}
```

работа с Future здесь разбита на два этапа. сначала с помощью конструктора `Future.delayed` определяется задача, которая будет выполнена:

```dart


Future<String> future = Future.delayed(

     Duration(seconds: 1),

     () {

        print("Выполнение Future");

        return "Hello Future";  // возвращаем строку

    });
```

задача выводит на консоль строку и возвращает строку, поэтому future имеет тип `Future<String>`. выполняется она с задержкой в одну секунду.

на втором этапе вызывается метод `then()`:

```dart


future.then((value){

    print("Из Future получено значение: $value");

});
```

в метод `then()` передаётся функция обратного вызова с параметром value, через который она получает значение, возвращённое задачей. сама функция просто выводит полученное значение на консоль. в результате консольный вывод таков:

```bash


Завершение функции main

Выполнение Future

Из Future получено значение: Hello Future
```

метод `then` регистрирует обработчик и сразу возвращает управление, поэтому строка из конца main выводится первой. аналогичным образом получают значения других типов: int, double и т.д. статический тип параметра value выводится из параметра типа объекта Future, здесь это String.

для `Future<void>` значение не несёт информации, и вместо имени параметра принято указывать символ подчёркивания:

```dart


void main() {

	Future<void> future = Future.delayed(

		Duration(seconds: 1), 

		() => print("Hello Future"));		// возвращаемый тип - void

	

	future.then((_) {	// прочерк вместо параметра для типа void

		print("Выполнение Future завершено");

	});

  

  print("Завершение функции main");

}
```

консольный вывод:

```bash


Завершение функции main

Hello Future

Выполнение Future завершено
```

### цепочки обратных вызовов

вызовы then можно объединять в цепочки, звенья которых выполняются последовательно:

```dart


void main() {



	Future<String> future = Future.delayed(

          Duration(seconds: 1), 

          () => "Hello Future"     // возвращаем строку

    );

	

	future.then((value){

		print("Из Future получено значение: $value");

		return 22;

	})

	.then((value) => print("Выполнение Future завершено. Получено: $value") );

  

  print("Завершение функции main");

}
```

функция из первого вызова then получает результат Future, строку, и выводит её на консоль. кроме того, она возвращает новый результат, для примера число 22.

функция из второго вызова then получает именно это число, а не исходное значение Future. дело в том, что then возвращает новый объект Future, который завершается результатом переданной функции, поэтому параметром функции в каждом следующем then служит результат функции из предыдущего then. если функция в then сама возвращает Future, следующее звено дождётся его завершения и получит его значение. в теории это соответствует монадической операции связывания (bind), той же, что лежит в основе цепочек promise в javascript и `thenCompose` в java.

консольный вывод:

```bash


Завершение функции main

Выполняется Future

Из Future получено значение: Hello Future

Выполнение Future завершено. Получено: 22
```

вторая строка этого вывода, "Выполняется Future", в приведённой программе на самом деле не печатается: функция в `Future.delayed` здесь только возвращает строку, ничего не выводя.

### обработка ошибок

при выполнении операции, которую представляет Future, может возникнуть ошибка. тогда Future переходит в завершённое состояние, храня вместо значения информацию об ошибке. для её получения служит метод **catchError()**, устроенный аналогично `then`: он тоже принимает функцию обратного вызова, в которую передаётся объект ошибки:

```dart


void main() {



	Future<String> future = Future.delayed(

        Duration(seconds: 1), 

        () { 

            print("Выполняется Future");

            throw "Непредвиденная ошибка"; 

        }

    );	

	

	future.then((value){

		print("Из Future получено значение: $value");

	})

	.catchError((err) => print(err) );

  

  	print("Ждем получения значения из Future");

}
```

здесь в функции, переданной конструктору Future, генерация ошибки эмулируется оператором throw (`throw "Непредвиденная ошибка";`). объектом ошибки служит обычная строка ("Непредвиденная ошибка"), и именно она передаётся через параметр err в функцию catchError.

в результате функция из then не вызывается, а вызывается функция из catchError, поскольку при выполнении Future произошла ошибка. ошибка проходит мимо звена then и распространяется по цепочке до первого обработчика, подобно тому как исключение поднимается по стеку вызовов до ближайшего блока catch. консольный вывод:

```bash


Ждем получения значения из Future

Выполняется Future

Непредвиденная ошибка
```

вторым, необязательным именованным параметром test метод catchError принимает предикат, который проверяет объект ошибки на соответствие условию и возвращает true, если ошибка ему удовлетворяет, и false в противном случае. если предикат возвращает false, функция из первого параметра не вызывается и ошибка распространяется дальше по цепочке.

пример:

```dart


void main() {

     Future<String> future = Future.delayed(

          Duration(seconds: 1), 

          () { 

               print("Выполняется Future");

               throw 404;

          }

     );	

     

     future.then((value){

        print("Из Future получено значение: $value");

     })

     .catchError((err) {

        print("Код ошибки: $err");

     }, 

     test: (err) {

        return err is int;

     });

   

     print("Ждем получения значения из Future");

}
```

выражение `throw 404` означает, что объектом ошибки является число 404, то есть значение типа int.

второй параметр catchError, функция `(err) { return err is int; }`, получает объект ошибки через параметр err и выражением `err is int` проверяет, является ли он экземпляром int. если является, возвращается true и выполняется функция `(err) { print("Код ошибки: $err");}`. по смыслу это аналог перехвата исключения конкретного типа в `on int catch (e)` синхронного кода.

в этом случае консольный вывод следующий:

```bash


Ждем получения значения из Future

Выполняется Future

Код ошибки: 404
```

если же ошибку сгенерировать так:

```dart
throw "404";
```

то передаваться будет строка, а не число, выражение `return err is int` для такой ошибки вернёт false, и ошибка не будет обработана. она останется необработанной асинхронной ошибкой и будет передана обработчику ошибок текущей зоны, который по умолчанию сообщает о ней как о неперехваченном исключении.

### метод whenComplete

метод **whenComplete** выполняет функцию при завершении Future независимо от того, завершился он значением или ошибкой. в цепочке ниже эта функция выполняется после функций из then и catchError. по семантике это асинхронный аналог блока finally. пример:

```dart


void main() {

    Future<String> future = Future.delayed(

        Duration(seconds: 1), 

        () { 

            print("Выполняется Future");

            return "Hello Dart";

        }

    );	

     

    future.then((value){

        print("Из Future получено значение: $value");

    })

    .catchError((err) {

        print("Ошибка: $err");

    })

    .whenComplete(() { print("Future завершил свою работу"); });

   

    print("Ждем получения значения из Future");

}
```

консольный вывод:

```bash


Ждем получения значения из Future

Выполняется Future

Из Future получено значение: Hello Dart

Future завершил свою работу
```
