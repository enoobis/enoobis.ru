### анонимные функции

анонимная функция (функциональный литерал, лямбда-выражение) отличается от обычной функции только отсутствием имени. например:

```dart
void main() {
	
	Function sum = (a, b) => a + b;
	print(sum(4, 5));		// 9
	print(sum(6, 5));		// 11
}
```

переменной sum присваивается ссылка на анонимную функцию `(a, b) => a + b`, которая принимает два параметра и возвращает сумму их значений. типы параметров здесь не указаны, поэтому они выводятся как dynamic, и операция `+` разрешается во время выполнения.

в этом примере анонимная функция записана в сокращённой форме с `=>`, где тело состоит из одного выражения. ту же функцию можно записать в полной форме с блоком:

```dart
void main() {
	
	Function sum = (int a, int b)
	{
		print("Sum of $a and $b");
		return a + b;
	};
	print(sum(4, 5));
}
```

анонимные функции особенно уместны, когда вызывается функция высшего порядка, принимающая другую функцию. для функции-аргумента проще записать литерал на месте вызова, чем объявлять именованную функцию, особенно если она больше нигде не нужна:

```dart
void main() {
	
    operation(10, 4, (a, b)=>a + b);    // 14
    operation(10, 4, (a,b)=>a - b);     // 6
    operation(10, 4, (a, b) => a * b);  // 40
}

void operation(int a, int b, Function op)
{
    print(op(a, b)); 
}
```

функция operation третьим параметром принимает функцию, которая выполняет действие над двумя числами и возвращает результат. вместо того чтобы объявлять отдельные функции, которые больше нигде не используются, в operation напрямую передаются анонимные функции. если бы параметр op имел функциональный тип `int Function(int, int)`, типы параметров литералов вывелись бы из контекста как int и вызов проверялся бы статически.

анонимные функции также можно возвращать из функции:

```dart
void main() {
     
    Function action = select(1);  // сложение
    print(action(8, 5)); // 13

    action = select(2);  // вычитание
    print(action(8, 5)); // 3

    action = select(3);  // умножение
    print(action(8, 5)); // 40
}
Function select(int choice)
{
    // возвращаем нужную функцию в зависимости от choice
    switch (choice)
    {
        case 2:
            return (a, b) => a - b;
        case 3:
            return (a, b) => a * b;
        default:
            return (a, b) => a + b;
    }
}
```

### вложенные функции

в dart функции могут быть объявлены внутри других функций. такие функции называются локальными:

```dart
void main() {
	
	void hello(){
		print("Hello!");
	}
	
	hello();
	hello();
}
```

объявление вложенной функции должно предшествовать её вызову: локальная функция, как и локальная переменная, видна только после точки объявления. вложенные функции оправданы, когда повторяющиеся действия нужны лишь внутри одной определённой функции, и их не следует выносить в область видимости библиотеки.

вложенные функции сами могут содержать вложенные функции:

```dart
void main() {
	
	void showMessage(){
		void hello(){
			print("Hello!");
		}
		
		hello();
		hello();
	}
	
	showMessage();
}
```

каждая вложенная функция образует собственную область видимости: объявленные в ней переменные и константы недоступны внешней функции. видимость в dart лексическая и направлена изнутри наружу, поэтому вложенная функция видит переменные объемлющей функции, но не наоборот. например:

```dart
void main() {
     
    void welcome(){
		var message = "Welcome!";
        print(message);
    }
     
	print(message);	// ! Ошибка - внешняя функция не может обращаться к переменным вложенных функций.
}
```

переменная message объявлена внутри функции welcome, поэтому обращаться к ней можно только в пределах этой функции. обращение вне её является ошибкой времени компиляции: идентификатор не разрешается в текущей области видимости.
