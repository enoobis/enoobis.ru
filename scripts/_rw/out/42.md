начиная с версии 3.0 в языке dart появились записи, **records**. запись представляет анонимный неизменяемый агрегатный тип, который, подобно коллекциям, позволяет объединить несколько объектов в один объект. в отличие от коллекций, записи имеют фиксированный размер, могут хранить значения разных типов и при этом типизированы поэлементно: тип каждой позиции известен статически. в других языках программирования аналогичная структура данных называется **кортежем**, а с точки зрения теории типов запись соответствует типу-произведению.

простейший кортеж определяется так:

```dart
void main() {

  var person = ("Tom", 38);
  print(person);    // ("Tom", 38)
}
```

здесь определён кортеж person из двух элементов: строки "Tom" и целого числа 38. для определения кортежа используются круглые скобки, внутри которых через запятую перечисляются элементы. содержимое кортежа можно вывести функцией print.

кортежи типизированы: тип кортежа определяет, данные каких типов и в какой последовательности он содержит. в примере выше кортеж объявлен через ключевое слово **var**, и его тип выводится автоматически из присваиваемого значения. тип можно указать и явно:

```dart
void main() {

  (String, int) person = ("Tom", 38);
  print(person);
}
```

кортеж `("Tom", 38)` имеет тип `(String, int)`. тип кортежа также записывается в круглых скобках, внутри которых перечисляются типы элементов. порядок существенен: тип `(String, int)` означает, что первым идёт строка и только затем число, а не наоборот. поэтому следующее определение ошибочно и отвергается уже на этапе компиляции:

```dart
(String, int) person = (22, "Tom");  // ! Ошибка
```

типы записей структурны, в отличие от номинальных типов классов: два типа записей совпадают, если у них одинаковые типы позиционных полей и одинаковый набор именованных полей с одинаковыми типами, и объявлять такой тип заранее не нужно. для записей также действует ковариантность по полям, так что `(int, int)` является подтипом `(num, num)`.

аналогично определяются кортежи с большим количеством элементов:

```dart
void main() {

  (String, int, String) person = ("Tom", 38, "Google");
  print(person);
}
```

### обращение к элементам кортежа

по умолчанию к элементам кортежа обращаются по их номерам с префиксом **$**, нумерация начинается с 1:

```dart
void main() {

  var person = ("Tom", 38);
  print(person.$1);   // Tom
  print(person.$2);   // 38
}
```

выражение `person.$1` обращается к первому элементу кортежа person, а `person.$2` ко второму. технически `$1` и `$2` являются геттерами, которые компилятор генерирует для каждого позиционного поля, и поскольку записи неизменяемы, сеттеров у них нет.

элементам кортежа можно также дать имена:

```dart
void main() {

  var person = (name:"Tom", age:38);
  print(person.name);   // Tom
  print(person.age);   // 38
}
```

в этом случае сначала указывается имя, затем через двоеточие значение элемента. тип такого кортежа записывается как `({int age, String name})`, именованные поля в нём заключаются в фигурные скобки:

```dart
void main() {

  ({int age, String name}) person = (name:"Tom", age:38);
  print(person.name);   // Tom
  print(person.age);   // 38
}
```

для именованных элементов порядок роли не играет: типы `({int age, String name})` и `({String name, int age})` совпадают. именованные и позиционные элементы можно комбинировать. в типе такой записи именованные поля в фигурных скобках идут после позиционных, например `(String, {int age})`, и в литерале их принято располагать так же:

```dart
void main() {

  var person = ("Tom", age:38);
  print(person.$1);   // Tom
  print(person.age);   // 38
}
```

### применение кортежей

основной сценарий применения кортежей связан с возвратом нескольких значений из функции. до появления записей функция в dart возвращала только одно значение, и для возврата нескольких значений их приходилось упаковывать в другие структуры, например в списки, теряя при этом типизацию отдельных элементов, либо объявлять отдельный класс для хранения таких множественных значений. кортежи решают эту задачу без лишних объявлений:

```dart
void main() {

  var person = defaultPerson();
  print(person);  // ("Tom", 22)
}

(String, int) defaultPerson(){
  
  return ("Tom", 22);
}
```

для простоты функция defaultPerson возвращает кортеж из двух элементов. в функции main её результат присваивается переменной person. в dart 3 такой результат можно сразу разложить на переменные с помощью деструктурирующего образца: `var (name, age) = defaultPerson();`.

функция может возвращать и кортеж с именованными элементами:

```dart
void main() {

  var person = defaultPerson();
  print(person.name);  // ("Tom", 22)
}

({String name, int age}) defaultPerson(){
  
  return (name:"Tom", age:22);
}
```

другой сценарий связан с передачей в функцию нескольких значений, которые объединяются в один кортеж:

```dart
void main() {

  createPerson(("Bob", 42));
}

void createPerson((String, int) data){
  print("Name: ${data.$1}");
  print("Age: ${data.$2}");
}
```

передача кортежа с именованными элементами:

```dart
void main() {

  createPerson((name:"Sam", age:27));
}

void createPerson(({String name, int age}) data){
  print("Name: ${data.name}");
  print("Age: ${data.age}");
}
```

### сравнение кортежей

кортежи сравниваются по значению, поэлементно в порядке следования элементов, а не по ссылке, как обычные объекты классов. операция `==` даёт true, если у двух записей одинаковая форма (одинаковое число позиционных полей и одинаковый набор имён) и соответствующие поля попарно равны. `hashCode` согласован с этим равенством, поэтому записи можно использовать как ключи словаря:

```dart
void main() {

  var person = ("Tom", 38);
  var tom = ("Tom", 38);
  var tomas = (name:"Tom", age:38);

  print(person == tom);     // true
  print(person == tomas);   // false
}
```

кортежи person и tom равны, хотя являются разными объектами. кортеж tomas с теми же значениями не равен person, поскольку его поля именованные и форма записи отличается.
