программы на dart можно писать в текстовом редакторе, а запускать и компилировать из консоли, однако на практике чаще используется интегрированная среда разработки. она предоставляет автодополнение, навигацию по коду, отображение ошибок статического анализатора по мере набора и встроенный запуск программ. для разработки на dart подходит среда intellij idea компании jetbrains. по умолчанию поддержки dart в ней нет, но она подключается через плагин. ниже описана последовательность настройки.

сначала на сайте среды открывается страница загрузки по адресу [https://www.jetbrains.com/idea/download/](https://www.jetbrains.com/idea/download/). среда доступна для windows, macos и linux. существуют бесплатный выпуск community и платный ultimate. в курсе используется бесплатный выпуск intellij idea community, возможностей которого для работы с dart достаточно; при желании и наличии лицензии можно использовать и ultimate:

![установка intellij idea community для dart](/uploads/course-lectures/2edb3815beeffa98f383f258053f0d597eb89a3e.png)

помимо среды требуется dart sdk: плагин лишь интегрирует в ide инструменты sdk, а сам компилятор, анализатор и виртуальная машина поставляются с sdk. zip-архив с sdk загружается с адреса [https://dart.dev/get-dart/archive](https://dart.dev/get-dart/archive) и распаковывается на жёсткий диск.

![установка dart sdk](/uploads/course-lectures/9b6e3e282447e91a80c81ef1e6b9d52d5b005341.png)

на странице загрузки есть пакеты для windows, linux и macos. кроме того, доступны разные каналы сборок: бета-сборки и сборки для разработчиков (dev). в курсе используется стабильная сборка, рекомендуемая для разработки, поэтому пакет выбирается в секции "stable channel".

после установки intellij idea запускается, и на стартовом экране открывается пункт **plugins**. в строке поиска на этой вкладке вводится слово "dart", и первым в результатах должен оказаться плагин для dart, который и следует установить.

![установка плагина dart в intellij idea community](/uploads/course-lectures/d073a10af52084697ec462a67ed0499f3d635a7c.png)

после установки плагина открывается пункт **projects**, и на этой вкладке нажимается кнопка **new project** для создания нового проекта:

![первый проект для dart в intellij idea community](/uploads/course-lectures/868ec593245e358e6a93cbb6c6b3404a2a94f3a2.png)

в следующем окне выбирается пункт **dart**, а в центральной части указывается путь к dart sdk:

![первый проект для dart sdk в intellij idea community](/uploads/course-lectures/a45aa88f245dd03f75bc957134b3096a6df2e26e.png)

далее в поле **project name** вводится имя проекта, в примере HelloApp, а в поле **project location** при необходимости указывается каталог проекта, если путь по умолчанию не подходит:

![первый проект для dart sdk в intellij idea community](/uploads/course-lectures/b7d6cd117e1ae961aa4ac8df3f860ff083bb274f.png)

остальные настройки остаются по умолчанию, и проект создаётся нажатием кнопки finish.

созданный проект по умолчанию пуст, поэтому в него добавляется файл кода. для этого в контекстном меню проекта (правая кнопка мыши на его названии) выбирается пункт **new -> dart file**:

![добавление файла кода dart в intellij idea](/uploads/course-lectures/04356dde41db986aff65f70a558c21b853979fce.png)

в появившемся окне вводится имя файла, например **main**:

![добавление файла кода на dart в intellij idea](/uploads/course-lectures/f7d767bd282d136f68313d4a83975f16a46653a3.png)

в файл помещается следующий простейший код:

```dart
void main() {
  print("Hello, enoobis.ru!");
}
```

![первая программа на языке dart в intellij idea](/uploads/course-lectures/86a8a6c33e8efe3401dadf23e878299559ebdcae.png)

любая исполняемая программа на dart обязана содержать функцию с именем **main**, которая служит точкой входа. в этом примере её возвращаемый тип **void**, а параметров она не принимает, поэтому после имени стоят пустые скобки.

тело функции заключается в фигурные скобки. здесь в функции main вызывается другая функция, **print()**, которая выводит на консоль переданную строку, в данном примере "Hello, enoobis.ru!".

для запуска программы в контекстном меню файла main.dart (правая кнопка мыши) выбирается пункт **run main.dart**:

![запуск проекта на dart в intellij idea](/uploads/course-lectures/b0d364502824d278466980955bedae4972fb8647.png)

после этого в нижней части ide открывается окно с результатами работы программы.

![запуск проекта на dart в intellij idea 2](/uploads/course-lectures/f5b87e4f9bbbbca5a0c12cfb3778468f7663962b.png)

при этом ide создаёт конфигурацию запуска, и в дальнейшем проект запускается кнопкой с зелёной стрелкой на панели инструментов.
