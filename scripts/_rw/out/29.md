наследование относится к основным механизмам объектно-ориентированного программирования: оно позволяет одному классу перенимать состояние и поведение другого и одновременно устанавливает между ними отношение подтипа. в dart наследование реализуется с помощью ключевого слова **extends**. сначала рассмотрим, зачем оно нужно, на примере следующей программы:



```dart

void main (){
     
    Person tom = Person();
    tom.name = "Tom";
    tom.age = 38;
    tom.display();  // Name: Tom  Age: 38

    Employee bob = Employee();
    bob.name = "Bob";
    bob.age = 42;
    bob.display();  // Name: Bob  Age: 42
} 
 
class Person{
  
    String name = "";
    int age = 0;
    void display() => print("Name: $name  Age: $age");
}
class Employee{
    String name = "";
    int age = 0;
    String company = "";
    void display() => print("Name: $name  Age: $age");
}
```



здесь класс Person представляет человека, а класс Employee представляет работника некоторой компании. оба класса работают корректно, но функциональность Person полностью дублируется в Employee, и с точки зрения типов эти классы никак не связаны. наследование позволяет устранить дублирование кода.



применим наследование:



```dart

void main (){
     
    Employee bob = Employee();
    bob.name = "Bob";
    bob.age = 42;
    bob.display();  // Name: Bob  Age: 42
} 
 
class Person{
  
    String name = "";
    int age = 0;
    void display() => print("Name: $name  Age: $age");
}
class Employee extends Person{
    String company = "";
}
```



теперь класс Employee наследуется от класса Person. для этого после имени класса указывается ключевое слово **extends**, а за ним класс, от которого идёт наследование.

```dart
class Employee extends Person{
```

при наследовании класс Employee получает всю функциональность класса Person, все его поля и методы, и может их использовать. в подклассе можно также определить новые поля и методы, которых нет в Person. код стал заметно проще, а у объекта Employee по-прежнему доступны поля name и age и метод display, хотя они определены в родительском классе Person. кроме того, Employee становится подтипом Person, и его экземпляр можно использовать везде, где ожидается Person. dart поддерживает только одиночное наследование реализации: у класса может быть ровно один суперкласс, а если extends не указан, суперклассом неявно является Object.



в этом случае класс Person называют родительским классом, базовым классом или суперклассом, а класс Employee называют классом-наследником, подклассом или производным классом.







### конструкторы и ключевое слово super



в отличие от полей и методов, конструкторы базового класса не наследуются. каждый генеративный конструктор подкласса должен вызвать какой-либо генеративный конструктор суперкласса. если вызов не указан явно, неявно вызывается безымянный конструктор без аргументов `super()`. поэтому если базовый класс явно определяет конструктор с параметрами (конструктор по умолчанию не в счёт), его необходимо вызвать в конструкторе класса-наследника:



```dart

void main (){
     
    Employee bob = Employee("Bob", 42, "Google");
    bob.display();  // Name: Bob  Age: 42
} 
 
class Person{
  
    String name;
    int age;
    Person(this.name, this.age);
    void display() => print("Name: $name  Age: $age");
}
class Employee extends Person{

    String company = "";
    Employee(String name, int age, this.company): super(name, age);
}
```



базовый класс Person определяет конструктор с двумя параметрами. производный класс Employee определяет свой конструктор, который вызывает конструктор базового класса и передаёт ему значения параметров name и age. для обращения к функциональности базового класса из производного применяется ключевое слово **super**. в частности, вызов `super(name, age)` означает обращение к конструктору базового класса `Person(name, age)`. вызов super записывается в списке инициализации и выполняется до тела конструктора подкласса.



если при определении конструктора производного класса не вызвать конструктор базового класса, компилятор выдаст ошибку.



начиная с dart 2.17 передачу значений базовому классу можно записать короче, с помощью super-параметров:



```dart

void main (){
     
    Employee bob = Employee("Bob", 42, "Google");
    bob.display();  // Name: Bob  Age: 42
} 
 
class Person{
  
    String name;
    int age = 18;
    Person(this.name, this.age);
    void display() => print("Name: $name  Age: $age");
}
class Employee extends Person{

    String company = "";
    Employee(super.name, super.age, this.company);
}
```



в классе Employee строка



```dart
Employee(super.name, super.age, this.company);
```



эквивалентна записи



```dart
Employee(String name, int age, this.company): super(name, age);
```



выражение `super.name` объявляет параметр, значение которого передаётся в параметр name конструктора базового класса Person. тип такого параметра выводится из соответствующего параметра суперконструктора.



#### переопределение именованных конструкторов



аналогично можно определять в подклассе одноимённые конструкторы и обращаться из них к именованным конструкторам базового класса:



```dart

void main (){
    Employee tim = Employee.withName("Tim");
    tim.display();  // Name: Tim  Age: 18
} 
 
class Person{
  
    String name;
    int age = 18;
    Person(this.name, this.age);
    // именнованный конструктор вызывает основной конструктор
    Person.withName(this.name);

    void display() => print("Name: $name  Age: $age");
}
class Employee extends Person{

    String company = "";
    Employee(super.name, super.age, this.company);
    // переопределяем именнованный конструктор
    Employee.withName(String name) : super.withName(name);
}
```



строго говоря, конструкторы не наследуются и потому не переопределяются в смысле динамической диспетчеризации: Employee.withName является отдельным конструктором подкласса, который явно делегирует инициализацию конструктору `Person.withName`.



### переопределение методов



производные классы могут не только определять собственные поля и методы, но и переопределять поведение методов базового класса. для этого используется аннотация **@override**. сама аннотация семантику не меняет, переопределение происходит и без неё, но анализатор с её помощью проверяет, что в суперклассе действительно есть член с таким именем. в примерах выше класс Employee определяет поле company для компании, в которой работает работник, и логично, чтобы метод display для объекта Employee выводил и компанию:



```dart

void main (){
     
    Employee bob = Employee("Bob", 42, "Google");
    bob.display();  // Name: Bob  Age: 42  Company: Google
} 
 
class Person{
  
    String name;
    int age = 18;
    Person(this.name, this.age);
    void display() => print("Name: $name  Age: $age");
}
class Employee extends Person{

    String company;
    Employee(super.name, super.age, this.company);
    // переопределяем метод display
    @override
    void display() {
        print("Name: $name  Age: $age");
        print("Company: $company");
    }
}
```



все методы экземпляра в dart виртуальные, ключевое слово вроде `virtual` в c# не требуется. вызов display диспетчеризуется по типу объекта во время выполнения, поэтому для переменной статического типа Person, которая ссылается на Employee, будет вызвана реализация из Employee.



### вызов методов базового класса в производном



в примере выше часть кода метода display в Employee повторяет код метода display из Person. чтобы избежать повторения, с помощью ключевого слова **super** можно вызвать реализацию метода display из базового класса:



```dart

void main (){
     
    Employee bob = Employee("Bob", 42, "Google");
    bob.display();
} 
 
class Person{
  
    String name;
    int age = 18;
    Person(this.name, this.age);
    void display() => print("Name: $name  Age: $age");
}
class Employee extends Person{

    String company;
    Employee(super.name, super.age, this.company);
    
    @override
    void display(){
        super.display();	// Вызов реализации из класса Person
        print("Company: $company");
    }
}
```



консольный вывод:



```bash

Name: Bob  Age: 42
Company: Google
```
