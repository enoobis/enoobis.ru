класс **Set** представляет множество, то есть коллекцию уникальных объектов. в математическом смысле множество не упорядочено, однако реализация по умолчанию, которую создает литерал, является `LinkedHashSet` и сохраняет порядок вставки элементов: именно в этом порядке они перебираются и выводятся. для создания множества применяются фигурные скобки `{}`. например, пустое множество:

тип множества можно указать явно: после имени типа Set в угловых скобках указывается тип элементов:

```dart


Set<String> set = {};
```

здесь множество состоит из объектов String.

угловые скобки с типом можно поставить и перед фигурными скобками, результат будет тем же:

```dart


var set = <String>{};
```

в обоих случаях тип данных множества указан явно. если же создается **пустой** литерал без аргумента типа:

```dart


var set = {};
```

то в действительности создается не объект Set, а объект другой коллекции, Map. литерал `{}` синтаксически допускает обе трактовки, а литералы словарей появились в языке раньше литералов множеств, поэтому неоднозначность разрешена в пользу Map, и такая переменная получает тип `Map<dynamic, dynamic>`. непустой литерал однозначен: элементы вида `ключ: значение` дают словарь, одиночные значения дают множество.

в фигурных скобках можно сразу перечислить значения множества:

```dart


var set = {"Tom", "Bob", "Sam"};
```

функция print выводит все элементы множества на консоль:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam"};

    print(set); // {Tom, Bob, Sam}

}
```

объект Set хранит только уникальные значения. повторяющиеся значения при определении или добавлении отбрасываются:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam", "Tom", "Bob"};

    print(set); // {Tom, Bob, Sam}

}
```

уникальность определяется оператором `==` и методом `hashCode` элементов, поэтому для собственных классов, экземпляры которых помещаются в множество, эти два члена должны быть переопределены согласованно.

### свойства класса Set

основные свойства класса Set:

- first : возвращает первый элемент

- last : возвращает последний элемент

- length : возвращает количество элементов множества

- isEmpty : возвращает true, если множество пусто

- isNotEmpty : возвращает true, если множество не пусто

применение свойств:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam"};

    print("Length: ${set.length}");         // 5

    print("First: ${set.first}");           // Tom

    print("Last: ${set.last}");             // Sam

    print("IsEmpty: ${set.isEmpty}");       // false

    print("IsNotEmpty: ${set.isNotEmpty}"); // true

}
```

в комментарии к первой строке указано число 5, однако множество содержит три элемента, и программа выведет `Length: 3`. первый и последний элементы определены здесь благодаря тому, что `LinkedHashSet` сохраняет порядок вставки.

### методы класса Set

основные методы множеств:

- add(E value) : добавляет элемент в множество

- addAll(Iterable<E> iterable) : добавляет в множество элементы другой коллекции

- clear() : удаляет все элементы из множества

- contains(Object element) : возвращает true, если элемент содержится в множестве

- containsAll(Iterable<Object?> other) : возвращает true, если все элементы коллекции other содержатся в множестве

- difference(Set<Object?> other) : возвращает разность текущего множества и множества other в виде нового множества

- intersection(Set<Object?> other) : возвращает пересечение текущего множества и множества other в виде нового множества

- remove(Object value) : удаляет объект из множества

- removeAll(Iterable<Object?> elements) : удаляет из множества все элементы коллекции elements

- union(Set<E> other) : возвращает объединение двух множеств, текущего и множества other

- join([String separator = "" ]) : объединяет все элементы множества в строку. необязательный параметр separator задает разделитель элементов в строке

- skip(int count) : возвращает коллекцию без первых count элементов

- take(int count) : возвращает коллекцию из первых count элементов

- where(bool test(E element)) : возвращает коллекцию из элементов, удовлетворяющих условию, которое передается в виде функции

- forEach(void action(E element)) : вызывает для каждого элемента множества функцию action

полный список полей, методов и конструкторов класса Set приведен в [документации](https://api.dart.dev/stable/dart-core/Set-class.html)

### перебор множества

для перебора множества можно использовать цикл **for..in**:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam"};

    for (var name in set){

		print(name);

	}

}
```

также для перебора множества применяется метод **forEach**, который принимает функцию и вызывает ее для каждого элемента:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam"};

    set.forEach(print);

}
```

здесь передается функция print, которая получает каждый элемент множества и выводит его на консоль. другой пример:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam"};

    int i = 1;

    set.forEach((name)=>print("${i++}.$name"));

}
```

здесь передается анонимная функция, которая получает каждый элемент множества в параметр name и выводит на консоль порядковый номер элемента и сам элемент. для нумерации используется внешняя переменная i: анонимная функция является лексическим замыканием и захватывает переменную, а не ее значение, поэтому инкремент `i++` внутри функции изменяет переменную, объявленную в main.

### получение элементов

для получения элемента множества по индексу применяется метод **elementAt()**, которому передается индекс элемента. индексация начинается с нуля, первый элемент имеет индекс 0:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam", "Kate"};

    print(set.elementAt(0));   // Tom

    print(set.elementAt(1));   // Bob

    print(set.elementAt(2));   // Sam

}
```

у множества нет оператора индексирования, и `elementAt` для него реализован последовательным обходом, поэтому его сложность линейна относительно индекса, в отличие от доступа к элементу списка за постоянное время.

### добавление элементов

для добавления одного элемента применяется метод **add()**. он возвращает `bool`: true, если элемент был добавлен, и false, если такой элемент в множестве уже был:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam"};

    set.add("Alice");

    print(set);	// {Tom, Bob, Sam, Alice}

}
```

для добавления коллекции применяется метод **addAll()**, которому передается добавляемая коллекция:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam"};

    set.addAll(["Alice", "Kate"]);

    print(set); // {Tom, Bob, Sam, Alice, Kate}

}
```

здесь добавляется список `["Alice", "Kate"]`, но передать можно любую коллекцию типа Iterable, в том числе и сам Set.

### проверка на наличие элементов

метод **contains()** возвращает true, если элемент есть в множестве. для хешированного множества эта проверка выполняется в среднем за постоянное время, тогда как `contains` у списка требует линейного поиска:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam"};

    print(set.contains("Tom"));     // true

    print(set.contains("Alex"));    // false

}
```

метод **containsAll()** возвращает true, если все элементы некоторой коллекции содержатся в множестве:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam"};

    print(set.containsAll({"Tom", "Bob"}));     // true

    print(set.containsAll({"Tom", "Alex"}));    // false

}
```

### удаление элементов

для удаления одного элемента применяется метод **remove()**, которому передается удаляемый элемент:

```dart


void main (){

    var set = {"Tom", "Bob", "Sam"};

    set.remove("Bob");

    print(set);    // {Tom, Sam}

}
```

для удаления по условию применяется метод **removeWhere()**, которому передается функция-предикат. она принимает элемент множества и возвращает значение типа bool: true, если элемент удовлетворяет условию, и false в противном случае. например, удалим из множества все строки длиной 3 символа:

```dart


void main (){

    var set = {"Tom", "Alice", "Bob", "Sam", "Kate"};

    set.removeWhere((item)=>item.length ==3);  // если длина строки - 3 символа

    print(set);   // {Alice, Kate}

}
```

метод **removeAll()** удаляет все элементы коллекции, переданной ему в качестве параметра. элементы, которых в множестве нет, как "Alex" в примере, просто игнорируются:

```dart


void main (){

    var set = {"Tom", "Alice", "Bob", "Sam", "Kate"};

    set.removeAll({"Alice", "Bob", "Alex"});

    print(set);   // {Tom, Sam, Kate}

}
```

### операции над множествами

класс Set поддерживает стандартные теоретико-множественные операции: объединение, пересечение и разность.

например, есть две группы студентов, изучающих dart и flutter:

```dart


var dart = {"Tom", "Alice", "Bob", "Mike"};     // изучают Dart

var flutter = {"Tom", "Alice","Sam", "Kate"};   // изучают Flutter
```

найдем студентов, которые изучают и dart, и flutter одновременно. для этого применяется операция пересечения в виде метода **intersection()**:

```dart


void main (){

    var dart = {"Tom", "Alice", "Bob", "Mike"};     // изучают Dart

    var flutter = {"Tom", "Alice","Sam", "Kate"};   // изучают Flutter

    var set = dart.intersection(flutter);   // учат и dart, и flutter одновременно

    print(set);   // {Tom, Alice}

}
```

метод `intersection()` принимает второе множество, с которым выполняется пересечение. результатом является новое множество, исходные множества не изменяются.

теперь найдем всех студентов из обеих групп. для этого выполняется объединение множеств методом **union()**:

```dart


void main (){

    var dart = {"Tom", "Alice", "Bob", "Mike"};     // изучают Dart

    var flutter = {"Tom", "Alice","Sam", "Kate"};   // изучают Flutter

    var set = dart.union(flutter);   // в обоих группах

    print(set);   // {Tom, Alice, Bob, Mike, Sam, Kate}

}
```

метод `union()`, как и `intersection()`, принимает второе множество, с которым выполняется объединение, и возвращает новое множество. повторяющиеся элементы, Tom и Alice, входят в результат один раз.

наконец, найдем студентов, которые изучают dart, но не изучают flutter. для этого применяется разность множеств. у класса Set для этого есть метод **difference()**, который принимает вычитаемое множество и возвращает результат в виде нового множества:

```dart


void main (){

    var dart = {"Tom", "Alice", "Bob", "Mike"};     // изучают Dart

    var flutter = {"Tom", "Alice","Sam", "Kate"};   // изучают Flutter

    var set = dart.difference(flutter);   // изучают dart, но не изучают flutter

    print(set);   // {Bob, Mike}

}
```
