побитовые операции и операции сдвига действуют на отдельные разряды, то есть биты двоичного представления целого числа. для их понимания нужна двоичная запись: число 4 в двоичной системе записывается как 100, число 5 как 101 и так далее.

для чисел со знаком используется **дополнительный код** (two’s complement), в котором старший разряд играет роль знакового. если он равен 0, число неотрицательно и его запись совпадает с записью беззнакового числа: например, 0000 0001 соответствует десятичной 1. в dart тип `int` на нативных платформах представлен 64-битным целым в дополнительном коде, а при компиляции в javascript целые отображаются на числа javascript, поэтому семантика побитовых операций там ограничена 32 разрядами.

если старший разряд равен 1, число отрицательно. так, 1111 1111 представляет -1, а 1111 0011 представляет -13. удобство дополнительного кода в том, что сложение и вычитание выполняются одной и той же схемой для знаковых и беззнаковых значений, а ноль имеет единственное представление.

### логические операции

логические операции над целыми числами выполняются поразрядно: каждый разряд результата вычисляется независимо по соответствующим разрядам операндов. число 2 в двоичной системе равно 10 и занимает два разряда, число 7 равно 111 и занимает три.

- `& (логическое умножение)` умножение выполняется поразрядно: если оба операнда имеют в данном разряде 1, в результат записывается 1, иначе 0. в первом примере участвуют числа 2 и 5, то есть 010 и 101. поразрядное умножение (0*1, 1*0, 0*1) даёт 000. во втором примере вместо двойки взято число 4, у которого старший из трёх разрядов равен 1, как и у числа 5, поэтому результат (1*1, 0*0, 0*1) равен 100, то есть десятичному 4.

```dart
int a1 = 2; 		//010
int b1 = 5;			//101
print(a1&b1); 	//000 - результат 0
            
int a2 = 4; 		//100
int b2 = 5; 		//101
print(a2 & b2); //100 - результат 4
```

- `|` (логическое сложение) операция также выполняется по разрядам, но в результат записывается единица, если хотя бы один из операндов имеет в данном разряде единицу (поразрядное «или»). например:

```dart
int a1 = 2; 	//010
int b1 = 5;		//101
print(a1|b1); 	//111- результат 7
int a2 = 4; 	//100
int b2 = 5;		//101
print(a2 | b2); //101 - результат 5
```

- `^` (логическое исключающее или) эту операцию также называют xor, и её нередко используют для простейшего шифрования. разряд результата равен 1, если разряды операндов различны, и 0, если совпадают. например, значение выражения 9^5 равно 12. поскольку xor является инволюцией относительно ключа, то есть (x ^ k) ^ k = x, расшифровка выполняется повторным применением той же операции с тем же ключом.

```dart
int number = 45; // 1001 Значение, которое надо зашифровать - в двоичной форме 101101
int key = 102; //Ключ шифрования - в двоичной системе 1100110
int encrypt = number ^ key; //Результатом будет число 1001011 или 75
print("Зашифрованное число: $encrypt");

int decrypt = encrypt ^ key; // Результатом будет исходное число 45
print("Расшифрованное число: $decrypt");
```

- `~` (логическое отрицание) унарная поразрядная операция, которая инвертирует все разряды числа: единицы становятся нулями и наоборот. в дополнительном коде это означает, что `~x` равно `-x - 1`.

```dart
int a = 12;                 // 0000 1100     
print(~a);				//  1111 0011   или -13
```

### операции сдвига

операции сдвига также работают с разрядами числа, сдвигая их вправо или влево.

- `a >> b` сдвигает число a вправо на b разрядов. например, `16>>1` сдвигает число 16 (в двоичной системе 10000) на один разряд вправо, в результате получается 1000, то есть десятичное 8. сдвиг `>>` арифметический: освободившиеся старшие разряды заполняются значением знакового бита, поэтому для неотрицательных чисел он эквивалентен целочисленному делению на 2 в степени b. симметричная операция `a << b` сдвигает разряды влево, а начиная с dart 2.14 есть и логический сдвиг вправо `>>>`, заполняющий старшие разряды нулями независимо от знака.
