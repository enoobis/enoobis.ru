функция может возвращать результат. для этого служит оператор **return**, после которого указывается возвращаемое значение:

```dart
return результат_функции;
```

результатом функции может быть литерал (число, строка, объект другого типа), значение переменной или константы, произвольное вычисляемое выражение, например арифметическая операция, или результат вызова другой функции.

например, определим функцию, которая возвращает сумму двух чисел:

```dart
int sum(int a, int b){
	return a + b;
}
```

тип возвращаемого значения указывается перед именем функции, в данном случае это **int**. после оператора **return** в теле функции записывается возвращаемое значение, здесь результат выражения (a + b). статический тип выражения после **return** должен быть совместим с объявленным типом функции, то есть являться его подтипом. функция имеет тип int и возвращает сумму `a + b`, которая также имеет тип `int`. если объявленный тип не допускает null, компилятор дополнительно проверяет, что функция не может завершиться без return.

кроме того, оператор return завершает выполнение функции, поэтому все инструкции, которые должны выполниться, располагаются до **return**.

результат функции можно присвоить переменной и затем использовать в программе:

```dart
void main() {
	
	int result = sum(2, 5);
	print(result);	// 7
}
int sum(int a, int b){
	return a + b;
}
```

здесь результат функции sum, то есть сумма двух чисел, присваивается переменной result.

поскольку sum возвращает число, вызов sum можно использовать везде, где допустимо выражение типа int:

```dart
void main() {
	
	print(sum(2, 5));	// 7
	print(sum(4, 5));	// 9
	print(sum(11, 5));	// 16
}
int sum(int a, int b){
	return a + b;
}
```

здесь результат функции sum передаётся непосредственно в функцию print.

возвращаемый тип при определении функции можно не указывать:

```dart
void main() {
	
	var n = sum(2, 5);
	print(n);
}

// функция имеет тип int
sum(int a, int b){
	return a + b;
}
```

для именованной функции без аннотации возвращаемый тип по выражению после return не выводится: статически он считается **dynamic**. во время выполнения sum действительно возвращает значение типа int, на что и указывает комментарий в коде, однако переменная n получает статический тип dynamic, и проверки типов для неё отключаются. возвращаемый тип выводится в других ситуациях, например для анонимных функций и для методов, переопределяющих метод супертипа, поэтому для объявлений верхнего уровня тип лучше указывать явно.

### сокращенная форма функции

если тело функции сводится к одному выражению, как у функции sum выше, определение можно сократить:

```dart
void main() {
	
	print(sum(2, 5));	// 7
}
int sum(int a, int b) => a + b;
```

в этом случае возвращаемое значение указывается после стрелки `=>`, а оператор `return` явно не пишется.

### функции типа void

если в теле функции нет оператора **return**, в его конец неявно добавляется инструкция `return null;`. например, функция sum в следующем коде

```dart
void main() {
	
	sum(2, 5);
}
sum(int a, int b){
	print(a + b);
}
```

фактически эквивалентна

```dart
sum(int a, int b){
	print(a + b);
	return null;
}
```

если функция не должна возвращать значения, её тип объявляется как void. переменную типа void можно даже объявить и присвоить ей результат void-функции, но использовать такое значение нельзя: тип void сообщает, что значение не предназначено для использования, и компилятор запрещает обращаться к нему.

```dart
void main() {
	
	void n = hello();
	// поскольку переменная n представляет тип void, 
	// ничего мы с ней не сможем сделать, даже вывести на консоль
	// print(n);
}

void hello(){
	print("Hello!");
	return null;
}
```

### выход из функции

оператор **return** не только возвращает результат из функции, но и прекращает её выполнение. например, возьмём следующее определение функции sum:

```dart
int sum(int a, int b){
	return a + b;
	int result = a + b;	// эта строка выполняться не будет
}
```

после оператора **return** управление покидает функцию sum, и последующие строки не выполняются. анализатор помечает такой код как недостижимый (dead code).

иногда требуется выйти из функции досрочно, в зависимости от некоторых условий. для этого в dart есть форма оператора **return** без значения:

```dart
return;
```

эта форма применяется в функциях с типом **void**. например:

```dart
void main() {
	
	checkAge(22);		// Ваш возраст: 22
	checkAge(222);		// Недействительный возраст
}
void checkAge(int age){
	if(age < 1 || age > 110)
	{
		print("Недействительный возраст");
		return;	// выходим из функции
	}
	print("Ваш возраст: $age");
}
```

функция checkAge получает через параметр age некоторый возраст. однако значение типа int может быть любым числом, в том числе отрицательным или очень большим, что не соответствует реально возможному возрасту. поэтому checkAge сначала проверяет, не меньше ли переданное значение 1 и не больше ли 110. в таком случае возраст считается недействительным: на консоль выводится сообщение, и функция завершается:

```dart
if(age < 1 || age > 110)
{
	print("Недействительный возраст");
	return;	// выходим из функции
}
```

если же условие ложно, то есть age лежит в диапазоне от 1 до 110, на консоль выводится другое сообщение:

```dart
print("Ваш возраст: $age");
```
