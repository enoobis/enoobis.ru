### абстрактные классы

в моделировании предметной области встречаются сущности, у которых нет конкретного воплощения. таково понятие «животное»: существуют кошка, собака и другие конкретные животные, но животное как таковое экземпляром быть не может. так же устроено понятие «геометрическая фигура»: есть прямоугольник, квадрат, круг, треугольник, а фигура вообще остаётся обобщением. для описания подобных сущностей служат абстрактные классы.

абстрактный класс объявляется с модификатором **abstract**. например, абстрактный класс геометрической фигуры:

```dart
abstract class Shape {
}
```

абстрактный класс устроен как обычный: он может содержать поля, методы и конструкторы. отличие одно: создать экземпляр абстрактного класса напрямую через его генеративный конструктор нельзя, компилятор отвергает такой код.

```dart
abstract class Shape { }
void main (){
     
    Shape shape = Shape();// ! Ошибка - так нельзя
}
```

конструкторы абстрактного класса при этом не бесполезны: их вызывают конструкторы производных классов через super. кроме того, абстрактный класс может объявить фабричный конструктор, возвращающий экземпляр одного из конкретных подклассов.

как правило, абстрактный класс задаёт общий интерфейс, который каждый наследник реализует по-своему. для фигуры это могут быть методы вычисления периметра, площади и т.д.

```dart
abstract class Shape { 
    void calculateArea(){
        print("Not Implemented");
    }
}
class Rectangle extends Shape{
     
	int width;
	int height;
    Rectangle(this.width, this.height);
     
    @override
    void calculateArea(){
        int area = width * height;
        print("area = $area");
    }
}
void main (){
     
    Shape rect = Rectangle(20, 30);
    rect.calculateArea();   // area = 600
}
```

абстрактный класс фигуры определяет метод `calculateArea()`, который выводит на консоль площадь фигуры, а класс прямоугольника переопределяет его собственной реализацией. вызов через переменную типа Shape диспетчеризуется динамически и попадает в реализацию Rectangle.

### абстрактные методы

в примере выше метод calculateArea базового класса Shape не выполняет полезной работы, поскольку у абстрактной фигуры площади нет. такой метод естественнее объявить абстрактным:

```dart
abstract class Shape { 
    void calculateArea();
}
class Rectangle extends Shape{
     
	int width;
	int height;
    Rectangle(this.width, this.height);
     
    @override
    void calculateArea(){
        int area = width * height;
        print("area = $area");
    }
}
void main (){
     
    Shape rect = Rectangle(20, 30);
    rect.calculateArea();   // area = 600
}
```

абстрактный метод записывается как обычный, но вместо тела после списка параметров ставится точка с запятой: `void calculateArea();`. он задаёт только сигнатуру, то есть часть контракта типа без реализации.

абстрактные методы допустимы только в абстрактных классах. если базовый класс объявляет абстрактный метод, конкретный класс-наследник обязан его реализовать, то есть определить тело метода, иначе программа не скомпилируется. наследник, который сам объявлен abstract, может оставить метод нереализованным и переложить эту обязанность на свои подклассы.
