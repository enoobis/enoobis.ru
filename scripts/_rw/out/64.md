### паттерны списков

паттерны списков сопоставляют значение со списками. шаблон списка проверяет, что значение является списком, что его длина соответствует шаблону, и затем сопоставляет каждый элемент с вложенным шаблоном. например, полное совпадение со списком:

```dart
void main() {
    
    print(getNumber([1, 2, 3, 4, 5]));  // 1
    print(getNumber([1, 2]));           // 3
    print(getNumber([]));               // 4
    print(getNumber([1, 2, 5]));        // 5
}

int getNumber(List<int> values) {
    switch(values)
    {
        case [1, 2, 3, 4, 5]:  return 1;
        case [1, 2, 3]:  return 2;
        case [1, 2]:  return 3;
        case []:  return  4;
        default: return 5;
    }
}
```

сравнение здесь структурное: шаблон `[1, 2]` совпадает с любым списком из двух элементов 1 и 2, а не с конкретным экземпляром списка.

#### подстановка _

паттерн _ обозначает одиночный элемент с произвольным значением. например, паттерн [2, _, 5] соответствует любому списку из трёх элементов, в котором между 2 и 5 расположено произвольное значение. паттерн [_, _] соответствует любому списку из двух произвольных элементов. несколько примеров:

```dart
void main() {
    
    print(getNumber([2, 3, 5]));    // 1
    print(getNumber([2, 4, 6]));    // 2
    print(getNumber([1, 2, 5]));    // 3
    print(getNumber([1, 2, 3]));    // 4
    print(getNumber([]));           // 5
}

int getNumber(List<int> values) {
    switch(values)
    {
        case [2, _, 5]: return 1;
        case [2, _, _]: return 2;
        case [_, _, 5]: return 3;
        case [_, _, _]: return 4;
        case _: return 5;
    }
}
```

выражение `case _` равнозначно ветви `default`: оно задаёт вариант по умолчанию, если ни одно из предыдущих выражений case не соответствует сравниваемому значению.

#### slice-паттерн

для обозначения произвольного количества элементов списка применяется slice-паттерн **...** (три точки), его также называют rest-элементом. например, паттерн `[1, 2, ..., 5]` соответствует списку, который начинается с 1, за которым следует 2, а последний элемент равен 5. между 2 и 5 может располагаться любое количество произвольных целых чисел, в том числе ни одного. паттерну `[1, 2, ..., 5]` соответствуют, например, следующие списки:

```dart
[1, 2, 3, 4, 5]
[1, 2, 5]
[1, 2, 66, 77, 88, 5]
```

паттерн **...** может стоять как в начале, так и в конце списка. паттерн `[2,...]` описывает список, который начинается с 2, паттерн `[..., 5]` описывает список, который заканчивается элементом 5, а паттерн `[...]` описывает список с произвольным количеством элементов. например:

```dart
void main() {
    
    print(getNumber([2, 5]));           // 1
    print(getNumber([2, 3, 4, 5]));     // 1
    
    print(getNumber([2]));               // 2
    print(getNumber([2, 3, 4]));         // 2
    
    print(getNumber([3, 4, 5]));        // 3
    print(getNumber([5]));              // 3
    
    print(getNumber([]));               // 4
    print(getNumber([1]));              // 4
    print(getNumber([1, 2, 3]));        // 4
}

int getNumber(List<int> values) {

    switch(values)
    {
        case [2, ..., 5]: return 1;    // если первый элемент - 2, а последний - 5
        case [2,...]: return 2;        // если первый элемент - 2
        case [..., 5]: return 3;       // если последний элемент - 5
        case [...]: return 4;          // произвольное количество элементов
    }
}
```

ветвь `default` здесь не нужна: шаблон `[...]` совпадает с любым списком, поэтому компилятор видит, что switch покрывает все значения типа `List<int>`, и функция гарантированно возвращает результат. порядок ветвей существен: список `[2]` подходит и под `[2,...]`, и под `[...]`, но выбирается первая подходящая ветвь.

slice-паттерн можно сочетать с символом подстановки _, например:

```dart
int getNumber(List<int> values) {

    switch(values)
    {
        case [_, ..., _]: return 1;
        case [...]: return 2;
    }
}
```

паттерн `[_, ..., _]` описывает список, который состоит как минимум из двух произвольных элементов, причём между первым и последним элементом может находиться любое количество других элементов:

```dart
void main() {
    
    print(getNumber([1, 2, 3, 4]));     // 1
    print(getNumber([1, 2, 3]));        // 1
    print(getNumber([1, 2]));           // 1

    print(getNumber([1]));              // 2
    print(getNumber([]));               // 2
}

int getNumber(List<int> values) {

    switch(values)
    {
        case [_, ..., _]: return 1;
        case [...]: return 2;
    }
}
```

### паттерны кортежей

паттерны кортежей сопоставляют значения кортежей (records). например, передадим в конструкцию switch кортеж из названия языка и времени суток и в зависимости от переданных данных вернём определённое сообщение:

```dart
void main() {
    
    print(createMessage(("english", "morning")));   // Good morning
    print(createMessage(("german", "evening")));    // Guten Abend
    print(createMessage(("undefined", "")));        // Hello World
}

String createMessage((String, String) data) {
    switch(data)
    {
        case ("english", "morning"): 
            return "Good morning";
        case ("english", "evening"):
            return "Good evening";
        case ("german", "morning"): 
            return "Guten Morgen";
        case ("german", "evening"):
            return "Guten Abend";
        default: 
            return "Hello World";
    }
}
```

функция createMessage принимает кортеж (record) из двух элементов типа String. конструкция switch сопоставляет этот кортеж с набором шаблонов, и в зависимости от результата возвращается та или иная строка. каждый элемент кортежа сопоставляется со своим вложенным константным шаблоном, и ветвь срабатывает только при совпадении всех элементов.

как и в случае со списками, в шаблоне кортежа можно применять паттерн `_`, который заменяет произвольный элемент:

```dart
void main() {
    
    print(createMessage(("english", "morning")));   // Good morning
    print(createMessage(("english", "evening")));    // Hello
    print(createMessage(("undefined", "")));        // Hello World
}

String createMessage((String, String) data) {
    switch(data)
    {
        case ("english", "morning"): 
            return "Good morning";
        case ("english", _):      // второй элемент не важен
            return "Hello";
        case _: 
            return "Hello World";
    }
}
```

здесь вторая ветвь срабатывает для любого кортежа, первый элемент которого равен "english", независимо от значения второго элемента.
