приложения часто оперируют составными объектами, которые требуется сохранить в файл и затем восстановить. эта задача называется сериализацией и десериализацией. один из наиболее распространённых форматов хранения и передачи данных это json, поэтому сохранение объектов собственных классов и их восстановление рассматриваются здесь на его примере.

для работы с json используется библиотека **dart:convert**, а именно функция **json.encode()**, преобразующая данные в json, и функция **json.decode()**, восстанавливающая данные из json. dart не предоставляет рефлексию во время выполнения в aot-компилируемых программах (библиотека `dart:mirrors` там недоступна), поэтому отображение объекта в json и обратно описывается в самом классе явно или генерируется на этапе сборки, например пакетом `json_serializable`.

### сохранение и восстановление одного объекта

пусть дан класс Person:

```dart
class Person{
  String name;
  int age;
  Person(this.name, this.age);

  factory Person.fromJson(Map<String, Object?> jsonMap){
    return Person(jsonMap["name"] as String, jsonMap["age"] as int);
  }

  Map toJson() => { "name": name, "age": age};
  @override
  toString() => "Name: $name \t Age: $age";
}
```

состояние Person хранится в двух полях: name и age. помимо обычного конструктора класс определяет фабричный конструктор `Person.fromJson()`. он получает словарь со строковыми ключами и значениями произвольного типа и по его элементам создаёт объект Person, то есть ожидается, что jsonMap содержит элементы с ключами "name" и "age". операции `as String` и `as int` выполняют приведение типа с проверкой во время выполнения, и при несоответствии данных генерируется `TypeError`.

метод `toJson()` выполняет обратную операцию: строит по объекту Person словарь Map с ключами "name" и "age".

сохранение одного объекта Person в файл json:

```dart
import 'dart:io';
import 'dart:convert';

void main() async {
  Person tom = Person("Tom", 38);
  var encoded = json.encode(tom);   // преобразуем в json
  File file = File("person.json");
  await file.writeAsString(encoded);    // запись в файл
  print("File has been written");
}
class Person{
  String name;
  int age;
  Person(this.name, this.age);

  factory Person.fromJson(Map<String, Object?> jsonMap){
    return Person(jsonMap["name"] as String, jsonMap["age"] as int);
  }

  Map toJson() => { "name": name, "age": age};
  @override
  toString() => "Name: $name \t Age: $age";
}
```

сначала объект преобразуется в json:

```dart
var encoded = json.encode(tom);
```

функция `json.encode` напрямую кодирует только числа, строки, логические значения, null, списки и словари со строковыми ключами. для любого другого объекта она по умолчанию вызывает метод `toJson()` и кодирует полученный словарь Map. сам метод `toJson()` не входит ни в какой интерфейс и вызывается динамически, по соглашению об имени.

результат кодирования является строкой, поэтому он записывается в текстовый файл. в итоге данные оказываются в файле "person.json".

обратное чтение данных из файла в объект Person:

```dart
import 'dart:io';
import 'dart:convert';

void main() async {
  File file = File("person.json");
  final data = await file.readAsString(); // считываем файл как строку
  final decoded = json.decode(data);      // преобразуем в словарь Map
  final Person person = Person.fromJson(decoded);  // создаем объект Person
  print(person);       // Name: Tom        Age: 38
}
```

сначала содержимое файла читается в строку методом `file.readAsString()`:

```dart
final data = await file.readAsString();
```

затем строка декодируется из json в объект Map:

```dart
final decoded = json.decode(data);
```

статический тип результата `json.decode` равен `dynamic`, а во время выполнения json-объект становится экземпляром `Map<String, dynamic>`. при передаче такого значения в параметр типа `Map<String, Object?>` выполняется неявное приведение от `dynamic` с проверкой во время выполнения.

в завершение объект Person создаётся фабричным конструктором:

```dart
final Person person = Person.fromJson(decoded);
```

### сохранение и восстановление списка объектов

более общая задача состоит в сохранении списка объектов:

```dart
import 'dart:io';
import 'dart:convert';

void main() async {
  final people = [Person("Tom", 38), Person("Bob", 42), Person("Sam", 25)];
  final encoded = json.encode(people);
  await File("people.json").writeAsString(encoded);
  print("Data saved");
}
```

список из трёх объектов сохраняется в файл "people.json". список кодируется как json-массив, а для каждого его элемента вызывается `toJson()`. в файл будут записаны следующие данные:

```browser
[{"name":"Tom","age":38},{"name":"Bob","age":42},{"name":"Sam","age":25}]
```

восстановление данных:

```dart
import 'dart:io';
import 'dart:convert';

void main() async {
  final data = await File("people.json").readAsString();
  final decoded = json.decode(data);
  var people = [];
  // перебираем словарь списков и создаем по каждому словарю объект Peron
  for(final item in decoded){
    final Person person = Person.fromJson(item);  // создаем объект Person
    people.add(person);
  }
  // перебираем объекты Person для вывода на консоль
  for(final person in people){
    print(person);
  }
}
```

сначала данные из файла читаются в строку:

```dart
final data = await File("people.json").readAsString();
```

далее строка json преобразуется в список словарей Map:

```dart
final decoded = json.decode(data);
```

здесь `decoded` является списком List, каждый элемент которого представляет собой словарь Map. из каждого словаря нужно получить объект Person, поэтому список decoded обходится в цикле, по каждому элементу создаётся объект Person, и он добавляется в список people:

```dart
var people = [];
  // перебираем словарь списков и создаем по каждому словарю объект Peron
  for(final item in decoded){
    final Person person = Person.fromJson(item);  // создаем объект Person
    people.add(person);
  }
```

литерал `[]` без аргумента типа и без контекста выводится как `List<dynamic>`. для сохранения статической типизации список можно объявить как `<Person>[]` или построить выражением `decoded.map(...).toList()` с явно указанным типом.
