класс **File** предоставляет методы для чтения и записи бинарных файлов, то есть для работы с содержимым как с последовательностью байтов без интерпретации в какой-либо кодировке.

### запись бинарных файлов

асинхронная запись набора байтов в файл выполняется методом **writeAsBytes()**:

```dart
writeAsBytes(List<int> bytes, {FileMode mode = FileMode.write, bool flush = false}) -> Future<File>
```

результатом метода является `Future` с записанным файлом. параметры:

- `bytes` : записываемый набор байтов в виде списка `List<int>`. каждый элемент должен лежать в диапазоне от 0 до 255

- `mode` : режим файла в виде объекта `FileMode`

- `flush` : логическое значение. при `true` записанные данные принудительно сбрасываются из буферов операционной системы на устройство до завершения метода.

метод **writeAsBytesSync** принимает те же параметры, но выполняется синхронно и ничего не возвращает:

```dart
writeAsBytesSync(List<int> bytes, {FileMode mode = FileMode.write, bool flush = false}) -> void
```

запись содержимого в бинарный файл:

```dart
import 'dart:io';
import 'dart:convert';    // для типа utf8

void main () async{
  
  String message = "Hello enoobis.ru";
  final file = File("content.bin");
  // конвертируем строку в набор байтов
  List<int> bytes = utf8.encode(message);
  await file.writeAsBytes(bytes);
  print("File has been written");
}
```

в файл записывается строка, предварительно преобразованная в список байтов `List<int>` функцией `utf8.encode()`, для чего импортируется библиотека **dart:convert**. строки в dart хранятся как последовательности кодовых единиц utf-16, поэтому для получения байтового представления всегда требуется явный выбор кодировки:

```dart
List<int> bytes = utf8.encode(message);
```

### чтение бинарных файлов

асинхронное чтение бинарного файла выполняет метод **readAsBytes()**, возвращающий список байтов в виде объекта **Uint8List** из библиотеки `dart:typed_data`. этот тип реализует `List<int>`, но хранит элементы в непрерывном буфере по одному байту на элемент:

```dart
Future<Uint8List> readAsBytes();
```

синхронное чтение выполняет метод **readAsBytesSync()**:

```dart
Uint8List readAsBytesSync();
```

чтение данных из записанного выше файла "content.bin":

```dart
import 'dart:io';
import 'dart:convert';    // для типа utf8

void main () async{
  
  final file = File("content.bin");
  List<int> content = await file.readAsBytes();
  // конвертируем из набора байтов в строку
  String message = utf8.decode(content);
  print(message);
}
```

при записи в "content.bin" строка была преобразована в набор байтов, поэтому после чтения выполняется обратное преобразование байтов в строку функцией `utf8.decode()`:

```dart
String message = utf8.decode(content);
```

отсюда общий порядок работы со сложными данными: перед записью в бинарный файл их сериализуют в набор байтов `List<int>`, а при чтении выполняют обратное преобразование из `List<int>` в нужный объект. формат сериализации полностью определяется программой. для чисел фиксированной разрядности с заданным порядком байтов используется класс `ByteData` из `dart:typed_data`.
