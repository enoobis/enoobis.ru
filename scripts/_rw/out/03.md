точкой входа в программу на dart является функция **main**: с неё начинается выполнение, и её наличие в исполняемой программе обязательно. простейшее определение выглядит так:

```dart
void main(){

}
```

слово `void` в начале определения указывает тип возвращаемого значения: функция ничего не возвращает и только выполняет некоторые действия. далее следует имя функции, **main**, и пустые скобки, означающие, что функция не принимает параметров. существует и другая форма main, принимающая параметр `List<String>`: через него программе при запуске передаются данные извне, а именно аргументы командной строки.

после скобок идёт тело функции, ограниченное открывающей и закрывающей фигурными скобками {}. внутри размещается последовательность инструкций, то есть действий, которые выполняет программа.

**инструкции** (statement) являются основным строительным элементом программы на dart. каждая инструкция выполняет некоторое действие: вызов функции или метода, объявление переменной, присваивание значения и т.п. в dart инструкция завершается точкой с запятой (;), которая обозначает её конец. в отличие от kotlin или javascript, точка с запятой в dart обязательна и автоматически не подставляется. например:

```dart
print("Hello Dart!");
```

эта строка представляет вызов функции `print`, выводящей на консоль строку "Hello Dart!". сам вызов функции является выражением, а с точкой с запятой он становится инструкцией-выражением (expression statement), поэтому и завершается этим знаком.

помимо отдельных инструкций широко используется блок кода. блок объединяет последовательность инструкций и заключается в фигурные скобки, между которыми размещаются инструкции:

```dart
{
	print("Hello!");
	print("Welcome to Dart!");
}
```

в этом блоке две инструкции, каждая из которых выводит на консоль строку. синтаксически блок сам является инструкцией, поэтому может стоять везде, где допустима инструкция. кроме того, блок задаёт лексическую область видимости: переменные, объявленные внутри него, недоступны за его пределами.

тело функции main также является блоком и может содержать вложенные блоки:

```dart
void main() {
	
	{
		print("Hello!");
		print("Welcome to Dart!");
	}
}
```

### комментарии

код программы может содержать комментарии, поясняющие смысл программы и назначение её частей. компилятор игнорирует комментарии, поэтому они не влияют ни на поведение приложения, ни на его размер.

в dart есть два вида комментариев: однострочные и многострочные. однострочный комментарий начинается двойным слешем // и продолжается до конца строки. многострочный комментарий заключается между символами **/* текст комментария */** и может занимать несколько строк. в отличие от c и java, многострочные комментарии в dart могут быть вложенными. например:

```dart
/*
	многострочный комментарий
	Первая программа
	на языке Dart
*/
// определение функции main
void main (){ 		// начало объявления функции
         
	print("Hello Dart!"); 	// вывод строки на консоль
} // конец объявления функции
```

отдельно выделяются документирующие комментарии, начинающиеся с /// (или /**). их обрабатывает инструмент dart doc при генерации документации, а ide показывает их во всплывающих подсказках.
