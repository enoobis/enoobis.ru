в завершение рассмотрим операции присваивания. составные формы объединяют простое присваивание с другой бинарной операцией: запись `c op= b` эквивалентна `c = c op b` с той разницей, что выражение слева вычисляется только один раз.

- `=` простое присваивание, записывает значение правого операнда в переменную слева: `c=b;`

- `+=` `c+=b;` (переменной c присваивается результат сложения c и b)

- `-=` `c-=b;` (переменной c присваивается результат вычитания b из c)

- `*=` `c*=b;` (переменной c присваивается результат произведения c и b)

- `/=` `c/=b;` (переменной c присваивается результат деления c на b; поскольку `/` в dart всегда возвращает `double`, для переменной типа `int` эта форма не пройдёт проверку типов)

- `~/=` `c~/=b;` (переменной c присваивается результат целочисленного деления c на b)

- `%=` `c%=b;` (переменной c присваивается остаток от деления c на b)

- `&=` `c&=b;` (переменной c присваивается значение c&b)

- `|=` `c|=b;` (переменной c присваивается значение c|b)

- `^=` `c^=b;` (переменной c присваивается значение c^b)

- `>>=` `c>>=b;` (переменной c присваивается значение c>>b), аналогично `<<=` присваивает c<<b

- `??=` `c ??= b;` (если переменная c имеет значение null, ей присваивается значение b; если c не равна null, она сохраняет своё значение, а правый операнд при этом не вычисляется)

примеры операций:

```dart
int a = 5;
a += 10;        // 15
a -= 3;         // 12
a *= 2;         // 24
a ~/= 6;         // 4
a <<= 4;      // 64
a >>= 2;      // 16
print(a);	// 16
```

### приоритет операций

порядок вычисления выражения определяется приоритетом операций, который описывает следующая таблица:

| expr++ expr-- |
| --- |
| -expr !expr ~expr ++expr --expr |
| * / % ~/ |
| + - |
| << >> >>> |
| & |
| ^ |
| \| |
| < > <= >= as is is! |
| == != |
| && |
| \|\| |
| ?? |
| ? : (тернарный оператор) |
| .. (каскадная нотация) |
| = += -= *= /= %= ~/= &= ^= \|= <<= >>= (операторы присваивания) |

чем выше строка в таблице, тем выше приоритет операции. скобки позволяют явно задать порядок вычисления и повысить приоритет нужной части выражения. в строке `..` речь идёт о каскадной нотации, которая позволяет выполнить последовательность обращений к одному и тому же объекту; spread-оператор записывается тремя точками `...` и используется только внутри литералов коллекций, поэтому в таблице приоритетов выражений не участвует.
