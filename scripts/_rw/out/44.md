в стандартной библиотеке dart есть два класса, на которых строится вся иерархия ошибок и исключений. первый, **Exception**, является базовым типом для всех исключений. второй, **Error**, является базовым классом для всех ошибок. оба объявлены в библиотеке `dart:core`.

тем самым в языке различаются два вида ситуаций: исключения и ошибки. исключения описывают ситуации, которые нельзя предсказать или исключить проверками в самом коде: отсутствующий файл, некорректный ввод, сбой сети. такие ситуации являются частью нормальной работы программы, и их предполагается перехватывать и обрабатывать. ошибки, наоборот, описывают ситуации, которые можно обнаружить и предотвратить на уровне программного кода: выход индекса за границы, неверный аргумент, недопустимое состояние объекта. ошибка сигнализирует о дефекте в программе, и правильной реакцией обычно является исправление кода, а не перехват в обработчике.

в конструкции try..catch можно обрабатывать исключения и ошибки определённого типа. для этого применяется оператор **on**:

```dart
void main (){
     
	 try{
		int x = 9;
		int y = 0;
		int z = x ~/ y;
	 
		print(z);
	}
	on Error{
		 print("Обработка ошибки в блоке on");
	}
	print("Завершение программы"); 
}
```

после оператора **on** указывается тип исключения или ошибки, которые нужно обработать. выражение `on Error` означает, что обрабатываются объекты типа Error. проверка выполняется во время выполнения по отношению подтипа: блок срабатывает для любого объекта, тип которого является подтипом указанного. поскольку Error является базовым типом для всех ошибок, фактически обрабатываются все ошибки.

аналогично обрабатываются исключения:

```dart
void main (){
     
	 try{
		int x = 9;
		int y = 0;
		int z = x ~/ y;
	 
		print(z);
	}
	on Exception{
		 print("Обработка исключения в блоке on");
	}
	print("Завершение программы"); 
}
```

тип ошибки или исключения можно конкретизировать:

```dart
void main (){
     
	 try{
		int x = 9;
		int y = 0;
		int z = x ~/ y;
	 
		print(z);
	}
	on IntegerDivisionByZeroException{
		 print("Обработка исключения IntegerDivisionByZeroException");
	}
	print("Завершение программы");
}
```

здесь обрабатываются только исключения типа IntegerDivisionByZeroException. если в блоке try возникнут исключения других типов, они останутся необработанными и будут распространяться дальше по стеку вызовов.

обработку конкретных типов исключений можно сочетать с блоком catch:

```dart
void main (){
     
	 try{
		int x = 9;
		int y = 0;
		int z = x ~/ y;
	 
		print(z);
	}
	on IntegerDivisionByZeroException{
		 print("Обработка исключения IntegerDivizionByZeroException");
	}
	catch(e){
		print("Возникло исключение: $e");
	}
	print("Завершение программы");
	 
}
```

если возникнет исключение типа IntegerDivisionByZeroException, его обработает блок **on**, а исключение любого другого типа обработает блок **catch**. блоки проверяются сверху вниз, и выполняется первый подходящий, поэтому более конкретные типы следует указывать раньше более общих, как и в java или c#.

IntegerDivisionByZeroException одновременно является и исключением, и ошибкой: этот класс реализует интерфейсы Exception и UnsupportedError (тип ошибки, производный от Error). такое возможно, поскольку в dart любой класс неявно задаёт интерфейс и класс может реализовать несколько интерфейсов.

блоки on и catch можно объединить:

```dart
void main (){
     
	 try{
		int x = 9;
		int y = 0;
		int z = x ~/ y;
	 
		print(z);
	}
	on IntegerDivisionByZeroException catch(e, s){
		 print("Обработка исключения $e");
		 print("Стек $s");
	}
	print("Завершение программы"); 
}
```

в такой форме параметр e получает статический тип, указанный после on (здесь IntegerDivisionByZeroException), и внутри блока доступны члены этого типа без явного приведения.

### встроенные типы исключений

в dart определено много типов исключений:

- DeferredLoadException

- FormatException

- IntegerDivisionByZeroException (помечен как устаревший)

- IOException

- FileSystemException

- PathNotFoundException

- HttpException

- RedirectException

- ProcessException

- SignalException

- SocketException

- StdinException

- StdoutException

- TlsException

- CertificateException

- HandshakeException

- WebSocketException

- IsolateSpawnException

- TimeoutException

- NullRejectionException

- OSError

часть из них относится не к `dart:core`, а к другим библиотекам, например к `dart:io` или `dart:async`, и доступна только на соответствующих платформах. для различных ситуаций определено также много типов ошибок:

- ArgumentError

- IndexError

- RangeError

- AssertionError

- AsyncError

- ConcurrentModificationError

- JsonUnsupportedObjectError

- JsonCyclicError

- NoSuchMethodError

- OutOfMemoryError

- RemoteError

- StackOverflowError

- StateError

- TypeError

- UnimplementedError

- UnsupportedError

для каждого типа исключения или ошибки, который требуется обработать, можно добавить отдельный блок on:

```dart
void main (){
     
	 try{
		int x = 9;
		int y = 0;
		int z = x ~/ y;
		print(z);
	}
	on IntegerDivisionByZeroException{
		 print("Обработка исключения IntegerDivisionByZeroException");
	}
	on FormatException{
		 print("Обработка исключения FormatException");
	}
	print("Завершение программы");
	 
}
```
