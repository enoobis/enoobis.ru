класс `Map`, или словарь, представляет коллекцию пар «ключ - значение»: каждому элементу соответствует ключ и связанное с ним значение. типы ключа и значения могут различаться. ключи уникальны, в словаре не может быть двух элементов с равными ключами, причём равенство определяется операцией `==` и согласованным с ней `hashCode`. по смыслу такая структура повторяет обычный словарь, где каждому слову сопоставлен перевод или толкование, отсюда и название. в теории структур данных её называют ассоциативным массивом или отображением (mapping).



для создания объекта `Map` используются фигурные скобки {}. так создаётся пустой словарь:



```dart

Map<int, String> map = {};
```



класс `Map` параметризован двумя типами: первый задаёт тип ключей, второй тип значений. в примере выше ключи имеют тип `int`, а значения тип **String**.



эквивалентная запись пустого словаря с явными аргументами типа у литерала:



```dart
var map = <int, String>{};
```



пустой словарь можно создать и без указания типов:



```dart
var map = {};
```



в этом случае создаётся словарь типа `Map<dynamic, dynamic>`: выводить аргументы типа не из чего, и компилятор подставляет `dynamic`. пустой литерал `{}` без контекста типа всегда интерпретируется как словарь, а не как множество, поскольку литералы `Map` появились в языке раньше литералов `Set`.



четвёртый способ состоит в вызове конструктора `Map`:



```dart
var map = Map();
```



### инициализация словаря



объект `Map` можно сразу заполнить значениями. для этого в фигурных скобках через запятую перечисляются элементы в формате `ключ : значение`:



```dart

var map = {
		1: "Tom",
		2: "Bob",
		3: "Sam"
};
```



здесь объект map получает тип `Map<int, String>`: тип ключей `int` и тип значений `String` выводятся статически из элементов литерала. в словаре три ключа 1, 2, 3, которым сопоставлены строки "Tom", "Bob", "Sam". и литерал, и конструктор `Map()` по умолчанию создают экземпляр `LinkedHashMap`, который сохраняет порядок вставки элементов, поэтому при выводе и переборе элементы идут в том порядке, в каком были добавлены.



функция print выводит содержимое словаря на консоль в читаемом виде:



```dart

void main (){
    var map = {
		1: "Tom",
		2: "Bob",
		3: "Sam"
    };
    print(map); // {1: Tom, 2: Bob, 3: Sam}
}
```



все ключи должны быть уникальными. если в литерале словаря указать (или позже добавить) элемент с уже существующим ключом, новое значение заменит прежнее. для неконстантного литерала анализатор выдаёт предупреждение о повторяющемся ключе, а в константном литерале `const {...}` повтор ключа является ошибкой компиляции:



```dart

void main (){
    var map = {
		1: "Tom",
		2: "Bob",
		3: "Sam",
        1: "Alice"
    };
    print(map); // {1: Alice, 2: Bob, 3: Sam}
}
```



позиция элемента при замене значения не меняется: ключ 1 остаётся первым, поскольку порядок определяется моментом первой вставки ключа.



### обращение к элементам



по ключу можно получить или изменить значение элемента:



```dart

void main (){
	
	var map = { 1: "Tom", 2: "Bob", 3: "Sam" };
    var second = map[2];    // получим значение элемента с ключом 2
    print(second);          // Bob

	map[1] = "Tomas";	    // изменим значение элемента с ключом 1
	print(map);		        // {1: Tomas, 2: Bob, 3: Sam}
}
```



для обращения к элементу после имени словаря в квадратных скобках указывается ключ. получение элемента с ключом 2:



```dart
var second = map[2];
```



оператор `[]` у `Map<K, V>` возвращает значение типа `V?`: ключа может не оказаться в словаре, и тогда результатом будет `null`. в условиях null safety это означает, что для `Map<int, String>` переменная second имеет статический тип `String?`, а не `String`. в отличие от java, где `get` тоже возвращает `null`, здесь возможное отсутствие значения отражено в системе типов.



изменение значения элемента с ключом 1:



```dart
map[1] = "Tomas";
```






### свойства и методы map



основные свойства:





- entries : возвращает объект `Iterable<MapEntry<K, V>>`, который представляет все элементы `Map`. каждый отдельный элемент словаря представлен объектом `MapEntry`

- keys : возвращает объект `Iterable<K>`, который представляет все ключи `Map`

- values : возвращает объект `Iterable<V>`, который представляет все значения `Map`

- length : возвращает количество элементов в `Map`

- isEmpty : возвращает true, если `Map` пуст

- isNotEmpty : возвращает true, если в `Map` есть элементы



использование свойств:



```dart

void main (){
	
	var map = { 1: "Tom", 2: "Bob", 3: "Sam" };
    print("Length: ${map.length}"); // Length: 3
    print("Empty: ${map.isEmpty}"); // Empty: false
	print(map.entries);     // (MapEntry(1: Tom), MapEntry(2: Bob), MapEntry(3: Sam))
	print(map.keys);        // (1, 2, 3)
	print(map.values);      // (Tom, Bob, Sam)
}
```



круглые скобки в выводе entries, keys и values указывают, что это объекты `Iterable`, а не списки: у списка print выводит квадратные скобки.



### основные методы map





- `addAll(Map<K, V> other)` : добавляет в `Map` элементы другого объекта `Map`

- `addEntries(Iterable<MapEntry<K, V>> newEntries)` : добавляет в `Map` коллекцию `Iterable<MapEntry<K, V>>`

- `clear()` : удаляет все элементы из `Map`

- `containsKey(Object? key)` : возвращает true, если `Map` содержит ключ key

- `containsValue(Object? value)` : возвращает true, если `Map` содержит значение value

- `forEach()` : перебирает все элементы и для каждого вызывает переданную функцию

- `V putIfAbsent(K key, V ifAbsent())` : если ключ key есть в `Map`, возвращает значение по этому ключу. если ключа нет, добавляет в `Map` значение, которое возвращает функция ifAbsent, и возвращает его

- `remove(Object? key)` : удаляет из `Map` элемент с ключом key



параметры containsKey, containsValue и remove имеют тип `Object?`, а не `K` или `V`: проверка принадлежности или удаление по значению другого типа корректны и просто дают отрицательный результат.



### перебор map



для перебора объекта `Map` применяется цикл `for-in`. через свойства entries, keys и values перебираются соответственно элементы, ключи и значения. сам `Map` не реализует `Iterable`, поэтому напрямую в `for-in` его подставить нельзя, нужно выбрать одно из этих представлений.



каждый элемент `Map` фактически представлен объектом `MapEntry<K, V>`, где K обозначает тип ключей, а V тип значений. у этого типа два свойства: **key** (ключ элемента) и **value** (значение элемента). через них можно получить содержимое элементов. в следующем примере перебираются все элементы словаря:



```dart

void main (){
	
	var map = { 1: "Tom", 2: "Bob", 3: "Sam" };

    for(final element in map.entries){
        print(element.key);     // получаем ключ элемента
        print(element.value);     // получаем значение элемента
    }
}
```



аналогично по отдельности перебираются ключи и значения:



```dart

void main (){
	
	var map = { 1: "Tom", 2: "Bob", 3: "Sam" };

    // перебираем ключи
    for(final key in map.keys){
        print(key);
    }

    // перебираем значения
    for(final value in map.values){
        print(value);
    }
}
```



добавление или удаление ключей во время такого перебора приводит к ошибке `ConcurrentModificationError` во время выполнения, поэтому модифицировать структуру словаря внутри цикла по его представлениям нельзя.



альтернативой служит метод **forEach()**. он принимает функцию, в которую передаются ключ и значение каждого элемента словаря:



```dart

void main (){
	
	var map = { 1: "Tom", 2: "Bob", 3: "Sam" };

    map.forEach((key, value) => print("$key - $value"));
}
```



в forEach передаётся анонимная функция с двумя параметрами, ключом и значением элемента, которая выводит их на консоль. типы параметров key и value выводятся из типа словаря как `int` и `String`. консольный вывод:



```bash

1 - Tom
2 - Bob
3 - Sam
```



### добавление элементов



чтобы добавить новый элемент, достаточно присвоить значение по ключу, которого ещё нет в словаре:



```dart

void main (){
	
	var map = { 1: "Tom", 2: "Bob", 3: "Sam" };
    map[4] = "Alice";   // добавляем элемент с ключом 4
    print(map);     // {1: Tom, 2: Bob, 3: Sam, 4: Alice}
}
```



элемента с ключом 4 изначально в map нет, поэтому присваивание по этому ключу добавляет новый элемент. операция `[]=` одна и та же для изменения и для добавления: семантика зависит только от того, присутствует ли ключ.



метод **addAll()** добавляет элементы из другого словаря, переданного в качестве параметра:



```dart

void main (){
	
    var women = {4: "Kate", 5: "Alice"};
	var map = { 1: "Tom", 2: "Bob", 3: "Sam" };
    map.addAll(women); // добавляем словарь women
    print(map);     // {1: Tom, 2: Bob, 3: Sam, 4: Kate, 5: Alice}
}
```



при совпадении ключей addAll ведёт себя как последовательность присваиваний: значения из переданного словаря заменяют существующие.



### удаление



для удаления применяется метод **remove()**, которому передаётся ключ удаляемого элемента:



```dart

void main (){
	var map ={ 1: "Tom", 2: "Bob", 3: "Sam" };
    map.remove(2);   // удаляем элемент с ключом 2
    print(map);     // {1: Tom, 3: Sam}
}
```



remove возвращает значение удалённого элемента или `null`, если ключа в словаре не было.



### проверка наличия элемента



методы **containsKey()** и **containsValue()** проверяют наличие в `Map` определённого ключа и значения соответственно:



```dart

void main (){
	var map ={ 1: "Tom", 2: "Bob", 3: "Sam" };
    print(map.containsKey(2));          // true
    print(map.containsKey(4));          // false
    print(map.containsValue("Sam"));    // true
    print(map.containsValue("Tim"));    // false
}
```



у хеш-словаря эти операции различаются по сложности: containsKey выполняется в среднем за константное время благодаря хешированию ключей, а containsValue требует линейного просмотра всех значений.
