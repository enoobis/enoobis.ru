тип данных определяет множество значений, которые может принимать объект, и набор допустимых над ними операций. среди базовых типов dart выделяются следующие:

- логический тип bool

- числовые типы (int, double)

- строковый тип (String)

поскольку в dart все значения являются объектами, эти типы, в отличие от примитивов java, представляют собой обычные классы с методами и свойствами. числовые типы int и double имеют общий супертип num.

### bool

тип **bool** включает два значения: **true** (истина) и **false** (ложь).

```dart
bool yes = true;
bool no = false;
```

как правило, переменные типа `bool` используются в условных выражениях, которые рассматриваются в последующих лекциях. в отличие от javascript или c, dart не допускает неявного приведения других значений к логическому типу: условие обязано иметь тип bool, и числа, строки или null в этой роли не принимаются.

### int

тип **int** представляет целые числа размером не более 64 бит, точный размер зависит от платформы. в нативных (настольных и мобильных) приложениях значения лежат в диапазоне от -2^63 до 2^63 - 1. при компиляции dart в javascript используется числовая система javascript, в которой целые представимы точно в диапазоне от -2^53 до 2^53 - 1.

любые целочисленные литералы трактуются как значения типа int:

```dart
int x = 8;
var y = -5;
```

### double

тип **double** представляет числа с плавающей точкой двойной точности (64 бита) в формате ieee 754.

все дробные литералы с точкой в качестве разделителя целой и дробной части трактуются как значения типа double:

```dart
double x = 8.8;
var y = -5.3;
var z = 0.09;
```

переменной типа double можно присвоить и целочисленный литерал, в этом случае он автоматически интерпретируется как дробное значение:

```dart
double x = 8;	// x = 8.0
print(x);	// 8.0
```

это правило касается только литералов: компилятор, зная ожидаемый тип double, трактует литерал 8 как 8.0. переменную типа int присвоить переменной типа double без явного преобразования (например, методом `toDouble()`) нельзя, так как int не является подтипом double.

### String

строки представлены типом **String**, который хранит последовательность кодовых единиц utf-16. строки в dart неизменяемы: любая операция над строкой порождает новую строку. строковый литерал можно заключать как в одинарные, так и в двойные кавычки, семантической разницы между ними нет:

```dart
String tom = "Tom";
String sam = 'Sam';
var kate = "Kate";
var alice = 'Alice';
```

многострочная строка заключается в тройные кавычки:

```dart
void main() {
	var multiline = '''
Многострочная
строка
	''';
	print(multiline);
	String text = """
Высокой страсти не имея
Для кода жизни не щадить,
Не мог он джаву от сишарпа,
Как мы ни бились, отличить.
	""";
	print(text);
}
```

интерполяция позволяет встраивать в строку значения других переменных:

```dart
String name = "Tom";
int age = 35;
String info = "Name: $name  Age: $age";
```

для подстановки значения перед именем переменной ставится знак доллара **$** ($name, $age): на место $name подставляется значение переменной name, а на место $age значение переменной age. для подстановки произвольного выражения используется форма ${выражение}, например ${age + 1}. подставляемое значение преобразуется в строку вызовом его метода toString().
