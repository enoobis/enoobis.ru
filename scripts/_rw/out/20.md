dart является объектно-ориентированным языком, и каждое значение, с которым работает программа на dart, является объектом. это относится и к числам, и к логическим значениям, и к функциям, и даже к `null`: в dart нет примитивных типов в смысле java, все типы входят в единую иерархию классов с корнем Object (точнее Object?, если учитывать null).

**объект** представляет **экземпляр** некоторого класса, а **класс** является шаблоном, описанием объекта. можно провести такую аналогию. у каждого есть общее представление о человеке: две руки, две ноги, голова, туловище и т.д. это общее представление и есть шаблон, его можно назвать классом. реально существующий человек, то есть конкретный экземпляр этого класса, является объектом класса.

класс определяется с помощью ключевого слова **class**:

```dart


class Person{



}
```

здесь определён класс Person. после имени класса в фигурных скобках следует тело класса, то есть его поля и методы. хотя класс пуст, он уже вводит новый тип, и можно объявлять переменные этого типа. класс в dart одновременно задаёт и тип, и неявный интерфейс, который могут реализовывать другие классы.

```dart


class Person{ } // пустой класс Person



void main() {

     

    Person tom;     // определяем переменную класса Person

}
```

переменная tom здесь имеет тип Person.

### создание объекта. конструктор

переменная tom пока не ссылается ни на какой объект, и использовать её нельзя: тип Person не допускает null, а анализ определённого присваивания (definite assignment) запрещает читать локальную переменную до присваивания ей значения. сначала необходимо создать объект класса Person. для создания объектов применяются специальные функции, называемые по имени класса, **конструкторы**. если в классе не определено ни одного конструктора, как в случае класса Person, компилятор автоматически создаёт для него конструктор без параметров. объект Person создаётся с помощью конструктора по умолчанию так:

```dart


class Person{ } // пустой класс Person



void main() {

     

    Person tom = Person();     // создаем объект класса Person

    print(tom);

}
```

для создания объекта используется выражение `Person()`. ключевое слово new в dart необязательно и в современном коде обычно опускается. конструктор по умолчанию не принимает параметров. при вычислении этого выражения в динамической памяти выделяется участок для хранения всех данных объекта Person, а переменная `tom` получает ссылку на созданный объект. после этого переменную можно использовать, например передать в функцию print и вывести на консоль. консоль покажет малоинформативное сообщение вида "Instance of 'Person'", которое формирует реализация toString, унаследованная от Object, но без вызова конструктора с переменной tom нельзя было бы сделать даже этого.

### поля и методы класса

любой объект характеризуется двумя основными аспектами: состоянием, то есть данными, которые хранит объект, и поведением, то есть действиями, которые объект может выполнять.

для хранения состояния объекта в классе применяются поля, или переменные экземпляра. поведение объекта задаётся методами. например, класс Person, представляющий человека, мог бы выглядеть так:

```dart


class Person{

	

	String name = "";		// имя

	int age = 0;					// возраст

	void display(){

		print("Name: $name \tAge: $age");

	}

}
```

в классе Person определены два поля: name представляет имя человека, а age его возраст. также определён метод display, который ничего не возвращает и выводит эти данные на консоль.

после создания объекта к его полям и методам можно обращаться через имя переменной с помощью оператора точки (.): после точки указывается имя поля или метода, например `tom.name`. ```dart


имя_объекта.поле

имя_объекта.метод()
``` используем поля и метод класса Person:

```dart


class Person{ 



    String name = "";		// имя

	int age = 0;					// возраст

    void display(){

        print("Name: $name \tAge: $age");

    }

}



void main() {

     

    Person tom = Person();  // создаем объект класса Person

	print(tom.age);		// обращаемся к полю age

    tom.display();          // обращаемся к методу display



    // изменяем имя и возраст

    tom.name = "Tom";

    tom.age = 38;

    tom.display();

}
```

обращаясь к полям объекта, можно получить или изменить их значения. строго говоря, внешний код обращается к полю через неявно сгенерированные геттер и сеттер, поэтому синтаксис доступа к полю и к свойству в dart одинаков:

```dart


print(tom.age);

tom.name = "Tom";

tom.age = 38;
```

обращаясь к методам объекта, можно вызвать действия, описанные в этих методах:

```dart


tom.display();
```

консольный вывод программы приведён ниже. первая строка вывода соответствует вызову `print(tom.age)`, поэтому фактически там будет выведено значение поля age, то есть 0:

```bash


Unknown

Name:           Age: 0

Name: Tom       Age: 38
```

### инициализация полей

поскольку поля name и age имеют типы String и int, которые не допускают значение `null`, им необходимо задать начальные значения: при звуковой null-безопасности (sound null safety) компилятор требует, чтобы каждое non-nullable поле было инициализировано до завершения конструирования объекта. альтернатива состоит в использовании nullable-типов, тогда начальные значения задавать необязательно, поскольку такие поля неявно инициализируются значением null:

```dart


class Person{ 



    String? name;		// равно null

	int? age;			// равно null

    void display(){

        print("Name: $name \tAge: $age");

    }

}



void main() {

     

    Person tom = Person();

    tom.display();          // Name: null      Age: null



    tom.name = "Tom";

    tom.age = 38;

    tom.display();          // Name: Tom       Age: 38

}
```

здесь поля name и age по умолчанию равны `null`, и программа выводит следующее:

```bash


Name: null      Age: null

Name: Tom       Age: 38
```

с nullable-полями следует обращаться осторожно. если использовать такое поле в операции, не определённой для null, возникнет ошибка. в dart 3 приведённый ниже код отвергается уже на этапе компиляции: значение типа `int?` нельзя использовать как операнд `+` без проверки на null или явного приведения. если же обойти статическую проверку, например оператором `!`, то при значении null будет выброшено исключение во время выполнения:

```dart


Person tom = Person();

tom.age = tom.age + 1;  // ! Ошибка
```

поэтому предпочтительнее всё же задавать полям начальные значения.

### каскадная нотация

каскадная нотация, операция **..**, позволяет выполнить последовательность операций над одним и тем же объектом. значением каскадного выражения является сам объект, а не результат последней операции:

```dart


class Person{

 

    String name = "";

	int age = 0;

     

    void display(){

        print("Name: $name \tAge: $age");

    }

}

void main (){

	

	Person tom = Person()

		..name = "Tom"

		..age = 38

		..display();	// Name: Tom  Age: 38

}
```

код в функции main здесь эквивалентен следующему (с точностью до значения возраста и точек с запятой, которые в приведённом фрагменте пропущены и обязательны в настоящей программе):

```dart


void main (){

	

	Person tom = Person();

	tom.name = "Tom"

	tom.age = 36

	tom.display();	// Name: Tom  Age: 36

}
```

### копирование объектов

переменные и константы классовых типов в dart хранят ссылки на объекты в памяти. если одной такой переменной присвоить значение другой, она получит ссылку на тот же объект, и обе переменные будут ссылаться на один и тот же объект. это ссылочная семантика присваивания, такая же, как для классов в java и c#. пример:

```dart


class Person{



	String name ="";

}



void main() {



    Person tom = Person();

    tom.name = "Tom";



    Person bob = tom;   // bob указывает на тот же объект, что и tom

    bob.name = "Bob";   // меняем у boba имя

    print(tom.name);    // Bob - у toma тоже поменялось имя

}
```

после присвоения переменной bob значения переменной tom обе переменные ссылаются на один объект в памяти:

```dart
Person bob = tom;
```

поэтому если через bob изменить значение поля name:

```dart
bob.name = "Bob";
```

то и через tom будет видно новое значение name, поскольку tom и bob указывают на один и тот же объект:

```dart
print(tom.name);    // Bob
```

если нужно скопировать данные одного объекта в другой так, чтобы оба объекта существовали и изменялись независимо, требуется отдельный механизм. встроенного универсального клонирования в dart нет, поэтому создают второй независимый объект и копируют в него значения полей первого, вручную или через специально написанный для этого метод.
