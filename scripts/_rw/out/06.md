иногда требуется выразить отсутствие значения у переменной. для этого в dart есть специальное значение **null**, единственный экземпляр типа Null. при его использовании необходимо учитывать, что в dart действует null-безопасность (null safety): начиная с dart 3 она обязательна и является звуковой, то есть гарантируется системой типов, а не соглашениями. рассмотрим следующую программу:

```dart
void main() {
	String name;	// нет никакого значения
	print(name);
	name = "Tom";
	print(name);
}
```

при объявлении переменной name ей не присваивается значение, и компиляция программы завершается ошибкой:

```bash
main.dart:3:8: Error: Non-nullable variable 'name' must be assigned before it can be used.
        print(name);
              ^^^^
```

ошибка сообщает, что переменная, которая не может принимать значение null, используется до присваивания ей значения. компилятор выполняет анализ потока управления (definite assignment analysis) и отвергает любое чтение локальной переменной, если на каком-либо пути выполнения ей ещё не было присвоено значение.

по умолчанию все типы считаются не допускающими значение **null** (non-nullable): переменная такого типа перед использованием обязана получить некоторое значение, например:

```dart
void main() {
	String name = "Bob";
	print(name);
	name = "Tom";
	print(name);
}
```

### оператор ? и nullable-типы

в ряде ситуаций требуется, чтобы переменная могла не иметь значения, то есть принимать **null**. для этого служат **nullable-типы**. каждый из них является двойником обычного типа и отличается лишь тем, что его переменные могут принимать значение `null`. с точки зрения теории типов `T?` представляет собой объединение типа T и типа Null, а T является подтипом `T?`. поэтому значение non-nullable типа можно присвоить nullable-переменной, но не наоборот.

чтобы отметить тип как `nullable` (допускающий значение null), после имени типа ставится **?** (вопросительный знак). например:

```dart
void main() {
	String? name;
	print(name);	// null
	name = "Tom";
	print(name);	// Tom
}
```

тип `String?` означает, что переменная может содержать либо строку, либо значение null. неинициализированная переменная nullable-типа неявно получает значение null, поэтому, в отличие от предыдущего примера, программа компилируется. при её выполнении на консоль выводится:

```consoletext
null
Tom
```

переменным таких типов можно и явно присваивать null:

```dart
void main() {
	String? name = "Tom";
	print(name);
	name = null;
	print(name);
}
```

консольный вывод:

```consoletext
Tom
null
```

### оператор ??

оператор **??** проверяет значение на null при присваивании. его назначение видно из следующего примера:

```dart
void main() {
	int? num1 = 23;
	int num2 = num1;
	print(num2);	// 23
	
	num1 = null;
	num2 = num1;	// ! Ошибка
	print(num2);
}
```

здесь объявлены две переменные, num1 и num2. обе хранят целые числа, однако num1 может хранить ещё и значение `null`. переменной num2, которая null принимать НЕ может, присваивается значение num1, допускающей null. в случае `num1 = null` это привело бы к ошибке, поэтому компилятор отказывается компилировать такую программу: проверка выполняется статически, по типам, а не по фактическим значениям во время выполнения.

для решения подобной проблемы применяется оператор **??**:

```dart
value1 ?? value2
```

если значение `value1` (операнд слева от ??) не равно `null`, оператор возвращает именно value1. если же оно равно `null`, оператор ?? возвращает value2 (операнд справа). правый операнд вычисляется только во втором случае, то есть оператор является сокращённо вычисляемым, как && и ||. результат имеет non-nullable тип, если правый операнд non-nullable.

```dart
void main() {
	int? num1 = 23;
	int num2 = num1 ?? 0;
	print(num2);		// 23
	
	num1 = null;
	num2 = num1 ?? 0;
	print(num2);		// 0
}
```

при первом присваивании переменная num2 получает значение num1 (число 23), так как num1 не равна null. при втором присваивании num2 получает значение 0, так как num1 равна null.

консольный вывод:

```consoletext
23
0
```

нередко переменной нужно присвоить значение только в том случае, если она равна `null`. например:

```dart
void main() {
	int? a;
	a = a ?? 10;
	print(a);		// 10
}
```

здесь переменной a присваивается число 10, если она равна null. для таких случаев в dart есть составной оператор присваивания **??=**:

```dart
void main() {
	int? a;
	a ??= 10;
	print(a);		// 10
}
```

как правило, операторы `??` и `??=` применяются, чтобы гарантировать, что переменная, допускающая null, будет содержать конкретное значение.
