для создания объекта класса и инициализации его состояния применяются специальные члены класса, называемые **конструкторами**. если класс явно не определяет ни одного конструктора, для него автоматически создаётся конструктор по умолчанию, который не принимает параметров:

```dart


class Person{ 



    String name = "";		// имя

	int age = 0;			// возраст

    void display() =>print("Name: $name \tAge: $age");

}



void main() {

     

    Person tom = Person();  // используем конструктор по умолчанию

    tom.display();	// Name:   Age: 0

}
```

класс может определять и собственные конструкторы. собственный конструктор позволяет передать полям конкретные значения или выполнить определённую логику в момент создания объекта. например:

```dart


class Person{ 



    String name = "";

	int age = 0;

    // конструктор

    Person(String personName, int personAge) 

    {

        name = personName;

        age = personAge;

    }



    void display() => print("Name: $name \tAge: $age");

}



void main() {

     

    Person tom = Person("Tom", 38); // используем наш конструктор

    tom.display();  // Name: Tom       Age: 38

}
```

теперь в классе определён конструктор, который принимает два параметра и с их помощью устанавливает значения полей объекта. имя конструктора совпадает с именем класса:

```dart


Person(String personName, int personAge) 

{

    name = personName;

    age = personAge;

}
```

поскольку в классе определён собственный конструктор, конструктор по умолчанию больше не генерируется, и для создания объекта Person необходимо использовать определённый конструктор:

```dart
Person tom = Person("Tom", 38);
```

в результате объект получает начальные значения полей уже при создании. консольный вывод программы:

```bash


Name: Tom  Age: 38
```

аналогично создаются и другие объекты:

```dart


void main() {

     

    Person tom = Person("Tom", 38);

    tom.display();  // Name: Tom       Age: 38



    Person bob = Person("Bob", 42);

    bob.display();  // Name: Bob       Age: 42



    Person sam = Person("Sam", 25);

    sam.display();  // Name: Sam       Age: 25

}
```

благодаря конструктору с параметрами каждый объект уже при создании инициализируется собственными данными.

### ключевое слово this

ключевое слово **this** обозначает ссылку на текущий экземпляр класса. через него можно обращаться к полям и методам объекта, а также вызывать другие его конструкторы. рассмотрим, где это нужно, на примере конструктора класса Person:

```dart


Person(String personName, int personAge) 

{

    name = personName;

    age = personAge;

}
```

здесь параметры конструктора называются personName и personAge. такие имена неудачны, и естественно было бы назвать параметры так же, как поля, которым передаются значения, например:

```dart


Person(String name, int age) 

{

    name = name;

    age = age;

}
```

однако в этом случае параметры затеняют (shadowing) одноимённые поля: в теле конструктора имя name разрешается в ближайшей лексической области видимости, то есть в параметр. в результате параметрам name и age присваиваются их же значения, а поля остаются без изменений. чтобы разграничить поля и параметры, применяется ключевое слово **this**:

```dart


class Person{



	String name = "";

	int age = 0;

	

    Person(String name, int age)

    {

        this.name = name;

        this.age = age;

    }

    void display(){

        print("Name: $name \tAge: $age");

    }

}
```

здесь значение параметра name присваивается полю name. выражение `this.name` обозначает обращение именно к полю экземпляра, а не к параметру.

### сокращённая форма конструктора

с помощью ключевого слова **this** определение конструктора можно сократить:

```dart


class Person{



	String name;

	int age;

	

    Person(this.name, this.age);

	

    void display(){

        print("Name: $name \tAge: $age");

    }

}

void main() {

     

    Person tom = Person("Tom", 38);

    tom.display();  // Name: Tom       Age: 38

}
```

параметры вида `this.name` называются инициализирующими формальными параметрами (initializing formals). при вызове конструктора

```dart
Person tom = Person("Tom", 38);
```

строка "Tom" передаётся в this.name, а число 38 в this.age.

при таком определении конструктора задавать полям начальные значения необязательно. инициализирующие формальные параметры присваивают значения полям до выполнения тела конструктора, поэтому компилятор считает non-nullable поля name и age гарантированно инициализированными.

### именованные конструкторы

в dart нет перегрузки функций и методов по сигнатуре, поэтому класс может иметь только один безымянный конструктор. если классу требуется несколько конструкторов, применяются **именованные конструкторы** (named constructors). для этого к имени класса через точку добавляется дополнительный идентификатор (произвольное имя):

```dart
имя_класса.идентификатор()
```

идентификатор фактически служит именем конструктора. добавим в класс Person два именованных конструктора:

```dart


class Person{



	String name = "";

	int age = 0;

	

    Person.undefined(){

        name = "undefined";

        age = 18;

    }

    Person.withName(String name){

        this.name = name;

        age = 18;

    }

    Person(String name, int age)

    {

        this.name = name; 

        this.age = age;

    }

	

    void display(){

        print("Name: $name \tAge: $age");

    }

}



void main() {

     

    Person bob = Person.undefined();      // вызов первого конструктора без параметров

    bob.display();



    Person tom = Person.withName("Tom"); // вызов второго конструктора с одним параметром

    tom.display();

          

    Person sam = Person("Sam", 25); // вызов третьего конструктора с двумя параметрами

    sam.display();

}
```

здесь определены два дополнительных конструктора: Person.undefined без параметров и Person.withName с одним параметром для установки имени. при вызове таких конструкторов указывается их полное имя:

```dart
Person tom = Person.withName("Tom");
```

консольный вывод программы:

```bash


Name: undefined         Age: 18

Name: Tom       Age: 18

Name: Sam       Age: 25
```

### вызов цепочки конструкторов

в примере с именованными конструкторами все три конструктора выполняют одинаковые действия: устанавливают поля name и age. чтобы избежать дублирования, конструктор может с помощью this вызвать другой конструктор того же класса и передать ему нужные значения параметров. такой конструктор называется перенаправляющим (redirecting constructor). в результате можно определить несколько конструкторов с разным количеством параметров, которые по цепочке вызывают друг друга:

```dart


class Person{



	String name;

	int age;



	Person.undefined(): this("undefined", 18);

	

	Person.withName(String name): this(name, 18);

	

    Person(this.name, this.age);

	

    void display(){

        print("Name: $name \tAge: $age");

    }

}



void main() {

     

    Person bob = Person.undefined();      // вызов первого конструктора без параметров

    bob.display();



    Person tom = Person.withName("Tom"); // вызов второго конструктора с одним параметром

    tom.display();

          

    Person sam = Person("Sam", 25); // вызов третьего конструктора с двумя параметрами

    sam.display();

}
```

конструкторы `Person.undefined` и `Person.withName` вызывают третий конструктор, в котором и устанавливаются поля name и age. перенаправляющий конструктор не может иметь тела и списка инициализации: после двоеточия допускается только вызов другого конструктора. поскольку третий конструктор определён в сокращённой форме, задавать полям значения по умолчанию необязательно.

### обязательные и необязательные параметры

конструктор по своей сути является функцией, поэтому, как и в любой функции, в нём можно определять обязательные и необязательные параметры:

```dart


class Person{



	String name;

	int age;

	

    Person({required this.name, this.age=18});

	

    void display(){

        print("Name: $name \tAge: $age");

    }

}



void main() {



    Person tom = Person(name:"Tom");  

    tom.display();          // Name: Tom       Age: 18

          

    Person sam = Person(name:"Sam", age:25);

    sam.display();          // Name: Sam       Age: 25

}
```

здесь параметры name и age конструктора являются именованными. параметр name помечен модификатором required и обязателен, а для age задано значение по умолчанию. для non-nullable именованного параметра без значения по умолчанию модификатор required необходим, иначе параметр получил бы недопустимое значение null.

### инициализаторы

список инициализации (initializer list) представляет ещё один способ инициализации полей класса:

```dart


class Person{



	String name ="";

	int age =0;

	

    Person(String name, int age) : this.name=name, this.age = age {

		print("Person $name created");

	}

	

    void display(){

        print("Name: $name \tAge: $age");

    }

}



void main() {



    Person tom = Person("Tom", 38);  

    tom.display();          // Name: Tom       Age: 38

}
```

список инициализации указывается после параметров конструктора через двоеточие, перед открывающей фигурной скобкой тела:

```dart
Person(String name, int age) : this.name=name, this.age = age {
```

обычно в списке инициализации поля получают значения из параметров конструктора, а тело конструктора выполняет прочую работу. в правых частях инициализаторов нельзя обращаться к this, поскольку объект в этот момент ещё не полностью инициализирован. именно через список инициализации задаются значения final-полей, которые нельзя присвоить в теле конструктора.

при инициализации полей можно использовать произвольные выражения:

```dart


Person(String name, int age) : this.name=name, this.age = age + 1 {

		print("Person $name created");

}
```

при использовании инициализаторов сначала выполняется список инициализации и только затем тело конструктора:

```dart


Person(String name, int age) : this.name=name, this.age = age {

	

    this.age = 22;

}
```

здесь поле age получит значение 22, поскольку тело конструктора перезапишет значение, установленное инициализатором.
