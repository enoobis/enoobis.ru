### реляционный паттерн

реляционный паттерн сравнивает значение, переданное в конструкцию, с константой при помощи операции сравнения. допускаются все стандартные операции сравнения: ==, !=, <, >, <= и >=. правый операнд должен быть константным выражением. например, процентная ставка по вкладу может зависеть от его суммы. рассчитаем сумму процентов в зависимости от суммы вклада с помощью реляционного паттерна:

```dart
void main() {
    
    print(calculate(-200));     // 0
    print(calculate(0));        // 0 
    print(calculate(10000));    // 500
    print(calculate(60000));    // 6000
    print(calculate(200000));   // 40000
}

double calculate(int sum)
{
    return switch(sum) {
        <= 0 => 0,              // если sum меньше или равно 0, возвращаем 0
        < 50000 => sum * 0.05, // если sum меньше 50000, возвращаем sum * 0.05
        < 100000 => sum * 0.1, // если sum меньше 100000, возвращаем sum * 0.1
        _ => sum * 0.2           // в остальных случаях возвращаем sum * 0.2
    };
}
```

ветви switch проверяются сверху вниз, и выбирается первая подходящая. поэтому шаблон `< 50000` фактически описывает диапазон от 1 до 49999: значения не больше нуля уже перехвачены предыдущей ветвью.

### логический паттерн

логический паттерн объединяет вложенные шаблоны оператором **&&** (логическое умножение, операция логического «и») и оператором **||** (логическое сложение, операция логического «или»). внутри шаблона эти операторы комбинируют шаблоны, а не булевы выражения. например, передадим в функцию возраст и вернём соответствующее сообщение:

```dart
void main() {
    
    print(checkAge(200));     // Недействительный возраст
    print(checkAge(0));      // Недействительный возраст 
    print(checkAge(17));    // Доступ запрещен
    print(checkAge(18));   // Доступ разрешен
}

String checkAge(int age)
{
    return switch(age)
    {
        <1 || >110 => "Недействительный возраст",   // если age больше 110 и меньше 1
        >=1 && <18 => "Доступ запрещен",           // если age равно или больше 1 и меньше 18
        _ => "Доступ разрешен"                      // в остальных случаях
    };
}
```

первая ветвь срабатывает, если возраст меньше 1 или больше 110, вторая, если возраст не меньше 1 и меньше 18. шаблон с `||` сопоставляется успешно, если подходит хотя бы одна из альтернатив, а шаблон с `&&` требует совпадения обеих частей. если в альтернативах `||` объявляются переменные, обе ветви обязаны объявлять один и тот же набор переменных одинаковых типов, чтобы после сопоставления все они были гарантированно определены.
