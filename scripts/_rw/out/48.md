как уже говорилось в одной из предыдущих лекций, при работе с асинхронными функциями, использующими Future, dart опирается на цикл событий **event loop**. при запуске приложения его единственный поток инициализирует две очереди, microtask queue и event queue, в которых будут храниться задачи Future. затем поток вызывает функцию main() и прежде всего выполняет все синхронные инструкции. синхронные задачи в основном потоке всегда выполняются немедленно. если dart встречает вызовы асинхронных функций, возвращающих Future, соответствующие задачи помещаются в очередь событий **event queue** или в очередь **microtask queue**.

после завершения синхронных задач цикл событий (**event loop**) проверяет очередь микрозадач **microtask queue**. если в ней есть задачи, цикл событий передаёт их в основной поток на выполнение.

когда синхронный код и задачи из **microtask queue** выполнены, цикл событий начинает извлекать задачи из очереди **event queue** и передавать их в основной поток, где они выполняются синхронно.

если в **microtask queue** поступает новая микрозадача, цикл событий выполняет её раньше любой следующей задачи из **event queue**.

процесс продолжается до тех пор, пока очереди не станут пустыми.

работу цикла событий удобно проследить на конкретной программе:

```dart
void main() {
  print("1 synchronous");
  Future(() => print("2 event queue")).then(
    (value) => print("3 synchronous"),
  );
  Future.microtask(() => print("4 microtask queue"));
  Future.microtask(() => print("5 microtask queue"));
  Future.delayed( Duration(seconds: 1), () => print("6 event queue"));
  Future(() => print("7 event queue")).then((value) => Future(() => print("8 event queue")));
  Future(() => print("9 event queue")).then((value) => Future.microtask(() => print("10 microtask queue")));
  print("11 synchronous");
}
```

консольный вывод программы:

```bash
1 synchronous
11 synchronous
4 microtask queue
5 microtask queue
2 event queue
3 synchronous
7 event queue
9 event queue
10 microtask queue
8 event queue
6 event queue
```

первыми выполняются все синхронные операции, то есть первая и последняя инструкции функции main:

```dart
print("1 synchronous");
//......................
print("11 synchronous");
```

соответственно на консоль выводится:

```bash
1 synchronous
11 synchronous
```

все задачи, созданные конструктором `Future.microtask` (микрозадачи), помещаются в очередь microtask queue. задачи, созданные остальными конструкторами Future, попадают в event queue. для `Future.delayed` это происходит не сразу, а по срабатыванию таймера, то есть по истечении задержки.

микрозадачи имеют приоритет перед обычными задачами, поэтому первой обрабатывается очередь microtask queue. выполняются задачи

```dart
Future.microtask(() => print("4 microtask queue"));
Future.microtask(() => print("5 microtask queue"));
```

и на консоль выводится:

```bash
4 microtask queue
5 microtask queue
```

затем выполняются задачи из event queue:

```dart
Future(() => print("2 event queue")).then((value) => print("3 synchronous"));

Future.delayed( Duration(seconds: 1), () => print("6 event queue"));
Future(() => print("7 event queue")).then((value) => Future(() => print("8 event queue")));
Future(() => print("9 event queue")).then((value) => Future.microtask(() => print("10 microtask queue")));
```

очередь является структурой fifo, поэтому задачи, добавленные первыми, первыми и выполняются. порядок добавления совпадает с порядком, в котором в коде записаны вызовы, создающие задачи. так, после 7-й задачи добавляется 9-я, а 8-я добавляется только после 9-й, потому что 8-я задача создаётся лишь при выполнении обратного вызова then, то есть после завершения 7-й.

строка "3 synchronous" выводится сразу после "2 event queue": обратный вызов then выполняется непосредственно по завершении соответствующего Future, без постановки в event queue, отсюда и пометка synchronous в тексте.

отдельного внимания заслуживает микрозадача, появляющаяся в результате выполнения 9-й задачи. микрозадачи имеют приоритет и выполняются раньше любых обычных задач, поэтому эта последняя микрозадача выполняется до 8-й и 6-й задач:

```dart
10 microtask queue
8 event queue
6 event queue
```

6-я задача завершается последней из-за задержки в одну секунду: за это время все остальные задачи успевают отработать.
