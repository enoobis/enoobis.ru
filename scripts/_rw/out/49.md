модификатор **async** и оператор **await** упрощают написание асинхронного кода. конструкция async-await позволяет обойтись без прямого обращения к api класса Future, в частности к его методам then и catchError. компилятор преобразует тело асинхронной функции в конечный автомат, который возобновляется при завершении ожидаемого Future, поэтому код сохраняет форму последовательного, а его семантика остаётся асинхронной. аналогичный механизм есть в c#, javascript и python.

для сравнения сначала приведём код, написанный с помощью api Future без async и await:

```dart
void doWork() {
	print("Начало функции doWork");
	Future<String> messageFuture = getMessage();
	messageFuture.then((message){
		print("Получено сообщение: $message");
	});
	print("Завершение функции doWork");
}

Future<String> getMessage() {
  // имитация долгой работы с помощью задержки в 3 секунды
  return Future.delayed(Duration(seconds: 3), () => "Hello Dart");
}

void main () {
  doWork();
  print("Выполнение функции main");
}
```

здесь определена функция `getMessage()`, которая получает некоторое сообщение. долгая работа имитируется в ней задержкой в три секунды. на практике на её месте может быть функция, выполняющая сетевые запросы, обращения к базе данных, чтение и запись файлов или другую тяжеловесную работу, требующую продолжительного времени.

функция `doWork()` вызывает getMessage, которая возвращает объект Future, через его метод then получает сообщение и выводит его на консоль. функция main вызывает doWork.

консольный вывод программы:

```bash
Начало функции doWork
Завершение функции doWork
Выполнение функции main
Получено сообщение: Hello Dart
```

функция doWork завершает своё выполнение раньше, чем завершится Future.

перепишем тот же код с использованием **async-await**:

```dart
Future<void> doWork() async {
	print("Начало функции doWork");
	String message = await getMessage();
	print("Получено сообщение: $message");
	print("Завершение функции doWork");
}

Future<String> getMessage() {
  // имитация долгой работы с помощью задержки в 3 секунды
  return Future.delayed(Duration(seconds: 3), () => "Hello Dart");
}

void main () {
  doWork();
  print("Выполнение функции main");
}
```

функция getMessage, выполняющая долгую работу (здесь получение сообщения), осталась прежней. основные изменения касаются функции doWork, которая обращается к getMessage за сообщением. теперь она объявлена **асинхронной**: для этого после списка параметров указывается модификатор **async**:

```dart
Future<void> doWork() async {
```

**асинхронная функция** содержит как минимум одну асинхронную операцию, хотя наряду с ней может выполнять и синхронные операции. внешне асинхронная функция выглядит как синхронная, за исключением использования ключевых слов **async** и **await**. асинхронная функция всегда возвращает Future: объявленный тип возврата `Future<void>` здесь означает, что вызывающий код получает объект Future, который завершится по окончании тела функции. return в теле async-функции завершает этот Future указанным значением.

асинхронная функция синхронно выполняет весь код до первого выражения **await**. в данном случае синхронно выполняется строка:

```dart
print("Начало функции doWork");
```

выражение **await** обозначает асинхронную операцию. **асинхронной** называется операция, которая не блокирует выполнение других операций и позволяет им выполняться до своего завершения. в данном случае это:

```dart
String message = await getMessage();
```

операндом выражения **await** обычно является объект Future. если операнд имеет другой тип, он автоматически оборачивается в Future. результатом выражения await служит значение, хранящееся в Future, и его можно получить обычным присваиванием. функция getMessage() возвращает `Future<String>`, то есть Future, который хранит строку, поэтому статический тип выражения `await getMessage()` равен String, и эта строка присваивается переменной message. дальше со строкой можно делать что угодно, например вывести на консоль.

выражение await приостанавливает выполнение асинхронной функции, пока нужный объект (здесь строка) не станет доступен. поток при этом не блокируется: управление возвращается вызывающему коду и циклу событий. функция getMessage тем временем вернула объект **Future**, операция которого уже начала выполняться.

после того как выражение **await** вернуло строку, функция doWork возобновляет выполнение и исполняет оставшийся код:

```dart
print("Получено сообщение: $message");
print("Завершение функции doWork");
```

в итоге консольный вывод выглядит так:

```bash
Начало функции doWork
Выполнение функции main
Получено сообщение: Hello Dart
Завершение функции doWork
```

если функция использует **await**, она обязательно должна быть объявлена с модификатором **async**, иначе возникает ошибка компиляции. асинхронная функция может содержать несколько выражений await. в этом случае они выполняются последовательно: следующее выражение await начинает выполняться только после завершения предыдущего.

### асинхронная функция main

выносить вызовы асинхронных операций в отдельные асинхронные функции не обязательно. асинхронной можно сделать и саму функцию main:

```dart
Future<String> getMessage() {
  // имитация долгой работы с помощью задержки в 3 секунды
  return Future.delayed(Duration(seconds: 3), () => "Hello Dart");
}
 
Future<void> main () async{
    print("Начало функции main");
    String message = await getMessage();
    print("Получено сообщение: $message");
    print("Завершение функции main");
}
```

в объявлении функции main можно убрать Future и оставить только void:

```dart
void main () async{
  print("Начало функции main");
  String message = await getMessage();
  print("Получено сообщение: $message");
  print("Завершение функции main");
}
```

dart допускает объявление async-функции с типом возврата void, однако вызывающий код тогда не получает Future и не может дождаться её завершения. для main это несущественно, а для прочих функций предпочтительна форма `Future<void>`.

### обработка ошибок

если в ходе долгой операции произошла ошибка, объект Future вместо данных будет содержать информацию об ошибке. чтобы её обработать, достаточно поместить выражение **await** в блок **try..catch**: ошибка, которой завершился Future, выбрасывается в точке await как обычное исключение.

```dart
Future<void> doWork() async {
  print("Начало функции doWork");
  try{
	String message = await getMessage();
	print("Получено сообщение: $message");
  }
  catch(e){
	print("Произошла ошибка: $e");
  }
  print("Завершение функции doWork");
}

Future<String> getMessage() {
  // с помощью оператора throw имитируем возникновение ошибки
  return Future.delayed(Duration(seconds: 3), () => throw "Сервер не отвечает");
}

void main () {
  doWork();
  print("Выполнение функции main");
}
```

для имитации ошибки используется оператор throw, после которого указывается текст ошибки. в асинхронной функции конструкция try..catch перехватывает ошибку и обрабатывает её. консольный вывод:

```bash
Начало функции doWork
Выполнение функции main
Произошла ошибка: Сервер не отвечает
Завершение функции doWork
```
