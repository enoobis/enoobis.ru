перечисление в dart, или **enum**, это тип данных с фиксированным и заранее известным набором константных значений. множество значений такого типа замкнуто: все его экземпляры перечислены в объявлении, и создать новый экземпляр во время выполнения нельзя. объявление перечисления вводится ключевым словом **enum**. простейший пример:

```dart
enum Operation{
 
    add, 
	subtract, 
	multiply
}
void main (){
     
    print(Operation.multiply);			// Operation.multiply
	print(Operation.multiply.index);	// 2
}
```

здесь объявлено перечисление Operation. внутри его тела перечисляются константы перечисления, у Operation их три: add, subtract и multiply. каждая константа является константой времени компиляции и единственным экземпляром своего значения, поэтому сравнение констант перечисления сводится к сравнению ссылок. все перечисления в dart неявно наследуют класс `Enum` из `dart:core`.

к константе перечисления обращаются через имя перечисления и точку:

```dart
print(Operation.multiply);
```

при выводе константы на консоль печатается ее квалифицированное имя "Operation.multiply": так реализован метод `toString()` у перечислений, а само имя без префикса доступно через свойство `name`. кроме того, каждой константе сопоставлен порядковый номер, доступный через поле **index** (`Operation.multiply.index`). константа Operation.multiply имеет индекс 2, потому что объявлена третьей. индексация начинается с нуля: первая константа, add, получает индекс 0, вторая индекс 1 и так далее. индекс определяется только порядком объявления, поэтому перестановка констант в исходном тексте меняет их индексы, и опираться на конкретные числовые значения при сохранении данных рискованно.

каждое перечисление определяет новый статический тип. переменную этого типа можно объявить и использовать как любую другую:

```dart
enum Operation{
 
    add, 
	subtract, 
	multiply
}
void main (){
     
	 // создаем переменную перечисления Operation
	Operation op;
	// присваиваем значение
	op = Operation.add;				
	print(op);			// Operation.add
	print(op.index);	// 0
}
```

значением такой переменной может быть только одна из констант этого перечисления. переменная `op` объявлена без инициализатора и с ненулевым типом, это допустимо для локальной переменной, поскольку анализ определенного присваивания проверяет, что до первого чтения ей будет присвоено значение.

чаще всего переменная перечислимого типа хранит состояние, от которого зависит выбор дальнейших действий. более содержательный пример:

```dart
enum Operation{
  
    add, 
    subtract, 
    multiply
}
void main (){
      
     // Тип операции задаем с помощью константы Operation.add
    runOperation(10, 5, Operation.add);
     
     // Тип операции задаем с помощью константы Operation.subtract
    runOperation(10, 5, Operation.subtract);

    // Тип операции задаем с помощью константы Operation.multiply
    runOperation(10, 5, Operation.multiply);
}
 
void runOperation(int x, int y, Operation op)
{
    int result = 0;
  
    switch (op){
        case Operation.add:
            result = x + y;
        case Operation.subtract:
            result = x - y;
        case Operation.multiply:
            result = x * y;
    }
  
    print("Результат операции равен $result");
}
```

функция runOperation принимает два числа и вид операции. в main она вызывается три раза с одними и теми же числами и разными константами Operation. конструкция `switch` по значению перечисления в dart 3 проверяется на полноту: если хотя бы одна константа не обработана и нет ветви `default`, компилятор сообщает об ошибке. ветви `case` с непустым телом не проваливаются в следующую, поэтому `break` здесь не нужен, в отличие от c и java до появления switch-выражений.

консольный вывод программы:

```bash
Результат операции равен 15
Результат операции равен 5
Результат операции равен 50
```
