dart представляет собой язык программирования общего назначения, разработанный компанией google и ориентированный прежде всего на создание прикладных приложений. основной областью его применения на сегодняшний день является разработка графических приложений на кроссплатформенном фреймворке flutter. flutter позволяет из одной кодовой базы получать клиентские веб-приложения, мобильные приложения для android и ios и десктопные приложения для windows, macos и linux. программа на dart с общим кодом компилируется под все поддерживаемые платформы: android, ios, windows, linux, macos и веб-браузер. при этом сфера применения dart фреймворком flutter не исчерпывается: язык используется и для консольных утилит, и для серверных приложений.

в своём развитии dart испытал влияние более ранних языков, в первую очередь smalltalk, java и javascript. синтаксически он принадлежит к семейству си-подобных языков. dart является объектно-ориентированным языком с последовательной объектной моделью: любое значение в программе, включая числа, логические значения, функции и `null`, представляет собой экземпляр некоторого класса. в этом dart ближе к smalltalk и kotlin, чем к java, где примитивные типы стоят вне иерархии объектов. типизация в dart статическая и звуковая (sound), с локальным выводом типов, а начиная с третьей версии null-безопасность является обязательной частью системы типов.

язык быстро развивается. текущая мажорная версия 3, в её рамках регулярно выходят минорные версии.

если dart используется вместе с flutter, отдельно устанавливать его не требуется: установочный пакет flutter уже содержит инструментарий dart. поскольку flutter остаётся лишь частным случаем применения языка, далее рассматривается самостоятельная установка dart sdk.

### установка dart на windows

для работы с dart необходим dart sdk. zip-архив с sdk загружается с адреса [https://dart.dev/get-dart/archive](https://dart.dev/get-dart/archive) и распаковывается на жёсткий диск.

![установка dart](/uploads/course-lectures/9b6e3e282447e91a80c81ef1e6b9d52d5b005341.png)

на странице загрузки представлены пакеты для windows, linux и macos. в курсе используется стабильная сборка, рекомендуемая для разработки, поэтому нужный пакет выбирается в секции "stable channel".

в качестве примера dart sdk распакован в каталог **C:\dart-sdk**. в подкаталоге bin распакованного sdk находится программа **dart.exe**:

![установка dart sdk на windows](/uploads/course-lectures/c3a2ccf6e7c71e2ef2b27f93062b5b0d35463612.png)

именно эта утилита запускает программы на dart. она же служит единой точкой входа для остальных инструментов sdk: создания проектов, управления зависимостями, анализа, форматирования и компиляции кода.

### установка на macos

на macos проще всего установить dart sdk через пакетный менеджер homebrew. если homebrew ещё не установлен, его устанавливают командой

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

после этого в терминале последовательно выполняются две команды: первая подключает репозиторий формул dart, вторая устанавливает sdk.

```
brew tap dart-lang/dart
brew install dart
```

### установка на linux

на linux (дистрибутивы семейства debian) сначала выполняется однократная настройка: устанавливается поддержка https для apt, импортируется ключ подписи google и добавляется репозиторий пакетов dart:

```bash
sudo apt-get update
sudo apt-get install apt-transport-https
wget -qO- https://dl-ssl.google.com/linux/linux_signing_key.pub | sudo gpg --dearmor -o /usr/share/keyrings/dart.gpg
echo 'deb [signed-by=/usr/share/keyrings/dart.gpg arch=amd64] https://storage.googleapis.com/download.dartlang.org/linux/debian stable main' | sudo tee /etc/apt/sources.list.d/dart_stable.list
```

затем устанавливается сам dart sdk:

```bash
sudo apt-get update
sudo apt-get install dart
```

### проверка установки

после установки следует убедиться, что sdk доступен и настроен правильно. для этого в консоли запрашивается его версия:

```bash
dart --version
```

при корректной установке и настройке консоль выведет текущую версию dart sdk, например:

```bash
C:> dart --version
Dart SDK version: 3.2.2 (stable) (Tue Nov 28 11:22:54 2023 +0000)
```

### первая программа

для первой программы на жёстком диске выделяется каталог, в примере это **C:\dart**. в нём создаётся текстовый файл **main.dart** (исходные файлы dart по соглашению имеют расширение ***.dart**). в любом текстовом редакторе в файл помещается следующий код:

```dart
void main() {
  print("Hello enoobis.ru!");
}
```

![первая программа на языке dart на windows](/uploads/course-lectures/4e39e827d6789b6a4a57bbebe5788a5b4578a03c.png)

любая исполняемая программа на dart обязана содержать функцию верхнего уровня с именем **main**, которая служит точкой входа. в этом примере её возвращаемый тип **void**, а параметров она не принимает, поэтому после имени стоят пустые скобки. в отличие от java и c#, функция main не обязана быть членом какого-либо класса: dart допускает функции верхнего уровня.

тело функции заключается в фигурные скобки. здесь в функции main вызывается другая функция, **print()**, которая выводит на консоль переданную строку, в данном примере "Hello enoobis.ru!".

для запуска программы в командной строке или терминале командой **cd** выполняется переход в каталог с файлом **main.dart**.

затем программа компилируется и запускается командой:

```bash
dart main.dart
```

здесь вызывается программа **dart** (dart.exe) из sdk, которой передаётся скрипт **main.dart**. в таком режиме код исполняется виртуальной машиной dart с jit-компиляцией, что ускоряет цикл разработки. программа выводит на консоль строку:

![первая программа на dart на windows](/uploads/course-lectures/5ec3b4e971da2c1ab88497e91218b03034f78322.png)

### компиляция программы

утилита dart.exe запускает программу, но для распространения нужен исполняемый файл, который можно запускать в любой момент без dart.exe и переносить на другой компьютер с той же операционной системой. для его получения утилите dart.exe вместе с исходным файлом передаётся команда **compile exe**. после флага **-o** указываются путь и имя создаваемого файла. например:

```bash
dart compile exe main.dart -o hello.exe
```

в результате будет скомпилирован файл **hello.exe**. в этом режиме используется ahead-of-time компиляция в машинный код целевой платформы, а в исполняемый файл встраивается компактная среда выполнения dart, поэтому установленный sdk для его запуска не нужен.

компиляция и запуск полученного файла:

![компиляция программы на dart с помощью dart compile exe](/uploads/course-lectures/6dbb520b557db44d3837c4bf18bc51eed14f193c.png)

после этого в каталоге программы появляется файл **hello.exe**, который запускается независимо от dart.exe.

при запуске в windows powershell исполняемый файл из текущего каталога вызывается по пути "./hello.exe", поскольку powershell не ищет команды в текущем каталоге. в классической командной строке windows достаточно написать "hello.exe" или "hello".
