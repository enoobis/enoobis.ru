расширения (extension methods) позволяют добавить функциональность к уже существующему типу без изменения его исходного кода и без наследования. это особенно полезно, когда класс принадлежит сторонней библиотеке или стандартной библиотеке и его исходный код недоступен для правки. общий синтаксис расширения:

```dart
extension on имя_класса {

	// код расширения
}
```

после слов **extension on** указывается тип, для которого определяется расширение. в фигурных скобках следует тело расширения: методы, геттеры, сеттеры и операторы. полей экземпляра расширение объявлять не может, так как оно не меняет структуру объекта, а только добавляет статически привязанные члены.

в качестве примера добавим встроенному типу **int** метод возведения в степень:

```dart
// расширение для класса int
extension on int {

    double pow(int n) {        // метод возведения в степень
        double result = 1;
        for (int i=0; i < n.abs(); i++) {
            result *= this;
        }
        if(n < 0) result = 1 / result;
        return result;
    }
}
void main (){

    int number = 2;
    print(number.pow(2));       // 4.0
    print(number.pow(-2));      // 0.25
    print(number.pow(3));       // 8
    print(number.pow(-3));      // 0.125
}
```

расширение типа int содержит один метод pow, который принимает показатель степени и вычисляет результат в цикле. показатель может быть как положительным, так и отрицательным, поэтому число итераций определяется модулем показателя, который возвращает метод `abs()`. пока счетчик не достигнет модуля показателя, переменная result последовательно умножается на текущее число:

```dart
for (int i=0; i < n.abs(); i++) {
    result *= this;
}
```

текущее число, то есть объект, на котором вызван метод и который возводится в степень n, доступно внутри расширения через **this**. для отрицательного показателя в конце берется обратная величина. метод возвращает `double`, поэтому при вызове `number.pow(3)` на консоль будет выведено `8.0`, а не `8`, как указано в комментарии.

после этого метод pow вызывается так же, как собственные методы класса int:

```dart
int number = 2;
print(number.pow(2));       // 4.0
```

синтаксическое сходство обманчиво: член расширения разрешается статически, по статическому типу выражения слева от точки, а не через динамическую диспетчеризацию. поэтому расширения не работают для выражений типа `dynamic`, а если у самого типа есть член с тем же именем, приоритет имеет член типа. по той же причине расширение без имени, как в этих примерах, доступно только в той библиотеке, где оно объявлено: чтобы импортировать расширение в другую библиотеку или вызвать его явно, ему нужно дать имя.

аналогично в расширении можно определять свойства с геттерами и сеттерами:

```dart
// расширение для класса int
extension on int {

    int get square => this * this;  		// квадрат числа
    int get cube => this * this * this;  // число в кубе

    double pow(int n) {
        double result = 1;
        for (int i=0; i < n.abs(); i++) {
            result *= this;
        }
        if(n < 0) result = 1 / result;
        return result;
    }
}
void main (){

    int number = 2;
    print(number.square);     // 4
    print(number.cube);      // 8 
}
```

другой пример:

```dart
extension on String {

    bool get isEmptyOrWhiteSpace => this.trim().length == 0;
}
void main (){

    String text = "   ";
    print(text.isEmptyOrWhiteSpace);  	// true
	text = "";    
    print(text.isEmptyOrWhiteSpace);	// true
    text = "h";    
    print(text.isEmptyOrWhiteSpace); 	// false 
}
```

класс String предоставляет свойство isEmpty, которое возвращает `true` для пустой строки. строка из одних пробелов формально не пуста, и `isEmpty` для нее вернет false. чтобы такая строка тоже считалась пустой, определяется дополнительный геттер isEmptyOrWhiteSpace:

```dart
bool get isEmptyOrWhiteSpace => this.trim().length == 0;
```

к текущей строке применяется метод trim(), который удаляет начальные и конечные пробельные символы и возвращает результат как новую строку. если длина новой строки равна 0, исходная строка пуста или состоит только из пробелов. явное `this.` здесь необязательно: внутри расширения обращение к членам расширяемого типа без квалификатора также разрешается через `this`.

более сложный пример:

```dart
extension on String {
    String get encoded =>_code(1);
    String get decoded =>_code(-1);
    
    String _code(int step) {
        final output = StringBuffer();
        for (final codePoint in runes) {
            output.writeCharCode(codePoint + step);
        }
        return output.toString();
    }
}
void main (){

    String text = "Hello";
    String secret = text.encoded;
    print(secret);     // Ifmmp
    String original = secret.decoded;
    print(original);    // Hello
}
```

здесь для класса String определены два геттера: encoded возвращает зашифрованную строку, decoded расшифрованную. фактическую работу выполняет приватный метод _code(). он принимает параметр step, задающий сдвиг кодовых точек строки. имя с подчеркиванием делает метод приватным на уровне библиотеки, как и для обычных членов класса.

строки в dart неизменяемы, поэтому для пошаговой сборки результата используется объект StringBuffer, изменяемый строковый буфер, который позволяет избежать создания промежуточной строки на каждом шаге:

```dart
final output = StringBuffer();
```

цикл for-in проходит по символам текущей строки, полученным через свойство **runes**. оно возвращает последовательность кодовых точек unicode в виде целых чисел, в отличие от `codeUnits`, где перечисляются кодовые единицы utf-16:

```dart
for (final codePoint in runes) {
    output.writeCharCode(codePoint + step);
}
```

метод `output.writeCharCode()` добавляет в буфер один символ по его числовому коду. в буфер записывается код символа, сдвинутый на step. при положительном step сдвиг идет вперед: вместо символа "A" записывается "B", вместо "B" записывается "C". при отрицательном step сдвиг идет назад. получается простейший шифр сдвига, подобный шифру цезаря без циклического переноса по алфавиту.

в конце метод toString строкового буфера возвращает итоговую строку, которая и является результатом метода.

затем в программе свойства encoded и decoded позволяют получить из строки зашифрованное и расшифрованное сообщение:

```dart
String text = "Hello";
String secret = text.encoded;
print(secret);     // Ifmmp
String original = secret.decoded;
print(original);    // Hello
```
