помимо обычных методов и полей класс может иметь статические поля и методы. статические члены относятся к классу в целом, а не к отдельным экземплярам. при объявлении перед ними указывается ключевое слово **static**.

### статические поля

статические поля хранят состояние класса как такового. объявляется такое поле так же, как обычное, но с ключевым словом **static** впереди. рассмотрим класс Employee, который представляет работника:

```dart
class Employee{
	
	String name;
	int age;
	static int retirementAge = 60;	 // статическое поле
	
	Employee(this.name, this.age);
	
	checkAge(){
		if(age >= retirementAge){
			print("Пора на пенсию");
		}
		else{
			print("До пенсии еще ${retirementAge - age} лет");
		}
	}
}
void main (){
	
	Employee bob = Employee("Bob", 55);
	bob.checkAge();
	Employee.retirementAge = 65;	// меняем значение статического поля
	bob.checkAge();
}
```

в классе работника определены поля для имени и возраста: у каждого работника они свои. кроме того, определено статическое поле retirementAge для пенсионного возраста. оно относится не к конкретному работнику, а ко всем работникам сразу, то есть к классу Employee в целом, поскольку пенсионный возраст не задаётся для каждого работника отдельно. внутри класса это поле используется так же, как любое другое, по простому имени.

вне класса к статическому полю обращаются через имя класса, например чтобы изменить его значение:

```dart
Employee.retirementAge = 65;
```

в отличие от java, в dart обратиться к статическому члену через ссылку на экземпляр (`bob.retirementAge`) нельзя: статические члены не входят в интерфейс экземпляра и не наследуются подклассами.

с точки зрения памяти статические поля выгоднее нестатических. поле экземпляра существует в каждом объекте и занимает память с момента его создания, независимо от того, используется значение или нет. статическое поле существует в единственном экземпляре на весь класс, а его инициализатор в dart вычисляется лениво, при первом обращении. соответственно память под значение и время на его вычисление расходуются только тогда, когда поле действительно начинает использоваться в программе. статические методы вообще не требуют инициализации и не привязаны к памяти конкретного объекта.

### статические константы

если пенсионный возраст менять не планируется, его можно определить как статическую константу:

```dart
class Employee{
	
	String name;
	int age;
	static const int retirementAge = 65;
	
	Employee(this.name, this.age);
	
	checkAge(){
		if(age >= retirementAge){
			print("Пора на пенсию");
		}
		else{
			print("До пенсии еще ${retirementAge - age} лет");
		}
	}
}
void main (){
	
	Employee bob = Employee("Bob", 55);
	bob.checkAge();
	print("Retirenment age: ${Employee.retirementAge}");
}
```

статическая константа объявляется сочетанием `static const`:

```dart
static const int retirementAge = 65;
```

значение такой константы известно во время компиляции и в программе изменить его нельзя. в dart модификатор const для члена класса допустим только вместе со static, поскольку константа времени компиляции по определению не может зависеть от конкретного экземпляра.

### статические методы

статические методы также относятся к классу в целом и объявляются с ключевым словом `static`. как правило, они выполняют вычисления, которые не затрагивают состояние или поведение объекта:

```dart
void main (){
	
	int a = Operation.sum(3, 5);
	int b = Operation.subtract(15, 7);
	int c = Operation.multiply(3, 5);
	print("a=$a  b=$b  c=$c");	// a=8  b=8  c=15
}
class Operation{
     
    static int sum(int x, int y) => x + y; 
    static int subtract(int x, int y) => x - y;
    static int multiply(int x, int y) => x * y;
}
```

для методов sum, subtract и multiply не важно, какой экземпляр класса Operation используется: они работают только со своими параметрами и не затрагивают состояние класса, поэтому их естественно сделать статическими. статический метод вызывается без получателя и диспетчеризуется статически, поэтому переопределить его в подклассе нельзя. в dart такие функции часто объявляют и просто на верхнем уровне библиотеки, без класса-обёртки.

статические методы могут использоваться для управления доступом к статическим приватным полям, то есть к состоянию, общему для всего класса. в статических методах при этом недоступны нестатические поля и методы класса, так как в них отсутствует `this`. пусть есть класс Person, размещённый в файле **person.dart**:

```dart
class Person{

	String _name;
	int _id = 0; 
    static int _count = 0;

    Person(this._name){

        _count += 1;
        _id = _count;
    }
    void display(){
        print("Id: $_id \tName: $_name");
    }
	// статический метод
    static int getCount() => _count;
}
```

в классе Person определены три приватных поля. приватность в dart определяется префиксом `_` и действует на уровне библиотеки, то есть файла, а не класса. два поля нестатические: _name и _id, они хранят соответственно имя и уникальный идентификатор человека. третье поле, _count, статическое: оно хранит количество созданных объектов Person. это количество относится к классу в целом и не зависит от конкретного объекта, поэтому поле объявлено статическим.

в конструкторе при создании объекта значение _count увеличивается на 1 и присваивается полю _id. так каждый объект Person получает уникальный числовой идентификатор.

в классе также определён статический метод getCount, который возвращает значение статической переменной _count. благодаря приватности поля код вне библиотеки не может произвольно изменить его значение, а метод getCount при этом позволяет его прочитать.

в программе этот статический метод используется, чтобы получить количество созданных объектов

```dart
import 'person.dart'; // подключаем файл с классом Person

void main (){
     
    Person tom = Person("Tom");
    Person bob = Person("Bob");
    Person sam = Person("Sam");

    tom.display();
    bob.display();
    sam.display();

    // получаем количество созданных объектов Person
    int personCount = Person.getCount();
    print("Person count: $personCount");
}
```

консольный вывод программы

```bash
Id: 1   Name: Tom
Id: 2   Name: Bob
Id: 3   Name: Sam
Person count: 3
```

### статические свойства

можно определять и статические свойства, то есть статические геттеры и сеттеры. в предыдущем примере вместо статического метода можно было использовать статический геттер. статические геттеры и сеттеры определяются так же, как нестатические, только перед ними указывается слово **static**:

```dart
class Person{

	String _name;
	int _id = 0; 
    static int _count = 0;

    Person(this._name){

        _count += 1;
        _id = _count;
    }
    void display(){
        print("Id: $_id \tName: $_name");
    }
	// статический геттер
    static int get count => _count;
}
```

к статическим геттерам и сеттерам обращаются через имя класса:

```dart
import 'person.dart';	// подключаем класс Person

void main (){
     
    Person tom = Person("Tom");
    Person bob = Person("Bob");
    Person sam = Person("Sam");

    tom.display();
    bob.display();
    sam.display();

    // обращаемся к статическому геттеру
    int personCount = Person.count;
    print("Person count: $personCount");
}
```
