для отправки ответа клиенту сервер использует класс **HttpResponse**. он реализует интерфейс **IOSink**, поэтому экземпляр ответа является потоком для записи: данные добавляются в него последовательно, а фактическая передача по сети выполняется асинхронно средой выполнения.

для записи в поток ответа класс предоставляет следующие методы:

- `write(Object? object)` : записывает в поток произвольный объект

- `writeAll(Iterable objects, [String separator = ""])` : записывает в поток набор объектов

- `writeCharCode(int charCode)` : записывает в поток числовой код символа

- `writeln([Object? object = ""])` : записывает в поток произвольный объект с переводом строки

методы `write` и `writeln` принимают любой объект и записывают результат вызова у него `toString()`, закодированный в текущей кодировке потока. чтобы закрыть поток ответа и отправить данные клиенту, вызывается метод **close()**. до его вызова ответ считается незавершённым, и клиент продолжает ожидать данные.

поток ответа доступен через свойство **response** объекта **HttpRequest**: каждый запрос связан ровно с одним ответом.

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
  print("Сервер запущен...");
  await server.forEach((HttpRequest request) {

    final response = request.response;  // получаем объект ответа HttpResponse
    response.write("Привет мир");
    response.write("Пока мир");
    response.close(); // отправляем ответ
  });
}
```

здесь в поток ответа последовательно записываются две строки методом `write()`. подобным образом в поток можно добавлять произвольное число фрагментов данных.

![отправка http ответа из http-сервера на dart](/uploads/course-lectures/1044c1e7c65171a5ad3ddb51199be5ed5d2f988c.png)

при обращении к приложению из браузера видно, что строки слились: поток не добавляет никаких разделителей, и тело ответа содержит данные ровно в том порядке, в каком они были записаны. перевод строки можно включить в саму строку либо воспользоваться методом `writeln`:

```dart
response.writeln("Привет мир");
response.writeln("Пока мир");
```

### отправка заголовков

для работы с заголовками в классе HttpResponse определено свойство **headers**:

```dart
HttpHeaders get headers;
```

свойство имеет тип **HttpHeaders**, который предоставляет методы управления заголовками. заголовок добавляется методом **add()**, получающим имя заголовка и его значение. заголовки передаются клиенту перед телом ответа, поэтому их нужно установить до первой записи в поток: после начала записи тела коллекция заголовков становится неизменяемой, и попытка её изменить приводит к исключению.

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
  print("Сервер запущен...");
  await server.forEach((HttpRequest request) {

    final response = request.response;
    // добавляем заголовок
    response.headers.add("Secret", "12345");
    response.write("Hello enoobis.ru");
    response.close();
  });
}
```

здесь добавляется произвольный заголовок "Secret" со значением "12345":

```dart
response.headers.add("Secret", "12345");
```

этот заголовок можно увидеть в инструментах разработчика браузера:

![установка заголовков ответа для httpserver в языке dart](/uploads/course-lectures/1e04e286c4e6af71cf2af5d0ee62e3dae6f47d61.png)

заголовок также устанавливается методом **set()**, который принимает название заголовка и его значение. различие между методами семантическое: `add` добавляет ещё одно значение к уже имеющимся значениям заголовка, а `set` удаляет прежние значения и оставляет только переданное.

```dart
response.headers.set("Secret", "12346");
```

для наиболее употребительных заголовков класс HttpHeaders определяет типизированные свойства:

- contentLength : устанавливает заголовок "Content-Length" (размер ответа)

- contentType : устанавливает заголовок "Content-Type" (тип содержимого) и имеет тип `ContentType`

- date : устанавливает заголовок "date" (дата формирования сообщения) и имеет тип `DateTime?`

- expires : устанавливает заголовок "expires" и имеет тип `DateTime?`

- host : устанавливает заголовок "host"

- ifModifiedSince : устанавливает заголовок "If-Modified-Since" и имеет тип `DateTime?`

- port : устанавливает заголовок "port"

преимущество этих свойств перед `add` в статической типизации: значение даты передаётся как `DateTime` и сериализуется в формат http автоматически, а ошибка в типе обнаруживается во время компиляции. пример использования:

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
  print("Сервер запущен...");
  await server.forEach((HttpRequest request) {

    final response = request.response;
    // добавляем заголовоки
    response.headers.contentType = ContentType("text", "plain");
    response.headers.host = "enoobis.ru";
    response.headers.date = DateTime.now();

    response.write("Hello enoobis.ru");
    response.close();
  });
}
```

значение заголовка Content-Type задаётся объектом **ContentType**, в конструктор которого передаётся тип содержимого. первый параметр конструктора задаёт основной тип, второй параметр задаёт подтип:

```dart
response.headers.contentType= ContentType("text", "plain");
```

в данном примере тип содержимого равен "text/plain": "text" является основным типом, "plain" подтипом. конструктор `ContentType` также принимает необязательный именованный параметр `charset`.

при ручном вводе имени стандартного заголовка легко допустить опечатку, особенно в длинных названиях, и такая ошибка проявится только во время выполнения. поэтому класс HttpHeaders содержит набор статических строковых констант с именами заголовков. основные из них:

- `acceptCharsetHeader` : представляет заголовок "accept-charset"

- `acceptEncodingHeader` : представляет заголовок "accept-encoding"

- `acceptHeader` : представляет заголовок "accept"

- `acceptLanguageHeader` : представляет заголовок "accept-language"

- `acceptRangesHeader` : представляет заголовок "accept-ranges"

- `ageHeader` : представляет заголовок "age"

- `allowHeader` : представляет заголовок "allow"

- `authorizationHeader` : представляет заголовок "authorization"

- `cacheControlHeader` : представляет заголовок "cache-control"

- `connectionHeader` : представляет заголовок "connection"

- `contentEncodingHeader` : представляет заголовок "content-encoding"

- `contentLanguageHeader` : представляет заголовок "content-language"

- `contentLengthHeader` : представляет заголовок "content-length"

- `contentRangeHeader` : представляет заголовок "content-range"

- `contentTypeHeader` : представляет заголовок "content-type"

- `cookieHeader` : представляет заголовок "cookie"

- `dateHeader` : представляет заголовок "date"

- `etagHeader` : представляет заголовок "etag"

- `expiresHeader` : представляет заголовок "expires"

- `hostHeader` : представляет заголовок "host"

- `lastModifiedHeader` : представляет заголовок "last-modified"

- `locationHeader` : представляет заголовок "location"

- `pragmaHeader` : представляет заголовок "pragma"

- `refererHeader` : представляет заголовок "referer"

- `serverHeader` : представляет заголовок "server"

- `setCookieHeader` : представляет заголовок "set-cookie"

- `userAgentHeader` : представляет заголовок "user-agent"

- `varyHeader` : представляет заголовок "vary"

- `viaHeader` : представляет заголовок "via"

- `warningHeader` : представляет заголовок "warning"

- `wwwAuthenticateHeader` : представляет заголовок "www-authenticate"

имена в константах записаны строчными буквами: по спецификации http имена заголовков нечувствительны к регистру. применение некоторых констант:

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
  print("Сервер запущен...");
  await server.forEach((HttpRequest request) {

    final response = request.response;
    // добавляем заголовки
    response.headers.add(HttpHeaders.contentTypeHeader, "text/plain; charset=utf-8");
    response.headers.add(HttpHeaders.hostHeader, "enoobis.ru");
    response.headers.add(HttpHeaders.dateHeader, DateTime.now());

    response.write("Hello enoobis.ru");
    response.close();
  });
}
```

### отправка html

html-код представляет собой обычную строку, содержащую html-элементы. чтобы клиент интерпретировал ответ как html-документ, заголовку `ContentType` нужно присвоить значение "text/html". без этого заголовка браузер получит ответ как простой текст и выведет разметку без обработки.

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
  print("Сервер запущен...");
  await server.forEach((HttpRequest request) {

    final response = request.response;
    response.headers.contentType= ContentType("text", "html");
    response.write("<h1>Hello enoobis.ru</h1><h3>Hello from Dart</h3>");
    response.close();
  });
}
```

в качестве ответа отправляется html-код с двумя элементами, двумя заголовками:

```dart
response.write("<h1>Hello enoobis.ru</h1><h3>Hello from Dart</h3>");
```
