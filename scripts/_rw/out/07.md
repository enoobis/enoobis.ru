dart поддерживает все распространённые арифметические операции. их операндами являются числа. различают бинарные арифметические операции (над двумя операндами) и унарные (над одним операндом). к бинарным относятся следующие:

- `+` сложение двух чисел:

```dart
int a = 10;
int b = 7;
int c = a + b;  // 17
int d = 4 + b;  // 11
```

- `-` вычитание двух чисел:

```dart
int a = 10;
int b = 7;
int c = a - b;  // 3
int d = 4 - a;  // -6
```

- `*` умножение двух чисел

```dart
int a = 10;
int b = 7;
int c = a * b;  // 70
int d = b * 5;  // 35
```

- `/` деление двух чисел. результат этой операции всегда имеет тип double, даже если оба операнда целые и делятся нацело. в этом dart расходится с java, c# и c, где деление целых даёт целое.

```dart
int a = 20;
int b = 5;
double c = a / b;  // 4.0
double d = 22.5 / 4.5;  // 5.0
```

- `~/` целочисленное деление двух чисел. результат всегда имеет тип int, дробная часть отбрасывается (округление в сторону нуля):

```dart
int a = 33;
int b = 5;
int c = a ~/ b;  // 6
int d = 22 ~/ 4; // 5
```

- `%` остаток от деления двух чисел:

```dart
int a = 33;
int b = 5;
int c = a % b;  // 3
int d = 22 % 4; // 2 (22 - 4*5 = 2)
```

для отрицательных операндов следует учитывать, что `%` в dart вычисляет евклидов остаток, который никогда не бывает отрицательным: `-7 % 3` даёт 2, тогда как в java и c# результат был бы -1. остаток со знаком делимого возвращает метод `remainder()`.

кроме того, есть две унарные арифметические операции над одной переменной: ++ (инкремент) и -- (декремент). каждая существует в префиксной и постфиксной форме. применять их можно только к выражениям, допускающим присваивание, например к переменным:

- ++ (префиксный инкремент) увеличивает переменную на единицу, например `z=++y` (сначала значение переменной y увеличивается на 1, затем новое значение присваивается переменной z)

```dart
int a = 8;
int b = ++a;
print(a);	// 9
print(b);	// 9
```

- ++ (постфиксный инкремент) также увеличивает переменную на единицу, например `z=y++` (сначала прежнее значение переменной y присваивается переменной z, затем значение y увеличивается на 1)

```dart
int a = 8;
int b = a++;
print(a);	// 9
print(b);	// 8
```

- `-- (префиксный декремент)` уменьшает переменную на единицу, например `z=--y` (сначала значение переменной y уменьшается на 1, затем новое значение присваивается переменной z)

```dart
int a = 8;
int b = --a;
print(a);	// 7
print(b);	// 7
```

- `-- (постфиксный декремент)` например `z=y--` (сначала прежнее значение переменной y присваивается переменной z, затем значение y уменьшается на 1)

```dart
int a = 8;
int b = a--;
print(a);	// 7
print(b);	// 8
```

### приоритет арифметических операций

одни операции имеют более высокий приоритет, чем другие, и поэтому выполняются раньше. операции в порядке убывания приоритета:

++ (постфиксный инкремент), -- (постфиксный декремент)

++ (префиксный инкремент), -- (префиксный декремент)

`*` (умножение), `/` (деление), `~/` (целочисленное деление), `%` (остаток от деления)

`+` (сложение), `-` (вычитание)

бинарные операции одного уровня приоритета левоассоциативны, то есть выполняются слева направо: `a - b - c` вычисляется как `(a - b) - c`. приоритет операций необходимо учитывать при вычислении составных арифметических выражений:

```dart
int a = 8;
int b = 7;
int c = a + 5 * ++b;      
print(c);	// 48
```

первой выполняется операция инкремента `++b`, имеющая наивысший приоритет: она увеличивает значение переменной b и возвращает его в качестве результата. затем выполняется умножение `5 * ++b`, и только последним выполняется сложение `a + 5 * ++b`.

скобки позволяют изменить порядок вычислений:

```dart
int a = 8;
int b = 7;
int c = (a + 5) * ++b;    
print(c);	// 104
```

хотя сложение имеет более низкий приоритет, здесь первым выполняется именно сложение, а не умножение, поскольку оно заключено в скобки.
