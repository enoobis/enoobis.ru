### определение списков

список, или тип **List**, представляет упорядоченную последовательность значений с доступом по индексу. в отличие от java, где массив и `ArrayList` являются разными сущностями, в dart отдельного типа массива нет, и его роль выполняет `List`. для определения списка служит литерал в квадратных скобках. пустой список:

```dart


var list = [];
```

в квадратных скобках можно сразу через запятую перечислить элементы списка:

```dart


var list = ["Tom", "Bob", "Sam"];
```

здесь список содержит три элемента, три строки. тип элементов в таком случае выводится компилятором из литерала: первый список получает тип `List<dynamic>`, поскольку выводить тип не из чего, второй тип `List<String>`. тип можно указать и явно:

```dart


List<String> list = ["Tom", "Bob", "Sam"];
```

после имени типа List в угловых скобках указывается аргумент типа, то есть тип элементов списка. в примере это String, и список содержит данные этого типа. обобщения в dart реифицированы: аргумент типа сохраняется во время выполнения, поэтому список `List<String>` знает тип своих элементов и проверка `list is List<String>` выполнима, в отличие от java со стиранием типов.

функция print выводит содержимое списка на консоль:

```dart


void main (){

	

    var list = ["Tom", "Bob", "Sam"];

	print(list);    // ["Tom", "Bob", "Sam"]

}
```

на практике строки при выводе не заключаются в кавычки, и консоль покажет `[Tom, Bob, Sam]`.

### обращение к элементам списка

для обращения к элементам списка применяются индексы. индекс представляет номер элемента, нумерация начинается с нуля, поэтому первый элемент имеет индекс 0, а третий индекс 2: `list[2]`. оператор индексирования используется как для чтения, так и для записи значения элемента:

```dart


void main (){

	

    var list = ["Tom", "Bob", "Sam"];

    var first = list[0];    // получаем первый элемент

    print(first);           //Tom

    list[0] = "Alice";      // изменяем первый элемент

	print(list);            // ["Alice", "Bob", "Sam"]

}
```

обращение по несуществующему индексу приводит к ошибке:

```dart


var list = ["Tom", "Bob", "Sam"];

list[9] = "Alice";      // ! Ошибка - элемента с индексом 9 не существует
```

в этом списке только 3 элемента, поэтому элемента с индексом 9 не существует. проверка границ выполняется во время выполнения, и такое обращение порождает исключение `RangeError`, компилятор его не обнаруживает.

### свойства списков

основные свойства списков:

- first : возвращает первый элемент

- last : возвращает последний элемент

- length : возвращает длину списка

- reversed : возвращает последовательность, в которой элементы расположены в обратном порядке

- isEmpty : возвращает true, если список пуст

- isNotEmpty : возвращает true, если список содержит хотя бы один элемент

применение свойств:

```dart


void main (){

	

    var list = ["Tom", "Bob", "Sam"];

	print(list.first);          // Tom

	print(list.last);           // Sam

	print(list.isEmpty);        // false

	print(list.isNotEmpty);     // true

	print(list.length);         // 3



    var reversed = list.reversed;   // получаем список в обратном порядке

    print(reversed);            // (Sam, Bob, Tom)

}
```

свойство reversed возвращает не новый список, а ленивый `Iterable`, который обходит исходный список с конца. поэтому при выводе он печатается в круглых скобках, как и любой `Iterable`, не являющийся списком. чтобы получить настоящий список, нужно вызвать у результата `toList()`. для пустого списка обращение к first или last порождает исключение `StateError`.

### методы списка

класс List предоставляет обширный набор методов. основные из них:

- add(E value) : добавляет элемент в конец списка

- addAll(Iterable<E> iterable) : добавляет в конец списка элементы другой коллекции

- clear() : удаляет все элементы из списка

- indexOf(E element) : возвращает индекс первого вхождения элемента

- insert(int index, E element) : вставляет элемент на заданную позицию

- remove(Object value) : удаляет объект из списка (удаляется только первое вхождение элемента)

- removeAt(int index) : удаляет элемент по индексу

- removeLast() : удаляет последний элемент списка

- removeRange(int start, int end) : удаляет диапазон элементов между индексами start и end

- removeWhere(bool test(E element)) : удаляет элементы, которые удовлетворяют условию, передаваемому в виде функции test

- forEach(void f(E element)) : выполняет над каждым элементом действие, заданное функцией-параметром, аналог цикла for..in

- sort() : сортирует список

- sublist(int start, [ int end ]) : возвращает часть списка от индекса start до индекса end

- contains(Object element) : возвращает true, если элемент содержится в списке

- join([String separator = "" ]) : объединяет все элементы списка в строку. необязательный параметр separator задает разделитель элементов в строке

- skip(int count) : возвращает коллекцию без первых count элементов

- take(int count) : возвращает коллекцию из первых count элементов

- where(bool test(E element)) : возвращает коллекцию из элементов, удовлетворяющих условию, которое передается в виде функции

буква E в сигнатурах обозначает параметр типа класса `List<E>`, то есть тип элементов. методы skip, take и where, как и reversed, возвращают ленивый `Iterable`: элементы вычисляются только при обходе результата. это лишь краткий перечень основных возможностей класса List. полный список полей, методов и конструкторов приведен в [документации](https://api.dart.dev/stable/dart-core/List-class.html)

### перебор списков

для перебора списка подходят обычные циклы for и while:

```dart


void main (){

	

	var list = ["Tom", "Bob", "Sam"];

	for(int i=0; i < list.length; i++){

		print(list[i]);

	}

}
```

переменная-счетчик i выполняет роль индекса. индекс увеличивается, пока не достигнет значения list.length, то есть длины списка.

для коллекций также есть специальная форма цикла:

```dart


void main (){

	

    var list = ["Tom", "Bob", "Sam"];

	for (var name in list){

		print(name);

	}

}
```

при переборе списка list каждый очередной элемент помещается в переменную name, значение которой затем выводится на консоль. цикл for-in применим к любому объекту типа `Iterable` и использует его итератор. изменение длины списка во время такого обхода приводит к исключению `ConcurrentModificationError`. еще одну альтернативу представляет метод **forEach()**:

```dart


void main (){

	

    var list = ["Tom", "Bob", "Sam"];

    list.forEach(print);

}
```

в метод forEach передается функция, которая вызывается для каждого элемента списка. в примере передается сама функция print в виде отрывка (tear-off), то есть ссылки на функцию без ее вызова. при выполнении метода print вызывается для каждого элемента и выводит его значение на консоль. передать можно любую функцию, которая принимает один параметр совместимого типа. например, анонимную функцию:

```dart


void main (){

	

    var list = ["Tom", "Bob", "Sam"];

    list.forEach((name)=>print("Name: $name"));

}
```

консольный вывод:

```bash


Name: Tom

Name: Bob

Name: Sam
```

### добавление элементов

списки, созданные литералом, расширяемы, и элементы в них можно добавлять динамически. для добавления одного элемента в конец списка применяется метод **add()**, которому передается добавляемый объект:

```dart


void main (){

	

    var list = ["Tom", "Bob", "Sam"];

    list.add("Alice");

    print(list);   //  [Tom, Bob, Sam, Alice]

}
```

для добавления элементов другого списка применяется метод **addAll()**:

```dart


void main (){

	

    var people = ["Alice", "Kate"];

    var list = ["Tom", "Bob", "Sam"];

    list.addAll(people);

    print(list);   // [Tom, Bob, Sam, Alice, Kate]

}
```

для вставки объекта по заданному индексу применяется метод **insert()**. элементы, начиная с этого индекса, сдвигаются вправо:

```dart


void main (){

	

    var list = ["Tom", "Bob", "Sam"];

    list.insert(1, "Alice");    // вставляем "Alice" по индексу 1

    print(list);   // [Tom, Alice, Bob, Sam]

}
```

### удаление элементов

для удаления одного элемента применяется метод **remove()**, которому передается удаляемый элемент. элемент ищется по равенству `==`, а метод возвращает `bool`, показывающий, был ли элемент найден и удален:

```dart


void main (){

	

    var list = ["Tom", "Bob", "Sam"];

    list.remove("Bob");

    print(list);   // [Tom, Sam]

}
```

метод **removeAt()** удаляет элемент по переданному индексу:

```dart


void main (){

	

    var list = ["Tom", "Bob", "Sam"];

    list.removeAt(2);

    print(list);   // [Tom, Bob]

}
```

при недействительном индексе генерируется ошибка `RangeError`.

для удаления по условию применяется метод **removeWhere()**, которому передается функция-предикат. она принимает элемент списка и возвращает значение типа bool: true, если элемент удовлетворяет условию, и false в противном случае. например, удалим из списка все строки длиной 3 символа:

```dart


void main (){

	

    var list = ["Tom", "Alice", "Bob", "Sam", "Kate"];

    list.removeWhere((item)=>item.length ==3);  // если длина строки - 3 символа

    print(list);   // [Alice, Kate]

}
```

метод **removeRange()** удаляет элементы между двумя индексами. интервал полуоткрытый: начальный индекс включается, конечный нет. поэтому вызов `removeRange(1, 3)` удаляет элементы с индексами 1 и 2:

```dart


void main (){

	

    var list = ["Tom", "Alice", "Bob", "Sam", "Kate"];

    list.removeRange(1, 3); // удаляем с 1 по 3 индексы

    print(list);   // [Tom, Sam, Kate]

}
```

### объединение элементов списка

метод **join()** объединяет все элементы списка в строку. в качестве параметра он принимает разделитель элементов. каждый элемент предварительно преобразуется в строку вызовом `toString()`:

```dart


void main (){

	

    var list = ["Tom", "Alice", "Bob", "Sam", "Kate"];

    String items = list.join(", ");

    print(items);   // Tom, Alice, Bob, Sam, Kate

}
```

в качестве разделителя здесь выступает строка ", ". в итоге из списка `["Tom", "Alice", "Bob", "Sam", "Kate"]` будет сформирована строка `"Tom, Alice, Bob, Sam, Kate"`.

### сортировка

для сортировки применяется метод **sort()**. он изменяет сам список и ничего не возвращает:

```dart


void main (){

	

    var list = ["Tom", "Alice", "Bob", "Sam", "Kate"];

    list.sort();

    print(list);   // [Alice, Bob, Kate, Sam, Tom]

}
```

без аргументов элементы сортируются по возрастанию в их естественном порядке (строки по алфавиту). естественный порядок определяется методом `compareTo` интерфейса `Comparable`, поэтому сортировка без аргументов требует, чтобы элементы его реализовывали. порядок можно переопределить, передав в sort функцию сравнения двух объектов:

```dart
int compare(E a, E b)
```

если первый объект a больше второго объекта b, функция возвращает число больше 0, если меньше, число меньше 0. если объекты равны, возвращается 0. это тот же контракт, что у `Comparator` в java.

например, требуется сортировать строки не по алфавиту, а по длине: сначала короткие, потом длинные:

```dart


void main (){

	

    var list = ["Tom", "Alice", "Bob", "Sam", "Kate"];

    list.sort((item1, item2)=> item1.length - item2.length);

    print(list);   // [Tom, Bob, Sam, Kate, Alice]

}
```

функция сравнения здесь задана анонимной функцией:

```dart
(item1, item2)=> item1.length - item2.length
```

если первая строка item1 длиннее второй item2, возвращается положительное число, что означает, что item1 больше item2. документация не гарантирует устойчивость сортировки, поэтому взаимный порядок строк одинаковой длины, например "Tom", "Bob" и "Sam", в общем случае не определен.

### неизменяемые списки

если список определен как константа с помощью **const**, изменить его нельзя:

```dart


void main (){

	

    const list = ["Tom", "Bob", "Sam"];

    // list = ["Alice", "Kate"];   // так нельзя

    // list.add("Alex");           // так нельзя

    // list[0] = "Tomas";          // так нельзя

    print(list);   // [Tom, Bob, Sam]

}
```

к такому списку нельзя ни добавить новый элемент, ни удалить или изменить существующий, а саму переменную нельзя переприсвоить. переприсваивание const-переменной является ошибкой компиляции. попытка же изменить элементы, например `list.add`, статически допустима, поскольку тип выражения остается `List<String>`, и завершается исключением `UnsupportedError` во время выполнения. const-список является константой времени компиляции: все его элементы должны быть константами, а одинаковые константные литералы канонизируются, то есть указывают на один и тот же объект.

если же список объявлен с помощью **final**, свободы больше:

```dart


void main (){

	

    final list = ["Tom", "Bob", "Sam"];

    // list = ["Alice", "Kate"];   // так нельзя

    list.add("Alex");           // так можно

    list[0] = "Tomas";          // так можно

    print(list);   // [Tomas, Bob, Sam, Alex]

}
```

final ограничивает только переменную: ей можно присвоить значение один раз, поэтому заменить final-список целиком нельзя. сам объект списка при этом остается изменяемым, и в него можно добавлять элементы, удалять и изменять их. в этом проявляется различие между неизменяемостью ссылки и неизменяемостью объекта.

еще один способ создать неизменяемый список дает именованный конструктор **List.unmodifiable()**, которому передается коллекция с исходными элементами:

```dart


void main (){

	

    // создаем неизменяемый список

    final list = List.unmodifiable(["Tom", "Bob", "Sam"]);

    // list = ["Alice", "Kate"];   // так нельзя

    // list.add("Alex");           // так нельзя

    // list[0] = "Tomas";          // так нельзя

    print(list);   // [Tom, Bob, Sam]

}
```

в этом случае добавлять, удалять и изменять элементы списка также нельзя, как и в случае с const-списками, и попытка изменения так же приводит к ошибке во время выполнения. отличие в том, что список создается во время выполнения из произвольной коллекции, элементы которой не обязаны быть константами, а результат является копией и не зависит от последующих изменений исходной коллекции.

### фиксированные и нефиксированные списки

списки бывают фиксированными, с жестко заданной длиной, и нефиксированными, то есть расширяемыми. нефиксированные списки рассматривались выше: их длину можно менять динамически, например добавляя элементы методом **add()**.

длину фиксированного списка изменить нельзя. для его создания используется один из именованных конструкторов класса List. например, конструктор **List.filled(количество_элементов, значение_по_умолчанию)** принимает два параметра: первый задает количество элементов, второй значение, которое получат все элементы при создании списка:

```dart


void main (){



    // создаем фиксированный список

    var list = List.filled(3, "Tom");

    //list.add("Alice"); // нельзя добавить новый элемент

    print(list);   // [Tom, Tom, Tom]

}
```

здесь создается фиксированный список из трех элементов, каждый из которых равен строке "Tom". у конструктора есть именованный параметр `growable`, по умолчанию равный false, поэтому без него список получается фиксированным. все элементы получают ссылку на один и тот же объект, что существенно, если значение по умолчанию изменяемо: заполнение `List.filled(3, [])` даст три ссылки на один и тот же вложенный список.

хотя длина списка фиксирована, значения отдельных элементов менять можно:

```dart


void main (){



    // создаем фиксированный список

    var list = List.filled(3, "Tom");

    list[1] = "Bob";

    list[2] = "Sam";

    print(list);   // [Tom, Bob, Sam]

}
```

еще один способ создания фиксированного списка дает конструктор **List.generate()**:

```dart
List.generate(количество_элементов, функция_наполнения, можно_ли_добавлять)
```

первый параметр задает количество элементов. второй представляет функцию заполнения, которой передается индекс элемента и которая возвращает его значение. третий параметр является именованным параметром `growable` логического типа: при `true` список нефиксированный (расширяемый), при `false` фиксированный. по умолчанию `growable` равен true.

применение конструктора `List.generate`:

```dart


void main (){

    var list = List.generate(4, (int index) => index + 1, growable: false); // фиксированный список [1, 2, 3, 4]



    list[0] = 2o; 

    //list.add(1); // нельзя добавить новый элемент

     

    print(list);   // [20, 2, 3, 4]  

}
```

в этом примере литерал `2o` следует читать как `20`: в исходном виде строка не скомпилируется, а при значении 20 вывод совпадет с комментарием. попытка вызвать `add` у фиксированного списка приводит к исключению `UnsupportedError` во время выполнения.

### spread-оператор ...

spread-оператор **...** раскладывает коллекцию на отдельные элементы внутри литерала коллекции. он позволяет наполнить один список элементами другого. например:

```dart


void main (){

    var employees = ["Tom", "Alice", "Kate"];

    var people = ["Bob", ...employees, "Sam"];



    print(people);  // [Bob, Tom, Alice, Kate, Sam]

}
```

после оператора **...** указывается коллекция, которую нужно разложить на элементы: `...employees` раскладывает список employees. в записи:

```dart
var people = ["Bob", ...employees, "Sam"];
```

все элементы списка employees помещаются между элементами "Bob" и "Sam". в результате получается список `[Bob, Tom, Alice, Kate, Sam]`. раскладывать можно любой `Iterable`, а сам оператор работает также в литералах множеств и словарей.

для коллекций, которые могут иметь значение **null**, есть модификация оператора, **null-aware spread** или **...?**. после него указывается выражение обнуляемого типа. если значение не равно null, оно раскладывается на элементы, если равно null, ничего не добавляется:

```dart


List<String> createList(String first, List<String>? otherList)

{

    return [first, ...?otherList];

}

void main (){

    List<String>? employees = ["Alice", "Kate"];

    var people = createList("Tom", employees);



    print(people);  // [Tom, Alice, Kate]

}
```

функция createList принимает первый элемент создаваемого списка и другой список обнуляемого типа `List<String>?`. оператор **...?** позволяет передать элементы этого списка в создаваемый без явной проверки на null. обычный `...` здесь не прошел бы статическую проверку, так как при звуковой null-безопасности dart раскладывать значение обнуляемого типа запрещено.

### collection if

при задании элементов списка в литерале можно использовать условие с помощью оператора **if**:

```dart


List<String> createProgram(bool web)

{

    return ["Dart", "Flutter", if(web) "JavaScript"];

}

void main (){

    var withWeb = createProgram(true);

    var withoutWeb = createProgram(false);



    print(withWeb);     // [Dart, Flutter, JavaScript]

    print(withoutWeb);  // [Dart, Flutter]

}
```

функция createProgram принимает логический параметр и, если он равен true, добавляет в создаваемый список строку "JavaScript". если параметр web равен `false`, эта строка не добавляется. такой `if` является элементом коллекции, а не инструкцией: он вычисляется при построении литерала и может иметь ветвь `else`.

### collection for

цикл `for-in` внутри литерала позволяет при построении списка пройти по другой коллекции и поместить ее элементы, возможно преобразованные, в текущий список:

```dart


void main (){

    var employees = ["Tom", "Alice"];

    var people = ["Bob", "Kate", 

                    for(var emp in employees) "Employee " + emp

                ];

    print(people);  // [Bob, Kate, Employee Tom, Employee Alice]

}
```

здесь в список people добавляются элементы списка employees. для этого применяется цикл for-in, который проходит по всем строкам списка employees и добавляет к каждой префикс "Employee ".

```dart
for(var emp in employees) "Employee " + emp
```

в результате итоговый список равен `[Bob, Kate, Employee Tom, Employee Alice]`. collection if, collection for и spread-оператор можно вкладывать друг в друга, они работают одинаково в литералах списков, множеств и словарей.
