приватные поля скрывают состояние объекта от внешнего кода. однако доступ к этому состоянию часто всё же нужен. геттеры и сеттеры сочетают приватность полей с возможностью обращаться к ним из внешнего кода и обеспечивают контролируемый доступ к приватным полям.

возьмём следующий класс Person:

```dart
class Person{

	String _name;   // приватное поле name
	int _age;        // приватное поле age
	
    Person(this._name, this._age);
}
```

приватность здесь защищает поля _name и _age от недопустимых значений, например пустой строки в качестве имени или отрицательного возраста. при этом внешнему коду желательно иметь возможность получать значения полей и устанавливать корректные значения. для этого служат геттеры и сеттеры.

### геттеры

геттеры (getters) предназначены для получения значения. геттер представляет специальный метод, который объявляется с ключевым словом **get** перед именем свойства и возвращает значение:

```dart
class Person{

	String _name;   // приватное поле name
	int _age;        // приватное поле age

    String get name {return _name;}
    int get age {return _age;}
	
    Person(this._name, this._age);
}
```

здесь определены два геттера:

```dart
String get name {return _name;}
int get age {return _age;}
```

объявление геттера начинается с типа возвращаемого значения, за которым следуют ключевое слово **get** и имя свойства. после имени свойства идёт блок кода, возвращающий значение. параметров геттер не принимает, и при обращении к нему скобки вызова не пишутся. в данном примере имя свойства совпадает с именем возвращаемого поля без начального подчёркивания, но это необязательно.

таким образом, свойство name возвращает значение поля _name, а свойство age значение поля _age.

далее в функции main можно обращаться к этим свойствам:

```dart
import 'person.dart';   // подключаем класс Person

void main() {

    Person tom = Person("Tom", 38);
    print(tom.name);    // Tom
    print(tom.age);     // 38
}
```

через геттер значение можно только получить, установить его нельзя: свойство без сеттера доступно только для чтения.

если геттер состоит из одного выражения, его, как и любой другой метод, можно записать в сокращённой форме:

```dart
String get name =>_name;
int get age => _age;
```

### сеттеры

сеттеры позволяют установить значение поля. сеттер представляет специальный метод, объявление которого начинается с ключевого слова **set**, за которым следует имя свойства и ровно один параметр, представляющий устанавливаемое значение:

```dart
set имя_свойство(параметр) { тело сеттера}
```

определим в классе Person сеттер для установки поля _age:

```dart
class Person{

	String _name;   // приватное поле name
	int _age;        // приватное поле age

    String get name =>_name;
    int get age => _age;
    // сеттер
    set age(int value){
        if(value > 0 && value < 111){     // если age в диапазоне от 1 до 110
            _age = value;
        }
    }
	
    Person(this._name, this._age);
}
```

сеттер задаёт свойство age. поскольку он устанавливает значение поля _age, его параметр имеет тип int:

```dart
set age(int value){
    
    if(value > 0 && value < 111){
         _age = value;
    }
}
```

сеттер проверяет устанавливаемое значение. если оно соответствует допустимому возрасту от 1 до 110, поле _age изменяется. некорректное значение на поле _age никак не влияет. так внешнему коду предоставляется контролируемый доступ к полю _age. на практике при недопустимом значении часто выбрасывают исключение (например ArgumentError), чтобы ошибка не оставалась незамеченной.

теперь значение свойства age, а фактически поля _age, можно изменять:

```dart
import 'person.dart';   // подключаем класс Person

void main() {

    Person tom = Person("Tom", 38);
    tom.age = 22;       // вызываем сеттер
    print(tom.age);     // 22
    tom.age = 100500;   // вызываем сеттер
    print(tom.age);     // 22
}
```

при присваивании значения свойству age вызывается сеттер. синтаксически это обычное присваивание полю, поэтому публичное поле позднее можно заменить парой геттер и сеттер без изменения клиентского кода. если значение корректно, сеттер изменяет поле _age:

```dart
tom.age = 22;       // вызываем сеттер
print(tom.age);     // 22
```

при передаче некорректного значения ничего не изменяется:

```dart
tom.age = 100500;   // вызываем сеттер
print(tom.age);     // 22
```

### вычисляемые свойства

свойства могут быть вычисляемыми: они не соответствуют какому-либо конкретному полю, а вычисляются при каждом обращении. например:

```dart
class Person{

	String _name;   // приватное поле name
	int _age;        // приватное поле age

    String get name =>_name;
    int get age => _age;
    
    // вычисляемое свойства
    bool get isChild => _age < 18;
	
    Person(this._name, this._age);
}
```

в класс Person добавлено вычисляемое свойство `isChild`, которое возвращает true, если объект Person условно представляет ребёнка, то есть если его возраст меньше 18 лет.

```dart
bool get isChild => _age < 18;
```

это свойство используется так же, как другие свойства-геттеры:

```dart
import 'person.dart';   // подключаем класс Person

void main() {

    Person tom = Person("Tom", 38);
    bool tomIsChild = tom.isChild;          // вызываем вычисляемое свойство isChild
    print("Tom is child? $tomIsChild");     // Tom is child? false
    

    Person sam = Person("Sam", 16);
    bool samIsChild = sam.isChild;
    print("Sam is child? $samIsChild");     // Sam is child? true
}
```
