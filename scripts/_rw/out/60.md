для взаимодействия с http-сервером в клиентском приложении используется класс **HttpClient** из библиотеки `dart:io`. эта библиотека доступна на платформах с собственной средой выполнения dart (консоль, сервер, мобильные и десктопные приложения), но не в веб-сборке.

объект HttpClient создаётся фабричным конструктором:

```dart
HttpClient({SecurityContext? context})
```

необязательный параметр типа SecurityContext задаёт дополнительные настройки для работы по защищённому протоколу https, например сертификаты и ключи.

работа HttpClient завершается методом **close()**:

```dart
void close({bool force = false})
```

если параметр `force` равен `false` (значение по умолчанию), HttpClient прекращает принимать новые запросы, но продолжает работу, пока не будут закрыты все активные подключения. если `force` равен `true`, при вызове метода все активные подключения закрываются принудительно и все ресурсы освобождаются.

```dart
import 'dart:io';

void main() async {
  var client = HttpClient(); // создаем клиент
  client.close();           // завершаем его работу
}
```

HttpClient содержит ряд методов, которые формируют запрос к http-серверу в виде объекта **HttpClientRequest**, а ответ затем поступает в виде объекта **HttpClientResponse**:

- `delete(String host, int port, String path)` : отправляет запрос типа DELETE, используя хост host, порт port и путь path

- `deleteUrl(Uri url)` : отправляет запрос типа DELETE по адресу url

- `get(String host, int port, String path)` : отправляет запрос типа GET

- `getUrl(Uri url)` : отправляет запрос типа GET

- `head(String host, int port, String path)` : отправляет запрос типа HEAD

- `headUrl(Uri url)` : отправляет запрос типа HEAD

- `patch(String host, int port, String path)` : отправляет запрос типа PATCH

- `patchUrl(Uri url)` : отправляет запрос типа PATCH

- `post(String host, int port, String path)` : отправляет запрос типа POST

- `postUrl(Uri url)` : отправляет запрос типа POST

- `put(String host, int port, String path)` : отправляет запрос типа PUT

- `putUrl(Uri url)` : отправляет запрос типа PUT

все эти методы однотипны. одна группа принимает хост, порт приложения и путь запроса, другая принимает адрес в виде объекта Uri. результатом любого из них является **`Future<HttpClientRequest>`**. рассмотрим отправку GET-запроса к сайту "www.google.com":

```dart
import 'dart:io';
import 'dart:convert';

void main() async {
  var client = HttpClient();
  try {
    // создаем запрос
    HttpClientRequest request = await client.get("www.google.com", 80, "/");
    // получаем ответ
    HttpClientResponse response = await request.close();
    // обрабатываем ответ
    final stringData = await response.transform(utf8.decoder).join();
    print(stringData);
  } finally {
    client.close();
  }
}
```

здесь создаётся запрос к главной странице (путь "/") на хосте "www.google.com" через порт 80.

```dart
HttpClientRequest request = await client.get("www.google.com", 80, "/");
```

результатом метода является объект класса **HttpClientRequest**. при его создании устанавливается соединение, но сами данные запроса ещё не отправляются: до отправки можно настроить заголовки и записать тело, поскольку HttpClientRequest, как и HttpResponse на стороне сервера, реализует IOSink. запрос отправляется вызовом метода **close()** у HttpClientRequest:

```dart
HttpClientResponse response = await request.close();
```

результатом отправки является ответ, объект **HttpClientResponse**, представляющий поток для чтения. этот поток выдаёт ответ порциями байтов, объектами `List<int>`. поскольку от google.com ожидается веб-страница, ответ можно преобразовать в строку:

```dart
final stringData = await response.transform(utf8.decoder).join();
```

метод `response.transform(utf8.decoder)` применяет к потоку декодер `utf8.decoder`, который преобразует байты в строки. декодер корректно обрабатывает многобайтовые символы utf-8, разрезанные границей между порциями. метод `join()` затем соединяет все полученные фрагменты в одну строку.

в итоге веб-страница www.google.com будет получена в текстовом виде:

аналогично используется и другая версия метода, принимающая объект **Uri**. конструктор Uri позволяет точнее задать отдельные компоненты адреса:

```dart
Uri( 
  {String? scheme,      // схема - http или https
  String? userInfo,     // логин и пароль пользователя
  String? host,         // хост
  int? port,            // порт
  String? path,         // путь
  Iterable<String>? pathSegments,   // сегменты пути, разделенные слешем
  String? query,                          // строка запроса
  Map<String, dynamic>? queryParameters,  // параметры строки запроса
  String? fragment}                       // фрагмент (часть после #)
)
```

пример запроса с использованием `Uri`:

```dart
import 'dart:io';
import 'dart:convert';

void main() async {
  var client = HttpClient();
  try {
    // создаем запрос
    HttpClientRequest request = await client.getUrl(Uri(scheme:"https", host:"www.google.com", path:"/", query:"q=enoobis.ru"));
    // получаем ответ
    HttpClientResponse response = await request.close();
    // обрабатываем ответ
    final stringData = await response.transform(utf8.decoder).join();
    print(stringData);
  } finally {
    client.close();
  }
}
```

из параметров, переданных в конструктор Uri, формируется адрес `https://www.google.com/?q=enoobis.ru`. результатом запроса снова является веб-страница в текстовом виде, которую затем можно обработать. сборка адреса из компонентов предпочтительнее конкатенации строк: Uri сам выполняет необходимое кодирование символов в компонентах.

### взаимодействие с собственным http-сервером

таким же образом запросы отправляются к любому серверу. определим собственный http-сервер на dart, для этого создадим файл **server.dart** со следующим кодом:

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
  print("Сервер запущен...");
  await server.forEach((HttpRequest request) {

    var response = request.response;
    response.write(DateTime.now());
    response.close(); 
  });
}
```

на любой запрос сервер отвечает текущими датой и временем.

определим также файл http-клиента **main.dart** со следующим кодом:

```dart
import 'dart:io';
import 'dart:convert';

void main() async {
  var client = HttpClient();
  try {
    // создаем запрос
    HttpClientRequest request = await client.get("localhost", 8888, "/");
    // получаем ответ
    HttpClientResponse response = await request.close();
    // обрабатываем ответ
    final stringData = await response.transform(utf8.decoder).join();
    print(stringData);
  } finally {
    client.close();
  }
}
```

сервер запускается локально на том же компьютере, что и клиент, и слушает порт 8888, поэтому для подключения в качестве хоста указывается "localhost", а в качестве порта 8888. полученный ответ, как и раньше, преобразуется в строку.

сначала запускается сервер **server.dart**, затем клиент **main.dart**:
