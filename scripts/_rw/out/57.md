библиотека `dart:io` предоставляет средства для работы с протоколами http и https. начнём с создания http-сервера.

http-сервер представляет собой программу, которая принимает запросы по протоколу http и возвращает на них ответы. например, чтобы веб-сайт был доступен пользователям, он должен размещаться на http-сервере.

для создания http-сервера в библиотеке `dart:io` определён класс **HttpServer**. эта реализация доступна только на платформах с `dart:io`, то есть в консольных и серверных приложениях и во flutter, но не в веб-сборке.

### создание сервера

сервер создаётся статическим методом **bind()**:

```dart
Future<HttpServer> bind(dynamic address, int port, {int backlog = 0, bool v6Only = false, bool shared = false})
```

метод принимает два обязательных параметра:

- `address` : адрес, по которому будет запущен сервер

- `port` : номер порта, по которому будет запущен сервер

среди необязательных параметров `backlog` задаёт длину очереди ожидающих подключений (0 означает значение по умолчанию системы), `v6Only` ограничивает сокет только протоколом ipv6, а `shared` позволяет нескольким серверам в разных изолятах привязаться к одному адресу и порту.

адрес может быть строкой (`String`) или объектом класса **InternetAddress**, поэтому параметр объявлен с типом `dynamic`. если передана строка, например "localhost", метод `bind()` вызывает `InternetAddress.lookup`, который возвращает набор ip-адресов, связанных с этим именем. bind берёт первый адрес из списка и прослушивает на нём входящие подключения.

в качестве адреса можно передать и объект `InternetAddress`. в этом классе есть четыре готовых адреса, хранящихся в статических свойствах:

- `InternetAddress.anyIPv4` : любой ip-адрес версии 4

- `InternetAddress.anyIPv6` : любой ip-адрес версии 6

- `InternetAddress.loopbackIPv4` : локальный ip-адрес версии 4, то есть 127.0.0.1 (доступен только для запросов с текущего компьютера)

- `InternetAddress.loopbackIPv6` : локальный ip-адрес версии 6, то есть ::1 (доступен только для запросов с текущего компьютера)

при использовании `InternetAddress.anyIPv6` и `InternetAddress.loopbackIPv6` прослушиваются как адреса ipv6, так и адреса ipv4, если параметр `v6Only` оставлен равным `false`.

каждое сетевое приложение, принимающее входящие запросы, работает на определённом порту. порт задаётся числом от 0 до 65535. выбрать можно любой незанятый порт, обычно занятых портов немного. порты ниже 1024 в unix-подобных системах, как правило, требуют повышенных прав. при значении 0 система выделит временный порт, который затем можно узнать через свойство `port` сервера.

создание объекта сервера с этими параметрами:

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
}
```

адрес `InternetAddress.anyIPv6` означает прослушивание на всех доступных сетевых интерфейсах, а запросы принимаются на порту 8888.

### получение запросов

класс HttpServer реализует `Stream<HttpRequest>`, то есть сервер является потоком объектов **HttpRequest**, каждый из которых соответствует отдельному запросу. при поступлении запроса сервер выдаёт его в поток в виде HttpRequest. поток не завершается, пока сервер не закрыт, поэтому обработка запросов по сути является бесконечным циклом, который можно организовать разными способами.

первый способ основан на методе **forEach()**:

```dart
Future forEach(void action(HttpRequest element))
```

в метод передаётся функция обратного вызова, принимающая запрос в виде объекта HttpRequest. она вызывается при поступлении каждого запроса. применение:

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
  print("Сервер запущен...");
  await server.forEach((HttpRequest request) {
      // обработка запроса
  });
}
```

с каждым объектом HttpRequest через свойство `response` связан объект класса **HttpResponse**, представляющий ответ сервера. HttpResponse реализует `IOSink`, и его метод `write()` позволяет отправить в ответ различное содержимое:

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
  print("Сервер запущен...");
  await server.forEach((HttpRequest request) {

    final response = request.response;    // получае объект ответа
    response.write("Hello enoobis.ru");  // отправляем в ответ строку "Hello enoobis.ru"
    response.close();                     // закрываем и отправляем ответ
  });
}
```

метод `write()` отправляет клиенту строку "Hello enoobis.ru". чтобы завершить ответ и отправить его клиенту, у объекта HttpResponse вызывается метод `close`:

```dart
response.close();
```

до первой записи в тело ответа можно настроить код состояния и заголовки через свойства `statusCode` и `headers`. после начала записи заголовки уже отправлены и изменить их нельзя.

запуск программы:

```bash
c:\dart>dart main.dart
Сервер запущен...
```

для обращения к http-серверу нужен http-клиент, и чаще всего в этой роли выступает веб-браузер. к локальному http-серверу обращаются, указывая его хост и порт в формате:

```dart
хост:порт
```

для локального сервера обычно используется хост "localhost" или "127.0.0.1". достаточно открыть веб-браузер и ввести адрес `http://localhost:8888`. браузер отобразит отправленную строку:

другой способ получать и обрабатывать запросы в бесконечном цикле состоит в использовании цикла for-in:

```dart
import 'dart:io';

void main() async {
  var server = await HttpServer.bind(InternetAddress.anyIPv6, 8888);
  print("Сервер запущен...");
  await for (final request in server) {

    final response = request.response;
    response.write("Hello enoobis.ru");
    response.close();
  }
}
```

результат будет таким же, как в предыдущем примере. обе формы эквивалентны подписке на поток запросов. запросы обрабатываются в одном изоляте, поэтому при асинхронной обработке их выполнение чередуется, но не идёт параллельно.
