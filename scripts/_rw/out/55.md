для работы с файлами в dart можно использовать потоки. **поток** (stream) представляет собой абстракцию асинхронной последовательности данных, элементы которой поступают со временем. при чтении файла приложение может получить файловый поток и принимать из него данные по мере их появления.



большой файл имеет смысл читать как поток: обработка начинается раньше, так как не нужно ждать загрузки всего файла, а потребление памяти ограничено размером одной порции. при потоковом чтении файл считывается отдельными фрагментами, или чанками (chunks). размер чанка зависит от системы, на которой работает приложение на dart, но обычно составляет 65 536 байт. для небольших файлов разница между чтением целиком и чтением через поток несущественна.



файловый поток получают одним из методов класса **File** в зависимости от того, что предполагается делать с файлом:




- openRead() : возвращает поток для чтения файла в виде объекта `Stream<List<int>>`. первый параметр `start` задаёт индекс байта от начала файла, с которого начинается чтение (по умолчанию с самого начала). второй параметр `end` задаёт индекс байта, до которого выполняется чтение (по умолчанию до конца файла).

```dart
Stream<List<int>> openRead([int? start, int? end]);
```



- openWrite() : возвращает приёмник для записи в файл в виде объекта IOSink. первый параметр `mode` задаёт режим открытия файла. по умолчанию это `FileMode.write` , то есть перезапись файла. для дозаписи используется значение `FileMode.append`. второй параметр `encoding` устанавливает кодировку записи, по умолчанию utf-8.

```dart
IOSink openWrite({FileMode mode = FileMode.write, Encoding encoding = utf8});
```



- open() : возвращает объект RandomAccessFile для произвольного доступа к файлу. параметром служит режим открытия, по умолчанию `FileMode.read` , то есть файл открывается для чтения. в отличие от двух предыдущих методов, здесь доступ строится вокруг текущей позиции в файле, которую можно перемещать.

```dart
Future<RandomAccessFile> open({FileMode mode = FileMode.read});
```




### запись в поток



поток для записи представлен типом **IOSink**. он реализует интерфейсы `StreamSink<List<int>>` и `StringSink` и предоставляет следующие методы записи:




- `void write(Object? object)` : записывает в поток произвольный объект, преобразуя его в строку

- `void writeAll(Iterable objects, [String separator = ""])` : записывает в поток набор objects. между объектами можно вставлять разделитель separator

- `void writeCharCode(int charCode)` : записывает в поток символ по его числовому коду

- `void writeln([Object? object = ""])` : преобразует объект в строку вызовом его метода `toString()` и записывает строку в поток, добавляя символ перевода строки \n.



запись строки в файл:



```dart

import 'dart:io';

void main() async {
  final file = File("file.txt");
  var sink = file.openWrite();
  sink.write("Hello enoobis.ru\n");

  // закрываем IOSink и освобождаем все ресурсы системы
  await sink.close();
  print("File has been written");
}
```



строка записывается методом `write()`. сам вызов синхронный: данные помещаются в буфер, а фактическая запись на диск происходит асинхронно.



по окончании работы поток записи нужно закрыть методом **close()**. он дожидается записи всех буферизованных данных и освобождает связанные системные ресурсы, поэтому его результат обычно ожидают через `await`.



для открытия файла в режиме дозаписи используется `FileMode.append`:



```dart

import 'dart:io';

void main() async {
  final file = File("file.txt");
  // открываем файл для дозаписи
  var sink = file.openWrite(mode: FileMode.append);
  sink.write("Hello enoobis.ru\n");
  await sink.close();
  print("File has been written");
}
```



при записи экземпляра класса в файл попадает его строковое представление, определяемое методом `toString()`:



```dart

import 'dart:io';

void main() async{

  Person tom = Person("Tom", 38);
  final file = File("person.dat");
  var sink = file.openWrite();
  sink.write(tom);
  await sink.close();
  print("File has been written");
}
class Person{
  String name;
  int age;
  Person(this.name, this.age);
  void display() => print("Name: $name \tAge: $age");
  @override
  toString() => "{name: $name, age: $age}";
}
```



при записи объекта tom в файл попадёт строка "{name: Tom, age: 38}". восстановить объект из такой строки автоматически нельзя, для этого нужен формат сериализации, например json.






### чтение из потока



для чтения используется поток **`Stream<List<int>>`**, передающий данные в виде списков байтов. получение данных устроено через подписку: при появлении новой порции данных поток уведомляет подписчика. подписка оформляется методом **listen()** класса Stream:



```dart
StreamSubscription<T> listen(void onData(T event)?,
    {Function? onError, void onDone()?, bool? cancelOnError});
```



основным параметром метода является функция `onData`, которая вызывается при каждом событии потока и получает очередную порцию данных.



дополнительно метод принимает функции `onError()`, вызываемую при ошибке, и `onDone()`, вызываемую после закрытия потока.



последний параметр `cancelOnError` при значении `true` отменяет подписку при первой ошибке.



файловый поток является потоком с единственной подпиской (single-subscription): повторный вызов `listen()` на том же объекте приводит к ошибке `StateError`.



пусть файл `file.txt` содержит строку "Hello enoobis.ru". чтение его через поток:



```dart

import 'dart:io';

void main(){
  final file = File("file.txt");
  final stream = file.openRead();
  stream.listen( (data) => print(data));
}
```



обработчиком данных в `listen()` служит анонимная функция, которая выводит полученную порцию на консоль. консольный вывод:



```bash
[72, 101, 108, 108, 111, 32, 77, 101, 116, 97, 110, 105, 116, 46, 99, 111, 109, 10]
```



поток чтения доставляет данные в виде списка байтов, поэтому анонимная функция получает именно список байтов и выводит его на консоль. фактически этот список кодирует записанную в файл строку, а отдельные числа в нём являются кодами её символов.



поскольку записанные данные на самом деле являются текстом, их можно преобразовать в строку встроенной функцией `utf8.decode()` из библиотеки `dart:convert`:



```dart

import 'dart:io';
import 'dart:convert';

void main(){
  final file = File("file.txt");
  final stream = file.openRead();
  // преобразуем в строку и выводим на консоль
  stream.listen( (data) => print(utf8.decode(data))); 
}
```



#### получение данных в цикле for-in



другой способ получения данных состоит в использовании цикла `for-in`:



```dart

import 'dart:io';
import 'dart:convert';

void main() {
  final file = File("file.txt");
  final stream = file.openRead();
  await for (var data in stream) {
    print(utf8.decode(data));
  }
}
```



служебное слово **await** перед циклом приостанавливает выполнение функции до поступления очередной порции данных. конструкция `await for` допустима только в асинхронной функции, поэтому main в этом случае должна быть объявлена как `void main() async`.



#### использование коллбеков и обработка ошибок



через необязательные параметры метода `listen()` класса Stream передаются функции обратного вызова, срабатывающие при ошибке и при завершении получения данных:



```dart

import 'dart:io';
import 'dart:convert';

void main() {
  final file = File("file.txt");
  final stream = file.openRead();
  stream.listen( 
    (data) => print(utf8.decode(data)),
    onError: (error) {print(error);},       // срабатывает при ошибке
    onDone: () { print("End of reading");}  // срабатывает при завершении
  );
}
```



обработчик `onError` принимает объект ошибки и вызывается при её возникновении.



обработчик `onDone` не принимает параметров и вызывается при завершении потока.



последний необязательный параметр `cancelOnError` при значении `true` прекращает подписку на поток при первой ошибке:



```dart

stream.listen( 
    (data) => print(utf8.decode(data)),
    onError: (error) {print(error);},       // срабатывает при ошибке
    onDone: () { print("End of reading");},  // срабатывает при завершении
    cancelOnError: true         // прекращаем работу потока при возникновении ошибки
  );
```



по умолчанию cancelOnError равен false: подписка переживает ошибку, и обработчик `onDone` всё равно будет вызван при закрытии потока. при `true` подписка отменяется, и `onDone` уже не вызывается.



для обработки ошибок также применяется конструкция `try-catch`, особенно при чтении в цикле `await for`: ошибка из потока пробрасывается в теле асинхронной функции как обычное исключение. вокруг вызова `listen()` блок `try-catch` такие ошибки не перехватит, так как они возникают уже после выхода из него.



```dart

import 'dart:io';
import 'dart:convert';

void main(){
  try {
    final file = File("file.txt");
    final stream = file.openRead();
    await for (var data in stream) {
      print(utf8.decode(data));
    }
  } on Exception catch (error) {
    print(error);
  } finally {
    print("End of reading");
  }
}
```



#### преобразование потока



в примерах выше читаемый файл содержал текст. однако для потока Stream все данные являются наборами байтов типа `List<int>`, и для получения строки к каждому набору приходилось применять `utf8.decode()`.



метод **transform()** класса Stream преобразует данные в нужную форму автоматически. параметром служит объект StreamTransformer, который задаёт преобразование и возвращает новый поток. применение метода **transform()**:



```dart

import 'dart:io';
import 'dart:convert';

void main(){
  final file = File("file.txt");
  final stream = file.openRead();
  await for (var data in stream.transform(utf8.decoder)) {
    print(data);  // data - уже представляет строку
  }
}
```



в `stream.transform()` передаётся объект `utf8.decoder`, преобразующий байты в строки, поэтому на выходе получаются строки. у такого подхода есть и семантическое преимущество: декодер сохраняет состояние между чанками и корректно обрабатывает многобайтовый символ utf-8, разрезанный границей чанка, тогда как `utf8.decode()` для каждого чанка в отдельности в этой ситуации даёт ошибку. для построчной обработки после декодера можно добавить `LineSplitter` из `dart:convert`.



то же преобразование при чтении через `stream.listen()`:



```dart

import 'dart:io';
import 'dart:convert';

void main(){
  final file = File("file.txt");
  final stream = file.openRead();
  stream
    .transform(utf8.decoder)  // преобразование данных
    .listen((data) => print(data) );
}
```
