условные выражения задают некоторое условие и вычисляются в значение типа **bool**: **true**, если условие истинно, или **false**, если ложно. к ним относятся операции сравнения и логические операции. в отличие от c или javascript, dart не выполняет неявного приведения чисел, строк или null к логическому типу, поэтому в условии допустимо только выражение со статическим типом `bool`.

### операции сравнения

операция сравнения принимает два операнда и возвращает значение типа `bool`: `true`, если отношение выполняется, и `false` в противном случае.

- `==` проверяет операнды на равенство и возвращает `true`, если они равны, и `false`, если не равны. для объектов эта операция вызывает переопределяемый оператор `==` левого операнда, то есть проверяет равенство значений, а не идентичность ссылок. идентичность проверяет функция `identical`.

```dart
int a = 10;
int b = 4;
bool c = a == b;    	// false
bool d = a == 10;       // true
```

- `!=` сравнивает два операнда и возвращает `true`, если операнды не равны, и `false`, если равны. семантически `a != b` определено как `!(a == b)` и отдельно не переопределяется.

```dart
int a = 10;
int b = 4;
bool c = a != b;    	// true
bool d = a != 10;       // false
```

- `>` (больше) возвращает `true`, если первый операнд больше второго, иначе `false`.

```dart
int a = 10;
int b = 4;
bool c = a > b; 	// true
bool d = a > 23; // false
```

- `>=` (больше или равно) возвращает `true`, если первый операнд больше второго или равен ему, иначе `false`. операции `<` и `<=` определены симметрично.

```dart
bool c = 10 >= 10; 	// true
bool b = 10 >= 4; 	// true
bool d = 10 >= 20; 	// false
```
