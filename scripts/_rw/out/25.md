### nullable-типы



как и все встроенные типы, класс по умолчанию задаёт тип, не допускающий значение null. иногда же требуется, чтобы переменная типа класса могла хранить `null`. типичный сценарий: запрос к сетевому ресурсу возвращает либо конкретные данные, либо null, если запрошенные данные не найдены. для объявления такой переменной используется nullable-тип, то есть к имени типа добавляется суффикс ?. в системе типов dart `Person?` представляет объединение `Person` и `Null`, а `Person` является подтипом `Person?`:



```dart

void main (){
     
	Person? sam;
	print(sam);  // null	- sam допускает значение null
	Person tom;
	// print(tom);	// ! Ошибка, tom не может принимать null
}
```



в случае `print(tom)`, как и для переменных любых других non-nullable типов, переменной нужно присвоить значение до первого использования. анализ определённого присваивания (definite assignment) выполняется во время компиляции, поэтому чтение неинициализированной локальной переменной считается ошибкой компиляции.



при работе с nullable-типами возникает следующая проблема. для обращения к полям и методам объекта используется оператор точка (.), за которой следует имя поля или метода. однако переменная nullable-типа без явной инициализации имеет значение null. попробуем обратиться к полю через такую переменную:



```dart

class Person{ 

    String name = "";
	int age = 0; 

    void display() => print("Name: $name \tAge: $age");
}
void main (){
     
	Person? tom;
	tom.age = 38;   // Ошибка, tom = null
}
```



строка `tom.age = 38` некорректна: объект класса Person не был создан конструктором, переменная tom равна null, то есть объекта не существует, и обратиться к его полю невозможно. в dart 3 со sound null safety такой код отвергается уже на этапе компиляции, поскольку член `age` не определён для статического типа `Person?`. чтобы обратиться к полю, переменную можно предварительно проверить на null:



```dart

if(tom != null){	// если tom не равна null
	tom.age = 38;	// то присваиваем полю age число
}
```



для краткости dart предоставляет оператор **?.** (null-aware access operator):



```dart

class Person{ 

    String name = "";
	int age = 0; 
    void display() => print("Name: $name \tAge: $age");
}
void main (){
     
    Person? tom;
	tom?.age =  38;     // не выполняется
	tom?.display();     // не выполняется
    
    tom = Person();     // объект создан
    tom.age =  38;     // выполняется
    tom.name = "Tom";   // выполняется
	tom.display();     // выполняется
}
```



оператор **?.** проверяет значение левого операнда: если оно не равно null, выполняется обращение к полю или методу, если равно null, всё выражение даёт null, а обращение не происходит. при этом короткое замыкание распространяется на всю оставшуюся цепочку обращений справа. например:



```dart

Person? tom;
tom?.age =  38;
```



переменная tom равна null, поэтому строка `tom?.age = 38` не имеет никакого эффекта: значение age не меняется, ошибки нет, программа продолжает выполнение.



после создания объекта оператор **?.** уже не применяется:



```dart

tom = Person();     // объект создан
tom.age =  38;     // выполняется
```



анализатор dart выполняет анализ потока управления (flow analysis) и выводит, что после присваивания объекта Person проверка на null не нужна. это называется **type promotion**, продвижение типа: статический тип переменной сужается с Person? до Person. продвижение работает для локальных переменных и параметров, а начиная с dart 3.2 и для приватных final-полей. для публичных полей оно не выполняется, потому что геттер может быть переопределён в подклассе и вернуть другое значение при повторном чтении.



вывести, что значение не равно null, удаётся не всегда:



```dart

void printPerson(Person? person){
    person?.display();
}

class Person{ 

     String name = "";
	int age = 0;
    void display() => print("Name: $name \tAge: $age");
}
void main (){
	
	Person? tom;
    printPerson(tom);  
    tom = Person();
    printPerson(tom);  
}
```



функция printPerson получает параметр типа Person? и вызывает у него метод display. анализатор не знает, какое значение будет передано в функцию, null или экземпляр Person, поэтому вызов метода display записывается через оператор ?.:



```dart
person?.display();
```



если person равен null, вызова не будет, и программа продолжит работу. если person не равен null, будет вызван метод display.






### ?..



особая форма этого оператора: **?..** (null-aware cascade operator). он позволяет применить каскадную нотацию, если переменная не равна null.



```dart

void setDefaultValues(Person? person){
    person
        ?..name = "Tom"
		..age = 38
		..display();
}

class Person{ 

    String name = "";
	int age = 0;
    void display() => print("Name: $name \tAge: $age");
}
void main (){
	
	Person? tom;
    setDefaultValues(tom);  

    tom = Person();
    setDefaultValues(tom);  
}
```



функция setDefaultValues принимает значение типа Person? и, если оно не равно null, через каскад устанавливает значения его полей и вызывает метод display. проверка на null выполняется один раз в начале каскада, поэтому последующие звенья записываются обычным `..`.



### оператор !



иногда переменная объявлена с nullable-типом, но логика программы исключает, что в ней окажется `null`. если программист уверен, что во время работы программы переменная не получит значение `null`, можно применить постфиксный оператор **!** (null assertion operator), который ставится после выражения.



рассмотрим код:



```dart

class Password{ 

    String? text; // текст пароля

    String get(){
        if(text == null){
            text = "qwerty";
        }
        return text;   // ! Ошибка
    }
}
void main (){
	
	Password myPassword = Password();
    print(myPassword.get());  
}
```



в классе Password поле text, которое хранит текст пароля, имеет тип `String?` и по умолчанию равно `null`. в методе get(), если text равно null, ему присваивается начальное значение. по логике метода get() он всегда возвращает String, то есть строку, а не null: даже если text был равен null, ему присваивается строка. тем не менее компиляция завершается ошибкой:



```bash

main.dart:9:16: Error: A value of type 'String?' can't be returned from a function with return type 'String' because 'String?' is nullable and 'String' isn't.
        return text;
               ^
```



причина в том, что text является публичным полем экземпляра, а для таких полей продвижение типа не выполняется: между проверкой и чтением геттер теоретически может вернуть другое значение. поскольку метод заведомо возвращает строку String, после имени можно поставить оператор !:



```dart
return text!;
```



полный код:



```dart

class Password{ 

    String? text;

    String get(){
        if(text == null){
            text = "qwerty";
        }
        return text!;   // метод возвращает String
    }
}
void main (){
	
	Password myPassword = Password();
    print(myPassword.get());  
}
```



оператор ! приводит выражение к non-nullable типу и вставляет проверку во время выполнения: если значение всё же окажется null, будет выброшено исключение. поэтому его следует применять только при полной уверенности, что значение не равно null. если такой уверенности нет, лучше не злоупотреблять этим оператором и вовсе обойтись без него, например сохранив значение в локальную переменную, для которой работает продвижение типа.



### оператор !.



сочетание **!.** позволяет обратиться к полям или методам объекта, который имеет nullable-тип, но заведомо не равен null:



```dart

class Password{ 

    String? text;

    bool isValid(){
        if(text == null){
            text = "";
        }
        return text.length > 6;   // ! Ошибка
    }
}
void main (){
	
	Password myPassword = Password();
    bool isValid = myPassword.isValid();
    print("Is Valid: $isValid");
}
```



ситуация та же, что и в предыдущем примере с оператором !. метод isValid() проверяет длину текста пароля через свойство length класса String и возвращает true, если длина больше 6 символов, то есть пароль действителен. поле text заведомо не равно null, поскольку при значении null ему присваивается строка, но компилятор этого вывести не может. чтобы обратиться к полям и методам объекта, который может быть равен null, используется **!.**:



```dart
return text!.length > 6;
```



полный код:



```dart

class Password{ 

    String? text;

    bool isValid(){
        if(text == null){
            text = "";
        }
        return text!.length > 6;   // больше 6 символов
    }
}
void main (){
	
	Password myPassword = Password();
    bool isValid = myPassword.isValid(); // false
    print("Is Valid: $isValid");  // Is Valid: false
}
```
