по умолчанию поля класса являются публичными, то есть доступны в любой точке программы, и внешний код может свободно читать и изменять их значения. такое поведение не всегда желательно. часто требуется скрыть внутреннюю реализацию от внешнего кода, чтобы исключить некорректное использование полей и присваивание им недопустимых значений. этот принцип называется инкапсуляцией.

dart позволяет сделать поля класса приватными, то есть недоступными извне. для этого перед именем поля ставится символ подчёркивания (_). в отличие от java, c# или kotlin, в dart нет модификаторов доступа private, protected и public: приватность выражается только именем идентификатора, и у неё есть важная особенность. пусть весь код программы размещён в одном файле **main.dart**, и в нём определён класс Person:

```dart
class Person{

	String _name ="";   // приватное поле name
	int _age =0;        // приватное поле age
	
    Person(String name, int age) {
		
        this._name = name;
        this._age = age;
	}
	
    void display(){
        print("Name: $_name \tAge: $_age");
    }
}

void main() {

    Person tom = Person("Tom", 38);  
    tom.display();      // Name: Tom       Age: 38
    tom._age = 100500;
    tom._name = "toidi";
    tom.display();      // Name: toidi     Age: 100500
}
```

в классе Person поля, представляющие имя и возраст, объявлены приватными:

```dart
String _name ="";   // приватное поле name
int _age =0;        // приватное поле age
```

тем не менее функция main по-прежнему может обращаться к этим полям и изменять их значения:

```dart
tom._age = 100500;
tom._name = "toidi";
```

консольный вывод подтверждает, что значения полей действительно изменились:

```bash
Name: Tom       Age: 38
Name: toidi     Age: 100500
```

дело в том, что единицей приватности в dart является библиотека, а не класс. идентификатор, начинающийся с подчёркивания, виден всему коду той же библиотеки и скрыт от других библиотек. каждый файл .dart по умолчанию образует отдельную библиотеку, поэтому приватность проявляется, когда класс определён в отдельном файле. создадим в той же папке, где находится главный файл, новый файл **person.dart**:

```dart
class Person{

	String _name ="";   // приватное поле name
	int _age =0;        // приватное поле age
	
    Person(String name, int age) {
		
        this._name = name;
        this._age = age;
	}
	
    void display() => print("Name: $_name \tAge: $_age");
}
```

здесь определён тот же класс Person. в главном файле **main.dart** подключим этот файл и используем класс Person:

```dart
import 'person.dart';     // подключаем файл с классом Person

void main() {

    Person tom = Person("Tom", 38);  
    tom.display();      // Name: Tom       Age: 38
    // tom._age = 100500;       // Ошибка
    // tom._name = "toidi";     // Ошибка
}
```

директива **import** подключает файл "person.dart", и в функции main создаётся объект Person. однако теперь обратиться к полям _name и _age нельзя, поэтому соответствующие строки в примере закомментированы. попытка обращения приведёт к ошибке компиляции: из другой библиотеки приватный идентификатор просто не виден.

то же самое относится к приватным методам: если имя метода начинается с подчёркивания, метод является приватным и вне библиотеки его вызвать нельзя:

```dart
class Person{

	String _name ="";   // приватное поле name
	int _age =0;        // приватное поле age
	
    Person(String name, int age) {
		
        this._name = name;
        this._age = age;
	}
    void _printPerson() => print("Name: $_name \tAge: $_age");
    void display() =>_printPerson();
}
```

здесь метод _printPerson является приватным, и вне текущего файла обратиться к нему нельзя.

### приватные конструкторы

приватными могут быть и именованные конструкторы. например:

```dart
class Person{

	String _name;   // приватное поле name
	int _age;        // приватное поле age
	
    Person(String name, int age): this._create(name, age);  // вызываем приватный конструктор

    Person._create(this._name, this._age);    // приватный конструктор
    void display() => print("Name: $_name \tAge: $_age");
}
```

конструктор `Person._create()` объявлен приватным: для этого перед его именем также ставится символ подчёркивания. этот конструктор устанавливает значения приватных полей:

```dart
Person._create(this._name, this._age);
```

внутри класса этот конструктор можно вызвать, например из перенаправляющего публичного конструктора:

```dart
Person(String name, int age): this._create(name, age);
```

вне файла данного класса приватный конструктор недоступен. если класс объявляет только приватные конструкторы, внешний код не может создавать его экземпляры напрямую. на этом основаны, например, реализация одиночки (singleton) и фабричных конструкторов, контролирующих создание объектов.
