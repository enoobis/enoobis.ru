в dart функции являются объектами первого класса: любая функция имеет тип **Function** и может храниться в переменной, передаваться как аргумент и возвращаться как результат. ниже переменной типа Function динамически присваивается ссылка на функцию, после чего функция вызывается через эту переменную:

```dart
void main() {
	
	Function func = hello;
	func();		// Hello!
	func = bye;
	func();		// Goodbye!
}
void hello() => print("Hello!");
void bye() => print("Goodbye!");
```

здесь объявлена переменная func типа Function, которой присваивается ссылка на функцию hello. имя функции без скобок обозначает сам функциональный объект (так называемый tear-off), а не результат вызова. затем переменная func вызывается как обычная функция: выражение `func()` вызывает ту функцию, на которую в данный момент ссылается переменная, в первом случае hello. ссылку можно переназначить во время выполнения, и следующий вызов `func()` выполнит уже функцию bye.

консольный вывод:

```bash
Hello!
Goodbye!
```

функции могут передаваться в качестве параметров других функций. функции, принимающие или возвращающие функции, называются функциями высшего порядка:

```dart
void main() {
	
	showMessage(hello);
	showMessage(bye);
}
void showMessage(Function func){
	func();		// вызываем переданную функцию
}
void hello() => print("Hello!");
void bye() => print("Goodbye!");
```

в функцию showMessage в качестве аргумента передаются функции hello и bye, и внутри showMessage переданная функция вызывается.

другой пример:

```dart
void main() {
     
    operation(5, 4, sum);		// 9
    operation(5, 4, subtract);	// 1
    operation(5, 4, multiply);	// 20
}
void operation(int a, int b, Function func){
    int result = func(a, b);     // вызываем переданную функцию
	print(result);
}
int sum(int a, int b) => a+ b;
int subtract(int a, int b) => a - b;
int multiply(int a, int b) => a * b;
```

функции sum, subtract и multiply принимают два числа и выполняют над ними арифметическую операцию: сложение, вычитание и умножение соответственно.

функция operation моделирует абстрактную операцию. первые два параметра задают операнды, а третий параметр представляет саму функцию, которая будет к ним применена:

```dart
void operation(int a, int b, Function func){
    int result = func(a, b);     // вызываем переданную функцию
	print(result);
}
```

на этапе определения operation неизвестно, какая конкретно функция будет передана через третий параметр. по замыслу это функция, которая принимает два числа и возвращает число, результат операции. тип Function этого контракта не выражает: он описывает любую функцию, поэтому вызов `func(a, b)` проверяется только во время выполнения как динамический вызов, а несовпадение числа или типов аргументов приведёт к ошибке времени выполнения. для статической проверки в dart используется функциональный тип с сигнатурой, например `int Function(int, int)`, тогда компилятор проверит и передаваемую функцию, и вызов.

функцию operation можно вызвать, передав ей два числа и одну из функций:

```dart
operation(5, 4, sum);		// 9
operation(5, 4, subtract);	// 1
operation(5, 4, multiply);	// 20
```

### функция как результат другой функции

функция также может быть возвращаемым значением:

```dart
void main() {
	
	Function message = getMessage(11);
	message();
	message = getMessage(15);
	message();
}

Function getMessage(int hour){
	if(hour < 12) return morning;
	else return evening;
}
void morning() =>print("Good morning!");
void evening() =>print("Good evening!");
```

функция getMessage в зависимости от переданного числа возвращает либо функцию morning, либо функцию evening.

полученную функцию затем можно сохранить в переменной и вызвать:

```dart
Function message = getMessage(11);
message();
```

более сложный пример:

```dart
void main() {
     
    Function action = select(1);  // получаем функцию add
    print(action(8, 5)); // 13

    action = select(2);  // получаем функцию subtract
    print(action(8, 5)); // 3

    action = select(3);  // получаем функцию multiply
    print(action(8, 5)); // 40
}
Function select(int choice)
{
    // возвращаем нужную функцию в зависимости от choice
    switch (choice)
    {
        case 2:
            return subtract;
        case 3:
            return multiply;
        default:
            return add;
    }
}
int add(int a, int b) => a+ b;
int subtract(int a, int b) => a - b;
int multiply(int a, int b) => a * b;
```

функция select в зависимости от значения параметра choice возвращает одну из функций add, subtract или multiply, каждая из которых выполняет свою операцию.

функцию select можно вызвать с конкретным значением:

```dart
Function action = select(1);  // получаем функцию add
```

в этом случае возвращается функция add, и переменная action ссылается именно на неё. затем эту функцию можно вызвать, передав ей пару чисел:

```dart
print(action(8, 5)); // 13
```
