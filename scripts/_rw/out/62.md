pattern matching в dart позволяет выполнять деструктуризацию: разложение структуры данных или объекта на отдельные компоненты (такой шаблон называют destructuring pattern). шаблон в объявлении переменной одновременно проверяет форму значения и связывает его части с новыми переменными. в объявлениях проверка формы выполняется статически: шаблон должен быть неопровержимым для типа значения, иначе возникает ошибка компиляции.

### разложение кортежа

разложим кортеж на отдельные переменные:

```dart
void main() {

  var person = ("Sam", 29);
  var (name, age) = person;

  print("Name: $name");
  print("Age: $age");
}
```

здесь кортеж person раскладывается на две переменные, name и age. их типы выводятся из статического типа кортежа `(String, int)`. переменные и при необходимости их типы указываются в круглых скобках:

```dart
var (String name, int age) = person;
```

ключевое слово **var** объявляет эти переменные. переменные также могут быть объявлены ранее в программе, и тогда шаблон используется в присваивании:

```dart
void main() {

    var name = "";
    var age = 0;
    var person = ("Sam", 29);
    (name, age) = person;

    print("Name: $name");
    print("Age: $age");
}
```

если нужны не все элементы кортежа, ненужные элементы обозначаются символом подчёркивания **_**:

```dart
void main() {

  var person = ("Sam", 29, "Google");
  var (name, _, company) = person;

  print("Name: $name");
  print("Company: $company");
}
```

здесь пропускается второй элемент кортежа. подобным образом можно пропустить любые ненужные элементы:

```dart
void main() {

  var person = ("Sam", 29, "Google");
  var (_, age, _) = person;

  print("Age: $age");   // 29
}
```

число позиций в шаблоне должно совпадать с числом элементов кортежа, так как форма записи входит в его тип.

если кортеж содержит именованные элементы, при разложении их нужно сопоставить с переменными по имени:

```dart
void main() {


    var person = (name: "Sam", age: 29, company: "Google");
    var (name: personName, age: _, company: personCompany) = person;

    print("Name: $personName");
    print("Company: $personCompany");
}
```

значение элемента name присваивается переменной personName, значение элемента company переменной personCompany. значение элемента age здесь не нужно, поэтому для него используется символ-заместитель _. если имя переменной совпадает с именем поля, допустима сокращённая запись `(:name)`.

один из распространённых сценариев разложения кортежа представляет обмен значениями:

```dart
void main() {

    int a = 15;
    int b = 50;
    (a, b) = (b, a);
    print("a = $a");    // a = 50
    print("b = $b");    // b = 15
}
```

запись `(a, b) = (b, a)` означает, что переменная a получает значение переменной b, а переменная b значение переменной a. обмен корректен без временной переменной, поскольку правая часть полностью вычисляется в кортеж до присваивания.

### разложение списка

аналогично кортежам раскладываются и списки:

```dart
void main() {

  var numbers = [1, 2, 3];
  var [a, b, c] = numbers;
  print("a=$a  b=$b  c=$c");  // a=1  b=2  c=3
}
```

в отличие от кортежа, длина списка не входит в его тип и известна только во время выполнения. поэтому при несовпадении длины списка с числом элементов шаблона разложение в объявлении завершается исключением во время выполнения.

символ-заместитель **_** позволяет пропустить ненужные элементы:

```dart
void main() {

  var numbers = [1, 2, 3];
  var [a, _, c] = numbers;  // пропускаем второй элемент
  print("a=$a  c=$c");  // a=1  c=3
}
```

многоточие **...** (rest-элемент) позволяет пропустить произвольное количество элементов. например, получим первый, второй и последний элементы списка:

```dart
void main() {

  var numbers = [1, 2, 3, 4, 5, 6, 7, 8];
  var [a, b, ..., c] = numbers;
  print("a=$a  b=$b  c=$c");  // a=1  b=2  c=8
}
```

подобным образом можно пропускать произвольное количество элементов в начале, середине и конце списка. в одном шаблоне списка допускается не более одного rest-элемента:

```dart
void main() {

  var numbers = [1, 2, 3, 4, 5, 6, 7, 8];
  var [a, b, ...] = numbers;  // получаем два первых элемента
  var [..., c, d] = numbers;  // получаем два последних элемента
  print("a=$a  b=$b  c=$c  d=$d");  // a=1  b=2  c=7  d=8
}
```

### разложение объектов

dart также позволяет раскладывать экземпляры классов на отдельные значения. например:

```dart
void main() {
    
    var tom = Person("Tom", 38);
    var Person(name: userName, age: userAge) = tom;
    print(userName);  // Tom
    print(userAge);   // 38
}

class Person{

  String name;
  int age;
  Person(this.name, this.age);
}
```

здесь объект класса Person раскладывается на две переменные, userName и userAge. в шаблоне сначала указывается имя класса, а в скобках свойства класса сопоставляются с переменными:

```dart
var Person(name: userName, age: userAge) = tom;
```

при сопоставлении объектный шаблон вызывает геттеры указанных свойств, поэтому разложению доступны любые доступные геттеры, а не только поля. в отличие от позиционных шаблонов c#, которые требуют метода `Deconstruct`, классу не нужно объявлять специальный метод деструктуризации.
