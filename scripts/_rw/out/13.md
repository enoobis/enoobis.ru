функция представляет собой именованный блок инструкций, который можно многократно вызывать в программе. в dart функции являются объектами первого класса: их можно присваивать переменным, передавать как аргументы и возвращать из других функций. формальное определение функции:

```dart
[тип] имя_функции(параметры){

    выполняемые_выражения
}
```

сначала указывается тип возвращаемого значения. если функция не возвращает значения, используется тип **void**.

затем следует имя функции. к нему применяются те же правила, что и к именам переменных.

после имени в скобках перечисляются параметры. функция может не иметь параметров, тогда указываются пустые скобки. далее в фигурных скобках располагается тело функции с выполняемыми выражениями.

например, определим функцию hello:

```dart
void main() {
}
void hello(){

    print("Hello!");
}
```

функция hello не возвращает результата, а только выполняет действие, поэтому её тип void. всё, что она делает, это выводит строку Hello!.

само по себе определение функции её не выполняет. при запуске программы среда выполнения вызывает только точку входа, функцию main. чтобы выполнить hello, её нужно вызвать из main. вызов записывается так:

```dart
имя_функции(аргументы);
```

после имени функции в скобках перечисляются аргументы, то есть значения для параметров функции. например, вызовем hello два раза:

```dart
void main() {
	
	hello();
	hello();
}
void hello(){

    print("Hello!");
}
```

заметим, что hello определена после main, но вызывается из неё без ошибок: объявления верхнего уровня видны во всей библиотеке независимо от их порядка в тексте, поэтому предварительные объявления, как в c, в dart не нужны.

если тело функции состоит из одного выражения, определение можно сократить:

```dart
[тип] имя_функции(параметры) => выполняемое_выражение
```

здесь после списка параметров ставится стрелка `=>`, а за ней выполняемое выражение. запись `=> e` эквивалентна телу `{ return e; }`, и после стрелки допускается только выражение, но не инструкция. функция hello выше выполняла ровно одно выражение, поэтому её можно сократить:

```dart
void main() {
	
	hello();
	hello();
}
void hello() => print("Hello!");
```
