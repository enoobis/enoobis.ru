### запись в файл

асинхронная запись текстового файла выполняется методом **writeAsString()**:

```dart
writeAsString(String contents, {FileMode mode = FileMode.write, Encoding encoding = utf8, bool flush = false}) -> Future<File>
```

метод возвращает `Future` с записанным файлом и принимает следующие параметры:

- `contents` : записываемая строка

- `mode` : режим файла в виде объекта `FileMode` . по умолчанию используется `FileMode.write` , при котором файл перезаписывается полностью. для добавления текста в конец файла используется значение FileMode.append

- `encoding` : кодировка в виде объекта `Encoding` . по умолчанию это utf8

- `flush` : логическое значение. при `true` записанные данные принудительно сбрасываются из буферов операционной системы на устройство до завершения метода.

синхронный вариант **writeAsStringSync** работает так же, но блокирует поток выполнения изолята до окончания записи и ничего не возвращает:

```dart
writeAsStringSync(String contents, {FileMode mode = FileMode.write, Encoding encoding = utf8, bool flush = false}) -> void
```

запись строки в файл:

```dart
import 'dart:io';

void main () async{
  String text = "Hello enoobis.ru\n";  // текст для записи
  File file = File("hello.txt");
  await file.writeAsString(text);
  print("File has been written");
}
```

после выполнения программы в текущем рабочем каталоге (каталоге проекта или скрипта) появится файл "hello.txt" со строкой "Hello enoobis.ru\n". если файла не было, он создаётся.

в этом примере прежнее содержимое файла полностью перезаписывается. параметр `mode: FileMode.append` позволяет дописывать данные в конец файла:

```dart
import 'dart:io';

void main () async{
  String text = "Hello enoobis.ru\n";  // текст для записи
  File file = File("hello.txt");
  // дозапись
  await file.writeAsString(text, mode: FileMode.append);
  await file.writeAsString(text, mode: FileMode.append);
  print("File has been written");
}
```

каждый вызов открывает файл, записывает данные и закрывает его. при большом числе последовательных записей эффективнее держать файл открытым через `openWrite()`, о чём пойдёт речь в лекции о потоках.

### чтение текстовых файлов

текстовый файл можно прочитать двумя способами: как список строк или как одну строку целиком. асинхронное построчное чтение выполняет метод **readAsLines()**, необязательным параметром которого служит кодировка:

```dart
Future<List<String>> readAsLines({Encoding encoding = utf8});
```

каждый элемент результата соответствует фрагменту текста, ограниченному символом перевода строки \n (или парой \r\n). сами символы-разделители в строки списка не включаются.

синхронное чтение выполняет метод **readAsLinesSync()** с той же семантикой:

```dart
List<String> readAsLinesSync({Encoding encoding = utf8});
```

построчное чтение ранее записанного файла "hello.txt":

```dart
import 'dart:io';

void main () async{
  //String text = "Hello enoobis.ru\n";  // текст для записи
  File file = File("hello.txt");
  var lines = await file.readAsLines();
  for(final line in lines){
    print(line);
  }
}
```

асинхронное чтение всего файла в одну строку выполняет метод **readAsString()**:

```dart
Future<String> readAsString({Encoding encoding = utf8});
```

параметром метода служит кодировка, в которой интерпретируются байты файла, а результатом является прочитанный текст в виде строки. если содержимое не является корректной последовательностью в указанной кодировке, генерируется исключение `FileSystemException`.

синхронное чтение в строку выполняет метод `readAsStringSync()`:

```dart
String readAsStringSync({Encoding encoding = utf8});
```

чтение всего текста из "hello.txt":

```dart
import 'dart:io';

void main () async{
  File file = File("hello.txt");
  String content = await file.readAsString();
  print(content);
}
```

оба способа загружают файл в память целиком, поэтому для больших файлов предпочтительно потоковое чтение.
