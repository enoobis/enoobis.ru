замыкание (closure) представляет функциональный объект, который сохраняет доступ к своему лексическому окружению даже тогда, когда выполняется вне той области видимости, где был создан.

технически замыкание включает три компонента:

- внешняя функция, которая задаёт область видимости и в которой определены переменные и параметры, образующие лексическое окружение

- переменные и параметры (лексическое окружение), определённые во внешней функции

- вложенная функция, которая использует переменные и параметры внешней функции

```dart
Function outer(){       // внешняя функция
    var n;              // некоторая переменная - лексическое окружение
    Function inner(){     // вложенная функция
        // действия с переменной n
    }
	return inner;
}
```

простейший пример замыкания:

```dart
Function outer(){       // внешняя функция
    var n = 5;         // некоторая переменная - лексическое окружение функции inner
    void inner(){     // вложенная функция
        // действия с переменной n
		n++;
		print(n);
    }
	return inner;
}
void main() {
	
	Function fn = outer();   // fn = inner, так как функция outer возвращает функцию inner
	// вызываем внутреннюю функцию inner
	fn();   // 6
	fn();   // 7
	fn();   // 8
}
```

функция outer задаёт область видимости, в которой определены внутренняя функция inner и переменная n. переменная n образует лексическое окружение функции inner. функция inner инкрементирует n и выводит её значение на консоль, а outer в конце возвращает inner.

далее вызывается функция outer:

```dart
Function fn = outer();
```

поскольку outer возвращает функцию inner, переменная fn хранит ссылку на inner. при этом функция захватила своё окружение, то есть внешнюю переменную n. захватывается сама переменная, а не копия её значения, поэтому переменная продолжает существовать после завершения вызова outer, пока на замыкание есть ссылки.

затем функция inner фактически вызывается три раза, и переменная n, определённая вне inner, каждый раз увеличивается на единицу:

```dart
fn();   // 6
fn();   // 7
fn();   // 8
```

несмотря на то, что n определена вне функции inner и inner вызывается вне функции outer, где была определена, функция сохраняет доступ к своему окружению и изменяет его. в этом и состоит суть замыкания. каждый новый вызов outer создаёт новую переменную n и, соответственно, новое независимое замыкание.

определение outer можно сократить с помощью анонимной функции:

```dart
Function outer(){
    var n = 5;
    return (){
		n++;
		print(n);
    };
}
```

другой пример:

```dart
Function multiply(int n){

    return (int m) => n * m;
}
void main() {
	
	Function func = multiply(5);
	int result1 = func(6); // 30
	print(result1); 	   // 30
 
	int result2 = func(5); // 25
	print(result2);		  // 25
}
```

здесь вызов функции `multiply()` возвращает внутреннюю функцию. внутренняя функция

```dart
(int m) => n * m;
```

запоминает окружение, в котором была создана, в частности параметр n.

в результате вызова multiply переменная `func` получает замыкание, то есть объединение двух вещей: функции и окружения, в котором функция была создана. окружение состоит из всех локальных переменных и параметров, которые находились в области видимости функции multiply в момент создания замыкания.

таким образом, func содержит и внутреннюю функцию `(int m) => n * m;`, и параметр n, существовавший во время создания замыкания, а result1 хранит уже результат его вызова. по сути multiply реализует частичное применение функции двух аргументов: первый аргумент фиксируется при создании замыкания, второй передаётся при вызове.

здесь легко перепутать параметры. при создании замыкания

```dart
Function func = multiply(5);
```

число 5 передаётся в параметр n функции multiply.

при вызове внутренней функции

```dart
int result1 = func(6); // 30
```

число 6 передаётся в параметр m внутренней функции `(int m) => n * m;`

замыкание можно вызвать и сразу, без промежуточной переменной:

```dart
Function multiply(int n){
    return (int m) => n * m;;
}
void main() {
	
	int result1 = multiply(5)(6); // 30
	print(result1); 	   // 30
}
```
