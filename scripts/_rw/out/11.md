**условные конструкции** позволяют направить выполнение программы по одному из путей в зависимости от истинности некоторого условия.

в dart для этого служат конструкции **if..else** и **switch..case**, а также условный оператор **?:**.

### конструкция if-else

оператор if проверяет условие и, если оно истинно, выполняет следующую за ним инструкцию или блок. сокращённая форма оператора:

```dart
if (условие) инструкция;
```

условием может быть любое выражение со статическим типом `bool`, то есть вычисляемое в `true` или `false`. неявного приведения других типов к `bool`, как в c или javascript, в dart нет. если выражение даёт `true`, выполняется последующая инструкция:

```dart

void main() {
	const int num1 = 8;
	const int num2 = 5;
	if(num1 > num2){
    	print("num1 больше, чем num2");
	}
	print("конец функции main");
}
```

условием здесь служит выражение `num1 > num2`. поскольку num1 больше num2, оно вычисляется в `true`, и управление передаётся в блок в фигурных скобках, где выполняется инструкция

```dart
print("num1 больше, чем num2");
```

после завершения блока if выполняются инструкции, следующие за всей конструкцией. вывод программы:

```bash

num1 больше, чем num2
конец функции main
```

противоположный случай, когда условие ложно и даёт `false`:

```dart

void main() {
	const int num1 = 8;
	const int num2 = 15;
	if(num1 > num2){
    	print("num1 больше, чем num2");
	}
	print("конец функции main");
}
```

здесь num1 меньше num2, условие ложно, поэтому инструкции блока `if` пропускаются, и вывод программы будет таким:

```bash

конец функции main
```

#### выражение else

если первое число меньше второго или равно ему, блок if не выполняется. чтобы задать действия для случая, когда условие не выполнено, к конструкции добавляется блок `else`:

```dart

void main() {
	const int num1 = 8;
	const int num2 = 15;
	if(num1 > num2){
		print("Первое число больше второго");
	}
	else{
		print("Первое число меньше второго");
	}
}
```

условие после `if` здесь равно false, поэтому выполняется блок инструкций после `else`.

#### else-if

при сравнении двух чисел возможны три исхода: первое больше второго, первое меньше второго или числа равны. выражение `else if` позволяет проверить дополнительные условия:

```dart

void main() {
    const int num1 = 8;
    const int num2 = 5;
    if(num1 > num2){
        print("Первое число больше второго");
    }
    else if(num1 < num2){
        print("Первое число меньше второго");
    }
    else{
        print("Числа равны");
    }
}
```

одна конструкция if может содержать произвольное число блоков `else if` с альтернативными условиями. условия проверяются сверху вниз, и выполняется только первая ветвь, условие которой истинно:

```dart

void main() {
	const int num1 = 8;
	if(num1 == 6){
		print("num1 = 6");
	}
	else if(num1 == 7){
		print("num1 = 6");
	}
	else if(num1 == 8){
		print("num1 = 8");
	}
	else{
		print("Undefined");
	}
}
```

### конструкция switch

конструкция **switch/case** позволяет сопоставить одно значение сразу с несколькими вариантами:

```dart

void main() {
	const int num = 8;
    switch(num){
                
        case 1: 
            print("число равно 1");
        case 2: 
            print("число равно 2");
        case 3: 
            print("число равно 3");
        default:
            print("число не равно 1, 2, 3");
    }
}
```

после ключевого слова **switch** в скобках указывается сравниваемое выражение. его значение последовательно сопоставляется со значениями после **case**, и при первом совпадении выполняется соответствующий блок **case**. начиная с dart 3 после `case` записывается образец (pattern), а константа является его частным случаем, поэтому switch умеет также сопоставлять типы, записи и деструктурировать значения.

до dart 3 непустой блок `case` должен был завершаться оператором **break** (либо `continue`, `return` или `throw`), иначе возникала ошибка компиляции:

```dart

void main() {
	const int num = 8;
    switch(num){
                
        case 1: 
            print("число равно 1");
			break;		// выходим из конструкции switch
        case 2: 
            print("число равно 2");
			break;		// выходим из конструкции switch
        case 3: 
            print("число равно 3");
			break;		// выходим из конструкции switch
        default:
            print("число не равно 1, 2, 3");
    }
}
```

начиная с dart 3 оператор **break** не обязателен: после выполнения непустого блока управление само покидает switch. неявного «проваливания» в следующий блок, как в c или java, при этом нет.

для случая, когда ни одно значение не совпало, можно добавить блок **default**, как в примере выше. блок **default** необязателен.

одно действие можно задать сразу для нескольких идущих подряд case. пустой блок case передаёт управление следующему, поэтому для значений 2, 3 и 4 выполняется одна и та же ветвь:

```dart

const int num = 3;
int output = 0;
switch(num){
	
	case 1: 
		output = 3;
	case 2: 
	case 3: 
	case 4: 
		output = 6;
	case 5: 
		output = 12;
	default:
		output = 24;
}
print(output);
```

внутри блока `case` допускается оператор **continue** с меткой, указывающей, куда передать управление:

```dart

int num = 2;
switch(num){
             
    case 1: 
        print("число равно 1");
    case 2: 
        print("число равно 2");
        num++;
        continue N3;	// переход на метку N3
    N3: case 3: 
        print("число равно 3");
    default:
        print("число не равно 1, 2, 3");
}
```

здесь continue передаёт управление на метку N3, которая помечает следующий блок case. имя метки выбирается произвольно. по действию такой continue напоминает goto в ряде языков, но с ограничением: метка обязана находиться внутри той же конструкции switch и помечать один из блоков case или блок default. повторного сопоставления значения при этом не происходит, поэтому результат работы программы:

```bash

число равно 2
число равно 3
```

### тернарный оператор

тернарный оператор отчасти аналогичен конструкции if-else, но является выражением, а не инструкцией. он принимает три операнда:

```dart
[первый операнд - условие] ? [второй операнд] : [третий операнд]
```

первый операнд задаёт условие. если оно истинно (равно true), вычисляется второй операнд, записанный после символа ?. если ложно, вычисляется третий операнд, записанный после двоеточия. вычисляется только один из двух операндов:

```dart

void main() {
	const int a = 5;
    const int b = 8 ;
    int c = a > b ? a - b : a + b;	// тернарный оператор
	print(c);	// 13
}
```

первым операндом здесь служит условие `a > b`. если оно истинно, результатом становится второй операнд, значение выражения `a - b`, иначе третий операнд, `a + b`. полученное значение присваивается переменной c.

результат тернарного оператора можно и не использовать, ограничившись побочными эффектами операндов:

```dart

void main() {
	const int a = 5;
    const int b = 8 ;
    a > b ? print(a - b) : print(a + b);	// тернарный оператор
}
```

условие здесь то же. если оно истинно, выполняется второй операнд `print(a - b)`, иначе третий `print(a + b)`. для таких случаев if-else обычно читается яснее, а тернарный оператор уместнее там, где нужно значение.
