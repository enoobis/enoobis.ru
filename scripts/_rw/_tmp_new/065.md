помимо классов собственный тип вводят **структурой**. конструкция унаследована c++ от c и в c++ является классом с другими правилами по умолчанию. структура, как и класс, описывает сущность: у неё бывают члены-данные, функции, конструкторы и деструкторы. на практике структурой оформляют набор открытых данных, а класс оставляют для типа с инвариантом и закрытым представлением.

по устройству структура совпадает с классом: обе формы задают пользовательский тип. расхождение в правилах по умолчанию. член `struct` без спецификатора доступа открыт (**public**). член `class` без спецификатора закрыт (**private**). то же умолчание действует для наследования: база `struct` без спецификатора наследуется открыто, база `class` закрыто. если спецификаторы выписаны явно, `struct` и `class` дают один и тот же тип с точностью до имени.

структуры применяют к данным, у которых есть только открытые атрибуты и нет инварианта, который нужно защищать функциями доступа. такова структура `person` в начале лекции. такие типы называют **агрегатными классами** (aggregate classes). для них работает агрегатная инициализация, и клиентский код обращается к членам напрямую.
